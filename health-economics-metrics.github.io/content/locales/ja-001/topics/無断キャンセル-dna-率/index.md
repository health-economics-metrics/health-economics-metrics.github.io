# 無断キャンセル(DNA)率

DNA率とは、予約された予約のうち、患者が来院もキャンセルもしない割合のことです。臨床医、部屋、そして枠には費用が支払われますが、何も起こりません。これは医療における最も純粋な無駄のメトリクスであり、最もソフトウェアで修正しやすいものの1つです。

## なぜ重要か

NHS Englandの数値(2019年):GPの予約の無断キャンセルは年間1,500万件を超え、1件あたり約£30 — 年間**£2億1,600万**以上 — であり、病院外来のDNAは年間約800万件(予約の約6.4%)、無断キャンセル1件あたり平均約**£160**です。リマインダーの限界費用はわずかであり、回収される価値は完全に人員配置された臨床枠であるため、DNAの削減はデジタルヘルスの中でも最良のROI計算のいくつかを持っています。それが、SMSリマインダー、簡単な再予約、予測的なオーバーブッキングが、実証された初期のデジタルヘルスの成功例の一部であった理由です。

## 数式

```
DNA率 = DNA件数 / 予約件数 × 100

削減の価値 = 予約件数 × ΔDNA率 × 回収された1枠あたりの価値

回収された1枠あたりの価値:その枠は埋め戻されるか(活動価値/待機リストの削減)、
埋め戻されないか(スタッフの時間は部分的に再利用可能)— 節約された病床日数と同様に、
仕組みが重要。
```

## 計算例

ある外来部門:年間200,000件の予約、DNA率8%。リマインダー+再予約サービス(ワンタップ再予約付きSMS、交通情報、アクセシブルな形式)がDNAを5.5%まで削減します。

```
回収された枠 = 200,000 × 0.025 = 年間5,000件
平均外来価値約£160で待機リストから埋め戻し:
  5,000 × £160 = 年間£800,000の回収された活動
サービス費用:200,000 × £0.40 = 年間£80,000

リターン ≈ 10:1、加えて5,000人の待機リスト患者がより早く診察を受けられる
(待機リストへの影響と紹介から治療までを参照)。
```

効果量(2.5ポイント)は現実的です:リマインダーのRCTは一貫して25〜40%の相対的なDNA削減を示しています。

## ソフトウェア工学との関連

- **これはスケジューリングシステムの問題です**:リマインダー、セルフサービスの再予約、キャンセルからの待機リストの自動埋め戻し、そして標的を絞ったダブルブッキングを可能にする無断キャンセル予測モデル。それぞれが、異例なほど明快な経済的ケースを持つ通常のソフトウェア工学です。
- **エンジニアリングの類似物**:予約された容量の無断キャンセル — 予約されているが未使用のCI枠、予約されたクラウド容量、会議室、面接パネル。経済学は転用できます:安価な自動化されたリマインダー(あるいは未使用の予約の自動解放)は、高価なコミット済み容量を回収します。
- **予測の倫理についての予告**:出席データで訓練された無断キャンセルモデルは、貧困やアクセスの障壁を符号化します;それを使って来院しそうにない人を*優先度を下げる*ために使うことは不公平を増幅し、出席を*支援する*ために使うこと(交通支援、電話での代替手段)はそれを減らします。[到達範囲と公平性](../到達範囲と公平性/)を参照してください。

## 落とし穴

- **キャンセルされ再予約されたものを、回収された価値として二重に数えること。**
- **埋め戻されない回収された枠を評価すること** — リマインダーが送られた空の枠は、依然として空です。
- **DNAをゼロまで追いかけること**:DNAの最後のポイントは、実際の障壁に直面している患者です;懲罰的なアプローチ(N回のDNAの後に退院させる)は、患者を見捨てることでメトリクスを削減します。
