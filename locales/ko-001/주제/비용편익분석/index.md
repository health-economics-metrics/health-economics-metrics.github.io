# 비용편익분석(CBA)

CBA는 비용과 결과 *모두*를 화폐로 평가합니다. "이것을 할 가치가 있는가?"에 답할 수 있는 유일한 분석 유형입니다.

## 왜 중요한가

CBA는 모든 공공지출 평가에 대한 영국 HM Treasury Green Book의 표준입니다.

## 수식

```
NPV = Σ_t [ (편익_t − 비용_t) / (1 + r)^t ]
```

## 계산 예시

전자 의뢰 시스템, 5년 기간: NPV = +£254만7천, BCR = 2.0.

## 소프트웨어 공학과의 연관성

**표준 낙관편향으로서** — 엔지니어는 부처가 인프라 비용을 과소평가하는 것만큼 신뢰성 있게 마이그레이션 비용을 과소평가합니다.

## 함정

- 편익을 부풀리기 위해 **화폐화할 수 없는 것을 화폐화하기.**
