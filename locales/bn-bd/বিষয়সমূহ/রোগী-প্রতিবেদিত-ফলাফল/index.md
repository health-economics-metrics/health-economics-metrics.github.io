# রোগী-প্রতিবেদিত ফলাফল (PROM, PREM, MCID)

PROM হলো প্রমিত যন্ত্র যেখানে রোগীরা তাদের নিজস্ব স্বাস্থ্য অবস্থা রিপোর্ট করে; PREM যত্নের *অভিজ্ঞতা* ধারণ করে। **MCID** — ন্যূনতম ক্লিনিক্যালি গুরুত্বপূর্ণ পার্থক্য — হলো সবচেয়ে ছোট স্কোর পরিবর্তন যা রোগীরা প্রকৃতপক্ষে উপকারী বলে উপলব্ধি করে।

## কেন এটি গুরুত্বপূর্ণ

PROM ডিজিটাল স্বাস্থ্যের জন্য প্রাথমিক কার্যকারিতা মুদ্রা। গুরুত্বপূর্ণ যন্ত্রগুলো কম এবং প্রমিত — **PHQ-9** (বিষণ্নতা), **GAD-7** (উদ্বেগ), **EQ-5D** ([QALY](../মান-সমন্বিত-জীবন-বছর/)-র জন্য উপযোগিতা)।

## গণিত

```
PROM স্কোরিং: যন্ত্র-নির্দিষ্ট যোগফল

MCID অনুমান:
  নোঙর-ভিত্তিক: যারা "কিছুটা ভালো" রিপোর্ট করে তাদের মধ্যে স্কোর পরিবর্তন

প্রতিক্রিয়া হার কাঠামো:
  প্রতিক্রিয়াকারী = রোগী যার উন্নতি ≥ MCID
  NNT = 1 / (প্রতিক্রিয়া_হার_চিকিৎসা − প্রতিক্রিয়া_হার_নিয়ন্ত্রণ)
```

## সমাধানকৃত উদাহরণ

একটি বিষণ্নতা-সহায়তা অ্যাপ, RCT বনাম অপেক্ষমাণ তালিকা, ১২ সপ্তাহ:

```
PHQ-9 পরিবর্তন: অ্যাপ −6.2 পয়েন্ট, নিয়ন্ত্রণ −2.1 → সমন্বিত পার্থক্য −4.1
MCID চেক: 4.1 < 5 → প্রতিক্রিয়াকারী রিপোর্ট করুন:
  প্রতিক্রিয়াকারী (≥5-পয়েন্ট ড্রপ): অ্যাপ 48%, নিয়ন্ত্রণ 22% → ARR 26%
  NNT = 1/0.26 ≈ 4
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

PROM একটি তথ্য-সংগ্রহ সমস্যা যা সফটওয়্যার অনন্যভাবে সমাধান করতে পারে। একটি কাজের উৎপাদনশীলতা-নির্দিষ্ট যন্ত্রের জন্য [WPAI](../কাজের-উৎপাদনশীলতা-ও-কার্যকলাপ-ক্ষতি/) দেখুন।

## ঝুঁকিপূর্ণ দিক

- **MCID-এর নিচে পরিসংখ্যানগত তাৎপর্য** ক্লিনিক্যাল সুবিধা হিসেবে উপস্থাপিত।
- **গড়ের দিকে প্রত্যাবর্তন**: ব্যবহারকারীরা উপসর্গের শিখরে নথিভুক্ত হয়।
