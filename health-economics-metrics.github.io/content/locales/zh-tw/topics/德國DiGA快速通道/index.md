# 德國DiGA快速通道

DiGA（Digitale Gesundheitsanwendungen，數位健康應用）是德國法定的"處方應用"通道——這是全球首個由醫師開具處方、法定醫保必須為已批准的健康應用報銷費用的國家級制度。它是目前在全國規模上為數位療法付費這一實踐中最具代表性的現存實驗。

## 為何重要

DiGA用立法（2019年的DVG法案）回答了每一家數位健康公司都會問的問題——"到底誰會真正付錢？"其制度設計頗為出色：

- **快速決策**：監管機構BfArM必須在3個月內作出決定。
- **臨時掛網**：應用可以先臨時掛網12個月，*同時繼續生成證據*——在其關鍵研究期間即可獲得收入。
- **證據截止期**：必須透過一項對照研究（通常是隨機對照試驗）證明其具有"積極的醫療效果"（醫學獲益，或對病患有意義的結構性/流程性改善），否則將被摘牌。約有一半的臨時掛網應用未能成功轉正。
- **定價**：廠商可自由設定第一年的價格；此後需與保險聯合會協商定價。首個3個月週期的價格中位數約為500歐元；從2026年起將引入按結果付費的定價要素。

市場現實檢驗（截至2024年底的研究資料）：約68款應用已掛網，累計處方量超過100萬份，約81%的處方被實際啟用，保險方累計支出約2.34億歐元——這是一個真實存在的市場，但相較於其所受到的熱議而言規模仍屬有限，且啟用後的依從性仍是其薄弱環節。

## 計算方法

每一位DiGA創業者都會運作的商業模型：

```
收入 = 處方數 × 啟用率 × 每個處方週期的價格
證據生成成本 = 在12個月視窗期內完成的關鍵隨機對照試驗（通常需要200萬–300萬歐元）
期望價值 = P(證據研究成功) × 穩態收入 − 證據生成成本

由於約有50%的轉正失敗率，P必須被誠實地評估——業界有一半的
企業花光了隨機對照試驗的經費，最終卻失去了掛網資格。
```

## 實例演算

某抑鬱症管理應用以每季度450歐元的價格臨時掛網：

```
第1年：20,000份處方 × 81%啟用率 × 450歐元 ≈ 730萬歐元收入
隨機對照試驗成本：200萬歐元，與經營同步進行
結果A（證據為陽性）：獲得永久掛網資格，協商後價格約為380歐元，
  穩態下每年60,000份處方 ≈ 每年1,850萬歐元
結果B（證據研究失敗）：第12個月被摘牌；收入隨之中止。
```

這一臨時掛網年度，為證據生成本身提供了資金——這正是該通道最核心的創新之處。與之形成對比的是傳統順序（先有證據，收入數年後才到來），而這種傳統順序恰恰會活活餓死DiGA最希望存在的那類產品。

## 與軟體工程的聯絡

DiGA的這一模式——**附帶預先登記成功指標、並自動設定日落條款的臨時採納**——可以直接套用到工程工具的治理上：先將工具交付給生產環境使用者使用12個月，預先登記好衡量指標（實測節省的時間、事件數量下降），若證據未能兌現則自動到期失效。這一機制解決了"試點悖論"（一個工具需要達到一定規模才能證明其價值，但從未真正獲得那個規模）的問題，同時又不會給未經證實的技術授予永久的"終身教職"。81%啟用率卻依從性偏低這一資料，同樣蘊含著一條產品層面的教訓：處方（或高層強制指令）能帶來安裝量；只有產品本身的品質，才能帶來持續使用——參見[依從性與持續性](../依從性與持續性/)。

## 陷阱

- **把"獲得掛網資格"當作終點線**——處方需要開處方者的信任；許多已掛網的DiGA應用實際處方量微乎其微。
- **為了在營收年度節省開支，而使關鍵研究的功效不足**——這正是那50%失敗率背後的假性節約。
- **照搬這一模式卻沒有對應的付費方**：DiGA之所以行得通，是因為報銷是法定強制的；若沒有強制付費機制而只照搬其形式，那不過是一個普通的試點專案。
