# Ekonomi för fjärrpatientövervakning

Ekonomi för fjärrpatientövervakning mäter de kostnadsbesparingar som hemövervakningsteknik ger genom att minska inläggningar, återinläggningar och fysiska besök.

## Varför det är viktigt

Fjärrövervakning kräver initiala utrustningskostnader men kan förhindra dyr akutvårdsanvändning.

## Matematiken

```
Nettobesparing = (antal undvikna inläggningar × kostnad per inläggning) − programkostnad
```

## Genomarbetat exempel

Fjärrövervakning av hjärtsvikt: 40 undvikna inläggningar × £4 000 = £160 000 besparing − programkostnad £60 000 = nettobesparing £100 000.

## Koppling till mjukvaruutveckling

Direkt kopplat till [sparade vårddagar](../bed-days-saved/) och [återinläggningsfrekvens](../readmission-rate/), och beroende av [validering av bärbara enheter](../wearable-validation/) för datakvalitet.

## Fallgropar

- **Att överskatta besparingar genom urvalsbias vid patienturval.**
