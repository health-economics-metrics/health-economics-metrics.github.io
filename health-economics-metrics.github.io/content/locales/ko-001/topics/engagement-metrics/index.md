# 참여 지표

참여 지표는 사용자가 건강 앱이나 디지털 서비스와 얼마나 자주, 얼마나 깊이 상호작용하는지 측정합니다: 활성 사용자, 세션 빈도, 체류 시간.

## 왜 중요한가

참여 없는 건강 앱은 효과를 낼 수 없습니다 — 임상적 근거가 아무리 강력해도.

## 수식

```
DAU/MAU 비율 = 일간 활성 사용자 / 월간 활성 사용자
```

## 계산 예시

당뇨병 관리 앱: DAU 3,000, MAU 12,000 = 0.25 (건강 앱으로는 양호).
