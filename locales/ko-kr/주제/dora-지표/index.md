# DORA 지표

DORA 지표는 소프트웨어 전달 성과의 네 가지 측정치입니다 — 배포 빈도, 변경 리드타임, 변경 실패율, 그리고 복구 시간.

## 왜 중요한가

10년간의 DORA 연구는 이 지표들을 조직 성과와 연결합니다.

## 수식

```
리드타임 = t(배포) − t(커밋), 중앙값
```

## 계산 예시

트러스트의 환자 흐름 소프트웨어 팀, 이전/이후: 배포 월별 → 주별.

## 소프트웨어 공학과의 연관성

이것은 *바로* 소프트웨어 측면입니다.
