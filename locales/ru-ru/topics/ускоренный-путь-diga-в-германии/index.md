# Ускоренный путь DiGA в Германии (Germany's DiGA Fast-Track)

DiGA (Digitale Gesundheitsanwendungen) — это немецкий законодательный путь «приложений по рецепту» — первая в мире национальная система, где врачи выписывают рецепты на одобренные медицинские приложения, а государственное страхование обязано их возмещать. Это ведущий действующий эксперимент по оплате цифровых терапевтических средств в национальном масштабе.

## Почему это важно

DiGA ответила на вопрос, который задаёт каждая компания цифрового здравоохранения — «кто на самом деле заплатит?» — законодательством (DVG, 2019 год). Дизайн примечателен:

- **Быстрое решение**: BfArM (регулятор) обязан принять решение в течение 3 месяцев.
- **Предварительный листинг**: приложения могут находиться в реестре 12 месяцев, *продолжая при этом собирать доказательства* — получая выручку во время своего ключевого исследования.
- **Дедлайн доказательств**: доказать «положительный эффект для здравоохранения» (медицинскую пользу или значимое для пациента структурное/процедурное улучшение) через сравнительное исследование — обычно RCT — иначе исключение из реестра. Примерно половина предварительных записей не проходит этот этап.
- **Ценообразование**: производитель свободно устанавливает цену на 1-й год; затем она согласовывается с федерацией страховщиков. Медианные начальные цены за 3 месяца около €500; элементы ценообразования по результатам появляются с 2026 года.

Проверка рыночной реальности (исследование по конец 2024 года): ~68 приложений в реестре, >1 млн совокупных рецептов, ~81% рецептов активированы, ~€234 млн совокупных расходов страховщиков — реальный рынок, но скромный по сравнению с ажиотажем, а приверженность после активации остаётся слабым местом.

## Математика

Коммерческая модель, которую использует каждый основатель DiGA:

```
Выручка = рецепты × доля активации × цена за период действия рецепта
Стоимость доказательств = ключевое RCT (обычно €1–3 млн) в рамках 12-месячного окна
Ожидаемая ценность = P(доказательства успешны) × устойчивая выручка − стоимость доказательств

При доле неудачных конверсий ~50% P нужно оценивать честно — половина
отрасли тратит деньги на RCT и теряет листинг.
```

## Практический пример

Приложение по управлению депрессией предварительно листингуется по €450/квартал:

```
Год 1: 20,000 рецептов × 81% активации × €450 ≈ €7.3 млн выручки
Стоимость RCT: €2 млн, проводится параллельно
Исход A (доказательства положительны): постоянный листинг, согласованная цена ~€380,
  устойчивое состояние 60,000 рецептов/год ≈ €18.5 млн/год
Исход B (доказательства не подтвердились): исключение из реестра на 12-й месяц; выручка прекращается.
```

Предварительный год финансирует генерацию доказательств — ключевую инновацию этого пути. Сравните с традиционной последовательностью (сначала доказательства, выручка годами позже), которая морит голодом именно те продукты, которым DiGA хочет дать возможность существовать.

## Связь с разработкой программного обеспечения

Паттерн DiGA — **предварительное принятие с заранее зарегистрированной метрикой успеха и автоматическим закатом** — напрямую копируем для управления инженерными инструментами: поставьте инструмент продуктивным пользователям на 12 месяцев, заранее зарегистрируйте метрику (измеренное сэкономленное время, снижение инцидентов), автоматически прекращайте действие, если доказательства не появились. Это решает парадокс пилота (инструменты, которым нужен масштаб для доказательства ценности, никогда не получают масштаб) без предоставления постоянного статуса недоказанным технологиям. Данные об активации 81% и низкой приверженности также несут продуктовый урок: рецепт (или мандат руководства) обеспечивает установки; только качество продукта обеспечивает устойчивое использование — см. [приверженность и устойчивость приёма](../приверженность-и-устойчивость-приёма/).

## Подводные камни

- **Отношение к листингу как к финишной черте** — рецепты требуют доверия выписывающего врача; многие приложения из реестра DiGA видят незначительные объёмы.
- **Недостаточная мощность ключевого исследования** ради экономии денег в год выручки — ложная экономия, объясняющая значительную долю 50%-ного уровня провалов.
- **Перенос модели без плательщика**: DiGA работает потому, что возмещение установлено законом; копия без обязательной оплаты — просто пилотная программа.
