# การตระหนักถึงผลประโยชน์

การตระหนักถึงผลประโยชน์เป็นวินัยที่ติดตามว่าผลประโยชน์ที่สัญญาไว้ในกรณีทางธุรกิจเกิดขึ้นจริงหรือไม่หลังจากส่งมอบโครงการ ไม่ใช่แค่ในระหว่างการส่งมอบ

## ทำไมจึงสำคัญ

โครงการจำนวนมากส่งมอบผลลัพธ์ทางเทคนิคที่ประสบความสำเร็จ แต่ไม่สามารถบรรลุผลลัพธ์ทางธุรกิจที่สัญญาไว้ — การตระหนักถึงผลประโยชน์รับผิดชอบต่อมูลค่าที่แท้จริง ไม่ใช่แค่การส่งมอบ

## คณิตศาสตร์

```
อัตราการตระหนักถึงผลประโยชน์ = ผลประโยชน์ที่บรรลุ / ผลประโยชน์ที่สัญญาไว้ในกรณีทางธุรกิจ × 100%
```

## ตัวอย่างที่คำนวณแล้ว

กรณีทางธุรกิจของระบบคัดกรองดิจิทัลสัญญาการประหยัด £500,000 ต่อปี แต่ 12 เดือนหลังการปรับใช้ การประหยัดจริงที่วัดได้คือ £320,000 — อัตราการตระหนักถึง 64% ซึ่งต้องการการตรวจสอบ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการติดตามการนำไปใช้ของฟีเจอร์หลังจากการปรับใช้ เพื่อตรวจสอบว่าการเติบโตของผู้ใช้ที่ผู้จัดการผลิตภัณฑ์คาดการณ์ไว้เกิดขึ้นจริงหรือไม่

## ข้อผิดพลาดที่พบบ่อย

- **การปิดโครงการโดยไม่ติดตามการตระหนักถึงผลประโยชน์**
- **การวัดการตระหนักถึงผลประโยชน์เร็วเกินไปก่อนที่การเปลี่ยนแปลงจะฝังรากลึกอย่างสมบูรณ์**
