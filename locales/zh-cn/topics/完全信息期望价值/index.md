# 完全信息期望价值 (Expected Value of Perfect Information, EVPI)

EVPI 是决策者在做出决策之前,为消除不确定性而应当支付的最高金额——它是"我们先做个研究再说"这句话的正式定价。

## 为什么重要

医疗系统持续面临这样的选择:凭不完美的证据现在就采纳,还是先资助更多研究。EVPI 为第二种选择给出了一个具体数字。如果 EVPI 是 5 万英镑,而拟议的试验成本是 200 万英镑,那就现在采纳。如果 EVPI 是 2000 万英镑,那么这项试验就很划算。同样的问题——"在全面推广之前,我们该不该先做试点?"——出现在每一项企业级工具决策中,而几乎没有人为它定价。 关于为日后扩张项目的期权（而不是先收集信息的期权）定价，见[实物期权估值](../实物期权估值/)。

## 计算方法

EVPI 是"以完美先见做决策"与"以当前预期做决策"之间的差距:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = 不确定参数(及其联合分布)
NMB(j,θ) = 在给定 θ 下,方案 j 的净货币收益
```

第一项:每一种可能世界中最优选择的收益的平均值(你总是选对)。第二项:平均表现最好的单一方案的收益(你必须现在就做出承诺)。EVPI 始终 ≥ 0。人群层面的 EVPI 需乘以受影响的决策数量。可直接由 [PSA](../概率敏感性分析/) 抽样计算得出。

## 实例演算

将一款 AI 文书助手推广给 5,000 名临床医生,或者不推广。存在两种情形:

```
情形 A(p = 0.6):助手每天节省 20 分钟 → 推广的 NMB = +£8M
情形 B(p = 0.4):助手几乎无效果(工作流摩擦) → 推广的 NMB = −£3M
"不推广"在两种情形下的 NMB 均为 £0。
```

现在就决策:E[推广的 NMB] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → 应推广。

若拥有完美信息:在情形 A 中选择推广(+£8M),在情形 B 中选择不推广(£0)。期望价值 = 0.6 × 8 + 0.4 × 0 = **£4.8M**。

```
EVPI = 4.8M − 3.6M = £1.2M
```

一次严谨的、成本为 15 万英镑、能实质性地判明你身处哪种情形的 3 个月试点,显然是值得的——而任何成本超过 120 万英镑的试点,无论多么详尽,都不值得。

## 与软件工程的关联

EVPI 就是"探针(spike)"、试点、A/B 测试以及概念验证的经济学。它给出两条实用规则:

- **只有当决策真的可能因此改变时,试点才值得资助。**如果无论试点结果如何你都会照常推广,那么 EVPI = 0,试点就是表演。
- **将试点支出的上限设为 EVPI。**信息的价值,受限于它所服务的那个决策本身的价值。

部分 EVPI(EVPPI)将这一概念扩展到单个参数:"具体把'节省的时间'这个数字弄准,值多少钱?"——这能告诉你试点应当测量什么。 关于评估*某一项具体拟议研究*而不是消除全部不确定性，见 [EVSI](../样本信息期望价值/)。

## 常见误区

- **在没有配套决策规则的情况下开展试点**——无法改变选择的信息,按定义毫无价值。
- **忽视收集信息所带来的延迟成本**:一个 6 个月的试点会延迟 6 个月的收益([延迟成本](../延迟成本/));试点的净价值 = 已解决的 EVPI − 延迟成本 − 试点成本。
- **把 EVPI 当作预测。**它是信息价值的上限,而不是对某项具体研究将带来多少价值的估计。
