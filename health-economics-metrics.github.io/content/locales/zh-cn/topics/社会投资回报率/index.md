# 社会投资回报率 (Social Return on Investment，SROI)

SROI 把 [ROI](../投资回报率/) 的概念扩展到市场无法定价的结果——幸福感、社会联结、环境影响——通过财务替代指标 (financial proxy) 为其中的价值定价，并覆盖*所有*受影响的利益相关方。

## 为什么重要

卫生与社区干预所产生的许多成果，从未真正进入过任何预算科目：孤独感的减轻、照护者的喘息、就业机会的提升、尊严感。SROI 以 Social Value International 的七项原则为准绳（让利益相关方参与、为真正重要的事物估值、不夸大、保持透明、可核实……），产出诸如"每投入 £1 产生 £3.20 社会价值"这样的表述。英国公共采购中的社会价值要求，使 SROI 类证据具有真实的商业意义：公共合同（包括 NHS 合同）的投标会因展示出的社会价值而获得加分。

## 计算方法

```
SROI 比率 = PV(已货币化的社会成果) / PV(投入)

对每项成果：
  价值 = 数量 × 财务替代指标 × 归因比例 × (1 − 无谓损失比例) × (1 − 位移比例)

无谓损失 (deadweight)   = 即使没有该项目也会发生的部分
归因 (attribution)      = 由其他方所促成的份额
位移 (displacement)     = 效益是从别处转移过来的，而非新创造的
衰减 (drop-off)         = 成果随年份推移而递减
```

这些调整系数正是该方法能否保持诚信的关键：没有它们，SROI 就只是一个带货币符号的虚构数字。

## 算例

一款把孤立的老年人与志愿者联系起来的陪伴应用；项目成本每年 £200,000；1,500 对活跃配对。

```
成果：为 1,500 人减轻孤独感
  替代指标：对"摆脱孤独"的幸福感估值 ≈ 每人每年 £1,800
  无谓损失 25%（有些人即使没有该项目也会找到联结）
  归因 80%（部分功劳属于其他服务）

价值 = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

成果：减少 GP 就诊，1,500 × 1.2 次就诊 × £42 = £75,600（对付费方而言是实打实的资金）

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

请注意，这个比率中 96% 是按替代指标估值的幸福感，只有 4% 是硬现金。这是合法的 SROI——但必须以"社会价值"的名义呈现，绝不能暗示这 £1.7M 是可以兑现的现金。

## 与软件工程的关联

对于受益方并非付费团队本身的工程工作——开源维护、无障碍改进、被其他团队消费的平台工作、对开发者社区的投入——SROI 提供了一个诚实的框架。可迁移的方法要点：识别所有利益相关方，用明示的替代指标进行货币化，并应用无谓损失/归因折扣（那个开源修复即使没有你，是不是也会发生？收益中有多少是你的工作、多少是生态系统本身的贡献？）。*对自身影响力主张打折扣*这一纪律，正是 SROI 区别于营销数字的地方。

## 陷阱

- **替代指标货比三家**：挑选现有可用估值中最慷慨的那个幸福感估值。
- **跳过无谓损失/归因折扣**——最常见的虚高手法，往往能让比率翻倍。
- **跨研究比较比率**：SROI 比率对方法高度敏感；只应在同一个一致的框架内比较。
- **向预算持有者把社会价值呈现为可兑现的节约。**
