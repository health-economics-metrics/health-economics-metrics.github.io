# Kostnads-nyttoanalys (CBA)

Kostnads-nyttoanalys omvandlar både kostnader och nyttor till monetärt värde, vilket gör det möjligt att beräkna nettonuvärdet direkt.

## Varför det är viktigt

CBA möjliggör jämförelser mellan sektorer (hälsa mot utbildning mot infrastruktur) eftersom allt uttrycks i samma enhet: pengar.

## Matematiken

```
NNV = Σ(t=0 till horisont) (Nyttor_t − Kostnader_t) / (1+r)^t
```

## Genomarbetat exempel

Ett statligt förebyggande program med nuvärdeskostnader på £10 miljoner och nuvärdesnyttor (undvikna vårdkostnader plus produktivitetsvinster) på £15 miljoner: NNV = +£5 miljoner.

## Koppling till mjukvaruutveckling

Liknar att motivera en plattformsinvestering genom att omvandla alla fördelar (hastighet, tillförlitlighet, minskade incidenter) till ett uppskattat monetärt värde.

## Fallgropar

- **Att omvandla hälsovärde till pengar med kontroversiella antaganden utan att ange dem.**
- **Att förbise icke-marknadsnyttor (som välbefinnande) som är svåra att prissätta.**
