# 예방 경제학

질병이 발생하거나 진행되기 전에 개입하는 경제학입니다. 핵심 발견은 직관에 반합니다: **대부분의 예방은 돈을 절약하지 않습니다** — 좋은 가격에 건강을 구매합니다.

## 왜 중요한가

"예방은 돈을 절약한다"는 보건 정책에서 가장 자주 반복되는 거짓 주장입니다. 예방 프로그램의 비용을 산정하기 전에, [인구기여분율](../인구기여분율/)이 먼저 규모 문제에 답합니다. 프로그램이 다루는 위험요인이 겨냥한 질병 부담의 얼마를 현실적으로 제거할 수 있는가 하는 것입니다.

## 수식

```
예방의 순비용(1인당) =
    개입 비용 × 모든 치료받은 사람
  − 회피된 하류 비용 × 진행했을 사람들
```

## 계산 예시

10만 명의 위험군 성인을 위한 고혈압 관리 앱: 순비용 ≈ £280만 — 절감이 아닙니다.

## 소프트웨어 공학과의 연관성

주의사항이 있는 시프트 레프트 품질은 예방 경제학입니다.
