# Цифрові кінцеві точки та біомаркери

Цифрові кінцеві точки та біомаркери — це об'єктивні, кількісно вимірювані показники здоров'я, зібрані за допомогою датчиків, носимих пристроїв чи цифрових інструментів.

## Чому це важливо

Цифрові біомаркери надають безперервні, об'єктивні дані, що заповнюють прогалину між традиційними клінічними візитами.

## Математика

```
Валідність цифрової кінцевої точки = коефіцієнт кореляції(цифровий вимір, валідований клінічний стандарт)
```

## Розібраний приклад

Вимір швидкості ходи на основі підрахунку кроків: кореляція з клінічним 6-хвилинним тестом ходьби r = 0,82.

## Зв'язок з інженерією програмного забезпечення

[Валідація носимих пристроїв](../wearable-validation/) є передумовою надійності цих даних.

## Підводні камені

- **Розгляд неваліованих даних датчиків як клінічно валідних.**
