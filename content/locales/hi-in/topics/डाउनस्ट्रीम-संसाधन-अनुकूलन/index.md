# डाउनस्ट्रीम संसाधन अनुकूलन

एक वरिष्ठ चिकित्सक के लिए एक घंटा बचाना — एक GP, वरिष्ठ रजिस्ट्रार, परामर्शदाता — अक्सर नर्सों, प्रशासनिक क्लर्कों, और चिकित्सकों की एक पूरी बहु-विषयक टीम (MDT) के लिए बाधा विलंब को रोकता है।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य सेवा अनुमोदन श्रृंखलाओं पर चलती है: छुट्टी परामर्शदाता की स्वीकृति की प्रतीक्षा करती है।

## गणित

```
अवरोधमुक्ति का मूल्य = Σ डाउनस्ट्रीम भूमिकाओं में (मुक्त अवरुद्ध घंटे × इकाई लागत)
```

## हल किया गया उदाहरण

एक वार्ड की छुट्टियों के लिए हर सुबह परामर्शदाता समीक्षा की आवश्यकता होती है।

```
बचाए गए बिस्तर-दिन = सालाना 1,460 बिस्तर-दिन
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यह कोड समीक्षा, वास्तुकला अनुमोदन है।
