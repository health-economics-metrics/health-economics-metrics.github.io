# 参与度指标 (Engagement Metrics)

参与度指标衡量用户实际使用健康类应用的程度:DAU/MAU 粘性、会话频率与时长、功能使用情况。在数字健康领域,参与度并非虚荣指标——它是**剂量(dose)**:任何临床效果都必须通过这一暴露量才能实现。

## 为什么重要

一瓶留在药柜里的药治不好任何人;一个从未安装或从未打开的应用,是同一种失败模式。任何消费级健康产品的健康经济学主张,都要乘以参与度这一系数——试验中测得的疗效是在某一使用水平下测得的,而现实世界的价值取决于实际部署中的使用水平与该水平的接近程度。标准产品基准:DAU/MAU 在**约 20% 通常被视为健康**(泛指移动应用),超过 25% 属于卓越水准;健康类应用往往更低。

## 计算方法

```
粘性 (DAU/MAU) = 日活跃用户数 / 月活跃用户数 × 100
会话指标        = 每用户每周期会话数;平均时长 = 总时长 / 会话数
功能参与度      = 执行关键操作的用户数 / 活跃用户数

剂量-反应框架(健康经济学升级版):
  实现效果 ≈ 试验效果 × f(实际使用量 / 试验使用量)
  其中 f 来自剂量-反应分析——参见 adherence-and-persistence.md 中
  "有效参与(effective engagement)"的概念:达到预期结局所需的
  使用量,这一量可能是适度且有限的
```

## 实例演算

某血压管理应用的关键性研究显示,每周记录读数 ≥4 次的用户,收缩压平均下降 6 mmHg。在 50,000 名注册用户的实际部署中:

```
MAU 为 20,000(40%);其中每周记录 ≥4 次的用户:7,000
有效剂量用户 = 7,000 / 50,000 = 占注册用户基数的 14%

人群层面的效果 ≈ 试验效果实际只作用于 14%,而非 100%:
任何引用"50,000 名用户 × 6 mmHg"的经济模型,都高估了约 7 倍。
诚实的模型应为:7,000 名用户享有完整效果 + 对 13,000 名未达标用户
给予部分权重(若有剂量-反应数据支持)。
```

这一乘算过程——从参与度漏斗一路推算到有效剂量——是数字健康经济学中最常见的虚高之处。

## 与软件工程的关联

工程师掌控着参与度漏斗,这也使他们成为一个*临床*变量的负责人:入门引导摩擦、通知策略、加载时间、离线韧性,都会影响所交付的剂量。这带来两个设计层面的启示:应埋点跟踪**具有临床意义的动作**(已记录的读数、已完成的课程),而不是打开次数——建立在通知反弹式会话之上的 DAU 是一种"剂量造假";并且应将参与度目标视为*充分性*目标,而非最大化目标——一款能在每周 5 分钟内实现预期结局并适时"退出"的应用,在临床上是理想的,但在指标上却显得"糟糕"(参见[依从性与持续性](../依从性与持续性/)中的有效参与概念)。用上述人群效果模型为参与度工作本身估值:有效剂量份额提升 2 个百分点,即是一条可量化的 QALY 收益线。

## 常见误区

- **将参与度本身当作结局**:使用量是手段;结局是 [PROM](../患者报告结局/) 或临床终点。
- **对双峰分布使用平均值**:健康类应用的用户群往往分裂为高度投入用户和"幽灵用户"两极;均值描述的是谁都不是——应分群处理。
- **暗黑模式式的剂量虚增**:连续打卡和愧疚式通知能拉高指标,却可能伤害健康类应用所服务的焦虑人群;临床产品须承担临床伦理责任。
- **供应商基准的来源问题**:大多数已发表的参与度基准来自分析工具供应商,而非同行评审;应以自身试验数据进行校准。
