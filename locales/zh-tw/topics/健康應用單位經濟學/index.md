# 健康應用單位經濟學

消費級健康產品的商業算術：客戶獲取成本（CAC）、生命週期價值（LTV）、每使用者平均收入（ARPU）、按會員每月計價（PMPM），以及在僱主市場中至關重要的**投資回報率（ROI）與投資價值率（VOI）**之分。

## 為何重要

健康應用面臨一種結構性擠壓：獲客成本高昂（受監管的宣稱限制、信任門檻、合規成本），而留存率則是所有軟體垂直領域中最差的（30天內約90%的使用者流失——參見[留存與流失](../留存與流失/)）。因此，標準的可行性檢驗——**LTV:CAC ≥ 3:1**——在消費級健康領域極其難以達成，這也是為什麼該行業正在向B2B2C模式遷移：由僱主、保險公司與醫療系統按PMPM為整個人群付費，此時的付費方不再是那個會流失的個體使用者。

## 計算方法

```
CAC（獲客成本）  = 銷售+行銷支出 / 新增付費客戶數
ARPU（每使用者平均收入） = 收入 / 活躍使用者數（按週期計）
LTV（生命週期價值） = ARPU × 平均生命週期 = ARPU / 流失率
可行性標準：LTV : CAC ≥ 3，回本週期 ≤ 12–18個月

每留存使用者的有效獲客成本 = CAC / 留存率(t)
  ——若第30天留存率為4%，每次安裝成本£5，則相當於每名
     30天留存使用者實際成本£125

PMPM收入 = 費率 × 已註冊會員數 × 月數
  供應商利潤率 = PMPM − 每會員每月服務成本
  ——參與度的作用在此發生反轉：在B2C訂閱模式下，參與度帶來收入；
    而在PMPM模式下，參與度高的會員服務成本反而高於不活躍的會員，
    而基於結果付費的合同又會將這一邏輯再次翻轉回來
```

## 實例演算

某B2C睡眠應用：£6.99/月，月流失率18%，綜合獲客成本£38。

```
LTV = 6.99 / 0.18 ≈ £38.8 → LTV:CAC ≈ 1.0——不可持續

轉向僱主PMPM模式：£1.20 PMPM × 40,000名覆蓋人員 = £48,000/月
服務成本：基礎設施£0.15 + 支援£0.10 + 內容£0.05
  每會員約£0.30 → 利潤率約75%，銷售週期雖長，但流失
  發生在合同層面（按年），而非使用者層面（按日）

僱主關心的問題會改變整個指標體系：對健康類產品而言，
硬性貨幣投資回報率（減少的理賠、缺勤率）通常難以證實——
業內的應對方式是使用VOI：生產力、招聘吸引力、參與度——
但這種做法只有在明確標註為VOI、而非包裝成ROI時才是誠實的
（參見return-on-investment.md與social-return-on-investment.md）。
```

## 與軟體工程的聯絡

工程決策同時決定著這一比值的兩端：**服務成本**取決於架構（[雲單位經濟學](../雲單位經濟學/)——PMPM的利潤率生死全在於每會員的基礎設施成本），而**LTV**則取決於留存工程（每一個流失點都對應著可計算的收入損失——[留存](../留存與流失/)檔案中的QALY算術，恰好有一個完全對應的收入版本）。對於健康類產品而言，單位經濟學儀表盤除了LTV與CAC之外，還應加上第三行：**每名獲取使用者的健康價值**（按留存加權的QALY × 閾值）——因為支付方與DiGA式的市場正日益依據這一指標定價，而且一款商業單位經濟學與臨床單位經濟學彼此背離的產品（盈利卻對健康毫無作用，或有效卻無法獲得資助），需要清楚知道自己究竟面臨的是哪一種問題。

## 陷阱

- **僅憑早期佇列流失率推算LTV**：流失率通常會逐漸趨於穩定下降；但同時也存在存活者偏差——早期採用者的留存往往優於後期規模化後的使用者群體。應使用佇列成熟後的資料。
- **將各渠道獲客成本混合計算**：付費社交渠道的獲客成本與臨床醫師轉介渠道的獲客成本可相差10倍，且二者的留存曲線截然相反——應分渠道分析，否則會被誤導。
- **未設使用量上限的PMPM模式**：極少數參與度極高的會員可能會使利潤率反轉為負；應對分佈建模，而非只看均值。
- **向CFO將VOI包裝成ROI呈現**——這正是僱主健康福利這一行業花了十年才積累起來、又極易毀於一旦的可信度問題。
