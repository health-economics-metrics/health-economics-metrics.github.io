# Valutazione Normativa dell'IA

I framework normativi che regolano l'IA nella sanità — il regime Software as a Medical Device (SaMD) della FDA con **Piani di Controllo delle Modifiche Predeterminati (PCCP)**.

## Perché è importante

La regolamentazione determina sia **il costo delle evidenze per l'ingresso nel mercato** sia **il costo di ogni successivo aggiornamento del modello**.

## La matematica

```
Costo per aggiornamento del modello (tradizionale) = costo di ripresentazione + ritardo di revisione × CoD
```

## Esempio risolto

Un fornitore di IA radiologica pianifica miglioramenti trimestrali del modello per 3 anni: risparmio con il percorso PCCP ≈ £2,75 milioni.

## Collegamento con l'ingegneria del software

Progettare bene il PCCP è un problema software.
