# อัตราการไม่มาตามนัด (DNA)

อัตราการไม่มาตามนัดวัดสัดส่วนของการนัดหมายที่จองไว้ซึ่งผู้ป่วยไม่มาโดยไม่ได้ยกเลิกล่วงหน้า

## ทำไมจึงสำคัญ

การนัดหมายที่พลาดไปอาจเป็นตัวชี้วัดความสูญเปล่าที่บริสุทธิ์ที่สุดในระบบสุขภาพ: ความจุที่จองเต็มแต่ให้มูลค่าเป็นศูนย์

## คณิตศาสตร์

```
อัตรา DNA = จำนวนการนัดหมายที่พลาด / จำนวนการนัดหมายที่จองทั้งหมด × 100%
```

## ตัวอย่างที่คำนวณแล้ว

คลินิกผู้ป่วยนอกที่มีการนัดหมาย 10,000 ครั้งต่อปีและอัตรา DNA 8% สูญเสียช่องการนัดหมาย 800 ครั้ง แต่ละครั้งมีมูลค่าเท่ากับต้นทุนคลินิกเต็มรูปแบบ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับความจุการประมวลผลบนคลาวด์ที่จองไว้แต่ไม่ได้ใช้งาน — จ่ายเงินเต็มจำนวนแต่ให้มูลค่าที่ส่งมอบเป็นศูนย์

## ข้อผิดพลาดที่พบบ่อย

- **การประเมินต้นทุนของ DNA โดยใช้ต้นทุนเฉลี่ยแทนต้นทุนส่วนเพิ่ม**
- **การใช้ระบบแจ้งเตือนโดยไม่แก้ไขอุปสรรคด้านการเข้าถึงที่เป็นสาเหตุหลัก**
