# سرمایہ کاری پر منافع (ROI)

ROI سرمایہ کاری شدہ رقم کے لیے خالص فائدے کا تناسب ہے۔ یہ ایک ایسا میٹرک ہے جسے انجینئرنگ اور مالیات پہلے سے شیئر کرتے ہیں۔

## یہ کیوں اہم ہے

ROI بجٹ رکھنے والوں کی مشترکہ زبان ہے۔ Masters et al. کے جائزے نے پبلک ہیلتھ مداخلتوں کے لیے **درمیانی ROI 14.3:1** پایا۔

## ریاضی

```
ROI = (فائدہ − قیمت) / قیمت
```

## حل شدہ مثال

ای-روسٹرنگ نظام، 3 سالوں میں £500,000 کی قیمت۔

## سافٹ ویئر انجینئرنگ سے تعلق

ہر ٹولنگ تجویز میں ایک ROI سلائیڈ ہوتی ہے۔

- **نقطہ نظر کی لانڈرنگ۔**
