# DORA-mittarit

DORA-mittarit ovat neljä ohjelmistotoimituksen suorituskyvyn mittaria — käyttöönottotaajuus, muutosten läpimenoaika, muutosvirheiden osuus ja palautumisaika.

## Miksi se on tärkeä

Kymmenen vuoden DORA-tutkimus yhdistää nämä mittarit organisaation suorituskykyyn.

## Matematiikka

```
Läpimenoaika = t(käyttöönotto) − t(commit), mediaani
```

## Ratkaistu esimerkki

Sairaalapiirin potilasvirran ohjelmistotiimi, ennen/jälkeen: käyttöönotot kuukausittaisista → viikoittaisiin.

## Yhteys ohjelmistokehitykseen

Tämä on *täsmälleen* ohjelmistopuoli.
