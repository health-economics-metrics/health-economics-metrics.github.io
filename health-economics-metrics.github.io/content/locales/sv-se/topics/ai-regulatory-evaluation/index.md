# AI-regulatorisk utvärdering

AI-regulatorisk utvärdering bedömer om medicinska AI-system uppfyller juridiska och regulatoriska godkännandekrav.

## Varför det är viktigt

Misslyckat regulatoriskt godkännande kan helt blockera driftsättningen av kliniskt effektiva AI-system.

## Matematiken

```
Kostnad för regulatorisk väg = kostnad för kliniska bevis + ansökningsavgifter + kostnad för marknadsövervakning efter lansering
```

## Genomarbetat exempel

Ett diagnostiskt stödverktyg klassificerat som SaMD klass III (mjukvara som medicinteknisk produkt): totala regulatoriska kostnader ≈ £800 000, 18 månader till godkännande.

## Koppling till mjukvaruutveckling

Bevis från [klinisk AI-utvärdering](../clinical-ai-evaluation/) är en nyckelfaktor för den regulatoriska ansökan.

## Fallgropar

- **Att fortsätta utvecklingen utan att tidigt fastställa den regulatoriska klassificeringen.**

## Källor

- MHRA, Software and AI as a Medical Device guidance.
- FDA, AI/ML-Based SaMD Action Plan.
