# Saksan DiGA-pikakaista

DiGA-pikakaista (Digitale Gesundheitsanwendungen) on Saksan järjestelmä digitaalisten terveyssovellusten väliaikaiseen listaamiseen reseptillä, kahdentoista kuukauden näyttöaikataululla.

## Miksi se on tärkeä

DiGA antaa valmistajille mahdollisuuden saada varhainen korvaus alustavan näytön perusteella, velvollisuudella toimittaa lopullinen näyttö positiivisesta hoitovaikutuksesta vuoden sisällä.

## Matematiikka

```
Väliaikainen hinta (vuosi 1) → lopullinen hinta (positiivisen hoitovaikutuksen näytön jälkeen)
```

## Ratkaistu esimerkki

Tinnitushoitosovellus saa väliaikaisen DiGA-listauksen ja saa korvausta, kun valmistaja suorittaa tutkimuksen osoittaakseen positiivisen hoitovaikutuksen 12 kuukauden sisällä.

## Yhteys ohjelmistokehitykseen

Muistuttaa beetajulkaisua asetetulla määräajalla menestysmittareiden todistamiseksi ennen täyden tuotestatuksen myöntämistä.

## Sudenkuopat

- **Näyttöaikataulun noudattamatta jättäminen, mikä johtaa poistamiseen rekisteristä.**
- **Oletus, että väliaikainen listaus vastaa pysyvää korvausta.**
