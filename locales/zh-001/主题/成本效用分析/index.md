# 成本效用分析（CUA）

成本效用分析是采用**通用的、经偏好加权的结果指标**的成本效果分析——几乎总是使用[QALY](../质量调整生命年/)（或所避免的[DALY](../伤残调整生命年/)）。由于结果计量单位是通用的，成本效用分析能够跨越完全不同的疾病领域比较各种干预措施。

## 为何重要

一个国家医疗服务体系必须在同一份预算下，在一种抗癌药物、一款心理健康应用和一台手术机器人之间做出选择。自然单位无法用来比较这三者；QALY则可以。因此，成本效用分析是NICE及大多数卫生技术评估机构的参考案例方法：其输出——每QALY成本，并依据某个[阈值](../支付意愿阈值/)进行判断——是卫生政策领域所拥有的、最接近"通用汇率"的东西。如果你希望自己的软件*取代其他方案*获得资助，成本效用分析就是那个角力场。

## 计算方法

```
增量成本效用比（ICUR） = ΔCost / ΔQALY      （即以QALY作为效果单位的ICER）

ΔQALY = Σ (时长_i × 效用值_i)_新方案 − Σ (时长_i × 效用值_i)_旧方案
```

效用值来自经过验证的量表工具（[EQ-5D](../EQ-5D/)）；成本与QALY均按3.5%（NICE参考案例标准）进行[贴现](../贴现与时间偏好/)；不确定性通过[概率敏感性分析（PSA）](../概率敏感性分析/)处理。

## 实例演算

一款用于中度焦虑症的CBT应用，对比面对面治疗的等候名单，按每名患者计算：

```
成本：应用许可+支持费用              £250
     被替代的治疗费用                −£680   （40%的用户不再需要面对面治疗）
     ΔC = 250 − 680 = −£430（节省了成本）

QALY：候诊期间效用值从0.68提升为0.76，持续6个月
     ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALY
```

ΔC < 0 且 ΔE > 0：该应用属于**占优方案**——既更好又更便宜，无需再计算比值。若"治疗替代率"这一假设仅为10%，则ΔC = 250 − 170 = +£80，此时ICUR = 80 / 0.04 = **每QALY £2,000**——仍远低于£20,000。即便将这一关键假设大幅削弱，该论证依然成立：这正是一份稳健的成本效用分析应有的样子（[龙卷风图](../敏感性分析/)可以证明这一点）。

## 与软件工程的联系

成本效用分析背后的深层理念——*用一个复合的、经偏好加权的单一单位，来比较彼此不同的事物*——正是比较不同类型工程投资（安全性 对比 开发者体验 对比 可靠性）时所需要的模式。诚实的选择要么是一个站得住脚的复合单位（罕见），要么是一份明确的[成本后果表](../成本后果分析/)（更常见）。成本效用分析所警示的，是那种虚假的复合指标：一个"影响力评分"，其权重是在结果出来之后才被反向调整、以确保偏好的方案胜出。健康经济学花了数十年时间将效用值的获取方法标准化，正是为了确保权重的确定必须先于比较本身。

## 陷阱

- **效用增益低于量表工具的灵敏度**（参见[患者报告结果](../患者报告结果/)中的最小临床重要差异概念）——用一个微小的ΔE乘以一个庞大的人群规模，是一种经典的"洗数据"手法。
- **遗漏对照护理的替代效应**——对数字化产品而言，最大的成本项往往正是它们所取代的东西。
- **将非偏好量表得分映射为效用值**，却使用了未经验证的换算方法。
