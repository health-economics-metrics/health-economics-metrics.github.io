# 筛查经济学 (Screening Economics)

筛查经济学研究的是对无症状人群进行检测的价值。其核心数学事实是：**在疾病患病率较低时，即便是优秀的检测方法，产生的也大多是假阳性**——追查这些假阳性的下游成本，可能会淹没真阳性发现所带来的收益。

## 为什么重要

自 1968 年以来，WHO 的 Wilson-Jungner 标准一直为人群筛查设定了门槛：该疾病必须重要、检测方法必须可被接受且准确、必须存在有效的治疗手段，且经济账必须算得平衡。英国国家筛查委员会（UK National Screening Committee）在批准任何全国性项目之前都会应用正式的成本效益分析——并且否决了大多数提案。每一个"AI 将为所有人筛查一切疾病"的方案设想，都会撞上这套机制，而且通常会输给下面这套算术。

## 计算方法

阳性预测值（PPV）——即阳性结果真实为病例的概率——在患病率较低时会急剧崩塌：

```
PPV = (敏感性 × 患病率) / [敏感性 × 患病率 + (1 − 特异性) × (1 − 患病率)]

示例：敏感性 90%，特异性 95%，患病率 0.5%：
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

十二个阳性结果中有十一个是假的。完整项目经济学：

```
每发现一例真病例的成本 = (筛查成本 + 检查成本 × 全部阳性人数) / 真阳性人数
然后追问：发现这样一例病例是否值这个价钱？（每例的早期介入价值，
      减去过度诊断的危害——那些即便发现了也本不会造成影响的病例）
```

## 实例计算

针对某罕见病症的 AI 视网膜筛查，10 万人，患病率 0.5%，敏感性 90%，特异性 95%，扫描费 £15，确诊检查费 £400：

```
真阳性：  100,000 × 0.005 × 0.90 = 450
假阳性：  100,000 × 0.995 × 0.05 = 4,975
成本 = 100,000 × 15 + (450 + 4,975) × 400 = 150 万 + 217 万 = £367 万
每例真病例成本 ≈ £8,156
```

如果早期治疗每例可节省 £20,000 并获得 1 个 QALY，该项目轻松过关。若将特异性提高到 99%（减少假警报）：检查成本降至 (450 + 995) × 400 = £58 万，总成本 £208 万，每例成本 ≈ **£4,622**——在患病率较低时，筛查经济学的胜负手在于特异性，而非敏感性。

## 与软件工程的关联

静态分析、安全扫描和异常检测，本质上是针对代码库和遥测数据的筛查项目，真实缺陷的患病率往往每次警报机会都远低于 1%。同样的算术解释了警报疲劳：一个特异性为 95% 的扫描器在低患病率代码上运行，会让团队淹没在假阳性中，而每一次假阳性都会消耗注意力、侵蚀信任，直到真正的警报也被忽视（临床术语是*筛查伤害*；工程术语是"寻呼机麻木"）。相应的解决方法可以从医疗领域直接迁移：先提高特异性，再考虑敏感性；对患病率更高的子群体进行筛查（基于风险的定向筛查 ↔ 仅扫描变更代码）；并将分诊成本计入工具的经济学模型——参见[必须治疗数（NNT）](../需要治疗人数/)和[临床 AI 评估](../临床-ai-评估/)。 关于整个筛查项目（而不是单个检验）的规模，见[需要筛查人数](../需要筛查人数/)——要有多少人走完整个筛查再治疗的路径才能预防一例结局。

## 常见陷阱

- **只引用敏感性/特异性而不给出患病率**——脱离 PPV 谈准确性，只是营销话术。
- **忽视过度诊断**：发现那些本不会造成伤害的"惰性疾病"，会引发真实的治疗成本和危害。
- **提前期偏倚（lead-time bias）**：更早发现但结局未改变，会人为夸大表观生存率——参见[更早介入](../更早干预/)。
