# निवेश पर प्रतिफल (ROI)

ROI निवेशित धन के लिए शुद्ध लाभ का अनुपात है। यह एक ऐसा मीट्रिक है जिसे इंजीनियरिंग और वित्त पहले से साझा करते हैं — स्वास्थ्य अर्थशास्त्र वह अनुशासन जोड़ता है जो एक ROI दावे को जाँच में टिकाए रखता है।

## यह क्यों महत्वपूर्ण है

ROI बजट धारकों की सामान्य भाषा है। Masters et al. समीक्षा ने सार्वजनिक स्वास्थ्य हस्तक्षेपों के लिए **माध्यिका ROI 14.3:1** पाया। लेकिन वह 14:1 एक *सामाजिक, दीर्घ-क्षितिज* आंकड़ा है।

## गणित

```
ROI = (लाभ − लागत) / लागत

एक ROI दावा चार घोषणाओं के बिना अधूरा है:
1. परिप्रेक्ष्य
2. तुलनाकर्ता
3. क्षितिज
4. लाभ वर्ग
```

## हल किया गया उदाहरण

ई-रोस्टरिंग प्रणाली, 3 वर्षों में £500,000 लागत:

```
कठोर वित्तीय ROI = −10%
आर्थिक ROI       = +110%
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

हर टूलिंग प्रस्ताव में एक ROI स्लाइड होती है; लगभग कोई भी चार पैरामीटर घोषित नहीं करता।
