# EQ-5D

EQ-5D হলো স্বাস্থ্য-সম্পর্কিত জীবনযাত্রার মান পরিমাপের জন্য EuroQol গ্রুপের প্রমিত প্রশ্নপত্র। এটি সেই যন্ত্র যা বেশিরভাগ [QALY](../quality-adjusted-life-year/) গণনার মধ্যে উপযোগিতা ওজন তৈরি করে — NICE-এর রেফারেন্স কেস একে প্রাপ্তবয়স্কদের জন্য পছন্দের পরিমাপ হিসেবে উল্লেখ করে।

## কেন এটি গুরুত্বপূর্ণ

QALY দাবি করতে চাওয়া যেকোনো ডিজিটাল স্বাস্থ্য পণ্যের একটি যাচাইকৃত যন্ত্র থেকে উপযোগিতা প্রয়োজন, এবং EQ-5D যুক্তরাজ্য এবং ইউরোপের অধিকাংশ স্থানে ডিফল্ট। এটি একটি অ্যাপে যুক্ত করার মতো যথেষ্ট সংক্ষিপ্ত (৫টি প্রশ্ন + একটি ভিজ্যুয়াল স্কেল), যার অর্থ সফটওয়্যার পণ্যগুলো স্বাভাবিক ব্যবহারের একটি উপজাত হিসেবে HTA-গ্রেড ফলাফল তথ্য সংগ্রহ করতে পারে — ওষুধের তুলনায় একটি কাঠামোগত সুবিধা, যাদের জন্য নিবেদিত গবেষণা প্রয়োজন।

## গণিত

EQ-5D-5L **৫টি মাত্রায়** একটি করে প্রশ্ন জিজ্ঞাসা করে — চলাফেরা, নিজের যত্ন, স্বাভাবিক কার্যক্রম, ব্যথা/অস্বস্তি, উদ্বেগ/বিষণ্নতা — প্রতিটির **৫টি স্তরে** উত্তর (কোনো সমস্যা নেই … চরম সমস্যা), প্লাস একটি ০–১০০ ভিজ্যুয়াল অ্যানালগ স্কেল (EQ VAS)।

```
স্বাস্থ্য অবস্থা = ৫-অঙ্কের প্রোফাইল, যেমন "21221"
উপযোগিতা সূচক = মান_সেট(প্রোফাইল)

মান সেট দেশ-নির্দিষ্ট, সাধারণ জনগণের সময়-বিনিময় /
বিচ্ছিন্ন-পছন্দ জরিপ থেকে প্রাপ্ত। ভিত্তি: 1 = সম্পূর্ণ সুস্থতা,
0 = মৃত; মৃত্যুর চেয়ে খারাপ অবস্থা নেতিবাচক (UK 3L সেট নিম্নসীমা: −0.594)।
```

QALY গণনা তারপর `সময়কাল × উপযোগিতা` হিসেবে এগোয়।

## সমাধানকৃত উদাহরণ

একটি পেশীবহুল পুনর্বাসন অ্যাপ ১,০০০ সম্পূর্ণকারী ব্যবহারকারীর জন্য অন্তর্ভুক্তির সময় এবং ৬ মাস পরে EQ-5D-5L পরিমাপ করে।

```
বেসলাইনে গড় উপযোগিতা:  0.62
৬ মাসে গড় উপযোগিতা:    0.71
১ বছর ধরে (ধরে নেওয়া) স্থায়ী লাভ: (0.71 − 0.62) × 1.0 = প্রতি ব্যবহারকারী 0.09 QALY
```

একটি নিয়ন্ত্রণ-গ্রুপ পরিবর্তন ০.০৩ (স্বাভাবিক পুনরুদ্ধার)-এর বিপরীতে, দায়যোগ্য লাভ হলো ০.০৬ QALY/ব্যবহারকারী। £২০,০০০–£৩০,০০০/QALY-তে অর্থমূল্যে: **প্রতি সম্পূর্ণকারী ব্যবহারকারীর £১,২০০–£১,৮০০ স্বাস্থ্য মূল্য** — এই সংখ্যাটি একটি প্রদানকারীর সাথে অ্যাপের মূল্য আলোচনার ভিত্তি তৈরি করে।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

- **এটি যন্ত্রায়ন করুন।** নিবন্ধনে এবং ফলোআপ ব্যবধানে EQ-5D কয়েকটি স্ক্রিনের UI মাত্র; প্রতিদান হলো HTA-গ্রেড প্রমাণ। EuroQol থেকে লাইসেন্স নিন (প্রয়োজনীয়, কিছু ব্যবহারের জন্য বিনামূল্যে)।
- স্থাপনার দেশের জন্য **সঠিক মান সেট ব্যবহার করুন** — একই উত্তর যুক্তরাজ্য বনাম জার্মানি বনাম জাপানে ভিন্নভাবে স্কোর করে।
- **নকশার শিক্ষা**: EQ-5D দেখায় কীভাবে একটি ছোট প্রমিত জরিপ এবং একটি প্রকাশিত স্কোরিং ফাংশন একটি তুলনাযোগ্য একক সূচক দেয়। এটি যেকোনো বিশ্বাসযোগ্য ডেভেলপার-অভিজ্ঞতা সূচকের জন্যও একই প্যাটার্ন। [SPACE এবং DevEx](../space-and-devex/) দেখুন।

## ঝুঁকিপূর্ণ দিক

- **তুলনাকারী ছাড়া আগে/পরে** — গড়ের দিকে প্রত্যাবর্তন এবং স্বাভাবিক পুনরুদ্ধার সরল লাভকে বাড়িয়ে দেখায়।
- **টিকে থাকা পক্ষপাত**: শুধুমাত্র যারা সম্পৃক্ত থেকেছে তাদের পরিমাপ করা ([ধরে রাখা এবং ছাড়া](../retention-and-churn/) দেখুন)।
- **গবেষণায় 3L এবং 5L সংস্করণ বা মান সেট মিশ্রিত করা** — পদ্ধতিগতভাবে ভিন্ন সংখ্যা।
- হালকাভাবে প্রভাবিত জনগোষ্ঠীতে **সিলিং প্রভাব**: অনেক ব্যবহারকারী বেসলাইনে ১.০-এর কাছাকাছি স্কোর করে, লাভ প্রদর্শনের কোনো জায়গা না রেখে।
- **একটি মান সেটকে স্ব-ন্যায্যতাপ্রাপ্ত হিসেবে বিবেচনা করা**: একটি মান সেট যে উপযোগিতা সংখ্যা ফেরত দেয় তা নিজেই সময়-বিনিময় (বা সম্পর্কিত পছন্দ-ভিত্তিক) জরিপের মাধ্যমে জনসাধারণ থেকে সংগ্রহ করা হয়েছিল।
