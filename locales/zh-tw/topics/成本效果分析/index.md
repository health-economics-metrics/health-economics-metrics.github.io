# 成本效果分析（CEA）

成本效果分析比較各替代介入方案的成本，其結果均以同一種**自然單位**衡量——生命年、檢出病例數、避免的住院數、血壓降低的mmHg數。其輸出結果是"每單位結果的成本"。

## 為何重要

當所有備選方案針對同一結果時，成本效果分析是最常用的比較方法。它回答的是"在實現X這一目標的諸多方式中，哪一種最能物盡其用？"——但*不能*回答"X這個目標本身是否值得追求？"（這需要[成本效益分析](../成本效益分析/)），也*不能*回答"X與其他不相關的優先事項相比如何？"（這需要[成本效用分析](../成本效用分析/)以及像QALY這樣的通用結果指標）。

## 計算方法

用於比較的統計量是以自然單位表示的[ICER](../增量成本效果比/)：

```
ICER = (成本_A − 成本_B) / (效果_A − 效果_B)
     = 每多檢出一例/每避免一次入院/等等所需的£成本
```

操作步驟：先定義結果計量單位；在相同的[視角](../分析視角/)、相同的[時間範圍](../時間範圍/)下，為每一個方案核算成本；剔除被佔優的方案（參見[效率前沿](../佔優關係與效率前沿/)）；沿著前沿計算增量比值。

## 實例演算

在一個10萬人的群體中，發現未確診心房顫動的三種方式：

```
方案                       成本         發現病例數
機會性脈搏檢測              £150,000        300
藥房篩查活動                £400,000        520
可穿戴裝置篩查               £900,000        610

藥房方案 相對 脈搏檢測方案的ICER： (400,000−150,000)/(520−300) = 每多發現一例£1,136
可穿戴方案 相對 藥房方案的ICER：   (900,000−400,000)/(610−520) = 每多發現一例£5,556
```

每多發現一例花費£5,556是否"值得"，取決於每發現一例所帶來的價值（下游的中風預防收益）——成本效果分析可以對方案進行排序，但採納決策仍需依賴那個外部的價值判斷。請注意，可穿戴裝置方案的*平均*每例成本（900,000/610 = £1,475）看起來還不錯；而*增量*成本£5,556，才是用於擴容決策的誠實數位。

## 與軟體工程的聯絡

只要各方案共享同一個結果指標，成本效果分析就是恰當的模板：三種補救方法下每消除一個不穩定測試的成本；不同可觀測性供應商下每避免一次事件的成本；不同CI架構下每次成功部署的成本。它所強制推行的紀律——明確設定一個結果計量單位、使用增量（而非平均）比值、先剔除被佔優的方案——能在定價討論開始之前，就扼殺掉大多數糟糕的供應商比較。

## 陷阱

- **在同一次成本效果分析中比較結果指標不同的方案**（例如"發現病例數"對比"滿意度"）——這需要[成本後果分析](../成本後果分析/)，或者一個通用的結果指標。
- **在本應使用增量比值的場合呈現平均成本效果比**（如上文可穿戴裝置的例子）。
- **為博取好感而挑選結果計量單位**："產生的警報數"是一種產出，而非一種結果；應堅持使用真正承載價值的計量單位。
