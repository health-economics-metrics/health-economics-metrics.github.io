# 質調整生存年(QALY)

QALYとは、完全な健康状態で生きた1年のことです。人々が*どれだけ長く*生きるかと*どれだけ良く*生きるかを組み合わせるため、不健康な状態での1年は1QALY未満として数えられます — これにより、まったく異なる医療介入を単一の尺度で比較できるようになります。

## なぜ重要か

QALYは医療技術評価の共通通貨です。NICE(イングランド)は健康の獲得を**1QALYあたり£20,000〜£30,000**と評価します:この閾値よりも安くQALYを得られる介入は通常推奨され、それより高くつく介入は通常却下されます。この単一の数値によって、国の医療サービスは、がん治療薬、股関節置換術、トリアージアプリを同じ軸上で比較できます。あなたのソフトウェアが、悪化の防止、治療の迅速化、安全性の向上によって信頼できる形でQALYを主張できるなら、その健康価値を医療そのものと同じ通貨で値付けできます。

## 数式

```
QALY = Σ_i (期間_i × 効用_i)

期間_i = 健康状態iで過ごした年数
効用_i = 状態iの質の重み、1 = 完全な健康、0 = 死亡を基準とする
        (死よりも悪い状態には負の値が許容される)
```

効用の重みは、最も一般的には[EQ-5D](../eq-5d/)などの検証済みの測定手法から得られます。介入によるQALYの*獲得*は、その介入がある場合とない場合のQALYの流れの差であり、NICEの基準ケースでは年3.5%で[割引](../discounting-and-time-preference/)されます。

## 計算例

ある患者が効用0.6の状態で心臓治療を待っています。治療により効用0.85まで回復します。

- **今すぐ治療した場合**:今年1年間0.85 = 今年0.85QALY。
- **6か月遅れて治療した場合**:0.5 × 0.6 + 0.5 × 0.85 = 0.725QALY。
- **遅延による患者1人あたりのQALY損失**:0.85 − 0.725 = **0.125QALY**。

NICEの閾値で金銭化すると:0.125 × £20,000〜£30,000 = **6か月の遅延1回につき、患者1人あたり£2,500〜£3,750の健康価値の損失**。もし経路を迅速化するソフトウェアが年間400人の患者についてこの遅延を取り除くなら、健康価値は50QALY ≈ **年間£100万〜£150万** — 運用上の節約を数える前の数値です。

## ソフトウェア工学との関連

- **経路が速くなる = QALYが早く得られる。** [紹介から治療まで](../referral-to-treatment/)を短縮するものは何であれ、待ち時間の不効用を健康の獲得に変換し、上記のように評価できます。
- **安全性 = 保たれたQALY。** 防がれた投薬ミスや見逃された診断は、回避されたQALY損失です。
- **QALYはメトリクス設計のテンプレートでもあります**:量×質の複合指標で、質の重みは標準化された測定手法から得られます。「質調整エンジニア年」(時間×DevEx調査の重み)も同じ構成です — [SPACEとDevEx](../space-and-devex/)を参照してください。
- QALYをビジネスケースのためのお金に変えるには[正味金銭的便益](../net-monetary-benefit/)を、意思決定に変えるには[支払意思額の閾値](../willingness-to-pay-thresholds/)を使ってください。

## 落とし穴

- **効用の重みをでっち上げること。** 重みは、直感ではなく検証済みの測定手法(EQ-5D)と公表された価値セットから得なければなりません。
- **因果経路のないQALYの主張。** 「私たちのアプリはウェルビーイングを改善する」はQALYの主張ではありません;「効用0.6の状態での待機をX週間取り除く」はQALYの主張です。
- **二重計上**:同じ回避された悪化について、QALYの獲得と費用の節約の両方を主張するには、それらが本当に別物であることを慎重に確認する必要があります。
- **公平性の盲点**:QALYは生存年の延長をベースラインの効用で評価するため、障害のある人々を不利にすることがあります — これが、ICER(米国)がevLYGも報告する理由です([獲得生存年](../life-years-gained/)を参照)。
