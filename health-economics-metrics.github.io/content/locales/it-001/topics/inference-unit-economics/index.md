# Economia Unitaria dell'Inferenza

L'economia unitaria dell'inferenza fissa il prezzo delle funzionalità IA in base al loro calcolo marginale: **costo per token**.

## Perché è importante

Due conseguenze seguono dal crollo dei prezzi.

## La matematica

```
Costo per chiamata = token di input × tariffa di input + token di output × tariffa di output
```

## Esempio risolto

Un servizio IA di riepilogo delle dimissioni: ≈$0,077 per riepilogo → ≈$7.700 per 100.000 riepiloghi/anno.
