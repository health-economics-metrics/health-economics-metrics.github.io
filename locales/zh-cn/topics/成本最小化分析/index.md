# 成本最小化分析 (Cost-Minimization Analysis，CMA)

CMA 只比较成本，并选择最便宜的方案——这种做法*仅在*各备选方案的结果已被证明等效时才成立。

## 为什么重要

CMA 是最简单的分析方法，也是最容易被滥用的方法。"等效"这一主张承担了全部论证责任：如果结果确实没有差异（生物类似药与原研药之间；满足相同规格的两家同类服务供应商之间），那么成本就是唯一的问题，CMA 是正确的。真正的严谨性在于*先证明*等效——通常通过一项设定了预先规定边界值的非劣效性研究——而这恰恰是采购方通常会跳过的一步。

## 计算方法

```
若已有证据表明 效果_A ≈ 效果_B（在预先设定的边界值 δ 之内）：
选择 min(成本_A, 成本_B)

成本须以相同视角、相同周期计量，
并包含转换/过渡成本。
```

如果无法用证据证明等效，CMA 就不成立——应改用 [CEA](../成本效果分析/)/[CUA](../成本效用分析/)。

## 算例

某信托机构在两个视频问诊平台之间做选择。一项为期 3 个月的平行试点显示：完成率分别为 94.1% 与 93.8%，患者满意度均为 4.4——差异都在事先约定的 δ = 2 个百分点之内。结果：等效。3 年成本如下：

```
                     平台 A         平台 B
许可费                £360,000       £210,000
集成                  £80,000        £150,000
培训/支持              £60,000        £90,000
合计                  £500,000       £450,000
```

平台 B 以 £50,000 之差胜出——这*已经包含*了它更高的集成成本。如果没有这次试点，等效性的主张就只能依赖供应商的宣传册，而一个 1 个百分点的完成率差异（每年约相当于数千次失败的问诊）就足以远远超过 £50,000。

## 与软件工程的关联

CMA 是大宗商品式采购的正式形态：两家满足相同 SLO 的 CI 供应商，两个具有相同持久性规格的对象存储服务。这里的卫生经济学教训在于*操作顺序*：先用证据证明等效（针对你自己的工作负载做基准测试，针对你自己的 SLO 做试点，边界值须事先约定），再比较包含迁移成本在内的总成本。跳过第一步、直接得出"它们基本一样，B 更便宜"的结论，正是组织买到"便宜 10%、但差 40%"那款工具的原因。推论：当供应商以价格作为论据时，要求他们同样明确承诺等效性——这个约束对双方都适用。

## 陷阱

- **假定等效**——这是最典型的错误；没有证据证明存在差异，并不等于有证据证明等效（功效不足的试点会"免费"地"证明"等效）。
- **遗漏转换成本**——迁移、再培训和并行运行都应计入成本一侧。
- **在错误的结果上等效**：在被测量的指标上等效，但在某个真正重要的指标上（可及性、尾部延迟、数据出口）却存在差异。
