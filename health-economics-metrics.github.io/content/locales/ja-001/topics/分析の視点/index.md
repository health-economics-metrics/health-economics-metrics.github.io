# 分析の視点

視点とは、経済分析において*誰の*費用と便益を数えるかを定義するものです:支払者、提供者、あるいは社会全体。同じ介入でも、ある視点からは素晴らしく見え、別の視点からはひどく見えることがあります。

## なぜ重要か

あらゆる経済評価は、視点をあらかじめ明示しなければなりません。なぜなら、視点によってどの項目が存在するかが決まるからです:

- **支払者の視点**(例:NHSのコミッショナー、保険者):支払者が償還する費用のみ。
- **提供者の視点**(例:病院トラスト):内部の提供コスト、人件費、施設。
- **社会的視点**:患者の時間、移動、家族によるインフォーマルケア、雇用主にとっての生産性損失を含む、すべて。

NICEの基準ケースは、費用について**NHSおよび対人社会サービス(PSS)**の視点を用います。米国の第2次費用効果パネルは、含まれるものを一覧にした「インパクト・インベントリ」とともに、医療部門の分析と社会的分析の両方を報告することを推奨しています。

## 数式

公式はありません — 計算の前に適用される範囲設定のルールです:

```
含まれる費用/便益のカテゴリー = f(視点)
```

有用な確認方法として、費用/便益ごとに1行、視点ごとに1列のインパクト・インベントリ表を作成し、どのセルが数えられるかを示すという方法があります。

## 計算例

症状チェッカーアプリが、年間1万件のGP(かかりつけ医)受診をセルフケアへ振り向けたとします。

- **支払者(NHS)**:10,000 × £42(GP受診1件あたり)の節約 = **£420,000/年** — 強く正の効果。
- **提供者(GP診療所)**:診療所が人頭払いで支払われている場合、収入は変わらないが業務量は減る — 軽度に正の効果。
- **社会的**:患者の節約された移動時間と待ち時間を加える。10,000 × 2時間 × £15/時間 = £300,000の時間価値。ただし、2%が誤って安心させられ、後により重症化して受診した場合、200 × £3,000 = £600,000の追加治療という害を差し引く。社会的な正味:420,000 + 300,000 − 600,000 = **£120,000/年** — 正の効果だが、安全性の前提に大きく左右される。

同じアプリで、3つの異なる答え。視点を明示することこそが、数値を比較可能で誠実なものにします。

## ソフトウェア工学との関連

ツールやプラットフォームのROIにも視点があります:

- **チームの予算(「支払者」)**:ライセンス料は自分のコストセンターに収まるか?
- **プラットフォーム組織(「提供者」)**:統合、サポート、保守を含めた総コスト。
- **会社(「社会的」)**:顧客への影響、セキュリティの外部性、影響を受けるすべてのチームの時間を含める。

購入するチームにとっては安価だが、移行作業を他の40チームに押し付けるCIツールは、コスト転嫁のソフトウェア版です — より広い視点からのみ見えるものです。すべてのビジネスケースで視点を明示してください。レビュアーは見えない前提には異議を唱えられません。

## 落とし穴

- **視点の暗黙の切り替え**:社会的便益は数えるが支払者の費用しか数えないと、何でも費用効果的に見えてしまいます。
- **視点を混ぜたときの二重計上**(例:支払者側の数値にすでに人件費が含まれているのに、節約されたGP受診を支払者の節約と患者の時間節約の両方として数える)。
- **コスト転嫁を無視する**:患者、介護者、あるいは他の部署にコストを移すだけの「節約」。
