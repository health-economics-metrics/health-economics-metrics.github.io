# 費用最小化分析(CMA)

CMAは費用のみを比較し、最も安い選択肢を選びます — これは代替案のアウトカムが同等であることが証明されている場合*にのみ*正当です。

## なぜ重要か

CMAは最もシンプルな分析であり、最も乱用されているものでもあります。同等性の主張がすべての鍵を握ります:もしアウトカムが本当に変わらないなら(バイオシミラーとその先発品;同じ仕様を満たす同じサービスの2つの供給業者)、費用だけが問題であり、CMAは正しい手法です。厳密さは、まず同等性を*証明する*ことにあります — 典型的には事前に指定されたマージンを用いた非劣性試験によってですが、これはまさに購入者が通常省略するステップです。

## 数式

```
効果_A ≈ 効果_B(事前に指定されたマージンδ以内)という証拠がある場合:
min(費用_A, 費用_B) を選ぶ

費用は同じ視点から、同じ評価期間にわたって測定され、
切り替え/移行費用を含む。
```

同等性が証拠づけられない場合、CMAは無効です — 代わりに[CEA](../費用効果分析/)/[CUA](../費用効用分析/)を使ってください。

## 計算例

あるトラストが2つのビデオ相談プラットフォームの間で選択します。3か月の並行パイロット試験は、完了率94.1% 対 93.8%、患者満足度4.4 対 4.4を示します — これらの差は、事前に合意されたδ2パーセントポイント以内です。アウトカム:同等。3年間の費用:

```
                     プラットフォームA  プラットフォームB
ライセンス           £360,000           £210,000
統合                 £80,000            £150,000
トレーニング/サポート £60,000            £90,000
合計                 £500,000           £450,000
```

プラットフォームBが£50,000の差で勝ちます — その高い統合費用を*含めても*です。パイロット試験がなければ、同等性の主張はベンダーのパンフレットに依存することになり、1ポイントの完了率の差(≈年間数千件の失敗した相談)は£50,000をはるかに上回ってしまうでしょう。

## ソフトウェア工学との関連

CMAはコモディティ調達の正式な形です:同一のSLOを満たす2つのCIプロバイダー、同じ耐久性仕様を持つ2つのオブジェクトストレージ。医療経済学の教訓は*操作の順序*です:まず同等性を証拠づけ(自分たちのワークロードに対してベンチマークし、事前に合意されたマージンで自分たちのSLOに対してパイロットし)、その後、移行を含めた総費用を比較します。最初のステップを踏まずに「基本的に同じで、Bの方が安い」と言うことが、組織が10%安くて40%悪いツールを買ってしまう理由です。系論:ベンダーが価格を主張するときは、同等性を明記させてください — それは逆方向にも拘束力を持ちます。

## 落とし穴

- **想定された同等性** — 決定的な過ちです;差の証拠がないことは同等性の証拠ではありません(検出力の低いパイロット試験は無料で同等性を「示して」しまいます)。
- **切り替え費用の省略** — 移行、再トレーニング、並行運用は費用側に属します。
- **誤ったアウトカムでの同等性**:測定された指標では同等でも、重要な何か(アクセシビリティ、テールレイテンシ、データ流出)では異なる。
