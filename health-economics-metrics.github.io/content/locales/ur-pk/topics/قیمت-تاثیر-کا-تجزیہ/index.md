# قیمت-تاثیر کا تجزیہ (CEA)

CEA متبادل مداخلتوں کی قیمتوں کا موازنہ **قدرتی اکائیوں** میں ماپے گئے ایک نتیجے کے خلاف کرتا ہے۔

## یہ کیوں اہم ہے

CEA اہم موازنہ ہے جب تمام آپشنز ایک ہی نتیجے کو ہدف بناتے ہیں۔

## ریاضی

```
ICER = (قیمت_A − قیمت_B) / (اثر_A − اثر_B)
```

## حل شدہ مثال

100,000 کی آبادی میں غیر تشخیص شدہ ایٹریل فبریلیشن تلاش کرنے کے تین طریقے۔

## سافٹ ویئر انجینئرنگ سے تعلق

CEA صحیح ٹیمپلیٹ ہے جب بھی آپشنز ایک نتیجہ شیئر کرتے ہیں۔

## عام غلطیاں

- **ایک CEA میں مختلف نتائج والے آپشنز کا موازنہ کرنا۔**
