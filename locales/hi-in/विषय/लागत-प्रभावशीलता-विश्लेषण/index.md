# लागत-प्रभावशीलता विश्लेषण (CEA)

CEA वैकल्पिक हस्तक्षेपों की लागतों की तुलना **प्राकृतिक इकाइयों** में मापे गए एक परिणाम के विरुद्ध करता है — जीवन-वर्ष, पहचाने गए मामले, बचाए गए प्रवेश।

## यह क्यों महत्वपूर्ण है

CEA मुख्य तुलना है जब सभी विकल्प एक ही परिणाम को लक्षित करते हैं। यह "इनमें से कौन सा तरीका X प्राप्त करने के लिए पैसे का सबसे अच्छा उपयोग है?" का उत्तर देता है।

## गणित

```
ICER = (लागत_A − लागत_B) / (प्रभाव_A − प्रभाव_B)
```

## हल किया गया उदाहरण

100,000 की जनसंख्या में अनिर्धारित अलिंद फिब्रिलेशन खोजने के तीन तरीके:

```
विकल्प                    लागत        पाए गए मामले
अवसरवादी नाड़ी जाँच        £150,000    300
फार्मेसी स्क्रीनिंग        £400,000    520
पहनने योग्य-आधारित स्क्रीनिंग £900,000  610
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

CEA सही टेम्पलेट है जब भी विकल्प एक परिणाम साझा करते हैं।

## सामान्य गलतियाँ

- एक CEA में **अलग-अलग परिणामों वाले विकल्पों की तुलना करना।**
- **औसत लागत-प्रभावशीलता अनुपात** जहाँ वृद्धिशील की आवश्यकता है।
