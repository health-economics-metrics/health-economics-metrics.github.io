# 卫生技术评估 (Health Technology Assessment，HTA)

HTA是卫生系统据以决定一项技术——药品、器械或软件——是否值得付费购买的正式化、制度化流程。它把临床有效性证据与经济学评估结合在一套已公开、强制执行的方法论之下。

## 为什么重要

如果你的产品面向国家卫生服务体系销售，HTA机构很可能直接决定你的市场准入。了解当地的流程，就是了解你真正的"价值监管者"：

- **NICE（英格兰）**：依据既定的*参考案例*进行法定评估——效用值来自[EQ-5D](../eq-5d/)，采用NHS+PSS[视角](../分析视角/)，按3.5%[贴现](../贴现与时间偏好/)，须提供[PSA](../概率敏感性分析/)——按每QALY £20,000–£30,000的阈值判断，并可应用[严重程度修正系数](../qaly-短缺与严重程度修正系数/)；高度专科化技术在加权后阈值可达£100,000以上。
- **ICER（美国，非政府机构）**：出具证据报告，给出一个*健康效益价格基准*——即按每QALY/evLYG $100,000–$150,000计算，产品若定价在此水平即为具有成本效果——用作谈判筹码；并附带预算影响的"可负担性警示"。
- **加拿大（CADTH → CDA-AMC）**：报销审查大致以每QALY约CAD$50,000为标准；历史上约95%的申报都被要求降价。

## 计算方法

HTA的威力不在于一个公式，而在于一套**强制性的方法**：每一份申报都必须依据同一套参考案例规则计算同一个[ICER](../增量成本效果比/)，从而使结果在不同产品、不同年份之间可以比较。参考案例规定了结果测量方式、效用测量工具、视角、对照选择、贴现率、时间跨度以及不确定性分析——消除了申报方可以钻营取巧的每一个自由度。

## 算例

一款数字疗法按NICE式评估方式申报：

```
模型：ΔC = +£450/患者，ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ 低于£20k
参考案例检查项：
  效用值来自EQ-5D-5L英国值集                    ✓
  对照组 = 当前诊疗路径（而非"不治疗"）          ✓
  PSA：在£20k处具有成本效果的概率为71%           ✓（已报告）
  严重程度修正系数：缺口低于×1.2的界限           —— 未主张适用
建议：纳入常规使用，并要求收集真实世界数据。
```

申报方自己首选的分析结果原本是£9,000/QALY；参考案例通过强制采用诚实的对照组，将其推高到£15,000。这一差距正*是*参考案例存在的原因。

## 与软件工程的关联

可迁移的成果是**内部参考案例**这一模式：为所有工具/平台类商业论证设定同一套强制方法——声明对照组、标准单位成本（参见[国家统一收费标准与单位成本](../国家统一收费标准与单位成本/)一文了解此模式）、固定贴现率、必需的敏感性分析、标准模板。向平台委员会提交一份"面向工具的AMCP档案"，能让各项提案彼此可比、让钻营取巧无所遁形——正如HTA之于药品一样。起步不必做到NICE那种规模：一份两页的模板加一本已公开的价格手册，胜过完全没有标准。

关于多周期 HTA 模型究竟如何逐队列、逐周期模拟，见[马尔可夫队列模拟](../马尔可夫队列模拟/)。

## 常见陷阱

- **把HTA当作获得监管许可之后的一道形式手续**——CE/UKCA/FDA许可只说明产品是安全的；HTA决定的是它是否*值得购买*。二者的门槛不同，所需证据也不同。
- **在试验结束后才搭建经济学模型**——证据生成工作理应从参考案例的要求出发、反向设计。
- **忽视司法辖区差异**：在美国以$120,000/QALY可获资助的ICER，在NICE的£30,000阈值下会失败；应按市场分别规划证据与定价策略。
