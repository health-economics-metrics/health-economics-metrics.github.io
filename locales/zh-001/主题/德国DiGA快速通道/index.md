# 德国DiGA快速通道

DiGA（Digitale Gesundheitsanwendungen，数字健康应用）是德国法定的"处方应用"通道——这是全球首个由医生开具处方、法定医保必须为已批准的健康应用报销费用的国家级制度。它是目前在全国规模上为数字疗法付费这一实践中最具代表性的现存实验。

## 为何重要

DiGA用立法（2019年的DVG法案）回答了每一家数字健康公司都会问的问题——"到底谁会真正付钱？"其制度设计颇为出色：

- **快速决策**：监管机构BfArM必须在3个月内作出决定。
- **临时挂网**：应用可以先临时挂网12个月，*同时继续生成证据*——在其关键研究期间即可获得收入。
- **证据截止期**：必须通过一项对照研究（通常是随机对照试验）证明其具有"积极的医疗效果"（医学获益，或对患者有意义的结构性/流程性改善），否则将被摘牌。约有一半的临时挂网应用未能成功转正。
- **定价**：厂商可自由设定第一年的价格；此后需与保险联合会协商定价。首个3个月周期的价格中位数约为500欧元；从2026年起将引入按结果付费的定价要素。

市场现实检验（截至2024年底的研究数据）：约68款应用已挂网，累计处方量超过100万份，约81%的处方被实际激活，保险方累计支出约2.34亿欧元——这是一个真实存在的市场，但相较于其所受到的热议而言规模仍属有限，且激活后的依从性仍是其薄弱环节。

## 计算方法

每一位DiGA创业者都会运行的商业模型：

```
收入 = 处方数 × 激活率 × 每个处方周期的价格
证据生成成本 = 在12个月窗口期内完成的关键随机对照试验（通常需要200万–300万欧元）
期望价值 = P(证据研究成功) × 稳态收入 − 证据生成成本

由于约有50%的转正失败率，P必须被诚实地评估——业界有一半的
企业花光了随机对照试验的经费，最终却失去了挂网资格。
```

## 实例演算

某抑郁症管理应用以每季度450欧元的价格临时挂网：

```
第1年：20,000份处方 × 81%激活率 × 450欧元 ≈ 730万欧元收入
随机对照试验成本：200万欧元，与经营同步进行
结果A（证据为阳性）：获得永久挂网资格，协商后价格约为380欧元，
  稳态下每年60,000份处方 ≈ 每年1,850万欧元
结果B（证据研究失败）：第12个月被摘牌；收入随之中止。
```

这一临时挂网年度，为证据生成本身提供了资金——这正是该通道最核心的创新之处。与之形成对比的是传统顺序（先有证据，收入数年后才到来），而这种传统顺序恰恰会活活饿死DiGA最希望存在的那类产品。

## 与软件工程的联系

DiGA的这一模式——**附带预先登记成功指标、并自动设定日落条款的临时采纳**——可以直接套用到工程工具的治理上：先将工具交付给生产环境用户使用12个月，预先登记好衡量指标（实测节省的时间、事件数量下降），若证据未能兑现则自动到期失效。这一机制解决了"试点悖论"（一个工具需要达到一定规模才能证明其价值，但从未真正获得那个规模）的问题，同时又不会给未经证实的技术授予永久的"终身教职"。81%激活率却依从性偏低这一数据，同样蕴含着一条产品层面的教训：处方（或高层强制指令）能带来安装量；只有产品本身的质量，才能带来持续使用——参见[依从性与持续性](../依从性与持续性/)。

## 陷阱

- **把"获得挂网资格"当作终点线**——处方需要开处方者的信任；许多已挂网的DiGA应用实际处方量微乎其微。
- **为了在营收年度节省开支，而使关键研究的功效不足**——这正是那50%失败率背后的假性节约。
- **照搬这一模式却没有对应的付费方**：DiGA之所以行得通，是因为报销是法定强制的；若没有强制付费机制而只照搬其形式，那不过是一个普通的试点项目。
