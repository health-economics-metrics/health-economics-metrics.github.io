# 获得的生命年（LYG）

获得的生命年，是指某项干预所带来的额外生存时间，不作任何质量调整：即"有该干预"与"无该干预"两条生存曲线之间的面积。等值获得生命年（evLYG）是一种现代变体，对所有延长的生命一视同仁地赋予相同价值。

## 为何重要

获得的生命年是最原始的健康结果指标：人们究竟多活了多久？在缺乏质量数据时、在面对对QALY持怀疑态度的受众时，以及在肿瘤学领域（生存曲线是主要的试验产出）中，这一指标都至关重要。**evLYG**（美国ICER研究所在每QALY成本之外同时采用的指标）的存在有其伦理学上的原因：QALY是按患者本人的效用值来衡量延长一年生命的价值，因此延长一名残障人士的生命，在计算上会"算得更少"——而evLYG则以固定效用值来衡量每一个被延长的年份，从而消除了这种歧视性。

## 计算方法

```
获得的生命年 = 新方案下的平均生存时间 − 对照方案下的平均生存时间
            = 生存曲线之间的面积（限定在所考察的时间范围内）

生命延长的QALY视角：   延长时间 × 患者本人的效用值
生命延长的evLYG视角：  延长时间 × 固定效用值（ICER采用约0.851，
                      即美国人群的平均效用值）
```

在经济学模型中，二者都需要进行[贴现](../贴现与时间偏好/)。

## 实例演算

某医院的脓毒症早期预警算法：建模显示，更早使用抗生素每年可预防12例死亡；这些患者的平均年龄意味着每人平均还剩8年生命，效用值为0.7。

```
获得的生命年 = 12 × 8            = 每年96个生命年
QALY        = 96 × 0.7          = 67.2
evLYG       = 96 × 0.851        = 81.7
```

按每QALY £20,000计算，QALY口径下这部分生存获益价值为每年£134万；而evLYG口径下则为£163万。这一差距，恰恰体现了"一个效用值为0.7的生命年，是否应算作一个'完整'生命年价值的70%"这一伦理判断本身。严谨的申报材料应同时报告这两种口径。

## 与软件工程的联系

- 生存分析是双方共用的工具箱：用于患者的Kaplan-Meier曲线，与用于*服务*的曲线（故障间隔时间、流失间隔时间）遵循同一套数学原理。某项可靠性投资带来的"获得的服务年数"= 该系统"有该投资"与"无该投资"两条生存曲线之间的面积——这比单点的平均故障间隔时间（MTTF）主张更为诚实。
- evLYG同样对工程领域的指标设计提出了警示：任何按"团队质量"因子对产出加权的生产力指标，都会系统性地低估那些资源受限或正在挣扎中的团队所取得的改进——有时你恰恰应当有意选择"等值"这一变体。

## 陷阱

- **中位数与均值生存时间的混淆**：经济学模型需要的是均值（即曲线下面积）；而试验结果通常以中位数作为头条数字呈现。在偏斜分布下，二者可能相差很大。
- **超出试验随访期的外推**，在慢性病建模中往往主导着"获得的生命年"这一数字——应明确说明所采用的外推模型，并在[敏感性分析](../敏感性分析/)中对其进行检验。
- **仅凭观察性的前后对比数据就主张预防了多少例死亡**，而未对病例组合与长期趋势做调整。
