# 增量成本效果比（ICER）

ICER是指当你选择某一方案而非次优替代方案时，每多获得一单位健康效果所需多付出的成本。它是卫生技术评估中最核心的头条数字。（当效果单位为QALY时，它也被称为增量成本效用比，ICUR。）

## 为何重要

卫生系统从不孤立地评估某项技术——而总是*相对增量地*，与本来会采取的替代方案相比较。NICE将某项技术的ICER与其**每QALY £20,000–£30,000**的阈值相比较；美国ICER研究所则在$50,000–$200,000/QALY的区间内报告；加拿大的工作标准大致为CAD$50,000/QALY。你的产品对一个国家医疗服务体系而言是否"值得"，形式上就等价于其ICER是否低于当地阈值。参见[支付意愿阈值](../支付意愿阈值/)。

## 计算方法

```
ICER = (成本_新方案 − 成本_对照方案) / (效果_新方案 − 效果_对照方案)
     = ΔC / ΔE
```

解读规则：

- ΔC < 0，ΔE > 0：新方案**占优**——既更便宜又更好；无需计算比值。
- ΔC > 0，ΔE > 0：计算ICER，与阈值λ比较；若ICER < λ则采纳。
- ΔC > 0，ΔE < 0：新方案被占优——应拒绝。
- 当ΔE接近0时，比值的表现会变得很不稳定——此时更适合使用[净货币效益](../净货币效益/)来排序。

对照方案必须是*次优、未被占优的方案*，而非"什么都不做"——参见[占优关系与效率前沿](../占优关系与效率前沿/)。

## 实例演算

某面向心力衰竭患者的远程监测服务，按每年1,000名患者计算，与常规照护相比：

```
成本：  服务£900,000；避免的入院节省£600,000
       ΔC = 900,000 − 600,000 = £300,000
效果：  更早干预获得25个QALY
       ΔE = 25

ICER = 300,000 / 25 = 每QALY £12,000
```

每QALY £12,000，明显低于NICE的£20,000阈值——是一个有力的论证案例。请注意*净*成本为何如此重要：如果没有那£600,000的冲抵，ICER将变为每QALY £36,000，该论证很可能就无法通过。成本冲抵项及其证据质量，正是这类分析成败的关键所在（参见[规避的下游成本](../规避的下游成本/)）。

## 与软件工程的联系

ICER这套纪律可以完整地迁移到工程决策中：

```
(方案B的成本 − 方案A的成本) / (方案B的结果 − 方案A的结果)
```

——每多一次部署的增量成本、每节省一个工程师-小时的增量成本、每避免一次事件的增量成本——始终是与次优替代方案相比较，而非与"什么都不做"相比较。这里有两个值得借鉴的习惯：(1) *明确指出对照方案*；大多数工具投资回报率的主张，实际上都在暗中与一个稻草人对照方案相比较；(2) *先对成本做净额计算*——一个成本£100,000、但能替代掉£80,000现有支出的工具，其ΔC实际上只有£20,000。

## 陷阱

- **对照方案操纵**：与一个过时或人为设定得很差的基线相比较，会虚增ΔE，从而美化ICER结果。
- **用平均值代替增量值**：一整个项目的每QALY成本，并不等同于扩展或采纳该项目的ICER。
- **迷信点估计**：ICER是两个本身就存在不确定性的差值之比；应通过[PSA与CEAC](../概率敏感性分析/)报告其不确定性。
- **负的ICER含义模糊**（"更便宜且更好"与"更贵且更差"两种情形会得出相同的符号）——报告负的ICER时，务必说明它究竟属于哪一象限。
- **在没有明确换算步骤的情况下跨币种比较 ICER**：以一国货币计算的 ICER，在与另一国阈值比较之前，必须用声明的方法换算——关于为什么换算系数的选择（购买力平价与市场汇率）本身就可能颠覆采纳决定，见[跨币种 ICER 比较](../跨币种-icer-比较/)。
