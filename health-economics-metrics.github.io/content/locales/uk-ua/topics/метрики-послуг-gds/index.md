# Метрики послуг GDS

Метрики послуг GDS (Government Digital Service) — це чотири ключові показники продуктивності цифрових державних послуг: задоволеність користувачів, рівень завершення, економія коштів та цифрове використання.

## Чому це важливо

Цифрові державні послуги повинні демонструвати результати платникам податків.

## Математика

```
Рівень завершення = завершені транзакції / розпочаті транзакції × 100%
```

## Розібраний приклад

Служба онлайн-реєстрації пацієнтів: розпочато 10 000, завершено 8200 = рівень завершення 82%.

## Зв'язок з інженерією програмного забезпечення

Разом з [реалізацією вигод](../реалізація-вигод/) обґрунтовує державні цифрові інвестиції.

## Підводні камені

- **Погляд лише на цифрове використання, ігноруючи витрати офлайн-каналів.**
