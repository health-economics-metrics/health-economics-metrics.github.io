# নিখুঁত তথ্যের প্রত্যাশিত মূল্য (ওসিপিআই)

ওসিপিআই হল সিদ্ধান্ত নেওয়ার আগে অনিশ্চয়তা দূর করতে একজন সিদ্ধান্ত গ্রহণকারীর সর্বোচ্চ পরিমাণ অর্থ প্রদান করা উচিত — "চলুন প্রথমে একটি অধ্যয়ন চালাই"-র আনুষ্ঠানিক মূল্য।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য ব্যবস্থাগুলি ক্রমাগত পছন্দের মুখোমুখি হয়: অসম্পূর্ণ প্রমাণে এখনই গ্রহণ করুন, নাকি প্রথমে আরও গবেষণা অর্থায়ন করুন। ওসিপিআই দ্বিতীয় বিকল্পে একটি সংখ্যা রাখে। যদি ওসিপিআই £50,000 হয় এবং প্রস্তাবিত ট্রায়াল £2 মিলিয়ন খরচ করে, এখনই গ্রহণ করুন। যদি ওসিপিআই £20 মিলিয়ন হয়, ট্রায়ালটি একটি দর কষাকষি। একই প্রশ্ন — "আমাদের কি এটি রোলআউট করার আগে পাইলট করা উচিত?" — প্রতিটি এন্টারপ্রাইজ সরঞ্জাম সিদ্ধান্তের জন্য উঠে, এবং প্রায় কেউ এটি মূল্য নির্ধারণ করে না। আগে তথ্য সংগ্রহের অপশনের বদলে পরে প্রকল্প সম্প্রসারণের অপশনের মূল্য নির্ধারণের জন্য [রিয়েল অপশন মূল্যায়ন](../রিয়েল-অপশন-মূল্যায়ন/) দেখুন।

## গণনা

ওসিপিআই হল নিখুঁত দূরদৃষ্টি দিয়ে সিদ্ধান্ত নেওয়া এবং প্রত্যাশার উপর এখন সিদ্ধান্ত নেওয়ার মধ্যে ব্যবধান:

```
ওসিপিআই = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = অনিশ্চিত পরামিতি (তাদের যৌথ বিতরণ সহ)
NMB(j,θ) = θ প্রদত্ত বিকল্প j-র নিট আর্থিক সুবিধা
```

প্রথম পদ: প্রতিটি সম্ভাব্য বিশ্ব জুড়ে সেরা-পছন্দ প্রতিদানের গড় (আপনি সর্বদা সঠিক বেছে নেন)। দ্বিতীয় পদ: একক বিকল্পের প্রতিদান যা গড়ে সেরা (আপনাকে এখনই প্রতিশ্রুতিবদ্ধ হতে হবে)। ওসিপিআই ≥ 0 সর্বদা। জনসংখ্যা ওসিপিআই প্রভাবিত সিদ্ধান্তের সংখ্যা দ্বারা গুণ হয়। [ভাচ](../সম্ভাব্যতা-সংবেদনশীলতা-বিশ্লেষণ/) ড্র থেকে সরাসরি গণনা করা।

## বিস্তারিত উদাহরণ

5,000 চিকিৎসকের কাছে একটি AI ডকুমেন্টেশন সহায়ক রোলআউট করুন, বা না করুন। দুটি বিশ্ব:

```
বিশ্ব A (p = 0.6): সহায়ক দিনে 20 মিনিট সাশ্রয় করে → রোলআউটের NMB = +£8M
বিশ্ব B (p = 0.4): সহায়ক ~0 সাশ্রয় করে (ওয়ার্কফ্লো ঘর্ষণ) → রোলআউটের NMB = −£3M
"রোলআউট নয়"-র NMB = উভয় বিশ্বে £0।
```

এখনই সিদ্ধান্ত নিন: E[NMB রোলআউট] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → রোলআউট করুন।

নিখুঁত তথ্য সহ: বিশ্ব A-তে রোলআউট বেছে নিন (+£8M), বিশ্ব B-তে কিছুই না বেছে নিন (£0)। প্রত্যাশিত মূল্য = 0.6 × 8 + 0.4 × 0 = **£4.8M**।

```
ওসিপিআই = 4.8M − 3.6M = £1.2M
```

£150,000 খরচের একটি কঠোর 3-মাসের পাইলট যা যথেষ্টভাবে সমাধান করে আপনি কোন বিশ্বে আছেন তা জোরালোভাবে মূল্যবান — এবং £1.2M-এর বেশি খরচের যেকোনো পাইলট নয়, যতই সম্পূর্ণ হোক না কেন।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

ওসিপিআই হল স্পাইক, পাইলট, A/B পরীক্ষা এবং ধারণার প্রমাণের অর্থনীতি। এটি দুটি ব্যবহারিক নিয়ম প্রদান করে:

- **একটি পাইলট শুধুমাত্র অর্থায়নের যোগ্য যদি সিদ্ধান্ত প্রকৃতপক্ষে পরিবর্তিত হতে পারে।** যদি আপনি পাইলট ফলাফল নির্বিশেষে রোলআউট করেন, ওসিপিআই = 0 এবং পাইলটটি থিয়েটার।
- **পাইলট ব্যয় ওসিপিআই-এ সীমাবদ্ধ করুন।** তথ্যের মূল্য যে সিদ্ধান্তকে অবহিত করে তার মূল্য দ্বারা আবদ্ধ।

আংশিক ওসিপিআই (EVPPI) এটিকে একক পরামিতিতে প্রসারিত করে: "নির্দিষ্টভাবে সঞ্চিত-সময় সংখ্যা নির্ধারণ করার মূল্য কত?" — যা আপনাকে বলে পাইলটটি কী পরিমাপ করা উচিত। সব অনিশ্চয়তা দূর করার বদলে *একটি নির্দিষ্ট প্রস্তাবিত গবেষণা* মূল্যায়নের জন্য [EVSI](../নমুনা-তথ্যের-প্রত্যাশিত-মূল্য/) দেখুন।

## ঝুঁকি

- **কোনো সিদ্ধান্ত নিয়ম সংযুক্ত না করে পাইলট চালানো** — তথ্য যা পছন্দ পরিবর্তন করতে পারে না তা সংজ্ঞা অনুযায়ী মূল্যহীন।
- **তথ্য সংগ্রহের বিলম্ব খরচ উপেক্ষা করা**: একটি 6-মাসের পাইলট 6 মাসের সুবিধা বিলম্বিত করে ([বিলম্বের খরচ](../বিলম্বের-খরচ/)); পাইলটের নিট মূল্য = সমাধানকৃত ওসিপিআই − বিলম্ব খরচ − পাইলট খরচ।
- **ওসিপিআইকে একটি পূর্বাভাস হিসেবে বিবেচনা করা।** এটি তথ্য মূল্যের একটি ঊর্ধ্ব সীমা, একটি নির্দিষ্ট অধ্যয়ন কী প্রদান করবে তার অনুমান নয়।
