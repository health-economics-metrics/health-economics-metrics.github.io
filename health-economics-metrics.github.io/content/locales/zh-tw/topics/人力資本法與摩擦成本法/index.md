# 人力資本法與摩擦成本法 (Human Capital vs Friction Cost)

這是在疾病成本研究和成本效益研究中，為因疾病、殘疾或死亡而損失的生產率估值的兩種相互競爭的方法。人力資本法（HCA）按工資率對整個缺勤期間損失的全部產出估值；摩擦成本法（FCM）只對僱主恢復生產實際所需的較短時期估值。兩者之間的選擇會使間接成本估計相差兩倍或更多。

## 為什麼重要

間接（生產率）成本是衛生經濟學中爭議最大的專案之一，恰恰因為兩種標準方法分歧如此之大。HCA 把每個缺勤日都當作經濟確實損失的產出日，按全額工資對整個期間估值——在死亡或永久殘疾的情形下則按剩餘的工作年限估值。FCM 則主張，在存在失業和勞動力市場冗餘的經濟體中，大多數長期缺勤實際上並不會降低國民產出，因為僱主會培訓替代者或重新分配工作；只有“摩擦期”——把產出恢復到先前水平所需的時間——才是真實的損失。因此 FCM 給出的間接成本估計系統性地低於、也更保守於 HCA，兩者不是可以互換的腳註：它們是關於“損失的生產率”是什麼意思的不同經濟學理論。這也是為什麼 [NICE 的基礎案例](../衛生技術評估/)預設排除生產率成本，如有報告，則作為單獨的社會視角敏感性分析，而不是混入基礎案例 ICER——見[分析視角](../分析視角/)。

## 計算方法

```
人力資本法：
HCA_成本 = 日工資 × 損失天數

摩擦成本法（簡化，以摩擦期為上限）：
FCM_成本 = 日工資 × min(損失天數, 摩擦期天數)

摩擦期天數 = 按國家/行業對恢復生產所需時間的估計
             （歷史上荷蘭 iMTA 成本指南中約 85 天；因國而異，並定期重新評估）
```

兩種方法之間的全部分歧都在 `min()` 裡：HCA 從不對 `損失天數` 設上限，所以成本隨整個缺勤期增長；FCM 把計入的天數限制在摩擦期，無論實際缺勤多長。

## 算例

一名員工缺勤 `損失天數 = 180` 天，`日工資 = £150`。

**人力資本法**：

```
HCA_成本 = 150 × 180 = £27,000
```

**摩擦成本法**，`摩擦期天數 = 85`（荷蘭 iMTA 的歷史基準，依據指南的定期重新評估）：

```
FCM_成本 = 150 × min(180, 85) = 150 × 85 = £12,750
```

對*同一次*缺勤，FCM 的 £12,750 不到 HCA 的 £27,000 的一半——僅僅方法的選擇就大幅改變了疾病成本的論證，還沒碰任何其他假設。

## 與軟體工程的關聯

這與團隊估計工程師離職成本的方式直接對應：

- **HCA 式的流失成本核算**：把損失估為離職工程師在職位空缺的整個期間的全額薪資。這是大多數流失成本模型的樸素版本，其高估的原因與 HCA 高估損失生產率相同——假定空出的產能原本完全高效，且沒有其他東西填補空缺。見[員工留任](../人才留任/)，其中量化了此方法所依賴的招聘/入職/填補空缺的鏈條。
- **FCM 式的流失成本核算**：只按尋找並引入替代者所需的實際時間估計損失——工程中的“摩擦期”。對商業案例而言這是更站得住腳的數位，正如在疾病成本研究裡 FCM 是更保守的選擇。
- 其背後的紀律與[機會成本](../機會成本/)相同：按實際損失的東西給被擠出的資源估值，而不是按標題時長與費率的乘積。

## 陷阱

- **在同一分析中混用 HCA 與 FCM，或只報告其中一個而不披露選擇。** 同樣的缺勤資料，按方法不同，報告出的成本可相差 2 倍或更多；選擇必須點明，不能隱藏。
- **在社會視角案例中使用 HCA 卻不標註為敏感性分析。** NICE 基礎案例明確排除生產率成本；社會視角的 HCA 估計屬於情景分析，而不是標題 ICER。
- **不加調整地把任一方法用於無報酬或非市場工作（如照護）。** 兩者都用工資率代表價值，而這無法乾淨地遷移到沒有市場工資的工作上。
