# পুনঃভর্তির হার

৩০-দিনের পুনঃভর্তির হার হলো স্রাবপ্রাপ্ত রোগীদের শতাংশ যারা ৩০ দিনের মধ্যে জরুরি বিভাগে ফিরে আসে। এটি স্বাস্থ্য ব্যবস্থার প্রামাণিক *স্রাব-মান* সূচক — এবং এটি সরাসরি আর্থিক জরিমানা বহন করে।

## কেন এটি গুরুত্বপূর্ণ

একটি পুনঃভর্তি মানে প্রথম স্রাব টেকেনি: আগাম স্রাব, ব্যর্থ ওষুধ হস্তান্তর, ফলোআপের অভাব, বা অনুপস্থিত সামাজিক সহায়তা। প্রদানকারীরা এটিকে স্পষ্টভাবে শাস্তি দেয় — US Hospital Readmissions Reduction Program একটি হাসপাতালের মেডিকেয়ার পরিশোধের ৩% পর্যন্ত কেটে নেয়।

## গণিত

```
পুনঃভর্তি হার = 30 দিনের মধ্যে জরুরি পুনঃভর্তি / সূচক স্রাব × 100

এড়ানোর মূল্য = এড়ানো পুনঃভর্তি × (প্রতি পুনঃভর্তি পর্ব ব্যয়
                     + প্রতি পুনঃভর্তি জরিমানার ঝুঁকি)
```

## সমাধানকৃত উদাহরণ

একটি হৃদরোগ স্রাব-সহায়তা অ্যাপ: বছরে ২,০০০ স্রাব, বেসলাইন পুনঃভর্তি হার ১৮%, ট্রায়াল অ্যাপসহ ১৪% দেখায়।

```
এড়ানো পুনঃভর্তি = 2,000 × (0.18 − 0.14) = বছরে 80
প্রতি পুনঃভর্তি পর্ব ব্যয় ≈ £3,500 → বছরে £280,000 এড়ানো চিকিৎসা ব্যয়
অ্যাপ ব্যয়: 2,000 × £60 = বছরে £120,000

নিট ≈ বছরে +£160,000
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

পুনঃভর্তি স্বাস্থ্য ব্যবস্থার **পরিবর্তন ব্যর্থতার হার** ([DORA মেট্রিক্স](../dora-metrics/) দেখুন): কাজ যা "পাঠানো" হয়েছিল এবং ৩০ দিনের মধ্যে ফিরে এসেছে। একটি "৩০-দিন পুনঃখোলা হার" সাইকেল টাইম উদযাপন করা যেকোনো টিম ড্যাশবোর্ডে থাকা উচিত।

## ঝুঁকিপূর্ণ দিক

- **পুনঃলেবেলিং দ্বারা কারচুপি**: পুনঃভর্তিকে পর্যবেক্ষণ থাকা বা নতুন অবস্থা হিসেবে কোড করা।
- **সব-কারণ বনাম সম্পর্কিত-কারণ**: ৩০-দিনের সব-কারণে প্রকৃতই অসম্পর্কিত ঘটনা অন্তর্ভুক্ত।
- **কেস-মিক্স অন্ধত্ব**: বেশি অসুস্থ, দরিদ্র জনগোষ্ঠীকে সেবা দেওয়া হাসপাতাল বেশি পুনঃভর্তি করে যা কোনো অ্যাপ ঠিক করে না।
