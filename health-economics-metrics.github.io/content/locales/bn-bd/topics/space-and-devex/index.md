# SPACE এবং DevEx

SPACE (সন্তুষ্টি ও সুস্থতা, কর্মক্ষমতা, কার্যকলাপ, যোগাযোগ ও সহযোগিতা, দক্ষতা ও প্রবাহ) এবং DevEx (ফিডব্যাক লুপ, জ্ঞানীয় বোঝা, প্রবাহ অবস্থা) হলো ডেভেলপার উৎপাদনশীলতা **বহু-মাত্রিকভাবে** পরিমাপের ফ্রেমওয়ার্ক।

## কেন এটি গুরুত্বপূর্ণ

উভয় ফ্রেমওয়ার্কই সেই একই কঠিন-অর্জিত শিক্ষা এনকোড করে যা স্বাস্থ্য ফলাফল গবেষণা দশক আগে শিখেছিল: একটি একক সংখ্যা (কোড লাইন; রক্তচাপ) বহু-মাত্রিক বাস্তবতাকে ভুলভাবে উপস্থাপন করে।

## গণিত

```
SPACE নিয়ম: ≥ 3 মাত্রা, ≥ 1 উপলব্ধিগত (জরিপ) + ≥ 1 সিস্টেম (টেলিমেট্রি) মেট্রিক

DevEx মাত্রা এবং উদাহরণ জোড়:
  ফিডব্যাক লুপ  → CI সময়কাল (টেলিমেট্রি) + "অপেক্ষা ধীর মনে হয়" (জরিপ)
  জ্ঞানীয় বোঝা  → ডক্স খুঁজে পাওয়া, অনবোর্ডিং সময় + অনুভূত প্রচেষ্টা
```

## সমাধানকৃত উদাহরণ

একটি প্ল্যাটফর্ম দল ৩০০ ডেভেলপারের জন্য একটি DevEx বিনিয়োগ (CI গতি বৃদ্ধি + ডক্স সংস্কার) ন্যায্যতা দেয়:

```
বেসলাইন: CI p75 = 28 মিনিট; জরিপ "বিল্ড অপেক্ষায় ফোকাস হারাই": 62% সম্মত
পরে:    CI p75 = 9 মিনিট;  সম্মতি 24%

সময় পুনরুদ্ধার (টেলিমেট্রি): দিনে 6 বিল্ড × 19 মিনিট × 0.4 ব্যবহারযোগ্য = দিনে ~45 মিনিট/ডেভ
ক্ষমতা মূল্য: 300 × 0.75h × 220d × £60/h ≈ £2.97M/বছর
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

এই নথিটি *হলো* সফটওয়্যার দিক; স্থানান্তর স্বাস্থ্য অর্থনীতির দিকে চলে। একটি "মান-সমন্বিত প্রকৌশলী বছর" [QALY](../quality-adjusted-life-year/)-র গঠন প্রকৌশল ক্ষমতায় প্রয়োগ করা।

## ঝুঁকিপূর্ণ দিক

- **একক-মেট্রিক সংকোচন**: SPACE-কে একটি স্কোরে হ্রাসকারী ড্যাশবোর্ড সমস্যা পুনঃতৈরি করে।
- **অউটকাম হিসেবে কার্যকলাপ মেট্রিক্স**: কমিট, PR, এবং স্টোরি পয়েন্ট হলো কার্যকলাপ।
- **জরিপ ক্লান্তি এবং হথর্ন প্রভাব**।
