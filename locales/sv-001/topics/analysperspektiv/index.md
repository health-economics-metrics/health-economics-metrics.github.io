# Analysperspektiv

Analysperspektivet bestämmer vems kostnader och nyttor som räknas i en ekonomisk utvärdering: betalarens, vårdgivarens eller samhällets som helhet.

## Varför det är viktigt

Samma intervention kan se kostnadseffektiv ut ur ett perspektiv och kostnadsdrivande ur ett annat, beroende på vem som betalar notan.

## Matematiken

```
Nettokostnad(perspektiv) = Σ kostnader som är relevanta för det perspektivet
```

## Genomarbetat exempel

En telemonitoreringstjänst kostar vårdgivaren £200 000/år men sparar samhället £500 000/år i förlorad produktivitet.

## Koppling till mjukvaruutveckling

Liknar att välja vem som är "kunden" vid prioritering av funktioner — det interna teamet, slutanvändaren eller den bredare organisationen.

## Fallgropar

- **Att tyst byta perspektiv mitt i en analys.**
- **Att hävda samhällsnyttor samtidigt som man budgeterar ur betalarens perspektiv.**
