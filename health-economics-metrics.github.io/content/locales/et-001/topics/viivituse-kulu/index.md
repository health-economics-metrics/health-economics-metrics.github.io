# Viivituse kulu

Viivituse kulu mõõdab väärtust, mis kaotatakse iga nädalaga (või kuuga), mil funktsiooni või sekkumise tarnimine edasi lükkub.

## Miks see on oluline

Viivituse kulu muudab abstraktse "me peaksime seda kiiremini tegema" konkreetseks rahaliseks numbriks, mis võimaldab objektiivset prioriseerimist konkureerivate algatuste vahel.

## Matemaatika

```
Viivituse kulu = Kaotatud väärtus nädalas × viivituse nädalate arv
```

## Lahendatud näide

Funktsioon, mis genereeriks £10 000 väärtust nädalas, mis lükkub edasi 8 nädalat, maksab £80 000 viivituse kulu — isegi kui funktsiooni enda arenduskulu jääb muutumatuks.

## Seos tarkvaraarendusega

Põhimõiste tarkvaraarenduse prioriseerimises; vt [WSJF ja CD3](../wsjf-ja-cd3/) selle rakendamiseks jadapõhises prioriseerimises.

## Lõksud

- **Viivituse kulu arvutamine ilma väärtuse jaotuse kuju arvestamata (lineaarne vs järsk langus).**
- **Viivituse kulu segiajamine arenduskuluga.**
