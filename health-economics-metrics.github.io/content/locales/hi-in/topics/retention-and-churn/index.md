# प्रतिधारण और मंथन

प्रतिधारण मापता है कि उपयोगकर्ता समूह का कितना भाग शुरू करने के N दिनों बाद भी सक्रिय है। नृशंस डिजिटल-स्वास्थ्य आधाररेखा: **लगभग 90% स्वास्थ्य-ऐप उपयोगकर्ता 30 दिनों के भीतर छोड़ देते हैं**।

## यह क्यों महत्वपूर्ण है

Eysenbach ने 2005 में इसे नाम दिया: **क्षरण का नियम**।

## गणित

```
प्रतिधारण_Dn = n दिन पर सक्रिय उपयोगकर्ता / समूह आकार × 100
```

## हल किया गया उदाहरण

एक मानसिक-स्वास्थ्य ऐप: परीक्षण ने प्रति उपयोगकर्ता 0.02 QALY दिखाया जो 8 सप्ताह पूरा करते हैं।

```
पूर्ण करने वाले = 100,000 × 0.04 = 4,000
प्राप्त QALY = 4,000 × 0.02 = 80
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

प्रतिधारण वह मीट्रिक है जहाँ उत्पाद इंजीनियरिंग सबसे सीधे स्वास्थ्य मूल्य का निर्माण करती है।

## सामान्य गलतियाँ
