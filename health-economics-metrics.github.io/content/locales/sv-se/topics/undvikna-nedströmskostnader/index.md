# Undvikna nedströmskostnader

Undvikna nedströmskostnader är kostnadskompensationer som uppstår genom att förhindra senare, dyrare hälsohändelser, och reglerna som gör dessa påståenden trovärdiga.

## Varför det är viktigt

Påståenden om nedströmskostnader är lätta att överdriva; trovärdiga påståenden kräver tydliga antaganden om kausalitet, tidshorisont och kontrafaktiska scenarier.

## Matematiken

```
Undvikna kostnader = (Grundnivå för händelsefrekvens − händelsefrekvens med intervention) × kostnad per händelse × population
```

## Genomarbetat exempel

Ett program för tidig upptäckt av hjärtsvikt minskar inläggningar med 3 procentenheter i en population på 5 000: 150 undvikna inläggningar × £4 000/inläggning = £600 000 undvikna kostnader.

## Koppling till mjukvaruutveckling

Liknar att hävda "undvikna incidentkostnader" genom proaktiv övervakning — trovärdigt endast med en tydlig grundnivå och kausal mekanism.

## Fallgropar

- **Att hävda undvikna kostnader utan en giltig kontrafaktisk grundnivå.**
- **Att blanda ihop regression mot medelvärdet med en verklig interventionseffekt.**
