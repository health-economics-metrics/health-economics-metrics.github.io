# ڈسکاؤنٹنگ اور وقت کی ترجیح

ڈسکاؤنٹنگ مستقبل کے اخراجات اور فوائد کو موجودہ قدروں میں تبدیل کرتی ہے، کیونکہ آج ایک فائدہ پانچ سالوں میں اسی فائدے سے زیادہ قیمت رکھتا ہے۔

## یہ کیوں اہم ہے

ہر صحت-معیشت کی تشخیص اور ہر سنجیدہ عوامی-شعبے کا کاروباری کیس کئی سالہ سلسلوں کو ڈسکاؤنٹ کرتا ہے۔ برطانیہ کا HM Treasury Green Book 3.5% سالانہ سماجی وقت کی ترجیح کی شرح کا مینڈیٹ دیتا ہے؛ NICE کا حوالہ کیس اخراجات اور صحت کے اثرات دونوں کو 3.5% فی سال پر ڈسکاؤنٹ کرتا ہے (30+ سالوں میں فوائد کے ساتھ تقریباً-شفا بخش علاج کے لیے 1.5% غیر-حوالہ-کیس شرح کے ساتھ)۔ اگر آپ کا سافٹ ویئر کاروباری کیس "10 سالوں میں £5 ملین بچت" کا دعویٰ کرتا ہے، تو ایک مالی جائزہ کار فوری طور پر ڈسکاؤنٹ شدہ اعداد و شمار مانگے گا۔

## حساب

ایک مستقبل کی رقم کی موجودہ قدر:

```
PV = FV / (1 + r)^t

PV = موجودہ قدر
FV = سال t میں مستقبل کی قدر
r  = ڈسکاؤنٹ کی شرح (NICE/Green Book: 0.035)
t  = اب سے سال
```

n سالوں میں ایک مستقل سالانہ فائدے B کے لیے (ایک سالانہ رقم):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## حل شدہ مثال

آپ کا سافٹ ویئر NHS ٹرسٹ کو گو-لائیو کے ایک سال بعد شروع ہو کر 5 سالوں کے لیے سالانہ £100,000 بچاتا ہے۔

غیر ڈسکاؤنٹ شدہ کل: £500,000۔

3.5% پر ڈسکاؤنٹ شدہ:

```
سال 1: 100,000 / 1.035^1 = £96,618
سال 2: 100,000 / 1.035^2 = £93,351
سال 3: 100,000 / 1.035^3 = £90,194
سال 4: 100,000 / 1.035^4 = £87,144
سال 5: 100,000 / 1.035^5 = £84,197

کل PV ≈ £451,505
```

ایماندار سرخی تقریباً £451,000 ہے، تقریباً 10% کم بھولی-بھالی رقم سے۔ اب فرض کریں فراہمی ایک سال پیچھے ہٹ جاتی ہے: ہر اصطلاح ایک سال بعد منتقل ہوتی ہے، اور PV تقریباً £436,000 تک گر جاتا ہے — [تاخیر کی لاگت](../تاخیر-کی-لاگت/) کا ڈسکاؤنٹنگ نظریہ۔

## سافٹ ویئر انجینئرنگ سے تعلق

- **ٹیک-قرض کی ادائیگی اور پلیٹ فارم کی ہجرت** سالوں دور فوائد کے سلسلے کا وعدہ کرتی ہیں؛ انہیں اس کام کے خلاف موازنہ کرنے سے پہلے ڈسکاؤنٹ کریں جو اس سہ ماہی میں خود کو ادا کرتا ہے۔
- **پیش گیر اخراجات، پس گیر فوائد** ایک ہجرت کی معیاری شکل ہے۔ ڈسکاؤنٹنگ اس شکل کو صحیح طور پر سزا دیتی ہے: یہ بعد میں قدر کے لیے اب صلاحیت وابستہ کرنے کے بغیر-خطرہ وقتی قدر کی قیمت طے کرتی ہے۔
- **"سال 5 میں بچتیں"** کے دعوے دو گنا شک کے مستحق ہیں — وہ دونوں شدید طور پر ڈسکاؤنٹ شدہ اور انتہائی غیر یقینی ہیں ([حساسیت تجزیہ](../حساسیت-تجزیہ/) دیکھیں)۔

## نقصانات

- **اخراجات کو ڈسکاؤنٹ کرنا لیکن فوائد کو نہیں** (یا اس کے برعکس) — حوالہ کیس دونوں کو ایک ہی شرح پر ڈسکاؤنٹ کرتا ہے۔
- **عوامی-شعبے کے کیس میں کمرشل شرح (8–12%) استعمال کرنا**، یا وینچر-بیک شدہ کیس میں 3.5%۔ فیصلہ کنندہ کے ساتھ شرح کو ملائیں۔
- **ڈسکاؤنٹنگ کو مہنگائی کے ساتھ الجھانا۔** ڈسکاؤنٹنگ *حقیقی* (مہنگائی-ایڈجسٹ شدہ) قدروں پر لاگو ہوتی ہے؛ دونوں کو ضمنی طور پر نہ کریں۔
