# スクリーニング必要数(NNS)

NNSは、定義された追跡期間にわたって**1件**の有害なアウトカムを防ぐために、(治療ではなく)スクリーニングを受けなければならない人数であり、集団のベースラインリスクと、早期発見と治療によって達成される相対リスク減少が与えられた場合のものです。これはNNTのスクリーニングプログラムレベルでの類似物です。NNTは1件のアウトカムを防ぐために何人を*治療*しなければならないかを問い、NNSはそこに到達するために何人が*スクリーニングしてから治療する*経路全体を通らなければならないかを問います。

## なぜ重要か

Rembold は1998年に、スクリーニングプログラムを治療と同じ土俵で比較できるようにするために、NNSを導入しました。スクリーニング検査の見出しの相対リスク減少は、治療のそれが隠さない2つのことを隠すからです。1つは実際にスクリーニングに招待される集団のベースラインリスク、もう1つは、最終的に利益を得る少数だけでなく、スクリーニングを受けた全員が検査のコストと偽陽性の負担を負うという事実です。英国国家スクリーニング委員会の費用対効果の関門([スクリーニングの経済学](../screening-economics/)を参照)は、まさにこの区別に基づいています。ベースラインリスクの低い集団で印象的な相対リスク減少を示すスクリーニングプログラムでも、NNSが数千になることがあり、その場合は防止したアウトカム1件あたりのプログラム費用が本当の問題になります。

## 数式

```
NNS = 1 / (ベースラインリスク × 相対リスク減少)

ベースラインリスク   = 追跡期間中にスクリーニング対象集団でアウトカムが
                       起こる確率(0〜1)
相対リスク減少       = スクリーニングによる早期治療で達成される
                       リスクの比例的な減少(0〜1)

防止したアウトカム1件あたりのプログラム費用 = NNS × スクリーニング1回あたり費用
```

[NNT](../number-needed-to-treat/)と直接比較してください。NNSはスクリーニング → 診断 → 治療というファネル全体の有効性を1つの数値に折りたたみますが、NNTはすでに患者が診断され治療を始めていることを前提としています。

## 計算例

スクリーニングプログラムの対象集団は、研究期間中のイベントのベースラインリスクが2%(`ベースラインリスク = 0.02`)で、早期発見により25%の相対リスク減少(`相対リスク減少 = 0.25`)が達成されます。

```
NNS = 1 / (0.02 × 0.25) = 1 / 0.005 = 200

1件のアウトカムを防ぐために200人をスクリーニングする必要がある。

スクリーニング1回あたり£50の場合:
防止したアウトカム1件あたりのプログラム費用 = 200 × £50 = £10,000
```

その£10,000こそ、アウトカム自体の費用と、それが失わせたであろうQALYに対して比較すべき数値であり、[予防の経済学](../prevention-economics/)が予防プログラム全般に対して行うのと同じ比較です。

## ソフトウェア工学との関連

NNSは、「検出やトリアージのフローに、対応する価値のある真陽性を1件捕らえるために、何人のユーザー、イベント、リクエストを通さなければならないか」です。これは、低有病率の対象状態が、陽性的中率を崩壊させるのと同じようにNNSを押し上げる、アラートベースの監視・トリアージシステムに直接関係します([スクリーニングの経済学](../screening-economics/)と[臨床AIの評価](../clinical-ai-evaluation/)を参照)。実際の検出1件あたり200件のイベントを処理しなければならない監視ルールは、その検出がイベントあたりのトリアージコストの少なくとも200倍の価値を持つ場合にのみ、実行する価値があります。上の医療の計算例と全く同じ算術です。

## 落とし穴

- **ベースラインリスクへの依存を無視すること**: 同じスクリーニング検査やプログラムでも、高リスク集団と低リスク集団とではNNSも費用対効果も大きく異なります。NNSは、それが計算された集団を明記せずに引用してはいけません。
- **誤った分母を数えること**: NNSは*スクリーニングを受けた*人数を数えるもので、検査が陽性だった人や治療を始めた人ではありません。すでにファネル全体の有効性を織り込んでいるため、陽性者のみで数えた指標と比較してはいけません。
- **追跡期間をまたいで比較すること**: 追跡期間が短いと、その期間内に観測されるイベントが少ないため、一般にNNSは大きくなります。NNSの数値は、同じ追跡期間で計算された場合にのみ比較できます。
