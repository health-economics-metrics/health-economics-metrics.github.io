# 国家统一收费标准与单位成本 (National Tariff and Unit Costs)

NHS按一套基于规则的国家价目表向服务提供方支付活动费用——历史上称为National Tariff / Payment by Results，自2023年4月1日起被**NHS Payment Scheme（NHSPS）**取代。在这些价格背后，是一套国家级的单位成本核算基础设施：**国家成本采集（National Cost Collection，NCC）**与**PSSRU卫生与社会照护单位成本 (Unit Costs of Health and Social Care)**汇编。

## 为什么重要

这些数据是每一份可信的NHS商业论证的分母。当一项主张说"一次门诊就诊价值£160"或"一个Band 6护士小时成本£31"时，这些数字都来自这套基础设施——使用官方数字而非凭空捏造的数字，正是让独立评估彼此可比、也让财务团队愿意配合的关键所在。对供应商而言，该收费标准也界定了*收入*那一端：你的软件所催生的活动量（额外门诊、回填的床位）会按该体系的价格计值。

## 计算方法

```
每单位活动量的收费标准价格（HRG编码病程、门诊就诊）
  = 国家平均单位成本（来自NCC）× 市场因素调整系数 (Market Forces Factor，本地调整)
  在NHSPS下：混合了固定与浮动（"统一支付与激励"）两种要素

NCC单位成本 = 信托机构上报的某类活动总成本 / 活动量
             （基于患者层面信息与成本核算系统 (Patient-Level Information
             and Costing Systems，PLICS) 构建）

PSSRU汇编：约80项标准单位成本（GP问诊、按等级划分的护士小时成本、
急诊就诊……）——英国经济学评估中默认采用的数据来源。
```

## 算例

你的软件在一个250个工作日的年度里，每天为一名Band 6护士释放1小时工作时间：

```
基于PSSRU、含管理费用的Band 6成本约为£31/小时（请核对当前版本）
产能价值 = 250 × £31 = £7,750/护士/年（非现金释放型）
```

或者，这名护士改为每天多完成2次门诊随访，每次按收费标准价值约£160计算：500 × £160 = **£80,000/年的获资助活动量**——同一段释放出来的时间，仅因再利用方式不同，所主张的价值就相差十倍，而两者都以官方单位成本为依据。这两种主张之所以都可被审计，正是因为其分母是公开发布的——这正是整套体系的意义所在。

## 与软件工程的关联

这是**内部价格手册**这一模式的体现。英国卫生经济学之所以行之有效，是因为每一项评估都使用同一套公开的单位成本；工程组织大多缺乏这一点，因此每一份商业论证都在自行编造一个工程师小时、一次事件、一次部署的成本。平台团队完全可以发布这样一本价格手册——按级别划分的负荷工程师小时成本、按严重程度划分的事件成本、按构建分钟计的成本——并要求所有提案都必须使用它。转嫁/展示计费系统同样会重演收费标准已知的失效模式：按平均成本定价会诱发用量刷单，固定支付则会诱发供给不足。NHSPS从纯活动量付费演变为固定+浮动混合模式，正是二十年来关于内部平台定价激励设计的经验教训。

## 常见陷阱

- **数字过时**：NCC、PSSRU与NHSPS的价格每年更新——每一个数字都应标注日期。
- **收费标准价格 ≠ 成本**：这些价格是经过调整的全国平均值；你所在机构的本地边际成本会有所不同（参见[边际成本与平均成本](../边际成本与平均成本/)）。
- **在没有实际交付机制的情况下按收费标准为产能估值**，却无法真正交付并获得那部分额外活动量的报酬。
