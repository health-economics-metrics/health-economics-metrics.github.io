# Økonomi for fjernpatientovervågning

Økonomi for fjernpatientovervågning måler de omkostningsbesparelser, som hjemmeovervågningsteknologi giver ved at reducere indlæggelser, genindlæggelser og fysiske besøg.

## Hvorfor det er vigtigt

Fjernovervågning kræver indledende udstyrsomkostninger, men kan forhindre dyr brug af akutbehandling.

## Matematikken

```
Nettobesparelse = (antal undgåede indlæggelser × omkostning pr. indlæggelse) − programomkostning
```

## Gennemarbejdet eksempel

Fjernovervågning af hjertesvigt: 40 undgåede indlæggelser × £4.000 = £160.000 besparelse − programomkostning £60.000 = nettobesparelse £100.000.

## Forbindelse til softwareudvikling

Direkte knyttet til [sparede sengedage](../bed-days-saved/) og [genindlæggelsesrate](../readmission-rate/), og afhængig af [validering af bærbare enheder](../wearable-validation/) for datakvalitet.

## Faldgruber

- **At overvurdere besparelser på grund af selektionsskævhed i patientudvælgelse.**
