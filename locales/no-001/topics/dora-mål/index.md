# DORA-mål

DORA-mål er fire mål på programvareleveringsytelse — utrullingsfrekvens, ledetid for endringer, feilrate ved endring og gjenopprettingstid.

## Hvorfor det er viktig

Ti års DORA-forskning kobler disse målene til organisasjonens ytelse.

## Matematikken

```
Ledetid = t(utrulling) − t(commit), median
```

## Gjennomarbeidet eksempel

Et helseforetaks programvareteam for pasientflyt, før/etter: utrullinger fra månedlige → ukentlige.

## Kobling til programvareutvikling

Dette er *nøyaktig* programvaresiden.
