# 患者报告结局 (Patient-Reported Outcomes，PROMs, PREMs, MCID)

PROMs是标准化的测评工具，由患者自行报告其健康状况（症状、功能、生活质量）；PREMs记录的则是就医*体验*。**MCID**——最小临床重要性差异（minimal clinically important difference）——是患者能够真正感知到获益的最小分值变化：任何被主张的改善都必须跨过这道门槛。

## 为什么重要

PROMs是数字健康领域最主要的疗效"通货"：应用很少能改变死亡率，但它们可以切实地改变经过验证的症状评分。真正重要的测评工具为数不多且高度标准化——**PHQ-9**（抑郁症，0–27分；严重程度分档为5/10/15/20）、**GAD-7**（焦虑症，0–21分；分档为5/10/15）、**EQ-5D**（用于[QALY](../质量调整生命年/)的效用值）——监管机构、HTA机构和支付方之所以接受它们，正是因为它们在不同产品和不同试验之间是可比的。MCID是诚实性的门槛：PHQ-9的MCID约为5分，GAD-7约为4分，EQ-5D指数通常约为0.03–0.08——在一个大样本中，一个具有统计显著性的PHQ-9 1.5分变化*真实存在，但在临床上毫无意义*，任何证据评审者都会这样指出。

## 计算方法

```
PROM计分：按工具各自的规则求和（例如PHQ-9 = Σ 9个条目 × 0–3分）

MCID估算：
  基于锚点法：      在自评"有所好转"的患者中观察到的分值变化
  基于分布法：      ≈ 基线分值标准差 (SD) 的0.5倍（粗略经验法则）

应答率框架（用于试验与申报文件）：
  应答者 = 改善幅度 ≥ MCID 的患者（或按PHQ-9惯例取≥50%改善）
  NNT = 1 / (治疗组应答率 − 对照组应答率)
  ——参见number-needed-to-treat.md
```

## 算例

一款抑郁症支持应用，随机对照试验对比候诊名单，为期12周：

```
PHQ-9变化：应用组 −6.2分，对照组 −2.1分 → 调整后差值 −4.1
MCID检验：4.1 < 5 → 均值差低于MCID；改为报告应答者：
  应答者（分值下降 ≥5分）：应用组48%，对照组22% → ARR 26%
  NNT = 1/0.26 ≈ 4 ——每4名用户接受治疗，即多产生1例临床应答

经济学换算：应答者的EQ-5D获益0.06，持续6个月
  = 0.03 QALY；按每1,000名用户计：260名额外应答者 × 0.03
  = 7.8 QALY ≈ 按NICE阈值计值£156,000–£234,000的健康价值
```

在均值差低于MCID本会被评审驳回之处，应答者/NNT这一框架依然站得住脚。

## 与软件工程的关联

PROMs是一个软件恰好最擅长解决的数据采集问题：应用内测评工具能实现纸质时代从未达到过的完成率与纵向数据密度，把日常的产品遥测数据变成HTA级证据（[EQ-5D](../eq-5d/)不过是五个屏幕）。工程规则：必须*逐字*使用已验证的工具版本（改写措辞会使其失效——且涉及许可问题）；应按协议安排测评时机，而不是按用户是否活跃来安排（只测活跃用户会带来幸存者偏差——参见[留存](../留存与流失/)）；并像对待任何模式 (schema) 一样对测评工具数据做版本锁定——研究中途改动措辞就是数据损坏。PREMs对应的是CSAT/NPS一类的工具，同样的教训适用：只要受众是支付方，标准化工具就胜过自制工具。 关于专门针对工作效率的工具，见 [WPAI](../工作效率与活动受损量表/)。

## 常见陷阱

- **把低于MCID的统计显著性当作临床获益来呈现**——这是该领域最常见的夸大手法。
- **回归均值**：用户往往在症状最严重时入组，单臂前后对比会严重高估效果——必须设置对照组，这一点没有商量余地。
- **测评工具购物**：同时跑PHQ-9、GAD-7和WHO-5，然后只报告有变化的那个——应事先登记主要终点指标。
- **数字化知情同意调查的诱导压力**：诱导用户给出更正面的回答会破坏测评工具本身（评审者也清楚这些基础比率）。
