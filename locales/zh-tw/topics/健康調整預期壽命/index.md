# 健康調整預期壽命（HALE）

HALE是一項人群層面的彙總指標：一個人預期能夠*在完全健康狀態下*生活的年數，需扣除因疾病或傷殘而度過的年數。2019年WHO資料顯示，全球出生時HALE約為61.9歲，而預期壽命為73.3歲——人類平均在其生命的最後十年中，處於不完全健康的狀態。

## 為何重要

HALE是國家與全球衛生政策的北極星指標——"健康老齡化"目標的分子，而它所揭示的差距（預期壽命減去HALE）正是預防、早期介入與慢性病管理所要彌合的負擔。在部委層面，數位健康戰略正是以HALE為依據來論證其正當性的；一整套應用、篩查服務與監測專案組合，最終都彙總體現在這一指標上。

## 計算方法

標準計算方法是**Sullivan法**：

```
HALE_年齡x = Σ (生命表中每個年齡段 ≥ x 的人年數 × 完全健康狀態佔比)
            / 存活至年齡x的人數

"完全健康狀態佔比" = 1 − Σ (患病率_病症 × 傷殘權重)
```

輸入資料包括：一份標準生命表，以及各健康狀態的患病率與傷殘權重（來自全球疾病負擔研究資料）。HALE與[DALY](../傷殘調整生命年/)相關聯——人群DALY負擔與HALE差距，是同一份健康損失的兩種不同視角。

## 實例演算

某國家級數位高血壓管理專案：50萬人註冊，血壓控制的改善程度足以使中風發生率每年下降0.2個百分點。以該佇列的終生週期建模，被避免的中風共節省15,000個傷殘權重年（其中YLD按權重0.32計算，另加因致命性中風而損失的YLL）。

```
對HALE的貢獻 ≈ 15,000個健康年 / 50萬人
            ≈ 每名註冊者0.03年（約11天）的HALE
```

11天聽起來微不足道——但在人群規模上，國家層面的指標正是這樣一點一滴移動的：各國衛生部委購買的正是數以百萬計的這類微小的人均獲益。這套算術也說明了為什麼**觸達範圍至關重要**：一項效果是其兩倍、但註冊人數只有其十分之一的介入措施，對HALE的推動作用反而只有前者的五分之一。參見[觸達與公平](../觸達與公平/)。

## 與軟體工程的聯絡

HALE是一種"機群健康度"指標模式：**預期服務壽命 × 該壽命中處於健康狀態的佔比**。一個平臺團隊同樣可以在其整個資產範圍內計算"健康服務壽命預期"——一項服務預期能運作的年數，再扣除處於降級、已棄用或故障狀態的時間（權重來自SLO缺口）。這能將可靠性從"某一時點的可用性"重新建置為"整個生命週期的健康度"，並將補救工作導向那些正在拖累整個資產組合HALE數值的系統。

## 陷阱

- **HALE的變動緩慢且多因素疊加**——沒有任何單一介入措施能帶來可測量的、獨立的"HALE變動"；應主張其建模貢獻值，而非籠統套用國家層面的統計數位。
- **患病率資料存在滯後**，通常滯後官方資料數年；近期的獲益不會立即體現在官方HALE數位中。
- **跨國比較HALE**存在陷阱，因為各國健康狀態測量方式不同；應在同一體系內做縱向比較。
