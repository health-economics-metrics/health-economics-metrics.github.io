# Economie van monitoring op afstand van patiënten

Economie van monitoring op afstand van patiënten meet de kostenbesparingen die thuismonitoringtechnologie oplevert door ziekenhuisopnames, heropnames en fysieke bezoeken te verminderen.

## Waarom het ertoe doet

Monitoring op afstand vereist initiële apparatuurkosten maar kan duur acuut zorggebruik voorkomen.

## De wiskunde

```
Nettobesparing = (aantal vermeden opnames × kosten per opname) − programmakosten
```

## Uitgewerkt voorbeeld

Hartfalenmonitoring op afstand: 40 vermeden opnames × £4.000 = £160.000 besparing − programmakosten £60.000 = nettobesparing £100.000.
