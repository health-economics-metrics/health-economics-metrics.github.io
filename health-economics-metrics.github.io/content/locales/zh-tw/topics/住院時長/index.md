# 住院時長（LOS）

住院時長是指從入院到出院之間的天數——這是住院醫療中最核心的流動效率指標。英國急症醫療的平均住院時長約為4–5天；每多住一天，都會佔用寶貴的床位資源，並使病患暴露於院內獲得性風險之中。

## 為何重要

住院時長几乎驅動著急症醫院經濟學中的一切：床位產能、擇期手術吞吐量、急診流動、人員配置。在規模效應下，即便只是將平均住院時長縮短几分之一天，也能釋放出巨大的產能（參見[節省的床位天數](../節省的床位天數/)）。住院時長同樣是雙向的品質訊號——過長可能暗示流程失靈（診斷延遲、出院文書、等待社會照護安排）；過短則可能意味著過早出院，其後果會以[再入院](../再入院率/)的形式在後期顯現。

## 計算方法

```
住院時長（單次住院）  = 出院日期 − 入院日期
平均住院時長          = 佔用床位天數 / 出院人次（應同時報告均值與中位數；
                       由於長期住院的極端值影響，住院時長呈明顯右偏分佈）

進行比較時需進行病例組合調整（年齡、診斷、病情嚴重程度），
否則你測量的只是醫院收治的是哪些病人，而非醫院的實際表現。
```

利特爾法則將各項流動變數聯絡在一起：`佔用床位數 = 入院速率 × 平均住院時長`——這與支配軟體佇列的法則完全相同（參見[流動指標](../流動指標/)）。

## 實例演算

某信託機構每天收治40名急診內科病患，平均住院時長6.0天：這意味著永久佔用240張床位（40 × 6）。出院協調軟體（任務追蹤、藥房帶藥自動化、轉運預訂）將住院時長中非臨床性質的尾部平均縮短了0.4天。

```
所需床位數 = 40 × 5.6 = 224 → 持續釋放出16張床位
           = 16 × 365 = 每年5,840個床位天
```

應依據具體機制（重新填滿/關閉/冗餘吸收）為這5,840個床位天估值，參見[節省的床位天數](../節省的床位天數/)。請注意，真正發生變化的並非醫療本身，而是*等待*——病患在醫學上早已適合出院；系統卻仍在處理文書工作。這本質上是一個排隊問題，而軟體恰恰擅長解決排隊問題。

## 與軟體工程的聯絡

住院時長就是醫院的週期時間，其改進方法與交付流程改進完全一致：為各階段埋點（入院 → 治療 → 醫學上適合出院 → 實際已出院），找出時間究竟積壓在哪裡（通常是在交接環節），移除等待狀態，而非一味增加產能。"醫學上已適合出院，卻仍佔用床位"的這批病患，正是醫院版本的"已獲批准卻尚未合併的PR"。可直接切入的軟體機會包括：出院任務編排、診斷週轉、出院用藥的電子處方開具、社會照護轉介整合。

## 陷阱

- **只報告均值**——極端值會主導結果；一個正在下降的均值，可能掩蓋了正在增長的長期住院尾部。
- **前後對比主張中缺乏病例組合調整**：入院門檻本身會隨季節及長期趨勢而變化。
- **住院時長的縮短以再入院的形式重新出現**——任何關於住院時長的主張，都應同時附上30天再入院資料。
