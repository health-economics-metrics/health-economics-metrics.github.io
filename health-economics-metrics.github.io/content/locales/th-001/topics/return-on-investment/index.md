# ผลตอบแทนจากการลงทุน (ROI)

ROI วัดผลประโยชน์ทางการเงินสุทธิของการลงทุนเป็นเปอร์เซ็นต์ของต้นทุน — ตัวชี้วัดที่ใช้กันอย่างแพร่หลายแต่มักขาดความชัดเจนเรื่องพารามิเตอร์ที่ใช้คำนวณ

## ทำไมจึงสำคัญ

ROI เป็นภาษาที่ผู้บริหารการเงินเข้าใจทันที แต่เนื่องจากไม่มีคำนิยามมาตรฐานที่บังคับใช้อย่างเคร่งครัด ตัวเลข ROI ที่รายงานจากโครงการต่างๆ มักไม่สามารถเปรียบเทียบกันได้โดยตรง

## คณิตศาสตร์

```
ROI = (ผลประโยชน์สุทธิ − ต้นทุนการลงทุน) / ต้นทุนการลงทุน × 100%
```

## ตัวอย่างที่คำนวณแล้ว

โครงการลงทุน £100,000 และให้ผลประโยชน์สุทธิ £150,000 ตลอด 3 ปี: ROI = (£150,000 − £100,000) / £100,000 = 50% แต่ไม่มีการระบุว่าได้คิดลดกระแสเงินสดในอนาคตหรือไม่

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ROI ของเทคโนโลยีสารสนเทศเป็นตัวชี้วัดที่ใช้กันทั่วไปในการให้เหตุผลสำหรับการลงทุนด้านเครื่องมือหรือแพลตฟอร์มใหม่ แต่ประสบปัญหาความไม่ชัดเจนแบบเดียวกันหากไม่มีการระบุพารามิเตอร์

## ข้อผิดพลาดที่พบบ่อย

- **การรายงาน ROI โดยไม่ระบุขอบเขตเวลา อัตราคิดลด หรือสิ่งที่นับรวมเป็นต้นทุน**
- **การเปรียบเทียบตัวเลข ROI จากแหล่งต่างๆ ที่ใช้วิธีการคำนวณต่างกัน**
