# 支付意愿阈值 (Willingness-to-Pay Thresholds)

支付意愿 (WTP) 阈值，是决策者愿意为每单位健康获益支付的最高金额——它是把一个 [ICER](../增量成本效果比/) 转化为"采纳/拒绝"决策的那条分界线。

## 为什么重要

阈值正是卫生经济学从"测量"走向"政策"的分水岭。每一个国家级卫生系统都有一个阈值，无论明示还是隐含，了解当地的具体数字，就能准确知道该如何为一项健康价值主张定价：

| 机构 | 阈值（截至 2024–2025 年的研究数据） |
|---|---|
| NICE（英格兰） | 每 QALY £20,000–£30,000；实证平均决策阈值 ≈ £24,400（2022–24 年）；严重程度调整系数将实际上限提高至约 £36k–£51k；高度专科化技术可达 £100k 以上 |
| ICER（美国，非政府机构） | 每 QALY/evLYG $100,000–$150,000 的定价基准；报告中提及 $50k–$200k 的区间 |
| 加拿大（CADTH / CDA-AMC） | 工作阈值约为每 QALY CAD$50,000 |
| WHO-CHOICE（历史性、全球性） | 每避免一个 DALY 为人均 GDP 的 1–3 倍（目前已不再推荐使用，因过于粗略） |
| 英国实证供给侧研究（Claxton 等） | NHS 边际实际被挤出的健康约为每 QALY £13,000 |

## 计算方法

阈值 λ 进入每一条决策规则：

```
若 ICER = ΔC/ΔE < λ，则采纳
等价地：若 NMB = λ×ΔE − ΔC > 0，则采纳
```

关于 λ *究竟是什么*，存在两种理论：

- **需求侧**：社会愿意为健康支付多少（一种价值判断）。
- **供给侧**：预算目前在边际上能产出多少健康（一个实证量——Claxton 给出的约 £13k/QALY）。如果用于决策的 λ 超过供给侧的产出率，批准新技术所挤出的健康就会多于它所增加的健康。

## 算例

你的数字疗法为每位接受治疗的患者带来 0.05 个 QALY，净成本（价格减去抵消项）为 £800。

```
ICER = 800 / 0.05 = 每 QALY £16,000
```

- 英格兰：低于 £20k → 可获资助。可站得住脚的最高价格：在 λ = £20,000 时，最高价格 = 0.05 × 20,000 + 抵消项 = £1,000 + 抵消项。
- 美国商业定价框架下按 $150k/QALY 计算：基于价值的定价远高于此。
- 在一个人均 GDP 阈值为 $4,000 的国家：同一产品的净成本必须低于约 $200。

同一产品，三个市场，三种价格——阈值*本身*就是定价模型。这是从 λ 反推出来的价值导向定价法。

## 与软件工程的关联

每一个工程组织都有一个隐含的 λ：即它愿意为每节省一个工程师小时投入多少工具化资金的门槛。把它明确化——"我们资助任何每可信节省一个工程师小时成本低于 £40 的方案"——就能像每 QALY 成本排行榜为卫生支出排序一样，对平台投资进行排行榜式的横向比较。供给侧的教训同样适用：你真正的内部 λ，是你*当前*积压需求在边际上所产出的价值，而不是管理层嘴上说的时间值多少钱。

## 陷阱

- **阈值货比三家**：跨司法辖区挑选阈值，或为一个普通产品援引高度专科化技术 (HST) 的上限。
- **把 λ 当作价格下限**：达到阈值是必要条件，而非充分条件——[预算影响](../预算影响分析/)依然可能拖垮一个单位成本可负担的产品。
- **忽视阈值本身会变动**：NICE 的严重程度调整系数（2022 年）和定期评审都会改变实际的 λ；务必为你的主张标注日期。
- **把另一种货币的 ICER 与阈值比较却不先换算**：见[跨币种 ICER 比较](../跨币种-icer-比较/)——换算方法（购买力平价与市场汇率）在方法学上具有决定性，不是舍入细节。
- **把基于 λ 的估值与劳动力市场的 VSL/VPF 传统混用**：它们来自不同的理论传统（受卫生预算约束的方法论与从工资—风险权衡中揭示的偏好），并不总是相容——关于为生命估值的替代性揭示偏好方法，见[统计生命价值](../统计生命价值/)。
