# Утримання та відтік

Утримання та відтік вимірюють, чи продовжують користувачі використовувати медичний застосунок з часом, чи припиняють.

## Чому це важливо

Рівні відтоку медичних застосунків зазвичай значно вищі, ніж у звичайних споживчих застосунках.

## Математика

```
Щомісячний рівень відтоку = кількість втрачених користувачів за місяць / загальна кількість користувачів на початок місяця × 100%
```

## Розібраний приклад

Застосунок психічного здоров'я: на початку 5000, втрачено 750 = щомісячний рівень відтоку 15%.

## Зв'язок з інженерією програмного забезпечення

Довгостроковий наслідок [метрик залученості](../метрики-залученості/) та безпосередньо впливає на [одиничну економіку медичних застосунків](../одинична-економіка-медичних-застосунків/).

## Підводні камені

- **Розгляд початкового відтоку користувачів як нормального без подальшого дослідження.**
