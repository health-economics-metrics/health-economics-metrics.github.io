# अनुपालन और दृढ़ता

अनुपालन यह है कि वास्तविक उपयोग निर्धारित उपयोग से कितना मेल खाता है। दृढ़ता यह है कि बंद होने से पहले उपयोग कितने समय तक जारी रहता है।

## यह क्यों महत्वपूर्ण है

भुगतानकर्ता पहले से ही इन संख्याओं पर चलते हैं: PDC ≥80% US Medicare Star Ratings में फीड करता है।

## गणित

```
MPR = Σ दिनों की आपूर्ति / अवधि में दिन × 100
PDC = आपूर्ति द्वारा कवर किए गए दिन / अवधि में दिन × 100
```

## हल किया गया उदाहरण

एक डिजिटल CBT-फॉर-इनसोम्निया उत्पाद, 6 सप्ताह में 6 मॉड्यूल के रूप में निर्धारित:

```
QALY प्राप्त = 1,000 × 0.38 × 0.025 = 9.5
प्रति QALY लागत = 250,000 / 9.5 ≈ £26,300
```
