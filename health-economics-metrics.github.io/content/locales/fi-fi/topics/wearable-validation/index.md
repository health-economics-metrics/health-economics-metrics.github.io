# Puettavien laitteiden validointi

Puettavien laitteiden validointi on prosessi, jolla varmistetaan, ovatko kuluttajien puettavien laitteiden (älykellot, aktiivisuusrannekkeet) tiedot kliinisesti tarkkoja ja luotettavia.

## Miksi se on tärkeä

Kuluttajien puettavia laitteita ei usein ole validoitu lääkinnällisten laitteiden sääntelystandardien mukaisesti.

## Matematiikka

```
Keskimääräinen absoluuttinen prosentuaalinen virhe (MAPE) = (1/n) × Σ |todellinen arvo − mitattu arvo| / todellinen arvo × 100 %
```

## Ratkaistu esimerkki

Ranteessa pidettävä sykeanturi: MAPE 4,2 % verrattuna EKG-standardiin (nousee 8,5 %:iin liikunnan aikana).
