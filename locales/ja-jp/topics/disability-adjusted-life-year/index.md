# 障害調整生存年(DALY)

DALYとは、失われた健康な生存年数のことであり、[QALY](../quality-adjusted-life-year/)の負担側の鏡像です。QALYが*得られた*健康を数えるのに対し、DALYは疾病によって*失われた*健康を数えます;介入は**回避された**DALYによって評価されます。

## なぜ重要か

DALYはグローバルヘルスの標準です(WHO、Global Burden of Disease研究、そして大半の低・中所得国の保健省がDALY単位で計画を立てます)。あなたのソフトウェアが国際的な医療システム、ドナー、あるいはWHOと連携したプログラムを対象とするなら、価値の言語は得られたQALYではなく回避されたDALYです。WHO-CHOICEの歴史的なベンチマーク:1人あたりGDPの1倍未満のコストでDALYを回避する介入は「非常に費用対効果が高い」、1〜3倍は「費用対効果が高い」(WHOは現在、これらの区分を硬直的に使うことを推奨していませんが、実務では依然として広く使われています)。

## 数式

```
DALY = YLL + YLD

YLL(損失生存年)     = 死亡数 × 死亡時年齢における標準余命
YLD(障害生存年)     = 有病率 × 障害の重み

障害の重み ∈ [0, 1]、0 = 完全な健康、1 = 死亡と同等
(重みはGlobal Burden of Disease研究によって公表される)
```

## 計算例

ある地域のスクリーニング・リマインダー・プラットフォームが、ある疾患の早期発見を増やします。年間で10件の早死(それぞれ標準余命に対して20年を失う)を防ぎ、障害の重みが0.2の状態を1年生きる人を200人防ぎます。

```
回避されたYLL = 10 × 20        = 200
回避されたYLD = 200 × 0.2      = 40
回避されたDALY               = 年間240
```

このプラットフォームの運用費が年間60万ドルなら、回避されたDALY1つあたりの費用は600,000 / 240 = **2,500ドル**です。1人あたりGDPが8,000ドルの国では、これは1倍GDPのベンチマークを大きく下回ります — WHO-CHOICEの用語で言えば「非常に費用対効果が高い」です。

## ソフトウェア工学との関連

- グローバルヘルスの資金提供者(Gavi、Global Fund、各国のプログラム)を対象とするデジタルヘルスは、影響を**回避されたDALYあたりの費用**として表現すべきです — これは助成金審査員がすでに考えている尺度です。
- DALYは、エンジニアリングにとっても有用な*負担会計*のテンプレートです:インシデント、不安定なビルド、レガシーの摩擦は、コードベースにとっての「障害を伴って生きた年数」です — 手間の重みをつけた負担一覧を作れば、GBDの負担表が保健支出の方向性を示すのと同じように、修復がどこで最も多くの「健全なエンジニアリング年」を買えるかがわかります。

## 落とし穴

- **獲得QALYと回避DALYは数値として同じではありません** — 異なる重み、異なる生命表、異なる慣習(DALYは歴史的に、測定手法の内部で年齢による重み付けと割引を使っていました)。安易に変換しないでください。
- **GDPの倍数による閾値を機械的な承認印として使うこと** — WHO自身が、これらは予算や機会費用を無視していると警告しています;[支払意思額の閾値](../willingness-to-pay-thresholds/)を参照してください。
- **利用者1人あたりの効果から、普及率や継続率を掛け合わせることなく集団規模のDALYを主張すること** — [到達範囲と公平性](../reach-and-equity/)を参照してください。
