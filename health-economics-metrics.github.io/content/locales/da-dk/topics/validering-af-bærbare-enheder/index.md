# Validering af bærbare enheder

Validering af bærbare enheder er processen med at verificere, om data fra forbrugernes bærbare enheder (smartwatches, aktivitetsmålere) er klinisk nøjagtige og pålidelige.

## Hvorfor det er vigtigt

Forbrugernes bærbare enheder er ofte ikke valideret efter regulatoriske standarder for medicinsk udstyr.

## Matematikken

```
Gennemsnitlig absolut procentvis fejl (MAPE) = (1/n) × Σ |faktisk værdi − målt værdi| / faktisk værdi × 100 %
```

## Gennemarbejdet eksempel

En håndledsbåret pulssensor: MAPE 4,2 % sammenlignet med EKG-standarden (stiger til 8,5 % under træning).
