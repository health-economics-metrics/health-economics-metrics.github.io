# Praktiku aeg

Praktiku aega tuleks hinnata kitsaskoha võimsusena — see, mida süsteem saab tarnida — mitte lihtsalt palgakuluna.

## Miks see on oluline

Säästetud arstitund on sageli palju väärtuslikum, kui arsti tunnipalk viitab, kuna arsti aeg on süsteemivõimsuse siduv piirang.

## Matemaatika

```
Säästetud aja väärtus = Säästetud tunnid × kitsaskoha võimsuse varihind
```

## Lahendatud näide

Radioloog teenib £80/tunnis, kuid iga säästetud radioloogitund võimaldab tõhusalt £300 järelvoolu patsiendipropustvõimet järjekorrasurve tõttu.

## Seos tarkvaraarendusega

Sarnaneb vanemarhitekti aja hindamisega nende otsuste kitsaskoha väärtuse, mitte ainult palga põhjal.

## Lõksud

- **Ainult palgakulu kasutamine säästetud aja hindamiseks.**
- **Mitte-kitsaskoha rollidele sama varihinna andmine kui kitsaskoha rollidele.**
