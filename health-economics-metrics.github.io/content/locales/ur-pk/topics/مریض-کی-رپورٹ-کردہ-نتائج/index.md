# مریض کی رپورٹ کردہ نتائج (PROM، PREM، MCID)

PROM معیاری آلات ہیں جہاں مریض اپنی صحت کی حالت کی خود رپورٹ کرتے ہیں۔ **MCID** سب سے چھوٹی سکور تبدیلی ہے جسے مریض اصل میں فائدہ مند سمجھتے ہیں۔

## یہ کیوں اہم ہے

PROM ڈیجیٹل صحت کے لیے بنیادی تاثیر کی کرنسی ہے۔

## ریاضی

```
ردعمل کی شرح فریم ورک:
  ردعمل دینے والا = مریض جس میں بہتری ≥ MCID
  NNT = 1 / (ردعمل_شرح_علاج − ردعمل_شرح_کنٹرول)
```

## حل شدہ مثال

ایک ڈپریشن-معاونت ایپ، RCT بمقابلہ انتظار کی فہرست: NNT ≈ 4۔

## سافٹ ویئر انجینئرنگ سے تعلق

PROM ایک ڈیٹا-جمع کرنے کا مسئلہ ہے جسے سافٹ ویئر خاص طور پر حل کر سکتا ہے۔ کام کی پیداواریت سے مخصوص آلے کے لیے [WPAI](../کام-کی-پیداواریت-اور-سرگرمی-کی-خرابی/) دیکھیں۔
