# 投资回报率（ROI）

ROI是净收益与投入资金之比。它是工程与财务领域早已共用的指标——健康经济学在此基础上增添的纪律，能让一项ROI主张经受住审查：明确声明的视角、对照方案、时间范围，以及效益分类。

## 为何重要

ROI是预算持有者的通用语言，公共卫生领域同样使用它：Masters等人具有里程碑意义的综述发现，公共卫生干预措施的**ROI中位数为14.3:1**（每£1能为更广泛的经济与卫生系统带来约£14的回报）——这一数字被广泛用于论证预防性支出的正当性。但那个14:1，是一个*社会层面、长时间范围*的数字；而一位医院CFO所关心的ROI，是支付方视角下1–3年的数字。大多数关于ROI的争论，其实都是未声明视角之争。

## 计算方法

```
ROI = (效益 − 成本) / 成本      （通常 × 100%表示）

回本周期 = 成本 / 年度净效益
```

一项ROI主张，若缺少以下四项声明，就是界定不完整的：

1. **视角**——谁的效益才算数？（参见[分析视角](../分析视角/)）
2. **对照方案**——相对于哪个替代方案？（参见[机会成本](../机会成本/)）
3. **时间范围**——覆盖多长时间，是否经过[贴现](../贴现与时间偏好/)？
4. **效益类别**——现金释放型、产能型，还是定性效益？（参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)）

## 实例演算

某电子排班系统，3年期成本£500,000。

```
现金释放型：  中介班次减少              £450,000
产能：       病区经理行政时间被释放     £600,000（已估值，但未真正入账）
定性效益：    员工满意度、安全性        未货币化

严格财务ROI  = (450,000 − 500,000)/500,000 = −10%
经济学ROI    = (1,050,000 − 500,000)/500,000 = +110%
```

两个数字都是真实的。向一位只能入账£450,000现金的CFO宣称"+110%的ROI"，会失去信任；同时呈现二者、并分别标注清楚，才能赢得信任。同样的拆分，也能在两年后财务部门审计这些效益时，保护住内部的推动者。

## 与软件工程的联系

每一份工具提案都有一张ROI幻灯片；却几乎没有一份声明了这四个参数。最常见的失败，是类别混用：把产能收益（开发者节省的分钟数）包装成财务回报呈现。应像上文实例演算那样结构化地呈现AI/平台的ROI——现金线、产能线、定性效益线——并对那些软性数字附加[敏感性分析](../敏感性分析/)。关于AI投资回报率具体的损益表现实检验，参见[AI投资回报率](../AI投资回报率/)。

## 陷阱

- **视角洗白**：把跨越十年的社会层面效益，说给一位时间范围只有12个月的预算持有者听。
- **用毛值代替净值**："在£200万支出上带来£300万回报"，那是50%的ROI，而不是300%。
- **比值最大化**：微小的分母能在无关紧要的投资上产生惊人的ROI数字；投资组合应按净现值或[净货币效益](../净货币效益/)排序，ROI只应作为初筛工具。
- **没有效益审计**：预测的ROI若没有[效益兑现](../效益兑现/)追踪，只是一个承诺，而非一个结果。
