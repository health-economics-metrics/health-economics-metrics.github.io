# DORA-metrieken

DORA-metrieken zijn vier maatstaven voor softwareleveringsprestaties — deploymentfrequentie, wijzigingsleadtime, wijzigingsfaalpercentage en hersteltijd.

## Waarom het ertoe doet

Tien jaar DORA-onderzoek koppelt deze metrieken aan organisatieprestaties.

## De wiskunde

```
Leadtime = t(deployment) − t(commit), mediaan
```

## Uitgewerkt voorbeeld

Een patiëntstroomsoftwareteam van een zorgtrust, voor/na: deployments van maandelijks → wekelijks.

## Verbinding met software-engineering

Dit is *precies* de softwarekant.
