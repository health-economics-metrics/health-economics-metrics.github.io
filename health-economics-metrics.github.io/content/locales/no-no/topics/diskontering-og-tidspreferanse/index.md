# Diskontering og tidspreferanse

Diskontering konverterer fremtidige kostnader og effekter til nåverdien deres, fordi mennesker og systemer foretrekker nytte nå fremfor nytte senere.

## Hvorfor det er viktig

Uten diskontering ville en intervensjon som gir nytte om 30 år, sett like attraktiv ut som en som gir nytte i morgen.

## Matematikken

```
Nåverdi = Fremtidig verdi / (1 + r)^t
```

Green Book/NICE-renten er **3,5 %** per år for både kostnader og helseeffekter.

## Gjennomarbeidet eksempel

Et forebyggingsprogram som gir £1 million i nytte om 10 år: nåverdi = £1 000 000 / (1,035)^10 ≈ £708 900.

## Kobling til programvareutvikling

Beslutninger om teknisk gjeld involverer lignende diskonteringslogikk — se [teknisk gjeld](../teknisk-gjeld/).

## Fallgruver

- **Å bruke en for høy rente for å fortrenge fremtidige kostnader.**
- **Å bruke ulike renter for kostnader og helse uten begrunnelse.**
