# Produttività degli Sviluppatori con l'IA

Metriche per ciò che l'assistenza alla codifica IA fa realmente all'output ingegneristico: tasso di accettazione dei suggerimenti, aumento di velocità in studi controllati.

## Perché è importante

I due studi controllati più citati puntano in direzioni opposte:

- **Peng et al. 2023 (GitHub Copilot RCT)**: gli sviluppatori hanno completato un compito greenfield **il 55,8% più velocemente**.
- **METR 2025 RCT**: sviluppatori open-source esperti erano **il 19% più lenti** sui propri repository maturi.

## La matematica

```
Tasso di accettazione = suggerimenti accettati / suggerimenti mostrati
```

## Esempio risolto

Un'organizzazione con 500 sviluppatori testa un assistente con un controllo adeguato: valore ≈ £990.000/anno di capacità.

## Collegamento con l'ingegneria del software

Importazioni dall'economia sanitaria per chi valuta strumenti IA: eseguire **prove pragmatiche**.
