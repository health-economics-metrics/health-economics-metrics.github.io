# Prevenzione degli Accessi al Pronto Soccorso

La prevenzione degli accessi al pronto soccorso conta le visite al PS e i ricoveri di emergenza prevenuti da un intervento a monte.

## Perché è importante

L'assistenza di emergenza è l'ambiente di routine più costoso del sistema.

## La matematica

```
Accessi evitati = popolazione × (tasso di base − tasso con intervento)
```

## Esempio risolto

Un servizio di monitoraggio remoto per BPCO per 3.000 pazienti ad alto rischio: netto ≈ +£342.000/anno.
