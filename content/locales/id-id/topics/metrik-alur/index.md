# Metrik Alur

Metrik alur mengukur bagaimana pekerjaan bergerak melalui sistem pengiriman: waktu siklus, waktu tunggu, throughput, pekerjaan dalam proses (WIP).

## Mengapa ini penting

Sebagian besar waktu pengiriman bukanlah pekerjaan — melainkan menunggu.

## Matematika

```
Hukum Little: WIP rata-rata = throughput × waktu siklus rata-rata
```

## Contoh yang diselesaikan

Sebuah tim memiliki 40 item dalam proses: mengurangi WIP menjadi 15 membuat waktu siklus menjadi **1,5 minggu**.

## Hubungan dengan rekayasa perangkat lunak

Metrik alur adalah bahasa bersama antara rekayasa pengiriman dan operasi kesehatan.
