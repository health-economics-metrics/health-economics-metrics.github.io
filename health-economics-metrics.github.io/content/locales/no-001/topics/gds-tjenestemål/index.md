# GDS-tjenestemål

GDS-tjenestemål (Government Digital Service) er fire nøkkeltall for ytelsen til digitale offentlige tjenester: brukertilfredshet, fullføringsgrad, kostnadsbesparelse og digital bruk.

## Hvorfor det er viktig

Digitale offentlige tjenester må vise resultater for skattebetalerne.

## Matematikken

```
Fullføringsgrad = fullførte transaksjoner / startede transaksjoner × 100 %
```

## Gjennomarbeidet eksempel

En nettbasert pasientregistreringstjeneste: 10 000 startet, 8 200 fullført = 82 % fullføringsgrad.

## Kobling til programvareutvikling

Begrunner sammen med [realisering av gevinster](../realisering-av-gevinster/) offentlige digitale investeringer.

## Fallgruver

- **Å bare se på digital bruk, ignorere kostnadene ved offline-kanaler.**
