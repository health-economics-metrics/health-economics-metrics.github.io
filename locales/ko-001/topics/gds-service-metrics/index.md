# GDS 서비스 지표

GDS(정부 디지털 서비스) 서비스 지표는 디지털 공공 서비스의 성과를 측정하는 네 가지 핵심 지표입니다: 사용자 만족도, 완료율, 비용 절감, 디지털 이용률.

## 왜 중요한가

공공 부문 디지털 서비스는 납세자에게 성과를 입증해야 합니다.

## 수식

```
완료율 = 완료된 거래 / 시작된 거래 × 100%
```

## 계산 예시

온라인 환자 등록 서비스: 시작 10,000건, 완료 8,200건 = 82% 완료율.

## 소프트웨어 공학과의 연관성

[편익 실현](../benefits-realization/)과 함께 공공 부문 디지털 투자를 정당화합니다.

## 함정
