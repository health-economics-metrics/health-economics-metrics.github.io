# Osta versus ehita

Osta versus ehita analüüs võrdleb olemasoleva lahenduse ostmise kulusid ja riske kohandatud lahenduse ehitamisega sisemiselt.

## Miks see on oluline

See on üks levinumaid ja kõrgeima panusega tehnoloogiaotsuseid, mida organisatsioonid teevad, mõjutades kulusid, kiirust turule ja pikaajalist paindlikkust.

## Matemaatika

```
Otsustuskriteerium: Ehitamise TCO + strateegiline väärtus versus Ostmise TCO + sõltuvuse risk
```

## Lahendatud näide

Kohandatud patsiendihaldussüsteemi ehitamine maksab £2 miljonit ja 18 kuud, samas kui olemasoleva lahenduse ostmine maksab £200 000/aastas, kuid piirab kohandamist — otsus sõltub sellest, kas kohandamine on strateegiliselt kriitiline.

## Seos tarkvaraarendusega

See ongi tarkvaraarenduse enda otsustusraamistik, tihedalt seotud [omamise koguhinnaga](../total-cost-of-ownership/).

## Lõksud

- **Ehitamise kulude alahindamine, jättes arvestamata pideva hoolduse.**
- **Ostulahenduse lukustusriski ja tuleviku hinnamuutuste eiramine.**
