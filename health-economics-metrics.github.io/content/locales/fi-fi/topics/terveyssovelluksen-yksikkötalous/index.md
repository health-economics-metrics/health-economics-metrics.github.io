# Terveyssovelluksen yksikkötalous

Terveyssovelluksen yksikkötalous mittaa käyttäjäkohtaisia kustannuksia hankinnalle, käytölle ja tuotetulle arvolle.

## Miksi se on tärkeä

Jopa kliinisesti tehokkaita sovelluksia ei voida skaalata, jos yksikkötalous ei ole kestävä.

## Matematiikka

```
Elinkaariarvon ja hankintakustannuksen suhde = käyttäjän elinkaariarvo (LTV) / käyttäjän hankintakustannus (CAC)
```

## Ratkaistu esimerkki

Krooninen sairaudenhallintasovellus: LTV £180, CAC £45 = suhde 4:1 (pidetään kestävänä).

## Yhteys ohjelmistokehitykseen

[Pysyvyys ja poistuma](../pysyvyys-ja-poistuma/) on LTV:n tärkein tekijä, ja [pilven yksikkötalous](../pilven-yksikkötalous/) muodostaa käyttökustannuspuolen.

## Sudenkuopat

- **Uudelleenhankintakustannusten (poistuman jälkeen) sisällyttämättä jättäminen hankintakustannukseen.**
