# ملکیت کی کل قیمت (TCO)

TCO ایک نظام کی زندگی میں مکمل قیمت ہے: حصول یا تعمیر، انضمام، آپریشن، دیکھ بھال۔ غیر آرام دہ بنیادی خط: **دیکھ بھال سافٹ ویئر TCO کا 50–80% ہے**۔

## یہ کیوں اہم ہے

صحت کی ٹیکنالوجی کی تشخیص نے بہت پہلے سیکھا کہ دوا کی قیمت اس کی لاگت نہیں ہے۔

## ریاضی

```
TCO = ابتدائی قیمت + Σ_t [آپریشن + دیکھ بھال + سپورٹ]_t / (1 + r)^t
```

## حل شدہ مثال

ایک ای-آبزرویشن نظام کے دو آپشنز، 5-سالہ افق: غیر رعایتی TCO £1,090,000 بمقابلہ £2,030,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرز تعمیر کی وکالت کرتے وقت اپنے ہی شعبے کے دیکھ بھال کے اعداد و شمار کو کم اہمیت دیتے ہیں۔ اوپر جیسا کثیر سالہ TCO کا عدد وقت کے ساتھ بہت سی لاگت کی مدوں کا مجموعہ ہے — جیسے ہی ماڈل کو سینٹ تک ملنا ہو، وہ مجموعہ فلوٹنگ پوائنٹ کی بجائے درست اعشاری کیوں ہونا چاہیے اس کے لیے [کرنسی کے لحاظ سے محفوظ لاگت کا مجموعہ](../کرنسی-کے-لحاظ-سے-محفوظ-لاگت-کا-مجموعہ/) دیکھیں، اور کل TCO کو سینٹ کھوئے بغیر لاگت کے مراکز میں بانٹنے کے لیے [سینٹ تک درست لاگت کی تقسیم](../سینٹ-تک-درست-لاگت-کی-تقسیم/) دیکھیں۔
