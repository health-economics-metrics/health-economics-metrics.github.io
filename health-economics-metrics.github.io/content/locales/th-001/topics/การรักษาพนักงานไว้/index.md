# การรักษาพนักงานไว้

การรักษาพนักงานไว้วัดสัดส่วนของพนักงานที่ยังคงทำงานต่อในช่วงระยะเวลาหนึ่ง โดยต้นทุนการหมุนเวียนพนักงานและเศรษฐศาสตร์ของภาวะหมดไฟเป็นด้านการเงินที่ซ่อนอยู่

## ทำไมจึงสำคัญ

พนักงานที่ลาออกแต่ละคนมีค่าใช้จ่ายมากกว่าเพียงต้นทุนการสรรหาอย่างมาก — เวลาในการปรับตัว การสูญเสียผลผลิต และการหยุดชะงักของทีมล้วนมีความสำคัญ

## คณิตศาสตร์

```
ต้นทุนการหมุนเวียน = ต้นทุนการสรรหา + ต้นทุนการปรับตัว + (การสูญเสียผลผลิต × ระยะเวลาการปรับตัว)
```

ประมาณการโดยทั่วไปอยู่ที่ 50–200% ของเงินเดือนประจำปีของพนักงานที่ลาออก

## ตัวอย่างที่คำนวณแล้ว

พยาบาลที่มีเงินเดือนประจำปี £35,000 ซึ่งลาออกมีต้นทุนการหมุนเวียนรวมโดยประมาณ £45,000 เมื่อพิจารณาการสรรหา การปรับตัว และการขาดแคลนพนักงานชั่วคราว

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

เปรียบเทียบได้โดยตรงกับ [SPACE และ DevEx](../space-และ-devex/) — การหมุนเวียนของทีมทำลายความรู้โดยปริยายและทำให้การส่งมอบหยุดชะงัก ซึ่งมีค่าใช้จ่ายสูงกว่าที่คิด

## ข้อผิดพลาดที่พบบ่อย

- **การนับเฉพาะต้นทุนการสรรหาโดยตรง โดยไม่สนใจการสูญเสียความรู้**
- **การระบุสาเหตุการหมุนเวียนจากภาวะหมดไฟว่าเป็นปัญหาส่วนบุคคลแทนที่จะเป็นปัญหาเชิงระบบ**
