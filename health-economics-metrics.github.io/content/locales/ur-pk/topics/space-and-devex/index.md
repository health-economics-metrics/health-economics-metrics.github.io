# SPACE اور DevEx

SPACE اور DevEx ڈویلپر کی پیداواریت کو **کثیر جہتی طور پر** ماپنے کے فریم ورک ہیں۔

## یہ کیوں اہم ہے

دونوں فریم ورک وہی مشکل سے حاصل شدہ سبق انکوڈ کرتے ہیں جو صحت کے نتائج کی تحقیق نے دہائیوں پہلے سیکھا تھا۔

## ریاضی

```
SPACE اصول: ≥ 3 جہتیں، ≥ 1 ادراکی + ≥ 1 سسٹم میٹرک
```

## حل شدہ مثال

ایک پلیٹ فارم ٹیم 300 ڈویلپرز کے لیے ایک DevEx سرمایہ کاری کا جواز پیش کرتی ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہ دستاویز *ہے* سافٹ ویئر پہلو؛ منتقلی صحت کی معاشیات کی طرف بہتی ہے۔
