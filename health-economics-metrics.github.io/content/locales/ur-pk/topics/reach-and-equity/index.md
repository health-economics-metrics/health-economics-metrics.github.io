# رسائی اور مساوات

RE-AIM — رسائی، تاثیر، اپنانا، عمل درآمد، دیکھ بھال — ایک مداخلت کے *آبادی* کے اثر کو جانچنے کے لیے معیاری فریم ورک ہے۔ اس کی مرکزی ریاضی: **عوامی صحت کا اثر ≈ رسائی × تاثیر**۔

## یہ کیوں اہم ہے

mHealth پر RE-AIM لاگو کرنے والے منظم جائزے ایک مستقل دستخط پاتے ہیں: مضبوط رسائی اور اپنانا، **کمزور تاثیر اور دیکھ بھال**۔

## ریاضی

```
آبادی کا اثر ≈ رسائی × تاثیر
  رسائی    = شرکاء / اہل آبادی
  تاثیر    = شرکاء کے درمیان حقیقی دنیا کا اثر

مساوات-درجہ بند ورژن:
  اثر_گروپ_g = رسائی_g × تاثیر_g، محرومی پنجم کے لحاظ سے رپورٹ کیا گیا
```

## حل شدہ مثال

ایک ڈیجیٹل ذیابیطس-روک تھام پروگرام، دو طریقوں سے رپورٹ کیا گیا:

```
مجموعی: رسائی 12%، اثر 0.02 QALY/شریک → 0.0024 QALY/اہل شخص

درجہ بند (محرومی پنجم):
  Q1 (کم ترین محروم): رسائی 22%، اثر 0.02 → 0.0044
  Q5 (زیادہ ترین محروم): رسائی 4%، اثر 0.025 → 0.0010
```

یہ پروگرام کم ترین محروم لوگوں کو 4.4× زیادہ صحت فراہم کرتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

رسائی بنیادی طور پر ایک انجینئرنگ کی کاریگری ہے: ڈیوائس اور OS کی کم از کم ضروریات، بینڈوڈتھ کے مفروضات، زبان کی حمایت۔

## عام غلطیاں

- **مکمل کرنے والوں پر رپورٹ کردہ تاثیر، آبادی پر دعویٰ کردہ اثر۔**
