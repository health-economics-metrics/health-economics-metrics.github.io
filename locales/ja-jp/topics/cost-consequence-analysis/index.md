# 費用結果分析(CCA)

CCAは、費用を**すべてのアウトカムの分解された表**(臨床的、運用的、体験的)と並べて提示し、それらを単一の比率やスコアに縮約することはありません。意思決定者は、トレードオフを明示的に検討します。

## なぜ重要か

CCAは、エビデンス基準フレームワークのもとで、ほとんどのデジタルヘルス技術に対するNICEの**好ましい経済フォーマット**です。デジタル製品は、正直に1つのQALYの数値に集約することに抵抗する異質な効果(節約時間、満足度、DNAの減少、小さな臨床的獲得)を生み出します。脆弱な複合指標を無理に作る代わりに、CCAは完全な台帳を示します。ほとんどのソフトウェアのビジネスケースにとって、これは最も正直なフォーマットであると同時に最も説得力のあるフォーマットでもあります。なぜなら、すべての利害関係者が自分にとって意思決定に関連する行を見つけられるからです。

## 数式

意図的に集約の公式はありません。出力は表です:

```
                          介入       比較対象    差
費用(年間)               £X         £Y         ΔC
アウトカム1(自然単位)     …          …          Δ1
アウトカム2                …          …          Δ2
定性的アウトカム           スコア化せず記述
```

各行は独自の単位を保ちます。ルール:すべての結果を事前に指定する(結果が出た後につまみ食いしない);全体を通して同じ[視点](../analysis-perspective/)と[評価期間](../time-horizon/);行ごとの不確実性。

## 計算例

デジタル術前評価プラットフォーム 対 電話ベースのプロセス、1年あたり、あるトラスト:

```
                              デジタル      電話        差
運用費                        £180,000     £95,000     +£85,000
評価にかかる看護師時間        6,200        11,800      −5,600時間
当日の手術キャンセル          92           174         −82
患者満足度(CSAT)             4.5/5        3.9/5       +0.6
評価の喪失/未完了             1.2%         4.8%        −3.6 pp
```

単一のスコアはありませんが — 意思決定について考えるのは簡単です:£85,000で5,600看護師時間を買え(≈£15/時間、どんな人件費よりもはるかに低い)、82件のキャンセルが回避され(それぞれ約£1,200相当の手術枠を無駄にする)、体験が向上します。委員会はまた、自分たちが*得ていないもの*も正確に見ることができます:主張されたQALYや死亡率への効果はありません。

## ソフトウェア工学との関連

CCAは、優れたプラットフォーム提案がすでに使っているバランス・スコアカードの正式版です:費用とDORAメトリクス、DevExスコア、インシデント件数を並べ、集約しません。加えるべき医療経済学の規律:**行を事前に指定すること**(パイロット試験の前に何を数えるかを決め、悪化した指標をこっそり落とせないようにする)、そして**不利な行も示すこと** — 良いニュースだけのCCAはマーケティングです。弁護可能な複合指標が存在しない場合にCCAを使ってください。開発者向けツールについては、それはほぼ常にそうです。

## 落とし穴

- **つまみ食いされた結果** — このフォーマットの誠実さは事前指定にかかっています。
- **こっそり紛れ込ませた集約**:色分けや「総合スコア」は、CCAが避けようとしている恣意的な重みを再導入してしまいます。
- **意思決定の麻痺**:CCAには、トレードオフを検討する意思のある意思決定者が必要です;推奨とその理由を添えてください。
