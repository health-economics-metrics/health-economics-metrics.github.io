# สัดส่วนที่เกิดจากสาเหตุในประชากร (PAF)

PAF คือสัดส่วนของภาระโรคหรือผลลัพธ์ในประชากรที่เกิดจากการสัมผัสปัจจัยเสี่ยงเฉพาะอย่าง — สัดส่วนที่จะหายไปหากกำจัดการสัมผัสนั้นได้ทั้งหมด มันเปลี่ยน "ปัจจัยเสี่ยงนี้เพิ่มโอกาสของคุณเป็นสองเท่า" ให้เป็นตัวเลขระดับประชากรที่ผู้วางแผนใช้ได้จริง: การสัมผัสนี้คุ้มกับการต่อสู้แค่ไหนในแง่ของจำนวนผู้ป่วยและต้นทุน

## ทำไมจึงสำคัญ

Levin นำ PAF มาใช้ในปี 1953 เพื่อตอบคำถามแคบและเฉพาะเจาะจง: หากไม่มีใครสูบบุหรี่ มะเร็งปอดจะหายไปเท่าใด เลขคณิตเดียวกันนี้ปัจจุบันกำหนดขนาดของการวางแผนป้องกันระดับชาติทั่วโลก ตั้งแต่ยุทธศาสตร์ยาสูบและโรคอ้วนไปจนถึงการจัดอันดับปัจจัยเสี่ยงของงานวิจัย Global Burden of Disease ขององค์การอนามัยโลก เพราะความเสี่ยงสัมพัทธ์อย่างเดียวบอกอะไรเกี่ยวกับผลกระทบน้อยมาก — ปัจจัยเสี่ยงอาจเพิ่มโอกาสของเหตุการณ์หายากเป็นสองเท่าแต่แทบไม่ขยับภาระโรคของประชากร หรือเพิ่มโอกาสของเหตุการณ์ที่พบบ่อยเพียงเล็กน้อยแต่ยังอธิบายผู้ป่วยส่วนใหญ่ PAF เปลี่ยน "ปัจจัยเสี่ยง X อันตราย" เป็น "การกำจัดปัจจัยเสี่ยง X จะป้องกันผู้ป่วยได้เท่านี้ต่อปี" ซึ่งเป็นตัวเลขที่กรณีธุรกิจของโปรแกรมป้องกันต้องการจริงๆ ดู[เศรษฐศาสตร์การป้องกัน](../เศรษฐศาสตร์การป้องกัน/) สำหรับการคิดต้นทุนของการลงมือทำตามตัวเลขนั้นเมื่อมีแล้ว

## คณิตศาสตร์

```
PAF = ความชุกของการสัมผัส × (ความเสี่ยงสัมพัทธ์ − 1) / (1 + ความชุกของการสัมผัส × (ความเสี่ยงสัมพัทธ์ − 1))

ความชุกของการสัมผัส = สัดส่วนของประชากรที่สัมผัสปัจจัยเสี่ยง (0–1)
ความเสี่ยงสัมพัทธ์   = ความเสี่ยงของผลลัพธ์ในผู้สัมผัสเทียบกับผู้ไม่สัมผัส (เช่น 2.5 = 2.5 เท่า)

ผู้ป่วยที่เกิดจากสาเหตุ = จำนวนผู้ป่วยรวม × PAF
```

PAF เพิ่มขึ้นทั้งตามความชุกของการสัมผัสและความเสี่ยงสัมพัทธ์ — ความเสี่ยงสัมพัทธ์ที่สูงขึ้นปานกลาง (สมมุติ 1.5 เท่า) ที่เกี่ยวกับการสัมผัสที่พบบ่อยมากอาจให้ PAF ใหญ่กว่าความเสี่ยงสัมพัทธ์ที่น่าตกใจ (สมมุติ 5 เท่า) ที่เกี่ยวกับการสัมผัสที่หายาก นี่คือเหตุผลทั้งหมดที่มันมีอยู่เป็นตัวเลขแยกต่างหากจากความเสี่ยงสัมพัทธ์

## ตัวอย่างที่คำนวณแล้ว

ปัจจัยเสี่ยงพบใน 30% ของประชากร (`ความชุกของการสัมผัส = 0.3`) และเพิ่มความเสี่ยงของผลลัพธ์ 2.5 เท่า (`ความเสี่ยงสัมพัทธ์ = 2.5`):

```
PAF = 0.3 × (2.5 − 1) / (1 + 0.3 × (2.5 − 1))
    = 0.3 × 1.5 / (1 + 0.3 × 1.5)
    = 0.45 / 1.45
    ≈ 0.3103 (31.0%)

ด้วยผู้ป่วย 1,000 รายต่อปีในประชากร:
ผู้ป่วยที่เกิดจากสาเหตุ = 1,000 × 0.3103 ≈ 310 รายต่อปี
```

เกือบหนึ่งในสามของภาระต่อปีของผลลัพธ์นี้เกิดจากการสัมผัส — การกำจัดทั้งหมด (เพดานทางทฤษฎี ไม่มีมาตรการแทรกแซงจริงใดทำให้การสัมผัสหมดไปได้ 100%) จะป้องกันได้ประมาณ 310 รายจาก 1,000 รายทุกปี

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

PAF คือเวอร์ชันระบาดวิทยาของคำถามที่ว่า "สัดส่วนปริมาณเหตุการณ์ของเราที่เกิดจากสาเหตุรากเหง้านี้เป็นเท่าใด" — คำถามชนิดเดียวกับที่ทีมถามเมื่อวัดคลาสเฉพาะของการปรับใช้หรือการพึ่งพาเทียบกับชุดเหตุการณ์ใน production แทนที่จะถือว่าเหตุการณ์ทุกรายการสมควรได้รับการแก้ไขเท่ากัน หมวดสาเหตุรากเหง้าที่ปรากฏในการปรับใช้ส่วนใหญ่และมีความเสี่ยงสัมพัทธ์ที่ทำให้เกิดเหตุการณ์เพียงปานกลางอาจเหนือกว่าหมวดหายากที่ความเสี่ยงสัมพัทธ์สูงในแง่ที่ควรทุ่มแรงวิศวกรรมก่อน — ข้อสังเกตของ PAF เป๊ะๆ แปลใหม่

## ข้อผิดพลาดที่พบบ่อย

- **รวม PAF ข้ามปัจจัยเสี่ยง**: PAF ของหลายปัจจัยที่ส่งผลต่อผลลัพธ์เดียวกันไม่รวมเป็น 100% — รวมกันอาจเกินได้ เพราะปัจจัยมีปฏิสัมพันธ์และใช้เส้นทางเชิงสาเหตุร่วมกัน ถือแต่ละ PAF เป็น "หากกำจัดเฉพาะปัจจัยนี้" ไม่ใช่การแบ่งสัดส่วนความเสี่ยงทั้งหมด
- **ย้ายความเสี่ยงสัมพัทธ์ข้ามประชากร**: ความเสี่ยงสัมพัทธ์ที่ประมาณในประชากรหนึ่ง (ความชุกการสัมผัสพื้นฐานต่างกัน ปัจจัยกวนต่างกัน) ให้ PAF ที่ชวนเข้าใจผิดเมื่อนำไปใช้กับความชุกของการสัมผัสในอีกประชากรหนึ่ง
- **สับสน PAF กับความเสี่ยงที่เกิดจากสาเหตุในผู้สัมผัส**: PAF อยู่ระดับประชากรและขึ้นกับความชุกของการสัมผัส ความเสี่ยงที่เกิดจากสาเหตุในผู้สัมผัสอยู่ระดับบุคคลและไม่ขึ้นกับความชุก ทั้งสองตอบคำถามต่างกัน — อย่านำอันหนึ่งไปตอบคำถามของอีกอัน
