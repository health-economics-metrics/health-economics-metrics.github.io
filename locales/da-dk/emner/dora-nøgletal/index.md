# DORA-nøgletal

DORA-nøgletal er fire mål for softwareleveringspræstation — udrulningsfrekvens, ledetid for ændringer, fejlrate ved ændring og genopretningstid.

## Hvorfor det er vigtigt

Ti års DORA-forskning kobler disse nøgletal til organisatorisk præstation.

## Matematikken

```
Ledetid = t(udrulning) − t(commit), median
```

## Gennemarbejdet eksempel

Et sundhedsteams software til patientflow, før/efter: udrulninger fra månedlige → ugentlige.

## Forbindelse til softwareudvikling

Dette er *netop* softwaresiden.
