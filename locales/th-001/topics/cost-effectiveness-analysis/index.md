# การวิเคราะห์ความคุ้มทุน (CEA)

การวิเคราะห์ความคุ้มทุนเปรียบเทียบต้นทุนของการแทรกแซงที่แตกต่างกันต่อหน่วยผลลัพธ์ตามธรรมชาติ (เช่น ปีชีวิตที่ได้รับ หรือกรณีที่ตรวจพบ) แทนที่จะใช้หน่วยทั่วไปอย่าง QALY

## ทำไมจึงสำคัญ

CEA มีประโยชน์เมื่อเปรียบเทียบการแทรกแซงภายในพื้นที่โรคเดียวกันที่มีผลลัพธ์ตามธรรมชาติร่วมกันชัดเจน ทำให้ตีความง่ายกว่า CUA สำหรับผู้มีส่วนได้ส่วนเสียทางคลินิก

## คณิตศาสตร์

```
อัตราส่วนความคุ้มทุน = ต้นทุน / หน่วยผลลัพธ์ตามธรรมชาติ
```

## ตัวอย่างที่คำนวณแล้ว

การตรวจคัดกรองสองวิธีเปรียบเทียบกันด้วยต้นทุนต่อกรณีที่ตรวจพบ: วิธี A มีต้นทุน £500 ต่อกรณี วิธี B มีต้นทุน £800 ต่อกรณี — วิธี A มีความคุ้มทุนมากกว่าในแง่นี้

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการเปรียบเทียบต้นทุนต่อข้อบกพร่องที่พบระหว่างกลยุทธ์การทดสอบที่แตกต่างกัน — หน่วยผลลัพธ์ตามธรรมชาติที่เข้าใจง่ายโดยไม่ต้องแปลงเป็นมาตรวัดรวม

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ CEA เพื่อเปรียบเทียบการแทรกแซงที่มีผลลัพธ์ตามธรรมชาติต่างกัน (ควรใช้ CUA แทน)**
- **การเพิกเฉยต่อผลข้างเคียงที่ไม่ถูกจับโดยผลลัพธ์หลักที่เลือก**
