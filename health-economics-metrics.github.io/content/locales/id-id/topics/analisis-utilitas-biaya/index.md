# Analisis Utilitas Biaya (CUA)

CUA adalah analisis efektivitas biaya dengan **hasil umum berbobot preferensi** — hampir selalu [QALY](../tahun-hidup-yang-disesuaikan-kualitas/).

## Mengapa ini penting

Layanan kesehatan nasional harus memilih antara obat kanker, aplikasi kesehatan mental, dan robot bedah dari satu anggaran.

## Matematika

```
ICUR = ΔBiaya / ΔQALY
```

## Contoh yang diselesaikan

Aplikasi CBT untuk kecemasan sedang vs daftar tunggu terapi tatap muka.

## Hubungan dengan rekayasa perangkat lunak

Gagasan mendalam CUA — *satu unit gabungan berbobot preferensi untuk membandingkan hal yang tidak serupa*.

## Jebakan

- **Perolehan utilitas di bawah sensitivitas instrumen.**
