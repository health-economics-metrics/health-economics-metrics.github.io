# भुगतान करने की इच्छा सीमा

भुगतान करने की इच्छा (WTP) सीमा वह अधिकतम राशि है जो एक निर्णय-निर्माता स्वास्थ्य लाभ की प्रति इकाई चुकाएगा — वह रेखा जो एक [ICER](../incremental-cost-effectiveness-ratio/) को स्वीकार/अस्वीकार निर्णय में बदल देती है।

## यह क्यों महत्वपूर्ण है

| निकाय | सीमा |
|---|---|
| NICE (इंग्लैंड) | £20,000–£30,000 प्रति QALY |
| ICER (US) | $100,000–$150,000 प्रति QALY/evLYG |
| कनाडा (CADTH) | ≈ CAD$50,000 प्रति QALY |

## गणित

```
ICER = ΔC/ΔE < λ हो तो स्वीकार करें
समकक्ष रूप से: NMB = λ×ΔE − ΔC > 0 हो तो स्वीकार करें
```

## हल किया गया उदाहरण

आपकी डिजिटल थेराप्यूटिक प्रति इलाज किए गए रोगी में 0.05 QALY प्रदान करती है, शुद्ध लागत £800 पर।

```
ICER = 800 / 0.05 = £16,000/QALY
```

इंग्लैंड में: £20k से नीचे → वित्तपोषण योग्य।

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

हर इंजीनियरिंग संगठन का एक अंतर्निहित λ होता है: बचाए गए प्रति इंजीनियर-घंटे पर टूलिंग को वित्तपोषित करने की बाधा।

## सामान्य गलतियाँ

- क्षेत्राधिकार में **सीमा खरीदारी**।
- **λ को मूल्य फर्श के रूप में मानना।**
- **यह अनदेखा करना कि सीमाएँ बदलती हैं।**
