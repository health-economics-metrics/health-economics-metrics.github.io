# সম্ভাব্যতা সংবেদনশীলতা বিশ্লেষণ (PSA)

PSA প্রতিটি অনিশ্চিত পরামিতিকে একটি সম্ভাবনা বিতরণ বরাদ্দ করে, তাদের সবাইকে একই সাথে হাজার হাজার বার নমুনা করে (Monte Carlo), এবং একটি একক পয়েন্ট অনুমানের পরিবর্তে একটি বিকল্প সেরা পছন্দ হওয়ার *সম্ভাবনা* রিপোর্ট করে।

## কেন এটি গুরুত্বপূর্ণ

NICE-এর রেফারেন্স কেস PSA *প্রয়োজন* করে। নির্ধারক বিশ্লেষণ "যদি একটি ইনপুট ভুল হয় তাহলে কী?" প্রশ্নের উত্তর দেয়; PSA "একসাথে আমরা যা জানি না সবকিছু বিবেচনা করে, আমরা সঠিক সিদ্ধান্ত নিচ্ছি কতটা সম্ভাব্য?" এর উত্তর দেয়। এর স্বাক্ষর আউটপুট, **খরচ-কার্যকারিতা গ্রহণযোগ্যতা বক্ররেখা (CEAC)**, পরিশোধ করার ইচ্ছার প্রান্তসীমার বিরুদ্ধে একটি বিকল্প খরচ-কার্যকর হওয়ার সম্ভাবনা প্লট করে — "ICER হল £24,000/QALY"-কে "£30,000-এ এটি সঠিক পছন্দ হওয়ার 78% সম্ভাবনা আছে"-তে রূপান্তরিত করে।

## গণনা

```
N ড্র-র প্রতিটির জন্য (N ≈ 10,000):
  প্রতিটি পরামিতি θ তার বিতরণ থেকে নমুনা করুন
    (খরচ ~ Gamma, সম্ভাবনা ~ Beta, উপযোগিতা ~ Beta, প্রভাব ~ Normal/logNormal)
  প্রতিটি বিকল্প j-র জন্য NMB_j(θ) = λ × প্রভাব_j(θ) − খরচ_j(θ) গণনা করুন

CEAC_j(λ) = প্রান্তসীমা λ-তে সর্বোচ্চ NMB সহ বিকল্প j-র ড্রয়ের ভগ্নাংশ
```

NMB-র জন্য দেখুন [নিট আর্থিক সুবিধা](../নিট-আর্থিক-সুবিধা/) এবং λ-র জন্য [পরিশোধ করার ইচ্ছার প্রান্তসীমা](../পরিশোধ-করার-ইচ্ছার-প্রান্তসীমা/)।

## বিস্তারিত উদাহরণ

প্ল্যাটফর্ম মাইগ্রেশন ব্যবসায়িক কেস। তিনটি অনিশ্চিত ইনপুট:

```
মাইগ্রেশন খরচ      ~ Gamma,  গড় £800হাজার, sd £200হাজার
বার্ষিক সুবিধা      ~ Normal, গড় £350হাজার, sd £150হাজার
সুবিধা স্থিতিকাল    ~ Uniform, 3-6 বছর
```

10,000 ড্র-র প্রতিটির জন্য নিট সুবিধা = স্থিতিকাল × বার্ষিক − খরচ গণনা করুন (স্পষ্টতার জন্য ছাড় বাদ)। দৃষ্টান্তমূলক ফলাফল:

```
গড় নিট সুবিধা:     £775হাজার
নিট > 0-র সম্ভাবনা: 0.86
5ম-95তম শতাংশক:    −£180হাজার … +£1.9M
```

পয়েন্ট অনুমান বলেছিল "স্পষ্টতই হ্যাঁ।" PSA বলে "86% হ্যাঁ, একটি প্রকৃত লেজ সহ যেখানে আমরা £180হাজার+ হারাই" — যা একজন পোর্টফোলিও মালিকের প্রকৃতপক্ষে প্রয়োজন, এবং এটি প্রথমে একটি অনুসন্ধান স্পাইক চালানোর কেসের মূল্য নির্ধারণ করে (দেখুন [EVPI](../নিখুঁত-তথ্যের-প্রত্যাশিত-মূল্য/))।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

ইঞ্জিনিয়াররা ইতিমধ্যে প্রদান পূর্বাভাসের জন্য Monte Carlo বিশ্বাস করেন (থ্রুপুট নমুনায়ন পয়েন্ট অনুমানকে হারায়)। একই যন্ত্রপাতি টাকায় প্রসারিত করুন: গ্রহণ, সঞ্চিত সময় এবং বেতনের উপর বিতরণ, তারপর মিথ্যা-নির্ভুল ROI-র পরিবর্তে "এই প্ল্যাটফর্ম বিনিয়োগ নিট-ইতিবাচক হওয়ার সম্ভাবনা" রিপোর্ট করুন। একটি CEAC-শৈলীর বক্ররেখা — সংস্থা একজন ইঞ্জিনিয়ার-ঘণ্টা কীভাবে মূল্যায়ন করে তার একটি ফাংশন হিসেবে সেরা বিকল্প হওয়ার সম্ভাবনা — একটি অর্থায়ন কমিটির জন্য যেকোনো একক সংখ্যার চেয়ে প্রকৃতপক্ষে ভালো নিদর্শন।

## ঝুঁকি

- **আবর্জনা বিতরণ**: উদ্ভাবিত মানক বিচ্যুতি সহ PSA একটি ল্যাব কোট পরা নির্ধারক বিশ্লেষণ। তথ্য বা কাঠামোগত বিশেষজ্ঞ প্রাপ্তির উপর বিস্তার ভিত্তি করুন।
- পরামিতির মধ্যে **পারস্পরিক সম্পর্ক উপেক্ষা করা** (উচ্চ গ্রহণ সাধারণত উচ্চ সঞ্চিত-সময়ের সাথে সম্পর্কিত); স্বাধীন নমুনায়ন লেজ ঝুঁকি কম দেখায়।
- সিমুলেশনের **শুধুমাত্র গড় রিপোর্ট করা** — পুরো বিষয়টি হল বিতরণ এবং সিদ্ধান্ত সম্ভাবনা।
