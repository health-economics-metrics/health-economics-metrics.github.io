# Nyttorealisering

Nyttorealisering är disciplinen att spåra och verifiera om ett projekt faktiskt levererade de utlovade nyttorna.

## Varför det är viktigt

Ett affärscase utlovar nyttor, men utan övervakning vet du aldrig om de realiserades.

## Matematiken

```
Nyttorealiseringsgrad = faktiska nyttor / planerade nyttor × 100 %
```

## Genomarbetat exempel

Ett digitalt triageverktyg: planerad besparing £500 000/år; efter 12 månader faktisk £320 000 = 64 % realisering.

## Koppling till mjukvaruutveckling

Verifierar i efterhand påståenden om [ROI](../return-on-investment/) och [social avkastning på investering](../social-return-on-investment/).

## Fallgropar

- **Att avsluta ett projekt utan att mäta nyttorna.**
