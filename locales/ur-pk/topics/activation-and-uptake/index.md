# فعال سازی اور اپنانا

فعال سازی کی شرح سائن اپ کا وہ حصہ ہے جو پہلی بامعنی قدر تک پہنچتا ہے۔ اپنانا آبادی کا ورژن ہے۔

## یہ کیوں اہم ہے

غیر فعال صارفین خالص قیمت ہیں۔

## ریاضی

```
فعال سازی کی شرح = ونڈو میں کلیدی کام مکمل کرنے والے صارفین / سائن اپ × 100
اپنانے کی شرح = اپنانے والے / اہل آبادی × 100
```

## حل شدہ مثال

ایک کمیشنر 80,000 اہل باشندوں کو ایک ذیابیطس-روک تھام ایپ فراہم کرتا ہے: آبادی کی قدر ≈ £1.25M۔

## سافٹ ویئر انجینئرنگ سے تعلق

فعال سازی فنل کا سب سے زیادہ انجینئرنگ-لچکدار مرحلہ ہے۔
