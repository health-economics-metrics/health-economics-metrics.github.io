# Hoitomyöntyvyys ja pysyvyys

Hoitomyöntyvyys mittaa, missä määrin määrättyä hoitoa tai interventiota noudatetaan; pysyvyys mittaa, jatkuuko hoito ajan mittaan.

## Miksi se on tärkeä

Hoito, jota ei noudateta, ei tuota hyötyjä käytännössä, vaikka se olisi tehokas kliinisissä tutkimuksissa.

## Matematiikka

```
Hoitomyöntyvyys (MPR) = määrätyt päivät toimitettu / seurantajakso (päivät) × 100 %
```

## Ratkaistu esimerkki

Digitaalisen lääkemuistutussovelluksen käyttäjät: MPR paranee 65 %:sta ennen interventiota 82 %:iin sen jälkeen.

## Yhteys ohjelmistokehitykseen
