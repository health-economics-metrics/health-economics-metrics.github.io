# ผลิตภาพนักพัฒนาด้วยปัญญาประดิษฐ์

ตัวชี้วัดผลิตภาพนักพัฒนาด้วยปัญญาประดิษฐ์วัดว่าเครื่องมือการเขียนโค้ดที่ช่วยเหลือด้วยปัญญาประดิษฐ์ช่วยปรับปรุงผลผลิตของนักพัฒนาจริงหรือไม่ ไม่ใช่แค่ความเร็วที่รับรู้ได้

## ทำไมจึงสำคัญ

การศึกษาเบื้องต้นแสดงให้เห็นว่าเครื่องมือปัญญาประดิษฐ์สามารถเพิ่มความเร็วในการเขียนบรรทัดโค้ดได้ โดยไม่เพิ่มมูลค่าทางธุรกิจที่ส่งมอบตามสัดส่วน — สิ่งสำคัญคือการวัดสิ่งที่ถูกต้อง

## คณิตศาสตร์

```
ผลกระทบสุทธิต่อผลิตภาพ = (เวลาที่ประหยัดได้ในการเขียนโค้ด) − (เวลาเพิ่มเติมสำหรับการตรวจสอบ การแก้ไขบั๊ก และการแก้ไข)
```

## ตัวอย่างที่คำนวณแล้ว

ทีมที่ประหยัดเวลาเขียนโค้ด 30% ด้วยเครื่องมือที่ช่วยเหลือด้วยปัญญาประดิษฐ์ แต่ใช้เวลาตรวจสอบโค้ดเพิ่มขึ้น 15% เนื่องจากปัญหาคุณภาพ จะได้รับผลประโยชน์สุทธิเพียง 15% ไม่ใช่ 30%

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือสาขาการวิจัยของการพัฒนาซอฟต์แวร์เอง ซึ่งเชื่อมโยงโดยตรงกับกรอบ [ตัวชี้วัด DORA](../dora-metrics/) และ [SPACE/DevEx](../space-and-devex/)

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ปริมาณโค้ดเป็นตัวแทนของผลิตภาพ**
- **การเพิกเฉยต่อต้นทุนคุณภาพปลายน้ำจากการพัฒนาที่เร็วขึ้นในช่วงต้น**
