# پریکٹیشنر کا وقت

پریکٹیشنر کا وقت زیادہ تر صحت کے نظاموں میں سب سے کمیاب وسیلہ ہے۔

## یہ کیوں اہم ہے

آپ جلدی سے مزید GPs، مشیر، یا ماہر نرسیں نہیں بنا سکتے۔

## ریاضی

```
1. تنخواہ کی بنیاد: گھنٹے × مکمل مختص تنخواہ کی شرح
2. آؤٹ پٹ کی بنیاد: گھنٹے → فعال ملاقاتیں × اسکیم قیمت
```

## حل شدہ مثال

ایمبینٹ اسکرائبنگ ایک GP کی فی مشاورت 2 منٹ بچاتی ہے: **فی GP سالانہ 220 گھنٹے**۔

## سافٹ ویئر انجینئرنگ سے تعلق

سینئر انجینئر کا وقت اسی طرح برتاؤ کرتا ہے۔

## عام غلطیاں

- **منٹ × تنخواہ = بچت۔**

## ذرائع
