# 사회적투자수익률(SROI)

SROI는 [ROI](../투자수익률/)를 시장이 가격을 매기지 않는 결과로 확장합니다 — 웰빙, 사회적 연결, 환경적 영향.

## 왜 중요한가

Social Value International의 일곱 가지 원칙에 의해 규제되는 SROI는 "투자된 £1당 £3.20의 사회적 가치"와 같은 진술을 생성합니다.

## 수식

```
SROI 비율 = PV(화폐화된 사회적 결과) / PV(투자)
```

## 계산 예시

친구 만들기 앱이 고립된 노인들을 자원봉사자와 연결합니다: SROI ≈ 8.5:1.

## 소프트웨어 공학과의 연관성

SROI는 수혜자가 지불하는 팀 외부에 있는 공학 작업을 위한 정직한 프레임워크입니다.
