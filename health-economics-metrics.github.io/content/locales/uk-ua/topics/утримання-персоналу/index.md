# Утримання персоналу

Утримання персоналу вимірює відсоток співробітників, які залишаються на роботі протягом певного періоду, з витратами на плинність кадрів та економікою вигорання як фінансовим зворотним боком.

## Чому це важливо

Кожен співробітник, що йде, коштує значно більше, ніж просто витрати на найм — час адаптації, втрачена продуктивність та порушення роботи команд усі мають значення.

## Математика

```
Витрати на плинність = витрати на найм + витрати на адаптацію + (втрата продуктивності × період адаптації)
```

Оцінки зазвичай досягають 50–200% річної зарплати співробітника, що йде.

## Розібраний приклад

Медсестра з річною зарплатою £35 000, яка йде, коштує приблизно £45 000 загальних витрат на плинність, враховуючи найм, адаптацію та тимчасову нестачу персоналу.

## Зв'язок з інженерією програмного забезпечення

Прямо порівнянне з [SPACE та DevEx](../space-та-devex/) — плинність команди руйнує неявні знання та порушує доставку, набагато дорожче, ніж здається.

## Підводні камені

- **Врахування лише прямих витрат на найм, ігнорування втрати знань.**
- **Приписування плинності, спричиненої вигоранням, індивідуальним, а не системним причинам.**
