# Evaluasi Regulasi AI

Kerangka kerja regulasi yang mengatur AI dalam layanan kesehatan — rezim Software as a Medical Device (SaMD) FDA dengan **Rencana Kontrol Perubahan yang Ditentukan Sebelumnya (PCCP)**.

## Mengapa ini penting

Regulasi menentukan baik **biaya bukti masuk pasar** maupun **biaya setiap pembaruan model berikutnya**.

## Matematika

```
Biaya per pembaruan model (tradisional) = biaya pengajuan ulang + penundaan tinjauan × CoD
```

## Contoh yang diselesaikan

Vendor AI radiologi merencanakan perbaikan model triwulanan selama 3 tahun: penghematan jalur PCCP ≈ £2,75 juta.

## Hubungan dengan rekayasa perangkat lunak

Merekayasa PCCP dengan baik adalah masalah perangkat lunak.

## Jebakan

- **Mimpi perluasan cakupan PCCP.**

## Sumber

- FDA, AI-enabled device software / SaMD.
