# 在院日数(LOS)

在院日数とは、入院から退院までの日数のことであり、入院ケアの中核となるフロー効率のメトリクスです。英国の急性期の平均は4〜5日程度で推移しており、超過する1日ごとに希少な病床を消費し、患者を院内感染リスクにさらします。

## なぜ重要か

LOSは急性期病院の経済学のほぼすべてを左右します:病床容量、選択的処置のスループット、救急のフロー、人員配置。規模において平均LOSをわずかな日数でも削減することは、莫大な容量を解放します([節約された病床日数](../節約された病床日数/)を参照)。LOSはまた、両方向の質のシグナルでもあります — 長すぎることはプロセスの失敗(遅れた診断、退院書類、社会的ケアの待機)を示唆し、短すぎることは早すぎる退院を意味することがあり、それは後に[再入院](../再入院率/)として現れます。

## 数式

```
LOS(1入院あたり)  = 退院日 − 入院日
平均LOS           = 占有病床日数 / 退院数(平均値と中央値の両方を報告する;
                    LOSは長期滞在の外れ値によって強く右に歪む)

比較には症例構成の調整(年齢、診断、重症度)が必要であり、
そうでなければ、病院がどう機能しているかではなく、誰を入院させているかを測定していることになる。
```

リトルの法則はフロー変数をつなぎます:「占有病床数 = 入院率 × 平均LOS」 — これはソフトウェアのキューを支配するのと同じ法則です([フローメトリクス](../フローメトリクス/)を参照)。

## 計算例

あるトラストは、平均LOS 6.0日で1日あたり40人の緊急内科患者を入院させています:240床が恒常的に占有されています(40 × 6)。退院調整ソフトウェア(タスク追跡、薬局から持ち帰りの自動化、交通手段の予約)は、在院の非臨床的な末尾部分を平均0.4日削減します。

```
必要な病床数 = 40 × 5.6 = 224 → 16床が継続的に解放される
             = 16 × 365 = 年間5,840病床日
```

[節約された病床日数](../節約された病床日数/)に従って、5,840病床日を仕組み(埋め戻し/閉鎖/余裕)ごとに評価してください。何が動いたかに注目してください:医療ではなく*待機*です — 患者は医学的には健康であり、システムはまだ書類作業をしていました。それはキューイングの問題であり、ソフトウェアはキューイングの問題を得意とします。

## ソフトウェア工学との関連

LOSは病院のサイクルタイムであり、改善の手順書はデリバリーフローの作業とまったく同じです:各段階を計測し(入院 → 治療 → 医学的に健康 → 実際に退院)、時間が滞留する場所を見つけ(それは引き継ぎの部分です)、容量を追加するのではなく待機状態を取り除きます。「医学的には退院可能だがまだ病床を占有している」というコホートは、病院版の「承認されたがマージされていないPR」です。直接的なソフトウェアの機会:退院タスクのオーケストレーション、診断のターンアラウンド、退院時薬剤のe処方、社会的ケアへの紹介の統合。

## 落とし穴

- **平均値のみの報告** — 外れ値が支配的になり、下がっていく平均値が増大する長期滞在の裾を隠すことがあります。
- 前後比較の主張における**症例構成の調整の欠如**:入院の閾値は季節的にも長期的にも変化します。
- **LOSの削減が再入院として再び現れること** — LOSの主張には常に30日再入院データを併せてください。
