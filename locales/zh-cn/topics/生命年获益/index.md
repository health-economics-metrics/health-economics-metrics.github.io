# 生命年获益 (Life-Years Gained，LYG)

生命年获益是指一项干预措施所带来的额外生存时间，不做任何质量调整：即有干预与无干预两条生存曲线之间的面积。等值生命年获益（equal-value life year gained，evLYG）是其现代变体，对所有延长的生命一视同仁地计值。

## 为什么重要

LYG是最原始的健康结局：人们究竟能多活多久？在缺乏质量数据时、在面向对QALY持怀疑态度的受众时，以及在生存曲线是主要试验产出的肿瘤学领域，这一指标尤为重要。**evLYG**（美国ICER研究所在报告每QALY成本的同时也会使用）之所以存在，是出于一种伦理考量：QALY按患者的效用值为延长的一年生命计值，因此为一位残障人士延长生命，其"分值会更低"；而evLYG为每一延长的一年赋予固定的效用值，从而消除这种歧视。

## 计算方法

```
LYG = 新方案平均生存期 − 对照方案平均生存期
    = 生存曲线之间的面积（限定在所研究的时间跨度内）

QALY视角下的生命延长价值：  延长时长 × 患者效用值
evLYG视角下的生命延长价值： 延长时长 × 固定效用值（ICER采用约0.851，
                            即美国人群的平均效用值）
```

两者在经济学模型中都需要[贴现](../贴现与时间偏好/)。

## 算例

某医院的脓毒症早期预警算法：模型显示更早使用抗生素每年可避免12例死亡；这些患者的平均年龄对应每人还剩8个生命年，效用值为0.7。

```
LYG   = 12 × 8            = 96 生命年/年
QALY  = 96 × 0.7          = 67.2
evLYG = 96 × 0.851        = 81.7
```

按每QALY £20,000计算，QALY框架下这些生存价值为£134万/年；evLYG框架下为£163万/年。这一差距，恰恰对应着一个伦理判断：效用值为0.7的一个生命年，是否只值一个"完整"生命年的70%。严谨的申报文件应同时报告两者。

## 与软件工程的关联

- 生存分析是双方共享的工具箱：面向患者与面向*服务*（故障间隔时间、流失时间）绘制的Kaplan-Meier曲线，其数学原理完全相同。一项可靠性投资带来的"服务年获益" = 有该投资与无该投资两条系统生存曲线之间的面积——这比孤立的MTTF点估计更诚实。
- evLYG也为工程指标设计提供了一条警示：任何按"团队质量"因子对产出加权的生产力指标，都会系统性地低估那些受限或挣扎中的团队所取得的改进——有时你恰恰应该有意选用等值加权的变体。

## 常见陷阱

- **中位生存期与平均生存期之别**：经济学模型需要的是平均值（曲线下面积）；而试验报告中往往以中位数作为主要结果。在偏态分布下两者可能相差很大。
- **超出试验随访期的外推**在慢性病的LYG建模中往往起决定性作用——应明确说明所用的外推模型，并在[敏感性分析](../敏感性分析/)中检验它。
- **依据观察性前后数据主张避免了多少死亡**，却未对病例组合和长期趋势做调整。
