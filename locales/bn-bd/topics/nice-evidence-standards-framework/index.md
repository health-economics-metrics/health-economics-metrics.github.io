# NICE এভিডেন্স স্ট্যান্ডার্ডস ফ্রেমওয়ার্ক (ESF)

ESF হলো NICE-এর ফ্রেমওয়ার্ক যা নির্দিষ্ট করে **একটি ডিজিটাল স্বাস্থ্য প্রযুক্তির কতটা প্রমাণ প্রয়োজন, এর ঝুঁকির সমানুপাতিক**।

## কেন এটি গুরুত্বপূর্ণ

ESF ডিজিটাল স্বাস্থ্য প্রযুক্তিকে ক্লিনিক্যাল ফাংশন দ্বারা স্তরে শ্রেণিবদ্ধ করে, **ক্রমবর্ধমান** প্রমাণ মান সহ:

```
স্তর A — সিস্টেম সেবা, কোনো সরাসরি রোগী ফলাফল নেই
স্তর B — জানানো, সরল পর্যবেক্ষণ, যোগাযোগ
স্তর C — চিকিৎসা, নির্ণয়, বা সক্রিয়ভাবে ক্লিনিক্যাল ব্যবস্থাপনা পরিচালনা
```

## গণিত

```
প্রয়োজনীয় প্রমাণ বিনিয়োগ = f(স্তর)
  স্তর A: নথিপত্র + নিশ্চয়তা ≈ £10হাজার–50হাজার
  স্তর B: পর্যবেক্ষণমূলক/তুলনামূলক গবেষণা ≈ £50হাজার–250হাজার
  স্তর C: RCT-গ্রেড তুলনামূলক গবেষণা + অর্থনৈতিক মডেল ≈ £250হাজার–£2M+
```

## সমাধানকৃত উদাহরণ

একটি ওষুধ-রিমাইন্ডার অ্যাপ নির্মাতা একটি ডোজ-সমন্বয় সুপারিশ বৈশিষ্ট্য যোগ করার কথা বিবেচনা করেন। একটি রিমাইন্ডার অ্যাপ হিসেবে: **স্তর B**। ডোজ সুপারিশসহ: **স্তর C**।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

ESF এই রেপোর সবচেয়ে স্থানান্তরযোগ্য গভর্নেন্স প্যাটার্ন: **টুল গ্রহণের জন্য ঝুঁকি-স্তরভিত্তিক প্রমাণ প্রয়োজনীয়তা**।

## ঝুঁকিপূর্ণ দিক

- **কল্পনাপ্রসূত চিন্তা দ্বারা স্তর ভুল শ্রেণিবিভাগ** — নিয়ন্ত্রক এবং ক্রেতারা পণ্য *কী করে* তা দিয়ে শ্রেণিবদ্ধ করে।
- **পণ্যের পরে নির্মিত প্রমাণ**।
- **ESF পূরণ করে বাকি সব ভুলে যাওয়া**: ESF DTAC-র পাশাপাশি বসে।
