# 遠端病患監測經濟學

在家中監測病患的報銷與成本衝抵經濟學：在美國，這對應一套明確的CPT編碼收入結構；在國家醫療服務體系中，則對應避免入院與虛擬病房經濟學，最高可達到完全的**居家醫院**替代模式。

## 為何重要

遠端病患監測（RPM）正是裝置資料轉化為可計費醫療服務的地方。美國Medicare的結構（2025年全國平均值）異常明確：

```
99453  設定與病患教育           約$19.73  一次性收費（需滿16天資料後）
99454  裝置供應+資料傳輸        約$43.03  每30天一次——要求30天內
                                        讀數天數 ≥16天
99457  每月首20分鐘管理         約$47.87  要求已記錄時長 ≥20分鐘
99458  每額外20分鐘             約$38.49
```

一個符合計費條件的病患-月，合計約為**每會員每月90–130美元**。在成本衝抵方面，居家醫院專案（CMS急症居家醫院照護豁免計劃：涵蓋300多家醫院）顯示，相較住院照護，每例可節省約1,800–3,000美元，同時再入院率與感染率更低——這是監測加虛擬照護能夠替代系統中最昂貴資源（有人力配置的病床）這一論點最清晰的證明。

## 計算方法

```
RPM收入（美國） = 註冊人數 × 符合計費條件的比例 × 每會員每月的編碼收入合計
  ——16天規則使佩戴時間合規性（參見wearable-validation.md）
    成為一個收入變數，而20分鐘規則則使臨床時間的
    記錄成為一項工程要求

NHS式價值      = 避免的入院數 × 邊際入院成本
              + 被替代的床位天數 × (住院日成本 − 虛擬病房日成本)
              − 服務成本（裝置、平臺、監測人員）
  （關於歸因與邊際成本規則，參見emergency-attendance-avoidance.md
   與bed-days-saved.md）
```

## 實例演算

某美國診所為400名高血壓病患註冊該服務；在典型月份中70%的病患達到16天閾值；60%記錄了管理時長：

```
月收入 ≈ 400 × [0.70 × 43.03 + 0.60 × 47.87] = 400 × 58.84 ≈ $23,500
年收入 ≈ $282,000；服務成本（裝置每月$12，人員0.8全職當量）≈ $180,000
利潤 ≈ 每年$100,000——請注意，這裡的槓桿都是工程層面的槓桿：
將16天合規率從70%提升到85%，每年可增加約$31,000
（裝置舒適度、同步可靠性、提醒設計）。
```

NHS版本的映象：一個擁有50張床位、入住率80%的虛擬病房，替代住院天數、每天淨節省£150 ≈ 50 × 0.8 × 365 × 150 ≈ **每年毛值£219萬**——需扣除平臺、裝置以及負責營運的社群護理團隊的成本。

## 與軟體工程的聯絡

RPM平臺是少數幾種**正常運作時間與同步可靠效能直接轉化為收入**的產品之一（一週的同步失敗，就可能使一整個佇列跌破16天門檻），也是審計級時間追蹤（20分鐘規則）作為一等公民功能、而非事後補充的產品之一。應重點建置：能在計費月尚可挽回時就浮現風險的按病患合規性儀表盤；帶時間戳、防篡改的資料軌跡（支付方的審計是家常便飯）；以及警報經濟學調優——每一條警報都會消耗監測團隊的時間，而這既是可計費單位，同時也是稀缺資源（閾值的選擇由[篩查經濟學](../篩查經濟學/)所支配）。

## 陷阱

- **註冊 ≠ 收入**：真正的數位是那個合規比例；應對其建模，而非假設它自然達成。
- **將美國編碼直接照搬到NHS場景**——國家醫療服務體系購買的是"避免入院"，而非CPT編碼收入結構；應改用後一套模型。
- **對那些固定成本依然持續存在的入院，按平均成本主張衝抵**（參見[邊際成本與平均成本](../邊際成本與平均成本/)）。
- **監測團隊飽和**：警報量會隨註冊人數增長而增長；人員配置這條線，正是大多數模型都遺漏的那個起決定作用的約束。
