# Оптимізація подальших ресурсів

Оптимізація подальших ресурсів зосереджується на розблокуванні ролі чи процесу, на який всі інші чекають, замість оптимізації навмання.

## Чому це важливо

Покращення непровідних кроків у шляху догляду не впливає на загальний час виконання — лише саме вузьке місце визначає системну потужність.

## Математика

```
Системна пропускна здатність = пропускна здатність обмежувального кроку (вузького місця)
```

## Розібраний приклад

Діагностичний шлях має п'ять кроків; крок 3 (інтерпретація зображень) має найдовший час очікування. Прискорення кроків 1, 2, 4 та 5 не впливає на загальний час виконання, доки не буде вирішено крок 3.

## Зв'язок з інженерією програмного забезпечення

Прямий аналог Теорії обмежень, застосованої до конвеєрів CI/CD — прискорити найповільніший крок, а не довільний крок.

## Підводні камені

- **Інвестування ресурсів у непровідні процеси, оскільки їх легше покращити.**
- **Не перевизначати вузьке місце після вирішення попереднього (вузьке місце зміщується).**
