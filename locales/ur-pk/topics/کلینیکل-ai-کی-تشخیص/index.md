# کلینیکل AI کی تشخیص

ایک کلینیکل AI یا تشخیصی ماڈل کی تشخیص کے لیے بنیادی اعداد و شمار: حساسیت، مخصوصیت، AUROC۔ مرکزی معاشی سبق: **ایک شاندار AUROC ایک قیمت کے لحاظ سے موثر تعیناتی نہیں بناتا**۔

## یہ کیوں اہم ہے

ریگولیٹرز (FDA، MHRA) ایک **مقفل آپریٹنگ پوائنٹ** پر کلینیکل AI کو مجاز قرار دیتے ہیں۔

## ریاضی

```
حساسیت = TP / (TP + FN)
PPV = TP / (TP + FP) ← پھیلاؤ پر منحصر
```

## حل شدہ مثال

ایک ہی ماڈل، دو ترتیبات: ماہر کلینک (پھیلاؤ 20%): PPV ≈ 76%؛ بنیادی دیکھ بھال (پھیلاؤ 1%): PPV ≈ 11.5%۔

## سافٹ ویئر انجینئرنگ سے تعلق

کلینیکل AI بنانے یا خریدنے والے انجینئرز کے لیے: تعیناتی پھیلاؤ پر کنفیوژن میٹرکس بھیجیں۔

## عام غلطیاں

- **AUROC کی خریداری۔**
