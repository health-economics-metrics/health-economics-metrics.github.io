# Capacità Generatrice di Valore (Svolta Operativa)

La capacità generatrice di valore è il "beneficio di opportunità" del tempo liberato: cosa può ora *ottenere* l'ospedale con le ore liberate dal vostro software.

## Perché è importante

L'NHS affronta un vasto backlog di rinvio-al-trattamento.

## La matematica

```
Capacità nascosta generata = tempo liberato → unità di attività abilitate × valore dello schema
```

## Esempio risolto

Infermiere specialiste di Fascia 6 gestiscono cliniche di valutazione preoperatoria: £1,5 milioni di capacità di cura creata all'anno.

## Collegamento con l'ingegneria del software

La stessa riformulazione salva le affermazioni sulla produttività degli sviluppatori dalla matematica salariale.

## Insidie

- **Rivendicare capacità senza domanda.**
