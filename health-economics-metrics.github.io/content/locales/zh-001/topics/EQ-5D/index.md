# EQ-5D

EQ-5D是EuroQol（欧洲生活质量学会）用于测量健康相关生活质量的标准化问卷。它正是大多数[QALY](../质量调整生命年/)计算中效用权重的来源——NICE的参考案例将其列为成年人首选的测量工具。

## 为何重要

任何希望主张QALY获益的数字健康产品，都需要来自经过验证的量表工具的效用值，而EQ-5D是英国及欧洲大部分地区的默认选择。它足够简短，可以直接嵌入应用中（5个问题+一条视觉模拟量表），这意味着软件产品能够在正常使用过程中，顺带采集到达到卫生技术评估标准的结果数据——这相对于药物是一项结构性优势，因为药物需要专门开展研究才能获得这类数据。

## 计算方法

EQ-5D-5L在**5个维度**——行动能力、自理能力、日常活动、疼痛/不适、焦虑/抑郁——中各提出一个问题，每个问题有**5个等级**的回答（从"没有问题"到"极度问题"），此外还包含一条0–100的视觉模拟量表（EQ VAS）。

```
健康状态 = 一个五位数字的健康状态组合，例如"21221"
效用指数 = 价值集(该健康状态组合)

该价值集是针对特定国家的，来自对一般公众进行的时间权衡法/
离散选择调查。锚点为：1 = 完全健康，0 = 死亡；比死亡更差的
健康状态取负值（英国3L版价值集的下限为−0.594）。
```

QALY的计算随后即可按"时长 × 效用值"进行。

## 实例演算

某肌肉骨骼康复应用，在1,000名完成随访的用户入组时与6个月后分别测量EQ-5D-5L。

```
基线平均效用值：  0.62
6个月后平均效用值：0.71
假设获益可持续1年：(0.71 − 0.62) × 1.0 = 每名用户0.09 QALY
```

对照组（自然恢复）的变化为0.03，因此可归因的获益为每名用户0.06 QALY。按每QALY £20,000–£30,000货币化：**每名完成随访的用户带来£1,200–£1,800的健康价值**——这一数字正是该应用与支付方进行价格谈判时的锚点。（EQ-5D指数的最小临床重要差异通常落在0.03–0.08区间，因此0.06是可信的，但必须经受住对照组比较的检验；参见[患者报告结果](../患者报告结果/)。）

## 与软件工程的联系

- **把它埋点采集起来。**在注册时以及后续随访节点测量EQ-5D，只需要几个UI界面；换来的回报却是达到卫生技术评估标准的证据。需从EuroQol获取授权许可（这是必须的，部分用途可免费获得）。
- **使用与部署国家相符的价值集**——同样的回答，在英国、德国和日本会得出不同的分数。
- **设计层面的启示**：EQ-5D展示了一个微型标准化问卷加一套已发布的计分函数，如何能产生一个具有可比性的单一指数。这也正是任何可信的开发者体验指数应遵循的模式——标准化工具、已发布的权重，而非临时拍脑袋决定。参见[SPACE与开发者体验](../SPACE与开发者体验/)。

## 陷阱

- **没有对照组的前后对比**——均值回归与自然恢复会虚增朴素的获益数字。
- **存活者偏倚**：只测量那些持续保持参与的用户（参见[留存与流失](../留存与流失/)）。
- **在不同研究间混用3L与5L版本或不同价值集**——会得出系统性不同的数字。
- **轻症人群中的天花板效应**：许多用户在基线时得分就已接近1.0，导致没有余地展现出获益。
- **把价值集当作不言自明**：价值集所返回的效用值，本身是通过时间权衡研究（或相关的选择调查）从公众那里获取的——具体方法见[时间权衡效用获取法 (TTO)](../时间权衡效用获取法/)。
