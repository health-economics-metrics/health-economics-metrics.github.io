# ছাড় এবং সময় অগ্রাধিকার

ছাড় ভবিষ্যতের ব্যয় ও সুবিধাকে বর্তমান মূল্যে রূপান্তরিত করে, কারণ আজকের একটি সুবিধা পাঁচ বছর পরের একই সুবিধার চেয়ে বেশি মূল্যবান।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি স্বাস্থ্য-অর্থনীতি মূল্যায়ন এবং প্রতিটি গুরুত্বপূর্ণ সরকারি-খাত ব্যবসায়িক ক্ষেত্র বহু-বছরের প্রবাহকে ছাড় দেয়। যুক্তরাজ্যের HM ট্রেজারি গ্রিন বুক বার্ষিক ৩.৫% সামাজিক সময় অগ্রাধিকার হার নির্দেশ করে; NICE-এর রেফারেন্স কেস ব্যয় এবং স্বাস্থ্য প্রভাব উভয়কেই বছরে ৩.৫% হারে ছাড় দেয় (৩০+ বছরের সুবিধাসহ প্রায়-নিরাময়যোগ্য থেরাপির জন্য ১.৫% অ-রেফারেন্স-কেস হারসহ)। আপনার সফটওয়্যার ব্যবসায়িক ক্ষেত্র যদি দাবি করে "১০ বছরে £৫০ লক্ষ সাশ্রয়," একজন অর্থ পর্যালোচক অবিলম্বে ছাড়যুক্ত সংখ্যা চাইবেন।

## গণিত

ভবিষ্যতের একটি পরিমাণের বর্তমান মূল্য:

```
PV = FV / (1 + r)^t

PV = বর্তমান মূল্য
FV = t বছরে ভবিষ্যত মূল্য
r  = ছাড়ের হার (NICE/গ্রিন বুক: 0.035)
t  = এখন থেকে বছর
```

n বছর ধরে একটি স্থির বার্ষিক সুবিধা B-এর জন্য (একটি বার্ষিকী):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## সমাধানকৃত উদাহরণ

আপনার সফটওয়্যার একটি NHS ট্রাস্টের বছরে £১০০,০০০ সাশ্রয় করে ৫ বছর ধরে, চালু হওয়ার এক বছর পর থেকে শুরু করে।

ছাড়বিহীন মোট: £৫০০,০০০।

৩.৫%-এ ছাড়যুক্ত:

```
বছর ১: 100,000 / 1.035^1 = £96,618
বছর ২: 100,000 / 1.035^2 = £93,351
বছর ৩: 100,000 / 1.035^3 = £90,194
বছর ৪: 100,000 / 1.035^4 = £87,144
বছর ৫: 100,000 / 1.035^5 = £84,197

মোট PV ≈ £451,505
```

সৎ শিরোনাম প্রায় £৪৫১,০০০, সরল যোগফলের চেয়ে প্রায় ১০% কম। এখন ধরুন বিতরণ এক বছর পিছিয়ে যায়: প্রতিটি পদ এক বছর পরে সরে যায়, এবং PV প্রায় £৪৩৬,০০০-এ নেমে আসে — এটি [বিলম্বের ব্যয়](../cost-of-delay/)-এর ছাড়যুক্ত দৃষ্টিভঙ্গি।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

- **প্রযুক্তিগত-ঋণ পরিশোধ এবং প্ল্যাটফর্ম মাইগ্রেশন** বছরের পর বছর দূরে সুবিধা প্রবাহের প্রতিশ্রুতি দেয়; এই ত্রৈমাসিকে ফেরত দেওয়া কাজের সাথে তুলনা করার আগে এগুলোকে ছাড় দিন।
- **সম্মুখ-ভারী ব্যয়, পশ্চাৎ-ভারী সুবিধা** একটি মাইগ্রেশনের প্রমিত আকৃতি। ছাড় সেই আকৃতিকে সঠিকভাবে জরিমানা করে: এটি এখন ক্ষমতা প্রতিশ্রুতিবদ্ধ করার এবং পরে মূল্য পাওয়ার ঝুঁকিমুক্ত সময়ের মূল্য নির্ধারণ করে।
- **"পঞ্চম বছরে সাশ্রয়" দাবি** দ্বিগুণ সংশয়ের যোগ্য — সেগুলো ব্যাপকভাবে ছাড়যুক্ত এবং অত্যন্ত অনিশ্চিত উভয়ই ([সংবেদনশীলতা বিশ্লেষণ](../sensitivity-analysis/) দেখুন)।

## ঝুঁকিপূর্ণ দিক

- **ব্যয় ছাড় দেওয়া কিন্তু সুবিধা নয়** (বা বিপরীত) — রেফারেন্স কেস উভয়কেই একই হারে ছাড় দেয়।
- **একটি সরকারি-খাত মামলায় বাণিজ্যিক হার (৮–১২%) ব্যবহার করা**, বা ভেঞ্চার-সমর্থিত একটিতে ৩.৫%। হারকে সিদ্ধান্ত গ্রহণকারীর সাথে মিলিয়ে নিন।
- **ছাড়কে মুদ্রাস্ফীতির সাথে গুলিয়ে ফেলা।** ছাড় *প্রকৃত* (মুদ্রাস্ফীতি-সমন্বিত) মূল্যের উপর প্রযোজ্য; উভয়টি একই সাথে প্রচ্ছন্নভাবে করবেন না।
