# روک تھام کی معاشیات

بیماری ہونے یا بڑھنے سے پہلے مداخلت کی معاشیات۔ اہم دریافت فطری فہم کے برعکس ہے: **زیادہ تر روک تھام پیسے نہیں بچاتی** — یہ ایک اچھی قیمت پر صحت خریدتی ہے۔

## یہ کیوں اہم ہے

"روک تھام پیسے بچاتی ہے" صحت کی پالیسی میں سب سے زیادہ دہرایا جانے والا جھوٹا دعویٰ ہے۔

## ریاضی

```
روک تھام کی خالص قیمت (فی شخص) =
    مداخلت کی قیمت × تمام علاج شدہ
  − ٹالی گئی ڈاؤن اسٹریم قیمت × جو ترقی کرتے
```

## حل شدہ مثال

100,000 خطرے والے بالغوں کے لیے ایک بلند فشار خون-انتظام ایپ: خالص قیمت ≈ £2.8M — بچت نہیں۔

## سافٹ ویئر انجینئرنگ سے تعلق

شفٹ-لیفٹ کوالٹی، تنبیہ کے ساتھ، روک تھام کی معاشیات ہے۔

## عام غلطیاں

- **شواہد قیمت-تاثیر کی حمایت کرنے پر قیمت کی بچت کا دعویٰ کرنا۔**
