# Realizacja korzyści

Realizacja korzyści to dyscyplina śledzenia i weryfikowania, czy projekt rzeczywiście dostarczył obiecane korzyści.

## Dlaczego to ważne

Uzasadnienie biznesowe obiecuje korzyści, ale bez monitorowania nigdy nie wiesz, czy zostały zrealizowane.

## Matematyka

```
Wskaźnik realizacji korzyści = rzeczywiste korzyści / planowane korzyści × 100%
```

## Rozwiązany przykład

Narzędzie cyfrowego triażu: planowana oszczędność £500 000/rok; po 12 miesiącach rzeczywista £320 000 = 64% realizacji.
