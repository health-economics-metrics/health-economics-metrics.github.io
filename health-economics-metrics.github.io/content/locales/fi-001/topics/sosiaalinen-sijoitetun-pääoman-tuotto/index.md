# Sosiaalinen sijoitetun pääoman tuotto (SROI)

SROI laajentaa ROI:ta sisällyttämällä yhteiskunnallisia ja ympäristöarvoja, joita perinteiset markkinat eivät hinnoittele, kuten hyvinvointia ja sosiaalista yhteenkuuluvuutta.

## Miksi se on tärkeä

Monet terveysinterventiot tuottavat arvoa suorien taloudellisten säästöjen ulkopuolella — SROI pyrkii tekemään tämän laajemman vaikutuksen näkyväksi.

## Matematiikka

```
SROI-suhde = Yhteiskunnallisten hyötyjen nykyarvo / Investoinnin nykyarvo
```

## Ratkaistu esimerkki

Yhteisön terveysohjelma, joka maksaa £1 miljoonaa, tuottaa arvioidun yhteiskunnallisen arvon £4 miljoonaa (vähentynyt yksinäisyys, parantunut työllisyys, vähemmän rikollisuutta): SROI-suhde 4:1.

## Yhteys ohjelmistokehitykseen

Muistuttaa laajempien organisatoristen hyötyjen (henkilöstön moraali, brändin maine) väittämistä teknisestä investoinnista, mikä on vaikeampi kvantifioida kuin suorat kustannussäästöt.

## Sudenkuopat

- **Proxy-arvostusten käyttäminen ilman niiden perustelua tai validointia.**
- **Päällekkäisten hyötyjen kaksinkertainen laskenta.**
