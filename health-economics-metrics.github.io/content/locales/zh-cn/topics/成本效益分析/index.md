# 成本效益分析 (Cost-Benefit Analysis，CBA)

CBA 同时以货币形式为成本*和*结果估值。它是唯一能够回答"这件事到底值不值得做？"——而不仅仅是"哪个方案更好？"——的分析类型，因为已货币化的效益可以直接与成本进行比较。

## 为什么重要

CBA 是英国财政部 (HM Treasury) **绿皮书 (Green Book)** 中所有公共支出评估的标准方法，只要结果能够被货币化，卫生领域也不例外。相较于[成本效果分析 CEA](../成本效果分析/)/[成本效用分析 CUA](../成本效用分析/)止步于"每单位健康的成本"，CBA 会为健康本身（QALY × 阈值价值）以及其他一切——时间、出行、碳排放——都定出价格，并汇报为一个净值。每一份完整的 NHS 数字化商业论证都包含一个 CBA 形态的经济论证。

## 计算方法

```
NPV（净现值，社会净现值） = Σ_t [ (效益_t − 成本_t) / (1 + r)^t ]
BCR（效益成本比）        = PV(效益) / PV(成本)

若 NPV > 0（等价于 BCR > 1）则采纳；按 NPV 排序，而非按 BCR。
r = 3.5%（绿皮书社会时间偏好率）
```

健康效果可以按 QALY × λ 货币化后纳入（参见[支付意愿阈值](../支付意愿阈值/)）。绿皮书还要求进行**乐观偏误调整 (optimism-bias adjustment)**——按基于证据的百分比上调成本估计、下调效益估计，因为评估报告系统性地过于乐观。

## 算例

一个电子转诊系统，5 年周期，贴现率 3.5%：

```
成本：    建设 £1.2M（第 0 年），运行每年 £300k（第 1–5 年）
效益：    行政节约每年 £250k，避免重复检查每年 £280k，
          患者节省时间每年 40,000 小时 × £15 = 每年 £600k → 合计每年 £1,130k

PV 成本    = 1,200k + 300k × 4.515（年金系数）= £2,555k
PV 效益    = 1,130k × 4.515                    = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

应用绿皮书乐观偏误调整（假设建设成本上调 +40%，效益下调 −20%）：PV 成本 ≈ £3,035k，PV 效益 ≈ £4,082k，NPV ≈ **+£1,047k**——仍为正值，而这正是该调整的意义所在：论证应当能经受住对自身乐观情绪的修正。

## 与软件工程的关联

工程类商业论证本质上就是非正式的 CBA。以下是值得借鉴的绿皮书做法：

- **将乐观偏误作为标准上调项**——工程师低估迁移成本的可靠程度，不亚于各部委低估基础设施成本的程度；应采用一个明确声明的上调系数，而不是假装这一次会有所不同。
- **诚实地货币化占主导的效益，否则就不要货币化**——患者/用户的时间可以按站得住脚的费率货币化；"品牌价值"则不行。
- **NPV 用于排序，BCR 不行**：一个 BCR 为 5 的小项目，其重要性可能不及一个 BCR 为 1.6 的大项目。

## 陷阱

- **为拉高效益而货币化不可货币化的东西**（士气、"战略契合度"）——按照[成本后果分析](../成本后果分析/)的做法，把这些保持为定性描述。
- **把转移支付算作效益**：资金在公共机构之间的流动，在社会[视角](../分析视角/)下净额为零。
- **缺少反事实基准**：效益应相对于"最低限度维持"方案来衡量，而不是相对于零。
