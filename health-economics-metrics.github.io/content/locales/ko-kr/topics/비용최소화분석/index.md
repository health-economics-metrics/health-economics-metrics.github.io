# 비용최소화분석(CMA)

CMA는 비용만 비교하며, 가장 저렴한 옵션을 선택합니다 — 대안들의 결과가 동등하다고 입증된 경우에만 유효합니다.

## 왜 중요한가

CMA는 가장 단순한 분석이며 가장 많이 남용됩니다.

## 수식

```
효과_A ≈ 효과_B가 입증되면: min(비용_A, 비용_B) 선택
```

## 계산 예시

트러스트가 두 화상 상담 플랫폼 중에서 선택합니다.

## 소프트웨어 공학과의 연관성

CMA는 상품 조달의 공식적인 형태입니다.

## 함정

- **가정된 동등성.**
