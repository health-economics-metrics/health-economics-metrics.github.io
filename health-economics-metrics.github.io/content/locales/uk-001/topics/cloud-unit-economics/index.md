# Одинична економіка хмари

Одинична економіка хмари вимірює витрати на інфраструктуру на окрему транзакцію, пацієнта чи запит.

## Чому це важливо

Хмарні рахунки показують загальну суму, але не те, яка функція чи шлях пацієнта спричиняє витрати.

## Математика

```
Одиничні витрати = хмарні витрати (£/місяць) / обсяг транзакцій (за місяць)
```

## Розібраний приклад

Служба зберігання зображень: £40 000/місяць, 200 000 сканувань = £0,20 за сканування.

## Зв'язок з інженерією програмного забезпечення

Розбиває [загальну вартість володіння](../total-cost-of-ownership/) на операційний масштаб.

## Підводні камені

- **Ігнорування знижок за резервування та розрахунок за тарифами на вимогу.**
