# 完美信息期望价值（EVPI）

EVPI是指决策者在做出决策之前，为消除不确定性而应当愿意支付的最高金额——这是"我们先做个研究再说"这句话的正式定价。

## 为何重要

医疗系统始终面临这样的选择：基于不完美的证据现在就采纳，还是先资助更多研究。EVPI为第二种选择给出了一个具体数字。如果EVPI是£50,000，而拟议中的试验成本为£200万，那就应该现在采纳。如果EVPI是£2,000万，那么这场试验就是笔划算的交易。同样的问题——"我们应不应该先试点一下再全面推广？"——出现在每一次企业级工具决策中，却几乎从来没有人为它定过价。 关于为日后扩张项目的期权（而不是先收集信息的期权）定价，见[实物期权估值](../实物期权估值/)。

## 计算方法

EVPI是"拥有完美预见能力时的决策"与"基于当前预期立即决策"二者之间的差距：

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = 不确定参数（及其联合分布）
NMB(j,θ) = 在给定θ的情况下，方案j的净货币效益
```

第一项：在每一种可能的世界状态下，取"最佳选择"所带来收益的平均值（你总是选对）。第二项：那个"平均而言最优"的单一方案所带来的收益（你必须现在就做出承诺）。EVPI恒 ≥ 0。人群层面的EVPI，需乘以受影响的决策数量。可直接从[概率敏感性分析（PSA）](../概率敏感性分析/)的抽样结果中计算得出。

## 实例演算

是否将一款AI文书助手推广给5,000名临床医生。存在两种可能的世界：

```
世界A（p = 0.6）：助手每天节省20分钟 → 推广的净货币效益 = +£800万
世界B（p = 0.4）：助手几乎不节省时间（工作流程摩擦） → 推广的净货币效益 = −£300万
"不推广"的净货币效益，在两种世界中均为£0。
```

现在就做决策：E[推广的净货币效益] = 0.6 × 800万 − 0.4 × 300万 = **+£360万** → 应予推广。

若拥有完美信息：在世界A中选择推广（+£800万），在世界B中选择不推广（£0）。期望值 = 0.6 × 800万 + 0.4 × 0 = **£480万**。

```
EVPI = 480万 − 360万 = £120万
```

一次严谨的、耗资£150,000、能大幅厘清你究竟身处哪个世界的3个月试点，显然是值得投入的——而任何成本超过£120万的试点，无论多么周全彻底，都不值得。

## 与软件工程的联系

EVPI正是"尖刺（spike）"、试点、A/B测试与概念验证背后的经济学原理。它给出了两条实用的规则：

- **一个试点只有在决策真的可能因此改变时，才值得投入资金。**如果无论试点结果如何你都会推广，那么EVPI = 0，这个试点不过是一场表演。
- **应将试点开支上限设定为EVPI。**信息的价值，其上限就是它所支撑的那项决策本身的价值。

部分EVPI（EVPPI）将这一概念拓展到单个参数层面："单独把'节省的时间'这个数字弄准，究竟值多少钱？"——这能告诉你，试点究竟应该测量什么。 关于评估*某一项具体拟议研究*而不是消除全部不确定性，见 [EVSI](../样本信息期望价值/)。

## 陷阱

- **在没有附带决策规则的情况下运行试点**——无法改变选择结果的信息，从定义上讲就是毫无价值的。
- **忽视收集信息本身的延迟成本**：一次6个月的试点，会延迟6个月的效益（参见[延迟成本](../延迟成本/)）；试点的净价值 = 已厘清的EVPI − 延迟成本 − 试点本身的成本。
- **把EVPI当作一次预测。**它是信息价值的上限，而不是对某项具体研究将会产出什么结果的估计。
