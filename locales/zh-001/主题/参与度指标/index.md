# 参与度指标

参与度指标衡量用户实际使用健康应用的程度：DAU/MAU粘性、会话频率与时长、功能使用率。在数字健康领域，参与度绝非虚荣指标——它就是**剂量**：任何临床效果都必须通过这一暴露程度才能实现。

## 为何重要

一瓶从未被打开服用的药，治愈不了任何人；一个从未被安装或打开的应用，也是同样的失败模式。任何面向消费者的健康产品，其健康经济学主张都要乘以参与度这一因子——试验中所展现的疗效，是在某个特定使用水平下测得的，而真实世界的价值，则取决于实际部署时的使用水平与该试验水平的接近程度。标准产品基准：对移动应用整体而言，DAU/MAU约**20%被视为健康水平**，超过25%则属出色；健康类应用的这一数字往往更低。

## 计算方法

```
粘性（DAU/MAU） = 日活跃用户数 / 月活跃用户数 × 100
会话指标       = 每用户每周期会话数；平均时长 = 总时长 / 会话数
功能参与度     = 执行关键动作的用户数 / 活跃用户数

剂量-反应框架（健康经济学层面的升级）：
  实现的效果 ≈ 试验效果 × f(实际使用量 / 试验使用量)
  其中f来自剂量-反应分析——参见adherence-and-persistence.md中
  的"有效参与"概念：足以达成预期结果的使用量，这个量
  可能是适度且有限的
```

## 实例演算

某血压管理应用的关键研究显示，每周记录≥4次读数的用户，收缩压平均下降6 mmHg。在部署给50,000名注册用户的实际场景中：

```
月活跃用户20,000（占40%）；其中每周记录≥4次的：7,000人
达到有效剂量的用户 = 7,000 / 50,000 = 占注册用户总数的14%

人群层面效果 ≈ 试验效果只被交付给了14%的人，而非100%：
任何以"50,000名用户 × 6 mmHg"来计算的经济模型，都会高估约7倍。
诚实的模型应为：7,000人享受全部效果 + 对未达阈值的13,000名用户
（若有剂量-反应数据可用）按比例给予部分权重。
```

这一层"通过参与度漏斗、折算到有效剂量"的乘法运算，正是数字健康经济学中最常见的虚增之处。

## 与软件工程的联系

工程师掌控着参与度漏斗，这也使他们成为了一个*临床*变量的把关人：引导流程的摩擦程度、通知策略、加载时间、离线韧性，这些都会影响实际交付的剂量。由此带来两点设计启示：应埋点采集**具有临床意义的动作**（已记录的读数、已完成的课程），而非单纯的"打开"次数——建立在被通知拉回的空洞会话之上的DAU数据，是一种"剂量造假"；应将参与度目标视为*充分性*目标，而非最大化目标——一款每周只需5分钟就能达成预期结果、随后便悄然退场的应用，在临床上是理想的，在指标上却会显得"表现不佳"（参见[依从性与持续性](../依从性与持续性/)中的"有效参与"概念）。参与度相关工作本身的价值，也应通过上述人群层面效果模型来估算：有效剂量占比提升2个百分点，就是一条可量化的QALY效益线。

## 陷阱

- **将参与度本身当作结果**：使用量只是手段；真正的结果是[患者报告结果（PROM）](../患者报告结果/)或临床终点。
- **对双峰分布的使用数据取平均值**：健康类应用的用户群往往分裂为高度投入的用户与幽灵用户两极；平均值谁都无法真实描述——应按队列分层分析。
- **暗黑模式式的剂量虚增**：连续打卡与愧疚式通知能拉升指标，却可能伤害健康类应用所服务的、本就容易焦虑的人群；临床产品需要承担临床伦理责任。
- **供应商基准数据的来源问题**：大多数已发布的参与度基准数据来自分析工具供应商，而非同行评审文献；应以你自己的试验数据进行校准。
