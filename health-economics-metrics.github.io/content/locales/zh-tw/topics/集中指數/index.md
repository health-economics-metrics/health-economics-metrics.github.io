# 集中指數 (Concentration Index)

集中指數（Wagstaff、Paci、van Doorslaer，1991）是衡量健康變數中社會經濟不平等的標準統計量。它的取值在 −1 到 1 之間：負值表示該健康變數集中在社會經濟上較弱勢的人群中，正值表示集中在較富裕的人群中，零表示不存在系統性的社會經濟梯度。它把“分配不均”的懷疑變成一個可比較的單一數位。

## 為什麼重要

一個專案可能整體看起來有效，卻把幾乎所有好處都送給了本來就較富裕的人。這正是[覆蓋面與公平性](../觸達與公平/)以描述方式追蹤的分配問題——按貧困五分位分層的覆蓋面，最高組與最低組之間的公平差距——但分層表格無法壓縮成一條趨勢線，也難以在兩個用不同尺度測量的完全不同的指標之間比較。集中指數同時解決了這兩個問題：它對任何健康變數、針對任何社會經濟排序，都按同樣方式計算，因此國家衛生服務機構可以追蹤某項具體數位服務的不平等在各個版本之間是在擴大還是縮小，並在標準化尺度上，把某款應用推廣的分配公平性與例如篩查專案相比較。

## 計算方法

```
CI = (2 / 均值(健康值)) × Cov(健康值, 社會經濟排名)

Cov(X, Y) = 均值(X × Y) − 均值(X) × 均值(Y)   （總體協方差）

社會經濟排名：每個人在社會經濟分佈中的分數排名，取值 [0, 1]
（0 = 最弱勢，1 = 最優勢；對分組/分檔資料，通常取每組的中點排名）
```

這是“便捷協方差公式”（O'Donnell、van Doorslaer、Wagstaff、Lindelow，世界銀行 2008）——實務者的標準捷徑，可直接由配對的觀測資料計算集中指數，而無需先繪製集中曲線再對其下方求積分。

## 算例

自評健康得分（1 = 最差，4 = 最好），在四個等大小的社會經濟四分位上觀測，每個四分位用其中點排名表示：

```
健康值              = [1.0, 2.0, 3.0, 4.0]
社會經濟排名        = [0.125, 0.375, 0.625, 0.875]

均值(健康值)        = 2.5
均值(健康 × 排名)   = 均值([0.125, 0.75, 1.875, 3.5]) = 1.5625
均值(排名)          = 0.5

Cov = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

正值 `0.25` 表示這一健康得分集中在社會經濟上較優勢的人群中——得分較高的受訪者偏向排名中較富裕的一端。

## 與軟體工程的關聯

這是一種基於協方差的不平等度量，與經濟學中常用的度量屬於同一家族（基尼係數的近親），並可轉化為衡量軟體產品的收益是集中在本已佔優的使用者群體中，還是公平分佈——是[覆蓋面與公平性](../觸達與公平/)（RE-AIM 的“reach”維度）的直接延伸，把描述性的差距變成正式的統計量。覆蓋面與公平性是逐層報告影響，而集中指數把整個分佈壓縮成一個帶符號的數位，適合作為跨版本追蹤的單一 KPI——對放不下完整分層分佈的儀表盤很實用。

## 陷阱

- **符號約定漂移**：符號取決於健康變數和排名兩者的定義——顛倒任意一個都會顛倒符號，所以在報告數值時務必明確所用約定。
- **用邊界排名而非中點排名**：分組或分檔的社會經濟資料（如五分位）需要每組在其*中點*處的分數排名，而不是邊界處的排名，否則指數會有偏。
- **把“接近零”讀成“沒有不平等”**：集中指數接近零表示“沒有系統性的社會經濟梯度”，並不是絕對意義上的“沒有不平等”——方向相反的不平等可能相互抵消。
