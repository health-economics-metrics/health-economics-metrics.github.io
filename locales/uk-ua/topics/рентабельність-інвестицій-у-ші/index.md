# Рентабельність інвестицій у ШІ

ROI ШІ вимірює фінансову цінність, отриману порівняно з витратами на створення та експлуатацію систем ШІ.

## Чому це важливо

Проєкти ШІ часто мають приховані операційні витрати: інфраструктура, навчання моделей та постійні витрати на інференс.

## Математика

```
ROI ШІ = (створена цінність − (витрати на розробку + операційні витрати)) / (витрати на розробку + операційні витрати) × 100%
```

## Розібраний приклад

ШІ для узагальнення клінічної документації: розробка £300 000 + експлуатація £100 000/рік; заощаджений час лікарів = £600 000/рік = 50% ROI в перший рік.
