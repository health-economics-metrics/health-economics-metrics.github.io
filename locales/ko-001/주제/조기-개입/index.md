# 조기 개입

절약된 용량이 임상의가 진단 백로그를 더 일찍 검토할 수 있게 하면, 환자들은 대기 명단에서 활성 치료로 더 빠르게 이동합니다.

## 왜 중요한가

질병의 진행은 의료의 복리 이자입니다.

## 수식

```
조기 개입의 가치(환자당) =
    [비용_늦음 − 비용_이름]
  + [QALY_이름 − QALY_늦음] × λ
  × P(지연 중 진행)
```

## 계산 예시

당뇨병성 망막병증 검진 백로그: 4,000명 환자, 6개월 지연. 가치 ≈ £540,000.

## 소프트웨어 공학과의 연관성

결함도 *진행*됩니다.

## 함정

- **모두에게 최악의 시나리오 진행을 가정하기.**
