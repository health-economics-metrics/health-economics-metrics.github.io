# 等候名单影响

等候名单影响，将被节省的临床产能，转化为从等候名单中移除（或更快通过等候名单）的患者数量。把节省下来的工时转化为额外的门诊名额，能直接缩减一家信托机构等候名单的规模——这是向一个医疗系统展示被释放的产能究竟*用来做什么*最直观的方式。

## 为何重要

择期手术等候名单是NHS疫情后最具代表性的挑战（其规模本身就是一项全国性的政治指标），每家信托机构都在围绕它推进择期医疗恢复计划。一份写着"节省2,000个护士工时"的商业论证是抽象的；而一份写着"创造4,000个额外预约名额，为3,800名等候患者提供诊疗，将该专科的等候名单缩减9%"的论证，才是一份运营总监能够带去董事会汇报的故事。等候名单影响，正是[非现金释放型产能](../现金释放型与非现金释放型节省/)最自然的*核算单位*。

## 计算方法

```
额外名额数     = 释放的工时 / 单次名额时长 × 利用率
接诊患者数     = 额外名额数 × (1 − 爽约率)
名单缩减数     = 接诊患者数 − 被诱发的新增需求
等待时间改善   = 服务速率提升带来的排队改善
               （对于稳定队列，以服务速率μ将积压量N削减ΔN，
               能使所有人平均提前约ΔN/μ）
```

更短等待时间所带来的健康价值：患者在治疗前较低效用状态下度过的周数减少——相关QALY算术参见[转诊至治疗](../转诊至治疗/)。

## 实例演算

环境文书记录软件为20名门诊护士中的每一位，每天节省45分钟。按250个工作日计算：20 × 0.75 × 250 = 每年3,750小时。

```
名额数（每个30分钟，85%可用率） = 3,750 / 0.5 × 0.85 = 6,375个名额
接诊患者数（爽约率7%）          = 6,375 × 0.93       ≈ 每年5,929人
```

对于一个等候名单有12,000人、需求匹配产能为每年24,000次预约的专科而言，约5,900次额外预约能将平均等待时间缩短约四分之一——使该信托机构在不招聘新人的情况下，实质性地朝18周标准迈进。按每次就诊约£160的标准价格计算，这部分活动价值约为每年£949,000（参见[全国统一收费标准与单位成本](../全国统一收费标准与单位成本/)）——但应优先以*等候名单*这一框架呈现；这正是该系统实际管理所依据的口径。

## 与软件工程的联系

等候名单本质上就是一份积压任务清单，而积压任务燃尽的经济学在两个方向上都可以相互迁移。从健康领域迁移到软件领域：应按*用户*等待获得价值所需的时长，而非按已关闭的条目数，来为积压任务的减少估值（每个排队项目的[延迟成本](../延迟成本/)）。从软件领域迁移到健康领域：利特尔法则告诉我们，只有当服务速率超过到达速率时，名单才会真正缩短——被新增转诊吃掉的产能提升，不会改变等待时间，因此同样需要为"到达"这一端建模。而在这两个领域中，都应按严重程度加权的价值来排定优先级（临床紧急程度分类 ↔ [严重程度调整因子](../QALY缺口与严重程度调整因子/)），而非简单的先进先出。

## 陷阱

- **名额数 ≠ 患者数**：忘记考虑爽约率，以及被释放时间中那些无法被有效利用的零碎片段。
- **被诱发的需求**：可见的额外产能会吸引更多转诊；名单净影响会小于毛影响。
- **主张为现金**：等候名单影响属于产能价值；而现金层面的主张（避免了将积压工作外包出去）是另一条独立的效益线——参见[可规避的外包成本](../可规避的外包成本/)。
