# 數位終點與生物標誌物

數位生物標誌物是透過感測器採集的、客觀的生理或行為測量指標（來自手機的步態速度、來自可穿戴裝置的睡眠資料、來自加速度計的震顫資料）。數位終點則是將這樣一種測量指標提升為**試驗結果指標**——用以證明治療效果。從"裝置產生的資料"晉升為"監管機構認可的證據"，需要經過一套明確界定的驗證階梯。

## 為何重要

傳統的試驗終點是片段性的（每3個月一次門診訪視），且成本高昂；數位終點則是連續的、生態化的（真實生活場景，而非門診表現），且單次觀測成本低廉——它們能夠縮小試驗規模、更早檢測到效應，並支援去中心化研究。但其代價在於驗證：被廣泛接受的框架（與FDA標準一致，包含三大支柱）要求：**驗證/分析層面的確認**（感測器能否準確測量該物理量）、**臨床驗證**（該測量指標是否真實反映其所聲稱代表的臨床狀態），以及被證實具有**對健康有意義的方面**（病患是否真的在意它所捕捉的內容）。缺少這三者中任何一項，得到的都只是遙測資料，而非證據。

## 計算方法

```
分析驗證：與參照標準的一致性（參見wearable-validation.md——
          MAPE、CCC、Bland-Altman法）
臨床驗證：與臨床錨點之間的相關性/區分能力
          （已知組別效度、對變化的回應能力）
終點經濟學：
  每病患-年檢測到的事件數（連續監測） 對比 按訪視抽樣
  試驗功效：當訪視間方差佔主導時，連續測量能減少所需樣本量
  ——N ∝ σ²/Δ²，而σ²會隨取樣密度增加而下降
```

## 實例演算

某帕金森病試驗，比較腕部感測器採集的步態速度與季度門診評分：

```
門診終點：  每病患每年4次測量，日間波動噪聲較大
數位終點：  每病患每年約200次被動測量

年度變化估計值的方差隨取樣密度提升下降約5倍 →
在固定功效下，可檢測的效應量提升約√5 ≈ 2.2倍，
等價於在相同假設檢驗下，樣本量可減少約40–60%。
按每名入組病患£25,000計算，減少200名病患
約相當於每項試驗節省£500萬——這正是那筆驗證投資
（本身或許需要100萬–200萬英鎊）在贊助方整條產品管線中
所對應的商業案例。
```

## 與軟體工程的聯絡

數位終點本質上是一門披著臨床外衣的資料工程學科：**來源可追溯性與版本管理**（研究進行期間對演算法的更新會威脅到結果的可比性——這正是[PCCP](../AI監管評估/)問題在試驗場景中的對應形態；應鎖定版本並進行橋接驗證）；**缺失資料的設計處理**（佩戴時間的缺口本身就是有資訊量的，而非隨機的——參見[可穿戴裝置驗證](../可穿戴裝置驗證/)；插補方式的選擇本身就是一種科學主張）；以及**邊緣/雲端拆分決策**會改變日後究竟哪些原始訊號還能被恢復。從第一天起就將測量流水線當作受監管軟體來對待——經過測試、有版本管理、有檔案記錄——的團隊，能以較低成本換來其終點資料的可信度；而在一條快速迭代的流水線上事後補做驗證，正是數位終點專案走向失敗的常見原因。

## 陷阱

- **將"與門診結果相關"當作完整驗證**：與一個本身有缺陷的門診測量指標相吻合，只能證明其"繼承了"該缺陷，並不能證明其真實性；應針對真正有意義的健康方面進行驗證。
- **新型終點的監管風險**：一個前所未有的終點可能在科學上更為優越，卻仍可能導致申報失敗——應儘早與監管機構接觸（相關資格認定專案是存在的）。
- **感測器與目標人群不匹配**：在年輕健康人群的手腕上完成驗證，卻部署到患有震顫、且皮膚色素差異是PPG（光電容積描記）感測器從未見過的老年病患身上。
- **特徵漂移**：在新資料上重新訓練步態演算法，會在研究進行過程中悄然重新定義該終點本身。
