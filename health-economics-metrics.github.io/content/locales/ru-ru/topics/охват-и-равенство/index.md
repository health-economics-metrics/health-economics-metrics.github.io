# Охват и равенство (Reach and Equity)

RE-AIM — Reach (охват), Effectiveness (эффективность), Adoption (внедрение), Implementation (реализация), Maintenance (устойчивость) — это стандартная рамка для оценки *популяционного* воздействия вмешательства. Её центральная арифметика: **воздействие на общественное здоровье ≈ охват × эффективность**. Цифровые инструменты добавляют измерение равенства: цифровой разрыв означает, что охват систематически неравномерен, а доставка в первую очередь через цифровые каналы может расширять пробелы в здоровье, которые призвана закрыть.

## Почему это важно

Систематические обзоры, применяющие RE-AIM к mHealth, обнаруживают устойчивую сигнатуру: сильные охват и внедрение, **слабые эффективность и устойчивость** — приложения легко распространяются и быстро угасают. Для национальной системы здравоохранения это означает, что впечатляющий продукт на пользователя может быть плохой популяционной инвестицией, и наоборот: скромно эффективный инструмент, охватывающий миллионы, может превзойти блестящий, охватывающий тысячи (см. арифметику [HALE](../ожидаемая-продолжительность-здоровой-жизни/)). Равенство доступа — не побочное ограничение, а драйвер ценности: цифровая исключённость отслеживает возраст, депривацию, инвалидность и язык — именно те популяции, которые несут наиболее поддающееся лечению бремя, — так что предельный исключённый пользователь часто имеет *выше среднего* потенциальную пользу. О формальной статистической мере социально-экономического неравенства в здоровье см. [Индекс концентрации](../индекс-концентрации/).

## Математика

```
Популяционное воздействие ≈ охват × эффективность
  охват         = участники / приемлемая популяция (см. activation-and-uptake.md)
  эффективность = реальный эффект среди участников (взвешенный по удержанию —
                  см. retention-and-churn.md)

Версия со стратификацией по равенству:
  воздействие_группа_g = охват_g × эффективность_g, представлено по квинтилю
  депривации / возрастной группе / языковой группе
  разрыв равенства = воздействие_верхний квинтиль − воздействие_нижний квинтиль

Дистрибутивная затратная эффективность: применяйте веса равенства к QALY по
группе получателей — один QALY для наиболее обездоленных весит больше (всё
более распространённое расширение HTA).
```

## Практический пример

Программа цифровой профилактики диабета, представленная двумя способами:

```
Агрегат: охват 12%, эффект 0.02 QALY/участник → 0.0024 QALY/приемлемый человек

Стратифицировано (квинтили депривации):
  Q1 (наименее депривированные): охват 22%, эффект 0.02 → 0.0044
  Q5 (наиболее депривированные): охват 4%,  эффект 0.025 → 0.0010

Программа обеспечивает в 4.4× больше здоровья наименее депривированным —
при этом эффект на участника у Q5 ВЫШЕ (больше пространства для роста).
Рукав ассистированного цифрового доступа (телефонный коучинг + доступ
через сообщество), стоящий на 20% дороже на участника Q5 и поднимающий
охват Q5 до 12%, утраивает воздействие на Q5 и улучшает агрегат — здесь
инвестиция в равенство И ЕСТЬ инвестиция в эффективность.
```

## Связь с разработкой программного обеспечения

Охват в значительной степени является инженерным артефактом: минимальные требования к устройствам и ОС, допущения о пропускной способности, языковая поддержка, соответствие доступности (WCAG), барьеры верификации личности и распространение только через магазины приложений — каждый из этих факторов вырезает популяции из знаменателя, обычно незаметно, потому что исключённые пользователи никогда не появляются в аналитике. Инженерные практики, двигающие равенство: измеряйте *знаменатель* (инструментируйте приемлемую популяцию, а не только пользователей); закладывайте в бюджет производительность для старых устройств и плохой связи; поставляйте пути ассистированного цифрового доступа (телефон, SMS, киоск) как полноценные потоки, а не как каналы стыда; и сегментируйте каждую метрику дашборда по измерениям равенства — несегментированное среднее — это то место, где скрывается неравенство ([внедрение GDS](../метрики-сервисов-gds/) несёт то же предупреждение).

## Подводные камни

- **Эффективность, отчитываемая по завершившим, воздействие, заявляемое по популяциям** — термины охвата тихо отброшены.
- **Равенство как запоздалый аудит**, а не как входной параметр дизайна; ретроспективное встраивание охвата намного дороже, чем проектирование для него изначально.
- **Амнезия устойчивости**: самое слабое измерение RE-AIM для mHealth — заявления о воздействии за пределами временного горизонта доказательств.
- **Экономия только цифрового канала**, перекладывающая затраты на исключённых пользователей и передовой персонал (см. [метрики сервисов GDS](../метрики-сервисов-gds/)).
