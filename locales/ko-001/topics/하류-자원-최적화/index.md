# 하류 자원 최적화

시니어 임상의를 위해 한 시간을 절약하는 것은 종종 전체 다학제 팀(MDT)에 대한 병목 지연을 방지합니다.

## 왜 중요한가

의료는 승인 사슬에서 작동합니다.

## 수식

```
병목 해소의 가치 = Σ 하류 역할(해방된 차단 시간 × 단위 비용)
```

## 계산 예시

병동 퇴원은 매일 아침 전문의 검토가 필요합니다: 연간 1,460 병상일 절약.
