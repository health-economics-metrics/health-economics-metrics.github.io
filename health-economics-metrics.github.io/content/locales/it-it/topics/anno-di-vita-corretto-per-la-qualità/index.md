# Anno di Vita Corretto per la Qualità (QALY)

Un QALY è un anno di vita vissuto in salute perfetta. Combina *per quanto tempo* le persone vivono con *quanto bene* vivono, in modo che un anno in cattiva salute conti meno di 1 QALY.

## Perché è importante

Il QALY è la valuta comune della valutazione delle tecnologie sanitarie. NICE (Inghilterra) valuta i guadagni di salute a **£20.000–£30.000 per QALY**.

## La matematica

```
QALY = Σ_i (durata_i × utilità_i)
```

## Esempio risolto

Un paziente attende un trattamento cardiaco con utilità 0,6. Il trattamento lo riporta a utilità 0,85. La perdita di QALY per paziente dovuta al ritardo di 6 mesi è 0,125 QALY.

## Collegamento con l'ingegneria del software

**Percorsi più veloci = QALY prima.**
