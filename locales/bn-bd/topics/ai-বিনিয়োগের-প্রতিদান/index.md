# AI বিনিয়োগের প্রতিদান

AI ROI হলো AI উদ্যোগের জন্য দায়ী পরিমাপযোগ্য লাভ-ক্ষতি প্রতিদান। সতর্ককারী বেঞ্চমার্ক: MIT-র ২০২৫ "GenAI Divide" গবেষণা খুঁজে পেয়েছে $৩০–৪০ বিলিয়ন এন্টারপ্রাইজ GenAI বিনিয়োগ সত্ত্বেও, **~৯৫% পাইলট কোনো পরিমাপযোগ্য লাভ-ক্ষতি প্রতিদান দেখায়নি**।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য ব্যবস্থায় AI-পাইলট প্যাটার্নের একটি নাম আছে: **পাইলটাইটিস** — প্রতিশ্রুতিশীল অ্যাপের NHS কবরস্থান চিরকাল পাইলট করা এবং কখনো স্কেল করা হয় না।

## গণিত

```
AI ROI = (দায়যোগ্য সুবিধা − মোট AI ব্যয়) / মোট AI ব্যয়

মোট AI ব্যয় = লাইসেন্স/অনুমান + একীকরণ + তথ্য প্রস্তুতি + মূল্যায়ন
              + কর্মপ্রবাহ পুনর্নকশা + গভর্নেন্স/নিশ্চয়তা
```

## সমাধানকৃত উদাহরণ

একটি হাসপাতাল গ্রুপ দুটি ব্যবহারের ক্ষেত্রে AI স্থাপন করে:

```
ব্যবহার ক্ষেত্র A — ক্লিনিক্যাল-লেটার খসড়া (ব্যাকঅফিস, ট্র্যাকযোগ্য):
  বেসলাইন: আউটসোর্সড ট্রান্সক্রিপশন £380k/বছর
  পরে:    ট্রান্সক্রিপশন চুক্তি বাতিল; চিকিৎসক পর্যালোচনা সময় +£60k
  AI ব্যয়:  £120k/বছর সবমিলিয়ে
  ROI = (380k − 60k − 120k) / 120k ≈ 167% — নগদ-মুক্তকারী, নিরীক্ষাযোগ্য ✓
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

AI বিনিয়োগের জন্য HTA-আকৃতির প্লেবুক: **[NICE ESF স্তর](../nice-এভিডেন্স-স্ট্যান্ডার্ডস-ফ্রেমওয়ার্ক/)-এর মতো প্রমাণ স্তরভাগ করুন**।

## ঝুঁকিপূর্ণ দিক

- **সুবিধা বিচ্ছুরণ**: হাজার হাজার ব্যবহারকারী জুড়ে পাতলাভাবে ছড়ানো মূল্য গঠনগতভাবে পরিমাপযোগ্য নয়।
- **শুধুমাত্র-লাইসেন্স খরচ নির্ধারণ**: একীকরণ, মূল্যায়ন, এবং কর্মপ্রবাহ পুনর্নকশা সাধারণত প্রকৃত হরকে প্রাধান্য দেয়।
