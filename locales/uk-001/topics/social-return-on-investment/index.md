# Соціальна рентабельність інвестицій (SROI)

SROI розширює ROI, включаючи суспільні та екологічні цінності, які звичайні ринки не оцінюють, такі як добробут та соціальна згуртованість.

## Чому це важливо

Багато втручань у сфері охорони здоров'я створюють цінність поза прямою фінансовою економією — SROI намагається зробити цей ширший вплив видимим.

## Математика

```
Коефіцієнт SROI = Теперішня вартість суспільних вигод / Теперішня вартість інвестиції
```

## Розібраний приклад

Програма охорони здоров'я громади, що коштує £1 мільйон, генерує оцінену суспільну цінність £4 мільйони (зменшена самотність, покращена зайнятість, менше злочинності): коефіцієнт SROI 4:1.

## Зв'язок з інженерією програмного забезпечення

Подібно до заяв про ширші організаційні вигоди (моральний дух співробітників, репутація бренду) від технічної інвестиції.

## Підводні камені

- **Використання проксі-оцінок без підтвердження чи валідації.**
- **Подвійний облік вигод, які перекриваються.**
