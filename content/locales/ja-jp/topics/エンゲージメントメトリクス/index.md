# エンゲージメントメトリクス

エンゲージメントメトリクスは、利用者が実際にどれだけ健康アプリを使っているかを測定します:DAU/MAUの粘着性、セッションの頻度と時間、機能の利用。デジタルヘルスにおいて、エンゲージメントは見栄えの数字ではなく — **用量**です:あらゆる臨床的効果が流れなければならない曝露です。

## なぜ重要か

瓶の中に残っている薬は誰も治しません;インストールされない、あるいは開かれないアプリも同じ失敗モードです。消費者向け健康製品のあらゆる医療経済学的な主張は、エンゲージメントを通じて掛け合わされます — 試験で示された有効性はある利用レベルで測定されたものであり、実世界の価値は、展開時の利用がそのレベルにどれだけ近づくかに応じてスケールします。標準的な製品ベンチマーク:DAU/MAUは一般的なモバイルアプリでは約**20%が健全**とされ、25%超は例外的です;健康アプリはしばしばそれより低く推移します。

## 数式

```
粘着性(DAU/MAU) = デイリーアクティブユーザー / マンスリーアクティブユーザー × 100
セッションのメトリクス = セッション数/利用者/期間;平均時間 = 総時間 / セッション数
機能のエンゲージメント = 主要な行動を行う利用者 / アクティブユーザー

用量反応の枠組み(医療経済学の改善点):
  実現された効果 ≈ 試験効果 × f(実際の利用 / 試験での利用)
  fは用量反応分析から得られる — アドヒアランスと継続における
  「効果的なエンゲージメント」の概念を参照:意図されたアウトカムを
  達成するのに十分な利用であり、それは控えめで有限かもしれない
```

## 計算例

ある血圧アプリの重要な研究は、週4回以上記録する利用者において収縮期血圧6mmHgの低下を示しました。登録利用者50,000人にわたる展開において:

```
MAU 20,000(40%);そのうち週4回以上記録:7,000人
有効用量の利用者 = 7,000 / 50,000 = 登録者ベースの14%

集団レベルの効果 ≈ 試験の効果が100%ではなく14%に届けられる:
「50,000人の利用者×6mmHg」と主張する経済モデルは約7倍過大評価しています。
正直なモデル:7,000人×完全な効果+(もしあれば用量反応データからの)
13,000人の閾値未満の利用者への部分的な効果。
```

この乗算 — エンゲージメントファネルを通じて有効用量に至るまで — は、デジタルヘルスの経済学が膨らむ単一の最も一般的な場所です。

## ソフトウェア工学との関連

エンジニアはエンゲージメントファネルを所有しており、これは彼らを*臨床*変数の所有者にします:オンボーディングの摩擦、通知戦略、読み込み時間、オフライン耐性はすべて、届けられる用量を動かします。2つの設計上の含意:オープン数ではなく**臨床的に意味のある行動**(記録された測定値、完了したレッスン)を計測すること — 通知のバウンスセッションで構築されたDAUは用量の詐称です;そしてエンゲージメントの目標を最大化ではなく*十分性*の目標として扱うこと — 週5分でアウトカムを達成し、邪魔をしないアプリは臨床的には理想的でメトリクス的には「乏しい」です([アドヒアランスと継続](../アドヒアランスと継続/)の効果的なエンゲージメントを参照)。エンゲージメント作業自体を、上記の集団効果モデルを通じて評価してください:有効用量シェアの2ポイントの獲得は、定量化可能なQALYの項目です。

## 落とし穴

- **アウトカムとしてのエンゲージメント**:利用は手段であり、アウトカムは[PROM](../患者報告アウトカム/)または臨床的エンドポイントです。
- **二峰性の利用にわたる平均**:健康アプリの利用者集団は、熱心な利用者と幽霊利用者に分かれます;平均は誰も説明しません — コホート分けしてください。
- **ダークパターンによる用量の水増し**:連続記録と罪悪感を煽る通知はメトリクスを上げますが、健康アプリがサービスを提供する不安を抱えた集団に害を与えることがあります;臨床製品は臨床倫理を伴います。
- **ベンダーベンチマークの出所**:公表されているエンゲージメントベンチマークのほとんどは、査読ではなく分析ベンダーからのものです;自分自身の試験に対して較正してください。
