# Costo Totale di Proprietà (TCO)

Il TCO è il costo completo di un sistema durante la sua vita: acquisizione o costruzione, integrazione, funzionamento, manutenzione. La linea di base scomoda: **la manutenzione è il 50–80% del TCO del software**.

## Perché è importante

La valutazione delle tecnologie sanitarie ha imparato da tempo che il prezzo di un farmaco non è il suo costo.

## La matematica

```
TCO = costo iniziale + Σ_t [funzionamento + manutenzione + supporto]_t / (1 + r)^t
```

## Esempio risolto

Due opzioni per un sistema di e-osservazione, orizzonte di 5 anni: TCO non attualizzato £1.090.000 vs £2.030.000.

## Collegamento con l'ingegneria del software

Gli ingegneri sottovalutano i dati di manutenzione del proprio campo quando sostengono la costruzione. Una cifra TCO pluriennale come quella sopra è la somma di molte voci di costo nel tempo — si veda l'[aggregazione dei costi sicura per le valute](../aggregazione-dei-costi-sicura-per-le-valute/) per capire perché quella somma dovrebbe essere decimale esatta anziché in virgola mobile non appena un modello deve quadrare al centesimo, e l'[allocazione dei costi al centesimo esatto](../allocazione-dei-costi-al-centesimo-esatto/) per ripartire un totale TCO tra centri di costo senza perdere centesimi.
