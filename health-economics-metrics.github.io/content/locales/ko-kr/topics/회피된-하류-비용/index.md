# 회피된 하류 비용

회피된 하류 비용(비용 상쇄)은 더 이른 또는 더 나은 조치에 의해 예방되는 미래 치료 지출입니다.

## 왜 중요한가

거의 모든 디지털 헬스 가치 제안에는 상쇄 주장이 포함되어 있습니다: "우리 앱은 입원을 예방합니다."

## 수식

```
순비용 = 개입 비용 − Σ 상쇄

유효한 상쇄는 다음을 만족해야 합니다:
  귀속 가능 — 개입과 인과적으로 연결됨
  한계적 — 돈이 실제로 지출되지 않게 됨
  확률가중 — P(하류 사건이 발생했을 것) 가중치 적용
```

## 계산 예시

수술후 환자 5,000명을 위한 상처 모니터링 앱: 순비용 = −£44,000 → 진정으로 비용을 절감합니다.

## 소프트웨어 공학과의 연관성

"이 마이그레이션은 향후 재작성을 방지합니다"는 상쇄 주장입니다.

## 함정

- **이중 계산.**
