# Totale eigendomskosten (TCO)

TCO zijn alle kosten die tijdens de volledige levensduur van een softwaresysteem worden gemaakt: bouwen, draaien, onderhouden en afstoten.

## Waarom het ertoe doet

Alleen naar de initiële bouwkosten kijken mist de schaduw van de operationele kosten.

## De wiskunde

```
TCO = kapitaaluitgaven + Σ(operationele kosten_per jaar) − restwaarde
```

## Uitgewerkt voorbeeld

Een klinisch systeem met een levensduur van 5 jaar: bouw £500.000 + operatie £150.000/jaar × 5 = £1.250.000.
