# 啟用與採納 (Activation and Uptake)

啟用率是指達到首次有意義價值（即"頓悟"時刻——首次記錄讀數、完成首堂課程等關鍵行動）的註冊使用者佔比。採納率則是其人群層面的對應指標：*符合條件*人群中最終採用該產品的比例。二者共同構成價值漏斗的前端關口：獲客 → 採納 → 啟用 → [留存](../留存與流失/) → 結果。

## 為何重要

未啟用使用者純屬成本：獲客支出、開通配置、支援成本，卻沒有產生任何臨床價值。基準資料顯示，醫療軟體的啟用率*低於*跨行業平均水平（某SaaS基準資料集中，新使用者啟用率約為24%，而跨行業平均約為37%；引導清單完成率約為20%），這反映了醫療場景中更繁重的引導流程（身份核驗、知情同意、臨床安全）。採納率則關乎整個人群層面的利害得失：按照[RE-AIM框架](../觸達與公平/)，公共衛生影響≈覆蓋率×有效性——一款再優秀的應用，如果只被3%的符合條件人群採用，其人群層面的影響力也僅相當於3%。對於處方類數位療法，採納這道關口在國家層面的資料中清晰可見：**德國DiGA處方中約81%被啟用使用**——五分之一已開具且已付費的治療方案從未真正開始（參見[DiGA快速通道](../德國DiGA快速通道/)）。

## 計算方法

```
啟用率     = 在視窗期內完成關鍵行動的使用者數 / 註冊使用者數 × 100
採納率     = 採用者數 / 符合條件人群數 × 100
DTx啟用率  = 已啟用處方碼數 / 已開具處方數 × 100

漏斗價值模型：
  符合條件人數 × 採納率 × 啟用率 × 留存加權收益 = 人群價值
  ——共四次相乘；改進其中最小的因子通常
  影響最大（漏斗場景下的約束理論）
```

## 實例演算

某委託方向80,000名符合條件的居民提供一款糖尿病預防應用：

```
邀請 → 註冊：  80,000 → 12,000（採納率15%）
註冊 → 啟用（首次使用會話 + 設定目標，7天內）：12,000 → 5,400（45%）
啟用 → 完成6個月專案：5,400 → 1,600（30%）

專案效果（試驗資料，完成者）：0.03 QALY + £180 避免成本
人群價值 = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
每名符合條件人員的價值 = £15.6 —— 若每位符合條件人員都完成專案，則為£780。

該投資何處？將採納率翻倍（15%→30%）可使價值翻倍；將
啟用率從45%提升至65%可增加約44%的價值；這兩者都優於
繼續打磨那1,600名已完成者所使用的專案內容。
```

## 與軟體工程的關聯

啟用是漏斗中工程可控性最強的階段：身份驗證摩擦、知情同意流程、空狀態設計以及首次價值實現時間，都是程式碼問題而非政策問題（基準資料顯示醫療領域的價值實現時間中位數約為1天7小時——每多耗一小時都意味著流失風險的增加）。採納則是一個分發系統問題：融入轉診路徑（開處方的那一刻）、全科醫師背書的邀請（信任轉移）以及無障礙可及性（語言、數位技能——參見[覆蓋與公平](../觸達與公平/)）。上述漏斗價值模型正是這兩者商業案例的生成器：將各因子相乘，找出瓶頸約束，再按其釋放的人群價值為修復方案定價。

## 常見陷阱

- **將啟用定義為便利性事件**（如郵箱已驗證）而非臨床意義事件（如首次治療性行動）——會虛增該指標，破壞價值鏈。
- **採納率分母的花招**："在訪問過網站的人中"而非真正符合條件的人群——委託方關心的是後者。
- **選擇效應**：容易被啟用的使用者往往病情最輕、處境最不弱勢；漏斗改進措施可能在提升平均水平的同時擴大公平差距。
