# Kostnadsminimeringsanalyse (CMA)

Kostnadsminimeringsanalyse velger det billigste alternativet etter at det er bevist at de sammenlignede intervensjonene har ekvivalent effektivitet.

## Hvorfor det er viktig

Når effektiviteten allerede er bevist ekvivalent, er det unødvendig å utføre komplekse kostnadseffektivitetsberegninger — velg bare det billigste.

## Matematikken

```
Velg alternativ med min(Kostnad), gitt Effekt_A = Effekt_B
```

## Gjennomarbeidet eksempel

To generiske legemidler med bevist identisk effekt: velg det med lavest innkjøpspris, uten ytterligere analyse.

## Kobling til programvareutvikling

Ligner på å velge den billigste skyleverandøren etter å ha bekreftet at begge oppfyller de samme ytelses- og pålitelighetskravene.

## Fallgruver

- **Å anta ekvivalens uten solid dokumentasjon.**
- **Å bruke CMA når effektene faktisk skiller seg subtilt.**
