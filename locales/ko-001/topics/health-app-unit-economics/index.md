# 건강 앱 단위 경제학

건강 앱 단위 경제학은 사용자당 획득 비용, 사용자당 운영 비용, 그리고 사용자당 창출 가치를 측정합니다.

## 왜 중요한가

임상적으로 효과적인 앱도 단위 경제학이 지속 불가능하면 확장할 수 없습니다.

## 수식

```
생애가치 대 획득비용 비율 = 사용자 생애가치(LTV) / 사용자 획득비용(CAC)
```

## 계산 예시

만성질환 관리 앱: LTV £180, CAC £45 = 비율 4:1 (지속 가능한 것으로 간주).

## 소프트웨어 공학과의 연관성

[유지율과 이탈](../retention-and-churn/)이 LTV의 핵심 동인이며 [클라우드 단위 경제학](../cloud-unit-economics/)이 운영 비용 측을 형성합니다.

## 함정

- **획득 비용에 재획득(이탈 후 재참여) 비용을 포함하지 않기.**
