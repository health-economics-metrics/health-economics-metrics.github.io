# 디지털 엔드포인트와 바이오마커

디지털 엔드포인트와 바이오마커는 센서, 웨어러블, 또는 디지털 도구를 통해 수집된 객관적이고 정량화 가능한 건강 측정치입니다.

## 왜 중요한가

디지털 바이오마커는 전통적인 임상 방문 사이의 간극을 메우는 연속적이고 객관적인 데이터를 제공합니다.

## 수식

```
디지털 엔드포인트 타당성 = 상관계수(디지털 측정치, 검증된 임상 기준)
```

## 계산 예시

걸음수 기반 보행 속도 측정: 임상 6분 보행 검사와의 상관계수 r = 0.82.

## 소프트웨어 공학과의 연관성

[웨어러블 검증](../웨어러블-검증/)이 이 데이터의 신뢰성을 확립하는 전제조건입니다.

## 함정

- **검증되지 않은 센서 데이터를 임상적으로 타당한 것으로 취급하기.**

## 출처

- FDA, digital health technologies for remote data acquisition.
