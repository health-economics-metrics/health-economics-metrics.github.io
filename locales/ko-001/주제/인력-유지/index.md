# 인력 유지

인력 유지 경제학은 직원 이직이 보건 시스템에 얼마나 많은 비용을 초래하는지 측정합니다.

## 왜 중요한가

임상의가 떠나면 트러스트는 세 번 지불합니다: 대체 인력을 채용하고, 그들을 온보딩하고, 그 사이 공석을 메우는 것.

## 수식

```
이직자당 비용 = 채용 비용 + 온보딩/생산성 향상 비용
              + 공석 충원 프리미엄 × 공석 기간
```

## 계산 예시

트러스트가 1,200명의 간호사를 고용합니다; 이직률 11%/년. 문서화 부담 소프트웨어: 연간 £222,000.

## 소프트웨어 공학과의 연관성

공학 유지 수학은 동일합니다.

## 함정

- **모든 이직 변동을 개입 탓으로 돌리기.**

## 출처

- NHS England, reducing agency spend.
- NHS Staff Survey.
