# Kassavaikutteiset vastaan ei-kassavaikutteiset säästöt

Kassavaikutteiset säästöt pienentävät todellista budjettia; ei-kassavaikutteiset säästöt (kuten "säästetty aika") tekevät niin vain, jos vapautunut kapasiteetti todella kohdennetaan uudelleen johonkin arvokkaaseen.

## Miksi se on tärkeä

Useimmat "säästää £X" -väitteet digitaalisen terveydenhuollon liiketoimintatapauksissa ovat ei-kassavaikutteisia ja haihtuvat pois ilman selkeää uudelleenkohdennussuunnitelmaa.

## Matematiikka

```
Todellinen säästö = Kassavaikutteinen summa + (Ei-kassavaikutteinen aika × uudelleenkohdennuksen todennäköisyys)
```

## Ratkaistu esimerkki

Dokumentaatiotyökalu säästää lääkäreiltä 10 minuuttia per konsultaatio. Ellei tätä aikaa käytetä lisäkonsultaatioihin, säästö on ei-kassavaikutteinen.

## Yhteys ohjelmistokehitykseen

Muistuttaa "automaation säästämä aika" -väitteitä, jotka eivät tuota tuottavuushyötyjä, ellei vapautunutta aikaa todella käytetä johonkin muuhun.

## Sudenkuopat

- **Kaiken ajansäästön käsitteleminen rahallisena säästönä.**
- **Uudelleenkohdennussuunnitelman määrittelemättä jättäminen.**
