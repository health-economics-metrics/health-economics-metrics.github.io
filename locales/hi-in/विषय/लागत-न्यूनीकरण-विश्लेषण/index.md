# लागत-न्यूनीकरण विश्लेषण (CMA)

CMA केवल लागतों की तुलना करता है, और सबसे सस्ता विकल्प चुनता है — यह तभी वैध है जब विकल्पों के परिणाम समान साबित हों।

## यह क्यों महत्वपूर्ण है

CMA सबसे सरल विश्लेषण है और सबसे अधिक दुरुपयोग किया जाने वाला।

## गणित

```
प्रमाण हो कि प्रभाव_A ≈ प्रभाव_B (पूर्व-निर्दिष्ट मार्जिन δ के भीतर):
min(लागत_A, लागत_B) चुनें
```

## हल किया गया उदाहरण

एक ट्रस्ट दो वीडियो-परामर्श प्लेटफ़ॉर्मों के बीच चुनता है। पूर्णता दर 94.1% बनाम 93.8%।

```
                     प्लेटफ़ॉर्म A     प्लेटफ़ॉर्म B
कुल                  £500,000         £450,000
```
