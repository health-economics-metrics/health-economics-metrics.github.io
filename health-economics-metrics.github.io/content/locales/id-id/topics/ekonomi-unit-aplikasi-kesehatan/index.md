# Ekonomi Unit Aplikasi Kesehatan

Matematika komersial produk kesehatan konsumen: biaya akuisisi pelanggan (CAC), nilai seumur hidup (LTV), dan perbedaan antara **ROI dan VOI** (nilai atas investasi) di pasar pemberi kerja.

## Mengapa ini penting

Aplikasi kesehatan menghadapi tekanan struktural: akuisisi mahal sementara retensi adalah yang terburuk dari vertikal perangkat lunak apa pun (~90% pengabaian dalam 30 hari).

## Matematika

```
CAC = pengeluaran penjualan + pemasaran / pelanggan baru yang membayar
LTV = ARPU × umur rata-rata = ARPU / tingkat churn
```

## Contoh yang diselesaikan

Aplikasi tidur B2C: £6,99/bulan, churn bulanan 18%: LTV:CAC ≈ 1,0 — tidak berkelanjutan.

## Hubungan dengan rekayasa perangkat lunak

Pilihan rekayasa menentukan kedua sisi rasio.

## Jebakan

- **LTV dari churn kohort awal.**
