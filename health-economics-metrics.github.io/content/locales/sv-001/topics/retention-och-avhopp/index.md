# Retention och avhopp

Retention och avhopp mäter om användare fortsätter använda en hälsoapp över tid eller slutar.

## Varför det är viktigt

Avhoppsfrekvenser för hälsoappar tenderar att vara mycket högre än för vanliga konsumentappar.

## Matematiken

```
Månatlig avhoppsfrekvens = antal förlorade användare den månaden / totalt antal användare vid månadens början × 100 %
```

## Genomarbetat exempel

En app för psykisk hälsa: vid början 5 000, förlorade 750 = månatlig avhoppsfrekvens 15 %.
