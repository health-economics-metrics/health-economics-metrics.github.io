# लाभ वास्तविकीकरण

लाभ वास्तविकीकरण प्रबंधन (BRM) वह अनुशासन है जो पहचानता है, आधाररेखा बनाता है, ट्रैक करता है, और *साबित* करता है कि एक व्यावसायिक मामले में वादा किया गया लाभ वास्तव में हुआ।

## यह क्यों महत्वपूर्ण है

व्यावसायिक मामले वादे हैं; लाभ वास्तविकीकरण ऑडिट है।

## गणित

```
वास्तविकीकरण दर = वास्तविक लाभ / पूर्वानुमानित लाभ
```

## हल किया गया उदाहरण

एक ई-रोस्टरिंग व्यावसायिक मामला सालाना वादा करता है: £450k एजेंसी-व्यय में कमी।

```
लाभ         पूर्वानुमान   वास्तविक    दर
एजेंसी व्यय £450,000     £287,000    64%
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इंजीनियरिंग संगठन पूर्वानुमानित लाभों के आधार पर प्लेटफ़ॉर्म निवेश को मंज़ूरी देते हैं।

## सामान्य गलतियाँ

- **चालू-पूर्व आधाररेखा नहीं होना।**
