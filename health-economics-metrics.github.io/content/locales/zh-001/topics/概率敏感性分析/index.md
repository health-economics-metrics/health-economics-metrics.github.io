# 概率敏感性分析（PSA）

PSA为每一个不确定参数赋予一个概率分布，将所有参数同时进行数千次联合抽样（蒙特卡洛模拟），并报告某个方案是最佳选择的*概率*——而非单一的点估计值。

## 为何重要

NICE的参考案例*要求*必须进行PSA。确定性分析回答的是"如果某一项输入是错的，会怎样？"；而PSA回答的是"考虑到我们同时存在的所有未知因素，我们做出正确决策的可能性究竟有多大？"其标志性输出——**成本效果可接受性曲线（CEAC）**——绘制的是某方案在不同支付意愿阈值下具有成本效果的概率，从而把"ICER是每QALY £24,000"这样的表述，转化为"在每QALY £30,000的阈值下，这是正确选择的可能性为78%"。

## 计算方法

```
对N次抽样（N ≈ 10,000）中的每一次：
  从各自分布中抽取每一个参数θ
    （成本 ~ Gamma分布，概率 ~ Beta分布，效用值 ~ Beta分布，效果 ~ 正态/对数正态分布）
  为每个方案j计算 NMB_j(θ) = λ × 效果_j(θ) − 成本_j(θ)

CEAC_j(λ) = 在阈值λ下，方案j拥有最高NMB的抽样次数占比
```

关于NMB，参见[净货币效益](../净货币效益/)；关于λ，参见[支付意愿阈值](../支付意愿阈值/)。

## 实例演算

某平台迁移商业论证。存在三项不确定输入：

```
迁移成本      ~ Gamma分布，均值£800,000，标准差£200,000
年度效益      ~ 正态分布，均值£350,000，标准差£150,000
效益持续年数   ~ 均匀分布，3–6年
```

对10,000次抽样中的每一次，计算净效益 = 持续年数 × 年度效益 − 成本（为清晰起见省略贴现）。示例结果如下：

```
净效益均值：           £775,000
净效益 > 0 的概率：     0.86
第5至第95百分位区间：  −£180,000 … +£190万
```

点估计的结论是"显然应该做"。而PSA的结论是"86%的可能性应该做，但确实存在一个尾部风险，可能损失£180,000以上"——这才是一位投资组合负责人真正需要的信息，也为先做一次探索性尖刺研究提供了定价依据（参见[EVPI](../完美信息期望价值/)）。

## 与软件工程的联系

工程师早已信赖蒙特卡洛方法用于交付预测（吞吐量抽样优于点估计）。可以将同一套方法直接延伸到金钱层面：为采纳率、节省的时间与薪资设定分布，然后报告"该平台投资净收益为正的概率"，而非一个虚假精确的投资回报率数字。一条CEAC式曲线——展示"作为组织对一个工程师-小时估值高低的函数，某方案是最佳选择的概率"——对资助委员会而言，确实是比任何单一数字都更有价值的呈现方式。

## 陷阱

- **垃圾分布**：使用凭空捏造的标准差做PSA，不过是披着白大褂的确定性分析。分布应基于数据，或结构化的专家意见征询。
- **忽视参数之间的相关性**（高采纳率通常与高节省时间相关）；独立抽样会低估尾部风险。
- **只报告模拟结果的均值**——PSA的全部意义，恰恰在于其分布本身以及决策概率。
