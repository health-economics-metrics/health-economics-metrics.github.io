# 多基準意思決定分析(MCDA)

多基準意思決定分析(MCDA)は、単一のICER/支払意思額の閾値では、公平性、満たされていないニーズ、イノベーション、予算影響、疾患の重症度など、意思決定者が重視するすべてを捉えきれない場合に、医療技術評価で使われる重み付き和のスコアリングモデルです。各基準にはその重要度を反映する重み(ステークホルダーから引き出し、合計が1になる)が与えられ、各選択肢には基準ごとの正規化されたスコア(通常0〜1)が与えられ、総合スコアは重み付き和になります。ソフトウェアベンダー選定のスコアカードと同じ数学的な形です。

## なぜ重要か

MCDAは、EVIDEMのような枠組みや、一部のHTA機関による希少疾病用医薬品や希少疾患の評価で使われます。そうした評価では、厳密なQALYあたり費用の閾値アプローチは、意思決定について重要なことをすべて捉えるには狭すぎると考えられています。ISPORのMCDA Emerging Good Practices Task Forceは、重みやスコアを根拠をもって引き出すためのグッドプラクティスのガイダンスを整理しました。非公式に重みづけされた意思決定は、作りやすく、操作もしやすいためです。ある医療技術が、単一の[支払意思額の閾値](../willingness-to-pay-thresholds/)では表現できない価値の次元(重症度、イノベーション、公平性)を本当に持つ場合、MCDAは意思決定者に、言明されない判断ではなく、それらを組み合わせるための明示的で監査可能な構造を与えます。

## 数式

```
MCDAスコア = Σ_i (重み_i × スコア_i)

重みの合計は1にすべき(スイング加重法や階層分析法(AHP)のような
ステークホルダー手法で引き出す)
```

## 計算例

HTA委員会が、あるデジタル治療を4つの基準で採点します。

```
基準                               重み     スコア  重み × スコア
臨床的便益                         0.4      0.8     0.32
費用への影響                       0.3      0.5     0.15
疾患の重症度 / 満たされていないニーズ 0.2   0.9     0.18
イノベーション                     0.1      0.6     0.06
                                    ─────                ─────
                                    1.0                  0.71
```

重みの合計は1.0(0.4 + 0.3 + 0.2 + 0.1)で、MCDAスコアは0.71(0.32 + 0.15 + 0.18 + 0.06)です。委員会は0.71を事前に合意した閾値と比較するか、同じ方法で採点された競合技術との間で順位づけします。

## ソフトウェア工学との関連

これは、重み付きのベンダー選定スコアカード、RFP評価マトリクス、機能優先順位づけのスコアリングモデルと全く同じ数学です。ソフトウェア調達における重み付きスコアカードの古典的な用途である[内製か購入か](../build-vs-buy/)を参照してください。[WSJFとCD3](../wsjf-and-cd3/)と対比する価値もあります。WSJF/CD3は*比*に基づく優先順位づけ手法(遅延コストを作業規模や期間で割ったもの)であるのに対し、MCDAは重み付きの*和*です。MCDAとWSJF/CD3は、「競合する選択肢をどう順位づけるか」に対する構造的に異なる2つの答えであり、どちらがより厳密に見える式かよりも、ある意思決定が実際にどちらを必要としているか、つまり独立した基準にわたる加算的な価値か、希少な容量の単位あたりの価値密度かを知ることのほうが重要です。

## 落とし穴

- **重みの引き出しにおけるバイアス**: 重みを設定する人が事実上順位を決めてしまうため、「数式」が政治的または商業的な決定を客観的な計算として正当化してしまうことがあります。誰がどのように重みを設定したかを文書化してください。
- **すでに別の場所で捉えられた基準の二重カウント**: 「費用対効果」を1つの基準として採点しながら、*さらに*「費用への影響」を別に採点すると、誰も意図しないまま、他の基準に比べて金銭が過大に重みづけされます。
- **見せかけの精度**: 小数2桁の重み付きスコア(0.71)は、その根拠となる0〜10のステークホルダー評価が実際に支えられる以上の厳密さを示唆し、そうした評価の評価者間のばらつきはしばしば全く報告されません。
