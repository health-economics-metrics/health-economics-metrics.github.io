# WSJF와 CD3

CD3와 WSJF는 **가치밀도**에 따라 작업을 우선순위화하는 규칙입니다.

## 왜 중요한가

모든 백로그는 배급 문제입니다.

## 수식

```
CD3 = 지연 비용(£/주) / 기간(주)
```

## 계산 예시

세 가지 기능, 한 팀: CD3 순서: B, C, A.
