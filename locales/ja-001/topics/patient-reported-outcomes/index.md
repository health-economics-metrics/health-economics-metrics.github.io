# 患者報告アウトカム(PROM、PREM、MCID)

PROMは、患者が自分自身の健康状態(症状、機能、生活の質)を報告する標準化された測定手法です;PREMはケアの*体験*を捉えます。**MCID**(最小臨床的に重要な差)とは、患者が実際に有益だと知覚する最小のスコア変化のことです:主張されるあらゆる改善がクリアしなければならない基準です。

## なぜ重要か

PROMはデジタルヘルスにとって主要な有効性の通貨です:アプリが死亡率を動かすことはめったにありませんが、検証済みの症状スコアを信頼できる形で動かすことはできます。重要な測定手法は少なく標準化されています — **PHQ-9**(うつ病、0〜27;重症度の区分は5/10/15/20)、**GAD-7**(不安、0〜21;区分は5/10/15)、**EQ-5D**([QALY](../quality-adjusted-life-year/)のための効用) — そして規制当局、HTA機関、支払者がこれらを受け入れるのは、まさにそれらが製品や試験をまたいで比較可能だからです。MCIDは正直さの関門です:PHQ-9のMCID≈5ポイント、GAD-7≈4、EQ-5D指数は一般的に約0.03〜0.08 — 大規模サンプルでの統計的に有意な1.5ポイントのPHQ-9の変化は*本物だが臨床的には無意味*であり、証拠のレビュアーはそう言うでしょう。

## 数式

```
PROMのスコアリング:測定手法固有の合計(例:PHQ-9 = Σ9項目 × 0〜3)

MCIDの推定:
  基準に基づく方法:      「やや良くなった」と報告した患者の間でのスコア変化
  分布に基づく方法:      ≈ベースラインスコアの標準偏差の0.5倍(大まかな経験則)

反応率の枠組み(試験と提出資料のための):
  反応者 = MCID以上改善した患者(あるいはPHQ-9の慣例では50%以上)
  NNT = 1 / (治療群の反応率 − 対照群の反応率)
  — 治療必要数を参照
```

## 計算例

あるうつ病支援アプリ、待機リストに対するRCT、12週間:

```
PHQ-9の変化:アプリ−6.2ポイント、対照−2.1 → 調整後の差−4.1
MCIDの確認:4.1 < 5 → 平均差はMCID未満;代わりに反応者を報告する:
  反応者(5ポイント以上の低下):アプリ48%、対照22% → ARR 26%
  NNT = 1/0.26 ≈ 4 — 追加の臨床的反応1件あたり4人の利用者を治療

経済的な橋渡し:反応者のEQ-5Dの獲得0.06が6か月持続
  = 0.03QALY;利用者1,000人あたり:260人の追加反応者 × 0.03 = 7.8QALY
  ≈ NICEの閾値で£156,000〜£234,000の健康価値
```

反応者/NNTの枠組みは、MCID未満の平均差なら却下されていたであろうレビューを乗り越えます。

## ソフトウェア工学との関連

PROMは、ソフトウェアが独自に解決できる立場にあるデータ収集の問題です:アプリ内の測定手法は、紙では決して達成できなかった完了率と縦断的な密度を得て、日常的な製品のテレメトリをHTAグレードの証拠に変えます([EQ-5D](../eq-5d/)は5画面です)。エンジニアリングのルール:検証済みの測定手法を*逐語的に*使うこと(言い換えはそれを無効にします — ライセンスが適用されます);エンゲージメントの都合ではなくプロトコルによって測定をスケジュールすること(アクティブな利用者だけを測定することは生存者バイアスです — [定着](../retention-and-churn/)を参照);そして測定手法のデータを、あらゆるスキーマと同じようにバージョンロックすること — 研究途中の文言変更はデータの破損です。PREMはCSAT/NPS式の測定手法にマッピングされ、同じ教訓が当てはまります:聴衆が支払者であるところでは、標準化されたものが独自のものに勝ります。 労働生産性に特化した尺度については、[WPAI](../work-productivity-and-activity-impairment/)を参照してください。

## 落とし穴

- **臨床的便益として提示されるMCID未満の統計的有意性** — この分野で最も一般的な水増しです。
- **平均への回帰**:利用者は症状のピーク時に登録します;単群の前後比較は大幅に過大評価します — 比較対象は交渉の余地がありません。
- **測定手法の買い物**:PHQ-9、GAD-7、WHO-5を実施し、動いたものだけを報告すること — 主要な測定手法を事前登録してください。
- **デジタル同意調査のプレッシャー**:利用者を好ましい回答に誘導することは測定手法を破損させます(そしてレビュアーは基準率を知っています)。
