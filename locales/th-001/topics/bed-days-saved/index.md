# วันเตียงที่ประหยัดได้

วันเตียงที่ประหยัดได้วัดจำนวนวันของการรักษาในโรงพยาบาลที่สิ่งแทรกแซงช่วยหลีกเลี่ยงได้ — ตัวชี้วัดผลประโยชน์หลักที่พบบ่อยที่สุดในกรณีทางธุรกิจของสุขภาพดิจิทัล

## ทำไมจึงสำคัญ

วันเตียงเป็นผลประโยชน์ "หลัก" ที่พบบ่อยที่สุดในกรณีทางธุรกิจ แต่มักถูกประเมินค่าผิดโดยใช้ต้นทุนเฉลี่ยแทนต้นทุนส่วนเพิ่ม

## คณิตศาสตร์

```
วันเตียงที่ประหยัดได้ = ผลรวมของ (จำนวนการเข้ารับการรักษาที่หลีกเลี่ยงได้ × ระยะเวลาเฉลี่ยของการรักษา)
```

## ตัวอย่างที่คำนวณแล้ว

โปรแกรมการออกจากโรงพยาบาลเร็วขึ้นช่วยหลีกเลี่ยงการรับผู้ป่วย 500 ราย เฉลี่ย 4 วันต่อราย: 2,000 วันเตียงที่ประหยัดได้ ประเมินด้วยต้นทุนส่วนเพิ่ม £150/วัน = £300,000

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการประเมินอินสแตนซ์เซิร์ฟเวอร์ที่ประหยัดได้โดยใช้ต้นทุนส่วนเพิ่ม ไม่ใช่ต้นทุนเฉลี่ยที่รวมค่าใช้จ่ายคงที่

## ข้อผิดพลาดที่พบบ่อย

- **การประเมินวันเตียงโดยใช้ต้นทุนเฉลี่ยแทนต้นทุนส่วนเพิ่ม — ดู [ต้นทุนส่วนเพิ่มเทียบกับต้นทุนเฉลี่ย](../marginal-vs-average-cost/)**
- **การสันนิษฐานว่าเตียงที่ว่างจะถูกนำกลับมาใช้โดยอัตโนมัติ**
