# Tervisetehnoloogia hindamine (HTA)

Tervisetehnoloogia hindamine on süstemaatiline protsess, mille käigus hinnatakse uue ravimi, seadme või sekkumise kliinilist ja majanduslikku väärtust enne selle laialdast kasutuselevõttu.

## Miks see on oluline

HTA on värav, mille kaudu peab enamik uusi tervishoiutehnoloogiaid läbima, enne kui süsteemid nõustuvad nende eest maksma — mõistmine, kuidas see toimib, on hädavajalik igaühele, kes ehitab tervisetehnoloogiat.

## Matemaatika

```
Inkrementaalne kulutõhususe suhe (ICER) = (Sekkumise kulu − Võrdluse kulu) / (Sekkumise tulemus − Võrdluse tulemus)
```

## Lahendatud näide

Uus diabeediseade maksab £2000 rohkem patsiendi kohta kui standardravi ja annab 0,1 lisakvaliteediga kohandatud eluaastat (QALY): ICER = £20 000/QALY, tõenäoliselt heaks kiidetud enamikus HTA raamistikes.

## Seos tarkvaraarendusega

Sarnaneb tootevalideerimise väravaga enne täielikku turuletoomist — tõendite kogumine enne laiaulatuslikku investeeringut.

## Lõksud

- **HTA nõuete arvestamata jätmine tootearenduse varases staadiumis.**
- **Ainult kliinilise tõhususe tõendamine ilma majandusliku juhtumita.**
