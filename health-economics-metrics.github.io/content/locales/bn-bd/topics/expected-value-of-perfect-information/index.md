# নিখুঁত তথ্যের প্রত্যাশিত মূল্য (EVPI)

EVPI হলো সিদ্ধান্ত নেওয়ার আগে অনিশ্চয়তা দূর করার জন্য একজন সিদ্ধান্ত গ্রহণকারীর সর্বোচ্চ যে পরিমাণ অর্থ পরিশোধ করা উচিত — "চলুন প্রথমে একটি গবেষণা চালাই" এই বিকল্পের আনুষ্ঠানিক মূল্য।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য ব্যবস্থা ক্রমাগত এই পছন্দের মুখোমুখি হয়: অসম্পূর্ণ প্রমাণের উপর এখনই গ্রহণ করা, নাকি প্রথমে আরও গবেষণায় অর্থায়ন করা। EVPI দ্বিতীয় বিকল্পের উপর একটি সংখ্যা বসায়। যদি EVPI £৫০,০০০ হয় এবং প্রস্তাবিত ট্রায়ালের খরচ £২০ লক্ষ হয়, এখনই গ্রহণ করুন। যদি EVPI £২ কোটি হয়, ট্রায়ালটি একটি দর কষাকষি। একই প্রশ্ন — "এটি চালু করার আগে কি আমাদের পাইলট করা উচিত?" — প্রতিটি এন্টারপ্রাইজ টুল সিদ্ধান্তের জন্যও উঠে আসে, এবং প্রায় কেউই এর মূল্য নির্ধারণ করে না।

## গণিত

EVPI হলো নিখুঁত দূরদর্শিতা নিয়ে সিদ্ধান্ত নেওয়া এবং প্রত্যাশার উপর ভিত্তি করে এখনই সিদ্ধান্ত নেওয়ার মধ্যকার ব্যবধান:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = অনিশ্চিত প্যারামিটার (তাদের যৌথ বণ্টনসহ)
NMB(j,θ) = θ প্রদত্ত বিকল্প j-এর নিট আর্থিক সুবিধা
```

প্রথম পদ: প্রতিটি সম্ভাব্য বিশ্বে সর্বোত্তম-পছন্দ পুরস্কারের গড় (আপনি সবসময় সঠিক বেছে নেন)। দ্বিতীয় পদ: গড়ে সর্বোত্তম একক বিকল্পের পুরস্কার (আপনাকে এখনই প্রতিশ্রুতিবদ্ধ হতে হবে)। EVPI সবসময় ≥ ০। জনসংখ্যা EVPI প্রভাবিত সিদ্ধান্তের সংখ্যা দিয়ে গুণিত হয়। [PSA](../probabilistic-sensitivity-analysis/) ড্র থেকে সরাসরি গণনা করা হয়।

## সমাধানকৃত উদাহরণ

৫,০০০ চিকিৎসকদের কাছে একটি AI নথিপত্র সহায়ক চালু করা, নাকি না। দুটি বিশ্ব:

```
বিশ্ব A (p = 0.6): সহায়ক দিনে ২০ মিনিট সাশ্রয় করে → চালুর NMB = +£8M
বিশ্ব B (p = 0.4): সহায়ক প্রায় ০ সাশ্রয় করে (কর্মপ্রবাহ ঘর্ষণ) → চালুর NMB = −£3M
"চালু না করা"-র NMB = উভয় বিশ্বেই £0।
```

এখনই সিদ্ধান্ত নেওয়া: E[চালুর NMB] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → চালু করুন।

নিখুঁত তথ্যসহ: বিশ্ব A-তে চালু বেছে নিন (+£8M), বিশ্ব B-তে কিছুই না বেছে নিন (£0)। প্রত্যাশিত মূল্য = 0.6 × 8 + 0.4 × 0 = **£4.8M**।

```
EVPI = 4.8M − 3.6M = £1.2M
```

কোন বিশ্বে আছেন তা উল্লেখযোগ্যভাবে সমাধান করে এমন £১৫০,০০০ খরচের একটি কঠোর ৩-মাসের পাইলট স্পষ্টতই মূল্যবান — এবং £১.২ কোটির বেশি খরচের যেকোনো পাইলট নয়, তা যতই পুঙ্খানুপুঙ্খ হোক না কেন।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

EVPI হলো স্পাইক, পাইলট, A/B টেস্ট, এবং ধারণার প্রমাণের অর্থনীতি। এটি দুটি ব্যবহারিক নিয়ম দেয়:

- **একটি পাইলট শুধুমাত্র তখনই অর্থায়নের যোগ্য যদি সিদ্ধান্ত প্রকৃতপক্ষে পরিবর্তিত হতে পারে।** যদি পাইলটের ফলাফল নির্বিশেষে আপনি চালু করতেন, EVPI = 0 এবং পাইলটটি নাটক মাত্র।
- **পাইলট ব্যয় EVPI-তে সীমাবদ্ধ রাখুন।** তথ্যের মূল্য যে সিদ্ধান্তকে জানায় তার মূল্য দ্বারা সীমাবদ্ধ।

আংশিক EVPI (EVPPI) এটিকে একক প্যারামিটারে প্রসারিত করে: "সাশ্রয়ী-সময় সংখ্যাটি নির্দিষ্টভাবে নিশ্চিত করার মূল্য কী?" — যা আপনাকে বলে পাইলটটি কী পরিমাপ করা উচিত।

## ঝুঁকিপূর্ণ দিক

- **কোনো সিদ্ধান্ত নিয়ম সংযুক্ত না করে পাইলট চালানো** — সংজ্ঞা অনুসারে পছন্দ পরিবর্তন করতে না পারা তথ্য মূল্যহীন।
- **তথ্য সংগ্রহের বিলম্ব ব্যয় উপেক্ষা করা**: একটি ৬-মাসের পাইলট ৬ মাসের সুবিধা বিলম্বিত করে ([বিলম্বের ব্যয়](../cost-of-delay/)); পাইলটের নিট মূল্য = সমাধানকৃত EVPI − বিলম্ব ব্যয় − পাইলট ব্যয়।
- **EVPI-কে একটি পূর্বাভাস হিসেবে বিবেচনা করা।** এটি তথ্য মূল্যের একটি ঊর্ধ্বসীমা, নির্দিষ্ট একটি গবেষণা কী দেবে তার অনুমান নয়।
