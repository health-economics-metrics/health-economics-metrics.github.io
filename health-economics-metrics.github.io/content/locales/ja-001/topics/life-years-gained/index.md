# 獲得生存年(LYG)

獲得生存年とは、質の調整を行わない、介入に起因する追加の生存のことです:介入がある場合とない場合の生存曲線の間の面積です。等価値獲得生存年(evLYG)は、すべての延命を等しく評価する現代的な派生形です。

## なぜ重要か

LYGは最も生の健康アウトカムです:人々はどれだけ長く生きるのか?質のデータが欠けている場合、QALYに懐疑的な聴衆と比較する場合、そして生存曲線が主要な試験成果である腫瘍学において、これは重要です。**evLYG**(米国のICER研究所が費用/QALYと併せて使用)は、倫理的な理由で存在します:QALYは延命された1年を患者の効用で評価するため、障害のある人の延命は「価値が少なく数えられ」ます — evLYGはすべての延命年を固定の効用で評価し、その差別を取り除きます。

## 数式

```
LYG = 平均生存_新 − 平均生存_比較対象
    = 生存曲線間の面積(評価期間に限定)

延命のQALYの見方:  延命年数 × 患者の効用
延命のevLYGの見方: 延命年数 × 固定効用(ICERは約0.851、
                   米国の平均的な人口効用を使用)
```

どちらも経済モデルの中で[割引](../discounting-and-time-preference/)されます。

## 計算例

病院における敗血症早期警告アルゴリズム:モデリングにより、早期の抗生物質投与が年間12件の死亡を防ぐことが示されています;これらの患者の平均年齢では、それぞれ効用0.7で残り8年の生存年数があります。

```
LYG    = 12 × 8            = 年間96生存年
QALY   = 96 × 0.7          = 67.2
evLYG  = 96 × 0.851        = 81.7
```

1QALYあたり£20,000では、QALYの枠組みは生存を年間£134万と評価します;evLYGの枠組みでは£163万です。この差は、まさに効用0.7の1生存年が「完全な」1年の70%の価値があるかどうかという倫理的判断です。本格的な提出資料は両方を報告します。

## ソフトウェア工学との関連

- 生存分析は共有ツールキットです:患者のためのカプラン・マイヤー曲線と、*サービス*のためのそれ(故障までの時間、離脱までの時間)は同じ数式です。信頼性投資による「サービス年の獲得」 = 導入前後の生存曲線間の面積 — これは、単純な平均故障間隔(MTTF)の主張よりも正直な枠組みです。
- evLYGは、エンジニアリングにとってもメトリクス設計上の警告を伴います:出力を「チームの質」の係数で重み付けする生産性メトリクスは何であれ、制約のある、あるいは苦戦しているチームの改善を体系的に過小評価します — 意図的に等価値の派生形が欲しい場合もあります。

## 落とし穴

- **中央値生存と平均値生存**:経済モデルには平均(曲線下面積)が必要ですが、試験ではしばしば中央値が見出しになります。歪んだ分布ではこれらは大きく異なります。
- 慢性疾患では**試験の追跡期間を超えた外挿**がモデル化されたLYGを支配します — 外挿モデルを明示し、[感度分析](../sensitivity-analysis/)で検証してください。
- **症例構成や時代的傾向を調整せずに、観察的な前後データから防がれた死亡を主張すること**。
