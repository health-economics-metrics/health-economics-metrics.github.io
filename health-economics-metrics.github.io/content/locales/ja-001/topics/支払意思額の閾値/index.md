# 支払意思額の閾値

支払意思額(WTP)の閾値とは、意思決定者が健康の獲得1単位あたりに支払う最大額のことです — [ICER](../増分費用効果比/)を採用/却下の決定に変える境界線です。

## なぜ重要か

閾値は、医療経済学が測定であることをやめ、政策となる場所です。あらゆる国の制度には、明示的であれ暗黙的であれ閾値があり、地域の数値を知ることで、健康価値の主張をどう値付けすべきかが正確にわかります:

| 機関 | 閾値(2024〜2025年時点の調査) |
|---|---|
| NICE(イングランド) | 1QALYあたり£20,000〜£30,000;実証的な平均意思決定閾値 ≈ £24,400(2022〜24年);重症度修正因子により実効上限は約£36k〜£51kに上昇;高度専門技術では£100k超まで |
| ICER(米国、非政府組織) | QALY/evLYGあたり$100,000〜$150,000の価格ベンチマーク;$50k〜$200kの範囲を報告 |
| カナダ(CADTH / CDA-AMC) | 作業用閾値としてQALYあたり約CAD$50,000 |
| WHO-CHOICE(歴史的、世界的) | 回避されたDALYあたり1人あたりGDPの1〜3倍(現在は大まか過ぎるとして非推奨) |
| 英国の実証的供給側(Claxtonら) | NHSの限界で実際に置き換えられるのはQALYあたり約£13,000 |

## 数式

閾値λは、あらゆる意思決定ルールに現れます:

```
ICER = ΔC/ΔE < λ なら採用する
同等に:NMB = λ×ΔE − ΔC > 0 なら採用する
```

λが*何であるか*についての2つの理論:

- **需要側**:社会が健康に対して支払う意思のある額(価値判断)。
- **供給側**:予算が現在、限界的に生み出している健康(実証的な量 — Claxtonの約£13k/QALY)。意思決定に使われるλが供給側の率を超えると、新技術の承認は、それが加える以上の健康を置き換えてしまいます。

## 計算例

あなたのデジタル治療薬は、治療を受けた患者1人あたり0.05QALYを、正味費用(価格から相殺分を引いたもの)£800でもたらします。

```
ICER = 800 / 0.05 = £16,000/QALY
```

- イングランド:£20k未満 → 資金提供可能。弁護可能な最大価格:λ = £20,000のとき、価格_最大 = 0.05 × 20,000 + 相殺分 = £1,000 + 相殺分。
- $150k/QALYでの米国の商業的な枠組みでは、価値ベースの価格ははるかに高くなります。
- 1人あたりGDPが4,000ドルの国の閾値では、同じ製品は正味で約200ドル未満でなければなりません。

同じ製品、3つの市場、3つの価格 — 閾値こそが価格設定モデル*そのもの*です。これは、λから逆算して行う価値ベースの価格設定です。

## ソフトウェア工学との関連

あらゆるエンジニアリング組織には暗黙のλがあります:節約されたエンジニア時間あたりで、ツールに資金を出すハードルです。それを明示すること — 「信頼できるエンジニア時間1時間あたり£40未満で節約できるものには資金を出す」 — によって、費用対効果ごとのQALYリーグテーブルが医療支出を順位付けするのとまったく同じように、プラットフォーム投資をリーグテーブルで比較できるようになります。供給側の教訓も転用できます:あなたの組織の真の内部λは、経営陣が時間の価値だと言うものではなく、*現在の*バックログが限界的に生み出しているものです。

## 落とし穴

- 管轄区域をまたいだ**閾値の都合の良い選び方**や、通常の製品にHST(高度専門技術)の上限を引用すること。
- **λを価格の下限として扱うこと**:閾値をクリアすることは必要条件であって十分条件ではありません — [予算影響](../予算影響分析/)は、単位あたり手頃な価格の製品であっても、それを沈めることがあります。
- **閾値が変動することを無視すること**:NICEの重症度修正因子(2022年)や定期的な見直しは実効λを変えます;主張には日付を付けてください。
- **異なる通貨のICERを変換せずに閾値と比較すること**。
- **λに基づく評価を、労働市場のVSL/VPFの伝統と混同すること**:これらは異なる理論的伝統(医療予算制約のある手法と、賃金リスクのトレードオフからの顕示選好)に由来し、必ずしも調和できるとは限りません。
- **換算せずにICERを別の通貨の閾値と比較すること**: [通貨をまたぐICER比較](../通貨をまたぐicer比較/)を参照してください。換算方法(購買力平価と市場為替レート)は、丸めの細部ではなく、方法論上重要です。
- **λに基づく評価と労働市場ベースのVSL/VPFの伝統を混同すること**: これらは異なる理論的伝統(保健予算に制約された方法論と、賃金とリスクのトレードオフから明らかになった選好)に由来し、常に調和できるとは限りません。命の評価に対する別の顕示選好アプローチについては、[統計的生命価値](../統計的生命価値/)を参照してください。
