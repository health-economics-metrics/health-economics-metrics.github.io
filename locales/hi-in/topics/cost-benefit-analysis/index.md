# लागत-लाभ विश्लेषण (CBA)

CBA लागत *और* परिणाम दोनों का मूल्यांकन पैसे में करता है। यह एकमात्र विश्लेषण प्रकार है जो "क्या यह करने लायक है?" का उत्तर दे सकता है।

## यह क्यों महत्वपूर्ण है

CBA यूके के HM Treasury **ग्रीन बुक** का मानक है सभी सार्वजनिक व्यय मूल्यांकन के लिए।

## गणित

```
NPV = Σ_t [ (लाभ_t − लागत_t) / (1 + r)^t ]
BCR = PV(लाभ) / PV(लागत)
```

## हल किया गया उदाहरण

एक ई-रेफरल प्रणाली, 5-वर्ष क्षितिज:

```
लागत:  निर्माण £1.2M, चलाना £300k/वर्ष
लाभ:   प्रशासनिक बचत £250k/वर्ष

NPV = +£2,547k     BCR = 2.0
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

**मानक आशावादी पूर्वाग्रह** के रूप में — इंजीनियर उतनी ही विश्वसनीय रूप से माइग्रेशन लागत को कम आंकते हैं जितना मंत्रालय बुनियादी ढाँचे की लागत को।

## सामान्य गलतियाँ

- लाभ बढ़ाने के लिए **गैर-मूल्यांकन योग्य का मूल्यांकन करना।**
- **NPV रैंक करता है, BCR नहीं।**
