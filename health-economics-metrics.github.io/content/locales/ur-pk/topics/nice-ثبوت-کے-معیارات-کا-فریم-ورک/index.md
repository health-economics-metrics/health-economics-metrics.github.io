# NICE ثبوت کے معیارات کا فریم ورک (ESF)

ESF NICE کا فریم ورک ہے جو یہ متعین کرتا ہے کہ **ایک ڈیجیٹل صحت کی ٹیکنالوجی کو کتنے ثبوت کی ضرورت ہے، اس کے خطرے کے تناسب سے**۔

## یہ کیوں اہم ہے

ESF ڈیجیٹل صحت کی ٹیکنالوجیز کو طبی فعل کے ذریعے درجوں میں درجہ بندی کرتا ہے۔

## ریاضی

```
درکار ثبوت سرمایہ کاری = f(درجہ)
```

## حل شدہ مثال

ایک دوا-یاد دہانی ایپ بنانے والا ایک خوراک-ایڈجسٹمنٹ کی سفارش کی خصوصیت شامل کرنے پر غور کرتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

ESF اس ریپو میں سب سے زیادہ منتقلی کے قابل حکمرانی کا نمونہ ہے۔

## عام غلطیاں

- **خواہشمندانہ سوچ کے ذریعے درجے کی غلط درجہ بندی۔**

## ذرائع

- NICE Evidence Standards Framework (ECD7).
- ESF evidence standards tables.
