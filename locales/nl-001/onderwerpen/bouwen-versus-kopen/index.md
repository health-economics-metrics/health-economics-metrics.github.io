# Bouwen versus kopen

Bouwen-versus-kopen-analyse vergelijkt de totale eigendomskosten en risico's van interne ontwikkeling met de aanschaf van commerciële software.

## Waarom het ertoe doet

Een verkeerde keuze kan miljoenen ponden en jaren aan vertragingskosten kosten.

## De wiskunde

```
Verschil in netto contante waarde = NCW(kopen) − NCW(bouwen)
```

## Uitgewerkt voorbeeld

Een patiëntenafsprakensysteem: kopen = £2 miljoen/5 jaar; bouwen = £3,2 miljoen/5 jaar (inclusief onderhoud).
