# Metrik Keterlibatan

Metrik keterlibatan mengukur seberapa banyak pengguna benar-benar menggunakan aplikasi kesehatan: kelengketan DAU/MAU, frekuensi dan durasi sesi. Dalam kesehatan digital, keterlibatan bukanlah kesombongan — ini adalah **dosis**.

## Mengapa ini penting

Obat yang tetap di botol tidak menyembuhkan siapa pun.

## Matematika

```
Kelengketan (DAU/MAU) = pengguna aktif harian / pengguna aktif bulanan × 100
```

## Contoh yang diselesaikan

Studi utama aplikasi tekanan darah menunjukkan penurunan sistolik 6 mmHg di antara pengguna yang mencatat ≥4 kali per minggu.

## Hubungan dengan rekayasa perangkat lunak

Insinyur memiliki corong keterlibatan.

## Jebakan

- **Keterlibatan sebagai hasil.**
