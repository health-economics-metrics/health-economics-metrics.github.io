# Tekoälyn sääntelyarviointi

Tekoälyn sääntelyarviointi arvioi, täyttävätkö lääketieteelliset tekoälyjärjestelmät oikeudelliset ja sääntelylliset hyväksyntävaatimukset.

## Miksi se on tärkeä

Sääntelyhyväksynnän epäonnistuminen voi täysin estää kliinisesti tehokkaiden tekoälyjärjestelmien käyttöönoton.

## Matematiikka

```
Sääntelypolun kustannus = kliinisen näytön kustannus + hakemusmaksut + markkinoille tulon jälkeisen valvonnan kustannus
```

## Ratkaistu esimerkki

Diagnostinen tukityökalu, luokiteltu luokan III SaMD:ksi (ohjelmisto lääkinnällisenä laitteena): kokonaissääntelykustannukset ≈ £800 000, 18 kuukautta hyväksyntään.

## Yhteys ohjelmistokehitykseen

Näyttö [kliinisestä tekoälyn arvioinnista](../kliininen-tekoälyn-arviointi/) on keskeinen tekijä sääntelyhakemukselle.

## Sudenkuopat

- **Kehityksen jatkaminen määrittelemättä sääntelyluokitusta varhain.**

## Lähteet
