# Analyseperspektiv

Analyseperspektivet avgjør hvis kostnader og gevinster som telles i en økonomisk evaluering: betalerens, tjenesteyterens eller samfunnets som helhet.

## Hvorfor det er viktig

Den samme intervensjonen kan se kostnadseffektiv ut fra ett perspektiv og kostnadsdrivende fra et annet, avhengig av hvem som betaler regningen.

## Matematikken

```
Nettokostnad(perspektiv) = Σ kostnader som er relevante for det perspektivet
```

## Gjennomarbeidet eksempel

En telemonitoreringstjeneste koster tjenesteyteren £200 000/år, men sparer samfunnet £500 000/år i tapt produktivitet.

## Kobling til programvareutvikling

Ligner på å velge hvem som er "kunden" ved prioritering av funksjoner — det interne teamet, sluttbrukeren eller den bredere organisasjonen.

## Fallgruver

- **Å stille bytte perspektiv midt i en analyse.**
- **Å hevde samfunnsgevinster mens man budsjetterer fra betalerens perspektiv.**
