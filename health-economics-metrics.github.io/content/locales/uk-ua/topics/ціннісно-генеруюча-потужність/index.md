# Ціннісно-генеруюча потужність (операційне відновлення)

Ціннісно-генеруюча потужність вимірює, скільки додаткової клінічної потужності створюється завдяки операційним покращенням, без найму додаткового персоналу.

## Чому це важливо

"Карбування" нової потужності через ефективність часто швидше та дешевше, ніж найм, особливо в спеціальностях з дефіцитом персоналу.

## Математика

```
Створена потужність = (початкова пропускна здатність × % виграшу ефективності) − витрати на впровадження, перетворені в еквівалентну пропускну здатність
```

## Розібраний приклад

Операційне відновлення у відділенні рентгенології збільшує потужність сканування на 30% завдяки оптимізації планування, еквівалентно найму 3 додаткових радіологів без витрат на найм.

## Зв'язок з інженерією програмного забезпечення

Подібно до збільшення частоти розгортання завдяки оптимізації конвеєра, а не найму більше інженерів для доставки того самого обсягу.

## Підводні камені

- **Недооцінка витрат на впровадження операційної зміни.**
- **Заяви про виграші, які насправді походять від тимчасових надзвичайних зусиль, а не сталої зміни.**
