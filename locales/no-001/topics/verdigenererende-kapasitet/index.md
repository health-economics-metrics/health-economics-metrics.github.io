# Verdigenererende kapasitet (operasjonell snuoperasjon)

Verdigenererende kapasitet måler hvor mye ekstra klinisk kapasitet som skapes gjennom operasjonelle forbedringer, uten å ansette mer personell.

## Hvorfor det er viktig

Å "myntprege" ny kapasitet gjennom effektivitet er ofte raskere og billigere enn rekruttering, spesielt innen bemanningsmangel-spesialiteter.

## Matematikken

```
Skapt kapasitet = (opprinnelig gjennomstrømning × effektivitetsgevinst %) − implementeringskostnader omregnet til tilsvarende gjennomstrømning
```

## Gjennomarbeidet eksempel

En operasjonell snuoperasjon ved en røntgenavdeling øker skannekapasiteten med 30 % gjennom planleggingsoptimalisering, tilsvarende å ansette 3 ekstra radiologer uten rekrutteringskostnadene.

## Kobling til programvareutvikling

Ligner på å øke utrullingsfrekvensen gjennom pipelineoptimalisering i stedet for å ansette flere ingeniører for å levere samme volum.

## Fallgruver

- **Å undervurdere implementeringskostnadene ved den operasjonelle endringen.**
- **Å hevde gevinster som egentlig skyldes midlertidig ekstraordinær innsats i stedet for varig endring.**
