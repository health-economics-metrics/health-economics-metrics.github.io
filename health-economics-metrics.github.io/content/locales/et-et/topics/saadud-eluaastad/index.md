# Saadud eluaastad

Saadud eluaastad mõõdavad puhast elulemuse kasu ilma elukvaliteedi korrigeerimiseta — lisaaastate arvu, mida inimene sekkumise tõttu elab.

## Miks see on oluline

Mõned otsustajad eelistavad elulemuse kasu QALY-le, kuna see on vähem tundlik vaieldavate kasulikkuse kaalude suhtes.

## Matemaatika

```
Saadud eluaastad = eeldatav eluiga(sekkumisega) − eeldatav eluiga(sekkumiseta)
```

evLYG variant (saadud eluaastate võrdne väärtus) rakendab fikseeritud kasulikkust 1,0 kõigile saadud aastatele.

## Lahendatud näide

Vähiravi pikendab mediaan elulemust 2-lt 3,5 aastale: 1,5 saadud eluaastat, olenemata nende aastate kvaliteedist.

## Seos tarkvaraarendusega

Sarnaneb "saadud tööaja" mõõtmisega, arvestamata teenuse kvaliteeti selle tööaja jooksul.

## Lõksud

- **Saadud eluaastate kasutamine, kui elukvaliteet on peamine tulemus.**
- **evLYG ja standardse QALY arvutuste segiajamine.**
