# अर्जित जीवन-वर्ष (LYG)

अर्जित जीवन-वर्ष एक हस्तक्ष के लिए जिम्मेदार अतिरिक्त उत्तरजीविता है, बिना किसी गुणवत्ता समायोजन के। समान-मूल्य अर्जित जीवन-वर्ष (evLYG) एक आधुनिक संस्करण है जो सभी जीवन विस्तार को समान श्रेय देता है।

## यह क्यों महत्वपूर्ण है

LYG सबसे कच्चा स्वास्थ्य परिणाम है: लोग कितनी देर जीते हैं? **evLYG** (US ICER संस्थान द्वारा प्रयुक्त) एक नैतिक कारण से मौजूद है: QALY रोगी की उपयोगिता से विस्तारित जीवन के एक वर्ष का मूल्यांकन करता है, इसलिए एक विकलांग व्यक्ति के जीवन का विस्तार "कम गिना जाता है"।

## गणित

```
LYG = औसत उत्तरजीविता_नया − औसत उत्तरजीविता_तुलनाकर्ता
```

## हल किया गया उदाहरण

एक अस्पताल में सेप्सिस प्रारंभिक-चेतावनी एल्गोरिदम सालाना 12 मौतों को रोकता है।

```
LYG   = 12 × 8 = सालाना 96 जीवन-वर्ष
QALY  = 96 × 0.7 = 67.2
evLYG = 96 × 0.851 = 81.7
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

उत्तरजीविता विश्लेषण एक साझा टूलकिट है: रोगियों के लिए कापलान-मेयर वक्र और *सेवाओं* के लिए वही गणित।

## सामान्य गलतियाँ

- **माध्यिका बनाम औसत उत्तरजीविता।**
- **परीक्षण अनुवर्ती से परे बहिर्वेशन।**

## स्रोत

- ICER, "Cost-Effectiveness, the QALY, and the evLYG."
