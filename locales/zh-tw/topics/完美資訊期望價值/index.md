# 完美資訊期望價值（EVPI）

EVPI是指決策者在做出決策之前，為消除不確定性而應當願意支付的最高金額——這是"我們先做個研究再說"這句話的正式定價。

## 為何重要

醫療系統始終面臨這樣的選擇：基於不完美的證據現在就採納，還是先資助更多研究。EVPI為第二種選擇給出了一個具體數位。如果EVPI是£50,000，而擬議中的試驗成本為£200萬，那就應該現在採納。如果EVPI是£2,000萬，那麼這場試驗就是筆劃算的交易。同樣的問題——"我們應不應該先試點一下再全面推廣？"——出現在每一次企業級工具決策中，卻幾乎從來沒有人為它定過價。 關於為日後擴張專案的期權（而不是先收集資訊的期權）定價，見[實物期權估值](../實物期權估值/)。

## 計算方法

EVPI是"擁有完美預見能力時的決策"與"基於當前預期立即決策"二者之間的差距：

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = 不確定引數（及其聯合分佈）
NMB(j,θ) = 在給定θ的情況下，方案j的淨貨幣效益
```

第一項：在每一種可能的世界狀態下，取"最佳選擇"所帶來收益的平均值（你總是選對）。第二項：那個"平均而言最優"的單一方案所帶來的收益（你必須現在就做出承諾）。EVPI恆 ≥ 0。人群層面的EVPI，需乘以受影響的決策數量。可直接從[機率敏感性分析（PSA）](../機率敏感性分析/)的抽樣結果中計算得出。

## 實例演算

是否將一款AI文書助手推廣給5,000名臨床醫師。存在兩種可能的世界：

```
世界A（p = 0.6）：助手每天節省20分鐘 → 推廣的淨貨幣效益 = +£800萬
世界B（p = 0.4）：助手幾乎不節省時間（工作流程摩擦） → 推廣的淨貨幣效益 = −£300萬
"不推廣"的淨貨幣效益，在兩種世界中均為£0。
```

現在就做決策：E[推廣的淨貨幣效益] = 0.6 × 800萬 − 0.4 × 300萬 = **+£360萬** → 應予推廣。

若擁有完美資訊：在世界A中選擇推廣（+£800萬），在世界B中選擇不推廣（£0）。期望值 = 0.6 × 800萬 + 0.4 × 0 = **£480萬**。

```
EVPI = 480萬 − 360萬 = £120萬
```

一次嚴謹的、耗資£150,000、能大幅釐清你究竟身處哪個世界的3個月試點，顯然是值得投入的——而任何成本超過£120萬的試點，無論多麼周全徹底，都不值得。

## 與軟體工程的聯絡

EVPI正是"尖刺（spike）"、試點、A/B測試與概念驗證背後的經濟學原理。它給出了兩條實用的規則：

- **一個試點只有在決策真的可能因此改變時，才值得投入資金。**如果無論試點結果如何你都會推廣，那麼EVPI = 0，這個試點不過是一場表演。
- **應將試點開支上限設定為EVPI。**資訊的價值，其上限就是它所支撐的那項決策本身的價值。

部分EVPI（EVPPI）將這一概念拓展到單個引數層面："單獨把'節省的時間'這個數位弄準，究竟值多少錢？"——這能告訴你，試點究竟應該測量什麼。 關於評估*某一項具體擬議研究*而不是消除全部不確定性，見 [EVSI](../樣本資訊期望價值/)。

## 陷阱

- **在沒有附帶決策規則的情況下運作試點**——無法改變選擇結果的資訊，從定義上講就是毫無價值的。
- **忽視收集資訊本身的延遲成本**：一次6個月的試點，會延遲6個月的效益（參見[延遲成本](../延遲成本/)）；試點的淨價值 = 已釐清的EVPI − 延遲成本 − 試點本身的成本。
- **把EVPI當作一次預測。**它是資訊價值的上限，而不是對某項具體研究將會產出什麼結果的估計。
