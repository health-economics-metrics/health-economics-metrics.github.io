# Społeczny zwrot z inwestycji (SROI)

SROI rozszerza ROI, uwzględniając wartości społeczne i środowiskowe, których konwencjonalne rynki nie wyceniają, takie jak dobrostan i spójność społeczna.

## Dlaczego to ważne

Wiele interwencji zdrowotnych generuje wartość wykraczającą poza bezpośrednie oszczędności finansowe — SROI próbuje uwidocznić ten szerszy wpływ.

## Matematyka

```
Współczynnik SROI = Wartość bieżąca korzyści społecznych / Wartość bieżąca inwestycji
```

## Rozwiązany przykład

Program zdrowia społeczności kosztujący £1 milion generuje szacowaną wartość społeczną £4 miliony (zmniejszona samotność, poprawiona zatrudnienie, mniej przestępczości): współczynnik SROI 4:1.

## Powiązanie z inżynierią oprogramowania

Przypomina twierdzenia o szerszych korzyściach organizacyjnych (morale pracowników, reputacja marki) z inwestycji technicznej, co jest trudniejsze do skwantyfikowania niż bezpośrednie oszczędności kosztowe.

## Pułapki

- **Używanie wycen zastępczych bez ich poparcia lub walidacji.**
- **Podwójne liczenie korzyści, które się nakładają.**
