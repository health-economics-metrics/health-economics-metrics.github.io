# การหาอรรถประโยชน์ด้วยวิธีแลกเปลี่ยนเวลา (TTO)

TTO คือวิธีมาตรฐานในการได้มาซึ่งค่าอรรถประโยชน์ของสถานะสุขภาพจากผู้ตอบโดยตรง แทนที่จะคิดขึ้นเอง เป็นหนึ่งในวิธีการหา — ร่วมกับ standard gamble และการทดลองเลือกแบบไม่ต่อเนื่อง — ที่สร้างชุดค่า (value set) เบื้องหลังเครื่องมืออย่าง[EQ-5D](../eq-5d/) และจึงอยู่เบื้องหลังการคำนวณ[QALY](../ปีสุขภาวะที่ปรับคุณภาพแล้ว/) ส่วนใหญ่ในขั้นต่อมา

## ทำไมจึงสำคัญ

ค่าน้ำหนักอรรถประโยชน์ทุกค่าที่เข้าสู่การคำนวณ QALY ต้องมาจากที่ใดที่หนึ่ง TTO คือ "อย่างไร": สำหรับสถานะที่ถือว่าดีกว่าการตาย ผู้ตอบถูกถามว่าต้องมีกี่ปี `X` ในสุขภาพสมบูรณ์จึงจะเทียบเท่ากับ `T` ปีในสถานะที่บกพร่อง (`X < T`) อรรถประโยชน์คือ `X / T` สำหรับสถานะที่ผู้ตอบบางคนถือว่าแย่กว่าการตาย สูตรมาตรฐานใช้ไม่ได้ (แสดงอรรถประโยชน์ต่ำกว่าศูนย์ไม่ได้อย่างสะอาด) จึงใช้ TTO ขยาย วิศวกรซอฟต์แวร์หรือนักวิเคราะห์ที่ถือน้ำหนักอรรถประโยชน์เป็นข้อมูลเข้าที่ให้มา โดยไม่รู้ว่าต้องใช้โพรโทคอลการหาที่ผ่านการตรวจสอบจึงได้มา อยู่ห่างเพียงก้าวเดียวจากตัวเลขที่ปกป้องไม่ได้เมื่อถูกท้าทาย

## คณิตศาสตร์

```
TTO มาตรฐาน (สถานะดีกว่าการตาย):
  อรรถประโยชน์ = เวลาในสุขภาพสมบูรณ์ / เวลาในสถานะบกพร่อง

TTO ขยาย (สถานะแย่กว่าการตาย):
  อรรถประโยชน์ = -เวลาที่แลกกับการตาย / (ระยะเวลารวม - เวลาที่แลกกับการตาย)
```

`เวลาในสุขภาพสมบูรณ์` / `เวลาในสถานะบกพร่อง` — `X` ปีในสุขภาพสมบูรณ์ที่ถือว่าเทียบเท่า `T` ปีในสถานะบกพร่อง `เวลาที่แลกกับการตาย` / `ระยะเวลารวม` — ในการตั้งคำถามแบบแย่กว่าการตาย จากชีวิตที่เหลือ `T` ปี จำนวนปี `a` ที่ผู้ตอบยอมแลกกับการตายทันที โดยเลือก `T − a` ปีในสุขภาพสมบูรณ์ตามด้วยการตาย แทน `T` ปีในสถานะที่แย่กว่าการตาย ผลลัพธ์เป็นลบ ยึดให้การตาย = 0

## ตัวอย่างที่คำนวณแล้ว

**มาตรฐาน**: ผู้ตอบอยู่ในสถานะบกพร่อง 10 ปี และไม่แตกต่างจาก 7 ปีในสุขภาพสมบูรณ์: อรรถประโยชน์ = 7 / 10 = **0.7**

**แย่กว่าการตาย**: จากชีวิตที่เหลือ 10 ปี ผู้ตอบยอมแลก 2 ปีกับการตายทันที — เลือก 8 ปีในสุขภาพสมบูรณ์ตามด้วยการตายแทน 10 ปีในสถานะที่แย่กว่าการตาย: อรรถประโยชน์ = −2 / (10 − 2) = −2 / 8 = **−0.25**

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ประเด็นเดียวกับที่แบบสำรวจ DevEx หรือความผูกพันพบเมื่อขอให้คนให้คะแนนสิ่งหนึ่งบนมาตราส่วน 0–10 ที่ไม่ผ่านการตรวจสอบ ใช้ในทางกลับกันที่นี่: TTO มีอยู่ก็เพราะ "แค่ขอให้คนให้คะแนน" ไม่ใช่วิธีการหาที่ผ่านการตรวจสอบโดยตัวมันเอง ก่อนสร้างดัชนีรวม — คะแนน DevEx ดัชนีความผูกพัน มาตราส่วนความเหนื่อยหมดไฟ — บนตัวเลขที่รายงานด้วยตนเอง ให้ถามว่าตัวเลขนั้นถูกหามาด้วยอะไรและวิธีนั้นผ่านการตรวจสอบแล้วหรือไม่ คำถามเดียวกับที่นักเศรษฐศาสตร์สุขภาพถามเกี่ยวกับน้ำหนักอรรถประโยชน์ก่อนที่มันจะเข้าสู่ QALY

## ข้อผิดพลาดที่พบบ่อย

- **สรุปจากค่าเดี่ยวไปทั่วไป**: ค่า TTO ได้จาก *ตัวอย่าง* ของประชาชนทั่วไป (หรือผู้ป่วย) ไม่ใช่จากบุคคลที่กำลังตัดสินใจเรื่องการดูแล — การใช้ค่า TTO ของผู้ตอบรายเดียวราวกับว่าสรุปไปทั่วไปได้คือความผิดพลาดด้านตัวอย่าง
- **ตั้งคำถามสถานะผิดรูปแบบ**: สูตร TTO มาตรฐานสมมุติว่าสถานะดีกว่าการตายอย่างไม่กำกวม การใช้กับสถานะที่ผู้ตอบบางคนถือว่าแย่กว่าการตายโดยไม่เปลี่ยนไปใช้รูปแบบขยาย ให้อรรถประโยชน์ที่ผิด (เป็นบวก) อย่างเงียบๆ
- **ระยะเวลาที่เทียบกันไม่ได้**: ค่า TTO ที่ได้จากชีวิตที่เหลือ `T` ต่างกันสำหรับการเปรียบเทียบแบบแย่กว่าการตาย เทียบกันตรงๆ ไม่ได้หากไม่ตรวจสอบว่าแบบการศึกษาตรึง `T` ไว้คงที่
