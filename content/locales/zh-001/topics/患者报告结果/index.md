# 患者报告结果（PROM、PREM、MCID）

PROM是一类标准化量表工具，由患者自行报告自身的健康状况（症状、功能、生活质量）；PREM则记录的是照护*体验*本身。**MCID**——最小临床重要差异——是患者能够真正感知为有益的最小分数变化：任何声称的改善都必须跨过这一门槛。

## 为何重要

PROM是数字健康领域最主要的疗效货币：应用很少能撼动死亡率，但它们能可信地改变经过验证的症状评分。真正重要、且已标准化的量表工具并不多——**PHQ-9**（抑郁症，0–27分；严重程度分界为5/10/15/20）、**GAD-7**（焦虑症，0–21分；分界为5/10/15）、**EQ-5D**（用于[QALY](../质量调整生命年/)计算的效用值）——监管机构、卫生技术评估机构与支付方之所以接受这些量表，正是因为它们能够跨产品、跨试验进行比较。MCID正是一道诚实度关卡：PHQ-9的MCID约为5分，GAD-7约为4分，EQ-5D指数通常约为0.03–0.08——在一个大样本中，一个具有统计显著性的1.5分PHQ-9变化，*确实真实存在，但在临床上毫无意义*，任何一位证据评审人都会这样指出。

## 计算方法

```
PROM计分：按各量表工具自身规则求和（例如PHQ-9 = Σ 9个条目 × 0–3分）

MCID估算方法：
  锚定法：      在自我报告"有所好转"的患者中观察分数变化
  分布法：      ≈ 基线分数标准差(SD) × 0.5（粗略经验法则）

响应率框架（用于试验与申报材料）：
  响应者 = 改善幅度 ≥ MCID 的患者（或按PHQ-9惯例取≥50%改善）
  NNT = 1 / (治疗组响应率 − 对照组响应率)
  ——参见number-needed-to-treat.md
```

## 实例演算

某抑郁症支持应用，随机对照试验对比等候名单组，为期12周：

```
PHQ-9变化：应用组−6.2分，对照组−2.1分 → 调整后差异−4.1分
MCID检验：4.1 < 5 → 均值差异低于MCID；改为报告响应者比例：
  响应者（分数下降≥5分）：应用组48%，对照组22% → 绝对风险降幅26%
  NNT = 1/0.26 ≈ 4——每4名用户接受治疗，即可多获得1例临床响应

经济学桥梁：响应者的EQ-5D获益为0.06，持续6个月
  = 0.03 QALY；每1,000名用户：260名额外响应者 × 0.03 = 7.8 QALY
  按NICE阈值折算约为£156,000–£234,000的健康价值
```

在均值差异低于MCID、本会被直接否决的情况下，改用"响应者/NNT"这一框架，反而能够经受住评审的检验。

## 与软件工程的联系

PROM本质上是一个数据采集问题，而软件恰好处于独一无二的有利位置来解决它：嵌入应用内的量表工具，能实现纸质问卷从未达到过的完成率与纵向数据密度，从而将日常产品遥测数据转化为达到卫生技术评估标准的证据（[EQ-5D](../EQ-5D/)只需要五个界面）。工程层面的规则：应*原样*使用经过验证的量表工具（改写措辞会使其失效——且涉及授权许可问题）；应按协议规定的时间点进行测量，而非按参与便利性来安排（只测量活跃用户会造成存活者偏倚——参见[留存](../留存与流失/)）；并应像对待任何数据模式一样对量表数据进行版本锁定——研究进行中途更改措辞，等同于数据损坏。PREM对应的是CSAT/NPS一类的量表工具，同样的教训在此适用：只要受众是支付方，标准化工具就总是胜过自制工具。 关于专门针对工作效率的工具，见 [WPAI](../工作效率与活动受损量表/)。

## 陷阱

- **将低于MCID的统计显著性，呈现为临床获益**——这是该领域中最常见的虚增手法。
- **均值回归**：用户往往在症状最严重时入组；单臂前后对比会严重高估效果——对照组是不可或缺的。
- **量表购物**：同时使用PHQ-9、GAD-7和WHO-5三个量表，然后只报告变化最明显的那一个——应事先登记好主要指标。
- **数字化知情同意调查中的诱导压力**：引导用户给出更有利的回答会破坏量表工具本身的有效性（而评审人对这类基础比率心知肚明）。
