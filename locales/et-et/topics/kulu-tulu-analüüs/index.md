# Kulu-tulu analüüs (CBA)

Kulu-tulu analüüs teisendab nii kulud kui ka kasud rahaliseks väärtuseks, võimaldades otse arvutada netonüüdisväärtust.

## Miks see on oluline

CBA võimaldab võrdlusi valdkondade vahel (tervis versus haridus versus infrastruktuur), kuna kõik väljendatakse samas ühikus: rahas.

## Matemaatika

```
NPV = Σ(t=0 kuni horisondini) (Kasud_t − Kulud_t) / (1+r)^t
```

## Lahendatud näide

Valitsuse ennetusprogramm nüüdisväärtuse kuludega £10 miljonit ja nüüdisväärtuse kasudega (väldatud tervishoiukulud pluss tootlikkuse kasu) £15 miljonit: NPV = +£5 miljonit.

## Seos tarkvaraarendusega

Sarnaneb platvormiinvesteeringu õigustamisega, teisendades kõik eelised (kiirus, usaldusväärsus, vähenenud intsidendid) hinnangulisse rahalisse väärtusesse.

## Lõksud

- **Terviseväärtuse rahaks teisendamine vastuoluliste eeldustega ilma neid täpsustamata.**
- **Mitteturuliste kasude (nagu heaolu) eiramine, mida on raske hinnastada.**
