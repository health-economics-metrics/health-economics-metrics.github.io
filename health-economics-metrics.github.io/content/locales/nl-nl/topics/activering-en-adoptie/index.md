# Activering en adoptie

Activering meet wanneer nieuwe gebruikers voor het eerst de kernwaarde van een app ervaren; adoptie meet welk deel van de doelpopulatie daadwerkelijk begint met het gebruik van de dienst.

## Waarom het ertoe doet

Lage adoptie maakt zelfs uitstekend ontworpen interventies betekenisloos op populatieniveau.

## De wiskunde

```
Adoptiepercentage = aantal actieve gebruikers / doelpopulatie × 100%
```

## Uitgewerkt voorbeeld

Programma voor bloeddrukmonitoring op afstand: doelpopulatie 10.000, actieve gebruikers 2.400 = 24% adoptiepercentage.
