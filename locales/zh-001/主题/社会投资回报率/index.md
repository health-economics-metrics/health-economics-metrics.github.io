# 社会投资回报率（SROI）

SROI将[ROI](../投资回报率/)的概念延伸至市场无法定价的结果——幸福感、社会联结、环境影响——通过为所有受影响的利益相关方，以财务代理指标为这些结果货币化。

## 为何重要

健康与社区干预所产生的许多结果，从未真正触及任何一条预算科目：孤独感的减轻、照护者的喘息、就业机会的增加、尊严感。SROI遵循"社会价值国际组织"的七项原则（让利益相关方参与、为真正重要的事物定价、不过度主张、保持透明、可验证……），能产出诸如"每投入£1，可产生£3.20社会价值"这样的表述。英国公共采购中的社会价值要求，使SROI式的证据具有商业相关性：竞标公共合同（包括NHS合同）时，能证明社会价值的投标方可获得加分。

## 计算方法

```
SROI比率 = 已货币化社会结果的现值 / 投资的现值

对每一项结果：
  价值 = 数量 × 财务代理指标 × 归因比例 × (1 − 无谓效应) × (1 − 替代效应)

无谓效应   = 即便没有该项目，这件事本来也会发生
归因比例   = 由其他因素/机构造成的部分应被排除
替代效应   = 效益只是从别处转移而来，而非真正被创造出来的
衰减率     = 该结果随年份推移而衰减的程度
```

这些调整因子正是这套方法公信力的核心所在：没有它们，SROI不过是印着货币符号的虚构故事。

## 实例演算

某陪伴应用，将孤立的老年人与志愿者连接起来；项目年成本£200,000；1,500对活跃配对。

```
结果：为1,500人减轻孤独感
  代理指标：孤独感缓解的幸福感估值 ≈ 每人每年£1,800
  无谓效应25%（部分人本来也会自行找到社交连接）
  归因比例80%（部分功劳应归于其他服务）

价值 = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

结果：全科医生就诊次数减少，1,500 × 1.2次就诊 × £42 = £75,600（这部分对支付方而言是真实的）

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

请注意，这一比率中96%是按代理指标估值的幸福感，只有4%是真实硬现金。这是合乎规范的SROI——但它必须以"社会价值"的名义呈现，绝不能暗示£170万可以直接兑现入账。

## 与软件工程的联系

对于那些受益方并非付费团队本身的工程工作而言，SROI是一套诚实的框架：开源维护、无障碍改进、被其他团队消费使用的平台工作、开发者社区投资。可迁移的具体机制是：识别所有利益相关方、用明确声明的代理指标进行货币化，并应用无谓效应/归因折扣（那个开源修复本来是否也会发生？这项收益中有多少是你的工作贡献，有多少来自整个生态系统？）。*对自身影响力主张进行折扣*这一纪律，正是SROI区别于一个纯营销数字的关键所在。

## 陷阱

- **代理指标购物**：挑选现有最慷慨的幸福感估值。
- **跳过无谓效应/归因调整**——这是最常见的虚增手法，往往能使比率翻倍。
- **跨研究比较比率**：SROI比率对方法高度敏感；只应在一致的框架内进行比较。
- **向预算持有者将社会价值呈现为可兑现的节省**。
