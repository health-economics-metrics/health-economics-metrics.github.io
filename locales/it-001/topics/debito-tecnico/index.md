# Debito Tecnico

Il debito tecnico è il costo futuro implicito di decisioni passate convenienti in una base di codice: il lavoro di rimedio dovuto (**capitale**) e la trazione continua che esercita sulla consegna (**interesse**).

## Perché è importante

Non quantificato, il debito tecnico è una lamentela; quantificato, è un business case.

## La matematica

```
Capitale SQALE = Σ violazioni (tempo di rimedio) × tariffa di costo dello sviluppatore
```

## Esempio risolto

Uno strato di integrazione di cartelle cliniche di 400 mila LOC: interesse ≈ £276.000/anno.

## Collegamento con l'ingegneria del software

Importazioni dall'economia sanitaria che migliorano gli argomenti sul debito tecnico.
