# Dominanza e Frontiera di Efficienza

Un'opzione è **dominata** se un'altra opzione costa meno *e* offre di più. La **frontiera di efficienza** è ciò che rimane dopo aver eliminato le opzioni dominate.

## Perché è importante

Prima di qualsiasi dibattito su soglie o budget, la valutazione delle tecnologie sanitarie elimina prima le opzioni che nessuno dovrebbe mai scegliere.

## La matematica

```
Dominanza stretta: A domina B se Costo_A ≤ Costo_B e Effetto_A ≥ Effetto_B
```

## Esempio risolto

Quattro opzioni per ridurre gli appuntamenti mancati. Le chiamate telefoniche sono strettamente dominate da SMS + triage IA.
