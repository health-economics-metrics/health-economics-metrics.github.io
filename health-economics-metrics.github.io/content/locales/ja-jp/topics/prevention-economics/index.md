# 予防の経済学

疾病が発生あるいは進行する前に介入することの経済学です。代表的な発見は直感に反します:**ほとんどの予防はお金を節約しません** — それは良い価格で健康を買います。Cohen、Neumann、Weinsteinの画期的なNEJM分析は、予防介入の20%未満しか正味の費用節約にならないことを発見しました;残りは良くて費用効果的です。

## なぜ重要か

「予防はお金を節約する」は、医療政策において最も繰り返される誤った主張であり、それに基づいて構築されたビジネスケースは医療経済学者によって解体されます。正直な構造:予防は今お金がかかり(集団全体をスクリーニングし、決して病気にならなかったであろう人々のリスク要因を治療する)、後で健康を返します — 通常はQALYあたり*良い*費用で、時には節約になり、時にはひどい価格になります。自分がどちらの体制にいるかを知ることが分析です。この区別は商業的に重要です:「NHSのお金を節約する」として売られる予防製品は、失敗する監査を招きます;「£4,000でQALYを買う」として売られれば、同じ事実で勝てます。経路内のバージョンについては[早期介入](../earlier-intervention/)を参照してください。

## 数式

```
予防の正味費用(1人あたり) =
    介入費用 × 治療を受けた全員
  − 回避された下流の費用 × 進行していたであろう少数
  (両方とも割引される — 回避された費用は何年も先である;
   割引と時間選好を参照)

費用節約になるには:介入費用 < P(進行) × 回避された費用 × 割引係数
費用効果的であるには:正味費用 / 獲得QALY < 閾値 だけで十分
```

予防のパラドックス:介入費用は集団全体にわたって積み重なりますが、便益は反実仮想の少数にしか生じません。

## 計算例

10万人のリスクのある成人に提供される高血圧管理アプリ、1人あたり年間£25。10年間で400件の脳卒中を防ぎます(それぞれ割引後£45,000の費用と3QALYの損失)。

```
費用:    100,000 × £25 × 10年(割引後 ≈ ×8.3) ≈ £2,080万
相殺:    400 × £45,000 = £1,800万
正味費用 ≈ £280万 — 費用節約には*ならない*

獲得QALY = 400 × 3 = 1,200
QALYあたり費用 = 2.8M / 1,200 ≈ £2,300/QALY — 卓越して費用効果的
```

同じプログラムで、両方とも真実です:現金では£280万の損失であり、NICEの閾値の10分の1で健康を買います。2つ目の数字で資金を得てください;決して1つ目を約束しないでください。

## ソフトウェア工学との関連

シフトレフトの品質は、注意点を含めて予防の経済学です。レビュー、テスト、静的解析は、本番インシデントに進行していたであろう少数を捕まえるために、*すべての*変更に費用を課します。欠陥費用曲線(段階ごとに10〜100倍)は脳卒中の費用の役割を演じます — そして正直な結論は医療を反映しています:シフトレフトは通常、自動的に費用*節約的*になるのではなく、費用*効果的*であるにすぎません。なぜなら、フラグが立てられた問題のほとんどは決してインシデントにならなかったであろうからです(反実仮想の少数の問題)。それを計算してください:期間あたりの総ゲート費用対、実際に回避されたインシデント×インシデント費用 — 同じ計算例の構造で、[NNT](../number-needed-to-treat/)を捕捉あたりの単位として使います。

## 落とし穴

- **証拠が費用効果性を支持するときに費用節約を主張すること** — これは両分野における予防提唱の決定的な過ちです。
- **割引されていない将来の相殺**:15年先の便益を額面通りに扱うこと。
- **過剰診断/過剰治療の費用を無視すること**:予防は偽の疾病も見つけます — [スクリーニングの経済学](../screening-economics/)を参照してください。
