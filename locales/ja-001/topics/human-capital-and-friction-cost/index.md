# 人的資本アプローチと摩擦費用法

これらは、疾病費用研究や費用便益研究において、疾病、障害、死亡による生産性の損失を評価する、競合する2つの方法です。人的資本アプローチ(HCA)は、欠勤の全期間にわたる失われた生産のすべてを賃金率で評価します。摩擦費用法(FCM)は、雇用主が生産を回復するのに実際に必要な、より短い期間についてのみ評価します。どちらを選ぶかで、間接費用の推定値が2倍以上変わります。

## なぜ重要か

間接(生産性)費用は、2つの標準的な方法が大きく食い違うがゆえに、ヘルスエコノミクスで最も議論の多い項目の一つです。HCAは、欠勤の1日1日を経済が実際に失う生産の1日として扱い、全期間にわたって全額の賃金で評価します。死亡や永続的な障害の場合は、残りの就労期間にわたって評価します。FCMは、失業や労働市場の余剰がある経済では、雇用主が代替要員を訓練したり仕事を再配分したりすれば、長期の欠勤の大部分は実際には国の生産を減らさないと主張します。実際の損失を表すのは「摩擦期間」、つまり生産を以前の水準に回復するまでの時間だけです。したがってFCMは、HCAより一貫して低く保守的な間接費用の推定値を生み、2つの方法は入れ替え可能な脚注ではなく、「生産性の損失」が何を意味するかについての異なる経済理論です。これは、[NICEのリファレンスケース](../health-technology-assessment/)が生産性費用を既定で除外し、報告する場合でもリファレンスケースのICERに混ぜず、社会的視点の別の感度分析として報告する理由でもあります。[分析の視点](../analysis-perspective/)を参照してください。

## 数式

```
人的資本アプローチ:
HCA費用 = 日額賃金 × 失われた日数

摩擦費用法(簡略化した、摩擦期間で上限を設ける形):
FCM費用 = 日額賃金 × min(失われた日数, 摩擦期間日数)

摩擦期間日数 = 生産回復までの時間についての国・部門ごとの推定値
               (歴史的にはオランダのiMTA費用算定ガイダンスで約85日。
               国によって異なり、定期的に再推定される)
```

2つの方法の不一致のすべては`min()`にあります。HCAは`失われた日数`に上限を設けないため、費用は欠勤の全期間にわたって増え続けます。一方FCMは、実際の欠勤がどれほど長く続いても、数える日数を摩擦期間に制限します。

## 計算例

ある従業員が`失われた日数 = 180`日欠勤し、`日額賃金 = £150`です。

**人的資本アプローチ**:

```
HCA費用 = 150 × 180 = £27,000
```

**摩擦費用法**(`摩擦期間日数 = 85`を使用。ガイダンスの定期的な再推定時点での、歴史的なオランダiMTAの基準値):

```
FCM費用 = 150 × min(180, 85) = 150 × 85 = £12,750
```

*同じ*欠勤について、FCMの£12,750はHCAの£27,000の半分未満です。ほかの仮定に一切触れる前に、方法の選択だけで疾病費用のケースが大きく変わります。

## ソフトウェア工学との関連

これは、チームがエンジニアの退職をどう評価するかにそのまま対応します。

- **HCA型の離職コスト算定**: 退職したエンジニアの給与全額を、その役職が空席である期間にわたって損失として評価するもの。これはほとんどの離職コストモデルの素朴な版で、HCAが生産性の損失を過大評価するのと同じ理由で損失を過大評価します。空席の分の稼働力がずっと完全に生産的で、ほかの誰もその余裕を吸収しなかったと仮定してしまうためです。この方法が入力となる、採用/オンボーディング/空席のカバーの連鎖を定量化した[人材の定着](../workforce-retention/)を参照してください。
- **FCM型の離職コスト算定**: 後任を補充して立ち上げるまでの実際の時間、つまりエンジニアリングにおける「摩擦期間」についてのみ損失を評価するもの。FCMが疾病費用研究でより保守的な選択であるのと同様に、ビジネスケースにはこちらのほうが説得力のある数値です。
- 根底にある規律は[機会費用](../opportunity-cost/)と同じです。置き換えられた資源は、見出しの期間に率を掛けたものではなく、実際に失われるものによって評価します。

## 落とし穴

- **1つの分析内でHCAとFCMを混ぜる、または選択を開示せずに片方だけ報告すること。** 同じ欠勤データでも、方法によって報告される費用が2倍以上違うことがあります。選択は埋もれさせず、明示する必要があります。
- **社会的視点のケースでHCAを感度分析と明示せずに使うこと。** NICEのリファレンスケースは生産性費用を明示的に除外しています。社会的視点のHCA推定値はシナリオ分析に属し、見出しのICERには入りません。
- **どちらの方法も、無給または非市場的な労働(介護など)に調整なしで適用すること。** どちらの方法も価値の代理として賃金率を仮定しており、市場賃金のない労働にはきれいに適用できません。
