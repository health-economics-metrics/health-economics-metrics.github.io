# مشغولیت کے میٹرکس

مشغولیت کے میٹرکس یہ ماپتے ہیں کہ صارفین اصل میں ایک صحت کی ایپ کا کتنا استعمال کرتے ہیں: DAU/MAU چپکاؤ، سیشن کی تعدد اور مدت۔ ڈیجیٹل صحت میں، مشغولیت فضول نہیں ہے — یہ **خوراک** ہے۔

## یہ کیوں اہم ہے

بوتل میں رکھی دوا کسی کو ٹھیک نہیں کرتی۔

## ریاضی

```
چپکاؤ (DAU/MAU) = روزانہ فعال صارفین / ماہانہ فعال صارفین × 100
```

## حل شدہ مثال

ایک بلڈ پریشر ایپ کا بنیادی مطالعہ ہفتہ وار ≥4 بار لاگ کرنے والے صارفین میں 6 mmHg سسٹولک کمی دکھاتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرز مشغولیت کے فنل کے مالک ہیں۔
