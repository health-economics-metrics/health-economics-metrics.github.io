# Räckvidd och rättvisa

Räckvidd och rättvisa mäter hur rättvist en digital hälsointervention når hela målpopulationen, särskilt sårbara och marginaliserade grupper.

## Varför det är viktigt

Digitala interventioner riskerar att fördjupa digitala hälsoklyftor genom att oproportionerligt nå grupper som redan har bättre tillgång. För ett formellt statistiskt mått på socioekonomiskt betingad hälsoojämlikhet, se [koncentrationsindex](../koncentrationsindex/).

## Matematiken

```
Rättviseklyfta = räckviddsandel(hög inkomst) − räckviddsandel(låg inkomst)
```

## Genomarbetat exempel

En diabetesapp: räckviddsandel hög inkomst 45 %, låg inkomst 22 % = rättviseklyfta 23 procentenheter.

## Koppling till mjukvaruutveckling

Uppdelat efter befolkningsundergrupper i [aktivering och upptagning](../aktivering-och-upptagning/) avslöjar klyftan.

## Fallgropar

- **Att bara titta på genomsnittlig räckvidd och dölja klyftor mellan undergrupper.**
