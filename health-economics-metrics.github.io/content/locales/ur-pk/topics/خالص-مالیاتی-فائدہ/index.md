# خالص مالیاتی فائدہ (NMB)

NMB ایک قیمت-تاثیر کے نتیجے کو ایک ہی مالیاتی قدر میں تبدیل کرتا ہے: ادائیگی کی رضامندی کی حد پر تشخیص شدہ صحت کا فائدہ مائنس قیمت۔

## یہ کیوں اہم ہے

تناسب ([ICER](../بتدریج-قیمت-تاثیر-کا-تناسب/)) عجیب ہیں: صفر اثر کے قریب وہ پھٹ جاتے ہیں۔ NMB لکیری ہے۔

## ریاضی

```
NMB = (ΔE × λ) − ΔC
```

## حل شدہ مثال

ذیابیطس کی سروس کے تین آپشنز، λ = £20,000/QALY۔

## سافٹ ویئر انجینئرنگ سے تعلق

`(بچائے گئے گھنٹے × مکمل مختص فی گھنٹہ شرح) − ٹول کی قیمت` — روزمرہ کا ٹولنگ کاروباری کیس۔
