# 可规避的外包成本

当信托机构无法仅凭内部产能达成目标时，便会以溢价购买产能：自有员工的周末加班，或将诊疗流程外包给私营医疗机构。释放产能类软件的经济价值，包括**这部分溢价工作中可被规避的成本**。

## 为何重要

在择期手术积压恢复的压力之下，信托机构经常按私营部门现价（通常为NHS标准价格的1.2–1.5倍）付费，或向本机构顾问医生支付周末专项名单的溢价费用。与普通的产能类主张不同，规避外包属于**现金释放型**收益：付给私营机构的账单确确实实不再产生。这使其成为能提升内部吞吐量的软件所能主张的最有力效益线之一——也是最容易举证的一种，因为外包支出本身就已经是一条清晰可见的预算科目。

## 计算方法

```
可规避外包成本 = 转回内部完成的诊疗量 × (外包单价
                − 内部边际成本/例)

内部边际成本：为额外活动所需的耗材 + 可变人力成本
——固定场地设施成本无论如何都已支付（参见marginal-vs-average-cost.md）。
```

该主张成立的前提是：被释放的内部产能确实能够承接这部分活动——手术室时段、床位和人员必须同时具备（起决定作用的仍是那个约束瓶颈——又是约束理论）。

## 实例演算

某信托机构每年将800例白内障手术外包，每例£900：即每年£720,000的外部支出，而标准价格约为£750。

手术室排程软件（名单优化、利用取消空档回填、周转时间追踪）使内部手术室利用率提升，足以将其中500例转回内部完成：

```
每例内部边际成本 ≈ £350（耗材+按场次计的人力成本）
节省 = 500 × (900 − 350) = 每年£275,000——现金释放型
剩余外包量：300 × £900 = £270,000（原为£720,000）
```

软件成本每年£90,000 → 净收益约为**每年+£185,000的可入账现金**，此外还有内部保留该工作所带来的质量与培训方面的额外收益。

## 与软件工程的联系

其直接对应物是**外包承包商与咨询溢价**：当内部工程产能无法满足承诺的交付时，组织会以1.5–3倍于内部负荷成本的价格购买外部产能。能提升内部吞吐量的平台与生产力投资，应当按照与上文完全相同的方式主张"规避的承包商支出"——外部日费率减去内部边际成本，再乘以转回内部完成的工作量——因为这是开发者生产力商业论证中少数真正属于现金释放型的效益线之一。同样的告诫在此依然适用：内部产能必须确实存在，并被实际排入转回内部的工作，否则这一主张就只是虚构。

## 陷阱

- **在缺乏完整产能链条的情况下主张转回内部完成**——外科医生被释放出来了，却没有手术室时段（或工程师被释放出来了，却没有产品管理带宽）——这样的"转回"其实什么也没转回。
- **将外包价格与内部平均成本而非边际成本比较**——说来矛盾，这样反而会低估实际节省，因为固定成本无论如何都会产生。
- **质量/复杂度的不对称性**：被外包的病例往往是相对简单的那些；将其转回内部会改变内部的病例结构与单位成本。
