# Unngåtte nedstrømskostnader

Unngåtte nedstrømskostnader er kostnadskompensasjoner som følger av å forhindre senere, dyrere helsehendelser, og reglene som gjør disse påstandene troverdige.

## Hvorfor det er viktig

Påstander om nedstrømskostnader er lette å overdrive; troverdige påstander krever klare antakelser om kausalitet, tidshorisont og kontrafaktiske scenarioer.

## Matematikken

```
Unngåtte kostnader = (Grunnlinje hendelsesrate − hendelsesrate med intervensjon) × kostnad per hendelse × populasjon
```

## Gjennomarbeidet eksempel

Et program for tidlig oppdagelse av hjertesvikt reduserer innleggelser med 3 prosentpoeng i en populasjon på 5 000: 150 unngåtte innleggelser × £4 000/innleggelse = £600 000 unngåtte kostnader.

## Kobling til programvareutvikling

Ligner på å hevde "unngåtte hendelseskostnader" gjennom proaktiv overvåking — troverdig bare med en klar grunnlinje og kausal mekanisme.

## Fallgruver

- **Å hevde unngåtte kostnader uten en gyldig kontrafaktisk grunnlinje.**
- **Å forveksle regresjon mot gjennomsnittet med en reell intervensjonseffekt.**
