# Analisis Minimalisasi Biaya (CMA)

CMA hanya membandingkan biaya, dan memilih opsi termurah — ini hanya valid ketika hasil dari alternatif terbukti setara.

## Mengapa ini penting

CMA adalah analisis paling sederhana dan paling disalahgunakan.

## Matematika

```
Jika terbukti Efek_A ≈ Efek_B: pilih min(Biaya_A, Biaya_B)
```

## Contoh yang diselesaikan

Sebuah trust memilih antara dua platform konsultasi video.

## Hubungan dengan rekayasa perangkat lunak

CMA adalah bentuk formal pengadaan komoditas.
