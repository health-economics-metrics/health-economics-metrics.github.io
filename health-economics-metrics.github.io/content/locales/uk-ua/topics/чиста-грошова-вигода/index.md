# Чиста грошова вигода (NMB)

Чиста грошова вигода перетворює здобуток здоров'я в гроші за пороговою вартістю та віднімає витрати, дозволяючи ранжувати втручання за одним числом.

## Чому це важливо

На відміну від ICER, NMB є лінійною, що значно спрощує статистичний аналіз (середні значення, довірчі інтервали).

## Математика

```
NMB = (Ефекти × порогова вартість) − Витрати
```

## Розібраний приклад

Втручання дає 0,3 QALY за £4000 витрат, поріг £20 000/QALY: NMB = (0,3 × £20 000) − £4000 = £2000 (позитивне = економічно ефективне).

## Зв'язок з інженерією програмного забезпечення

Подібно до перетворення кількох вимірів впливу (швидкість, надійність, функції) в один складений показник цінності для пріоритизації.

## Підводні камені

- **Використання неправильної порогової вартості при розрахунку NMB.**
- **Порівняння NMB між дослідженнями, які використовували різні пороги.**
