# Zaoszczędzone dni łóżkowe

Zaoszczędzone dni łóżkowe mierzą, ile dni pobytu szpitalnego unika interwencja — powszechny wskaźnik wartości interwencji zdrowia cyfrowego.

## Dlaczego to ważne

Dni łóżkowe to najczęstsza "podstawowa" korzyść w uzasadnieniach biznesowych, ale często są wyceniane błędnie przy użyciu kosztu średniego zamiast krańcowego.

## Matematyka

```
Zaoszczędzone dni łóżkowe = Σ (unikniete przyjęcia × średni czas pobytu)
```

## Rozwiązany przykład

Program wczesnej wypisów unika 500 przyjęć średnio o 4 dni: 2000 zaoszczędzonych dni łóżkowych, wycenionych po koszcie krańcowym £150/dzień = £300 000.

## Powiązanie z inżynierią oprogramowania

Przypomina wycenę zaoszczędzonych instancji serwerowych po koszcie krańcowym obliczeń, a nie koszcie średnim na użytkownika wliczając stałe koszty ogólne.

## Pułapki

- **Wycenianie dni łóżkowych po koszcie średnim zamiast krańcowym — zobacz [koszt krańcowy kontra koszt średni](../koszt-krańcowy-kontra-koszt-średni/).**
- **Zakładanie, że wolne łóżko jest automatycznie ponownie wykorzystywane.**
