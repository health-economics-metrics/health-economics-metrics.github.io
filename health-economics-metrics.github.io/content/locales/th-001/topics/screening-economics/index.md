# เศรษฐศาสตร์การคัดกรอง

เศรษฐศาสตร์การคัดกรองประเมินความคุ้มทุนของโปรแกรมการคัดกรอง โดยพิจารณาต้นทุนของผลบวกลวง ผลลบลวง และการวินิจฉัยเกินจริง ควบคู่กับผลประโยชน์ของการตรวจพบแต่เนิ่นๆ

## ทำไมจึงสำคัญ

การคัดกรองดูเหมือนจะดีเสมอ ("การตรวจพบแต่เนิ่นๆ ช่วยชีวิตคน") แต่ทุกโปรแกรมมีต้นทุนที่ซ่อนอยู่จากการทดสอบผลบวกลวง ความวิตกกังวล และการวินิจฉัยเกินจริง ซึ่งต้องชั่งน้ำหนักกับผลประโยชน์

## คณิตศาสตร์

```
มูลค่าสุทธิของการคัดกรอง = (มูลค่าของกรณีที่ตรวจพบ × ความไว) − (ต้นทุนผลบวกลวง × (1 − ความจำเพาะ)) − ต้นทุนโปรแกรม
```

## ตัวอย่างที่คำนวณแล้ว

โปรแกรมคัดกรองมะเร็งเต้านมตรวจพบ 10 กรณีต่อ 10,000 การสแกน แต่สร้างผลบวกลวง 500 รายการ ซึ่งแต่ละรายการต้องการการตรวจเพิ่มเติม — การประเมินทางเศรษฐศาสตร์โดยรวมต้องพิจารณาทั้งสองด้าน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับอัตราผลบวกลวงในการทดสอบอัตโนมัติ — การทดสอบที่ไวเกินไปสร้างสัญญาณรบกวนที่ทำให้ต้องเสียเวลาในการตรวจสอบ

## ข้อผิดพลาดที่พบบ่อย

- **การเพิ่มประสิทธิภาพเฉพาะความไวโดยไม่พิจารณาความจำเพาะ**
- **การเพิกเฉยต่อต้นทุนของการวินิจฉัยเกินจริงและการรักษาเกินจริง**
