# 依从性与持续性 (Adherence and Persistence)

依从性衡量实际使用与处方规定使用之间的吻合程度（强度）；持续性衡量使用在中断前持续了多长时间（时长）。药学领域已有标准化的衡量方法——**MPR**（用药占有率）与**PDC**（覆盖天数比例），两者均以≥80%作为传统的"依从"门槛——数字疗法则继承了这两个概念及其背后的问题：依从性是疗效与实现价值之间的乘数因子。

## 为何重要

支付方早已依赖这些数字运作：PDC≥80%被纳入美国Medicare星级评定（Star Ratings）体系，直接影响支付方的实际收入——依从性是具有财务承重意义的基础设施，而非软性指标。数字疗法也重复着同样的模式：DiGA数据显示处方量强劲，但持续依从性薄弱，而2026年起将在德国推行的基于结果的DTx定价，将按依从性门槛下的结果付费。来自数字健康研究的一项概念升级是：**有效参与度**（effective engagement）——达成预期结果所需的*充分*参与度，及其推论**最低有效剂量**（minimum effective dose）——这一剂量应针对每种干预措施通过实证确立，而非想当然地认为"越多越好"。

## 计算方法

```
MPR = Σ已配发供药天数 / 期间总天数 × 100（可超过100%；
      因提前续药而高估）
PDC = 有供药覆盖的天数 / 期间总天数 × 100（上限为100%；
      属于保守估计方法，CMS倾向采用）
数字依从性 = 实际使用事件数 / 处方规定使用事件数 × 100
持续性     = 从启动到中断的天数
            （报告N个月时的持续使用百分比；采用生存分析方法）

价值门控：实现结果 ≈ 疗效 × g(依从性)
  其中g为剂量-反应函数；低于最低有效剂量时，
  g≈0——成本已发生，收益未实现
```

## 实例演算

某数字化失眠认知行为疗法（CBT）产品，处方为6周内完成6个模块；试验疗效为0.025 QALY，适用于完成≥4个模块的人群（经实证确立的最低有效剂量）：

```
1,000份处方，每份£250 → 支付方支出£250,000
模块完成情况：完成≥4个模块38%；完成1-3个模块34%；完成0个模块28%

实现的QALY = 1,000 × 0.38 × 0.025 = 9.5
每QALY成本 = 250,000 / 9.5 ≈ £26,300 —— 处于NICE阈值的边缘

依从性工程改造（重新设计提醒机制、缩短单次时长）将
完成≥4模块的比例提升至50%：QALY增至12.5 → £20,000/QALY。该产品
在未改动疗法内容本身的情况下跨过了资助门槛。
```

在2026年式的绩效定价模式下，同样的转变将直接带动*收入*变化——依从性工程由此成为商业路线图的一部分。

## 与软件工程的关联

两套术语体系正在汇聚到同一个概念上：软件分析领域的[激活](../激活与采纳/)、[黏性](../参与度指标/)、[留存](../留存与流失/)，与临床药学领域的MPR、PDC、持续性，衡量的其实都是对某项干预的暴露程度——将你的产品事件映射到临床术语体系，支付方就能读懂你的仪表盘。工程团队掌控着依从性的关键杠杆：提醒逻辑（僵化的每日推送会训练出用户的忽略反应；自适应的提醒时机则不会）、单次使用成本（一个20分钟的模块，完成率低于3个7分钟模块），以及能定位用户在治疗流程中*具体在哪一步*流失的摩擦遥测数据。从第一天起就应埋点采集剂量-反应数据——决定整个经济模型能否成立的最低有效剂量分析，需要的正是唯有产品本身才能采集到的"使用量-结果"关联数据。

## 常见陷阱

- **混淆MPR与PDC**：MPR会虚高数值；须注明所用的估计方法，面向支付方的场景应使用PDC。
- **对指标的依从而非对疗法的依从**：把打开应用当作服药剂量来计数（参见[参与度指标](../参与度指标/)）。
- **"越多越好"式的参与度目标**：而该干预措施本身存在有限剂量——完成疗程即是成功，无限期持续使用并非目标。
- **基于幸存者的疗效主张**：依从人群的结果本身就带有选择效应（依从的人本就不同于常人）；诚实的因果估计需要随机化或审慎的调整方法。
