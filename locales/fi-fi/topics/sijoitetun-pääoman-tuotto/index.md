# Sijoitetun pääoman tuotto (ROI)

ROI mittaa investoinnin nettotaloudellista voittoa prosenttiosuutena investointikustannuksesta.

## Miksi se on tärkeä

ROI on yhteinen kieli terveystaloustieteen ja yleisen liiketoiminnan välillä, mutta on merkityksellinen vain selkeästi ilmoitetuilla parametreilla (ajanjakso, vertailukohta, diskonttokorko).

## Matematiikka

```
ROI = (Nettohyöty − Kustannus) / Kustannus × 100 %
```

## Ratkaistu esimerkki

Digitaalinen triage-järjestelmä maksaa £300 000 ja tuottaa £450 000 säästöjä ensimmäisenä vuonna: ROI = (£450 000 − £300 000) / £300 000 = 50 %.

## Yhteys ohjelmistokehitykseen

Muistuttaa refaktoroinnin tuoton laskemista: vähentyneet ylläpitokustannukset jaettuna refaktorointi-investoinnilla.

## Sudenkuopat

- **Ajanjakson määrittelemättä jättäminen, mikä tekee ROI-väitteistä vertailukelvottomia.**
- **Pehmeiden hyötyjen laskeminen mukaan ilman näyttöä.**
