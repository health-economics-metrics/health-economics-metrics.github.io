# এনগেজমেন্ট মেট্রিক্স

এনগেজমেন্ট মেট্রিক্স পরিমাপ করে ব্যবহারকারীরা প্রকৃতপক্ষে একটি স্বাস্থ্য অ্যাপ কতটা ব্যবহার করে: DAU/MAU স্টিকিনেস, সেশন ফ্রিকোয়েন্সি এবং সময়কাল, বৈশিষ্ট্য ব্যবহার। ডিজিটাল স্বাস্থ্যে, এনগেজমেন্ট ভ্যানিটি নয় — এটি **ডোজ**: সেই এক্সপোজার যার মধ্য দিয়ে যেকোনো ক্লিনিক্যাল প্রভাব প্রবাহিত হতে হবে।

## কেন এটি গুরুত্বপূর্ণ

বোতলে থাকা একটি ওষুধ কাউকে সারায় না; আনইনস্টল বা কখনো না খোলা একটি অ্যাপ একই ব্যর্থতা মোড। একটি ভোক্তা স্বাস্থ্য পণ্যের প্রতিটি স্বাস্থ্য-অর্থনৈতিক দাবি এনগেজমেন্টের মধ্য দিয়ে গুণিত হয়।

## গণিত

```
স্টিকিনেস (DAU/MAU) = দৈনিক সক্রিয় ব্যবহারকারী / মাসিক সক্রিয় ব্যবহারকারী × 100

ডোজ-প্রতিক্রিয়া কাঠামো:
  উপলব্ধ প্রভাব ≈ ট্রায়াল প্রভাব × f(প্রকৃত ব্যবহার / ট্রায়াল ব্যবহার)
```

## সমাধানকৃত উদাহরণ

একটি রক্তচাপ অ্যাপের মূল গবেষণা সপ্তাহে ≥৪ বার লগ করা ব্যবহারকারীদের মধ্যে ৬ mmHg সিস্টোলিক হ্রাস দেখিয়েছে। ৫০,০০০ নিবন্ধিত ব্যবহারকারী জুড়ে স্থাপনায়:

```
MAU 20,000 (40%); তাদের মধ্যে, সপ্তাহে ≥4× লগ করা: 7,000
কার্যকর-ডোজ ব্যবহারকারী = 7,000 / 50,000 = নিবন্ধিত ভিত্তির 14%
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

প্রকৌশলীরা এনগেজমেন্ট ফানেলের মালিক, যা তাদের একটি *ক্লিনিক্যাল* চলকের মালিক করে তোলে: অনবোর্ডিং ঘর্ষণ, নোটিফিকেশন কৌশল, লোড সময় সবই বিতরণকৃত ডোজ নাড়ায়।

## ঝুঁকিপূর্ণ দিক

- **ফলাফল হিসেবে এনগেজমেন্ট**: ব্যবহার একটি মাধ্যম; ফলাফল হলো [PROM](../রোগী-প্রতিবেদিত-ফলাফল/) বা ক্লিনিক্যাল এন্ডপয়েন্ট।
- **দ্বিমাত্রিক ব্যবহারের উপর গড়**।
- **ডার্ক-প্যাটার্ন ডোজ স্ফীতি**: স্ট্রিক এবং অপরাধবোধ-নোটিফিকেশন মেট্রিক্স বাড়ায় কিন্তু ক্ষতি করতে পারে।
