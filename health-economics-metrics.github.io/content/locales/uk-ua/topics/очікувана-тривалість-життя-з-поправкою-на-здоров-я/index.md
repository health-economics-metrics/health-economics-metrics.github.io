# Очікувана тривалість життя з поправкою на здоров'я (HALE)

HALE вимірює середню кількість років, які новонароджений, як очікується, проживе у доброму здоров'ї, враховуючи поточні моделі смертності та захворюваності.

## Чому це важливо

HALE дає особам, що приймають рішення, зведення на рівні популяції, яке поєднує тривалість життя та якість здоров'я.

## Математика

```
HALE = очікувана тривалість життя − роки, прожиті в поганому здоров'ї (зважені за тяжкістю)
```

## Розібраний приклад

Країна X має очікувану тривалість життя 80 років, але HALE 70 років, що вказує на те, що в середньому 10 років проводяться зі значними обмеженнями здоров'я.

## Зв'язок з інженерією програмного забезпечення

Подібно до "ефективного часу безвідмовної роботи", який коригує грубий час безвідмовної роботи на періоди зниженої продуктивності.

- **Порівняння тенденцій між країнами з непослідовними методами вимірювання.**
