# Sotsiaalne investeeringutasuvus (SROI)

SROI laiendab ROI-d, kaasates sotsiaalseid ja keskkonnaväärtusi, mida tavapärased turud ei hinnasta, nagu heaolu ja sotsiaalne sidusus.

## Miks see on oluline

Paljud tervishoiu sekkumised loovad väärtust, mis ületab otsest rahalist säästu — SROI püüab seda laiemat mõju nähtavaks teha.

## Matemaatika

```
SROI suhe = Sotsiaalsete kasude nüüdisväärtus / Investeeringu nüüdisväärtus
```

## Lahendatud näide

Kogukonna tervishoiuprogramm, mis maksab £1 miljoni, loob hinnangulise sotsiaalse väärtuse £4 miljonit (vähenenud üksindus, parem tööhõive, vähem kuritegevust): SROI suhe 4:1.

## Seos tarkvaraarendusega

Sarnaneb laiemate organisatsiooniliste kasude (töötajate moraal, kaubamärgi maine) väitmisega tehnilisest investeeringust, mida on raskem kvantifitseerida kui otseseid kulusäästu.

## Lõksud

- **Asenduse hinnangute kasutamine ilma neid toetamata või valideerimata.**
- **Kattuvate kasude topeltarvestus.**
