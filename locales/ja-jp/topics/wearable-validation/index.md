# ウェアラブルの検証

検証メトリクスは、ウェアラブルの測定値が臨床的なゴールドスタンダード(心拍数の場合はECG、睡眠の場合はポリソムノグラフィー)とどれだけ一致するかを定量化します:**MAPE**、一致相関、Bland-Altman一致性 — に加えて、実世界のデータの質をゲーティングする運用上のメトリクス:**装着時間コンプライアンス**とデータの完全性。

## なぜ重要か

検証は、下流のあらゆるものの前提条件です:基準となる測定との一致を証明できない機器は、[デジタルエンドポイント](../digital-endpoints-and-biomarkers/)を根拠づけることも、[RPMの請求](../remote-patient-monitoring-economics/)を支えることも、臨床的な主張を持つこともできません。この分野の心拍数に対する受け入れられた閾値:ECGに対して**MAPE≤5%**(厳格)または**≤10%**(緩やか)。文献からの基準点:Oura Gen 3の安静時心拍数MAPE 1.67%(CCC 0.97);Fitbit Charge 6のMAPE約5.5% — 消費者向け機器は現在、臨床グレードの境界にまたがっており、これがまさに、この測定が機器ごと、条件ごとに重要である理由です。

## 数式

```
MAPE = (1/n) Σ |測定値_i − 基準値_i| / 基準値_i × 100

CCC(一致相関) = 相関と系統的バイアスの両方を含む一致性
      (位置/尺度のシフトによって減点されたピアソンのr)

Bland-Altman:平均バイアス±1.96標準偏差の一致限界 — 誤差が値の
      大きさに依存するかどうかを示す

運用上のゲート:
装着時間コンプライアンス = 装着時間 / プロトコル時間 × 100
データの完全性         = 観測されたデータポイント数 / 期待される数 × 100
```

検証は、**活動条件ごとに**(安静、運動、睡眠)、そして集団ごとに報告されなければなりません — PPG光学センシングは、動きのアーティファクト、接触不良、より濃い肌の色調によって劣化します。これは文書化された公平性に関連する失敗モードです。

## 計算例

あるバーチャル病棟プログラムがモニタリング用ウェアラブルを選定します。候補A:安静時MAPE 2.1%、運動時MAPE 11.4%。候補B:安静時3.8%、運動時6.9%。

```
ユースケース:自宅での状態悪化患者の検出 — アラートは持続的な心拍数上昇で
発動し、しばしば活動中に起こる。
候補Aの見出し(2.1%)がパンフレットでは勝ちますが、候補Bがユースケースでは
勝ちます:アラートに関連する条件(運動)では、Aの心拍数100での11.4%の誤差は
±11拍/分であり — アラート閾値帯全体にまたがり、誤ったエスカレーション
(それぞれ看護師の呼び出し、約£40)または見逃しを生み出します。

誤アラートの経済性:500人の患者 × 週2回の余分な誤アラート × £40
= 誤った検証数値を選んだことによる年間£208万のエラー費用。
```

## ソフトウェア工学との関連

エンジニアは、センサーを選ぶときに検証データを消費し、測定機能を構築するときにそれを*生成*します — どちらの役割も同じ規律を必要とします:デモの条件ではなく展開の条件でテストすること(ソフトウェア版の類似物:ベンダーのワークロードではなく自分たちの本番ワークロードでベンチマークすること)。装着時間と完全性はプロダクトエンジニアリングのアウトカムです — 快適さ、バッテリー寿命、充電の儀式のデザイン、同期の信頼性が、30日中16日というRPM請求のゲート([遠隔患者モニタリングの経済学](../remote-patient-monitoring-economics/)を参照)が満たされるかどうか、そして試験データセットが分析可能かどうかを決定します。欠損を設計されたシグナルとして扱ってください:「装着していない」「装着しているが信号なし」「同期失敗」をスキーマの中で最初から区別してください — nullに縮約されると、下流のあらゆる分析を汚染します。

## 落とし穴

- **条件固有の失敗を隠す集約されたMAPE** — 上記の計算例の罠です。
- **検証対象集団≠展開対象集団**:年齢、肌の色調、震え、肥満はすべて光学センサーの誤差を変えます;研究の人口統計を確認してください。
- **一致性が必要な場面で相関が報告されること**:系統的バイアスを伴う高いピアソンのrは、絶対閾値に対して依然として誤分類を生み出します — CCC/Bland-Altmanを要求してください。
- **補完によって水増しされた完全性**:埋められたギャップが観測データとして報告されること。
