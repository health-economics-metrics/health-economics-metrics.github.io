# স্বাস্থ্য প্রযুক্তি মূল্যায়ন (HTA)

HTA হলো আনুষ্ঠানিক, প্রাতিষ্ঠানিক প্রক্রিয়া যার মাধ্যমে স্বাস্থ্য ব্যবস্থা সিদ্ধান্ত নেয় একটি প্রযুক্তি — ওষুধ, ডিভাইস, বা সফটওয়্যার — অর্থ পরিশোধের যোগ্য কিনা।

## কেন এটি গুরুত্বপূর্ণ

আপনি যদি একটি জাতীয় স্বাস্থ্যসেবায় বিক্রি করেন, একটি HTA সংস্থা আক্ষরিক অর্থেই আপনার বাজার প্রবেশাধিকার নির্ধারণ করতে পারে:

- **NICE (ইংল্যান্ড)**: একটি সংজ্ঞায়িত *রেফারেন্স কেস*-এর অধীনে সংবিধিবদ্ধ মূল্যায়ন — [EQ-5D](../eq-5d/) থেকে QALY, NHS+PSS [দৃষ্টিকোণ](../বিশ্লেষণের-দৃষ্টিকোণ/), ৩.৫% [ছাড়](../ছাড়-এবং-সময়-অগ্রাধিকার/) — £২০হাজার–£৩০হাজার/QALY-এর বিরুদ্ধে বিচার করা।
- **ICER (US, বেসরকারি)**: $১০০হাজার–$১৫০হাজার প্রতি QALY/evLYG মূল্য বেঞ্চমার্কসহ প্রমাণ প্রতিবেদন।
- **কানাডা (CADTH → CDA-AMC)**: ≈CAD$৫০হাজার/QALY-তে পরিশোধ পর্যালোচনা।

## গণিত

HTA-র শক্তি একটি সূত্র নয় বরং একটি **বাধ্যতামূলক পদ্ধতি**: প্রতিটি জমা একই রেফারেন্স-কেস নিয়মের অধীনে একই [ICER](../বর্ধিত-ব্যয়-কার্যকারিতা-অনুপাত/) গণনা করে।

## সমাধানকৃত উদাহরণ

একটি ডিজিটাল থেরাপিউটিক NICE-শৈলীর মূল্যায়নে জমা দেয়:

```
মডেল: ΔC = +£450/রোগী, ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ £20হাজারের নিচে
রেফারেন্স-কেস পরীক্ষা:
  UK মান সেটসহ EQ-5D-5L থেকে উপযোগিতা                    ✓
  তুলনাকারী = বর্তমান যত্ন পথ ("কোনো চিকিৎসা নয়" নয়)     ✓
সুপারিশ: নিয়মিত কমিশনিং, বাস্তব-বিশ্ব তথ্য সংগ্রহসহ।
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

স্থানান্তরযোগ্য শিল্পকর্ম হলো **অভ্যন্তরীণ রেফারেন্স কেস**: সব টুলিং/প্ল্যাটফর্ম ব্যবসায়িক ক্ষেত্রের জন্য একটি বাধ্যতামূলক পদ্ধতি — ঘোষিত তুলনাকারী, প্রমিত একক ব্যয়, স্থির ছাড় হার, প্রয়োজনীয় সংবেদনশীলতা বিশ্লেষণ।

একটি বহু-চক্র HTA মডেল আসলে কীভাবে সিমুলেট হয়, কোহর্ট ধরে ধরে ও চক্র ধরে ধরে, তার জন্য [মার্কভ কোহর্ট সিমুলেশন](../মার্কভ-কোহর্ট-সিমুলেশন/) দেখুন।

## ঝুঁকিপূর্ণ দিক

- **নিয়ন্ত্রক অনুমোদনের পরে HTA-কে আনুষ্ঠানিকতা হিসেবে বিবেচনা করা**।
- **ট্রায়ালের পরে অর্থনৈতিক মডেল তৈরি করা**।
- **এখতিয়ারের পার্থক্য উপেক্ষা করা**: US-এ $১২০হাজার/QALY-তে অর্থায়নযোগ্য একটি ICER NICE-এ £৩০হাজারে ব্যর্থ হয়।
