# 硬性现金释放型节省（赤字防线）

硬性现金释放型节省，是指医院能因你的软件而真正主动**从下个月的预算中删除**的那些具体科目。对一位严格的财务会计师而言——尤其是对一家正在运营赤字的信托机构而言——这是唯一能被完全计数的效益类别。

## 为何重要

许多NHS信托机构在赤字恢复计划下运营，每一条支出科目都受到严格审查。在这种环境下，无论产能效益与质量改善多么真实，都无法弥合赤字缺口；唯有现金才能。一款能够证明自己确实删除了预算科目的软件产品，在CFO看来*是能自我造血的*，这会彻底改变采购的对话方式：讨论不再是"我们负担得起吗？"，而变成"我们负担得起不用它吗？"本文正是[现金释放型与非现金释放型节省](../现金释放型与非现金释放型节省/)在赤字场景下最锋利的那一面。

## 计算方法

NHS最可靠的硬性现金目标，是**溢价临时用工**。信托机构通过内部"银行"人员（支付接近标准的费率）与外部"中介"人员（通常为Agenda for Change标准费率的2–3倍，虽设有上限，但在稀缺岗位上经常被突破）来填补人力缺口。

```
硬性节省 = 被避免的溢价班次数 × (溢价费率 − 标准费率)
        + 被避免的加班小时数 × 加班溢价
        + 被取消的外部合同数 × 合同价值

机制要求：必须指明具体的预算科目，以及将确认其削减的具体负责经理。
若没有人能指出那条具体科目，那就不是硬性现金。
```

## 实例演算

一名5级职级护士，每班次因行政管理负担损失约1小时；文书工作经常拖延到班次结束后，变成加班，而各病区又需额外预订"银行"人员来弥补文书积压。

某软件将这一小时归还给300名护士的排班时段：

```
避免的加班：   300名护士 × 每周2.5小时有偿加班 × £8溢价 × 46周
              ≈ 每年£276,000
银行/中介班次： 每周15个文书补救班次 × £180溢价 × 52周
              ≈ 每年£140,400
硬性现金总计    ≈ 每年£416,000，对比约£150,000的许可成本
```

每一英镑都可以对照电子排班系统与薪资系统进行审计——而这正是应当通过[效益兑现](../效益兑现/)机制、按月核实该效益的正确方式。（已发布的NHS人力模型曾声称过高达"每花£1可节省£11以上"这样的比率；对任何此类比率，都应将其视为一个需要用*你自己*信托机构排班数据来检验的假设，而非可以直接照搬的既定事实。）

## 与软件工程的联系

中介溢价在工程领域的对应物，正是组织自身的"应急采购"：用于填补交付缺口的承包商日费率、由事件驱动的加班、加急支持合同，以及云端按需抢购价格所带来的恐慌性支出。声称能带来硬性现金的生产力软件，应以同样的严谨态度瞄准这些科目——指明具体预算科目、责任人，以及哪个月开始真正收缩。它所带来的其他一切，则属于产能（参见[创造价值的产能](../创造价值的产能运营扭转/)）或质量：同样真实、有价值，但性质不同。

## 陷阱

- **把产能称为"节省"**——这在财务人员面前会瞬间摧毁可信度；参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)中的分类法。
- **将供应商模型的比率当作本地事实来呈现**（即"£11:£1问题"）——应基于信托机构自身的排班数据重新构建模型。
- **混淆一次性节省与持续性节省**：一份被取消的合同，每年都能节省其价值，而不是只节省一次；一个被裁撤的岗位，只有在其持续保持被裁撤状态时，才能持续节省薪资。
