# 跨幣種 ICER 比較 (Cross-Currency ICER Comparison)

把以一國貨幣計算的 [ICER](../增量成本效果比/) 與另一國的[支付意願閾值](../支付意願閾值/)比較——或彙總來自多國試驗的成本資料——需要一個明確、可審計的貨幣換算步驟。選錯換算方法，可能讓同樣的證據得出相反的採納決定，儘管臨床資料和成本資料都沒有變。

## 為什麼重要

ISPOR 針對多國臨床試驗的方法學指南（Willke 等，*Health Economics*，1998）建議，在比較各國資源的真實經濟價值時，用**購買力平價（PPP）**而非市場匯率來換算資源成本，並把市場匯率留給它的真正用途：為實際的跨境現金支付流建模。混淆兩者是多國衛生技術評估中最常見的方法學錯誤之一，因為對沒讀過指南的人來說，兩者看起來都是“一個匯率”，而電子表格也不會阻止你出錯。

## 計算方法

```
本幣_icer = 換算(源幣種_icer, 換算係數)

換算係數應當是：
  PPP 換算係數   —— 用於比較各國資源的真實經濟價值
                   （ISPOR 對多國 CEA 的建議）
  市場匯率       —— 僅用於真實的跨境現金支付

若 本幣_icer < 本國閾值，則採納
```

決策規則本身就是常規的 [ICER 規則](../支付意願閾值/)——`若 ICER < λ 則採納`——本主題的方法學問題在於*哪個換算係數*產生了該規則所作用的 `本幣_icer`。

## 算例

某藥物來自美國試驗的 ICER 為 $45,000/QALY。一個假想的進口國自行設定了複合閾值 £34,000/QALY（僅為本示例的假想國別數位——真實閾值因國而異，並隨時間變化，應始終註明來源和日期）。

**使用 PPP 換算係數 0.72**（僅為本示例的示意數位）：$45,000 × 0.72 = £32,400/QALY。£32,400 < £34,000 → **採納**。

**改用市場匯率 0.79**（示意數位）：$45,000 × 0.79 = £35,550/QALY。£35,550 > £34,000 → **拒絕**。

同樣的 $45,000/QALY ICER，用 PPP 換算得到採納的決定，用市場匯率換算得到拒絕的決定。這具體說明了為什麼 ISPOR 指南認為換算係數的選擇具有方法學意義——它不是舍入細節，也不是可以隱含在沒人複核的電子表格公式裡的東西。

## 與軟體工程的關聯

這是衛生經濟學裡一個眾所周知的工程問題的翻版：商業軟體中多幣種定價 i18n/l10n 的正確性——SaaS 定價頁面不應悄悄把 `$` 金額與 `£` 價格相比較。設計良好的 `Money` 型別在型別層面提供的保證——比較方法拒絕比較不匹配的幣種，並強制先做明確的換算——正是這裡衛生經濟學方法學要點的軟體工程對應：不要在幣種之間比較未換算的數位，也不要讓換算步驟隱含或沒有記錄。

## 陷阱

- **悄悄比較不同幣種的金額**：在電子表格裡做臨時的 HTA 工作，不先換算就把美元數位與英鎊數位相減或比較——這類缺陷，具備幣種意識的 `Money` 型別會從結構上抓出來，而不是任其成為無聲的錯誤。
- **混淆市場匯率與 PPP**：按 ISPOR 指南，這是多國 HTA 中最常見的方法學錯誤——兩個數位可能相差很大，回答的是不同的問題（真實經濟價值與實際現金流）。
- **不給所用匯率或 PPP 指數標註日期**：兩者都隨時間變化，因此每個引用的換算係數都應標註日期，就像本倉庫為其他參考數位（Green Book 碳價、避免死亡的價值等）標註日期那樣。
