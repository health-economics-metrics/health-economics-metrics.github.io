# ادائیگی کی رضامندی کی حدیں

ادائیگی کی رضامندی (WTP) کی حد وہ زیادہ سے زیادہ رقم ہے جو ایک فیصلہ ساز صحت کے فائدے کی فی اکائی ادا کرے گا۔

## یہ کیوں اہم ہے

| ادارہ | حد |
|---|---|
| NICE (انگلینڈ) | £20,000–£30,000 فی QALY |
| ICER (US) | $100,000–$150,000 فی QALY |
| کینیڈا (CADTH) | ≈ CAD$50,000 فی QALY |

## ریاضی

```
ICER = ΔC/ΔE < λ ہو تو قبول کریں
```

## حل شدہ مثال

آپ کی ڈیجیٹل تھراپیوٹک ICER = £16,000/QALY فراہم کرتی ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

ہر انجینئرنگ تنظیم کا ایک اندرونی λ ہوتا ہے۔

## عام غلطیاں

- **دائرہ اختیار میں حد کی خریداری۔**
