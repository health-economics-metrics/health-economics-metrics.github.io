# انتظار کی فہرست کا اثر

انتظار کی فہرست کا اثر بچائی گئی طبی صلاحیت کو انتظار کی فہرست سے ہٹائے گئے (یا تیزی سے آگے بڑھائے گئے) مریضوں میں تبدیل کرتا ہے۔

## یہ کیوں اہم ہے

انتخابی انتظار کی فہرست NHS کا وبائی مرض کے بعد کا وضاحتی چیلنج ہے۔

## ریاضی

```
اضافی سلاٹس = آزاد گھنٹے / سلاٹ کی مدت × استعمال
```

## حل شدہ مثال

ایمبینٹ دستاویزی سافٹ ویئر 20 کلینک نرسوں کے لیے روزانہ 45 منٹ بچاتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

ایک انتظار کی فہرست ایک بیک لاگ ہے۔

## عام غلطیاں

- **سلاٹس ≠ مریض۔**
