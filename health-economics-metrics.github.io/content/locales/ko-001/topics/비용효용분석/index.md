# 비용효용분석(CUA)

CUA는 **일반적이고 선호가중된 결과**를 사용하는 비용효과분석입니다 — 거의 항상 [QALY](../질보정-생존연수/)입니다.

## 왜 중요한가

국가 보건 서비스는 하나의 예산에서 암 치료제, 정신건강 앱, 수술 로봇 중에서 선택해야 합니다.

## 수식

```
ICUR = Δ비용 / ΔQALY
```

## 계산 예시

중등도 불안을 위한 CBT 앱 대 대면 치료 대기 명단.

## 소프트웨어 공학과의 연관성

CUA의 깊은 아이디어 — *서로 다른 것들을 비교하기 위한 하나의 통합된 선호가중 단위*.

## 함정

- **도구의 민감도 이하의 효용 이득.**
