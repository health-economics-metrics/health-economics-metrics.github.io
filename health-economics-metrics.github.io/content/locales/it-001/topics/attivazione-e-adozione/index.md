# Attivazione e Adozione

Il tasso di attivazione è la quota di iscrizioni che raggiunge il primo valore significativo. L'adozione è la versione a livello di popolazione.

## Perché è importante

Gli utenti non attivati sono puro costo.

## La matematica

```
Tasso di attivazione = utenti che completano l'azione chiave nella finestra / iscrizioni × 100
Tasso di adozione = adottanti / popolazione idonea × 100
```

## Esempio risolto

Un commissario offre un'app di prevenzione del diabete a 80.000 residenti idonei: valore della popolazione ≈ £1,25 milioni.

## Collegamento con l'ingegneria del software

L'attivazione è la fase dell'imbuto più trattabile dal punto di vista ingegneristico.
