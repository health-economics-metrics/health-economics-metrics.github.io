# アドヒアランスと継続

アドヒアランスとは、実際の利用が処方された利用にどれだけ近いか(強度)のことです;継続とは、中止までどれだけ長く利用が続くか(期間)のことです。薬局には標準化された測定値があります — **MPR**と**PDC**であり、80%以上が従来の「アドヒアランスがある」基準です — そしてデジタル治療薬は概念と問題の両方を受け継ぎます:アドヒアランスは、有効性と実現される価値の間の乗数です。

## なぜ重要か

支払者はすでにこれらの数値で運用しています:PDC 80%以上は米国メディケアのスターレーティングに入力され、実際の支払者の収益を動かします — アドヒアランスは、ソフトな指標ではなく財務的に重要なインフラです。デジタル治療薬にもこのパターンは繰り返されます:DiGAのデータは、強い処方量と弱い持続的アドヒアランスを示しており、成果連動型のDTx価格設定(2026年からドイツに導入)は、アドヒアランスに条件付けられた成果に対して支払います。デジタルヘルス研究からの概念的な改善点:**効果的なエンゲージメント** — 意図されたアウトカムを達成するのに*十分な*エンゲージメント — そしてその系である**最小有効用量**は、「多いほど良い」と想定されるのではなく、介入ごとに実証的に確立されます。

## 数式

```
MPR = Σ調剤された供給日数 / 期間内の日数 × 100   (100%を超えることがある;
      早期の補充を通じて過大評価する)
PDC = 供給でカバーされた日数 / 期間内の日数 × 100 (100%で上限;
      保守的で、CMSが好む推定量)
デジタルアドヒアランス = 実際の利用イベント数 / 処方された利用イベント数 × 100
継続                  = 開始から中止までの日数
                       (N か月時点での継続率%を報告;生存分析の手法)

価値のゲーティング:実現されたアウトカム ≈ 有効性 × g(アドヒアランス)
  gは用量反応関数;最小有効用量を下回ると、g≈0 — 費用は発生するが
  便益は失われる
```

## 計算例

ある不眠症向けデジタルCBT製品、6週間にわたる6モジュールとして処方;試験の有効性は、4モジュール以上完了した人々(実証的に確立された最小有効用量)で0.025QALY:

```
1,000件の処方、£250 → £250,000の支払者支出
モジュール完了:4モジュール以上38%;1〜3モジュール34%;ゼロモジュール28%

実現されたQALY = 1,000 × 0.38 × 0.025 = 9.5
QALYあたり費用 = 250,000 / 9.5 ≈ £26,300 — NICEの閾値で境界線上

アドヒアランスのエンジニアリング(リマインダーの再設計、セッションの短縮)により、
4モジュール以上の完了率が50%に上昇:12.5QALY → £20,000/QALY。この製品は、
治療内容に触れることなく資金提供の閾値を超えました。
```

2026年式の成果連動型価格設定のもとでは、同じシフトが*収益*を直接動かします — アドヒアランスのエンジニアリングが商業的なロードマップになります。

## ソフトウェア工学との関連

2つの語彙が1つの概念に収束します:ソフトウェア分析([アクティベーション](../アクティベーションと普及/)、[粘着性](../エンゲージメントメトリクス/)、[定着](../定着と離脱/))と臨床薬学(MPR、PDC、継続)は、どちらも介入への曝露を測定しています — 製品のイベントを臨床用語にマッピングすれば、支払者はあなたのダッシュボードを読めるようになります。エンジニアリングはアドヒアランスのレバーを所有しています:リマインダーのロジック(単純な毎日のピンは無視を訓練しますが、適応的なタイミングはそうではありません)、セッションの費用(20分のモジュールは、7分のモジュール3回よりも完了率が低い)、そしてプロトコルの*どこで*利用者が脱落するかを特定する摩擦のテレメトリです。1日目から用量反応を計測してください — 経済モデル全体をゲーティングする最小有効用量の分析には、製品だけが収集できる利用とアウトカムを結びつけたデータが必要です。

## 落とし穴

- **MPR/PDCの混同**:MPRは水増しします;どちらの推定量を使っているかを明示し、支払者向けのものにはPDCを使ってください。
- **治療ではなくメトリクスへのアドヒアランス**:オープンが用量として数えられること([エンゲージメントメトリクス](../エンゲージメントメトリクス/)を参照)。
- 介入が有限の用量を持つ場合の**「多いほど良い」というエンゲージメント目標** — 修了は成功であり、永続的な利用はそうではありません。
- **生存者ベースの有効性の主張**:アドヒアランスのある人々の間でのアウトカムには選択効果が含まれます(アドヒアランスのある人々は異なります);正直な因果推定にはランダム化か慎重な調整が必要です。
