# WSJF og CD3

CD3 og WSJF er regler for å prioritere arbeid basert på **verditetthet**.

## Hvorfor det er viktig

Enhver backlogg er et rasjoneringsproblem.

## Matematikken

```
CD3 = kostnad ved forsinkelse (£/uke) / varighet (uker)
```

## Gjennomarbeidet eksempel

Tre funksjoner, ett team: CD3-rekkefølge: B, C, A.

## Kobling til programvareutvikling

For helseprogramvareporteføljer, uttrykk CoD i QALY/uke.

## Fallgruver

- **WSJF-poengteater.**
