# 等候名單影響

等候名單影響，將被節省的臨床產能，轉化為從等候名單中移除（或更快透過等候名單）的病患數量。把節省下來的工時轉化為額外的門診名額，能直接縮減一家信託機構等候名單的規模——這是向一個醫療系統展示被釋放的產能究竟*用來做什麼*最直觀的方式。

## 為何重要

擇期手術等候名單是NHS疫情後最具代表性的挑戰（其規模本身就是一項全國性的政治指標），每家信託機構都在圍繞它推進擇期醫療恢復計劃。一份寫著"節省2,000個護士工時"的商業案例是抽象的；而一份寫著"創造4,000個額外預約名額，為3,800名等候病患提供診療，將該專科的等候名單縮減9%"的論證，才是一份營運總監能夠帶去董事會彙報的故事。等候名單影響，正是[非現金釋放型產能](../現金釋放型與非現金釋放型節省/)最自然的*核算單位*。

## 計算方法

```
額外名額數     = 釋放的工時 / 單次名額時長 × 利用率
接診病患數     = 額外名額數 × (1 − 爽約率)
名單縮減數     = 接診病患數 − 被誘發的新增需求
等待時間改善   = 服務速率提升帶來的排隊改善
               （對於穩定佇列，以服務速率μ將積壓量N削減ΔN，
               能使所有人平均提前約ΔN/μ）
```

更短等待時間所帶來的健康價值：病患在治療前較低效用狀態下度過的週數減少——相關QALY算術參見[轉診至治療](../轉診至治療/)。

## 實例演算

環境文書記錄軟體為20名門診護士中的每一位，每天節省45分鐘。按250個工作日計算：20 × 0.75 × 250 = 每年3,750小時。

```
名額數（每個30分鐘，85%可用率） = 3,750 / 0.5 × 0.85 = 6,375個名額
接診病患數（爽約率7%）          = 6,375 × 0.93       ≈ 每年5,929人
```

對於一個等候名單有12,000人、需求匹配產能為每年24,000次預約的專科而言，約5,900次額外預約能將平均等待時間縮短約四分之一——使該信託機構在不招聘新人的情況下，實質性地朝18周標準邁進。按每次就診約£160的標準價格計算，這部分活動價值約為每年£949,000（參見[全國統一收費標準與單位成本](../全國統一收費標準與單位成本/)）——但應優先以*等候名單*這一框架呈現；這正是該系統實際管理所依據的口徑。

## 與軟體工程的聯絡

等候名單本質上就是一份積壓任務清單，而積壓任務燃盡的經濟學在兩個方向上都可以相互遷移。從健康領域遷移到軟體領域：應按*使用者*等待獲得價值所需的時長，而非按已關閉的條目數，來為積壓任務的減少估值（每個排隊專案的[延遲成本](../延遲成本/)）。從軟體領域遷移到健康領域：利特爾法則告訴我們，只有當服務速率超過到達速率時，名單才會真正縮短——被新增轉診吃掉的產能提升，不會改變等待時間，因此同樣需要為"到達"這一端建模。而在這兩個領域中，都應按嚴重程度加權的價值來排定優先順序（臨床緊急程度分類 ↔ [嚴重程度調整因子](../QALY缺口與嚴重程度調整因子/)），而非簡單的先進先出。

## 陷阱

- **名額數 ≠ 病患數**：忘記考慮爽約率，以及被釋放時間中那些無法被有效利用的零碎片段。
- **被誘發的需求**：可見的額外產能會吸引更多轉診；名單淨影響會小於毛影響。
- **主張為現金**：等候名單影響屬於產能價值；而現金層面的主張（避免了將積壓工作外包出去）是另一條獨立的效益線——參見[可規避的外包成本](../可規避的外包成本/)。
