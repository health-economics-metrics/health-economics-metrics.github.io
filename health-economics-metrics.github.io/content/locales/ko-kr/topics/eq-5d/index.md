# EQ-5D

EQ-5D는 건강 관련 삶의 질을 측정하기 위한 EuroQol 그룹의 표준화된 설문지입니다.

## 왜 중요한가

QALY를 주장하고자 하는 모든 디지털 헬스 제품은 검증된 도구로부터의 효용이 필요합니다.

## 수식

```
건강 상태 = 5자리 프로필, 예: "21221"
효용 지수 = 가치_세트(프로필)
```

## 계산 예시

근골격계 재활 앱이 등록 시점과 6개월 후에 EQ-5D-5L을 측정합니다.
