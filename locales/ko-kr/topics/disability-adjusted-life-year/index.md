# 장애보정 생존연수(DALY)

DALY는 잃어버린 건강한 삶의 1년입니다 — [QALY](../quality-adjusted-life-year/)의 부담 측면 거울상입니다.

## 왜 중요한가

DALY는 국제 보건의 표준입니다.

## 수식

```
DALY = YLL + YLD
```

## 계산 예시

검진-알림 플랫폼이 연간 240 DALY를 절약합니다.

## 소프트웨어 공학과의 연관성

DALY는 공학을 위한 유용한 *부담 인벤토리* 템플릿이기도 합니다.

## 함정

- **획득한 QALY ≠ 회피된 DALY, 수치적으로.**
