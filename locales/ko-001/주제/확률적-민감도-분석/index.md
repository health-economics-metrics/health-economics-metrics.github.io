# 확률적 민감도 분석(PSA)

PSA는 모든 불확실한 매개변수에 확률 분포를 할당하고, 모두를 동시에 수천 번 샘플링하며(몬테카를로), 단일 점 추정치 대신 한 옵션이 최선일 *확률*을 보고합니다.

## 왜 중요한가

NICE의 기준 사례는 PSA를 *요구*합니다. 그 특징적인 결과물인 **비용효과 수용가능곡선(CEAC)**은 옵션이 비용효과적일 확률을 지불의사 임계값에 대해 표시합니다.

## 수식

```
N개의 추출 각각에 대해(N ≈ 10,000):
  각 매개변수 θ를 그 분포에서 샘플링
  각 옵션 j에 대해 NMB_j(θ) = λ × 효과_j(θ) − 비용_j(θ) 계산
```

## 계산 예시

플랫폼 마이그레이션 비즈니스 케이스. 평균 순편익 £775천; 순편익 > 0일 확률 0.86.

## 소프트웨어 공학과의 연관성

엔지니어들은 이미 전달 예측에 몬테카를로를 신뢰합니다.
