# 可避免的外包成本 (Avoidable Outsourcing Costs)

当一家信托机构无法用内部产能达成目标时，它便只能以溢价购买产能：让自己的员工加班周末，或将手术转由私立机构外包。能够释放内部产能的软件，其经济价值就包括**避免这类溢价工作所节省下来的成本**。

## 为何重要

在择期手术积压压力下，信托机构经常按私营部门的市场即时价（往往是NHS结算价的1.2–1.5倍）支付费用，或以溢价形式支付"等候名单专项"（waiting-list-initiative）费率，让本院顾问医生在周末加开手术清单。与一般的产能收益主张不同，避免外包属于**现金释放型**收益：这笔本应开给私营提供方的发票，真的不会再开出了。这使其成为能提升内部吞吐量的软件所能主张的最有力的收益线之一——也是最容易举证的一条，因为外包支出本身就已经是一条清晰可见的预算科目。

## 计算方法

```
可避免的外包成本 = 转回内部完成的业务量 × (外包单价 − 每例内部边际成本)

内部边际成本：为完成新增业务所需的耗材 + 可变人力成本
——固定的场地成本本就已经付过了（参见marginal-vs-average-cost.md）。
```

这一收益主张必须以"释放出来的内部产能确实能够消化这些业务"为前提：手术室时段、床位与人员必须均可调配到位（起决定作用的是那道约束瓶颈——依然是约束理论）。

## 实例演算

某信托机构每年将800例白内障手术外包，每例£900：每年外部支出£720,000，而结算价约为£750。

手术室排程软件（清单优化、利用取消档期回填空档、周转时间跟踪）将内部手术室利用率提升到足以把500例手术转回内部完成：

```
每例内部边际成本约£350（耗材 + 阶段性人力）
节省 = 500 × (900 − 350) = 每年£275,000——现金释放型
剩余外包量：300 × £900 = £270,000（原为£720,000）
```

软件成本为每年£90,000 → 净收益约为**每年+£185,000的可入账现金**，此外还有将业务留在院内带来的内部质量与培训收益。

## 与软件工程的关联

其直接对应物是**外包合同与咨询费溢价**：当内部工程产能无法满足承诺交付时，机构便会以内部全成本时薪1.5–3倍的价格购买外部产能。能提升内部吞吐量的平台与生产力投资，同样应按上述方式主张避免的外包支出——外部日薪减去内部边际成本，再乘以转回内部完成的工作量——因为这是开发者生产力商业论证中少数真正属于现金释放型的收益线之一。同样的前提条件也适用：内部产能必须真实存在，并确实被排入转回的工作，否则该收益主张就是空谈。

## 常见陷阱

- **在缺乏完整产能链条的情况下主张转回内部完成**——外科医生被腾出来了，却没有手术室时段（或工程师被腾出来了，却没有产品管理带宽），结果什么也转不回来。
- **将外包价格与内部平均成本相比较**而非边际成本——这会低估节省额，颇为反常；因为固定成本无论如何都要发生。
- **质量/复杂度不对称**：被外包的病例往往是较简单的病例；将其转回内部会改变内部的病例组合与单位成本。
