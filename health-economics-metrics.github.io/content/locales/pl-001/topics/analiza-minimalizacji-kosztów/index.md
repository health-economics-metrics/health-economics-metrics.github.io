# Analiza minimalizacji kosztów (CMA)

Analiza minimalizacji kosztów wybiera najtańszą opcję po udowodnieniu, że porównywane interwencje mają równoważną skuteczność.

## Dlaczego to ważne

Gdy skuteczność jest już udowodniona jako równoważna, przeprowadzanie złożonych obliczeń efektywności kosztowej jest niepotrzebne — wystarczy wybrać najtańszą.

## Matematyka

```
Wybierz opcję z min(Koszt), przy Efekt_A = Efekt_B
```

## Rozwiązany przykład

Dwa generyczne leki o udowodnionej identycznej skuteczności: wybierz ten z najniższą ceną zakupu, bez dalszej analizy.

## Powiązanie z inżynierią oprogramowania

Przypomina wybieranie najtańszego dostawcy chmury po potwierdzeniu, że oba spełniają te same wymagania dotyczące wydajności i niezawodności.

## Pułapki

- **Zakładanie równoważności bez solidnych dowodów.**
- **Używanie CMA, gdy efekty faktycznie różnią się subtelnie.**
