# Сравнение ICER между валютами (Cross-Currency ICER Comparison)

Сравнение [ICER](../инкрементальное-соотношение-затрат-и-эффективности/), рассчитанного в валюте одной страны, с [порогом готовности платить](../пороги-готовности-платить/) другой — или объединение данных о затратах, собранных в многонациональном исследовании, — требует явного, поддающегося аудиту шага конвертации валюты. Неверный способ конвертации может перевернуть решение о принятии при тех же доказательствах, хотя клинические данные и данные о затратах не изменились.

## Почему это важно

Методические рекомендации ISPOR для многонациональных клинических исследований (Willke и др., *Health Economics*, 1998) советуют конвертировать затраты на ресурсы по **паритету покупательной способности (ППС)**, а не по рыночному курсу, когда сравнивается реальная экономическая стоимость ресурсов между странами, а рыночный валютный курс оставлять для его настоящей цели — моделирования реальных трансграничных денежных потоков. Путаница между ними — одна из самых распространённых методологических ошибок в многонациональной HTA, потому что для не читавшего рекомендации обе величины выглядят как «один валютный курс», а электронная таблица не помешает ошибиться.

## Математика

```
icer_в_местной_валюте = конвертировать(icer_в_исходной_валюте, коэффициент_конвертации)

коэффициент_конвертации должен быть:
  коэффициент ППС        — для сравнения реальной экономической стоимости
                           ресурсов между странами (рекомендация ISPOR для
                           многонациональной CEA)
  рыночный валютный курс — только для реальных трансграничных денежных платежей

принять, если icer_в_местной_валюте < местный_порог
```

Правило решения — обычное [правило ICER](../пороги-готовности-платить/): `принять, если ICER < λ`; методологический вопрос этой темы — *какой коэффициент конвертации* даёт то `icer_в_местной_валюте`, к которому применяется это правило.

## Практический пример

У лекарства ICER из американского исследования составляет $45 000/QALY. Гипотетическая страна-импортёр установила собственный составной порог £34 000/QALY (гипотетическая цифра, специфичная для страны, только для этого примера; реальные пороги различаются по странам, меняются со временем и всегда должны указывать источник и дату).

**С коэффициентом конвертации по ППС 0,72** (иллюстративная цифра только для этого примера): $45 000 × 0,72 = £32 400/QALY. £32 400 < £34 000 → **принять**.

**С рыночным валютным курсом 0,79** (иллюстративная цифра): $45 000 × 0,79 = £35 550/QALY. £35 550 > £34 000 → **отклонить**.

Один и тот же ICER в $45 000/QALY даёт решение «принять» при конвертации по ППС и «отклонить» при конвертации по рыночному курсу. Это конкретная иллюстрация того, почему рекомендации ISPOR считают выбор коэффициента конвертации методологически значимым — это не деталь округления и не то, что можно оставить неявным в формуле таблицы, которую никто не перепроверяет.

## Связь с разработкой программного обеспечения

Это зеркальное отражение в экономике здравоохранения хорошо знакомой инженерной задачи: корректности мультивалютного ценообразования i18n/l10n в коммерческом ПО, где страница цен SaaS не должна молча сравнивать сумму в `$` с ценой в `£`. Гарантия на уровне типов, которую даёт хорошо спроектированный тип `Money` — метод сравнения, отказывающийся сравнивать несовпадающие валюты и сначала требующий явной конвертации, — прямая программно-инженерная параллель методологическому пункту экономики здравоохранения: не сравнивайте неконвертированные числа между валютами и не оставляйте шаг конвертации неявным или недокументированным.

## Подводные камни

- **Молчаливое сравнение сумм в разных валютах**: разовая работа по HTA в электронной таблице, которая вычитает или сравнивает числа в долларах с числами в фунтах без предварительной конвертации, — тот тип ошибки, который валютно-осведомлённый тип `Money` ловит структурно вместо того, чтобы оставить её тихой.
- **Путаница рыночного курса и ППС**: самая распространённая методологическая ошибка в многонациональной HTA согласно рекомендациям ISPOR — две величины могут сильно различаться и отвечают на разные вопросы (реальная экономическая стоимость против реального денежного потока).
- **Отсутствие даты у использованного курса или индекса ППС**: оба меняются со временем, поэтому каждый приводимый коэффициент конвертации должен быть датирован, как этот репозиторий датирует прочие справочные цифры (цену углерода из Green Book, стоимость предотвращённой смерти и т. д.).
