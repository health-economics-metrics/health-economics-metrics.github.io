# 全国统一收费标准与单位成本

NHS按照一套基于规则的全国价目表为医疗提供方的活动付费——历史上称为"全国统一收费标准/按结果付费"，自2023年4月1日起被**NHS支付方案（NHSPS）**取代。在这些价格背后，是一整套全国性的单位成本核算基础设施：**全国成本采集（NCC）**，以及**PSSRU《医疗与社会照护单位成本》**汇编。

## 为何重要

这些数据是每一份可信的NHS商业论证的分母所在。当某个主张说"一次门诊就诊价值£160"或"一个5级职级护士-小时的成本为£31"时，这些数字正是来自这套基础设施——使用官方数字而非凭空捏造的数字，正是让独立评估具有可比性、让财务团队愿意配合的关键所在。对供应商而言，该收费标准同样界定了*收入*的一侧：你的软件所促成的活动（额外的门诊、被重新填满的床位）会按标准价格计价。

## 计算方法

```
每单位活动的标准价格（HRG编码住院单元、门诊就诊）
  = 全国平均单位成本（来自NCC）× 市场力量系数（本地调整因子）
  在NHSPS下：混合固定+可变（"对齐支付与激励机制"）要素

NCC单位成本 = 各信托机构报告的某类活动总成本 / 活动量
             （建立在病人层面信息与成本系统PLICS之上）

PSSRU汇编：约80项标准单位成本（全科医生问诊、按职级划分的护士-小时、
急诊就诊……）——英国经济学评估中的默认数据来源。
```

## 实例演算

你的软件在一个250个工作日的年度中，为一名5级职级护士每天释放1小时时间：

```
基于PSSRU数据的5级职级成本（含管理费用）约为£31/小时（需核对当前版本）
产能价值 = 250 × £31 = 每名护士每年£7,750（非现金释放型）
```

或者，这名护士可以用这些时间每天多完成2次门诊复诊，按标准价格约£160计算：500 × £160 = **每年£80,000的可获资助活动量**——同样的时间，仅因重新部署方式不同，所主张的价值就相差十倍，而这一切都基于官方单位成本数据。两种主张都是可审计的，因为它们的分母都是公开发布的；这正是整套体系的意义所在。

## 与软件工程的联系

这正是**内部价目手册**这一模式的体现。英国健康经济学之所以行得通，是因为每一项评估都使用同一套已发布的单位成本；而工程组织大多缺乏这样一套体系，因此每一份商业论证都在自行编造一个工程师-小时、一次事件、一次部署各自的成本。平台团队完全可以发布这样一本价目手册——按职级划分的每工程师-小时负荷成本、按严重程度划分的每次事件成本、每构建分钟成本——并要求所有提案都必须采用这套统一标准。内部计费系统同样会复现这套收费标准已知的失灵模式：按平均成本定价会助长用量操纵，固定付费则会导致供给不足。NHSPS从纯粹按活动付费、演变为混合固定+可变支付的这二十年历程，正是内部平台定价激励机制设计方面的宝贵经验教训。

## 陷阱

- **数据陈旧**：NCC、PSSRU与NHSPS的价格每年都会更新——每一个数字都应标注日期。
- **标准价格 ≠ 成本**：价格是经过调整的全国平均值；你所在地的边际成本可能与之不同（参见[边际成本与平均成本](../边际成本与平均成本/)）。
- **按标准价格为产能估值，却没有真正实现并获得那部分额外活动付费的实际机制**。
