# চিকিৎসার প্রয়োজনীয় সংখ্যা (NNT)

NNT হলো একটি নির্দিষ্ট সময়সীমার মধ্যে **একজন** অতিরিক্ত রোগীর উপকার পেতে কতজন রোগীর একটি হস্তক্ষেপ পাওয়া প্রয়োজন। এটি বিভ্রান্তিকর শতাংশ ঝুঁকি হ্রাসকে যেকেউ যুক্তি দিতে পারে এমন প্রচেষ্টা-প্রতি-সুবিধা এককে রূপান্তরিত করে।

## কেন এটি গুরুত্বপূর্ণ

"হৃদরোগের আক্রমণ ২৫% কমায়!" সিদ্ধান্তমূলক শোনায়। যদি বেসলাইন ঝুঁকি ৫ বছরে ৪% হয়, পরম হ্রাস ১ শতাংশ পয়েন্ট, তাই **১ জনের উপকার পেতে ১০০ জনকে ৫ বছর ওষুধ খেতে হবে**।

## গণিত

```
ARR = নিয়ন্ত্রণ ঘটনা হার − চিকিৎসা ঘটনা হার
NNT = 1 / ARR

NNH = 1 / (ক্ষতি হার_চিকিৎসা − ক্ষতি হার_নিয়ন্ত্রণ)
```

## সমাধানকৃত উদাহরণ

একটি হাসপাতালে একটি পতন-পূর্বাভাস ব্যবস্থা উচ্চ-ঝুঁকিপূর্ণ রোগীদের হস্তক্ষেপের জন্য চিহ্নিত করে। ট্রায়াল: আঘাতসহ পতন ভর্তির ৩.২% থেকে ২.৪%-এ নামে।

```
ARR = 0.8 শতাংশ পয়েন্ট → NNT = 1/0.008 = 125
হস্তক্ষেপ ব্যয় ≈ £40/রোগী → প্রতি প্রতিরোধিত পতনের ব্যয় = 125 × 40 = £5,000
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

NNT যেকোনো গেট বা চেকের জন্য সঠিক একক যা অনেক আইটেমে কাজ করে অল্প ধরার জন্য: **"একটি উৎপাদন-বাউন্ড ত্রুটি ধরতে AI পর্যালোচনা গেটের মধ্য দিয়ে কতগুলো PR পাস করতে হবে।"** [স্ক্রিনিংয়ের প্রয়োজনীয় সংখ্যা](../স্ক্রিনিংয়ের-প্রয়োজনীয়-সংখ্যা/) এক স্তর ওপরের সমতুল্য সংখ্যা, শুধু চিকিৎসা নয়, সম্পূর্ণ স্ক্রিন-তারপর-চিকিৎসা কর্মসূচির জন্য।

## ঝুঁকিপূর্ণ দিক

- **সময়সীমা নেই**: "NNT = 50" কিছুই বোঝায় না।
- **বেসলাইন-ঝুঁকি প্রতিস্থাপন**: একটি উচ্চ-ঝুঁকিপূর্ণ ট্রায়াল জনসংখ্যায় গণনাকৃত NNT একটি নিম্ন-ঝুঁকিপূর্ণ স্থাপনা জনসংখ্যায় ভেঙে পড়ে।
- **NNH উপেক্ষা করা** — NNT 400 এবং NNH 3-সহ একটি গেট একটি উপদ্রব জেনারেটর, নিরাপত্তা ব্যবস্থা নয়।
