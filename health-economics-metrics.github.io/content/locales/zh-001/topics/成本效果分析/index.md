# 成本效果分析（CEA）

成本效果分析比较各替代干预方案的成本，其结果均以同一种**自然单位**衡量——生命年、检出病例数、避免的住院数、血压降低的mmHg数。其输出结果是"每单位结果的成本"。

## 为何重要

当所有备选方案针对同一结果时，成本效果分析是最常用的比较方法。它回答的是"在实现X这一目标的诸多方式中，哪一种最能物尽其用？"——但*不能*回答"X这个目标本身是否值得追求？"（这需要[成本效益分析](../成本效益分析/)），也*不能*回答"X与其他不相关的优先事项相比如何？"（这需要[成本效用分析](../成本效用分析/)以及像QALY这样的通用结果指标）。

## 计算方法

用于比较的统计量是以自然单位表示的[ICER](../增量成本效果比/)：

```
ICER = (成本_A − 成本_B) / (效果_A − 效果_B)
     = 每多检出一例/每避免一次入院/等等所需的£成本
```

操作步骤：先定义结果计量单位；在相同的[视角](../分析视角/)、相同的[时间范围](../时间范围/)下，为每一个方案核算成本；剔除被占优的方案（参见[效率前沿](../占优关系与效率前沿/)）；沿着前沿计算增量比值。

## 实例演算

在一个10万人的群体中，发现未确诊心房颤动的三种方式：

```
方案                       成本         发现病例数
机会性脉搏检测              £150,000        300
药房筛查活动                £400,000        520
可穿戴设备筛查               £900,000        610

药房方案 相对 脉搏检测方案的ICER： (400,000−150,000)/(520−300) = 每多发现一例£1,136
可穿戴方案 相对 药房方案的ICER：   (900,000−400,000)/(610−520) = 每多发现一例£5,556
```

每多发现一例花费£5,556是否"值得"，取决于每发现一例所带来的价值（下游的中风预防收益）——成本效果分析可以对方案进行排序，但采纳决策仍需依赖那个外部的价值判断。请注意，可穿戴设备方案的*平均*每例成本（900,000/610 = £1,475）看起来还不错；而*增量*成本£5,556，才是用于扩容决策的诚实数字。

## 与软件工程的联系

只要各方案共享同一个结果指标，成本效果分析就是恰当的模板：三种补救方法下每消除一个不稳定测试的成本；不同可观测性供应商下每避免一次事件的成本；不同CI架构下每次成功部署的成本。它所强制推行的纪律——明确设定一个结果计量单位、使用增量（而非平均）比值、先剔除被占优的方案——能在定价讨论开始之前，就扼杀掉大多数糟糕的供应商比较。

## 陷阱

- **在同一次成本效果分析中比较结果指标不同的方案**（例如"发现病例数"对比"满意度"）——这需要[成本后果分析](../成本后果分析/)，或者一个通用的结果指标。
- **在本应使用增量比值的场合呈现平均成本效果比**（如上文可穿戴设备的例子）。
- **为博取好感而挑选结果计量单位**："产生的警报数"是一种产出，而非一种结果；应坚持使用真正承载价值的计量单位。
