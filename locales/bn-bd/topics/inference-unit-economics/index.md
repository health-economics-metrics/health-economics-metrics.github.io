# অনুমান একক অর্থনীতি

অনুমান একক অর্থনীতি AI বৈশিষ্ট্যগুলোকে তাদের প্রান্তিক কম্পিউট দ্বারা মূল্য নির্ধারণ করে: **প্রতি টোকেন ব্যয়**, প্রতি লেনদেন, প্রতি ব্যবহারকারী, প্রতি ক্লিনিক্যাল পর্বে সংকলিত।

## কেন এটি গুরুত্বপূর্ণ

মূল্য পতন থেকে দুটি পরিণতি অনুসরণ করে। বাণিজ্যিকভাবে, আজ প্রান্তিক একটি AI বৈশিষ্ট্য ১৮ মাসে তুচ্ছভাবে লাভজনক হতে পারে।

## গণিত

```
প্রতি কল ব্যয়     = ইনপুট টোকেন × ইনপুট হার + আউটপুট টোকেন × আউটপুট হার
মূল্য-পতন দৃশ্যকল্প বহু-বছরের মডেলের জন্য:
  ব্যয়_t = ব্যয়_0 × d^t, সংবেদনশীলতা বিশ্লেষণে d ∈ {0.3, 0.5, 0.7}/বছর পরীক্ষা করুন
```

## সমাধানকৃত উদাহরণ

একটি AI স্রাব-সারাংশ সেবা: গড় সারাংশ ১২,০০০ ইনপুট টোকেন + ১,২০০ আউটপুট ব্যবহার করে। $৩/M ইনপুট, $১৫/M আউটপুটে:

```
খসড়া:   12,000 × 3/1M + 1,200 × 15/1M  = $0.054
প্রতি সারাংশ ≈ $0.077 → বছরে 100,000 সারাংশ প্রতি ≈ $7,700

প্রতি সারাংশ ~20 চিকিৎসক-মিনিট সাশ্রয়ের বিপরীতে (≈£25), অনুমান
তৈরি হওয়া মূল্যের 0.25% — অর্থনীতি টোকেন ব্যতীত সবকিছু দ্বারা প্রভাবিত।
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

এটি AI-এর জন্য বিশেষায়িত [ক্লাউড একক অর্থনীতি](../cloud-unit-economics/), তিনটি অনুশীলন নোটসহ: **ব্যবসায়িক একক প্রতি মিটার করুন**, API কল প্রতি নয়।

## ঝুঁকিপূর্ণ দিক

- **স্থির-মূল্য বহু-বছরের মডেল** — ব্যয় বাড়িয়ে দেখায়।
- **মূল্যায়ন ওভারহেড উপেক্ষা করা**: গার্ডরেল, বিচারক, এবং পুনঃচেষ্টা প্রকৃত টোকেন।
