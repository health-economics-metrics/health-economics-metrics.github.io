# Økonomi for fjernpasientovervåking

Økonomi for fjernpasientovervåking måler kostnadsbesparelsene som hjemmeovervåkingsteknologi gir ved å redusere innleggelser, reinnleggelser og fysiske besøk.

## Hvorfor det er viktig

Fjernovervåking krever innledende utstyrskostnader, men kan forhindre kostbar bruk av akuttbehandling.

## Matematikken

```
Nettobesparelse = (antall unngåtte innleggelser × kostnad per innleggelse) − programkostnad
```

## Gjennomarbeidet eksempel

Fjernovervåking av hjertesvikt: 40 unngåtte innleggelser × £4 000 = £160 000 besparelse − programkostnad £60 000 = nettobesparelse £100 000.
