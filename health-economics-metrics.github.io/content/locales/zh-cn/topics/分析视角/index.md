# 分析视角 (Analysis Perspective)

视角决定了在一项经济分析中，*谁*的成本与收益才算数：是支付方的、提供方的，还是整个社会的。同一项干预措施，从一个视角看可能极为出色，从另一个视角看却可能相当糟糕。

## 为何重要

每一项经济评估都必须事先声明其分析视角，因为视角决定了哪些具体项目会被纳入计算：

- **支付方视角**（例如NHS委托方、保险公司）：只计入支付方需要报销的成本。
- **提供方视角**（例如某医院信托机构）：内部服务提供成本、人员配置、场地设施。
- **社会视角**：涵盖一切——包括患者时间、交通、家庭成员提供的非正式照护，以及雇主承受的生产力损失。

NICE的参考案例采用**NHS及个人社会服务（Personal Social Services，PSS）**视角来核算成本。美国"第二届成本效果评估小组"（Second Panel on Cost-Effectiveness）则建议同时报告医疗行业视角与社会视角两套分析，并附上列明纳入项目的"影响清单"（impact inventory）。

## 计算方法

没有固定公式——这是一条须先于任何计算而应用的界定规则：

```
纳入的成本/收益类别 = f(视角)
```

一个有用的检验方法：建立一张影响清单表，每行对应一项成本/收益，每列对应一种视角，逐格标记该项在该视角下是否计入。

## 实例演算

某症状自查应用每年将10,000次全科医生（GP）就诊转移为自我照护。

- **支付方（NHS）**：节省10,000 × 每次GP问诊£42 = **每年£420,000**——明显为正。
- **提供方（全科诊所）**：若诊所按人头付费（capitation）结算，其收入不变，但工作量下降——轻度为正。
- **社会视角**：加上患者节省的交通与等待时间，假设为10,000 × 2小时 × £15/小时 = £300,000的时间价值；但若2%的用户因误得安心而延误就诊，病情加重，需按200 × £3,000 = £600,000计入额外治疗成本，则应予扣减。社会净值：420,000 + 300,000 − 600,000 = **每年£120,000**——为正，但结果高度取决于安全性假设。

同一款应用，三种不同的答案。正是对分析视角的明确声明，才使这些数字具备可比性与诚实性。

## 与软件工程的关联

工具和平台的投资回报率同样存在多重视角：

- **团队预算（"支付方"）**：许可证费用是否能落在我的成本中心里？
- **平台部门（"提供方"）**：包括系统集成、支持与维护在内的总成本。
- **公司整体（"社会"）**：需纳入对客户的影响、安全性外部性以及受影响的每个团队所耗费的时间。

一款对采购团队而言价格低廉、却把迁移工作转嫁给另外40个团队的CI工具，正是软件世界里的"成本转嫁"（cost-shifting）现象——唯有从更宽的视角才能看清。应在每一份商业论证中明确声明所采用的视角；评审者无法质疑他们看不到的假设。

## 常见陷阱

- **悄然切换视角**：只计入社会层面的收益，却只计入支付方一侧的成本，这样几乎任何方案都能显得具有成本效益。
- **视角合并导致的重复计算**（例如，当支付方数据本身已包含人员时间时，同时把一次节省的GP问诊既计入支付方节省，又计入患者时间节省）。
- **忽视成本转嫁**："节省"的成本其实只是转移给了患者、照护者或另一个部门。
