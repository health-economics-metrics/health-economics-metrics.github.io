# EQ-5D

EQ-5D — это стандартизированный опросник группы EuroQol для измерения качества жизни, связанного со здоровьем. Это инструмент, производящий весовые коэффициенты полезности внутри большинства расчётов [QALY](../год-жизни-с-поправкой-на-качество/) — референсный кейс NICE называет его предпочтительным инструментом для взрослых.

## Почему это важно

Любому продукту цифрового здравоохранения, желающему заявлять о QALY, нужны полезности из валидированного инструмента, и EQ-5D — вариант по умолчанию в Великобритании и большей части Европы. Он достаточно короткий, чтобы встроить его в приложение (5 вопросов + визуальная шкала), а значит программные продукты могут собирать данные об исходах уровня HTA как побочный эффект обычного использования — структурное преимущество перед лекарствами, которым нужны выделенные исследования.

## Математика

EQ-5D-5L задаёт по одному вопросу в каждом из **5 измерений** — мобильность, самообслуживание, привычная деятельность, боль/дискомфорт, тревога/депрессия — каждое с ответом на **5 уровнях** (нет проблем … крайние проблемы), плюс визуальная аналоговая шкала 0–100 (EQ VAS).

```
Состояние здоровья = 5-значный профиль, напр. «21221»
Индекс полезности = набор_значений(профиль)

Набор значений специфичен для страны и получен из опросов общего населения
методом компромисса по времени (time-trade-off) / дискретного выбора. Якоря: 1 = полное здоровье,
0 = смерть; состояния хуже смерти отрицательны (нижняя граница набора 3L для Великобритании: −0.594).
```

Арифметика QALY затем идёт как `длительность × полезность`.

## Практический пример

Приложение реабилитации опорно-двигательного аппарата измеряет EQ-5D-5L при онбординге и через 6 месяцев для 1 000 завершивших пользователей.

```
Средняя полезность на исходном уровне: 0.62
Средняя полезность через 6 месяцев:    0.71
Прирост удерживается (допущение) 1 год: (0.71 − 0.62) × 1.0 = 0.09 QALY на пользователя
```

Относительно изменения в контрольной группе на 0,03 (естественное восстановление) атрибутируемый прирост составляет 0,06 QALY на пользователя. Монетизировано при £20 000–£30 000/QALY: **£1 200–£1 800 ценности здоровья на завершившего пользователя** — цифра, закрепляющая переговоры о цене приложения с плательщиком. (Минимально клинически значимые различия для индекса EQ-5D обычно лежат в диапазоне 0,03–0,08, так что 0,06 правдоподобно, но должно пройти сравнение с контролем; см. [исходы, сообщаемые пациентами](../исходы-сообщаемые-пациентами/).)

## Связь с разработкой программного обеспечения

- **Инструментируйте это.** EQ-5D при регистрации и на контрольных интервалах — это несколько экранов UI; отдача — доказательства уровня HTA. Получите лицензию у EuroQol (обязательна, для некоторых применений бесплатна).
- **Используйте правильный набор значений (value set)** для страны развёртывания — одни и те же ответы оцениваются по-разному в Великобритании, Германии и Японии.
- **Урок дизайна**: EQ-5D показывает, как крошечный стандартизированный опрос плюс опубликованная функция подсчёта дают сопоставимый единый индекс. Это тот же паттерн для любого заслуживающего доверия индекса опыта разработчика — стандартизированный инструмент, опубликованные веса, а не произвольные ощущения. См. [SPACE и DevEx](../space-и-devex/).

## Подводные камни

- **«До/после» без компаратора** — регрессия к среднему и естественное восстановление раздувают наивные приросты.
- **Смещение выживаемости**: измерение только пользователей, оставшихся вовлечёнными (см. [удержание и отток](../удержание-и-отток/)).
- **Смешение версий 3L и 5L или наборов значений** между исследованиями — систематически разные цифры.
- **Эффекты потолка** в слабо затронутых популяциях: многие пользователи набирают около 1,0 на базовой линии, не оставляя пространства для демонстрации прироста.
- **Принятие набора значений за самоочевидное**: значения полезности, которые возвращает набор значений, сами были получены от населения в исследованиях обмена времени (или родственных опросах выбора) — как именно, см. [Выявление полезности методом обмена времени (TTO)](../выявление-полезности-методом-обмена-времени/).
