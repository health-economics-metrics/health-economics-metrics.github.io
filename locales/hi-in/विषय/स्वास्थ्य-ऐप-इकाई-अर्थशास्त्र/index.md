# स्वास्थ्य ऐप इकाई अर्थशास्त्र

उपभोक्ता स्वास्थ्य उत्पादों का वाणिज्यिक गणित: ग्राहक अधिग्रहण लागत (CAC), जीवनकाल मूल्य (LTV), और नियोक्ता-बाज़ार में **ROI और VOI** (निवेश पर मूल्य) के बीच अंतर।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य ऐप एक संरचनात्मक दबाव का सामना करते हैं: अधिग्रहण महंगा है जबकि प्रतिधारण किसी भी सॉफ़्टवेयर वर्टिकल का सबसे खराब है (30 दिनों में ~90% परित्याग)।

## गणित

```
CAC = बिक्री + विपणन व्यय / नए भुगतान करने वाले ग्राहक
LTV = ARPU × औसत जीवनकाल = ARPU / मंथन दर
स्थिरता: LTV : CAC ≥ 3
```

## हल किया गया उदाहरण

एक B2C स्लीप ऐप: £6.99/माह, मासिक मंथन 18%, मिश्रित CAC £38।

```
LTV = 6.99 / 0.18 ≈ £38.8 → LTV:CAC ≈ 1.0 — अस्थिर

नियोक्ता PMPM में स्थानांतरण: £1.20 PMPM × 40,000 कवर्ड लाइव्स = माह में £48k
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इंजीनियरिंग विकल्प अनुपात के दोनों पक्षों को निर्धारित करते हैं: **सेवा-प्रदान लागत** वास्तुकला है।

## सामान्य गलतियाँ
