# Horyzont czasowy

Horyzont czasowy to okres, w którym liczone są koszty i efekty w ocenie ekonomicznej.

## Dlaczego to ważne

Zbyt krótki horyzont pomija późne korzyści (profilaktyka); zbyt długi horyzont dodaje niepewne założenia.

## Matematyka

```
Wartość całkowita = Σ(t=0 do horyzontu) (korzyści_t − koszty_t) / (1+r)^t
```

## Rozwiązany przykład

Program profilaktyki cukrzycy pokazuje oszczędności netto dopiero po 15 latach; ocena z horyzontem 5-letnim błędnie oceniłaby program jako generujący koszty.

## Powiązanie z inżynierią oprogramowania

Przypomina wybór okna pomiarowego dla ROI spłaty długu technicznego.

## Pułapki

- **Manipulacja horyzontem: wybieranie okresu dającego najkorzystniejszy wynik.**
- **Ignorowanie efektów resztkowych po horyzoncie.**

## Źródła

- NICE, time horizon guidance in technology appraisal.
- ISPOR, good practices for cost-effectiveness analysis.
