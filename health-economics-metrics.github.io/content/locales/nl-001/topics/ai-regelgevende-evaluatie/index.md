# AI-regelgevende evaluatie

AI-regelgevende evaluatie beoordeelt of medische AI-systemen voldoen aan wettelijke en regelgevende goedkeuringsvereisten.

## Waarom het ertoe doet

Falen van regelgevende goedkeuring kan de inzet van klinisch effectieve AI-systemen volledig blokkeren.

## De wiskunde

```
Kosten regelgevend traject = kosten klinisch bewijs + aanvraagkosten + kosten post-marketingsurveillance
```

## Uitgewerkt voorbeeld

Een diagnostisch ondersteuningshulpmiddel geclassificeerd als klasse III SaMD (software als medisch hulpmiddel): totale regelgevende kosten ≈ £800.000, 18 maanden tot goedkeuring.

## Verbinding met software-engineering

Bewijs uit [klinische AI-evaluatie](../klinische-ai-evaluatie/) is de kerninput voor de regelgevende indiening.

## Valkuilen

- **Ontwikkeling voortzetten zonder de regelgevende classificatie vroegtijdig vast te stellen.**
