# Метрики DORA

Метрики DORA — це чотири показники продуктивності доставки програмного забезпечення: частота розгортання, час виконання змін, рівень невдалих змін та час відновлення.

## Чому це важливо

Десять років досліджень DORA пов'язують ці метрики з організаційною продуктивністю.

## Математика

```
Час виконання = t(розгортання) − t(коміт), медіана
```

## Розібраний приклад

Команда програмного забезпечення потоку пацієнтів трасту, до/після: розгортання з щомісячних → щотижневих.

## Зв'язок з інженерією програмного забезпечення

Це *саме* сторона програмного забезпечення.
