# Realisatie van baten

Realisatie van baten is de discipline van het volgen en verifiëren of een project de beloofde baten daadwerkelijk heeft geleverd.

## Waarom het ertoe doet

Een businesscase belooft baten, maar zonder monitoring weet u nooit of ze zijn gerealiseerd.

## De wiskunde

```
Batenrealisatiepercentage = werkelijke baten / geplande baten × 100%
```

## Uitgewerkt voorbeeld

Een digitaal triage-instrument: geplande besparing £500.000/jaar; na 12 maanden werkelijk £320.000 = 64% realisatie.

## Verbinding met software-engineering

Verifieert achteraf [ROI](../rendement-op-investering/)- en [sociaal rendement op investering](../sociaal-rendement-op-investering/)-claims.

## Valkuilen

- **Een project als afgerond beschouwen zonder de baten te meten.**
