# Вплив списку очікування

Вплив списку очікування вимірює, як заощаджені клінічні години чи покращена ефективність перетворюються на реально прийнятих додаткових пацієнтів.

## Чому це важливо

Виграші в ефективності приносять реальну цінність лише тоді, коли вони перетворюються на додаткову пропускну здатність — інакше вони залишаються теоретичними.

## Математика

```
Додаткові прийняті пацієнти = Заощаджені клінічні години / Середній час на консультацію з пацієнтом
```

## Розібраний приклад

Проєкт з підвищення ефективності заощаджує 500 клінічних годин на місяць; при середньому часі консультації 20 хвилин це відповідає 1500 додатковим прийнятим пацієнтам на місяць.

## Зв'язок з інженерією програмного забезпечення

Подібно до перетворення заощадженого часу конвеєра CI/CD на реально додаткові доставлені функції, а не просто заяви про "швидші збірки".

## Підводні камені

- **Припущення, що заощаджений час автоматично використовується повторно для додаткових пацієнтів — дивіться [грошові проти негрошових заощаджень](../cash-releasing-vs-non-cash-releasing/).**
- **Ігнорування накопиченого попиту, який швидко знову заповнює список очікування.**
