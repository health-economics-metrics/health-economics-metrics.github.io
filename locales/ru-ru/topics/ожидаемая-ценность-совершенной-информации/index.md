# Ожидаемая ценность совершенной информации (Expected Value of Perfect Information, EVPI)

EVPI — это максимальная сумма, которую лицо, принимающее решение, должно заплатить, чтобы устранить неопределённость перед принятием решения — формальная цена фразы «давайте сначала проведём исследование».

## Почему это важно

Системы здравоохранения постоянно сталкиваются с выбором: внедрить сейчас на неполных доказательствах или сначала профинансировать дополнительное исследование. EVPI присваивает число второму варианту. Если EVPI составляет £50 000, а предложенное испытание стоит £2 млн — внедряйте сейчас. Если EVPI составляет £20 млн — испытание выгодно. Тот же вопрос — «стоит ли пилотировать это перед развёртыванием?» — возникает для каждого решения о корпоративном инструменте, и почти никто не оценивает его в деньгах. Об оценке опциона расширить проект позже, а не опциона сначала собрать информацию, см. [Оценку реальных опционов](../оценка-реальных-опционов/).

## Математика

EVPI — это разрыв между решением с совершенным предвидением и решением сейчас на основе ожиданий:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = неопределённые параметры (с их совместным распределением)
NMB(j,θ) = чистая денежная выгода варианта j при данном θ
```

Первое слагаемое: среднее наилучшей отдачи по каждому возможному миру (вы всегда выбираете правильно). Второе слагаемое: отдача единственного варианта, наилучшего в среднем (вы должны определиться сейчас). EVPI всегда ≥ 0. Популяционный EVPI умножается на число затронутых решений. Вычисляется напрямую из выборок [PSA](../вероятностный-анализ-чувствительности/).

## Практический пример

Развернуть ИИ-ассистента документирования для 5 000 клиницистов или нет. Два мира:

```
Мир A (p = 0.6): ассистент экономит 20 мин/день → NMB развёртывания = +£8 млн
Мир B (p = 0.4): ассистент экономит ~0 (трение процессов) → NMB развёртывания = −£3 млн
NMB варианта «не развёртывать» = £0 в обоих мирах.
```

Решение сейчас: E[NMB развёртывания] = 0,6 × 8 − 0,4 × 3 = **+£3,6 млн** → развёртывать.

С совершенной информацией: в мире A выбираем развёртывание (+£8 млн), в мире B выбираем ничего (£0). Ожидаемая ценность = 0,6 × 8 + 0,4 × 0 = **£4,8 млн**.

```
EVPI = 4.8 млн − 3.6 млн = £1.2 млн
```

Строгий трёхмесячный пилот стоимостью £150 000, существенно проясняющий, в каком вы мире, однозначно оправдан — а любой пилот дороже £1,2 млн — нет, каким бы тщательным он ни был.

## Связь с разработкой программного обеспечения

EVPI — это экономика спайка, пилота, A/B-теста и proof-of-concept. Из неё вытекают два практических правила:

- **Пилот стоит финансировать, только если решение может действительно измениться.** Если вы развернёте продукт в любом случае, независимо от результата пилота, EVPI = 0, и пилот — театр.
- **Ограничьте расходы на пилот величиной EVPI.** Ценность информации ограничена ценностью решения, которое она информирует.

Частичный EVPI (EVPPI) расширяет это на отдельные параметры: «сколько стоит точно установить именно цифру сэкономленного времени?» — это подсказывает, что должен измерять пилот. Об оценке *одного конкретного предлагаемого исследования* вместо устранения всей неопределённости см. [EVSI](../ожидаемая-ценность-выборочной-информации/).

## Подводные камни

- **Проведение пилотов без прикреплённого правила решения** — информация, которая не может изменить выбор, по определению бесполезна.
- **Игнорирование стоимости задержки сбора информации**: шестимесячный пилот задерживает 6 месяцев выгоды ([стоимость задержки](../стоимость-задержки/)); чистая ценность пилота = разрешённый EVPI − стоимость задержки − стоимость пилота.
- **Трактовка EVPI как прогноза.** Это верхняя граница ценности информации, а не оценка того, что даст конкретное исследование.
