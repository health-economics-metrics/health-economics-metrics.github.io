# عدم حاضری کی شرح (DNA)

DNA کی شرح بک کی گئی ملاقاتوں کا وہ فیصد ہے جہاں مریض نہ تو حاضر ہوتا ہے نہ ہی منسوخ کرتا ہے۔

## یہ کیوں اہم ہے

NHS England کے اعداد و شمار (2019): چھوٹی ہوئی GP ملاقاتیں سالانہ 1.5 کروڑ سے زیادہ — سالانہ **£21.6 کروڑ** سے زیادہ۔

## ریاضی

```
DNA کی شرح = DNA / بک کی گئی ملاقاتیں × 100
```

## حل شدہ مثال

ایک آؤٹ پیشنٹ ڈیپارٹمنٹ: سالانہ 200,000 ملاقاتیں، DNA کی شرح 8%۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہ ایک **شیڈولنگ-سسٹم کا مسئلہ** ہے۔
