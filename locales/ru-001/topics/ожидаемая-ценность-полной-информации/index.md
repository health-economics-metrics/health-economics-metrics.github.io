# Ожидаемая ценность полной информации (ОЦПИ)

ОЦПИ — это максимальная сумма, которую лицо, принимающее решение, должно заплатить, чтобы устранить неопределённость перед принятием решения — формальная цена фразы «давайте сначала проведём исследование».

## Почему это важно

Системы здравоохранения постоянно сталкиваются с выбором: принять решение сейчас на основе несовершенных доказательств или сначала профинансировать дополнительное исследование. ОЦПИ ставит цифру на второй вариант. Если ОЦПИ составляет £50 000, а предложенное испытание стоит £2 миллиона, принимайте решение сейчас. Если ОЦПИ составляет £20 миллионов, испытание — это выгодная сделка. Тот же вопрос — «должны ли мы сначала опробовать это, прежде чем развёртывать?» — возникает при каждом решении о корпоративном инструменте, и почти никто его не оценивает. Об оценке опциона расширить проект позже, а не опциона сначала собрать информацию, см. [Оценку реальных опционов](../оценка-реальных-опционов/).

## Расчёт

ОЦПИ — это разрыв между принятием решения с идеальным предвидением и принятием решения сейчас на основе ожиданий:

```
ОЦПИ = О_θ[ max_j ЧДС(j, θ) ]  −  max_j О_θ[ ЧДС(j, θ) ]

θ        = неопределённые параметры (с их совместным распределением)
ЧДС(j,θ) = чистая денежная стоимость варианта j при заданном θ
```

Первый член: среднее значение выплаты лучшего выбора по каждому возможному миру (вы всегда выбираете правильно). Второй член: выплата единственного варианта, который лучший в среднем (вы должны обязаться сейчас). ОЦПИ ≥ 0 всегда. Популяционная ОЦПИ умножается на количество затронутых решений. Вычисляется напрямую из выборок [ВАЧ](../вероятностный-анализ-чувствительности/).

## Разобранный пример

Развернуть ИИ-помощника документации для 5000 клиницистов или нет. Два мира:

```
Мир A (p = 0,6): помощник экономит 20 мин/день → ЧДС развёртывания = +£8 млн
Мир B (p = 0,4): помощник экономит ~0 (трение рабочего процесса) → ЧДС развёртывания = −£3 млн
ЧДС «не развёртывать» = £0 в обоих мирах.
```

Решайте сейчас: О[ЧДС развёртывания] = 0,6 × 8 − 0,4 × 3 = **+£3,6 млн** → развёртывать.

С полной информацией: в мире A выберите развёртывание (+£8 млн), в мире B выберите ничего (£0). Ожидаемая ценность = 0,6 × 8 + 0,4 × 0 = **£4,8 млн**.

```
ОЦПИ = 4,8млн − 3,6млн = £1,2 млн
```

Строгий 3-месячный пилот стоимостью £150 000, который существенно решает, в каком мире вы находитесь, определённо того стоит — и любой пилот, стоящий больше £1,2 млн, не стоит, каким бы тщательным он ни был.

## Связь с программной инженерией

ОЦПИ — это экономика исследовательского спринта, пилота, A/B-теста и подтверждения концепции. Она даёт два практических правила:

- **Пилот стоит финансировать только если решение может реально измениться.** Если бы вы развернули в любом случае, независимо от результата пилота, ОЦПИ = 0, и пилот — это театр.
- **Ограничьте расходы на пилот значением ОЦПИ.** Ценность информации ограничена ценностью решения, которое она информирует.

Частичная ОЦПИ (ОЦЧПИ) расширяет это на отдельные параметры: «чего стоит точно определить конкретно цифру сэкономленного времени?» — это говорит вам, что должен измерять пилот. Об оценке *одного конкретного предлагаемого исследования* вместо устранения всей неопределённости см. [EVSI](../ожидаемая-ценность-выборочной-информации/).

## Подводные камни

- **Проведение пилотов без прикреплённого правила решения** — информация, которая не может изменить выбор, по определению не имеет ценности.
- **Игнорирование стоимости задержки от сбора информации**: 6-месячный пилот задерживает 6 месяцев выгоды ([стоимость задержки](../стоимость-задержки/)); чистая ценность пилота = решённая ОЦПИ − стоимость задержки − стоимость пилота.
- **Отношение к ОЦПИ как к прогнозу.** Это верхняя граница ценности информации, а не оценка того, что даст конкретное исследование.
