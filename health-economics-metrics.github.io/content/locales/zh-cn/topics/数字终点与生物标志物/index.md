# 数字终点与生物标志物 (Digital Endpoints and Biomarkers)

数字生物标志物是通过传感器采集的客观生理或行为测量值（手机测得的步态速度、可穿戴设备测得的睡眠、加速度计测得的震颤）。数字终点则是把这类测量值提升为**试验结果**——用来证明治疗效果。从"设备发出的数据"晋升为"监管机构接受的证据"，需要经过一套明确规定的验证阶梯。

## 为什么重要

传统的试验终点是断续采集的（每 3 个月一次门诊访视），且成本高昂；数字终点则是连续的、生态化的（真实生活场景，而非门诊表现），且每次观测的成本低廉——它们能够缩小试验规模、更早检测到效果，并支持去中心化研究。问题在于验证：公认的框架（与 FDA 立场一致，含三大支柱）要求具备**验证/分析验证**（传感器能准确测量该物理量）、**临床验证**（该测量值确实反映了它所声称反映的临床状态），以及被证实的**具有意义的健康层面**（患者确实在意它所捕捉的内容）。缺少这三者之一的终点只是遥测数据，而非证据。

## 计算方法

```
分析验证：与参考标准的一致性（参见 wearable-validation.md ——
          MAPE、CCC、Bland-Altman）
临床验证：与临床锚点之间的相关性/区分度
          （已知组效度、对变化的响应性）
终点经济学：
  每患者年检测到的事件数（连续采集）vs 按访视采样
  试验检验效能：当访视间方差占主导时，连续测量可以
  缩减样本量——N ∝ σ²/Δ²，且 σ² 随密集采样而下降
```

## 算例

一项帕金森病试验，比较来自腕部传感器的步态速度与季度门诊评分：

```
门诊终点：  每位患者每年 4 次测量，日间噪声较大
数字终点：  每位患者每年约 200 次被动测量

密集采样使年度变化估计值的方差下降约 5 倍 →
在固定检验效能下，可检测的效应量改善约 √5 ≈ 2.2 倍，
等价于在相同假设检验下样本量可缩减约 40–60%。
按每位入组患者 £25,000 计算，减少 200 名患者
约等于每项试验节省 £5M——这正是验证投入
（本身或许需要 £1–2M）在赞助方整个管线中的商业理由。
```

## 与软件工程的关联

数字终点本质上是一门披着临床外衣的数据工程学科：**溯源与版本管理**（研究进行中途的算法更新会威胁可比性——这是[PCCP](../ai监管评估/)问题在试验中的呈现形式；应锁定版本并做桥接验证）；**缺失数据设计**（佩戴时间的缺口是有信息量的，而非随机的——参见[可穿戴设备验证](../可穿戴设备验证/)；插补方式本身就是一种科学主张）；以及**边缘/云端拆分决策**，它决定了原始信号在日后是否还能被恢复。从第一天起就把测量流水线当作受监管软件来对待（经过测试、有版本管理、有文档记录）的团队，能以低成本换取终点的可信度；在一条"快速迭代"的流水线上事后补做验证，正是数字终点项目走向失败的地方。

## 陷阱

- **把"与门诊结果相关"当作完整验证**：与一个本身有缺陷的门诊测量值相符，证明的是"继承了缺陷"，而非"真实性"；应针对那个有意义的健康层面进行验证。
- **新颖终点的监管风险**：一个前所未有的终点即便在科学上更优越，也仍可能导致申报失败——应尽早与监管机构沟通（资格认定项目是存在的）。
- **传感器与人群不匹配**：在年轻健康的手腕上完成验证，却部署给震颤和色素差异是 PPG 从未见过的老年患者。
- **特征漂移**：在新数据上重新训练步态算法，会在研究进行中途悄悄重新定义该终点。
