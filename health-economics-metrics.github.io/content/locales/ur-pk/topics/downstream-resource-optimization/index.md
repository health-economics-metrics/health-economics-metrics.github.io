# ڈاؤن اسٹریم وسائل کی اصلاح

ایک سینئر معالج کے لیے ایک گھنٹہ بچانا اکثر ایک پوری کثیر شعبہ جاتی ٹیم (MDT) کے لیے رکاوٹ کی تاخیر کو روکتا ہے۔

## یہ کیوں اہم ہے

صحت کی دیکھ بھال منظوری کی زنجیروں پر چلتی ہے۔

## ریاضی

```
رکاوٹ کھولنے کی قدر = Σ ڈاؤن اسٹریم کرداروں میں (آزاد رکاوٹ گھنٹے × اکائی قیمت)
```

## حل شدہ مثال

ایک وارڈ کے ڈسچارجز کے لیے ہر صبح مشیر کا جائزہ درکار ہے: سالانہ 1,460 بستر کے دن بچائے گئے۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہ کوڈ کا جائزہ، فن تعمیر کی منظوری ہے۔

## عام غلطیاں

- **غیر-رکاوٹ کی اصلاح کرنا۔**
