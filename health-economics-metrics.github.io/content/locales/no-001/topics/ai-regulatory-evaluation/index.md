# KI-regulatorisk evaluering

KI-regulatorisk evaluering vurderer om medisinske KI-systemer oppfyller juridiske og regulatoriske godkjenningskrav.

## Hvorfor det er viktig

Manglende regulatorisk godkjenning kan fullstendig blokkere innføringen av klinisk effektive KI-systemer.

## Matematikken

```
Kostnad ved regulatorisk vei = kostnad ved klinisk dokumentasjon + søknadsgebyrer + kostnad ved overvåking etter markedsføring
```

## Gjennomarbeidet eksempel

Et diagnostisk støtteverktøy klassifisert som klasse III SaMD (programvare som medisinsk utstyr): totale regulatoriske kostnader ≈ £800 000, 18 måneder til godkjenning.

## Kobling til programvareutvikling

Dokumentasjon fra [klinisk KI-evaluering](../clinical-ai-evaluation/) er en nøkkelfaktor for den regulatoriske søknaden.

## Fallgruver

- **Å fortsette utviklingen uten å fastsette den regulatoriske klassifiseringen tidlig.**
