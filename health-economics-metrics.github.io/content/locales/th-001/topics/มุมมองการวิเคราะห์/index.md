# มุมมองการวิเคราะห์

มุมมองการวิเคราะห์กำหนดว่าต้นทุนและผลประโยชน์ของใครที่นับรวมในการประเมินทางเศรษฐศาสตร์ — ผู้จ่ายเงิน ผู้ให้บริการ หรือสังคมโดยรวม

## ทำไมจึงสำคัญ

การวิเคราะห์เดียวกันสามารถให้คำตอบที่แตกต่างกันอย่างมากขึ้นอยู่กับมุมมองที่เลือก สิ่งที่ประหยัดเงินของผู้ให้บริการอาจย้ายต้นทุนไปยังผู้ป่วยหรือระบบอื่นเท่านั้น

## คณิตศาสตร์

ไม่มีสูตรเดียว; มุมมองกำหนดว่าต้นทุนและผลประโยชน์ใดที่รวมอยู่ในตัวเศษและตัวส่วนของการวิเคราะห์ความคุ้มทุนใดๆ

## ตัวอย่างที่คำนวณแล้ว

โปรแกรมดูแลที่บ้านประหยัดเงินให้โรงพยาบาล £500,000/ปี (มุมมองผู้ให้บริการ) แต่เพิ่มภาระให้ผู้ดูแลครอบครัวมูลค่า £200,000/ปี (มุมมองสังคม) — ผลลัพธ์สุทธิทางสังคมคือ £300,000 ไม่ใช่ £500,000

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการเพิ่มประสิทธิภาพสำหรับทีมเดียวในขณะที่ย้ายความซับซ้อนไปยังทีมอื่น — ต้นทุนทั้งหมดของระบบยังคงเท่าเดิมหรือเพิ่มขึ้น แม้ว่าตัวชี้วัดของทีมหนึ่งจะดีขึ้นก็ตาม

## ข้อผิดพลาดที่พบบ่อย

- **การเลือกมุมมองที่แคบเพื่อให้โครงการดูดีกว่าความเป็นจริง**
- **การผสมมุมมองต่างๆ เข้าด้วยกันโดยไม่ระบุอย่างชัดเจน**
