# कठोर नकद-मुक्तकारी बचत (घाटा बचाव)

कठोर नकद-मुक्तकारी बचत वे लाइन आइटम हैं जिन्हें एक अस्पताल आपके सॉफ़्टवेयर के कारण अगले महीने के बजट से सक्रिय रूप से **हटा** सकता है।

## यह क्यों महत्वपूर्ण है

कई NHS ट्रस्ट हर व्यय लाइन की गहन जाँच के साथ घाटा-सुधार योजनाओं के तहत काम करते हैं।

## गणित

```
कठोर बचत = टाली गई प्रीमियम शिफ्ट × (प्रीमियम दर − मूल दर)
          + टाले गए ओवरटाइम घंटे × ओवरटाइम प्रीमियम
```

## हल किया गया उदाहरण

एक बैंड 6 नर्स प्रशासनिक ओवरहेड में प्रति शिफ्ट ~1 घंटा खोती है।

```
टाला गया ओवरटाइम: सालाना ≈ £276,000
कठोर नकद कुल ≈ सालाना £416,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

एजेंसी प्रीमियम का इंजीनियरिंग समकक्ष संगठन की अपनी संकट खरीद है।
