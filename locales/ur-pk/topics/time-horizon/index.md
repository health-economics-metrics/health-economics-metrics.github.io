# وقت کی حد

وقت کی حد وہ مدت ہے جس کے اندر ایک تجزیہ قیمتوں اور اثرات کو شمار کرتا ہے۔

## یہ کیوں اہم ہے

ایک مختصر حد کا انتخاب دیر سے آنے والے فوائد (روک تھام) یا دیر سے آنے والی قیمتوں (دیکھ بھال) کو چھوڑ دیتا ہے۔

## ریاضی

```
خالص موجودہ قدر = Σ (t = 0 … T) [ (فائدہ_t − قیمت_t) / (1 + r)^t ]
```

## حل شدہ مثال

ایک الیکٹرانک نسخہ نظام کو نافذ کرنے میں £20 لاکھ خرچ ہوتے ہیں۔ 5 سالوں میں نیٹ صفر، 10 سالوں میں +£20 لاکھ۔

## سافٹ ویئر انجینئرنگ سے تعلق

**1 اسپرنٹ میں ماپا گیا ٹول کی تشخیص** سیکھنے کے منحنی خط کی کمی کو منظم طریقے سے چھوڑ دیتا ہے۔
