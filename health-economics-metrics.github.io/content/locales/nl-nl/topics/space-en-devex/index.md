# SPACE en DevEx

SPACE en DevEx zijn frameworks om ontwikkelaarsproductiviteit **multidimensionaal** te meten.

## Waarom het ertoe doet

Beide frameworks bevatten dezelfde les die het gezondheidsuitkomstenonderzoek decennia geleden al leerde.

## De wiskunde

```
SPACE-regel: ≥ 3 dimensies, ≥ 1 perceptuele + ≥ 1 systeemmetriek
```

## Uitgewerkt voorbeeld

Een platformteam rechtvaardigt een DevEx-investering voor 300 ontwikkelaars.

## Verbinding met software-engineering

Dit document is *precies* de softwarekant; de overdracht stroomt richting gezondheidseconomie.

## Valkuilen

- **Reductie tot één enkele metriek.**
