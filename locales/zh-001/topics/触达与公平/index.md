# 触达与公平

RE-AIM——触达（Reach）、有效性（Effectiveness）、采纳（Adoption）、实施（Implementation）、维持（Maintenance）——是判断一项干预措施*人群层面*影响力的标准框架。其核心算式是：**公共卫生影响 ≈ 触达率 × 有效性**。数字化工具则额外带来了一个公平维度：数字鸿沟意味着触达率本身就系统性地不均衡，而以数字化为主的服务交付方式，反而可能扩大它本想缩小的健康差距。

## 为何重要

将RE-AIM应用于移动健康（mHealth）的系统性综述，一致发现了同一种特征：触达与采纳表现强劲，**有效性与维持表现薄弱**——应用容易迅速传播，也容易迅速衰退。对一个国家医疗服务体系而言，这意味着一款单用户表现亮眼的产品，可能是一项糟糕的人群层面投资；反之亦然：一款效果适中、却能触达数百万人的工具，其产出可能超过一款效果出色、却只能触达数千人的工具（参见[HALE](../健康调整预期寿命/)的算术）。公平并非一项附带约束，而是一个价值驱动因素：数字排斥往往与年龄、贫困程度、残障状况和语言能力高度相关——而这些恰恰正是承载着最多可治疗负担的人群——因此，那名处于边缘、被排斥在外的用户，其潜在获益往往*高于*平均水平。 关于衡量社会经济健康不平等的正式统计量，见[集中指数](../集中指数/)。

## 计算方法

```
人群影响 ≈ 触达率 × 有效性
  触达率  = 参与人数 / 符合条件人群数（参见activation-and-uptake.md）
  有效性  = 参与者中的真实世界效果（按留存加权——
           参见retention-and-churn.md）

按公平维度分层的版本：
  群体g的影响 = 触达率_g × 有效性_g，按贫困五分位数/
  年龄段/语言群体分别报告
  公平差距 = 最高五分位数群体的影响 − 最低五分位数群体的影响

分布性成本效果分析：按接受者群体对QALY施加公平权重——
处境最差群体所获得的一个QALY，计数应更高（这是一种正日益
成为主流的卫生技术评估扩展方法）。
```

## 实例演算

某数字化糖尿病预防项目，以两种方式呈现：

```
汇总口径：触达率12%，每名参与者效果0.02 QALY → 每名符合条件人员0.0024 QALY

分层口径（按贫困五分位数）：
  第1分位（最不贫困）：触达率22%，效果0.02 → 0.0044
  第5分位（最贫困）：  触达率4%， 效果0.025 → 0.0010

该项目为最不贫困群体所交付的健康价值是最贫困群体的4.4倍——
而第5分位群体的人均效果反而更高（改善空间更大）。一项
辅助数字化方案（电话辅导+社区接入渠道），每名第5分位参与者
成本增加20%，却能将该群体触达率提升至12%，使其影响力
提高至三倍，同时也改善了汇总数字——在这里，公平投资
正是效率投资本身。
```

## 与软件工程的联系

触达率在很大程度上是一个工程层面的产物：设备与操作系统的最低要求、带宽假设、语言支持、无障碍合规性（WCAG）、身份验证门槛，以及仅限应用商店的分发方式，每一项都会把部分人群排除在分母之外——而且通常是不可见的，因为被排斥的用户根本不会出现在分析数据中。能够推动公平的工程实践包括：测量*分母*本身（对符合条件的人群进行埋点，而非仅仅统计用户）；为老旧设备与不良网络连接预算相应的性能表现；将辅助数字化路径（电话、短信、自助终端）作为一等公民的流程来交付，而非令人羞于使用的备选渠道；并按公平维度对每一块仪表盘指标进行分层——未经分层的平均值，正是不公平藏身之处（[GDS使用率](../GDS服务指标/)也带有同样的警示）。

## 陷阱

- **有效性只按完成者报告，影响力却按整个人群主张**——触达率这一项被悄悄丢弃了。
- **把公平当作事后审计**，而非设计输入；事后补救触达率，远比一开始就为其设计要昂贵得多。
- **对"维持"这一环节的遗忘**：这是移动健康领域中RE-AIM最薄弱的维度——影响力的主张常常超出了证据所覆盖的时间范围。
- **仅限数字渠道的节省**，实际上是把成本转嫁给了被排斥的用户与一线员工（参见[GDS服务指标](../GDS服务指标/)）。
