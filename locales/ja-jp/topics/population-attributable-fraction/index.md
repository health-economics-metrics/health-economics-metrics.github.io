# 集団寄与割合(PAF)

PAFは、集団における疾患やアウトカムの負担のうち、特定のリスク因子への曝露に帰せられる割合であり、曝露を完全に取り除いた場合に消える分です。「このリスク因子はオッズを2倍にする」という情報を、ある曝露にどれだけの症例とコストを追う価値があるのかという、保健医療の発注者が実際に計画の材料にできる集団レベルの数値に変換します。

## なぜ重要か

Levinは1953年に、狭く具体的な問いに答えるためにPAFを導入しました。もし誰も喫煙しなければ、肺がんはどれだけ減るか、という問いです。同じ算術が今では、たばこや肥満の戦略から、WHOの世界疾病負荷研究のリスク因子ランキングまで、国の予防計画を至るところで規模づけています。相対リスクだけでは影響について何も語らないからです。リスク因子は稀なイベントのオッズを2倍にしても集団の疾病負担をほとんど動かさないことがあり、ありふれたイベントのオッズをわずかに高めるだけで、症例の大きな割合を占めることもあります。PAFは「リスク因子Xは危険だ」を「リスク因子Xを取り除けば、年間これだけの症例を防げる」に変えるもので、予防プログラムのビジネスケースが実際に必要とする数値です。その数値が得られたときに、それに基づいて行動するのにどれだけかかるかについては、[予防の経済学](../prevention-economics/)を参照してください。

## 数式

```
PAF = 曝露者の有病率 × (相対リスク − 1) / (1 + 曝露者の有病率 × (相対リスク − 1))

曝露者の有病率 = リスク因子に曝露された集団の割合(0〜1)
相対リスク     = 曝露者対非曝露者でのアウトカムのリスク(例: 2.5 = 2.5倍)

寄与する症例数 = 総症例数 × PAF
```

PAFは曝露の有病率と相対リスクの両方とともに上昇します。非常にありふれた曝露に伴う、ほどほどに高い相対リスク(たとえば1.5倍)は、稀な曝露に伴う劇的な相対リスク(たとえば5倍)より大きなPAFを生み出しうるのです。これこそが、相対リスクとは別の数値として存在する理由のすべてです。

## 計算例

あるリスク因子が集団の30%に存在し(`曝露者の有病率 = 0.3`)、アウトカムのリスクを2.5倍に高めます(`相対リスク = 2.5`)。

```
PAF = 0.3 × (2.5 − 1) / (1 + 0.3 × (2.5 − 1))
    = 0.3 × 1.5 / (1 + 0.3 × 1.5)
    = 0.45 / 1.45
    ≈ 0.3103 (31.0%)

集団で年間1,000症例の場合:
寄与する症例数 = 1,000 × 0.3103 ≈ 年間310症例
```

このアウトカムの年間負担の3分の1弱が曝露に帰せられます。曝露を完全に取り除けば(理論上の上限で、実際の介入で曝露を100%取り除けるものはありません)、毎年1,000症例のうち約310症例を防げることになります。

## ソフトウェア工学との関連

PAFは、「インシデント量のうち、この1つの根本原因に帰せられる割合はどれだけか」という問いの疫学版です。すべてのインシデントを同じように直す価値があるものとして扱うのではなく、特定の種類のデプロイや依存関係を本番インシデント全体に対して規模づけるときにチームが立てるのと同じ形の問いです。デプロイの大部分に存在し、インシデントを引き起こす相対リスクはそれほど高くない根本原因のカテゴリは、まれで相対リスクの高いカテゴリよりも、エンジニアリングの労力をどこに最初に使うかという点で優先されることがあります。まさにPAFの洞察を、置き換えて表したものです。

## 落とし穴

- **リスク因子をまたいでPAFを合計すること**: 同じアウトカムに影響する複数の因子のPAFは100%にはなりません。因子が相互作用して因果経路を共有するため、合計が100%を超えることさえあります。各PAFは「この因子だけが取り除かれたら」として扱い、総リスクの分割として扱ってはいけません。
- **相対リスクを集団間で移植すること**: ある集団で推定された相対リスク(ベースラインの曝露有病率や交絡因子が異なる)を、別の集団の曝露有病率に適用すると、誤解を招くPAFが計算されます。
- **PAFと曝露者における寄与リスクの混同**: PAFは集団レベルで曝露の有病率に依存します。曝露者における寄与リスクは個人レベルで、依存しません。両者は別の問いに答えるものであり、一方を引用して他方の問いに答えてはいけません。
