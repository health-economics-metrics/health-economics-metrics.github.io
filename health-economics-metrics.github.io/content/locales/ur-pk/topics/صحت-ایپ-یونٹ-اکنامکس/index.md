# صحت ایپ یونٹ اکنامکس

صارف صحت کی مصنوعات کی تجارتی ریاضی: گاہک حاصل کرنے کی قیمت (CAC)، زندگی بھر کی قدر (LTV)، اور آجر-مارکیٹ میں **ROI اور VOI** (سرمایہ کاری پر قدر) کے درمیان فرق۔

## یہ کیوں اہم ہے

صحت کی ایپس ایک ساختی دباؤ کا سامنا کرتی ہیں: حصول مہنگا ہے جبکہ برقراری کسی بھی سافٹ ویئر ورٹیکل کی بدترین ہے (30 دنوں میں ~90% ترک)۔

## ریاضی

```
CAC = فروخت + مارکیٹنگ کا خرچ / نئے ادائیگی کرنے والے گاہک
LTV = ARPU × اوسط زندگی بھر = ARPU / چرن کی شرح
```

## حل شدہ مثال

ایک B2C نیند ایپ: £6.99/ماہ، ماہانہ چرن 18%: LTV:CAC ≈ 1.0 — غیر مستحکم۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرنگ کے انتخاب تناسب کے دونوں اطراف کا تعین کرتے ہیں۔
