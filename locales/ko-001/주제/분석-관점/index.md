# 분석 관점

관점은 경제적 분석에서 *누구의* 비용과 편익이 계산되는지를 정의합니다: 지불자, 제공자, 또는 사회. 동일한 개입이 한 관점에서는 훌륭해 보이지만 다른 관점에서는 끔찍해 보일 수 있습니다.

## 왜 중요한가

모든 경제적 평가는 관점을 미리 선언해야 합니다. 관점이 어떤 항목이 존재하는지를 결정하기 때문입니다:

- **지불자 관점**: 지불자가 상환하는 비용만.
- **제공자 관점**: 내부 제공 비용, 직원 시간, 시설.
- **사회적 관점**: 환자의 시간, 이동, 가족의 비공식 돌봄을 포함한 모든 것.

NICE의 기준 사례는 비용에 대해 **NHS 및 개인사회서비스(PSS)** 관점을 사용합니다.

## 수식

```
포함된 비용/편익 범주 = f(관점)
```

## 계산 예시

증상 확인 앱이 연간 10,000건의 GP 방문을 자가 관리로 전환합니다: 지불자 편익 £420,000/년; 사회적 순편익 £120,000/년.

## 소프트웨어 공학과의 연관성

도구와 플랫폼 ROI에도 관점이 있습니다.
