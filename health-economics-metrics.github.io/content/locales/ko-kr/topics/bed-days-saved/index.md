# 절약된 병상일

병상일은 한 환자가 하루 동안 병원 침상 하나를 차지하는 것입니다. "절약된 병상일"은 NHS 디지털 비즈니스 케이스의 주력 편익이며, 가장 자주 과대평가되는 것입니다.

## 왜 중요한가

병상은 급성 치료의 제약적 병목입니다. 병상일을 해방시키는 개입의 가치는 해방된 병상에 무슨 일이 일어나는지에 전적으로 달려 있습니다.

## 수식

```
절약된 병상일 = 영향받은 환자 × Δ 재원일수

가치는 해방된 용량의 사용에 따라 달라집니다:
  선택적 활동으로 다시 채워짐 → 가치 = 활동 수입
  병동 폐쇄/축소 → 가치 = 해방된 직원+운영비(현금)
  여유분으로 흡수됨 → 가치 ≈ 한계(호텔) 비용만
```

## 계산 예시

원격 모니터링 "가상 병동"이 연간 600명의 환자가 2일 일찍 귀가할 수 있게 합니다: 절약된 병상일 1,200일.

- **순진한 주장**: £480,000. 병동이 폐쇄되지 않는 한 틀렸습니다.
- **정직한 주장**: **£240만의 추가 자금 지원 활동**.

## 소프트웨어 공학과의 연관성

"절약된 서버 일수"는 같은 방식으로 작동합니다.

## 함정

- 한계 용량의 **평균비용 평가.**
- **이중 계산.**
