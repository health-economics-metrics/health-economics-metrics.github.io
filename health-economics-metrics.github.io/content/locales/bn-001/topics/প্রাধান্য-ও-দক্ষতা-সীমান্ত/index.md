# প্রাধান্য ও দক্ষতা সীমান্ত

একটি বিকল্প **প্রভাবিত** যদি অন্য একটি বিকল্প কম খরচ করে *এবং* বেশি প্রদান করে। **দক্ষতা সীমান্ত** হল যা প্রভাবিত বিকল্পগুলি বাদ দেওয়ার পরে অবশিষ্ট থাকে: পছন্দগুলির সেট যেখানে আরও পেতে আরও অর্থ প্রদান করতে হয়।

## কেন এটি গুরুত্বপূর্ণ

প্রান্তসীমা বা বাজেট নিয়ে যেকোনো বিতর্কের আগে, স্বাস্থ্য প্রযুক্তি মূল্যায়ন প্রথমে এমন বিকল্প বাদ দেয় যা কারো কখনো বেছে নেওয়া উচিত নয়। প্রতিটি বিকল্পকে একটি খরচ-বনাম-প্রভাব সমতলে প্লট করা এবং সীমান্ত আঁকা একটি পাঁচ-মিনিটের ব্যায়াম যা নিয়মিতভাবে অর্ধেক সংক্ষিপ্ত তালিকা মেরে ফেলে। ইনক্রিমেন্টাল তুলনা ([ICER](../ইনক্রিমেন্টাল-খরচ-কার্যকারিতা-অনুপাত/)) তারপর শুধুমাত্র *সীমান্ত বরাবর* গণনা করা হয়, প্রতিটি বিকল্প পরবর্তী-সস্তা অ-প্রভাবিতের বিরুদ্ধে — যখন ভালো মধ্যবর্তী বিকল্প বিদ্যমান তখন কখনো "কিছুই না করা"-র বিরুদ্ধে নয়।

## গণনা

```
কঠোর প্রাধান্য:      A প্রভাবিত করে B যদি খরচ_A ≤ খরচ_B এবং প্রভাব_A ≥ প্রভাব_B
                     (কমপক্ষে একটি কঠোর অসমতা সহ)

বর্ধিত প্রাধান্য:    B বাদ দেওয়া হয় যদি A এবং C-র মিশ্রণ প্রতি পাউন্ডে বেশি
                     প্রভাব অর্জন করে — সনাক্ত করা হয় যখন সীমান্ত উপরে
                     যাওয়ার সাথে সাথে ICER কমে। বৈধ সীমান্ত ICER অবশ্যই
                     বৃদ্ধি পেতে হবে।
```

পদ্ধতি: প্রভাব অনুযায়ী বিকল্পগুলি সাজান; কঠোরভাবে প্রভাবিতগুলি সরান; প্রতিবেশীদের মধ্যে জোড়াভিত্তিক ICER গণনা করুন; যেকোনো বিকল্প সরান যার ICER পরবর্তী আরও-কার্যকর বিকল্পের চেয়ে বেশি (বর্ধিত প্রাধান্য); ICER একঘেয়েভাবে বৃদ্ধি না পাওয়া পর্যন্ত পুনরাবৃত্তি করুন।

## বিস্তারিত উদাহরণ

মিস করা অ্যাপয়েন্টমেন্ট কমানোর জন্য চারটি বিকল্প (প্রভাব = পুনরুদ্ধারকৃত অ্যাপয়েন্টমেন্ট/বছর):

```
বিকল্প           খরচ/বছর    পুনরুদ্ধারকৃত
কিছুই না         £0         0
SMS রিমাইন্ডার    £20,000    2,000
ফোন কল           £120,000   2,200
SMS + AI ট্রায়াজ £90,000    3,500
```

ফোন কল **কঠোরভাবে প্রভাবিত** SMS + AI ট্রায়াজ দ্বারা (বেশি খরচ, কম পুনরুদ্ধার)। সীমান্ত: কিছুই না → SMS → SMS + AI।

```
ICER(SMS বনাম কিছুই না)   = 20,000 / 2,000  = প্রতি পুনরুদ্ধারকৃত অ্যাপয়েন্টমেন্টে £10
ICER(SMS+AI বনাম SMS)     = (90,000 − 20,000) / (3,500 − 2,000) = প্রতি অ্যাপয়েন্টমেন্টে £46.67
```

বর্ধমান ICER → বৈধ সীমান্ত। প্রতি পুনরুদ্ধারকৃত হাসপাতাল অ্যাপয়েন্টমেন্টে ~£160 সাশ্রয়ে (দেখুন [অনুপস্থিতি হার](../অনুপস্থিতি-dna-হার/)), উভয় সীমান্ত ধাপই নেওয়ার যোগ্য; ফোন-ব্যাংক প্রস্তাব কখনো কমিটিতে পৌঁছানো উচিত নয়।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

যেকোনো টুলিং সিদ্ধান্তের জন্য একই চার্ট তৈরি করুন: এক অক্ষে বছরে খরচ, অন্য অক্ষে পরিমাপিত ফলাফল (সঞ্চিত ঘণ্টা, এড়ানো ঘটনা, সক্ষম স্থাপনা)। সীমান্তের উপরে-এবং-বামে থাকা পয়েন্টগুলি কেউ বাজেট নিয়ে তর্ক করার আগে বাদ দেওয়া হয়। এটি বিক্রেতা নির্বাচনকে ফিচার-চেকলিস্ট বিতর্ক থেকে "আপনি প্রভাবিত; মিটিং শেষ"-এ পুনর্গঠন করে। এটি একটি প্রান্তিক লাভের জন্য সবচেয়ে ব্যয়বহুল বিকল্প কেনার সাধারণ এন্টারপ্রাইজ প্যাটার্নও উন্মোচিত করে — বৈধ শুধুমাত্র যদি ইনক্রিমেন্টাল ইউনিট প্রতি ইনক্রিমেন্টাল মূল্য এমন একটি হয় যা সংস্থা জেনেশুনে প্রদান করবে।

## ঝুঁকি

- **সীমান্তে পরবর্তী বিকল্পের পরিবর্তে বেসলাইনের সাথে সবকিছু তুলনা করা** — এটি সস্তা কাছাকাছি-সমতুল্য লুকিয়ে ব্যয়বহুল বিকল্পগুলিকে চাটুকারিতা করে।
- **একক-মাত্রিক প্রভাব স্কোর** যা গুরুত্বপূর্ণ তা লুকায়; যদি দুটি ফলাফল গণনা করে, হয় তাদের প্রতিরক্ষাযোগ্যভাবে একত্রিত করুন (দেখুন [খরচ-উপযোগিতা বিশ্লেষণ](../খরচ-উপযোগিতা-বিশ্লেষণ/)) অথবা দুটি সীমান্ত দেখান।
- **অনিশ্চয়তা ভুলে যাওয়া**: সীমান্তের কাছাকাছি বিকল্পগুলি [সংবেদনশীলতা বিশ্লেষণ](../সংবেদনশীলতা-বিশ্লেষণ/)-এর অধীনে স্থান পরিবর্তন করতে পারে।
