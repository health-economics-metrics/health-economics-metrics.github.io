# Förebyggande ekonomi

Förebyggande ekonomi undersöker varför förebyggande interventioner nästan alltid är kostnadseffektiva men sällan faktiskt sparar pengar för systemet som helhet.

## Varför det är viktigt

Beslutsfattare hävdar ofta att förebyggande arbete sparar pengar, men de flesta förebyggande åtgärder tillför hälsa till ett rimligt pris utan att sänka de totala utgifterna. Innan man kostnadsberäknar ett förebyggande program besvarar [populationsattribuerbar andel](../populationsattribuerbar-andel/) först dimensioneringsfrågan — hur stor del av den avsedda sjukdomsbördan som riskfaktorn programmet adresserar rimligen skulle kunna eliminera.

## Matematiken

```
Kostnadsbesparande: Kostnad(förebyggande) < Kostnad(undviken sjukdom)
Kostnadseffektivt men inte kostnadsbesparande: Kostnad(förebyggande) > Kostnad(undviken sjukdom), men ICER < tröskel
```

## Genomarbetat exempel

Ett rökavvänjningsprogram kostar £200/deltagare och sparar i genomsnitt £150 i framtida vårdkostnader per deltagare, men ger 0,1 QALY — kostnadseffektivt (£500/QALY) men inte kostnadsbesparande.

## Koppling till mjukvaruutveckling

Liknar att investera i automatiserad testning: det tillför värde (färre buggar) till ett rimligt pris, men sparar sällan faktiskt pengar på de totala utvecklingskostnaderna.

## Fallgropar

- **Att blanda ihop "kostnadseffektiv" och "kostnadsbesparande" i affärscase.**
- **Att bara räkna direkta vårdkostnader och ignorera bredare samhällsnyttor.**
