# Twarde oszczędności uwalniające gotówkę (obrona przed deficytem)

Twarde oszczędności uwalniające gotówkę to pozycje budżetowe, które są rzeczywiście usuwane — pieniądze, których system już nie wydaje — w przeciwieństwie do teoretycznych zysków wydajności.

## Dlaczego to ważne

Gdy organizacja musi bronić deficytu przed organami nadzorczymi, liczy się tylko twarde uwolnienie gotówki; nieuwalniające gotówki "oszczędności" są ignorowane przez organy nadzoru finansowego.

## Matematyka

```
Twarda oszczędność = rzeczywista redukcja pozycji budżetowej (zweryfikowana w sprawozdaniach finansowych)
```

## Rozwiązany przykład

Zamknięcie fizycznego obiektu i usunięcie związanych z nim kosztów wynajmu £500 000/rok to twarda oszczędność; twierdzenie, że pracownicy "pracują wydajniej" bez redukcji personelu, nie jest.

## Powiązanie z inżynierią oprogramowania

Przypomina rzeczywiste anulowanie usługi chmurowej w przeciwieństwie do twierdzenia o "poprawionej wydajności" bez obniżenia rachunku.

## Pułapki

- **Przedstawianie oszczędności nieuwalniających gotówki jako twardych oszczędności organom nadzoru finansowego.**
- **Nieuwzględnianie kosztów przejścia przy realizacji oszczędności.**

## Źródła

- HM Treasury, Green Book supplementary guidance.
- NHS England, financial recovery guidance.
