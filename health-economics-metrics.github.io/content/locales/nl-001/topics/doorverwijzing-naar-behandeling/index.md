# Doorverwijzing naar behandeling (RTT)

RTT meet de tijd van eerste doorverwijzing tot start van behandeling, met de 18-wekennorm als de belangrijkste nationale prestatie-indicator.

## Waarom het ertoe doet

RTT is in wezen een leveringsleadtime-metriek toegepast op patiëntenzorg — hoe lang duurt het voordat waarde (behandeling) wordt geleverd na een verzoek (doorverwijzing).

## De wiskunde

```
RTT-naleving = Aantal patiënten behandeld binnen 18 weken / Totaal aantal patiënten op de wachtlijst × 100%
```

## Uitgewerkt voorbeeld

Een specialisme met 5.000 patiënten in het RTT-traject waarvan 4.100 binnen 18 weken worden behandeld: 82% naleving, onder de nationale norm van 92%.

## Verbinding met software-engineering

Direct analoog aan [DORA-leadtime](../dora-metrieken/) — de tijd van commit (doorverwijzing) tot levering (behandeling).

## Valkuilen

- **Klokstops (patiëntinitiatief) verkeerd toepassen om nalevingscijfers te vertekenen.**
- **Alleen op het gemiddelde letten terwijl de staart van de verdeling het echte probleem is.**
