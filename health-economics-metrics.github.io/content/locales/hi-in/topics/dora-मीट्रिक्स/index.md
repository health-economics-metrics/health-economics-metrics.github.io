# DORA मीट्रिक्स

DORA मीट्रिक्स सॉफ़्टवेयर डिलीवरी प्रदर्शन के चार माप हैं — डिप्लॉयमेंट आवृत्ति, परिवर्तन के लिए लीड टाइम, परिवर्तन विफलता दर, और पुनर्प्राप्ति समय।

## यह क्यों महत्वपूर्ण है

DORA के एक दशक के शोध इन मीट्रिक्स को संगठनात्मक प्रदर्शन से जोड़ते हैं।

## गणित

```
लीड टाइम = t(डिप्लॉय) − t(कमिट), माध्यिका
```

## हल किया गया उदाहरण

एक ट्रस्ट की रोगी-प्रवाह सॉफ़्टवेयर टीम, पहले/बाद:

```
                    पहले       बाद
डिप्लॉय             मासिक      साप्ताहिक
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यह *है* सॉफ़्टवेयर पक्ष — DORA मीट्रिक्स अस्पताल के परिचालनात्मक मीट्रिक्स का अलग पहनावा हैं।
