# Aktywacja i adopcja

Aktywacja mierzy, kiedy nowi użytkownicy po raz pierwszy doświadczają podstawowej wartości aplikacji; adopcja mierzy, jaki odsetek populacji docelowej rzeczywiście zaczyna korzystać z usługi.

## Dlaczego to ważne

Niska adopcja czyni nawet doskonale zaprojektowane interwencje bezsensownymi na poziomie populacji.

## Matematyka

```
Wskaźnik adopcji = liczba aktywnych użytkowników / populacja docelowa × 100%
```

## Rozwiązany przykład

Program zdalnego monitorowania ciśnienia krwi: populacja docelowa 10 000, aktywni użytkownicy 2400 = wskaźnik adopcji 24%.

## Powiązanie z inżynierią oprogramowania

Punkt wejścia dla [wskaźników zaangażowania](../wskaźniki-zaangażowania/) i ściśle powiązany z [zasięgiem i sprawiedliwością](../zasięg-i-sprawiedliwość/).
