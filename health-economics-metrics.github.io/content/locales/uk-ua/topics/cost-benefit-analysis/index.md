# Аналіз витрат і вигод (CBA)

Аналіз витрат і вигод перетворює як витрати, так і вигоди в грошову цінність, дозволяючи безпосередньо розрахувати чисту теперішню вартість.

## Чому це важливо

CBA дозволяє порівняння між секторами (охорона здоров'я проти освіти проти інфраструктури), оскільки все виражається в одній одиниці: грошах.

## Математика

```
NPV = Σ(t=0 до горизонту) (Вигоди_t − Витрати_t) / (1+r)^t
```

## Розібраний приклад

Урядова профілактична програма з теперішньою вартістю витрат £10 мільйонів та теперішньою вартістю вигод (уникнені витрати на охорону здоров'я плюс виграш продуктивності) £15 мільйонів: NPV = +£5 мільйонів.

## Зв'язок з інженерією програмного забезпечення

Подібно до обґрунтування інвестицій у платформу шляхом перетворення всіх переваг (швидкість, надійність, зменшення інцидентів) у оцінену грошову цінність.

## Підводні камені

- **Перетворення цінності здоров'я в гроші зі спірними припущеннями без їх зазначення.**
- **Пропуск неринкових вигод (наприклад, добробуту), які важко оцінити.**
