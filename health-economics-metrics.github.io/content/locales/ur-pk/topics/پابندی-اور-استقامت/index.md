# پابندی اور استقامت

پابندی یہ ہے کہ اصل استعمال مقررہ استعمال سے کتنا میل کھاتا ہے۔ استقامت یہ ہے کہ بند ہونے سے پہلے استعمال کتنی دیر تک جاری رہتا ہے۔

## یہ کیوں اہم ہے

ادا کنندگان پہلے سے ہی ان اعداد پر چلتے ہیں: PDC ≥80% US Medicare Star Ratings میں شامل ہوتا ہے۔

## ریاضی

```
MPR = Σ دنوں کی فراہمی / مدت میں دن × 100
PDC = فراہمی سے احاطہ کردہ دن / مدت میں دن × 100
```

## حل شدہ مثال

ایک ڈیجیٹل CBT-برائے-بے خوابی پروڈکٹ: فی QALY قیمت ≈ £26,300۔

## سافٹ ویئر انجینئرنگ سے تعلق

دو اصطلاحات ایک تصور میں ملتی ہیں: سافٹ ویئر اینالیٹکس اور کلینیکل فارمیسی دونوں ایک مداخلت کے سامنے آنے کی پیمائش کر رہے ہیں۔
