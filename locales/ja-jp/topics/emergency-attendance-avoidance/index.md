# 救急受診の回避

救急受診回避は、上流の介入 — トリアージアプリ、遠隔モニタリング、バーチャル病棟、緊急ケアへの振り向け直し — によって防がれたED(救急)受診と緊急入院を数えます。これは「私たちは早く発見した」を費用計算された主張に変換します。

## なぜ重要か

救急ケアはシステムの中で最も高価な日常的な現場であり(ED受診の単位費用はNational Cost Collection/PSSRUの数値によると£250〜£400の範囲、緊急入院は数千ポンド)、EDの混雑は救急車の遅延や選択的処置のキャンセルへと波及します。上流で安全に需要を解決するもの何であれ — セルフケアのアドバイス、当日のプライマリケア、地域の対応 — は、システムが最もストレスを受けているポイントで容量を買います。これは、症状チェッカー、111式トリアージサービス、そして[遠隔患者モニタリングの経済学](../remote-patient-monitoring-economics/)の標準的な便益項目です。

## 数式

```
回避された受診 = 人口 × (ベースライン率 − 介入後の率)
総節約         = 回避された受診 × 受診1件あたりの単位費用
                (+ 回避された入院 × 入院費用、別途計上)

正味節約       = 総節約 − 介入費用 − 新しい経路利用の費用
                (振り向けられた需要は無料ではない:111への電話、GPの枠、
                 バーチャル病棟の1日、それぞれに単位費用がある)
```

因果的な主張には比較対象が必要です:受診率は季節によってトレンドと変動があるため、前後比較だけでは何も証明できません。

## 計算例

3,000人の高リスク患者向けのCOPD遠隔モニタリングサービス。マッチさせた対照群による評価は、増悪関連のED受診が患者1人年あたり0.9から0.7に、緊急入院が0.5から0.42に減少することを示します。

```
回避された受診 = 3,000 × 0.2  = 600 × £300   = £180,000
回避された入院 = 3,000 × 0.08 = 240 × £3,800 = £912,000
総額                                          年間£1,092,000

費用:モニタリングサービス£600,000;追加の地域看護師の対応£150,000
正味 ≈ 年間+£342,000 — 加えて、より早く治療された増悪のQALYの獲得。
```

入院の項目が支配的であることに注目してください:受診回避だけでモニタリングサービスの費用を賄えることはめったにありません;お金があるのは*入院*回避です。

## ソフトウェア工学との関連

これは**インシデント回避の経済学**です。観測可能性、カナリアデプロイ、早期警告システムの価値は、回避された「救急受診」 — ページング、対策室、Sev-1 — であり、それぞれに全負担費用(エンジニア時間×時給+顧客への影響)があります。同じモデリングのルールが当てはまります:新しい上流の経路の費用を差し引く(アラートのトリアージは無料ではない)、代替に注意する(インシデントを防がずに作業を生み出すアラートは、健康ではなく健康不安です)、そして対照群で反実仮想を証明する(チームのインシデント率は、ED受診とまったく同じように、トレンドがあり平均に回帰します)。

## 落とし穴

- **平均への回帰**:悪い年に基づいて選ばれた高リスクコホートは、治療なしでも改善します;マッチさせた対照群または段階的導入デザインが不可欠です。
- **供給誘発需要**:簡単なデジタルトリアージは、ED受診の割合を減らしながらも、総接触数を*増やす*ことがあります(助けを求める閾値が下がるため) — システム全体の費用を数えてください。
- EDの固定費が下がらないのに**受診を平均費用で評価すること** — [限界費用と平均費用](../marginal-vs-average-cost/)を参照してください。
