# 人才留任

人才留任經濟學量化的是人員流失給一個醫療系統帶來的成本——招聘、入職培訓、空缺期覆蓋——從而也量化了能減輕行政性職業倦怠的軟體究竟值多少錢。反覆性的行政資料錄入工作所造成的職業倦怠，是NHS員工流失與病假缺勤的主要驅動因素之一。

## 為何重要

一名臨床人員離職時，信託機構要為此三次付費：招聘替代人選（廣告、中介費、面試）、為其提供入職培訓（數月生產力下降、需要督導），以及在此期間覆蓋該空缺——通常以中介或臨時醫師的形式，費率為在職Agenda for Change標準費率的2–3倍（參見[可規避的外包成本](../可規避的外包成本/)與[硬性現金釋放型節省](../硬性現金釋放型節省赤字防線/)）。由於人員流失的成本是真實的現金支出，留任率的改善是財務總監少數能夠真正入賬的人力資源效益之一。行政摩擦始終位列臨床職業倦怠最常被提及的驅動因素前列，這使其成為一項軟體可以解決的成本。

## 計算方法

```
每名離職者的成本 = 招聘成本 + 入職/生產力爬坡成本
                + 空缺覆蓋溢價 × 空缺持續時長

年度流失成本 = 員工總數 × 流失率 × 每名離職者的成本

軟體的價值   = 員工總數 × Δ流失率 × 每名離職者的成本
             + 病假缺勤減少量 × 每日覆蓋成本
```

這條因果鏈條包含兩個需要分別估計的環節——軟體 → 職業倦怠/摩擦，以及職業倦怠 → 人員流失——因此二者都需要證據支撐（前後對比的員工調查；已發表的職業倦怠-流失關聯研究），並應保持所主張的Δ值適度保守。

## 實例演算

某信託機構僱有1,200名護士；年流失率11%。每名離職者的成本：

```
招聘 ≈ £4,500；入職/爬坡 ≈ £6,000
空缺覆蓋：4個月 × 0.6全職當量，由中介溢價覆蓋 ≈ £8,000
合計 ≈ 每名離職者£18,500
基線流失成本 = 1,200 × 0.11 × 18,500 ≈ 每年£244萬
```

文書負擔軟體（自動填充的評估表、單點登入、語音聽寫）合理估計能將流失率改善1個百分點：

```
價值 = 1,200 × 0.01 × 18,500 = 每年£222,000的現金相關效益
```

一份有員工調查摩擦分數支撐的1個百分點主張是可信的；一份4個百分點的主張則不然。應對Δ流失率進行[龍捲風圖](../敏感性分析/)分析：它在整個模型中的影響遠超其他所有因素。

## 與軟體工程的聯絡

工程領域的留任算術完全相同，只是記錄得更不完善：替換一名資深工程師，成本相當於6–12個月的負荷薪資（招聘、爬坡、丟失的上下文），因此一個200人的組織，在15%的流失率下，每年因人員流失而燒掉數百萬。開發者體驗投資（[SPACE與開發者體驗](../SPACE與開發者體驗/)）正是護士文書負擔減負工作的直接對應物——也應以同樣的方式論證其正當性：經實測的摩擦分數、對流失率適度保守的預期影響、來自你自己財務資料的每名離職者成本。值得借鑑的健康經濟學紀律，是*誠實地為離職者計價*，而非爭論人們是否"真的"是因為工具問題而離職。

## 陷阱

- **將全部流失率變動歸因於你的介入措施**——勞動力市場對流失率的影響，遠大於任何軟體；應使用對照組，或至少進行行業趨勢調整。
- **重複計算**：留任節省與中介支出節省存在重疊（空缺覆蓋*本身就是*中介支出）；應對這兩條效益線進行核對調和。
- **忽視滯後效應**：由職業倦怠驅動的人員流失，對摩擦變化的回應通常需要1–2年，而非下一個季度就能體現。
