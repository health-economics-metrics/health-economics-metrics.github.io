# Nettomonetär nytta (NMB)

Nettomonetär nytta omvandlar hälsovinst till pengar vid tröskelvärdet och drar av kostnaderna, vilket gör det möjligt att rangordna interventioner med ett enda tal.

## Varför det är viktigt

Till skillnad från ICER är NMB linjär, vilket gör statistisk analys (medelvärden, konfidensintervall) mycket enklare.

## Matematiken

```
NMB = (Effekt × tröskelvärde) − Kostnad
```

## Genomarbetat exempel

En intervention ger 0,3 QALY till en kostnad av £4 000, tröskel £20 000/QALY: NMB = (0,3 × £20 000) − £4 000 = £2 000 (positivt = kostnadseffektivt).

## Koppling till mjukvaruutveckling

Liknar att omvandla flera effektdimensioner (hastighet, tillförlitlighet, funktioner) till ett sammansatt värdemått för prioritering.

## Fallgropar

- **Att använda fel tröskelvärde vid beräkning av NMB.**
- **Att jämföra NMB mellan studier som använde olika trösklar.**
