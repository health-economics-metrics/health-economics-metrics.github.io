# Varasem sekkumine

Varasem sekkumine käsitleb terviseprobleemide lahendamise majandust enne nende halvenemist, kui ravi on tavaliselt odavam ja tõhusam.

## Miks see on oluline

Haiguse progresseerumise kulud on harva lineaarsed — seisundi varajane ravi 1. staadiumis maksab vaid murdosa sama seisundi ravist 4. staadiumis.

## Matemaatika

```
Säästetud progresseerumiskulud = Σ (hilise faasi kulu − varase faasi kulu) × avastatud juhtude arv
```

## Lahendatud näide

Kroonilise neeruhaiguse varajane avastamine 2. staadiumis maksab £500/patsient/aastas haldamiseks, võrreldes £45 000/aastas dialüüsiga 5. staadiumis — varajane sekkumine 100 patsiendi puhul võib potentsiaalselt säästa miljoneid.

## Seos tarkvaraarendusega

Sarnaneb koodikvaliteediprobleemide varajase tuvastamisega (staatiline analüüs) võrreldes samade vigade avastamisega tootmises, kus nende parandamise kulu on eksponentsiaalselt kõrgem.

## Lõksud

- **Sõeluuringu enda infrastruktuuri kulu arvestamata jätmine.**
- **Eeldus, et iga varajane sekkumine on kulusid kokkuhoidev — vt [ennetusmajandus](../prevention-economics/) nüansside kohta.**
