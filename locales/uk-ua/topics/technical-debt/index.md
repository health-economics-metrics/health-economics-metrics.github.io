# Технічний борг

Технічний борг — це неявна майбутня вартість минулих рішень, які були зручними на той момент у кодовій базі: несплачена коригувальна робота (**основна сума**) та постійний опір, який вони чинять доставці (**відсотки**).

## Чому це важливо

Без кількісної оцінки технічний борг — це скарга; з кількісною оцінкою — це бізнес-кейс.

## Математика

```
Основна сума SQALE = Σ порушення(час виправлення) × ставка витрат розробника
```

## Розібраний приклад

Інтеграційний рівень клінічних записів на 400 000 рядків коду: відсотки ≈ £276 000/рік.

## Зв'язок з інженерією програмного забезпечення

Імпорти з економіки охорони здоров'я, що збагачують дебати про технічний борг.

## Підводні камені

- **Звітування лише про основну суму.**
