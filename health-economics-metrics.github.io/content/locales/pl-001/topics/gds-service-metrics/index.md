# Wskaźniki usług GDS

Wskaźniki usług GDS (Government Digital Service) to cztery kluczowe wskaźniki wydajności cyfrowych usług publicznych: satysfakcja użytkowników, wskaźnik ukończenia, oszczędność kosztów i wykorzystanie cyfrowe.

## Dlaczego to ważne

Cyfrowe usługi publiczne muszą wykazywać rezultaty podatnikom.

## Matematyka

```
Wskaźnik ukończenia = ukończone transakcje / rozpoczęte transakcje × 100%
```

## Rozwiązany przykład

Usługa rejestracji pacjentów online: 10 000 rozpoczętych, 8200 ukończonych = 82% wskaźnika ukończenia.

## Powiązanie z inżynierią oprogramowania

Uzasadnia wraz z [realizacją korzyści](../benefits-realization/) publiczne inwestycje cyfrowe.

## Pułapki

- **Patrzenie tylko na wykorzystanie cyfrowe, ignorowanie kosztów kanałów offline.**
