# 빌드 대 구매

빌드 대 구매 분석은 사내 개발과 상용 소프트웨어 조달의 총소유비용과 위험을 비교합니다.

## 왜 중요한가

잘못된 선택은 수백만 파운드와 수년의 지연 비용을 초래할 수 있습니다.

## 수식

```
순현재가치 차이 = NPV(구매) − NPV(빌드)
```

## 계산 예시

환자 예약 시스템: 구매 = £2M/5년; 빌드 = £3.2M/5년 (유지보수 포함).

## 소프트웨어 공학과의 연관성

[총소유비용](../총소유비용/) 계산이 이 결정의 핵심 입력입니다.
