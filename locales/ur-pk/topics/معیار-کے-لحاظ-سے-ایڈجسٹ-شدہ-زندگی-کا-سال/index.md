# معیار کے لحاظ سے ایڈجسٹ شدہ زندگی کا سال (QALY)

ایک QALY مکمل صحت میں گزارا گیا ایک سال ہے۔ یہ لوگ *کتنی دیر* زندہ رہتے ہیں اور *کتنا اچھا* زندہ رہتے ہیں دونوں کو یکجا کرتا ہے۔

## یہ کیوں اہم ہے

QALY صحت کی ٹیکنالوجی کی تشخیص کی مشترکہ کرنسی ہے۔ NICE (انگلینڈ) صحت کے فائدے کی قدر **£20,000–£30,000 فی QALY** رکھتا ہے۔

## ریاضی

```
QALY = Σ_i (مدت_i × افادیت_i)
```

## حل شدہ مثال

ایک مریض 0.6 افادیت کی حالت میں دل کے علاج کا انتظار کر رہا ہے۔ علاج انہیں 0.85 افادیت میں بحال کرتا ہے۔ تاخیر سے QALY کا نقصان 0.125۔

## سافٹ ویئر انجینئرنگ سے تعلق

**تیز راستہ = پہلے QALY۔**

## عام غلطیاں

- **افادیت کے وزن ایجاد کرنا۔**
