# Budować kontra kupić

Analiza budować kontra kupić porównuje całkowity koszt posiadania i ryzyko dla rozwoju wewnętrznego z nabyciem oprogramowania komercyjnego.

## Dlaczego to ważne

Zły wybór może kosztować miliony funtów i lata kosztu opóźnienia.

## Matematyka

```
Różnica wartości bieżącej netto = NPV(kupić) − NPV(budować)
```

## Rozwiązany przykład

System rezerwacji wizyt pacjentów: kupić = £2 miliony/5 lat; budować = £3,2 miliona/5 lat (wliczając utrzymanie).

## Powiązanie z inżynierią oprogramowania

Obliczenia [całkowitego kosztu posiadania](../total-cost-of-ownership/) są kluczowym czynnikiem tej decyzji.

## Pułapki

- **Ignorowanie kosztów uzależnienia od dostawcy.**
