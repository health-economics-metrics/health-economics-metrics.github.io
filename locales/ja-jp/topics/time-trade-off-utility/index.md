# タイムトレードオフ(TTO)による効用値の導出

TTOは、健康状態の効用値を考案するのではなく、回答者から直接引き出すための標準的な方法です。スタンダードギャンブルや離散選択実験と並ぶ導出法の一つで、[EQ-5D](../eq-5d/)のような尺度の背後にある価値セットを生み出し、したがって下流のほとんどの[QALY](../quality-adjusted-life-year/)計算の背後にあります。

## なぜ重要か

QALYの計算に入力されるあらゆる効用の重みは、どこかから来なければなりませんでした。TTOはその方法です。死よりも良いと考えられる状態について、回答者は、障害のある状態での`T`年と同等とみなす完全な健康状態での年数`X`(`X < T`)を尋ねられ、効用は`X / T`になります。一部の回答者が死より悪いと考える状態では、標準の式は成り立たず(ゼロ未満の効用をきれいに表せないため)、代わりに拡張TTOが適用されます。効用の重みを、導出に検証されたプロトコルが必要だったことを知らずに所与の入力として扱うソフトウェアエンジニアやアナリストは、異議を唱えられたときに擁護できない数値から一歩のところにいます。

## 数式

```
標準TTO(死より良い状態):
  効用 = 完全な健康での時間 / 障害のある状態での時間

拡張TTO(死より悪い状態):
  効用 = −死と交換した時間 / (総期間 − 死と交換した時間)
```

`完全な健康での時間` / `障害のある状態での時間` — 障害のある状態での`T`年と同等と判断される、完全な健康での`X`年。`死と交換した時間` / `総期間` — 死より悪い状態の定式化では、`T`年の残りの人生のうち、即時の死と交換する年数`a`で、回答者は`T`年を死より悪い状態で過ごすより、`T − a`年を完全な健康で過ごしたあとに死ぬほうを好みます。結果は負で、死 = 0になるよう固定されています。

## 計算例

**標準**: 回答者は障害のある状態に10年間置かれ、完全な健康での7年と無差別です。効用 = 7 / 10 = **0.7**。

**死より悪い**: 残りの人生が10年のうち、回答者は2年を即時の死と交換します。死より悪い状態での10年より、完全な健康での8年とその後の死を好みます。効用 = −2 / (10 − 2) = −2 / 8 = **−0.25**。

## ソフトウェア工学との関連

DevExやエンゲージメントの調査が、検討されていない0〜10の尺度で何かを評価するよう人々に求めるときに直面するのと同じ問題が、ここでは逆の形で当てはまります。TTOは、「人に評価してもらえばいい」ことが、それだけでは検証された導出方法ではないからこそ存在します。自己評価された数値の上に総合指標(DevExスコア、エンゲージメント指数、バーンアウト尺度)を構築する前に、何がそれを導いたのか、その方法が検証されていたのかを尋ねてください。ヘルスエコノミストが、効用の重みがQALYに入る前に問うのと同じ質問です。

## 落とし穴

- **個人の値の一般化**: TTOの値は、ケアが決められる個人からではなく、一般市民(または患者)の*標本*から導出されます。1人の回答者のTTOの値を一般化できるかのように用いるのは、標本誤差です。
- **状態に対する誤った定式化**: 標準のTTOの式は、状態が死より明確に良いことを前提としています。一部の回答者が死より悪いと考える状態に、拡張定式化に切り替えずに適用すると、黙って誤った(正の)効用が生じます。
- **比較できない期間**: 死より悪い状態の比較に異なる残存寿命`T`を用いて導出されたTTO値は、研究デザインが`T`を一定に保っていたかを確認せずに直接比較することはできません。
