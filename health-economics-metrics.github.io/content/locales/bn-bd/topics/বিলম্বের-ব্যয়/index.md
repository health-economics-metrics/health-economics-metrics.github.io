# বিলম্বের ব্যয় (CoD)

বিলম্বের ব্যয় হলো একটি বৈশিষ্ট্য, পণ্য, বা সেবা *বিতরণ না হওয়া* প্রতি একক সময়ে হারানো অর্থনৈতিক মূল্য। এটি সফটওয়্যার ডেলিভারি মেট্রিক্স এবং স্বাস্থ্য অর্থনীতির মধ্যে সবচেয়ে শক্তিশালী সেতু: এটি "আমরা দেরিতে পাঠিয়েছি"-কে মুদ্রায় — বা QALY-তে রূপান্তরিত করে।

## কেন এটি গুরুত্বপূর্ণ

Reinertsen-এর নিয়ম: "যদি আপনি শুধুমাত্র একটি জিনিস পরিমাপ করেন, বিলম্বের ব্যয় পরিমাপ করুন।" স্বাস্থ্যসেবা সফটওয়্যারের জন্য ঝুঁকি আক্ষরিক: প্রতি সপ্তাহ একটি পথ উন্নতি বিলম্বিত হলে, রোগীরা খারাপ স্বাস্থ্য অবস্থায় বেশি অপেক্ষা করে।

## গণিত

```
CoD = অবিতরণ থাকাকালীন একক সময়ে হারানো সুবিধা (£/সপ্তাহ বা QALY/সপ্তাহ)
মোট বিলম্ব ক্ষতি = CoD × বিলম্ব সময়কাল
```

ক্লিনিক্যাল সফটওয়্যারের জন্য, অর্থের পাশাপাশি স্বাস্থ্যেও প্রকাশ করুন:

```
CoD_স্বাস্থ্য = সপ্তাহে প্রভাবিত রোগী × প্রতি রোগী QALY লাভ
CoD_অর্থ  = CoD_স্বাস্থ্য × λ + সপ্তাহে হারানো কার্যক্রম সাশ্রয়
```

## সমাধানকৃত উদাহরণ

**কার্যক্রমগত**: একটি সফটওয়্যার একটি পথে প্রতি রোগী £২০০ সাশ্রয় করে; একটি ট্রাস্ট সপ্তাহে ৫০ জন এমন রোগী প্রক্রিয়া করে।

```
CoD = 200 × 50 = £10,000/সপ্তাহ
একটি ১০-সপ্তাহের সংগ্রহ বিলম্ব খরচ করে 200 × 50 × 10 = £100,000 এড়ানো অপচয়।
```

**ক্লিনিক্যাল**: একটি ট্রায়াজ উন্নতি সপ্তাহে ১০০ রোগীর জন্য ৫ সপ্তাহ বিশুদ্ধ সারিবদ্ধতা দূর করে:

```
QALY লাভ = 100 × (5/52) × 0.12 ≈ 1.15 QALY/সপ্তাহ
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

CoD সেই সূচক যা [DORA লিড টাইম](../dora-মেট্রিক্স/) এবং [ফ্লো দক্ষতা](../প্রবাহ-সূচক/)-কে আর্থিকভাবে পাঠযোগ্য করে তোলে: লিড টাইম × CoD = সারিতে পুড়ে যাওয়া অর্থ (বা স্বাস্থ্য)।

## ঝুঁকিপূর্ণ দিক

- **CoD-কে রৈখিক ধরে নেওয়া**: কিছু কাজের সময়সীমা-আকৃতির মূল্য আছে (নিয়ন্ত্রক তারিখ)।
- **কেউ চায় না এমন আউটপুটে CoD**: বিলম্ব তখনই খরচ করে যদি জিনিসটির মূল্য থাকে।
- **বিলম্ব এবং ছাড়ের দ্বিগুণ গণনা**।
