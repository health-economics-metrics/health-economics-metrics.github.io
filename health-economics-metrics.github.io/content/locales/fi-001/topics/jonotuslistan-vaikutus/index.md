# Jonotuslistan vaikutus

Jonotuslistan vaikutus mittaa, kuinka säästetyt kliiniset tunnit tai parantunut tehokkuus muuntuvat todella hoidetuiksi lisäpotilaiksi.

## Miksi se on tärkeä

Tehokkuushyödyt tuottavat todellista arvoa vain, kun ne muunnetaan lisäläpimenoksi — muuten ne jäävät teoreettisiksi.

## Matematiikka

```
Lisähoidetut potilaat = Säästetyt kliiniset tunnit / Keskimääräinen aika per potilaskonsultaatio
```

## Ratkaistu esimerkki

Tehokkuusprojekti säästää 500 kliinistä tuntia kuukaudessa; keskimääräisellä 20 minuutin konsultaatioajalla tämä vastaa 1 500 lisähoidettua potilasta kuukaudessa.

## Yhteys ohjelmistokehitykseen

Muistuttaa säästetyn CI/CD-putkiajan muuntamista todella toimitetuiksi lisäominaisuuksiksi sen sijaan, että väitettäisiin vain "nopeampia koontiversioita".

## Sudenkuopat

- **Oletus, että säästetty aika käytetään automaattisesti uudelleen lisäpotilaille — katso [kassavaikutteiset vastaan ei-kassavaikutteiset säästöt](../kassavaikutteiset-vastaan-ei-kassavaikutteiset-säästöt/).**
- **Padotun kysynnän jättäminen huomiotta, joka täyttää jonotuslistan nopeasti uudelleen.**
