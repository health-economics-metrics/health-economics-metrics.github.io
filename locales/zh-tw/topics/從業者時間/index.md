# 從業者時間

從業者時間是大多數醫療系統中最稀缺的資源。要衡量為臨床醫師每天節省幾分鐘的價值，需要從簡單的薪資算術，轉向**機會成本與系統產能**的視角：在一個國家醫療服務體系內，從業者的時間是一個剛性的營運瓶頸，而非一條可以彈性伸縮的成本科目。

## 為何重要

你無法迅速培養出更多的全科醫師、顧問醫師或專科護士——培訓週期長達5–15年，且崗位空缺長期存在。因此，節省下來的一小時從業者時間，並不是"避免支付的工資"（該從業者依然照常領取薪水）；它是*被釋放出來的瓶頸產能*，而瓶頸產能的價值，取決於該瓶頸所能產出的東西。這正是為什麼"每次問診節省10分鐘"這類主張，既是數位健康領域中最常見的一條效益線，也是最常被錯誤定價的一條。

## 計算方法

三個估值層級，誠實度依次遞增：

```
1. 薪資基礎：      小時數 × 負荷薪資費率（PSSRU單位成本）
                  ——衡量的是這段時間的成本，而非它所產生的價值
2. 產出基礎：      小時數 → 轉化為可完成的問診/運算元 × 標準價格
                  （參見national-tariff-and-unit-costs.md）
3. 瓶頸基礎：      若該角色是整條路徑的關卡，則為 小時數 × 被釋放的
                  路徑吞吐量價值（約束理論）
```

碎片化折扣：低於可用最小單元的零散節省時間（例如一次門診中分散節省的3分鐘），很難被有效重新部署；應採用一個明示的利用率折扣因子。

## 實例演算

環境語音記錄技術為每次問診節省全科醫師2分鐘，每天30次問診：每天60分鐘，按220個工作日計算，相當於**每名全科醫師每年220小時**。

```
薪資基礎：   220 × £80（負荷後的全科醫師小時成本，PSSRU區域資料）≈ 每名全科醫師每年£17,600
產出基礎：   每天60分鐘 = 每天多完成5次12分鐘的問診
            = 每名全科醫師每年多完成1,100次問診 × £42 ≈ 每年£46,200
            ——或者，同樣這些問診時間也可能被吸收為減少的加班時間，
            以及更從容、不匆忙的問診品質（這屬於定性效益線）
```

在一個由50名全科醫師組成的聯合體中，按產出基礎計算的這部分產能價值約為每年£230萬——前提是這些分鐘數是真實的（經過實測，而非供應商單方面宣稱）、是被整合起來的（完整的問診時段，而非零碎片段），並且確實被重新部署投入使用（參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)）。

## 與軟體工程的聯絡

資深工程師的時間表現出完全相同的模式：它是設計、評審與事件處理所流經的瓶頸，因此應按該瓶頸所把控的產出來估值，而非僅按薪資估值。同樣的三層估值方法，適用於任何"AI為每名開發者節省X分鐘"的主張——薪資算術容易美化微小的數位；真正誠實的問題在於，這些分鐘數是否能整合成可用的時間塊，以及被釋放出的產能究竟真正產出了什麼。當被節省的這一小時屬於所有人都在等待的那個人時，其乘數效應參見[下游資源最佳化](../下游資源最佳化/)。

## 陷阱

- **分鐘數 × 薪資 = 節省**——這是最經典的虛增手法；它其實是產能，且只有在明示的利用率下才成立。
- **忽視最小可用單元問題**：12次5分鐘的節省，並不等於1個完整空閒的小時。
- **對所有角色一視同仁地估值**：路徑瓶頸處的一小時，其價值遠高於非關卡角色的一小時。
