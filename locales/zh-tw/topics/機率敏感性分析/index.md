# 機率敏感性分析（PSA）

PSA為每一個不確定引數賦予一個機率分佈，將所有引數同時進行數千次聯合抽樣（蒙特卡洛模擬），並報告某個方案是最佳選擇的*機率*——而非單一的點估計值。

## 為何重要

NICE的參考案例*要求*必須進行PSA。確定性分析回答的是"如果某一項輸入是錯的，會怎樣？"；而PSA回答的是"考慮到我們同時存在的所有未知因素，我們做出正確決策的可能性究竟有多大？"其標誌性輸出——**成本效果可接受性曲線（CEAC）**——繪製的是某方案在不同支付意願閾值下具有成本效果的機率，從而把"ICER是每QALY £24,000"這樣的表述，轉化為"在每QALY £30,000的閾值下，這是正確選擇的可能性為78%"。

## 計算方法

```
對N次抽樣（N ≈ 10,000）中的每一次：
  從各自分佈中抽取每一個引數θ
    （成本 ~ Gamma分佈，機率 ~ Beta分佈，效用值 ~ Beta分佈，效果 ~ 正態/對數正態分佈）
  為每個方案j計算 NMB_j(θ) = λ × 效果_j(θ) − 成本_j(θ)

CEAC_j(λ) = 在閾值λ下，方案j擁有最高NMB的抽樣次數佔比
```

關於NMB，參見[淨貨幣效益](../淨貨幣效益/)；關於λ，參見[支付意願閾值](../支付意願閾值/)。

## 實例演算

某平臺遷移商業案例。存在三項不確定輸入：

```
遷移成本      ~ Gamma分佈，均值£800,000，標準差£200,000
年度效益      ~ 正態分佈，均值£350,000，標準差£150,000
效益持續年數   ~ 均勻分佈，3–6年
```

對10,000次抽樣中的每一次，計算淨效益 = 持續年數 × 年度效益 − 成本（為清晰起見省略貼現）。示例結果如下：

```
淨效益均值：           £775,000
淨效益 > 0 的機率：     0.86
第5至第95百分位區間：  −£180,000 … +£190萬
```

點估計的結論是"顯然應該做"。而PSA的結論是"86%的可能性應該做，但確實存在一個尾部風險，可能損失£180,000以上"——這才是一位投資組合負責人真正需要的資訊，也為先做一次探索性尖刺研究提供了定價依據（參見[EVPI](../完美資訊期望價值/)）。

## 與軟體工程的聯絡

工程師早已信賴蒙特卡洛方法用於交付預測（吞吐量抽樣優於點估計）。可以將同一套方法直接延伸到金錢層面：為採納率、節省的時間與薪資設定分佈，然後報告"該平臺投資淨收益為正的機率"，而非一個虛假精確的投資回報率數位。一條CEAC式曲線——展示"作為組織對一個工程師-小時估值高低的函式，某方案是最佳選擇的機率"——對資助委員會而言，確實是比任何單一數位都更有價值的呈現方式。

## 陷阱

- **垃圾分佈**：使用憑空捏造的標準差做PSA，不過是披著白大褂的確定性分析。分佈應基於資料，或結構化的專家意見徵詢。
- **忽視引數之間的相關性**（高採納率通常與高節省時間相關）；獨立抽樣會低估尾部風險。
- **只報告模擬結果的均值**——PSA的全部意義，恰恰在於其分佈本身以及決策機率。
