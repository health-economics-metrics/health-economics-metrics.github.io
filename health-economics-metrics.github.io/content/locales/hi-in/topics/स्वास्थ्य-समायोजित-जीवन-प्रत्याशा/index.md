# स्वास्थ्य-समायोजित जीवन प्रत्याशा (HALE)

HALE एक जनसंख्या-स्तरीय सारांश है: एक व्यक्ति *पूर्ण स्वास्थ्य में* कितने वर्ष जीने की उम्मीद कर सकता है।

## यह क्यों महत्वपूर्ण है

HALE राष्ट्रीय और वैश्विक स्वास्थ्य नीति का उत्तर-सितारा मीट्रिक है।

## गणित

मानक गणना **सुलिवन विधि** है:

```
HALE_आयु_x = Σ (प्रत्येक आयु ≥ x पर जीवन-सारणी व्यक्ति-वर्ष × पूर्ण स्वास्थ्य में अनुपात)
```

## हल किया गया उदाहरण

एक राष्ट्रीय डिजिटल उच्च-रक्तचाप कार्यक्रम 500,000 नामांकित करता है।

```
HALE योगदान ≈ 500,000 में 15,000 स्वस्थ वर्ष
             ≈ प्रति नामांकित व्यक्ति लगभग 0.03 वर्ष (≈ 11 दिन) HALE
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

HALE एक फ्लीट-स्वास्थ्य मीट्रिक पैटर्न है: **अपेक्षित सेवा जीवन × उस जीवन के स्वस्थ अनुपात**।

## सामान्य गलतियाँ

- **HALE धीरे और बहु-कारणात्मक रूप से चलता है।**
- **प्रसार डेटा पिछड़ जाता है।**

## स्रोत

- WHO indicator registry: HALE.
- Global Burden of Disease study (IHME).
