# 人才留任

人才留任经济学量化的是人员流失给一个医疗系统带来的成本——招聘、入职培训、空缺期覆盖——从而也量化了能减轻行政性职业倦怠的软件究竟值多少钱。反复性的行政数据录入工作所造成的职业倦怠，是NHS员工流失与病假缺勤的主要驱动因素之一。

## 为何重要

一名临床人员离职时，信托机构要为此三次付费：招聘替代人选（广告、中介费、面试）、为其提供入职培训（数月生产力下降、需要督导），以及在此期间覆盖该空缺——通常以中介或临时医生的形式，费率为在职Agenda for Change标准费率的2–3倍（参见[可规避的外包成本](../可规避的外包成本/)与[硬性现金释放型节省](../硬性现金释放型节省赤字防线/)）。由于人员流失的成本是真实的现金支出，留任率的改善是财务总监少数能够真正入账的人力资源效益之一。行政摩擦始终位列临床职业倦怠最常被提及的驱动因素前列，这使其成为一项软件可以解决的成本。

## 计算方法

```
每名离职者的成本 = 招聘成本 + 入职/生产力爬坡成本
                + 空缺覆盖溢价 × 空缺持续时长

年度流失成本 = 员工总数 × 流失率 × 每名离职者的成本

软件的价值   = 员工总数 × Δ流失率 × 每名离职者的成本
             + 病假缺勤减少量 × 每日覆盖成本
```

这条因果链条包含两个需要分别估计的环节——软件 → 职业倦怠/摩擦，以及职业倦怠 → 人员流失——因此二者都需要证据支撑（前后对比的员工调查；已发表的职业倦怠-流失关联研究），并应保持所主张的Δ值适度保守。

## 实例演算

某信托机构雇有1,200名护士；年流失率11%。每名离职者的成本：

```
招聘 ≈ £4,500；入职/爬坡 ≈ £6,000
空缺覆盖：4个月 × 0.6全职当量，由中介溢价覆盖 ≈ £8,000
合计 ≈ 每名离职者£18,500
基线流失成本 = 1,200 × 0.11 × 18,500 ≈ 每年£244万
```

文书负担软件（自动填充的评估表、单点登录、语音听写）合理估计能将流失率改善1个百分点：

```
价值 = 1,200 × 0.01 × 18,500 = 每年£222,000的现金相关效益
```

一份有员工调查摩擦分数支撑的1个百分点主张是可信的；一份4个百分点的主张则不然。应对Δ流失率进行[龙卷风图](../敏感性分析/)分析：它在整个模型中的影响远超其他所有因素。

## 与软件工程的联系

工程领域的留任算术完全相同，只是记录得更不完善：替换一名资深工程师，成本相当于6–12个月的负荷薪资（招聘、爬坡、丢失的上下文），因此一个200人的组织，在15%的流失率下，每年因人员流失而烧掉数百万。开发者体验投资（[SPACE与开发者体验](../SPACE与开发者体验/)）正是护士文书负担减负工作的直接对应物——也应以同样的方式论证其正当性：经实测的摩擦分数、对流失率适度保守的预期影响、来自你自己财务数据的每名离职者成本。值得借鉴的健康经济学纪律，是*诚实地为离职者计价*，而非争论人们是否"真的"是因为工具问题而离职。

## 陷阱

- **将全部流失率变动归因于你的干预措施**——劳动力市场对流失率的影响，远大于任何软件；应使用对照组，或至少进行行业趋势调整。
- **重复计算**：留任节省与中介支出节省存在重叠（空缺覆盖*本身就是*中介支出）；应对这两条效益线进行核对调和。
- **忽视滞后效应**：由职业倦怠驱动的人员流失，对摩擦变化的响应通常需要1–2年，而非下一个季度就能体现。
