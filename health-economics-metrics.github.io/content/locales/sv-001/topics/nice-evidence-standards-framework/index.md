# NICE Evidence Standards Framework

NICE Evidence Standards Framework specificerar riskgraderade evidenskrav för digitala hälsoteknologier, från lågrisk välmåendeappar till högrisk diagnostiska verktyg.

## Varför det är viktigt

Digitala hälsoprodukter behöver inte alla uppfylla samma evidensribba — ramverket skalar kraven efter risknivå.

## Matematiken

```
Evidensnivå = f(funktionell riskklass, klinisk risknivå)
```

Ingen numerisk formel; det är ett klassificeringssystem med tillhörande evidenströsklar.

## Genomarbetat exempel

En app för stressreduktion hamnar i nivå 1 (beskrivande evidens räcker); ett AI-diagnostikverktyg för cancerdetektion hamnar i nivå 3b (randomiserade kontrollerade studier krävs).

## Koppling till mjukvaruutveckling

Liknar riskbaserade testkrav — ett internt verktyg behöver mindre rigorös validering än ett patientsäkerhetskritiskt system.

## Fallgropar

- **Att felklassificera ett verktyg för att uppfylla lägre evidenskrav.**
- **Att inte ompröva evidenskraven när en produkts funktionalitet ändras.**

## Källor

- NICE, Evidence Standards Framework for digital health technologies.
- NHS Digital, digital technology assessment criteria.
