# 敏感性分析

确定性敏感性分析（DSA）在一个合理区间内，每次只改变一个假设，观察结论是否依然成立。其标准可视化形式是龙卷风图：按参数对结果的摆动幅度进行排序。

## 为何重要

每一个经济学模型都建立在各种估计之上——节省的时间、采纳率、单位成本。卫生技术评估拒绝接受一个点估计（"ROI是340%"），除非有证据表明该结论在对输入数据存在合理分歧的情况下依然稳健。龙卷风图能告诉决策者*应该质询哪一个假设*：如果这个论证只有在争议最大的那个参数取乐观值时才成立，所有人都能立刻看清这一点。

这是健康经济学中最具可迁移性、最适合直接用于软件商业论证的一项习惯。

## 计算方法

对每一个参数p，在其合理区间[p_低, p_高]内：

```
结果_低  = 模型(p = p_低,  其余参数取基准情形)
结果_高  = 模型(p = p_高, 其余参数取基准情形)
摆动幅度(p) = |结果_高 − 结果_低|
```

按摆动幅度对各参数排序；围绕基准情形的结果绘制水平条形图。其变体包括：双向DSA（在网格上同时改变两个参数）、阈值分析（找出使决策发生翻转的参数取值）。

## 实例演算

面向200名开发者的AI编程助手。基准情形：每名开发者每月许可费£39；每名开发者每天节省30分钟；负荷成本£60/小时；220个工作日。

```
基准情形年度效益 = 200 × 0.5小时 × 220 × £60 = £1,320,000
年度成本         = 200 × £39 × 12         = £93,600
基准情形净值     = £1,226,400
```

龙卷风图（每次改变一个参数）：

```
每天节省时间0.1–1.0小时：净值 = £170,400 … £2,546,400   （摆动£238万）← 主导因素
负荷成本£40–£80/小时：    净值 = £786,400 … £1,666,400   （摆动£88万）
工作日数200–240：         净值 = £1,106,400 … £1,346,400 （摆动£24万）
许可费£30–£50/月：        净值 = £1,248,000 … £1,200,000 （摆动£48,000）
```

阈值分析：净效益在每天节省约**2.1分钟**时归零。这项决策对许可价格并不敏感，而完全取决于"节省时间"这一项估计——因此应重点测量这一项，而非其他项。（并请记住，这个结果代表的是产能，而非现金——参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)。）

## 与软件工程的联系

工程师早已凭直觉在做这件事——"如果我们对X的判断是错的怎么办？"——DSA只是把这一过程变得系统化、可视化。应在每一份工具提案、产能规划以及自建与外购分析中，都附上一张龙卷风图。它能把"到底谁的直觉更准"这类争论，转化为"应该去实测哪个参数"这样的共识——往往可以通过一次试点来实现，而这次试点本身的价值也可以被定价（参见[完美信息期望价值](../完美信息期望价值/)）。

## 陷阱

- **为博取好感而选定区间**：无论实际不确定性如何，一律对每项输入取±10%。节省时间的估计理应取±80%的区间；许可价格则可取±10%。
- **一次一个参数会遗漏交互效应**——存在相关性的参数（如采纳率与节省时间）需要双向分析，或完整的[概率敏感性分析](../概率敏感性分析/)。
- **做了分析却对其置之不理**：如果龙卷风图显示整个论证系于一个软性数字之上，下一步应是去实测它，而不是直接批准放行。
