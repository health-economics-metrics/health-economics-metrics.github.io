# ہنگامی حاضری سے بچاؤ

ہنگامی حاضری سے بچاؤ بالادست مداخلت — ٹرائیج ایپ، دور دراز نگرانی، ورچوئل وارڈز — کے ذریعے روکے گئے ED دوروں اور ہنگامی داخلوں کو شمار کرتا ہے۔

## یہ کیوں اہم ہے

ہنگامی نگہداشت نظام میں سب سے مہنگی معمول کی سیٹنگ ہے۔

## ریاضی

```
بچائی گئی حاضری = آبادی × (بیس لائن شرح − مداخلت کی شرح)
```

## حل شدہ مثال

3,000 اعلی خطرے والے مریضوں کے لیے ایک COPD دور دراز-نگرانی سروس: خالص ≈ سالانہ +£342,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہ **واقعہ-بچاؤ کی معاشیات** ہے۔
