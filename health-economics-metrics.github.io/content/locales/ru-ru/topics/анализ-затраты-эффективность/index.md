# Анализ «затраты-эффективность» (Cost-Effectiveness Analysis, CEA)

CEA сравнивает затраты альтернативных вмешательств относительно единого исхода, измеряемого в **натуральных единицах** — годах жизни, выявленных случаях, предотвращённых госпитализациях, мм рт. ст. снижения артериального давления. Её результат — стоимость на единицу исхода.

## Почему это важно

CEA — это рабочая лошадка сравнения, когда все варианты нацелены на один и тот же исход. Она отвечает на вопрос «какой из этих способов достижения X — лучшее использование денег?» — но *не* «стоит ли вообще достигать X?» (для этого нужен [анализ «затраты-выгоды»](../анализ-затраты-выгоды/)) и *не* «как X соотносится с несвязанными приоритетами?» (для этого нужны [анализ «затраты-полезность»](../анализ-затраты-полезность/) и универсальный исход вроде QALY).

## Математика

Сравнительная статистика — это [ICER](../инкрементальное-соотношение-затрат-и-эффективности/) в натуральных единицах:

```
ICER = (Затраты_A − Затраты_B) / (Эффект_A − Эффект_B)
     = £ за дополнительный выявленный случай / предотвращённую госпитализацию / и т. д.
```

Процедура: определите единицу исхода; оцените затраты каждого варианта с одной и той же [перспективы](../перспектива-анализа/) на одном и том же [временном горизонте](../временной-горизонт/); исключите доминируемые варианты ([граница эффективности](../доминирование-и-граница-эффективности/)); вычислите инкрементальные коэффициенты вдоль границы.

## Практический пример

Три способа выявить недиагностированную фибрилляцию предсердий в популяции из 100 000 человек:

```
Вариант                    Затраты      Найдено случаев
Случайные проверки пульса   £150,000       300
Скрининг в аптеках          £400,000       520
Скрининг на носимых устройствах £900,000   610

ICER аптеки vs пульс:  (400k−150k)/(520−300) = £1,136 за дополнительный случай
ICER носимые vs аптеки:(900k−400k)/(610−520) = £5,556 за дополнительный случай
```

Стоит ли £5 556 за дополнительный случай «того», зависит от ценности выявленного случая (предотвращение инсульта в дальнейшем) — CEA ранжирует варианты, но решение о принятии нуждается в этой внешней оценке. Обратите внимание: *средняя* стоимость случая для варианта с носимыми устройствами (900 тыс./610 = £1 475) выглядит приемлемо; *инкрементальные* £5 556 — честная цифра для решения о расширении.

## Связь с разработкой программного обеспечения

CEA — правильный шаблон всякий раз, когда варианты имеют один общий исход: стоимость устранённого нестабильного (flaky) теста при трёх подходах к исправлению; стоимость предотвращённого инцидента при сравнении вендоров наблюдаемости (observability); стоимость успешного развёртывания при сравнении архитектур CI. Дисциплина, которую она навязывает — одна заявленная единица исхода, инкрементальные (а не средние) коэффициенты, доминируемые варианты исключаются первыми — убивает большинство плохих сравнений вендоров ещё до обсуждения цены.

## Подводные камни

- **Сравнение вариантов с разными исходами** («найденные случаи» против «удовлетворённости») в одном CEA — для этого нужен [анализ «затраты-последствия»](../анализ-затраты-последствия/) или универсальный исход.
- **Средние коэффициенты затратной эффективности**, представленные там, где нужны инкрементальные (пример с носимыми устройствами выше).
- **Единицы исхода, выбранные ради лести**: «сгенерированные оповещения» — это выпуск (output), а не исход; настаивайте на единицах, несущих ценность.
