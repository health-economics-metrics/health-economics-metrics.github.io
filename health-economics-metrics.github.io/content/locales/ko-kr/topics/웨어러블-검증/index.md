# 웨어러블 검증

웨어러블 검증은 소비자 웨어러블 기기(스마트워치, 피트니스 트래커)가 측정하는 데이터가 임상적으로 정확하고 신뢰할 수 있는지 확인하는 과정입니다.

## 왜 중요한가

소비자 웨어러블은 의료기기 규제 기준으로 검증되지 않은 경우가 많습니다.

## 수식

```
평균 절대 백분율 오차(MAPE) = (1/n) × Σ |실제값 − 측정값| / 실제값 × 100%
```

## 계산 예시

손목 심박수 센서: 심전도 기준 대비 MAPE 4.2% (운동 중 8.5%로 증가).
