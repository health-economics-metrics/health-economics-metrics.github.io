# QALY缺口與嚴重程度調整因子

QALY缺口衡量的是，與一般人群相比，某種疾病究竟從病患身上奪走了多少未來的健康。NICE用它來應用**嚴重程度調整因子**：人群病情越嚴重，每獲得一個QALY的價值就越高——最高可達標準閾值的1.7倍。

## 為何重要

自NICE 2022年手冊起，嚴重程度成為對健康獲益價值的一項明確乘數，取代了原先的"臨終溢價"機制。一項針對嚴重病情的技術，其判定標準可高達約每QALY £51,000的有效閾值，而非£30,000。如果你的軟體服務的是病情嚴重的人群（晚期心力衰竭、重度精神疾病），嚴重程度調整因子可能是一份經濟學論證能否獲得資助的關鍵分水嶺——而要主張它，你需要用到缺口計算方法。

## 計算方法

兩項指標，均基於當前標準照護下的剩餘預期壽命計算：

```
絕對缺口   = 一般人群的QALY − 患病人群的QALY
比例缺口   = 絕對缺口 / 一般人群的QALY
```

NICE 2022年權重（取兩種測量方式中給出更高權重的一種）：

```
權重×1.0：絕對缺口 < 12 且比例缺口 < 0.85
權重×1.2：絕對缺口 ≥ 12 或比例缺口 ≥ 0.85
權重×1.7：絕對缺口 ≥ 18 或比例缺口 ≥ 0.95
```

該權重會作用於ΔE（等價地作用於閾值）：有效λ在×1.2權重下變為£24,000–£36,000，在×1.7權重下變為£34,000–£51,000。

## 實例演算

某侵襲性病症病患，平均年齡60歲。一般人群在60歲時預期尚有14.2個貼現後QALY；而患有該病症、接受當前照護的病患僅為2.1個。

```
絕對缺口   = 14.2 − 2.1 = 12.1  （≥ 12 → 符合×1.2權重條件）
比例缺口   = 12.1 / 14.2 = 0.852（≥ 0.85 → 同樣符合×1.2權重條件）
```

你的監測平臺ICER為每QALY £26,000——高於標準的£20,000–£30,000中點判定區間，處於邊緣地帶。應用×1.2權重後：有效ICER = 26,000 / 1.2 ≈ **每QALY £21,700**——輕鬆達到可獲資助的水平。僅僅是缺口計算這一步，就改變了整個決策結果。

## 與軟體工程的聯絡

嚴重程度加權是工程組織憑直覺早已在做的一件事的正式化版本：在處境最糟的系統上，為每單位改進投入更多資源。可遷移的模式是：計算每項服務的"SLO缺口"（它相對於其預期健康基線的偏離程度，同時以絕對值與比例表示），並據此對補救工作的價值進行加權。這能用算術而非爭論，來證明為什麼那個正在燃燒的遺留系統，每節省一小時所獲得的投資應當高於一個健康的系統。它同樣帶來了同一條治理層面的教訓：應在優先順序排序會議*之前*就公佈好這套權重，否則每個團隊都會聲稱自己才是最"嚴重"的那個。

## 陷阱

- **對照錯誤的基線計算缺口**：該缺口應基於*當前標準照護*下的情況測量，而非未經治療的自然病程。
- **對年齡的敏感性**：缺口高度依賴人群年齡（更年輕的病患有更多QALY可能損失 → 絕對缺口更大）；應使用實際接受治療人群的真實年齡分佈。
- **假設該調整因子在其他場景也同樣適用**——它是NICE（英格蘭）特有的機制；其他衛生技術評估機構對嚴重程度的處理方式各不相同（有些甚至完全不予考慮）。
