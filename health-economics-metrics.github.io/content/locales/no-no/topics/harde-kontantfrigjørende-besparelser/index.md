# Harde kontantfrigjørende besparelser (underskuddsforsvar)

Harde kontantfrigjørende besparelser er budsjettlinjer som faktisk slettes — penger systemet ikke lenger bruker — i motsetning til teoretiske effektivitetsgevinster.

## Hvorfor det er viktig

Når en organisasjon må forsvare et underskudd overfor tilsynsmyndigheter, teller bare hard kontantfrigjøring; ikke-kontantfrigjørende "besparelser" blir ignorert av økonomiske tilsynsmyndigheter.

## Matematikken

```
Hard besparelse = faktisk reduksjon av budsjettlinje (verifisert i regnskapet)
```

## Gjennomarbeidet eksempel

Å stenge et fysisk anlegg og slette de tilhørende leiekostnadene på £500 000/år er en hard besparelse; å hevde at ansatte "jobber mer effektivt" uten personellreduksjon er det ikke.

## Kobling til programvareutvikling

Ligner på faktisk å si opp en skytjeneste kontra å hevde "forbedret effektivitet" uten å redusere fakturaen.

## Fallgruver

- **Å presentere ikke-kontantfrigjørende besparelser som harde besparelser for økonomiske tilsynsmyndigheter.**
- **Å ikke telle med overgangskostnadene ved å realisere besparelsen.**
