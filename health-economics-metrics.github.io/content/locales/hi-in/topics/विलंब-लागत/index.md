# विलंब लागत (CoD)

विलंब लागत वह आर्थिक मूल्य है जो एक सुविधा, उत्पाद, या सेवा *वितरित न होने* की प्रति इकाई समय में खोया जाता है।

## यह क्यों महत्वपूर्ण है

Reinertsen का नियम: "यदि आप केवल एक चीज़ मापते हैं, तो विलंब लागत मापें।"

## गणित

```
CoD = अवितरित रहते हुए प्रति इकाई समय खोया लाभ (£/सप्ताह या QALY/सप्ताह)
```

## हल किया गया उदाहरण

**परिचालनात्मक**: एक सॉफ़्टवेयर एक मार्ग में प्रति रोगी £200 बचाता है; एक ट्रस्ट सप्ताह में ऐसे 50 रोगियों को संसाधित करता है।

```
CoD = 200 × 50 = £10,000/सप्ताह
```
