# Molnets enhetsekonomi

Molnets enhetsekonomi mäter infrastrukturkostnad per enskild transaktion, patient eller förfrågan.

## Varför det är viktigt

Molnfakturor visar totalsumman men inte vilken funktion eller patientväg som orsakar kostnaden.

## Matematiken

```
Enhetskostnad = molnkostnad (£/månad) / transaktionsvolym (per månad)
```

## Genomarbetat exempel

En bildlagringstjänst: £40 000/månad, 200 000 skanningar = £0,20 per skanning.

## Koppling till mjukvaruutveckling

Bryter ned [total ägandekostnad](../total-ägandekostnad/) till operativ skala.
