# DiGA kiirrada

DiGA (Digitale Gesundheitsanwendungen) on Saksamaa kiirendatud regulatiivne rada digitervise rakenduste hüvitamiseks riikliku tervisekindlustuse kaudu.

## Miks see on oluline

DiGA pakub digitervise arendajatele selget, kiiret (kuni 3 kuud) rada riiklikku hüvitamisse, erinevalt paljude teiste turgude ebamäärasematest protsessidest.

## Matemaatika

```
Esialgne hind × kasutajate arv = esialgne tulu, kuni lõplik hind kinnitatakse pärast 12-kuulist tõendite kogumise perioodi
```

## Lahendatud näide

DiGA-heakskiidetud rakendus võib esimese aasta jooksul hinnastada end ise (näiteks £450), kogudes samal ajal reaalse maailma tõendeid, mis mõjutavad lõplikku läbiräägitud hinda.

## Seos tarkvaraarendusega

Sarnaneb katsetatud turuletulekuga, kus esialgne turuletoomine võimaldab kiiret kasutuselevõttu, millele järgneb tõenditepõhine hinnakohandus.

## Lõksud

- **Esialgse hinnastrateegia planeerimata jätmine ümberhindamiseks pärast tõendite perioodi.**
- **12-kuulise tõendite kogumise nõuete alahindamine.**
