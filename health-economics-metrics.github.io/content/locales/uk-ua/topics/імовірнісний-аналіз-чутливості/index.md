# Імовірнісний аналіз чутливості

Імовірнісний аналіз чутливості (PSA) варіює всі невизначені параметри одночасно за допомогою симуляції Монте-Карло для отримання ймовірнісного розподілу результатів.

## Чому це важливо

Простий аналіз чутливості тестує одну змінну за раз; PSA охоплює сукупну невизначеність усіх параметрів разом.

## Математика

```
Для кожної симуляції i: витягнути значення параметрів з їхніх розподілів, обчислити результат_i
Ймовірність економічної ефективності = кількість симуляцій нижче порогу / загальна кількість симуляцій
```

## Розібраний приклад

10 000 симуляцій Монте-Карло нового діагностичного інструменту показують, що він є економічно ефективним у 72% симуляцій при порозі £20 000/QALY.

## Зв'язок з інженерією програмного забезпечення

Подібно до навантажувального тестування Монте-Карло, яке варіює кілька невизначених параметрів системи одночасно.

## Підводні камені

- **Ігнорування кореляцій між параметрами при вибірці.**
- **Неправильне тлумачення CEAC як простого відсотка замість ймовірнісного розподілу.**
