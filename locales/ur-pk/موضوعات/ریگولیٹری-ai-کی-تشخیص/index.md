# ریگولیٹری AI کی تشخیص

صحت کی دیکھ بھال میں AI کو کنٹرول کرنے والے ریگولیٹری فریم ورک — FDA کا Software as a Medical Device (SaMD) نظام **پیشگی-متعین تبدیلی کنٹرول کے منصوبوں (PCCP)** کے ساتھ۔

## یہ کیوں اہم ہے

ریگولیشن دونوں **مارکیٹ میں داخلے کی ثبوت کی قیمت** اور **ہر بعد کے ماڈل اپ ڈیٹ کی قیمت** کا تعین کرتا ہے۔

## ریاضی

```
فی ماڈل اپ ڈیٹ قیمت (روایتی) = دوبارہ پیشکش قیمت + جائزہ تاخیر × CoD
```

## حل شدہ مثال

ایک ریڈیالوجی-AI بیچنے والا 3 سالوں میں سہ ماہی ماڈل بہتری کی منصوبہ بندی کرتا ہے: PCCP راستے سے بچت ≈ £2.75M۔

## سافٹ ویئر انجینئرنگ سے تعلق

PCCP کو اچھی طرح سے انجینئر کرنا ایک سافٹ ویئر کا مسئلہ ہے۔

## عام غلطیاں

- **PCCP دائرہ کار میں توسیع کے خواب۔**

## ذرائع

- FDA, AI-enabled device software / SaMD.
