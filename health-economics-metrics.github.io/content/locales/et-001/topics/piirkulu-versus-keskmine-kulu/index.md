# Piirkulu versus keskmine kulu

Piirkulu on ühe lisaühiku kulu; keskmine kulu on kogukulu jagatud ühikute arvuga. Need on harva võrdsed.

## Miks see on oluline

Keskmisel kulul põhinevad säästuväited hindavad peaaegu alati üle tegeliku säästu, kuna fikseeritud kulud ei kao mahu vähenemisel.

## Matemaatika

```
Piirkulu = ΔKogukulu / ΔKogus
Keskmine kulu = Kogukulu / Kogus
```

## Lahendatud näide

Haiglavoodi keskmine kulu on £400/päevas (sh üldkulud), kuid ühe voodi vabastamine säästab vaid umbes £150/päevas tegelikult väldatavaid kulusid.

## Seos tarkvaraarendusega

Sarnaneb pilveinfrastruktuuriga: ühe eksemplari vähendamine säästab arvutuse piirkulu, mitte keskmist kulu kasutaja kohta, sealhulgas fikseeritud platvormikulud.

## Lõksud

- **Keskmise kulu kasutamine väikesemahuliste muudatuste säästu hindamiseks.**
- **Fikseeritud kulude käsitlemine muutuvatena.**
