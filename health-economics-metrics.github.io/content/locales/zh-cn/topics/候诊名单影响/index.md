# 候诊名单影响 (Waiting List Impact)

候诊名单影响把节省下来的临床产能，转化为从候诊名单上移除（或更快通过候诊名单）的患者数。把节省的工时转化为额外的门诊名额，能直接缩小一家信托机构的候诊名单规模——这是向卫生系统说明"被释放的产能究竟是为了什么"的最直观方式。

## 为什么重要

择期候诊名单是 NHS 后疫情时代最具代表性的挑战（其规模本身就是一项全国性的政治指标），每一家信托机构都在针对它推进一项择期医疗恢复计划。一份写着"节省 2,000 护士工时"的商业论证是抽象的；一份写着"创造 4,000 个额外预约名额，为 3,800 名候诊患者提供服务，使该专科的候诊名单缩短 9%"的商业论证，则是运营总监能够拿去向董事会汇报的故事。候诊名单影响是[非现金释放型产能](../现金释放型-vs-非现金释放型节约/)天然的*计量单位*。

## 计算方法

```
额外名额        = 释放的工时 / 单次名额时长 × 利用率
接诊患者数      = 额外名额 × (1 − DNA 率)
名单缩减量      = 接诊患者数 − 被诱发出的新增需求
等待时间收益    = 服务速率提升所带来的排队改善
                 （对于稳定队列，以服务速率 μ 将积压量 N 削减 ΔN，
                  会使所有人整体提前约 ΔN/μ）
```

等待更短所带来的健康价值：患者在治疗前较低效用值状态下停留的周数减少——具体的 QALY 算法参见[转诊至治疗](../转诊至治疗/)。

## 算例

环境文书记录软件为 20 名门诊护士中的每一位每天节省 45 分钟。以 250 个工作日计：20 × 0.75 × 250 = 每年 3,750 小时。

```
名额数（每次 30 分钟，85% 可用）= 3,750 / 0.5 × 0.85 = 6,375 个名额
接诊患者数（DNA 率 7%）        = 6,375 × 0.93       ≈ 每年 5,929 人
```

对于一个候诊名单为 12,000 人、按需匹配产能每年提供 24,000 次预约的专科而言，约 5,900 次额外预约能把平均等待时间缩短约四分之一——在不招聘的情况下，让该信托机构实质性地向 18 周标准迈进。按每次就诊约 £160 的方案价值计算，这部分活动量价值约为每年 £949,000（参见[国家统一收费标准与单位成本](../国家统一收费标准与单位成本/)）——但应优先呈现*候诊名单*这个框架；这正是该系统被考核所依据的那个框架。

## 与软件工程的关联

候诊名单本质上是一份积压需求 (backlog)，积压消化的经济学在两个方向上都可以迁移。从卫生领域迁移到软件领域：应按*用户*等待价值兑现的时长来为积压消化定价，而不是按关闭的条目数（即每个排队条目的[延迟成本](../延迟成本/)）。从软件领域迁移到卫生领域：利特尔法则 (Little's Law) 指出，只有当服务速率超过到达速率时，名单才会缩短——如果产能提升被不断上升的转诊量所吸收，等待时间就不会改变，因此也必须为到达速率建模。而在这两个领域中，都应按严重程度加权的价值来排定优先级（临床紧急程度分类 ↔ [严重程度调整系数](../qaly-短缺与严重程度修正系数/)），而不是先到先服务。

## 陷阱

- **名额数 ≠ 患者数**：忘记计入 DNA 率以及被释放时间中不可用的碎片。
- **诱发需求**：明显增加的产能会吸引更多转诊；名单的净影响会小于毛值。
- **把它当作现金来主张**：候诊名单影响是产能价值；现金层面的主张（避免的积压工作外包）是另外一条线——参见[可避免的外包成本](../可避免的外包成本/)。
