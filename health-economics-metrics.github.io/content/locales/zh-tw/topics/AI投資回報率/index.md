# AI投資回報率

AI投資回報率指可歸因於AI專案、且可測量的損益表回報。一個發人深省的基準資料：麻省理工學院2025年的"生成式AI鴻溝"（GenAI Divide）研究發現，儘管企業級生成式AI投資高達300–400億美元，但**約95%的試點專案未展現出可測量的損益表回報**——而成功的那5%則共享著一些可識別的共同做法。

## 為何重要

醫療系統對這種AI試點模式有個專門的說法：**"試點症"（pilotitis）**——NHS的應用墳場裡，堆滿了被永遠試點、卻從未真正推廣的"有前景"應用。麻省理工的發現，與衛生技術評估領域早已知曉的道理高度吻合：價值主張需要預先設定的終點指標，歸因需要對照組，而"大家都覺得它有幫助"並不能構成一條真正的效益線。在麻省理工的資料中，成功的少數派集中在具有可追蹤成本基線的後臺自動化場景，並且**採購的現成工具成功率約為67%，而內部自建工具的成功率大約只有其三分之一**——這一先驗經驗應當納入每一份AI投資論證（參見[自建與外購](../自建與外購/)）。

## 計算方法

```
AI投資回報率 = (可歸因效益 − AI總成本) / AI總成本

AI總成本 = 許可/推理費用（參見inference-unit-economics.md）
         + 整合成本 + 資料就緒成本 + 評估成本
         + 工作流程重新設計成本 + 治理/保障成本
         （許可費用通常只佔分母中的一小部分）

可歸因效益：需相對於基線或對照組測量，並按照
cash-releasing-vs-non-cash-releasing.md分類為現金/產能/品質三類
```

## 實例演算

某醫院集團在兩個用例中部署AI：

```
用例A——臨床信函起草（後臺場景，可追蹤）：
  基線：外包轉錄費用 每年£380,000
  實施後：轉錄合同已取消；臨床醫師複核時間成本增加£60,000
  AI成本：全包每年£120,000
  投資回報率 = (380,000 − 60,000 − 120,000) / 120,000 ≈ 167%——現金釋放型，可審計 ✓

用例B——"面向臨床醫師的AI副駕"（覆蓋面廣，未被追蹤）：
  效益主張："為4,000名員工節省時間"——未採集任何基線資料
  實測損益表影響：無法證實
  → 落入那95%的失敗群體，無論其實際上是否真的有幫助
```

二者的差別並不在於AI本身的品質高低——而在於該效益是否擁有**基線、責任人和預算科目**（參見[效益兌現](../效益兌現/)）。

## 與軟體工程的聯絡

適用於AI投資的衛生技術評估式打法：**像[NICE證據標準框架分級](../NICE證據標準框架/)那樣分階段積累證據**——低風險工具用演示級證據，全組織鋪開前先做對照試點，並預先登記推廣關口（參照[DiGA](../德國DiGA快速通道/)"附截止日期的臨時掛網"模式）；**像健康經濟學計算"需求規避"那樣計算"成本規避"**——只有當某個具體預算科目真正發生變化時，它才是真實的；並且**用[完美資訊期望價值（EVPI）](../完美資訊期望價值/)為試點本身定價**——一個無法改變推廣決策的試點，其價值為£0。關於開發者工具這一細分領域，另見[AI開發者生產力](../AI與開發者生產力/)。

## 陷阱

- **效益稀釋**：價值若稀薄地分散在成千上萬名使用者身上，從結構上就註定無法測量；應選擇基線集中、可追蹤的用例。
- **只計算許可費用**：整合、評估與工作流程重新設計的成本，通常才是分母中的主導部分。
- **歸因竊取**：AI與流程重新設計同時部署時，AI會"竊取"全部收益歸因。
- **沉沒試點的持續升級**：僅僅因為停止會等於承認失敗，就不斷延長已經失敗的試點——退出日期必須提前商定。
