# Xây dựng so với mua

Phân tích xây dựng so với mua so sánh tổng chi phí sở hữu và rủi ro cho việc phát triển nội bộ với việc mua sắm phần mềm thương mại.

## Tại sao điều này quan trọng

Một lựa chọn sai lầm có thể tốn hàng triệu bảng Anh và nhiều năm chi phí trì hoãn.

## Toán học

```
Chênh lệch giá trị hiện tại ròng = NPV(mua) − NPV(xây dựng)
```

## Ví dụ đã giải

Một hệ thống đặt lịch hẹn bệnh nhân: mua = £2 triệu/5 năm; xây dựng = £3,2 triệu/5 năm (bao gồm bảo trì).
