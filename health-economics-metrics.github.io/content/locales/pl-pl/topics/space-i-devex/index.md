# SPACE i DevEx

SPACE i DevEx to ramy do pomiaru produktywności deweloperów **wielowymiarowo**.

## Dlaczego to ważne

Obie ramy zawierają tę samą lekcję, której badania nad wynikami zdrowotnymi nauczyły się dekady temu.

## Matematyka

```
Reguła SPACE: ≥ 3 wymiary, ≥ 1 percepcyjny + ≥ 1 wskaźnik systemowy
```

## Rozwiązany przykład

Zespół platformy uzasadnia inwestycję w DevEx dla 300 deweloperów.

## Powiązanie z inżynierią oprogramowania

Ten dokument jest *dokładnie* stroną oprogramowania; transfer płynie w kierunku ekonomii zdrowia.
