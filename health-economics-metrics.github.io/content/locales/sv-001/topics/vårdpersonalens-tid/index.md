# Vårdpersonalens tid

Vårdpersonalens tid bör värderas som flaskhalskapacitet — det systemet kan leverera — inte bara som lönekostnad.

## Varför det är viktigt

En sparad läkartimme är ofta mycket mer värdefull än läkarens timlön antyder, eftersom läkartid är den begränsande faktorn för systemkapacitet.

## Matematiken

```
Värde av sparad tid = Sparade timmar × skuggpris för flaskhalskapacitet
```

## Genomarbetat exempel

En radiolog tjänar £80/timme, men varje sparad radiologtimme möjliggör effektivt £300 i nedströms patientgenomströmning på grund av kötryck.

## Koppling till mjukvaruutveckling

Liknar att värdera en senior arkitekts tid baserat på flaskhalsvärdet av deras beslut, inte bara deras lön.

## Fallgropar

- **Att bara använda lönekostnad för att värdera sparad tid.**
- **Att ge icke-flaskhalsroller samma skuggpris som flaskhalsroller.**
