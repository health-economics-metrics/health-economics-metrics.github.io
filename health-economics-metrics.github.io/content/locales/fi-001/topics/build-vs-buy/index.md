# Rakenna vastaan osta

Rakenna vastaan osta -analyysi vertailee kokonaisomistuskustannusta ja riskiä sisäisen kehityksen ja kaupallisen ohjelmiston hankinnan välillä.

## Miksi se on tärkeä

Väärä valinta voi maksaa miljoonia puntia ja vuosia viivästymisen kustannusta.

## Matematiikka

```
Nettonykyarvon ero = NNA(osta) − NNA(rakenna)
```

## Ratkaistu esimerkki

Potilaiden ajanvarausjärjestelmä: osta = £2 miljoonaa/5 vuotta; rakenna = £3,2 miljoonaa/5 vuotta (sisältäen ylläpidon).

## Yhteys ohjelmistokehitykseen

[Kokonaisomistuskustannuksen](../total-cost-of-ownership/) laskelmat ovat keskeinen tekijä tälle päätökselle.
