# Избежанные последующие затраты

Избежанные последующие затраты (компенсации затрат) — это будущие расходы на лечение, предотвращённые более ранним или лучшим действием, зачтённые против стоимости самого вмешательства. Компенсации — это механизм, благодаря которому вмешательство может стать *доминирующим* — дешевле **и** лучше, — и они же являются наиболее часто дублируемой, завышенной строкой в экономике здравоохранения.

## Почему это важно

Почти каждое ценностное предложение цифрового здравоохранения содержит заявление о компенсации: «наше приложение предотвращает госпитализации», «наши оповещения предотвращают ухудшение», «наша платформа избегает дублирующих анализов». Когда компенсации реальны, они трансформируют экономику (см. разобранный пример [ИКЭЭ](../инкрементальный-коэффициент-экономической-эффективности/), где компенсация в £600 тыс делает кейс успешным). Плательщики это знают — поэтому заявления о компенсации привлекают самое пристальное внимание в любой оценке. Приведённые ниже правила достоверности отличают финансируемую модель от маркетинга.

## Расчёт

```
Чистая стоимость = стоимость вмешательства − Σ компенсаций

Действительная компенсация должна быть:
  Относимой — причинно связанной с вмешательством (сравнительные доказательства)
  Предельной     — деньги реально перестают тратиться, по предельной, а не
                 средней стоимости (см. marginal-vs-average-cost.md)
  Взвешенной по вероятности — взвешенной по В(последующее событие произошло бы)
  Дисконтированной   — будущие избежанные затраты по текущей стоимости
  Уникальной       — учтённой один раз, в одной строке выгоды
```

## Разобранный пример

«Это заявление о риске миграции, сделанное правильно»: приложение мониторинга ран для 5000 послеоперационных пациентов заявляет об избежании реадмиссий, связанных с инфекциями.

```
Базовая реадмиссия по инфекции: 4,0%; с приложением (РКИ): 3,1%
Относимые избежанные события = 5000 × 0,009 = 45/год
Стоимость на эпизод реадмиссии (предельная, этот траст): £3200
Компенсация = 45 × 3200 = £144 000/год
Стоимость приложения = 5000 × £20 = £100 000/год
Чистая стоимость = −£44 000 → действительно экономит затраты, при этом:
  атрибуция из РКИ ✓  предельный расчёт ✓  вероятность из данных испытания ✓
```

То же заявление, построенное на «реадмиссии стоят в среднем £5800, мы предотвратим много», проваливает все четыре теста и заслуживает того отказа, который получает.

## Связь с программной инженерией

«Эта миграция избегает будущего переписывания» — это заявление о компенсации, и правила экономики здравоохранения делают его честным:

- **Контрфактическая стоимость**: сколько реально будет стоить переписывание, доказано как?
- **Вероятность**: насколько вероятно это будущее? (Не 100% — продукты закрываются, приоритеты меняются.)
- **Дисконтирование**: переписывание, избежанное в 4-м году при дисконте 3,5-10%, стоит намного меньше номинала.
- **Уникальность**: не заявляйте то же избежанное переписывание одновременно в строке технического долга и строке удержания.

`Ценность компенсации = В(будущее событие) × контрфактическая стоимость × коэффициент дисконтирования` — впишите эту строку в предложение и наблюдайте, как оценка становится предметом дискуссии, что и является целью.

## Подводные камни

- **Двойной учёт** — одна и та же избежанная госпитализация, заявленная как компенсация, койко-дни и QALY с прикреплённой стоимостью.
- **Компенсации по средней стоимости** для событий, чьи фиксированные затраты продолжаются в любом случае.
- **Тихая 100%-ная вероятность** для последующих событий, которые были лишь возможны.
- **Компенсации в другие бюджеты**, представленные как экономия плательщику, которого просят заплатить — см. [перспектива анализа](../перспектива-анализа/).
