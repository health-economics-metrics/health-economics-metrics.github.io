# 労働生産性・活動障害(WPAI)

WPAIは、健康上の問題が有給の仕事と日常活動にどれだけ影響するかを、通常は過去7日間について測定する、検証済みの自己記入式質問票です(Reilly、Zbrozek、Dasbach、1993年)。損失を、文字どおり失われた労働時間である*欠勤*(アブセンティーイズム)と、身体的には職場にいるものの生産性が下がっている*出勤しているが生産性が低下した状態*(プレゼンティーイズム)に分けます。後者は通常、より大きく、より見えにくいコストの構成要素です。

## なぜ重要か

単純な病欠日数の集計では、欠勤しか見えません。一度も休まないが慢性疾患のために60%の能力で働いている臨床医や知識労働者は、欠勤記録には何も寄与しませんが、それでも大きな現実の生産性の損失を生み出します。WPAIは、まさにこの見えないコストを浮かび上がらせるよう設計されています。特注の調査ではなく検証済みの尺度であるため、その得点は、査読者が尺度を再検証しなくても、[患者報告アウトカム](../患者報告アウトカム/)のエビデンスパッケージや疾病費用研究で使えます。自己記入式の尺度として、それ自体がPROMの一種であり、症状や生活の質ではなく仕事と活動に焦点を当てていることが主な特徴です。

## 数式

```
欠勤率 % = 健康上の理由で欠勤した時間 / (健康上の理由で欠勤した時間 + 働いた時間) × 100

プレゼンティーイズム率 % = 勤務中の自己評価による0〜10の障害度 × 10
                  (質問票で直接引き出し、ここでは導出しない)

総労働障害率 % =
    欠勤率% + (1 − 欠勤率%/100) × プレゼンティーイズム率%
    (2つを合成し、合計が100%を超えないようにする)

生産性コスト = 総労働障害率% / 100 × 期間の収入
```

総障害率の式は、意図的に単純な和ではありません。2つの割合を直接足すと100%を超える可能性があるため、プレゼンティーイズムは労働時間の*残り*(欠勤していない)部分にのみ適用します。

## 計算例

片頭痛のある従業員が週40時間勤務の予定ですが、そのうち4時間を欠勤します。

```
欠勤時間 = 4, 働いた時間 = 36
欠勤率% = 4 / (4 + 36) × 100 = 10%
```

その人は勤務中の生産性への影響を、WPAIの質問票で10点満点中3と別途自己評価しており、`プレゼンティーイズム率% = 30%`です(このステップは質問票の生の回答であり、他の数値から導かれるものではありません)。

```
総労働障害率% = 10 + (1 − 10/100) × 30
              = 10 + 0.9 × 30
              = 10 + 27
              = 37%
```

収入が週5日で£800(1日£160)の場合:

```
生産性コスト = 37/100 × 800 = £296
```

単純な病欠日数の集計では、欠勤した4時間(10%)しか記録されなかったはずです。プレゼンティーイズムの要素を数えると、実際の障害はほぼ3倍近くになります。

## ソフトウェア工学との関連

これは、エンジニアリングチームの健全性メトリクスにそのまま対応します。

- **欠勤**は病気休暇や有給休暇で、目に見え、すでに追跡されている、容易な部分です。
- **プレゼンティーイズム**は、燃え尽きた、あるいはコンテキストスイッチに圧倒されたエンジニアが、毎回のスタンドアップに出席していながら能力が低下した状態で働いていることで、通常はより大きく、より隠れたコストであり、人数や出勤のデータからは見えません。代わりに、[DORA](../doraメトリクス/)や[フローメトリクス](../フローメトリクス/)でのスループットの低下として、あるいは、その「利子」が障害をさらに悪化させる[技術的負債](../技術的負債/)の解消の遅れとして現れます。
- エンジニアリングの教訓は臨床のものと同じです。欠勤だけを測ってそれを「生産性の損失」と呼ぶと、出勤していても能力が落ちている全員を見逃すため、実際のコストを体系的に過小評価します。

## 落とし穴

- **自己申告の想起バイアス。** 7日間の想起期間は、あらゆる後ろ向きの自己申告と同じ報告の歪みの影響を受けます。
- **0〜10のプレゼンティーイズム尺度を真の物理的測定として扱うこと。** これは順序尺度で、自己評価によって引き出されたものであり、検証された物理量ではありません。その差を厳密に線形または間隔尺度として扱うのは、検証された物理的事実ではなく、モデル化上の便宜です。
- **WPAIのバリアントをまたいで得点をプールすること。** WPAIには、状態に特化した複数のバージョンがあります。WPAI:GH(一般的健康)、WPAI:SHP(特定の健康問題)、疾患特異的なバリアントなどで、異なるバリアントの得点は、同じ尺度のバージョンであることを先に確認せずにプールしたり比較したりしてはいけません。
