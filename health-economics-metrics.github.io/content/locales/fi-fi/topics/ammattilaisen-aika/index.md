# Ammattilaisen aika

Ammattilaisen aika tulisi arvostaa pullonkaulakapasiteettina — sitä, mitä järjestelmä voi toimittaa — ei pelkästään palkkakustannuksena.

## Miksi se on tärkeä

Säästetty lääkärintunti on usein paljon arvokkaampi kuin lääkärin tuntipalkka antaisi ymmärtää, koska lääkäriaika on järjestelmäkapasiteetin sitova rajoite.

## Matematiikka

```
Säästetyn ajan arvo = Säästetyt tunnit × pullonkaulakapasiteetin varjohinta
```

## Ratkaistu esimerkki

Radiologi ansaitsee £80/tunti, mutta jokainen säästetty radiologin tunti mahdollistaa tehokkaasti £300 alavirran potilasläpimenoa jonopaineen vuoksi.

## Yhteys ohjelmistokehitykseen

Muistuttaa vanhemman arkkitehdin ajan arvostamista heidän päätöstensä pullonkaula-arvon perusteella, ei pelkästään palkan.

## Sudenkuopat

- **Vain palkkakustannuksen käyttäminen säästetyn ajan arvostamiseen.**
- **Muille kuin pullonkaularooleille saman varjohinnan antaminen kuin pullonkaularooleille.**
