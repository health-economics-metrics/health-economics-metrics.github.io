# 予算影響分析(BIA)

BIAは、ある介入を採用することが、特定の支払者の**予算**に今後1〜5年間でどう影響するかを推定します。これは*手頃さ*に答えます;費用効果は*価値*に答えます。ある技術は優れた価値がありながら手頃ではない、あるいは手頃でありながら価値が乏しいことがあります。本格的な評価にはその両方が必要です。

## なぜ重要か

財務担当者の問いは決して「ICERはいくつか?」ではなく、「これが来年度の予算にどう影響するか?」です。ISPORの実務指針(この分野の標準)は次のように定めています:支払者自身の視点、1〜5年の評価期間、*割引前*の年間キャッシュフロー、現実的な普及曲線、そして(確率的ではなく)シナリオによる不確実性。NICEは費用効果とともに予算影響の情報を要求します;イングランドで年間約£2,000万を超える全国予算影響を持つ製品は、そのICERにかかわらず商業交渉を引き起こします。

## 数式

```
予算影響_年t = 費用シナリオ_新規導入時(t) − 費用シナリオ_現状(t)

費用シナリオ(t) = 患者グループにわたる合計:
   対象人口(t) × 普及率(t) × 患者1人あたりの正味費用(t)

患者1人あたりの正味費用 = 介入費用 − 置き換えられたケアの費用 + 誘発されたケアの費用
```

主要なモデリング上の選択:対象人口の成長、普及曲線(導入は決して瞬時ではない)、新しい選択肢が何を置き換えるか、そしてそれが*誘発する*需要(アクセスが容易になる → 利用者が増える)。

## 計算例

200万人をカバーする支払者が、患者1人あたり年間£300のデジタル治療薬の導入を検討しています;対象となるのはメンバーの1.5%(30,000人);普及率は3年間で20% → 40% → 60%;各利用者は年間£120の他のケアを置き換えます。

```
利用者1人あたりの正味費用 = 300 − 120 = £180

1年目: 30,000 × 0.20 × 180 = £1.08M
2年目: 30,000 × 0.40 × 180 = £2.16M
3年目: 30,000 × 0.60 × 180 = £3.24M
```

たとえこの製品のICERが見事な£8,000/QALYであっても、支払者は3年目までに£3.24Mの*新規資金*を見つけなければなりません — 置き換えられた£120は他の予算項目に薄く広がっており、現金として解放されることはありません([現金化可能な節約と非現金化節約](../cash-releasing-vs-non-cash-releasing/)を参照)。これが、単位あたりの価値と手頃さが別々のハードルである理由です。

## ソフトウェア工学との関連

BIAは、1席あたりのROIの主張に対する、まさにCFO向けの補完物です:「開発者1人あたりでは費用効果が高いが、今年度の会計年度で組織全体への展開を賄えるか?」ライセンスの階層、採用のSカーブ、旧契約が実際に終了したときにのみ現金化される置き換えられたツール支出、そして誘発された利用(より安いCI → より多くのCI)をモデル化してください。3年間の予算影響表をROIと並べて提示することが、企業向けツール提案を財務的に信頼できるものにします。 公表された予算影響額の合計を拠点、コホート、会計年度に分割し、各部分が公表された数値にちょうど一致するようにすることは、まさに[セント単位で正確なコスト配分](../exact-cents-cost-allocation/)です。そもそも合計を構成する多数の項目を足し合わせることは、[通貨安全なコスト集計](../currency-safe-cost-rollup/)です。

## 落とし穴

- **瞬時普及という空想**:1年目の影響が定常状態の採用率で計算されている。
- 置き換えられた費用が拡散した容量であるにもかかわらず、それを**現金として数えること**。
- **誘発需要を無視すること** — アクセスの改善は対象人口の利用を増加させます。
- **BIAとCEAの評価期間/割引を混同すること**:BIAは設計上、短い評価期間、割引なし、支払者に特化しています。
