# Економіка віддаленого моніторингу пацієнтів

Економіка віддаленого моніторингу пацієнтів вимірює економію коштів, яку приносить технологія домашнього моніторингу, зменшуючи госпіталізації, повторні госпіталізації та особисті візити.

## Чому це важливо

Віддалений моніторинг вимагає початкових витрат на обладнання, але може запобігти дорогому використанню невідкладної допомоги.

## Математика

```
Чиста економія = (кількість уникнених госпіталізацій × вартість на госпіталізацію) − вартість програми
```

## Розібраний приклад

Віддалений моніторинг серцевої недостатності: 40 уникнених госпіталізацій × £4000 = £160 000 економії − вартість програми £60 000 = чиста економія £100 000.

## Зв'язок з інженерією програмного забезпечення

Прямо пов'язане з [заощадженими ліжко-днями](../заощаджені-ліжко-дні/) та [рівнем повторної госпіталізації](../рівень-повторної-госпіталізації/), та залежить від [валідації носимих пристроїв](../валідація-носимих-пристроїв/) для якості даних.
