# टाली गई डाउनस्ट्रीम लागत

टाली गई डाउनस्ट्रीम लागत (लागत समायोजन) वे भविष्य के उपचार व्यय हैं जिन्हें पहले या बेहतर कार्रवाई द्वारा रोका जाता है।

## यह क्यों महत्वपूर्ण है

लगभग हर डिजिटल स्वास्थ्य मूल्य प्रस्ताव में एक समायोजन दावा होता है: "हमारा ऐप प्रवेश रोकता है।"

## गणित

```
शुद्ध लागत = हस्तक्षेप लागत − Σ समायोजन

एक वैध समायोजन होना चाहिए:
  श्रेय योग्य — हस्तक्षेप से कारणात्मक रूप से जुड़ा
  सीमांत     — पैसा वास्तव में खर्च होना बंद हो जाता है
  संभावना-  — P(डाउनस्ट्रीम घटना होती) द्वारा भारित
  भारित
  छूट प्राप्त — भविष्य की टाली गई लागत वर्तमान मूल्य पर
```

## हल किया गया उदाहरण

5,000 पोस्ट-सर्जिकल रोगियों के लिए एक घाव-निगरानी ऐप संक्रमण-संबंधी पुनः प्रवेश से बचाव का दावा करता है:

```
श्रेय योग्य टाली गई घटनाएँ = 5,000 × 0.009 = सालाना 45
समायोजन = 45 × 3,200 = सालाना £144,000
शुद्ध लागत = −£44,000 → वास्तव में लागत-बचत करने वाला
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

"यह माइग्रेशन भविष्य के पुनर्लेखन से बचाता है" एक समायोजन दावा है।

## सामान्य गलतियाँ

- **दोहरी गिनती।**
- स्थिर लागत के लिए **औसत-लागत समायोजन।**
