# การรักษาผู้ใช้และการเลิกใช้

การรักษาผู้ใช้และการเลิกใช้วัดสัดส่วนของผู้ใช้ที่ยังคงใช้ผลิตภัณฑ์สุขภาพดิจิทัลต่อไปตามเวลา เทียบกับจำนวนที่หยุดใช้งาน

## ทำไมจึงสำคัญ

อัตราการเลิกใช้งานที่สูงบ่อนทำลายคุณค่าระยะยาวของการแทรกแซงด้านสุขภาพดิจิทัล แม้ว่าการนำไปใช้เริ่มต้นจะแข็งแกร่งก็ตาม

## คณิตศาสตร์

```
อัตราการเลิกใช้ = ผู้ใช้ที่สูญเสียในช่วงเวลา / จำนวนผู้ใช้ ณ ต้นช่วงเวลา × 100%
```

## ตัวอย่างที่คำนวณแล้ว

แอปสุขภาพจิตที่มีผู้ใช้ 1,000 คนในต้นเดือนและมีผู้ใช้ 150 คนหยุดใช้งานในเดือนนั้น ให้อัตราการเลิกใช้ 15%/เดือน — อัตราที่ไม่ยั่งยืนสำหรับผลกระทบระยะยาว

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

เปรียบเทียบได้โดยตรงกับอัตราการเลิกใช้ของลูกค้าในผลิตภัณฑ์ SaaS ซึ่งมีความสำคัญต่อกรณีทางธุรกิจแบบรายได้ซ้ำ

## ข้อผิดพลาดที่พบบ่อย

- **การสับสนระหว่างการเลิกใช้งานในระยะแรกกับการใช้งานระยะสั้นที่ตั้งใจไว้ (เช่น โปรแกรม 6 สัปดาห์)**
- **การไม่ตรวจสอบสาเหตุของการเลิกใช้งานก่อนออกแบบการแทรกแซง**
