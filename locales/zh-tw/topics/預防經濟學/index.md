# 預防經濟學

預防經濟學關注的是在疾病發生或進展之前進行介入的經濟學問題。其頭條結論頗為反直覺：**大多數預防措施並不能省錢**——它們只是以一個不錯的價格買到了健康。Cohen、Neumann與Weinstein在NEJM發表的里程碑式分析發現，不到20%的預防性介入措施能真正實現淨成本節約；其餘的充其量只是具有成本效果。

## 為何重要

"預防能省錢"是衛生政策領域中被重複最多的錯誤說法，凡是建立在這一說法之上的商業案例，都會被健康經濟學家徹底拆穿。誠實的結構是：預防措施現在就要花錢（為整個人群做篩查、為那些本來根本不會生病的人治療風險因素），而回報卻在未來才能兌現——通常是以一個*不錯*的每QALY成本實現，偶爾能真正省錢，有時價格卻極為糟糕。搞清楚自己究竟處於哪種情形，正是這項分析的核心所在。這一區分在商業上同樣至關重要：一款以"為NHS省錢"為賣點銷售的預防類產品，會招來一場它註定通不過的審計；而若以"以£4,000買到一個QALY"為賣點銷售，在完全相同的事實基礎上卻能夠勝出。路徑內部版本的類似討論，參見[更早介入](../更早介入/)。 在為預防專案核算成本之前，[人群歸因分數](../人群歸因分數/)先回答規模問題——專案所針對的危險因素能夠合理地消除目標疾病負擔的多大比例。

## 計算方法

```
預防措施的淨成本（每人） =
    介入成本 × 所有接受治療的人數
  − 被避免的下游成本 × 那少數本來會病情進展的人
  （二者均需貼現——被避免的成本往往在多年之後才會發生；參見
   discounting-and-time-preference.md）

要實現成本節約，需滿足：介入成本 < P(病情進展) × 被避免的成本 × 貼現因子
要實現具有成本效果，只需滿足：淨成本 / 獲得的QALY < 閾值
```

預防悖論：介入成本要乘以整個人群規模；而效益卻只惠及那反事實情形下少數會真正病情進展的人。

## 實例演算

某高血壓管理應用面向10萬名高風險成年人推廣，每人每年£25。10年內，它預防了400例中風（每例貼現後成本£45,000，並損失3個QALY）。

```
成本：    100,000 × £25 × 10年（貼現後約×8.3）≈ £2,080萬
衝抵額：  400 × £45,000 = £1,800萬
淨成本 ≈ £280萬——並*未*實現成本節約

獲得的QALY = 400 × 3 = 1,200
每QALY成本 = 280萬 / 1,200 ≈ £2,300/QALY——極其具有成本效果
```

同一個專案，兩種同時成立的事實：它在現金上損失了£280萬，卻以NICE閾值的十分之一價格買到了健康。應據第二個數位為其提供資助；絕不能承諾第一個數位。

## 與軟體工程的聯絡

左移品質正是預防經濟學的體現，連同其中的告誡一併適用。評審、測試與靜態分析，會為*每一次*變更都增加成本，以求在那少數本會演變為生產環境事件的變更中捕獲問題。缺陷成本曲線（按階段相差10–100倍）扮演的角色，正相當於中風的成本——而誠實的結論也與健康領域如出一轍：左移通常具有成本*效果*，而非自動就能*節省*成本，因為大多數被標記出的問題，本來根本就不會演變成真正的事件（這正是"反事實情形下的少數問題"這一困境）。可以這樣計算：每個週期的關卡總成本，對比實際避免的事件數 × 每次事件的成本——與上文實例演算結構完全相同，其中[NNT](../需治療人數/)則是"每捕獲一次問題"所對應的計量單位。

## 陷阱

- **在證據只支援"具有成本效果"時，卻主張"節省了成本"**——這是預防倡導者在兩個領域中都會犯的典型錯誤。
- **未貼現的未來衝抵額**：將15年後的效益按其面值直接計算。
- **忽視過度診斷/過度治療的成本**：預防措施同樣會發現"偽疾病"——參見[篩查經濟學](../篩查經濟學/)。
