# Bygga kontra köpa

Analysen bygga kontra köpa jämför total ägandekostnad och risk för intern utveckling med anskaffning av kommersiell mjukvara.

## Varför det är viktigt

Ett felaktigt val kan kosta miljontals pund och flera års kostnad för fördröjning.

## Matematiken

```
Skillnad i nettonuvärde = NNV(köpa) − NNV(bygga)
```

## Genomarbetat exempel

Ett patientbokningssystem: köpa = £2 miljoner/5 år; bygga = £3,2 miljoner/5 år (inklusive underhåll).

## Koppling till mjukvaruutveckling

Beräkningar av [total ägandekostnad](../total-cost-of-ownership/) är en nyckelfaktor för detta beslut.

## Fallgropar

- **Att ignorera leverantörsbindningskostnader.**
