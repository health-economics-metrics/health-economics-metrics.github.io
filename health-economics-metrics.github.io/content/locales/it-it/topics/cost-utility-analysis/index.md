# Analisi Costo-Utilità (CUA)

La CUA è un'analisi costo-efficacia con un **risultato generico ponderato per preferenza** — quasi sempre il [QALY](../quality-adjusted-life-year/).

## Perché è importante

Un servizio sanitario nazionale deve scegliere tra un farmaco antitumorale, un'app per la salute mentale e un robot chirurgico da un unico budget.

## La matematica

```
ICUR = ΔCosto / ΔQALY
```

## Esempio risolto

Un'app CBT per l'ansia moderata rispetto a una lista d'attesa per terapia faccia a faccia.

## Collegamento con l'ingegneria del software

L'idea profonda della CUA — *un'unica unità composita ponderata per preferenza per confrontare cose dissimili*.

## Insidie

- **Guadagni di utilità al di sotto della sensibilità dello strumento.**
