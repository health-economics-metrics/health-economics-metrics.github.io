# 卫生技术评估（HTA）

卫生技术评估是卫生系统用以决定某项技术——药物、器械或软件——是否值得付费采用的正式化、制度化流程。它在一套已公开、强制执行的方法论下，将临床效果证据与经济学评估结合起来。

## 为何重要

如果你向国家医疗服务体系销售产品，卫生技术评估机构很可能直接决定你的市场准入。了解当地的具体流程，就是了解真正决定你产品价值的那道监管关卡：

- **NICE（英格兰）**：在明确界定的*参考案例*下进行法定评审——QALY来自[EQ-5D](../EQ-5D/)，采用NHS+PSS[视角](../分析视角/)，3.5%[贴现率](../贴现与时间偏好/)，要求[概率敏感性分析（PSA）](../概率敏感性分析/)——以£20,000–£30,000/QALY为判定标准，并结合[严重程度调整因子](../QALY缺口与严重程度调整因子/)；高度专科化技术可加权至£100,000以上。
- **ICER（美国，非政府组织）**：出具带有*健康获益价格基准*的证据报告——即在每QALY/evLYG（当量生命年）$100,000–$150,000下，产品具有成本效果所对应的价格——被用作谈判筹码；此外还包含预算影响"可负担性警示"。
- **加拿大（CADTH → CDA-AMC）**：以约CAD$50,000/QALY为标准进行报销审查；历史上约95%的申报都被要求降价。

## 计算方法

卫生技术评估的力量并非来自某个公式，而是来自一套**强制执行的方法**：每一份申报都在相同的参考案例规则下计算相同的[ICER](../增量成本效果比/)，从而使结果能够跨产品、跨年份进行比较。参考案例明确规定了结果指标、效用量表工具、视角、对照方案的选择、贴现率、时间范围以及不确定性分析——消除了赞助方可能用来操纵结果的每一个自由度。

## 实例演算

某数字疗法提交至NICE式评审：

```
模型：ΔC = +£450/患者，ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ 低于£20,000
参考案例检查项：
  效用值来自采用英国价值集的EQ-5D-5L                  ✓
  对照方案 = 现行照护路径（而非"不治疗"）              ✓
  PSA：在£20,000阈值下具有成本效果的概率为71%           ✓（已报告）
  严重程度调整因子：缺口低于×1.2的边界                 ——未主张
建议：纳入常规委托服务范围，并同步开展真实世界数据采集。
```

赞助方自己偏好的分析结果原本显示每QALY £9,000；正是参考案例通过强制使用诚实的对照方案，才将其推高至£15,000。这个差距，正是参考案例制度存在的*根本原因*。

## 与软件工程的联系

可迁移的产物是**内部参考案例**：为所有工具/平台商业论证设立一套强制统一的方法——明确声明的对照方案、标准单位成本（相关模式参见[全国统一收费标准](../全国统一收费标准与单位成本/)）、固定贴现率、强制要求的敏感性分析、标准模板。向平台委员会提交一份"面向工具的AMCP式档案"，能使各项提案具有可比性，并使操纵行为无所遁形——正如卫生技术评估对药物所做的那样。不必一开始就做到NICE那种规模：一份两页纸的模板，配上一本已公开的价目手册，胜过完全没有标准。

关于多周期 HTA 模型究竟如何逐队列、逐周期模拟，见[马尔可夫队列模拟](../马尔可夫队列模拟/)。

## 陷阱

- **把卫生技术评估当作获得监管批准后的一道形式手续**——CE/UKCA/FDA认证只说明产品是安全的；而卫生技术评估决定的是它是否*值得购买*。这是两道不同的门槛，需要不同的证据。
- **在试验之后才构建经济学模型**——证据生成的设计，应当从参考案例的要求出发反向推导。
- **忽视司法辖区之间的差异**：一个在美国以$120,000/QALY可获资助的ICER，在英国£30,000的NICE标准下会不通过；应按每个市场分别规划证据与定价策略。
