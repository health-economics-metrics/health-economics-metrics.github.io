# Järelvoolu ressursside optimeerimine

Järelvoolu ressursside optimeerimine keskendub rolli või protsessi avamisele, mida kõik teised ootavad, selle asemel et optimeerida juhuslikult.

## Miks see on oluline

Mitte-kitsaskoha sammude parandamine raviteekonnal ei mõjuta kogu tarneaega — ainult kitsaskoht ise määrab süsteemivõimsuse.

## Matemaatika

```
Süsteemi läbilaskevõime = piirava sammu (kitsaskoha) läbilaskevõime
```

## Lahendatud näide

Diagnostikateekonnal on viis sammu; samm 3 (pildi tõlgendamine) on pikima ooteajaga. Sammude 1, 2, 4 ja 5 kiirendamine ei mõjuta kogu tarneaega enne, kui samm 3 lahendatakse.

## Seos tarkvaraarendusega

Otsene analoog piirangute teooriale, mida rakendatakse CI/CD torustikele — kiirendage aeglaseimat sammu, mitte juhuslikku sammu.

## Lõksud

- **Ressursside investeerimine mitte-kitsaskoha protsessidesse, kuna neid on lihtsam parandada.**
- **Kitsaskoha mittetuvastamine uuesti pärast eelmise lahendamist (kitsaskoht nihkub).**
