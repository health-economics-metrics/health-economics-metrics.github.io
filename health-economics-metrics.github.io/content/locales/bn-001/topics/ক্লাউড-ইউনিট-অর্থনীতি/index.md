# ক্লাউড ইউনিট অর্থনীতি (FinOps)

ক্লাউড ইউনিট অর্থনীতি কাঁচা ক্লাউড ব্যয়কে **প্রতি ইউনিট আউটপুট খরচে** অনুবাদ করে — প্রতি গ্রাহক, প্রতি লেনদেন, প্রতি সমাধানকৃত কেস, প্রতি টোকেন। এটি FinOps ক্ষমতা যা "আমাদের AWS বিল £400হাজার/মাস"-কে "একজন রোগীর সেবা করতে খরচ £0.83"-এ পরিণত করে।

## কেন এটি গুরুত্বপূর্ণ

মোট ব্যয় সংখ্যা সেই প্রশ্নগুলির উত্তর দিতে পারে না যা গুরুত্বপূর্ণ: পণ্যটি কি আরও বা কম দক্ষ হচ্ছে? বৃদ্ধি কি মার্জিন উন্নত করে নাকি ধ্বংস করে? আমাদের কী চার্জ করা উচিত? ইউনিট খরচ তিনটিরই উত্তর দেয়। বিশেষভাবে ডিজিটাল স্বাস্থ্যের জন্য, "প্রতি সমাধানকৃত কেস খরচ" *হল* একটি স্বাস্থ্য-সেবা ইউনিট খরচ — একজন কমিশনার প্রতিটি অন্য পরিষেবার জন্য ব্যবহার করেন এমন [National Cost Collection](../জাতীয়-তারিখ-ও-ইউনিট-খরচ/) পরিসংখ্যানের সাথে সরাসরি তুলনাযোগ্য, যা এটিকে ঐতিহ্যবাহী পথের বিরুদ্ধে ডিজিটাল পথের মূল্য নির্ধারণের প্রাকৃতিক ভাষা করে তোলে।

## গণনা

```
ইউনিট খরচ = মোট বরাদ্দকৃত খরচ (ভাগাভাগি/প্ল্যাটফর্ম খরচ সহ) / প্রদত্ত ইউনিট

দুটি পরিবার:
  সম্পদ-দক্ষতা ইউনিট: খরচ/GB সংরক্ষিত, খরচ/vCPU-ঘণ্টা, খরচ/টোকেন,
                       খরচ/বিল্ড-মিনিট
  ব্যবসায়িক ইউনিট:    খরচ/গ্রাহক, খরচ/লেনদেন, খরচ/পরামর্শ,
                       খরচ/সমাধানকৃত-কেস

প্রান্তিক বনাম গড় শৃঙ্খলা প্রযোজ্য (marginal-vs-average-cost.md):
প্রতিশ্রুত/সংরক্ষিত ব্যয় পরবর্তী প্রতিশ্রুতি ধাপ পর্যন্ত প্রান্তিক ইউনিট
খরচকে ≈ 0 করে তোলে — প্রান্তিকে সম্প্রসারণ সিদ্ধান্ত মূল্য নির্ধারণ করুন,
গড়ে দক্ষতা প্রবণতা।
```

## বিস্তারিত উদাহরণ

একটি ডিজিটাল ট্রায়াজ পরিষেবা: ক্লাউড ব্যয় £62,000/মাস (কম্পিউট £30হাজার, ডেটা £18হাজার, ভাগাভাগি প্ল্যাটফর্ম বরাদ্দ £14হাজার), মাসে 380,000টি ট্রায়াজ এপিসোড পরিচালনা করে:

```
প্রতি এপিসোড গড় খরচ = 62,000 / 380,000 ≈ £0.163

কমিশনার তুলনা: টেলিফোন ট্রায়াজ ≈ £8-12/কল, জিপি পরামর্শ ≈ £42
→ ডিজিটাল এপিসোড সবচেয়ে সস্তা মানব বিকল্পের ~2%-এ চলে —
gds-service-metrics.md-এর চ্যানেল-স্থানান্তর অর্থনীতি, খরচের দিক থেকে।

প্রবণতা পরীক্ষা: গত বছর £0.21/এপিসোড 240হাজার এপিসোডে → উন্নত স্কেল
অর্থনীতি (নির্দিষ্ট প্ল্যাটফর্ম খরচ পরিশোধিত হচ্ছে), QBR-এ একটি শিরোনামের যোগ্য।
```

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

ইউনিট অর্থনীতি হল যেখানে ইঞ্জিনিয়ারিং পছন্দগুলি অর্থ-পাঠযোগ্য হয়ে ওঠে: একটি স্থাপত্য যা প্রতি-এপিসোড-খরচ অর্ধেক করে একটি মূল্য নির্ধারণ সুবিধা; যেটি সুপার-লিনিয়ারভাবে স্কেল করে তা একটি টাইম বোমা যা শুধুমাত্র এই মেট্রিকে দৃশ্যমান। স্বাস্থ্য খরচ নির্ধারণ থেকে স্থানান্তরিত অনুশীলন: **বরাদ্দ নিয়মগুলি প্রকাশ করুন** (ভাগাভাগি খরচ PLICS রোগী-স্তরের খরচ নির্ধারণ মানসম্মত করা পর্যন্ত প্রতি-ইউনিট পরিসংখ্যান বিকৃত করেছিল — আপনার প্ল্যাটফর্ম-খরচ বরাদ্দের একই কঠোরতা প্রয়োজন); **ক্রেতা যে ইউনিটে চিন্তা করেন তা বেছে নিন** (কমিশনাররা এপিসোড কেনেন, vCPU নয়); এবং প্রতিটি [ICER](../ইনক্রিমেন্টাল-খরচ-কার্যকারিতা-অনুপাত/) এবং [বাজেট প্রভাব](../বাজেট-প্রভাব-বিশ্লেষণ/) মডেলে কর্তৃত্বপূর্ণ খরচ হর হিসেবে ইউনিট খরচ প্রবেশ করান। AI ফিচারের জন্য, ইউনিট হল টোকেন — দেখুন [ইনফারেন্স ইউনিট অর্থনীতি](../ইনফারেন্স-ইউনিট-অর্থনীতি/)।

## ঝুঁকি

- **ভাগাভাগি খরচ উপেক্ষা করা**: প্ল্যাটফর্ম/নিরাপত্তা/অন-কল বরাদ্দ বাদ দেওয়া ইউনিট খরচ 30-50% কম দেখায় এবং নিরীক্ষায় ভেঙে পড়ে।
- **অহংকার হর**: "প্রতি API কল খরচ" চাটুকারিতা করে; "প্রতি সম্পন্ন রোগী এপিসোড খরচ" অবহিত করে।
- **প্রান্তিক সিদ্ধান্তের গড়-খরচ মূল্য নির্ধারণ**: প্রান্তিকভাবে বিনামূল্যে ব্যবহারের জন্য গড় ইউনিট খরচ দলগুলিকে চার্জ করা অপচয়-এড়ানো থিয়েটার চালায় (এই প্রণোদনা বাগের NHS সংস্করণের জন্য দেখুন [জাতীয় তারিখ](../জাতীয়-তারিখ-ও-ইউনিট-খরচ/))।
