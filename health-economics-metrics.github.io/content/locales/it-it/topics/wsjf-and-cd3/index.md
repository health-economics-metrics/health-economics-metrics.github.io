# WSJF e CD3

CD3 e WSJF sono regole di prioritizzazione che pianificano il lavoro in base alla **densità di valore**.

## Perché è importante

Ogni backlog è un problema di razionamento.

## La matematica

```
CD3 = Costo del Ritardo (£/settimana) / Durata (settimane)
```

## Esempio risolto

Tre funzionalità, un team: ordine CD3: B, C, A.

## Collegamento con l'ingegneria del software

Per i portafogli software sanitari, esprimete il CoD in QALY/settimana.
