# 유지율과 이탈

유지율과 이탈은 사용자가 시간이 지남에 따라 건강 앱 사용을 계속하는지 또는 중단하는지를 측정합니다.

## 왜 중요한가

건강 앱의 이탈률은 일반 소비자 앱보다 훨씬 높은 경향이 있습니다.

## 수식

```
월간 이탈률 = 해당 월 이탈 사용자 수 / 월초 총 사용자 수 × 100%
```

## 계산 예시

정신건강 앱: 월초 5,000명, 이탈 750명 = 월간 이탈률 15%.
