# การเปรียบเทียบ ICER ข้ามสกุลเงิน

การเปรียบเทียบ[ICER](../อัตราส่วนความคุ้มทุนส่วนเพิ่ม/)ที่คำนวณเป็นสกุลเงินของประเทศหนึ่งกับ[เกณฑ์ความเต็มใจจ่าย](../เกณฑ์ความเต็มใจจ่าย/)ของอีกประเทศหนึ่ง — หรือการรวมข้อมูลต้นทุนที่เก็บจากการทดลองหลายประเทศ — ต้องมีขั้นตอนแปลงสกุลเงินที่ชัดเจนและตรวจสอบได้ หากเลือกวิธีแปลงผิด หลักฐานเดียวกันอาจพลิกการตัดสินใจนำมาใช้ ทั้งที่ข้อมูลทางคลินิกหรือต้นทุนไม่ได้เปลี่ยนแปลง

## ทำไมจึงสำคัญ

แนวทางด้านระเบียบวิธีของ ISPOR สำหรับการทดลองทางคลินิกหลายประเทศ (Willke และคณะ, *Health Economics*, 1998) แนะนำให้แปลงต้นทุนทรัพยากรด้วย **ความเท่าเทียมของอำนาจซื้อ (PPP)** — ไม่ใช่อัตราแลกเปลี่ยนตลาด — เมื่อเปรียบเทียบมูลค่าทางเศรษฐกิจที่แท้จริงของทรัพยากรข้ามประเทศ และสงวนอัตราแลกเปลี่ยนเงินตราต่างประเทศของตลาดไว้ใช้ตามวัตถุประสงค์จริง คือการสร้างแบบจำลองกระแสการชำระเงินสดข้ามพรมแดนจริง การสับสนระหว่างสองสิ่งนี้เป็นข้อผิดพลาดด้านระเบียบวิธีที่พบบ่อยที่สุดอย่างหนึ่งใน HTA หลายประเทศ เพราะทั้งสองดูเหมือน "อัตราแลกเปลี่ยน" สำหรับคนที่ไม่ได้อ่านแนวทาง และสเปรดชีตจะไม่หยุดคุณจากการทำผิด

## คณิตศาสตร์

```
icer_ในสกุลเงินท้องถิ่น = แปลง(icer_ในสกุลเงินต้นทาง, ตัวคูณแปลง)

ตัวคูณแปลงควรเป็น:
  ตัวคูณแปลง PPP      — สำหรับเปรียบเทียบมูลค่าทางเศรษฐกิจที่แท้จริงของ
                         ทรัพยากรข้ามประเทศ (ISPOR แนะนำสำหรับ CEA หลายประเทศ)
  อัตราแลกเปลี่ยนตลาด  — เฉพาะการชำระเงินสดข้ามพรมแดนจริงเท่านั้น

นำมาใช้ ถ้า icer_ในสกุลเงินท้องถิ่น < เกณฑ์ท้องถิ่น
```

กฎการตัดสินใจเองคือ[กฎเกณฑ์ ICER](../เกณฑ์ความเต็มใจจ่าย/)ธรรมดา — `นำมาใช้ ถ้า ICER < λ` — คำถามเชิงระเบียบวิธีของหัวข้อนี้เกี่ยวกับ *ตัวคูณแปลงใด* ที่ให้ค่า `icer_ในสกุลเงินท้องถิ่น` ซึ่งกฎนั้นนำไปใช้ทั้งหมด

## ตัวอย่างที่คำนวณแล้ว

ICER ของยาตัวหนึ่งจากการทดลองในสหรัฐฯ คือ $45,000/QALY ประเทศผู้นำเข้าสมมุติกำหนดเกณฑ์ประกอบของตนเองที่ £34,000/QALY (ตัวเลขสมมุติเฉพาะประเทศสำหรับตัวอย่างนี้เท่านั้น — เกณฑ์จริงแตกต่างกันตามประเทศและเปลี่ยนแปลงตามเวลา และต้องระบุแหล่งที่มาและวันที่เสมอ)

**ใช้ตัวคูณแปลง PPP เท่ากับ 0.72** (ตัวเลขประกอบ เฉพาะตัวอย่างนี้): $45,000 × 0.72 = £32,400/QALY. £32,400 < £34,000 → **นำมาใช้**

**ใช้อัตราแลกเปลี่ยนตลาด 0.79** แทน (ตัวเลขประกอบ): $45,000 × 0.79 = £35,550/QALY. £35,550 > £34,000 → **ปฏิเสธ**

ICER เดิมที่ $45,000/QALY ให้ผลการตัดสินใจนำมาใช้เมื่อแปลงด้วย PPP และผลการตัดสินใจปฏิเสธเมื่อแปลงด้วยอัตราตลาด นี่คือตัวอย่างรูปธรรมว่าทำไมแนวทางของ ISPOR จึงถือว่าการเลือกตัวคูณแปลงมีนัยสำคัญเชิงระเบียบวิธี — ไม่ใช่รายละเอียดการปัดเศษ และไม่ใช่สิ่งที่ปล่อยให้เป็นนัยในสูตรสเปรดชีตที่ไม่มีใครตรวจซ้ำ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือภาพสะท้อนในเศรษฐศาสตร์สุขภาพของสาขาวิศวกรรมที่รู้จักกันดี: ความถูกต้องของการกำหนดราคาหลายสกุลเงิน i18n/l10n ในซอฟต์แวร์เชิงพาณิชย์ ที่หน้าราคา SaaS ต้องไม่เปรียบเทียบจำนวนเงิน `$` กับราคา `£` อย่างเงียบๆ การรับประกันระดับชนิดข้อมูลที่ชนิด `Money` ที่สร้างมาอย่างดีให้ — เมธอดเปรียบเทียบที่ปฏิเสธการเปรียบเทียบสกุลเงินที่ไม่ตรงกัน และบังคับให้ทำขั้นตอนแปลงที่ชัดเจนก่อน — เป็นภาพคู่ขนานทางวิศวกรรมซอฟต์แวร์โดยตรงกับประเด็นเชิงระเบียบวิธีด้านเศรษฐศาสตร์สุขภาพที่นี่: อย่าเปรียบเทียบตัวเลขที่ยังไม่ได้แปลงข้ามสกุลเงิน และอย่าปล่อยให้ขั้นตอนการแปลงเป็นนัยหรือไม่ได้บันทึกไว้

## ข้อผิดพลาดที่พบบ่อย

- **เปรียบเทียบจำนวนเงินในสกุลเงินต่างกันอย่างเงียบๆ**: งาน HTA เฉพาะกิจในสเปรดชีตที่ลบหรือเปรียบเทียบตัวเลขดอลลาร์กับตัวเลขปอนด์โดยไม่แปลงก่อน — ประเภทของบั๊กที่ชนิด `Money` ที่รับรู้สกุลเงินจริงจับได้โดยโครงสร้าง แทนที่จะปล่อยเป็นข้อผิดพลาดเงียบ
- **สับสนอัตราแลกเปลี่ยนตลาดกับ PPP**: ข้อผิดพลาดเชิงระเบียบวิธีที่พบบ่อยที่สุดใน HTA หลายประเทศตามแนวทางของ ISPOR — สองตัวเลขนี้อาจต่างกันมากและตอบคำถามต่างกัน (มูลค่าทางเศรษฐกิจที่แท้จริงเทียบกับกระแสเงินสดจริง)
- **ไม่ระบุวันที่ของอัตราแลกเปลี่ยนหรือดัชนี PPP ที่ใช้**: ทั้งสองเปลี่ยนไปตามเวลา ดังนั้นทุกตัวคูณแปลงที่อ้างอิงต้องระบุวันที่ในลักษณะเดียวกับที่คลังนี้ระบุวันที่ของตัวเลขอ้างอิงอื่นๆ (ค่าคาร์บอนของ Green Book มูลค่าของการป้องกันการเสียชีวิต และอื่นๆ)
