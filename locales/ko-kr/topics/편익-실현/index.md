# 편익 실현

편익 실현은 프로젝트가 실제로 약속된 편익을 전달했는지 추적하고 검증하는 규율입니다.

## 왜 중요한가

비즈니스 케이스는 편익을 약속하지만, 추적하지 않으면 실현 여부를 결코 알 수 없습니다.

## 수식

```
편익 실현율 = 실제 편익 / 계획된 편익 × 100%
```

## 계산 예시

디지털 트리아지 도구: 계획된 절감 £500,000/년; 12개월 후 실제 £320,000 = 64% 실현.

## 소프트웨어 공학과의 연관성

[ROI](../투자수익률/)와 [사회적 투자수익률](../사회적투자수익률/) 주장을 사후에 검증합니다.

## 함정

- **편익을 측정하지 않고 프로젝트를 종료 처리하기.**
