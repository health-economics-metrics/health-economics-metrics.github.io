# QALY당 탄소 발자국

QALY당 탄소는 효율성 비율로, 개입의 탄소 배출량(또는 회피된 배출량)을 그 개입이 제공하는 QALY로 나눈 값입니다. QALY당 비용과 직접 대응하므로 개입의 탄소 효율성을 비용 효율성과 나란히 평가할 수 있습니다. "탄소 보정 순금전편익"은 한 걸음 더 나아가, 영국 그린북의 공식 비거래 탄소 가치를 사용해 탄소 영향을 금전으로 환산하고 이를 표준 [순금전편익](../net-monetary-benefit/)에서 차감합니다.

## 왜 중요한가

NICE와 NHS 잉글랜드는 이제 비용과 QALY와 함께 환경 영향도 고려하기를 기대합니다. NHS는 공개적인 넷제로 약속을 하고 있으며, 직접 배출은 2040년까지, 전체 공급망 발자국은 2045년까지 넷제로를 달성한다는 것입니다. NICE의 보건기술평가 매뉴얼(PMG36)은 환경적 지속가능성을 기술 평가에서 새롭게 부상하는 고려사항으로 언급합니다. 디지털 헬스 제품에게 이는 탄소가 비용, QALY, [효율성 경계상의 지배](../dominance-and-efficiency-frontier/)와 나란히 가치 논거의 네 번째 기둥이 되고 있음을 의미합니다. 어느 것도 대체하는 것은 아니지만, 잘 만든 비즈니스 케이스가 점점 더 보고해야 하는 차원입니다.

## 수식

```
QALY당 탄소 = 총_배출량_톤_CO2e / 총_QALY
  (음수 값은 획득한 QALY당 순 회피 배출량을 뜻함 —
  더 나은 건강과 더 적은 탄소라는 이중의 이득)

금전 환산 탄소 영향 = 배출량_톤_CO2e × 톤당_탄소_가치
  (음의 배출량 × 양의 가치 = 음의 비용, 즉 편익)

탄소 보정 NMB = 순금전편익 − 금전 환산 탄소 영향
```

이는 비용/QALY 효율성 경계의 개념에 QALY당 탄소라는 두 번째 축을 더하는 것으로, [지배와 효율성 경계](../dominance-and-efficiency-frontier/)와 같은 "모든 선택지를 그려 보고 지배당하는 것을 찾는다"는 논리를 비용 대신 탄소에 적용한 것입니다.

## 계산 예시

원격의료 서비스가 대면 진료를 대체해 연간 자동차 이동 5,000회(회당 약 8kg CO2e)를 피합니다. 회피된 CO2e는 40톤이며 음의 배출량 수치(−40.0톤)로 표현되고, 연간 25 QALY를 제공합니다.

```
QALY당 탄소 = −40.0 / 25.0 = 획득 QALY당 1.6톤 CO2e 회피
```

그린북의 비거래 탄소 가치를 사용합니다(설명용 수치이며, 2023년 비거래 중앙값은 약 £269/톤 CO2e입니다. 그린북은 탄소 가치를 매년 갱신하므로 실제 분석에서 인용하기 전에 다시 확인하세요).

```
금전 환산 탄소 영향 = −40.0 × £269 = −£10,760
```

−£10,760의 "비용"은 £10,760의 편익입니다. 개입 단독의 순금전편익이 £500,000이라면 다음과 같습니다.

```
탄소 보정 NMB = £500,000 − (−£10,760) = £510,760
```

탄소 절감은 논거를 약화하지 않고 오히려 강화합니다. 음의 배출량이라는 틀이 드러내려는 것이 바로 이 이중의 이득입니다.

## 소프트웨어 공학과의 연관성

이는 AI/클라우드 경제학과 맞닿은 현재 진행형의 접점입니다. AI 모델을 학습하고 실행하는 데 드는 컴퓨팅의 탄소 발자국은 이제 NHS 조달에서 실제 항목이며, 일정 기준을 넘는 NHS 공급업체 계약에는 탄소 감축 계획이 요구됩니다. [클라우드 단위 경제학](../cloud-unit-economics/)은 이미 컴퓨팅 산출 단위당 비용을 추적합니다. QALY당 탄소는 그 모듈과 추론 단위 경제학을 환경 차원으로 확장하는 미래의 "추론당 탄소 비용" 지표의 자연스러운 템플릿입니다. 다만 그 지표는 아직 존재하지 않습니다.

## 함정

- **경계 설정 조작**: 직접 배출(Scope 1)만 세고, 디지털 헬스 제품의 실제 발자국에서 대부분을 차지하는 공급망 배출(Scope 3)은 제외하는 것.
- **오래된 탄소 가치 사용**: 그린북은 비거래 탄소 가치를 매년 갱신하므로, 인용하는 £/톤 수치에는 날짜를 붙여야 하며 고정된 상수처럼 제시해서는 안 됩니다.
- **"탄소 효율적"을 "비용 효과적"의 대용으로 취급하기**: 탄소 배출이 낮아도 가치가 낮은 개입은 여전히 NHS 자원의 나쁜 사용입니다. 탄소는 비용과 QALY와 나란히 있는 네 번째 기둥이지 어느 쪽의 대체물도 아닙니다.
