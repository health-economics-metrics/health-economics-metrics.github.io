# Перспектива аналізу

Перспектива аналізу визначає, чиї витрати та вигоди враховуються в економічній оцінці: платника, постачальника послуг чи суспільства в цілому.

## Чому це важливо

Те саме втручання може виглядати економічно ефективним з однієї перспективи та витратним з іншої, залежно від того, хто оплачує рахунок.

## Математика

```
Чисті витрати(перспектива) = Σ витрати, релевантні для цієї перспективи
```

## Розібраний приклад

Служба телемоніторингу коштує постачальнику £200 000/рік, але заощаджує суспільству £500 000/рік втраченої продуктивності.

## Зв'язок з інженерією програмного забезпечення

Подібно до вибору того, хто є "клієнтом" при пріоритизації функцій — внутрішня команда, кінцевий користувач чи ширша організація.

## Підводні камені

- **Мовчазна зміна перспективи посеред аналізу.**
- **Заявляти суспільні вигоди, бюджетуючи з перспективи платника.**
