# قدر پیدا کرنے والی صلاحیت (آپریشنل تبدیلی)

قدر پیدا کرنے والی صلاحیت آزاد وقت کا "موقع کا فائدہ" ہے: آپ کا سافٹ ویئر آزاد کرنے والے گھنٹوں سے ہسپتال اب کیا *حاصل* کر سکتا ہے۔

## یہ کیوں اہم ہے

NHS کو وسیع حوالگی-سے-علاج بیک لاگ کا سامنا ہے۔

## ریاضی

```
پیدا شدہ چھپی صلاحیت = آزاد وقت → فعال سرگرمی اکائیاں × اسکیم قیمت
```

## حل شدہ مثال

بینڈ 6 ماہر نرسیں پری-آپریٹو تشخیصی کلینک چلاتی ہیں: سالانہ £1.5M دیکھ بھال کی صلاحیت پیدا ہوئی۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہی تنظیم نو ڈویلپر-پیداواریت کے دعووں کو تنخواہ کی ریاضی سے بچاتی ہے۔

## عام غلطیاں

- **مانگ کے بغیر صلاحیت کا دعویٰ۔**
