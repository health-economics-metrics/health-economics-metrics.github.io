# খরচ-সুবিধা বিশ্লেষণ (CBA)

CBA খরচ *এবং* ফলাফল উভয়কেই টাকায় মূল্যায়ন করে। এটি একমাত্র বিশ্লেষণ ধরন যা "এটি করার মূল্য আছে কিনা?" উত্তর দিতে পারে — শুধু "কোন বিকল্পটি সেরা?" নয় — কারণ মুদ্রায়িত সুবিধাগুলি সরাসরি খরচের বিরুদ্ধে তুলনা করা যায়।

## কেন এটি গুরুত্বপূর্ণ

সমস্ত পাবলিক ব্যয় মূল্যায়নের জন্য CBA হল যুক্তরাজ্যের HM Treasury **Green Book**-এর মান, স্বাস্থ্য সহ যখন ফলাফল মুদ্রায়িত করা যায়। যেখানে [CEA](../খরচ-কার্যকারিতা-বিশ্লেষণ/)/[CUA](../খরচ-উপযোগিতা-বিশ্লেষণ/) "প্রতি ইউনিট স্বাস্থ্যে খরচ"-এ থামে, CBA স্বাস্থ্য নিজেই মূল্য নির্ধারণ করে (QALY × প্রান্তসীমা মূল্য) এবং বাকি সবকিছু — সময়, ভ্রমণ, কার্বন — এবং একটি নিট পরিসংখ্যান রিপোর্ট করে। প্রতিটি সম্পূর্ণ NHS ডিজিটাল ব্যবসায়িক কেসে একটি CBA-আকৃতির অর্থনৈতিক কেস থাকে।

## গণনা

```
NPV (নিট বর্তমান সামাজিক মূল্য) = Σ_t [ (সুবিধা_t − খরচ_t) / (1 + r)^t ]
BCR (সুবিধা-খরচ অনুপাত)         = PV(সুবিধা) / PV(খরচ)

NPV > 0 হলে গ্রহণ করুন (সমতুল্যভাবে BCR > 1); NPV দ্বারা র‍্যাংক করুন, BCR দ্বারা নয়।
r = 3.5% (Green Book সামাজিক সময় পছন্দ হার)
```

স্বাস্থ্য প্রভাব QALY × λ হিসেবে মুদ্রায়িত প্রবেশ করতে পারে (দেখুন [পরিশোধ করার ইচ্ছার প্রান্তসীমা](../পরিশোধ-করার-ইচ্ছার-প্রান্তসীমা/))। Green Book **আশাবাদ-পক্ষপাত সমন্বয়**ও নির্দেশ করে — প্রমাণ-ভিত্তিক শতাংশ দ্বারা খরচ অনুমান বৃদ্ধি এবং সুবিধা হ্রাস করা, কারণ মূল্যায়নগুলি পদ্ধতিগতভাবে গোলাপী।

## বিস্তারিত উদাহরণ

একটি ই-রেফারেল সিস্টেম, 5-বছরের দিগন্ত, 3.5% ছাড়:

```
খরচ:      নির্মাণ £1.2 মিলিয়ন (বছর 0), চালানো £300হাজার/বছর (বছর 1-5)
সুবিধা:   প্রশাসনিক সঞ্চয় £250হাজার/বছর, এড়ানো ডুপ্লিকেট ডায়াগনস্টিক্স £280হাজার/বছর,
          রোগীর সঞ্চিত সময় 40,000 ঘণ্টা/বছর × £15 = £600হাজার/বছর → £1,130হাজার/বছর

PV খরচ    = 1,200হাজার + 300হাজার × 4.515 (বার্ষিকী গুণক) = £2,555হাজার
PV সুবিধা = 1,130হাজার × 4.515                              = £5,102হাজার

NPV = 5,102 − 2,555 = +£2,547হাজার     BCR = 2.0
```

Green Book আশাবাদ পক্ষপাত প্রয়োগ করুন (ধরুন নির্মাণ খরচে +40%, সুবিধায় −20%): PV খরচ ≈ £3,035হাজার, PV সুবিধা ≈ £4,082হাজার, NPV ≈ **+£1,047হাজার** — এখনও ইতিবাচক, যা সমন্বয়ের মূল বিষয়: কেসগুলি তাদের নিজস্ব আশাবাদ থেকে বাঁচতে হবে।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

ইঞ্জিনিয়ারিং ব্যবসায়িক কেসগুলি অনানুষ্ঠানিক CBA। Green Book-এর উন্নতি যা চুরি করার যোগ্য:

- **আশাবাদ পক্ষপাতকে একটি মানক বৃদ্ধি হিসেবে** — ইঞ্জিনিয়াররা মাইগ্রেশন খরচ ততটাই নির্ভরযোগ্যভাবে অবমূল্যায়ন করে যতটা মন্ত্রণালয়গুলি অবকাঠামো খরচ অবমূল্যায়ন করে; এবার ভিন্ন ভান করার পরিবর্তে একটি বর্ণিত বৃদ্ধি প্রয়োগ করুন।
- **প্রধান সুবিধাকে সততার সাথে মুদ্রায়িত করুন অথবা মোটেই না** — রোগী/ব্যবহারকারীর সময় প্রতিরক্ষাযোগ্য হারে মুদ্রায়িত করা হয়; "ব্র্যান্ড মূল্য" নয়।
- **NPV র‍্যাংক করে, BCR করে না**: BCR 5 সহ একটি ছোট প্রকল্প BCR 1.6 সহ একটি বড় প্রকল্পের চেয়ে কম গুরুত্বপূর্ণ হতে পারে।

## ঝুঁকি

- **অ-মুদ্রায়নযোগ্যকে মুদ্রায়িত করা** সুবিধা স্ফীত করতে (মনোবল, "কৌশলগত সারিবদ্ধতা") — এগুলিকে গুণগত রাখুন, [খরচ-পরিণতি বিশ্লেষণ](../খরচ-পরিণতি-বিশ্লেষণ/) অনুযায়ী।
- **স্থানান্তরকে সুবিধা হিসেবে গণনা করা**: পাবলিক সংস্থার মধ্যে চলমান টাকা সামাজিক [দৃষ্টিকোণে](../বিশ্লেষণ-দৃষ্টিকোণ/) শূন্যে নিট হয়।
- **কোনো কাউন্টারফ্যাকচুয়াল নেই**: সুবিধা ন্যূনতম-করা বিকল্পের বিরুদ্ধে পরিমাপ করা হয়, শূন্যের বিরুদ্ধে নয়।
