# প্রযুক্তিগত ঋণ

প্রযুক্তিগত ঋণ হলো একটি কোডবেসে সুবিধাজনক অতীত সিদ্ধান্তের অন্তর্নিহিত ভবিষ্যত ব্যয়: প্রতিকার কাজ যা বকেয়া (**আসল**) এবং ডেলিভারিতে এটি যে ক্রমাগত টান প্রয়োগ করে (**সুদ**)।

## কেন এটি গুরুত্বপূর্ণ

পরিমাপবিহীন, প্রযুক্তিগত ঋণ একটি অভিযোগ; পরিমাপকৃত, এটি একটি ব্যবসায়িক ক্ষেত্র। শিল্প বেসলাইন (CAST Appmarq): ঐতিহাসিকভাবে ≈ **কোড প্রতি লাইনে $৩.৬১ প্রযুক্তিগত-ঋণ আসল**, সাধারণ কোডবেস পুনর্নির্মাণ ব্যয়ের ১৫–২০% ঋণ অনুপাত বহন করে।

## গণিত

```
SQALE আসল = Σ লঙ্ঘন জুড়ে (প্রতিকার সময়) × ডেভেলপার ব্যয় হার
প্রযুক্তিগত ঋণ অনুপাত (TDR) = প্রতিকার ব্যয় / পুনর্নির্মাণ ব্যয় × 100

সুদ (যে সংখ্যা পরিশোধকে ন্যায্যতা দেয়):
  বার্ষিক সুদ = Δ ডেলিভারি বেগ × গতি একক প্রতি মূল্য + Δ ত্রুটি হার × ত্রুটি প্রতি ব্যয়
```

## সমাধানকৃত উদাহরণ

একটি ৪ লক্ষ-LOC ক্লিনিক্যাল-রেকর্ড একীকরণ স্তর: SQALE আসল ৩,৮০০ ঘণ্টা × £৭৫ = **£২৮৫হাজার**; TDR ≈ ১২% (গ্রেড C)। পরিমাপকৃত সুদ:

```
সুদ ≈ 6,000 × 0.40 × £75      = বছরে £180,000
     + 12 অতিরিক্ত ব্যর্থতা × £8,000 = বছরে £96,000
     ≈ বছরে £276,000
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

স্বাস্থ্য-অর্থনীতির আমদানি যা প্রযুক্তিগত-ঋণ যুক্তিকে উন্নত করে: সম্পত্তিকে একটি **বোঝার তালিকা** হিসেবে প্রকাশ করুন।

## ঝুঁকিপূর্ণ দিক

- **শুধুমাত্র-আসল রিপোর্টিং**: সুদের অনুমান ছাড়া একটি বড় ভয়ঙ্কর সংখ্যা কিছুই ন্যায্যতা দেয় না।
- **আক্ষরিকভাবে নেওয়া টুল-উৎপাদিত ঋণ সংখ্যা**।
- **ঋণ-শূন্য ইউটোপিয়ানিজম**: সর্বোত্তম ঋণ স্তর শূন্য নয়।
