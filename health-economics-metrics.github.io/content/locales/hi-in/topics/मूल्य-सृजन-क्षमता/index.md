# मूल्य-सृजन क्षमता (परिचालन बदलाव)

मूल्य-सृजन क्षमता मुक्त समय का "अवसर लाभ" है: आपका सॉफ़्टवेयर मुक्त करने वाले घंटों से अस्पताल अब क्या *हासिल* कर सकता है।

## यह क्यों महत्वपूर्ण है

NHS विशाल रेफरल-से-उपचार बैकलॉग का सामना कर रहा है।

## गणित

```
सृजित छिपी क्षमता = मुक्त समय → सक्षम गतिविधि इकाइयाँ × योजना मूल्य
```

## हल किया गया उदाहरण

बैंड 6 विशेषज्ञ नर्सें प्री-ऑपरेटिव मूल्यांकन क्लीनिक चलाती हैं।

```
अतिरिक्त मूल्यांकन = 25 × 2/दिन × 250 दिन = सालाना 12,500
सालाना £1.5M देखभाल क्षमता निर्मित
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यही पुनर्गठन डेवलपर-उत्पादकता दावों को वेतन गणित से बचाता है।

## सामान्य गलतियाँ

- **माँग के बिना क्षमता का दावा।**
- **क्षमता को नकद के रूप में प्रस्तुत करना।**
