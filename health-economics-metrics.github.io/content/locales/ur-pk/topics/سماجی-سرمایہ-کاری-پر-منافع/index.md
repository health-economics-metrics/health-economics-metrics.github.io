# سماجی سرمایہ کاری پر منافع (SROI)

SROI [ROI](../سرمایہ-کاری-پر-منافع/) کو ان نتائج تک بڑھاتا ہے جن کی بازار قیمت نہیں لگاتا — بہبود، سماجی تعلق، ماحولیاتی اثر۔

## یہ کیوں اہم ہے

SROI، Social Value International کے سات اصولوں کے تحت، "فی £1 سرمایہ کاری میں £3.20 سماجی قدر" جیسے بیانات پیدا کرتا ہے۔

## ریاضی

```
SROI تناسب = PV(مالیاتی سماجی نتائج) / PV(سرمایہ کاری)
```

## حل شدہ مثال

ایک دوستی ایپ الگ تھلگ بزرگوں کو رضاکاروں سے جوڑتی ہے: SROI ≈ 8.5:1۔

## سافٹ ویئر انجینئرنگ سے تعلق

SROI اس انجینئرنگ کام کے لیے ایماندار فریم ورک ہے جس کے فائدہ اٹھانے والے ادا کرنے والی ٹیم سے باہر ہیں۔
