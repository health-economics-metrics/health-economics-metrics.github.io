# 医療従事者の時間

医療従事者の時間は、ほとんどの医療システムにおいて最も希少な資源です。臨床医の1日あたりの時間を節約することの価値を測定するには、単純な賃金計算から**機会費用とシステムの容量**へと発想を転換する必要があります:国の医療サービスの中では、医療従事者の時間は柔軟に伸縮する費用項目ではなく、硬直的な運用上のボトルネックです。

## なぜ重要か

GP、コンサルタント、専門看護師をすぐに増やすことはできません — 養成のパイプラインは5〜15年かかり、欠員は慢性的です。したがって、節約された医療従事者の1時間は「回避された賃金」(医療従事者にはまだ給与が支払われています)ではなく、*解放されたボトルネック容量*であり、ボトルネック容量はボトルネックが生み出すものの価値があります。これが、「1診察あたり10分節約」という主張が、デジタルヘルスにおいて最も一般的であると同時に最も誤って値付けされる項目である理由です。

## 数式

3つの評価レベル、正直さが増す順に:

```
1. 賃金ベース:      時間 × 全負担給与率(PSSRU単位費用)
                    — 時間が何を生み出すかではなく、何を費やすか
2. アウトプットベース:時間 → 可能になった予約/処置の数 × 制度上の価値
                    (全国診療報酬と単位費用を参照)
3. ボトルネックベース:この役割が経路全体を制限しているなら、時間 ×
                    解放された経路スループットの価値(制約理論)
```

分断の割引:使える量子を下回る断片で節約された時間(例えば、診療所全体に散らばった3分間)はうまく再配置できません;明示された稼働率係数を適用してください。

## 計算例

アンビエント口述筆記が、GPの1診察あたり2分を節約し、1日30診察とすると:1日60分、220営業日で**GP1人あたり年間220時間**です。

```
賃金ベース:        220 × £80(PSSRU地域の全負担GP時給) ≈ GP1人あたり年間£17,600
アウトプットベース: 1日60分 = 1日5件の追加の12分診察
                   = GP1人あたり年間1,100件の追加予約 × £42 ≈ 年間£46,200
                   — あるいは、同じ予約が、残業の削減とより安全で
                   急がされない診察として吸収される(定性的な項目)
```

50人のGPの連合全体では、アウトプットベースの容量は年間約£230万の価値があります — ただし、その分が本物であり(測定されたものであり、ベンダーの主張ではない)、まとまっており(断片ではなく完全な診察であり)、再配置される場合に限ります([現金化可能な節約と非現金化節約](../現金化可能な節約と非現金化節約/)を参照)。

## ソフトウェア工学との関連

シニアエンジニアの時間もまったく同じように振る舞います:それは設計、レビュー、インシデントが流れるボトルネックであるため、給与ではなくボトルネックが何を制限しているかで評価してください。同じ3段階の評価は、「AIが各開発者のX分を節約する」というあらゆる主張に当てはまります — 賃金計算は小さな数字を実際以上に良く見せます;正直な問いは、その分がまとまった使える塊になるかどうか、そして解放された容量が実際に何を生み出すかです。節約された時間が誰もが待っている人のものである場合の乗数については、[下流のリソース最適化](../下流のリソース最適化/)を参照してください。

## 落とし穴

- **分 × 給与 = 節約** — 典型的な水増しです;それは容量であり、明示された稼働率でのみそうです。
- **量子の問題を無視すること**:5分の節約×12回 ≠ 自由に使える1時間。
- **すべての役割を同じように評価すること**:経路のボトルネックの1時間は、制約になっていない役割の1時間の何倍もの価値があります。
