# Retensi Tenaga Kerja

Ekonomi retensi tenaga kerja mengukur berapa biaya pergantian staf bagi sistem kesehatan.

## Mengapa ini penting

Ketika seorang klinisi pergi, trust membayar tiga kali: merekrut pengganti, mengonboardingnya, dan menutupi kekosongan sementara itu.

## Matematika

```
Biaya per orang yang pergi = biaya rekrutmen + biaya onboarding/peningkatan produktivitas
                            + premi penutup kekosongan × durasi kekosongan
```

## Contoh yang diselesaikan

Sebuah trust mempekerjakan 1.200 perawat; pergantian 11%/tahun. Perangkat lunak beban dokumentasi: £222.000/tahun.

## Hubungan dengan rekayasa perangkat lunak

Matematika retensi rekayasa identik.
