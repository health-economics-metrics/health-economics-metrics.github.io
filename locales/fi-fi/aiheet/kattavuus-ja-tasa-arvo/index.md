# Kattavuus ja tasa-arvo

Kattavuus ja tasa-arvo mittaavat, kuinka tasapuolisesti digitaalinen terveysinterventio tavoittaa koko kohdeväestön, erityisesti haavoittuvat ja marginalisoidut ryhmät.

## Miksi se on tärkeä

Digitaaliset interventiot voivat riskeerata digitaalisten terveyserojen syvenemisen tavoittamalla suhteettoman paljon jo paremman pääsyn omaavia ryhmiä. Muodollisesta tilastollisesta mittarista sosioekonomiseen asemaan liittyvälle terveyseriarvoisuudelle katso [keskittymisindeksi](../keskittymisindeksi/).

## Matematiikka

```
Tasa-arvokuilu = kattavuusosuus(korkea tulotaso) − kattavuusosuus(matala tulotaso)
```

## Ratkaistu esimerkki

Diabetessovellus: kattavuusosuus korkealla tulotasolla 45 %, matalalla tulotasolla 22 % = tasa-arvokuilu 23 prosenttiyksikköä.

## Yhteys ohjelmistokehitykseen

[Aktivoinnin ja käyttöönoton](../aktivointi-ja-käyttöönotto/) jakaminen väestön alaryhmien mukaan paljastaa kuilun.

## Sudenkuopat
