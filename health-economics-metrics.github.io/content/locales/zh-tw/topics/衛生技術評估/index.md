# 衛生技術評估（HTA）

衛生技術評估是衛生系統用以決定某項技術——藥物、器械或軟體——是否值得付費採用的正式化、制度化流程。它在一套已公開、強制執行的方法論下，將臨床效果證據與經濟學評估結合起來。

## 為何重要

如果你向國家醫療服務體系銷售產品，衛生技術評估機構很可能直接決定你的市場準入。瞭解當地的具體流程，就是了解真正決定你產品價值的那道監管關卡：

- **NICE（英格蘭）**：在明確界定的*參考案例*下進行法定評審——QALY來自[EQ-5D](../EQ-5D/)，採用NHS+PSS[視角](../分析視角/)，3.5%[貼現率](../貼現與時間偏好/)，要求[機率敏感性分析（PSA）](../機率敏感性分析/)——以£20,000–£30,000/QALY為判定標準，並結合[嚴重程度調整因子](../QALY缺口與嚴重程度調整因子/)；高度專科化技術可加權至£100,000以上。
- **ICER（美國，非政府組織）**：出具帶有*健康獲益價格基準*的證據報告——即在每QALY/evLYG（當量生命年）$100,000–$150,000下，產品具有成本效果所對應的價格——被用作談判籌碼；此外還包含預算影響"可負擔性警示"。
- **加拿大（CADTH → CDA-AMC）**：以約CAD$50,000/QALY為標準進行報銷審查；歷史上約95%的申報都被要求降價。

## 計算方法

衛生技術評估的力量並非來自某個公式，而是來自一套**強制執行的方法**：每一份申報都在相同的參考案例規則下計算相同的[ICER](../增量成本效果比/)，從而使結果能夠跨產品、跨年份進行比較。參考案例明確規定了結果指標、效用量表工具、視角、對照方案的選擇、貼現率、時間範圍以及不確定性分析——消除了贊助方可能用來操縱結果的每一個自由度。

## 實例演算

某數位療法提交至NICE式評審：

```
模型：ΔC = +£450/病患，ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ 低於£20,000
參考案例檢查項：
  效用值來自採用英國價值集的EQ-5D-5L                  ✓
  對照方案 = 現行照護路徑（而非"不治療"）              ✓
  PSA：在£20,000閾值下具有成本效果的機率為71%           ✓（已報告）
  嚴重程度調整因子：缺口低於×1.2的邊界                 ——未主張
建議：納入常規委託服務範圍，並同步開展真實世界資料採集。
```

贊助方自己偏好的分析結果原本顯示每QALY £9,000；正是參考案例透過強制使用誠實的對照方案，才將其推高至£15,000。這個差距，正是參考案例制度存在的*根本原因*。

## 與軟體工程的聯絡

可遷移的產物是**內部參考案例**：為所有工具/平臺商業案例設立一套強制統一的方法——明確宣告的對照方案、標準單位成本（相關模式參見[全國統一收費標準](../全國統一收費標準與單位成本/)）、固定貼現率、強制要求的敏感性分析、標準模板。向平臺委員會提交一份"面向工具的AMCP式檔案"，能使各項提案具有可比性，並使操縱行為無所遁形——正如衛生技術評估對藥物所做的那樣。不必一開始就做到NICE那種規模：一份兩頁紙的模板，配上一本已公開的價目手冊，勝過完全沒有標準。

關於多週期 HTA 模型究竟如何逐佇列、逐週期模擬，見[馬爾可夫佇列模擬](../馬爾可夫佇列模擬/)。

## 陷阱

- **把衛生技術評估當作獲得監管批准後的一道形式手續**——CE/UKCA/FDA認證只說明產品是安全的；而衛生技術評估決定的是它是否*值得購買*。這是兩道不同的門檻，需要不同的證據。
- **在試驗之後才建置經濟學模型**——證據生成的設計，應當從參考案例的要求出發反向推導。
- **忽視司法轄區之間的差異**：一個在美國以$120,000/QALY可獲資助的ICER，在英國£30,000的NICE標準下會不透過；應按每個市場分別規劃證據與定價策略。
