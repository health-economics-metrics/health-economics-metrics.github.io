# AIの投資収益率

AI ROIとは、AIの取り組みに帰属する測定可能な損益計算書上のリターンのことです。厳しいベンチマーク:MITの2025年の「GenAIの分断」研究は、300億〜400億ドルの企業GenAI投資にもかかわらず、**パイロット試験の約95%が測定可能な損益計算書上のリターンを示さなかった**ことを発見しました — そして成功した5%は識別可能な習慣を共有していました。

## なぜ重要か

医療システムには、AIパイロットのパターンに名前があります:**パイロット病** — 有望なアプリが永遠にパイロット試験され、決してスケールしないNHSの墓場です。MITの発見は、医療技術評価がすでに知っていることにきれいに対応します:価値の主張には事前に指定されたエンドポイントが必要であり、帰属には比較対象が必要であり、「みんなが役立っていると感じる」は便益項目ではありません。MITのデータにおける成功した少数派は、追跡可能な費用の基準値を持つバックオフィスの自動化に集中しており、**購入されたツールは約67%の確率で成功した一方、社内構築はその約3分の1でした** — これはあらゆるAI投資のケースに属する事前分布です([内製か購入か](../内製か購入か/)を参照)。

## 数式

```
AI ROI = (帰属可能な便益 − AIの総費用) / AIの総費用

AIの総費用 = ライセンス/推論(推論単位経済学を参照)
           + 統合 + データの準備 + 評価
           + ワークフローの再設計 + ガバナンス/保証
           (ライセンスは典型的には分母の少数派です)

帰属可能な便益:基準値または対照群に対して測定され、現金化可能な節約と
非現金化節約に従って現金/容量/質に分類される
```

## 計算例

ある病院グループが2つのユースケースにAIを展開します:

```
ユースケースA — 臨床レターの下書き(バックオフィス、追跡可能):
  基準値:外部委託された筆記£38万/年
  後:    筆記契約を解約;臨床医のレビュー時間+£6万
  AI費用:£12万/年、全込み
  ROI = (380k − 60k − 120k) / 120k ≈ 167% — 現金化可能、監査可能 ✓

ユースケースB — 「臨床医向けAIコパイロット」(広範、追跡なし):
  便益の主張:「4,000人のスタッフ全体で時間を節約」 — 基準値なし
  測定された損益計算書上の効果:実証可能なものなし
  → 実際に役立っているかどうかにかかわらず、95%のバケット
```

この違いはAIの質ではなく — 便益が**基準値、責任者、予算項目**を持っていたかどうかです([便益実現](../便益実現/))。

## ソフトウェア工学との関連

AI投資のためのHTA形式の手順書:**[NICE ESFの階層](../niceエビデンス基準フレームワーク/)のように証拠を段階付けること** — 低リスクのツールにはデモグレードの証拠、組織全体への支出の前に対照パイロット試験を行い、事前登録された展開ゲートを設ける([DiGA](../ドイツのdiga早期承認/)の期限付き暫定掲載のパターン);**医療経済学が需要回避を数えるのと同じように費用回避を数えること** — 特定の予算項目が実際に動いたときにのみ本物です;そして**[EVPI](../完全情報の期待価値/)でパイロット試験自体を価格設定すること** — 展開の意思決定を変えられないパイロット試験は£0の価値です。開発者ツールに特化した部分については、[AI開発者生産性](../ai開発者生産性/)を参照してください。

## 落とし穴

- **便益の拡散**:何千人もの利用者に薄く広がった価値は、構造上測定不可能です;集中した追跡可能な基準値を持つユースケースを選んでください。
- **ライセンスのみの費用計算**:統合、評価、ワークフローの再設計が通常、真の分母を支配します。
- **帰属の盗用**:プロセスの再設計と並んで展開されたAIが、差分全体を主張すること。
- **サンクコストのパイロット試験の延長**:停止することが失敗を認めることになるため失敗したパイロット試験を延長すること — 日没の日付は事前に合意されなければなりません。
