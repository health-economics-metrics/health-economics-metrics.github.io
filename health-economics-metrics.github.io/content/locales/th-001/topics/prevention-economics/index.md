# เศรษฐศาสตร์การป้องกัน

เศรษฐศาสตร์การป้องกันศึกษาว่าเมื่อใดการป้องกันโรคจึงประหยัดเงินจริง เทียบกับเมื่อใดที่เพียงแค่เลื่อนต้นทุนออกไปหรือแม้แต่เพิ่มต้นทุนเนื่องจากอายุขัยที่ยืนยาวขึ้น

## ทำไมจึงสำคัญ

"การป้องกันช่วยประหยัดเงิน" เป็นสมมติฐานที่ใช้สัญชาตญาณแต่มักไม่ถูกต้อง — มาตรการป้องกันหลายอย่างปรับปรุงผลลัพธ์ด้านสุขภาพโดยไม่เพิ่มการประหยัดต้นทุนสุทธิ เนื่องจากผู้คนมีชีวิตยืนยาวขึ้นและใช้บริการอื่นในภายหลัง

## คณิตศาสตร์

```
การประหยัดสุทธิ = ต้นทุนการรักษาที่หลีกเลี่ยงได้ − ต้นทุนโครงการป้องกัน − ต้นทุนอายุขัยที่เพิ่มขึ้น
```

## ตัวอย่างที่คำนวณแล้ว

โครงการเลิกบุหรี่ช่วยหลีกเลี่ยงต้นทุนการรักษามะเร็งปอด แต่ผู้เข้าร่วมมีชีวิตยืนยาวขึ้นและในที่สุดใช้บริการผู้สูงอายุอื่นๆ — ผลกระทบสุทธิมักเป็นบวกต่อสุขภาพ แต่เป็นกลางหรือเพิ่มต้นทุน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการลงทุนในโครงสร้างพื้นฐานเชิงป้องกัน — ช่วยปรับปรุงความน่าเชื่อถือแต่อาจไม่ลดต้นทุนรวมหากเพิ่มความซับซ้อน

## ข้อผิดพลาดที่พบบ่อย

- **การสันนิษฐานว่าการป้องกันทั้งหมดช่วยประหยัดเงินโดยไม่ตรวจสอบหลักฐาน**
- **การเพิกเฉยต่อต้นทุนอายุขัยที่เพิ่มขึ้นในการวิเคราะห์ทางเศรษฐศาสตร์**
