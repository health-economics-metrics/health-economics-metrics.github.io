# ผลกระทบของบัญชีรายชื่อรอ

ผลกระทบของบัญชีรายชื่อรอวัดว่าชั่วโมงทางคลินิกที่ประหยัดได้หรือประสิทธิภาพที่ดีขึ้นแปลงเป็นผู้ป่วยเพิ่มเติมที่ได้รับการรักษาจริงได้อย่างไร

## ทำไมจึงสำคัญ

ผลประโยชน์ด้านประสิทธิภาพจะให้มูลค่าจริงก็ต่อเมื่อถูกแปลงเป็นความจุเพิ่มเติม — มิฉะนั้นมันจะยังคงเป็นทฤษฎี

## คณิตศาสตร์

```
ผู้ป่วยเพิ่มเติมที่ได้รับการรักษา = ชั่วโมงทางคลินิกที่ประหยัดได้ / เวลาเฉลี่ยต่อการให้คำปรึกษาผู้ป่วย
```

## ตัวอย่างที่คำนวณแล้ว

โครงการประสิทธิภาพประหยัดชั่วโมงทางคลินิกได้ 500 ชั่วโมงต่อเดือน ด้วยเวลาให้คำปรึกษาเฉลี่ย 20 นาที เทียบเท่ากับผู้ป่วยเพิ่มเติม 1,500 รายต่อเดือน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการแปลงเวลาไปป์ไลน์ CI/CD ที่ประหยัดได้ให้เป็นฟีเจอร์เพิ่มเติมที่ส่งมอบจริง แทนที่จะอ้างเพียง "การสร้างที่เร็วขึ้น"

## ข้อผิดพลาดที่พบบ่อย

- **การสันนิษฐานว่าเวลาที่ประหยัดได้จะถูกนำไปใช้ซ้ำโดยอัตโนมัติสำหรับผู้ป่วยเพิ่มเติม**
- **การเพิกเฉยต่อความต้องการที่สะสมไว้ซึ่งจะเติมเต็มบัญชีรายชื่อรออย่างรวดเร็ว**
