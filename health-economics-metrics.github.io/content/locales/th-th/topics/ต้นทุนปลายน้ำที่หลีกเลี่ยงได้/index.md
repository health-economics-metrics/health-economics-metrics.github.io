# ต้นทุนปลายน้ำที่หลีกเลี่ยงได้

ต้นทุนปลายน้ำที่หลีกเลี่ยงได้วัดต้นทุนที่ระบบจะหลีกเลี่ยงได้ในอนาคตเนื่องจากการแทรกแซงในปัจจุบัน — เป็นหมวดหมู่ผลประโยชน์ที่พิสูจน์ได้ยากที่สุด แต่มักเป็นหมวดหมู่ที่ใหญ่ที่สุดในกรณีทางธุรกิจด้านเศรษฐศาสตร์สุขภาพ

## ทำไมจึงสำคัญ

การลงทุนด้านสุขภาพดิจิทัลและการป้องกันจำนวนมากพึ่งพาข้อเรียกร้องเกี่ยวกับต้นทุนในอนาคตที่ยังไม่เกิดขึ้นเป็นอย่างมาก — สิ่งเหล่านี้ต้องการสถานการณ์เปรียบเทียบที่น่าเชื่อถือจึงจะน่าเชื่อถือได้

## คณิตศาสตร์

```
ต้นทุนที่หลีกเลี่ยงได้ = (ความน่าจะเป็นของผลลัพธ์ในสถานการณ์เปรียบเทียบ − ความน่าจะเป็นของผลลัพธ์หลังการแทรกแซง) × ต้นทุนของผลลัพธ์
```

## ตัวอย่างที่คำนวณแล้ว

โปรแกรมจัดการโรคเรื้อรังอ้างว่าหลีกเลี่ยงการเข้ารับบริการฉุกเฉิน 50 ครั้งต่อปีที่ราคา £2,000 ต่อครั้ง ให้ต้นทุนที่หลีกเลี่ยงได้ £100,000 — แต่สิ่งนี้ขึ้นอยู่กับอัตราการเปรียบเทียบที่มีหลักฐานรองรับ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการประเมินมูลค่าของเหตุการณ์ด้านความปลอดภัยที่หลีกเลี่ยงได้ในการตรวจสอบความปลอดภัย — เป็นจริงแต่วัดได้ยาก เนื่องจากสถานการณ์เปรียบเทียบไม่เคยเกิดขึ้นจริง

## ข้อผิดพลาดที่พบบ่อย

- **การประเมินสถานการณ์เปรียบเทียบสูงเกินไปเพื่อทำให้การแทรกแซงดูน่าสนใจมากขึ้น**
- **การระบุต้นทุนที่หลีกเลี่ยงได้ทั้งหมดให้กับการแทรกแซงเดียวเมื่อมีการเปลี่ยนแปลงหลายอย่างเกิดขึ้นพร้อมกัน**
