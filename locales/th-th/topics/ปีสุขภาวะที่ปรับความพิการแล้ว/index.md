# ปีสุขภาวะที่ปรับความพิการแล้ว (DALY)

DALY วัดภาระโรคโดยรวมปีที่สูญเสียไปจากการเสียชีวิตก่อนวัยอันควรและปีที่ใช้ชีวิตด้วยความพิการเข้าด้วยกัน — เป็นภาพสะท้อนของ QALY ที่เน้นภาระแทนที่จะเน้นผลประโยชน์

## ทำไมจึงสำคัญ

DALY เป็นตัวชี้วัดมาตรฐานที่องค์การอนามัยโลกและธนาคารโลกใช้เปรียบเทียบภาระโรคระหว่างประเทศและกำหนดลำดับความสำคัญด้านสาธารณสุขทั่วโลก

## คณิตศาสตร์

```
DALY = ปีชีวิตที่สูญเสียจากการเสียชีวิตก่อนวัยอันควร (YLL) + ปีที่ใช้ชีวิตด้วยความพิการ (YLD)
```

## ตัวอย่างที่คำนวณแล้ว

โรคหนึ่งทำให้มีผู้เสียชีวิตก่อนวัย 1,000 คน (เฉลี่ยสูญเสีย 20 ปีต่อคน = 20,000 YLL) และมีผู้ป่วยเรื้อรัง 5,000 คนด้วยน้ำหนักความพิการ 0.3 เป็นเวลา 5 ปี (7,500 YLD) รวม DALY = 27,500

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการวัดผลกระทบของดาวน์ไทม์ที่รวมทั้งการสูญเสียธุรกรรมโดยตรง (คล้าย YLL) และประสบการณ์ผู้ใช้ที่เสื่อมลงระหว่างการให้บริการบางส่วน (คล้าย YLD) เข้าเป็นตัวชี้วัดผลกระทบเดียว

## ข้อผิดพลาดที่พบบ่อย

- **การเปรียบเทียบ DALY ข้ามประเทศโดยไม่พิจารณาความแตกต่างของวิธีการเก็บข้อมูล**
- **การสับสนระหว่าง DALY (ภาระ ยิ่งน้อยยิ่งดี) กับ QALY (ประโยชน์ ยิ่งมากยิ่งดี)**
