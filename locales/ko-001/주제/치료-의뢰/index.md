# 치료 의뢰(RTT)

치료 의뢰는 GP 의뢰부터 전문의 주도 치료 시작까지 경과된 시간입니다. NHS 헌법은 기준을 설정합니다: **92%의 환자가 18주 이내에 치료를 시작해야 합니다**.

## 왜 중요한가

RTT 목표를 놓치는 트러스트는 규제 감시에 직면합니다.

## 수식

```
RTT 성과 = 18주 이내 치료받은 환자 / 총 치료받은 환자 × 100
```

## 계산 예시

한 전문과가 연간 5,000명의 경로 환자를 치료합니다.

## 소프트웨어 공학과의 연관성

RTT는 **다단계 대기열의 리드타임 지표**입니다.
