# 다기준 의사결정 분석(MCDA)

다기준 의사결정 분석(MCDA)은 단일 ICER/지불의사 임계값이 형평성, 미충족 수요, 혁신, 예산 영향, 질병 중증도 등 의사결정자가 중시하는 모든 것을 담아내지 못할 때 보건기술평가에서 쓰는 가중합 점수 모델입니다. 각 기준에는 그 중요도를 반영하는 가중치(이해관계자로부터 도출하며, 가중치의 합은 1)가 주어지고, 각 선택지에는 기준별 정규화된 점수(보통 0–1)가 주어지며, 종합 점수는 가중합입니다. 소프트웨어 공급업체 선정 스코어카드와 같은 수학적 형태입니다.

## 왜 중요한가

MCDA는 EVIDEM 같은 틀에서, 그리고 엄격한 QALY당 비용 임계값 접근이 결정에서 중요한 모든 것을 담기에 너무 좁다고 여겨지는 희귀의약품/희귀질환 평가에서 일부 HTA 기관이 사용합니다. ISPOR의 MCDA Emerging Good Practices Task Force는 가중치와 점수를 근거 있게 도출하기 위한 모범 사례 지침을 정리했는데, 비공식적으로 가중치를 매긴 의사결정은 만들기 쉽고 조작하기도 쉽기 때문입니다. 보건기술이 단일 [지불의사 임계값](../지불의사-임계값/)으로는 표현할 수 없는 가치 차원(중증도, 혁신, 형평성)을 정말로 지니고 있을 때, MCDA는 의사결정자에게 말로 하지 않는 판단 대신 그것들을 결합하는 명시적이고 감사 가능한 구조를 제공합니다.

## 수식

```
MCDA 점수 = Σ_i (가중치_i × 점수_i)

가중치의 합은 1이어야 함(스윙 가중법이나 계층분석과정(AHP) 같은
이해관계자 방법으로 도출)
```

## 계산 예시

HTA 위원회가 디지털 치료제를 네 가지 기준으로 채점합니다.

```
기준                               가중치   점수    가중치 × 점수
임상적 편익                        0.4      0.8     0.32
비용 영향                          0.3      0.5     0.15
질병 중증도 / 미충족 수요          0.2      0.9     0.18
혁신                               0.1      0.6     0.06
                                    ─────                ─────
                                    1.0                  0.71
```

가중치의 합은 1.0(0.4 + 0.3 + 0.2 + 0.1)이고 MCDA 점수는 0.71(0.32 + 0.15 + 0.18 + 0.06)입니다. 위원회는 0.71을 사전에 합의한 임계값과 비교하거나, 같은 방식으로 채점된 경쟁 기술과 순위를 매깁니다.

## 소프트웨어 공학과의 연관성

이는 가중치를 둔 공급업체 선정 스코어카드, RFP 평가 매트릭스, 기능 우선순위 점수 모델과 정확히 같은 수학입니다. 소프트웨어 조달에서 가중 스코어카드의 전형적인 사용 사례인 [빌드 대 구매](../빌드-대-구매/)를 참고하세요. [WSJF와 CD3](../wsjf와-cd3/)와 대비해 볼 가치도 있습니다. WSJF/CD3는 *비율* 기반 우선순위 방법(지연 비용을 작업 규모나 기간으로 나눈 것)인 반면, MCDA는 가중 *합*입니다. MCDA와 WSJF/CD3는 "경쟁하는 선택지를 어떻게 순위 매길 것인가"에 대한 구조적으로 다른 두 가지 답이며, 주어진 결정이 실제로 무엇을 요구하는지, 즉 독립적인 기준에 걸친 가산적 가치인지 희소한 용량 단위당 가치 밀도인지를 아는 것이 어느 공식이 더 엄밀해 보이는지보다 중요합니다.

## 함정

- **가중치 도출의 편향**: 가중치를 정하는 사람이 사실상 순위를 미리 결정하므로, "공식"이 정치적 또는 상업적 결정을 객관적 계산으로 세탁할 수 있습니다. 누가 어떻게 가중치를 정했는지 문서화하세요.
- **이미 다른 곳에서 포착된 기준의 이중 계산**: "비용효과성"을 한 기준으로 채점하면서 *동시에* "비용 영향"도 따로 채점하면, 아무도 의도하지 않았는데 다른 기준에 비해 돈이 과도하게 가중됩니다.
- **거짓 정밀도**: 소수 둘째 자리의 가중 점수(0.71)는 그 바탕이 되는 0–10 이해관계자 평가가 실제로 뒷받침하는 것보다 더 큰 엄밀성을 암시하며, 그 평가의 평가자 간 변동은 흔히 전혀 보고되지 않습니다.
