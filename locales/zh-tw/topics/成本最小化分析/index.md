# 成本最小化分析（CMA）

成本最小化分析只比較成本，並選擇最便宜的方案——*只有*在已證明各備選方案的結果彼此等效的前提下，這樣做才是正當的。

## 為何重要

成本最小化分析是最簡單的分析方法，也是最容易被濫用的一種。真正起關鍵作用的是"等效性"這一主張：如果結果確實沒有差異（例如生物類似藥與其原研藥之間；兩家供應商提供滿足同一規格的同一服務），那麼成本就是唯一需要考慮的問題，此時使用成本最小化分析是正確的。其嚴謹性體現在*事先證明*等效性這一步——通常需要藉助帶有預先設定邊界值的非劣效性研究——而這恰恰是採購方最常跳過的一步。

## 計算方法

```
若有證據表明 效果_A ≈ 效果_B （在預先設定的邊界值δ範圍內）：
選擇 min(成本_A, 成本_B)

成本須以相同視角、相同時間範圍計算，
並須包含切換/過渡成本。
```

如果等效性無法被證實，成本最小化分析就不成立——此時應改用[成本效果分析](../成本效果分析/)/[成本效用分析](../成本效用分析/)。

## 實例演算

某信託機構在兩個視訊問診平臺之間做選擇。一項為期3個月的平行試點顯示，完成率分別為94.1%與93.8%，病患滿意度均為4.4——差異均落在事先約定的2個百分點邊界值δ之內。結果：等效。3年期成本如下：

```
                     平臺A          平臺B
許可費用             £360,000       £210,000
整合成本             £80,000        £150,000
培訓/支援            £60,000        £90,000
總計                £500,000       £450,000
```

平臺B以£50,000的優勢勝出——且這已*包含*了它更高的整合成本。如果沒有那次試點，等效性的主張就只能依賴供應商的宣傳冊，而一個百分點的完成率差異（相當於每年數千次失敗的問診）足以遠遠超過£50,000這一成本差距。

## 與軟體工程的聯絡

成本最小化分析是大宗商品化採購的正式形態：兩家滿足相同SLO（服務水平目標）的CI服務提供商，兩個具有相同永續性規格的物件儲存服務。健康經濟學在此給出的教訓在於*操作順序*：先用證據證明等效性（針對你自己的工作負載做基準測試，針對你自己的SLO做試點，並事先約定好邊界值），再比較包含遷移成本在內的總成本。跳過第一步、直接說"它們基本一樣，B更便宜"，正是許多組織最終買到"便宜10%卻差40%"的工具的原因所在。推論：當供應商以價格為論據時，應要求其同時承諾等效性——這一約束在反方向上同樣有效。

## 陷阱

- **假定等效性**——這是最典型的錯誤；沒有證據顯示存在差異，並不等於有證據證明二者等效（功效不足的試點很容易"免費"就"證明"了等效性）。
- **遺漏切換成本**——遷移、重新培訓與並行運作的成本，都應計入成本一側。
- **在錯誤的結果上求等效**：在被測量的指標上等效，卻在某個真正重要的方面存在差異（可及性、尾部延遲、資料出口）。
