# Betrokkenheidsmetrieken

Betrokkenheidsmetrieken meten hoe vaak en hoe diep gebruikers interactie hebben met een gezondheidsapp of digitale dienst: actieve gebruikers, sessiefrequentie, verblijftijd.

## Waarom het ertoe doet

Een gezondheidsapp zonder betrokkenheid kan geen effect sorteren — hoe sterk het klinische bewijs ook is.

## De wiskunde

```
DAU/MAU-ratio = dagelijks actieve gebruikers / maandelijks actieve gebruikers
```

## Uitgewerkt voorbeeld

Diabetesmanagementapp: DAU 3.000, MAU 12.000 = 0,25 (goed voor een gezondheidsapp).

## Verbinding met software-engineering

Een voorlopende indicator voor [retentie en verloop](../retentie-en-verloop/) en [activering en adoptie](../activering-en-adoptie/).
