# GDS-dienstmetrieken

GDS-dienstmetrieken (Government Digital Service) zijn vier kernmetrieken voor de prestaties van digitale overheidsdiensten: gebruikerstevredenheid, voltooiingspercentage, kostenbesparing en digitaal gebruik.

## Waarom het ertoe doet

Digitale overheidsdiensten moeten resultaten aantonen aan belastingbetalers.

## De wiskunde

```
Voltooiingspercentage = voltooide transacties / gestarte transacties × 100%
```

## Uitgewerkt voorbeeld

Online patiëntregistratiedienst: 10.000 gestart, 8.200 voltooid = 82% voltooiingspercentage.

## Verbinding met software-engineering

Rechtvaardigt samen met [realisatie van baten](../benefits-realization/) publieke digitale investeringen.
