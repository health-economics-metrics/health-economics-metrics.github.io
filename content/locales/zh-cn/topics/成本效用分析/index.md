# 成本效用分析 (Cost-Utility Analysis，CUA)

CUA 是一种以**通用的、按偏好加权的结果**为核心的成本效果分析——几乎总是使用[QALY](../质量调整生命年/)（或避免的 [DALY](../伤残调整生命年/)）。由于结果单位是通用的，CUA 能够跨越完全不同的疾病来比较各种干预措施。

## 为什么重要

一个国家卫生服务体系必须用同一笔预算，在一种抗癌药、一款心理健康应用和一台手术机器人之间做出选择。自然单位无法比较它们；QALY 可以。因此 CUA 是 NICE 及大多数卫生技术评估 (HTA) 机构的参考案例方法：其输出——每 QALY 的成本，再对照[阈值](../支付意愿阈值/)进行判断——是卫生政策领域最接近"通用汇率"的东西。如果你希望自己的软件*取代其他方案*而获得资助，CUA 就是决胜的舞台。

## 计算方法

```
ICUR = ΔCost / ΔQALYs      （以 QALY 作为效果单位的 ICER）

ΔQALYs = Σ (持续时间_i × 效用值_i)_新 − Σ (持续时间_i × 效用值_i)_旧
```

效用值来自经过验证的量表工具（[EQ-5D](../eq-5d/)）；成本与 QALY 均按 3.5%（NICE 参考案例）进行[贴现](../贴现与时间偏好/)；不确定性通过[概率敏感性分析 PSA](../概率敏感性分析/)处理。

## 算例

一款针对中度焦虑的 CBT（认知行为疗法）应用，对比面对面治疗的等候名单，按每位患者计算：

```
成本：应用许可 + 支持       £250
      被替代的治疗           −£680   （40% 的用户不再需要）
      ΔC = 250 − 680 = −£430（节省了资金）

QALY：等待期间的 6 个月，效用值由 0.68 提前提升为 0.76
      ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALY
```

ΔC < 0 且 ΔE > 0：该应用**占优 (dominates)**——效果更好、成本更低，无需计算比率。若治疗替代假设仅为 10%，则 ΔC = 250 − 170 = +£80，ICUR = 80 / 0.04 = **£2,000/QALY**——仍远低于 £20,000。即使把关键假设大幅削减，该论证依然成立：这正是一份稳健的 CUA 应有的样子（[龙卷风图](../敏感性分析/)可以证明这一点）。

## 与软件工程的关联

CUA 的深层理念——*用一个综合的、按偏好加权的单位来比较性质不同的事物*——正是比较性质不同的工程投资（安全性 vs 开发者体验 vs 可靠性）的范式。诚实的选项要么是一个站得住脚的复合单位（罕见），要么是一张明确的[成本后果表](../成本后果分析/)（常见）。CUA 所警惕的是虚假的复合指标：一个"影响力评分"，其权重是在事后为了让偏好的方案胜出而调出来的。卫生经济学花了数十年将效用值的获取方式标准化，正是为了确保权重先于比较而确定。

## 陷阱

- **低于量表工具灵敏度的效用增益**（参见[患者报告结局](../患者报告结局/)中的最小临床重要差异）——用极小的 ΔE 乘以庞大的人群，是一种经典的"洗白"手法。
- **遗漏了对照组的替代照护效应**——对数字化产品而言，最大的成本项往往是它所取代的东西。
- **将非偏好类评分未经验证就映射为效用值**。
