# Fidelizzazione e Abbandono

La fidelizzazione misura quale frazione di una coorte di utenti è ancora attiva N giorni dopo l'inizio. La brutale linea di base della sanità digitale: **circa il 90% degli utenti di app sanitarie abbandona entro 30 giorni**.

## Perché è importante

Eysenbach l'ha nominata nel 2005: **la legge dell'attrito**.

## La matematica

```
Fidelizzazione_Dn = utenti attivi al giorno n / dimensione della coorte × 100
```

## Esempio risolto

Un'app per la salute mentale: QALY guadagnati = 80 (non 100.000 × 0,02 = 2.000).

## Collegamento con l'ingegneria del software

La fidelizzazione è la metrica in cui l'ingegneria del prodotto genera più direttamente valore sanitario.

## Insidie

- **Riciclaggio inverso dell'intention-to-treat.**
