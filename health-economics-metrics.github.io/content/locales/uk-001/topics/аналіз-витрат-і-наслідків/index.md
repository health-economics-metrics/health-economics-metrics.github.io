# Аналіз витрат і наслідків (CCA)

Аналіз витрат і наслідків представляє витрати та кілька результатів поруч у деагрегованій таблиці, не об'єднуючи їх в одне співвідношення.

## Чому це важливо

CCA особливо підходить для втручань у цифрове здоров'я, де ефекти охоплюють кілька вимірів (клінічний, користувацький досвід, операційний), які не зливаються акуратно в одне число QALY.

## Математика

```
Жодної єдиної формули: представити {Витрати, Результат_1, Результат_2, ..., Результат_n} як таблицю
```

## Розібраний приклад

Застосунок цифрового здоров'я повідомляє: витрати £200 000/рік, 15% зменшення повторних госпіталізацій, 20% збільшення задоволеності пацієнтів та 500 заощаджених клінічних годин — кожне представлено окремо.

## Зв'язок з інженерією програмного забезпечення

Подібно до панелі приладів, яка показує кілька KPI (затримка, частота помилок, задоволеність користувачів) поруч, замість стиснення їх в один показник.

## Підводні камені

- **Включення занадто багатьох результатів, що паралізує прийняття рішень замість допомоги.**
- **Вибіркове представлення результатів для створення сприятливого враження.**
