# เศรษฐศาสตร์หน่วยคลาวด์ (FinOps)

เศรษฐศาสตร์หน่วยคลาวด์วิเคราะห์ต้นทุนของทรัพยากรการประมวลผลต่อหน่วยกิจกรรม (เช่น ต่อผู้ใช้ ต่อคำขอ หรือต่อธุรกรรม) เพื่อเข้าใจเศรษฐศาสตร์ของการขยายขนาด

## ทำไมจึงสำคัญ

ต้นทุนบริการคลาวด์ขยายขนาดตามการใช้งาน แตกต่างจากต้นทุนทุนคงที่ — การเข้าใจเศรษฐศาสตร์หน่วยเป็นสิ่งจำเป็นในการคาดการณ์ต้นทุนเมื่อเติบโต

## คณิตศาสตร์

```
ต้นทุนต่อหน่วย = ต้นทุนคลาวด์รวม / จำนวนกิจกรรมทั้งหมด (ผู้ใช้ คำขอ ฯลฯ)
```

## ตัวอย่างที่คำนวณแล้ว

แอปพลิเคชันที่มีต้นทุน £10,000/เดือนสำหรับผู้ใช้ที่ใช้งาน 100,000 คน มีต้นทุน £0.10 ต่อผู้ใช้ — หากเติบโตเป็น 1 ล้านผู้ใช้ด้วยเศรษฐศาสตร์หน่วยเดียวกัน จะมีต้นทุน £100,000/เดือน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือแนวคิดของการพัฒนาซอฟต์แวร์เอง ซึ่งใช้ที่นี่เป็นการเปรียบเทียบกับ [อัตราค่าบริการแห่งชาติและต้นทุนต่อหน่วย](../national-tariff-and-unit-costs/) ในระบบสุขภาพ

## ข้อผิดพลาดที่พบบ่อย

- **การคาดการณ์เศรษฐศาสตร์หน่วยโดยไม่พิจารณาการประหยัดหรือสิ้นเปลืองจากขนาด**
- **การขาดการติดตามต้นทุนคลาวด์เมื่อการใช้งานเติบโต ทำให้เกิดบิลที่น่าประหลาดใจ**
