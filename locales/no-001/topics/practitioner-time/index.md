# Fagpersonellets tid

Fagpersonellets tid bør verdsettes som flaskehalskapasitet — det systemet kan levere — ikke bare som lønnskostnad.

## Hvorfor det er viktig

En spart legetime er ofte mye mer verdifull enn legens timelønn tilsier, fordi legetid er den bindende begrensningen på systemkapasitet.

## Matematikken

```
Verdien av spart tid = Sparte timer × skyggepris for flaskehalskapasitet
```

## Gjennomarbeidet eksempel

En radiolog tjener £80/time, men hver spart radiologitime muliggjør effektivt £300 i nedstrøms pasientgjennomstrømning på grunn av køpress.

## Kobling til programvareutvikling

Ligner på å verdsette en senior arkitekts tid basert på flaskehalsverdien av beslutningene deres, ikke bare lønnen.

## Fallgruver

- **Å bare bruke lønnskostnad for å verdsette spart tid.**
- **Å gi ikke-flaskehalsroller samme skyggepris som flaskehalsroller.**
