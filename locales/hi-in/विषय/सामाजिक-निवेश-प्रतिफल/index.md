# सामाजिक निवेश प्रतिफल (SROI)

SROI [ROI](../निवेश-पर-प्रतिफल/) को उन परिणामों तक विस्तारित करता है जिन्हें बाज़ार मूल्य नहीं देता — भलाई, सामाजिक संबंध, पर्यावरणीय प्रभाव।

## यह क्यों महत्वपूर्ण है

SROI, Social Value International के सात सिद्धांतों द्वारा शासित, "प्रति £1 निवेश में £3.20 सामाजिक मूल्य" जैसे बयान उत्पन्न करता है।

## गणित

```
SROI अनुपात = PV(मुद्रीकृत सामाजिक परिणाम) / PV(निवेश)

मूल्य = मात्रा × वित्तीय प्रॉक्सी × श्रेयता × (1 − डेडवेट) × (1 − विस्थापन)
```

## हल किया गया उदाहरण

एक मित्रता ऐप अलग-थलग वृद्धों को स्वयंसेवकों से जोड़ता है:

```
SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

SROI उस इंजीनियरिंग कार्य के लिए ईमानदार ढाँचा है जिसके लाभार्थी भुगतान करने वाली टीम के बाहर हैं।
