# 集中度指数

集中度指数(Wagstaff、Paci、van Doorslaer、1991年)は、健康変数における社会経済的な不平等の標準的な統計指標で、−1から1の範囲をとります。負の値は健康変数が社会経済的に不利な人々に集中していること、正の値はより裕福な人々に集中していること、ゼロは一貫した社会経済的勾配がないことを意味します。不平等な分布への疑念を、比較可能な単一の数値に変えます。

## なぜ重要か

あるプログラムは全体としては効果的に見えても、その便益がほぼ全面的に、もともと恵まれていた人々に届いていることがあります。こうした分配上の懸念は、まさに[到達範囲と公平性](../reach-and-equity/)が記述的に追跡するものです。剥奪五分位で層別した到達範囲や、最上位群と最下位群の公平性ギャップなどです。しかし、層別した表は単一の傾向線に圧縮できず、異なる尺度で測定された全く別の2つの介入を比較することも容易ではありません。集中度指数は両方の問題を解決します。任意の健康変数を任意の社会経済的順位に対して同じ方法で計算できるため、国の保健サービスは特定のデジタルサービスの不平等がリリースごとに拡大しているか縮小しているかを追跡でき、アプリ展開の分配上の公平性を、たとえばスクリーニングプログラムと同じ正規化された尺度で比較できます。

## 数式

```
CI = (2 / 平均(健康値)) × 共分散(健康値, 社会経済的順位)

共分散(X, Y) = 平均(X × Y) − 平均(X) × 平均(Y)   (母集団共分散)

社会経済的順位: 社会経済的分布における各人の分数順位、[0, 1]
(0 = 最も不利、1 = 最も有利。グループ化・階級化されたデータでは、
慣例として各グループの中点順位)
```

これは「簡便共分散式」(O'Donnell、van Doorslaer、Wagstaff、Lindelow、世界銀行、2008年)で、集中曲線を描いてその下を積分することなく、対になった観測値から直接集中度指数を計算するための実務家向けの標準的な近道です。

## 計算例

自己申告の良好な健康度スコア(1 = 最悪、4 = 最良)を、等しい大きさの4つの社会経済的四分位にわたって観測し、各四分位をその中点順位で表します。

```
健康値               = [1.0, 2.0, 3.0, 4.0]
社会経済的順位       = [0.125, 0.375, 0.625, 0.875]

平均(健康値)         = 2.5
平均(健康 × 順位)    = 平均([0.125, 0.75, 1.875, 3.5]) = 1.5625
平均(社会経済的順位) = 0.5

共分散 = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

正の`0.25`は、この健康スコアが社会経済的に有利なグループに集中していることを意味します。スコアの高い回答者が、順位の裕福な側に偏っています。

## ソフトウェア工学との関連

これは経済学全般で使われる共分散に基づく不平等の測定(ジニ係数の親戚)であり、ソフトウェア製品の便益が公平に行き渡るのではなく、すでに恵まれたユーザーセグメントに集中していないかを測ることに対応します。記述的なギャップではなく正式な統計指標にする点で、[到達範囲と公平性](../reach-and-equity/)(RE-AIMの「到達範囲」の次元)の直接の拡張です。到達範囲と公平性が層ごとの影響を報告するのに対し、集中度指数は分布全体を符号付きの単一の数値に圧縮します。リリースをまたいで追跡する単一のKPIとして適しており、層別の完全な内訳が収まらないダッシュボードで実用的です。

## 落とし穴

- **符号規約のずれ**: 符号は健康変数と順位の両方がどう定義されるかに依存し、どちらかを反転すると符号が反転します。報告する値には必ず使用した規約を明示してください。
- **中点順位ではなく境界順位を使うこと**: グループ化・階級化された社会経済データ(五分位など)では、各グループの分数順位をその境界ではなく*中点*で用いる必要があり、そうしないと指数に偏りが生じます。
- **「ゼロに近い」を「不平等がない」と読むこと**: 集中度指数がゼロに近いことは「一貫した社会経済的勾配がない」ことを意味し、絶対的な意味での「不平等がない」ことではありません。異なる方向の相殺的な不平等は打ち消し合うことがあります。
