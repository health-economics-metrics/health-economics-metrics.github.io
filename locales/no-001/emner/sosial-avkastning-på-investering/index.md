# Sosial avkastning på investering (SROI)

SROI utvider ROI ved å inkludere samfunnsmessige og miljømessige verdier som konvensjonelle markeder ikke prissetter, som velvære og sosial samhørighet.

## Hvorfor det er viktig

Mange helseintervensjoner genererer verdi utover direkte økonomiske besparelser — SROI forsøker å synliggjøre denne bredere påvirkningen.

## Matematikken

```
SROI-ratio = Nåverdi av samfunnsmessige gevinster / Nåverdi av investering
```

## Gjennomarbeidet eksempel

Et samfunnshelseprogram som koster £1 million, genererer en estimert samfunnsverdi på £4 millioner (redusert ensomhet, forbedret sysselsetting, mindre kriminalitet): SROI-ratio 4:1.

## Kobling til programvareutvikling

Ligner på å hevde bredere organisatoriske gevinster (ansattes moral, merkevarens omdømme) fra en teknisk investering, noe som er vanskeligere å kvantifisere enn direkte kostnadsbesparelser.

## Fallgruver

- **Å bruke proxy-verdsettelser uten å underbygge eller validere dem.**
- **Dobbelttelling av gevinster som overlapper hverandre.**
