# 回避された下流の費用

回避された下流の費用(費用の相殺)とは、より早い、あるいはより良い行動によって防がれた将来の治療費用のことであり、介入自体の費用と相殺されます。相殺は、介入が*優越*になり得る仕組みです — より安く**かつ**より良く — そして、医療経済学において最も二重計上され、過大に主張される項目でもあります。

## なぜ重要か

ほとんどすべてのデジタルヘルスの価値提案には相殺の主張が含まれています:「私たちのアプリは入院を防ぐ」「私たちのアラートは悪化を防ぐ」「私たちのプラットフォームは重複検査を回避する」。相殺が本物であるとき、それは経済性を一変させます([ICER](../incremental-cost-effectiveness-ratio/)の計算例で、£60万の相殺がそのケースを成立させているのを見てください)。支払者はこれを知っています — したがって相殺の主張は、あらゆる評価において最も厳しい精査を引き寄せます。以下の信頼性のルールこそが、資金提供可能なモデルとマーケティングを分けるものです。

## 数式

```
正味費用 = 介入費用 − Σ相殺

有効な相殺は以下でなければならない:
  帰属可能 — 介入に因果的に結びついている(比較対象の証拠)
  限界的   — お金が実際に、平均費用ではなく限界費用で使われなくなる
            (限界費用と平均費用を参照)
  確率で   — 下流の出来事が起こっていたであろう確率で重み付けされる
  重み付け
  割引済み — 将来の回避された費用は現在価値で
  一意     — 一度だけ、1つの便益項目で数える
```

## 計算例

「正しく行われたこの移行リスクの主張」:5,000人の術後患者向けの創傷モニタリングアプリが、感染関連の再入院を回避すると主張します。

```
感染によるベースライン再入院:4.0%;アプリあり(RCT):3.1%
帰属可能な回避されたイベント = 5,000 × 0.009 = 年間45件
1再入院あたりの費用(限界的、このトラスト):£3,200
相殺 = 45 × 3,200 = 年間£144,000
アプリの費用 = 5,000 × £20 = 年間£100,000
正味費用 = −£44,000 → 本当に費用節約になる、以下を伴う:
  RCTからの帰属 ✓  限界的な費用計算 ✓  試験データからの確率 ✓
```

「再入院は平均£5,800かかり、大量に防げるだろう」に基づいて構築された同じ主張は、4つのテストすべてに失敗し、受けるべき却下を受けます。

## ソフトウェア工学との関連

「この移行は将来の書き直しを回避する」は相殺の主張であり、医療経済学のルールはそれを正直にします:

- **反実仮想の費用**:その書き直しは実際にどれだけの費用がかかるのか、どう証拠づけられるのか?
- **確率**:その将来はどれくらいありそうか?(100%ではありません — 製品は打ち切られ、優先順位は変わります。)
- **割引**:3.5〜10%の割引で4年目に回避される書き直しは、額面よりもはるかに価値が低くなります。
- **一意性**:同じ回避された書き直しを、技術的負債の項目と定着の項目の両方で主張しないでください。

「相殺の価値 = P(将来のイベント) × 反実仮想の費用 × 割引係数」 — その行を提案書に書いて、その推定値が議論の対象になるのを見てください。それが要点です。

## 落とし穴

- **二重計上** — 同じ回避された入院が、相殺、病床日、そして費用が付随したQALYとして主張されること。
- 固定費がどのみち継続するイベントに対する**平均費用の相殺**。
- 単に可能性があっただけの下流イベントに対する**暗黙の100%確率**。
- 支払いを求められている支払者への節約として提示される**他の予算への相殺** — [分析の視点](../analysis-perspective/)を参照してください。
