# Вартість затримки (CoD)

Вартість затримки — це економічна цінність, яка втрачається за одиницю часу через те, що функція, продукт чи послуга *не* доставляється.

## Чому це важливо

Закон Райнертсена: "Якщо ви вимірюєте лише одне, вимірюйте вартість затримки."

## Математика

```
CoD = втрачена вигода за одиницю часу в стані недоставки (£/тиждень або QALY/тиждень)
```

## Розібраний приклад

**Операційний**: програмне забезпечення заощаджує £200 на пацієнта на шляху; CoD = £10 000/тиждень.

## Зв'язок з інженерією програмного забезпечення

CoD — це метрика, яка робить [час виконання DORA](../метрики-dora/) фінансово читабельним.
