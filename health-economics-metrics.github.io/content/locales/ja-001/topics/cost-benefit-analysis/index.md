# 費用便益分析(CBA)

CBAは費用と成果の*両方*をお金で評価します。「そもそもこれをやる価値があるか?」に答えられる唯一の分析手法であり、単に「どの選択肢が最良か?」に答えるだけではありません — なぜなら、金銭化された便益を費用と直接比較できるからです。

## なぜ重要か

CBAは、公共支出のあらゆる評価に対する英国財務省の**グリーンブック**の標準であり、成果が金銭化できる場合には医療も含まれます。[CEA](../cost-effectiveness-analysis/)/[CUA](../cost-utility-analysis/)が「健康1単位あたりの費用」で止まるところ、CBAは健康そのもの(QALY×閾値の価値)とその他すべて — 時間、移動、炭素 — を値付けし、単一の正味の数値を報告します。あらゆる完全なNHSデジタルビジネスケースには、CBA形式の経済的ケースが含まれています。

## 数式

```
NPV(正味現在社会的価値) = Σ_t [ (便益_t − 費用_t) / (1 + r)^t ]
BCR(便益費用比)         = PV(便益) / PV(費用)

NPV > 0 なら採用する(同等にBCR > 1);BCRではなくNPVで順位付けする。
r = 3.5%(グリーンブックの社会的時間選好率)
```

健康効果は、QALY × λとして金銭化された形で入力できます([支払意思額の閾値](../willingness-to-pay-thresholds/)を参照)。グリーンブックはまた、**楽観バイアス調整**も義務付けています — 評価は体系的にバラ色になりがちであるため、証拠に基づいた割合で費用推定を引き上げ、便益を割り引きます。

## 計算例

eリファラルシステム、5年間の評価期間、3.5%割引:

```
費用:     構築£1.2M(0年目)、運用£300k/年(1〜5年目)
便益:     事務作業の節約£250k/年、回避された重複診断£280k/年、
          患者の節約時間 年間40,000時間 × £15 = £600k/年 → £1,130k/年

PV費用    = 1,200k + 300k × 4.515(年金係数) = £2,555k
PV便益    = 1,130k × 4.515                    = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

グリーンブックの楽観バイアス(構築費用に+40%、便益に−20%とする)を適用すると:PV費用 ≈ £3,035k、PV便益 ≈ £4,082k、NPV ≈ **+£1,047k** — それでもプラスであり、これがこの調整の趣旨です:ケースは自らの楽観主義を割り引いても持ちこたえるべきです。

## ソフトウェア工学との関連

エンジニアリングのビジネスケースは非公式なCBAです。盗む価値のあるグリーンブックの改善点:

- **標準的な引き上げとしての楽観バイアス** — エンジニアが移行費用を過小評価するのは、省庁がインフラ費用を過小評価するのと同じくらい確実です;今回は違うふりをするのではなく、明示された引き上げを適用してください。
- **支配的な便益を正直に金銭化するか、まったく金銭化しないか** — 患者/利用者の時間は弁護可能な率で金銭化されますが、「ブランド価値」はそうではありません。
- **NPVは順位付けできるが、BCRはできません**:BCR 5の小さなプロジェクトは、BCR 1.6の大きなプロジェクトよりも重要でないことがあります。

## 落とし穴

- 便益を水増しするために**金銭化できないものを金銭化すること**(士気、「戦略的整合性」) — それらは[費用結果分析](../cost-consequence-analysis/)に従って定性的なままにしておいてください。
- **移転を便益として数えること**:公的機関間で動くお金は、社会的な[視点](../analysis-perspective/)ではネットでゼロになります。
- **反実仮想がないこと**:便益は最小限の対応という選択肢と比較して測定されるべきであり、ゼロと比較するのではありません。
