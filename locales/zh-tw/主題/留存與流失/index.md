# 留存與流失

留存率衡量的是，一個使用者佇列在開始使用後第N天，仍保持活躍的比例（D1/D7/D30曲線）；流失率則是其對立面。數位健康領域一個殘酷的基線資料是：**約90%的健康應用使用者會在30天內放棄使用**——數位健康類應用的D30留存率約為3–4%，而全部應用的平均水平約為6%。

## 為何重要

Eysenbach在2005年為這一現象命名：**損耗定律（law of attrition）**——以高比例流失使用者，是電子健康介入措施內在的、結構性的特徵，而非某次具體實施的失誤，電子健康試驗中的損耗率經常超過50%。其經濟學後果是全域性性的：留存決定了任何效益能夠被交付的*治療視窗期*，而[單位經濟學](../健康應用單位經濟學/)也隨之受制——為一個只堅持使用12天的使用者支付的獲客成本，既換不來LTV，也換不來QALY。任何一個消費級健康產品的經濟學模型，如果不按留存曲線對效益進行加權，描述的其實是一個並不存在的產品。

## 計算方法

```
留存_Dn = 第n天仍活躍的使用者數 / 佇列總人數 × 100
流失率  = 該週期內流失的使用者數 / 該週期起始時的使用者數 × 100

效益加權（健康經濟學的關鍵操作）：
  每名獲取使用者的期望效益 = Σ_t 留存率(t) × 單位時間效益率(t)
  ≈ 留存曲線下面積 × 單位時間效益
  ——而絕不是"試驗效益 × 100%的已獲取使用者"

每名D30留存使用者的成本 = CAC / D30留存率
  （在D30留存率4%的情況下，£5的CAC實際相當於每名留存使用者£125）
```

## 實例演算

某心理健康應用：試驗顯示，每名完成8周使用的使用者獲得0.02 QALY。部署佇列共10萬次下載，D7留存率25%，D30留存率8%，第8周留存率4%：

```
完成者人數         = 100,000 × 0.04 = 4,000
交付的QALY         = 4,000 × 0.02 = 80  （而非100,000 × 0.02 = 2,000）
按每QALY £20,000計算 = £160萬的健康價值（而非£4,000萬）

每次下載對應的健康價值 = £16——這個數位才應該用來
設定支付方願意為每次下載支付多少，它僅相當於樸素主張的4%。
留存改善的論證案例：將第8周完成率從4%提升到6%，每年可
增加40個QALY ≈ £800,000——留存工程本身就是健康生產。
```

## 與軟體工程的聯絡

按照上述算術，留存正是產品工程最直接創造健康價值的那個指標。能撬動它的做法都很平常：引導流程的首次價值實現時間、重新喚起參與的設計、效能表現，以及至關重要的**計劃性劑量完成**——一個有明確終點（8周後"畢業"）的專案，應當衡量*完成率*，而非永續的DAU，這能使該指標與臨床模型對齊，而非與廣告驅動的注意力模型對齊。生存分析正是恰當的工具箱（與[獲得的生命年](../獲得的生命年/)所用的Kaplan-Meier數學方法相同）；應按獲客渠道對曲線分段，因為渠道組合對留存的影響，往往超過大多數功能改動。

## 陷阱

- **反向的意向性治療式"洗資料"**：試驗報告的是完成者；而部署階段的經濟學核算，必須計入所有被獲取的使用者（這正是Eysenbach最核心的警示）。
- **留存表演**：那些由通知驅動、卻從未真正執行治療性動作的"活躍"使用者（參見[參與度指標](../參與度指標/)）。
- **跨越不同定義比較曲線**："活躍"被定義為"開啟應用"還是"執行有意義的動作"，會使D30數位相差數倍。
- **忽視究竟是誰在流失**：如果病情最重的使用者流失得最快，那麼隨著留存率在健康使用者中不斷改善，人均效益反而會下降——應將留存曲線與病例組合一併分析（參見[觸達與公平](../觸達與公平/)）。
