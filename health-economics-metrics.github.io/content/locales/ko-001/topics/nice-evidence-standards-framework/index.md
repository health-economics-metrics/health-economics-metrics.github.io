# NICE 근거 표준 프레임워크(ESF)

ESF는 **디지털 헬스 기술이 그 위험에 비례하여 얼마나 많은 근거를 필요로 하는지**를 명시하는 NICE의 프레임워크입니다.

## 왜 중요한가

ESF는 디지털 헬스 기술을 임상 기능에 따라 등급으로 분류합니다.

## 수식

```
필요한 근거 투자 = f(등급)
```

## 계산 예시

약물 알림 앱 제조사가 용량 조정 권장 기능 추가를 고려합니다.

## 소프트웨어 공학과의 연관성

ESF는 이 저장소에서 가장 전이 가능한 거버넌스 패턴입니다.

## 함정

- **희망적 사고로 인한 등급 오분류.**

## 출처

- NICE Evidence Standards Framework (ECD7).
- ESF evidence standards tables.
