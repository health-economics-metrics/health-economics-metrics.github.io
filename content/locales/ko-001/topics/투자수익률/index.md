# 투자수익률(ROI)

ROI는 투자된 돈 대비 순이익의 비율입니다. 이것은 공학과 재무가 이미 공유하는 지표입니다 — 보건경제학은 ROI 주장이 검토를 견뎌내게 하는 원칙을 추가합니다.

## 왜 중요한가

ROI는 예산 보유자들의 공통 언어입니다. Masters 등의 검토는 공중보건 개입에 대해 **중앙값 ROI 14.3:1**을 발견했습니다.

## 수식

```
ROI = (편익 − 비용) / 비용
```

## 계산 예시

전자 근무표 시스템, 3년간 £500,000 비용.

## 소프트웨어 공학과의 연관성

모든 도구 제안에는 ROI 슬라이드가 있습니다; 네 가지 매개변수를 명시하는 경우는 거의 없습니다.
