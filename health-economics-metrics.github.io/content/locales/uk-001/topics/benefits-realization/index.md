# Реалізація вигод

Реалізація вигод — це дисципліна відстеження та перевірки того, чи проєкт фактично доставив обіцяні вигоди.

## Чому це важливо

Бізнес-кейс обіцяє вигоди, але без моніторингу ви ніколи не дізнаєтеся, чи вони були реалізовані.

## Математика

```
Рівень реалізації вигод = фактичні вигоди / заплановані вигоди × 100%
```

## Розібраний приклад

Інструмент цифрового тріажу: запланована економія £500 000/рік; через 12 місяців фактична £320 000 = 64% реалізації.
