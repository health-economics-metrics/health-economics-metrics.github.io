# WSJF और CD3

## यह क्यों महत्वपूर्ण है

हर बैकलॉग एक राशनिंग समस्या है।

## गणित

```
CD3 = विलंब लागत (£/सप्ताह) / अवधि (सप्ताह)
```

## हल किया गया उदाहरण

तीन विशेषताएँ, एक टीम:

```
विशेषता CoD (£/सप्ताह) अवधि   CD3
A       30,000          10सप्ताह 3,000
B       12,000          2सप्ताह  6,000
```
