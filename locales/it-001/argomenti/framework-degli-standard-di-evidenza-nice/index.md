# Framework degli Standard di Evidenza NICE (ESF)

L'ESF è il framework di NICE che specifica **quante evidenze necessita una tecnologia di sanità digitale, proporzionalmente al suo rischio**.

## Perché è importante

L'ESF classifica le tecnologie di sanità digitale in livelli in base alla funzione clinica.

## La matematica

```
Investimento in evidenze richiesto = f(livello)
```

## Esempio risolto

Il produttore di un'app di promemoria per farmaci considera di aggiungere una funzione di raccomandazione per l'aggiustamento del dosaggio.

## Collegamento con l'ingegneria del software

L'ESF è il modello di governance più trasferibile in questo repository.
