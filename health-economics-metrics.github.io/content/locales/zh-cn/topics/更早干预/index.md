# 更早干预 (Earlier Intervention)

如果节省下来的产能让从业者能更早处理诊断积压,患者就能更快地从等候名单转入积极治疗——而更早治疗通常比更晚治疗更便宜、效果更好,因为未经治疗的病情会持续进展。

## 为什么重要

病情进展是医疗保健领域的复利。带着未治疗病情等待的患者并非处于稳定状态:癌症会发生分期跃迁,心力衰竭会失代偿,轻度抑郁会转为重度。因此更早干预带来双重红利——**更好的结局**(更多 QALY,从更健康的基线开始治疗)以及往往**更低的治疗成本**(早期治疗强度低于晚期抢救)。正是这一机制,使"更快的路径"从一种运营层面的便利,上升为临床与经济层面的当务之急——这也是[延迟成本](../延迟成本/)适用于临床软件的深层原因。

## 计算方法

```
更早干预的价值(每位患者) =
    [Cost_晚 − Cost_早]                       (治疗成本抵消)
  + [QALY_早 − QALY_晚] × λ                   (健康增益 × 阈值)
  × P(等待期内发生进展的概率)                   (概率加权)
```

概率加权是不可或缺的:并非所有等待的患者都会病情进展。应基于自然病程数据对单位时间的转变概率建模,而非套用最坏情形。然后再贴现:未来数年才避免的成本,其今天的价值更低([贴现](../贴现与时间偏好/))——并且需注意,大多数早期干预是成本*效果好*而非成本*节省*(参见[预防经济学](../预防经济学/))。

## 实例演算

糖尿病视网膜病变筛查积压:4,000 名患者,落后 6 个月。AI 辅助分级使吞吐量提高三倍,8 周内清空积压。自然病程数据显示:在未被复查期间,约 2% 的等待患者/年会进展至威胁视力的阶段。

```
提速约 4 个月所避免的病情进展事件:
  4,000 × 2% × (4/12) ≈ 27 名患者

每例避免进展的价值:
  治疗成本抵消(玻璃体内注射治疗 vs 激光治疗)≈ £4,000
  QALY 增益(保留视力)≈ 0.8 QALY × £20,000 = £16,000

价值 ≈ 27 × (4,000 + 16,000) ≈ £540,000——仅来自一次性清空一批积压,
尚未计入永久性的吞吐量提升。
```

## 与软件工程的关联

有两层迁移。第一层显而易见:加速诊断与治疗路径的软件(分诊、AI 分级、结果路由)正是通过这个模型实现货币化——而该模型也告诉你应优先加速哪条路径:病情进展曲线最陡的那条,而不是队列最长的那条。第二层则是工程领域的镜像:**缺陷同样会"进展"**。在设计阶段被发现的缺陷,代价只是一次对话;到了生产环境,代价就是一次事故;"左移(shift-left)"成本曲线(按阶段相差 10–100 倍)本质上就是一个进展模型,而其诚实版本也带有同样的告诫——早期发现通常是成本效果好,而非白捡的便宜,因为评审和测试本身是有实际成本的,而且大多数被发现的问题原本也未必会真正进展。

## 常见误区

- **对所有人都假设最坏情形的病情进展**——概率加权正是分析与倡导之间的区别所在。
- **提前发现偏倚(lead-time bias)**:更早发现疾病而未改变结局,看似是获益,实则不然;真正的主张应是更早的*有效干预*,而不仅仅是更早的检测(参见[筛查经济学](../筛查经济学/))。
- **重复计算**:等候名单与 RTT 的收益主张若建立在同一次提速之上——一次路径改进,只应归属一组收益,只计一次。
