# Rajakustannus vastaan keskimääräinen kustannus

Rajakustannus on yhden lisäyksikön kustannus; keskimääräinen kustannus on kokonaiskustannus jaettuna yksiköiden määrällä. Ne ovat harvoin yhtä suuret.

## Miksi se on tärkeä

Keskimääräiseen kustannukseen perustuvat säästöväitteet yliarvioivat lähes aina todellisen säästön, koska kiinteät kustannukset eivät katoa määrän pienentyessä.

## Matematiikka

```
Rajakustannus = ΔKokonaiskustannus / ΔMäärä
Keskimääräinen kustannus = Kokonaiskustannus / Määrä
```

## Ratkaistu esimerkki

Sairaalavuoteen keskimääräinen kustannus on £400/päivä (sisältäen yleiskustannukset), mutta yhden paikan vapauttaminen säästää vain noin £150/päivä todella vältettävissä olevista kustannuksista.

## Yhteys ohjelmistokehitykseen

Muistuttaa pilvi-infrastruktuuria: yhden instanssin skaalaaminen alaspäin säästää laskennan rajakustannuksen, ei keskimääräistä kustannusta käyttäjää kohden mukaan lukien kiinteät alustakustannukset.

## Sudenkuopat

- **Keskimääräisen kustannuksen käyttäminen pienimuotoisten muutosten säästöjen arviointiin.**
- **Kiinteiden kustannusten käsitteleminen muuttuvina.**
