# 紹介から治療まで(RTT)

紹介から治療までとは、GPの紹介からコンサルタント主導の治療開始までの経過時間のことです。NHS憲章は基準を定めています:**患者の92%が18週間以内に治療を開始すべき**。RTTは、イングランドのNHSにおいて政治的に最も可視化された単一の運用メトリクスです。

## なぜ重要か

RTTの目標を逃すトラストは、規制上の精査、介入、評判の損失に直面します;全国の待機リストは一面を飾る数字です。患者が待つ毎週は失われた健康であり(より悪い健康状態で待つこと — 以下のQALYの計算を参照)、しばしば費用の増加でもあります(症状が悪化する;[早期介入](../早期介入/)を参照)。紹介から治療までの経路のどこかで時間を節約するソフトウェア — トリアージ、診断のターンアラウンド、診療所の容量、スケジューリング — は、基準を満たせないことの運用上・財政上の結果を直接軽減します。これが、RTTへの影響がNHSデジタルビジネスケースにおいて第一級の便益項目である理由です。

## 数式

```
RTTパフォーマンス = 18週間以内に治療された患者数 / 治療された総患者数 × 100
患者1人あたりの待機時間の健康コスト = 待機期間 × (効用_治療後 − 効用_待機中)

経路の見方:RTT = Σ 各段階の期間(紹介トリアージ → 初回予約 →
診断 → 決定 → 治療) — 最も忙しい段階ではなく、最も長いキューを
改善する(フローメトリクスを参照)。
```

## 計算例

ある専門科は年間5,000人の経路患者を治療します;平均待機24週間;待機中の効用0.68に対し治療後は0.80です。

デジタルトリアージと直接検査プロトコルにより、純粋な待機の5週間が取り除かれます:

```
QALYの獲得 = 5,000 × (5/52) × (0.80 − 0.68) = 年間57.7QALY
£20,000〜£30,000/QALYで金銭化(支払意思額の閾値を参照):
  ≈ 年間£115万〜£173万の健康価値
```

— 加えて、トラストは18週間基準を違反する状態から満たす状態へと移行し、これはどんなスプレッドシートも完全には捉えられないガバナンス上の価値を持ちます。

## ソフトウェア工学との関連

RTTは**多段階キューにわたるリードタイムのメトリクス**です — コミットから本番稼働までのリードタイムの病院版です([DORAメトリクス](../doraメトリクス/)を参照)。改善の方法はまったく同じです:すべての段階を計測し、暦時間がどこに滞留するかを見つけ(それはほぼ常に、臨床作業ではなく引き継ぎとキューです)、待機状態を取り除きます。典型的なソフトウェアの成功例:週次バッチではなく数時間で紹介を振り分けるeトリアージ、フォローアップ予約の代わりの診断結果のプッシュ通知、そして自動化された直接検査の基準。改善は、週あたりのQALYで表した[遅延コスト](../遅延コスト/)で評価してください。

## 落とし穴

- **制約になっていない段階を改善すること** — 診断のキューが増えている一方で初回予約の待機を削減することは、単に滞留を移動させるだけです。
- **ごまかし**:経路のリセットや時計の一時停止は、誰も早く治療することなく報告されるRTTを改善できます;基礎となる分布を監査してください。
- 複数の変更が同時に導入された場合に**経路全体の改善を1つのツールに帰属させること** — 帰属には比較対象が必要です。
