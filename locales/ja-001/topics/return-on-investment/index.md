# 投資収益率(ROI)

ROIは、投資したお金に対する正味の利得の比率です。これはエンジニアリングと財務がすでに共有している指標です — 医療経済学が加えるのは、ROIの主張が精査に耐えられるようにする規律です:明示された視点、比較対象、評価期間、便益のカテゴリー。

## なぜ重要か

ROIは予算保有者の共通言語であり、公衆衛生でも使われています:画期的なMastersらのレビューは、公衆衛生介入について**ROIの中央値14.3:1**を発見しました(£1ごとに、より広い経済と医療システムに約£14が返ってくる) — この数字は予防への支出を主張するために広く使われています。しかしその14:1は*社会的で長期の評価期間*の数値です;病院のCFOのROIは支払者の視点で、1〜3年です。ほとんどのROIをめぐる論争は、実際には視点が明示されていないことによる論争です。

## 数式

```
ROI = (便益 − 費用) / 費用      (しばしば×100%で表示)

投資回収期間 = 費用 / 年間正味便益
```

ROIの主張は、4つの明示なしには定義不足です:

1. **視点** — 誰の便益を数えるのか?([分析の視点](../analysis-perspective/)を参照)
2. **比較対象** — どの代替案との比較か?([機会費用](../opportunity-cost/)を参照)
3. **評価期間** — どれくらいの期間で、[割引](../discounting-and-time-preference/)されるのか?
4. **便益の種類** — 現金化可能、容量、それとも定性的か?([現金化可能な節約と非現金化節約](../cash-releasing-vs-non-cash-releasing/)を参照)

## 計算例

eローステリング(勤務表)システム、3年間で費用£500,000。

```
現金化可能:  派遣シフトの削減              £450,000
容量:        解放された病棟管理者の事務時間  £600,000(評価はされるが蓄えられない)
定性的:      スタッフの満足度、安全性        金銭化されず

厳密な財務ROI  = (450,000 − 500,000)/500,000 = −10%
経済的ROI      = (1,050,000 − 500,000)/500,000 = +110%
```

どちらの数字も真実です。£450kしか蓄えられないCFOに「+110%のROI」を提示するベンダーは信頼を失います;両方をラベル付けして提示することが信頼を勝ち取ります。同じ分割は、2年後に財務部門が便益を監査するときに、社内の推進者を守ります。

## ソフトウェア工学との関連

あらゆるツール導入の提案にはROIのスライドがありますが、4つのパラメータを明示するものはほとんどありません。最も一般的な失敗はカテゴリーの混同です:容量の獲得(開発者の分単位の時間)が財務的な収益として提示されることです。AI/プラットフォームのROIを上記の計算例のように構造化してください — 現金の行、容量の行、定性的な行 — そして曖昧な数値には[感度分析](../sensitivity-analysis/)を加えてください。AI ROIに特有の損益計算書上の現実チェックについては、[AIの投資収益率](../ai-return-on-investment/)を参照してください。

## 落とし穴

- **視点のロンダリング**:10年間の社会的便益が、12か月の評価期間を持つ予算保有者に提示されること。
- **総額と正味額の混同**:£200万の支出に対して「£300万のリターン」は50%のROIであり、300%ではありません。
- **比率の最大化**:小さな分母は、些細な投資に対して壮観なROIを生み出します;ポートフォリオはNPVまたは[正味金銭的便益](../net-monetary-benefit/)で順位付けし、ROIはふるい分けに使ってください。
- **便益監査がないこと**:[便益実現](../benefits-realization/)の追跡なしに予測されたROIは、結果ではなく約束にすぎません。
