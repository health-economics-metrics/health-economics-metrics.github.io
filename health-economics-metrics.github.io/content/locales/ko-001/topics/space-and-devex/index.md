# SPACE와 DevEx

SPACE와 DevEx는 개발자 생산성을 **다차원적으로** 측정하기 위한 프레임워크입니다.

## 왜 중요한가

두 프레임워크 모두 수십 년 전 건강 결과 연구가 배운 것과 동일한 교훈을 담고 있습니다.

## 수식

```
SPACE 규칙: ≥ 3차원, ≥ 1개의 지각적 + ≥ 1개의 시스템 지표
```

## 계산 예시

플랫폼 팀이 300명의 개발자를 위한 DevEx 투자를 정당화합니다.

## 소프트웨어 공학과의 연관성

이 문서는 *바로* 소프트웨어 측면입니다; 전이는 보건경제학 쪽으로 흐릅니다.
