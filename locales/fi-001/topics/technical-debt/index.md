# Tekninen velka

Tekninen velka on aiempien päätösten implisiittinen tulevaisuuden kustannus, jotka olivat kätevä sillä hetkellä koodikannassa: maksamaton korjaustyö (**pääoma**) ja jatkuva vastustus, jonka ne kohdistavat toimitukseen (**korko**).

## Miksi se on tärkeä

Ilman kvantifiointia tekninen velka on valitus; kvantifioinnilla se on liiketoimintatapaus.

## Matematiikka

```
SQALE-pääoma = Σ rikkomukset(korjausaika) × kehittäjän kustannuskorko
```

## Ratkaistu esimerkki

400 000 rivin kliinisten tietueiden integraatiokerros: korko ≈ £276 000/vuosi.

## Yhteys ohjelmistokehitykseen

Terveystaloustieteelliset tuonnit, jotka rikastuttavat teknisen velan keskustelua.

## Sudenkuopat

- **Vain pääoman raportointi.**
