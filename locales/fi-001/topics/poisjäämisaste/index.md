# Poisjäämisaste (DNA)

Poisjäämisaste mittaa varattujen tapaamisten osuutta, joissa potilas ei saavu paikalle peruuttamatta.

## Miksi se on tärkeä

Peruuttamattomat poisjäännit ovat ehkä puhtain hukkamittari terveydenhuollossa: täysin varattu kapasiteetti, joka tuottaa nolla-arvon.

## Matematiikka

```
DNA-aste = Poisjääneiden tapaamisten määrä / Varattujen tapaamisten kokonaismäärä × 100 %
```

## Ratkaistu esimerkki

Poliklinikka, jolla on 10 000 tapaamista vuodessa ja DNA-aste 8 %, menettää 800 tapaamisaikaa, kukin arvostettuna täydellä kliinisellä omakustannushinnalla.

## Yhteys ohjelmistokehitykseen

Muistuttaa varattua mutta käyttämätöntä laskentakapasiteettia pilvisuunnittelussa — täysin maksettu, nolla toimitettua arvoa.

## Sudenkuopat

- **DNA-kustannusten arvostaminen keskimääräisellä rajakustannuksen sijaan.**
- **Muistutusjärjestelmien käyttöönotto puuttumatta taustalla oleviin pääsyesteisiin.**
