# AI 개발자 생산성

AI 개발자 생산성은 AI 코딩 도우미가 개발자 처리량과 코드 품질에 미치는 영향을 측정합니다.

## 왜 중요한가

AI 도구 도입에는 라이선스 비용이 들지만, 생산성 향상이 실제인지 검증해야 합니다.

## 수식

```
생산성 변화율 = (AI 이후 처리량 − AI 이전 처리량) / AI 이전 처리량 × 100%
```

## 계산 예시

50명의 개발자 팀: AI 도구 도입 후 PR 처리량이 주당 120건에서 145건으로 증가 = 21% 향상.
