# 費用効用分析(CUA)

CUAは、**汎用的で選好によって重み付けされたアウトカム**を用いる費用効果分析です — ほとんどの場合[QALY](../質調整生存年/)(または回避された[DALY](../障害調整生存年/))です。アウトカムの単位が普遍的であるため、CUAはまったく異なる疾患にわたって介入を比較できます。

## なぜ重要か

国の医療サービスは、1つの予算から、がん治療薬、メンタルヘルスアプリ、手術ロボットの間で選ばなければなりません。自然単位ではそれらを比較できませんが、QALYならできます。したがってCUAは、NICEやほとんどのHTA機関における基準ケースの手法です:その出力である、[閾値](../支払意思額の閾値/)に照らして判断されるQALYあたりの費用は、医療政策が持つ普遍的な為替レートに最も近いものです。あなたのソフトウェアが*他の何かの代わりに*資金提供されることを望むなら、CUAがその舞台です。

## 数式

```
ICUR = Δ費用 / ΔQALY      (効果の単位としてQALYを用いたICER)

ΔQALY = Σ(期間_i × 効用_i)_新 − Σ(期間_i × 効用_i)_旧
```

効用は検証済みの測定手法([EQ-5D](../eq-5d/))から得られます;費用とQALYはどちらも3.5%(NICE基準ケース)で[割引](../割引と時間選好/)されます;不確実性は[PSA](../確率的感度分析/)を通じて扱われます。

## 計算例

中等度の不安症に対するCBTアプリ 対 対面療法の待機リスト、患者1人あたり:

```
費用:  アプリのライセンス+サポート      £250
       置き換えられた療法              −£680   (利用者の40%がもはや不要になる)
       ΔC = 250 − 680 = −£430(お金を節約)

QALY:  待機中の効用0.68の代わりに、6か月間効用0.76
       ΔE = 0.5 × (0.76 − 0.68) = +0.04QALY
```

ΔC < 0かつΔE > 0:アプリは**優越します** — より良くより安く、比率は不要です。療法の置き換え率の前提がわずか10%だったとしても、ΔC = 250 − 170 = +£80、ICUR = 80 / 0.04 = **£2,000/QALY** — それでも£20,000をはるかに下回ります。主要な前提が大幅に削減されてもケースは持ちこたえます:これが頑健なCUAの姿です(そしてそれを証明するのが[トルネード図](../感度分析/)です)。

## ソフトウェア工学との関連

CUAの深い発想 — *異なるものを比較するための1つの複合的で選好重み付けされた単位* — は、異質なエンジニアリング投資(セキュリティ対開発者体験対信頼性)を比較するためのパターンです。正直な選択肢は、弁護可能な複合単位(まれ)か、明示的な[費用結果表](../費用結果分析/)(通常)のどちらかです。CUAが警告するのは偽の複合指標です:好ましい選択肢を勝たせるために事後に調整された重みを持つ「インパクトスコア」。医療経済学は、まさに比較の*前に*重みを決めるために、数十年をかけて効用の引き出し方を標準化してきました。

## 落とし穴

- **測定手法の感度を下回る効用の獲得**([患者報告アウトカム](../患者報告アウトカム/)における最小臨床的に重要な差を参照) — 小さなΔEに大きな人口を掛けることは典型的な粉飾です。
- **比較対象のケアの置き換えを見逃すこと** — デジタル製品にとって最大の費用項目は、しばしばそれが置き換えるものです。
- 検証されていない対応表を用いて、**非選好スコアを効用にマッピングすること**。
