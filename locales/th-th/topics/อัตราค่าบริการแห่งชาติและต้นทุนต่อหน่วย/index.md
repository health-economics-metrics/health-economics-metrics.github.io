# อัตราค่าบริการแห่งชาติและต้นทุนต่อหน่วย

อัตราค่าบริการแห่งชาติและต้นทุนต่อหน่วยคือราคามาตรฐานที่ระบบสุขภาพจ่ายสำหรับการรักษาหรือขั้นตอนทางคลินิกที่เฉพาะเจาะจง ซึ่งเผยแพร่โดยหน่วยงานกำหนดต้นทุนส่วนกลาง

## ทำไมจึงสำคัญ

อัตราที่เผยแพร่เหล่านี้ให้แหล่งข้อมูลที่เชื่อถือได้สำหรับวิศวกรและนักวิเคราะห์ในการประเมินมูลค่าของกิจกรรมทางคลินิกโดยไม่ต้องใช้การประมาณต้นทุนแบบด้นสด

## คณิตศาสตร์

```
มูลค่าอัตราค่าบริการรวม = ผลรวมของ (ปริมาณกิจกรรมต่อรหัส HRG × อัตราค่าบริการต่อรหัส HRG)
```

## ตัวอย่างที่คำนวณแล้ว

เส้นทางการรักษาที่มีผู้ป่วย 1,000 รายซึ่งได้รับการรักษาภายใต้รหัส HRG ที่มีอัตราค่าบริการ £850: มูลค่าอัตราค่าบริการรวม = £850,000 เพื่อวัตถุประสงค์ในการเปรียบเทียบต้นทุน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับบัญชีราคาคลาวด์มาตรฐานที่ให้ต้นทุนต่อหน่วยที่สอดคล้องกันแทนที่จะให้แต่ละทีมประมาณการของตนเอง

## ข้อผิดพลาดที่พบบ่อย

- **การใช้อัตราค่าบริการเป็นต้นทุนจริงแทนที่จะเป็นค่าเปรียบเทียบเฉลี่ย**
- **การใช้ข้อมูลอัตราค่าบริการที่ล้าสมัยจากปีงบประมาณก่อนหน้า**

## แหล่งที่มา

- NHS England, national tariff payment system.
- NHS Improvement, reference costs collection.
