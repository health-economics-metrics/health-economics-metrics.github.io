# Följsamhet och uthållighet

Följsamhet mäter i vilken grad en föreskriven behandling eller intervention följs; uthållighet mäter om behandlingen fortsätter över tid.

## Varför det är viktigt

En behandling som inte följs ger inga fördelar i praktiken, även om den är effektiv i kliniska prövningar.

## Matematiken

```
Följsamhet (MPR) = föreskrivna dagar levererade / observationsperiod (dagar) × 100 %
```

## Genomarbetat exempel

Användare av en digital app för läkemedelspåminnelser: MPR förbättras från 65 % före interventionen till 82 % efter.

## Koppling till mjukvaruutveckling

Kombineras med [patientrapporterade utfall](../patient-reported-outcomes/) för att verifiera den verkliga effekten av digitala interventioner.

## Fallgropar

- **Att likställa receptutlämning med faktisk användning.**
