# ผลประโยชน์สุทธิทางการเงิน (NMB)

ผลประโยชน์สุทธิทางการเงินแปลงผลลัพธ์ด้านสุขภาพและต้นทุนให้เป็นตัวเลขเงินตัวเดียว โดยใช้เกณฑ์ความเต็มใจจ่ายเพื่อแปลง QALY เป็นมูลค่าเงิน

## ทำไมจึงสำคัญ

NMB แก้ปัญหาทางสถิติบางอย่างของ ICER (เช่นการหารด้วยศูนย์หรือค่าลบ) และทำให้การเปรียบเทียบตัวเลือกหลายตัวตรงไปตรงมามากขึ้น — เลือกตัวเลือกที่มี NMB สูงสุดเสมอ

## คณิตศาสตร์

```
NMB = (ผลลัพธ์ × เกณฑ์ความเต็มใจจ่าย) − ต้นทุน
```

## ตัวอย่างที่คำนวณแล้ว

การรักษาให้ 0.5 QALY เพิ่มเติมด้วยต้นทุน £8,000 ที่เกณฑ์ £20,000/QALY: NMB = (0.5 × £20,000) − £8,000 = £2,000 ซึ่งเป็นค่าบวก แสดงว่าคุ้มทุน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการแปลงตัวชี้วัดคุณภาพซอฟต์แวร์และต้นทุนการพัฒนาให้เป็นมูลค่าธุรกิจตัวเดียวโดยใช้อัตราแปลงมาตรฐาน ทำให้การเปรียบเทียบโครงการที่แตกต่างกันโดยสิ้นเชิงเป็นไปได้

## ข้อผิดพลาดที่พบบ่อย

- **การเลือกเกณฑ์ความเต็มใจจ่ายที่ไม่เหมาะสมซึ่งบิดเบือนผลลัพธ์ NMB**
- **การเปรียบเทียบ NMB ที่คำนวณด้วยเกณฑ์ต่างกัน**
