# 점증적 비용효과비(ICER)

ICER은 차선책 대신 한 옵션을 선택할 때 건강 효과의 추가 단위당 추가 비용입니다.

## 왜 중요한가

보건 시스템은 기술을 결코 고립적으로 평가하지 않습니다 — 항상 *점증적으로* 평가합니다. NICE는 기술의 ICER을 **QALY당 £20,000–£30,000** 임계값과 비교합니다.

## 수식

```
ICER = (비용_신규 − 비용_비교대상) / (효과_신규 − 효과_비교대상)
```

## 계산 예시

심부전 환자를 위한 원격 모니터링 서비스: ICER = £12,000/QALY.

## 소프트웨어 공학과의 연관성

ICER의 원칙은 공학적 결정에 완전히 전이됩니다.

## 함정

- **비교대상 조작.**
- **명시적인 환산 단계 없이 통화 간에 ICER를 비교하기**: 한 나라의 통화로 계산한 ICER는 다른 나라의 임계값과 비교하기 전에 밝혀 둔 방법으로 환산해야 합니다. 환산계수의 선택(구매력평가 대 시장 환율)이 그 자체로 도입 결정을 뒤집을 수 있는 이유는 [통화 간 ICER 비교](../통화-간-icer-비교/)를 참고하세요.
