# 健康调整预期寿命 (Health-Adjusted Life Expectancy, HALE)

HALE 是一个人群层面的汇总指标:一个人预期能够*在完全健康状态下*生活的年数,即从预期寿命中扣除患病或残疾状态所占的年数。全球出生时 HALE 约为 61.9 岁,而预期寿命为 73.3 岁(WHO,2019 年数据)——人类平均而言,人生的最后十年是在非完全健康状态下度过的。

## 为什么重要

HALE 是国家及全球卫生政策的北极星指标——"健康老龄化"目标的分子,而它所揭示的差距(预期寿命减去 HALE)正是预防、早期干预与慢性病管理所要弥合的负担。部委层面的数字健康战略往往以 HALE 为依据加以论证;由各类应用、筛查服务和监测项目组成的整体组合,最终都会汇总到这一指标上。

## 计算方法

标准计算方法是**沙利文法 (Sullivan method)**:

```
HALE_年龄x = Σ (各年龄段 ≥ x 的生命表人年数 × 完全健康状态占比)
             / x 岁时的存活人数

"完全健康状态占比" = 1 − Σ (病症患病率 × 残疾权重)
```

输入数据包括:标准生命表,以及来自全球疾病负担 (Global Burden of Disease) 数据的各健康状态患病率和残疾权重。HALE 与 [DALY](../伤残调整生命年/) 相关联——人群 DALY 负担与 HALE 差距,是对同一份"失去的健康"的两种不同视角。

## 实例演算

某全国性数字高血压项目:纳入 50 万人,平均血压控制改善程度足以将中风发生率每年降低 0.2 个百分点。按该队列的终生周期建模,避免的中风共节省了 15,000 个残疾权重年(伤残所致寿命损失年 YLD,权重 0.32,加上致命中风导致的寿命损失年 YLL)。

```
HALE 贡献 ≈ 15,000 健康年 / 500,000 人
          ≈ 0.03 年(约 11 天)每名参与者的 HALE
```

11 天听起来微不足道——但在人群规模下,这正是国家层面指标实际移动的方式:各国卫生部靠的正是数百万个微小的人均增益。这一算术也说明了为什么**覆盖面(reach)具有主导作用**:一项效果翻倍、但覆盖人数只有十分之一的干预措施,对 HALE 的推动作用要小五倍。参见[覆盖面与公平性](../覆盖面与公平性/)。

## 与软件工程的关联

HALE 是一种"机队健康(fleet-health)"指标模式:**预期服务寿命 × 该寿命中处于健康状态的比例**。平台团队可以为其整个服务资产计算"健康服务寿命预期"——即服务预期运行的年数,再按处于降级、废弃或故障状态所占的时间加以折扣(权重来自 SLO 未达标情况)。这将可靠性的视角,从某一时刻的可用性,重新定义为贯穿全生命周期的"健康"状况,并将修复工作导向那些正在拖累整个资产 HALE 的系统。

## 常见误区

- **HALE 变化缓慢且成因多元**——没有任何单一干预措施能在统计上"撬动"HALE;应主张自身建模得出的贡献,而不是国家层面的统计数字。
- **患病率数据存在滞后**,往往落后数年;近期的改善不会立即体现在官方 HALE 数字中。
- **跨国比较 HALE** 存在陷阱,因为各国健康状态测量方式不同;应在同一系统内进行纵向比较。
