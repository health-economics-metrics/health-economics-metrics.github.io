# 投资回报率 (Return on Investment, ROI)

ROI 是净收益与投入资金之比。这是工程和财务领域早已共用的指标——卫生经济学为其增添的纪律，是让一项 ROI 主张能够经得起审视：明确声明分析视角、比较对象、时间跨度和收益类别。

## 为什么重要

ROI 是预算持有者的通用语言，公共卫生领域也在使用它：具有里程碑意义的 Masters 等人综述发现，公共卫生干预措施的**中位数 ROI 为 14.3:1**（每投入 £1，可为更广泛的经济和医疗系统带来约 £14 的回报）——这一数字被广泛用于论证预防性支出的合理性。但这个 14:1 是一个*社会层面、长时间跨度*的数字；而一位医院财务总监（CFO）关心的 ROI，是支付方视角下 1-3 年的数字。大多数关于 ROI 的争论，实际上都是未声明分析视角所引发的争论。

## 计算方法

```
ROI = （收益 − 成本）/ 成本      （通常以 × 100% 表示）

投资回收期 = 成本 / 年度净收益
```

一项 ROI 主张若缺少以下四项声明，就属于定义不完整：

1. **分析视角**——谁的收益被计入？（参见[分析视角](../分析视角/)）
2. **比较对象**——相对于哪种替代方案？（参见[机会成本](../机会成本/)）
3. **时间跨度**——跨越多长时间，是否经过[贴现](../贴现与时间偏好/)？
4. **收益类别**——现金释放型、产能型，还是定性收益？（参见[现金释放型与非现金释放型收益](../现金释放型-vs-非现金释放型节约/)）

## 实例计算

一套电子排班系统，三年成本为 £500,000。

```
现金释放型：  临时工班次削减           £450,000
产能型：      病区经理释放出的行政时间 £600,000（已估值，但未实际入账）
定性型：      员工满意度、安全性       未货币化

严格财务 ROI  = (450,000 − 500,000)/500,000 = −10%
经济学 ROI    = (1,050,000 − 500,000)/500,000 = +110%
```

两个数字都是真实的。如果向一位只能实际入账 £450k 的财务总监宣传"+110% 的 ROI"，会失去信任；同时展示两者并加以标注，则能赢得信任。同样的拆分，也能在两年后财务审计收益时保护一位内部推动者的信誉。

## 与软件工程的关联

几乎每一份工具提案都会有一张 ROI 幻灯片；但几乎没有一份会声明这四项参数。最常见的错误是类别混淆：将产能收益（开发者节省的分钟数）当作财务回报来展示。应按照上述实例计算的结构来组织 AI/平台 ROI 论证——现金一行、产能一行、定性一行——并对软性数字加做[敏感性分析](../敏感性分析/)。关于 AI ROI 的损益表现实核查，具体参见 [AI 投资回报率](../ai投资回报率/)。

## 常见陷阱

- **视角清洗**：把跨越十年的社会层面收益，展示给一位时间跨度只有 12 个月的预算持有者。
- **用毛值代替净值**："花 £200 万带来 £300 万回报"是 50% 的 ROI，而不是 300%。
- **比率最大化**：分母极小会让微不足道的投资产生惊人的 ROI 数字；应按 NPV 或[净货币效益](../净货币效益/)对项目组合排序，ROI 只用作初步筛选工具。
- **缺少收益审计**：没有[收益实现](../收益实现/)追踪的预测型 ROI，只是一个承诺，而不是一个结果。
