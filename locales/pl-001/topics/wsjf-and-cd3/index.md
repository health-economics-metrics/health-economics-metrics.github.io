# WSJF i CD3

CD3 i WSJF to reguły priorytetyzacji pracy oparte na **gęstości wartości**.

## Dlaczego to ważne

Każdy backlog to problem racjonowania.

## Matematyka

```
CD3 = koszt opóźnienia (£/tydzień) / czas trwania (tygodnie)
```

## Rozwiązany przykład

Trzy funkcje, jeden zespół: kolejność CD3: B, C, A.

## Powiązanie z inżynierią oprogramowania

Dla portfeli oprogramowania zdrowotnego wyrażaj CoD w QALY/tydzień.

- **Teatr punktacji WSJF.**
