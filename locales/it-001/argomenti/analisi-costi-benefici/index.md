# Analisi Costi-Benefici (CBA)

La CBA valuta sia i costi *che* i risultati in denaro. È l'unico tipo di analisi che può rispondere a "vale la pena farlo?"

## Perché è importante

La CBA è lo standard dell'HM Treasury Green Book del Regno Unito per tutte le valutazioni di spesa pubblica.

## La matematica

```
VAN = Σ_t [ (Beneficio_t − Costo_t) / (1 + r)^t ]
```

## Esempio risolto

Un sistema di e-referral, orizzonte di 5 anni: VAN = +£2.547 mila, BCR = 2,0.

## Collegamento con l'ingegneria del software

**Come bias di ottimismo standard** — gli ingegneri sottostimano i costi di migrazione tanto quanto i ministeri sottostimano i costi infrastrutturali.

## Insidie

- **Monetizzare l'immonetizzabile** per gonfiare i benefici.
