# Afkast af KI-investering

KI-ROI måler den økonomiske værdi, der skabes, sammenlignet med omkostningerne ved at bygge og drive KI-systemer.

## Hvorfor det er vigtigt

KI-projekter har ofte skjulte driftsomkostninger: infrastruktur, modeltræning og løbende inferensomkostninger.

## Matematikken

```
KI-ROI = (skabt værdi − (udviklingsomkostning + driftsomkostning)) / (udviklingsomkostning + driftsomkostning) × 100 %
```

## Gennemarbejdet eksempel

KI til opsummering af klinisk dokumentation: udvikling £300.000 + drift £100.000/år; sparet lægetid = £600.000/år = 50 % ROI i år 1.

## Forbindelse til softwareudvikling

Kombinerer [return on investment](../return-on-investment/) med [inferensens enhedsøkonomi](../inferensens-enhedsøkonomi/).

## Faldgruber

- **At udelade inferensomkostninger fra driftsbudgettet.**
