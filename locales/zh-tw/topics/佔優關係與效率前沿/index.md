# 佔優關係與效率前沿

如果一個方案的成本更低*且*效果更好，那麼另一個方案就被稱為**被佔優**的。**效率前沿**是剔除掉所有被佔優方案之後剩下的部分：在這個集合中，要獲得更多效果，就必須付出更多成本。

## 為何重要

在討論閾值或預算之前，衛生技術評估首先要做的，是剔除掉那些任何人都不應該選擇的方案。將每個方案標繪在"成本-效果"平面上並畫出前沿線，是一項只需五分鐘的練習，卻往往能直接淘汰掉候選清單中的一半方案。此後，增量比較（[ICER](../增量成本效果比/)）只在*沿著這條前沿線*進行計算——每個方案都只與緊鄰其下、未被佔優的次便宜方案比較——而絕不是在存在更好的中間方案時，仍與"什麼都不做"相比較。

## 計算方法

```
嚴格佔優：  若 成本_A ≤ 成本_B 且 效果_A ≥ 效果_B（其中至少一項為嚴格不等式），
           則稱A佔優於B

擴充套件佔優：  若A與C的某種組合能以更低的每英鎊成本實現更多效果，
           則B將被排除——判定方法是：隨著沿前沿線向上移動，
           若ICER反而下降，即表明存在擴充套件佔優。有效前沿上的ICER必須遞增。
```

操作步驟：按效果對各方案排序；剔除所有嚴格被佔優的方案；計算相鄰方案之間的ICER；剔除任何ICER高於其右側效果更好方案的選項（即擴充套件佔優的情形）；重複此過程，直至ICER呈單調遞增。

## 實例演算

針對降低爽約率有四個備選方案（效果 = 每年挽回的預約數）：

```
方案             年成本      挽回預約數
什麼都不做        £0          0
簡訊提醒          £20,000     2,000
電話呼叫          £120,000    2,200
簡訊+AI分診       £90,000     3,500
```

電話呼叫方案被"簡訊+AI分診"方案**嚴格佔優**（成本更高，挽回數卻更少）。有效前沿為：什麼都不做 → 簡訊 → 簡訊+AI。

```
ICER(簡訊 相對 什麼都不做)   = 20,000 / 2,000  = 每挽回一次預約£10
ICER(簡訊+AI 相對 簡訊)      = (90,000 − 20,000) / (3,500 − 2,000) = 每挽回一次預約£46.67
```

ICER遞增 → 前沿有效。按每挽回一次醫院預約節省約£160計算（參見[爽約率](../爽約率/)），前沿上的這兩步都值得采納；而"電話呼叫中心"這一方案，本就不應該被擺上委員會的會議桌。

## 與軟體工程的聯絡

對任何工具決策都可以繪製同樣的圖表：一個軸是每年成本，另一個軸是實測結果（節省的工時、避免的事件數、啟用的部署次數）。位於前沿左上方的那些方案，在任何人開始討論預算之前就應被剔除。這能把供應商選型，從圍繞功能清單的爭論，重塑為"你被佔優了，會議到此結束"。它同樣能揭示一種常見的企業病症：為一點微小的邊際收益，購買最昂貴的方案——只有當組織願意在明知情況下為那份邊際單位收益支付相應邊際價格時，這樣做才是合理的。

## 陷阱

- **將一切都與基線相比較**，而非與前沿上的相鄰方案相比較——這會透過掩蓋更便宜的近似等效方案，人為抬高昂貴方案的吸引力。
- **單一維度的效果評分**掩蓋了真正重要的資訊；如果有兩個結果都算數，要麼以站得住腳的方式將其合併（參見[成本效用分析](../成本效用分析/)），要麼就展示兩條前沿線。
- **忽視不確定性**：在[敏感性分析](../敏感性分析/)下，靠近前沿線的方案排序可能會發生互換。
