# Jumlah yang Perlu Diobati (NNT)

NNT adalah jumlah pasien yang harus menerima suatu intervensi agar **satu** pasien tambahan mendapat manfaat.

## Mengapa ini penting

"Mengurangi serangan jantung 25%!" terdengar meyakinkan. Jika risiko dasar 4% dalam 5 tahun, pengurangan absolut adalah 1 poin persentase.

## Matematika

```
ARR = tingkat kejadian kontrol − tingkat kejadian pengobatan
NNT = 1 / ARR
```

## Contoh yang diselesaikan

Sistem prediksi jatuh di rumah sakit: NNT = 125.

## Hubungan dengan rekayasa perangkat lunak

NNT adalah unit yang tepat untuk gerbang atau pemeriksaan apa pun.

## Jebakan

- **Tidak ada kerangka waktu.**
