# Dominans og effektivitetsfronten

Ett alternativ dominerer et annet når det er billigere og minst like effektivt. Effektivitetsfronten viser de ikke-dominerte alternativene.

## Hvorfor det er viktig

Dominerte alternativer kan elimineres umiddelbart, noe som forenkler beslutningsrommet før detaljerte kostnadseffektivitetsberegninger er nødvendig.

## Matematikken

```
Alternativ A dominerer alternativ B hvis: kostnad(A) ≤ kostnad(B) OG effekt(A) ≥ effekt(B)
```

## Gjennomarbeidet eksempel

Fire behandlingsalternativer på en kostnads-effektgraf: alternativ C koster mer enn alternativ B, men gir mindre helse enn en blanding av A og D — alternativ C er utvidet dominert og elimineres.

## Kobling til programvareutvikling

Ligner på å eliminere arkitekturalternativer som er både dyrere og tregere enn et alternativ.

## Fallgruver

- **Å overse utvidet dominans og bare sjekke enkel dominans.**
- **Å sammenligne alternativer parvis i stedet for mot hele fronten.**
