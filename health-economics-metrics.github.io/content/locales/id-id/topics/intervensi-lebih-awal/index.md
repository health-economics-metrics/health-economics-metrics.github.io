# Intervensi Lebih Awal

Jika kapasitas yang dihemat memungkinkan seorang klinisi meninjau backlog diagnostik lebih cepat, pasien pindah dari daftar tunggu ke pengobatan aktif lebih cepat.

## Mengapa ini penting

Perkembangan penyakit adalah bunga majemuk perawatan kesehatan.

## Matematika

```
Nilai intervensi lebih awal (per pasien) =
    [Biaya_lambat − Biaya_awal]
  + [QALY_awal − QALY_lambat] × λ
  × P(perkembangan selama penundaan)
```

## Contoh yang diselesaikan

Backlog skrining retinopati diabetik: 4.000 pasien, tertinggal 6 bulan. Nilai ≈ £540.000.

## Hubungan dengan rekayasa perangkat lunak

Cacat juga *berkembang*.

## Jebakan

- **Mengasumsikan perkembangan skenario terburuk untuk semua orang.**
