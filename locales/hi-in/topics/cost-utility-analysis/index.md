# लागत-उपयोगिता विश्लेषण (CUA)

CUA एक **सामान्य, प्राथमिकता-भारित परिणाम** के साथ लागत-प्रभावशीलता विश्लेषण है — लगभग हमेशा [QALY](../quality-adjusted-life-year/)।

## यह क्यों महत्वपूर्ण है

एक राष्ट्रीय स्वास्थ्य सेवा को एक बजट से एक कैंसर दवा, एक मानसिक-स्वास्थ्य ऐप, और एक सर्जिकल रोबोट के बीच चुनना होता है।

## गणित

```
ICUR = Δलागत / ΔQALY
```

## हल किया गया उदाहरण

मध्यम चिंता के लिए एक CBT ऐप बनाम आमने-सामने थेरेपी की प्रतीक्षा सूची:

```
लागत:  ऐप लाइसेंस + सहायता £250, विस्थापित थेरेपी −£680
       ΔC = −£430 (पैसे बचाता है)
QALY:  ΔE = +0.04
```

ΔC < 0 और ΔE > 0: ऐप **हावी है**।

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

CUA का गहरा विचार — *असमान चीज़ों की तुलना के लिए एक संयुक्त, प्राथमिकता-भारित इकाई* — असमान इंजीनियरिंग निवेशों की तुलना का पैटर्न है।

## सामान्य गलतियाँ

- **उपकरण की संवेदनशीलता से नीचे उपयोगिता लाभ।**
- **तुलनाकर्ता देखभाल विस्थापन को छोड़ना।**
