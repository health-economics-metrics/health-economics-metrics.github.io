# Kekurangan QALY dan Pengubah Keparahan

Kekurangan QALY mengukur berapa banyak kesehatan masa depan yang diambil suatu penyakit dari pasien dibandingkan dengan populasi umum.

## Mengapa ini penting

Sejak manual NICE 2022, keparahan adalah pengali eksplisit pada nilai perolehan kesehatan.

## Matematika

```
Kekurangan absolut = QALY_populasi_umum − QALY_dengan_kondisi
```

## Contoh yang diselesaikan

Pasien dengan kondisi agresif, usia rata-rata 60. Kekurangan absolut = 12,1 (≥ 12 → memenuhi syarat ×1,2).

## Hubungan dengan rekayasa perangkat lunak

Pembobotan keparahan adalah versi formal dari apa yang secara naluriah dilakukan organisasi rekayasa.

## Jebakan

- **Menghitung kekurangan terhadap garis dasar yang salah.**
