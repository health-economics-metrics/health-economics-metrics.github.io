# Ventelisteeffekt

Ventelisteeffekt måler hvordan sparte kliniske timer eller forbedret effektivitet omdannes til faktisk behandlede ekstra pasienter.

## Hvorfor det er viktig

Effektivitetsgevinster gir bare reell verdi når de omdannes til ekstra gjennomstrømning — ellers forblir de teoretiske.

## Matematikken

```
Ekstra behandlede pasienter = Sparte kliniske timer / Gjennomsnittlig tid per pasientkonsultasjon
```

## Gjennomarbeidet eksempel

Et effektivitetsprosjekt sparer 500 kliniske timer per måned; ved en gjennomsnittlig konsultasjonstid på 20 minutter tilsvarer dette 1 500 ekstra behandlede pasienter per måned.

## Kobling til programvareutvikling

Ligner på å omdanne spart CI/CD-pipelinetid til faktisk leverte ekstra funksjoner, i stedet for bare å hevde "raskere bygg".

## Fallgruver

- **Å anta at spart tid automatisk gjenbrukes for ekstra pasienter — se [kontantfrigjørende kontra ikke-kontantfrigjørende besparelser](../kontantfrigjørende-kontra-ikke-kontantfrigjørende-besparelser/).**
- **Å ignorere oppdemmet etterspørsel som raskt fyller ventelisten igjen.**
