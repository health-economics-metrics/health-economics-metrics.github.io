# 创造价值的产能（运营扭转）

创造价值的产能，是被释放时间所带来的"机会效益"：借助你的软件释放出的这些工时，医院现在能够*实现*什么。这是运营总监与医务总监最看重的指标，因为它使用的正是他们日常管理所依据的那套货币——活动量、目标达成，以及周转效率。

## 为何重要

NHS正面临巨大的转诊至治疗积压，而未能达成国家等候时间标准的信托机构，将面临监管审查与介入干预（参见[转诊至治疗](../转诊至治疗/)）。招聘进度缓慢且受限；场地设施是固定的。唯一能快速见效的杠杆，就是从现有员工与场地中榨取出更多创造价值的活动量。能重新夺回专科人员时间的软件，不只是"省钱"——它*凭空铸造出产能*：那些原本根本无法开设的门诊、原本根本无法排上的评估，在不招聘、不建设的情况下变得可能。

## 计算方法

```
被创造的隐性产能 = 被释放的时间 → 转化为可实现的活动单位数 × 标准价格

活动单位：门诊就诊、术前评估、监测复查
标准价格：全国统一收费标准/NHS支付方案价格
         （参见national-tariff-and-unit-costs.md）
```

这正是[从业者时间](../从业者时间/)按产出基础估值的方法，被扩展到一整条服务线，并以运营团队本已在使用的那套活动单位来表达。

## 实例演算

5级职级专科护士负责运营术前评估门诊。文书自动化为25名护士中的每一位每天回收1小时；每小时可容纳2次评估。

```
额外评估次数 = 25名护士 × 每天2次 × 250个工作日 = 每年12,500次
按每次术前评估约£120的标准价格计算：
  12,500 × £120 = 每年创造£150万的照护产能
```

——且无需招聘一名护士，也无需新建一间诊室。（本文最初所参照的那份被广泛引用的模型，对一个规模更小的队列给出的数字是每年£766,920；其算术模式完全相同——该数字随护士人数 × 场次 × 标准价格等比例缩放。）对运营总监而言，这一运营框架的意义在于：术前评估不再是手术室排期的约束瓶颈——当日临时取消的手术随之减少，手术室利用率随之上升，而这正是*下一条*效益线的起点（参见[下游资源优化](../下游资源优化/)）。

## 与软件工程的联系

同样的重新框定，也能把开发者生产力的主张从单纯的薪资算术中解救出来：将被释放的工程时间，表述为*组织原本无力承担、如今却能交付的能力*——功能、迁移工作、可靠性改进——按组织在边际上为此类能力所需支付的价格来估值（承包商费率，或延后招聘的等效成本）。这套运营总监式的框定方式，同样对如何推介平台工作有所启示：应以听众所依据管理的那套计量单位来表述效益。运营领导者以活动量与目标达成为思考单位，而非抽象的小时数；工程领导者以路线图条目与人员编制为思考单位，而非节省的分钟数。

## 陷阱

- **没有需求支撑的产能主张**：额外的12,500个评估名额，只有在手术管线能够真正填满它们时才有意义——应核查下游约束是否存在。
- **有标准价格却没有对应的付费机制**：在混合支付模式下，额外的活动量未必能带来额外收入；其价值也许应体现为等候名单的缩减（参见[等候名单影响](../等候名单影响/)）。
- **将产能呈现为现金**——这是最具代表性的非现金释放型效益；务必如实标注（参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)）。
