# Wskaźniki zaangażowania

Wskaźniki zaangażowania mierzą, jak często i jak głęboko użytkownicy wchodzą w interakcję z aplikacją zdrowotną lub usługą cyfrową: aktywni użytkownicy, częstotliwość sesji, czas przebywania.

## Dlaczego to ważne

Aplikacja zdrowotna bez zaangażowania nie może mieć żadnego efektu — bez względu na to, jak silne są dowody kliniczne.

## Matematyka

```
Współczynnik DAU/MAU = dziennie aktywni użytkownicy / miesięcznie aktywni użytkownicy
```

## Rozwiązany przykład

Aplikacja do zarządzania cukrzycą: DAU 3000, MAU 12 000 = 0,25 (dobry wynik dla aplikacji zdrowotnej).
