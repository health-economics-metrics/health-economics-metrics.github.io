# 品質調整生命年（QALY）

一個QALY，是指在完全健康狀態下度過的一年生命。它將人們*活多久*與*活得好不好*結合在一起，因此在不良健康狀態下度過的一年，其計數會少於一個QALY——從而使得完全不同的健康介入措施，能夠在同一個尺度上進行比較。

## 為何重要

QALY是衛生技術評估領域的通用貨幣。NICE（英格蘭）將健康獲益的價值定為**每QALY £20,000–£30,000**：一項能以低於該閾值的價格買到QALY的介入措施，通常會獲得推薦；而價格更高的，通常會被拒絕。正是這一個數位，讓一個國家醫療服務體系能夠在同一個座標軸上，比較一種抗癌藥、一次髖關節置換手術，以及一款分診應用。如果你的軟體能夠可信地主張獲得了QALY——透過預防病情惡化、加速治療，或提升安全性——你就能用與醫學本身完全相同的貨幣，為其健康價值定價。

## 計算方法

```
QALY = Σ_i (時長_i × 效用值_i)

時長_i = 處於健康狀態i的年數
效用值_i = 狀態i的品質權重，錨定為1 = 完全健康，0 = 死亡
          （對於比死亡更差的狀態，允許取負值）
```

效用權重來自經過驗證的量表工具，最常用的是[EQ-5D](../EQ-5D/)。某項介入措施所帶來的QALY*增量*，是"有該介入"與"無該介入"兩條QALY軌跡之間的差值，在NICE參考案例中按每年3.5%進行[貼現](../貼現與時間偏好/)。

## 實例演算

某病患在等待心臟治療，處於效用值為0.6的狀態。治療能將其恢復至效用值0.85。

- **立即接受治療**：這一年為0.85 × 1 = 0.85 QALY。
- **延遲6個月後再接受治療**：0.5 × 0.6 + 0.5 × 0.85 = 0.725 QALY。
- **該延遲為每名病患造成的QALY損失**：0.85 − 0.725 = **0.125 QALY**。

按NICE閾值貨幣化：0.125 × £20,000–£30,000 = **每延遲6個月，每名病患損失£2,500–£3,750的健康價值**。如果某軟體能為每年400名病患加速這一路徑、消除這一延遲，其健康價值為50個QALY，約合**每年£100萬–£150萬**——這還不包括任何營運層面的節省。

## 與軟體工程的聯絡

- **更快的路徑 = 更早獲得的QALY。**任何能縮短[轉診至治療](../轉診至治療/)時間的手段，都能將等待期間的負效用轉化為健康獲益，其估值方式如上所述。
- **安全性 = 被保留下來的QALY。**被預防的用藥錯誤與漏診，等同於被避免的QALY損失。
- **QALY同樣是一種指標設計模板**：它是"數量 × 品質"的複合指標，其品質權重來自一套標準化量表工具的徵詢。一個"品質調整工程師年"（時間 × 開發者體驗調查權重）正是同樣的構造方式——參見[SPACE與開發者體驗](../SPACE與開發者體驗/)。
- 若要將QALY轉化為商業案例所需的貨幣價值，請使用[淨貨幣效益](../淨貨幣效益/)；若要將其轉化為決策，請使用[支付意願閾值](../支付意願閾值/)。

## 陷阱

- **憑空捏造效用權重。**權重必須來自經過驗證的量表工具（EQ-5D）與已釋出的價值集，而非直覺。
- **在沒有明確因果路徑的情況下主張獲得了QALY。**"我們的應用能改善幸福感"並不構成一項QALY主張；"消除了效用值0.6狀態下X周的等待時間"才是。
- **重複計算**：同時主張同一次被避免的病情惡化所帶來的QALY獲益與成本節省，需要格外審慎地確保二者確實彼此獨立、互不重疊。
- **公平性盲點**：QALY是按基線效用值來衡量延長一年生命的價值，這可能會對殘障人士不利——這正是美國ICER之所以同時報告evLYG的原因（參見[獲得的生命年](../獲得的生命年/)）。
