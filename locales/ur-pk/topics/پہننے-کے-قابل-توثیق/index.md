# پہننے کے قابل توثیق

توثیق کے میٹرکس یہ مقدار طے کرتے ہیں کہ ایک پہننے کے قابل آلے کے پیمانے ایک کلینیکل گولڈ اسٹینڈرڈ سے کتنے میل کھاتے ہیں: **MAPE**، معاہدہ ارتباط، Bland-Altman معاہدہ — ساتھ ہی آپریشنل میٹرکس: **پہننے-کا-وقت کی پابندی** اور **ڈیٹا کی مکملیت**۔

## یہ کیوں اہم ہے

توثیق ڈاؤن اسٹریم ہر چیز کی پیشگی شرط ہے۔ دل کی دھڑکن کے لیے اس شعبے کی منظور شدہ حدیں: ECG کے خلاف **MAPE ≤5%** (سخت) یا **≤10%** (نرم)۔

## ریاضی

```
MAPE = (1/n) Σ |ماپا_i − حوالہ_i| / حوالہ_i × 100
```

## حل شدہ مثال

ایک ورچوئل-وارڈ پروگرام ایک نگرانی پہننے کے قابل آلہ منتخب کرتا ہے۔ امیدوار A: آرام MAPE 2.1%، ورزش MAPE 11.4%۔ امیدوار B: آرام 3.8%، ورزش 6.9%۔

```
استعمال کا معاملہ: گھر پر بگڑتے مریض کی شناخت — اکثر سرگرمی کے دوران۔
امیدوار A کا سرخی نمبر (2.1%) بروشر جیتتا ہے؛ امیدوار B استعمال
کا معاملہ جیتتا ہے: متعلقہ حالت (حرکت) میں، A کی 11.4% غلطی
پورے الرٹ حد بینڈ میں پھیلی ہوئی ہے۔
```

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرز سینسرز چنتے وقت توثیق کا ڈیٹا استعمال کرتے ہیں اور پیمائش کی خصوصیات بناتے وقت اسے *پیدا* کرتے ہیں۔

## عام غلطیاں

- **مجموعی MAPE حالت-مخصوص ناکامی چھپاتا ہے۔**
