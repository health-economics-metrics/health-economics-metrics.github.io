# Kovat kassavaikutteiset säästöt (alijäämän puolustus)

Kovat kassavaikutteiset säästöt ovat budjettirivejä, jotka todella poistetaan — rahaa, jota järjestelmä ei enää käytä — toisin kuin teoreettiset tehokkuushyödyt.

## Miksi se on tärkeä

Kun organisaation on puolustettava alijäämää sääntelyviranomaisille, vain kova kassavaikutus lasketaan; ei-kassavaikutteiset "säästöt" jätetään huomiotta talouden sääntelyviranomaisten toimesta.

## Matematiikka

```
Kova säästö = budjettirivin todellinen vähennys (varmennettu tilinpäätöksessä)
```

## Ratkaistu esimerkki

Fyysisen toimipisteen sulkeminen ja siihen liittyvien £500 000/vuosi vuokrakustannusten poistaminen on kova säästö; väite, että henkilöstö "työskentelee tehokkaammin" ilman henkilöstövähennystä, ei ole.

## Yhteys ohjelmistokehitykseen

Muistuttaa pilvipalvelun todellista irtisanomista verrattuna "parantuneen tehokkuuden" väittämiseen laskematta laskua.

## Sudenkuopat

- **Ei-kassavaikutteisten säästöjen esittäminen kovina säästöinä talouden sääntelyviranomaisille.**
- **Säästön toteuttamisen siirtymäkustannusten jättäminen huomiotta.**

## Lähteet

- HM Treasury, Green Book supplementary guidance.
- NHS England, financial recovery guidance.
