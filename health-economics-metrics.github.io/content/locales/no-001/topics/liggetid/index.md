# Liggetid

Liggetid måler antall dager en pasient tilbringer på sykehus, fra innleggelse til utskrivning — sykehusets syklustid.

## Hvorfor det er viktig

Kortere liggetid sparer ressurser og reduserer risikoen for sykehusrelaterte komplikasjoner, men for aggressiv forkorting øker reinnleggelser.

## Matematikken

```
Gjennomsnittlig liggetid = Totalt antall liggedøgn / Antall innleggelser
```

## Gjennomarbeidet eksempel

En avdeling forkorter gjennomsnittlig liggetid fra 6 til 4,5 dager gjennom forbedret utskrivningskoordinering, noe som frigjør sengekapasitet for 25 % flere pasienter uten ekstra senger.

## Kobling til programvareutvikling

Ligner på syklustid i [flytmål](../flytmål/) — hvor lenge en oppgave befinner seg i systemet fra start til fullføring.

## Fallgruver

- **Å forkorte liggetiden uten å ta hensyn til effekten på reinnleggelser.**
- **Å bruke gjennomsnitt som forvrenges av ekstreme avvik.**
