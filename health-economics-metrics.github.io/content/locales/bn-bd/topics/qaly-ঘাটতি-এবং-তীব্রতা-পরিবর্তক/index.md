# QALY ঘাটতি এবং তীব্রতা পরিবর্তক

QALY ঘাটতি পরিমাপ করে একটি রোগ সাধারণ জনসংখ্যার তুলনায় রোগীদের থেকে কত ভবিষ্যৎ স্বাস্থ্য কেড়ে নেয়। NICE এটি ব্যবহার করে **তীব্রতা পরিবর্তক** প্রয়োগ করতে: জনগোষ্ঠী যত বেশি অসুস্থ, প্রতিটি অর্জিত QALY তত বেশি মূল্যবান — প্রমিত থ্রেশহোল্ডের ১.৭× পর্যন্ত।

## কেন এটি গুরুত্বপূর্ণ

NICE-এর ২০২২ ম্যানুয়াল থেকে, তীব্রতা স্বাস্থ্য লাভের মূল্যের উপর একটি স্পষ্ট গুণক, পুরনো জীবনের-শেষ প্রিমিয়ামকে প্রতিস্থাপন করে। একটি গুরুতর অবস্থার জন্য একটি প্রযুক্তি £৩০,০০০-এর পরিবর্তে ~£৫১,০০০/QALY পর্যন্ত একটি কার্যকর থ্রেশহোল্ডের বিরুদ্ধে বিচার করা হয়। আপনার সফটওয়্যার যদি গুরুতরভাবে প্রভাবিত একটি জনগোষ্ঠীকে সেবা দেয় (উন্নত হৃদরোগ, গুরুতর মানসিক অসুস্থতা), তীব্রতা পরিবর্তক একটি অর্থায়নযোগ্য এবং অ-অর্থায়নযোগ্য অর্থনৈতিক ক্ষেত্রের মধ্যে পার্থক্য হতে পারে — এবং এটি দাবি করতে আপনার ঘাটতি গণিত প্রয়োজন।

## গণিত

বর্তমান স্ট্যান্ডার্ড যত্নসহ অবশিষ্ট জীবদ্দশায় গণনাকৃত দুটি পরিমাপ:

```
পরম ঘাটতি      = QALY_সাধারণ_জনসংখ্যা − QALY_অবস্থাসহ
আনুপাতিক ঘাটতি = পরম ঘাটতি / QALY_সাধারণ_জনসংখ্যা
```

NICE ২০২২ ওজন (যে পরিমাপ বেশি ওজন দেয় তা প্রযোজ্য):

```
ওজন ×1.0: পরম < 12 এবং আনুপাতিক < 0.85
ওজন ×1.2: পরম ≥ 12 বা আনুপাতিক ≥ 0.85
ওজন ×1.7: পরম ≥ 18 বা আনুপাতিক ≥ 0.95
```

ওজনটি ΔE (বা সমতুল্যভাবে থ্রেশহোল্ড) দিয়ে গুণিত হয়: কার্যকর λ ×1.2-এ £24হাজার–£36হাজার এবং ×1.7-এ £34হাজার–£51হাজার হয়ে যায়।

## সমাধানকৃত উদাহরণ

একটি আক্রমণাত্মক অবস্থার রোগী, গড় বয়স ৬০। ৬০ বছরে সাধারণ জনসংখ্যা ১৪.২ ছাড়যুক্ত QALY প্রত্যাশা করে; বর্তমান যত্নের অধীনে এই অবস্থাসহ, ২.১।

```
পরম ঘাটতি      = 14.2 − 2.1 = 12.1  (≥ 12 → ×1.2-এর যোগ্য)
আনুপাতিক ঘাটতি = 12.1 / 14.2 = 0.852 (≥ 0.85 → ×1.2ও)
```

আপনার পর্যবেক্ষণ প্ল্যাটফর্মের ICER £২৬,০০০/QALY — প্রমিত £২০হাজার–£৩০হাজার মধ্যবিন্দু বিচারের উপরে, সীমান্তরেখায়। ×১.২ ওজনসহ: কার্যকর ICER = 26,000 / 1.2 ≈ **£21,700/QALY** — স্বাচ্ছন্দ্যে অর্থায়নযোগ্য। ঘাটতি গণনাই সিদ্ধান্ত স্থানান্তরিত করেছে।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

তীব্রতা ওজন প্রকৌশল সংস্থাগুলো সহজাতভাবে যা করে তার একটি আনুষ্ঠানিক সংস্করণ: সবচেয়ে খারাপ অবস্থার ব্যবস্থায় প্রতি এককে উন্নতিতে বেশি খরচ করা। স্থানান্তরযোগ্য প্যাটার্ন — প্রতিটি সেবার "SLO ঘাটতি" গণনা করুন (এটি তার প্রত্যাশিত সুস্থ বেসলাইনের কতটা নিচে চলছে, পরম এবং আনুপাতিকভাবে), এবং সেই অনুযায়ী প্রতিকারের মূল্য ওজন করুন।

## ঝুঁকিপূর্ণ দিক

- **ভুল বেসলাইনের বিপরীতে ঘাটতি গণনা করা**: এটি *বর্তমান স্ট্যান্ডার্ড যত্নের* অধীনে পরিমাপ করা হয়, চিকিৎসাহীন স্বাভাবিক ইতিহাস নয়।
- **বয়স সংবেদনশীলতা**: ঘাটতি জনগোষ্ঠীর বয়সের উপর ব্যাপকভাবে নির্ভর করে (তরুণ রোগীদের হারানোর জন্য বেশি QALY আছে → বেশি পরম ঘাটতি); প্রকৃত চিকিৎসিত জনগোষ্ঠীর বয়স বণ্টন ব্যবহার করুন।
- **পরিবর্তক অন্যত্র প্রযোজ্য বলে ধরে নেওয়া** — এটি একটি NICE (ইংল্যান্ড) প্রক্রিয়া; অন্যান্য HTA সংস্থা তীব্রতা ভিন্নভাবে পরিচালনা করে (বা একেবারেই না)।
