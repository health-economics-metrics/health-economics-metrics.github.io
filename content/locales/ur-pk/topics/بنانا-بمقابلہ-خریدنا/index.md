# بنانا بمقابلہ خریدنا

بنانا-بمقابلہ-خریدنا حسب ضرورت ترقی اور تجارتی حصول کا ایک منظم موازنہ ہے۔

## یہ کیوں اہم ہے

صحت کے نظام مسلسل اس فیصلے کا سامنا کرتے ہیں۔

## ریاضی

```
NPV_آپشن = PV(فوائد) − PV(TCO)
```

## حل شدہ مثال

ایک ٹرسٹ کو ایک ای-رضامندی نظام کی ضرورت ہے۔ خریدیں: £150k/سال SaaS، 3 ماہ میں لائیو۔

## سافٹ ویئر انجینئرنگ سے تعلق

منتقلی کے قابل صحت-معاشیات کا ضابطہ تین گنا ہے۔

## عام غلطیاں

- **بیچنے والے کی فہرست کی قیمت کا خطرے کے لحاظ سے غیر ایڈجسٹ شدہ تعمیر کے تخمینوں سے موازنہ کرنا۔**
