# Предотвращённые последующие затраты (Avoided Downstream Costs)

Предотвращённые последующие затраты (компенсации затрат, cost offsets) — это будущие расходы на лечение, предотвращённые более ранним или более качественным действием, зачтённые против собственной стоимости вмешательства. Компенсации — это механизм, посредством которого вмешательство может стать *доминирующим* — дешевле **и** лучше одновременно, — и они же являются наиболее часто задваиваемой и переоцениваемой статьёй в экономике здравоохранения.

## Почему это важно

Почти каждое ценностное предложение цифрового здравоохранения содержит утверждение о компенсации: «наше приложение предотвращает госпитализации», «наши оповещения предотвращают ухудшение состояния», «наша платформа избегает дублирующих анализов». Когда компенсации реальны, они преобразуют экономику (см. практический пример в [ICER](../инкрементальное-соотношение-затрат-и-эффективности/), где компенсация в £600 тыс. решает исход). Плательщики это знают — поэтому заявления о компенсациях привлекают самую жёсткую проверку в любой оценке. Правила достоверности ниже — это то, что отличает финансируемую модель от маркетинга.

## Математика

```
Чистые затраты = стоимость вмешательства − Σ компенсаций

Валидная компенсация должна быть:
  Атрибутируемой   — причинно связанной с вмешательством (доказательства по компаратору)
  Предельной       — деньги действительно перестают тратиться, по предельной, а не
                     средней стоимости (см. marginal-vs-average-cost.md)
  Взвешенной по    — взвешена по P(наступило бы последующее событие)
  вероятности
  Дисконтированной — будущие предотвращённые затраты по приведённой стоимости
  Уникальной       — засчитана один раз, в одной строке выгоды
```

## Практический пример

«Это утверждение о риске миграции, сделанное правильно»: приложение мониторинга ран для 5 000 послеоперационных пациентов заявляет о предотвращении повторных госпитализаций, связанных с инфекциями.

```
Базовая частота повторных госпитализаций по инфекции: 4.0% ; с приложением (RCT): 3.1%
Предотвращено атрибутируемых событий = 5,000 × 0.009 = 45/год
Стоимость случая повторной госпитализации (предельная, для данного траста): £3,200
Компенсация = 45 × 3,200 = £144,000/год
Стоимость приложения = 5,000 × £20 = £100,000/год
Чистые затраты = −£44,000 → действительно экономит средства, при этом:
  атрибуция из RCT ✓  предельное калькулирование затрат ✓  вероятность из данных испытания ✓
```

То же самое утверждение, построенное на «повторные госпитализации стоят в среднем £5 800, мы предотвратим кучу», провалит все четыре проверки и заслуживает отказа, который получает.

## Связь с разработкой программного обеспечения

«Эта миграция позволяет избежать будущего переписывания» — это утверждение о компенсации, и правила экономики здравоохранения делают его честным:

- **Контрфактические затраты**: сколько на самом деле будет стоить переписывание, какими доказательствами это подтверждено?
- **Вероятность**: насколько вероятно это будущее? (Не 100% — продукты закрывают, приоритеты меняются.)
- **Дисконтирование**: переписывание, предотвращённое в 4-й год, при дисконте 3,5–10% стоит намного меньше номинала.
- **Уникальность**: не заявляйте то же самое предотвращённое переписывание одновременно в строке технического долга и в строке удержания.

`Offset value = P(future event) × counterfactual cost × discount factor` — впишите эту строку в предложение и наблюдайте, как оценка становится предметом обсуждения, что и является целью.

## Подводные камни

- **Двойной счёт** — одна и та же предотвращённая госпитализация заявляется и как компенсация, и как койко-дни, и как QALY с привязанной стоимостью.
- **Компенсации по средним затратам** для событий, чьи постоянные затраты продолжаются в любом случае.
- **Тихая 100%-ная вероятность** для последующих событий, которые были лишь возможны.
- **Компенсации другим бюджетам**, представленные как экономия для плательщика, которого просят заплатить — см. [перспектива анализа](../перспектива-анализа/).
