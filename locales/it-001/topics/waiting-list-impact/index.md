# Impatto della Lista d'Attesa

L'impatto della lista d'attesa converte la capacità clinica risparmiata in pazienti rimossi da (o spostati più velocemente attraverso) la lista d'attesa.

## Perché è importante

La lista d'attesa elettiva è la sfida post-pandemica che definisce l'NHS.

## La matematica

```
Slot aggiuntivi = ore liberate / durata dello slot × utilizzo
```

## Esempio risolto

Il software di documentazione ambientale risparmia 45 minuti al giorno per 20 infermiere di clinica.

## Collegamento con l'ingegneria del software

Una lista d'attesa è un backlog.

## Insidie

- **Slot ≠ pazienti.**
