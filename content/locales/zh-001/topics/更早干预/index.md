# 更早干预

如果被释放的产能能让从业者更早地处理诊断积压，患者就能更快地从等候名单转入积极治疗——而更早治疗通常比更晚治疗更便宜、效果也更好，因为未经治疗的病情会不断进展。

## 为何重要

疾病进展是医疗领域的"复利"。一名带着未经治疗的病情等候的患者，并不处于一个稳定状态：癌症会发生分期上移，心力衰竭会失代偿，轻度抑郁会转为重度。因此，更早干预能带来双重红利——**更好的结果**（获得更多QALY，且是从更健康的基线开始治疗）以及往往**更低的治疗成本**（早期治疗强度通常低于晚期抢救）。正是这一机制，将"更快的诊疗路径"从一项锦上添花的运营改善，提升为临床与经济双重意义上的必要之举——这也是[延迟成本](../延迟成本/)之所以适用于临床软件的深层原因。

## 计算方法

```
更早干预的价值（每名患者） =
    [晚期治疗成本 − 早期治疗成本]                    （治疗成本冲抵）
  + [早期治疗QALY − 晚期治疗QALY] × λ                （健康获益 × 阈值）
  × P(等待期间发生病情进展的概率)                     （概率加权）
```

概率加权这一环节至关重要：并非每一位等候患者都会病情进展。应基于自然病程数据，对单位时间内的转变概率建模，而不是按最坏情形估算。随后还需贴现：数年后才避免的成本，其现值更低（参见[贴现](../贴现与时间偏好/)）——并且需要注意，大多数早期干预是具有成本*效果*，而非直接*节省*成本（参见[预防经济学](../预防经济学/)）。

## 实例演算

糖尿病视网膜病变筛查积压：4,000名患者，积压达6个月。AI辅助分级将吞吐量提升至三倍，8周内清空积压。自然病程数据显示：等待期间未被复查的患者中，每年约2%会进展至威胁视力的阶段。

```
因提前约4个月而避免的病情进展事件：
  4,000 × 2% × (4/12) ≈ 27名患者

每例避免的病情进展：
  治疗成本冲抵（玻璃体内注射治疗 对比 激光治疗）≈ £4,000
  QALY获益（保留视力）≈ 0.8 QALY × £20,000 = £16,000

价值 ≈ 27 × (4,000 + 16,000) ≈ £540,000——这还仅仅是一次性清空
一批积压所带来的价值，尚未计入永久性的吞吐量提升。
```

## 与软件工程的联系

这里有两层迁移关系。第一层是显而易见的：能加速诊断与治疗路径的软件（分诊、AI分级、结果路由）正是通过这套模型实现货币化——而这套模型也告诉你应优先加速哪条路径：应是那条进展曲线最陡峭的路径，而非队列最长的那条。第二层是工程领域的镜像："缺陷"同样会"进展"。一个在设计阶段就被发现的bug，代价只是一次讨论；而到了生产环境才被发现，代价则是一次事件；"左移"成本曲线（按阶段相差10–100倍）本身就是一个进展模型，而其诚实的版本也带有相同的告诫——早期检测通常是具有成本效果，而非天上掉下来的免费午餐，因为评审与测试本身都有真实成本，而且大多数被发现的问题本来也未必会真正进展恶化。

## 陷阱

- **对所有人都假设最坏情形的病情进展**——概率加权正是区分"分析"与"倡导性宣传"的关键所在。
- **前导时间偏倚**：更早发现疾病却并未改变最终结果，看似是效益，实则不然；真正的主张应是更早的*有效干预*，而不仅仅是更早的检测本身（参见[筛查经济学](../筛查经济学/)）。
- **重复计算**：等候名单主张与转诊至治疗主张若都建立在同一次加速之上——应记住，这是一次路径改进，只对应一组效益，只应分配计算一次。
