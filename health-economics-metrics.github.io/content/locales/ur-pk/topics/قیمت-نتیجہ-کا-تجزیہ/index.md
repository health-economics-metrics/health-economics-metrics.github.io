# قیمت-نتیجہ کا تجزیہ (CCA)

CCA قیمت کو **تمام نتائج کی الگ کی گئی جدول** کے ساتھ پیش کرتا ہے۔

## یہ کیوں اہم ہے

CCA ڈیجیٹل صحت کی ٹیکنالوجیز کے لیے NICE کا **ترجیحی معاشی فارمیٹ** ہے۔

## ریاضی

آؤٹ پٹ ایک جدول ہے:

```
                     مداخلت   موازنہ کنندہ   فرق
قیمت (سالانہ)        £X       £Y             ΔC
```

## حل شدہ مثال

ڈیجیٹل پری-آپریٹو تشخیصی پلیٹ فارم بمقابلہ فون-بنیاد پر عمل۔

## سافٹ ویئر انجینئرنگ سے تعلق

CCA ایک اچھے پلیٹ فارم تجویز کے پہلے سے استعمال ہونے والے متوازن اسکور کارڈ کی رسمی شکل ہے۔

## عام غلطیاں

- **چنیدہ نتائج۔**

## ذرائع

- NICE Evidence Standards Framework (ECD7).
