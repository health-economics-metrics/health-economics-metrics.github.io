# จำนวนที่ต้องรักษา (NNT)

จำนวนที่ต้องรักษาวัดว่าต้องมีผู้ป่วยกี่รายที่ต้องได้รับการแทรกแซงเพื่อป้องกันผลลัพธ์ไม่ดีเพิ่มเติมหนึ่งกรณี เมื่อเทียบกับกลุ่มควบคุม

## ทำไมจึงสำคัญ

NNT เปลี่ยนสถิติประสิทธิผลทางคลินิกที่เป็นนามธรรม (ความเสี่ยงสัมพัทธ์) ให้เป็นตัวชี้วัดที่เป็นรูปธรรมและเข้าใจง่าย ซึ่งสามารถเชื่อมโยงโดยตรงกับต้นทุนต่อผู้ป่วยได้

## คณิตศาสตร์

```
NNT = 1 / (อัตราเหตุการณ์ในกลุ่มควบคุม − อัตราเหตุการณ์ในกลุ่มรักษา)
```

## ตัวอย่างที่คำนวณแล้ว

ยาลดความเสี่ยงหัวใจวายจาก 10% เป็น 8% (การลดความเสี่ยงสัมบูรณ์ 2%): NNT = 1/0.02 = 50 หมายความว่าต้องรักษาผู้ป่วย 50 รายเพื่อป้องกันหัวใจวายหนึ่งราย

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการเปลี่ยนอัตราการแก้ไขข้อบกพร่องให้เป็น "จำนวนผู้ใช้ที่ได้รับผลกระทบจากการแก้ไขหนึ่งครั้ง" — จากเปอร์เซ็นต์ที่เป็นนามธรรมสู่หน่วยที่เป็นรูปธรรม [จำนวนที่ต้องคัดกรอง](../จำนวนที่ต้องคัดกรอง/)เป็นตัวเลขคู่เทียบที่สูงขึ้นหนึ่งระดับ สำหรับโปรแกรมคัดกรองแล้วจึงรักษาทั้งหมด ไม่ใช่เฉพาะการรักษา

## ข้อผิดพลาดที่พบบ่อย

- **การสับสน NNT ระหว่างขอบเขตเวลาและประชากรที่แตกต่างกัน**
- **การไม่พิจารณาต้นทุนการแทรกแซงควบคู่กับ NNT เพื่อให้ได้ต้นทุนที่แท้จริงต่อผลลัพธ์ที่หลีกเลี่ยงได้**
