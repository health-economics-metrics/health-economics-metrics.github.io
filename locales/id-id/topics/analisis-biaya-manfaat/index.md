# Analisis Biaya-Manfaat (CBA)

CBA menilai biaya *dan* hasil dalam uang. Ini adalah satu-satunya jenis analisis yang dapat menjawab "apakah ini layak dilakukan sama sekali?"

## Mengapa ini penting

CBA adalah standar HM Treasury Green Book Inggris untuk semua penilaian pengeluaran publik.

## Matematika

```
NPV = Σ_t [ (Manfaat_t − Biaya_t) / (1 + r)^t ]
```

## Contoh yang diselesaikan

Sistem e-rujukan, cakrawala 5 tahun: NPV = +£2.547 ribu, BCR = 2,0.

## Hubungan dengan rekayasa perangkat lunak

**Sebagai bias optimisme standar** — insinyur meremehkan biaya migrasi seandal kementerian meremehkan biaya infrastruktur.

## Jebakan

- **Memonetisasi yang tidak dapat dimonetisasi** untuk menggembungkan manfaat.
