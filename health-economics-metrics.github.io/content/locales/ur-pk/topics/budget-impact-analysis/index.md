# بجٹ کے اثرات کا تجزیہ (BIA)

BIA اندازہ لگاتا ہے کہ ایک مداخلت اپنانے سے اگلے 1–5 سالوں میں ایک مخصوص ادا کنندہ کے **بجٹ** پر کیا اثر پڑتا ہے۔

## یہ کیوں اہم ہے

مالیاتی ڈائریکٹر کا سوال کبھی بھی "ICER کیا ہے؟" نہیں ہوتا۔

## ریاضی

```
BI_سال_t = قیمت_منظرنامہ_نیا(t) − قیمت_منظرنامہ_موجودہ(t)
```

## حل شدہ مثال

20 لاکھ لوگوں کا احاطہ کرنے والا ادا کنندہ £300/مریض/سال کی ایک ڈیجیٹل تھراپیوٹک پر غور کرتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

BIA فی-سیٹ ROI دعوے کے لیے صحیح CFO-مرکوز تکمیل ہے۔

## عام غلطیاں

- **فوری-اپنانے کا خیالی تصور۔**
