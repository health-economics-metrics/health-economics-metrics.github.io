# KI og utviklerproduktivitet

KI og utviklerproduktivitet måler effekten av KI-kodeassistenter på utvikleres gjennomstrømning og kodekvalitet.

## Hvorfor det er viktig

Innføring av KI-verktøy medfører lisenskostnader, men om produktivitetsgevinstene er reelle, må verifiseres.

## Matematikken

```
Produktivitetsendring = (gjennomstrømning etter KI − gjennomstrømning før KI) / gjennomstrømning før KI × 100 %
```

## Gjennomarbeidet eksempel

Et team med 50 utviklere: PR-gjennomstrømningen øker fra 120 til 145 per uke etter innføring av KI-verktøy = 21 % forbedring.
