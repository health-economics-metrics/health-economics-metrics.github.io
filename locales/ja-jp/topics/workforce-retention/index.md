# 人材の定着

人材定着の経済学は、スタッフの離職が医療システムにとってどれだけの費用になるか — 採用、オンボーディング、欠員のカバー — を定量化し、したがって管理業務の燃え尽きを減らすソフトウェアがどれだけの価値を持つかを定量化します。反復的な管理データ業務による燃え尽きは、NHSにおけるスタッフの離職と病欠の主要な要因です。

## なぜ重要か

臨床医が退職すると、トラストは3度支払うことになります:代替要員を採用するため(広告、派遣手数料、面接)、その人をオンボーディングするため(数か月の生産性低下、指導監督)、そしてその間の欠員をカバーするため — 通常はAgenda for Changeの本来の給与の2〜3倍の派遣スタッフや代診医によってです([回避可能な外部委託費用](../avoidable-outsourcing-costs/)と[確実な現金化削減](../hard-cash-releasing-savings-deficit-defence/)を参照)。離職費用は実際の現金であるため、定着の改善は財務担当者が銀行に入れられる数少ない人材関連の便益の1つです。管理上の摩擦は、臨床医の燃え尽きの原因として一貫して上位に挙げられており、これはソフトウェアで対処できる費用にします。

## 数式

```
離職者1人あたりの費用 = 採用費用 + オンボーディング/立ち上げの生産性費用
                       + 欠員カバーのプレミアム × 欠員期間

年間離職費用 = 人員数 × 離職率 × 離職者1人あたりの費用

ソフトウェアの価値 = 人員数 × Δ離職率 × 離職者1人あたりの費用
                    + 病欠削減 × 1日あたりのカバー費用
```

因果連鎖には2つの推定されたつながりがあります — ソフトウェア → 燃え尽き/摩擦、そして燃え尽き → 離職 — なので両方に証拠を求め(前後のスタッフ調査;公表された燃え尽き-離職の関連性)、主張するΔは控えめに保ってください。

## 計算例

あるトラストは1,200人の看護師を雇用しています;離職率は年11%。離職者1人あたりの費用:

```
採用 ≈ £4,500;  オンボーディング/立ち上げ ≈ £6,000
欠員カバー:4か月 × 派遣プレミアムでカバーされる0.6WTE ≈ £8,000
合計 ≈ 離職者1人あたり£18,500
ベースライン離職費用 = 1,200 × 0.11 × 18,500 ≈ 年間£244万
```

文書作成負担を軽減するソフトウェア(自動入力される評価、シングルサインオン、口述筆記)は、離職率を1パーセントポイント動かすことがもっともらしいです:

```
価値 = 1,200 × 0.01 × 18,500 = 年間£222,000の現金関連価値
```

スタッフ調査の摩擦スコアに裏付けられた1ポイントの主張は信頼できますが、4ポイントの主張はそうではありません。Δ離職率について[トルネード](../sensitivity-analysis/)を実行してください:それはモデルの他のすべてを支配します。

## ソフトウェア工学との関連

エンジニアリングの定着計算はまったく同じですが、文書化がより不十分です:シニアエンジニアを交代させるには全負担給与の6〜12か月分がかかります(採用、立ち上げ、失われたコンテキスト)。したがって、離職率15%の200人組織は、離職だけで年間数百万を燃やしています。開発者体験への投資([SPACEとDevEx](../space-and-devex/))は、看護師にとっての文書作成負担軽減の直接的な類似物であり — 同じように正当化されるべきです:測定された摩擦スコア、離職への控えめな主張された効果、自社の財務データからの離職者1人あたりの費用。コピーすべき医療経済学の規律は、人々が本当にツールのせいで辞めるのかどうかを議論することではなく、*離職者を正直に費用計算する*ことです。

## 落とし穴

- **すべての離職の変動を自分の介入に帰属させること** — 労働市場は、ソフトウェアよりもはるかに離職を動かします;対照群を使うか、少なくとも業界トレンドの調整を行ってください。
- **二重計上**:定着の節約と派遣支出の節約は重複します(欠員カバーは*まさに*派遣支出です);項目を突き合わせてください。
- **時間差を無視すること**:燃え尽きによる離職は、摩擦の変化に対して次の四半期ではなく1〜2年かけて反応します。
