# ต้นทุนค่าเสียโอกาส

ต้นทุนค่าเสียโอกาสคือมูลค่าของทางเลือกที่ดีที่สุดที่คุณสละไปเมื่อคุณผูกมัดทรัพยากร ในระบบสุขภาพที่มีงบประมาณคงที่ การใช้จ่าย 1 ล้านปอนด์กับสิ่งหนึ่งหมายความว่าสุขภาพมูลค่า 1 ล้านปอนด์จะ *ไม่ถูก* ผลิตขึ้นที่อื่น

## ทำไมจึงสำคัญ

ต้นทุนค่าเสียโอกาสเป็นแนวคิดที่ลึกซึ้งที่สุดในเศรษฐศาสตร์สุขภาพ และเป็นสิ่งที่วิศวกรซอฟต์แวร์มักมองข้ามบ่อยที่สุด งบประมาณด้านสุขภาพถูกกำหนดคงที่ในแต่ละปี ดังนั้นเทคโนโลยีใหม่จึงไม่เคยได้รับเงินทุนจาก "เงินส่วนเกิน" แต่มันเข้ามาแทนที่สิ่งอื่น คำถามที่ผู้จ่ายเงินถามจริงๆ ไม่ใช่ "สิ่งนี้ดีหรือไม่" แต่คือ "สิ่งนี้ดีกว่าสิ่งที่เงินจำนวนเดียวกันซื้อได้ในปัจจุบันหรือไม่"

## คณิตศาสตร์

```
ต้นทุนค่าเสียโอกาสของการเลือก A = มูลค่าของทางเลือก B ที่ดีที่สุดที่ถูกสละไป
ผลกำไรสุทธิจาก A = มูลค่า(A) − มูลค่า(B)
```

## ตัวอย่างที่คำนวณแล้ว

งบประมาณการเปลี่ยนแปลงขององค์กรด้านสุขภาพสามารถให้เงินทุนได้เพียงหนึ่งในสองตัวเลือก: ซอฟต์แวร์จัดตารางงานที่ประหยัดเงิน £400,000/ปี หรือซอฟต์แวร์ประสานงานการจำหน่ายที่ประหยัด 2,000 วันเตียง/ปี (มูลค่า £300,000) การให้เงินทุนกับตัวเลือกแรกหมายถึงการสละตัวเลือกที่สอง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ความสามารถทางวิศวกรรมก็เป็นงบประมาณคงที่เช่นกัน — ช่องแผนงาน ไม่ใช่เงินปอนด์ ทีมแพลตฟอร์มที่ให้เงินทุนเครื่องมือ A ซึ่งประหยัดชั่วโมงวิศวกรที่ £500/ชั่วโมง ในขณะที่เครื่องมือ B ส่งมอบสิ่งเดียวกันที่ £200/ชั่วโมง กำลังทำลายความสามารถ

## ข้อผิดพลาดที่พบบ่อย

- **การเปรียบเทียบกับความว่างเปล่า** ตัวเปรียบเทียบที่ถูกต้องคือการใช้เงินที่ดีที่สุดรองลงมา ไม่ใช่ "ไม่ทำอะไรเลย"
- **การสันนิษฐานว่าเวลาที่ประหยัดได้ไม่มีต้นทุนค่าเสียโอกาส** — ดู [การประหยัดที่ปลดปล่อยเงินสดเทียบกับที่ไม่ปลดปล่อยเงินสด](../cash-releasing-vs-non-cash-releasing/)
