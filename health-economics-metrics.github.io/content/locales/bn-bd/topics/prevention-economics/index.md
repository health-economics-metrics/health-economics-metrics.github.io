# প্রতিরোধ অর্থনীতি

রোগ ঘটা বা অগ্রসর হওয়ার আগে হস্তক্ষেপের অর্থনীতি। শিরোনাম আবিষ্কারটি সহজাত বোধের বিপরীত: **বেশিরভাগ প্রতিরোধ অর্থ সাশ্রয় করে না** — এটি একটি ভালো মূল্যে স্বাস্থ্য কেনে।

## কেন এটি গুরুত্বপূর্ণ

"প্রতিরোধ অর্থ সাশ্রয় করে" স্বাস্থ্য নীতিতে সবচেয়ে বেশি পুনরাবৃত্ত মিথ্যা দাবি। সৎ কাঠামো: প্রতিরোধ এখন অর্থ খরচ করে এবং পরে স্বাস্থ্য ফেরত দেয় — সাধারণত প্রতি QALY *ভালো* ব্যয়ে, মাঝেমধ্যে সাশ্রয়ে, কখনো ভয়ঙ্কর মূল্যে।

## গণিত

```
প্রতিরোধের নিট ব্যয় (প্রতি ব্যক্তি) =
    হস্তক্ষেপ ব্যয় × সবাই চিকিৎসিত
  − এড়ানো নিম্নধারা ব্যয় × যারা অগ্রসর হতো তাদের অল্প সংখ্যা

ব্যয়-সাশ্রয়ী হতে প্রয়োজন: হস্তক্ষেপ ব্যয় < P(অগ্রগতি) × এড়ানো ব্যয় × ছাড় ফ্যাক্টর
```

## সমাধানকৃত উদাহরণ

১০০,০০০ ঝুঁকিপূর্ণ প্রাপ্তবয়স্কদের একটি উচ্চ-রক্তচাপ-ব্যবস্থাপনা অ্যাপ, £২৫/ব্যক্তি/বছর। ১০ বছরে এটি ৪০০টি স্ট্রোক প্রতিরোধ করে।

```
ব্যয়:    100,000 × £25 × 10 বছর (ছাড়যুক্ত ≈ ×8.3) ≈ £20.8M
অফসেট: 400 × £45,000 = £18.0M
নিট ব্যয় ≈ £2.8M — সাশ্রয়ী নয়

QALY লাভ = 400 × 3 = 1,200
প্রতি QALY ব্যয় = 2.8M / 1,200 ≈ £2,300/QALY — অসাধারণভাবে ব্যয়-কার্যকর
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

শিফট-লেফট মান প্রতিরোধ অর্থনীতি, সতর্কতাসহ। পর্যালোচনা, টেস্ট, এবং স্ট্যাটিক বিশ্লেষণ *প্রতিটি* পরিবর্তনে ব্যয় প্রয়োগ করে অল্প যারা উৎপাদন ঘটনায় অগ্রসর হতো তাদের ধরতে।

## ঝুঁকিপূর্ণ দিক

- **প্রমাণ ব্যয়-কার্যকারিতা সমর্থন করলে ব্যয় সাশ্রয় দাবি করা**।
- **অ-ছাড়যুক্ত ভবিষ্যত অফসেট**: ১৫ বছর দূরের সুবিধা মুখমূল্যে।
- **অতিরিক্ত-নির্ণয়/অতিরিক্ত-চিকিৎসা ব্যয় উপেক্ষা করা**।
