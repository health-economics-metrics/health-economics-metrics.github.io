# Bygge kontra købe

Bygge kontra købe-analysen sammenligner samlet ejeromkostning og risiko for intern udvikling med anskaffelse af kommerciel software.

## Hvorfor det er vigtigt

Et forkert valg kan koste millioner af pund og år med omkostning ved forsinkelse.

## Matematikken

```
Forskel i nettonutidsværdi = NNV(købe) − NNV(bygge)
```

## Gennemarbejdet eksempel

Et patientbookingsystem: købe = £2 millioner/5 år; bygge = £3,2 millioner/5 år (inklusive vedligeholdelse).

## Forbindelse til softwareudvikling

Beregninger af [samlet ejeromkostning](../samlet-ejeromkostning/) er en nøglefaktor for denne beslutning.

## Faldgruber

- **At ignorere leverandørbindingsomkostninger.**
