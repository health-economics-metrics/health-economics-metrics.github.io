# ต้นทุนส่วนเพิ่มเทียบกับต้นทุนเฉลี่ย

ต้นทุนส่วนเพิ่มคือต้นทุนของการผลิตหน่วยเพิ่มเติมหนึ่งหน่วย ในขณะที่ต้นทุนเฉลี่ยคือต้นทุนรวมหารด้วยจำนวนหน่วยทั้งหมด — ทั้งสองมักแตกต่างกันอย่างมาก

## ทำไมจึงสำคัญ

โครงการธุรกิจจำนวนมากประเมินการประหยัดผิดพลาดโดยใช้ต้นทุนเฉลี่ยแทนต้นทุนส่วนเพิ่ม การปลดเตียงหนึ่งเตียงไม่ได้ประหยัดต้นทุนเฉลี่ยต่อเตียงเพราะต้นทุนคงที่ (อาคาร เจ้าหน้าที่หลัก) ยังคงอยู่

## คณิตศาสตร์

```
ต้นทุนเฉลี่ย = ต้นทุนรวม / จำนวนหน่วย
ต้นทุนส่วนเพิ่ม = การเปลี่ยนแปลงของต้นทุนรวม / การเปลี่ยนแปลงของจำนวนหน่วย
```

## ตัวอย่างที่คำนวณแล้ว

โรงพยาบาลมีต้นทุนเฉลี่ยต่อวันเตียง £400 แต่ต้นทุนส่วนเพิ่มที่แท้จริงของการปลดหนึ่งเตียง (อาหาร ยา เจ้าหน้าที่ล่วงเวลา) อยู่ที่เพียง £150 เท่านั้น — การอ้างว่าประหยัด £400 ต่อเตียงที่ปลดนั้นเกินจริงกว่าสองเท่า

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการประเมินมูลค่าของอินสแตนซ์เซิร์ฟเวอร์ที่ประหยัดได้โดยใช้ต้นทุนเฉลี่ยต่ออินสแตนซ์แทนที่จะเป็นต้นทุนส่วนเพิ่มที่แท้จริงของการสเกลลง ซึ่งรวมถึงต้นทุนคงที่เช่นใบอนุญาตและโครงสร้างพื้นฐาน

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ต้นทุนเฉลี่ยในกรณีทางธุรกิจแทนต้นทุนส่วนเพิ่ม**
- **การสันนิษฐานว่าต้นทุนคงที่จะหายไปเมื่อปริมาณลดลงเล็กน้อย**
