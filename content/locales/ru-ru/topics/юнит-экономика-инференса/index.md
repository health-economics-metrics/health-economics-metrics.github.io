# Юнит-экономика инференса (Inference Unit Economics)

Юнит-экономика инференса оценивает ИИ-функции по их предельным вычислениям: **стоимость за токен**, сворачиваемая в стоимость на транзакцию, на пользователя, на клинический эпизод. Определяющая динамика: цены LLM падали примерно **на порядок каждые 1–2 года** при постоянных возможностях — темп дефляции, не имеющий прецедента в учёте затрат медицинских технологий.

## Почему это важно

Из обвала цен следуют два последствия. Коммерчески ИИ-функция, сегодня маргинально прибыльная, может стать тривиально прибыльной через 18 месяцев — а конкурент, ценообразующий по сегодняшним затратам, будет подрезан по цене. Для экономической оценки любая модель затратной эффективности для клинического сервиса с ИИ, замораживающая цены инференса 2024 года, **существенно завышает текущую стоимость** — анализу нужны сценарии снижения цен так же, как лекарственные модели учитывают истечение патента и выход дженериков. (Референсные точки из исследований: передовые выходные токены ~$15–75/млн в середине 2026 года, модели среднего уровня на порядок дешевле, возможности уровня GPT-4 упали с ~$20/млн в 2022 году до ~$0,40/млн; Epoch AI измерил снижение в 9×–900× в год в зависимости от рубежа возможностей.)

## Математика

```
Стоимость_за_вызов   = входные_токены × ставка_за_вход + выходные_токены × ставка_за_выход
Стоимость_за_единицу = Σ вызовов на единицу бизнес-результата (на эпизод триажа,
                        на составленное письмо, на резюме консультации)

Смешанная реальность = базовый_вызов + повторы + RAG-контекст (тяжёлый по входу)
                        + вызовы оценки/защитных механизмов (часто 20–50% накладных расходов)

Сценарий снижения цены для многолетних моделей:
  стоимость_t = стоимость_0 × d^t, проверяйте d ∈ {0.3, 0.5, 0.7}/год в анализе чувствительности
```

## Практический пример

Служба сводок выписки на ИИ: средняя сводка использует 12 000 входных токенов (контекст записи) + 1 200 выходных, плюс проход верификации (6 000 вход / 300 выход). При $3/млн вход, $15/млн выход:

```
Черновик:  12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Проверка:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
На сводку ≈ $0.077 → на 100,000 сводок/год ≈ $7,700

При ~20 сэкономленных минутах врача на сводку (≈ £25) инференс составляет
0.25% созданной ценности — экономика определяется всем,
КРОМЕ токенов: интеграцией, оценкой, управлением, внедрением.
```

Этот вывод — стоимость инференса редко является связывающим ограничением при текущих ценах для высокоценных клинических задач — сам по себе находка, которую стоит уносить на встречи по ценообразованию.

## Связь с разработкой программного обеспечения

Это [юнит-экономика облака](../юнит-экономика-облачных-сервисов/), специализированная для ИИ, с тремя практическими замечаниями: **измеряйте на бизнес-единицу**, а не на вызов API, чтобы цифра напрямую подставлялась в модели [ICER](../инкрементальное-соотношение-затрат-и-эффективности/)/[бюджетного воздействия](../анализ-бюджетного-воздействия/); **следите за асимметрией вход/выход** (выход обычно стоит ~в 4 раза дороже входа; архитектуры RAG тяжелы по входу — выбор архитектуры — это выбор ценообразования); и **маршрутизируйте по уровню задачи** — сопоставление возможностей модели со сложностью задачи (дешёвые модели для классификации, передовые для синтеза) регулярно снижает смешанную стоимость в 5–10 раз при равном качестве — программная версия использования самого дешёвого эффективного вмешательства ([минимизация затрат](../анализ-минимизации-затрат/), с доказанной эквивалентностью).

## Подводные камни

- **Многолетние модели с замороженной ценой** — завышают стоимость; но также **модели выручки с предполагаемой дефляцией** — ценовая война — не контракт; учитывайте оба сценария.
- **Игнорирование накладных расходов на оценку**: защитные механизмы, судьи-модели и повторы — это реальные токены, часто составляющие большинство в регулируемых средах.
- **Близорукость на уровне токена**: задержка, лимиты частоты запросов и ограничения контекстного окна несут затраты, которые не отражает ни одна цена за токен.
