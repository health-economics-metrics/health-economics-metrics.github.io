# การประเมินปัญญาประดิษฐ์ทางคลินิก

การประเมินปัญญาประดิษฐ์ทางคลินิกเป็นกระบวนการเฉพาะทางในการประเมินระบบปัญญาประดิษฐ์เรื่องความปลอดภัยของผู้ป่วย ประสิทธิผลทางคลินิก และการปฏิบัติตามข้อกำหนด ก่อนการนำไปใช้ในระบบสุขภาพ

## ทำไมจึงสำคัญ

ข้อผิดพลาดของปัญญาประดิษฐ์ทางคลินิกสามารถก่อให้เกิดอันตรายโดยตรงต่อผู้ป่วย ซึ่งต้องการมาตรฐานการประเมินที่เข้มงวดกว่าการประยุกต์ใช้ปัญญาประดิษฐ์ทั่วไป

## คณิตศาสตร์

```
ความไว/ความจำเพาะทางคลินิก = คล้ายกับ [เศรษฐศาสตร์การคัดกรอง](../screening-economics/) แต่นำไปใช้กับผลลัพธ์การวินิจฉัยของปัญญาประดิษฐ์
```

## ตัวอย่างที่คำนวณแล้ว

เครื่องมือคัดแยกเอกซเรย์ด้วยปัญญาประดิษฐ์ต้องแสดงความไวอย่างน้อยเท่ากับนักรังสีวิทยา (โดยทั่วไป >90%) ก่อนที่จะสามารถใช้ในกระบวนการทำงานทางคลินิกโดยไม่มีการตรวจสอบจากมนุษย์

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

เชื่อมโยงอย่างใกล้ชิดกับ [กรอบมาตรฐานหลักฐานของ NICE](../nice-evidence-standards-framework/) และการวัด [ตัวชี้วัดคุณภาพปัญญาประดิษฐ์](../ai-quality-metrics/) ทั่วไป แต่มีเกณฑ์ความเสี่ยงที่สูงกว่า

## ข้อผิดพลาดที่พบบ่อย

- **การนำวิธีการประเมินปัญญาประดิษฐ์ทั่วไปมาใช้โดยไม่ปรับให้เข้ากับบริบททางคลินิก**
- **การทดสอบไม่เพียงพอในกลุ่มผู้ป่วยที่ไม่ได้รับการเป็นตัวแทนเพียงพอ ซึ่งนำไปสู่ผลลัพธ์ที่ลำเอียง**
