# 多准则决策分析 (Multi-Criteria Decision Analysis, MCDA)

多准则决策分析（MCDA）是卫生技术评估中使用的加权和评分模型，用于单一的 ICER/支付意愿阈值无法涵盖决策者所关心的一切时：公平性、未满足的需求、创新性、预算影响、疾病严重程度。每个准则被赋予一个反映其重要性的权重（来自利益相关者，总和为 1），每个备选方案在每个准则上获得一个归一化得分（通常为 0–1），总分就是加权和——与软件供应商评估计分卡同样的数学形式。

## 为什么重要

MCDA 被用于 EVIDEM 等框架，以及一些 HTA 机构对孤儿药/罕见病的评估，在那里严格的每 QALY 成本阈值方法被认为过于狭窄，无法涵盖决策中重要的一切。ISPOR MCDA Emerging Good Practices Task Force 把获取站得住脚的权重和得分的良好实践正式化，正因为非正式的加权决策既容易构造，也容易被操纵。当一项卫生技术具有单一的[支付意愿阈值](../支付意愿阈值/)无法表示的价值维度——严重程度、创新性、公平性——MCDA 为决策者提供了一个明确、可审计的结构来整合它们，而不是一个未说出口的判断。

## 计算方法

```
MCDA 得分 = Σ_i (权重_i × 得分_i)

权重之和应为 1（通过 swing weighting 或 Analytic Hierarchy Process
等利益相关者方法获得）
```

## 算例

一个 HTA 委员会按四个准则评估一种数字疗法：

```
准则                              权重    得分    权重 × 得分
临床获益                          0.4     0.8     0.32
成本影响                          0.3     0.5     0.15
疾病严重程度 / 未满足需求          0.2     0.9     0.18
创新性                            0.1     0.6     0.06
                                  ─────           ─────
                                  1.0             0.71
```

权重之和为 1.0（0.4 + 0.3 + 0.2 + 0.1），MCDA 得分为 0.71（0.32 + 0.15 + 0.18 + 0.06）。委员会把 0.71 与事先约定的阈值比较，或与以同样方式评分的竞争技术排序。

## 与软件工程的关联

这与加权的供应商选择计分卡、RFP 评估矩阵或功能优先级评分模型是同样的数学——关于加权计分卡在软件采购中的经典用例，见[自建与外购](../自建与外购/)。也值得与 [WSJF 与 CD3](../wsjf-与-cd3/)对照：WSJF/CD3 是基于*比值*的优先级方法（延迟成本除以工作量大小或时长），而 MCDA 是加权*和*。MCDA 与 WSJF/CD3 是对“如何给相互竞争的选项排序”这一问题在结构上不同的两种回答，而弄清某个决策实际需要哪一种——跨独立准则的总价值，还是每单位稀缺产能的价值密度——比哪个公式看起来更严谨更重要。

## 陷阱

- **权重获取偏差**：谁设定权重，实际上就预先决定了排名，因此“公式”可能把政治或商业决定洗成看似客观的计算。要记录谁设定了权重以及如何设定。
- **重复计算已在别处涵盖的准则**：把“成本效果”作为一个准则打分，*同时*又单独给“成本影响”打分，会使金钱相对其他准则被过度加权，却没人有意为之。
- **虚假精度**：保留两位小数的加权得分（0.71）所暗示的严谨程度，超过了利益相关者在 0–10 量表上的评价所能支撑的，而这些评价中评分者之间的变异往往完全没有报告。
