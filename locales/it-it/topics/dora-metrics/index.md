# Metriche DORA

Le metriche DORA sono quattro misure delle prestazioni di consegna del software — frequenza di distribuzione, lead time per le modifiche, tasso di fallimento delle modifiche, e tempo di ripristino.

## Perché è importante

Un decennio di ricerca DORA collega queste metriche alle prestazioni organizzative.

## La matematica

```
Lead time = t(deploy) − t(commit), mediana
```

## Esempio risolto

Il team software del flusso pazienti di un trust, prima/dopo: deploy mensile → settimanale.

## Collegamento con l'ingegneria del software

Questo *è* il lato software.
