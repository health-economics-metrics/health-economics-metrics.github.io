# Домінування та межа ефективності

Один варіант домінує над іншим, коли він дешевший і принаймні настільки ж ефективний. Межа ефективності показує недоміновані варіанти.

## Чому це важливо

Доміновані варіанти можна одразу виключити, що спрощує простір рішень перед детальними розрахунками економічної ефективності.

## Математика

```
Варіант A домінує над варіантом B, якщо: витрати(A) ≤ витрати(B) І ефект(A) ≥ ефект(B)
```

## Розібраний приклад

Чотири варіанти лікування на графіку витрати-ефект: варіант C коштує більше, ніж варіант B, але дає менше здоров'я, ніж суміш A і D — варіант C розширено домінований і виключається.

## Зв'язок з інженерією програмного забезпечення

Подібно до виключення архітектурних варіантів, які одночасно дорожчі та повільніші за альтернативу.

## Підводні камені

- **Пропуск розширеного домінування та перевірка лише простого домінування.**
- **Порівняння варіантів попарно замість повної межі.**
