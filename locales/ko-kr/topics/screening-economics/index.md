# 선별검사 경제학

선별검사 경제학은 무증상 인구를 검사하는 가치를 지배합니다. 핵심 수학적 사실: **낮은 질병 유병률에서는 우수한 검사조차 주로 위양성을 생성합니다**.

## 왜 중요한가

1968년부터, WHO의 Wilson–Jungner 기준은 인구 선별검사의 표준을 설정해왔습니다.

## 수식

```
PPV = (민감도 × 유병률) / [민감도 × 유병률 + (1 − 특이도) × (1 − 유병률)]
```

## 계산 예시

희귀 질환에 대한 AI 망막 선별검사, 100,000명, 유병률 0.5%: 실제 사례당 비용 ≈ £8,156.

## 소프트웨어 공학과의 연관성

정적 분석, 보안 스캐닝은 코드베이스에서의 선별검사 프로그램입니다. 단일 검사가 아니라 선별 프로그램 전체의 규모를 따지려면 [필요선별수](../number-needed-to-screen/)를 참고하세요. 결과 한 건을 예방하기 위해 선별과 치료의 전체 경로를 몇 명이 거쳐야 하는지를 보여 줍니다.
