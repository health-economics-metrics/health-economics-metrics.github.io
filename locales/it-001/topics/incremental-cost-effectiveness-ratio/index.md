# Rapporto Costo-Efficacia Incrementale (ICER)

L'ICER è il costo extra per unità extra di effetto sulla salute quando si sceglie un'opzione rispetto alla migliore alternativa successiva.

## Perché è importante

I sistemi sanitari non valutano mai una tecnologia in isolamento — sempre *in modo incrementale*. NICE confronta l'ICER di una tecnologia con la sua soglia di **£20.000–£30.000 per QALY**.

## La matematica

```
ICER = (Costo_nuovo − Costo_comparatore) / (Effetto_nuovo − Effetto_comparatore)
```

## Esempio risolto

Un servizio di monitoraggio remoto per pazienti con insufficienza cardiaca: ICER = £12.000/QALY.

## Collegamento con l'ingegneria del software

La disciplina dell'ICER si trasferisce completamente alle decisioni ingegneristiche.
