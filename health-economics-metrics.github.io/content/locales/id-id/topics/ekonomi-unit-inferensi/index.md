# Ekonomi Unit Inferensi

Ekonomi unit inferensi menetapkan harga fitur AI berdasarkan komputasi marginalnya: **biaya per token**.

## Mengapa ini penting

Dua konsekuensi mengikuti dari keruntuhan harga.

## Matematika

```
Biaya per panggilan = token input × tarif input + token output × tarif output
```

## Contoh yang diselesaikan

Layanan ringkasan pemulangan AI: ≈$0,077 per ringkasan → ≈$7.700 untuk 100.000 ringkasan/tahun.

## Hubungan dengan rekayasa perangkat lunak

Ini adalah [ekonomi unit cloud](../ekonomi-unit-cloud/) yang dikhususkan untuk AI.

## Jebakan

- **Model multi-tahun harga tetap.**
