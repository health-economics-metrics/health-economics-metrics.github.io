# 創造價值的產能（營運扭轉）

創造價值的產能，是被釋放時間所帶來的"機會效益"：藉助你的軟體釋放出的這些工時，醫院現在能夠*實現*什麼。這是營運總監與醫務總監最看重的指標，因為它使用的正是他們日常管理所依據的那套貨幣——活動量、目標達成，以及週轉效率。

## 為何重要

NHS正面臨巨大的轉診至治療積壓，而未能達成國家等候時間標準的信託機構，將面臨監管審查與介入介入（參見[轉診至治療](../轉診至治療/)）。招聘進度緩慢且受限；場地設施是固定的。唯一能快速見效的槓桿，就是從現有員工與場地中榨取出更多創造價值的活動量。能重新奪回專科人員時間的軟體，不只是"省錢"——它*憑空鑄造出產能*：那些原本根本無法開設的門診、原本根本無法排上的評估，在不招聘、不建設的情況下變得可能。

## 計算方法

```
被創造的隱性產能 = 被釋放的時間 → 轉化為可實現的活動單位數 × 標準價格

活動單位：門診就診、術前評估、監測複查
標準價格：全國統一收費標準/NHS支付方案價格
         （參見national-tariff-and-unit-costs.md）
```

這正是[從業者時間](../從業者時間/)按產出基礎估值的方法，被擴充套件到一整條服務線，並以營運團隊本已在使用的那套活動單位來表達。

## 實例演算

5級職級專科護士負責營運術前評估門診。文書自動化為25名護士中的每一位每天回收1小時；每小時可容納2次評估。

```
額外評估次數 = 25名護士 × 每天2次 × 250個工作日 = 每年12,500次
按每次術前評估約£120的標準價格計算：
  12,500 × £120 = 每年創造£150萬的照護產能
```

——且無需招聘一名護士，也無需新建一間診室。（本文最初所參照的那份被廣泛引用的模型，對一個規模更小的佇列給出的數位是每年£766,920；其算術模式完全相同——該數位隨護士人數 × 場次 × 標準價格等比例縮放。）對營運總監而言，這一營運框架的意義在於：術前評估不再是手術室排期的約束瓶頸——當日臨時取消的手術隨之減少，手術室利用率隨之上升，而這正是*下一條*效益線的起點（參見[下游資源最佳化](../下游資源最佳化/)）。

## 與軟體工程的聯絡

同樣的重新框定，也能把開發者生產力的主張從單純的薪資算術中解救出來：將被釋放的工程時間，表述為*組織原本無力承擔、如今卻能交付的能力*——功能、遷移工作、可靠性改進——按組織在邊際上為此類能力所需支付的價格來估值（承包商費率，或延後招聘的等效成本）。這套營運總監式的框定方式，同樣對如何推介平臺工作有所啟示：應以聽眾所依據管理的那套計量單位來表述效益。營運領導者以活動量與目標達成為思考單位，而非抽象的小時數；工程領導者以路線圖條目與人員編制為思考單位，而非節省的分鐘數。

## 陷阱

- **沒有需求支撐的產能主張**：額外的12,500個評估名額，只有在手術管線能夠真正填滿它們時才有意義——應核查下游約束是否存在。
- **有標準價格卻沒有對應的付費機制**：在混合支付模式下，額外的活動量未必能帶來額外收入；其價值也許應體現為等候名單的縮減（參見[等候名單影響](../等候名單影響/)）。
- **將產能呈現為現金**——這是最具代表性的非現金釋放型效益；務必如實標註（參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)）。
