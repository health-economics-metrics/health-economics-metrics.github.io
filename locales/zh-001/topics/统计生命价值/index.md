# 统计生命价值 (Value of a Statistical Life, VSL)

统计生命价值（VSL）——英国用法中称为“避免死亡的价值”（VPF）——是*人群*集体愿意为降低一例统计学死亡的风险而支付的金额，由工资—风险权衡研究（工人为更危险的工作要求多少额外工资）和陈述偏好调查推得。它不是某个可识别个人生命的价格；它是一种人群风险的构造，而构建降低风险系统——分诊算法、救护车调度、安全监控——的软件工程师应当知道，它来自与[支付意愿阈值](../支付意愿阈值/)不同的理论传统。

## 为什么重要

VSL/VPF 是监管性成本效益分析中把死亡风险降低货币化的标准工具：交通安全、环境监管和一些公共卫生干预都通过它构建商业论证。HM Treasury 的 Green Book 发布一个由英国劳动力市场和调查数据推得的 VPF 数字，交通部在评估道路安全时直接使用它。这是一种与 QALY × 支付意愿阈值方法论确实不同的估值传统：阈值方法按*卫生预算*目前在边际上产出的水平为健康收益估值，而 VSL/VPF 则按人们在劳动力市场或调查中表明愿意为降低风险所付的钱为风险降低估值。这两种框架并不总是相容，而在同一案例中同时使用二者却不加承认，是常见的分析错误。

## 计算方法

```
避免的死亡数 = 人口 × 人均风险降低
  （人均风险降低是一个概率，如 0.000001 =
   年死亡风险降低百万分之一）

货币化的死亡收益 = 避免的死亡数 × 避免死亡的价值
```

## 算例

一个 80 万人口的地区受益于一项道路安全数字调度/分诊干预，使每个人的年死亡风险降低百万分之一（0.000001）：

```
避免的死亡数 = 800,000 × 0.000001 = 0.8
```

采用英国避免死亡的价值 £2,180,000（HM Treasury/DfT 数字，2023/24 价格——Green Book 每年更新，在正在进行的分析中引用前请核对）：

```
货币化的死亡收益 = 0.8 × £2,180,000 = £1,744,000/年
```

每年略低于 £175 万的货币化死亡收益，来自大多数受影响人群个人永远不会察觉的风险降低。

## 与软件工程的关联

安全关键软件团队——医疗器械固件、自动驾驶车辆软件、工业控制系统——在为安全投资构建成本效益论证时，面对的正是这一定价问题：当故障罕见、严重且分散在庞大的用户群体中时，如何为“预防一次灾难性故障”定价？VSL/VPF 是为罕见而严重的人群层面风险降低赋予数字的、已有数十年历史且公开记录的真实先例——与为 SRE 投资针对罕见灾难性中断定价是同样的论证形式，只不过结果是死亡而不是停机。

## 陷阱

- **把 VSL 当作“某个可识别生命的价格”**：它不是。VSL/VPF 是由许多人之间的风险降低权衡推得的统计人群构造，不是对任何特定个人生死的估价。
- **与基于 QALY 的净货币效益计算重复计算**：在同一案例中同时使用 VSL/VPF 数字和单独的 QALY × 阈值计算而不加协调，会悄悄地把同样的避免死亡价值计算两次。每个案例选择一个框架。
- **不加调整地在不同情境间转移 VSL 估计**：由一国劳动力市场或劳动年龄人口工资—风险数据推得的 VSL，不加调整就应用于另一种收入情境或另一类人群（儿童、老年人），是一个真正有争议的、长期存在的方法学问题——尚未解决。
