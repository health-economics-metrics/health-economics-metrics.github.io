# Інкрементальне співвідношення витрат і ефективності (ICER)

ICER вимірює додаткові витрати на додаткову одиницю результату здоров'я одного втручання порівняно з альтернативою.

## Чому це важливо

ICER — центральне правило прийняття рішень у більшості систем HTA: нижче порогу = економічно ефективно, вище — ні.

## Математика

```
ICER = (Витрати_A − Витрати_B) / (Ефекти_A − Ефекти_B)
```

## Розібраний приклад

Нове лікування коштує на £5000 більше та дає на 0,25 QALY більше порівняно зі стандартним лікуванням: ICER = £5000 / 0,25 = £20 000/QALY — трохи нижче порогу NICE.

## Зв'язок з інженерією програмного забезпечення

Подібно до розрахунку додаткових витрат на інфраструктуру на додаткову одиницю надійності чи продуктивності при порівнянні архітектурних варіантів.

## Підводні камені

- **Розрахунок ICER проти неправильного компаратора.**
- **Неправильне тлумачення негативного ICER без вказівки квадранта.**
- **Порівняння ICER між валютами без явного кроку перерахунку**: ICER, обчислений у валюті однієї країни, треба перерахувати за зазначеним методом, перш ніж порівнювати з порогом іншої країни, — див. [порівняння ICER між валютами](../порівняння-icer-між-валютами/), чому сам вибір коефіцієнта перерахунку (паритет купівельної спроможності проти ринкового курсу) може перевернути рішення про впровадження.
