# Dominanssi ja tehokkuusraja

Yksi vaihtoehto dominoi toista, kun se on halvempi ja vähintään yhtä tehokas. Tehokkuusraja näyttää dominoimattomat vaihtoehdot.

## Miksi se on tärkeä

Dominoidut vaihtoehdot voidaan eliminoida välittömästi, mikä yksinkertaistaa päätöksentekotilaa ennen yksityiskohtaisia kustannusvaikuttavuuslaskelmia.

## Matematiikka

```
Vaihtoehto A dominoi vaihtoehtoa B, jos: kustannus(A) ≤ kustannus(B) JA vaikutus(A) ≥ vaikutus(B)
```

## Ratkaistu esimerkki

Neljä hoitovaihtoehtoa kustannus-vaikutusgraafissa: vaihtoehto C maksaa enemmän kuin vaihtoehto B mutta tuottaa vähemmän terveyttä kuin A:n ja D:n yhdistelmä — vaihtoehto C on laajennetusti dominoitu ja eliminoidaan.

## Yhteys ohjelmistokehitykseen

Muistuttaa sellaisten arkkitehtuurivaihtoehtojen eliminointia, jotka ovat sekä kalliimpia että hitaampia kuin vaihtoehto.

## Sudenkuopat

- **Laajennetun dominanssin ohittaminen ja vain yksinkertaisen dominanssin tarkistaminen.**
- **Vaihtoehtojen vertailu pareittain koko rajan sijaan.**
