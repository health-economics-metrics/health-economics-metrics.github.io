# 기술 부채

기술 부채는 코드베이스에서 편리했던 과거 결정의 암묵적인 미래 비용입니다: 미지불된 시정 작업(**원금**)과 전달에 계속 가하는 견인력(**이자**).

## 왜 중요한가

정량화되지 않으면, 기술 부채는 불평입니다; 정량화되면, 비즈니스 케이스입니다.

## 수식

```
SQALE 원금 = Σ 위반(시정 시간) × 개발자 비용률
```

## 계산 예시

40만 LOC 임상 기록 통합 계층: 이자 ≈ 연간 £276,000.

## 소프트웨어 공학과의 연관성

기술 부채 논쟁을 향상시키는 보건경제학 수입품들.
