# वृद्धिशील लागत-प्रभावशीलता अनुपात (ICER)

ICER एक विकल्प को अगले-सर्वोत्तम विकल्प के बजाय चुनने पर स्वास्थ्य प्रभाव की अतिरिक्त इकाई प्रति अतिरिक्त लागत है। यह स्वास्थ्य प्रौद्योगिकी मूल्यांकन की मुख्य संख्या है।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य प्रणालियाँ कभी भी किसी तकनीक का अलगाव में मूल्यांकन नहीं करतीं — हमेशा *वृद्धिशील रूप से*। NICE किसी तकनीक के ICER की तुलना अपनी **£20,000–£30,000 प्रति QALY** सीमा से करता है।

## गणित

```
ICER = (लागत_नया − लागत_तुलनाकर्ता) / (प्रभाव_नया − प्रभाव_तुलनाकर्ता)
     = ΔC / ΔE
```

## हल किया गया उदाहरण

हृदय-विफलता रोगियों के लिए एक दूरस्थ-निगरानी सेवा:

```
लागत:  सेवा £900,000; बचाए गए प्रवेश £600,000 बचाते हैं
       ΔC = £300,000
प्रभाव: पहले हस्तक्षेप से 25 QALY प्राप्त होते हैं
       ΔE = 25

ICER = 300,000 / 25 = £12,000/QALY
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

ICER का अनुशासन इंजीनियरिंग निर्णयों में पूरी तरह से स्थानांतरित होता है: हमेशा अगले-सर्वोत्तम विकल्प के विरुद्ध तुलना करें, "कुछ न करने" के विरुद्ध नहीं।

## सामान्य गलतियाँ

- **तुलनाकर्ता हेरफेर**: एक पुरानी या कृत्रिम रूप से खराब आधाररेखा से तुलना करना।
- **वृद्धिशील के बजाय औसत।**
- **नकारात्मक ICER अस्पष्ट हैं।**
- **स्पष्ट रूपांतरण चरण के बिना मुद्राओं के पार ICER की तुलना**: एक देश की मुद्रा में गणना किए गए ICER को दूसरे देश की सीमा से तुलना करने से पहले घोषित विधि से रूपांतरित करना होगा — रूपांतरण गुणक का चुनाव (क्रय शक्ति समता बनाम बाज़ार विनिमय दर) अपनाने का निर्णय क्यों स्वयं पलट सकता है, इसके लिए [मुद्राओं के पार ICER तुलना](../मुद्राओं-के-पार-icer-तुलना/) देखें।
