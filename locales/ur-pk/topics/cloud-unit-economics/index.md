# کلاؤڈ یونٹ اکنامکس (FinOps)

کلاؤڈ یونٹ اکنامکس خام کلاؤڈ خرچ کو **آؤٹ پٹ اکائی کی فی قیمت** میں تبدیل کرتا ہے۔

## یہ کیوں اہم ہے

کل خرچ کے اعداد اہم سوالات کا جواب نہیں دے سکتے: کیا پروڈکٹ زیادہ موثر ہو رہا ہے؟

## ریاضی

```
اکائی قیمت = کل مختص قیمت / فراہم کردہ اکائیاں
```

## حل شدہ مثال

ایک ڈیجیٹل ٹرائیج سروس: کلاؤڈ خرچ £62,000/ماہ، ماہ میں 380,000 ٹرائیج ایپیسوڈز سنبھالتی ہے: اوسط قیمت ≈ £0.163۔

## سافٹ ویئر انجینئرنگ سے تعلق

یونٹ اکنامکس وہ جگہ ہے جہاں انجینئرنگ کے انتخاب مالی طور پر پڑھنے کے قابل ہو جاتے ہیں۔

## عام غلطیاں

- **مشترکہ اخراجات کو نظر انداز کرنا۔**
