# 人力资本法与摩擦成本法 (Human Capital vs Friction Cost)

这是在疾病成本研究和成本效益研究中，为因疾病、残疾或死亡而损失的生产率估值的两种相互竞争的方法。人力资本法（HCA）按工资率对整个缺勤期间损失的全部产出估值；摩擦成本法（FCM）只对雇主恢复生产实际所需的较短时期估值。两者之间的选择会使间接成本估计相差两倍或更多。

## 为什么重要

间接（生产率）成本是卫生经济学中争议最大的项目之一，恰恰因为两种标准方法分歧如此之大。HCA 把每个缺勤日都当作经济确实损失的产出日，按全额工资对整个期间估值——在死亡或永久残疾的情形下则按剩余的工作年限估值。FCM 则主张，在存在失业和劳动力市场冗余的经济体中，大多数长期缺勤实际上并不会降低国民产出，因为雇主会培训替代者或重新分配工作；只有“摩擦期”——把产出恢复到先前水平所需的时间——才是真实的损失。因此 FCM 给出的间接成本估计系统性地低于、也更保守于 HCA，两者不是可以互换的脚注：它们是关于“损失的生产率”是什么意思的不同经济学理论。这也是为什么 [NICE 的基础案例](../卫生技术评估/)默认排除生产率成本，如有报告，则作为单独的社会视角敏感性分析，而不是混入基础案例 ICER——见[分析视角](../分析视角/)。

## 计算方法

```
人力资本法：
HCA_成本 = 日工资 × 损失天数

摩擦成本法（简化，以摩擦期为上限）：
FCM_成本 = 日工资 × min(损失天数, 摩擦期天数)

摩擦期天数 = 按国家/行业对恢复生产所需时间的估计
             （历史上荷兰 iMTA 成本指南中约 85 天；因国而异，并定期重新评估）
```

两种方法之间的全部分歧都在 `min()` 里：HCA 从不对 `损失天数` 设上限，所以成本随整个缺勤期增长；FCM 把计入的天数限制在摩擦期，无论实际缺勤多长。

## 算例

一名员工缺勤 `损失天数 = 180` 天，`日工资 = £150`。

**人力资本法**：

```
HCA_成本 = 150 × 180 = £27,000
```

**摩擦成本法**，`摩擦期天数 = 85`（荷兰 iMTA 的历史基准，依据指南的定期重新评估）：

```
FCM_成本 = 150 × min(180, 85) = 150 × 85 = £12,750
```

对*同一次*缺勤，FCM 的 £12,750 不到 HCA 的 £27,000 的一半——仅仅方法的选择就大幅改变了疾病成本的论证，还没碰任何其他假设。

## 与软件工程的关联

这与团队估计工程师离职成本的方式直接对应：

- **HCA 式的流失成本核算**：把损失估为离职工程师在职位空缺的整个期间的全额薪资。这是大多数流失成本模型的朴素版本，其高估的原因与 HCA 高估损失生产率相同——假定空出的产能原本完全高效，且没有其他东西填补空缺。见[员工留任](../员工留任/)，其中量化了此方法所依赖的招聘/入职/填补空缺的链条。
- **FCM 式的流失成本核算**：只按寻找并引入替代者所需的实际时间估计损失——工程中的“摩擦期”。对商业论证而言这是更站得住脚的数字，正如在疾病成本研究里 FCM 是更保守的选择。
- 其背后的纪律与[机会成本](../机会成本/)相同：按实际损失的东西给被挤出的资源估值，而不是按标题时长与费率的乘积。

## 陷阱

- **在同一分析中混用 HCA 与 FCM，或只报告其中一个而不披露选择。** 同样的缺勤数据，按方法不同，报告出的成本可相差 2 倍或更多；选择必须点明，不能隐藏。
- **在社会视角案例中使用 HCA 却不标注为敏感性分析。** NICE 基础案例明确排除生产率成本；社会视角的 HCA 估计属于情景分析，而不是标题 ICER。
- **不加调整地把任一方法用于无报酬或非市场工作（如照护）。** 两者都用工资率代表价值，而这无法干净地迁移到没有市场工资的工作上。
