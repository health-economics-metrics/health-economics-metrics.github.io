# এড়ানো নিম্নমুখী খরচ

এড়ানো নিম্নমুখী খরচ (খরচ অফসেট) হল ভবিষ্যতের চিকিৎসা ব্যয় যা আগের বা উন্নত কর্ম দ্বারা প্রতিরোধ করা হয়, হস্তক্ষেপের নিজস্ব খরচের বিপরীতে নেট করা। অফসেট হল সেই প্রক্রিয়া যার মাধ্যমে একটি হস্তক্ষেপ *প্রভাবশালী* হতে পারে — সস্তা **এবং** ভালো — এবং এগুলি স্বাস্থ্য অর্থনীতিতে সবচেয়ে দ্বৈত-গণনা করা, অতি-দাবিকৃত রেখাও।

## কেন এটি গুরুত্বপূর্ণ

প্রায় প্রতিটি ডিজিটাল স্বাস্থ্য মূল্য প্রস্তাবে একটি অফসেট দাবি থাকে: "আমাদের অ্যাপ ভর্তি প্রতিরোধ করে," "আমাদের সতর্কতা অবনতি প্রতিরোধ করে," "আমাদের প্ল্যাটফর্ম ডুপ্লিকেট পরীক্ষা এড়ায়।" যখন অফসেট বাস্তব হয়, তারা অর্থনীতি রূপান্তরিত করে (দেখুন [ICER](../ইনক্রিমেন্টাল-খরচ-কার্যকারিতা-অনুপাত/) বিস্তারিত উদাহরণ, যেখানে একটি £600হাজার অফসেট কেসটি তৈরি করে)। প্রদানকারীরা এটি জানে — তাই অফসেট দাবি যেকোনো মূল্যায়নে সবচেয়ে কঠিন পরীক্ষা আকর্ষণ করে। নিচের বিশ্বাসযোগ্যতা নিয়মগুলি হল যা একটি অর্থায়নযোগ্য মডেলকে বিপণন থেকে আলাদা করে।

## গণনা

```
নিট খরচ = হস্তক্ষেপ খরচ − Σ অফসেট

একটি বৈধ অফসেট অবশ্যই হতে হবে:
  দায়ী        — হস্তক্ষেপের সাথে কার্যকারণগতভাবে সংযুক্ত (তুলনাকারী প্রমাণ)
  প্রান্তিক     — টাকা প্রকৃতপক্ষে খরচ হওয়া বন্ধ হয়, গড় নয় প্রান্তিক খরচে
                 (দেখুন marginal-vs-average-cost.md)
  সম্ভাবনা-     — P(নিম্নমুখী ঘটনা ঘটত) দ্বারা ওজনযুক্ত
  ওজনযুক্ত
  ছাড়যুক্ত     — বর্তমান মূল্যে ভবিষ্যতের এড়ানো খরচ
  অনন্য        — একবার গণনা করা, একটি সুবিধা রেখায়
```

## বিস্তারিত উদাহরণ

"এই স্থানান্তর-ঝুঁকি দাবি, সঠিকভাবে করা": 5,000 পোস্ট-সার্জিক্যাল রোগীর জন্য একটি ক্ষত-পর্যবেক্ষণ অ্যাপ সংক্রমণ-সম্পর্কিত পুনঃভর্তি এড়ানোর দাবি করে।

```
সংক্রমণের জন্য বেসলাইন পুনঃভর্তি: 4.0%; অ্যাপ সহ (RCT): 3.1%
দায়ী এড়ানো ঘটনা = 5,000 × 0.009 = 45/বছর
প্রতি পুনঃভর্তি পর্বের খরচ (প্রান্তিক, এই ট্রাস্ট): £3,200
অফসেট = 45 × 3,200 = £144,000/বছর
অ্যাপ খরচ = 5,000 × £20 = £100,000/বছর
নিট খরচ = −£44,000 → প্রকৃতপক্ষে খরচ-সাশ্রয়ী, সাথে:
  RCT থেকে দায়িত্ব ✓  প্রান্তিক খরচ নির্ধারণ ✓  ট্রায়াল তথ্য থেকে সম্ভাবনা ✓
```

"পুনঃভর্তি গড়ে £5,800 খরচ করে, আমরা প্রচুর প্রতিরোধ করব" এর উপর নির্মিত একই দাবি চারটি পরীক্ষায় ব্যর্থ হয় এবং যে প্রত্যাখ্যান পায় তার প্রাপ্য।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

"এই স্থানান্তর ভবিষ্যতের পুনর্লিখন এড়ায়" একটি অফসেট দাবি, এবং স্বাস্থ্য-অর্থনীতির নিয়মগুলি এটিকে সৎ করে তোলে:

- **কাউন্টারফ্যাকচুয়াল খরচ**: পুনর্লিখনের প্রকৃত খরচ কত হবে, কীভাবে প্রমাণিত?
- **সম্ভাবনা**: সেই ভবিষ্যৎ কতটা সম্ভাব্য? (100% নয় — পণ্য বাতিল হয়, অগ্রাধিকার পরিবর্তিত হয়।)
- **ছাড়করণ**: 3.5-10% ছাড়ে 4র্থ বছরে এড়ানো একটি পুনর্লিখন নামমাত্র মূল্যের চেয়ে অনেক কম মূল্যবান।
- **অনন্যতা**: প্রযুক্তি-ঋণ রেখা এবং ধারণ রেখায় একই এড়ানো পুনর্লিখনের দাবি করবেন না।

`অফসেট মূল্য = P(ভবিষ্যৎ ঘটনা) × কাউন্টারফ্যাকচুয়াল খরচ × ছাড় গুণক` — প্রস্তাবে সেই রেখাটি লিখুন এবং অনুমানটি বিতর্কযোগ্য হয়ে উঠতে দেখুন, যা আসল বিষয়।

## ঝুঁকি

- **দ্বৈত গণনা** — একই এড়ানো ভর্তি অফসেট, বেড দিন এবং খরচ-সংযুক্ত-QALY হিসেবে দাবি করা।
- **গড়-খরচ অফসেট** সেই ঘটনার জন্য যাদের নির্দিষ্ট খরচ যাই হোক চলতে থাকে।
- **নীরব 100% সম্ভাবনা** নিম্নমুখী ঘটনায় যা কেবল সম্ভব ছিল।
- **অন্য বাজেটে অফসেট** সঞ্চয় হিসেবে উপস্থাপিত যা অর্থ প্রদান করতে বলা প্রদানকারীর কাছে — দেখুন [বিশ্লেষণ দৃষ্টিকোণ](../বিশ্লেষণ-দৃষ্টিকোণ/)।
