# 도달범위와 형평성

도달범위와 형평성은 디지털 건강 개입이 대상 인구 전체에 걸쳐, 특히 취약 계층과 소외된 집단에 얼마나 공평하게 도달하는지 측정합니다.

## 왜 중요한가

디지털 개입은 이미 더 나은 접근성을 가진 집단에 편중되어 디지털 건강 격차를 심화시킬 위험이 있습니다.

## 수식

```
형평성 격차 = 도달률(고소득 집단) − 도달률(저소득 집단)
```

## 계산 예시

당뇨병 앱: 고소득층 도달률 45%, 저소득층 도달률 22% = 형평성 격차 23%p.

## 소프트웨어 공학과의 연관성

[활성화와 채택](../activation-and-uptake/)을 인구집단별로 세분화하여 격차를 드러냅니다.

## 함정

- **전체 평균 도달률만 보고 하위 집단 격차를 은폐하기.**
