# SPACE та DevEx

SPACE та DevEx — це рамки для **багатовимірного** вимірювання продуктивності розробників.

## Чому це важливо

Обидві рамки містять той самий урок, який дослідження результатів здоров'я засвоїло десятиліття тому.

## Математика

```
Правило SPACE: ≥ 3 виміри, ≥ 1 перцептивна + ≥ 1 системна метрика
```

## Розібраний приклад

Команда платформи обґрунтовує інвестицію DevEx для 300 розробників.

## Зв'язок з інженерією програмного забезпечення

Цей документ — *саме* сторона програмного забезпечення; передача тече в бік економіки охорони здоров'я.
