# 増分費用効果比(ICER)

ICERとは、ある選択肢を次善の代替案の代わりに選んだときの、健康効果の追加単位あたりの追加費用のことです。これは医療技術評価の代表的な数値です。(効果の単位がQALYの場合、これは増分費用効用比、ICURとも呼ばれます。)

## なぜ重要か

医療システムは決して技術を単独で評価しません — 常に*増分的に*、他に行われたであろうことと比較して評価します。NICEは技術のICERを**1QALYあたり£20,000〜£30,000**の閾値と比較します;米国のICER研究所は50,000〜200,000ドル/QALYの範囲で報告します;カナダはおおよそCAD$50,000/QALYを基準に運用しています。あなたの製品が国の医療サービスにとって「価値がある」かどうかは、形式的には、そのICERが地域の閾値をクリアするかどうかです。[支払意思額の閾値](../支払意思額の閾値/)を参照してください。

## 数式

```
ICER = (費用_新 − 費用_比較対象) / (効果_新 − 効果_比較対象)
     = ΔC / ΔE
```

解釈のルール:

- ΔC < 0、ΔE > 0:新しい選択肢が**優越する** — より安くより良い;比率は不要。
- ΔC > 0、ΔE > 0:ICERを計算し、閾値λと比較する;ICER < λなら採用する。
- ΔC > 0、ΔE < 0:新しい選択肢は劣位 — 却下する。
- ΔE = 0付近では比率の振る舞いが悪くなる — 順位付けには[正味金銭的便益](../正味金銭的便益/)を優先してください。

比較対象は*次善の非劣位の選択肢*でなければならず、「何もしない」ではありません — [優越関係と効率フロンティア](../優越関係と効率フロンティア/)を参照してください。

## 計算例

心不全患者向けの遠隔モニタリングサービス、患者1,000人あたり年間、通常のケアとの比較:

```
費用:  サービス£900,000;回避された入院で£600,000を節約
       ΔC = 900,000 − 600,000 = £300,000
効果:  早期介入により25QALYを獲得
       ΔE = 25

ICER = 300,000 / 25 = £12,000/QALY
```

£12,000/QALYは、NICEの£20,000の閾値を余裕を持って下回っており、強力なケースです。*正味*の費用がいかに重要かに注目してください:£600,000の相殺がなければ、ICERは£36,000/QALYとなり、このケースはおそらく失敗していたでしょう。費用の相殺とその証拠の質こそが、これらの分析の勝敗を分ける場所です([下流の回避費用](../回避された下流の費用/)を参照)。

## ソフトウェア工学との関連

ICERの規律は、エンジニアリングの意思決定にそっくりそのまま転用できます:

```
(選択肢Bの費用 − 選択肢Aの費用) / (成果B − 成果A)
```

— 追加のデプロイ1回あたり、節約されたエンジニア時間1時間あたり、回避されたインシデント1件あたりの増分費用 — 常に何もしないことではなく、次善の代替案と比較します。盗む価値のある2つの習慣:(1)*比較対象を明示的に名指しすること*;ほとんどのツールROIの主張は、密かに藁人形と比較しています。(2)*まず費用を相殺すること* — £100kかかるが既存の支出£80kを置き換えるツールは、ΔC = £20kです。

## 落とし穴

- **比較対象を都合よく選ぶこと**:時代遅れの、あるいは人為的に悪いベースラインと比較すると、ΔEが膨らみICERが実際以上に良く見えます。
- **増分の代わりに平均を使うこと**:プログラム全体のQALYあたり費用は、それを拡大あるいは採用することのICERではありません。
- **点推定値への過信**:ICERは2つの不確実な差の比率です;不確実性は[PSAとCEAC](../確率的感度分析/)を通じて報告してください。
- **負のICERは曖昧です**(安くて良い場合とコストが高くて悪い場合が同じ符号になる) — どの象限にあるかを述べずに負のICERを報告してはいけません。
- **明示的な換算ステップなしに通貨をまたいでICERを比較すること**: ある国の通貨で計算されたICERは、別の国の閾値と比較する前に、明示した方法で換算する必要があります。換算係数の選択(購買力平価と市場為替レート)自体が導入判断を覆しうる理由については、[通貨をまたぐICER比較](../通貨をまたぐicer比較/)を参照してください。
