# การวิเคราะห์ผลลัพธ์ต้นทุน (CCA)

การวิเคราะห์ผลลัพธ์ต้นทุนนำเสนอต้นทุนและผลลัพธ์หลายรายการแยกกันในตารางที่แยกส่วน แทนที่จะรวมเข้าเป็นอัตราส่วนเดียว ทำให้ผู้ตัดสินใจเห็นภาพรวมทั้งหมด

## ทำไมจึงสำคัญ

CCA มีประโยชน์เมื่อผลลัพธ์หลายรายการมีความสำคัญและไม่ควรถูกบีบอัดให้เป็นตัวเลขเดียว ซึ่งเป็นเหตุผลที่ NICE นิยมใช้วิธีนี้สำหรับการประเมินเทคโนโลยีสุขภาพดิจิทัล

## คณิตศาสตร์

ไม่มีสูตรรวม; CCA แสดงรายการต้นทุนและผลลัพธ์แต่ละรายการ (ต้นทุน ผลลัพธ์ทางคลินิก คุณภาพชีวิต ผลกระทบต่อผู้ดูแล) ในตารางแยกให้ผู้ตัดสินใจประเมินน้ำหนักเอง

## ตัวอย่างที่คำนวณแล้ว

แอปสุขภาพจิตแสดงตารางที่มีต้นทุน £200/ปีต่อผู้ใช้ ควบคู่กับคะแนนความวิตกกังวลที่ลดลง 15% อัตราการคงอยู่ของผู้ใช้ 60% และคะแนนความพึงพอใจ 4.2/5 โดยไม่รวมเป็นตัวเลขเดียว

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับแดชบอร์ดตัวชี้วัดหลายมิติที่แสดงประสิทธิภาพ ความน่าเชื่อถือ ต้นทุน และความพึงพอใจของผู้ใช้แยกกัน แทนที่จะรวมเป็นคะแนนสุขภาพระบบตัวเดียวที่อาจซ่อนรายละเอียดสำคัญ

## ข้อผิดพลาดที่พบบ่อย

- **การนำเสนอผลลัพธ์มากเกินไปจนผู้ตัดสินใจไม่สามารถประเมินน้ำหนักได้อย่างมีความหมาย**
- **การขาดกรอบที่ชัดเจนสำหรับวิธีที่ผู้ตัดสินใจควรรวมผลลัพธ์ที่แตกต่างกัน**
