# 实物期权估值 (Real Options Valuation)

实物期权估值把金融期权定价的逻辑应用于真实的（不在金融市场交易的）投资决策——具体而言是*扩张期权*：若项目成功，日后扩大该项目的权利，而无需承担必须这样做的义务。简化的单期二叉树模型（Cox、Ross、Rubinstein，1979）可以直接为这种灵活性估值，把“先小规模交付，再看情况”从直觉变成可定价的数字。

## 为什么重要

静态现值计算把项目当作“全有或全无”的赌注来定价：按今天的规模资助或不资助，永远如此。真实项目——尤其是分阶段推广的数字健康项目——很少这样安排：卫生系统可以资助一个小试点，看看结果，只有在它有效时才追加投入。这种灵活性有真实的价值，忽视它会系统性地低估分阶段投资相对于一次性投资的价值，这恰恰与奖励看起来更安全的分阶段提案的采购流程相反。实物期权估值为灵活性本身定价，使分阶段的提案可以与全额承诺的备选方案公平比较，而不是因为在朴素的现值一行上显得更小而受罚。

## 计算方法

```
“上涨”状态的风险中性概率：
  p = ((1 + 无风险利率) − 下跌因子) / (上涨因子 − 下跌因子)

每个状态下的扩张收益（下限为零——扩张是可选的）：
  收益_上涨 = max(项目价值 × 上涨因子 − 扩张成本, 0)
  收益_下跌 = max(项目价值 × 下跌因子 − 扩张成本, 0)

期权价值（折现后的期望收益）：
  期权价值 = (p × 收益_上涨 + (1 − p) × 收益_下跌) / (1 + 无风险利率)

扩展 NPV = 静态_npv + 期权价值
```

项目价值到下一个决策点要么上涨（`上涨因子`），要么下跌（`下跌因子`）。只有在该状态下有利可图时才行使扩张——收益的零下限正是使它成为真正的*期权*而非义务的原因。关于如何为先收集信息的期权（而不是日后扩张的期权）定价，见[完全信息期望价值](../完全信息期望价值/)。关于等待这一决策的成本，见[延迟成本](../延迟成本/)。

## 算例

一个数字服务试点，`项目价值 = £1,000,000`，到下一个决策点可能上涨至 1.5 倍或下跌至 0.5 倍，无风险利率 8%，扩张成本 £600,000：

```
p = (1.08 − 0.5) / (1.5 − 0.5) = 0.58

收益_上涨 = max(1,000,000 × 1.5 − 600,000, 0) =  900,000
收益_下跌 = max(1,000,000 × 0.5 − 600,000, 0) = max(−100,000, 0) = 0

下限起作用：若市场令人失望，该期权将不会被行使——
扩张成本 £600,000 超过项目在“下跌”状态下价值的 £500,000。

期权价值 = (0.58 × 900,000 + 0.42 × 0) / 1.08
         = 522,000 / 1.08
         ≈ £483,333.33
```

把期权价值加到静态 NPV 基数 £200,000 上：扩展 NPV = 200,000 + 483,333.33 ≈ **£683,333.33**。只报告静态 NPV £200,000 而没有这一期权的价值，会把分阶段项目的真实价值低估一倍以上。

## 与软件工程的关联

这是“现在先交付最小版本，保留在它见效时追加投资的选择权”的形式化版本——与数字健康产品的分阶段推广直接相关，在结构上与[延迟成本](../延迟成本/)和 [WSJF 与 CD3](../wsjf-与-cd3/)中不确定性下的排序框架平行，并与[完全信息期望价值](../完全信息期望价值/)和[样本信息期望价值](../样本信息期望价值/)互补——三者从不同角度为不确定性下的灵活性或信息定价。

## 陷阱

- **借用风险中性定价却不具备其依赖的可交易资产假设**：实物期权模型借用金融期权定价中的风险中性概率，而它假定标的价值是*可交易*资产——对真正不可交易的实际项目，这是建模的便利，而不是字面意义上的市场事实。
- **把 `上涨因子`/`下跌因子` 当作自由参数**：二叉树的上涨/下跌输入本身就是需要论证的假设，不是为了得到想要的答案而挑选的自由参数。
- **只报告期权价值**：实物期权的价值是*加到*独立项目的静态 NPV 上的——常见错误是只报告期权价值而省略基准情形，这在静态 NPV 为负时夸大了论证，而在完全省略静态 NPV 时（如上面的算例）又低估了它。
