# Оцінка медичних технологій (HTA)

Оцінка медичних технологій — це формальний процес, за допомогою якого органи, такі як NICE, ICER (США) та CADTH, оцінюють, чи варто фінансувати нову технологію.

## Чому це важливо

Органи HTA фактично визначають доступ на ринок для нових медичних технологій у більшості розвинутих систем охорони здоров'я.

## Математика

```
Рекомендація HTA = f(ICER проти порогу, вплив на бюджет, якість доказів, міркування рівності)
```

## Розібраний приклад

NICE оцінює новий діагностичний інструмент: ICER £18 000/QALY (нижче порогу), помірний вплив на бюджет та надійні клінічні докази призводять до позитивної рекомендації для рутинного використання.

## Зв'язок з інженерією програмного забезпечення

Подібно до формального процесу затвердження архітектури, який оцінює витрати, ризик та докази ефективності перед схваленням нової технології в масштабах організації.

Про те, як багатоциклову модель HTA насправді моделюють, когорта за когортою, цикл за циклом, див. [когортне моделювання за Марковим](../когортне-моделювання-за-марковим/).

## Підводні камені

- **Припущення, що позитивне клінічне випробування автоматично призводить до схвалення HTA.**
- **Розгляд впливу на бюджет та економічної ефективності як одного критерію.**
