# Аналіз чутливості

Аналіз чутливості перевіряє, наскільки чутливий висновок економічної оцінки до змін у базових припущеннях.

## Чому це важливо

Кожен бізнес-кейс ґрунтується на невизначених припущеннях; аналіз чутливості показує, які припущення дійсно мають значення.

## Математика

```
Чутливість змінної X = ΔРезультат / ΔX
```

Торнадо-діаграми ранжують змінні за впливом, від найбільшого до найменшого.

## Розібраний приклад

Бізнес-кейс для програми тріажу варіює припущення про рівень прийняття між 20% та 60%: діапазон ROI коливається від негативного до сильно позитивного.

## Зв'язок з інженерією програмного забезпечення

Подібно до тестування припущень щодо продуктивності в різних сценаріях навантаження.

## Підводні камені

- **Тестування лише однієї змінної за раз, коли припущення корельовані.**
- **Вибір нереалістичних діапазонів, що спотворюють чутливість.**
