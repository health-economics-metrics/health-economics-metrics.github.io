# Etäpotilasseurannan talous

Etäpotilasseurannan talous mittaa kotiseurantateknologian tuottamia kustannussäästöjä vähentämällä sisäänottoja, uudelleensisäänottoja ja fyysisiä käyntejä.

## Miksi se on tärkeä

Etäseuranta vaatii alkuperäisiä laitekustannuksia, mutta voi estää kallista päivystyshoidon käyttöä.

## Matematiikka

```
Nettosäästö = (vältettyjen sisäänottojen määrä × kustannus per sisäänotto) − ohjelman kustannus
```

## Ratkaistu esimerkki

Sydämen vajaatoiminnan etäseuranta: 40 vältettyä sisäänottoa × £4 000 = £160 000 säästö − ohjelman kustannus £60 000 = nettosäästö £100 000.
