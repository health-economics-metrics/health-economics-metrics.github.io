# Ottimizzazione delle Risorse a Valle

Risparmiare un'ora per un clinico senior spesso previene ritardi del collo di bottiglia per un intero team multidisciplinare (MDT).

## Perché è importante

L'assistenza sanitaria funziona su catene di autorizzazione.

## La matematica

```
Valore dello sblocco = Σ ruoli a valle (ore bloccate liberate × costo unitario)
```

## Esempio risolto

Le dimissioni di un reparto richiedono una revisione del consulente ogni mattina: 1.460 giorni di degenza risparmiati all'anno.

## Collegamento con l'ingegneria del software

Questa è la revisione del codice, l'approvazione dell'architettura.

- **Ottimizzare un non-collo di bottiglia.**
