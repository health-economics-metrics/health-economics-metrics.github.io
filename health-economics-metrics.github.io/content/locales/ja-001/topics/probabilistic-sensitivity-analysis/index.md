# 確率的感度分析(PSA)

PSAは、不確実なすべてのパラメータに確率分布を割り当て、それらすべてを同時に何千回もサンプリングし(モンテカルロ法)、単一の点推定値の代わりに、ある選択肢が最良である*確率*を報告します。

## なぜ重要か

NICEの基準ケースはPSAを*要求*します。決定論的分析は「1つの入力が間違っていたらどうなるか?」に答えます。PSAは「私たちが同時に知らないすべてのことを踏まえると、正しい選択をしている可能性はどれくらいか?」に答えます。その代表的な出力である**費用効果受容曲線(CEAC)**は、ある選択肢が費用効果的である確率を支払意思額の閾値に対してプロットします — これは「ICERは£24,000/QALYです」を「£30,000/QALYではこれが正しい選択である確率は78%です」に変えます。

## 数式

```
N回の抽出それぞれについて(N ≈ 10,000):
  すべてのパラメータθをその分布からサンプリング
    (費用〜ガンマ分布、確率〜ベータ分布、効用〜ベータ分布、効果〜正規/対数正規分布)
  各選択肢jについて NMB_j(θ) = λ × 効果_j(θ) − 費用_j(θ) を計算

CEAC_j(λ) = 閾値λにおいて選択肢jが最も高いNMBを持つ抽出の割合
```

NMBについては[正味金銭的便益](../net-monetary-benefit/)を、λについては[支払意思額の閾値](../willingness-to-pay-thresholds/)を参照してください。

## 計算例

プラットフォーム移行のビジネスケース。3つの不確実な入力:

```
移行費用     〜ガンマ分布、平均£800k、標準偏差£200k
年間便益     〜正規分布、平均£350k、標準偏差£150k
便益の継続期間 〜一様分布、3〜6年
```

10,000回の抽出それぞれについて、正味便益 = 継続期間 × 年間便益 − 費用 を計算します(わかりやすさのため割引は省略)。例示的な結果:

```
平均正味便益:        £775k
正味 > 0 となる確率: 0.86
5〜95パーセンタイル: −£180k … +£1.9M
```

点推定値は「明らかにイエス」と言いました。PSAは「86%イエスだが、£180k以上の損失となる現実的な裾野がある」と言います — これはポートフォリオの責任者が実際に必要としているものであり、まず発見用のスパイクを実施することの価値を値付けするものです([EVPI](../expected-value-of-perfect-information/)を参照)。

## ソフトウェア工学との関連

エンジニアはすでに、デリバリー予測にモンテカルロ法を信頼しています(スループットのサンプリングは点推定に勝ります)。同じ仕組みをお金にも拡張してください:普及率、節約時間、給与に分布を与え、誤った精密さのROIの代わりに「このプラットフォーム投資が正味プラスである確率」を報告します。CEACのような曲線 — 組織がエンジニア時間をどう評価するかの関数として、最良の選択肢である確率を示すもの — は、資金委員会にとって単一の数字よりも本質的に優れた成果物です。

## 落とし穴

- **でたらめな分布**:でっち上げた標準偏差を使ったPSAは、白衣を着た決定論的分析にすぎません。データまたは構造化された専門家意見聴取に基づいて幅を決めてください。
- **パラメータ間の相関を無視すること**(高い普及率は通常、高い節約時間と相関する);独立なサンプリングは裾野のリスクを過小評価します。
- **シミュレーションの平均値だけを報告すること** — 分布と意思決定確率こそが要点全体です。
