# Кількість, яку потрібно лікувати (NNT)

NNT вимірює, скільки пацієнтів потрібно лікувати, щоб запобігти одному додатковому несприятливому результату — інтуїтивна одиниця зусиль на вигоду.

## Чому це важливо

NNT перекладає абстрактну статистичну значущість у практичне число, яке клініцисти та особи, що приймають рішення, можуть зрозуміти та порівняти між методами лікування.

## Математика

```
NNT = 1 / Абсолютне зниження ризику
```

## Розібраний приклад

Ліки знижують ризик серцевого нападу з 10% до 8% (абсолютне зниження ризику 2%): NNT = 1/0,02 = 50 — потрібно лікувати 50 пацієнтів, щоб запобігти одному серцевому нападу.

## Зв'язок з інженерією програмного забезпечення

Подібно до розрахунку того, скільки користувачів повинні відчути нову функцію, щоб згенерувати одну додаткову конверсію. [Кількість, яку потрібно скринувати](../кількість-яку-потрібно-скринувати/) — аналогічний показник рівнем вище, для всієї програми «скринінг-а-потім-лікування», а не лише лікування.

## Підводні камені

- **Порівняння NNT між дослідженнями з різними базовими ризиками без коригування.**
- **Плутанина низького NNT з клінічно важливим ефектом без урахування серйозності результату.**
