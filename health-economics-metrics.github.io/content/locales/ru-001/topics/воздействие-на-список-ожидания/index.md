# Воздействие на список ожидания

Воздействие на список ожидания превращает сэкономленную клиническую мощность в пациентов, удалённых из списка ожидания (или проведённых через него быстрее). Превращение сэкономленных часов в дополнительные слоты клиники напрямую сокращает размер списка ожидания траста — самый осязаемый способ показать системе здравоохранения, *для чего* нужна высвобожденная мощность.

## Почему это важно

Список ожидания планового лечения — определяющий постпандемический вызов NHS (его размер — национальная политическая метрика), и каждый траст ведёт программу восстановления планового лечения против него. Бизнес-кейс, говорящий «экономит 2000 сестринских часов», абстрактен; кейс, говорящий «создаёт 4000 дополнительных слотов приёма, принимает 3800 ожидающих пациентов, сокращая список специальности на 9%» — это история, которую операционный директор может принести своему совету. Воздействие на список ожидания — естественная *единица учёта* для [не высвобождающей наличные мощности](../экономия-высвобождающая-наличные-против-не-высвобождающей/).

## Расчёт

```
Дополнительные слоты   = высвобожденные часы / длительность слота × использование
Принятые пациенты      = дополнительные слоты × (1 − частота неявок)
Сокращение списка      = принятые пациенты − индуцированный новый спрос
Прирост времени ожидания = улучшение очереди от более высокой скорости обслуживания
                     (для стабильных очередей сокращение отставания N на ΔN при
                     скорости обслуживания μ продвигает всех вперёд ~ΔN/μ)
```

Ценность здоровья от более коротких ожиданий: пациенты проводят меньше недель в состоянии более низкой полезности до лечения — арифметика QALY из [направления на лечение](../направление-на-лечение/).

## Разобранный пример

ПО амбиентной документации экономит каждой из 20 клинических медсестёр 45 мин/день. За 250 дней: 20 × 0,75 × 250 = 3750 часов/год.

```
Слоты (30 мин, 85% пригодно) = 3750 / 0,5 × 0,85 = 6375 слотов
Принятые пациенты (7% неявок) = 6375 × 0,93       ≈ 5929/год
```

Для специальности со списком в 12 000 пациентов и 24 000 приёмов/год мощности, соответствующей спросу, ~5900 дополнительных приёмов сокращают среднее время ожидания примерно на четверть — материально продвигая траст к 18-недельному стандарту без найма. При ~£160 ценности схемы на приём активность стоит ~£949 000/год (см. [национальный тариф и удельные затраты](../национальный-тариф-и-удельные-затраты/)) — но представляйте сначала *формулировку списка ожидания*; именно по ней управляется система.

## Связь с программной инженерией

Список ожидания — это отставание, и экономика сжигания отставания переносится в обоих направлениях. Из здравоохранения в ПО: оценивайте сокращение отставания по тому, сколько *пользователи* ждут ценности, а не по закрытым пунктам ([стоимость задержки](../стоимость-задержки/) на элемент в очереди). Из ПО в здравоохранение: закон Литтла говорит, что список сокращается только если скорость обслуживания превышает скорость поступления — приросты мощности, поглощённые растущими направлениями, оставляют ожидания неизменными, так что моделируйте также поступления. И в обеих областях приоритизируйте по ценности, взвешенной по тяжести (категории клинической срочности ↔ [модификаторы тяжести](../дефицит-qaly-и-модификаторы-тяжести/)), а не по принципу «первым пришёл — первым обслужен».

## Подводные камни

- **Слоты ≠ пациенты**: забывание частоты неявок и непригодных фрагментов высвобожденного времени.
- **Индуцированный спрос**: видимая дополнительная мощность привлекает направления; чистое воздействие на список меньше валового.
- **Заявление о наличных**: воздействие на список ожидания — это ценность мощности; заявление о наличных (избежание аутсорсинга работы по отставанию) — это другая строка — см. [избегаемые затраты на аутсорсинг](../предотвратимые-затраты-на-аутсорсинг/).
