# 完全情報の期待価値(EVPI)

EVPIとは、意思決定者が決定を下す前に不確実性を排除するために支払うべき最大額のことです — 「まず研究をしよう」という選択肢に対する正式な価格です。

## なぜ重要か

医療システムは常にこの選択に直面します:不完全な証拠のもとで今すぐ導入するか、それとも先にもっと研究に資金を投じるか。EVPIは後者の選択肢に数値を与えます。EVPIが£50,000で、提案されている試験の費用が£200万なら、今すぐ導入すべきです。EVPIが£2,000万なら、その試験は割安です。同じ問い — 「これを展開する前にパイロット試験をすべきか?」 — は、あらゆる企業向けツールの意思決定にも生じますが、それに値段をつける人はほとんどいません。 先に情報を集めるオプションではなく、後でプロジェクトを拡張するオプションの価格づけについては、[リアルオプション評価](../リアルオプション評価/)を参照してください。

## 数式

EVPIは、完全な予見のもとで決定する場合と、期待値に基づいて今決定する場合との差です:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = 不確実なパラメータ(その同時分布を伴う)
NMB(j,θ) = θが与えられたときの選択肢jの正味金銭的便益
```

第1項:それぞれのあり得る世界における最良選択の利得の平均(常に正しく選ぶ場合)。第2項:平均して最良である単一の選択肢の利得(今コミットしなければならない場合)。EVPIは常に≥0です。集団EVPIは、影響を受ける意思決定の件数を掛け合わせたものです。[PSA](../確率的感度分析/)の抽出から直接計算されます。

## 計算例

5,000人の臨床医にAI文書作成アシスタントを展開するか、しないか。2つの世界:

```
世界A(p = 0.6):アシスタントが1日20分節約する → 展開のNMB = +£8M
世界B(p = 0.4):アシスタントがほぼ何も節約しない(ワークフローの摩擦) → 展開のNMB = −£3M
「展開しない」のNMB = 両方の世界で£0。
```

今決定する場合:E[展開のNMB] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → 展開する。

完全情報がある場合:世界Aでは展開を選び(+£8M)、世界Bでは何もしないことを選ぶ(£0)。期待値 = 0.6 × 8 + 0.4 × 0 = **£4.8M**。

```
EVPI = 4.8M − 3.6M = £1.2M
```

どちらの世界にいるかを実質的に解明できる、費用£150,000の厳密な3か月のパイロット試験は間違いなく価値があります — そして、どんなに徹底していても£1.2Mを超える費用のパイロット試験は価値がありません。

## ソフトウェア工学との関連

EVPIはスパイク、パイロット試験、A/Bテスト、概念実証の経済学です。これは2つの実用的なルールをもたらします:

- **パイロット試験は、意思決定が実際に変わりうる場合にのみ資金を投じる価値があります。** パイロットの結果にかかわらず展開するつもりなら、EVPI = 0であり、そのパイロットは茶番です。
- **パイロットの支出をEVPIで上限とすること。** 情報の価値は、それが情報提供する意思決定の価値によって制限されます。

部分EVPI(EVPPI)はこれを単一のパラメータに拡張します:「節約時間の数値を具体的に確定させることには、どれだけの価値があるか?」 — これはパイロットが何を測定すべきかを教えてくれます。 不確実性をすべて解消するのではなく、*特定の*提案された研究の価格づけについては、[EVSI](../標本情報の期待価値/)を参照してください。

## 落とし穴

- **意思決定ルールが結びついていないパイロット試験を実施すること** — 選択を変えられない情報は、定義上無価値です。
- **情報収集の遅延コストを無視すること**:6か月のパイロット試験は6か月分の便益を遅らせます([遅延コスト](../遅延コスト/));パイロットの正味価値 = 解消されたEVPI − 遅延コスト − パイロット費用。
- **EVPIを予測として扱うこと。** それは情報価値の上限であり、特定の研究が実際にもたらすものの推定値ではありません。
