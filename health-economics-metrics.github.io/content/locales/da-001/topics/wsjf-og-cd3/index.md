# WSJF og CD3

CD3 og WSJF er regler til prioritering af arbejde baseret på **værditæthed**.

## Hvorfor det er vigtigt

Enhver backlog er et rationeringsproblem.

## Matematikken

```
CD3 = omkostning ved forsinkelse (£/uge) / varighed (uger)
```

## Gennemarbejdet eksempel

Tre funktioner, ét team: CD3-rækkefølge: B, C, A.

## Forbindelse til softwareudvikling

For sundhedssoftwareporteføljer, udtryk CoD i QALY/uge.
