# জরুরি বিভাগে উপস্থিতি এড়ানো

জরুরি বিভাগে উপস্থিতি এড়ানো উজানের হস্তক্ষেপ — ট্রায়াজ অ্যাপ, দূরবর্তী পর্যবেক্ষণ, ভার্চুয়াল ওয়ার্ড — দ্বারা প্রতিরোধিত ED (দুর্ঘটনা ও জরুরি) ভ্রমণ এবং জরুরি ভর্তি গণনা করে।

## কেন এটি গুরুত্বপূর্ণ

জরুরি যত্ন ব্যবস্থার সবচেয়ে ব্যয়বহুল নিয়মিত সেটিং (ED উপস্থিতি একক ব্যয় £250–£400 পরিসরে), এবং ED ভিড় অ্যাম্বুলেন্স বিলম্ব এবং বাতিলকৃত নির্বাচনীতে ঝরনার মতো প্রবাহিত হয়।

## গণিত

```
এড়ানো উপস্থিতি = জনসংখ্যা × (বেসলাইন হার − হস্তক্ষেপ হার)
মোট সাশ্রয়      = এড়ানো উপস্থিতি × প্রতি উপস্থিতি একক ব্যয়

নিট সাশ্রয়      = মোট সাশ্রয় − হস্তক্ষেপ ব্যয় − নতুন পথ ব্যবহারের ব্যয়
```

## সমাধানকৃত উদাহরণ

৩,০০০ উচ্চ-ঝুঁকিপূর্ণ রোগীর জন্য একটি COPD দূরবর্তী-পর্যবেক্ষণ সেবা।

```
এড়ানো উপস্থিতি = 3,000 × 0.2  = 600 × £300   = £180,000
এড়ানো ভর্তি    = 3,000 × 0.08 = 240 × £3,800 = £912,000
মোট                                          £1,092,000/বছর

ব্যয়: পর্যবেক্ষণ সেবা £600,000; অতিরিক্ত কমিউনিটি-নার্স প্রতিক্রিয়া £150,000
নিট ≈ +£342,000/বছর
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

এটি **ঘটনা-এড়ানোর অর্থনীতি**। পর্যবেক্ষণযোগ্যতা, ক্যানারি ডেপ্লয়, এবং প্রাথমিক-সতর্কতা ব্যবস্থার মূল্য হলো এড়ানো "জরুরি উপস্থিতি" — পেজ, ওয়ার রুম, সেভ-১।

## ঝুঁকিপূর্ণ দিক

- **গড়ের দিকে প্রত্যাবর্তন**: খারাপ বছরের ভিত্তিতে নির্বাচিত উচ্চ-ঝুঁকিপূর্ণ কোহোর্ট চিকিৎসাহীন অবস্থাতেও উন্নত হয়।
- **সরবরাহ-প্ররোচিত চাহিদা**: সহজ ডিজিটাল ট্রায়াজ মোট যোগাযোগ বাড়াতে পারে।
- **গড় ব্যয়ে উপস্থিতি মূল্যায়ন করা** যখন ED স্থির ব্যয় কমে না।
