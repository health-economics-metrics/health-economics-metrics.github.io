# নাগাল এবং ন্যায্যতা

RE-AIM — নাগাল, কার্যকারিতা, গ্রহণ, বাস্তবায়ন, রক্ষণাবেক্ষণ — একটি হস্তক্ষেপের *জনসংখ্যা* প্রভাব বিচারের জন্য প্রমিত কাঠামো। এর কেন্দ্রীয় গণিত: **জনস্বাস্থ্য প্রভাব ≈ নাগাল × কার্যকারিতা**।

## কেন এটি গুরুত্বপূর্ণ

mHealth-এ RE-AIM প্রয়োগকারী পদ্ধতিগত পর্যালোচনা একটি সামঞ্জস্যপূর্ণ স্বাক্ষর খুঁজে পায়: শক্তিশালী নাগাল এবং গ্রহণ, **দুর্বল কার্যকারিতা এবং রক্ষণাবেক্ষণ**। ন্যায্যতা একটি পার্শ্ব সীমাবদ্ধতা নয় বরং একটি মূল্য চালক: ডিজিটাল বর্জন বয়স, বঞ্চনা, অক্ষমতা, এবং ভাষা অনুসরণ করে।

## গণিত

```
জনসংখ্যা প্রভাব ≈ নাগাল × কার্যকারিতা
  নাগাল         = অংশগ্রহণকারী / যোগ্য জনসংখ্যা
  কার্যকারিতা   = অংশগ্রহণকারীদের মধ্যে বাস্তব-বিশ্ব প্রভাব (ধরে-রাখা-ওজনযুক্ত)

ন্যায্যতা-স্তরভুক্ত সংস্করণ:
  প্রভাব_গ্রুপ_g = নাগাল_g × কার্যকারিতা_g, বঞ্চনা পঞ্চমাংশ প্রতি রিপোর্টকৃত
```

## সমাধানকৃত উদাহরণ

একটি ডিজিটাল ডায়াবেটিস-প্রতিরোধ কর্মসূচি, দুইভাবে রিপোর্টকৃত:

```
সমষ্টি: নাগাল 12%, প্রভাব 0.02 QALY/অংশগ্রহণকারী → 0.0024 QALY/যোগ্য ব্যক্তি

স্তরভুক্ত (বঞ্চনা পঞ্চমাংশ):
  Q1 (সবচেয়ে কম বঞ্চিত): নাগাল 22%, প্রভাব 0.02 → 0.0044
  Q5 (সবচেয়ে বেশি বঞ্চিত): নাগাল 4%, প্রভাব 0.025 → 0.0010
```

কর্মসূচিটি সবচেয়ে কম বঞ্চিতদের ৪.৪× বেশি স্বাস্থ্য প্রদান করে — যখন Q5-এর প্রতি-অংশগ্রহণকারী প্রভাব বেশি (আরও অগ্রগতির সুযোগ)।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

নাগাল মূলত একটি প্রকৌশল শিল্পকর্ম: ডিভাইস এবং OS ন্যূনতম প্রয়োজনীয়তা, ব্যান্ডউইথ অনুমান, ভাষা সহায়তা, অ্যাক্সেসযোগ্যতা সঙ্গতি প্রতিটি জনসংখ্যাকে হর থেকে বাদ দেয়।

## ঝুঁকিপূর্ণ দিক

- **সম্পূর্ণকারীদের উপর রিপোর্টকৃত কার্যকারিতা, জনসংখ্যায় দাবিকৃত প্রভাব**।
- **নকশা ইনপুটের পরিবর্তে পরবর্তী-চিন্তা নিরীক্ষা হিসেবে ন্যায্যতা**।
