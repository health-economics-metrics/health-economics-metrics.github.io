# Kostnad för fördröjning (CoD)

Kostnad för fördröjning är det ekonomiska värde som går förlorat per tidsenhet genom att en funktion, produkt eller tjänst *inte* levereras.

## Varför det är viktigt

Reinertsens lag: "Om du bara mäter en sak, mät kostnaden för fördröjning."

## Matematiken

```
CoD = förlorad nytta per tidsenhet i icke-levererat tillstånd (£/vecka eller QALY/vecka)
```

## Genomarbetat exempel

**Operativt**: mjukvara sparar £200 per patient på vägen; CoD = £10 000/vecka.

## Koppling till mjukvaruutveckling

CoD är måttet som gör [DORA-ledtid](../dora-mått/) finansiellt läsbar.

## Fallgropar

- **Att anta att CoD är linjär.**
