# ตัวชี้วัดการไหล

ตัวชี้วัดการไหลวัดว่างานไหลผ่านระบบได้อย่างราบรื่นเพียงใดตั้งแต่เริ่มต้นจนถึงเสร็จสิ้น โดยเน้นที่เวลารอบ ปริมาณงาน และงานที่อยู่ระหว่างดำเนินการ

## ทำไมจึงสำคัญ

การไหลเน้นที่ผลลัพธ์ (ความเร็วในการส่งมอบคุณค่าให้ลูกค้า) แทนที่จะเน้นการใช้ทรัพยากร (ความยุ่งของคน) ซึ่งมักเป็นตัวทำนายผลิตภาพที่ดีกว่า

## คณิตศาสตร์

```
กฎของลิตเติล: เวลารอบ = งานที่อยู่ระหว่างดำเนินการ / ปริมาณงาน
```

## ตัวอย่างที่คำนวณแล้ว

ทีมที่มีงาน 20 รายการระหว่างดำเนินการและปริมาณงาน 5 รายการต่อสัปดาห์ ควรคาดหวังเวลารอบเฉลี่ย 4 สัปดาห์ตามกฎของลิตเติล

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

เปรียบเทียบได้โดยตรงกับ [ระยะเวลานอนโรงพยาบาล](../length-of-stay/) และ [RTT](../referral-to-treatment/) — ทั้งสองเป็นตัวชี้วัดเวลารอบในบริบทที่แตกต่างกัน

## ข้อผิดพลาดที่พบบ่อย

- **การอนุญาตให้มีงานระหว่างดำเนินการมากเกินไป ซึ่งยืดเวลารอบตามกฎของลิตเติล**
- **การเพิ่มประสิทธิภาพปริมาณงานโดยแลกกับเวลารอบในลักษณะที่ทำร้ายประสบการณ์ลูกค้า**
