# এড়ানো যায় এমন আউটসোর্সিং ব্যয়

যখন একটি ট্রাস্ট অভ্যন্তরীণ ক্ষমতা দিয়ে লক্ষ্য পূরণ করতে পারে না, তারা প্রিমিয়াম হারে ক্ষমতা কেনে: নিজস্ব কর্মীদের জন্য সাপ্তাহিক ওভারটাইম, বা বেসরকারি প্রদানকারীদের কাছে প্রক্রিয়া আউটসোর্স করা।

## কেন এটি গুরুত্বপূর্ণ

নির্বাচনী-পুনরুদ্ধার চাপের অধীনে, ট্রাস্টগুলো নিয়মিতভাবে বেসরকারি-খাত স্পট মূল্য পরিশোধ করে (প্রায়ই NHS স্কিম মূল্যের ১.২–১.৫×)। সাধারণ ক্ষমতা দাবির বিপরীতে, এড়ানো আউটসোর্সিং **নগদ-মুক্তকারী**।

## গণিত

```
এড়ানো যায় এমন আউটসোর্সিং ব্যয় = ইন-হাউসে স্থানান্তরিত কার্যক্রম × (আউটসোর্সড একক মূল্য
                                 − প্রতি কেস অভ্যন্তরীণ প্রান্তিক ব্যয়)
```

## সমাধানকৃত উদাহরণ

একটি ট্রাস্ট বছরে ৮০০টি ছানি প্রক্রিয়া আউটসোর্স করে প্রতিটি £৯০০-এ: বছরে £৭২০,০০০ বহিঃস্থ ব্যয়। থিয়েটার-সময়সূচি সফটওয়্যার অভ্যন্তরীণ থিয়েটার ব্যবহার যথেষ্ট বাড়ায় ৫০০টি প্রক্রিয়া প্রত্যাবাসন করতে:

```
প্রতি কেস অভ্যন্তরীণ প্রান্তিক ব্যয় ≈ £350
সাশ্রয় = 500 × (900 − 350) = বছরে £275,000 — নগদ-মুক্তকারী
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

সরাসরি উপমা হলো **ঠিকাদার এবং পরামর্শক প্রিমিয়াম**: যখন অভ্যন্তরীণ প্রকৌশল ক্ষমতা প্রতিশ্রুতি পূরণ করতে পারে না, সংস্থাগুলো ১.৫–৩× সম্পূর্ণ বরাদ্দকৃত অভ্যন্তরীণ হারে বহিঃস্থ ক্ষমতা কেনে।

## ঝুঁকিপূর্ণ দিক

- সম্পূর্ণ ক্ষমতা শৃঙ্খল ছাড়া **প্রত্যাবাসন দাবি করা**।
- **আউটসোর্সড মূল্যকে অভ্যন্তরীণ গড় ব্যয়ের সাথে তুলনা করা** প্রান্তিক ব্যয়ের পরিবর্তে।
- **মান/জটিলতা অসামঞ্জস্যতা**: আউটসোর্সড কেসগুলো প্রায়ই সহজ।
