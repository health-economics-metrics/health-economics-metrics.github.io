# Анализ «затраты-выгоды» (Cost-Benefit Analysis, CBA)

CBA оценивает в деньгах и затраты, *и* исходы. Это единственный тип анализа, способный ответить на вопрос «стоит ли вообще этим заниматься?» — а не только «какой вариант лучше?» — потому что монетизированные выгоды можно напрямую сравнивать с затратами.

## Почему это важно

CBA — это стандарт **Green Book** Казначейства Её Величества (HM Treasury) для оценки всех государственных расходов, включая здравоохранение, когда исходы можно монетизировать. Там, где [CEA](../анализ-затраты-эффективность/)/[CUA](../анализ-затраты-полезность/) останавливаются на «стоимости за единицу здоровья», CBA оценивает само здоровье (QALY × пороговое значение) и всё остальное — время, поездки, углеродный след — и выдаёт одну итоговую чистую цифру. Каждый полноценный цифровой бизнес-кейс NHS содержит экономический раздел в форме CBA.

## Математика

```
NPV (чистая приведённая общественная ценность) = Σ_t [ (Выгоды_t − Затраты_t) / (1 + r)^t ]
BCR (соотношение выгод и затрат)                = PV(выгоды) / PV(затраты)

Принимать, если NPV > 0 (эквивалентно BCR > 1); ранжируйте по NPV, а не по BCR.
r = 3.5% (ставка социального предпочтения по времени Green Book)
```

Эффекты для здоровья могут входить в монетизированном виде как QALY × λ (см. [пороги готовности платить](../пороги-готовности-платить/)). Green Book также требует **корректировок на систематическую переоценку (optimism bias)** — завышение оценок затрат и урезание выгод на научно обоснованные проценты, потому что оценки систематически слишком оптимистичны.

## Практический пример

Система электронных направлений, горизонт 5 лет, дисконт 3,5%:

```
Затраты: строительство £1.2M (год 0), эксплуатация £300k/год (годы 1–5)
Выгоды:  экономия на администрировании £250k/год, предотвращённая дублирующая диагностика £280k/год,
         сэкономленное время пациентов 40,000 ч/год × £15 = £600k/год → £1,130k/год

PV затрат = 1,200k + 300k × 4.515 (аннуитетный коэффициент) = £2,555k
PV выгод  = 1,130k × 4.515                                  = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

Применим систематическую переоценку Green Book (скажем, +40% к стоимости строительства, −20% к выгодам): PV затрат ≈ £3 035 тыс., PV выгод ≈ £4 082 тыс., NPV ≈ **+£1 047 тыс.** — всё ещё положительно, что и есть смысл корректировки: кейсы должны пережить собственный оптимизм.

## Связь с разработкой программного обеспечения

Инженерные бизнес-кейсы — это неформальные CBA. Апгрейды Green Book, которые стоит позаимствовать:

- **Систематическая переоценка как стандартная надбавка** — инженеры недооценивают стоимость миграции так же надёжно, как министерства недооценивают стоимость инфраструктуры; применяйте заявленную надбавку, а не притворяйтесь, что на этот раз всё иначе.
- **Монетизируйте доминирующую выгоду честно или не монетизируйте вовсе** — время пациента/пользователя монетизируется по обоснованным ставкам; «ценность бренда» — нет.
- **NPV ранжирует, BCR — нет**: крошечный проект с BCR 5 может иметь меньшее значение, чем большой с BCR 1,6.

## Подводные камни

- **Монетизация немонетизируемого** для раздувания выгод (моральный дух, «стратегическое соответствие») — оставляйте их качественными, согласно [анализу «затраты-последствия»](../анализ-затраты-последствия/).
- **Учёт трансфертов как выгод**: деньги, перемещающиеся между государственными органами, обнуляются на общественной [перспективе](../перспектива-анализа/).
- **Отсутствие контрфактического сценария**: выгоды измеряются относительно варианта «минимального действия», а не относительно нуля.
