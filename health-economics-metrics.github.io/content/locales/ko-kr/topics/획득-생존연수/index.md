# 획득 생존연수(LYG)

획득 생존연수는 어떤 질적 조정도 없이 개입으로 인한 추가 생존입니다. evLYG는 모든 생명 연장을 동등하게 인정하는 현대적 변형입니다.

## 왜 중요한가

LYG는 가장 원초적인 건강 결과입니다: 사람들이 얼마나 더 오래 사는가? evLYG(미국 ICER 연구소가 사용)는 윤리적 이유로 존재합니다.

## 수식

```
LYG = 평균 생존_신규 − 평균 생존_비교대상
```

## 계산 예시

병원의 패혈증 조기 경보 알고리즘이 연간 96 생존연수를 절약합니다.

## 소프트웨어 공학과의 연관성

생존 분석은 공유된 도구상자입니다.

## 함정

- **중앙값 대 평균 생존.**
