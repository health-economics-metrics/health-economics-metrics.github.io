# WSJF اور CD3

CD3 اور WSJF ترجیحی اصول ہیں جو **قدر-کثافت** کے ذریعے کام کا تعین کرتے ہیں۔

## یہ کیوں اہم ہے

ہر بیک لاگ ایک راشننگ کا مسئلہ ہے۔

## ریاضی

```
CD3 = تاخیر کی قیمت (£/ہفتہ) / مدت (ہفتے)
```

## حل شدہ مثال

تین خصوصیات، ایک ٹیم: CD3 ترتیب: B، C، A۔

## سافٹ ویئر انجینئرنگ سے تعلق

ہیلتھ کیئر سافٹ ویئر پورٹ فولیوز کے لیے، CoD کو QALY/ہفتہ میں بیان کریں۔
