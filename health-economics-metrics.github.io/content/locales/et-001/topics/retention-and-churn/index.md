# Hoidmine ja kasutajate lahkumine

Hoidmine ja kasutajate lahkumine mõõdavad, kui suur osa kasutajatest jätkab digitervise toote kasutamist aja jooksul versus kui paljud lõpetavad kasutamise.

## Miks see on oluline

Kõrge kasutajate lahkumise määr õõnestab digitervise sekkumise pikaajalist väärtust, isegi kui esialgne kasutuselevõtt on tugev.

## Matemaatika

```
Kasutajate lahkumise määr = Kaotatud kasutajad perioodi jooksul / Perioodi alguse kasutajate arv × 100%
```

## Lahendatud näide

Vaimse tervise rakendus, millel on 1000 kasutajat kuu alguses ja 150 kasutajat lõpetab kasutamise selle kuu jooksul, annab kasutajate lahkumise määraks 15%/kuus — jätkusuutmatu määr pikaajalise mõju jaoks.

## Seos tarkvaraarendusega

Otseselt analoogne SaaS-toodete klientide lahkumise näitajatele, mis on kriitiline korduvtulu äriprojektide jaoks.

## Lõksud

- **Varajase kasutajate lahkumise segiajamine kavandatud lühiajalise kasutusega (nt 6-nädalane programm).**
- **Kasutajate lahkumise põhjuste mitte uurimine enne sekkumisi kavandamist.**
