# Валідація носимих пристроїв

Валідація носимих пристроїв — це процес перевірки того, чи дані від споживчих носимих пристроїв (смарт-годинники, фітнес-трекери) є клінічно точними та надійними.

## Чому це важливо

Споживчі носимі пристрої часто не валідовані відповідно до регуляторних стандартів медичних виробів.

## Математика

```
Середня абсолютна відсоткова помилка (MAPE) = (1/n) × Σ |фактичне значення − виміряне значення| / фактичне значення × 100%
```

## Розібраний приклад

Датчик частоти серцевих скорочень на зап'ясті: MAPE 4,2% порівняно зі стандартом ЕКГ (зростає до 8,5% під час фізичних вправ).
