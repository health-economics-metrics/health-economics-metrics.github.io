# সংবেদনশীলতা বিশ্লেষণ

নির্ধারক সংবেদনশীলতা বিশ্লেষণ (DSA) একটি প্রশংসনীয় সীমায় একবারে একটি অনুমান পরিবর্তন করে দেখতে যে উপসংহার টিকে থাকে কিনা। মানক ভিজ্যুয়ালাইজেশন হল একটি টর্নেডো ডায়াগ্রাম: পরামিতিগুলি ফলাফলকে কতটা দোলায় তা দিয়ে র‍্যাংক করা।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি অর্থনৈতিক মডেল অনুমানের উপর নির্মিত — সঞ্চিত সময়, গ্রহণ, ইউনিট খরচ। স্বাস্থ্য প্রযুক্তি মূল্যায়ন ইনপুট সম্পর্কে যুক্তিসঙ্গত মতবিরোধে উপসংহার শক্তিশালী তার প্রমাণ ছাড়া একটি পয়েন্ট অনুমান ("ROI হল 340%") গ্রহণ করতে অস্বীকার করে। একটি টর্নেডো ডায়াগ্রাম সিদ্ধান্ত গ্রহণকারীকে বলে *কোন অনুমান জিজ্ঞাসাবাদ করতে হবে*: যদি কেসটি শুধুমাত্র কাজ করে যখন সবচেয়ে বিতর্কিত পরামিতি তার আশাবাদী প্রান্তে থাকে, সবাই তা অবিলম্বে দেখতে পায়।

এটি স্বাস্থ্য অর্থনীতি থেকে সফটওয়্যার ব্যবসায়িক কেসে একক সবচেয়ে হস্তান্তরযোগ্য অভ্যাস।

## গণনা

প্রশংসনীয় সীমা [p_নিম্ন, p_উচ্চ] সহ প্রতিটি পরামিতি p-র জন্য:

```
ফলাফল_নিম্ন  = মডেল(p = p_নিম্ন,  বাকি সব বেস কেসে)
ফলাফল_উচ্চ  = মডেল(p = p_উচ্চ, বাকি সব বেস কেসে)
দোলন(p)    = |ফলাফল_উচ্চ − ফলাফল_নিম্ন|
```

দোলন অনুযায়ী পরামিতি র‍্যাংক করুন; বেস-কেস ফলাফলের চারপাশে অনুভূমিক বার প্লট করুন। রূপ: দ্বিমুখী DSA (একটি গ্রিডে দুটি পরামিতি পরিবর্তন), প্রান্তসীমা বিশ্লেষণ (পরামিতির মান খুঁজুন যেখানে সিদ্ধান্ত উল্টে যায়)।

## বিস্তারিত উদাহরণ

200 ডেভেলপারের জন্য AI কোডিং সহায়ক। বেস কেস: £39/ডেভেলপার/মাস লাইসেন্স; 30 মিনিট/ডেভেলপার/দিন সাশ্রয়; লোডকৃত খরচ £60/ঘণ্টা; 220 কর্মদিবস।

```
বেস-কেস বার্ষিক সুবিধা = 200 × 0.5ঘ × 220 × £60 = £1,320,000
বার্ষিক খরচ            = 200 × £39 × 12         = £93,600
বেস-কেস নিট             = £1,226,400
```

টর্নেডো (একবারে একটি পরামিতি):

```
সঞ্চিত সময় 0.1-1.0 ঘ/দিন: নিট = £170,400 … £2,546,400   (দোলন £2.38M) ← প্রাধান্যকারী
লোডকৃত খরচ £40-£80/ঘ:     নিট = £786,400 … £1,666,400   (দোলন £0.88M)
কর্মদিবস 200-240:          নিট = £1,106,400 … £1,346,400 (দোলন £0.24M)
লাইসেন্স £30-£50/মাস:      নিট = £1,248,000 … £1,200,000 (দোলন £48হাজার)
```

প্রান্তসীমা বিশ্লেষণ: নিট সুবিধা প্রায় **প্রতিদিন 2.1 মিনিট** সঞ্চিত হলে শূন্যে আঘাত করে। সিদ্ধান্ত লাইসেন্স মূল্যে সংবেদনশীল নয় এবং সম্পূর্ণভাবে সঞ্চিত-সময় অনুমানের উপর নির্ভর করে — তাই বাকিটা নয়, সেটাই পরিমাপ করুন। (এবং মনে রাখবেন ফলাফলটি ক্ষমতা, নগদ নয় — দেখুন [নগদ-মুক্তকারী বনাম নগদ-অ-মুক্তকারী](../নগদ-মুক্তকারী-বনাম-নগদ-অ-মুক্তকারী-সঞ্চয়/)।)

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

ইঞ্জিনিয়াররা ইতিমধ্যে এটি স্বজ্ঞাতভাবে "যদি আমরা X সম্পর্কে ভুল হই তাহলে কী?" হিসেবে করেন — DSA শুধু এটিকে পদ্ধতিগত এবং দৃশ্যমান করে তোলে। প্রতিটি টুলিং প্রস্তাব, ক্ষমতা পরিকল্পনা এবং নির্মাণ-বনাম-ক্রয় বিশ্লেষণে একটি টর্নেডো ডায়াগ্রাম রাখুন। এটি কার অন্তর্দৃষ্টি সঠিক সে সম্পর্কে যুক্তিকে কোন পরামিতি পরিমাপ করতে হবে সে সম্পর্কে চুক্তিতে রূপান্তরিত করে — প্রায়ই একটি পাইলটের মাধ্যমে, যার মূল্য নিজেই মূল্য নির্ধারণ করা যেতে পারে (দেখুন [নিখুঁত তথ্যের প্রত্যাশিত মূল্য](../নিখুঁত-তথ্যের-প্রত্যাশিত-মূল্য/))।

## ঝুঁকি

- **স্তুতির জন্য বেছে নেওয়া সীমা**: প্রকৃত অনিশ্চয়তা নির্বিশেষে প্রতিটি ইনপুটের চারপাশে ±10%। সঞ্চিত-সময় অনুমান ±80%-র যোগ্য; লাইসেন্স মূল্য ±10%।
- **একবারে-একটি মিথষ্ক্রিয়া মিস করে** — সম্পর্কিত পরামিতি (গ্রহণ এবং সঞ্চিত সময়) দ্বিমুখী বিশ্লেষণ বা সম্পূর্ণ [সম্ভাব্যতা সংবেদনশীলতা বিশ্লেষণ](../সম্ভাব্যতা-সংবেদনশীলতা-বিশ্লেষণ/) প্রয়োজন।
- **বিশ্লেষণ করা এবং এটি উপেক্ষা করা**: যদি টর্নেডো বলে কেসটি একটি নরম সংখ্যার উপর নির্ভর করে, পরবর্তী পদক্ষেপ পরিমাপ, স্বাক্ষর নয়।
