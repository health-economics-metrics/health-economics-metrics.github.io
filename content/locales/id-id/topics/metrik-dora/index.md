# Metrik DORA

Metrik DORA adalah empat ukuran kinerja pengiriman perangkat lunak — frekuensi penerapan, waktu tunggu untuk perubahan, tingkat kegagalan perubahan, dan waktu pemulihan.

## Mengapa ini penting

Satu dekade penelitian DORA menghubungkan metrik ini dengan kinerja organisasi.

## Matematika

```
Waktu tunggu = t(deploy) − t(commit), median
```

## Contoh yang diselesaikan

Tim perangkat lunak alur pasien sebuah trust, sebelum/sesudah: deploy bulanan → mingguan.

## Hubungan dengan rekayasa perangkat lunak

Ini *adalah* sisi perangkat lunak.
