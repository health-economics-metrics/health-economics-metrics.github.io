# การวิเคราะห์อรรถประโยชน์ต้นทุน (CUA)

การวิเคราะห์อรรถประโยชน์ต้นทุนเปรียบเทียบต้นทุนของการแทรกแซงต่อ QALY ที่ได้รับ ทำให้สามารถเปรียบเทียบการแทรกแซงที่แตกต่างกันโดยสิ้นเชิงบนมาตราส่วนร่วมเดียวกันได้

## ทำไมจึงสำคัญ

CUA เป็นวิธีมาตรฐานที่หน่วยงาน HTA อย่าง NICE ใช้ตัดสินใจเรื่องเงินทุน เพราะช่วยให้สามารถเปรียบเทียบยามะเร็งกับการผ่าตัดข้อสะโพกบนมาตราส่วนเดียวกันได้

## คณิตศาสตร์

```
CUA = ต้นทุนของการแทรกแซง / QALY ที่ได้รับจากการแทรกแซง
```

ผลลัพธ์คือ ICER ที่เปรียบเทียบกับเกณฑ์ความเต็มใจจ่าย

## ตัวอย่างที่คำนวณแล้ว

ยาใหม่มีต้นทุนเพิ่ม £15,000 ให้ 0.6 QALY เพิ่มเติมเทียบกับมาตรฐานเดิม: CUA = £15,000 / 0.6 = £25,000 ต่อ QALY

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการสร้างตัวชี้วัดต้นทุนต่อหน่วยคุณค่าผู้ใช้รวม (composite) ที่ช่วยเปรียบเทียบการลงทุนในฟีเจอร์ที่แตกต่างกันโดยสิ้นเชิงบนมาตราส่วนร่วมเดียว

## ข้อผิดพลาดที่พบบ่อย

- **การเพิกเฉยต่อ [มุมมองการวิเคราะห์](../analysis-perspective/) ที่เลือกใช้**
