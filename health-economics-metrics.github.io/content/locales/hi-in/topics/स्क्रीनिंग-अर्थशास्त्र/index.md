# स्क्रीनिंग अर्थशास्त्र

स्क्रीनिंग अर्थशास्त्र लक्षणहीन आबादी की जाँच के मूल्य को नियंत्रित करता है। मुख्य गणितीय तथ्य: **कम रोग प्रसार पर, उत्कृष्ट परीक्षण भी अधिकतर झूठे सकारात्मक उत्पन्न करते हैं**।

## यह क्यों महत्वपूर्ण है

1968 से, WHO के विल्सन-जंगनर मानदंड जनसंख्या स्क्रीनिंग के लिए मानक निर्धारित करते हैं।

## गणित

```
PPV = (संवेदनशीलता × प्रसार) / [संवेदनशीलता × प्रसार + (1 − विशिष्टता) × (1 − प्रसार)]
```

## हल किया गया उदाहरण

एक दुर्लभ स्थिति के लिए AI रेटिनल स्क्रीनिंग, 100,000 लोग, प्रसार 0.5%:

```
सच्चे सकारात्मक: 450
झूठे सकारात्मक: 4,975
प्रति सच्चा मामला लागत ≈ £8,156
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

स्टैटिक विश्लेषण, सुरक्षा स्कैनिंग कम-प्रसार घटना धाराओं में स्क्रीनिंग कार्यक्रम हैं। एकल परीक्षण की नहीं बल्कि पूरे स्क्रीनिंग कार्यक्रम के पैमाने के लिए [स्क्रीनिंग के लिए आवश्यक संख्या](../स्क्रीनिंग-के-लिए-आवश्यक-संख्या/) देखें — एक परिणाम रोकने के लिए कितने लोगों को पूरे स्क्रीनिंग-फिर-उपचार मार्ग से गुज़रना पड़ता है।

## सामान्य गलतियाँ
