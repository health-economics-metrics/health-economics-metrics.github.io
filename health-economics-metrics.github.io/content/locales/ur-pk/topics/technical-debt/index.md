# تکنیکی قرض

تکنیکی قرض ایک کوڈ بیس میں آسان ماضی کے فیصلوں کی مضمر مستقبل کی قیمت ہے: واجب الادا تدارک کا کام (**اصل رقم**) اور ڈیلیوری پر اس کی مسلسل کھینچاؤ (**سود**)۔

## یہ کیوں اہم ہے

غیر ماپا، تکنیکی قرض ایک شکایت ہے؛ ماپا گیا، یہ ایک کاروباری کیس ہے۔

## ریاضی

```
SQALE اصل رقم = Σ خلاف ورزیوں میں (تدارک کا وقت) × ڈویلپر کی قیمت کی شرح
```

## حل شدہ مثال

ایک 4-لاکھ-LOC طبی-ریکارڈ انضمام کی تہہ: سود ≈ سالانہ £276,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

صحت-معاشیات کی درآمدات جو تکنیکی-قرض کے دلائل کو بہتر بناتی ہیں۔

## عام غلطیاں

- **صرف-اصل رقم کی رپورٹنگ۔**
