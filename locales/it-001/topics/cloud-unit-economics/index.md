# Economia Unitaria del Cloud (FinOps)

L'economia unitaria del cloud converte la spesa cloud grezza in **costo per unità di output**.

## Perché è importante

Le cifre di spesa totale non possono rispondere a domande importanti: il prodotto sta diventando più efficiente?

## La matematica

```
Costo unitario = costo totale allocato / unità fornite
```

## Esempio risolto

Un servizio di triage digitale: spesa cloud £62.000/mese, gestisce 380.000 episodi di triage al mese: costo medio ≈ £0,163.

## Collegamento con l'ingegneria del software

L'economia unitaria è dove le scelte ingegneristiche diventano finanziariamente leggibili.

## Insidie

- **Ignorare i costi condivisi.**
