# Kostenutiliteitsanalyse (CUA)

Kostenutiliteitsanalyse vergelijkt interventies op kosten per QALY, waardoor volledig ongelijksoortige behandelingen vergelijkbaar worden op één schaal.

## Waarom het ertoe doet

CUA is de standaardmethode van NICE en de meeste HTA-instanties omdat het een hartmedicijn kan vergelijken met een geestelijke-gezondheidsinterventie.

## De wiskunde

```
CUA-ratio (ICER) = (Kosten_A − Kosten_B) / (QALY's_A − QALY's_B)
```

## Uitgewerkt voorbeeld

Een nieuw geneesmiddel tegen reuma kost £8.000 meer en levert 0,4 QALY op ten opzichte van standaardzorg: £20.000/QALY.

## Verbinding met software-engineering

Vergelijkbaar met het normaliseren van kosten per eenheid gebruikerswaarde over volledig verschillende soorten functies.

## Valkuilen

- **Utiliteitsgewichten gebruiken die niet gevalideerd zijn voor de betreffende populatie.**
- **CUA en CEA-resultaten door elkaar rapporteren zonder de eenheid te specificeren.**
