# NICE Evidence Standards Framework

Het NICE Evidence Standards Framework specificeert risicogelaagde bewijsvereisten voor digitale gezondheidstechnologieën, van laag-risico welzijnsapps tot hoog-risico diagnostische hulpmiddelen.

## Waarom het ertoe doet

Digitale gezondheidsproducten hoeven niet allemaal aan dezelfde bewijslat te voldoen — het framework schaalt de vereisten naar het risiconiveau, wat innovatie mogelijk maakt zonder patiëntveiligheid in gevaar te brengen.

## De wiskunde

```
Bewijstier = f(functioneel risicoklasse, klinisch risiconiveau)
```

Geen enkele numerieke formule; het is een classificatiesysteem met bijbehorende bewijsdrempels.

## Uitgewerkt voorbeeld

Een welzijnsapp voor stressvermindering valt in tier 1 (beschrijvend bewijs volstaat); een AI-diagnostisch hulpmiddel voor kankerdetectie valt in tier 3b (gerandomiseerde gecontroleerde studies vereist).

## Verbinding met software-engineering

Vergelijkbaar met risicogebaseerde testvereisten — een interne tool heeft minder rigoureuze validatie nodig dan een patiëntveilig systeem.

## Valkuilen

- **Een tool verkeerd classificeren om aan lagere bewijsvereisten te voldoen.**
- **Bewijsvereisten niet herzien wanneer de functionaliteit van een product verandert.**
