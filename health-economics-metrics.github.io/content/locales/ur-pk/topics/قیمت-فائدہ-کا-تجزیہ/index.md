# قیمت-فائدہ کا تجزیہ (CBA)

CBA قیمت *اور* نتیجہ دونوں کی قدر پیسے میں لگاتا ہے۔ یہ واحد تجزیاتی قسم ہے جو "کیا یہ کرنے کے قابل ہے؟" کا جواب دے سکتی ہے۔

## یہ کیوں اہم ہے

CBA برطانیہ کے HM Treasury **گرین بک** کا معیار ہے تمام سرکاری اخراجات کی تشخیص کے لیے۔

## ریاضی

```
NPV = Σ_t [ (فائدہ_t − قیمت_t) / (1 + r)^t ]
```

## حل شدہ مثال

ایک ای-حوالگی نظام، 5 سالہ افق: NPV = +£2,547k، BCR = 2.0۔

## سافٹ ویئر انجینئرنگ سے تعلق

**معیاری امیدپرستانہ تعصب کے طور پر** — انجینئرز اتنی ہی قابل اعتماد طریقے سے منتقلی کی قیمت کو کم سمجھتے ہیں۔

## عام غلطیاں

- **فوائد بڑھانے کے لیے غیر-تشخیص کے قابل کی تشخیص کرنا۔**
