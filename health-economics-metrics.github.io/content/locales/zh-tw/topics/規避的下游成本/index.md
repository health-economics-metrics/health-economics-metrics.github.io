# 規避的下游成本

規避的下游成本（成本衝抵）是指因更早或更好的介入行動而得以避免的未來治療支出，需與介入措施自身的成本相抵。衝抵是介入措施得以成為*佔優方案*——既更便宜**又**更有效——的機制所在，同時也是健康經濟學中最容易被重複計算、最容易被過度主張的一條效益線。

## 為何重要

幾乎每一個數位健康價值主張中都包含某種衝抵主張："我們的應用能預防住院"、"我們的預警能防止病情惡化"、"我們的平臺能避免重複檢查"。當衝抵確實真實存在時，它能徹底改變整個經濟學結論（參見[ICER](../增量成本效果比/)的實例演算，其中£600,000的衝抵扭轉了整個論證）。支付方深知這一點——因此衝抵主張在任何評審中都會受到最嚴格的審查。以下這些可信度規則，正是區分"可獲資助的模型"與"行銷話術"的分水嶺。

## 計算方法

```
淨成本 = 介入成本 − Σ衝抵項

一項有效的衝抵必須滿足：
  可歸因性 —— 與該介入措施存在因果關聯（有對照組證據支撐）
  邊際性  —— 那筆錢真的不再被花出去了，且是按邊際成本
             而非平均成本計算（參見marginal-vs-average-cost.md）
  機率加權 —— 按"該下游事件本會發生"的機率加權
  已貼現  —— 未來規避的成本需折算為現值
  唯一性  —— 只在一條效益線中計入一次
```

## 實例演算

"一個做對了的遷移風險主張"：某傷口監測應用面向5,000名術後病患，主張能避免因感染導致的再入院。

```
基線感染再入院率：4.0%；使用該應用後（隨機對照試驗資料）：3.1%
可歸因避免事件數 = 5,000 × 0.009 = 每年45例
每次再入院療程的邊際成本（該信託機構口徑）：£3,200
衝抵額 = 45 × 3,200 = 每年£144,000
應用成本 = 5,000 × £20 = 每年£100,000
淨成本 = −£44,000 → 真正意義上的成本節約，且同時滿足：
  來自隨機對照試驗的歸因 ✓  邊際成本核算 ✓  基於試驗資料的機率 ✓
```

同樣的主張，若建立在"再入院平均花費£5,800，我們能防止一大堆"這種說法之上，則四項檢驗全部不透過，理應遭到拒絕。

## 與軟體工程的聯絡

"這次遷移能避免未來的重寫"本身就是一種衝抵主張，而健康經濟學的這些規則能讓它變得誠實可信：

- **反事實成本**：那次重寫實際上會花多少錢？有何證據支撐？
- **機率**：那個未來場景發生的可能性有多大？（並非100%——產品會被砍掉，優先順序會改變。）
- **貼現**：以3.5%–10%的貼現率計算，第4年才規避的一次重寫，其價值遠低於其面值。
- **唯一性**：不要在技術債務線和留存率線中，重複主張同一次被規避的重寫。

`衝抵價值 = P(未來事件發生) × 反事實成本 × 貼現因子`——在提案中寫下這一行，你會看到這個估算立刻變得可以被質疑與討論，而這正是其意義所在。

## 陷阱

- **重複計算**——同一次被避免的入院，同時被計為衝抵、床位天數、以及附帶成本的QALY。
- **對那些固定成本無論如何都會持續發生的事件，使用平均成本計算衝抵**。
- **對僅僅"有可能"發生的下游事件，悄悄按100%機率計算**。
- **將轉嫁給其他預算的衝抵，包裝成向正被要求付費的支付方展示的"節省"**——參見[分析視角](../分析視角/)。
