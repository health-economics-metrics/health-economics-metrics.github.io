# GDS सेवा मीट्रिक्स

यूके की Government Digital Service (GDS) सर्विस मैनुअल हर सरकारी डिजिटल सेवा के लिए चार KPI अनिवार्य करती है: प्रति लेनदेन लागत, उपयोगकर्ता संतुष्टि, पूर्णता दर, और डिजिटल अपनाना।

## यह क्यों महत्वपूर्ण है

GDS मीट्रिक्स उस चैनल-शिफ्ट व्यावसायिक मामले को एन्कोड करते हैं जिसने सरकारी डिजिटलीकरण के एक दशक को वित्तपोषित किया।

## गणित

```
प्रति लेनदेन लागत = कुल सेवा लागत / पूर्ण लेनदेन
```

## हल किया गया उदाहरण

एक NHS अपॉइंटमेंट-प्रबंधन सेवा: सालाना 20 लाख लेनदेन, वर्तमान में 70% फोन:

```
अपनाने की शिफ्ट बचत = सालाना £1,475,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

ये चार KPI एक उत्पादन-ग्रेड [लागत-परिणाम तालिका](../cost-consequence-analysis/) उदाहरण हैं।
