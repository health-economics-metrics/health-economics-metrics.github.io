# 統計的生命価値(VSL)

統計的生命価値(VSL)は、英国では「予防された死亡の価値」(VPF)と呼ばれ、1件の統計的な死のリスクを下げるために*集団*が全体として支払ってもよいと考える金額で、賃金とリスクのトレードオフ研究(より危険な仕事に労働者がどれだけ追加の賃金を求めるか)や表明選好調査から導かれます。特定の個人の命の価格ではなく、集団のリスクの構成概念であり、リスクを低減するシステム(トリアージアルゴリズム、救急搬送の手配、安全監視)を構築するソフトウェアエンジニアは、それが[支払意思額の閾値](../willingness-to-pay-thresholds/)とは異なる理論的伝統から来ていることを知っておく必要があります。

## なぜ重要か

VSL/VPFは、規制上の費用便益分析で死亡リスクの低減を金銭換算するための標準的なツールです。交通安全、環境規制、一部の公衆衛生介入は、いずれもこれを通じてビジネスケースを作ります。HM Treasuryのグリーンブックは、英国の労働市場と調査の証拠から導いたVPFの数値を公表しており、運輸省は道路安全の評価でそれを直接使っています。これはQALY × 支払意思額の閾値という方法論とは、本当に異なる評価の伝統です。閾値アプローチは、保健*予算*が現在限界で生み出すものに対して健康の向上を評価するのに対し、VSL/VPFは、労働市場や調査で人々がそれに対して支払うと明らかにしたものに対して、リスク低減を評価します。この2つの枠組みは常に調和できるとは限らず、それを認めずに同じケースで両方を使うことは、よくある分析上の誤りです。

## 数式

```
回避された死亡 = 人口 × 1人あたりのリスク低減
  (1人あたりのリスク低減は確率で、たとえば0.000001 =
   年間死亡リスクが100万分の1低下)

金銭換算した死亡の便益 = 回避された死亡 × 予防された死亡の価値
```

## 計算例

人口80万人の地域が、道路安全のためのデジタルな配車/トリアージ介入の恩恵を受け、1人ひとりの年間死亡リスクが100万分の1(0.000001)下がります。

```
回避された死亡 = 800,000 × 0.000001 = 0.8
```

英国の予防された死亡の価値£2,180,000(HM Treasury/DfTの数値、2023/24年価格。グリーンブックは毎年更新するため、実際の分析で引用する前に再確認してください)を使います。

```
金銭換算した死亡の便益 = 0.8 × £2,180,000 = £1,744,000/年
```

年間約£175万弱の金銭換算した死亡の便益で、影響を受ける人口の大半は個人としては決して気づかないようなリスク低減から生じます。

## ソフトウェア工学との関連

安全性が重要なソフトウェアのチーム(医療機器のファームウェア、自動運転車のソフトウェア、産業用制御システム)は、安全投資の費用便益ケースを構築するときに、まさにこの価格づけの問題に直面します。障害がまれで、深刻で、多数のユーザーに分散しているとき、「1件の壊滅的な障害を防ぐ」ことをどう価格づけるのか。VSL/VPFは、まれで深刻な集団レベルのリスク低減に数値を付けるための、数十年の歴史を持つ、公に文書化された実世界の先例です。まれな壊滅的な停止に対してSRE投資を価格づけするのと同じ形の議論で、ダウンタイムの成果の代わりに死亡の成果を用いているだけです。

## 落とし穴

- **VSLを「特定された命の価格」として扱うこと**: そうではありません。VSL/VPFは、多くの人々にわたるリスク低減のトレードオフから導かれた、集団の統計的な構成概念であり、特定の人物の生死の評価ではありません。
- **QALYに基づく正味金銭的便益の計算との二重計上**: VSL/VPFの数値と、別のQALY × 閾値の計算を、調整せずに同じケースで使うと、同じ回避された死亡の価値を黙って二重に数えます。1つのケースにつき1つの枠組みを選んでください。
- **調整なしに文脈をまたいでVSLの推定値を移植すること**: 1国の労働市場や、就労年齢の賃金-リスクデータから導かれたVSLを、調整なしに、異なる所得の文脈や異なる集団(子ども、退職者)に適用することは、長年にわたり本当に争われている方法論上の問題であり、解決済みではありません。
