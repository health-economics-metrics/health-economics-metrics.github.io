# Ravisoostumus ja püsivus

Ravisoostumus mõõdab, kas patsiendid järgivad ettenähtud ravirežiimi vastavalt juhistele, samas kui püsivus mõõdab, kui kaua nad jätkavad ravi üldse.

## Miks see on oluline

Isegi tõhusaim sekkumine ei anna kasu, kui patsiendid ei järgi seda piisavalt kaua või piisavalt täpselt — ravisoostumus on kriitiline eeltingimus kliinilise tõhususe jaoks.

## Matemaatika

```
Ravisoostumuse määr = Tegelikult võetud annuste arv / Ettenähtud annuste koguarv × 100%
```

## Lahendatud näide

Krooniliste haiguste ravimil on kliinilistes katsetes näidatud 70% riski vähenemist, kuid reaalses maailmas, kus ravisoostumus on ainult 50%, on tegelik populatsioonitasandi mõju oluliselt väiksem kui katsetes näidatu.

## Seos tarkvaraarendusega

Sarnaneb funktsioonide kasutuselevõtu jälgimisega pärast esialgset aktiveerimist — kas kasutajad jätkavad soovitatud kasutusmustri järgimist aja jooksul.

## Lõksud

- **Kliiniliste katsete tõhususe eeldamine reaalse maailma populatsioonidele ilma ravisoostumust arvestamata.**
- **Ravisoostumuse ja püsivuse segiajamine — patsient võib olla püsiv, kuid mitteravisoostuv.**
