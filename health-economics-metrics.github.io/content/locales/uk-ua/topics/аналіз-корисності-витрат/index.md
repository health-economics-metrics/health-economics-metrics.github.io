# Аналіз корисності витрат (CUA)

Аналіз корисності витрат порівнює втручання за вартістю на QALY, роблячи повністю непорівнянні методи лікування порівнюваними за однією шкалою.

## Чому це важливо

CUA — стандартний метод NICE та більшості органів HTA, оскільки він може порівняти ліки від серця з втручанням для психічного здоров'я.

## Математика

```
Коефіцієнт CUA (ICER) = (Витрати_A − Витрати_B) / (QALY_A − QALY_B)
```

## Розібраний приклад

Нові ліки від ревматизму коштують на £8000 більше та дають на 0,4 QALY більше порівняно зі стандартним лікуванням: £20 000/QALY.

## Зв'язок з інженерією програмного забезпечення

Подібно до нормалізації вартості на одиницю користувацької цінності для повністю різних типів функцій.

## Підводні камені

- **Використання вагових коефіцієнтів корисності, не валідованих для відповідної популяції.**
- **Змішування результатів CUA та CEA без вказівки одиниці.**
