# قیمت کم سے کم کرنے کا تجزیہ (CMA)

CMA صرف قیمتوں کا موازنہ کرتا ہے، اور سستا ترین آپشن چنتا ہے — یہ صرف اس وقت درست ہے جب آپشنز کے نتائج برابر ثابت ہوں۔

## یہ کیوں اہم ہے

CMA سب سے آسان تجزیہ ہے اور سب سے زیادہ غلط استعمال ہونے والا۔

## ریاضی

```
ثبوت ہو کہ اثر_A ≈ اثر_B: min(قیمت_A, قیمت_B) چنیں
```

## حل شدہ مثال

ایک ٹرسٹ دو ویڈیو-مشاورت پلیٹ فارمز کے درمیان انتخاب کرتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

CMA کموڈٹی خریداری کی رسمی شکل ہے۔
