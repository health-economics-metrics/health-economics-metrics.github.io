# पुनः प्रवेश दर

30-दिन पुनः प्रवेश दर छुट्टी दिए गए रोगियों का वह प्रतिशत है जो 30 दिनों के भीतर आपातकालीन रूप से वापस आते हैं। यह स्वास्थ्य प्रणाली का प्रामाणिक *छुट्टी-गुणवत्ता* मीट्रिक है।

## यह क्यों महत्वपूर्ण है

एक पुनः प्रवेश का मतलब है कि पहली छुट्टी टिकी नहीं। भुगतानकर्ता इसे स्पष्ट रूप से दंडित करते हैं — US Hospital Readmissions Reduction Program एक अस्पताल के मेडिकेयर भुगतान का 3% तक काटता है।

## गणित

```
पुनः प्रवेश दर = 30 दिनों के भीतर आपातकालीन पुनः प्रवेश / सूचकांक छुट्टियाँ × 100
```

## हल किया गया उदाहरण

एक हृदय-विफलता छुट्टी-सहायता ऐप: सालाना 2,000 छुट्टियाँ, आधाररेखा पुनः प्रवेश दर 18%, ऐप के साथ ट्रायल 14% दिखाता है।

```
बचाए गए पुनः प्रवेश = 2,000 × (0.18 − 0.14) = सालाना 80
शुद्ध ≈ सालाना +£160,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

पुनः प्रवेश स्वास्थ्य प्रणाली की **परिवर्तन विफलता दर** है ([DORA मीट्रिक्स](../dora-metrics/) देखें)।
