# Cyfrowe punkty końcowe i biomarkery

Cyfrowe punkty końcowe i biomarkery to obiektywne, kwantyfikowalne pomiary zdrowia zbierane za pomocą czujników, urządzeń do noszenia lub narzędzi cyfrowych.

## Dlaczego to ważne

Cyfrowe biomarkery dostarczają ciągłych, obiektywnych danych, które wypełniają lukę między tradycyjnymi wizytami klinicznymi.

## Matematyka

```
Ważność cyfrowego punktu końcowego = współczynnik korelacji(pomiar cyfrowy, zwalidowany standard kliniczny)
```
