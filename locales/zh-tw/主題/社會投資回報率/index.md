# 社會投資回報率（SROI）

SROI將[ROI](../投資回報率/)的概念延伸至市場無法定價的結果——幸福感、社會聯結、環境影響——透過為所有受影響的利益相關方，以財務代理指標為這些結果貨幣化。

## 為何重要

健康與社群介入所產生的許多結果，從未真正觸及任何一條預算科目：孤獨感的減輕、照護者的喘息、就業機會的增加、尊嚴感。SROI遵循"社會價值國際組織"的七項原則（讓利益相關方參與、為真正重要的事物定價、不過度主張、保持透明、可驗證……），能產出諸如"每投入£1，可產生£3.20社會價值"這樣的表述。英國公共採購中的社會價值要求，使SROI式的證據具有商業相關性：競標公共合同（包括NHS合同）時，能證明社會價值的投標方可獲得加分。

## 計算方法

```
SROI比率 = 已貨幣化社會結果的現值 / 投資的現值

對每一項結果：
  價值 = 數量 × 財務代理指標 × 歸因比例 × (1 − 無謂效應) × (1 − 替代效應)

無謂效應   = 即便沒有該專案，這件事本來也會發生
歸因比例   = 由其他因素/機構造成的部分應被排除
替代效應   = 效益只是從別處轉移而來，而非真正被創造出來的
衰減率     = 該結果隨年份推移而衰減的程度
```

這些調整因子正是這套方法公信力的核心所在：沒有它們，SROI不過是印著貨幣符號的虛構故事。

## 實例演算

某陪伴應用，將孤立的老年人與志願者連線起來；專案年成本£200,000；1,500對活躍配對。

```
結果：為1,500人減輕孤獨感
  代理指標：孤獨感緩解的幸福感估值 ≈ 每人每年£1,800
  無謂效應25%（部分人本來也會自行找到社交連線）
  歸因比例80%（部分功勞應歸於其他服務）

價值 = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

結果：全科醫師就診次數減少，1,500 × 1.2次就診 × £42 = £75,600（這部分對支付方而言是真實的）

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

請注意，這一比率中96%是按代理指標估值的幸福感，只有4%是真實硬現金。這是合乎規範的SROI——但它必須以"社會價值"的名義呈現，絕不能暗示£170萬可以直接兌現入賬。

## 與軟體工程的聯絡

對於那些受益方並非付費團隊本身的工程工作而言，SROI是一套誠實的框架：開源維護、無障礙改進、被其他團隊消費使用的平臺工作、開發者社群投資。可遷移的具體機制是：識別所有利益相關方、用明確宣告的代理指標進行貨幣化，並應用無謂效應/歸因折扣（那個開源修復本來是否也會發生？這項收益中有多少是你的工作貢獻，有多少來自整個生態系統？）。*對自身影響力主張進行折扣*這一紀律，正是SROI區別於一個純行銷數位的關鍵所在。

## 陷阱

- **代理指標購物**：挑選現有最慷慨的幸福感估值。
- **跳過無謂效應/歸因調整**——這是最常見的虛增手法，往往能使比率翻倍。
- **跨研究比較比率**：SROI比率對方法高度敏感；只應在一致的框架內進行比較。
- **向預算持有者將社會價值呈現為可兌現的節省**。
