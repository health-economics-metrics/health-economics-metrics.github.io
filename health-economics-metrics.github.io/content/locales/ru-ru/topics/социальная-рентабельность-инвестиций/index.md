# Социальная рентабельность инвестиций (Social Return on Investment, SROI)

SROI расширяет [ROI](../рентабельность-инвестиций/) на исходы, которые рынки не оценивают — благополучие, социальные связи, воздействие на окружающую среду — монетизируя их финансовыми прокси, для *всех* затронутых заинтересованных сторон.

## Почему это важно

Многое из того, что производят вмешательства здравоохранения и сообщества, никогда не касается бюджетной строки: снижение одиночества, облегчение для ухаживающих лиц, выигрыши в занятости, достоинство. SROI, регулируемый семью принципами Social Value International (вовлекайте заинтересованные стороны, оценивайте то, что важно, не завышайте заявления, будьте прозрачны, верифицируйте…), производит утверждения вроде «£3,20 социальной ценности на каждый вложенный £1». Требования социальной ценности в государственных закупках Великобритании делают доказательства в стиле SROI коммерчески значимыми: заявки на государственные контракты (включая NHS) получают баллы за продемонстрированную социальную ценность.

## Математика

```
Коэффициент SROI = PV(монетизированные социальные исходы) / PV(инвестиции)

Для каждого исхода:
  ценность = количество × финансовый прокси × атрибуция × (1 − мёртвый груз) × (1 − вытеснение)

мёртвый груз = произошло бы в любом случае
атрибуция    = доля, вызванная другими
вытеснение   = выгода, перемещённая откуда-то ещё, а не созданная
затухание    = убывание исхода с течением лет
```

Поправочные факторы — это то, что составляет целостность метода: без них SROI — это фикция со знаком валюты.

## Практический пример

Приложение-компаньон, соединяющее изолированных пожилых людей с волонтёрами; стоимость программы £200 000/год; 1 500 активных пар.

```
Исход: снижение одиночества для 1,500 человек
  прокси: оценка благополучия «облегчение от одиночества» ≈ £1,800/чел/год
  мёртвый груз 25% (некоторые нашли бы связь в любом случае)
  атрибуция 80% (часть заслуги принадлежит другим услугам)

Ценность = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

Исход: снижение визитов к врачу общей практики, 1,500 × 1.2 визита × £42 = £75,600 (реальные средства плательщика)

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

Обратите внимание, что коэффициент на 96% состоит из благополучия, оценённого через прокси, и на 4% из реальных денежных средств. Это легитимный SROI — но он должен быть представлен как социальная ценность, никогда не подразумевая, что £1,7 млн можно положить в кассу.

## Связь с разработкой программного обеспечения

SROI — честная рамка для инженерной работы, чьи бенефициары находятся вне оплачивающей команды: поддержка open-source, улучшения доступности, работа над платформой, потребляемая другими командами, инвестиции в сообщество разработчиков. Переносимая механика: определите всех заинтересованных сторон, монетизируйте с заявленными прокси, и примените скидки на мёртвый груз/атрибуцию (произошло бы это исправление OSS в любом случае? какая доля выигрыша принадлежит вашей работе, а не экосистеме?). Дисциплина *дисконтирования собственных заявлений о воздействии* — это то, что отличает SROI от маркетинговой цифры.

## Подводные камни

- **Шопинг по прокси**: выбор самой щедрой из доступных оценок благополучия.
- **Пропуск мёртвого груза/атрибуции** — самое частое раздувание, часто удваивающее коэффициент.
- **Сравнение коэффициентов между исследованиями**: коэффициенты SROI чувствительны к методу; сравнивайте только внутри согласованной рамки.
- **Представление социальной ценности как обналичиваемой экономии** держателю бюджета.
