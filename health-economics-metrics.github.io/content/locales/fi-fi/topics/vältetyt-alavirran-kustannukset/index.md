# Vältetyt alavirran kustannukset

Vältetyt alavirran kustannukset ovat kustannuskompensaatioita, jotka syntyvät myöhempien, kalliimpien terveystapahtumien estämisestä, ja säännöt, jotka tekevät näistä väitteistä uskottavia.

## Miksi se on tärkeä

Alavirran kustannusväitteitä on helppo liioitella; uskottavat väitteet vaativat selkeitä oletuksia kausaalisuudesta, aikahorisontista ja vastafaktuaalisista skenaarioista.

## Matematiikka

```
Vältetyt kustannukset = (Perustason tapahtumaosuus − tapahtumaosuus interventiolla) × kustannus per tapahtuma × väestö
```

## Ratkaistu esimerkki

Sydämen vajaatoiminnan varhaisen havaitsemisen ohjelma vähentää sisäänottoja 3 prosenttiyksiköllä 5 000 hengen väestössä: 150 vältettyä sisäänottoa × £4 000/sisäänotto = £600 000 vältettyjä kustannuksia.

## Yhteys ohjelmistokehitykseen

Muistuttaa "vältettyjen häiriökustannusten" väittämistä ennakoivan valvonnan avulla — uskottava vain selkeällä perustasolla ja kausaalisella mekanismilla.

## Sudenkuopat

- **Vältettyjen kustannusten väittäminen ilman pätevää vastafaktuaalista perustasoa.**
- **Regressoinnin keskiarvoon sekoittaminen todelliseen interventiovaikutukseen.**
