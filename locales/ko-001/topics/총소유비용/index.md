# 총소유비용(TCO)

TCO는 소프트웨어 시스템의 전체 수명 동안 발생하는 모든 비용입니다: 구축, 실행, 유지보수, 그리고 폐기.

## 왜 중요한가

초기 구축 비용만 보면 운영 비용의 그림자를 놓칩니다.

## 수식

```
TCO = 자본 지출 + Σ(운영 비용_연도별) − 잔존 가치
```

## 계산 예시

5년 수명의 임상 시스템: 구축 £500,000 + 운영 £150,000/년 × 5 = £1,250,000.

## 소프트웨어 공학과의 연관성

TCO는 [클라우드 단위 경제학](../클라우드-단위-경제학/)과 [빌드 대 구매](../빌드-대-구매/) 결정의 기초입니다. 위와 같은 다년간의 TCO 수치는 시간에 걸친 많은 비용 항목의 합입니다. 모델이 센트 단위까지 맞아야 할 때 그 합이 왜 부동소수점이 아닌 정확한 십진이어야 하는지는 [통화 안전 비용 집계](../통화-안전-비용-집계/)를, TCO 총액을 센트를 잃지 않고 비용 센터에 나누는 방법은 [센트 단위 정확한 비용 배분](../센트-단위-정확한-비용-배분/)을 참고하세요.
