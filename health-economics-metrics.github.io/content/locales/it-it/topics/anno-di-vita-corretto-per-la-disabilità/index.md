# Anno di Vita Corretto per la Disabilità (DALY)

Un DALY è un anno di vita sana perduto — lo specchio dal lato del carico del [QALY](../anno-di-vita-corretto-per-la-qualità/).

## Perché è importante

Il DALY è lo standard della salute globale.

## La matematica

```
DALY = YLL + YLD
```

## Esempio risolto

Una piattaforma di screening e promemoria risparmia 240 DALY all'anno.

## Collegamento con l'ingegneria del software

Il DALY è anche un modello utile di *inventario del carico* per l'ingegneria.

## Insidie

- **QALY guadagnati ≠ DALY evitati numericamente.**
