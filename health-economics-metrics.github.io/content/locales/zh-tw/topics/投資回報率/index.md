# 投資回報率（ROI）

ROI是淨收益與投入資金之比。它是工程與財務領域早已共用的指標——健康經濟學在此基礎上增添的紀律，能讓一項ROI主張經受住審查：明確宣告的視角、對照方案、時間範圍，以及效益分類。

## 為何重要

ROI是預算持有者的通用語言，公共衛生領域同樣使用它：Masters等人具有里程碑意義的綜述發現，公共衛生介入措施的**ROI中位數為14.3:1**（每£1能為更廣泛的經濟與衛生系統帶來約£14的回報）——這一數位被廣泛用於論證預防性支出的正當性。但那個14:1，是一個*社會層面、長時間範圍*的數位；而一位醫院CFO所關心的ROI，是支付方視角下1–3年的數位。大多數關於ROI的爭論，其實都是未宣告視角之爭。

## 計算方法

```
ROI = (效益 − 成本) / 成本      （通常 × 100%表示）

回本週期 = 成本 / 年度淨效益
```

一項ROI主張，若缺少以下四項宣告，就是界定不完整的：

1. **視角**——誰的效益才算數？（參見[分析視角](../分析視角/)）
2. **對照方案**——相對於哪個替代方案？（參見[機會成本](../機會成本/)）
3. **時間範圍**——覆蓋多長時間，是否經過[貼現](../貼現與時間偏好/)？
4. **效益類別**——現金釋放型、產能型，還是定性效益？（參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)）

## 實例演算

某電子排班系統，3年期成本£500,000。

```
現金釋放型：  中介班次減少              £450,000
產能：       病區經理行政時間被釋放     £600,000（已估值，但未真正入賬）
定性效益：    員工滿意度、安全性        未貨幣化

嚴格財務ROI  = (450,000 − 500,000)/500,000 = −10%
經濟學ROI    = (1,050,000 − 500,000)/500,000 = +110%
```

兩個數位都是真實的。向一位只能入賬£450,000現金的CFO宣稱"+110%的ROI"，會失去信任；同時呈現二者、並分別標註清楚，才能贏得信任。同樣的拆分，也能在兩年後財務部門審計這些效益時，保護住內部的推動者。

## 與軟體工程的聯絡

每一份工具提案都有一張ROI幻燈片；卻幾乎沒有一份宣告瞭這四個引數。最常見的失敗，是類別混用：把產能收益（開發者節省的分鐘數）包裝成財務回報呈現。應像上文實例演算那樣結構化地呈現AI/平臺的ROI——現金線、產能線、定性效益線——並對那些軟性數位附加[敏感性分析](../敏感性分析/)。關於AI投資回報率具體的損益表現實檢驗，參見[AI投資回報率](../AI投資回報率/)。

## 陷阱

- **視角洗白**：把跨越十年的社會層面效益，說給一位時間範圍只有12個月的預算持有者聽。
- **用毛值代替淨值**："在£200萬支出上帶來£300萬回報"，那是50%的ROI，而不是300%。
- **比值最大化**：微小的分母能在無關緊要的投資上產生驚人的ROI數位；投資組合應按淨現值或[淨貨幣效益](../淨貨幣效益/)排序，ROI只應作為初篩工具。
- **沒有效益審計**：預測的ROI若沒有[效益兌現](../效益兌現/)追蹤，只是一個承諾，而非一個結果。
