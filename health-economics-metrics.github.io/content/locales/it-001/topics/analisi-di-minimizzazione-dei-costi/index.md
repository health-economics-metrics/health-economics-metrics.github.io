# Analisi di Minimizzazione dei Costi (CMA)

La CMA confronta solo i costi e sceglie l'opzione più economica — è valida solo quando i risultati delle alternative sono dimostrati equivalenti.

## Perché è importante

La CMA è l'analisi più semplice e la più abusata.

## La matematica

```
Se dimostrato che Effetto_A ≈ Effetto_B: scegli min(Costo_A, Costo_B)
```

## Esempio risolto

Un trust sceglie tra due piattaforme di videoconsulto.

## Collegamento con l'ingegneria del software

La CMA è la forma formale dell'approvvigionamento di beni commodity.
