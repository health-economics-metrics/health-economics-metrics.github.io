# Kaasatuse näitajad

Kaasatuse näitajad mõõdavad, kui aktiivselt kasutajad digitervise toodet kasutavad — sagedus, kestus ja sügavus —, mis on sageli eeltingimus tervisetulemuste saavutamiseks.

## Miks see on oluline

Digitervise sekkumine ei saa toota tervisekasu, kui patsiendid seda ei kasuta; kaasatus on vahenäitaja, mis ennustab lõplikke kliinilisi tulemusi.

## Matemaatika

```
Kaasatuse määr = Aktiivsete kasutajate arv / Registreerunud kasutajate koguarv × 100%
```

## Lahendatud näide

Krooniliste haiguste juhtimise rakendus 10 000 registreeritud kasutajaga ja 3000 igakuiselt aktiivse kasutajaga annab kaasatuse määraks 30%, mis viitab olulisele kasutuselt loobumisele.

## Seos tarkvaraarendusega

Otseselt analoogne toote kaasatuse näitajatele (DAU/MAU) tarkvaratoodetes laiemalt.

## Lõksud

- **Kaasatuse segiajamine tervisetulemustega ilma põhjuslikkust tõendamata.**
- **Pindmiste kaasatuse näitajate (avamiste arv) kasutamine ilma sisulist kasutust mõõtmata.**
