# 질보정 생존연수(QALY)

QALY는 완전한 건강 상태에서 산 1년입니다. 사람들이 *얼마나 오래* 사는지와 *얼마나 잘* 사는지를 결합하여, 나쁜 건강 상태의 1년이 1 QALY 미만으로 계산되도록 합니다.

## 왜 중요한가

QALY는 보건기술평가의 공통 통화입니다. NICE(잉글랜드)는 건강 이득을 **QALY당 £20,000–£30,000**로 평가합니다.

## 수식

```
QALY = Σ_i (기간_i × 효용_i)
```

## 계산 예시

환자가 효용 0.6 상태로 심장 치료를 기다립니다. 치료는 그들을 효용 0.85로 회복시킵니다. 6개월 지연으로 인한 환자당 QALY 손실은 0.125 QALY입니다.

## 소프트웨어 공학과의 연관성

**더 빠른 경로 = 더 빠른 QALY.**
