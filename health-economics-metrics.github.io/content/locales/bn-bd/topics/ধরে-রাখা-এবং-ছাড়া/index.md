# ধরে রাখা এবং ছাড়া

ধরে রাখা পরিমাপ করে একটি ব্যবহারকারী কোহোর্টের কত ভগ্নাংশ শুরুর N দিন পরেও সক্রিয় থাকে; ছাড়া তার পরিপূরক। নির্মম ডিজিটাল-স্বাস্থ্য বেসলাইন: **প্রায় ৯০% স্বাস্থ্য-অ্যাপ ব্যবহারকারী ৩০ দিনের মধ্যে ছেড়ে যায়**।

## কেন এটি গুরুত্বপূর্ণ

Eysenbach ২০০৫ সালে এর নাম দিয়েছেন: **ক্ষয়ের নিয়ম** — উচ্চ হারে ব্যবহারকারী হারানো eHealth হস্তক্ষেপের একটি অন্তর্নিহিত, কাঠামোগত বৈশিষ্ট্য।

## গণিত

```
ধরে_রাখা_Dn = n দিনে সক্রিয় ব্যবহারকারী / কোহোর্ট আকার × 100

সুবিধা ওজন (স্বাস্থ্য-অর্থনীতির পদক্ষেপ):
  প্রতি অর্জিত ব্যবহারকারী প্রত্যাশিত সুবিধা = Σ_t ধরে_রাখা(t) × সুবিধা_হার(t)
```

## সমাধানকৃত উদাহরণ

একটি মানসিক-স্বাস্থ্য অ্যাপ: ট্রায়াল ৮ সপ্তাহ সম্পূর্ণকারী প্রতি ব্যবহারকারী ০.০২ QALY লাভ দেখিয়েছে। স্থাপনা কোহোর্ট ১০০,০০০ ডাউনলোড, ধরে-রাখা D7 25%, D30 8%, সপ্তাহ-8 4%:

```
সম্পূর্ণকারী = 100,000 × 0.04 = 4,000
প্রদত্ত QALY = 4,000 × 0.02 = 80 (100,000 × 0.02 = 2,000 নয়)
প্রতি-ডাউনলোড স্বাস্থ্য মূল্য = £16
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

ধরে রাখা সেই সূচক যেখানে পণ্য প্রকৌশল সবচেয়ে সরাসরি স্বাস্থ্য মূল্য উৎপাদন করে।

## ঝুঁকিপূর্ণ দিক

- **বিপরীতে Intention-to-treat লন্ডারিং**: ট্রায়াল সম্পূর্ণকারী রিপোর্ট করে; স্থাপনা অর্থনীতিতে অর্জিত সবাইকে গণনা করতে হবে।
- **ধরে-রাখার থিয়েটার**: নোটিফিকেশন-চালিত "সক্রিয়" ব্যবহারকারী যারা কখনো থেরাপিউটিক কাজ করে না।
