# มูลค่าของชีวิตทางสถิติ (VSL)

มูลค่าของชีวิตทางสถิติ (VSL) — ในการใช้ของสหราชอาณาจักรเรียกว่า "มูลค่าของการป้องกันการเสียชีวิต" (VPF) — คือจำนวนเงินที่ *ประชากร* โดยรวมเต็มใจจ่ายเพื่อลดความเสี่ยงของการเสียชีวิตทางสถิติหนึ่งราย ได้มาจากการศึกษาการแลกเปลี่ยนค่าจ้าง-ความเสี่ยง (ค่าจ้างที่เพิ่มขึ้นซึ่งคนงานเรียกร้องเพื่อทำงานอันตรายกว่า) และการสำรวจความชอบที่แถลง ไม่ใช่ราคาของชีวิตบุคคลที่ระบุตัวได้ แต่เป็นโครงสร้างความเสี่ยงระดับประชากร และวิศวกรซอฟต์แวร์ที่สร้างระบบลดความเสี่ยง — อัลกอริทึมคัดแยก การจัดส่งรถพยาบาล การเฝ้าระวังความปลอดภัย — ควรรู้ว่ามันมาจากประเพณีทางทฤษฎีที่ต่างจาก[เกณฑ์ความเต็มใจจ่าย](../เกณฑ์ความเต็มใจจ่าย/)

## ทำไมจึงสำคัญ

VSL/VPF เป็นเครื่องมือมาตรฐานในการแปลงการลดความเสี่ยงการเสียชีวิตเป็นตัวเงินในการวิเคราะห์ต้นทุนผลประโยชน์เชิงกำกับดูแล: ความปลอดภัยการขนส่ง กฎระเบียบสิ่งแวดล้อม และมาตรการสาธารณสุขบางอย่างสร้างกรณีธุรกิจผ่านมัน Green Book ของ HM Treasury เผยแพร่ตัวเลข VPF ที่ได้จากข้อมูลตลาดแรงงานและการสำรวจของสหราชอาณาจักร และกระทรวงคมนาคมใช้มันโดยตรงในการประเมินความปลอดภัยถนน นี่เป็นประเพณีการประเมินที่ต่างกันจริงจากระเบียบวิธี QALY × เกณฑ์ความเต็มใจจ่าย: แนวทางเกณฑ์ตีมูลค่าผลประโยชน์สุขภาพเทียบกับสิ่งที่ *งบประมาณสุขภาพ* ผลิตได้ที่ขอบในปัจจุบัน ขณะที่ VSL/VPF ตีมูลค่าการลดความเสี่ยงเทียบกับสิ่งที่ผู้คนเปิดเผยในตลาดแรงงานหรือการสำรวจว่าจะจ่าย สองกรอบนี้ไม่เสมอไปที่จะเข้ากันได้ และการใช้ทั้งสองในกรณีเดียวโดยไม่รับรู้เป็นข้อผิดพลาดการวิเคราะห์ที่พบบ่อย

## คณิตศาสตร์

```
การเสียชีวิตที่ป้องกันได้ = ประชากร × การลดความเสี่ยงต่อคน
  (การลดความเสี่ยงต่อคนเป็นความน่าจะเป็น เช่น 0.000001 =
   ลดลงหนึ่งในล้านของความเสี่ยงการเสียชีวิตรายปี)

ผลประโยชน์การเสียชีวิตที่แปลงเป็นเงิน = การเสียชีวิตที่ป้องกันได้ × มูลค่าของการป้องกันการเสียชีวิต
```

## ตัวอย่างที่คำนวณแล้ว

ภูมิภาคที่มีประชากร 800,000 คนได้ประโยชน์จากมาตรการจัดส่ง/คัดแยกดิจิทัลด้านความปลอดภัยถนน ซึ่งลดความเสี่ยงการเสียชีวิตรายปีของแต่ละคนลงหนึ่งในล้าน (0.000001):

```
การเสียชีวิตที่ป้องกันได้ = 800,000 × 0.000001 = 0.8
```

ด้วยมูลค่าของการป้องกันการเสียชีวิตของสหราชอาณาจักร £2,180,000 (ตัวเลขของ HM Treasury/DfT ราคาปี 2023/24 — Green Book ปรับปรุงทุกปี โปรดตรวจสอบก่อนอ้างอิงในการวิเคราะห์ที่ดำเนินอยู่):

```
ผลประโยชน์การเสียชีวิตที่แปลงเป็นเงิน = 0.8 × £2,180,000 = £1,744,000 ต่อปี
```

ผลประโยชน์การเสียชีวิตที่แปลงเป็นเงินเกือบ £1.75 ล้านต่อปี จากการลดความเสี่ยงที่ประชากรที่ได้รับผลกระทบส่วนใหญ่จะไม่เคยสังเกตเห็นเป็นรายบุคคล

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ทีมซอฟต์แวร์ที่เกี่ยวข้องกับความปลอดภัยสูง — เฟิร์มแวร์อุปกรณ์การแพทย์ ซอฟต์แวร์ยานยนต์ขับเคลื่อนอัตโนมัติ ระบบควบคุมอุตสาหกรรม — เผชิญปัญหาการตั้งราคาเดียวกันนี้เมื่อสร้างกรณีต้นทุนผลประโยชน์ของการลงทุนด้านความปลอดภัย: จะตั้งราคา "ป้องกันความล้มเหลวร้ายแรงหนึ่งครั้ง" อย่างไร เมื่อความล้มเหลวหายาก รุนแรง และกระจายในกลุ่มผู้ใช้ขนาดใหญ่ VSL/VPF เป็นบรรทัดฐานจริงที่เผยแพร่เปิดเผยมานานหลายทศวรรษในการใส่ตัวเลขให้กับการลดความเสี่ยงระดับประชากรที่หายากและรุนแรง — รูปแบบข้อโต้แย้งเดียวกับการตั้งราคาการลงทุน SRE เทียบกับการล่มร้ายแรงที่หายาก เพียงแต่ผลลัพธ์เป็นการเสียชีวิตแทนการหยุดทำงาน

## ข้อผิดพลาดที่พบบ่อย

- **ถือ VSL เป็น "ราคาของชีวิตที่ระบุตัวได้"**: มันไม่ใช่ VSL/VPF เป็นโครงสร้างประชากรทางสถิติที่ได้จากการแลกเปลี่ยนการลดความเสี่ยงของคนจำนวนมาก ไม่ใช่การประเมินชีวิตหรือความตายของบุคคลใดโดยเฉพาะ
- **นับซ้ำกับการคำนวณผลประโยชน์สุทธิทางการเงินแบบ QALY**: การใช้ตัวเลข VSL/VPF และการคำนวณ QALY × เกณฑ์แยกต่างหากในกรณีเดียวโดยไม่ปรับให้ตรงกัน นับมูลค่าของการเสียชีวิตที่ป้องกันได้เดียวกันสองครั้งอย่างเงียบๆ เลือกหนึ่งกรอบต่อหนึ่งกรณี
- **ย้ายค่าประมาณ VSL ข้ามบริบทโดยไม่ปรับ**: VSL ที่ได้จากตลาดแรงงานหรือข้อมูลค่าจ้าง-ความเสี่ยงของวัยทำงานในประเทศหนึ่ง ที่นำไปใช้กับบริบทรายได้อื่นหรือประชากรอื่น (เด็ก ผู้สูงอายุ) โดยไม่ปรับ เป็นคำถามเชิงระเบียบวิธีที่ยังโต้แย้งอยู่จริงและยาวนาน — ไม่ใช่เรื่องที่ยุติแล้ว
