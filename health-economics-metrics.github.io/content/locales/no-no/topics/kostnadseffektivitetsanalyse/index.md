# Kostnadseffektivitetsanalyse (CEA)

Kostnadseffektivitetsanalyse sammenligner intervensjoner basert på kostnad per naturlig utfallsenhet, som reddede liv eller unngåtte tilfeller.

## Hvorfor det er viktig

CEA lar beslutningstakere sammenligne intervensjoner uten å konvertere alt til pengeverdi, noe som er nyttig når pengeverdsettelse er kontroversiell.

## Matematikken

```
CEA-ratio = (Kostnad_A − Kostnad_B) / (Naturlige enheter_A − Naturlige enheter_B)
```

## Gjennomarbeidet eksempel

To screeningprogrammer sammenlignet på kostnad per oppdaget tilfelle: program A koster £50/screenet person og oppdager 1 av 200; program B koster £80 og oppdager 1 av 150.

## Kobling til programvareutvikling

Ligner på å sammenligne arkitekturer på kostnad per løst supportsak i stedet for en pengemessig ROI.

## Fallgruver

- **Å sammenligne intervensjoner med ulike naturlige enheter.**
- **Å bruke CEA når livskvalitet er det dominerende utfallet (bruk CUA i stedet).**
