# रोकथाम अर्थशास्त्र

रोग होने या बढ़ने से पहले हस्तक्षेप का अर्थशास्त्र। मुख्य खोज सहज बोध के विपरीत है: **अधिकांश रोकथाम पैसे नहीं बचाती** — यह एक अच्छी कीमत पर स्वास्थ्य खरीदती है।

## यह क्यों महत्वपूर्ण है

"रोकथाम पैसे बचाती है" स्वास्थ्य नीति में सबसे अधिक दोहराया जाने वाला झूठा दावा है।

## गणित

```
रोकथाम की शुद्ध लागत (प्रति व्यक्ति) =
    हस्तक्षेप लागत × सभी इलाज किए गए
  − टाली गई डाउनस्ट्रीम लागत × जो प्रगति करते
```

## हल किया गया उदाहरण

100,000 जोखिम वाले वयस्कों के लिए एक उच्च-रक्तचाप-प्रबंधन ऐप, £25/व्यक्ति/वर्ष।

```
शुद्ध लागत ≈ £2.8M — बचत नहीं
प्रति QALY लागत ≈ £2,300/QALY — असाधारण रूप से लागत-प्रभावी
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

शिफ्ट-लेफ्ट गुणवत्ता, चेतावनी के साथ, रोकथाम अर्थशास्त्र है।

## सामान्य गलतियाँ

- **साक्ष्य लागत-प्रभावशीलता का समर्थन करने पर लागत बचत का दावा करना।**
