# Nationell taxa och enhetskostnader

Nationell taxa och enhetskostnader är standardiserade priser som hälso- och sjukvården betalar för specifika behandlingar eller procedurer, publicerade av centrala kostnadsmyndigheter.

## Varför det är viktigt

Dessa publicerade taxor ger ingenjörer och analytiker en pålitlig källa för att värdera klinisk aktivitet utan improviserade kostnadsuppskattningar.

## Matematiken

```
Totalt taxavärde = Σ (aktivitetsvolym per HRG-kod × taxa per HRG-kod)
```

## Genomarbetat exempel

En vårdväg med 1 000 patienter som behandlas under en HRG-kod med en taxa på £850: totalt taxavärde = £850 000 för kostnadsjämförelseändamål.

## Koppling till mjukvaruutveckling

Liknar standardiserade molnprislistor som ger enhetliga enhetskostnader istället för att varje team gör egna uppskattningar.

## Fallgropar

- **Att använda taxor som faktiska kostnader istället för genomsnittliga referensvärden.**
- **Att använda föråldrad taxadata från ett tidigare räkenskapsår.**

## Källor

- NHS England, national tariff payment system.
- NHS Improvement, reference costs collection.
