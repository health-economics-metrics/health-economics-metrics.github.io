# 治療必要数(NNT)

NNTとは、指定された期間にわたって、**1人**の追加患者が便益を得るために介入を受けなければならない患者数のことです。これは、誤解を招くパーセンテージのリスク削減を、誰もが検討できる努力対便益の単位に変換します。

## なぜ重要か

「心臓発作を25%削減!」は決定的に聞こえます。ベースラインのリスクが5年間で4%なら、絶対的な削減は1パーセントポイントであり、したがって**1人が便益を得るために100人が5年間その薬を服用しなければならず**、100人全員が費用と副作用を負担します。NNTは相対リスクのマーケティングに対する解毒剤であり、これがエビデンスに基づく医療がこれを先頭に立てる理由です。一次予防のためのスタチン:防がれた心臓発作1件あたり5年間でNNT≈50〜100。その鏡像である**NNH**(害必要数)は、1人が害を受けるまでに何人が治療を受けるかを数えます。

## 数式

```
ARR = 対照群のイベント率 − 治療群のイベント率   (絶対リスク減少)
NNT = 1 / ARR

NNH = 1 / (治療群の害の率 − 対照群の害の率)

経済的な橋渡し:
防がれたイベント1件あたりの費用 = NNT × 治療1コースあたりの費用
```

常に期間とベースラインの集団を明示してください — NNTはその両方なしには無意味です。

## 計算例

病院の転倒予測システムが高リスクの患者に介入(ベッドセンサー、レビュー、監視)を促します。試験:負傷を伴う転倒が入院の3.2%から2.4%に減少します。

```
ARR = 0.8パーセントポイント → NNT = 1/0.008 = 125
   (1件の負傷を伴う転倒を防ぐために125人の患者が介入バンドルを受ける必要がある)

介入費用 ≈ £40/患者 → 防がれた転倒1件あたりの費用 = 125 × 40 = £5,000
負傷を伴う入院患者の転倒の費用(追加の入院、画像検査、訴訟) ≈ £12,000
正味:予防は約2.4:1の割合で報われます — そしてQALYの獲得はそれに加えてです。
```

NNTがどのように主張を正直に保つかに注目してください:「転倒を25%削減」と「治療を受けた125人の患者ごとに1件の転倒を防ぐ」は同じ結果であり、説得力の伝わり方が異なるだけです。

## ソフトウェア工学との関連

NNTは、多くの項目に作用してわずかなものを捕まえるあらゆるゲートやチェックにとって正しい単位です:**「1件の本番環境に向かう欠陥を捕まえるために、AIレビューゲートを通過しなければならないPRの数」**。もしそのゲートが1件の実際の捕捉ごとに400件のPRをレビューする(NNT = 400)なら、1回あたり4分の開発者の注意を払うとして、1件の捕捉には約27開発者時間の費用がかかります — それを、防がれるインシデントの費用と比較してください。NNHは偽陽性に対応します:1件の*偽*フラグあたり何件のPRがあり、それぞれが注意と信頼の面でどれだけの費用がかかるか?スクリーニング型のツール(リンター、セキュリティスキャナー、異常検知)はNNT/NNHの計算とともに出荷されるべきです — 低い有病率がこれらの数字をどれほど厳しくするかについては[スクリーニングの経済学](../スクリーニングの経済学/)を参照してください。 [スクリーニング必要数](../スクリーニング必要数/)は、治療単独ではなく、スクリーニングしてから治療するプログラム全体を対象とする、1段階上の類似の数値です。

## 落とし穴

- **期間がないこと**:「NNT = 50」は無意味です;「5年間でNNT = 50」は主張です。
- **ベースラインリスクの移植**:高リスクの試験対象集団で計算されたNNTは、低リスクの展開対象集団では崩壊します。
- **NNHを無視すること** — NNT 400、NNH 3のゲートは、安全システムではなく迷惑発生装置です。
