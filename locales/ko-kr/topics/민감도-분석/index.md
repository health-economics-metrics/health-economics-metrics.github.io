# 민감도 분석

결정론적 민감도 분석(DSA)은 결론이 유지되는지 확인하기 위해 그럴듯한 범위 내에서 한 번에 하나의 가정을 변화시킵니다. 표준 시각화는 토네이도 다이어그램입니다: 매개변수들이 결과를 얼마나 흔드는지에 따라 순위가 매겨집니다.

## 왜 중요한가

모든 경제 모델은 추정치 위에 세워집니다 — 절약된 시간, 채택률, 단위 비용. 보건기술평가는 투입값에 대한 합리적인 이견에도 불구하고 결론이 견고하다는 증거 없이는 단일 점 추정치("ROI는 340%")를 받아들이지 않습니다. 토네이도 다이어그램은 의사결정자에게 *어떤 가정을 조사해야 하는지*를 알려줍니다.

## 수식

```
결과_낮음 = 모델(p = p_낮음, 나머지는 기본 사례)
결과_높음 = 모델(p = p_높음, 나머지는 기본 사례)
변동폭(p) = |결과_높음 − 결과_낮음|
```

## 계산 예시

200명의 개발자를 위한 AI 코딩 어시스턴트. 절약된 시간이 지배적인 매개변수입니다.
