# การปฏิบัติตามและความต่อเนื่อง

การปฏิบัติตามวัดว่าผู้ป่วยปฏิบัติตามแผนการรักษาที่กำหนดไว้ตามคำแนะนำหรือไม่ ในขณะที่ความต่อเนื่องวัดว่าพวกเขาใช้การรักษานานเพียงใดโดยรวม

## ทำไมจึงสำคัญ

แม้แต่การแทรกแซงที่มีประสิทธิผลที่สุดก็ไม่สามารถให้ประโยชน์ได้หากผู้ป่วยไม่ปฏิบัติตามนานพอหรือแม่นยำพอ — การปฏิบัติตามเป็นเงื่อนไขเบื้องต้นที่สำคัญสำหรับประสิทธิผลทางคลินิก

## คณิตศาสตร์

```
อัตราการปฏิบัติตาม = จำนวนขนาดยาที่ใช้จริง / จำนวนขนาดยาที่กำหนดทั้งหมด × 100%
```

## ตัวอย่างที่คำนวณแล้ว

ยาสำหรับโรคเรื้อรังแสดงให้เห็นการลดความเสี่ยง 70% ในการทดลองทางคลินิก แต่ในโลกจริงที่มีอัตราการปฏิบัติตามเพียง 50% ผลกระทบที่แท้จริงในระดับประชากรต่ำกว่าที่แสดงในการทดลองอย่างมาก

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการติดตามการนำฟีเจอร์ไปใช้ต่อเนื่องหลังจากการเปิดใช้งานครั้งแรก — ผู้ใช้ยังคงปฏิบัติตามรูปแบบการใช้งานที่แนะนำต่อไปหรือไม่ตามเวลา

## ข้อผิดพลาดที่พบบ่อย

- **การสันนิษฐานว่าประสิทธิผลของการทดลองทางคลินิกจะเกิดขึ้นในประชากรจริงโดยไม่พิจารณาการปฏิบัติตาม**
- **การสับสนระหว่างการปฏิบัติตามและความต่อเนื่อง — ผู้ป่วยอาจต่อเนื่องแต่ไม่ปฏิบัติตาม**
