# Omkostningsminimeringsanalyse (CMA)

Omkostningsminimeringsanalyse vælger den billigste mulighed, efter det er bevist, at de sammenlignede interventioner har ækvivalent effektivitet.

## Hvorfor det er vigtigt

Når effektiviteten allerede er bevist ækvivalent, er det unødvendigt at udføre komplekse omkostningseffektivitetsberegninger — vælg blot den billigste.

## Matematikken

```
Vælg mulighed med min(Omkostning), givet Effekt_A = Effekt_B
```

## Gennemarbejdet eksempel

To generiske lægemidler med bevist identisk effekt: vælg det med den laveste indkøbspris, uden yderligere analyse.

## Forbindelse til softwareudvikling

Ligner det at vælge den billigste cloududbyder, efter det er bekræftet, at begge opfylder de samme ydeevne- og pålidelighedskrav.

## Faldgruber

- **At antage ækvivalens uden solid dokumentation.**
- **At bruge CMA, når effekterne rent faktisk adskiller sig subtilt.**
