# Dominantsus ja efektiivsuspiir

Üks variant domineerib teise üle, kui see on odavam ja vähemalt sama tõhus. Efektiivsuspiir näitab mittedomineeritud variante.

## Miks see on oluline

Domineeritud variandid saab kohe kõrvaldada, lihtsustades otsustusruumi enne üksikasjalikke kulutõhususe arvutusi.

## Matemaatika

```
Variant A domineerib variandi B üle, kui: kulu(A) ≤ kulu(B) JA mõju(A) ≥ mõju(B)
```

## Lahendatud näide

Neli ravivarianti kulu-mõju graafikul: variant C maksab rohkem kui variant B, kuid annab vähem tervist kui A ja D segu — variant C on laiendatult domineeritud ja kõrvaldatud.

## Seos tarkvaraarendusega

Sarnaneb nende arhitektuurivariantide kõrvaldamisega, mis on korraga nii kallimad kui ka aeglasemad kui alternatiiv.

## Lõksud

- **Laiendatud dominantsuse vahelejätmine ja ainult lihtsa dominantsuse kontrollimine.**
- **Variantide võrdlemine paarikaupa kogu piiri asemel.**
