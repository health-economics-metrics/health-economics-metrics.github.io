# Гранична проти середньої вартості

Гранична вартість — це вартість однієї додаткової одиниці; середня вартість — це загальні витрати, поділені на кількість одиниць. Вони рідко рівні.

## Чому це важливо

Заяви про економію, засновані на середній вартості, майже завжди переоцінюють реальну економію, оскільки фіксовані витрати не зникають при зменшенні обсягу.

## Математика

```
Гранична вартість = ΔЗагальні витрати / ΔКількість
Середня вартість = Загальні витрати / Кількість
```

## Розібраний приклад

Лікарняне ліжко має середню вартість £400/день (включаючи накладні витрати), але звільнення одного ліжка заощаджує лише близько £150/день реально уникнених витрат.

## Зв'язок з інженерією програмного забезпечення

Подібно до хмарної інфраструктури: масштабування одного екземпляра вниз заощаджує граничну вартість обчислень, а не середню вартість на користувача.

## Підводні камені

- **Використання середньої вартості для оцінки економії від дрібномасштабних змін.**
- **Розгляд фіксованих витрат як змінних.**
