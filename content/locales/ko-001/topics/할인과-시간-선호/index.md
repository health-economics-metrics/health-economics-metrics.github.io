# 할인과 시간 선호

할인은 미래의 비용과 편익을 현재 가치로 전환합니다. 오늘의 편익이 5년 후의 같은 편익보다 더 가치 있기 때문입니다.

## 왜 중요한가

모든 보건경제학 평가와 모든 진지한 공공부문 비즈니스 케이스는 다년간의 흐름을 할인합니다. 영국의 HM Treasury Green Book은 연 3.5%의 사회적 시간 선호율을 의무화합니다; NICE의 기준 사례는 비용과 건강 효과 모두를 연 3.5%로 할인합니다. 여러분의 소프트웨어 비즈니스 케이스가 "10년간 500만 파운드 절감"을 주장한다면, 재무 검토자는 즉시 할인된 수치를 요구할 것입니다.

## 수식

미래 금액의 현재 가치:

```
PV = FV / (1 + r)^t

PV = 현재 가치
FV = t년의 미래 가치
r  = 할인율 (NICE/Green Book: 0.035)
t  = 현재로부터의 연수
```

## 계산 예시

여러분의 소프트웨어가 NHS 트러스트에 5년간 연간 £100,000을 절약해줍니다.

```
할인 전 총액: £500,000
할인된 총 PV ≈ £451,505
```

정직한 제목은 약 £451,000이며, 순진한 합계보다 약 10% 낮습니다. 이제 전달이 1년 지연된다고 가정해봅시다: 모든 항이 1년씩 늦춰지고, PV는 약 £436,000으로 떨어집니다 — 이것이 [지연 비용](../지연-비용/)의 할인 관점입니다.

## 소프트웨어 공학과의 연관성

- **기술 부채 상환과 플랫폼 마이그레이션**은 몇 년 후의 편익 흐름을 약속합니다; 이번 분기에 보상되는 작업과 비교하기 전에 이를 할인하세요.
- **선불 비용, 후불 편익**은 마이그레이션의 표준 형태입니다. 할인은 그 형태를 정확하게 불리하게 만듭니다.
- **"5년차 절감"이라는 주장**은 두 배로 의심받을 만합니다 — 그것들은 크게 할인되면서도 매우 불확실합니다([민감도 분석](../민감도-분석/) 참조).

## 함정

- **비용은 할인하지만 편익은 할인하지 않기**(또는 그 반대).
- **공공부문 사례에서 상업적 할인율(8–12%)을 사용하기**, 또는 벤처 지원 사례에서 3.5%를 사용하기.
- **할인을 인플레이션과 혼동하기.**
