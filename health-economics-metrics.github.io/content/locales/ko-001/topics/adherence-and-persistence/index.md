# 순응도와 지속성

순응도는 처방된 대로 치료나 개입을 따르는 정도를 측정하며, 지속성은 시간이 지나도 계속 치료를 이어가는지를 측정합니다.

## 왜 중요한가

순응하지 않는 치료는 임상시험에서 효과가 있어도 실제로는 편익을 내지 못합니다.

## 수식

```
순응도(MPR) = 처방일수 공급된 일수 / 관찰 기간(일수) × 100%
```

## 계산 예시

디지털 약물 복용 알림 앱 사용자: MPR이 개입 전 65%에서 개입 후 82%로 향상.
