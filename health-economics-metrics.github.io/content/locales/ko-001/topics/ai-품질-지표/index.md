# AI 품질 지표

AI 품질 지표는 모델 출력의 정확성, 신뢰성, 그리고 안전성을 측정합니다: 정밀도, 재현율, 환각률.

## 왜 중요한가

높은 처리량의 AI 시스템도 품질이 낮으면 하류 수정 비용이 절감액을 초과할 수 있습니다.

## 수식

```
F1 점수 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
```

## 계산 예시

임상 코딩 보조 AI: 정밀도 0.85, 재현율 0.78 = F1 0.81.
