# Вероятностный анализ чувствительности (Probabilistic Sensitivity Analysis, PSA)

PSA присваивает распределение вероятностей каждому неопределённому параметру, отбирает выборки по всем ним одновременно тысячи раз (Монте-Карло) и сообщает *вероятность* того, что вариант является лучшим выбором — вместо единой точечной оценки.

## Почему это важно

Референсный кейс NICE *требует* PSA. Детерминированный анализ отвечает на вопрос «что если один вход неверен?»; PSA отвечает на вопрос «учитывая всё, чего мы не знаем одновременно, насколько вероятно, что мы принимаем правильное решение?» Его характерный результат, **кривая приемлемости затратной эффективности (cost-effectiveness acceptability curve, CEAC)**, строит вероятность того, что вариант затратно-эффективен, в зависимости от порога готовности платить — превращая «ICER составляет £24 000/QALY» в «вероятность того, что это правильный выбор при £30 000/QALY, составляет 78%».

## Математика

```
Для каждой из N выборок (N ≈ 10,000):
  выбирайте каждый параметр θ из его распределения
    (затраты ~ Гамма, вероятности ~ Бета, полезности ~ Бета, эффекты ~ Нормальное/логнормальное)
  вычисляйте NMB_j(θ) = λ × Эффект_j(θ) − Затраты_j(θ) для каждого варианта j

CEAC_j(λ) = доля выборок, в которых вариант j имеет наибольший NMB при пороге λ
```

См. [чистую денежную выгоду](../чистая-денежная-выгода/) для NMB и [пороги готовности платить](../пороги-готовности-платить/) для λ.

## Практический пример

Бизнес-кейс миграции платформы. Три неопределённых входа:

```
Стоимость миграции   ~ Гамма,      среднее £800k, стандартное отклонение £200k
Годовая выгода       ~ Нормальное, среднее £350k, стандартное отклонение £150k
Длительность выгоды  ~ Равномерное, 3–6 лет
```

Для каждой из 10 000 выборок вычислите чистую выгоду = длительность × годовая выгода − стоимость (дисконтирование опущено для ясности). Иллюстративные результаты:

```
Средняя чистая выгода:        £775k
Вероятность, что выгода > 0:  0.86
5-й–95-й процентиль:         −£180k … +£1.9M
```

Точечная оценка говорила «очевидно да». PSA говорит «да с вероятностью 86%, с реальным хвостом, где мы теряем £180 тыс.+» — именно это нужно владельцу портфеля, и это обосновывает кейс для запуска разведочного спайка сначала (см. [EVPI](../ожидаемая-ценность-совершенной-информации/)).

## Связь с разработкой программного обеспечения

Инженеры уже доверяют Монте-Карло для прогнозирования поставки (выборка пропускной способности превосходит точечные оценки). Расширьте тот же механизм на деньги: распределения на внедрение, сэкономленное время и зарплату, затем отчитайтесь «вероятность того, что эта инвестиция в платформу чистоположительна» вместо ложноточного ROI. Кривая в стиле CEAC — вероятность быть лучшим вариантом как функция того, как организация оценивает инженеро-час — это по-настоящему лучший артефакт для комитета по финансированию, чем любая единая цифра.

## Подводные камни

- **Мусорные распределения**: PSA с выдуманными стандартными отклонениями — это детерминированный анализ в лабораторном халате. Основывайте разбросы на данных или структурированном извлечении экспертных мнений.
- **Игнорирование корреляции** между параметрами (высокое внедрение обычно коррелирует с большим сэкономленным временем); независимая выборка занижает хвостовой риск.
- **Отчётность только по среднему** результату симуляции — весь смысл в распределении и вероятности решения.
