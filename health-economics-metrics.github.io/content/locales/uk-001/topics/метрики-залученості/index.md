# Метрики залученості

Метрики залученості вимірюють, як часто та наскільки глибоко користувачі взаємодіють з медичним застосунком чи цифровою послугою: активні користувачі, частота сеансів, час перебування.

## Чому це важливо

Медичний застосунок без залученості не може мати ефекту — якими б сильними не були клінічні докази.

## Математика

```
Коефіцієнт DAU/MAU = щоденно активні користувачі / щомісячно активні користувачі
```

## Розібраний приклад

Застосунок для управління діабетом: DAU 3000, MAU 12 000 = 0,25 (добре для медичного застосунку).

## Зв'язок з інженерією програмного забезпечення

Випереджальний показник для [утримання та відтоку](../утримання-та-відтік/) та [активації та впровадження](../активація-та-впровадження/).
