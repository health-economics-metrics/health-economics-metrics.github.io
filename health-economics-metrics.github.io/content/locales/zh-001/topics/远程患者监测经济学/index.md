# 远程患者监测经济学

在家中监测患者的报销与成本冲抵经济学：在美国，这对应一套明确的CPT编码收入结构；在国家医疗服务体系中，则对应避免入院与虚拟病房经济学，最高可达到完全的**居家医院**替代模式。

## 为何重要

远程患者监测（RPM）正是设备数据转化为可计费医疗服务的地方。美国Medicare的结构（2025年全国平均值）异常明确：

```
99453  设置与患者教育           约$19.73  一次性收费（需满16天数据后）
99454  设备供应+数据传输        约$43.03  每30天一次——要求30天内
                                        读数天数 ≥16天
99457  每月首20分钟管理         约$47.87  要求已记录时长 ≥20分钟
99458  每额外20分钟             约$38.49
```

一个符合计费条件的患者-月，合计约为**每会员每月90–130美元**。在成本冲抵方面，居家医院项目（CMS急症居家医院照护豁免计划：涵盖300多家医院）显示，相较住院照护，每例可节省约1,800–3,000美元，同时再入院率与感染率更低——这是监测加虚拟照护能够替代系统中最昂贵资源（有人力配置的病床）这一论点最清晰的证明。

## 计算方法

```
RPM收入（美国） = 注册人数 × 符合计费条件的比例 × 每会员每月的编码收入合计
  ——16天规则使佩戴时间合规性（参见wearable-validation.md）
    成为一个收入变量，而20分钟规则则使临床时间的
    记录成为一项工程要求

NHS式价值      = 避免的入院数 × 边际入院成本
              + 被替代的床位天数 × (住院日成本 − 虚拟病房日成本)
              − 服务成本（设备、平台、监测人员）
  （关于归因与边际成本规则，参见emergency-attendance-avoidance.md
   与bed-days-saved.md）
```

## 实例演算

某美国诊所为400名高血压患者注册该服务；在典型月份中70%的患者达到16天阈值；60%记录了管理时长：

```
月收入 ≈ 400 × [0.70 × 43.03 + 0.60 × 47.87] = 400 × 58.84 ≈ $23,500
年收入 ≈ $282,000；服务成本（设备每月$12，人员0.8全职当量）≈ $180,000
利润 ≈ 每年$100,000——请注意，这里的杠杆都是工程层面的杠杆：
将16天合规率从70%提升到85%，每年可增加约$31,000
（设备舒适度、同步可靠性、提醒设计）。
```

NHS版本的镜像：一个拥有50张床位、入住率80%的虚拟病房，替代住院天数、每天净节省£150 ≈ 50 × 0.8 × 365 × 150 ≈ **每年毛值£219万**——需扣除平台、设备以及负责运营的社区护理团队的成本。

## 与软件工程的联系

RPM平台是少数几种**正常运行时间与同步可靠性能直接转化为收入**的产品之一（一周的同步失败，就可能使一整个队列跌破16天门槛），也是审计级时间追踪（20分钟规则）作为一等公民功能、而非事后补充的产品之一。应重点构建：能在计费月尚可挽回时就浮现风险的按患者合规性仪表盘；带时间戳、防篡改的数据轨迹（支付方的审计是家常便饭）；以及警报经济学调优——每一条警报都会消耗监测团队的时间，而这既是可计费单位，同时也是稀缺资源（阈值的选择由[筛查经济学](../筛查经济学/)所支配）。

## 陷阱

- **注册 ≠ 收入**：真正的数字是那个合规比例；应对其建模，而非假设它自然达成。
- **将美国编码直接照搬到NHS场景**——国家医疗服务体系购买的是"避免入院"，而非CPT编码收入结构；应改用后一套模型。
- **对那些固定成本依然持续存在的入院，按平均成本主张冲抵**（参见[边际成本与平均成本](../边际成本与平均成本/)）。
- **监测团队饱和**：警报量会随注册人数增长而增长；人员配置这条线，正是大多数模型都遗漏的那个起决定作用的约束。
