# 可穿戴裝置驗證

驗證指標量化的是一款可穿戴裝置的測量結果，與臨床金標準（心率對應ECG心電圖，睡眠對應多導睡眠圖）之間的一致程度：**MAPE（平均絕對百分比誤差）**、一致性相關係數、Bland–Altman一致性分析——此外還有把控真實世界資料品質的營運指標：**佩戴時間合規性**與**資料完整性**。

## 為何重要

驗證是下游一切工作的前提條件：一款無法證明其測量結果與參照標準一致的裝置，無法作為[數位終點](../數位終點與生物標誌物/)的支撐，無法支援[遠端病患監測計費](../遠端病患監測經濟學/)，也無法承載任何臨床主張。該領域對心率驗證公認的閾值為：與ECG相比，**MAPE ≤5%**（嚴格標準）或**≤10%**（寬鬆標準）。文獻中的參照資料：Oura Gen 3靜息心率MAPE為1.67%（CCC為0.97）；Fitbit Charge 6的MAPE約為5.5%——消費級裝置如今已橫跨臨床級標準的邊界線，這正是為什麼必須按裝置、按具體條件分別進行測量的原因所在。

## 計算方法

```
MAPE = (1/n) Σ |實測值_i − 參照值_i| / 參照值_i × 100

CCC（一致性相關係數） = 同時衡量相關性與系統性偏差的一致程度
      （在Pearson相關係數r的基礎上，對位置/尺度偏移進行懲罰）

Bland–Altman分析：平均偏差 ± 1.96倍標準差的一致性界限——
      展示誤差是否隨數值大小而變化

營運層面的關卡指標：
佩戴時間合規性 = 實際佩戴時長 / 協議要求時長 × 100
資料完整性     = 實際觀測資料點數 / 預期資料點數 × 100
```

驗證結果必須**按活動條件**（靜息、運動、睡眠）以及按人群分別報告——PPG光學感測在運動偽影、接觸不良以及膚色較深的情況下表現會下降，這是一種已被記錄在案、且與公平性相關的失效模式。

## 實例演算

某虛擬病房專案正在挑選一款監測用可穿戴裝置。候選A：靜息MAPE 2.1%，運動MAPE 11.4%。候選B：靜息3.8%，運動6.9%。

```
應用場景：在家中檢測病情惡化——警報由持續升高的心率觸發，
而這種情況往往發生在活動期間。
候選A的頭條數位（2.1%）在宣傳冊上很好看，但候選B更適合這一
實際應用場景：在與警報相關的條件（運動）下，A方案在心率100時
誤差達11.4% = ±11 bpm——這一誤差幅度橫跨了整個警報閾值區間，
會導致誤報升級（每次都意味著一次護士出診，約£40）或漏報。

誤報經濟學：500名病患 × 每週2次額外誤報 × £40
= 因選錯驗證數位而產生每年£208萬的誤差成本。
```

## 與軟體工程的聯絡

工程師在選擇感測器時是驗證資料的使用者，而在建置測量類功能時則是驗證資料的*生產者*——這兩種角色需要遵循相同的紀律：應在實際部署條件下測試，而非在演示條件下測試（軟體領域的對應說法是：應基於你自己的生產環境工作負載做基準測試，而非供應商自己的）。佩戴時間與資料完整性屬於產品工程層面的結果——舒適度、電池續航、充電習慣設計與同步可靠性，共同決定了"30天內16天"這一遠端病患監測計費關卡（參見[遠端病患監測經濟學](../遠端病患監測經濟學/)）能否達成，也決定了試驗資料集是否可供分析。應把缺失資料當作一種有設計意義的訊號來對待：從一開始就在資料模式中區分"未佩戴"、"已佩戴但無訊號"與"同步失敗"這幾種情形——一旦被統一壓縮成空值，它們會汙染下游的每一項分析。

## 陷阱

- **彙總MAPE掩蓋了特定條件下的失效**——這正是上述實例演算中的陷阱所在。
- **驗證人群 ≠ 部署人群**：年齡、膚色、震顫、肥胖程度，都會改變光學感測器的誤差；應核查研究所用的人口統計學特徵。
- **在需要一致性的場合，卻只報告相關性**：高Pearson相關係數、外加系統性偏差，在絕對閾值判定下依然會造成分類錯誤——應堅持要求提供CCC/Bland–Altman分析。
- **透過插補虛增完整性**：把被填補的缺口當作實際觀測資料來報告。
