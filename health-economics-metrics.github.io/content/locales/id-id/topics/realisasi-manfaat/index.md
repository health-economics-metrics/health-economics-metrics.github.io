# Realisasi Manfaat

Manajemen realisasi manfaat (BRM) adalah disiplin yang mengidentifikasi, menetapkan garis dasar, melacak, dan *membuktikan* bahwa manfaat yang dijanjikan dalam kasus bisnis benar-benar terjadi.

## Mengapa ini penting

Kasus bisnis adalah janji; realisasi manfaat adalah audit.

## Matematika

```
Tingkat realisasi = manfaat yang terealisasi / manfaat yang diperkirakan
```

## Contoh yang diselesaikan

Kasus bisnis penjadwalan elektronik menjanjikan £450 ribu pengurangan biaya agensi per tahun: tingkat realisasi 64%.

## Hubungan dengan rekayasa perangkat lunak

Organisasi rekayasa menyetujui investasi platform berdasarkan manfaat yang diperkirakan.

## Jebakan

- **Tidak ada garis dasar sebelum peluncuran.**
