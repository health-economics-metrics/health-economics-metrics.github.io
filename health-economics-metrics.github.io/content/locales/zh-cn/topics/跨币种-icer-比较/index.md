# 跨币种 ICER 比较 (Cross-Currency ICER Comparison)

把以一国货币计算的 [ICER](../增量成本效果比/) 与另一国的[支付意愿阈值](../支付意愿阈值/)比较——或汇总来自多国试验的成本数据——需要一个明确、可审计的货币换算步骤。选错换算方法，可能让同样的证据得出相反的采纳决定，尽管临床数据和成本数据都没有变。

## 为什么重要

ISPOR 针对多国临床试验的方法学指南（Willke 等，*Health Economics*，1998）建议，在比较各国资源的真实经济价值时，用**购买力平价（PPP）**而非市场汇率来换算资源成本，并把市场汇率留给它的真正用途：为实际的跨境现金支付流建模。混淆两者是多国卫生技术评估中最常见的方法学错误之一，因为对没读过指南的人来说，两者看起来都是“一个汇率”，而电子表格也不会阻止你出错。

## 计算方法

```
本币_icer = 换算(源币种_icer, 换算系数)

换算系数应当是：
  PPP 换算系数   —— 用于比较各国资源的真实经济价值
                   （ISPOR 对多国 CEA 的建议）
  市场汇率       —— 仅用于真实的跨境现金支付

若 本币_icer < 本国阈值，则采纳
```

决策规则本身就是常规的 [ICER 规则](../支付意愿阈值/)——`若 ICER < λ 则采纳`——本主题的方法学问题在于*哪个换算系数*产生了该规则所作用的 `本币_icer`。

## 算例

某药物来自美国试验的 ICER 为 $45,000/QALY。一个假想的进口国自行设定了复合阈值 £34,000/QALY（仅为本示例的假想国别数字——真实阈值因国而异，并随时间变化，应始终注明来源和日期）。

**使用 PPP 换算系数 0.72**（仅为本示例的示意数字）：$45,000 × 0.72 = £32,400/QALY。£32,400 < £34,000 → **采纳**。

**改用市场汇率 0.79**（示意数字）：$45,000 × 0.79 = £35,550/QALY。£35,550 > £34,000 → **拒绝**。

同样的 $45,000/QALY ICER，用 PPP 换算得到采纳的决定，用市场汇率换算得到拒绝的决定。这具体说明了为什么 ISPOR 指南认为换算系数的选择具有方法学意义——它不是舍入细节，也不是可以隐含在没人复核的电子表格公式里的东西。

## 与软件工程的关联

这是卫生经济学里一个众所周知的工程问题的翻版：商业软件中多币种定价 i18n/l10n 的正确性——SaaS 定价页面不应悄悄把 `$` 金额与 `£` 价格相比较。设计良好的 `Money` 类型在类型层面提供的保证——比较方法拒绝比较不匹配的币种，并强制先做明确的换算——正是这里卫生经济学方法学要点的软件工程对应：不要在币种之间比较未换算的数字，也不要让换算步骤隐含或没有记录。

## 陷阱

- **悄悄比较不同币种的金额**：在电子表格里做临时的 HTA 工作，不先换算就把美元数字与英镑数字相减或比较——这类缺陷，具备币种意识的 `Money` 类型会从结构上抓出来，而不是任其成为无声的错误。
- **混淆市场汇率与 PPP**：按 ISPOR 指南，这是多国 HTA 中最常见的方法学错误——两个数字可能相差很大，回答的是不同的问题（真实经济价值与实际现金流）。
- **不给所用汇率或 PPP 指数标注日期**：两者都随时间变化，因此每个引用的换算系数都应标注日期，就像本仓库为其他参考数字（Green Book 碳价、避免死亡的价值等）标注日期那样。
