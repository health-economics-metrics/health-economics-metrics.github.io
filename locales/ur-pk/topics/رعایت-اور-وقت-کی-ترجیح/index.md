# رعایت اور وقت کی ترجیح

رعایت مستقبل کی قیمتوں اور فوائد کو موجودہ قدروں میں تبدیل کرتی ہے، کیونکہ آج کا ایک فائدہ پانچ سال بعد کے اسی فائدے سے زیادہ قیمتی ہے۔

## یہ کیوں اہم ہے

ہر صحت-معاشیات کی تشخیص اور ہر سنجیدہ سرکاری شعبے کا کاروباری کیس کثیر سالہ بہاؤ پر رعایت لاگو کرتا ہے۔ برطانیہ کا HM Treasury گرین بک 3.5% سالانہ سماجی وقت کی ترجیح کی شرح لازمی قرار دیتا ہے۔

## ریاضی

مستقبل کی رقم کی موجودہ قدر:

```
PV = FV / (1 + r)^t

PV = موجودہ قدر
FV = سال t میں مستقبل کی قدر
r  = رعایت کی شرح (NICE/گرین بک: 0.035)
t  = ابھی سے سال
```

## حل شدہ مثال

آپ کا سافٹ ویئر ایک NHS ٹرسٹ کو 5 سال تک سالانہ £100,000 بچاتا ہے۔

```
سال 1: 100,000 / 1.035^1 = £96,618
کل PV ≈ £451,505
```

ایماندار سرخی تقریباً £451,000 ہے، سادہ مجموعے سے تقریباً 10% کم۔

## سافٹ ویئر انجینئرنگ سے تعلق

- **تکنیکی-قرض کی ادائیگی اور پلیٹ فارم کی منتقلی** سالوں دور کے فائدے کے بہاؤ کا وعدہ کرتے ہیں۔
- **آگے-بھاری قیمت، پیچھے-بھاری فوائد** ایک منتقلی کی معیاری شکل ہے۔

## عام غلطیاں

- **قیمتوں پر رعایت دینا لیکن فوائد پر نہیں۔**
- **ایک تجارتی شرح (8–12%) کو سرکاری شعبے کے کیس میں استعمال کرنا۔**
