# 成本效果分析 (Cost-Effectiveness Analysis，CEA)

CEA 比较不同干预方案的成本，针对以**自然单位**衡量的同一个结果——生命年、检出病例数、避免的住院数、血压下降的 mmHg 数。其输出是每单位结果的成本。

## 为什么重要

当所有备选方案都以同一个结果为目标时，CEA 是最主力的比较方法。它能回答"在实现 X 的这些方式中，哪一种最物有所值？"——但*不能*回答"X 本身值不值得实现？"（那需要[成本效益分析](../成本效益分析/)），也*不能*回答"X 与不相关的优先事项相比如何？"（那需要[成本效用分析](../成本效用分析/)以及像 QALY 这样的通用结果单位）。

## 计算方法

比较统计量是以自然单位表示的 [ICER](../增量成本效果比/)：

```
ICER = (成本_A − 成本_B) / (效果_A − 效果_B)
     = 每多检出一例 / 每避免一次住院 等等所需的 £ 数
```

流程：先确定结果单位；从相同的[视角](../分析视角/)、在相同的[时间周期](../时间周期/)内为每个方案计算成本；剔除被支配的方案（参见[效率前沿](../优势与效率前沿/)）；沿前沿计算增量比率。

## 算例

在 100,000 人群中发现未确诊心房颤动的三种方式：

```
方案                        成本         发现病例数
机会性脉搏检查                £150,000      300
药房筛查活动                  £400,000      520
可穿戴设备筛查                £900,000      610

ICER（药房 vs 脉搏检查）：(400k−150k)/(520−300) = 每多发现一例 £1,136
ICER（可穿戴 vs 药房）：  (900k−400k)/(610−520) = 每多发现一例 £5,556
```

每多发现一例花费 £5,556 是否"值得"，取决于一个被发现病例的价值（下游的卒中预防）——CEA 能为各方案排序，但采纳决策还需要这个外部估值。请注意，可穿戴方案的*平均*每例成本（900k/610 = £1,475）看起来还不错；但*增量*的 £5,556 才是关于扩大规模决策的诚实数字。

## 与软件工程的关联

每当各方案共享同一个结果时，CEA 就是正确的模板：三种修复方案下每消除一个不稳定测试 (flaky test) 的成本；不同可观测性供应商下每避免一次事件的成本；不同 CI 架构下每次成功部署的成本。它所强制要求的纪律——声明一个结果单位、使用增量（而非平均）比率、先剔除被支配的方案——能在定价讨论开始之前就扼杀大多数糟糕的供应商比较。

## 陷阱

- **在一次 CEA 中比较结果不同的方案**（"发现病例数" vs "满意度"）——这需要[成本后果分析](../成本后果分析/)或一个通用结果单位。
- **在需要增量比率的场合呈现平均成本效果比**（如上文的可穿戴设备例子）。
- **为了好看而挑选结果单位**："产生的告警数"是一种产出，不是一种结果；应坚持使用真正承载价值的单位。
