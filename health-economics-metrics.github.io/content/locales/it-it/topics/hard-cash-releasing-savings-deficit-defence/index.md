# Risparmi Rigidi che Liberano Cassa (Difesa del Deficit)

I risparmi rigidi che liberano cassa sono voci di bilancio che un ospedale può eliminare attivamente dal bilancio del mese prossimo grazie al vostro software.

## Perché è importante

Molti trust NHS operano sotto piani di recupero del deficit con un controllo intenso su ogni voce di spesa.

## La matematica

```
Risparmio rigido = turni premium evitati × (tariffa premium − tariffa base)
```

## Esempio risolto

Un'infermiera di Fascia 6 perde ~1 ora per turno in oneri amministrativi: totale cassa rigida ≈ £416.000/anno.

## Collegamento con l'ingegneria del software

L'equivalente ingegneristico del premio dell'agenzia è l'acquisto di crisi dell'organizzazione stessa.

## Insidie

- **Chiamare la capacità "risparmio."**
