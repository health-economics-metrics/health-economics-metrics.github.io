# Рентабельность инвестиций в ИИ (AI Return on Investment)

ROI ИИ — это измеримая отдача в отчёте о прибылях и убытках, относимая на счёт ИИ-инициатив. Отрезвляющий бенчмарк: исследование MIT 2025 года «GenAI Divide» обнаружило, что несмотря на $30–40 млрд корпоративных инвестиций в GenAI, **~95% пилотов не показали измеримой отдачи в P&L** — а успешные 5% разделяли узнаваемые привычки.

## Почему это важно

В системах здравоохранения есть название для паттерна ИИ-пилотов: **«пилотит» (pilotitis)** — кладбище NHS перспективных приложений, вечно пилотируемых и никогда не масштабируемых. Выводы MIT чисто накладываются на то, что уже известно оценке медицинских технологий: заявления о ценности требуют заранее заданных конечных точек, атрибуция требует компараторов, а «все чувствуют, что это помогает» — не строка выгоды. Успешное меньшинство в данных MIT концентрировалось в автоматизации бэк-офиса с отслеживаемыми базовыми показателями, и **приобретённые инструменты преуспевали в ~67% случаев против примерно трети у внутренних разработок** — априорные данные, которым место в каждом инвестиционном кейсе по ИИ (см. [разработка своими силами или покупка готового решения](../разработка-своими-силами-или-покупка-готового-решения/)).

## Математика

```
ROI ИИ = (относимая на счёт ИИ выгода − совокупные затраты на ИИ) / совокупные затраты на ИИ

Совокупные затраты на ИИ = лицензии/инференс (см. inference-unit-economics.md)
              + интеграция + готовность данных + оценка
              + редизайн рабочих процессов + управление/гарантии качества
              (лицензия обычно составляет меньшую часть знаменателя)

Относимая выгода: измеряется относительно базовой линии или контроля, классифицируется как
денежная / ёмкостная / качественная согласно cash-releasing-vs-non-cash-releasing.md
```

## Практический пример

Больничная группа развёртывает ИИ для двух сценариев использования:

```
Сценарий A — составление клинических писем (бэк-офис, отслеживаемо):
  базовая линия: аутсорсинговая транскрипция £380k/год
  после:    контракт на транскрипцию расторгнут; время рецензирования клиницистом +£60k
  затраты на ИИ:  £120k/год «под ключ»
  ROI = (380k − 60k − 120k) / 120k ≈ 167% — высвобождает денежные средства, поддаётся аудиту ✓

Сценарий B — «ИИ-копилот для клиницистов» (широкий, неотслеживаемый):
  заявление о выгоде: «экономит время для 4,000 сотрудников» — базовая линия не зафиксирована
  измеренный эффект на P&L: не поддаётся демонстрации
  → попадает в те самые 95%, независимо от того, помогает ли на самом деле
```

Разница не в качестве ИИ — она в том, имела ли выгода **базовую линию, ответственного владельца и бюджетную строку** ([реализация выгод](../реализация-выгод/)).

## Связь с разработкой программного обеспечения

Плейбук в стиле HTA для инвестиций в ИИ: **выстраивайте доказательства ступенями, как [уровни NICE ESF](../система-стандартов-доказательности-nice/)** — демонстрационные доказательства для низкорисковых инструментов, контролируемые пилоты перед расходами на весь орган, с заранее зарегистрированными воротами развёртывания (паттерн [DiGA](../ускоренный-путь-diga-в-германии/) с предварительным листингом и дедлайном); **считайте избегание затрат так же, как экономика здравоохранения считает избегание спроса** — реально только тогда, когда двигается конкретная бюджетная строка; и **оценивайте сам пилот с помощью [EVPI](../ожидаемая-ценность-совершенной-информации/)** — пилот, который не может изменить решение о развёртывании, стоит £0. Про срез инструментов для разработчиков конкретно см. [продуктивность разработчиков с ИИ](../продуктивность-разработчиков-с-ии/).

## Подводные камни

- **Диффузия выгоды**: ценность, размазанная тонким слоем по тысячам пользователей, по построению неизмерима; выбирайте сценарии использования с концентрированными, отслеживаемыми базовыми линиями.
- **Учёт затрат только на лицензии**: интеграция, оценка и редизайн рабочих процессов обычно доминируют в истинном знаменателе.
- **Кража атрибуции**: ИИ, развёрнутый вместе с редизайном процессов, присваивает себе всю дельту.
- **Эскалация убыточного пилота**: продление провалившихся пилотов, потому что остановка означает признание провала — дата завершения должна быть согласована заранее.
