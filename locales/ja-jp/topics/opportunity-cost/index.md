# 機会費用

機会費用とは、あるリソースを投入する際に断念する最善の代替案の価値のことです。予算が固定された医療システムでは、あることに£100万を使うということは、他のどこかで£100万分の健康が*生み出されない*ことを意味します。

## なぜ重要か

機会費用は医療経済学における最も深遠な考え方であり、ソフトウェアエンジニアが最も見落としがちな考え方でもあります。医療予算はどの年も固定されているため、新しい技術が「余った」お金から資金提供されることは決してありません — それは何かを置き換えるのです。支払者が実際に問うのは「これは良いものか?」ではなく、「同じお金が現在買っているものより優れているか?」です。

これこそが費用効果閾値が存在する理由です。閾値とは、現行システムの限界における、お金が買う健康の推定値です。[支払意思閾値](../willingness-to-pay-thresholds/)を参照してください。

## 数式

単一の公式は存在しません。機会費用は比較の規律です:

```
Aを選ぶことの機会費用 = 断念した最善の代替案Bの価値
Aからの純利益 = 価値(A) − 価値(B)
```

実証的な基準値として、Claxtonら(2015)はNHSが限界において1QALYを約**£13,000**で生み出していると推定しました。つまり、1QALY未満しか生み出さない技術に£13,000を費やすことは、その技術が「効く」としても、国全体を*より不健康に*します。

## 計算例

あるNHSトラストの変革予算は、以下のいずれか1つにしか使えません:

- **選択肢A**:電子勤務表ソフトウェア — 派遣職員への支出を年間£400,000節約する。
- **選択肢B**:退院調整ソフトウェア — 年間2,000病床日を節約する。実際に空いた病床日あたり約£150の限界費用なので、これは年間£300,000に加え、待機患者への早期治療という便益がある。

Aに資金を出すことはBを断念することを意味します。Aの機会費用はBの£300,000に患者への便益を加えたものです。Aの*正味*の主張はこの差額のみであり、Aの見出しの£400,000ではありません。ある提案を最善の代替案ではなく「何もしない」と比較するビジネスケースは、その価値を過大評価します。

## ソフトウェア工学との関連

エンジニアリングの能力もまた固定された予算です — ポンドではなく、ロードマップの枠です。エンジニア時間を時給£500で節約するツールAに資金を出すプラットフォームチームは、ツールBが同じことを時給£200で実現できるのであれば、まさに£40,000/QALYの薬に資金を出す医療システムが£13,000/QALYのケアを押しのけるのと同じように、能力を破壊しています。この規律は直接転用できます:

- 常に比較対象を明示する(「何と比べて?」)。
- エンジニアの時間は、給与だけでなく、それが本来生み出すはずだったものの価値で評価する。
- 「予算が余っている」を分析の終わりではなく、始まりとして扱う。

## 落とし穴

- **何もしない状態と比較する。** 正しい比較対象はそのお金の次善の使い道であり、「何もしない」であることはめったにありません。
- **節約された時間の機会費用がゼロだと仮定する。** 節約された時間は、何か価値あるものに再投入されて初めて価値を持ちます — [現金化可能な節約と非現金化節約](../cash-releasing-vs-non-cash-releasing/)を参照してください。
- **置き換えを無視する。** 「予算はそれに合わせて拡大する」というのは、国のヘルスケアサービスにおいて年度内にはほぼ成り立ちません。
- **置き換えられた資源をどの方法で評価するかを無視すること。** 特に、疾病、障害、退職する従業員による失われた生産性については、この考え方の生産性費用版である[人的資本アプローチと摩擦費用法](../human-capital-and-friction-cost/)を参照してください。
