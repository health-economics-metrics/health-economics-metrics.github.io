# 回避可能な外部委託費用

トラストが内部の容量では目標を達成できない場合、割増料金で容量を買います:自らのスタッフの週末残業、あるいは民間提供者への処置の外部委託です。容量を解放するソフトウェアの経済的価値には、**その割増料金の作業の回避可能な費用**が含まれます。

## なぜ重要か

選択的処置回復のプレッシャーのもと、トラストは日常的に、民間セクターのスポット価格(しばしばNHS制度価格の1.2〜1.5倍)や、週末リストに対する自らのコンサルタントへの割増待機リスト・イニシアティブ料率を支払います。通常の容量の主張とは異なり、回避された外部委託は**現金化可能**です:民間提供者への請求書は本当に発行されません。それが、内部のスループットを増加させるソフトウェアにとって利用可能な最も強力な便益項目の1つであり、証拠を示すのが最も簡単なものの1つでもあります。なぜなら、外部委託支出はすでに目に見える予算項目だからです。

## 数式

```
回避可能な外部委託費用 = 内製化された活動 × (外部委託の単価
                        − 症例あたりの内部限界費用)

内部限界費用:追加の活動のための消耗品と変動人員配置
— 固定資産はすでに支払い済みです(限界費用と平均費用を参照)。
```

この主張には、解放された内部容量が実際にその活動を吸収する必要があります:手術室のセッション、病床、スタッフがすべて利用可能でなければなりません(拘束制約が支配します — 再び制約理論です)。

## 計算例

あるトラストは、年間800件の白内障手術を1件あたり£900で外部委託しています:年間£720,000の外部支出であり、制度価格は約£750です。

手術室スケジューリングソフトウェア(リストの最適化、キャンセルからのギャップの埋め戻し、回転時間の追跡)は、内部の手術室稼働率を十分に高め、500件の処置を内製化します:

```
症例あたりの内部限界費用 ≈ £350(消耗品+セッション人員配置)
節約 = 500 × (900 − 350) = 年間£275,000 — 現金化可能
残りの外部委託:300 × £900 = £270,000(以前は£720,000)
```

ソフトウェアの費用は年間£90,000 → 正味 ≈ **年間+£185,000の蓄えられる現金**、加えて、作業を内部に保つことによる内部品質とトレーニングの便益。

## ソフトウェア工学との関連

直接的な類似物は**外部委託業者とコンサルタントの割増料金**です:内部のエンジニアリング容量がコミットメントを満たせないとき、組織は内部の全負担率の1.5〜3倍で外部の容量を購入します。内部のスループットを高めるプラットフォームや生産性への投資は、上記とまったく同じように回避された外部委託業者支出を主張すべきです — 外部の日次料金から内部の限界費用を引き、内製化された作業を掛けたもの — なぜならそれは、開発者生産性のビジネスケースにおいて本当に現金化可能な数少ない項目の1つだからです。同じ注意点が当てはまります:内部の容量が実際に存在し、内製化された作業にスケジュールされなければ、その主張はフィクションです。

## 落とし穴

- **完全な容量の連鎖なしに内製化を主張すること** — 外科医が解放されても手術室の枠がない(あるいはエンジニアが解放されてもプロダクトマネジメントの余力がない)場合、何も内製化されません。
- 外部委託の価格を内部の限界費用ではなく**内部の平均費用と比較すること** — 奇妙なことに、これは節約を過小評価します;固定費はどちらにせよ発生します。
- **質/複雑さの非対称性**:外部委託される症例はしばしば単純なものです;それらを内製化すると内部の症例構成と単位費用が変わります。
