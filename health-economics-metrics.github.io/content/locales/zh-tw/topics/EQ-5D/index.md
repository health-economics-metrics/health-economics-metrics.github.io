# EQ-5D

EQ-5D是EuroQol（歐洲生活品質學會）用於測量健康相關生活品質的標準化問卷。它正是大多數[QALY](../品質調整生命年/)計算中效用權重的來源——NICE的參考案例將其列為成年人首選的測量工具。

## 為何重要

任何希望主張QALY獲益的數位健康產品，都需要來自經過驗證的量表工具的效用值，而EQ-5D是英國及歐洲大部分地區的預設選擇。它足夠簡短，可以直接嵌入應用中（5個問題+一條視覺模擬量表），這意味著軟體產品能夠在正常使用過程中，順帶採集到達到衛生技術評估標準的結果資料——這相對於藥物是一項結構性優勢，因為藥物需要專門開展研究才能獲得這類資料。

## 計算方法

EQ-5D-5L在**5個維度**——行動能力、自理能力、日常活動、疼痛/不適、焦慮/抑鬱——中各提出一個問題，每個問題有**5個等級**的回答（從"沒有問題"到"極度問題"），此外還包含一條0–100的視覺模擬量表（EQ VAS）。

```
健康狀態 = 一個五位數位的健康狀態組合，例如"21221"
效用指數 = 價值集(該健康狀態組合)

該價值集是針對特定國家的，來自對一般公眾進行的時間權衡法/
離散選擇調查。錨點為：1 = 完全健康，0 = 死亡；比死亡更差的
健康狀態取負值（英國3L版價值集的下限為−0.594）。
```

QALY的計算隨後即可按"時長 × 效用值"進行。

## 實例演算

某肌肉骨骼康復應用，在1,000名完成隨訪的使用者入組時與6個月後分別測量EQ-5D-5L。

```
基線平均效用值：  0.62
6個月後平均效用值：0.71
假設獲益可持續1年：(0.71 − 0.62) × 1.0 = 每名使用者0.09 QALY
```

對照組（自然恢復）的變化為0.03，因此可歸因的獲益為每名使用者0.06 QALY。按每QALY £20,000–£30,000貨幣化：**每名完成隨訪的使用者帶來£1,200–£1,800的健康價值**——這一數位正是該應用與支付方進行價格談判時的錨點。（EQ-5D指數的最小臨床重要差異通常落在0.03–0.08區間，因此0.06是可信的，但必須經受住對照組比較的檢驗；參見[病患報告結果](../病患報告結果/)。）

## 與軟體工程的聯絡

- **把它埋點採集起來。**在註冊時以及後續隨訪節點測量EQ-5D，只需要幾個UI介面；換來的回報卻是達到衛生技術評估標準的證據。需從EuroQol獲取授權許可（這是必須的，部分用途可免費獲得）。
- **使用與部署國家相符的價值集**——同樣的回答，在英國、德國和日本會得出不同的分數。
- **設計層面的啟示**：EQ-5D展示了一個微型標準化問卷加一套已釋出的計分函式，如何能產生一個具有可比性的單一指數。這也正是任何可信的開發者體驗指數應遵循的模式——標準化工具、已釋出的權重，而非臨時拍腦袋決定。參見[SPACE與開發者體驗](../SPACE與開發者體驗/)。

## 陷阱

- **沒有對照組的前後對比**——均值迴歸與自然恢復會虛增樸素的獲益數位。
- **存活者偏倚**：只測量那些持續保持參與的使用者（參見[留存與流失](../留存與流失/)）。
- **在不同研究間混用3L與5L版本或不同價值集**——會得出系統性不同的數位。
- **輕症人群中的天花板效應**：許多使用者在基線時得分就已接近1.0，導致沒有餘地展現出獲益。
- **把價值集當作不言自明**：價值集所返回的效用值，本身是透過時間權衡研究（或相關的選擇調查）從公眾那裡獲取的——具體方法見[時間權衡效用獲取法 (TTO)](../時間權衡效用獲取法/)。
