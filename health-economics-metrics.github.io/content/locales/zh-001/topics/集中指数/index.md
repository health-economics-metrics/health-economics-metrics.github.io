# 集中指数 (Concentration Index)

集中指数（Wagstaff、Paci、van Doorslaer，1991）是衡量健康变量中社会经济不平等的标准统计量。它的取值在 −1 到 1 之间：负值表示该健康变量集中在社会经济上较弱势的人群中，正值表示集中在较富裕的人群中，零表示不存在系统性的社会经济梯度。它把“分配不均”的怀疑变成一个可比较的单一数字。

## 为什么重要

一个项目可能整体看起来有效，却把几乎所有好处都送给了本来就较富裕的人。这正是[覆盖面与公平性](../触达与公平/)以描述方式追踪的分配问题——按贫困五分位分层的覆盖面，最高组与最低组之间的公平差距——但分层表格无法压缩成一条趋势线，也难以在两个用不同尺度测量的完全不同的指标之间比较。集中指数同时解决了这两个问题：它对任何健康变量、针对任何社会经济排序，都按同样方式计算，因此国家卫生服务机构可以追踪某项具体数字服务的不平等在各个版本之间是在扩大还是缩小，并在标准化尺度上，把某款应用推广的分配公平性与例如筛查项目相比较。

## 计算方法

```
CI = (2 / 均值(健康值)) × Cov(健康值, 社会经济排名)

Cov(X, Y) = 均值(X × Y) − 均值(X) × 均值(Y)   （总体协方差）

社会经济排名：每个人在社会经济分布中的分数排名，取值 [0, 1]
（0 = 最弱势，1 = 最优势；对分组/分档数据，通常取每组的中点排名）
```

这是“便捷协方差公式”（O'Donnell、van Doorslaer、Wagstaff、Lindelow，世界银行 2008）——实务者的标准捷径，可直接由配对的观测数据计算集中指数，而无需先绘制集中曲线再对其下方求积分。

## 算例

自评健康得分（1 = 最差，4 = 最好），在四个等大小的社会经济四分位上观测，每个四分位用其中点排名表示：

```
健康值              = [1.0, 2.0, 3.0, 4.0]
社会经济排名        = [0.125, 0.375, 0.625, 0.875]

均值(健康值)        = 2.5
均值(健康 × 排名)   = 均值([0.125, 0.75, 1.875, 3.5]) = 1.5625
均值(排名)          = 0.5

Cov = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

正值 `0.25` 表示这一健康得分集中在社会经济上较优势的人群中——得分较高的受访者偏向排名中较富裕的一端。

## 与软件工程的关联

这是一种基于协方差的不平等度量，与经济学中常用的度量属于同一家族（基尼系数的近亲），并可转化为衡量软件产品的收益是集中在本已占优的用户群体中，还是公平分布——是[覆盖面与公平性](../触达与公平/)（RE-AIM 的“reach”维度）的直接延伸，把描述性的差距变成正式的统计量。覆盖面与公平性是逐层报告影响，而集中指数把整个分布压缩成一个带符号的数字，适合作为跨版本追踪的单一 KPI——对放不下完整分层分布的仪表盘很实用。

## 陷阱

- **符号约定漂移**：符号取决于健康变量和排名两者的定义——颠倒任意一个都会颠倒符号，所以在报告数值时务必明确所用约定。
- **用边界排名而非中点排名**：分组或分档的社会经济数据（如五分位）需要每组在其*中点*处的分数排名，而不是边界处的排名，否则指数会有偏。
- **把“接近零”读成“没有不平等”**：集中指数接近零表示“没有系统性的社会经济梯度”，并不是绝对意义上的“没有不平等”——方向相反的不平等可能相互抵消。
