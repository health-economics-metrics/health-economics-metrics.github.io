# 지불의사 임계값

지불의사(WTP) 임계값은 의사결정자가 건강 이득 단위당 지불할 최대 금액입니다.

## 왜 중요한가

| 기관 | 임계값 |
|---|---|
| NICE(잉글랜드) | QALY당 £20,000–£30,000 |
| ICER(미국) | QALY당 $100,000–$150,000 |
| 캐나다(CADTH) | QALY당 ≈ CAD$50,000 |

## 수식

```
ICER = ΔC/ΔE < λ이면 채택
```

## 계산 예시

여러분의 디지털 치료제는 ICER £16,000/QALY를 제공합니다.

## 소프트웨어 공학과의 연관성

모든 공학 조직은 암묵적인 내부 λ를 가지고 있습니다.

## 함정

- **관할권 간 임계값 쇼핑.**
- **먼저 환산하지 않고 ICER를 다른 통화의 임계값과 비교하기**: [통화 간 ICER 비교](../cross-currency-icer-comparison/)를 참고하세요. 환산 방법(구매력평가 대 시장 환율)은 반올림의 세부 사항이 아니라 방법론적으로 중대합니다.
- **λ 기반 평가와 노동시장 기반 VSL/VPF 전통을 뒤섞기**: 이 둘은 서로 다른 이론적 전통(보건 예산 제약 방법론 대 임금-위험 상충에서 드러난 선호)에서 나와 항상 조화될 수 있는 것은 아닙니다. 생명 평가에 대한 대안적인 현시선호 접근은 [통계적 생명가치](../value-of-a-statistical-life/)를 참고하세요.
