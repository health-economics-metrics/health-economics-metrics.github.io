# 依從性與持續性 (Adherence and Persistence)

依從性衡量實際使用與處方規定使用之間的吻合程度（強度）；持續性衡量使用在中斷前持續了多長時間（時長）。藥學領域已有標準化的衡量方法——**MPR**（用藥佔有率）與**PDC**（覆蓋天數比例），兩者均以≥80%作為傳統的"依從"門檻——數位療法則繼承了這兩個概念及其背後的問題：依從性是療效與實現價值之間的乘數因子。

## 為何重要

支付方早已依賴這些數位運作：PDC≥80%被納入美國Medicare星級評定（Star Ratings）體系，直接影響支付方的實際收入——依從性是具有財務承重意義的基礎設施，而非軟性指標。數位療法也重複著同樣的模式：DiGA資料顯示處方量強勁，但持續依從性薄弱，而2026年起將在德國推行的基於結果的DTx定價，將按依從性門檻下的結果付費。來自數位健康研究的一項概念升級是：**有效參與度**（effective engagement）——達成預期結果所需的*充分*參與度，及其推論**最低有效劑量**（minimum effective dose）——這一劑量應針對每種介入措施透過實證確立，而非想當然地認為"越多越好"。

## 計算方法

```
MPR = Σ已配發供藥天數 / 期間總天數 × 100（可超過100%；
      因提前續藥而高估）
PDC = 有供藥覆蓋的天數 / 期間總天數 × 100（上限為100%；
      屬於保守估計方法，CMS傾向採用）
數位依從性 = 實際使用事件數 / 處方規定使用事件數 × 100
持續性     = 從啟動到中斷的天數
            （報告N個月時的持續使用百分比；採用生存分析方法）

價值門控：實現結果 ≈ 療效 × g(依從性)
  其中g為劑量-反應函式；低於最低有效劑量時，
  g≈0——成本已發生，收益未實現
```

## 實例演算

某數位化失眠認知行為療法（CBT）產品，處方為6周內完成6個模組；試驗療效為0.025 QALY，適用於完成≥4個模組的人群（經實證確立的最低有效劑量）：

```
1,000份處方，每份£250 → 支付方支出£250,000
模組完成情況：完成≥4個模組38%；完成1-3個模組34%；完成0個模組28%

實現的QALY = 1,000 × 0.38 × 0.025 = 9.5
每QALY成本 = 250,000 / 9.5 ≈ £26,300 —— 處於NICE閾值的邊緣

依從性工程改造（重新設計提醒機制、縮短單次時長）將
完成≥4模組的比例提升至50%：QALY增至12.5 → £20,000/QALY。該產品
在未改動療法內容本身的情況下跨過了資助門檻。
```

在2026年式的績效定價模式下，同樣的轉變將直接帶動*收入*變化——依從性工程由此成為商業路線圖的一部分。

## 與軟體工程的關聯

兩套術語體系正在匯聚到同一個概念上：軟體分析領域的[啟用](../啟用與採納/)、[黏性](../參與度指標/)、[留存](../留存與流失/)，與臨床藥學領域的MPR、PDC、持續性，衡量的其實都是對某項介入的暴露程度——將你的產品事件對映到臨床術語體系，支付方就能讀懂你的儀表盤。工程團隊掌控著依從性的關鍵槓桿：提醒邏輯（僵化的每日推送會訓練出使用者的忽略反應；自適應的提醒時機則不會）、單次使用成本（一個20分鐘的模組，完成率低於3個7分鐘模組），以及能定位使用者在治療流程中*具體在哪一步*流失的摩擦遙測資料。從第一天起就應埋點採集劑量-反應資料——決定整個經濟模型能否成立的最低有效劑量分析，需要的正是唯有產品本身才能採集到的"使用量-結果"關聯資料。

## 常見陷阱

- **混淆MPR與PDC**：MPR會虛高數值；須註明所用的估計方法，面向支付方的場景應使用PDC。
- **對指標的依從而非對療法的依從**：把開啟應用當作服藥劑量來計數（參見[參與度指標](../參與度指標/)）。
- **"越多越好"式的參與度目標**：而該介入措施本身存在有限劑量——完成療程即是成功，無限期持續使用並非目標。
- **基於倖存者的療效主張**：依從人群的結果本身就帶有選擇效應（依從的人本就不同於常人）；誠實的因果估計需要隨機化或審慎的調整方法。
