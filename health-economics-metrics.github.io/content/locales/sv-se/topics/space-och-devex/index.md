# SPACE och DevEx

SPACE och DevEx är ramverk för att mäta utvecklarproduktivitet **flerdimensionellt**.

## Varför det är viktigt

Båda ramverken innehåller samma lärdom som hälsoutfallsforskningen lärde sig för decennier sedan.

## Matematiken

```
SPACE-regel: ≥ 3 dimensioner, ≥ 1 perceptuell + ≥ 1 systemmått
```

## Genomarbetat exempel

Ett plattformsteam motiverar en DevEx-investering för 300 utvecklare.

## Koppling till mjukvaruutveckling

Detta dokument är *precis* mjukvarusidan; överföringen flödar mot hälsoekonomi.

## Fallgropar

- **Reduktion till ett enda mått.**
