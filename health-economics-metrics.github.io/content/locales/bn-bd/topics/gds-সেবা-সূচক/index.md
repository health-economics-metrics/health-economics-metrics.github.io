# GDS সেবা সূচক

যুক্তরাজ্যের Government Digital Service (GDS) সার্ভিস ম্যানুয়াল প্রতিটি সরকারি ডিজিটাল সেবার জন্য চারটি KPI বাধ্যতামূলক করে: **প্রতি লেনদেন ব্যয়, ব্যবহারকারী সন্তুষ্টি, সমাপ্তি হার, এবং ডিজিটাল গ্রহণ**।

## কেন এটি গুরুত্বপূর্ণ

GDS মেট্রিক্স চ্যানেল-শিফট ব্যবসায়িক ক্ষেত্র এনকোড করে যা সরকারি ডিজিটালাইজেশনের এক দশকে অর্থায়ন করেছে: Digital Efficiency Report দেখেছে ডিজিটাল লেনদেন ফোনের চেয়ে ~২০× সস্তা।

## গণিত

```
প্রতি লেনদেন ব্যয় = মোট সেবা ব্যয় / সম্পন্ন লেনদেন
সমাপ্তি হার      = সম্পন্ন / শুরু হওয়া লেনদেন × 100
ডিজিটাল গ্রহণ    = ডিজিটাল লেনদেন / সব-চ্যানেল লেনদেন × 100

চ্যানেল-শিফট সাশ্রয় = আয়তন × গ্রহণ শিফট × (ব্যয়_পুরনো_চ্যানেল − ব্যয়_ডিজিটাল)
```

## সমাধানকৃত উদাহরণ

একটি NHS অ্যাপয়েন্টমেন্ট-ব্যবস্থাপনা সেবা: বছরে ২০ লক্ষ লেনদেন, বর্তমানে ৭০% ফোন (£৩.২০/কল) / ৩০% ডিজিটাল (£০.২৫)। একটি পুনর্নকশা ডিজিটাল গ্রহণ ৫৫%-এ উঠায়:

```
গ্রহণ শিফট সাশ্রয় = 2M × 0.25 × (3.20 − 0.25) = বছরে £1,475,000
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

এই চারটি KPI একটি প্রোডাকশন-গ্রেড [ব্যয়-পরিণাম সারণি](../ব্যয়-পরিণাম-বিশ্লেষণ/) উদাহরণ: একটি ব্যয় মেট্রিক, তিনটি ফলাফল মেট্রিক, কখনো একটি স্কোরে সংকুচিত নয়।

## ঝুঁকিপূর্ণ দিক

- **জবরদস্তি দ্বারা গ্রহণ**: ফোন লাইন বন্ধ করা গ্রহণ বাড়ায় এবং ব্যর্থতা চাহিদা সম্মুখ-সারির কর্মীদের উপর ফেলে দেয়।
- **পৃষ্ঠা-২ থেকে পরিমাপকৃত সমাপ্তি**।
- **সহায়ক-ডিজিটাল সহায়তা উপেক্ষা করা প্রতি-লেনদেন ব্যয়**।
