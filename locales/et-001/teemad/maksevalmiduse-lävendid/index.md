# Maksevalmiduse lävendid

Maksevalmiduse lävendid määravad maksimaalse summa, mida süsteem on valmis maksma iga saavutatud QALY eest.

## Miks see on oluline

Lävend on otsustuspiir: sekkumised alla läve rahastatakse tavaliselt, sekkumisi üle läve tavaliselt mitte.

## Matemaatika

```
Rahastamisotsus: rahasta, kui ICER < lävend (£/QALY)
```

## Lahendatud näide

NICE kasutab tavaliselt £20 000–£30 000/QALY; USA kasutab mitteametlikult $50 000–$150 000/QALY; Tai kasutab umbes 1× SKT elaniku kohta.

## Seos tarkvaraarendusega

Sarnaneb sisemise "kulu vähendatud intsidendi kohta" lävendiga, mis otsustab, millised usaldusväärsuse investeeringud on seda väärt.

## Lõksud

- **Lävendite võrdlemine riikide vahel ilma ostujõu erinevusi arvestamata.**
- **Läve käsitlemine range piirina juhise asemel.**
- **ICER-i võrdlemine teises valuutas lävendiga ilma esmalt ümber arvestamata**: vaata [ICER-i võrdlemist üle valuutade](../icer-i-võrdlemine-üle-valuutade/) — ümberarvestusmeetod (ostujõupariteet vs turuvahetuskurss) on metoodiliselt otsustav, mitte ümardamisdetail.
- **λ-põhise hindamise segamine tööturu VSL/VPF-traditsiooniga**: need pärinevad eri teoreetilistest traditsioonidest (tervise eelarvega piiratud metoodika vs palga–riski kompromissidest paljastatud eelistus) ning ei ole alati ühitatavad — alternatiivse paljastatud eelistuse lähenemise kohta elu hindamisel vaata [Statistilise elu väärtust](../statistilise-elu-väärtus/).
