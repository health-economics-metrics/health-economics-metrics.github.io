# 순금전편익(NMB)

NMB는 비용효과 결과를 단일 금전적 가치로 전환합니다: 지불의사 임계값으로 평가된 건강 이득에서 비용을 뺀 것입니다.

## 왜 중요한가

비율([ICER](../incremental-cost-effectiveness-ratio/))은 다루기 어렵습니다: 효과가 0에 가까워지면 폭발합니다. NMB는 선형적입니다.

## 수식

```
NMB = (ΔE × λ) − ΔC
```

## 계산 예시

당뇨병 서비스의 세 가지 옵션, λ = £20,000/QALY.

## 소프트웨어 공학과의 연관성

`(절약된 시간 × 완전 배분된 시간당 요율) − 도구 비용`.

## 함정

- **임계값 숨기기.**
