# 추론 단위 경제학

추론 단위 경제학은 AI 모델의 개별 예측 또는 생성당 비용을 측정합니다.

## 왜 중요한가

훈련 비용은 일회성이지만 추론 비용은 사용량에 비례하여 무한히 반복됩니다.

## 수식

```
추론당 비용 = (GPU 시간당 비용 × 처리 시간) / 요청 수
```

## 계산 예시

영상 판독 지원 모델: GPU £2/시간, 1,000건/시간 처리 = 판독당 £0.002.

## 소프트웨어 공학과의 연관성

[클라우드 단위 경제학](../클라우드-단위-경제학/)의 AI 특화 사례이며 [AI 투자수익률](../ai-투자수익률/)의 핵심 입력입니다.

## 함정

- **배치 처리 할인을 무시하고 개별 요청 비용으로 계산하기.**
