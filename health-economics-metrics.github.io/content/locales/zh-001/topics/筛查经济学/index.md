# 筛查经济学

筛查经济学支配着对无症状人群进行检测的价值。其核心数学事实是：**在低患病率条件下，即便是极其优秀的检测方法，产生的结果也大多是假阳性**——而追查这些假阳性所带来的下游成本，足以淹没真正发现病例所带来的收益。

## 为何重要

自1968年以来，WHO的Wilson–Jungner标准一直是人群筛查的准入门槛：该病症必须重要、检测手段必须可接受且准确、必须存在有效的治疗方法，且经济学上必须能够平衡。英国国家筛查委员会在批准任何一项全国性项目之前，都会开展正式的成本效果分析——并否决大多数提案。每一个"AI将为所有人筛查一切"的推介方案，最终都会撞上这套机制，而且通常会败给下面这套算术。

## 计算方法

阳性预测值（PPV）——即一个阳性结果为真的概率——在低患病率下会急剧崩塌：

```
PPV = (灵敏度 × 患病率) / [灵敏度 × 患病率 + (1 − 特异度) × (1 − 患病率)]

例：灵敏度90%，特异度95%，患病率0.5%：
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

每十二次阳性结果中就有十一次是假的。完整的项目层面经济学：

```
每例真阳性的成本 = (筛查成本 + 核查成本 × 所有阳性结果数) / 真阳性数
随后需追问：发现一例是否值得这个价钱？（每例更早干预的价值，
          减去过度诊断的危害——那些本来根本不重要的被发现病例）
```

## 实例演算

某罕见病症的AI视网膜筛查，覆盖10万人，患病率0.5%，灵敏度90%，特异度95%，每次扫描£15，确诊性核查每次£400：

```
真阳性数：  100,000 × 0.005 × 0.90 = 450
假阳性数：  100,000 × 0.995 × 0.05 = 4,975
成本 = 100,000 × 15 + (450 + 4,975) × 400 = £150万 + £217万 = £367万
每例真阳性成本 ≈ £8,156
```

如果早期治疗每例能节省£20,000外加1个QALY，该项目能轻松通过检验。将特异度提高到99%（减少误报）：核查成本降至(450 + 995) × 400 = £58万，总成本£208万，每例成本降至约**£4,622**——在低患病率条件下，筛查经济学的胜负手在于特异度，而非灵敏度。

## 与软件工程的联系

静态分析、安全扫描与异常检测，本质上都是针对代码库与遥测数据的筛查项目，其真实缺陷的患病率，往往每次告警机会远低于1%。完全相同的数学原理解释了告警疲劳：一个特异度95%的扫描工具，在低患病率的代码上运行，会让团队被假阳性淹没，而每一次假阳性都会消耗注意力、侵蚀信任，直到真正的告警也开始被忽视（临床术语称之为*筛查危害*；工程术语则称之为*寻呼机麻木*）。其应对方法可以从医疗领域直接迁移过来：先提高特异度，再考虑灵敏度；对患病率更高的子人群进行筛查（基于风险的定向筛查 ↔ 仅对已变更代码进行扫描）；并将分诊成本计入该工具的经济学核算之中——参见[NNT](../需治疗人数/)与[临床AI评估](../临床AI评估/)。 关于整个筛查项目（而不是单个检验）的规模，见[需要筛查人数](../需要筛查人数/)——要有多少人走完整个筛查再治疗的路径才能预防一例结局。

## 陷阱

- **只报告灵敏度/特异度而不说明患病率**——脱离PPV谈准确率，不过是营销话术。
- **忽视过度诊断**：发现那些本来根本不会造成伤害的惰性"疾病"，却触发了真实的治疗成本与伤害。
- **前导时间偏倚**：在未改变最终结果的情况下更早发现疾病，会人为夸大表观生存率——参见[更早干预](../更早干预/)。
