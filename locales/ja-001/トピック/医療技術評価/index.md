# 医療技術評価(HTA)

HTAは、医療システムがある技術 — 医薬品、機器、ソフトウェア — に対価を支払う価値があるかどうかを決定する、正式で制度化されたプロセスです。これは、公表された義務的な手法のもとで、臨床的有効性の証拠と経済評価を組み合わせます。

## なぜ重要か

国の医療サービスに販売するなら、HTA機関は文字通りあなたの市場アクセスを決定するかもしれません。地域のプロセスを知ることは、あなたの本当の価値の規制当局を知ることです:

- **NICE(イングランド)**:定義された*基準ケース*のもとでの法定評価 — [EQ-5D](../eq-5d/)からのQALY、NHS+PSSの[視点](../分析の視点/)、3.5%の[割引](../割引と時間選好/)、[PSA](../確率的感度分析/)が必要 — [重症度修正因子](../qaly不足分と重症度修正因子/)を伴う£20k〜£30k/QALYに照らして判断される;高度専門技術は重み付けを伴い£100k以上まで。
- **ICER(米国、非政府組織)**:*健康便益価格ベンチマーク*を伴うエビデンスレポート — QALY/evLYGあたり$100k〜$150kで製品が費用効果的になる価格 — 交渉材料として使われる;加えて予算影響の「手頃さアラート」。
- **カナダ(CADTH → CDA-AMC)**:約CAD$50k/QALYでの償還レビュー;歴史的に、申請の約95%で価格引き下げを要求してきました。

## 数式

HTAの力は公式ではなく**義務付けられた手法**にあります:すべての申請は同じ基準ケースのルールのもとで同じ[ICER](../増分費用効果比/)を計算するため、結果は製品や年にわたって比較可能です。基準ケースは、アウトカム測定、効用の測定手法、視点、比較対象の選択、割引率、評価期間、不確実性分析を規定します — スポンサーがごまかせるすべての自由度を取り除きます。

## 計算例

あるデジタル治療薬がNICE式の評価に申請します:

```
モデル:ΔC = +£450/患者、ΔE = +0.03QALY → ICER = £15,000/QALY ✓ £20k未満
基準ケースの確認:
  UKの価値セットを用いたEQ-5D-5Lからの効用              ✓
  比較対象 = 現在のケア経路(「治療なし」ではない)      ✓
  PSA:£20kで費用効果的である確率71%                    ✓(報告済み)
  重症度修正因子:×1.2の境界を下回る不足分               — 主張なし
推奨:実世界データ収集を伴う通常のコミッショニング。
```

スポンサー自身の好ましい分析は£9,000/QALYを示していました;基準ケースは、正直な比較対象を強制することで、それを£15,000まで押し上げました。そのギャップこそが、基準ケースが存在する*理由*です。

## ソフトウェア工学との関連

転用できる成果物は**内部基準ケース**です:すべてのツール/プラットフォームのビジネスケースに対する1つの義務的な手法 — 明示された比較対象、標準的な単位費用([全国診療報酬と単位費用](../全国診療報酬と単位費用/)のパターンを参照)、固定された割引率、必須の感度分析、標準テンプレート。プラットフォーム評議会に提出される「ツールのためのAMCPドッシエ」は、医療にとってのHTAとまったく同じように、提案を比較可能にし、ごまかしを可視化します。NICEよりも小さく始めてください:2ページのテンプレートと公表された価格表は、標準が何もないよりましです。

複数サイクルのHTAモデルが実際にコホートごと、サイクルごとにどうシミュレートされるかについては、[マルコフコホートシミュレーション](../マルコフコホートシミュレーション/)を参照してください。

## 落とし穴

- **HTAを規制上の許可の後の形式として扱うこと** — CE/UKCA/FDAの許可は製品が安全であることを示しますが、HTAはそれが*買う価値がある*かどうかを決定します。異なるハードル、異なる証拠です。
- **試験の後に経済モデルを構築すること** — 証拠の生成は、基準ケースの要件から逆算して設計されるべきです。
- **管轄区域の違いを無視すること**:米国で$120k/QALYで資金提供可能なICERは、£30kのNICEでは失敗します;市場ごとに証拠と価格設定を計画してください。
