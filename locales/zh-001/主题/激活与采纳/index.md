# 激活与采纳 (Activation and Uptake)

激活率是指达到首次有意义价值（即"顿悟"时刻——首次记录读数、完成首堂课程等关键行动）的注册用户占比。采纳率则是其人群层面的对应指标：*符合条件*人群中最终采用该产品的比例。二者共同构成价值漏斗的前端关口：获客 → 采纳 → 激活 → [留存](../留存与流失/) → 结果。

## 为何重要

未激活用户纯属成本：获客支出、开通配置、支持成本，却没有产生任何临床价值。基准数据显示，医疗软件的激活率*低于*跨行业平均水平（某SaaS基准数据集中，新用户激活率约为24%，而跨行业平均约为37%；引导清单完成率约为20%），这反映了医疗场景中更繁重的引导流程（身份核验、知情同意、临床安全）。采纳率则关乎整个人群层面的利害得失：按照[RE-AIM框架](../触达与公平/)，公共卫生影响≈覆盖率×有效性——一款再优秀的应用，如果只被3%的符合条件人群采用，其人群层面的影响力也仅相当于3%。对于处方类数字疗法，采纳这道关口在国家层面的数据中清晰可见：**德国DiGA处方中约81%被激活使用**——五分之一已开具且已付费的治疗方案从未真正开始（参见[DiGA快速通道](../德国DiGA快速通道/)）。

## 计算方法

```
激活率     = 在窗口期内完成关键行动的用户数 / 注册用户数 × 100
采纳率     = 采用者数 / 符合条件人群数 × 100
DTx激活率  = 已激活处方码数 / 已开具处方数 × 100

漏斗价值模型：
  符合条件人数 × 采纳率 × 激活率 × 留存加权收益 = 人群价值
  ——共四次相乘；改进其中最小的因子通常
  影响最大（漏斗场景下的约束理论）
```

## 实例演算

某委托方向80,000名符合条件的居民提供一款糖尿病预防应用：

```
邀请 → 注册：  80,000 → 12,000（采纳率15%）
注册 → 激活（首次使用会话 + 设定目标，7天内）：12,000 → 5,400（45%）
激活 → 完成6个月项目：5,400 → 1,600（30%）

项目效果（试验数据，完成者）：0.03 QALY + £180 避免成本
人群价值 = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
每名符合条件人员的价值 = £15.6 —— 若每位符合条件人员都完成项目，则为£780。

该投资何处？将采纳率翻倍（15%→30%）可使价值翻倍；将
激活率从45%提升至65%可增加约44%的价值；这两者都优于
继续打磨那1,600名已完成者所使用的项目内容。
```

## 与软件工程的关联

激活是漏斗中工程可控性最强的阶段：身份验证摩擦、知情同意流程、空状态设计以及首次价值实现时间，都是代码问题而非政策问题（基准数据显示医疗领域的价值实现时间中位数约为1天7小时——每多耗一小时都意味着流失风险的增加）。采纳则是一个分发系统问题：融入转诊路径（开处方的那一刻）、全科医生背书的邀请（信任转移）以及无障碍可及性（语言、数字技能——参见[覆盖与公平](../触达与公平/)）。上述漏斗价值模型正是这两者商业论证的生成器：将各因子相乘，找出瓶颈约束，再按其释放的人群价值为修复方案定价。

## 常见陷阱

- **将激活定义为便利性事件**（如邮箱已验证）而非临床意义事件（如首次治疗性行动）——会虚增该指标，破坏价值链。
- **采纳率分母的花招**："在访问过网站的人中"而非真正符合条件的人群——委托方关心的是后者。
- **选择效应**：容易被激活的用户往往病情最轻、处境最不弱势；漏斗改进措施可能在提升平均水平的同时扩大公平差距。
