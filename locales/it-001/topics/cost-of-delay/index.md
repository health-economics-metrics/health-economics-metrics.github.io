# Costo del Ritardo (CoD)

Il costo del ritardo è il valore economico perso per unità di tempo in cui una funzionalità, prodotto o servizio *non* viene consegnato.

## Perché è importante

La regola di Reinertsen: "Se misurate solo una cosa, misurate il Costo del Ritardo."

## La matematica

```
CoD = beneficio perso per unità di tempo mentre non consegnato (£/settimana o QALY/settimana)
```

## Esempio risolto

**Operativo**: un software fa risparmiare £200 per paziente in un percorso; CoD = £10.000/settimana.

## Collegamento con l'ingegneria del software

Il CoD è la metrica che rende [il lead time DORA](../dora-metrics/) finanziariamente leggibile.

## Insidie

- **Assumere che il CoD sia lineare.**
