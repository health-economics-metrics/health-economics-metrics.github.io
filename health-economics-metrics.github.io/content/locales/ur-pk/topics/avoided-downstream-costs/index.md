# ٹالی گئی ڈاؤن اسٹریم لاگت

ٹالی گئی ڈاؤن اسٹریم لاگت (لاگت کی ایڈجسٹمنٹ) وہ مستقبل کے علاج کے اخراجات ہیں جنہیں پہلے یا بہتر کارروائی کے ذریعے روکا جاتا ہے۔

## یہ کیوں اہم ہے

تقریباً ہر ڈیجیٹل صحت کی قدر کی تجویز میں ایک ایڈجسٹمنٹ کا دعویٰ ہوتا ہے: "ہماری ایپ داخلے کو روکتی ہے۔"

## ریاضی

```
خالص قیمت = مداخلت کی قیمت − Σ ایڈجسٹمنٹ

ایک درست ایڈجسٹمنٹ ہونا چاہیے:
  قابل اعتبار — مداخلت سے وجہی طور پر جڑا ہوا
  حاشیائی    — پیسہ واقعی خرچ ہونا بند ہو جاتا ہے
  امکان-    — P(ڈاؤن اسٹریم واقعہ ہوتا) کے ذریعے وزن دار
  وزن دار
```

## حل شدہ مثال

5,000 سرجری کے بعد کے مریضوں کے لیے ایک زخم-نگرانی ایپ انفیکشن سے متعلق دوبارہ داخلے سے بچاؤ کا دعویٰ کرتی ہے: خالص قیمت = −£44,000 → واقعی قیمت بچانے والا۔

## سافٹ ویئر انجینئرنگ سے تعلق

"یہ منتقلی مستقبل کی دوبارہ تحریر سے بچاتی ہے" ایک ایڈجسٹمنٹ کا دعویٰ ہے۔
