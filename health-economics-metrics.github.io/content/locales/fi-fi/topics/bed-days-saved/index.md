# Säästetyt vuodepäivät

Säästetyt vuodepäivät mittaavat, kuinka monta päivää sairaalahoitoa interventio välttää — yleinen mittari digitaalisten terveydenhuollon interventioiden arvolle.

## Miksi se on tärkeä

Vuodepäivät ovat liiketoimintatapausten yleisin "työjuhta"-hyöty, mutta ne arvostetaan usein väärin käyttämällä keskimääräistä rajakustannuksen sijaan.

## Matematiikka

```
Säästetyt vuodepäivät = Σ (vältetyt sisäänotot × keskimääräinen hoitoaika)
```

## Ratkaistu esimerkki

Varhaisen kotiutuksen ohjelma välttää 500 sisäänottoa keskimäärin 4 päivän ajalta: 2 000 säästettyä vuodepäivää, arvostettuna rajakustannuksella £150/päivä = £300 000.

## Yhteys ohjelmistokehitykseen

Muistuttaa säästettyjen palvelininstanssien arvostamista laskennan rajakustannuksella, ei keskimääräisellä kustannuksella mukaan lukien kiinteät yleiskustannukset.

## Sudenkuopat

- **Vuodepäivien arvostaminen keskimääräisellä rajakustannuksen sijaan — katso [rajakustannus vastaan keskimääräinen kustannus](../marginal-vs-average-cost/).**
- **Oletus, että vapaa paikka käytetään automaattisesti uudelleen.**
