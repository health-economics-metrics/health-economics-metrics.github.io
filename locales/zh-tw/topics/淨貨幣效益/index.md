# 淨貨幣效益（NMB）

NMB將一項成本效果結果轉化為單一的貨幣數值：按支付意願閾值為健康獲益定價，再減去成本。它的孿生指標——淨健康效益（NHB），則以健康單位來表達同一條規則。

## 為何重要

比值型指標（如[ICER](../增量成本效果比/)）用起來頗為棘手：當效果趨近於零時會發生爆炸性變化，無法在不確定性抽樣中直接取平均，也無法清晰地對三個及以上的方案進行排序。NMB解決了這一切問題——它是線性的，因此你可以對方案排序、對蒙特卡洛抽樣結果取平均、並分解各項貢獻。它同時也正是每一位工程師早已熟悉的那種健康經濟學數學形式：*價值減去成本*。

## 計算方法

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = 增量效果（例如QALY）
ΔC = 增量成本
λ  = 支付意願閾值（參見willingness-to-pay-thresholds.md）

決策規則：若NMB > 0則採納（等價於NHB > 0）。
在多個備選方案中：應選擇NMB最高的那一個。
```

NMB > 0 ⇔ ICER < λ（當ΔE > 0時），因此這兩條規則是一致的——NMB只是表現得更為穩定規整。

## 實例演算

針對某糖尿病服務的三個方案，按每1,000名病患計算，λ = £20,000/QALY：

```
方案              ΔC           ΔE (QALY)   NMB = 20,000×ΔE − ΔC
應用+輔導          £400,000     30          600,000 − 400,000 = £200,000
僅應用             £150,000     12          240,000 − 150,000 = £90,000
增設門診           £700,000     32          640,000 − 700,000 = −£60,000
```

"增設門診"方案獲得的QALY最多，但在這一閾值下反而毀損了價值（NMB < 0）。"應用+輔導"方案勝出。請注意，NMB能讓你*一次性對所有三個方案同時排序*——若用兩兩比較的ICER，則需要藉助[佔優關係與效率前沿](../佔優關係與效率前沿/)中的前沿法，但最終會得出相同的結論。

以NHB視角看待獲勝方案：30 − 400,000/20,000 = 30 − 20 = **淨獲益10個QALY**——即相對於把同樣這筆錢花在其他地方所能產生的健康獲益，這項方案額外獲得的健康價值。

## 與軟體工程的聯絡

`(節省的工時 × 負荷小時費率) − 工具成本`——這正是日常工具類商業案例的標準演算法——本質上就是一次以λ = 工程師負荷成本為引數的NMB計算。健康經濟學在此基礎上帶來了兩點升級：

- **讓λ成為一個變數，而非一個常數。**將NMB相對λ（"一個工程師-小時的價值"）作圖，展示決策在何處發生翻轉；不同的利益相關方就可以據此代入自己的估值，而無需重新做你的數學計算。
- **NHB式思維**："這個平臺節省了5,000個工程師-小時，但所消耗的預算原本足以購買3,000個工程師-小時的承包商產能——淨收益為2,000小時"，這種表述方式強制以產能單位來進行機會成本比較。參見[機會成本](../機會成本/)。

## 陷阱

- **隱藏閾值**：不說明λ，NMB就毫無意義；應在£20,000和£30,000兩種閾值下分別報告NMB，或直接繪製曲線。
- **用NMB來"洗白"微不足道的效應**：一個龐大的人群規模乘以一個微不足道的人均效應，也能產生一個看起來很大的NMB數位——應同時報告人均效應。
- **忘記NMB會繼承ΔC與ΔE各自攜帶的一切不確定性**——應搭配[機率敏感性分析](../機率敏感性分析/)一併使用。
