# การประเมินมูลค่าออปชันจริง

การประเมินมูลค่าออปชันจริงนำตรรกะการตั้งราคาออปชันทางการเงินมาใช้กับการตัดสินใจลงทุนจริง (ไม่ได้ซื้อขายในตลาดการเงิน) — โดยเฉพาะ *ออปชันขยาย* คือสิทธิ์ที่จะขยายโครงการภายหลังหากประสบความสำเร็จ โดยไม่ต้องทำ แบบจำลองทวินามช่วงเดียวอย่างง่าย (Cox, Ross, Rubinstein, 1979) ตีมูลค่าความยืดหยุ่นนี้โดยตรง เปลี่ยน "ส่งมอบเล็กๆ แล้วดู" จากสัญชาตญาณเป็นตัวเลขที่ตั้งราคาได้

## ทำไมจึงสำคัญ

การคำนวณมูลค่าปัจจุบันแบบคงที่ตั้งราคาโครงการเป็นการเดิมพันแบบทั้งหมดหรือไม่เลย: ให้ทุนหรือไม่ ที่ขนาดวันนี้ ตลอดไป โครงการจริง — และโดยเฉพาะการเปิดตัวสุขภาพดิจิทัลเป็นระยะ — แทบไม่ได้ตั้งขึ้นแบบนั้น ระบบสุขภาพอาจให้ทุนโครงการนำร่องเล็กๆ ดูว่าเกิดอะไรขึ้น และผูกเงินเพิ่มก็ต่อเมื่อมันได้ผล ความยืดหยุ่นนั้นมีมูลค่าจริง และการละเลยมันประเมินการลงทุนเป็นระยะต่ำกว่าการลงทุนครั้งเดียวอย่างเป็นระบบ ซึ่งตรงข้ามกับกระบวนการจัดซื้อที่ให้รางวัลข้อเสนอเป็นระยะที่ดูปลอดภัยกว่า การประเมินมูลค่าออปชันจริงตั้งราคาความยืดหยุ่นเอง เพื่อให้เปรียบเทียบข้อเสนอเป็นระยะกับทางเลือกผูกมัดเต็มที่ได้อย่างเป็นธรรม แทนที่จะถูกลงโทษเพราะดูเล็กกว่าในบรรทัดมูลค่าปัจจุบันอย่างไร้เดียงสา

## คณิตศาสตร์

```
ความน่าจะเป็นแบบเสมือนเป็นกลางต่อความเสี่ยงของสถานะ "ขึ้น":
  p = ((1 + อัตราดอกเบี้ยปลอดความเสี่ยง) − ตัวคูณลง) / (ตัวคูณขึ้น − ตัวคูณลง)

ผลตอบแทนจากการขยายในแต่ละสถานะ (มีขอบล่างที่ศูนย์ — การขยายเป็นทางเลือก):
  ผลตอบแทน_ขึ้น = max(มูลค่าโครงการ × ตัวคูณขึ้น − ต้นทุนการขยาย, 0)
  ผลตอบแทน_ลง  = max(มูลค่าโครงการ × ตัวคูณลง − ต้นทุนการขยาย, 0)

มูลค่าออปชัน (ผลตอบแทนคาดหวังคิดลด):
  มูลค่าออปชัน = (p × ผลตอบแทน_ขึ้น + (1 − p) × ผลตอบแทน_ลง) / (1 + อัตราดอกเบี้ยปลอดความเสี่ยง)

NPV ขยาย = npv_คงที่ + มูลค่าออปชัน
```

มูลค่าโครงการขึ้น (`ตัวคูณขึ้น`) หรือลง (`ตัวคูณลง`) จนถึงจุดตัดสินใจถัดไป ใช้สิทธิ์ขยายเฉพาะเมื่อมันทำกำไรในสถานะนั้น — ขอบล่างที่ศูนย์ของผลตอบแทนคือสิ่งที่ทำให้มันเป็น *ออปชัน* จริงๆ ไม่ใช่ข้อผูกมัด สำหรับวิธีตีมูลค่าสิทธิ์ที่จะเก็บข้อมูลก่อน แทนสิทธิ์ที่จะขยายภายหลัง ดู[มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ](../มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ/) สำหรับต้นทุนของการรอการตัดสินใจนี้ ดู[ต้นทุนของความล่าช้า](../ต้นทุนของความล่าช้า/)

## ตัวอย่างที่คำนวณแล้ว

โครงการนำร่องบริการดิจิทัลที่ `มูลค่าโครงการ = £1,000,000` ซึ่งอาจขึ้น 1.5 เท่าหรือลงเหลือ 0.5 เท่าจนถึงจุดตัดสินใจถัดไป อัตราดอกเบี้ยปลอดความเสี่ยง 8% และต้นทุนการขยาย £600,000:

```
p = (1.08 − 0.5) / (1.5 − 0.5) = 0.58

ผลตอบแทน_ขึ้น = max(1,000,000 × 1.5 − 600,000, 0) =  900,000
ผลตอบแทน_ลง  = max(1,000,000 × 0.5 − 600,000, 0) = max(−100,000, 0) = 0

ขอบล่างมีผล: จะ *ไม่* ใช้ออปชันหากตลาดผิดหวัง —
ต้นทุนการขยาย £600,000 เกิน £500,000 ที่โครงการมีค่าในสถานะ "ลง"

มูลค่าออปชัน = (0.58 × 900,000 + 0.42 × 0) / 1.08
             = 522,000 / 1.08
             ≈ £483,333.33
```

เมื่อบวกมูลค่าออปชันเข้ากับฐาน NPV คงที่ £200,000: NPV ขยาย = 200,000 + 483,333.33 ≈ **£683,333.33** การรายงานเฉพาะ NPV คงที่ £200,000 โดยไม่มีมูลค่าของออปชันนี้จะประเมินมูลค่าจริงของโครงการเป็นระยะต่ำกว่าสองเท่า

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือรูปแบบทางการของ "ส่งมอบเวอร์ชันขั้นต่ำตอนนี้ รักษาสิทธิ์ที่จะลงทุนเพิ่มหากมันติด" — เกี่ยวข้องโดยตรงกับการเปิดตัวผลิตภัณฑ์สุขภาพดิจิทัลเป็นระยะ ขนานเชิงโครงสร้างกับกรอบการจัดลำดับภายใต้ความไม่แน่นอนใน[ต้นทุนของความล่าช้า](../ต้นทุนของความล่าช้า/)และ[WSJF และ CD3](../wsjf-และ-cd3/) และเสริม[มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ](../มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ/)และ[มูลค่าคาดหวังของข้อมูลตัวอย่าง](../มูลค่าคาดหวังของข้อมูลตัวอย่าง/) — ทั้งสามตั้งราคาความยืดหยุ่นหรือข้อมูลภายใต้ความไม่แน่นอนจากมุมต่างกัน

## ข้อผิดพลาดที่พบบ่อย

- **ยืมการตั้งราคาแบบเสมือนเป็นกลางต่อความเสี่ยงโดยไม่มีข้อสมมติสินทรัพย์ที่ซื้อขายได้ที่มันพึ่งพา**: แบบจำลองออปชันจริงยืมความน่าจะเป็นแบบเสมือนเป็นกลางต่อความเสี่ยงจากการตั้งราคาออปชันทางการเงิน ซึ่งสมมุติว่ามูลค่าพื้นฐานเป็นสินทรัพย์ที่ *ซื้อขายได้* — สำหรับโครงการจริงที่ซื้อขายไม่ได้อย่างแท้จริง นี่คือความสะดวกในการสร้างแบบจำลอง ไม่ใช่ข้อเท็จจริงของตลาดตามตัวอักษร
- **ถือ `ตัวคูณขึ้น`/`ตัวคูณลง` เป็นพารามิเตอร์อิสระ**: ข้อมูลเข้าขึ้น/ลงของทวินามเองเป็นข้อสมมติที่ต้องมีเหตุผลรองรับ ไม่ใช่พารามิเตอร์อิสระที่เลือกเพื่อให้ได้คำตอบที่ต้องการ
- **รายงานเฉพาะมูลค่าออปชัน**: มูลค่าของออปชันจริง *บวกเพิ่ม* เข้ากับ NPV คงที่ของโครงการเดี่ยว ข้อผิดพลาดที่พบบ่อยคือรายงานเฉพาะมูลค่าออปชันและละกรณีฐาน ซึ่งขยายกรณีเมื่อ NPV คงที่เป็นลบ และประเมินต่ำเกิน (ดังตัวอย่างข้างต้น) หากละ NPV คงที่ทั้งหมด
