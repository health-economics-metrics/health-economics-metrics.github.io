# Costi a Valle Evitati

I costi a valle evitati (compensazioni di costo) sono le spese future di trattamento prevenute da un'azione anticipata o migliore.

## Perché è importante

Quasi ogni proposta di valore per la sanità digitale contiene un'affermazione di compensazione: "la nostra app previene i ricoveri."

## La matematica

```
Costo netto = costo dell'intervento − Σ compensazioni

Una compensazione valida deve essere:
  Attribuibile — causalmente collegata all'intervento
  Marginale — il denaro smette effettivamente di essere speso
  Ponderata per probabilità — dall'evento a valle P(si sarebbe verificato)
```

## Esempio risolto

Un'app di monitoraggio delle ferite per 5.000 pazienti post-chirurgici: costo netto = −£44.000 → genuinamente risparmia costi.

## Collegamento con l'ingegneria del software

"Questa migrazione evita una futura riscrittura" è un'affermazione di compensazione.
