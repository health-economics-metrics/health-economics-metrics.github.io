# पूर्व हस्तक्षेप

यदि बचाई गई क्षमता एक चिकित्सक को नैदानिक बैकलॉग की जल्दी समीक्षा करने देती है, तो रोगी प्रतीक्षा सूची से सक्रिय उपचार में तेज़ी से आगे बढ़ते हैं।

## यह क्यों महत्वपूर्ण है

रोग की प्रगति स्वास्थ्य सेवा का चक्रवृद्धि ब्याज है।

## गणित

```
पूर्व हस्तक्षेप का मूल्य (प्रति रोगी) =
    [लागत_देर − लागत_पूर्व]
  + [QALY_पूर्व − QALY_देर] × λ
  × P(विलंब के दौरान प्रगति)
```

## हल किया गया उदाहरण

डायबिटिक रेटिनोपैथी स्क्रीनिंग बैकलॉग: 4,000 रोगी, 6 महीने पीछे।

```
मूल्य ≈ 27 × (4,000 + 16,000) ≈ £540,000
```
