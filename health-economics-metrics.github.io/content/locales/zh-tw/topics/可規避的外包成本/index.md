# 可規避的外包成本

當信託機構無法僅憑內部產能達成目標時，便會以溢價購買產能：自有員工的週末加班，或將診療流程外包給私營醫療機構。釋放產能類軟體的經濟價值，包括**這部分溢價工作中可被規避的成本**。

## 為何重要

在擇期手術積壓恢復的壓力之下，信託機構經常按私營部門現價（通常為NHS標準價格的1.2–1.5倍）付費，或向本機構顧問醫師支付週末專項名單的溢價費用。與普通的產能類主張不同，規避外包屬於**現金釋放型**收益：付給私營機構的賬單確確實實不再產生。這使其成為能提升內部吞吐量的軟體所能主張的最有力效益線之一——也是最容易舉證的一種，因為外包支出本身就已經是一條清晰可見的預算科目。

## 計算方法

```
可規避外包成本 = 轉回內部完成的診療量 × (外包單價
                − 內部邊際成本/例)

內部邊際成本：為額外活動所需的耗材 + 可變人力成本
——固定場地設施成本無論如何都已支付（參見marginal-vs-average-cost.md）。
```

該主張成立的前提是：被釋放的內部產能確實能夠承接這部分活動——手術室時段、床位和人員必須同時具備（起決定作用的仍是那個約束瓶頸——又是約束理論）。

## 實例演算

某信託機構每年將800例白內障手術外包，每例£900：即每年£720,000的外部支出，而標準價格約為£750。

手術室排程軟體（名單最佳化、利用取消空檔回填、週轉時間追蹤）使內部手術室利用率提升，足以將其中500例轉回內部完成：

```
每例內部邊際成本 ≈ £350（耗材+按場次計的人力成本）
節省 = 500 × (900 − 350) = 每年£275,000——現金釋放型
剩餘外包量：300 × £900 = £270,000（原為£720,000）
```

軟體成本每年£90,000 → 淨收益約為**每年+£185,000的可入賬現金**，此外還有內部保留該工作所帶來的品質與培訓方面的額外收益。

## 與軟體工程的聯絡

其直接對應物是**外包承包商與諮詢溢價**：當內部工程產能無法滿足承諾的交付時，組織會以1.5–3倍於內部負荷成本的價格購買外部產能。能提升內部吞吐量的平臺與生產力投資，應當按照與上文完全相同的方式主張"規避的承包商支出"——外部日費率減去內部邊際成本，再乘以轉回內部完成的工作量——因為這是開發者生產力商業案例中少數真正屬於現金釋放型的效益線之一。同樣的告誡在此依然適用：內部產能必須確實存在，並被實際排入轉回內部的工作，否則這一主張就只是虛構。

## 陷阱

- **在缺乏完整產能鏈條的情況下主張轉回內部完成**——外科醫師被釋放出來了，卻沒有手術室時段（或工程師被釋放出來了，卻沒有產品管理頻寬）——這樣的"轉回"其實什麼也沒轉回。
- **將外包價格與內部平均成本而非邊際成本比較**——說來矛盾，這樣反而會低估實際節省，因為固定成本無論如何都會產生。
- **品質/複雜度的不對稱性**：被外包的病例往往是相對簡單的那些；將其轉回內部會改變內部的病例結構與單位成本。
