# क्लिनिकल AI मूल्यांकन

एक क्लिनिकल AI या डायग्नोस्टिक मॉडल का मूल्यांकन करने के लिए मूल आँकड़े: संवेदनशीलता, विशिष्टता, AUROC। केंद्रीय आर्थिक सबक: **एक शानदार AUROC एक लागत-प्रभावी तैनाती नहीं बनाता**।

## यह क्यों महत्वपूर्ण है

नियामक (FDA, MHRA) एक **लॉक किए गए ऑपरेटिंग पॉइंट** पर क्लिनिकल AI को अधिकृत करते हैं।

## गणित

```
संवेदनशीलता = TP / (TP + FN)
PPV = TP / (TP + FP) ← प्रसार-निर्भर
```

## हल किया गया उदाहरण

एक ही मॉडल, दो सेटिंग्स:

```
विशेषज्ञ क्लिनिक (प्रसार 20%): PPV ≈ 76%
प्राथमिक देखभाल (प्रसार 1%): PPV ≈ 11.5%
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

क्लिनिकल AI बनाने या खरीदने वाले इंजीनियरों के लिए: तैनाती प्रसार पर कन्फ्यूजन मैट्रिक्स भेजें।
