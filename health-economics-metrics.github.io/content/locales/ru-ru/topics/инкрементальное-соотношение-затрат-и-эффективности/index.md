# Инкрементальное соотношение затрат и эффективности (Incremental Cost-Effectiveness Ratio, ICER)

ICER — это дополнительная стоимость на дополнительную единицу эффекта для здоровья при выборе одного варианта вместо следующего по предпочтительности альтернативного. Это заглавная цифра оценки медицинских технологий. (Когда единица эффекта — QALY, её также называют инкрементальным соотношением «затраты-полезность», ICUR.)

## Почему это важно

Системы здравоохранения никогда не оценивают технологию изолированно — всегда *инкрементально*, относительно того, что было бы сделано иначе. NICE сравнивает ICER технологии со своим порогом **£20 000–£30 000 за QALY**; американский ICER Institute отчитывается в диапазоне $50 000–$200 000/QALY; Канада работает примерно на уровне CAD$50 000/QALY. «Стоит ли того» ваш продукт для национальной системы здравоохранения формально сводится к тому, преодолевает ли его ICER локальный порог. См. [пороги готовности платить](../пороги-готовности-платить/).

## Математика

```
ICER = (Стоимость_новый − Стоимость_компаратор) / (Эффект_новый − Эффект_компаратор)
     = ΔC / ΔE
```

Правила интерпретации:

- ΔC < 0, ΔE > 0: новый вариант **доминирует** — дешевле и лучше; коэффициент не нужен.
- ΔC > 0, ΔE > 0: вычислите ICER, сравните с порогом λ; принимайте, если ICER < λ.
- ΔC > 0, ΔE < 0: новый вариант доминируется — отклоняйте.
- Коэффициенты плохо ведут себя вблизи ΔE = 0 — предпочитайте [чистую денежную выгоду](../чистая-денежная-выгода/) для ранжирования.

Компаратор должен быть *следующим лучшим недоминируемым вариантом*, а не «ничего не делать» — см. [доминирование и границу эффективности](../доминирование-и-граница-эффективности/).

## Практический пример

Служба удалённого мониторинга пациентов с сердечной недостаточностью, на 1 000 пациентов/год, против обычной помощи:

```
Затраты: услуга £900,000; предотвращённые госпитализации экономят £600,000
         ΔC = 900,000 − 600,000 = £300,000
Эффекты: более раннее вмешательство даёт 25 QALY
         ΔE = 25

ICER = 300,000 / 25 = £12,000 за QALY
```

£12 000/QALY удобно ниже порога NICE в £20 000 — сильный кейс. Обратите внимание, насколько важна именно *чистая* стоимость: без компенсации в £600 000 ICER составил бы £36 000/QALY, и кейс, скорее всего, провалился бы. Компенсации затрат и качество их доказательств — это то место, где эти анализы выигрываются и проигрываются (см. [предотвращённые последующие затраты](../предотвращённые-последующие-затраты/)).

## Связь с разработкой программного обеспечения

Дисциплина ICER целиком переносится на инженерные решения:

```
(стоимость варианта B − стоимость варианта A) / (результат B − результат A)
```

— инкрементальная стоимость на дополнительный деплой, на сэкономленный инженеро-час, на предотвращённый инцидент — всегда относительно следующего лучшего варианта, а не относительно бездействия. Две привычки, которые стоит позаимствовать: (1) *явно называйте компаратор*; большинство заявлений о ROI инструмента тайно сравниваются с соломенным чучелом; (2) *сначала вычтите затраты* — инструмент стоимостью £100 тыс., вытесняющий £80 тыс. существующих расходов, имеет ΔC = £20 тыс.

## Подводные камни

- **Манипуляция компаратором**: сравнение с устаревшей или искусственно плохой базовой линией раздувает ΔE и льстит ICER.
- **Средние вместо инкрементальных значений**: стоимость на QALY всей программы — это не ICER её расширения или принятия.
- **Культ точечной оценки**: ICER — это отношения двух неопределённых разностей; отчитывайтесь о неопределённости через [PSA и CEAC](../вероятностный-анализ-чувствительности/).
- **Отрицательные ICER неоднозначны** (дешевле-и-лучше против дороже-и-хуже дают один и тот же знак) — никогда не сообщайте отрицательный ICER, не указав, в каком он квадранте.
- **Сравнение ICER между валютами без явного шага конвертации**: ICER, рассчитанный в валюте одной страны, нужно конвертировать заявленным методом, прежде чем сравнивать с порогом другой страны, — почему выбор коэффициента конвертации (паритет покупательной способности или рыночный курс) сам способен перевернуть решение о принятии, см. [Сравнение ICER между валютами](../сравнение-icer-между-валютами/).
