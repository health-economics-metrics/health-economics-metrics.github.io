# ผลตอบแทนทางสังคมจากการลงทุน (SROI)

ผลตอบแทนทางสังคมจากการลงทุนพยายามแปลงมูลค่าทางสังคมที่ตลาดไม่ได้กำหนดราคาไว้ (เช่น ความเป็นอยู่ที่ดี ความสามัคคีในชุมชน) ให้เป็นหน่วยเงินตรา เพื่อรวมเข้ากับการวิเคราะห์ทางการเงินแบบดั้งเดิม

## ทำไมจึงสำคัญ

โครงการทางสังคมหลายโครงการสร้างมูลค่าที่แท้จริงแต่ไม่มีราคาตลาดโดยตรง (เช่น การลดความเหงาในผู้สูงอายุ) SROI ให้กรอบในการนับมูลค่าเหล่านี้ในกรณีทางธุรกิจ

## คณิตศาสตร์

```
อัตราส่วน SROI = มูลค่าทางสังคมที่สร้างขึ้น (เป็นเงิน) / การลงทุน
```

## ตัวอย่างที่คำนวณแล้ว

โครงการชุมชนที่ลดความเหงาในผู้สูงอายุมีต้นทุน £50,000 และสร้างมูลค่าทางสังคมที่ประเมินไว้ (ผ่านตัวแทนทางการเงินสำหรับความเป็นอยู่ที่ดีที่ดีขึ้น) £200,000: อัตราส่วน SROI = 4:1

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการพยายามหาปริมาณมูลค่าของซอฟต์แวร์โอเพนซอร์สหรือเครื่องมือภายในที่ไม่มีการขาย แต่สร้างมูลค่าที่แท้จริงให้กับระบบนิเวศผ่านช่องทางที่ยากต่อการวัด

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ตัวแทนทางการเงินที่เป็นอัตวิสัยสูงโดยไม่มีความโปร่งใสเกี่ยวกับวิธีการได้มา**
- **การรายงานอัตราส่วน SROI ที่น่าประทับใจโดยไม่มีการตรวจสอบโดยอิสระ**
