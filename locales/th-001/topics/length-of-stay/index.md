# ระยะเวลานอนโรงพยาบาล

ระยะเวลานอนโรงพยาบาลวัดจำนวนวันที่ผู้ป่วยอยู่ในโรงพยาบาลตั้งแต่เข้ารับการรักษาจนถึงออกจากโรงพยาบาล — เวลารอบของโรงพยาบาล

## ทำไมจึงสำคัญ

ระยะเวลานอนที่สั้นลงช่วยประหยัดทรัพยากรและลดความเสี่ยงของภาวะแทรกซ้อนที่เกี่ยวข้องกับโรงพยาบาล แต่การลดลงที่รุนแรงเกินไปจะเพิ่มอัตราการกลับเข้ารักษาซ้ำ

## คณิตศาสตร์

```
ระยะเวลานอนเฉลี่ย = จำนวนวันเตียงทั้งหมด / จำนวนการเข้ารับการรักษา
```

## ตัวอย่างที่คำนวณแล้ว

แผนกหนึ่งลดระยะเวลานอนเฉลี่ยจาก 6 วันเหลือ 4.5 วันด้วยการประสานงานการออกจากโรงพยาบาลที่ดีขึ้น ทำให้มีความจุเตียงเพิ่มขึ้น 25% สำหรับผู้ป่วยเพิ่มเติมโดยไม่ต้องเพิ่มเตียง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับเวลารอบใน [ตัวชี้วัดการไหล](../flow-metrics/) — งานใช้เวลานานแค่ไหนในระบบตั้งแต่เริ่มต้นจนเสร็จสิ้น

## ข้อผิดพลาดที่พบบ่อย

- **การลดระยะเวลานอนโดยไม่พิจารณาผลกระทบต่ออัตราการกลับเข้ารักษาซ้ำ**
- **การใช้ค่าเฉลี่ยที่บิดเบือนโดยค่าผิดปกติสุดขั้ว**
