# तकनीकी ऋण

तकनीकी ऋण एक कोडबेस में सुविधाजनक पिछले निर्णयों की निहित भविष्य लागत है: बकाया प्रतिकार कार्य (**मूलधन**) और डिलीवरी पर इसका निरंतर खिंचाव (**ब्याज**)।

## यह क्यों महत्वपूर्ण है

अमापित, तकनीकी ऋण एक शिकायत है; मापा गया, यह एक व्यावसायिक मामला है।

## गणित

```
SQALE मूलधन = Σ उल्लंघनों में (प्रतिकार समय) × डेवलपर लागत दर
```

## हल किया गया उदाहरण

एक 4-लाख-LOC क्लिनिकल-रिकॉर्ड एकीकरण परत: SQALE मूलधन £285k; TDR ≈ 12%।

```
ब्याज ≈ सालाना £276,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

स्वास्थ्य-अर्थशास्त्र आयात जो तकनीकी-ऋण तर्कों को उन्नत करते हैं।
