# Fidelizzazione della Forza Lavoro

L'economia della fidelizzazione della forza lavoro misura quanto costa a un sistema sanitario il turnover del personale.

## Perché è importante

Quando un clinico se ne va, il trust paga tre volte: reclutare un sostituto, inserirlo, e coprire il posto vacante nel frattempo.

## La matematica

```
Costo per persona che se ne va = costo di reclutamento + costo di inserimento/aumento di produttività
                                 + premio di copertura del posto vacante × durata del posto vacante
```

## Esempio risolto

Un trust impiega 1.200 infermiere; turnover 11%/anno. Software per il carico di documentazione: £222.000/anno.

## Collegamento con l'ingegneria del software

La matematica della fidelizzazione ingegneristica è identica.

## Insidie

- **Attribuire tutto il movimento di turnover al proprio intervento.**
