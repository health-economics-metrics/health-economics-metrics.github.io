# 응급실 방문 회피

응급실 방문 회피는 상류 개입에 의해 예방된 응급실 방문과 응급 입원을 계산합니다.

## 왜 중요한가

응급 치료는 시스템에서 가장 비용이 많이 드는 일상적 환경입니다.

## 수식

```
회피된 방문 = 인구 × (기준 비율 − 개입 비율)
```

## 계산 예시

3,000명의 고위험 환자를 위한 COPD 원격 모니터링 서비스: 순 ≈ 연간 +£342,000.

## 소프트웨어 공학과의 연관성

이것은 **사고 회피 경제학**입니다.

## 함정

- **평균으로의 회귀.**
