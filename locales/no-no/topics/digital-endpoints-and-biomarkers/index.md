# Digitale endepunkter og biomarkører

Digitale endepunkter og biomarkører er objektive, kvantifiserbare helsemålinger samlet inn via sensorer, bærbare enheter eller digitale verktøy.

## Hvorfor det er viktig

Digitale biomarkører gir kontinuerlige, objektive data som bygger bro over gapet mellom tradisjonelle kliniske besøk.

## Matematikken

```
Validitet for digitalt endepunkt = korrelasjonskoeffisient(digital måling, validert klinisk standard)
```

## Gjennomarbeidet eksempel

En skritttellingsbasert måling av ganghastighet: korrelasjon med klinisk 6-minutters gangtest r = 0,82.

## Kobling til programvareutvikling

[Validering av bærbare enheter](../wearable-validation/) er en forutsetning for påliteligheten til disse dataene.

## Fallgruver

- **Å behandle uvaliderte sensordata som klinisk gyldige.**
