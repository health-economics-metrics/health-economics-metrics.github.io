# Kustannusten minimointianalyysi (CMA)

Kustannusten minimointianalyysi valitsee halvimman vaihtoehdon sen jälkeen, kun on todistettu, että vertaillut interventiot ovat yhtä tehokkaita.

## Miksi se on tärkeä

Kun tehokkuus on jo todistettu yhtäläiseksi, on tarpeetonta suorittaa monimutkaisia kustannusvaikuttavuuslaskelmia — valitse vain halvin.

## Matematiikka

```
Valitse vaihtoehto, jolla min(Kustannus), kun Vaikutus_A = Vaikutus_B
```

## Ratkaistu esimerkki

Kaksi geneeristä lääkettä, joilla on todistetusti identtinen teho: valitse se, jolla on alhaisin ostohinta, ilman lisäanalyysiä.

## Yhteys ohjelmistokehitykseen

Muistuttaa halvimman pilvipalveluntarjoajan valitsemista sen jälkeen, kun on vahvistettu, että molemmat täyttävät samat suorituskyky- ja luotettavuusvaatimukset.

## Sudenkuopat

- **Yhtäläisyyden olettaminen ilman vankkaa näyttöä.**
- **CMA:n käyttäminen, kun vaikutukset todellisuudessa eroavat hienovaraisesti.**
