# 通貨をまたぐICER比較

ある国の通貨で計算した[ICER](../incremental-cost-effectiveness-ratio/)を別の国の[支払意思額の閾値](../willingness-to-pay-thresholds/)と比較する場合や、多国籍試験で収集した費用データをプールする場合には、明示的で監査可能な通貨換算のステップが必要です。換算方法を誤ると、臨床データや費用データが何も変わっていなくても、同じ根拠が導入判断をひっくり返すことがあります。

## なぜ重要か

ISPORの多国籍臨床試験に関する方法論ガイダンス(Willkeら、*Health Economics*、1998年)は、国をまたいで資源の実質的な経済的価値を比較する際には、市場為替レートではなく**購買力平価(PPP)**で資源費用を換算することを推奨しています。市場の外国為替レートは、実際の国境を越える現金支払いの流れをモデル化するという本来の用途のために取っておきます。この2つを混同することは、多国籍HTAで最も多い方法論上の誤りの一つです。ガイダンスを読んでいない人には、どちらも「為替レート」に見えるためで、表計算ソフトは間違った使い方を止めてくれません。

## 数式

```
現地通貨ICER = 換算(原通貨ICER, 換算係数)

換算係数は次のようにすべき:
  PPP換算係数     — 国をまたいで資源の実質的な経済的価値を比較する場合
                    (ISPORが多国籍CEAに推奨)
  市場為替レート  — 実際の国境を越える現金支払いのみ

現地通貨ICER < 現地閾値 であれば導入
```

判断ルール自体は通常の[ICER閾値ルール](../willingness-to-pay-thresholds/)、すなわち`ICER < λなら導入`です。このトピックが扱う方法論上の問題は、そのルールが適用される`現地通貨ICER`の値を、*どの換算係数*が生み出すのかという点に尽きます。

## 計算例

ある薬剤の米国試験でのICERは$45,000/QALYです。仮想の輸入国が、独自の説明用閾値を£34,000/QALYに設定しています(この例のためだけの仮想の国別数値であり、実際の閾値は国によって異なり時間とともに変わるため、必ず出典と日付を付ける必要があります)。

**PPP換算係数0.72を用いる場合**(説明用で、この計算例のみ): $45,000 × 0.72 = £32,400/QALY。£32,400 < £34,000 → **導入**。

**代わりに市場為替レート0.79を用いる場合**(説明用): $45,000 × 0.79 = £35,550/QALY。£35,550 > £34,000 → **却下**。

同じ$45,000/QALYというICERが、PPP換算では導入、市場為替レート換算では却下という判断になります。これは、ISPORのガイダンスが換算係数の選択を方法論上重要なものとして扱う理由の具体的な例です。丸めの細部ではなく、誰も再確認しない表計算の式に暗黙のまま置いておいてよいものでもありません。

## ソフトウェア工学との関連

これは、よく知られたエンジニアリング領域のヘルスエコノミクス版です。商用ソフトウェアにおけるi18n/l10nの多通貨価格設定の正しさで、SaaSの価格ページは`$`の金額と`£`の価格を黙って比較してはなりません。よく作られた`Money`型が提供する型レベルの保証、つまり通貨が一致しないものの比較を拒否し、まず明示的な換算ステップを強制する比較メソッドは、ここでのヘルスエコノミクスの方法論上のポイントに直接対応するソフトウェア工学上の類似物です。換算前の数値を通貨をまたいで比較しないこと、そして換算ステップを暗黙的または文書化されないままにしないことです。

## 落とし穴

- **異なる通貨の金額を黙って比較すること**: 換算ステップなしにドルの数値とポンドの数値を引いたり比較したりする、その場しのぎの表計算でのHTA作業。通貨を認識する本物の`Money`型なら構造上これを捕捉でき、黙ったエラーのまま放置されません。
- **市場為替レートとPPPの混同**: ISPORガイダンスによれば多国籍HTAで最も一般的な方法論上の誤りです。2つの数値は大きく異なり得て、別の問いに答えます(実質的な経済的価値と実際の現金フロー)。
- **使用した為替レートやPPP指数に日付を付けないこと**: どちらも時間とともに変動するため、引用する換算係数には、このリポジトリが他の基準値(グリーンブックの炭素価値、予防された死亡の価値など)に日付を付けるのと同じ方法で日付を付ける必要があります。
