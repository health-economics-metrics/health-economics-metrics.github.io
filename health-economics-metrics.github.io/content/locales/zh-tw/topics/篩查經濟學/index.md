# 篩查經濟學

篩查經濟學支配著對無症狀人群進行檢測的價值。其核心數學事實是：**在低患病率條件下，即便是極其優秀的檢測方法，產生的結果也大多是假陽性**——而追查這些假陽性所帶來的下游成本，足以淹沒真正發現病例所帶來的收益。

## 為何重要

自1968年以來，WHO的Wilson–Jungner標準一直是人群篩查的准入門檻：該病症必須重要、檢測手段必須可接受且準確、必須存在有效的治療方法，且經濟學上必須能夠平衡。英國國家篩查委員會在批准任何一項全國性專案之前，都會開展正式的成本效果分析——並否決大多數提案。每一個"AI將為所有人篩查一切"的推介方案，最終都會撞上這套機制，而且通常會敗給下面這套算術。

## 計算方法

陽性預測值（PPV）——即一個陽性結果為真的機率——在低患病率下會急劇崩塌：

```
PPV = (靈敏度 × 患病率) / [靈敏度 × 患病率 + (1 − 特異度) × (1 − 患病率)]

例：靈敏度90%，特異度95%，患病率0.5%：
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

每十二次陽性結果中就有十一次是假的。完整的專案層面經濟學：

```
每例真陽性的成本 = (篩查成本 + 核查成本 × 所有陽性結果數) / 真陽性數
隨後需追問：發現一例是否值得這個價錢？（每例更早介入的價值，
          減去過度診斷的危害——那些本來根本不重要的被發現病例）
```

## 實例演算

某罕見病症的AI視網膜篩查，覆蓋10萬人，患病率0.5%，靈敏度90%，特異度95%，每次掃描£15，確診性核查每次£400：

```
真陽性數：  100,000 × 0.005 × 0.90 = 450
假陽性數：  100,000 × 0.995 × 0.05 = 4,975
成本 = 100,000 × 15 + (450 + 4,975) × 400 = £150萬 + £217萬 = £367萬
每例真陽性成本 ≈ £8,156
```

如果早期治療每例能節省£20,000外加1個QALY，該專案能輕鬆透過檢驗。將特異度提高到99%（減少誤報）：核查成本降至(450 + 995) × 400 = £58萬，總成本£208萬，每例成本降至約**£4,622**——在低患病率條件下，篩查經濟學的勝負手在於特異度，而非靈敏度。

## 與軟體工程的聯絡

靜態分析、安全掃描與異常檢測，本質上都是針對程式碼庫與遙測資料的篩查專案，其真實缺陷的患病率，往往每次告警機會遠低於1%。完全相同的數學原理解釋了告警疲勞：一個特異度95%的掃描工具，在低患病率的程式碼上運作，會讓團隊被假陽性淹沒，而每一次假陽性都會消耗注意力、侵蝕信任，直到真正的告警也開始被忽視（臨床術語稱之為*篩查危害*；工程術語則稱之為*尋呼機麻木*）。其應對方法可以從醫療領域直接遷移過來：先提高特異度，再考慮靈敏度；對患病率更高的子人群進行篩查（基於風險的定向篩查 ↔ 僅對已變更程式碼進行掃描）；並將分診成本計入該工具的經濟學核算之中——參見[NNT](../需治療人數/)與[臨床AI評估](../臨床AI評估/)。 關於整個篩查專案（而不是單個檢驗）的規模，見[需要篩查人數](../需要篩查人數/)——要有多少人走完整個篩查再治療的路徑才能預防一例結局。

## 陷阱

- **只報告靈敏度/特異度而不說明患病率**——脫離PPV談準確率，不過是行銷話術。
- **忽視過度診斷**：發現那些本來根本不會造成傷害的惰性"疾病"，卻觸發了真實的治療成本與傷害。
- **前導時間偏倚**：在未改變最終結果的情況下更早發現疾病，會人為誇大表觀生存率——參見[更早介入](../更早介入/)。
