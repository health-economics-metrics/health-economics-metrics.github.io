# 健康应用单位经济学

消费级健康产品的商业算术：客户获取成本（CAC）、生命周期价值（LTV）、每用户平均收入（ARPU）、按会员每月计价（PMPM），以及在雇主市场中至关重要的**投资回报率（ROI）与投资价值率（VOI）**之分。

## 为何重要

健康应用面临一种结构性挤压：获客成本高昂（受监管的宣称限制、信任门槛、合规成本），而留存率则是所有软件垂直领域中最差的（30天内约90%的用户流失——参见[留存与流失](../留存与流失/)）。因此，标准的可行性检验——**LTV:CAC ≥ 3:1**——在消费级健康领域极其难以达成，这也是为什么该行业正在向B2B2C模式迁移：由雇主、保险公司与医疗系统按PMPM为整个人群付费，此时的付费方不再是那个会流失的个体用户。

## 计算方法

```
CAC（获客成本）  = 销售+营销支出 / 新增付费客户数
ARPU（每用户平均收入） = 收入 / 活跃用户数（按周期计）
LTV（生命周期价值） = ARPU × 平均生命周期 = ARPU / 流失率
可行性标准：LTV : CAC ≥ 3，回本周期 ≤ 12–18个月

每留存用户的有效获客成本 = CAC / 留存率(t)
  ——若第30天留存率为4%，每次安装成本£5，则相当于每名
     30天留存用户实际成本£125

PMPM收入 = 费率 × 已注册会员数 × 月数
  供应商利润率 = PMPM − 每会员每月服务成本
  ——参与度的作用在此发生反转：在B2C订阅模式下，参与度带来收入；
    而在PMPM模式下，参与度高的会员服务成本反而高于不活跃的会员，
    而基于结果付费的合同又会将这一逻辑再次翻转回来
```

## 实例演算

某B2C睡眠应用：£6.99/月，月流失率18%，综合获客成本£38。

```
LTV = 6.99 / 0.18 ≈ £38.8 → LTV:CAC ≈ 1.0——不可持续

转向雇主PMPM模式：£1.20 PMPM × 40,000名覆盖人员 = £48,000/月
服务成本：基础设施£0.15 + 支持£0.10 + 内容£0.05
  每会员约£0.30 → 利润率约75%，销售周期虽长，但流失
  发生在合同层面（按年），而非用户层面（按日）

雇主关心的问题会改变整个指标体系：对健康类产品而言，
硬性货币投资回报率（减少的理赔、缺勤率）通常难以证实——
业内的应对方式是使用VOI：生产力、招聘吸引力、参与度——
但这种做法只有在明确标注为VOI、而非包装成ROI时才是诚实的
（参见return-on-investment.md与social-return-on-investment.md）。
```

## 与软件工程的联系

工程决策同时决定着这一比值的两端：**服务成本**取决于架构（[云单位经济学](../云单位经济学/)——PMPM的利润率生死全在于每会员的基础设施成本），而**LTV**则取决于留存工程（每一个流失点都对应着可计算的收入损失——[留存](../留存与流失/)文档中的QALY算术，恰好有一个完全对应的收入版本）。对于健康类产品而言，单位经济学仪表盘除了LTV与CAC之外，还应加上第三行：**每名获取用户的健康价值**（按留存加权的QALY × 阈值）——因为支付方与DiGA式的市场正日益依据这一指标定价，而且一款商业单位经济学与临床单位经济学彼此背离的产品（盈利却对健康毫无作用，或有效却无法获得资助），需要清楚知道自己究竟面临的是哪一种问题。

## 陷阱

- **仅凭早期队列流失率推算LTV**：流失率通常会逐渐趋于稳定下降；但同时也存在存活者偏差——早期采用者的留存往往优于后期规模化后的用户群体。应使用队列成熟后的数据。
- **将各渠道获客成本混合计算**：付费社交渠道的获客成本与临床医生转介渠道的获客成本可相差10倍，且二者的留存曲线截然相反——应分渠道分析，否则会被误导。
- **未设使用量上限的PMPM模式**：极少数参与度极高的会员可能会使利润率反转为负；应对分布建模，而非只看均值。
- **向CFO将VOI包装成ROI呈现**——这正是雇主健康福利这一行业花了十年才积累起来、又极易毁于一旦的可信度问题。
