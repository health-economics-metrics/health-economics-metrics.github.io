# 統計生命價值 (Value of a Statistical Life, VSL)

統計生命價值（VSL）——英國用法中稱為“避免死亡的價值”（VPF）——是*人群*集體願意為降低一例統計學死亡的風險而支付的金額，由工資—風險權衡研究（工人為更危險的工作要求多少額外工資）和陳述偏好調查推得。它不是某個可識別個人生命的價格；它是一種人群風險的構造，而建置降低風險系統——分診演算法、救護車排程、安全監控——的軟體工程師應當知道，它來自與[支付意願閾值](../支付意願閾值/)不同的理論傳統。

## 為什麼重要

VSL/VPF 是監管性成本效益分析中把死亡風險降低貨幣化的標準工具：交通安全、環境監管和一些公共衛生介入都透過它建置商業案例。HM Treasury 的 Green Book 釋出一個由英國勞動力市場和調查資料推得的 VPF 數位，交通部在評估道路安全時直接使用它。這是一種與 QALY × 支付意願閾值方法論確實不同的估值傳統：閾值方法按*衛生預算*目前在邊際上產出的水平為健康收益估值，而 VSL/VPF 則按人們在勞動力市場或調查中表明願意為降低風險所付的錢為風險降低估值。這兩種框架並不總是相容，而在同一案例中同時使用二者卻不加承認，是常見的分析錯誤。

## 計算方法

```
避免的死亡數 = 人口 × 人均風險降低
  （人均風險降低是一個機率，如 0.000001 =
   年死亡風險降低百萬分之一）

貨幣化的死亡收益 = 避免的死亡數 × 避免死亡的價值
```

## 算例

一個 80 萬人口的地區受益於一項道路安全數位排程/分診介入，使每個人的年死亡風險降低百萬分之一（0.000001）：

```
避免的死亡數 = 800,000 × 0.000001 = 0.8
```

採用英國避免死亡的價值 £2,180,000（HM Treasury/DfT 數位，2023/24 價格——Green Book 每年更新，在正在進行的分析中引用前請核對）：

```
貨幣化的死亡收益 = 0.8 × £2,180,000 = £1,744,000/年
```

每年略低於 £175 萬的貨幣化死亡收益，來自大多數受影響人群個人永遠不會察覺的風險降低。

## 與軟體工程的關聯

安全關鍵軟體團隊——醫療器械韌體、自動駕駛車輛軟體、工業控制系統——在為安全投資建置成本效益論證時，面對的正是這一定價問題：當故障罕見、嚴重且分散在龐大的使用者群體中時，如何為“預防一次災難性故障”定價？VSL/VPF 是為罕見而嚴重的人群層面風險降低賦予數位的、已有數十年曆史且公開記錄的真實先例——與為 SRE 投資針對罕見災難性中斷定價是同樣的論證形式，只不過結果是死亡而不是停機。

## 陷阱

- **把 VSL 當作“某個可識別生命的價格”**：它不是。VSL/VPF 是由許多人之間的風險降低權衡推得的統計人群構造，不是對任何特定個人生死的估價。
- **與基於 QALY 的淨貨幣效益計算重複計算**：在同一案例中同時使用 VSL/VPF 數位和單獨的 QALY × 閾值計算而不加協調，會悄悄地把同樣的避免死亡價值計算兩次。每個案例選擇一個框架。
- **不加調整地在不同情境間轉移 VSL 估計**：由一國勞動力市場或勞動年齡人口工資—風險資料推得的 VSL，不加調整就應用於另一種收入情境或另一類人群（兒童、老年人），是一個真正有爭議的、長期存在的方法學問題——尚未解決。
