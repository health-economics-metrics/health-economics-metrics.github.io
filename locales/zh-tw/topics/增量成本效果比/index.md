# 增量成本效果比（ICER）

ICER是指當你選擇某一方案而非次優替代方案時，每多獲得一單位健康效果所需多付出的成本。它是衛生技術評估中最核心的頭條數位。（當效果單位為QALY時，它也被稱為增量成本效用比，ICUR。）

## 為何重要

衛生系統從不孤立地評估某項技術——而總是*相對增量地*，與本來會採取的替代方案相比較。NICE將某項技術的ICER與其**每QALY £20,000–£30,000**的閾值相比較；美國ICER研究所則在$50,000–$200,000/QALY的區間內報告；加拿大的工作標準大致為CAD$50,000/QALY。你的產品對一個國家醫療服務體系而言是否"值得"，形式上就等價於其ICER是否低於當地閾值。參見[支付意願閾值](../支付意願閾值/)。

## 計算方法

```
ICER = (成本_新方案 − 成本_對照方案) / (效果_新方案 − 效果_對照方案)
     = ΔC / ΔE
```

解讀規則：

- ΔC < 0，ΔE > 0：新方案**佔優**——既更便宜又更好；無需計算比值。
- ΔC > 0，ΔE > 0：計算ICER，與閾值λ比較；若ICER < λ則採納。
- ΔC > 0，ΔE < 0：新方案被佔優——應拒絕。
- 當ΔE接近0時，比值的表現會變得很不穩定——此時更適合使用[淨貨幣效益](../淨貨幣效益/)來排序。

對照方案必須是*次優、未被佔優的方案*，而非"什麼都不做"——參見[佔優關係與效率前沿](../佔優關係與效率前沿/)。

## 實例演算

某面向心力衰竭病患的遠端監測服務，按每年1,000名病患計算，與常規照護相比：

```
成本：  服務£900,000；避免的入院節省£600,000
       ΔC = 900,000 − 600,000 = £300,000
效果：  更早介入獲得25個QALY
       ΔE = 25

ICER = 300,000 / 25 = 每QALY £12,000
```

每QALY £12,000，明顯低於NICE的£20,000閾值——是一個有力的論證案例。請注意*淨*成本為何如此重要：如果沒有那£600,000的衝抵，ICER將變為每QALY £36,000，該論證很可能就無法透過。成本衝抵項及其證據品質，正是這類分析成敗的關鍵所在（參見[規避的下游成本](../規避的下游成本/)）。

## 與軟體工程的聯絡

ICER這套紀律可以完整地遷移到工程決策中：

```
(方案B的成本 − 方案A的成本) / (方案B的結果 − 方案A的結果)
```

——每多一次部署的增量成本、每節省一個工程師-小時的增量成本、每避免一次事件的增量成本——始終是與次優替代方案相比較，而非與"什麼都不做"相比較。這裡有兩個值得借鑑的習慣：(1) *明確指出對照方案*；大多數工具投資回報率的主張，實際上都在暗中與一個稻草人對照方案相比較；(2) *先對成本做淨額計算*——一個成本£100,000、但能替代掉£80,000現有支出的工具，其ΔC實際上只有£20,000。

## 陷阱

- **對照方案操縱**：與一個過時或人為設定得很差的基線相比較，會虛增ΔE，從而美化ICER結果。
- **用平均值代替增量值**：一整個專案的每QALY成本，並不等同於擴充套件或採納該專案的ICER。
- **迷信點估計**：ICER是兩個本身就存在不確定性的差值之比；應透過[PSA與CEAC](../機率敏感性分析/)報告其不確定性。
- **負的ICER含義模糊**（"更便宜且更好"與"更貴且更差"兩種情形會得出相同的符號）——報告負的ICER時，務必說明它究竟屬於哪一象限。
- **在沒有明確換算步驟的情況下跨幣種比較 ICER**：以一國貨幣計算的 ICER，在與另一國閾值比較之前，必須用宣告的方法換算——關於為什麼換算係數的選擇（購買力平價與市場匯率）本身就可能顛覆採納決定，見[跨幣種 ICER 比較](../跨幣種-icer-比較/)。
