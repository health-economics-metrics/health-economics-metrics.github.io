# تاخیر کی قیمت (CoD)

تاخیر کی قیمت وہ معاشی قدر ہے جو ایک سہولت، پروڈکٹ، یا سروس *فراہم نہ ہونے* کی فی اکائی وقت میں کھو جاتی ہے۔

## یہ کیوں اہم ہے

Reinertsen کا اصول: "اگر آپ صرف ایک چیز کی پیمائش کرتے ہیں، تو تاخیر کی قیمت کی پیمائش کریں۔"

## ریاضی

```
CoD = غیر فراہم شدہ رہتے ہوئے فی اکائی وقت میں کھویا گیا فائدہ (£/ہفتہ یا QALY/ہفتہ)
```

## حل شدہ مثال

**آپریشنل**: ایک سافٹ ویئر ایک راستے میں فی مریض £200 بچاتا ہے: CoD = £10,000/ہفتہ۔

## سافٹ ویئر انجینئرنگ سے تعلق

CoD وہ میٹرک ہے جو [DORA لیڈ ٹائم](../dora-metrics/) کو مالی طور پر پڑھنے کے قابل بناتا ہے۔
