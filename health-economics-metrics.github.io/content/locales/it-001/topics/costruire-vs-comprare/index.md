# Costruire vs Comprare

Costruire-vs-comprare è un confronto strutturato tra sviluppo personalizzato e acquisizione commerciale.

## Perché è importante

I sistemi sanitari affrontano continuamente questa decisione.

## La matematica

```
VAN_opzione = PV(benefici) − PV(TCO)
```

## Esempio risolto

Un trust ha bisogno di un sistema di consenso elettronico. Comprare: £150 mila/anno SaaS, operativo in 3 mesi.

## Collegamento con l'ingegneria del software

La disciplina di economia sanitaria trasferibile è triplice.

## Insidie

- **Confrontare il prezzo di listino del fornitore con stime di costruzione non aggiustate per il rischio.**
