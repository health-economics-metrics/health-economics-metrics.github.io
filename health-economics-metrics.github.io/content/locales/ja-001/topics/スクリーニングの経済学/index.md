# スクリーニングの経済学

スクリーニングの経済学は、無症状の集団を検査することの価値を左右します。核心的な数学的事実:**低い疾病有病率では、優れた検査であってもほとんどが偽陽性を生み出します** — そして、それらを追いかける下流の費用は、真の発見の便益を圧倒することがあります。

## なぜ重要か

1968年以来、WHOのウィルソン・ジャングナー基準は集団スクリーニングの基準を設定してきました:その状態は重要でなければならず、検査は受け入れられ正確でなければならず、有効な治療が存在しなければならず、経済性が釣り合わなければなりません。英国National Screening Committeeは、あらゆる国家プログラムを承認する前に正式な費用効果分析を適用します — そしてほとんどの提案を却下します。「AIがすべての人のすべてをスクリーニングする」というあらゆる売り込みは、この仕組みにぶつかり、通常は以下の計算に負けます。

## 数式

陽性的中率(PPV) — 陽性結果が本物である確率 — は低い有病率で崩壊します:

```
PPV = (感度 × 有病率) / [感度 × 有病率 + (1 − 特異度) × (1 − 有病率)]

例:感度90%、特異度95%、有病率0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

12件の陽性のうち11件が偽です。プログラム全体の経済性:

```
真の症例1件を見つける費用 = (スクリーニング費用 + すべての陽性への精密検査費用) / 真陽性数
そして:症例を見つけることはその価値があるか?(症例あたりの早期介入の価値、
      過剰診断の害を差し引く — 決して問題にならなかったであろう見つかった症例)
```

## 計算例

ある希少な状態に対するAI網膜スクリーニング、10万人、有病率0.5%、感度90%、特異度95%、スキャン£15、確認精密検査£400:

```
真陽性:  100,000 × 0.005 × 0.90 = 450
偽陽性:  100,000 × 0.995 × 0.05 = 4,975
費用 = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £367万
真の症例1件あたりの費用 ≈ £8,156
```

早期治療が症例あたり£20,000+1QALYを節約するなら、このプログラムは容易に基準をクリアします。特異度を99%に上げる(誤警報を減らす):精密検査費用は(450 + 995) × 400 = £58万に下がり、総額£208万、症例あたりの費用 ≈ **£4,622** — 低い有病率では、感度ではなく特異度こそが、スクリーニングの経済性が勝負を決める場所です。

## ソフトウェア工学との関連

静的解析、セキュリティスキャン、異常検知は、コードベースとテレメトリにわたるスクリーニングプログラムであり、アラートの機会あたりの真の欠陥有病率はしばしば1%を大きく下回ります。まったく同じ数学がアラート疲れを説明します:低有病率のコードに対する特異度95%のスキャナーは、チームを偽陽性で溺れさせ、すべての偽陽性は注意力を消費し信頼を蝕み、やがて本物のアラートも無視されるようになります(臨床用語では*スクリーニングの害*、エンジニアリング用語では*ページャー麻痺*)。対策は医療から転用できます:感度の前に特異度を上げること、より有病率の高いサブ集団をスクリーニングすること(リスクベースの標的化 ↔ 変更されたコードのみのスキャン)、そしてトリアージの費用をツールの経済性に数えることです — [NNT](../治療必要数/)と[臨床AI評価](../臨床ai評価/)を参照してください。 1つの検査ではなくスクリーニングプログラム全体の規模づけについては、[スクリーニング必要数](../スクリーニング必要数/)を参照してください。1件のアウトカムを防ぐために、スクリーニングと治療の経路全体を何人が通らなければならないかを示します。

## 落とし穴

- **有病率を示さずに感度/特異度を引用すること** — PPVのない精度はマーケティングです。
- **過剰診断を無視すること**:決して害をもたらさなかったであろう無害な「疾病」を見つけることは、実際の治療費用と害を引き起こします。
- **リードタイムバイアス**:アウトカムが変わらないまま早期発見することは、見かけの生存率を膨らませます — [早期介入](../早期介入/)を参照してください。
