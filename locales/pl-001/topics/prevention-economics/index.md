# Ekonomia profilaktyki

Ekonomia profilaktyki bada, dlaczego interwencje profilaktyczne są niemal zawsze efektywne kosztowo, ale rzadko rzeczywiście oszczędzają pieniądze dla całego systemu.

## Dlaczego to ważne

Decydenci często twierdzą, że profilaktyka oszczędza pieniądze, ale większość działań profilaktycznych dodaje zdrowie po rozsądnej cenie bez obniżania całkowitych wydatków.

## Matematyka

```
Oszczędzająca koszty: Koszt(profilaktyka) < Koszt(unikniona choroba)
Efektywna kosztowo, ale nieoszczędzająca: Koszt(profilaktyka) > Koszt(unikniona choroba), ale ICER < próg
```

## Rozwiązany przykład

Program rzucania palenia kosztuje £200/uczestnika i oszczędza średnio £150 przyszłych kosztów opieki zdrowotnej na uczestnika, ale daje 0,1 QALY — efektywny kosztowo (£500/QALY), ale nieoszczędzający kosztów.

## Powiązanie z inżynierią oprogramowania

Przypomina inwestowanie w zautomatyzowane testowanie: dodaje wartość (mniej błędów) po rozsądnej cenie, ale rzadko rzeczywiście oszczędza pieniądze na całkowitych kosztach rozwoju.

## Pułapki

- **Mieszanie "efektywny kosztowo" i "oszczędzający koszty" w uzasadnieniach biznesowych.**
- **Liczenie tylko bezpośrednich kosztów zdrowotnych, ignorowanie szerszych korzyści społecznych.**
