# 质量调整生命年（QALY）

一个QALY，是指在完全健康状态下度过的一年生命。它将人们*活多久*与*活得好不好*结合在一起，因此在不良健康状态下度过的一年，其计数会少于一个QALY——从而使得完全不同的健康干预措施，能够在同一个尺度上进行比较。

## 为何重要

QALY是卫生技术评估领域的通用货币。NICE（英格兰）将健康获益的价值定为**每QALY £20,000–£30,000**：一项能以低于该阈值的价格买到QALY的干预措施，通常会获得推荐；而价格更高的，通常会被拒绝。正是这一个数字，让一个国家医疗服务体系能够在同一个坐标轴上，比较一种抗癌药、一次髋关节置换手术，以及一款分诊应用。如果你的软件能够可信地主张获得了QALY——通过预防病情恶化、加速治疗，或提升安全性——你就能用与医学本身完全相同的货币，为其健康价值定价。

## 计算方法

```
QALY = Σ_i (时长_i × 效用值_i)

时长_i = 处于健康状态i的年数
效用值_i = 状态i的质量权重，锚定为1 = 完全健康，0 = 死亡
          （对于比死亡更差的状态，允许取负值）
```

效用权重来自经过验证的量表工具，最常用的是[EQ-5D](../EQ-5D/)。某项干预措施所带来的QALY*增量*，是"有该干预"与"无该干预"两条QALY轨迹之间的差值，在NICE参考案例中按每年3.5%进行[贴现](../贴现与时间偏好/)。

## 实例演算

某患者在等待心脏治疗，处于效用值为0.6的状态。治疗能将其恢复至效用值0.85。

- **立即接受治疗**：这一年为0.85 × 1 = 0.85 QALY。
- **延迟6个月后再接受治疗**：0.5 × 0.6 + 0.5 × 0.85 = 0.725 QALY。
- **该延迟为每名患者造成的QALY损失**：0.85 − 0.725 = **0.125 QALY**。

按NICE阈值货币化：0.125 × £20,000–£30,000 = **每延迟6个月，每名患者损失£2,500–£3,750的健康价值**。如果某软件能为每年400名患者加速这一路径、消除这一延迟，其健康价值为50个QALY，约合**每年£100万–£150万**——这还不包括任何运营层面的节省。

## 与软件工程的联系

- **更快的路径 = 更早获得的QALY。**任何能缩短[转诊至治疗](../转诊至治疗/)时间的手段，都能将等待期间的负效用转化为健康获益，其估值方式如上所述。
- **安全性 = 被保留下来的QALY。**被预防的用药错误与漏诊，等同于被避免的QALY损失。
- **QALY同样是一种指标设计模板**：它是"数量 × 质量"的复合指标，其质量权重来自一套标准化量表工具的征询。一个"质量调整工程师年"（时间 × 开发者体验调查权重）正是同样的构造方式——参见[SPACE与开发者体验](../SPACE与开发者体验/)。
- 若要将QALY转化为商业论证所需的货币价值，请使用[净货币效益](../净货币效益/)；若要将其转化为决策，请使用[支付意愿阈值](../支付意愿阈值/)。

## 陷阱

- **凭空捏造效用权重。**权重必须来自经过验证的量表工具（EQ-5D）与已发布的价值集，而非直觉。
- **在没有明确因果路径的情况下主张获得了QALY。**"我们的应用能改善幸福感"并不构成一项QALY主张；"消除了效用值0.6状态下X周的等待时间"才是。
- **重复计算**：同时主张同一次被避免的病情恶化所带来的QALY获益与成本节省，需要格外审慎地确保二者确实彼此独立、互不重叠。
- **公平性盲点**：QALY是按基线效用值来衡量延长一年生命的价值，这可能会对残障人士不利——这正是美国ICER之所以同时报告evLYG的原因（参见[获得的生命年](../获得的生命年/)）。
