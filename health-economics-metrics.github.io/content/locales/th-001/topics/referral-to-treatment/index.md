# การส่งต่อเพื่อรับการรักษา (RTT)

RTT วัดเวลาตั้งแต่การส่งต่อครั้งแรกจนถึงการเริ่มการรักษา โดยมีมาตรฐาน 18 สัปดาห์เป็นตัวชี้วัดผลงานหลักระดับชาติ

## ทำไมจึงสำคัญ

RTT เป็นตัวชี้วัดเวลานำส่งที่ถูกนำไปใช้กับการดูแลผู้ป่วยโดยพื้นฐาน — ใช้เวลานานเท่าใดในการส่งมอบมูลค่า (การรักษา) หลังจากมีคำขอ (การส่งต่อ)

## คณิตศาสตร์

```
การปฏิบัติตาม RTT = จำนวนผู้ป่วยที่ได้รับการรักษาภายใน 18 สัปดาห์ / จำนวนผู้ป่วยในเส้นทาง RTT ทั้งหมด × 100%
```

## ตัวอย่างที่คำนวณแล้ว

แผนกเฉพาะทางหนึ่งมีผู้ป่วย 5,000 รายในเส้นทาง RTT โดย 4,100 รายได้รับการรักษาภายใน 18 สัปดาห์: การปฏิบัติตาม 82% ต่ำกว่ามาตรฐานระดับชาติที่ 92%

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายโดยตรงกับเวลานำส่งของ [DORA](../dora-metrics/) — เวลาตั้งแต่ commit (การส่งต่อ) จนถึงการส่งมอบ (การรักษา)

## ข้อผิดพลาดที่พบบ่อย

- **การใช้การหยุดนาฬิกา (ความคิดริเริ่มของผู้ป่วย) อย่างไม่ถูกต้องเพื่อบิดเบือนตัวเลขการปฏิบัติตาม**
- **การติดตามเฉพาะค่าเฉลี่ยในขณะที่หางของการแจกแจงเป็นปัญหาที่แท้จริง**
