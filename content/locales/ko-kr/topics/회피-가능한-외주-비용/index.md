# 회피 가능한 외주 비용

트러스트가 내부 용량으로 목표를 충족할 수 없을 때, 프리미엄 요금으로 용량을 구매합니다.

## 왜 중요한가

선택적 진료 회복 압박 하에서, 트러스트는 정기적으로 민간 부문 현물 가격을 지불합니다.

## 수식

```
회피 가능한 외주 비용 = 내부로 이전된 활동 ×
    (외주 단위 가격 − 사례당 내부 한계비용)
```

## 계산 예시

트러스트가 연간 800건의 백내장 시술을 외주합니다: 절약 = 연간 £275,000 — 현금화 가능.

## 소프트웨어 공학과의 연관성

직접적인 비유는 **계약자 및 컨설턴트 프리미엄**입니다.

## 함정

- **완전한 용량 사슬 없이 송환을 주장하기.**

## 출처

- NHS England, NHS Payment Scheme.
