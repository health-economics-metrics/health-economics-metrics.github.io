# Valore Atteso dell'Informazione Perfetta (EVPI)

L'EVPI è l'importo massimo che un decisore dovrebbe pagare per eliminare l'incertezza prima di decidere.

## Perché è importante

I sistemi sanitari affrontano costantemente questa scelta: adottare subito con prove imperfette, o finanziare prima più ricerca. Per prezzare l'opzione di espandere un progetto in seguito, anziché l'opzione di raccogliere prima informazione, si veda la [Valutazione delle Opzioni Reali](../valutazione-delle-opzioni-reali/).

## La matematica

```
EVPI = E_θ[ max_j NMB(j, θ) ] − max_j E_θ[ NMB(j, θ) ]
```

## Esempio risolto

Lanciare un assistente di documentazione IA a 5.000 clinici: EVPI = £1,2 milioni.

## Collegamento con l'ingegneria del software

L'EVPI è l'economia dello spike, del pilota e del test A/B. Per prezzare uno studio *specifico* proposto anziché eliminare ogni incertezza, si veda l'[EVSI](../valore-atteso-dell-informazione-campionaria/).

## Insidie

- **Eseguire piloti senza una regola decisionale.**
