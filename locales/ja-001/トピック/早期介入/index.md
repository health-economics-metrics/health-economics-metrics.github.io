# 早期介入

節約された容量によって医療従事者が診断のバックログをより早くレビューできるようになると、患者は待機リストから積極的な治療へとより速く移行します — そして、未治療の状態は進行するため、早く治療することは通常、後で治療するよりも安く、より良い結果をもたらします。

## なぜ重要か

疾病の進行は、医療における複利です。未治療の状態で待っている患者は定常状態にはありません:がんはステージが進み、心不全は代償不全に陥り、軽度のうつ病は重度になります。したがって、より早く介入することは二重の配当をもたらします — **より良いアウトカム**(より健康なベースラインから治療されるため、より多くのQALY)、そしてしばしば**より低い治療費用**(早期段階の治療は、後期段階の救済よりも集中的ではありません)。この仕組みこそが、「より速い経路」を運用上の便利さから臨床的・経済的な必須事項へと引き上げるものであり、[遅延コスト](../遅延コスト/)が臨床ソフトウェアに当てはまる深い理由です。

## 数式

```
早期介入の価値(患者1人あたり) =
    [費用_後期 − 費用_早期]                    (治療費用の相殺)
  + [QALY_早期 − QALY_後期] × λ               (健康の獲得×閾値)
  × P(遅延中の進行の確率)                       (確率による重み付け)
```

確率による重み付けは不可欠です:待機しているすべての患者が進行するわけではありません。最悪のケースではなく、(自然経過データからの)単位時間あたりの遷移確率をモデル化してください。そして割引してください:何年も先の回避された費用は今日ではより価値が低くなります([割引](../割引と時間選好/));そして、ほとんどの早期介入は費用*節約的*ではなく費用*効果的*であることに注目してください([予防の経済学](../予防の経済学/)を参照)。

## 計算例

糖尿病性網膜症スクリーニングのバックログ:4,000人の患者、6か月の遅れ。AI支援の等級判定はスループットを3倍にし、8週間でキューを解消します。自然経過:未レビューのまま待機している患者の約2%/年が視力を脅かす段階に進行します。

```
約4か月の加速によって回避される進行イベント:
  4,000 × 2% × (4/12) ≈ 27人

回避された進行1件あたり:
  治療の相殺(硝子体内注射療法 対 レーザー) ≈ £4,000
  QALYの獲得(視力の保持) ≈ 0.8QALY × £20,000 = £16,000

価値 ≈ 27 × (4,000 + 16,000) ≈ £540,000 — 一度きりのバックログ解消から、
永続的なスループットの獲得を数える前の数値。
```

## ソフトウェア工学との関連

2つの転用があります。まず、明白なもの:診断・治療経路を加速するソフトウェア(トリアージ、AI等級判定、結果のルーティング)は、まさにこのモデルを通じて金銭化されます — そしてこのモデルは、どの経路を加速すべきかを教えてくれます:最も長いキューではなく、最も急な進行曲線を持つものです。次に、エンジニアリングの鏡像:**欠陥も進行します**。設計段階で捕まったバグは会話1回分の費用で済みますが、本番環境では1件のインシデントの費用がかかります;「シフトレフト」の費用曲線(段階ごとに10〜100倍)は進行モデルであり、正直な版には同じ注意点が伴います — 早期発見は通常、無料のお金ではなく費用効果的であるにすぎません。なぜなら、レビューやテストには実際の費用がかかり、捕まった問題のほとんどは決して進行しなかったであろうからです。

## 落とし穴

- **全員に最悪ケースの進行を想定すること** — 確率による重み付けが、分析と主張の違いです。
- **リードタイムバイアス**:アウトカムを変えずに疾病を早く見つけることは便益のように見えますが、そうではありません;主張すべきは早期*発見*だけではなく、早期*有効介入*です([スクリーニングの経済学](../スクリーニングの経済学/)を参照)。
- 同じ加速に基づいて構築された待機リストとRTTの主張との**二重計上** — 1つの経路の改善、1組の便益、一度だけ配分すること。
