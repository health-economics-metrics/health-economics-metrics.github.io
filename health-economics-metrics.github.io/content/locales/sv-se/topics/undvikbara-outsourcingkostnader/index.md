# Undvikbara outsourcingkostnader

Undvikbara outsourcingkostnader mäter premien som betalas för bemanningspersonal eller outsourcade tjänster som kunde ha levererats med intern kapacitet till lägre kostnad.

## Varför det är viktigt

Kronisk personalbrist tvingar organisationer att använda dyra bemanningstaxor — ofta 2–3 gånger den vanliga taxan — för att hålla kritiska tjänster igång.

## Matematiken

```
Undvikbar kostnad = (Bemanningstaxa − intern taxa) × levererade timmar
```

## Genomarbetat exempel

En avdelning använder 2 000 bemanningstimmar per år till £70/timme jämfört med en intern taxa på £30/timme: undvikbar merkostnad = £80 000/år.

## Koppling till mjukvaruutveckling

Liknar att anlita dyra konsulter för att fylla kronisk personalbrist istället för att investera i permanent teamkapacitet.

## Fallgropar

- **Att behandla bemanningskostnader som oundvikliga snarare än som ett symptom på underliggande personalplaneringsproblem.**
- **Att ignorera kvalitetspåverkan av hög personalomsättning på patientvården.**

## Källor

- NHS Improvement, agency staff cost controls.
- Health Education England, workforce planning.
