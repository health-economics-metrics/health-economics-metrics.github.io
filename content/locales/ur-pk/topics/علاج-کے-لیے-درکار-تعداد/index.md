# علاج کے لیے درکار تعداد (NNT)

NNT ایک متعین وقت کی حد میں **ایک** اضافی مریض کو فائدہ پہنچانے کے لیے کتنے مریضوں کو ایک مداخلت ملنی چاہیے، یہ تعداد ہے۔

## یہ کیوں اہم ہے

"دل کے دورے کو 25% کم کرتا ہے!" فیصلہ کن لگتا ہے۔ اگر بنیادی خطرہ 5 سالوں میں 4% ہے، تو مطلق کمی 1 فیصد پوائنٹ ہے۔

## ریاضی

```
ARR = کنٹرول واقعہ شرح − علاج واقعہ شرح
NNT = 1 / ARR
```

## حل شدہ مثال

ایک ہسپتال میں ایک گرنے-پیشن گوئی نظام اعلی خطرے والے مریضوں کو مداخلت کے لیے نشان زد کرتا ہے: NNT = 125۔

## سافٹ ویئر انجینئرنگ سے تعلق

NNT کسی بھی گیٹ یا جانچ کے لیے صحیح اکائی ہے۔ [اسکریننگ کے لیے درکار تعداد](../اسکریننگ-کے-لیے-درکار-تعداد/) ایک سطح اوپر کا ہم منصب عدد ہے، صرف علاج کے لیے نہیں بلکہ پورے اسکریننگ-پھر-علاج پروگرام کے لیے۔
