# Retencja i odpływ

Retencja i odpływ mierzą, czy użytkownicy nadal korzystają z aplikacji zdrowotnej w czasie, czy przestają.

## Dlaczego to ważne

Wskaźniki odpływu aplikacji zdrowotnych mają tendencję do bycia znacznie wyższymi niż w zwykłych aplikacjach konsumenckich.

## Matematyka

```
Miesięczny wskaźnik odpływu = liczba utraconych użytkowników w tym miesiącu / całkowita liczba użytkowników na początku miesiąca × 100%
```

## Rozwiązany przykład

Aplikacja zdrowia psychicznego: na początku 5000, utracono 750 = miesięczny wskaźnik odpływu 15%.

## Powiązanie z inżynierią oprogramowania

Długoterminowa konsekwencja [wskaźników zaangażowania](../wskaźniki-zaangażowania/) i bezpośrednio wpływa na [ekonomię jednostkową aplikacji zdrowotnych](../ekonomia-jednostkowa-aplikacji-zdrowotnych/).

## Pułapki

- **Postrzeganie początkowego odpływu użytkowników jako normalnego bez dalszego badania.**
