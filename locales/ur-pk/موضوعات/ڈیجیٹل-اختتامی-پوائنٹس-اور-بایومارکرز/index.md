# ڈیجیٹل اختتامی پوائنٹس اور بایومارکرز

ایک ڈیجیٹل بایومارکر سینسرز کے ذریعے جمع کیا گیا ایک معروضی جسمانی یا رویے کا پیمانہ ہے۔ ایک ڈیجیٹل اختتامی پوائنٹ ایک ایسا پیمانہ ہے جسے ایک **آزمائشی نتیجے** کے طور پر ترقی دی گئی ہے۔

## یہ کیوں اہم ہے

روایتی آزمائشی اختتامی پوائنٹس وقفے وقفے سے اور مہنگے ہیں؛ ڈیجیٹل اختتامی پوائنٹس مسلسل، ماحولیاتی ہوتے ہیں۔

## ریاضی

```
تجزیاتی درستگی: حوالہ کے ساتھ معاہدہ (MAPE، CCC، Bland-Altman)
```

## حل شدہ مثال

ایک پارکنسن آزمائش ایک کلائی سینسر سے چال کی رفتار بمقابلہ سہ ماہی کلینک-درجہ بند سکور پر غور کرتی ہے: گھنے نمونے سے تغیر ~5× کم ہو جاتا ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

ڈیجیٹل اختتامی پوائنٹس کلینیکل لباس میں ایک ڈیٹا-انجینئرنگ ضابطہ ہیں۔

## عام غلطیاں

- **مکمل توثیق کے طور پر کلینک-کے-ساتھ-ارتباط۔**
