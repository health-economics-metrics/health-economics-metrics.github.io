# क्लाउड इकाई अर्थशास्त्र (FinOps)

क्लाउड इकाई अर्थशास्त्र कच्चे क्लाउड व्यय को **आउटपुट इकाई प्रति लागत** में बदल देता है।

## यह क्यों महत्वपूर्ण है

कुल व्यय संख्याएँ महत्वपूर्ण प्रश्नों का उत्तर नहीं दे सकतीं: क्या उत्पाद अधिक कुशल हो रहा है?

## गणित

```
इकाई लागत = कुल आवंटित लागत / प्रदत्त इकाइयाँ
```

## हल किया गया उदाहरण

एक डिजिटल ट्राइएज सेवा: क्लाउड व्यय £62,000/माह, माह में 380,000 ट्राइएज एपिसोड संभालती है:

```
प्रति एपिसोड औसत लागत ≈ £0.163
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इकाई अर्थशास्त्र वह जगह है जहाँ इंजीनियरिंग विकल्प वित्तीय रूप से सुपाठ्य हो जाते हैं।

## सामान्य गलतियाँ

- **साझा लागतों को अनदेखा करना।**
