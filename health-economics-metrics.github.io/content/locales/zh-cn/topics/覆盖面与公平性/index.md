# 覆盖面与公平性 (Reach and Equity)

RE-AIM——覆盖面（Reach）、有效性（Effectiveness）、采纳度（Adoption）、实施情况（Implementation）、可持续性（Maintenance）——是判断一项干预措施对*整体人群*影响的标准框架。其核心算式是：**公共卫生影响 ≈ 覆盖面 × 有效性**。数字工具还增加了一个公平性维度：数字鸿沟意味着覆盖面天然分布不均，而以数字优先的交付方式，反而可能加剧它本应缩小的健康差距。

## 为什么重要

将 RE-AIM 框架应用于移动医疗（mHealth）的系统综述发现一种一致的特征：覆盖面和采纳度表现强劲，**有效性和可持续性表现薄弱**——应用容易普及，但也很快就会消退。对国家医疗服务体系而言，这意味着一款人均表现出色的产品，可能是一项糟糕的人群层面投资；反之亦然：一款效果一般但能触及数百万人的工具，其产出可能超过一款效果卓越但只能触及数千人的工具（参见 [HALE](../健康调整预期寿命/) 的算式）。公平性不是一个附加约束，而是一个价值驱动因素：数字排斥与年龄、贫困程度、残障和语言高度相关——而这些恰恰是承载着最多可治疗疾病负担的人群——因此被边缘化的那位用户往往具有*高于平均水平*的潜在获益。 关于衡量社会经济健康不平等的正式统计量，见[集中指数](../集中指数/)。

## 计算方法

```
人群影响 ≈ 覆盖面 × 有效性
  覆盖面   = 参与者人数 / 符合条件人群总数（参见 activation-and-uptake.md）
  有效性   = 参与者中的真实世界效应（按留存率加权——
             参见 retention-and-churn.md）

公平性分层版本：
  影响_组g = 覆盖面_g × 有效性_g，按贫困程度五分位数
  / 年龄段 / 语言群体分别报告
  公平性差距 = 影响_最高五分位 − 影响_最低五分位

分布式成本效益分析：按受益群体对 QALY 施加公平性权重——
处境最差人群获得的一个 QALY 权重更高（这是一种日益主流的
HTA 扩展方法）。
```

## 实例计算

一项数字糖尿病预防项目，以两种方式报告：

```
汇总数据：覆盖面 12%，效应 0.02 QALY/参与者 → 每名合格人员 0.0024 QALY

分层数据（按贫困程度五分位）：
  Q1（贫困程度最低）：覆盖面 22%，效应 0.02 → 0.0044
  Q5（贫困程度最高）：覆盖面 4%，  效应 0.025 → 0.0010

该项目为贫困程度最低群体提供的健康量是最高群体的 4.4 倍——
而 Q5 的人均效应反而更高（改善空间更大）。若增加一项
"辅助式数字化"分支（电话指导 + 社区接入渠道），使 Q5 每名
参与者成本提高 20%，将 Q5 覆盖面提升至 12%，则 Q5 的整体影响
提升为三倍，并改善了汇总指标——在这里，公平性投资本身
就是效率投资。
```

## 与软件工程的关联

覆盖面在很大程度上是一种工程产物：设备与操作系统的最低要求、带宽假设、语言支持、无障碍合规性（WCAG）、身份验证门槛，以及仅通过应用商店分发——这些都会将部分人群排除在分母之外，而且往往是不可见的，因为被排除的用户根本不会出现在分析数据中。能够推动公平性的工程实践包括：测量*分母*（对符合条件的人群进行埋点，而不仅仅是用户）；为旧设备和差网络条件预留性能预算；将辅助式数字化路径（电话、短信、自助终端）作为一等公民的主流程，而非"耻辱通道"；以及按公平性维度对每一项仪表盘指标进行分层——未分层的平均值正是不公平藏身之处（[GDS 使用率](../gds-服务指标/)也给出了同样的警示）。

## 常见陷阱

- **有效性基于完成者报告，影响却按整体人群主张**——覆盖面这一项被悄悄丢弃了。
- **把公平性当作事后审计**而非设计输入；事后弥补覆盖面的代价远高于一开始就为其设计。
- **可持续性遗忘症**：这是 RE-AIM 中移动医疗表现最弱的维度——影响主张超出了证据所覆盖的时间跨度。
- **仅数字渠道带来的成本节约**，实际上是把成本转嫁给了被排除的用户和一线员工（参见 [GDS 服务指标](../gds-服务指标/)）。
