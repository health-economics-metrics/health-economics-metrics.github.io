# 遅延コスト(CoD)

遅延コストとは、機能、製品、サービスが提供*されない*単位時間あたりに失われる経済的価値のことです。これは、ソフトウェアデリバリーのメトリクスと医療経済学の間で最も強力な橋渡しです:「出荷が遅れた」を通貨に — あるいはQALYに — 変換します。

## なぜ重要か

Reinertsenの法則:「もし1つだけ定量化するなら、遅延コストを定量化せよ」。ほとんどの組織は、プロジェクトの費用は知っていても、1か月の遅延がどれだけの費用になるかは知らないため、予算を最適化しながら時間の価値を失血し続けます。ヘルスケアソフトウェアにとって、賭け金は文字通りです:経路の改善が1週間遅れるごとに、患者はより悪い健康状態でより長く待ちます。CoDは、NHSの利害関係者に提示する最も強力な数学的枠組みです。なぜなら、それはあなたのソフトウェアの*不在*を値付けするからです。

## 数式

```
CoD = 未提供の間、単位時間あたりに失われる便益   (£/週またはQALY/週)

総遅延損失 = CoD × 遅延期間

優先順位付けについては、WSJFとCD3を参照:CD3 = CoD / 期間。
```

臨床ソフトウェアについては、お金だけでなく健康でも表してください:

```
CoD_健康 = 週あたり影響を受ける患者数 × 患者1人あたりのQALY獲得
CoD_金銭 = CoD_健康 × λ(支払意思額の閾値、£20k〜30k/QALY)
          + 失われる週あたりの運用上の節約
```

## 計算例

**運用面**:あるソフトウェアが経路1件あたり患者1人につき£200を節約します;あるトラストは週に50人のそのような患者を処理します。

```
CoD = 200 × 50 = £10,000/週
10週間の調達遅延は、200 × 50 × 10 = £100,000の回避可能な無駄になります。
```

**臨床面**:あるトリアージの改善が、週100人の患者について5週間の純粋な待機を取り除きます(効用0.68→0.80がより早く得られる):

```
患者1人あたりのQALY獲得 = (5/52) × 0.12 ≈ 0.0115
CoD_健康 = 100 × 0.0115 = 1.15QALY/週
CoD_金銭  = 1.15 × £20,000 ≈ £23,000/週の健康価値
```

6か月の展開遅延は約30QALYの「コスト」となります — これは、IT本番稼働の遅れを臨床的な出来事として再構成する論拠です。(規模の基準として:Black Swan Farmingの有名なMaersk分析は、38週間待たされ、CoD≈$20万/週の単一の機能を発見しました。)

## ソフトウェア工学との関連

CoDは、[DORAのリードタイム](../dora-metrics/)と[フロー効率](../flow-metrics/)を財務的に可読にするメトリクスです:リードタイム × CoD = キューで燃やされたお金(あるいは健康)。用途:

- **優先順位付け**:最も声の大きい利害関係者ではなく、CoD/期間([WSJF/CD3](../wsjf-and-cd3/))で作業を順位付けする。
- **プロセスの経済性**:2週間のリリース周期は、継続的デリバリーと比較して、機能あたり約1週間×CoDの期待される遅延コストを持ちます — バッチに値段をつけてください。
- **調達**:6〜18か月のNHS調達サイクルにはCoDがあります;それを示すことは緊急性についての議論を変えます([予算影響分析](../budget-impact-analysis/)を手頃さの対応物として参照)。

## 落とし穴

- **CoDが線形であると仮定すること**:一部の作業は締め切り型の価値(規制上の日付 — その日以降は無限大のCoD、それ以前はゼロ)や減衰する価値(先行者利益の窓)を持ちます。掛け合わせる前に緊急性のプロファイルを分類してください。
- **誰も欲しがらないアウトプットに対するCoD**:遅延が費用になるのは、そのものに価値がある場合だけです;遅れたゴミは無料です。
- **遅延と割引の二重計上**:[割引](../discounting-and-time-preference/)はすでに複数年の評価期間で時間を値付けしています;CoDは評価期間内の運用版です。CoDは週/月単位に、NPVのシフトは年単位に使ってください。
