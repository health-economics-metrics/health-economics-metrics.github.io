# 节省的床位天数 (Bed Days Saved)

一个床位天数（bed day）是指一名患者占用一张医院床位一天。"节省的床位天数"——通过提前出院、避免入院或虚拟病房（virtual ward）实现——是NHS数字化商业论证中最常用的收益指标，同时也是最常被高估的一项。

## 为何重要

床位是急性医疗的约束瓶颈：一旦床位告罄，择期手术就会被取消，救护车就会排队等候，急诊科就会出现积压。因此，能释放床位天数的干预措施确实具有真实价值——但价值的*性质*完全取决于被释放的那张床位后续会发生什么。财务总监们早已学会对未加推敲的床位天数主张大打折扣；把这笔账算对，是一道信誉检验。

## 计算方法

```
节省的床位天数 = 受影响患者数 × 住院时长变化Δ（或避免的入院数 × 平均住院时长）

价值取决于释放出的产能被如何使用：
  用择期手术重新填满  → 价值 = 手术活动收入或等候名单收益
  病房关闭/缩减规模   → 价值 = 所释放的人员及运营成本（现金）
  被作为冗余产能吸收   → 价值 ≈ 仅相当于边际（"酒店式"）成本，
                        每天£50–£150
```

一个急性床位天数的全额分摊平均成本常被引用为£400以上（国家成本采集数据历史上对超额床位天数的均值约为£350）——但参见[边际成本与平均成本](../边际成本与平均成本/)：平均成本几乎从来都不是真正被节省下来的那部分。

## 实例演算

某远程监测型"虚拟病房"让每年600名患者提前2天出院：共节省1,200个床位天数。

- **未加推敲的主张**：1,200 × £400 = £480,000。除非有病房因此关闭，否则这个数字是错的。
- **诚实的主张**：该信托机构用骨科择期患者回填这些床位。1,200个床位天数 ÷ 平均住院时长3天 = 400例额外的择期手术病程，按活动量付费（activity-based payment）机制每例收入约£6,000计算 = **£240万的额外获资助活动量**（须扣除治疗这些患者的边际成本），*外加*400名患者从等候名单上移出。虚拟病房本身的运营成本（£350,000）应与此相抵。

被*再利用*的释放产能，其价值往往高于那个未加推敲的现金主张——但这是另一种性质的价值，必须被相应地标注清楚（参见[现金释放型与非现金释放型](../现金释放型-vs-非现金释放型节约/)）。

## 与软件工程的关联

"节省的服务器天数"的表现完全相同。停用常驻运行的环境，只有在实例被真正终止或预留资源真正到期失效时，才能释放现金；被重新纳入资源池吸收的产能，其价值只相当于边际成本（在已承诺支出上约等于0）。对应的纪律是一致的：每一条声称的节省，都要说明其背后的*机制*——是被终止了、被有价值的工作重新填满了，还是干脆凭空消散了。能缩短住院时长的软件（出院协调、远程监测、诊断周转）应当把这三种情形都建模出来，交由信托机构按病房逐一选择。

## 常见陷阱

- **对边际产能采用平均成本估值**——这是最典型的错误。
- **重复计算**：同一张被释放的床位，既算作节省的床位天数，又算作避免的入院数，还算作等候名单的缩减。
- **假设被节省的天数就是最昂贵的天数**：其实住院末期被节省下来的那些天，往往是最便宜（病情最轻）的天数。
