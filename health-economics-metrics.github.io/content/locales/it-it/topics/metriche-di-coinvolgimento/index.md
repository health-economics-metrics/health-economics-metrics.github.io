# Metriche di Coinvolgimento

Le metriche di coinvolgimento misurano quanto gli utenti utilizzano effettivamente un'app sanitaria: viscosità DAU/MAU, frequenza e durata delle sessioni. Nella sanità digitale, il coinvolgimento non è vanità — è **dose**.

## Perché è importante

Un farmaco che rimane nella bottiglia non guarisce nessuno.

## La matematica

```
Viscosità (DAU/MAU) = utenti attivi giornalieri / utenti attivi mensili × 100
```

## Esempio risolto

Lo studio principale di un'app per la pressione sanguigna mostra una riduzione sistolica di 6 mmHg tra gli utenti che registrano ≥4 volte a settimana.

## Collegamento con l'ingegneria del software

Gli ingegneri possiedono l'imbuto di coinvolgimento.
