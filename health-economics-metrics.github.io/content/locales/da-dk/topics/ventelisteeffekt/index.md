# Ventelisteeffekt

Ventelisteeffekt måler, hvordan sparede kliniske timer eller forbedret effektivitet omdannes til faktisk behandlede ekstra patienter.

## Hvorfor det er vigtigt

Effektivitetsgevinster giver kun reel værdi, når de omdannes til ekstra gennemløb — ellers forbliver de teoretiske.

## Matematikken

```
Ekstra behandlede patienter = Sparede kliniske timer / Gennemsnitlig tid pr. patientkonsultation
```

## Gennemarbejdet eksempel

Et effektivitetsprojekt sparer 500 kliniske timer om måneden; ved en gennemsnitlig konsultationstid på 20 minutter svarer dette til 1.500 ekstra behandlede patienter om måneden.

## Forbindelse til softwareudvikling

Ligner det at omdanne sparet CI/CD-pipelinetid til faktisk leverede ekstra funktioner i stedet for blot at hævde "hurtigere builds".

## Faldgruber

- **At antage, at sparet tid automatisk genanvendes til ekstra patienter — se [kontantfrigørende kontra ikke-kontantfrigørende besparelser](../kontantfrigørende-kontra-ikke-kontantfrigørende-besparelser/).**
- **At ignorere ophobet efterspørgsel, der hurtigt fylder ventelisten igen.**
