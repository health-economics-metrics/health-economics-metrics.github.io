# 비용효과분석(CEA)

CEA는 **자연 단위**로 측정된 단일 결과에 대해 대안적 개입의 비용을 비교합니다 — 생존연수, 발견된 사례, 회피된 입원.

## 왜 중요한가

CEA는 모든 옵션이 동일한 결과를 목표로 할 때의 주요 비교입니다.

## 수식

```
ICER = (비용_A − 비용_B) / (효과_A − 효과_B)
```

## 계산 예시

100,000명 인구에서 미진단 심방세동을 찾는 세 가지 방법.

## 소프트웨어 공학과의 연관성

CEA는 옵션들이 하나의 결과를 공유할 때마다 올바른 템플릿입니다.

## 함정

- 하나의 CEA에서 **서로 다른 결과를 가진 옵션들을 비교하기.**
