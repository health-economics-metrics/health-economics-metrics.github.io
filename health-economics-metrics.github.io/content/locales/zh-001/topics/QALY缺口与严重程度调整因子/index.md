# QALY缺口与严重程度调整因子

QALY缺口衡量的是，与一般人群相比，某种疾病究竟从患者身上夺走了多少未来的健康。NICE用它来应用**严重程度调整因子**：人群病情越严重，每获得一个QALY的价值就越高——最高可达标准阈值的1.7倍。

## 为何重要

自NICE 2022年手册起，严重程度成为对健康获益价值的一项明确乘数，取代了原先的"临终溢价"机制。一项针对严重病情的技术，其判定标准可高达约每QALY £51,000的有效阈值，而非£30,000。如果你的软件服务的是病情严重的人群（晚期心力衰竭、重度精神疾病），严重程度调整因子可能是一份经济学论证能否获得资助的关键分水岭——而要主张它，你需要用到缺口计算方法。

## 计算方法

两项指标，均基于当前标准照护下的剩余预期寿命计算：

```
绝对缺口   = 一般人群的QALY − 患病人群的QALY
比例缺口   = 绝对缺口 / 一般人群的QALY
```

NICE 2022年权重（取两种测量方式中给出更高权重的一种）：

```
权重×1.0：绝对缺口 < 12 且比例缺口 < 0.85
权重×1.2：绝对缺口 ≥ 12 或比例缺口 ≥ 0.85
权重×1.7：绝对缺口 ≥ 18 或比例缺口 ≥ 0.95
```

该权重会作用于ΔE（等价地作用于阈值）：有效λ在×1.2权重下变为£24,000–£36,000，在×1.7权重下变为£34,000–£51,000。

## 实例演算

某侵袭性病症患者，平均年龄60岁。一般人群在60岁时预期尚有14.2个贴现后QALY；而患有该病症、接受当前照护的患者仅为2.1个。

```
绝对缺口   = 14.2 − 2.1 = 12.1  （≥ 12 → 符合×1.2权重条件）
比例缺口   = 12.1 / 14.2 = 0.852（≥ 0.85 → 同样符合×1.2权重条件）
```

你的监测平台ICER为每QALY £26,000——高于标准的£20,000–£30,000中点判定区间，处于边缘地带。应用×1.2权重后：有效ICER = 26,000 / 1.2 ≈ **每QALY £21,700**——轻松达到可获资助的水平。仅仅是缺口计算这一步，就改变了整个决策结果。

## 与软件工程的联系

严重程度加权是工程组织凭直觉早已在做的一件事的正式化版本：在处境最糟的系统上，为每单位改进投入更多资源。可迁移的模式是：计算每项服务的"SLO缺口"（它相对于其预期健康基线的偏离程度，同时以绝对值与比例表示），并据此对补救工作的价值进行加权。这能用算术而非争论，来证明为什么那个正在燃烧的遗留系统，每节省一小时所获得的投资应当高于一个健康的系统。它同样带来了同一条治理层面的教训：应在优先级排序会议*之前*就公布好这套权重，否则每个团队都会声称自己才是最"严重"的那个。

## 陷阱

- **对照错误的基线计算缺口**：该缺口应基于*当前标准照护*下的情况测量，而非未经治疗的自然病程。
- **对年龄的敏感性**：缺口高度依赖人群年龄（更年轻的患者有更多QALY可能损失 → 绝对缺口更大）；应使用实际接受治疗人群的真实年龄分布。
- **假设该调整因子在其他场景也同样适用**——它是NICE（英格兰）特有的机制；其他卫生技术评估机构对严重程度的处理方式各不相同（有些甚至完全不予考虑）。
