# อัตราส่วนความคุ้มทุนส่วนเพิ่ม (ICER)

ICER วัดต้นทุนเพิ่มเติมต่อหน่วยผลลัพธ์สุขภาพเพิ่มเติมหนึ่งหน่วย (มักเป็น QALY) เมื่อเปรียบเทียบสองการรักษา

## ทำไมจึงสำคัญ

ICER เป็นตัวชี้วัดหลักที่หน่วยงาน HTA เช่น NICE ใช้ตัดสินใจว่าเทคโนโลยีใหม่คุ้มค่าที่จะจ่ายเงินหรือไม่ โดยเปรียบเทียบกับเกณฑ์ความเต็มใจจ่าย

## คณิตศาสตร์

```
ICER = (ต้นทุนของ A − ต้นทุนของ B) / (ผลลัพธ์ของ A − ผลลัพธ์ของ B)
```

## ตัวอย่างที่คำนวณแล้ว

ยาใหม่มีต้นทุนสูงกว่ายามาตรฐาน £5,000 และให้ผลลัพธ์เพิ่มขึ้น 0.25 QALY: ICER = £5,000 / 0.25 = £20,000 ต่อ QALY ซึ่งอยู่ในช่วงที่ NICE มักยอมรับ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการคำนวณต้นทุนเพิ่มเติมต่อหน่วยประสิทธิภาพที่ดีขึ้นหนึ่งหน่วยเมื่อเปรียบเทียบสถาปัตยกรรมสองแบบ — ช่วยตัดสินใจว่าการอัปเกรดคุ้มค่ากับต้นทุนที่เพิ่มขึ้นหรือไม่

## ข้อผิดพลาดที่พบบ่อย

- **การเปรียบเทียบ ICER ข้ามการศึกษาที่ใช้วิธีการวัดผลลัพธ์ต่างกัน**
