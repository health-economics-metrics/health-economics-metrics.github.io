# Viivästymisen kustannus (CoD)

Viivästymisen kustannus on taloudellinen arvo, joka menetetään aikayksikköä kohden siitä, että ominaisuutta, tuotetta tai palvelua *ei* toimiteta.

## Miksi se on tärkeä

Reinertsenin laki: "Jos mittaat vain yhtä asiaa, mittaa viivästymisen kustannus."

## Matematiikka

```
CoD = menetetty hyöty aikayksikköä kohden toimittamattomassa tilassa (£/viikko tai QALY/viikko)
```

## Ratkaistu esimerkki

**Operatiivinen**: ohjelmisto säästää £200 per potilas polulla; CoD = £10 000/viikko.

## Yhteys ohjelmistokehitykseen

CoD on mittari, joka tekee [DORA-läpimenoajasta](../dora-mittarit/) taloudellisesti luettavan.

## Sudenkuopat

- **Oletus, että CoD on lineaarinen.**
