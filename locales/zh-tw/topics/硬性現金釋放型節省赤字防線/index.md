# 硬性現金釋放型節省（赤字防線）

硬性現金釋放型節省，是指醫院能因你的軟體而真正主動**從下個月的預算中刪除**的那些具體科目。對一位嚴格的財務會計師而言——尤其是對一家正在營運赤字的信託機構而言——這是唯一能被完全計數的效益類別。

## 為何重要

許多NHS信託機構在赤字恢復計劃下營運，每一條支出科目都受到嚴格審查。在這種環境下，無論產能效益與品質改善多麼真實，都無法彌合赤字缺口；唯有現金才能。一款能夠證明自己確實刪除了預算科目的軟體產品，在CFO看來*是能自我造血的*，這會徹底改變採購的對話方式：討論不再是"我們負擔得起嗎？"，而變成"我們負擔得起不用它嗎？"本文正是[現金釋放型與非現金釋放型節省](../現金釋放型與非現金釋放型節省/)在赤字場景下最鋒利的那一面。

## 計算方法

NHS最可靠的硬性現金目標，是**溢價臨時用工**。信託機構透過內部"銀行"人員（支付接近標準的費率）與外部"中介"人員（通常為Agenda for Change標準費率的2–3倍，雖設有上限，但在稀缺崗位上經常被突破）來填補人力缺口。

```
硬性節省 = 被避免的溢價班次數 × (溢價費率 − 標準費率)
        + 被避免的加班小時數 × 加班溢價
        + 被取消的外部合同數 × 合同價值

機制要求：必須指明具體的預算科目，以及將確認其削減的具體負責經理。
若沒有人能指出那條具體科目，那就不是硬性現金。
```

## 實例演算

一名5級職級護士，每班次因行政管理負擔損失約1小時；文書工作經常拖延到班次結束後，變成加班，而各病區又需額外預訂"銀行"人員來彌補文書積壓。

某軟體將這一小時歸還給300名護士的排班時段：

```
避免的加班：   300名護士 × 每週2.5小時有償加班 × £8溢價 × 46周
              ≈ 每年£276,000
銀行/中介班次： 每週15個文書補救班次 × £180溢價 × 52周
              ≈ 每年£140,400
硬性現金總計    ≈ 每年£416,000，對比約£150,000的許可成本
```

每一英鎊都可以對照電子排班系統與薪資系統進行審計——而這正是應當透過[效益兌現](../效益兌現/)機制、按月核實該效益的正確方式。（已釋出的NHS人力模型曾聲稱過高達"每花£1可節省£11以上"這樣的比率；對任何此類比率，都應將其視為一個需要用*你自己*信託機構排班資料來檢驗的假設，而非可以直接照搬的既定事實。）

## 與軟體工程的聯絡

中介溢價在工程領域的對應物，正是組織自身的"應急採購"：用於填補交付缺口的承包商日費率、由事件驅動的加班、加急支援合同，以及雲端按需搶購價格所帶來的恐慌性支出。聲稱能帶來硬性現金的生產力軟體，應以同樣的嚴謹態度瞄準這些科目——指明具體預算科目、責任人，以及哪個月開始真正收縮。它所帶來的其他一切，則屬於產能（參見[創造價值的產能](../創造價值的產能營運扭轉/)）或品質：同樣真實、有價值，但性質不同。

## 陷阱

- **把產能稱為"節省"**——這在財務人員面前會瞬間摧毀可信度；參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)中的分類法。
- **將供應商模型的比率當作本地事實來呈現**（即"£11:£1問題"）——應基於信託機構自身的排班資料重新建置模型。
- **混淆一次性節省與持續性節省**：一份被取消的合同，每年都能節省其價值，而不是隻節省一次；一個被裁撤的崗位，只有在其持續保持被裁撤狀態時，才能持續節省薪資。
