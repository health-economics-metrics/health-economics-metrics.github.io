# सक्रियण और अपनाना

सक्रियण दर साइन-अप का वह भाग है जो पहले सार्थक मूल्य तक पहुँचता है। अपनाना जनसंख्या संस्करण है।

## यह क्यों महत्वपूर्ण है

गैर-सक्रिय उपयोगकर्ता शुद्ध लागत हैं।

## गणित

```
सक्रियण दर = विंडो में मुख्य कार्य पूरा करने वाले उपयोगकर्ता / साइन-अप × 100
अपनाना दर = अपनाने वाले / योग्य जनसंख्या × 100
```

## हल किया गया उदाहरण

एक कमीशनर 80,000 योग्य निवासियों को एक मधुमेह-रोकथाम ऐप प्रदान करता है:

```
आमंत्रित → नामांकित: 15% अपनाना
जनसंख्या मूल्य ≈ £1.25M
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

सक्रियण फ़नल का सबसे इंजीनियरिंग-नमनीय चरण है।
