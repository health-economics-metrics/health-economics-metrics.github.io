# 人群归因分数 (Population Attributable Fraction, PAF)

PAF 是人群中疾病或结局负担里可归因于接触某一特定危险因素的比例——若完全消除这一暴露就会消失的那部分。它把“这个危险因素使你的几率翻倍”变成规划者真正可以据以规划的人群层面数字：这一暴露在病例数和成本方面值得多大力度去对抗。

## 为什么重要

Levin 在 1953 年提出 PAF，以回答一个狭窄而具体的问题：如果没有人吸烟，会有多少肺癌消失？同样的算术如今在各处决定着国家预防规划的规模，从烟草和肥胖战略，到世界卫生组织全球疾病负担研究的危险因素排名，因为单是相对风险对影响的说明太少——一个危险因素可能使罕见事件的几率翻倍，却几乎不改变人群的疾病负担；也可能只把常见事件的几率略微抬高，却仍能解释大部分病例。PAF 把“危险因素 X 很危险”变成“消除危险因素 X 每年将预防这么多病例”，这正是预防项目商业论证真正需要的数字。该数字到手后，关于如何为据此采取行动核算成本，见[预防经济学](../预防经济学/)。

## 计算方法

```
PAF = 暴露流行率 × (相对风险 − 1) / (1 + 暴露流行率 × (相对风险 − 1))

暴露流行率 = 暴露于该危险因素的人群比例 (0–1)
相对风险   = 暴露者与非暴露者的结局风险之比（如 2.5 = 2.5 倍）

可归因病例 = 总病例数 × PAF
```

PAF 随暴露流行率和相对风险两者增大——与非常普遍的暴露相关联的中度升高的相对风险（比如 1.5 倍），可能给出比与罕见暴露相关联的惊人相对风险（比如 5 倍）更大的 PAF。这就是它作为一个独立于相对风险的数字而存在的全部理由。

## 算例

某危险因素存在于 30% 的人群中（`暴露流行率 = 0.3`），并使结局风险升高 2.5 倍（`相对风险 = 2.5`）：

```
PAF = 0.3 × (2.5 − 1) / (1 + 0.3 × (2.5 − 1))
    = 0.3 × 1.5 / (1 + 0.3 × 1.5)
    = 0.45 / 1.45
    ≈ 0.3103 (31.0%)

人群中每年 1,000 例：
可归因病例 = 1,000 × 0.3103 ≈ 每年 310 例
```

该结局年度负担的略少于三分之一可归因于这一暴露——完全消除它（理论上限；没有任何实际干预能消除 100% 的暴露）每年将预防约 310 例（每 1,000 例中）。

## 与软件工程的关联

PAF 是“我们的事故量中有多大比例可归因于这一根因？”这一问题的流行病学版本——团队在把某一类部署或依赖与生产事故集合对照衡量时，问的就是同类问题，而不是把每起事故都当作同等值得修复。一个出现在大多数部署中、但引发事故的相对风险只是中等的根因类别，在“工程精力应当先投向哪里”这一点上，可能胜过一个罕见而相对风险很高的类别——这正是 PAF 的观察，换了个说法。

## 陷阱

- **跨危险因素相加 PAF**：影响同一结局的多个因素的 PAF 之和不等于 100%——合起来甚至可能超过，因为各因素相互作用并共享因果通路。把每个 PAF 当作“如果只消除这一个因素”，而绝不是对总风险的划分。
- **在人群之间转移相对风险**：在一个人群中估计的相对风险（基线暴露流行率不同、混杂因素不同），套用到另一人群的暴露流行率上会给出误导性的 PAF。
- **把 PAF 与暴露者中的归因风险混淆**：PAF 是人群层面的，取决于暴露流行率；暴露者中的归因风险是个体层面的，不取决于流行率。它们回答不同的问题——不要用一个去回答另一个的问题。
