# 재입원율

30일 재입원율은 퇴원한 환자 중 30일 이내에 응급으로 돌아오는 비율입니다.

## 왜 중요한가

재입원은 첫 번째 퇴원이 지속되지 않았다는 것을 의미합니다.

## 수식

```
재입원율 = 30일 이내 응급 재입원 / 지표 퇴원 × 100
```

## 계산 예시

심부전 퇴원 지원 앱: 회피된 재입원 연간 80건.

## 소프트웨어 공학과의 연관성

재입원은 보건 시스템의 **변경 실패율**입니다.

## 함정

- **재라벨링을 통한 조작.**
