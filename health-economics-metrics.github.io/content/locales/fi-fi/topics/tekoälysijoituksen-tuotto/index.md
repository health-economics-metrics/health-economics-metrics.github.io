# Tekoälysijoituksen tuotto

Tekoälyn ROI mittaa taloudellista arvoa, joka syntyy verrattuna tekoälyjärjestelmien rakentamisen ja käytön kustannuksiin.

## Miksi se on tärkeä

Tekoälyprojekteilla on usein piilotettuja käyttökustannuksia: infrastruktuuri, mallien koulutus ja jatkuvat päättelykustannukset.

## Matematiikka

```
Tekoälyn ROI = (tuotettu arvo − (kehityskustannus + käyttökustannus)) / (kehityskustannus + käyttökustannus) × 100 %
```

## Ratkaistu esimerkki

Tekoäly kliinisen dokumentaation tiivistämiseen: kehitys £300 000 + käyttö £100 000/vuosi; säästetty lääkäriaika = £600 000/vuosi = 50 %:n ROI ensimmäisenä vuonna.
