# ปีชีวิตที่ได้รับ

ปีชีวิตที่ได้รับวัดจำนวนปีเพิ่มเติมของชีวิตที่สิ่งแทรกแซงให้ผล โดยไม่ปรับตามคุณภาพชีวิต — ต่างจาก QALY ที่รวมทั้งปริมาณและคุณภาพ

## ทำไมจึงสำคัญ

บางครั้งการวัดปริมาณชีวิตล้วนๆ มีประโยชน์เมื่อการปรับคุณภาพสร้างความซับซ้อนหรือเป็นที่ถกเถียง โดยเฉพาะในบริบทของความเสมอภาค ที่ผู้มีความพิการอาจได้รับน้ำหนักอรรถประโยชน์ต่ำกว่าอย่างไม่เป็นธรรม

## คณิตศาสตร์

```
ปีชีวิตที่ได้รับ = อายุคาดเฉลี่ยหลังการรักษา − อายุคาดเฉลี่ยก่อนการรักษา (หรือเทียบกับกลุ่มควบคุม)
```

evLYG (equal value of life years gained) เป็นตัวแปรที่ให้ค่าเท่ากันแก่ทุกปีชีวิตโดยไม่คำนึงถึงความพิการที่มีอยู่ก่อน

## ตัวอย่างที่คำนวณแล้ว

การรักษามะเร็งใหม่เพิ่มอายุคาดเฉลี่ยของผู้ป่วยจาก 3 ปีเป็น 5 ปีหลังการวินิจฉัย ให้ปีชีวิตที่ได้รับ 2 ปี โดยไม่คำนึงถึงคุณภาพชีวิตระหว่างปีเหล่านั้น

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการวัดเวลาทำงาน (uptime) ของระบบล้วนๆ โดยไม่ปรับตามคุณภาพประสบการณ์ผู้ใช้ระหว่างเวลานั้น — บางครั้งมีประโยชน์เป็นตัวชี้วัดง่ายๆ ที่ไม่ต้องการการตัดสินเชิงอัตนัย

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ปีชีวิตที่ได้รับแทน QALY เมื่อคุณภาพชีวิตแตกต่างกันอย่างมากระหว่างตัวเลือก**
- **การเพิกเฉยต่อข้อถกเถียงเรื่องความเสมอภาคที่ evLYG พยายามแก้ไข**
