# Koszt opóźnienia (CoD)

Koszt opóźnienia to wartość ekonomiczna tracona na jednostkę czasu przez to, że funkcja, produkt lub usługa *nie* jest dostarczana.

## Dlaczego to ważne

Prawo Reinertsena: "Jeśli mierzysz tylko jedną rzecz, mierz koszt opóźnienia."

## Matematyka

```
CoD = utracona korzyść na jednostkę czasu w stanie niedostarczonym (£/tydzień lub QALY/tydzień)
```

## Rozwiązany przykład

**Operacyjny**: oprogramowanie oszczędza £200 na pacjenta na ścieżce; CoD = £10 000/tydzień.

## Powiązanie z inżynierią oprogramowania

CoD to wskaźnik, który czyni [czas realizacji DORA](../wskaźniki-dora/) czytelnym finansowo.

## Pułapki

- **Zakładanie, że CoD jest liniowy.**
