# AI निवेश पर प्रतिफल

AI ROI AI पहलों के लिए जिम्मेदार मापनीय लाभ-हानि प्रतिफल है। MIT का 2025 "GenAI Divide" शोध पाता है कि **~95% पायलट कोई मापने योग्य प्रतिफल नहीं दिखाते**।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य प्रणालियों में AI-पायलट पैटर्न का एक नाम है: **पायलटाइटिस**।

## गणित

```
AI ROI = (श्रेय योग्य लाभ − कुल AI लागत) / कुल AI लागत
```

## हल किया गया उदाहरण

एक अस्पताल समूह दो उपयोग मामलों में AI तैनात करता है:

```
उपयोग मामला A — क्लिनिकल-लेटर मसौदा:
  ROI = (380k − 60k − 120k) / 120k ≈ 167% — नकद-मुक्तकारी
```
