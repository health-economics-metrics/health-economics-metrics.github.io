# Оценка медицинских технологий (Health Technology Assessment, HTA)

HTA — это формальный, институционализированный процесс, посредством которого системы здравоохранения решают, стоит ли платить за технологию — лекарство, устройство или ПО. Она объединяет доказательства клинической эффективности с экономической оценкой по опубликованной, обязательной методологии.

## Почему это важно

Если вы продаёте в национальную систему здравоохранения, орган HTA может буквально решить вопрос вашего доступа на рынок. Знание локального процесса — это знание вашего настоящего регулятора ценности:

- **NICE (Англия)**: законодательные оценки по определённому *референсному кейсу* — QALY из [EQ-5D](../eq-5d/), перспектива NHS+PSS [(perspective)](../перспектива-анализа/), [дисконтирование](../дисконтирование-и-временные-предпочтения/) 3,5%, обязателен [PSA](../вероятностный-анализ-чувствительности/) — оценивается относительно £20 тыс.–£30 тыс./QALY с [модификаторами тяжести](../дефицит-qaly-и-модификаторы-тяжести/); высокоспециализированные технологии — до £100 тыс.+ со взвешиванием.
- **ICER (США, неправительственная организация)**: отчёты о доказательствах с *эталоном цены на основе пользы для здоровья* — ценой, при которой продукт был бы затратно-эффективен при $100 тыс.–$150 тыс. за QALY/evLYG — используемым как рычаг на переговорах; плюс «предупреждения о доступности» по бюджетному воздействию.
- **Канада (CADTH → CDA-AMC)**: обзоры возмещения при ≈CAD$50 тыс./QALY; исторически требовали снижения цены примерно в 95% заявок.

## Математика

Сила HTA — не в формуле, а в **предписанном методе**: каждая заявка вычисляет один и тот же [ICER](../инкрементальное-соотношение-затрат-и-эффективности/) по одним и тем же правилам референсного кейса, так что результаты сопоставимы между продуктами и годами. Референсный кейс определяет показатель исхода, инструмент полезности, перспективу, выбор компаратора, ставку дисконтирования, временной горизонт и анализ неопределённости — устраняя каждую степень свободы, которой мог бы воспользоваться спонсор.

## Практический пример

Цифровое терапевтическое средство подаётся на оценку в стиле NICE:

```
Модель: ΔC = +£450/пациент, ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ ниже £20 тыс.
Проверки референсного кейса:
  полезности из EQ-5D-5L с британским набором значений        ✓
  компаратор = текущий маршрут лечения (не «отсутствие лечения») ✓
  PSA: вероятность затратной эффективности 71% при £20 тыс.   ✓ (указано)
  модификатор тяжести: дефицит ниже границ ×1.2               — не заявлен
Рекомендация: рутинное финансирование, со сбором данных реальной клинической практики.
```

Собственный предпочитаемый анализ спонсора показывал £9 000/QALY; референсный кейс поднял это до £15 000, вынудив использовать честный компаратор. Именно этот разрыв — причина существования референсных кейсов.

## Связь с разработкой программного обеспечения

Переносимый артефакт — это **внутренний референсный кейс**: единый предписанный метод для всех бизнес-кейсов по инструментам/платформам — заявленный компаратор, стандартные удельные затраты (см. [национальный тариф и удельные затраты](../национальный-тариф-и-удельные-затраты/) для паттерна), фиксированная ставка дисконтирования, обязательный анализ чувствительности, стандартный шаблон. «Досье AMCP для инструментов», подаваемое в совет по платформе, делает предложения сопоставимыми, а манипуляции — видимыми, точно так же, как HTA делает это для медицины. Начните меньше, чем NICE: шаблон на две страницы плюс опубликованная книга цен лучше, чем отсутствие стандарта вовсе.

О том, как на самом деле моделируется многоцикловая модель HTA, когорта за когортой и цикл за циклом, см. [Когортное моделирование Маркова](../когортное-моделирование-маркова/).

## Подводные камни

- **Отношение к HTA как к формальности после регуляторного допуска** — допуск CE/UKCA/FDA говорит, что продукт безопасен; HTA решает, *стоит ли его покупать*. Разный барьер, разные доказательства.
- **Построение экономической модели после испытания** — генерация доказательств должна проектироваться в обратном порядке от требований референсного кейса.
- **Игнорирование юрисдикционных различий**: ICER, финансируемый в США при $120 тыс./QALY, проваливается у NICE при £30 тыс.; планируйте доказательства и ценообразование по каждому рынку отдельно.
