# Результати, повідомлені пацієнтом

Результати, повідомлені пацієнтом, — це виміри стану здоров'я, симптомів та якості життя, які повідомляє безпосередньо пацієнт без інтерпретації клініциста.

## Чому це важливо

Навіть якщо клінічні показники покращуються, цінність втручання залишається сумнівною, якщо не покращується якість життя, відчута пацієнтом.

## Математика

```
Показник зміни PRO = показник після втручання − показник до втручання (порівняно з мінімальною клінічно важливою різницею)
```

## Розібраний приклад

Застосунок для управління хронічним болем: показник болю PROMIS знижується з 58 до 48, зниження на 10 пунктів (MCID перевищено на 5 пунктів).

## Зв'язок з інженерією програмного забезпечення

Використовується разом з [EQ-5D](../eq-5d/) та доповнює [цифрові кінцеві точки та біомаркери](../цифрові-кінцеві-точки-та-біомаркери/). Про інструмент, специфічний для продуктивності праці, див. [WPAI](../work-productivity-and-activity-impairment/).

## Підводні камені

- **Звітування про статистичну значущість без мінімальної клінічно важливої різниці.**

## Джерела
