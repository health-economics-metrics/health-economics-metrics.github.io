# WSJF এবং CD3

CD3 (সময়কাল দিয়ে ভাগ করা বিলম্বের ব্যয়) এবং WSJF (ওজনযুক্ত সংক্ষিপ্ততম কাজ প্রথম) হলো অগ্রাধিকারকরণ নিয়ম যা **মূল্য-ঘনত্ব** দ্বারা কাজ নির্ধারণ করে: দুর্লভ ক্ষমতার একক প্রতি কত বিলম্ব ব্যয় দূর হয়।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি ব্যাকলগ একটি রেশনিং সমস্যা: অনেক যোগ্য আইটেম, একটি পাইপলাইন। স্বাস্থ্য অর্থনীতি ব্যয়-কার্যকারিতা লিগ টেবিল দিয়ে স্বাস্থ্য বাজেটের জন্য একই সমস্যা সমাধান করেছে।

## গণিত

```
CD3  = বিলম্বের ব্যয় (£/সপ্তাহ) / সময়কাল (সপ্তাহ)

WSJF = (ব্যবহারকারী-ব্যবসায়িক মূল্য + সময় জরুরিতা + ঝুঁকি হ্রাস/সুযোগ
        সক্ষমকরণ) / কাজের আকার
```

## সমাধানকৃত উদাহরণ

তিনটি বৈশিষ্ট্য, একটি দল:

```
বৈশিষ্ট্য CoD (£/সপ্তাহ)   সময়কাল   CD3
A        30,000             10সপ্তাহ  3,000
B        12,000             2সপ্তাহ   6,000
C        5,000              1সপ্তাহ   5,000
```

CD3 ক্রম: B, C, A। একই বৈশিষ্ট্য, একই দল — শুধুমাত্র ক্রমবিন্যাস £৮০,০০০ সাশ্রয় করে।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

হেলথকেয়ার সফটওয়্যার পোর্টফোলিওর জন্য, CoD-কে QALY/সপ্তাহ × থ্রেশহোল্ড + কার্যক্রমগত £/সপ্তাহে প্রকাশ করুন।

## ঝুঁকিপূর্ণ দিক

- **WSJF স্কোর থিয়েটার**: এককহীন ফিবোনাচি বিতর্ক সবচেয়ে জোরে যুক্তিদানকারীর দিকে একত্রিত হয়।
- **সময়কাল কারচুপি**: CD3 র‍্যাঙ্ক স্ফীত করতে আইটেম ভাগ করা।
- **জরুরিতা প্রোফাইল উপেক্ষা করা**: সময়সীমা-আকৃতির CoD স্থির-হার অনুমান ভাঙে।
