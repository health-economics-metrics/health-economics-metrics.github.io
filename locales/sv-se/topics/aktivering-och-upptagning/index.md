# Aktivering och upptagning

Aktivering mäter när nya användare först upplever appens kärnvärde; upptagning mäter hur stor andel av målpopulationen som faktiskt börjar använda tjänsten.

## Varför det är viktigt

Låg upptagning gör även utmärkt utformade interventioner meningslösa på befolkningsnivå.

## Matematiken

```
Upptagningsgrad = antal aktiva användare / målpopulation × 100 %
```

## Genomarbetat exempel

Ett program för fjärrövervakning av blodtryck: målpopulation 10 000, aktiva användare 2 400 = upptagningsgrad 24 %.
