# QALYあたりの炭素フットプリント

QALYあたりの炭素は効率指標であり、介入の炭素排出量(または回避した排出量)を、その介入がもたらすQALYで割ったものです。QALYあたりのコストと直接対応しており、介入の炭素効率をコスト効率と並べて評価できます。「炭素調整済み正味金銭的便益」はさらに一歩進み、英国グリーンブックの公式な非取引炭素価値で炭素の影響を金銭換算し、標準的な[正味金銭的便益](../net-monetary-benefit/)から差し引きます。

## なぜ重要か

NICEとNHSイングランドは現在、コストとQALYに加えて環境への影響も考慮することを求めています。NHSは公的なネットゼロ公約を掲げており、直接排出は2040年までに、サプライチェーン全体のフットプリントは2045年までにネットゼロにするとしています。NICEの医療技術評価マニュアル(PMG36)は、技術評価において環境的持続可能性を新たに出てきた考慮事項として挙げています。デジタルヘルス製品にとっては、炭素がコスト、QALY、[効率フロンティア上の優越関係](../dominance-and-efficiency-frontier/)と並ぶ価値のケースの第4の柱になりつつあることを意味します。どれかの代わりになるわけではありませんが、よく練られたビジネスケースがますます報告を求められる次元です。

## 数式

```
QALYあたりの炭素 = 総排出量_トンCO2e / 総QALY
  (負の値は、獲得したQALYあたりの正味の回避排出量を意味する —
  健康の改善と炭素の削減という二重の利得)

金銭換算した炭素の影響 = 排出量_トンCO2e × トンあたり炭素価値
  (負の排出量 × 正の価値 = 負のコスト、つまり便益)

炭素調整済みNMB = 正味金銭的便益 − 金銭換算した炭素の影響
```

これはコスト/QALYの効率フロンティアの考え方に、QALYあたりの炭素という第2の軸を加えるものです。[優越関係と効率フロンティア](../dominance-and-efficiency-frontier/)と同じ「全選択肢をプロットして劣位のものを見つける」論理を、コストではなく炭素に適用します。

## 計算例

遠隔医療サービスが対面診療を置き換え、年間5,000回の自動車移動(1回あたり約8kg CO2e)を回避します。回避されたCO2eは40トンで、負の排出量(−40.0トン)として表され、年間25QALYをもたらします。

```
QALYあたりの炭素 = −40.0 / 25.0 = 獲得QALYあたり1.6トンCO2eの回避
```

グリーンブックの非取引炭素価値を使います(説明用の数値で、2023年の非取引中央値は約£269/トンCO2eです。グリーンブックは炭素価値を毎年更新するため、実際の分析で引用する前に再確認してください)。

```
金銭換算した炭素の影響 = −40.0 × £269 = −£10,760
```

−£10,760の「コスト」は£10,760の便益です。介入単独の正味金銭的便益が£500,000であれば、次のとおりです。

```
炭素調整済みNMB = £500,000 − (−£10,760) = £510,760
```

炭素の削減はケースを弱めるのではなく強めます。負の排出量という枠組みが浮かび上がらせようとしているのは、この二重の利得です。

## ソフトウェア工学との関連

これはAI/クラウド経済学との、現在進行形の接点です。AIモデルの学習と実行にかかる計算の炭素フットプリントは、NHSの調達における現実の項目になっており、一定の閾値を超えるNHSの供給業者契約にはカーボン削減計画が求められます。[クラウド単位経済学](../cloud-unit-economics/)はすでに計算出力の単位あたりコストを追跡しています。QALYあたりの炭素は、そのモジュールと推論の単位経済学を環境次元へ拡張する将来の「推論あたり炭素コスト」指標の自然なひな形です。ただし、その指標はまだ存在しません。

## 落とし穴

- **境界設定の操作**: 直接排出(スコープ1)だけを数え、デジタルヘルス製品の実際のフットプリントの大半を占めるのが普通であるサプライチェーン排出(スコープ3)を除外すること。
- **古い炭素価値の使用**: グリーンブックは非取引炭素価値を毎年更新するため、引用する£/トンの数値には日付を付ける必要があり、固定の定数として示してはいけません。
- **「炭素効率が良い」を「費用対効果が高い」の代用とすること**: 低炭素でも価値の低い介入は、NHSの資源の使い方として依然として良くありません。炭素はコストやQALYと並ぶ第4の柱であり、どちらの代わりでもありません。
