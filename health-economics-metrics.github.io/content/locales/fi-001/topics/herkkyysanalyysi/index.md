# Herkkyysanalyysi

Herkkyysanalyysi testaa, kuinka herkkä taloudellisen arvioinnin johtopäätös on taustalla olevien oletusten muutoksille.

## Miksi se on tärkeä

Jokainen liiketoimintatapaus perustuu epävarmoihin oletuksiin; herkkyysanalyysi osoittaa, mitkä oletukset todella ovat merkityksellisiä.

## Matematiikka

```
Muuttujan X herkkyys = ΔTulos / ΔX
```

Tornadokaaviot järjestävät muuttujat vaikutuksen mukaan, suurimmasta pienimpään.

## Ratkaistu esimerkki

Triage-sovelluksen liiketoimintatapaus vaihtelee omaksumisasteen oletusta 20 %:n ja 60 %:n välillä: ROI-vaihteluväli ulottuu negatiivisesta vahvasti positiiviseen.

## Yhteys ohjelmistokehitykseen

Muistuttaa suorituskykyoletusten testaamista eri kuormitusskenaarioissa.

## Sudenkuopat

- **Vain yhden muuttujan testaaminen kerrallaan, kun oletukset ovat korreloituneita.**
- **Epärealististen vaihteluvälien valitseminen, jotka vääristävät herkkyyttä.**

## Lähteet
