# Analiza wrażliwości

Analiza wrażliwości testuje, jak wrażliwy jest wniosek z oceny ekonomicznej na zmiany w podstawowych założeniach.

## Dlaczego to ważne

Każde uzasadnienie biznesowe opiera się na niepewnych założeniach; analiza wrażliwości pokazuje, które założenia rzeczywiście mają znaczenie.

## Matematyka

```
Wrażliwość zmiennej X = ΔWynik / ΔX
```

Diagramy tornado rankingują zmienne według wpływu, od największego do najmniejszego.

## Rozwiązany przykład

Uzasadnienie biznesowe dla aplikacji triażowej zmienia założenie o wskaźniku adopcji między 20% a 60%: zakres ROI rozciąga się od negatywnego do silnie pozytywnego.

## Powiązanie z inżynierią oprogramowania

Przypomina testowanie założeń dotyczących wydajności w różnych scenariuszach obciążenia.

## Pułapki

- **Testowanie tylko jednej zmiennej naraz, gdy założenia są skorelowane.**
- **Wybieranie nierealistycznych zakresów, które zniekształcają wrażliwość.**

## Źródła
