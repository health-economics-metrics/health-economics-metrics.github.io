# حاشیائی بمقابلہ اوسط قیمت

اوسط قیمت کل قیمت کو پیداواری اکائیوں کی تعداد سے تقسیم کرنا ہے۔ حاشیائی قیمت *اضافی* ایک اکائی پیدا کرنے کی قیمت ہے۔

## یہ کیوں اہم ہے

ڈیجیٹل صحت کے کاروباری کیسز میں سب سے عام غلطی بچائے گئے وسیلے کی قدر **اوسط** قیمت سے لگانا ہے۔

## ریاضی

```
اوسط قیمت: AC = TC / Q
حاشیائی قیمت: MC = dTC/dQ
```

## حل شدہ مثال

فرض کریں آپ کا سافٹ ویئر سالانہ 1,000 بستر کے دن خالی کرتا ہے۔ بھولا دعویٰ £400,000؛ حاشیائی قیمت پر مبنی دعویٰ £120,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

کلاؤڈ اکنامکس بالکل حاشیائی قیمت کا علاقہ ہے۔
