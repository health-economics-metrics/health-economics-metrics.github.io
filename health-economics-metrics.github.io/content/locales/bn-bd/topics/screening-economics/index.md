# স্ক্রিনিং অর্থনীতি

স্ক্রিনিং অর্থনীতি উপসর্গহীন জনগোষ্ঠীকে পরীক্ষা করার মূল্য নিয়ন্ত্রণ করে। মূল গাণিতিক সত্য: **নিম্ন রোগ প্রাদুর্ভাবে, চমৎকার পরীক্ষাও বেশিরভাগ মিথ্যা ইতিবাচক তৈরি করে**।

## কেন এটি গুরুত্বপূর্ণ

১৯৬৮ সাল থেকে, WHO-র উইলসন-জাংনার মানদণ্ড জনসংখ্যা স্ক্রিনিংয়ের মান নির্ধারণ করেছে: অবস্থা গুরুত্বপূর্ণ হতে হবে, পরীক্ষা গ্রহণযোগ্য এবং সঠিক হতে হবে, কার্যকর চিকিৎসা বিদ্যমান থাকতে হবে।

## গণিত

ইতিবাচক ভবিষ্যদ্বাণীমূলক মান (PPV) নিম্ন প্রাদুর্ভাবে ভেঙে পড়ে:

```
PPV = (সংবেদনশীলতা × প্রাদুর্ভাব) / [সংবেদনশীলতা × প্রাদুর্ভাব + (1 − বিশেষত্ব) × (1 − প্রাদুর্ভাব)]

উদাহরণ: সংবেদনশীলতা 90%, বিশেষত্ব 95%, প্রাদুর্ভাব 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995) ≈ 8.3%
```

## সমাধানকৃত উদাহরণ

একটি বিরল অবস্থার জন্য AI রেটিনাল স্ক্রিনিং, ১০০,০০০ মানুষ, প্রাদুর্ভাব ০.৫%, সংবেদনশীলতা ৯০%, বিশেষত্ব ৯৫%:

```
সত্য ইতিবাচক:  100,000 × 0.005 × 0.90 = 450
মিথ্যা ইতিবাচক: 100,000 × 0.995 × 0.05 = 4,975
প্রতি সত্য কেস ব্যয় ≈ £8,156
```

বিশেষত্ব ৯৯%-এ বাড়ালে: প্রতি কেস ব্যয় ≈ **£4,622** — নিম্ন প্রাদুর্ভাবে সংবেদনশীলতা নয়, বিশেষত্বই যেখানে স্ক্রিনিং অর্থনীতি জেতে বা হারে।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

স্ট্যাটিক বিশ্লেষণ, নিরাপত্তা স্ক্যানিং, এবং অস্বাভাবিকতা সনাক্তকরণ কোডবেস এবং টেলিমেট্রি জুড়ে স্ক্রিনিং কর্মসূচি, সতর্কতা-সুযোগ প্রতি প্রায়ই ১%-এর অনেক নিচে সত্য-ত্রুটি প্রাদুর্ভাবসহ।

## ঝুঁকিপূর্ণ দিক

- **প্রাদুর্ভাব ছাড়া সংবেদনশীলতা/বিশেষত্ব উদ্ধৃত করা** — PPV ছাড়া নির্ভুলতা মার্কেটিং।
- **অতিরিক্ত-নির্ণয় উপেক্ষা করা**: এমন নিষ্ক্রিয় "রোগ" খুঁজে পাওয়া যা কখনো ক্ষতি করত না।
- **লিড-টাইম পক্ষপাত**: পরিবর্তিত ফলাফল ছাড়া আগাম শনাক্তকরণ আপাত বেঁচে থাকা বাড়িয়ে দেখায়।
