# การเปิดใช้งานและการนำไปใช้

การเปิดใช้งานและการนำไปใช้วัดสัดส่วนของประชากรเป้าหมายที่ลงทะเบียนและเริ่มใช้บริการสุขภาพดิจิทัลจริง หลังจากที่มีให้ใช้งานแล้ว

## ทำไมจึงสำคัญ

ผลิตภัณฑ์สุขภาพดิจิทัลที่ยอดเยี่ยมที่ไม่มีใครใช้งานไม่สามารถสร้างมูลค่าได้ — การนำไปใช้เป็นขั้นตอนแรกและมักเป็นจุดที่สูญเสียมูลค่ามากที่สุดในห่วงโซ่การตระหนักถึงมูลค่า

## คณิตศาสตร์

```
อัตราการนำไปใช้ = จำนวนผู้ใช้ที่เปิดใช้งาน / ขนาดประชากรเป้าหมาย × 100%
```

## ตัวอย่างที่คำนวณแล้ว

โปรแกรมดิจิทัลสำหรับโรคเบาหวานที่มีให้ใช้งานสำหรับผู้ป่วยที่มีสิทธิ์ 50,000 ราย แต่มีการลงทะเบียนที่ใช้งานอยู่เพียง 5,000 ราย ให้อัตราการนำไปใช้ 10% ซึ่งแสดงว่ามูลค่าที่เป็นไปได้ส่วนใหญ่ยังไม่ได้รับการตระหนักถึง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับตัวชี้วัดช่องทางการเริ่มต้นใช้งานของผู้ใช้ในผลิตภัณฑ์ซอฟต์แวร์ — จากการลงทะเบียนไปจนถึงช่วงเวลามูลค่าแรก

## ข้อผิดพลาดที่พบบ่อย

- **การระบุสาเหตุของการนำไปใช้ต่ำว่ามาจากการขาดความตระหนักรู้เพียงอย่างเดียว ในขณะที่อุปสรรคด้านการเข้าถึงอาจเป็นสาเหตุหลัก**
- **การวัดการนำไปใช้โดยไม่พิจารณาความแตกต่างด้านทักษะดิจิทัลและการเข้าถึง — ดู [การเข้าถึงและความเสมอภาค](../การเข้าถึงและความเสมอภาค/)**
