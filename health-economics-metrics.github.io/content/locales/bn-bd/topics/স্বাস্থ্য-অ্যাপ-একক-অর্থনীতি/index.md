# স্বাস্থ্য অ্যাপ একক অর্থনীতি

ভোক্তা স্বাস্থ্য পণ্যের বাণিজ্যিক গণিত: গ্রাহক অধিগ্রহণ ব্যয় (CAC), জীবনকাল মূল্য (LTV), ব্যবহারকারী-প্রতি গড় রাজস্ব (ARPU), সদস্য-প্রতি-মাস (PMPM) মূল্য নির্ধারণ, এবং নিয়োগকর্তা-বাজারে **ROI এবং VOI** (বিনিয়োগের মূল্য)-এর মধ্যে পার্থক্য।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য অ্যাপগুলো একটি কাঠামোগত চাপের মুখোমুখি: অধিগ্রহণ ব্যয়বহুল (নিয়ন্ত্রিত দাবি, বিশ্বাসের বাধা) যখন ধরে রাখা যেকোনো সফটওয়্যার ভার্টিক্যালের সবচেয়ে খারাপ (৩০ দিনে ~৯০% পরিত্যাগ)।

## গণিত

```
CAC   = বিক্রয় + বিপণন ব্যয় / নতুন পরিশোধকারী গ্রাহক
LTV   = ARPU × গড় জীবনকাল = ARPU / ছাড়ার হার
স্থায়িত্ব: LTV : CAC ≥ 3

PMPM রাজস্ব = হার × নিবন্ধিত সদস্য × মাস
  ভেন্ডর মার্জিন = PMPM − প্রতি সদস্য প্রতি মাস সেবা-প্রদান ব্যয়
```

## সমাধানকৃত উদাহরণ

একটি B2C স্লিপ অ্যাপ: £৬.৯৯/মাস, মাসিক ছাড়া ১৮%, মিশ্রিত CAC £৩৮।

```
LTV = 6.99 / 0.18 ≈ £38.8 → LTV:CAC ≈ 1.0 — অস্থিতিশীল

নিয়োগকর্তা PMPM-এ স্থানান্তর: £1.20 PMPM × 40,000 কভারড লাইভস = মাসে £48k
সেবা-প্রদান ব্যয়: প্রতি সদস্য ≈ £0.30 → মার্জিন ~75%
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

প্রকৌশল পছন্দ অনুপাতের উভয় দিক নির্ধারণ করে: **সেবা-প্রদান ব্যয়** স্থাপত্য।

## ঝুঁকিপূর্ণ দিক

- **প্রাথমিক-কোহোর্ট ছাড়া থেকে LTV**।
- CFO-র কাছে **ROI হিসেবে উপস্থাপিত VOI**।
