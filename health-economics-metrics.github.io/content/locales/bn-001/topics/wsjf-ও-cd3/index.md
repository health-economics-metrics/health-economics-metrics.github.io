# WSJF ও CD3

CD3 (সময়কাল দ্বারা বিভক্ত বিলম্বের খরচ) এবং WSJF (ওজনযুক্ত সংক্ষিপ্ততম কাজ প্রথম) হল অগ্রাধিকার নিয়ম যা **মূল্য ঘনত্ব** দ্বারা কাজ নির্ধারণ করে: প্রতি ইউনিট দুর্লভ ক্ষমতা ব্যবহারে কতটা বিলম্ব খরচ অপসারিত হয়। একটি ভাগাভাগি, স্থির ক্ষমতার অধীনে, সর্বোচ্চ-CD3-প্রথম মোট বিলম্ব খরচ কমানোর জন্য গাণিতিকভাবে সর্বোত্তম ক্রম।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি ব্যাকলগ একটি রেশনিং সমস্যা: অনেক যোগ্য আইটেম, একটি পাইপলাইন। স্বাস্থ্য অর্থনীতি খরচ-কার্যকারিতা লিগ টেবিল দিয়ে স্বাস্থ্য বাজেটের জন্য একই সমস্যা সমাধান করেছে — প্রতি পাউন্ডে অর্জিত স্বাস্থ্য দ্বারা হস্তক্ষেপ র‍্যাংক করুন, বাজেট নিঃশেষ না হওয়া পর্যন্ত তালিকা নিচে অর্থায়ন করুন। CD3 প্রদান ক্ষমতার জন্য অভিন্ন যুক্তি: *সীমাবদ্ধ সম্পদের* প্রতি ইউনিটে সুবিধা, র‍্যাংক ক্রমে অর্থায়িত। ক্রম সঠিক করা বিনামূল্যে টাকা — একই কাজ, একই ক্ষমতা, কম মোট বিলম্ব খরচ।

## গণনা

```
CD3  = বিলম্বের খরচ (£/সপ্তাহ) / সময়কাল (সপ্তাহ)      — বাস্তব ইউনিট (Black Swan Farming)

WSJF = (ব্যবহারকারী-ব্যবসায়িক মূল্য + সময় জরুরিতা + ঝুঁকি হ্রাস/সুযোগ
        সক্ষমকরণ) / কাজের আকার                       — SAFe-র আপেক্ষিক-স্কেল প্রক্সি,
                                                        পরিবর্তিত-ফিবোনাচ্চি স্কোর
```

প্রকৃত মুদ্রা সহ CD3 ([বিলম্বের খরচ](../বিলম্বের-খরচ/)) WSJF-র ইউনিটবিহীন পয়েন্টের চেয়ে কঠোরভাবে শক্তিশালী — WSJF CD3-র প্রতি তেমনি যেমন বহু-মানদণ্ড স্কোরিং সম্পূর্ণ [খরচ-উপযোগিতা বিশ্লেষণ](../খরচ-উপযোগিতা-বিশ্লেষণ/)-র প্রতি: মুদ্রায়ন অব্যবহারিক হলে ব্যবহারযোগ্য, স্কোরের কোনো নোঙর না থাকলে ম্যানিপুলেশনযোগ্য।

## বিস্তারিত উদাহরণ

তিনটি ফিচার, একটি দল:

```
ফিচার   CoD (£/সপ্তাহ)   সময়কাল    CD3
A       30,000          10 সপ্তাহ   3,000
B       12,000          2 সপ্তাহ    6,000
C       5,000           1 সপ্তাহ    5,000
```

CD3 ক্রম: B, C, A। "সবচেয়ে বড় CoD প্রথম" (A, B, C)-এর বিরুদ্ধে মোট বিলম্ব খরচ তুলনা করুন:

```
CD3 ক্রম  (B,C,A): A 3 সপ্তাহ অপেক্ষা করে, C 2 → 30হাজার×3 + 5হাজার×2  = £100হাজার বিলম্ব খরচ
CoD ক্রম  (A,B,C): B 10 অপেক্ষা করে, C 12   → 12হাজার×10 + 5হাজার×12 = £180হাজার
```

একই ফিচার, একই দল — শুধুমাত্র ক্রম £80,000 সাশ্রয় করে। স্বজ্ঞা: ছোট, জরুরি আইটেম প্রথমে যায় কারণ তারা সস্তায় তাদের বিলম্ব খরচ মুক্ত করে; বড় আইটেম সংক্ষিপ্তভাবে অপেক্ষা করে সামান্য হারায়।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

স্বাস্থ্যসেবা সফটওয়্যার পোর্টফোলিওর জন্য, এই সংগ্রহশালা যে ইউনিটে শেখায় তাতে CoD প্রকাশ করুন: QALY/সপ্তাহ × প্রান্তসীমা + অপারেশনাল £/সপ্তাহ, এবং ব্যাকলগ সরাসরি সাধারণ্য হয়ে ওঠে স্বাস্থ্য ব্যবস্থা যা কিনে তার বাকি সবকিছুর সাথে যেভাবে এটি র‍্যাংক করে। দুটি অনুশীলন নোট: (1) সময়কাল মানে *সীমাবদ্ধতা দখলকারী ক্যালেন্ডার সময়*, প্রচেষ্টা নয় — একটি 2-সপ্তাহ অতিবাহিত আইটেম যার বাঁধাই দলের 2 দিন প্রয়োজন তা মনে হওয়ার চেয়ে সস্তা (দেখুন [নিম্নমুখী সম্পদ অপ্টিমাইজেশন](../নিম্নমুখী-সম্পদ-অপ্টিমাইজেশন/)); (2) হাসপাতালগুলি একই নিয়ম অন্তর্নিহিতভাবে চালায় যখন তারা জরুরিতা-ভারযুক্ত থ্রুপুট দ্বারা থিয়েটার তালিকা অর্ডার করে — ক্লিনিক্যাল অগ্রাধিকার বিভাগগুলি তীব্রতা-ভারযুক্ত CD3 (দেখুন [QALY ঘাটতি ও তীব্রতা মডিফায়ার](../qaly-ঘাটতি-ও-তীব্রতা-মডিফায়ার/))।

## ঝুঁকি

- **WSJF স্কোর থিয়েটার**: ইউনিটবিহীন ফিবোনাচ্চি বিতর্ক যে কেউ জোরে তর্ক করে তার দিকে একত্রিত হয়; কমপক্ষে ব্যাকলগের শীর্ষ আইটেমগুলি বাস্তব CoD-এ নোঙর করুন।
- **সময়কাল ম্যানিপুলেশন**: CD3 র‍্যাংক স্ফীত করতে আইটেম বিভক্ত করা — যখন বিভাজন স্বাধীনভাবে মূল্য প্রদান করে তখন ঠিক, না করলে জালিয়াতি।
- **জরুরিতা প্রোফাইল উপেক্ষা করা**: দেড লাইন-আকৃতির CoD (নিয়ন্ত্রক তারিখ) স্থির-হার অনুমান ভাঙে; সেগুলি তারিখ সম্ভাব্যতা দিয়ে নির্ধারণ করুন, তারপর বাকিগুলি CD3।
- **পুনঃর‍্যাংকিং হাঁকপাঁক**: CD3 প্রতিশ্রুতি সময়ে ক্রম সিদ্ধান্তের জন্য, চলমান কাজের দৈনিক পুনর্বিন্যাসের জন্য নয় (WIP-এর উপর [প্রবাহ মেট্রিক](../প্রবাহ-মেট্রিক/) দেখুন)।
