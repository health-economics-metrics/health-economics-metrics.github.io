# অপেক্ষমাণ তালিকার প্রভাব

অপেক্ষমাণ তালিকার প্রভাব সাশ্রয়ী ক্লিনিক্যাল ক্ষমতাকে অপেক্ষমাণ তালিকা থেকে সরানো (বা দ্রুত সরানো) রোগীতে রূপান্তরিত করে।

## কেন এটি গুরুত্বপূর্ণ

নির্বাচনী অপেক্ষমাণ তালিকা NHS-এর সংজ্ঞায়িত মহামারী-পরবর্তী চ্যালেঞ্জ। "২,০০০ নার্স-ঘণ্টা সাশ্রয় করে" বলা একটি ব্যবসায়িক ক্ষেত্র বিমূর্ত; "৪,০০০ অতিরিক্ত অ্যাপয়েন্টমেন্ট স্লট তৈরি করে, ৩,৮০০ অপেক্ষমাণ রোগী দেখে" একটি প্রধান কার্যনির্বাহী কর্মকর্তা তার বোর্ডে নিয়ে যেতে পারেন এমন একটি গল্প।

## গণিত

```
অতিরিক্ত স্লট     = মুক্ত ঘণ্টা / স্লট সময়কাল × ব্যবহারযোগ্যতা
দেখা রোগী        = অতিরিক্ত স্লট × (1 − DNA হার)
তালিকা হ্রাস      = দেখা রোগী − প্ররোচিত নতুন চাহিদা
```

## সমাধানকৃত উদাহরণ

অ্যাম্বিয়েন্ট নথিপত্র সফটওয়্যার ২০ জন ক্লিনিক নার্সের প্রত্যেকের জন্য দিনে ৪৫ মিনিট সাশ্রয় করে। ২৫০ দিনে: 20 × 0.75 × 250 = বছরে ৩,৭৫০ ঘণ্টা।

```
স্লট (৩০ মিনিট, ৮৫% ব্যবহারযোগ্য) = 3,750 / 0.5 × 0.85 = 6,375 স্লট
দেখা রোগী (৭% DNA)              = 6,375 × 0.93       ≈ বছরে 5,929
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

একটি অপেক্ষমাণ তালিকা একটি ব্যাকলগ, এবং ব্যাকলগ-বার্নডাউন অর্থনীতি দুই দিকেই স্থানান্তরযোগ্য। স্বাস্থ্য থেকে সফটওয়্যারে: ব্যাকলগ হ্রাসকে বন্ধ করা আইটেম দিয়ে নয়, *ব্যবহারকারীরা* মূল্যের জন্য কতক্ষণ অপেক্ষা করে তা দিয়ে মূল্যায়ন করুন।

## ঝুঁকিপূর্ণ দিক

- **স্লট ≠ রোগী**: DNA হার এবং মুক্ত সময়ের অব্যবহারযোগ্য খণ্ড ভুলে যাওয়া।
- **প্ররোচিত চাহিদা**: দৃশ্যমান অতিরিক্ত ক্ষমতা রেফারেল আকর্ষণ করে।
- **নগদ দাবি করা**: অপেক্ষমাণ-তালিকা প্রভাব ক্ষমতা মূল্য; নগদ দাবি ভিন্ন একটি লাইন।
