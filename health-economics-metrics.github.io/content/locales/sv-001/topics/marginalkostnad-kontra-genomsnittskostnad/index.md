# Marginalkostnad kontra genomsnittskostnad

Marginalkostnad är kostnaden för en extra enhet; genomsnittskostnad är den totala kostnaden delad med antalet enheter. De är sällan lika.

## Varför det är viktigt

Besparingspåståenden baserade på genomsnittskostnad överskattar nästan alltid den verkliga besparingen, eftersom fasta kostnader inte försvinner när volymen minskar.

## Matematiken

```
Marginalkostnad = ΔTotal kostnad / ΔKvantitet
Genomsnittskostnad = Total kostnad / Kvantitet
```

## Genomarbetat exempel

En sjukhusplats har en genomsnittskostnad på £400/dag (inklusive omkostnader), men att frigöra en plats sparar bara cirka £150/dag i faktiskt undvikbara kostnader.

## Koppling till mjukvaruutveckling

Liknar molninfrastruktur: att skala ner en instans sparar marginalkostnaden för beräkning, inte genomsnittskostnaden per användare inklusive fasta plattformskostnader.

## Fallgropar

- **Att använda genomsnittskostnad för att uppskatta besparingar från småskaliga förändringar.**
- **Att behandla fasta kostnader som rörliga.**
