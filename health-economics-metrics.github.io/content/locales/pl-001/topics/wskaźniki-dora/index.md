# Wskaźniki DORA

Wskaźniki DORA to cztery miary wydajności dostawy oprogramowania — częstotliwość wdrożeń, czas realizacji zmian, wskaźnik nieudanych zmian i czas odzyskiwania.

## Dlaczego to ważne

Dziesięć lat badań DORA łączy te wskaźniki z wydajnością organizacyjną.

## Matematyka

```
Czas realizacji = t(wdrożenie) − t(commit), mediana
```

## Rozwiązany przykład

Zespół oprogramowania przepływu pacjentów trustu, przed/po: wdrożenia z miesięcznych → tygodniowych.

## Powiązanie z inżynierią oprogramowania

To jest *dokładnie* strona oprogramowania.
