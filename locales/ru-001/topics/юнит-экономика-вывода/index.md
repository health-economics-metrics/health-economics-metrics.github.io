# Юнит-экономика вывода

Юнит-экономика вывода оценивает функции ИИ по их предельным вычислениям: **стоимость на токен**, суммированная в стоимость на транзакцию, на пользователя, на клинический эпизод. Определяющая динамика: цены БЯМ падали примерно **на порядок каждые 1-2 года** при постоянных возможностях — темп дефляции, не имеющий прецедента в расчёте затрат медицинских технологий.

## Почему это важно

Из обвала цен следуют два последствия. Коммерчески, функция ИИ, маргинальная сегодня, может стать тривиально прибыльной через 18 месяцев — а конкурент, оценивающий по сегодняшним затратам, будет вытеснен по цене. Для экономической оценки любая модель экономической эффективности для клинического сервиса с поддержкой ИИ, которая фиксирует цены вывода 2024 года, **существенно завышает текущие затраты** — анализ нуждается в сценариях снижения цен так же, как модели лекарств обрабатывают истечение патентов и выход дженериков. (Референсные точки из исследований: передовые выходные токены ~$15–75/M к середине 2026 года, модели среднего уровня на порядок дешевле, возможности уровня GPT-4 упали с ~$20/M в 2022 году до ~$0,40/M; Epoch AI измерила падения в 9×–900×/год в зависимости от вехи возможностей.)

## Расчёт

```
Стоимость на вызов     = входные токены × входная ставка + выходные токены × выходная ставка
Стоимость на единицу     = Σ вызовов на единицу бизнес-результата (на эпизод
                    триажа, на составленное письмо, на резюме консультации)

Смешанная реальность   = базовый вызов + повторы + контекст RAG (входоёмкий)
                    + вызовы оценки/защитных механизмов (часто 20–50% накладных расходов)

Сценарий снижения цен для многолетних моделей:
  затраты_t = затраты_0 × d^t, тестируйте d ∈ {0,3, 0,5, 0,7}/год в анализе чувствительности
```

## Разобранный пример

Служба резюме выписки на базе ИИ: среднее резюме использует 12 000 входных токенов (контекст записи) + 1200 выходных, плюс проход верификации (6000 вход / 300 выход). При $3/M вход, $15/M выход:

```
Черновик:   12 000 × 3/1M + 1200 × 15/1M  = $0,036 + $0,018 = $0,054
Верификация:   6000 × 3/1M +   300 × 15/1M  = $0,018 + $0,0045 ≈ $0,023
На резюме ≈ $0,077 → на 100 000 резюме/год ≈ $7700

Против ~20 минут-клинициста, сэкономленных на резюме (≈ £25), вывод
составляет 0,25% созданной ценности — экономика доминируется всем
КРОМЕ токенов: интеграция, оценка, управление, внедрение.
```

Этот вывод — стоимость вывода редко является связывающим ограничением при текущих ценах для высокоценных клинических задач — сам по себе является находкой, которую стоит принести на встречи по ценообразованию.

## Связь с программной инженерией

Это [юнит-экономика облака](../юнит-экономика-облака/), специализированная для ИИ, с тремя практическими замечаниями: **измеряйте на бизнес-единицу**, а не на вызов API, чтобы цифра напрямую подключалась к моделям [ИКЭЭ](../инкрементальный-коэффициент-экономической-эффективности/)/[бюджетного воздействия](../анализ-бюджетного-воздействия/); **следите за асимметрией вход/выход** (выход обычно ~4× цены входа; архитектуры RAG входоёмки — архитектурные решения — это ценовые решения); и **маршрутизируйте по уровню задачи** — сопоставление возможностей модели со сложностью задачи (дешёвые модели для классификации, передовые для синтеза) регулярно сокращает смешанную стоимость в 5-10 раз при равном качестве, программная версия использования самого дешёвого эффективного вмешательства ([минимизация затрат](../анализ-минимизации-затрат/), доказанная эквивалентность).

## Подводные камни

- **Многолетние модели с замороженной ценой** — завышает затраты; но также **модели дохода с предполагаемой дефляцией** — ценовая война — это не контракт; смоделируйте оба сценария.
- **Игнорирование накладных расходов оценки**: защитные механизмы, судьи и повторы — это реальные токены, часто большинство в регулируемых средах.
- **Близорукость по токену**: латентность, лимиты скорости и ограничения окна контекста несут затраты, которые не захватывает ни одна цена токена.
