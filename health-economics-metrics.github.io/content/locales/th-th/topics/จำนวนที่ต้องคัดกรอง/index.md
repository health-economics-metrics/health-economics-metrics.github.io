# จำนวนที่ต้องคัดกรอง (NNS)

NNS คือจำนวนคนที่ต้องเข้ารับการคัดกรอง — ไม่ใช่แค่การรักษา — เพื่อป้องกันผลลัพธ์ไม่พึงประสงค์ **หนึ่งราย** ในช่วงติดตามผลที่กำหนด โดยพิจารณาจากความเสี่ยงพื้นฐานของประชากรและการลดความเสี่ยงสัมพัทธ์ที่การตรวจพบและการรักษาตั้งแต่เนิ่นๆ ทำได้ เป็นคู่เทียบระดับโปรแกรมคัดกรองของ NNT: NNT ถามว่าต้อง *รักษา* กี่คนเพื่อป้องกันหนึ่งผลลัพธ์ NNS ถามว่ากี่คนต้องผ่านเส้นทาง *คัดกรองแล้วจึงรักษา* ทั้งหมดจึงจะไปถึงจุดนั้น

## ทำไมจึงสำคัญ

Rembold นำ NNS มาใช้ในปี 1998 ก็เพื่อให้เปรียบเทียบโปรแกรมคัดกรองบนฐานเดียวกับการรักษาได้ เพราะตัวเลขการลดความเสี่ยงสัมพัทธ์ของการทดสอบคัดกรองซ่อนสองสิ่งที่การรักษาไม่ซ่อน: ความเสี่ยงพื้นฐานของประชากรที่ถูกเชิญคัดกรองจริง และข้อเท็จจริงที่ว่าทุกคนที่ได้รับการคัดกรองแบกต้นทุนของการทดสอบและภาระของผลบวกลวง ไม่ใช่เฉพาะส่วนน้อยที่ภายหลังได้ประโยชน์ เกณฑ์ความคุ้มทุนของคณะกรรมการคัดกรองแห่งชาติของสหราชอาณาจักร (ดู[เศรษฐศาสตร์การคัดกรอง](../เศรษฐศาสตร์การคัดกรอง/)) สร้างบนการแยกแยะนี้เอง — โปรแกรมคัดกรองที่มีการลดความเสี่ยงสัมพัทธ์น่าประทับใจในประชากรที่มีความเสี่ยงพื้นฐานต่ำ ก็ยังอาจมี NNS เป็นหลักพัน และต้นทุนโปรแกรมต่อผลลัพธ์ที่ป้องกันได้ก็กลายเป็นคำถามจริง

## คณิตศาสตร์

```
NNS = 1 / (ความเสี่ยงพื้นฐาน × การลดความเสี่ยงสัมพัทธ์)

ความเสี่ยงพื้นฐาน        = ความน่าจะเป็นของผลลัพธ์ในประชากรที่คัดกรอง
                           ตลอดช่วงติดตามผล (0–1)
การลดความเสี่ยงสัมพัทธ์   = สัดส่วนการลดความเสี่ยงที่การรักษาตั้งแต่เนิ่นๆ
                           ซึ่งเกิดขึ้นได้จากการคัดกรองทำได้ (0–1)

ต้นทุนโปรแกรมต่อผลลัพธ์ที่ป้องกันได้ = NNS × ต้นทุนต่อการคัดกรอง
```

เปรียบเทียบตรงกับ[NNT](../จำนวนที่ต้องรักษา/): NNS พับประสิทธิผลของทั้งกรวย คัดกรอง → วินิจฉัย → รักษา เป็นตัวเลขเดียว ขณะที่ NNT สมมุติว่าผู้ป่วยได้รับการวินิจฉัยและเริ่มรักษาแล้ว

## ตัวอย่างที่คำนวณแล้ว

ประชากรเป้าหมายของโปรแกรมคัดกรองมีความเสี่ยงพื้นฐานของเหตุการณ์ 2% ในช่วงศึกษา (`ความเสี่ยงพื้นฐาน = 0.02`) และการตรวจพบตั้งแต่เนิ่นๆ ลดความเสี่ยงสัมพัทธ์ได้ 25% (`การลดความเสี่ยงสัมพัทธ์ = 0.25`):

```
NNS = 1 / (0.02 × 0.25) = 1 / 0.005 = 200

ต้องคัดกรอง 200 คนเพื่อป้องกันหนึ่งผลลัพธ์

ที่ £50 ต่อการคัดกรอง:
ต้นทุนโปรแกรมต่อผลลัพธ์ที่ป้องกันได้ = 200 × £50 = £10,000
```

£10,000 นี้ควรชั่งกับต้นทุนของผลลัพธ์เองและ QALY ที่มันจะทำให้สูญเสีย — การเปรียบเทียบเดียวกับที่[เศรษฐศาสตร์การป้องกัน](../เศรษฐศาสตร์การป้องกัน/)ทำสำหรับโปรแกรมป้องกันโดยทั่วไป

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

NNS คือ "กี่ผู้ใช้ เหตุการณ์ หรือคำขอต้องผ่านเวิร์กโฟลว์ตรวจจับหรือคัดแยก จึงจะจับผลบวกจริงที่ควรลงมือทำได้หนึ่งราย" — เกี่ยวข้องโดยตรงกับระบบมอนิเตอร์และคัดแยกที่ขับเคลื่อนด้วยการแจ้งเตือน ซึ่งสภาวะเป้าหมายที่พบน้อยทำให้ NNS พองตัวเช่นเดียวกับที่ทำให้ค่าพยากรณ์บวกยุบตัว (ดู[เศรษฐศาสตร์การคัดกรอง](../เศรษฐศาสตร์การคัดกรอง/) และ[การประเมินปัญญาประดิษฐ์ทางคลินิก](../การประเมินปัญญาประดิษฐ์ทางคลินิก/)) กฎมอนิเตอร์ที่ต้องประมวลผล 200 เหตุการณ์ต่อการจับได้จริงหนึ่งครั้ง คุ้มรันก็ต่อเมื่อการจับนั้นมีมูลค่าอย่างน้อย 200 เท่าของต้นทุนการคัดแยกต่อเหตุการณ์ — เลขคณิตเดียวกับตัวอย่างสุขภาพข้างต้น

## ข้อผิดพลาดที่พบบ่อย

- **ละเลยการพึ่งพาความเสี่ยงพื้นฐาน**: การทดสอบหรือโปรแกรมคัดกรองเดียวกันมี NNS — และความคุ้มทุน — ต่างกันมากในประชากรเสี่ยงสูงกับเสี่ยงต่ำ อย่านำเสนอ NNS โดยไม่ระบุประชากรที่คำนวณให้
- **อ่านตัวหารผิด**: NNS นับคนที่ *ถูกคัดกรอง* ไม่ใช่คนที่ผลตรวจเป็นบวกหรือเริ่มรักษา มันรวมประสิทธิผลของกรวยทั้งหมดไว้แล้ว ดังนั้นห้ามนำไปเทียบกับตัวชี้วัดที่นับเฉพาะผู้ที่ผลเป็นบวก
- **เปรียบเทียบข้ามช่วงติดตามผล**: ช่วงติดตามผลที่สั้นกว่ามักทำให้ NNS พองตัว เพราะสังเกตเหตุการณ์ได้น้อยกว่าในหน้าต่างนั้น ตัวเลข NNS เปรียบเทียบกันได้ก็ต่อเมื่อคำนวณสำหรับระยะเวลาติดตามผลเท่ากัน
