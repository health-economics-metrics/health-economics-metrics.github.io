# Ekonomi Skrining

Ekonomi skrining mengatur nilai pengujian populasi tanpa gejala. Fakta matematis intinya: **pada prevalensi penyakit yang rendah, bahkan tes yang sangat baik menghasilkan sebagian besar positif palsu**.

## Mengapa ini penting

Sejak 1968, kriteria Wilson–Jungner WHO telah menetapkan standar untuk skrining populasi.

## Matematika

```
PPV = (sensitivitas × prevalensi) / [sensitivitas × prevalensi + (1 − spesifisitas) × (1 − prevalensi)]
```

## Contoh yang diselesaikan

Skrining retina AI untuk kondisi langka, 100.000 orang, prevalensi 0,5%: biaya per kasus nyata ≈ £8.156.

## Hubungan dengan rekayasa perangkat lunak

Analisis statis, pemindaian keamanan adalah program skrining dalam basis kode. Untuk skala seluruh program skrining, bukan satu uji, lihat [jumlah yang perlu diskrining](../jumlah-yang-perlu-diskrining/) — berapa banyak orang yang harus menempuh seluruh jalur skrining-lalu-pengobatan untuk mencegah satu hasil.

## Jebakan

- **Mengutip sensitivitas/spesifisitas tanpa prevalensi.**
