# Dominacja i granica efektywności

Jedna opcja dominuje inną, gdy jest tańsza i co najmniej tak samo skuteczna. Granica efektywności pokazuje opcje niezdominowane.

## Dlaczego to ważne

Zdominowane opcje można natychmiast wyeliminować, co upraszcza przestrzeń decyzyjną przed szczegółowymi obliczeniami efektywności kosztowej.

## Matematyka

```
Opcja A dominuje opcję B, jeśli: koszt(A) ≤ koszt(B) I efekt(A) ≥ efekt(B)
```

## Rozwiązany przykład

Cztery opcje leczenia na wykresie koszt-efekt: opcja C kosztuje więcej niż opcja B, ale daje mniej zdrowia niż mieszanka A i D — opcja C jest rozszerzenie zdominowana i zostaje wyeliminowana.

## Powiązanie z inżynierią oprogramowania

Przypomina eliminowanie opcji architektonicznych, które są jednocześnie droższe i wolniejsze niż alternatywa.

## Pułapki

- **Pomijanie rozszerzonej dominacji i sprawdzanie tylko prostej dominacji.**
- **Porównywanie opcji parami zamiast względem całej granicy.**
