# 現金釋放型與非現金釋放型節省

現金釋放型節省會減少實際支出——某條預算科目金額真正變小。非現金釋放型節省則是釋放出時間或產能，但這些被*重新利用*，而非真正入賬。醫療系統的財務總監將二者視為完全不同的兩個物種，你也應當如此。

## 為何重要

這是應用於任何國家醫療服務體系數位化商業案例中最嚴苛的誠實度檢驗。NHS的效益框架明確要求，將每一項聲稱的效益歸類為現金釋放型、非現金釋放型或定性效益三類之一。大多數數位健康類"節省"——每名病患節省的臨床人員分鐘數、更快的文書記錄——都屬於非現金釋放型：有價值，但不會縮小財政赤字。面對資金缺口的信託機構首席財務官，能花的只有現金。另見[硬性現金釋放型節省](../硬性現金釋放型節省赤字防線/)。

## 計算方法

```
現金釋放型節省 = 變動前的預算科目金額 − 變動後的預算科目金額
                （必須是可真正抽取出來的：被取消的合同、被關閉的病區、
                 減少的中介用工支出、被避免的採購）

非現金釋放型價值 = 被釋放的時間 × 該時間的單位成本
                  （按機會成本估值；這筆錢並*不能*被抽取出來）
```

同一個物理事件（節省下來的一小時），落入哪一類完全取決於接下來發生了什麼：

```
節省一小時 → 加班/中介班次被取消          → 現金釋放型
節省一小時 → 臨床人員多看了一名等候病患    → 非現金釋放型（產能）
節省一小時 → 被吸收進冗餘時間，什麼都沒改變 → 完全沒有效益
```

## 實例演算

某軟體為100名護士每人每個班次節省30分鐘。合計為100 × 0.5 × 每週5個班次 × 46周 ≈ 每年11,500小時。按5級職級約£25/小時的僱主成本計算，一個誘人的頭條數位是每年£287,500。

誠實的拆分應為：

- 20%的時間落在病區目前需以銀行/中介溢價來覆蓋文書記錄超時的場景中：2,300小時 × £35中介費率 = **£80,500現金釋放型**（這些班次確實不再需要預訂）。
- 60%被重新投入直接病患照護：6,900小時 × £25 = **£172,500非現金釋放型產能**——真實價值，但應單獨報告，絕不能稱為"節省"。
- 20%消散在休息與打斷之中：**£0**。若主張這部分收益，則純屬虛構。

一份呈現"£80,500現金 + £172,500產能"的商業案例是可信的。而一份呈現"£287,500節省"的商業案例，會被第一位讀到它的會計師直接否決。

## 與軟體工程的聯絡

完全相同的邏輯也適用於AI程式設計助手的投資回報率："每名開發者每天30分鐘"屬於非現金釋放型產能，除非人員編制、承包商支出或雲成本真的因此下降。應分類分別報告：

- 現金釋放型：被取消的承包商合作、被停用的工具許可、下降的雲支出。
- 產能：更早交付的功能（其價值透過[延遲成本](../延遲成本/)體現）、被消化掉的積壓任務。
- 無效益：碎片化在上下文切換中而消失的分鐘數。

同時也要追蹤*被釋放的時間實際去了哪裡*——效益兌現（參見[benefits-realization.md](../效益兌現/)）之所以存在，正是因為聲稱的產能收益在審計時往往會蒸發消失。

## 陷阱

- **用分鐘數乘以薪資，再稱之為"節省"**——這是最經典的罪過。
- **按平均負荷成本為釋放出的時間估值**，而該時間的邊際用途其實價值很低——參見[邊際成本與平均成本](../邊際成本與平均成本/)。
- **同一小時被重複計算兩次**：既算作現金（避免了一個班次），又算作產能（多看了幾名病患）。
