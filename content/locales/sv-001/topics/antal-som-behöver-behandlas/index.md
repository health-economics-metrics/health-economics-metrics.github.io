# Antal som behöver behandlas (NNT)

NNT mäter hur många patienter som behöver behandlas för att förhindra ett ytterligare negativt utfall — en intuitiv enhet av insats per nytta.

## Varför det är viktigt

NNT översätter abstrakt statistisk signifikans till ett praktiskt tal som kliniker och beslutsfattare kan förstå och jämföra mellan behandlingar.

## Matematiken

```
NNT = 1 / Absolut riskreduktion
```

## Genomarbetat exempel

Ett läkemedel minskar risken för hjärtinfarkt från 10 % till 8 % (absolut riskreduktion 2 %): NNT = 1/0,02 = 50 — 50 patienter behöver behandlas för att förhindra en hjärtinfarkt.

## Koppling till mjukvaruutveckling

Liknar att beräkna hur många användare som behöver uppleva en ny funktion för att generera en extra konvertering. [Antal som behöver screenas](../antal-som-behöver-screenas/) är motsvarande tal en nivå upp, för ett helt screena-och-sedan-behandla-program i stället för en behandling ensam.

## Fallgropar

- **Att jämföra NNT mellan studier med olika grundrisker utan justering.**
- **Att blanda ihop en låg NNT med en kliniskt viktig effekt utan att beakta utfallets allvarlighetsgrad.**
