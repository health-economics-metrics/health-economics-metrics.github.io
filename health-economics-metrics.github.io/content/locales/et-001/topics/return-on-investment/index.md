# Investeeringutasuvus (ROI)

ROI mõõdab investeeringu netofinantskasumit protsendina investeeringukulust.

## Miks see on oluline

ROI on ühine keel tervishoiumajanduse ja üldise äritegevuse vahel, kuid on mõttekas ainult selgelt deklareeritud parameetritega (periood, võrdluspunkt, diskontomäär).

## Matemaatika

```
ROI = (Netokasu − Kulu) / Kulu × 100%
```

## Lahendatud näide

Digitaalne triaažisüsteem maksab £300 000 ja toob esimesel aastal £450 000 säästu: ROI = (£450 000 − £300 000) / £300 000 = 50%.

## Seos tarkvaraarendusega

Sarnaneb refaktoorimispingutuse tasuvuse arvutamisega: vähenenud hoolduskulud jagatud refaktoorimisinvesteeringuga.

## Lõksud

- **Ajaperioodi määratlemata jätmine, muutes ROI väited võrreldamatuks.**
- **Pehmete kasude arvestamine ilma tõenditeta.**
