# کامل معلومات کی متوقع قدر (EVPI)

EVPI وہ زیادہ سے زیادہ رقم ہے جو ایک فیصلہ ساز کو فیصلہ کرنے سے پہلے غیر یقینی صورتحال کو ختم کرنے کے لیے ادا کرنی چاہیے۔

## یہ کیوں اہم ہے

صحت کے نظام مسلسل اس انتخاب کا سامنا کرتے ہیں: نامکمل شواہد پر ابھی اپنانا، یا پہلے مزید تحقیق کی مالی اعانت کرنا۔ پہلے معلومات جمع کرنے کے اختیار کی بجائے بعد میں منصوبہ بڑھانے کے اختیار کی قیمت لگانے کے لیے [حقیقی اختیارات کی قدر پیمائی](../حقیقی-اختیارات-کی-قدر-پیمائی/) دیکھیں۔

## ریاضی

```
EVPI = E_θ[ max_j NMB(j, θ) ] − max_j E_θ[ NMB(j, θ) ]
```

## حل شدہ مثال

5,000 معالجین کو ایک AI دستاویزی معاون شروع کرنا ہے یا نہیں۔ EVPI = £1.2M۔

## سافٹ ویئر انجینئرنگ سے تعلق

EVPI اسپائیک، پائلٹ، A/B ٹیسٹ کی معاشیات ہے۔ تمام غیر یقینی کو ختم کرنے کی بجائے *ایک مخصوص تجویز کردہ مطالعے* کا جائزہ لینے کے لیے [EVSI](../نمونے-کی-معلومات-کی-متوقع-قدر/) دیکھیں۔
