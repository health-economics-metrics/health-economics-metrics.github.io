# Deficit di QALY e Modificatori di Gravità

Il deficit di QALY misura quanta salute futura una malattia toglie ai pazienti rispetto alla popolazione generale.

## Perché è importante

Dal manuale NICE del 2022, la gravità è un moltiplicatore esplicito sul valore dei guadagni di salute.

## La matematica

```
Deficit assoluto = QALY_popolazione_generale − QALY_con_condizione
```

## Esempio risolto

Pazienti con una condizione aggressiva, età media 60 anni. Deficit assoluto = 12,1 (≥ 12 → idoneo per ×1,2).

## Collegamento con l'ingegneria del software

La ponderazione della gravità è una versione formale di ciò che le organizzazioni ingegneristiche fanno istintivamente.
