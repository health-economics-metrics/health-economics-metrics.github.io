# Юнит-экономика облачных сервисов (Cloud Unit Economics, FinOps)

Юнит-экономика облака переводит сырые облачные расходы в **стоимость на единицу результата** — на клиента, на транзакцию, на разрешённый случай, на токен. Это способность FinOps, превращающая «наш счёт AWS — £400 тыс./месяц» в «обслуживание одного пациента стоит £0,83».

## Почему это важно

Цифры общих расходов не могут ответить на важные вопросы: становится ли продукт более или менее эффективным? Улучшает ли рост маржу или разрушает её? Сколько нам следует брать за услугу? Удельные затраты отвечают на все три вопроса. Специфически для цифрового здравоохранения «стоимость разрешённого случая» *является* удельной стоимостью медицинской услуги — напрямую сопоставимой с показателями [National Cost Collection](../национальный-тариф-и-удельные-затраты/), которые заказчик использует для любой другой услуги, что делает её естественным языком для ценообразования цифровых путей в сравнении с традиционными.

## Математика

```
Удельная стоимость = общие распределённые затраты (включая общие/платформенные затраты) / поставленные единицы

Два семейства:
  единицы эффективности ресурсов: стоимость/ГБ хранения, стоимость/час-vCPU, стоимость/токен,
                             стоимость/минуту сборки
  бизнес-единицы:            стоимость/клиент, стоимость/транзакция, стоимость/консультация,
                             стоимость/решённый случай

Применяется дисциплина предельных и средних издержек (marginal-vs-average-cost.md):
законтрактованные/зарезервированные расходы делают предельную удельную стоимость ≈ 0 до следующего
шага обязательств — решения о расширении оценивайте по предельным издержкам, тренды
эффективности — по средним.
```

## Практический пример

Служба цифровой сортировки (триажа): облачные расходы £62 000/месяц (вычисления £30 тыс., данные £18 тыс., распределённая доля платформы £14 тыс.), обрабатывает 380 000 эпизодов сортировки в месяц:

```
Средняя стоимость на эпизод = 62,000 / 380,000 ≈ £0.163

Сравнение с заказчиком: телефонная сортировка ≈ £8–12/звонок, консультация ВОП ≈ £42
→ цифровой эпизод обходится примерно в 2% от самой дешёвой альтернативы с участием
человека — экономика смены канала из gds-service-metrics.md, со стороны затрат.

Проверка тренда: в прошлом году £0.21/эпизод при 240k эпизодов → улучшающаяся экономика
масштаба (амортизация фиксированных затрат платформы), достойно упоминания в ежеквартальном обзоре бизнеса.
```

## Связь с разработкой программного обеспечения

Юнит-экономика — это то место, где инженерные решения становятся понятны финансам: архитектура, вдвое снижающая стоимость эпизода, — это ценовое преимущество; та, что масштабируется супралинейно, — бомба замедленного действия, видимая только в этой метрике. Практики, переносимые из медицинского учёта затрат: **публикуйте правила распределения** (распределённые затраты искажали удельные показатели, пока PLICS не стандартизировала учёт затрат на уровне пациента — распределение затрат на вашу платформу нуждается в той же строгости); **выбирайте единицы, в которых мыслит покупатель** (заказчики покупают эпизоды, а не vCPU); и подавайте удельные затраты в каждую модель [ICER](../инкрементальное-соотношение-затрат-и-эффективности/) и [бюджетного воздействия](../анализ-бюджетного-воздействия/) как авторитетный знаменатель затрат. Для функций ИИ единица — это токен, см. [юнит-экономику инференса](../юнит-экономика-инференса/).

## Подводные камни

- **Игнорирование распределённых затрат**: удельные затраты, исключающие распределение платформы/безопасности/дежурств, занижают показатель на 30–50% и рассыпаются при аудите.
- **Тщеславные знаменатели**: «стоимость вызова API» льстит; «стоимость завершённого эпизода пациента» информирует.
- **Ценообразование предельных решений по средней стоимости**: взимание с команд средней удельной стоимости за использование, которое предельно бесплатно, порождает театр избегания траты (см. [национальный тариф](../национальный-тариф-и-удельные-затраты/) для версии этого стимулирующего бага в NHS).
