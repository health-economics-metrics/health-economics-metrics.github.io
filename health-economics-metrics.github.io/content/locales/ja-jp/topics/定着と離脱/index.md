# 定着と離脱

定着とは、利用者コホートのうちN日後もアクティブなままである割合を測定するものです(D1/D7/D30曲線);離脱はその補集合です。厳しいデジタルヘルスのベースライン:**健康アプリの利用者のおよそ90%が30日以内に離脱します** — デジタルヘルスのD30定着は約3〜4%であり、全アプリの平均約6%に対してです。

## なぜ重要か

Eysenbachは2005年にこれを名付けました:**離脱の法則** — 高い率で利用者を失うことは、実装のバグではなく、eヘルス介入に本質的で構造的な性質であり、eヘルス試験における離脱は日常的に50%を超えます。経済的な帰結は全面的です:定着は、あらゆる便益が届けられ得る*治療の窓*を定義し、[単位経済学](../健康アプリの単位経済学/) — 12日で離脱する利用者に支払われるCACは、LTVもQALYももたらしません。定着曲線で便益を重み付けしない消費者向け健康製品の経済モデルは、存在しない製品を記述しています。

## 数式

```
定着_Dn = n日目にアクティブな利用者数 / コホートサイズ × 100
離脱率  = 期間中に失われた利用者数 / 期間開始時の利用者数 × 100

便益の重み付け(医療経済学の手法):
  獲得された利用者1人あたりの期待便益 = Σ_t 定着(t) × 便益率(t)
  ≈ 定着曲線の下の面積 × 単位時間あたりの便益
  — 試験の便益 × 獲得された利用者の100%「ではない」

D30時点で定着した利用者1人あたりの費用 = CAC / D30定着率
  (D30が4%なら、£5のCACは実際には定着した利用者1人あたり£125)
```

## 計算例

あるメンタルヘルスアプリ:試験は8週間を完了した利用者1人あたり0.02QALYの獲得を示しました。展開コホートは100,000ダウンロード、定着D7 25%、D30 8%、8週目4%:

```
完了者数          = 100,000 × 0.04 = 4,000
届けられたQALY    = 4,000 × 0.02 = 80(100,000 × 0.02 = 2,000ではない)
£20,000/QALYで    = £160万の健康価値(£4,000万ではない)

1ダウンロードあたりの健康価値 = £16 — この数値が、支払者が1ダウンロード
あたりいくら払うべきかを決めるべきものであり、それは素朴な主張の4%です。
定着改善のケース:8週目の完了率を4%→6%に移すと年間40QALYが追加され、
≈£80万 — 定着のエンジニアリングは健康の生産「そのもの」です。
```

## ソフトウェア工学との関連

定着は、上記の計算に従って、プロダクトエンジニアリングが最も直接的に健康価値を製造するメトリクスです。それを動かす実践は日常的です:オンボーディングの初回価値到達までの時間、再エンゲージメントの設計、パフォーマンス、そして決定的に**計画された用量の完了** — 明確な終わり(8週間、その後修了)を持つプログラムは、永続的なDAUではなく*完了*を測定すべきであり、これは広告収益モデルではなく臨床モデルにメトリクスを合わせます。生存分析が正しいツールキットです([獲得生存年](../獲得生存年/)と同じカプラン・マイヤーの数学);獲得チャネルによって曲線をセグメント化してください。チャネルの構成は、ほとんどの機能よりも定着を大きく変えるからです。

## 落とし穴

- **逆方向のIntention-to-treatのロンダリング**:試験は完了者を報告します;展開の経済性は獲得されたすべての人を数えなければなりません(Eysenbachの中心的な警告)。
- **定着の茶番**:治療的な行動を決して行わない通知駆動の「アクティブな」利用者([エンゲージメントメトリクス](../エンゲージメントメトリクス/)を参照)。
- **定義をまたいだ曲線の比較**:「アクティブ」がオープンと定義されるか意味のある行動と定義されるかで、D30は数倍変わります。
- **誰が離脱するかを無視すること**:最も病状の重い人が最も速く離脱するなら、健康な人々の間で定着が改善するにつれて1人あたりの便益は下がります — 曲線を症例構成と組み合わせてください([到達範囲と公平性](../到達範囲と公平性/)を参照)。
