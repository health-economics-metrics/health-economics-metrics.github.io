# अनुपस्थिति दर (DNA)

DNA दर बुक की गई नियुक्तियों का वह प्रतिशत है जहाँ रोगी न तो उपस्थित होता है न ही रद्द करता है। चिकित्सक, कमरा, और स्लॉट के लिए भुगतान किया जाता है; कुछ नहीं होता।

## यह क्यों महत्वपूर्ण है

NHS England के आँकड़े (2019): छूटी हुई GP नियुक्तियाँ सालाना 1.5 करोड़ से अधिक, प्रत्येक ~£30 पर — सालाना **£21.6 करोड़** से अधिक।

## गणित

```
DNA दर = DNA / बुक की गई नियुक्तियाँ × 100
```

## हल किया गया उदाहरण

एक आउटपेशेंट विभाग: सालाना 200,000 नियुक्तियाँ, DNA दर 8%। एक रिमाइंडर-प्लस-रीबुकिंग सेवा DNA को 5.5% तक कम करती है।

```
पुनर्प्राप्त स्लॉट = 200,000 × 0.025 = सालाना 5,000
रिटर्न ≈ 10:1
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यह एक **शेड्यूलिंग-सिस्टम समस्या** है: रिमाइंडर, स्व-सेवा रीबुकिंग।

## सामान्य गलतियाँ

- **रद्द-और-पुनः-बुक को दो बार गिनना।**
- **DNA को शून्य तक पीछा करना।**
