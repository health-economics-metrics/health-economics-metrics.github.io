# Sparade vårddagar

Sparade vårddagar mäter hur många dagar sjukhusvistelse en intervention undviker — ett vanligt mått på värdet av digitala hälsointerventioner.

## Varför det är viktigt

Vårddagar är den vanligaste "arbetshäst"-nyttan i affärscase, men värderas ofta felaktigt genom att använda genomsnittlig istället för marginalkostnad.

## Matematiken

```
Sparade vårddagar = Σ (undvikna inläggningar × genomsnittlig vistelsetid)
```

## Genomarbetat exempel

Ett program för tidig utskrivning undviker 500 inläggningar på i genomsnitt 4 dagar: 2 000 sparade vårddagar, värderade till marginalkostnaden £150/dag = £300 000.

## Koppling till mjukvaruutveckling

Liknar att värdera sparade serverinstanser till marginalkostnaden för beräkning, inte genomsnittskostnaden inklusive fasta omkostnader.

## Fallgropar

- **Att värdera vårddagar till genomsnittlig istället för marginalkostnad — se [marginalkostnad kontra genomsnittskostnad](../marginalkostnad-kontra-genomsnittskostnad/).**
- **Att anta att en ledig plats automatiskt återanvänds.**
