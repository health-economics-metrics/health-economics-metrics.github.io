# Часовий горизонт

Часовий горизонт — це період, протягом якого враховуються витрати та ефекти в економічній оцінці.

## Чому це важливо

Занадто короткий горизонт пропускає пізні вигоди (профілактика); занадто довгий горизонт додає невизначені припущення.

## Математика

```
Загальна цінність = Σ(t=0 до горизонту) (вигоди_t − витрати_t) / (1+r)^t
```

## Розібраний приклад

Програма профілактики діабету показує чисту економію лише через 15 років; оцінка з горизонтом у 5 років помилково оцінить програму як витратну.

## Зв'язок з інженерією програмного забезпечення

Подібно до вибору вікна вимірювання для ROI погашення технічного боргу.

## Підводні камені

- **Маніпуляція горизонтом: вибір періоду, що дає найсприятливіший результат.**
- **Ігнорування залишкових ефектів після горизонту.**

## Джерела

- NICE, time horizon guidance in technology appraisal.
- ISPOR, good practices for cost-effectiveness analysis.
