# प्रतीक्षा सूची प्रभाव

प्रतीक्षा सूची प्रभाव बचाई गई नैदानिक क्षमता को प्रतीक्षा सूची से हटाए गए (या तेज़ी से आगे बढ़ाए गए) रोगियों में बदल देता है।

## यह क्यों महत्वपूर्ण है

वैकल्पिक प्रतीक्षा सूची NHS की परिभाषित महामारी-बाद चुनौती है।

## गणित

```
अतिरिक्त स्लॉट = मुक्त घंटे / स्लॉट अवधि × उपयोगिता
देखे गए रोगी    = अतिरिक्त स्लॉट × (1 − DNA दर)
```

## हल किया गया उदाहरण

एम्बिएंट दस्तावेज़ीकरण सॉफ़्टवेयर 20 क्लिनिक नर्सों में से प्रत्येक के लिए प्रतिदिन 45 मिनट बचाता है।

```
स्लॉट (30 मिनट, 85% उपयोगी) = 6,375 स्लॉट
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

एक प्रतीक्षा सूची एक बैकलॉग है।

## सामान्य गलतियाँ

- **स्लॉट ≠ रोगी।**
- **प्रेरित माँग।**
