# পরিধানযোগ্য যাচাইকরণ

যাচাইকরণ মেট্রিক্স পরিমাণ নির্ধারণ করে একটি পরিধানযোগ্যের পরিমাপ একটি ক্লিনিক্যাল গোল্ড স্ট্যান্ডার্ডের সাথে কতটা মেলে: **MAPE**, সামঞ্জস্য সম্পর্ক, Bland-Altman সামঞ্জস্য — প্লাস পরিচালনামূলক মেট্রিক্স: **পরিধান-সময় কমপ্লায়েন্স** এবং **তথ্য সম্পূর্ণতা**।

## কেন এটি গুরুত্বপূর্ণ

যাচাইকরণ নিম্নধারার সবকিছুর পূর্বশর্ত। হৃদস্পন্দনের জন্য এই ক্ষেত্রের গৃহীত থ্রেশহোল্ড: ECG-র বিরুদ্ধে **MAPE ≤5%** (কঠোর) বা **≤10%** (শিথিল)।

## গণিত

```
MAPE = (1/n) Σ |পরিমাপ_i − রেফারেন্স_i| / রেফারেন্স_i × 100

পরিচালনামূলক গেট:
পরিধান-সময় কমপ্লায়েন্স = পরিধানকৃত সময় / প্রোটোকল সময় × 100
তথ্য সম্পূর্ণতা        = পর্যবেক্ষিত তথ্য বিন্দু / প্রত্যাশিত × 100
```

## সমাধানকৃত উদাহরণ

একটি ভার্চুয়াল-ওয়ার্ড প্রোগ্রাম একটি পর্যবেক্ষণ পরিধানযোগ্য নির্বাচন করে। প্রার্থী A: বিশ্রাম MAPE 2.1%, ব্যায়াম MAPE 11.4%। প্রার্থী B: বিশ্রাম 3.8%, ব্যায়াম 6.9%।

```
ব্যবহারের ক্ষেত্র: বাড়িতে অবনতিশীল-রোগী সনাক্তকরণ — সতর্কতা সক্রিয় হয়
স্থায়ী উচ্চ হৃদস্পন্দনে, প্রায়ই কার্যকলাপের সময়।
প্রার্থী A-এর শিরোনাম (2.1%) ব্রোশিওর জেতে; প্রার্থী B ব্যবহারের
ক্ষেত্র জেতে: সতর্কতা-প্রাসঙ্গিক অবস্থায় (গতি), A-এর 11.4% ত্রুটি
সম্পূর্ণ সতর্কতা থ্রেশহোল্ড ব্যান্ড জুড়ে বিস্তৃত।
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

প্রকৌশলীরা সেন্সর বেছে নেওয়ার সময় যাচাইকরণ তথ্য গ্রহণ করে এবং পরিমাপ বৈশিষ্ট্য তৈরি করার সময় তা *তৈরি* করে — উভয় ভূমিকায় একই শৃঙ্খলা প্রয়োজন: স্থাপনা অবস্থায় পরীক্ষা করুন, ডেমো অবস্থায় নয়।

## ঝুঁকিপূর্ণ দিক

- **সামগ্রিক MAPE লুকায় অবস্থা-নির্দিষ্ট ব্যর্থতা**।
- **যাচাইকরণ জনসংখ্যা ≠ স্থাপনা জনসংখ্যা**: বয়স, ত্বকের রঙ, কম্পন অপটিক্যাল-সেন্সর ত্রুটি স্থানান্তরিত করে।
