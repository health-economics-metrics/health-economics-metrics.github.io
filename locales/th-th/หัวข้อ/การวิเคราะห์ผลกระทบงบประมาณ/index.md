# การวิเคราะห์ผลกระทบงบประมาณ (BIA)

การวิเคราะห์ผลกระทบงบประมาณประเมินว่าเทคโนโลยีใหม่จะส่งผลกระทบต่อค่าใช้จ่ายรวมของระบบสุขภาพในระยะเวลาสั้นอย่างไร — แยกจากคำถามเรื่องความคุ้มค่าในระยะยาว

## ทำไมจึงสำคัญ

เทคโนโลยีที่คุ้มทุนในระยะยาวอาจยังคงไม่สามารถจ่ายได้ในทันทีหากมีผู้ป่วยจำนวนมากที่มีสิทธิ์ได้รับการรักษาพร้อมกัน BIA ตอบคำถาม "เราจ่ายไหวหรือไม่" แยกจาก "มันคุ้มค่าหรือไม่"

## คณิตศาสตร์

```
ผลกระทบงบประมาณต่อปี = (จำนวนผู้ป่วยที่มีสิทธิ์ × อัตราการนำไปใช้ × ต้นทุนสุทธิต่อผู้ป่วย)
```

## ตัวอย่างที่คำนวณแล้ว

ยาใหม่สำหรับโรคเบาหวานมีต้นทุนคุ้มทุนที่ £15,000/QALY (คุ้มค่า) แต่หากมีผู้ป่วยที่มีสิทธิ์ 500,000 คนทั่วประเทศ ต้นทุนรวมปีแรกอาจสูงถึง £1 พันล้าน ซึ่งอาจเกินงบประมาณที่มีอยู่

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการตรวจสอบว่าฟีเจอร์ใหม่ที่คุ้มค่าในระยะยาวจะไม่ทำให้ต้นทุนโครงสร้างพื้นฐานพุ่งสูงเกินงบประมาณรายไตรมาสหากผู้ใช้ทั้งหมดเปิดใช้งานพร้อมกัน การแบ่งยอดผลกระทบต่องบประมาณที่เผยแพร่ตามสถานที่ กลุ่มประชากร หรือปีงบประมาณ — ให้ส่วนแบ่งรวมกันได้ตรงกับตัวเลขที่เผยแพร่พอดี — คือ[การจัดสรรต้นทุนแบบเป๊ะถึงเซ็นต์](../การจัดสรรต้นทุนแบบเป๊ะถึงเซ็นต์/) ส่วนการรวมรายการจำนวนมากที่ป้อนยอดรวมนั้นคือ[การรวมต้นทุนที่ปลอดภัยต่อสกุลเงิน](../การรวมต้นทุนที่ปลอดภัยต่อสกุลเงิน/)

## ข้อผิดพลาดที่พบบ่อย

- **การสับสนระหว่างความคุ้มทุน (ICER ต่ำ) กับความสามารถในการจ่าย (ผลกระทบงบประมาณต่ำ)**
- **การประเมินอัตราการนำไปใช้ต่ำเกินไป ทำให้ผลกระทบงบประมาณจริงสูงกว่าที่คาดการณ์**
