# القيمة المتوقعة للمعلومات الكاملة (EVPI)

EVPI هي أقصى مبلغ ينبغي على صانع القرار دفعه لإزالة عدم اليقين قبل اتخاذ القرار - السعر الرسمي لعبارة "دعنا نُجرِ دراسة أولًا".

## لماذا يهم هذا

الأنظمة الصحية تواجه باستمرار الخيار: التبني الآن بأدلة غير كاملة، أو تمويل المزيد من البحث أولًا. EVPI تضع رقمًا للخيار الثاني. إذا كانت EVPI تساوي 50,000£ وتكلفة التجربة المقترحة 2 مليون£، تبنَّ الآن. إذا كانت EVPI تساوي 20 مليون£، فالتجربة صفقة رابحة. نفس السؤال - "هل ينبغي أن نجرّب هذا قبل التوسّع فيه؟" - يطرح نفسه لكل قرار أداة مؤسسية، ولا يكاد أحد يسعّره. لتسعير خيار توسيع المشروع لاحقًا، لا خيار جمع المعلومات أولًا، انظر [تقييم الخيارات الحقيقية](../تقييم-الخيارات-الحقيقية/).

## الحساب

EVPI هي الفجوة بين اتخاذ القرار بتبصر كامل واتخاذه الآن بناءً على التوقعات:

```
EVPI = E_θ[ أقصى_j NMB(j, θ) ]  −  أقصى_j E_θ[ NMB(j, θ) ]

θ        = المعاملات غير المؤكدة (بتوزيعها المشترك)
NMB(j,θ) = الفائدة النقدية الصافية للخيار j بمعطيات θ
```

الحد الأول: متوسط عائد الخيار الأفضل عبر كل عالَم ممكن (تختار الصحيح دومًا). الحد الثاني: عائد الخيار الواحد الأفضل في المتوسط (يجب أن تلتزم الآن). EVPI ≥ 0 دومًا. EVPI السكانية تُضرَب في عدد القرارات المتأثرة. تُحسَب مباشرةً من عينات [PSA](../تحليل-الحساسية-الاحتمالي/).

## مثال محلول

انشر مساعد توثيق بالذكاء الاصطناعي لـ5,000 طبيب، أو لا. عالمان:

```
العالم أ (احتمال = 0.6): المساعد يوفر 20 دقيقة/يوم ← NMB للنشر = +8 مليون£
العالم ب (احتمال = 0.4): المساعد يوفر ~صفر (احتكاك سير العمل) ← NMB للنشر = −3 مليون£
NMB لـ"عدم النشر" = 0£ في كلا العالمين.
```

قرِّر الآن: E[NMB النشر] = 0.6 × 8 − 0.4 × 3 = **+3.6 مليون£** ← انشر.

بمعلومات كاملة: في العالم أ اختر النشر (+8 مليون£)، وفي العالم ب اختر لا شيء (0£). القيمة المتوقعة = 0.6 × 8 + 0.4 × 0 = **4.8 مليون£**.

```
EVPI = 4.8 مليون − 3.6 مليون = 1.2 مليون£
```

مشروع تجريبي صارم لمدة 3 أشهر بتكلفة 150,000£ يحل بشكل كبير أي عالَم أنت فيه يستحق العناء بوضوح - وأي مشروع تجريبي تتجاوز تكلفته 1.2 مليون£ لا يستحق، مهما كان شاملًا.

## الصلة بهندسة البرمجيات

EVPI هي اقتصاديات الاستطلاع السريع (spike)، والمشروع التجريبي، واختبار A/B، وإثبات المفهوم. تنتج قاعدتين عمليتين:

- **المشروع التجريبي يستحق التمويل فقط إذا كان القرار قد يتغير فعليًا.** إذا كنت ستنشر بصرف النظر عن نتيجة المشروع التجريبي، فإن EVPI = 0 والمشروع مسرحية.
- **حدّد إنفاق المشروع التجريبي عند EVPI.** قيمة المعلومات محدودة بقيمة القرار الذي تُعلمه.

الـEVPI الجزئية (EVPPI) توسّع هذا إلى معاملات منفردة: "ما قيمة تحديد رقم الوقت الموفَّر بدقة؟" - وهذا يخبرك بما ينبغي أن يقيسه المشروع التجريبي. لتقييم *دراسة مقترحة محددة* بدل إزالة كل عدم اليقين، انظر [EVSI](../القيمة-المتوقعة-لمعلومات-العيّنة/).

## المزالق

- **إجراء مشاريع تجريبية دون قاعدة قرار مرفقة** - المعلومات التي لا تستطيع تغيير الاختيار عديمة القيمة بحكم التعريف.
- **تجاهل تكلفة تأخير جمع المعلومات**: مشروع تجريبي لمدة 6 أشهر يؤخر 6 أشهر من الفائدة ([تكلفة التأخير](../تكلفة-التأخير/))؛ القيمة الصافية للمشروع التجريبي = EVPI المحلولة − تكلفة التأخير − تكلفة المشروع التجريبي.
- **معاملة EVPI كتنبؤ.** إنها حد أعلى لقيمة المعلومات، لا تقدير لما ستحققه دراسة محددة.
