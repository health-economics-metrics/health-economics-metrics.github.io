# भुगतान करने की इच्छा सीमा

भुगतान करने की इच्छा (WTP) सीमा वह अधिकतम राशि है जो एक निर्णय-निर्माता स्वास्थ्य लाभ की प्रति इकाई चुकाएगा — वह रेखा जो एक [ICER](../वृद्धिशील-लागत-प्रभावशीलता-अनुपात/) को स्वीकार/अस्वीकार निर्णय में बदल देती है।

## यह क्यों महत्वपूर्ण है

| निकाय | सीमा |
|---|---|
| NICE (इंग्लैंड) | £20,000–£30,000 प्रति QALY |
| ICER (US) | $100,000–$150,000 प्रति QALY/evLYG |
| कनाडा (CADTH) | ≈ CAD$50,000 प्रति QALY |

## गणित

```
ICER = ΔC/ΔE < λ हो तो स्वीकार करें
समकक्ष रूप से: NMB = λ×ΔE − ΔC > 0 हो तो स्वीकार करें
```

## हल किया गया उदाहरण

आपकी डिजिटल थेराप्यूटिक प्रति इलाज किए गए रोगी में 0.05 QALY प्रदान करती है, शुद्ध लागत £800 पर।

```
ICER = 800 / 0.05 = £16,000/QALY
```

इंग्लैंड में: £20k से नीचे → वित्तपोषण योग्य।

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

हर इंजीनियरिंग संगठन का एक अंतर्निहित λ होता है: बचाए गए प्रति इंजीनियर-घंटे पर टूलिंग को वित्तपोषित करने की बाधा।

## सामान्य गलतियाँ

- क्षेत्राधिकार में **सीमा खरीदारी**।
- **λ को मूल्य फर्श के रूप में मानना।**
- **यह अनदेखा करना कि सीमाएँ बदलती हैं।**
- **पहले रूपांतरित किए बिना दूसरी मुद्रा के ICER की सीमा से तुलना**: [मुद्राओं के पार ICER तुलना](../मुद्राओं-के-पार-icer-तुलना/) देखें — रूपांतरण विधि (क्रय शक्ति समता बनाम बाज़ार विनिमय दर) पद्धतिगत रूप से निर्णायक है, पूर्णांकन का ब्योरा नहीं।
- **λ-आधारित मूल्यांकन को श्रम-बाज़ार VSL/VPF परंपरा से मिलाना**: वे भिन्न सैद्धांतिक परंपराओं से आते हैं (स्वास्थ्य-बजट-सीमित पद्धति बनाम मज़दूरी-जोखिम समझौतों से प्रकट वरीयता) और हमेशा संगत नहीं होते — जीवन के मूल्य निर्धारण के वैकल्पिक प्रकट-वरीयता दृष्टिकोण के लिए [सांख्यिकीय जीवन का मूल्य](../सांख्यिकीय-जीवन-का-मूल्य/) देखें।
