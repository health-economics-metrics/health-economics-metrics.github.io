# 优势与效率前沿 (Dominance and the Efficiency Frontier)

如果某个方案的成本更低*且*效果更好,那么另一个方案就被称为**被支配(dominated)**。**效率前沿(efficiency frontier)**是剔除所有被支配方案后剩下的部分:在这个集合中,想获得更多效果就必须付出更多成本。

## 为什么重要

在讨论阈值或预算之前,卫生技术评估首先要剔除任何人都不该选择的方案。将每个方案绘制在成本-效果平面上并画出前沿线,是一个五分钟就能完成的练习,却常常能直接淘汰候选清单中的一半。增量比较([ICER](../增量成本效果比/))随后只在*前沿线上*计算,即每个方案与下一个成本最低的非被支配方案比较——而不是在存在更优中间方案的情况下与"什么都不做"比较。

## 计算方法

```
严格支配(Strict dominance):若 Cost_A ≤ Cost_B 且 Effect_A ≥ Effect_B
                    (至少一个不等式严格成立),则 A 支配 B

扩展支配(Extended dominance):若 A 和 C 的某种组合能以更低的每英镑成本
                    实现更高效果,则 B 被排除——当沿前沿线向上移动时
                    ICER 出现下降即可判定。有效前沿线上的 ICER 必须递增。
```

流程:按效果对方案排序;剔除严格被支配的方案;计算相邻方案间的两两 ICER;剔除任何 ICER 高于下一个效果更优方案的方案(扩展支配);重复直至 ICER 单调递增。

## 实例演算

减少爽约预约的四个方案(效果 = 每年挽回的预约数):

```
方案             年成本      挽回数
什么都不做        £0         0
短信提醒          £20,000    2,000
电话提醒          £120,000   2,200
短信 + AI 分诊     £90,000    3,500
```

电话提醒被短信 + AI 分诊**严格支配**(成本更高,挽回数更少)。前沿线:什么都不做 → 短信 → 短信 + AI。

```
ICER(短信 vs 什么都不做)   = 20,000 / 2,000  = 每挽回一次预约 £10
ICER(短信+AI vs 短信)     = (90,000 − 20,000) / (3,500 − 2,000) = 每次预约 £46.67
```

ICER 递增 → 有效前沿。按每挽回一次住院预约节省约 160 英镑计算(参见[爽约率](../爽约率/)),前沿线上的两步都值得采取;而电话中心方案本就不该被提交到委员会讨论。

## 与软件工程的关联

对任何工具决策都可以绘制同样的图表:一轴是年成本,另一轴是衡量的产出(节省的工时、避免的事故、可实现的部署次数)。位于前沿线左上方的方案在预算争论开始之前就已被淘汰。这将供应商选型从"功能清单式"的争论,重新定义为"你已被支配,会议结束"。它也揭示了企业中常见的模式:为边际收益购买最昂贵的方案——只有当组织愿意为每增量单位支付相应的增量价格时,这种做法才是合理的。

## 常见误区

- **将所有方案与基线比较**,而不是与前沿线上的下一个方案比较——这会通过掩盖更便宜的近似替代方案,而美化昂贵方案。
- **单一维度的效果评分**掩盖了真正重要的信息;如果有两个结果都很重要,要么以站得住脚的方式将它们合并(参见[成本效用分析](../成本效用分析/)),要么呈现两条前沿线。
- **忽视不确定性**:靠近前沿线的方案在[敏感性分析](../敏感性分析/)下可能会互换位置。
