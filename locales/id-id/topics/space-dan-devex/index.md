# SPACE dan DevEx

SPACE dan DevEx adalah kerangka kerja untuk mengukur produktivitas pengembang secara **multidimensi**.

## Mengapa ini penting

Kedua kerangka kerja mengkodekan pelajaran yang sama yang dipelajari penelitian hasil kesehatan beberapa dekade lalu.

## Matematika

```
Aturan SPACE: ≥ 3 dimensi, ≥ 1 perseptual + ≥ 1 metrik sistem
```

## Contoh yang diselesaikan

Sebuah tim platform membenarkan investasi DevEx untuk 300 pengembang.

## Hubungan dengan rekayasa perangkat lunak

Dokumen ini *adalah* sisi perangkat lunak; transfer mengalir ke arah ekonomi kesehatan.

## Jebakan

- **Kontraksi metrik tunggal.**
