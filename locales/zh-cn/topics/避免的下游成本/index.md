# 避免的下游成本 (Avoided Downstream Costs)

避免的下游成本（成本抵消，cost offsets）是指因更早或更好的干预行动而得以避免的未来治疗支出，需与干预措施自身的成本相抵。抵消成本正是一项干预措施能够变得*占优*（既更便宜*又*更好）的机制所在——同时，它也是健康经济学中被重复计算、被过度主张得最严重的一条收益线。

## 为何重要

几乎每一个数字健康价值主张中都包含某种抵消成本的说法："我们的应用能预防入院"、"我们的警报能预防病情恶化"、"我们的平台能避免重复检查"。当抵消成本确实真实存在时，它们会彻底改变整个经济账（参见[ICER增量成本效果比](../增量成本效果比/)的实例演算，其中一笔£60万的抵消成本足以令方案成立）。支付方深知这一点——因此抵消成本主张在任何评审中都会受到最严苛的审视。以下这些可信度规则，正是区分"可获得资助的模型"与"纯营销说辞"的关键所在。

## 计算方法

```
净成本 = 干预成本 − Σ抵消成本

一项有效的抵消成本主张必须满足：
  可归因   ——与该干预措施存在因果关联（有对照组证据支持）
  边际性   ——那笔钱确实不再花出去了，且是按边际成本
            而非平均成本计算（参见marginal-vs-average-cost.md）
  概率加权 ——按该下游事件"原本会发生"的概率加权
  贴现     ——未来避免的成本须折算为现值
  唯一性   ——只计一次，归入一条收益线
```

## 实例演算

"这类迁移风险主张，正确的做法应是这样"：某伤口监测应用面向5,000名术后患者，宣称能避免感染相关的再入院。

```
基线感染再入院率：4.0%；使用该应用后（随机对照试验数据）：3.1%
可归因的避免事件数 = 5,000 × 0.009 = 每年45例
每次再入院病程的成本（该信托机构的边际成本）：£3,200
抵消成本 = 45 × 3,200 = 每年£144,000
应用成本 = 5,000 × £20 = 每年£100,000
净成本 = −£44,000 → 确实实现了成本节约，并且满足：
  来自随机对照试验的归因 ✓  边际成本核算 ✓  来自试验数据的概率 ✓
```

若同样的主张建立在"再入院平均花费£5,800，我们能预防一大批"这种说法之上，则四项检验全部不通过，理应被驳回。

## 与软件工程的关联

"这次迁移能避免未来的重写"本身就是一种抵消成本主张，健康经济学的这些规则能让它变得诚实可信：

- **反事实成本**：这次重写实际上会花多少钱？有什么证据支撑这个数字？
- **概率**：这种未来场景发生的可能性有多大？（不可能是100%——产品会被砍掉，优先级会变。）
- **贴现**：第4年才避免的一次重写，按3.5–10%的贴现率折算，其价值远低于面值。
- **唯一性**：不要把同一次避免的重写既算进技术债这条线，又算进留存那条线。

`抵消价值 = P(未来事件发生) × 反事实成本 × 贴现因子`——把这一行写进提案里，你会发现这个估算数字立刻变得可以被质疑，而这正是它的意义所在。

## 常见陷阱

- **重复计算**——同一次避免的入院，既被算作抵消成本，又被算作节省的床位天数，还被算作附带成本的QALY。
- **对固定成本仍会持续发生的事件使用平均成本来核算抵消额**。
- **对本来只是可能发生的下游事件，悄悄按100%概率处理**。
- **把抵消给其他预算的成本，包装成付费支付方本身的节省**——参见[分析视角](../分析视角/)。
