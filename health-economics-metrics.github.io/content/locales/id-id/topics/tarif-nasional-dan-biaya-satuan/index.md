# Tarif Nasional dan Biaya Satuan

NHS membayar penyedia untuk aktivitas berdasarkan daftar harga nasional berbasis aturan — **NHS Payment Scheme (NHSPS)**.

## Mengapa ini penting

Ini adalah penyebut dari setiap kasus bisnis NHS yang kredibel.

## Matematika

```
Harga tarif = biaya satuan rata-rata nasional (dari NCC) × Market Forces Factor
```

## Contoh yang diselesaikan

Perangkat lunak Anda membebaskan 1 jam per hari untuk perawat Band 6 dalam tahun kerja 250 hari: **£7.750/perawat/tahun** (bukan tunai).

## Hubungan dengan rekayasa perangkat lunak

Ini adalah pola **buku harga internal**.
