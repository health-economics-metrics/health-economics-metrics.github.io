# SPACE og DevEx

SPACE og DevEx er rammeværker til at måle udviklerproduktivitet **flerdimensionalt**.

## Hvorfor det er vigtigt

Begge rammeværker indeholder den samme lærdom, som sundhedsresultatforskningen lærte for årtier siden.

## Matematikken

```
SPACE-regel: ≥ 3 dimensioner, ≥ 1 perceptuel + ≥ 1 systemnøgletal
```

## Gennemarbejdet eksempel

Et platformsteam begrunder en DevEx-investering for 300 udviklere.

## Forbindelse til softwareudvikling

Dette dokument er *netop* softwaresiden; overførslen flyder mod sundhedsøkonomi.

## Faldgruber

- **Reduktion til ét enkelt nøgletal.**
