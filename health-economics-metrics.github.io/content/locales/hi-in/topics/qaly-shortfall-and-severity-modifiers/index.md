# QALY कमी और गंभीरता संशोधक

QALY कमी मापती है कि एक बीमारी सामान्य जनसंख्या की तुलना में रोगियों से कितना भविष्य का स्वास्थ्य छीनती है। NICE इसका उपयोग **गंभीरता संशोधक** लागू करने के लिए करता है।

## यह क्यों महत्वपूर्ण है

NICE के 2022 मैनुअल के बाद से, गंभीरता स्वास्थ्य लाभ के मूल्य पर एक स्पष्ट गुणक है।

## गणित

```
पूर्ण कमी      = QALY_सामान्य_जनसंख्या − QALY_स्थिति_सहित
आनुपातिक कमी  = पूर्ण कमी / QALY_सामान्य_जनसंख्या
```

## हल किया गया उदाहरण

एक आक्रामक स्थिति वाले रोगी, औसत आयु 60।

```
पूर्ण कमी = 14.2 − 2.1 = 12.1 (≥ 12 → ×1.2 के योग्य)
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

गंभीरता भार इंजीनियरिंग संगठन सहज रूप से जो करते हैं उसका एक औपचारिक संस्करण है।
