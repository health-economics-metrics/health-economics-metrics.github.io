# ต้นทุนรวมของการเป็นเจ้าของ (TCO)

ต้นทุนรวมของการเป็นเจ้าของพิจารณาต้นทุนทั้งหมดตลอดวงจรชีวิตของระบบ — การซื้อ การปรับใช้ การบำรุงรักษา และในที่สุดการยกเลิก — ไม่ใช่แค่ราคาซื้อเริ่มต้น

## ทำไมจึงสำคัญ

การมุ่งเน้นเฉพาะราคาซื้อเริ่มต้นมักนำไปสู่ตัวเลือกที่ดูถูกแต่จบลงด้วยค่าใช้จ่ายสูงกว่ามากในระยะยาวเนื่องจากการบำรุงรักษา การฝึกอบรม หรือต้นทุนการผสานรวม

## คณิตศาสตร์

```
TCO = ราคาซื้อ + ต้นทุนการปรับใช้ + ผลรวมของ (ต้นทุนการบำรุงรักษาประจำปี) + ต้นทุนการยกเลิก
```

## ตัวอย่างที่คำนวณแล้ว

ใบอนุญาตซอฟต์แวร์มีราคา £50,000 ต่อปีเป็นเวลา 5 ปี (£250,000) แต่ยังต้องการ £30,000 สำหรับการผสานรวมและ £20,000/ปีสำหรับการสนับสนุนภายใน: TCO = £250,000 + £30,000 + £100,000 = £380,000 ซึ่งสูงกว่าราคาเริ่มต้นอย่างมาก

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

แนวคิดพื้นฐานในการตัดสินใจทางสถาปัตยกรรมซอฟต์แวร์ โดยเฉพาะการพิจารณา [สร้างเทียบกับซื้อ](../สร้างเทียบกับซื้อ/) ตัวเลข TCO หลายปีอย่างข้างต้นเป็นผลรวมของรายการต้นทุนจำนวนมากตามเวลา — ดู[การรวมต้นทุนที่ปลอดภัยต่อสกุลเงิน](../การรวมต้นทุนที่ปลอดภัยต่อสกุลเงิน/) ว่าทำไมผลรวมนั้นควรเป็นทศนิยมที่แม่นยำ ไม่ใช่ทศนิยมลอยตัว เมื่อแบบจำลองต้องลงตัวถึงเซ็นต์ และ[การจัดสรรต้นทุนแบบเป๊ะถึงเซ็นต์](../การจัดสรรต้นทุนแบบเป๊ะถึงเซ็นต์/) สำหรับการแบ่งยอด TCO รวมให้ศูนย์ต้นทุนโดยไม่เสียเซ็นต์

## ข้อผิดพลาดที่พบบ่อย

- **การเปรียบเทียบราคาเริ่มต้นโดยไม่พิจารณาต้นทุนการบำรุงรักษา**
- **การเพิกเฉยต่อต้นทุนการยกเลิก/ออกจากระบบเมื่อสัญญาสิ้นสุด**
