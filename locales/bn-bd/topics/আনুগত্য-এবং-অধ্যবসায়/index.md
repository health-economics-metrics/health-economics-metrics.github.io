# আনুগত্য এবং অধ্যবসায়

আনুগত্য হলো প্রকৃত ব্যবহার নির্ধারিত ব্যবহারের কতটা কাছাকাছি (তীব্রতা); অধ্যবসায় হলো বন্ধ হওয়ার আগে ব্যবহার কতদিন চলতে থাকে (সময়কাল)। ফার্মেসির প্রমিত পরিমাপ আছে — **MPR** এবং **PDC**।

## কেন এটি গুরুত্বপূর্ণ

প্রদানকারীরা ইতিমধ্যে এই সংখ্যায় চলে: PDC ≥৮০% US Medicare Star Ratings-এ প্রবেশ করে। ধারণাগত উন্নতি: **কার্যকর এনগেজমেন্ট** — উদ্দিষ্ট ফলাফল অর্জনের জন্য *যথেষ্ট* এনগেজমেন্ট।

## গণিত

```
MPR = Σ দিনের সরবরাহ / সময়কালে দিন × 100 (১০০% অতিক্রম করতে পারে)
PDC = সরবরাহ দ্বারা আবৃত দিন / সময়কালে দিন × 100 (১০০%-এ সীমাবদ্ধ)

মূল্য গেটিং: উপলব্ধ ফলাফল ≈ কার্যকারিতা × g(আনুগত্য)
```

## সমাধানকৃত উদাহরণ

একটি ডিজিটাল CBT-ফর-ইনসমনিয়া পণ্য, ৬ সপ্তাহে ৬ মডিউল হিসেবে নির্ধারিত; ট্রায়াল কার্যকারিতা ০.০২৫ QALY যারা ≥৪ মডিউল সম্পন্ন করেছে তাদের মধ্যে:

```
1,000 প্রেসক্রিপশন £250-এ → £250,000 প্রদানকারী খরচ
মডিউল সম্পূর্ণতা: ≥4 মডিউল 38%
QALY উপলব্ধ = 1,000 × 0.38 × 0.025 = 9.5
প্রতি QALY ব্যয় = 250,000 / 9.5 ≈ £26,300
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

দুটি শব্দভাণ্ডার একটি ধারণায় মিলিত হয়: সফটওয়্যার অ্যানালিটিক্স ([সক্রিয়করণ](../সক্রিয়করণ-এবং-গ্রহণ/), স্টিকিনেস, [ধরে রাখা](../ধরে-রাখা-এবং-ছাড়া/)) এবং ক্লিনিক্যাল ফার্মেসি (MPR, PDC) উভয়ই একটি হস্তক্ষেপে এক্সপোজার পরিমাপ করছে।

## ঝুঁকিপূর্ণ দিক

- **MPR/PDC মিশ্রণ**: MPR স্ফীত করে।
- **থেরাপির পরিবর্তে মেট্রিক্সের প্রতি আনুগত্য**: ডোজ হিসেবে গণনাকৃত ওপেন।
