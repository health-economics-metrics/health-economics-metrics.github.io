# सहभागिता मीट्रिक्स

सहभागिता मीट्रिक्स मापते हैं कि उपयोगकर्ता वास्तव में एक स्वास्थ्य ऐप का कितना उपयोग करते हैं: DAU/MAU स्टिकीनेस, सत्र आवृत्ति और अवधि। डिजिटल स्वास्थ्य में, सहभागिता व्यर्थ नहीं है — यह **खुराक** है।

## यह क्यों महत्वपूर्ण है

बोतल में रखी दवा किसी को ठीक नहीं करती; अनइंस्टॉल किया गया या कभी न खोला गया ऐप वही विफलता है।

## गणित

```
स्टिकीनेस (DAU/MAU) = दैनिक सक्रिय उपयोगकर्ता / मासिक सक्रिय उपयोगकर्ता × 100

खुराक-प्रतिक्रिया ढाँचा:
  वास्तविक प्रभाव ≈ परीक्षण प्रभाव × f(वास्तविक उपयोग / परीक्षण उपयोग)
```

## हल किया गया उदाहरण

एक रक्तचाप ऐप का मुख्य अध्ययन साप्ताहिक ≥4 बार लॉग करने वाले उपयोगकर्ताओं में 6 mmHg सिस्टोलिक कमी दिखाता है।

```
कार्यात्मक-खुराक उपयोगकर्ता = 7,000 / 50,000 = नामांकित आधार का 14%
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इंजीनियर सहभागिता फ़नल के मालिक हैं, जो उन्हें एक *क्लिनिकल* चर का मालिक बनाता है।
