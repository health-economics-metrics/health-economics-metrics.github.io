# 再入院率

30日再入院率とは、退院した患者のうち30日以内に緊急で戻ってくる割合のことです。これは医療システムにとって代表的な*退院の質*のメトリクスであり、直接的な財政的ペナルティを伴います。

## なぜ重要か

再入院は、最初の退院が定着しなかったことを意味します:早すぎる退院、薬剤の引き継ぎの失敗、フォローアップの欠如、あるいは社会的支援の欠如です。支払者はこれを明示的にペナルティの対象とします — 米国のHospital Readmissions Reduction Programは、病院のメディケア支払いの最大3%を差し引きます;NHSは歴史的に、回避可能な30日緊急再入院に対して支払いを行っていません。したがって、再入院の回避は、単なる容量ではなく、提供者にとって*直接*現金に関連する数少ない便益カテゴリーの1つです。

## 数式

```
再入院率 = 30日以内の緊急再入院数 / 対象退院数 × 100

リスク標準化された比較は症例構成を調整する;ペナルティプログラムは
同種の病院について観測値と期待値を比較する。

回避の価値 = 回避された再入院数 × (1再入院あたりの費用
            + 1再入院あたりのペナルティリスク)
```

## 計算例

心不全の退院支援アプリ(症状追跡、体重アラート、服薬リマインダー、看護師へのエスカレーション):年間2,000件の退院、ベースラインの再入院率18%、試験ではアプリありで14%を示す。

```
回避された再入院 = 2,000 × (0.18 − 0.14) = 年間80件
1再入院あたりの費用 ≈ £3,500 → 年間£280,000の回避された治療費
加えて、それらの入院に対するペナルティ/不払いのリスク。
アプリの費用:2,000 × £60 = 年間£120,000

正味 ≈ 年間+£160,000、回避された悪化に対するQALYの主張を行う前の数値。
```

守るべき数字は4パーセントポイントの効果です:それは対照比較から得られなければなりません。なぜなら再入院率は症例構成と季節によって変動するからです。

## ソフトウェア工学との関連

再入院は医療システムの**変更失敗率**です([DORAメトリクス](../dora-metrics/)を参照):「出荷」されたが30日以内に跳ね返ってきた作業です。この類似性は深いところまで及びます — 再開されたチケットと回帰インシデントは、質の低い「退院の質」(弱い検証、早すぎるクローズ、欠落した引き継ぎ文書)を示します;ペナルティ式の会計(修正するチームが払うのであって、受け取るチームではない)は行動を変えます;そしてどちらの分野も同じ教訓を学びました。引き継ぎへの投資なしに生の処理量(より速い退院、より速い出荷)を押し進めることは、単に目に見えるキューを目に見えない手戻りに変換するだけだということです。「30日再開率」は、サイクルタイムを称賛するあらゆるチームのダッシュボードに載るべきものです。

## 落とし穴

- **再ラベリングによるごまかし**:再入院が観察入院や新しい疾患として分類コード化されること;定義を監査してください。
- **全原因 対 関連原因**:30日全原因には本当に無関係な出来事も含まれます;ペナルティは通常、まさに「関連」がごまかせるという理由で全原因を使います。
- **症例構成への盲目**:より病状が重く貧しい集団にサービスを提供する病院は、どんなアプリも修正できない理由で再入院が多くなります — 比較する前にリスク調整してください。
