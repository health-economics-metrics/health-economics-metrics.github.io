# GDS-palvelumittarit

GDS-palvelumittarit (Government Digital Service) ovat neljä avainmittaria digitaalisten julkisten palveluiden suorituskyvylle: käyttäjätyytyväisyys, valmistumisaste, kustannussäästö ja digitaalinen käyttö.

## Miksi se on tärkeä

Digitaalisten julkisten palveluiden on osoitettava tuloksia veronmaksajille.

## Matematiikka

```
Valmistumisaste = valmistuneet transaktiot / aloitetut transaktiot × 100 %
```

## Ratkaistu esimerkki

Verkossa toimiva potilasrekisteröintipalvelu: 10 000 aloitettu, 8 200 valmistunut = 82 % valmistumisaste.

## Yhteys ohjelmistokehitykseen

Perustelee yhdessä [hyötyjen toteutumisen](../hyötyjen-toteutuminen/) kanssa julkisia digitaalisia investointeja.

## Sudenkuopat

- **Vain digitaalisen käytön tarkastelu, offline-kanavien kustannusten huomiotta jättäminen.**
