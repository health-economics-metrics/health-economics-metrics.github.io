# Intervento Precoce

Se la capacità risparmiata permette a un clinico di rivedere il backlog diagnostico prima, i pazienti passano dalla lista d'attesa al trattamento attivo più velocemente.

## Perché è importante

La progressione della malattia è l'interesse composto dell'assistenza sanitaria.

## La matematica

```
Valore dell'intervento precoce (per paziente) =
    [Costo_tardivo − Costo_precoce]
  + [QALY_precoce − QALY_tardivo] × λ
  × P(progressione durante il ritardo)
```

## Esempio risolto

Backlog di screening per retinopatia diabetica: 4.000 pazienti, in ritardo di 6 mesi. Valore ≈ £540.000.

## Collegamento con l'ingegneria del software

Anche i difetti *progrediscono*.

## Insidie

- **Assumere la progressione nel caso peggiore per tutti.**
