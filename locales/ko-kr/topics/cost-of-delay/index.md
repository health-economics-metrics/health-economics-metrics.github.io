# 지연 비용(CoD)

지연 비용은 기능, 제품, 또는 서비스가 *전달되지 않는* 단위 시간당 손실되는 경제적 가치입니다.

## 왜 중요한가

Reinertsen의 법칙: "한 가지만 측정한다면, 지연 비용을 측정하라."

## 수식

```
CoD = 전달되지 않은 상태에서 단위 시간당 손실된 편익(£/주 또는 QALY/주)
```

## 계산 예시

**운영적**: 소프트웨어가 경로에서 환자당 £200을 절약합니다; CoD = £10,000/주.

## 소프트웨어 공학과의 연관성

CoD는 [DORA 리드타임](../dora-metrics/)을 재무적으로 읽을 수 있게 만드는 지표입니다.
