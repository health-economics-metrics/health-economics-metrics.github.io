# Дисконтування та часова перевага

Дисконтування перетворює майбутні витрати та ефекти на їхню теперішню вартість, оскільки люди та системи надають перевагу вигодам зараз, а не пізніше.

## Чому це важливо

Без дисконтування втручання, що приносить вигоди через 30 років, виглядало б настільки ж привабливим, як те, що приносить вигоди завтра.

## Математика

```
Теперішня вартість = Майбутня вартість / (1 + r)^t
```

Ставка Green Book/NICE становить **3,5%** на рік як для витрат, так і для показників здоров'я.

## Розібраний приклад

Профілактична програма, що приносить £1 мільйон вигоди через 10 років: теперішня вартість = £1 000 000 / (1,035)^10 ≈ £708 900.

## Зв'язок з інженерією програмного забезпечення

Рішення щодо технічного боргу передбачають подібну логіку дисконтування — дивіться [технічний борг](../technical-debt/).

## Підводні камені

- **Використання надто високої ставки для витіснення майбутніх витрат.**
- **Використання різних ставок для витрат і здоров'я без обґрунтування.**
