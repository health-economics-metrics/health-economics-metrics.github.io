# การวิเคราะห์ต้นทุนผลประโยชน์ (CBA)

การวิเคราะห์ต้นทุนผลประโยชน์แปลงทั้งต้นทุนและผลประโยชน์ทั้งหมด รวมถึงผลลัพธ์ด้านสุขภาพ ให้เป็นหน่วยเงินตรา เพื่อคำนวณมูลค่าปัจจุบันสุทธิ

## ทำไมจึงสำคัญ

CBA ช่วยให้สามารถเปรียบเทียบการลงทุนด้านสุขภาพกับการลงทุนในภาคส่วนอื่นโดยสิ้นเชิง (เช่น การศึกษาหรือการขนส่ง) เพราะทุกอย่างถูกแปลงเป็นหน่วยเงินตราเดียวกัน

## คณิตศาสตร์

```
มูลค่าปัจจุบันสุทธิ (NPV) = ผลรวมของ (ผลประโยชน์ที่คิดลดแล้ว − ต้นทุนที่คิดลดแล้ว) ตลอดขอบเขตเวลา
```

## ตัวอย่างที่คำนวณแล้ว

โครงการสาธารณสุขมีต้นทุน £2 ล้าน และให้ผลประโยชน์รวม (รวมมูลค่าชีวิตทางสถิติที่ช่วยไว้) £5 ล้านตลอด 10 ปี เมื่อคิดลดแล้ว NPV = £3 ล้านเป็นบวก แสดงว่าคุ้มค่าลงทุน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการสร้างกรณีทางธุรกิจแบบ NPV มาตรฐานสำหรับโครงการเทคโนโลยี ที่แปลงทั้งต้นทุนการพัฒนาและผลประโยชน์ทางธุรกิจทั้งหมดให้เป็นหน่วยเงินเดียวกัน

## ข้อผิดพลาดที่พบบ่อย

- **การแปลงผลลัพธ์ด้านสุขภาพเป็นเงินโดยใช้วิธีที่ไม่โปร่งใสหรือเป็นที่ถกเถียง**
- **การเพิกเฉยต่อการกระจายผลประโยชน์และต้นทุนระหว่างกลุ่มประชากรต่างๆ**
