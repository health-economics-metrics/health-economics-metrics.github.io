# 원격 환자 모니터링 경제학

원격 환자 모니터링 경제학은 재택 모니터링 기술이 입원, 재입원, 그리고 대면 방문을 줄여 발생시키는 비용 절감을 측정합니다.

## 왜 중요한가

원격 모니터링은 초기 기기 비용이 들지만 값비싼 급성 치료 이용을 방지할 수 있습니다.

## 수식

```
순 절감액 = (방지된 입원 수 × 입원당 비용) − 모니터링 프로그램 비용
```

## 계산 예시

심부전 원격 모니터링: 방지된 입원 40건 × £4,000 = £160,000 절감 − 프로그램 비용 £60,000 = 순 절감 £100,000.

## 소프트웨어 공학과의 연관성

[병상일 절감](../절약된-병상일/)과 [재입원율](../재입원율/)에 직접 연결되며 [웨어러블 검증](../웨어러블-검증/)에 데이터 품질을 의존합니다.

## 함정

- **모니터링 대상 선정 편향으로 절감액을 과대평가하기.**
