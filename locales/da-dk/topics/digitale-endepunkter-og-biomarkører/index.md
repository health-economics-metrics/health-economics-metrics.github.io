# Digitale endepunkter og biomarkører

Digitale endepunkter og biomarkører er objektive, kvantificerbare sundhedsmålinger indsamlet via sensorer, bærbare enheder eller digitale værktøjer.

## Hvorfor det er vigtigt

Digitale biomarkører giver kontinuerlige, objektive data, der bygger bro over kløften mellem traditionelle kliniske besøg.

## Matematikken

```
Validitet for digitalt endepunkt = korrelationskoefficient(digital måling, valideret klinisk standard)
```

## Gennemarbejdet eksempel

En skridttællingsbaseret måling af ganghastighed: korrelation med klinisk 6-minutters gangtest r = 0,82.

## Forbindelse til softwareudvikling

[Validering af bærbare enheder](../validering-af-bærbare-enheder/) er en forudsætning for pålideligheden af disse data.

## Faldgruber

- **At behandle ikke-validerede sensordata som klinisk gyldige.**
