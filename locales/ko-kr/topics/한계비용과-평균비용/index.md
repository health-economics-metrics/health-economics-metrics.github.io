# 한계비용과 평균비용

평균비용은 총비용을 생산 단위 수로 나눈 것입니다. 한계비용은 *추가* 한 단위를 생산하는 비용입니다. 결정은 한계비용에 기반해야 하지만, 발표되는 단위 비용은 거의 항상 평균비용입니다.

## 왜 중요한가

디지털 헬스 비즈니스 케이스에서 가장 흔한 오류는 절약된 자원을 **평균**비용으로 평가하는 것입니다. 실제 절약은 **한계**비용인데도 말입니다. 병원 병상 1일당 평균비용(완전 배분)은 £400가 넘지만, 하루 동안 병상 하나를 비운다고 £400가 절약되지는 않습니다 — 건물, 난방, 그리고 대부분의 직원 비용은 중단 없이 계속됩니다.

## 수식

```
평균비용: AC = TC / Q
한계비용: MC = dTC/dQ

TC = 총비용, Q = 수량
```

## 계산 예시

여러분의 소프트웨어가 평균 재원일수를 줄이고 트러스트에서 연간 1,000 병상일을 비운다고 가정해봅시다.

- **순진한 주장**: £400,000 절약. 틀렸습니다.
- **한계비용 기반 주장**: 병상일당 변동비(식사, 세탁, 소모품) ≈ £120. 절약 = **£120,000**, 비워진 병상이 대기 중인 선택적 수술 환자로 채워질 경우의 용량 가치를 더함.

## 소프트웨어 공학과의 연관성

클라우드 경제학은 정확히 한계비용의 영역입니다: 이미 예약된 용량에서 추가 CI 실행 하나를 하는 한계비용은 ≈£0이지만, 실행당 평균비용(플랫폼 전체 지출 ÷ 실행 횟수)은 몇 파운드가 될 수 있습니다.

## 함정

- 용량을 **평균비용으로 평가**하고 이를 현금으로 제시하기.
- **한계비용이 일정하다고 가정하기.**
- 같은 사례에서 **확장에는 한계비용, 축소에는 평균비용**을 사용하기.
