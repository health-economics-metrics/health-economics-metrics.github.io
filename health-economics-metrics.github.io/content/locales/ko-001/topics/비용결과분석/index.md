# 비용결과분석(CCA)

CCA는 **모든 결과의 분리된 표**와 함께 비용을 제시합니다 — 임상적, 운영적, 경험적.

## 왜 중요한가

CCA는 대부분의 디지털 헬스 기술에 대한 NICE의 **선호되는 경제적 형식**입니다.

## 수식

산출물은 집계 공식이 없는 표입니다.

## 계산 예시

디지털 수술전 평가 플랫폼 대 전화 기반 프로세스.

## 소프트웨어 공학과의 연관성

CCA는 좋은 플랫폼 제안이 이미 사용하는 균형 스코어카드의 공식적인 버전입니다.

## 함정

- **선택적으로 골라낸 결과.**

## 출처

- NICE Evidence Standards Framework for digital health technologies (ECD7).
