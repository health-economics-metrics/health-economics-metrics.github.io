# 흐름 지표

흐름 지표는 작업이 전달 시스템을 통해 어떻게 이동하는지 측정합니다: 사이클 타임, 리드타임, 처리량, 진행중 작업(WIP).

## 왜 중요한가

대부분의 전달 시간은 작업이 아니라 대기입니다.

## 수식

```
리틀의 법칙: 평균 WIP = 처리량 × 평균 사이클 타임
```

## 계산 예시

팀에 40개의 진행중 항목이 있습니다: WIP를 15로 줄이면 사이클 타임이 **1.5주**가 됩니다.

## 소프트웨어 공학과의 연관성

흐름 지표는 전달 공학과 보건 운영 사이의 공유 언어입니다.
