# Optimalisasi Sumber Daya Hilir

Menghemat satu jam untuk seorang klinisi senior sering mencegah keterlambatan hambatan bagi seluruh tim multi-disiplin (MDT).

## Mengapa ini penting

Layanan kesehatan berjalan pada rantai otorisasi.

## Matematika

```
Nilai membuka hambatan = Σ peran hilir (jam terhambat yang dibebaskan × biaya satuan)
```

## Contoh yang diselesaikan

Pemulangan bangsal memerlukan tinjauan konsultan setiap pagi: 1.460 hari tempat tidur dihemat per tahun.

## Hubungan dengan rekayasa perangkat lunak

Ini adalah tinjauan kode, persetujuan arsitektur.

## Jebakan

- **Mengoptimalkan non-hambatan.**
