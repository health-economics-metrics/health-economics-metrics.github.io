# 예산영향분석(BIA)

BIA는 개입을 채택하는 것이 향후 1–5년 동안 특정 지불자의 **예산**에 어떤 영향을 미치는지 추정합니다.

## 왜 중요한가

재무 이사의 질문은 결코 "ICER이 얼마인가?"가 아닙니다 — "내년 예산에 이것이 무엇을 하는가?"입니다.

## 수식

```
BI_연도_t = 비용_시나리오_신규(t) − 비용_시나리오_현재(t)
```

## 계산 예시

200만 명을 커버하는 지불자가 환자당 연간 £300의 디지털 치료제를 고려합니다.

## 소프트웨어 공학과의 연관성

BIA는 좌석당 ROI 주장에 대한 완벽한 CFO 지향적 보완물입니다.

## 함정

- **즉각적 채택이라는 환상.**
