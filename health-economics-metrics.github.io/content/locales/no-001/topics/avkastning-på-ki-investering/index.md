# Avkastning på KI-investering

KI-ROI måler den økonomiske verdien som genereres sammenlignet med kostnadene ved å bygge og drifte KI-systemer.

## Hvorfor det er viktig

KI-prosjekter har ofte skjulte driftskostnader: infrastruktur, modelltrening og løpende inferenskostnader.

## Matematikken

```
KI-ROI = (generert verdi − (utviklingskostnad + driftskostnad)) / (utviklingskostnad + driftskostnad) × 100 %
```

## Gjennomarbeidet eksempel

KI for oppsummering av klinisk dokumentasjon: utvikling £300 000 + drift £100 000/år; spart legetid = £600 000/år = 50 % ROI i år 1.
