# Economia Unitaria delle App Sanitarie

La matematica commerciale dei prodotti sanitari per i consumatori: costo di acquisizione del cliente (CAC), valore a vita (LTV), e la distinzione tra **ROI e VOI** (valore sull'investimento) nel mercato dei datori di lavoro.

## Perché è importante

Le app sanitarie affrontano una pressione strutturale: l'acquisizione è costosa mentre la fidelizzazione è la peggiore di qualsiasi verticale software (~90% di abbandono entro 30 giorni).

## La matematica

```
CAC = spesa vendite + marketing / nuovi clienti paganti
LTV = ARPU × vita media = ARPU / tasso di abbandono
```

## Esempio risolto

Un'app per il sonno B2C: £6,99/mese, abbandono mensile 18%: LTV:CAC ≈ 1,0 — insostenibile.

## Collegamento con l'ingegneria del software

Le scelte ingegneristiche determinano entrambi i lati del rapporto.
