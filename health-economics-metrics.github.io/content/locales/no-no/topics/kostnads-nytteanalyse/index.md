# Kostnads-nytteanalyse (CBA)

Kostnads-nytteanalyse omgjør både kostnader og gevinster til pengeverdi, noe som gjør det mulig å beregne netto nåverdi direkte.

## Hvorfor det er viktig

CBA muliggjør sammenligninger på tvers av sektorer (helse mot utdanning mot infrastruktur) fordi alt uttrykkes i samme enhet: penger.

## Matematikken

```
NNV = Σ(t=0 til horisont) (Gevinster_t − Kostnader_t) / (1+r)^t
```

## Gjennomarbeidet eksempel

Et statlig forebyggingsprogram med nåverdikostnader på £10 millioner og nåverdigevinster (unngåtte helsekostnader pluss produktivitetsgevinster) på £15 millioner: NNV = +£5 millioner.

## Kobling til programvareutvikling

Ligner på å begrunne en plattforminvestering ved å omgjøre alle fordeler (hastighet, pålitelighet, reduserte hendelser) til en estimert pengeverdi.

## Fallgruver

- **Å omgjøre helseverdi til penger med kontroversielle antakelser uten å oppgi dem.**
- **Å overse ikke-markedsgevinster (som velvære) som er vanskelige å prissette.**
