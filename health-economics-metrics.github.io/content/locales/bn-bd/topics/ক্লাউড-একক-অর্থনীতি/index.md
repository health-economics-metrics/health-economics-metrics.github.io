# ক্লাউড একক অর্থনীতি (FinOps)

ক্লাউড একক অর্থনীতি কাঁচা ক্লাউড ব্যয়কে **আউটপুট এককের প্রতি ব্যয়**-এ রূপান্তরিত করে — প্রতি গ্রাহক, প্রতি লেনদেন, প্রতি সমাধানকৃত কেস।

## কেন এটি গুরুত্বপূর্ণ

মোট ব্যয় সংখ্যা গুরুত্বপূর্ণ প্রশ্নের উত্তর দিতে পারে না: পণ্য কি আরও দক্ষ হচ্ছে নাকি কম? ডিজিটাল স্বাস্থ্যের জন্য নির্দিষ্টভাবে, "প্রতি সমাধানকৃত কেস ব্যয়" *হলো* একটি স্বাস্থ্য-সেবা একক ব্যয়।

## গণিত

```
একক ব্যয় = মোট বরাদ্দকৃত ব্যয় (ভাগ করা/প্ল্যাটফর্ম ব্যয়সহ) / প্রদত্ত একক

দুটি পরিবার:
  সম্পদ-দক্ষতা একক: GB প্রতি ব্যয়, vCPU-ঘণ্টা প্রতি ব্যয়, টোকেন প্রতি ব্যয়
  ব্যবসায়িক একক:    গ্রাহক প্রতি ব্যয়, লেনদেন প্রতি ব্যয়, পরামর্শ প্রতি ব্যয়
```

## সমাধানকৃত উদাহরণ

একটি ডিজিটাল ট্রায়াজ সেবা: ক্লাউড ব্যয় মাসে £৬২,০০০, মাসে ৩৮০,০০০ ট্রায়াজ পর্ব পরিচালনা করে:

```
প্রতি পর্ব গড় ব্যয় = 62,000 / 380,000 ≈ £0.163

কমিশনার তুলনা: টেলিফোন ট্রায়াজ ≈ £8–12/কল, GP পরামর্শ ≈ £42
→ ডিজিটাল পর্ব সবচেয়ে সস্তা মানব বিকল্পের ~2%-এ চলে
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

একক অর্থনীতি সেই জায়গা যেখানে প্রকৌশল পছন্দ আর্থিকভাবে পাঠযোগ্য হয়ে যায়: একটি স্থাপত্য যা প্রতি-পর্ব ব্যয় অর্ধেক করে তা একটি মূল্য নির্ধারণ সুবিধা।

## ঝুঁকিপূর্ণ দিক

- **ভাগ করা ব্যয় উপেক্ষা করা**: প্ল্যাটফর্ম/নিরাপত্তা/অনকল বরাদ্দ বাদ দিয়ে একক ব্যয় ৩০–৫০% কম মূল্যায়ন করে।
- **ভ্যানিটি ডিনোমিনেটর**: "প্রতি API কল ব্যয়" তোষামোদ করে; "সম্পূর্ণ রোগী পর্ব প্রতি ব্যয়" তথ্য দেয়।
