# Одинична економіка медичних застосунків

Одинична економіка медичних застосунків вимірює витрати на користувача для залучення, експлуатації та створеної цінності.

## Чому це важливо

Навіть клінічно ефективні застосунки не можуть масштабуватися, якщо одинична економіка нестійка.

## Математика

```
Співвідношення довічної цінності до вартості залучення = довічна цінність користувача (LTV) / вартість залучення користувача (CAC)
```

## Розібраний приклад

Застосунок для управління хронічними захворюваннями: LTV £180, CAC £45 = співвідношення 4:1 (вважається стійким).

## Зв'язок з інженерією програмного забезпечення

[Утримання та відтік](../утримання-та-відтік/) є основним рушієм LTV, а [одинична економіка хмари](../одинична-економіка-хмари/) формує сторону операційних витрат.

## Підводні камені

- **Невключення витрат на повторне залучення (після відтоку) до вартості залучення.**
