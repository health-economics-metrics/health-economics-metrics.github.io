# GDSサービスメトリクス

英国のGovernment Digital Service(GDS)サービスマニュアルは、あらゆる政府デジタルサービスに対して4つのKPIを義務付けています:**取引あたりの費用、利用者満足度、完了率、そしてデジタル利用率**です。これらは合わせて、公共デジタルサービスの最小限の経済学であり — NHSデジタルサービスが受け継ぐテンプレートです。

## なぜ重要か

GDSのメトリクスは、10年にわたる政府のデジタル化に資金を提供したチャネルシフトのビジネスケースを符号化しています:Digital Efficiency Reportは、デジタル取引が電話の約20分の1、対面の約50分の1の費用であることを発見しました(地方自治体の数値:ウェブ£0.15、電話£2.83、対面£8.62)。しかし、その節約は、人々が高価なチャネルの*代わりに*デジタルの旅を*完了する*とき(完了率)(利用率)にしか実現しません — 4つのKPIは4つのダッシュボードではなく1つの経済モデルです。

## 数式

```
取引あたりの費用 = 総サービス費用 / 完了した取引数
完了率           = 完了数 / 開始された取引数 × 100
デジタル利用率   = デジタル取引数 / 全チャネル取引数 × 100
利用者満足度     = 満足+非常に満足の割合(5段階、サービス内調査)

チャネルシフトの節約 = 量 × 利用率のシフト × (旧チャネル費用 − デジタル費用)
… 失敗需要を差し引く:(1 − 完了率) × フォールバックチャネルの費用
```

## 計算例

あるNHS予約管理サービス:年間200万件の取引、現在は電話70%(£3.20/通話)/デジタル30%(£0.25)。再設計により、デジタル利用率が55%に上昇し、完了率が84%から93%に上昇します:

```
利用率シフトの節約 = 200万 × 0.25 × (3.20 − 0.25) = 年間£1,475,000

失敗需要の節約:失敗したデジタルの旅は電話にフォールバックする
  前:200万 × 0.30 × 0.16 × £3.20 = £307,200
  後:200万 × 0.55 × 0.07 × £3.20 = £246,400
  正味£60,800/年 — 完了率の改善が利用率の獲得を守ります

満足度は先行指標です:不満足な利用者は電話に戻るため、満足度の低下は
利用率の減衰が現れる前にそれを予測します。
```

## ソフトウェア工学との関連

これら4つのKPIは、[費用結果表](../cost-consequence-analysis/)の実運用グレードの例です:1つの費用メトリクスと3つのアウトカムメトリクス、決して1つのスコアに縮約されません。プロダクトエンジニアにとっての運用上の教訓:**完了率はファネル計測の問題です**(すべての離脱ポイントは発見可能で修正可能です);**取引あたりの費用は[クラウド単位経済学](../cloud-unit-economics/)**に加えてスタッフ支援チャネルの費用です;**利用率は変装した公平性のメトリクスです** — チャネルを移行できない、あるいはしたくない利用者は、不釣り合いに高齢者、障害者、貧困層であり、積極的なチャネル閉鎖は「節約」をアクセスの害に変えます([到達範囲と公平性](../reach-and-equity/)を参照)。KPIを公表すること(GOV.UKはサービスごとにそうしています)自体が1つの仕組みです:透明性は、[便益実現](../benefits-realization/)の監査と同じように予測を規律づけます。

## 落とし穴

- **強制による利用率**:電話回線を閉鎖することは利用率を上げ、失敗需要を最前線のスタッフに押し付けます;システム全体の費用を測定してください。
- **2ページ目から測定される完了率**:離脱ポイントの後にファネルを開始することは、その率を実際以上に良く見せます。
- 支援付きデジタルサポートと失敗需要の対応を無視する**取引あたりの費用**。
- **成功した完了時のみの満足度調査** — 不満足な人々のほとんどは決して調査に到達しません。
