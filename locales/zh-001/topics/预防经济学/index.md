# 预防经济学

预防经济学关注的是在疾病发生或进展之前进行干预的经济学问题。其头条结论颇为反直觉：**大多数预防措施并不能省钱**——它们只是以一个不错的价格买到了健康。Cohen、Neumann与Weinstein在NEJM发表的里程碑式分析发现，不到20%的预防性干预措施能真正实现净成本节约；其余的充其量只是具有成本效果。

## 为何重要

"预防能省钱"是卫生政策领域中被重复最多的错误说法，凡是建立在这一说法之上的商业论证，都会被健康经济学家彻底拆穿。诚实的结构是：预防措施现在就要花钱（为整个人群做筛查、为那些本来根本不会生病的人治疗风险因素），而回报却在未来才能兑现——通常是以一个*不错*的每QALY成本实现，偶尔能真正省钱，有时价格却极为糟糕。搞清楚自己究竟处于哪种情形，正是这项分析的核心所在。这一区分在商业上同样至关重要：一款以"为NHS省钱"为卖点销售的预防类产品，会招来一场它注定通不过的审计；而若以"以£4,000买到一个QALY"为卖点销售，在完全相同的事实基础上却能够胜出。路径内部版本的类似讨论，参见[更早干预](../更早干预/)。 在为预防项目核算成本之前，[人群归因分数](../人群归因分数/)先回答规模问题——项目所针对的危险因素能够合理地消除目标疾病负担的多大比例。

## 计算方法

```
预防措施的净成本（每人） =
    干预成本 × 所有接受治疗的人数
  − 被避免的下游成本 × 那少数本来会病情进展的人
  （二者均需贴现——被避免的成本往往在多年之后才会发生；参见
   discounting-and-time-preference.md）

要实现成本节约，需满足：干预成本 < P(病情进展) × 被避免的成本 × 贴现因子
要实现具有成本效果，只需满足：净成本 / 获得的QALY < 阈值
```

预防悖论：干预成本要乘以整个人群规模；而效益却只惠及那反事实情形下少数会真正病情进展的人。

## 实例演算

某高血压管理应用面向10万名高风险成年人推广，每人每年£25。10年内，它预防了400例中风（每例贴现后成本£45,000，并损失3个QALY）。

```
成本：    100,000 × £25 × 10年（贴现后约×8.3）≈ £2,080万
冲抵额：  400 × £45,000 = £1,800万
净成本 ≈ £280万——并*未*实现成本节约

获得的QALY = 400 × 3 = 1,200
每QALY成本 = 280万 / 1,200 ≈ £2,300/QALY——极其具有成本效果
```

同一个项目，两种同时成立的事实：它在现金上损失了£280万，却以NICE阈值的十分之一价格买到了健康。应据第二个数字为其提供资助；绝不能承诺第一个数字。

## 与软件工程的联系

左移质量正是预防经济学的体现，连同其中的告诫一并适用。评审、测试与静态分析，会为*每一次*变更都增加成本，以求在那少数本会演变为生产环境事件的变更中捕获问题。缺陷成本曲线（按阶段相差10–100倍）扮演的角色，正相当于中风的成本——而诚实的结论也与健康领域如出一辙：左移通常具有成本*效果*，而非自动就能*节省*成本，因为大多数被标记出的问题，本来根本就不会演变成真正的事件（这正是"反事实情形下的少数问题"这一困境）。可以这样计算：每个周期的关卡总成本，对比实际避免的事件数 × 每次事件的成本——与上文实例演算结构完全相同，其中[NNT](../需治疗人数/)则是"每捕获一次问题"所对应的计量单位。

## 陷阱

- **在证据只支持"具有成本效果"时，却主张"节省了成本"**——这是预防倡导者在两个领域中都会犯的典型错误。
- **未贴现的未来冲抵额**：将15年后的效益按其面值直接计算。
- **忽视过度诊断/过度治疗的成本**：预防措施同样会发现"伪疾病"——参见[筛查经济学](../筛查经济学/)。
