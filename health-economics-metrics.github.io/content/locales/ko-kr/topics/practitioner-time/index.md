# 의료진 시간

의료진 시간은 대부분의 보건 시스템에서 가장 희소한 자원입니다.

## 왜 중요한가

여러분은 더 많은 GP, 전문의, 전문 간호사를 빠르게 만들 수 없습니다.

## 수식

```
1. 임금 기준: 시간 × 완전 배분된 임금률
2. 산출 기준: 시간 → 가능해진 예약 × 제도 가치
```

## 계산 예시

주변 필사가 GP의 진료당 2분을 절약합니다: **GP당 연간 220시간**.

## 소프트웨어 공학과의 연관성

시니어 엔지니어의 시간도 같은 방식으로 작동합니다.

## 함정

- **분 × 급여 = 절약.**
