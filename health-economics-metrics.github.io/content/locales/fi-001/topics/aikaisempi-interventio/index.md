# Aikaisempi interventio

Aikaisempi interventio käsittelee terveysongelmien korjaamisen taloutta ennen niiden pahenemista, jolloin hoito on tyypillisesti halvempaa ja tehokkaampaa.

## Miksi se on tärkeä

Sairauden etenemisen kustannukset ovat harvoin lineaarisia — vaiheen 1 sairauden varhainen hoito maksaa vain murto-osan saman sairauden hoitamisesta vaiheessa 4.

## Matematiikka

```
Säästetyt etenemiskustannukset = Σ (myöhäisen vaiheen kustannus − varhaisen vaiheen kustannus) × havaittujen tapausten määrä
```

## Ratkaistu esimerkki

Kroonisen munuaissairauden varhainen havaitseminen vaiheessa 2 maksaa £500/potilas/vuosi hallita, verrattuna £45 000/vuosi dialyysiin vaiheessa 5 — varhainen interventio 100 potilaalla voi säästää miljoonia.

## Yhteys ohjelmistokehitykseen

Muistuttaa koodin laatuongelmien varhaista havaitsemista (staattinen analyysi) verrattuna samojen virheiden havaitsemiseen tuotannossa, jossa niiden korjaamisen kustannus on eksponentiaalisesti korkeampi.

## Sudenkuopat

- **Seulontainfrastruktuurin oman kustannuksen huomiotta jättäminen.**
- **Oletus, että kaikki varhainen interventio on kustannuksia säästävää — katso [ennaltaehkäisyn talous](../ennaltaehkäisyn-talous/) vivahteista.**
