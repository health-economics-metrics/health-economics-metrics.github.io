# WSJF ja CD3

CD3 ja WSJF ovat sääntöjä työn priorisoimiseksi **arvotiheyden** perusteella.

## Miksi se on tärkeä

Jokainen kehitysjono on säännöstelyongelma.

## Matematiikka

```
CD3 = viivästymisen kustannus (£/viikko) / kesto (viikkoa)
```

## Ratkaistu esimerkki

Kolme ominaisuutta, yksi tiimi: CD3-järjestys: B, C, A.

## Yhteys ohjelmistokehitykseen

Terveydenhuollon ohjelmistoportfolioille ilmaise CoD QALY/viikkona.
