# 優越関係と効率フロンティア

ある選択肢が、別の選択肢よりも費用が低く*かつ*効果が高い場合、その選択肢は**劣位**にあるとされます。**効率フロンティア**とは、劣位の選択肢を排除した後に残るもの:より多くを得るにはより多く支払う必要がある選択肢の集合です。

## なぜ重要か

閾値や予算をめぐる議論の前に、医療技術評価はまず、誰も決して選ぶべきでない選択肢を排除します。すべての選択肢を費用対効果の平面上にプロットしてフロンティアを描くことは、5分でできる作業でありながら、候補リストの半分を日常的に消し去ります。増分比較([ICER](../incremental-cost-effectiveness-ratio/))はその後、*フロンティア上でのみ*計算されます — 各選択肢を次に安い非劣位の選択肢と比較するのであり、より良い中間の選択肢が存在するときに「何もしない」と比較することは決してありません。

## 数式

```
厳密な優越:   AがBを優越するのは Cost_A ≤ Cost_B かつ Effect_A ≥ Effect_B
             (少なくとも1つは厳密な不等号)

拡張優越:     AとCの組み合わせが£あたりでより多くの効果を達成する場合、
             Bは排除される — フロンティアを上るにつれてICERが減少する
             ときに検出される。有効なフロンティアのICERは増加していなければならない。
```

手順:選択肢を効果で並べ替える;厳密に劣位のものを除去する;隣接する選択肢間の対のICERを計算する;次により効果的な選択肢のICERを超えるICERを持つ選択肢を除去する(拡張優越);ICERが単調に増加するまで繰り返す。

## 計算例

予約の無断キャンセルを減らすための4つの選択肢(効果 = 年間で回復した予約数):

```
選択肢              年間費用    回復数
何もしない          £0          0
SMSリマインダー     £20,000     2,000
電話連絡            £120,000    2,200
SMS+AIトリアージ    £90,000     3,500
```

電話連絡は、SMS+AIトリアージによって**厳密に劣位**です(費用が高く、回復数も少ない)。フロンティア:何もしない → SMS → SMS+AI。

```
ICER(SMS 対 何もしない)   = 20,000 / 2,000  = 回復した予約1件あたり£10
ICER(SMS+AI 対 SMS)       = (90,000 − 20,000) / (3,500 − 2,000) = 予約1件あたり£46.67
```

増加するICER → 有効なフロンティア。回復した病院の予約1件あたり約£160の節約([無断キャンセル率](../did-not-attend-rate/)を参照)では、フロンティア上のどちらのステップも取る価値があります;電話バンクの提案は、決して委員会に届くべきではありません。

## ソフトウェア工学との関連

あらゆるツール導入の意思決定について同じ図を作成してください:一方の軸に年間費用、もう一方の軸に測定された成果(節約時間、回避されたインシデント、可能になったデプロイ数)。フロンティアの左上にある点は、予算について誰かが議論する前に排除されます。これは、ベンダー選定を機能チェックリストの議論から、「あなたは劣位です;この会議は終わりです」へと再構成します。また、わずかな増分のために最も高価な選択肢を購入するという、よくある企業のパターンを露呈させます — これは、増分単位あたりの増分価格が、組織が知った上で支払う価格である場合にのみ正当です。

## 落とし穴

- フロンティア上の次の選択肢ではなく**すべてをベースラインと比較すること** — これは、安価に近い代替案を隠すことで高価な選択肢を実際以上に良く見せます。
- **重要な要素を隠す単一次元の効果スコア**;2つの成果が重要なら、それらを弁護可能な形で組み合わせる([費用効用分析](../cost-utility-analysis/)を参照)か、2つのフロンティアを示してください。
- **不確実性を忘れること**:フロンティア付近の選択肢は、[感度分析](../sensitivity-analysis/)のもとで入れ替わることがあります。
