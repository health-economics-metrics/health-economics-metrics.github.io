# การคิดลดและความชอบเวลา

การคิดลดจะแปลงต้นทุนและผลประโยชน์ในอนาคตให้เป็นมูลค่าปัจจุบัน เนื่องจากสังคมให้ความสำคัญกับการได้รับประโยชน์ในวันนี้มากกว่าในอนาคต

## ทำไมจึงสำคัญ

หากไม่มีการคิดลด การเปรียบเทียบโครงการที่มีระยะเวลาต่างกันจะไม่ยุติธรรม — โครงการที่ให้ผลประโยชน์ในอนาคตอันไกลโพ้นจะดูดีเกินจริงเมื่อเทียบกับโครงการที่ให้ผลประโยชน์ทันที

## คณิตศาสตร์

```
มูลค่าปัจจุบัน = มูลค่าในอนาคต / (1 + r)^n
```

โดยที่ r คืออัตราคิดลด (3.5% ตามคำแนะนำของ Green Book/NICE) และ n คือจำนวนปี

## ตัวอย่างที่คำนวณแล้ว

ผลประโยชน์ด้านสุขภาพมูลค่า £100,000 ที่จะเกิดขึ้นใน 10 ปีข้างหน้า เมื่อคิดลดที่ 3.5% ต่อปี มีมูลค่าปัจจุบันเพียง £70,892 ซึ่งต่ำกว่ามูลค่าที่ระบุไว้อย่างมาก

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการประเมินมูลค่าปัจจุบันสุทธิของโครงการทางเทคนิคระยะยาว — ผลประโยชน์ที่ห่างไกลออกไปในอนาคตมีค่าน้อยกว่าผลประโยชน์ในทันที แม้ว่าตัวเลขที่ระบุไว้จะเท่ากันก็ตาม

## ข้อผิดพลาดที่พบบ่อย

- **การใช้อัตราคิดลดที่ไม่สอดคล้องกันระหว่างการวิเคราะห์ที่เปรียบเทียบกัน**
- **การลืมคิดลดทั้งต้นทุนและผลประโยชน์อย่างสม่ำเสมอ**
