# SPACE และ DevEx

กรอบ SPACE (Satisfaction, Performance, Activity, Communication, Efficiency) และ DevEx (Developer Experience) วัดผลิตภาพของนักพัฒนาในหลายมิติ แทนที่จะพึ่งพาตัวชี้วัดเดียว

## ทำไมจึงสำคัญ

การเพิ่มประสิทธิภาพตัวชี้วัดเดียว (เช่น จำนวนบรรทัดโค้ด) มักนำไปสู่ผลที่ไม่พึงประสงค์; กรอบหลายมิติให้ภาพที่สมดุลกว่าของผลิตภาพที่แท้จริง

## คณิตศาสตร์

ไม่มีสูตรรวม; กรอบใช้ตัวชี้วัดผสมผสานจากห้าหมวดหมู่ (ความพึงพอใจ ผลงาน กิจกรรม การสื่อสาร ประสิทธิภาพ)

## ตัวอย่างที่คำนวณแล้ว

ทีมที่มีตัวชี้วัดกิจกรรมสูง (commit จำนวนมาก) แต่มีตัวชี้วัดความพึงพอใจต่ำ อาจบ่งชี้ถึงภาวะหมดไฟ ซึ่งจะถูกมองข้ามหากวัดเพียงกิจกรรมเท่านั้น

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือกรอบของการพัฒนาซอฟต์แวร์เอง ซึ่งใช้ที่นี่เป็นการเปรียบเทียบกับ [การรักษาพนักงานไว้](../การรักษาพนักงานไว้/) และความเป็นอยู่ที่ดีของบุคลากรในระบบสุขภาพ

## ข้อผิดพลาดที่พบบ่อย

- **การเพิ่มประสิทธิภาพมิติเดียวของ SPACE โดยแลกกับมิติอื่น**
- **การใช้ตัวชี้วัดสำหรับการประเมินรายบุคคลแทนที่จะเป็นการปรับปรุงระบบ**
