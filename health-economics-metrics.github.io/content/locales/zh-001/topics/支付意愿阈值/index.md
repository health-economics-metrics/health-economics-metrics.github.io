# 支付意愿阈值

支付意愿（WTP）阈值，是决策者愿意为每单位健康获益支付的最高金额——正是这条线，将一项[ICER](../增量成本效果比/)转化为一个采纳或拒绝的决策。

## 为何重要

阈值，正是健康经济学从"测量"跨越到"政策"的地方。每一个国家体系都有一个这样的阈值，无论是明示还是默示的，了解当地的具体数字，就能准确知道该如何为一项健康价值主张定价：

| 机构 | 阈值（截至2024–2025年的研究数据） |
|---|---|
| NICE（英格兰） | 每QALY £20,000–£30,000；实证平均决策阈值约为£24,400（2022–24年）；严重程度调整因子可将有效上限提高至约£36,000–£51,000；高度专科化技术可达£100,000以上 |
| ICER（美国，非政府组织） | 每QALY/evLYG价格基准为$100,000–$150,000；报告范围为$50,000–$200,000 |
| 加拿大（CADTH/CDA-AMC） | 工作阈值约为每QALY CAD$50,000 |
| WHO-CHOICE（历史性，全球） | 每避免一个DALY，人均GDP的1–3倍（目前已不再鼓励使用，因过于粗略） |
| 英国供给侧实证数据（Claxton等） | NHS边际上实际被挤出的健康，约为每QALY £13,000 |

## 计算方法

阈值λ贯穿于每一条决策规则之中：

```
若ICER = ΔC/ΔE < λ，则采纳
等价地：若NMB = λ×ΔE − ΔC > 0，则采纳
```

关于λ究竟*是什么*，存在两种理论：

- **需求侧**：社会愿意为健康支付多少（一种价值判断）。
- **供给侧**：当前预算在边际上实际能产生多少健康（一个实证数量——Claxton的研究约为每QALY £13,000）。如果用于决策的λ超过了供给侧速率，那么批准一项新技术，实际挤出的健康量会超过它所增加的健康量。

## 实例演算

你的数字疗法为每名接受治疗的患者带来0.05 QALY，净成本（价格减去冲抵）为£800。

```
ICER = 800 / 0.05 = 每QALY £16,000
```

- 英格兰：低于£20,000 → 可获资助。可论证的最高价格：在λ = £20,000时，最高价格 = 0.05 × 20,000 + 冲抵额 = £1,000 + 冲抵额。
- 美国商业框架下按每QALY $150,000计算：基于价值的定价要高得多。
- 一个人均GDP阈值为$4,000的国家：同一款产品的净成本必须低于约$200。

同一款产品，三个市场，三个价格——阈值本身*就是*定价模型。这正是从λ反推而来的基于价值的定价方法。

## 与软件工程的联系

每一个工程组织都有一个隐含的λ：即它为每节省一个工程师-小时愿意资助工具投入的门槛。将其明确化——"我们资助任何每可信节省一个工程师-小时成本低于£40的项目"——能使平台投资像每QALY成本排行榜为卫生支出排序那样，进行排行榜式的比较。供给侧的教训同样可以迁移：你真正的内部λ，应是你*当前*积压任务在边际上实际产出的价值，而非管理层声称时间值多少钱。

## 陷阱

- **跨司法辖区的阈值购物**，或将高度专科技术（HST）的上限用于普通产品。
- **把λ当作价格下限**：跨过阈值是必要条件，而非充分条件——[预算影响](../预算影响分析/)依然可能使一个单价可负担的产品被否决。
- **忽视阈值会随时间变化**：NICE的严重程度调整因子（2022年）以及定期审查，都会改变有效的λ；应为你的主张标注日期。
- **把另一种货币的 ICER 与阈值比较却不先换算**：见[跨币种 ICER 比较](../跨币种-icer-比较/)——换算方法（购买力平价与市场汇率）在方法学上具有决定性，不是舍入细节。
- **把基于 λ 的估值与劳动力市场的 VSL/VPF 传统混用**：它们来自不同的理论传统（受卫生预算约束的方法论与从工资—风险权衡中揭示的偏好），并不总是相容——关于为生命估值的替代性揭示偏好方法，见[统计生命价值](../统计生命价值/)。
