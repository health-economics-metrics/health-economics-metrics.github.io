# اقتصاديات وحدة الحوسبة السحابية (FinOps)

اقتصاديات وحدة الحوسبة السحابية تترجم الإنفاق السحابي الخام إلى **تكلفة لكل وحدة مخرجات** - لكل عميل، ولكل معاملة، ولكل حالة تمت معالجتها، ولكل رمز (token). إنها قدرة FinOps التي تحوّل "فاتورة AWS لدينا 400 ألف£/شهر" إلى "خدمة مريض واحد تكلف 0.83£".

## لماذا يهم هذا

أرقام الإنفاق الإجمالي لا تستطيع الإجابة عن الأسئلة المهمة: هل يزداد المنتج كفاءة أم ينخفض؟ هل النمو يحسّن الهامش أم يدمّره؟ ماذا ينبغي أن نتقاضى؟ تكاليف الوحدة تجيب عن الأسئلة الثلاثة جميعًا. وبالنسبة للصحة الرقمية تحديدًا، فإن "التكلفة لكل حالة تمت معالجتها" *هي* تكلفة وحدة على مستوى الخدمة الصحية - قابلة للمقارنة المباشرة بأرقام [مجموعة التكلفة الوطنية](../التعريفة-الوطنية-والتكاليف-الوحدوية/) التي تستخدمها جهة التكليف لكل خدمة أخرى، ما يجعلها اللغة الطبيعية لتسعير المسارات الرقمية مقابل التقليدية.

## الحساب

```
التكلفة الوحدوية = إجمالي التكلفة المخصَّصة (بما يشمل تكاليف المشترَك/المنصة) / الوحدات المسلَّمة

فئتان:
  وحدات كفاءة الموارد: التكلفة/جيجابايت مخزَّن، والتكلفة/ساعة-معالج افتراضي، والتكلفة/رمز،
                             والتكلفة/دقيقة-بناء
  وحدات الأعمال:            التكلفة/عميل، والتكلفة/معاملة، والتكلفة/استشارة،
                             والتكلفة/حالة تمت معالجتها

انضباط الحدي مقابل المتوسط ينطبق هنا (marginal-vs-average-cost.md):
الإنفاق الملتزَم/المحجوز يجعل التكلفة الوحدوية الحدية ≈ صفر حتى خطوة
الالتزام التالية - سعِّر قرارات التوسّع بالحدي، واتجاهات الكفاءة بالمتوسط.
```

## مثال محلول

خدمة فرز رقمي: إنفاق سحابي 62,000£/شهر (حوسبة 30 ألف£، بيانات 18 ألف£، تخصيص منصة مشتركة 14 ألف£)، تعالج 380,000 نوبة فرز/شهر:

```
متوسط التكلفة لكل نوبة = 62,000 / 380,000 ≈ 0.163£

مقارنة جهة التكليف: الفرز الهاتفي ≈ 8-12£/مكالمة، استشارة طبيب أسرة ≈ 42£
← النوبة الرقمية تعمل بنحو 2% من أرخص بديل بشري - اقتصاديات تحول
القناة الواردة في gds-service-metrics.md، من جانب التكلفة.

فحص الاتجاه: العام الماضي 0.21£/نوبة عند 240 ألف نوبة ← تحسن
اقتصاديات الحجم (استهلاك تكاليف المنصة الثابتة)، يستحق عنوانًا في مراجعة الربع.
```

## الصلة بهندسة البرمجيات

اقتصاديات الوحدة هي حيث تصبح الخيارات الهندسية مفهومة ماليًا: معمارية تخفّض التكلفة لكل نوبة إلى النصف تمثل ميزة تسعيرية؛ ومعمارية تتوسع بشكل فوق خطي قنبلة موقوتة لا تُرى إلا في هذا المقياس. الممارسات القابلة للنقل من التكاليف الصحية: **انشر قواعد التخصيص** (التكاليف المشتركة شوّهت أرقام الوحدة حتى وحّد PLICS تكلفة المريض على مستوى الفرد - تخصيص تكلفة منصتك يحتاج نفس الصرامة)؛ **اختر الوحدات التي يفكر بها المشتري** (جهات التكليف تشتري نوبات، لا معالجات افتراضية)؛ وغذِّ التكاليف الوحدوية إلى كل نموذج [ICER](../نسبة-فعالية-التكلفة-التزايدية/) و[أثر على الميزانية](../تحليل-الأثر-على-الميزانية/) كمقام تكلفة معتمَد. وبالنسبة لميزات الذكاء الاصطناعي، فالوحدة هي الرمز (token) - انظر [اقتصاديات وحدة الاستدلال](../اقتصاديات-وحدة-الاستدلال/).

## المزالق

- **تجاهل التكاليف المشتركة**: التكاليف الوحدوية التي تستبعد تخصيصات المنصة/الأمان/المناوبة تُقلِّل التقدير بنسبة 30-50% وتنهار عند التدقيق.
- **مقامات زائفة**: "التكلفة لكل استدعاء API" تُجمِّل الصورة؛ "التكلفة لكل نوبة مريض مكتملة" تُخبِر بالحقيقة.
- **تسعير القرارات الحدية بالتكلفة المتوسطة**: تحميل الفرق التكلفة الوحدوية المتوسطة لاستخدام شبه مجاني حديًا يدفع نحو مسرحية تجنب الهدر (انظر [التعريفة الوطنية](../التعريفة-الوطنية-والتكاليف-الوحدوية/) للنسخة الخاصة بـ NHS من هذا الخلل الحافز).
