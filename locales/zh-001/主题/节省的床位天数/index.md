# 节省的床位天数

一个床位天，是指一名患者占用一张医院床位一天。通过提前出院、避免入院或虚拟病房实现的"节省床位天数"，是NHS数字化商业论证中最常用的效益线，也是最常被高估的一条。

## 为何重要

床位是急症医疗中起决定作用的约束条件：一旦床位满员，择期手术就会被取消，救护车就会排队等候，急诊科也会随之积压。因此，能释放床位天数的干预措施确实具有真实价值——但价值的*类型*完全取决于被释放的床位后续被如何使用。财务总监们早已学会对朴素的床位天数主张大打折扣；把这套算术做对，本身就是一道信誉检验。

## 计算方法

```
节省的床位天数 = 受影响患者数 × Δ住院时长（或：避免的入院数 × 平均住院时长）

价值取决于被释放产能的实际用途：
  重新用于择期活动     → 价值 = 活动收入或等候名单收益
  病区关闭/缩减规模     → 价值 = 释放出的人员配置与运营成本（现金）
  被吸收为冗余产能      → 价值 ≈ 仅相当于边际（"酒店式"）成本，每天£50–£150
```

一个急症床位天的平均全成本常被引用为£400以上（"全国成本采集"数据中，超额床位天历史上约为£350）——但参见[边际成本与平均成本](../边际成本与平均成本/)：几乎从来都不是平均成本才是真正的节省。

## 实例演算

某远程监测"虚拟病房"项目使每年600名患者提前2天出院：共节省1,200个床位天。

- **朴素主张**：1,200 × £400 = £480,000。除非真的关闭了一个病区，否则这是错的。
- **诚实的主张**：该信托机构将这些床位重新用于骨科择期患者。1,200个床位天 ÷ 平均3天住院时长 = 400台额外的择期手术，在按活动付费机制下每台约创造£6,000收入 = **共计£240万的额外可获资助活动量**（需扣除治疗这些患者的边际成本），*此外*还有400名患者从等候名单中移出。虚拟病房本身的运营成本（£350,000）需与此相抵。

被*重新利用*的释放产能，其价值往往高于朴素的现金主张——但这是另一种类型的价值，必须如实标注（参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)）。

## 与软件工程的联系

"节省的服务器天数"表现出完全相同的逻辑。停用常驻运行的环境，只有在实例被真正终止或预留资源到期失效时，才会释放现金；被重新吸收回资源池的产能，其价值仅相当于边际成本（在已承诺支出下约等于0）。相同的纪律在此依然适用：对于每一项声称的节省，都应说明其*具体机制*——是被终止了、被重新用于有价值的工作，还是就此蒸发消失了。能缩短住院时长的软件（出院协调、远程监测、诊断周转）应当对上述三种情形分别建模，并让各病区自行选择适用哪一种。

## 陷阱

- **对边际产能采用平均成本估值**——这是经典的错误。
- **重复计算**：同一张被释放的床位，既被计为"节省的床位天数"，又被计为"避免的入院"，还被计为"等候名单缩减"。
- **假设被节省的天数就是花费最高的天数**：住院末期被节省的那些天数，往往恰恰是病情最轻、花费最低的那些天。
