# Aktivering og adopsjon

Aktivering måler når nye brukere først opplever appens kjerneverdi; adopsjon måler hvor stor andel av målpopulasjonen som faktisk begynner å bruke tjenesten.

## Hvorfor det er viktig

Lav adopsjon gjør selv utmerket utformede intervensjoner meningsløse på befolkningsnivå.

## Matematikken

```
Adopsjonsrate = antall aktive brukere / målpopulasjon × 100 %
```

## Gjennomarbeidet eksempel

Et program for fjernovervåking av blodtrykk: målpopulasjon 10 000, aktive brukere 2 400 = adopsjonsrate 24 %.
