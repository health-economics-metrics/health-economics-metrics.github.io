# Membangun vs Membeli

Membangun-vs-membeli adalah perbandingan terstruktur antara pengembangan khusus dan akuisisi komersial.

## Mengapa ini penting

Sistem kesehatan terus-menerus menghadapi keputusan ini.

## Matematika

```
NPV_opsi = PV(manfaat) − PV(TCO)
```

## Contoh yang diselesaikan

Sebuah trust membutuhkan sistem persetujuan elektronik. Beli: £150 ribu/tahun SaaS, langsung dalam 3 bulan.

## Hubungan dengan rekayasa perangkat lunak

Disiplin ekonomi kesehatan yang dapat dipindahkan bersifat tiga kali lipat.

## Jebakan

- **Membandingkan harga daftar vendor dengan perkiraan pembangunan yang tidak disesuaikan risiko.**
