# 參與度指標

參與度指標衡量使用者實際使用健康應用的程度：DAU/MAU黏著度、會話頻率與時長、功能使用率。在數位健康領域，參與度絕非虛榮指標——它就是**劑量**：任何臨床效果都必須透過這一暴露程度才能實現。

## 為何重要

一瓶從未被開啟服用的藥，治癒不了任何人；一個從未被安裝或開啟的應用，也是同樣的失敗模式。任何面向消費者的健康產品，其健康經濟學主張都要乘以參與度這一因子——試驗中所展現的療效，是在某個特定使用水平下測得的，而真實世界的價值，則取決於實際部署時的使用水平與該試驗水平的接近程度。標準產品基準：對移動應用整體而言，DAU/MAU約**20%被視為健康水平**，超過25%則屬出色；健康類應用的這一數位往往更低。

## 計算方法

```
黏著度（DAU/MAU） = 日活躍使用者數 / 月活躍使用者數 × 100
會話指標       = 每使用者每週期會話數；平均時長 = 總時長 / 會話數
功能參與度     = 執行關鍵動作的使用者數 / 活躍使用者數

劑量-反應框架（健康經濟學層面的升級）：
  實現的效果 ≈ 試驗效果 × f(實際使用量 / 試驗使用量)
  其中f來自劑量-反應分析——參見adherence-and-persistence.md中
  的"有效參與"概念：足以達成預期結果的使用量，這個量
  可能是適度且有限的
```

## 實例演算

某血壓管理應用的關鍵研究顯示，每週記錄≥4次讀數的使用者，收縮壓平均下降6 mmHg。在部署給50,000名註冊使用者的實際場景中：

```
月活躍使用者20,000（佔40%）；其中每週記錄≥4次的：7,000人
達到有效劑量的使用者 = 7,000 / 50,000 = 佔註冊使用者總數的14%

人群層面效果 ≈ 試驗效果只被交付給了14%的人，而非100%：
任何以"50,000名使用者 × 6 mmHg"來計算的經濟模型，都會高估約7倍。
誠實的模型應為：7,000人享受全部效果 + 對未達閾值的13,000名使用者
（若有劑量-反應資料可用）按比例給予部分權重。
```

這一層"透過參與度漏斗、折算到有效劑量"的乘法運算，正是數位健康經濟學中最常見的虛增之處。

## 與軟體工程的聯絡

工程師掌控著參與度漏斗，這也使他們成為了一個*臨床*變數的把關人：引導流程的摩擦程度、通知策略、載入時間、離線韌性，這些都會影響實際交付的劑量。由此帶來兩點設計啟示：應埋點採集**具有臨床意義的動作**（已記錄的讀數、已完成的課程），而非單純的"開啟"次數——建立在被通知拉回的空洞會話之上的DAU資料，是一種"劑量造假"；應將參與度目標視為*充分性*目標，而非最大化目標——一款每週只需5分鐘就能達成預期結果、隨後便悄然退場的應用，在臨床上是理想的，在指標上卻會顯得"表現不佳"（參見[依從性與持續性](../依從性與持續性/)中的"有效參與"概念）。參與度相關工作本身的價值，也應透過上述人群層面效果模型來估算：有效劑量佔比提升2個百分點，就是一條可量化的QALY效益線。

## 陷阱

- **將參與度本身當作結果**：使用量只是手段；真正的結果是[病患報告結果（PROM）](../病患報告結果/)或臨床終點。
- **對雙峰分佈的使用資料取平均值**：健康類應用的使用者群往往分裂為高度投入的使用者與幽靈使用者兩極；平均值誰都無法真實描述——應按佇列分層分析。
- **暗黑模式式的劑量虛增**：連續打卡與愧疚式通知能拉昇指標，卻可能傷害健康類應用所服務的、本就容易焦慮的人群；臨床產品需要承擔臨床倫理責任。
- **供應商基準資料的來源問題**：大多數已釋出的參與度基準資料來自分析工具供應商，而非同行評審文獻；應以你自己的試驗資料進行校準。
