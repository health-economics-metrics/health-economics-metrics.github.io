# รอยเท้าคาร์บอนต่อ QALY

คาร์บอนต่อ QALY คืออัตราส่วนประสิทธิภาพ — ปริมาณการปล่อยคาร์บอนของมาตรการแทรกแซง (หรือปริมาณที่ป้องกันได้) หารด้วย QALY ที่มาตรการนั้นสร้างขึ้น ซึ่งสอดคล้องโดยตรงกับต้นทุนต่อ QALY และช่วยให้ประเมินประสิทธิภาพด้านคาร์บอนควบคู่กับประสิทธิภาพด้านต้นทุนได้ "ผลประโยชน์สุทธิทางการเงินที่ปรับด้วยคาร์บอน" ก้าวไปอีกขั้น โดยแปลงผลกระทบด้านคาร์บอนเป็นตัวเงินด้วยค่าคาร์บอนนอกตลาดอย่างเป็นทางการจาก Green Book ของสหราชอาณาจักร แล้วนำไปหักออกจาก[ผลประโยชน์สุทธิทางการเงิน](../ผลประโยชน์สุทธิทางการเงิน/)มาตรฐาน

## ทำไมจึงสำคัญ

ปัจจุบัน NICE และ NHS England คาดหวังให้พิจารณาผลกระทบต่อสิ่งแวดล้อมควบคู่กับต้นทุนและ QALY NHS มีพันธกรณีสาธารณะด้านการปล่อยก๊าซเรือนกระจกสุทธิเป็นศูนย์ คือการปล่อยทางตรงเป็นศูนย์สุทธิภายในปี 2040 และรอยเท้าตลอดห่วงโซ่อุปทานทั้งหมดเป็นศูนย์สุทธิภายในปี 2045 คู่มือการประเมินเทคโนโลยีสุขภาพของ NICE (PMG36) อ้างถึงความยั่งยืนด้านสิ่งแวดล้อมว่าเป็นข้อพิจารณาที่กำลังเกิดขึ้นในการประเมินเทคโนโลยี สำหรับผลิตภัณฑ์สุขภาพดิจิทัล หมายความว่าคาร์บอนกำลังกลายเป็นเสาหลักที่สี่ของข้อโต้แย้งเรื่องคุณค่า ควบคู่กับต้นทุน QALY และ[ความเหนือกว่าบนขอบเขตประสิทธิภาพ](../ความเหนือกว่าและขอบเขตประสิทธิภาพ/) — ไม่ได้มาแทนที่สิ่งใดสิ่งหนึ่ง แต่เป็นมิติที่แผนธุรกิจที่ดีต้องรายงานมากขึ้นเรื่อยๆ

## คณิตศาสตร์

```
คาร์บอนต่อ QALY = การปล่อยรวม_ตัน_co2e / qaly_รวม
  (ค่าลบหมายถึงการปล่อยสุทธิที่ป้องกันได้ต่อ QALY ที่ได้มา —
  ชนะสองต่อ: สุขภาพดีขึ้นและคาร์บอนน้อยลง)

ผลกระทบคาร์บอนที่แปลงเป็นเงิน = การปล่อย_ตัน_co2e × ค่าคาร์บอนต่อตัน
  (การปล่อยติดลบ × ค่าบวก = ต้นทุนติดลบ คือผลประโยชน์)

NMB ที่ปรับด้วยคาร์บอน = ผลประโยชน์สุทธิทางการเงิน − ผลกระทบคาร์บอนที่แปลงเป็นเงิน
```

สิ่งนี้ขยายแนวคิดขอบเขตประสิทธิภาพต้นทุน/QALY ด้วยแกนที่สอง — คาร์บอนต่อ QALY — ด้วยตรรกะ "พล็อตทุกทางเลือกแล้วดูว่าอะไรถูกเหนือกว่า" เช่นเดียวกับ[ความเหนือกว่าและขอบเขตประสิทธิภาพ](../ความเหนือกว่าและขอบเขตประสิทธิภาพ/) เพียงแต่ใช้กับคาร์บอนแทนต้นทุน

## ตัวอย่างที่คำนวณแล้ว

บริการการแพทย์ทางไกลมาแทนการเข้าพบแบบเห็นหน้า ช่วยลดการเดินทางด้วยรถยนต์ 5,000 เที่ยวต่อปี เที่ยวละประมาณ 8 กก. CO2e — ป้องกัน CO2e ได้ 40 ตัน แสดงเป็นค่าการปล่อยติดลบ (−40.0 ตัน) — และให้ 25 QALY ต่อปี:

```
คาร์บอนต่อ QALY = −40.0 / 25.0 = ป้องกัน CO2e ได้ 1.6 ตันต่อ QALY ที่ได้มา
```

ใช้ค่าคาร์บอนนอกตลาดของ Green Book (ตัวเลขประกอบ ค่ากลางนอกตลาดปี 2023 ≈ £269/ตัน CO2e — Green Book ปรับค่าคาร์บอนทุกปี โปรดตรวจสอบอีกครั้งก่อนอ้างอิงในการวิเคราะห์จริง):

```
ผลกระทบคาร์บอนที่แปลงเป็นเงิน = −40.0 × £269 = −£10,760
```

"ต้นทุน" −£10,760 คือผลประโยชน์ £10,760 หากผลประโยชน์สุทธิทางการเงินแบบเดี่ยวของมาตรการแทรกแซงคือ £500,000:

```
NMB ที่ปรับด้วยคาร์บอน = £500,000 − (−£10,760) = £510,760
```

การประหยัดคาร์บอนเพิ่มน้ำหนักให้กรณีศึกษา ไม่ได้ลดทอน — เป็นชัยชนะสองต่อที่กรอบแนวคิดการปล่อยติดลบมีไว้เพื่อให้มองเห็น

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือจุดตัดที่เป็นปัจจุบันกับเศรษฐศาสตร์ของ AI และคลาวด์: รอยเท้าคาร์บอนของการประมวลผลเพื่อฝึกและรันโมเดล AI เป็นรายการจริงในการจัดซื้อของ NHS แล้ว เพราะสัญญาผู้ขายของ NHS ที่เกินเกณฑ์บางระดับต้องมีแผนลดคาร์บอน (Carbon Reduction Plan) [เศรษฐศาสตร์หน่วยคลาวด์](../เศรษฐศาสตร์หน่วยคลาวด์/)ติดตามต้นทุนต่อหน่วยผลลัพธ์การประมวลผลอยู่แล้ว คาร์บอนต่อ QALY เป็นแม่แบบตามธรรมชาติสำหรับตัวชี้วัด "ต้นทุนคาร์บอนต่อการอนุมาน" ในอนาคต ซึ่งจะขยายโมดูลนั้นและเศรษฐศาสตร์หน่วยของการอนุมานไปสู่มิติด้านสิ่งแวดล้อม แม้ว่าตัวชี้วัดนั้นจะยังไม่มีอยู่ก็ตาม

## ข้อผิดพลาดที่พบบ่อย

- **การเล่นกับขอบเขตของระบบ**: นับเฉพาะการปล่อยทางตรง (Scope 1) และตัดการปล่อยในห่วงโซ่อุปทาน (Scope 3) ออก ซึ่งมักเป็นส่วนใหญ่ของรอยเท้าจริงของผลิตภัณฑ์สุขภาพดิจิทัล
- **ใช้ค่าคาร์บอนที่ล้าสมัย**: Green Book ปรับค่าคาร์บอนนอกตลาดทุกปี ดังนั้นตัวเลข £/ตัน ที่อ้างอิงต้องระบุวันที่ ไม่ใช่นำเสนอเป็นค่าคงที่
- **ถือว่า "ประหยัดคาร์บอน" แทน "คุ้มทุน" ได้**: มาตรการที่ปล่อยคาร์บอนต่ำแต่คุณค่าต่ำก็ยังเป็นการใช้ทรัพยากรของ NHS ที่ไม่ดี คาร์บอนเป็นเสาหลักที่สี่ควบคู่กับต้นทุนและ QALY ไม่ใช่ตัวแทนของสิ่งใดสิ่งหนึ่ง
