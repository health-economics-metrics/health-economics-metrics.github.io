# ছাড়করণ ও সময় পছন্দ

ছাড়করণ ভবিষ্যতের খরচ এবং সুবিধাকে বর্তমান মূল্যে রূপান্তরিত করে, কারণ আজকের একটি সুবিধা পাঁচ বছরে একই সুবিধার চেয়ে বেশি মূল্যবান।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি স্বাস্থ্য-অর্থনীতি মূল্যায়ন এবং প্রতিটি গুরুত্বপূর্ণ পাবলিক-সেক্টর ব্যবসায়িক কেস বহু-বছরের স্ট্রিম ছাড় দেয়। যুক্তরাজ্যের HM Treasury Green Book একটি 3.5% বার্ষিক সামাজিক সময় পছন্দ হার নির্দেশ করে; NICE-এর রেফারেন্স কেস বছরে 3.5%-এ খরচ এবং স্বাস্থ্য প্রভাব উভয়ই ছাড় দেয় (30+ বছর ধরে সুবিধা সহ প্রায়-নিরাময় থেরাপির জন্য 1.5% অ-রেফারেন্স-কেস হার সহ)। যদি আপনার সফটওয়্যার ব্যবসায়িক কেস "10 বছরে £5 মিলিয়ন সঞ্চয়" দাবি করে, একজন আর্থিক পর্যালোচক অবিলম্বে ছাড়যুক্ত পরিসংখ্যান জিজ্ঞাসা করবেন।

## গণনা

একটি ভবিষ্যৎ পরিমাণের বর্তমান মূল্য:

```
PV = FV / (1 + r)^t

PV = বর্তমান মূল্য
FV = t বছরে ভবিষ্যৎ মূল্য
r  = ছাড় হার (NICE/Green Book: 0.035)
t  = এখন থেকে বছর
```

n বছর ধরে একটি ধ্রুবক বার্ষিক সুবিধা B-র জন্য (একটি বার্ষিকী):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## বিস্তারিত উদাহরণ

আপনার সফটওয়্যার গো-লাইভের এক বছর পরে শুরু করে 5 বছরের জন্য একটি NHS ট্রাস্টে বছরে £100,000 সাশ্রয় করে।

ছাড়বিহীন মোট: £500,000।

3.5%-এ ছাড়যুক্ত:

```
বছর 1: 100,000 / 1.035^1 = £96,618
বছর 2: 100,000 / 1.035^2 = £93,351
বছর 3: 100,000 / 1.035^3 = £90,194
বছর 4: 100,000 / 1.035^4 = £87,144
বছর 5: 100,000 / 1.035^5 = £84,197

মোট PV ≈ £451,505
```

সৎ শিরোনাম হল প্রায় £451,000, সরল যোগফলের চেয়ে মোটামুটি 10% কম। এখন ধরুন প্রদান এক বছর পিছিয়ে যায়: প্রতিটি পদ এক বছর পরে স্থানান্তরিত হয়, এবং PV প্রায় £436,000-এ পড়ে — [বিলম্বের খরচ](../বিলম্বের-খরচ/)-র ছাড়করণ দৃষ্টিভঙ্গি।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

- **প্রযুক্তি-ঋণ পরিশোধ এবং প্ল্যাটফর্ম মাইগ্রেশন** বছরের পর বছর পরে সুবিধা স্ট্রিমের প্রতিশ্রুতি দেয়; এই ত্রৈমাসিকে প্রতিদান দেওয়া কাজের সাথে তুলনা করার আগে তাদের ছাড় দিন।
- **সামনে-লোড করা খরচ, পিছনে-লোড করা সুবিধা** একটি মাইগ্রেশনের আদর্শ আকার। ছাড়করণ সঠিকভাবে সেই আকারকে শাস্তি দেয়: এটি পরে মূল্যের জন্য এখন ক্ষমতা প্রতিশ্রুতিবদ্ধ করার ঝুঁকিমুক্ত সময় মূল্য নির্ধারণ করে।
- **"বছর 5-এ সঞ্চয়" দাবি** দ্বিগুণ সংশয়ের যোগ্য — এগুলি ভারীভাবে ছাড়যুক্ত এবং অত্যন্ত অনিশ্চিত উভয়ই (দেখুন [সংবেদনশীলতা বিশ্লেষণ](../সংবেদনশীলতা-বিশ্লেষণ/))।

## ঝুঁকি

- **খরচ ছাড় দেওয়া কিন্তু সুবিধা নয়** (অথবা এর বিপরীত) — রেফারেন্স কেস উভয়ই একই হারে ছাড় দেয়।
- **একটি পাবলিক-সেক্টর কেসে একটি বাণিজ্যিক হার (8-12%) ব্যবহার করা**, অথবা একটি ভেঞ্চার-ব্যাকড কেসে 3.5%। সিদ্ধান্ত গ্রহণকারীর সাথে হার মেলান।
- **ছাড়করণকে মুদ্রাস্ফীতির সাথে বিভ্রান্ত করা।** ছাড়করণ *প্রকৃত* (মুদ্রাস্ফীতি-সামঞ্জস্যপূর্ণ) মানের জন্য প্রযোজ্য; নিভৃতে উভয়ই করবেন না।
