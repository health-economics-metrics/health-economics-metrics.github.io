# 機會成本

機會成本是指當你投入一項資源時，所放棄的最佳替代方案的價值。在一個預算固定的醫療系統中，把100萬英鎊花在某件事上，就意味著有100萬英鎊的健康價值*不會*在其他地方被創造出來。

## 為何重要

機會成本是健康經濟學中最深刻的理念，也是軟體工程師最常忽略的一個。在任何給定年度，醫療預算都是固定的，因此一項新技術從來都不是靠"額外"的錢來獲得資助——它總是在替代某樣東西。支付方實際提出的問題從來都不是"這個東西好不好？"，而是"它是否比同樣這筆錢目前正在購買的東西更好？"

這正是成本效果閾值之所以存在的根本原因：該閾值本質上是對"這筆錢在當前系統的邊際上能買到多少健康"的一種估算。參見[支付意願閾值](../支付意願閾值/)。

## 計算方法

沒有單一公式；機會成本本質上是一種比較紀律：

```
選擇A的機會成本 = 被放棄的最佳替代方案B的價值
選擇A的淨收益   = 價值(A) − 價值(B)
```

經驗性基準：Claxton等人（2015年）估算，NHS在邊際上每產生一個QALY的成本約為**£13,000**。因此，如果將£13,000花在一項產生不到一個QALY的技術上，即便該技術"確實有效"，整個國家的健康水平實際上也會*下降*。

## 實例演算

某NHS信託機構的轉型預算恰好只夠資助以下兩個方案中的一個：

- **方案A**：電子排班軟體——每年節省£400,000的中介用工支出。
- **方案B**：出院協調軟體——每年節省2,000個床位天。按每個真正被釋放的床位天約£150的邊際成本計算，相當於每年£300,000，外加等候病患更早獲得治療的額外獲益。

資助A就意味著放棄B。A的機會成本，就是B所帶來的£300,000加上病患獲益；A方案真正的*淨*論證依據，其實只是二者之間的差額，而非A那個表面亮眼的£400,000。任何將某項提案與"什麼都不做"相比較、而非與最佳替代方案相比較的商業案例，都會高估其自身價值。

## 與軟體工程的聯絡

工程產能同樣是一份固定預算——只不過單位是路線圖席位，而非英鎊。一個平臺團隊若花£500/小時資助工具A來節省工程師工時，而工具B能以£200/小時提供同樣的效果，那麼這個團隊實際上是在毀滅產能——這與一個醫療系統資助一款每QALY成本£40,000的藥物、從而擠出每QALY成本£13,000的其他照護，是完全相同的道理。這套紀律可以直接遷移：

- 始終明確指出對照物件（"相對於什麼？"）。
- 應按工程師時間原本能產生的價值來估值，而非僅僅按薪資來估值。
- 應把"我們還有預算剩餘"當作分析的*起點*，而非終點。

## 陷阱

- **與"什麼都不做"相比較。**正確的對照物件，應是這筆錢的次優用途，而這幾乎從來都不是"什麼都不做"。
- **假設節省下來的時間機會成本為零。**節省下來的時間只有在被重新投入到有價值的事情上時才真正有價值——參見[現金釋放型與非現金釋放型節省](../現金釋放型與非現金釋放型節省/)。
- **忽視替代效應。**"預算會相應擴張來容納新支出"這種說法，在一個國家醫療服務體系的當年度預算中幾乎從未成真。
- **忽視由哪種方法為被擠出的資源估值。** 尤其是對因疾病、殘疾或員工離職而損失的生產率——見[人力資本法與摩擦成本法](../人力資本法與摩擦成本法/)，這是該思想在生產率成本上的專門版本。
