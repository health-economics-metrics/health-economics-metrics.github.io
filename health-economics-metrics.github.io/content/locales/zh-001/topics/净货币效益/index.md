# 净货币效益（NMB）

NMB将一项成本效果结果转化为单一的货币数值：按支付意愿阈值为健康获益定价，再减去成本。它的孪生指标——净健康效益（NHB），则以健康单位来表达同一条规则。

## 为何重要

比值型指标（如[ICER](../增量成本效果比/)）用起来颇为棘手：当效果趋近于零时会发生爆炸性变化，无法在不确定性抽样中直接取平均，也无法清晰地对三个及以上的方案进行排序。NMB解决了这一切问题——它是线性的，因此你可以对方案排序、对蒙特卡洛抽样结果取平均、并分解各项贡献。它同时也正是每一位工程师早已熟悉的那种健康经济学数学形式：*价值减去成本*。

## 计算方法

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = 增量效果（例如QALY）
ΔC = 增量成本
λ  = 支付意愿阈值（参见willingness-to-pay-thresholds.md）

决策规则：若NMB > 0则采纳（等价于NHB > 0）。
在多个备选方案中：应选择NMB最高的那一个。
```

NMB > 0 ⇔ ICER < λ（当ΔE > 0时），因此这两条规则是一致的——NMB只是表现得更为稳定规整。

## 实例演算

针对某糖尿病服务的三个方案，按每1,000名患者计算，λ = £20,000/QALY：

```
方案              ΔC           ΔE (QALY)   NMB = 20,000×ΔE − ΔC
应用+辅导          £400,000     30          600,000 − 400,000 = £200,000
仅应用             £150,000     12          240,000 − 150,000 = £90,000
增设门诊           £700,000     32          640,000 − 700,000 = −£60,000
```

"增设门诊"方案获得的QALY最多，但在这一阈值下反而毁损了价值（NMB < 0）。"应用+辅导"方案胜出。请注意，NMB能让你*一次性对所有三个方案同时排序*——若用两两比较的ICER，则需要借助[占优关系与效率前沿](../占优关系与效率前沿/)中的前沿法，但最终会得出相同的结论。

以NHB视角看待获胜方案：30 − 400,000/20,000 = 30 − 20 = **净获益10个QALY**——即相对于把同样这笔钱花在其他地方所能产生的健康获益，这项方案额外获得的健康价值。

## 与软件工程的联系

`(节省的工时 × 负荷小时费率) − 工具成本`——这正是日常工具类商业论证的标准算法——本质上就是一次以λ = 工程师负荷成本为参数的NMB计算。健康经济学在此基础上带来了两点升级：

- **让λ成为一个变量，而非一个常数。**将NMB相对λ（"一个工程师-小时的价值"）作图，展示决策在何处发生翻转；不同的利益相关方就可以据此代入自己的估值，而无需重新做你的数学计算。
- **NHB式思维**："这个平台节省了5,000个工程师-小时，但所消耗的预算原本足以购买3,000个工程师-小时的承包商产能——净收益为2,000小时"，这种表述方式强制以产能单位来进行机会成本比较。参见[机会成本](../机会成本/)。

## 陷阱

- **隐藏阈值**：不说明λ，NMB就毫无意义；应在£20,000和£30,000两种阈值下分别报告NMB，或直接绘制曲线。
- **用NMB来"洗白"微不足道的效应**：一个庞大的人群规模乘以一个微不足道的人均效应，也能产生一个看起来很大的NMB数字——应同时报告人均效应。
- **忘记NMB会继承ΔC与ΔE各自携带的一切不确定性**——应搭配[概率敏感性分析](../概率敏感性分析/)一并使用。
