# Створювати чи купувати

Аналіз "створювати чи купувати" порівнює загальну вартість володіння та ризики внутрішньої розробки з придбанням комерційного програмного забезпечення.

## Чому це важливо

Неправильний вибір може коштувати мільйони фунтів та роки вартості затримки.

## Математика

```
Різниця чистої теперішньої вартості = NPV(купити) − NPV(створити)
```

## Розібраний приклад

Система запису пацієнтів на прийом: купити = £2 мільйони/5 років; створити = £3,2 мільйона/5 років (включаючи обслуговування).
