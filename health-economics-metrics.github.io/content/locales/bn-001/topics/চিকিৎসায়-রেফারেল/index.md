# চিকিৎসায় রেফারেল (RTT)

চিকিৎসায় রেফারেল হল জিপির রেফারেল থেকে পরামর্শদাতা-নেতৃত্বাধীন চিকিৎসা শুরু হওয়া পর্যন্ত অতিবাহিত সময়। NHS সংবিধান মান নির্ধারণ করে: **92% রোগীর 18 সপ্তাহের মধ্যে চিকিৎসা শুরু করা উচিত**। RTT ইংরেজি NHS-এর একক সবচেয়ে রাজনৈতিকভাবে দৃশ্যমান অপারেশনাল মেট্রিক।

## কেন এটি গুরুত্বপূর্ণ

ট্রাস্ট যারা RTT লক্ষ্য মিস করে তারা নিয়ন্ত্রক পরীক্ষা, হস্তক্ষেপ এবং খ্যাতির ক্ষতির সম্মুখীন হয়; জাতীয় অপেক্ষা তালিকা একটি প্রথম-পৃষ্ঠার সংখ্যা। প্রতি সপ্তাহ একজন রোগী অপেক্ষা করেন তা হারানো স্বাস্থ্য (খারাপ স্বাস্থ্য অবস্থায় অপেক্ষা করা — নিচের QALY গণিত দেখুন) এবং প্রায়ই অর্জিত খরচ (অবস্থা অবনতি হয়; দেখুন [আরও আগে হস্তক্ষেপ](../আরও-আগে-হস্তক্ষেপ/))। সফটওয়্যার যা রেফারেল-থেকে-চিকিৎসা পথে যেকোনো স্থানে সময় সাশ্রয় করে — ট্রায়াজ, ডায়াগনস্টিক্স টার্নঅ্যারাউন্ড, ক্লিনিক ক্ষমতা, সময়সূচী — মান পূরণে ব্যর্থতার অপারেশনাল এবং আর্থিক পরিণতি সরাসরি প্রশমিত করে, যে কারণে RTT প্রভাব NHS ডিজিটাল ব্যবসায়িক কেসে একটি প্রথম-শ্রেণীর সুবিধা রেখা।

## গণনা

```
RTT কর্মক্ষমতা = 18 সপ্তাহের মধ্যে চিকিৎসিত রোগী / মোট চিকিৎসিত × 100
অপেক্ষার-সময় স্বাস্থ্য খরচ প্রতি রোগী = অপেক্ষার সময়কাল × (উপযোগিতা_চিকিৎসিত − উপযোগিতা_অপেক্ষা)

পথ দৃশ্য: RTT = Σ পর্যায়ের সময়কাল (রেফারেল ট্রায়াজ → প্রথম অ্যাপয়েন্টমেন্ট →
ডায়াগনস্টিক্স → সিদ্ধান্ত → চিকিৎসা) — সবচেয়ে ব্যস্ত পর্যায় নয়, সবচেয়ে
দীর্ঘ সারি উন্নত করুন (দেখুন flow-metrics.md)।
```

## বিস্তারিত উদাহরণ

একটি বিশেষত্ব বছরে 5,000 পথ রোগী চিকিৎসা করে; গড় অপেক্ষা 24 সপ্তাহ; অপেক্ষা উপযোগিতা 0.68 বনাম চিকিৎসিত 0.80।

ডিজিটাল ট্রায়াজ প্লাস সরাসরি-পরীক্ষা প্রোটোকল বিশুদ্ধ সারিবদ্ধকরণের 5 সপ্তাহ সরায়:

```
QALY লাভ = 5,000 × (5/52) × (0.80 − 0.68) = 57.7 QALY/বছর
£20,000-£30,000/QALY-এ মুদ্রায়িত (দেখুন willingness-to-pay-thresholds.md):
  ≈ £1.15M-£1.73M/বছর স্বাস্থ্য মূল্য
```

— প্লাস ট্রাস্ট লঙ্ঘন থেকে 18-সপ্তাহের মান পূরণে সরে যায়, যার শাসন মূল্য আছে যা কোনো স্প্রেডশিট সম্পূর্ণভাবে ধরে না।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

RTT একটি **বহু-পর্যায়ের সারির উপর লিড-টাইম মেট্রিক** — কমিট-থেকে-উৎপাদন লিড টাইমের হাসপাতাল সংস্করণ (দেখুন [DORA মেট্রিক](../dora-মেট্রিক/))। উন্নতির পদ্ধতি অভিন্ন: প্রতিটি পর্যায় ইন্সট্রুমেন্ট করুন, ক্যালেন্ডার সময় কোথায় জমা হয় তা খুঁজুন (এটি প্রায় সবসময় হস্তান্তর এবং সারি, ক্লিনিক্যাল কাজ নয়), এবং অপেক্ষা অবস্থা সরান। সাধারণ সফটওয়্যার জয়: ই-ট্রায়াজ যা সাপ্তাহিক ব্যাচের পরিবর্তে ঘণ্টায় রেফারেল রুট করে, ফলো-আপ অ্যাপয়েন্টমেন্টের পরিবর্তে ডায়াগনস্টিক-ফলাফল পুশ, এবং স্বয়ংক্রিয় সরাসরি-পরীক্ষা মানদণ্ড। QALY/সপ্তাহে প্রকাশিত [বিলম্বের খরচ](../বিলম্বের-খরচ/) দিয়ে উন্নতি মূল্যায়ন করুন।

## ঝুঁকি

- **সীমাবদ্ধতা নয় এমন একটি পর্যায় উন্নত করা** — ডায়াগনস্টিক্স সারি বাড়ার সময় প্রথম-অ্যাপয়েন্টমেন্ট অপেক্ষা কাটা শুধু জমাটা সরায়।
- **ম্যানিপুলেশন**: পথ রিসেট এবং ঘড়ি বিরতি কাউকে আগে চিকিৎসা না করেই রিপোর্ট করা RTT উন্নত করতে পারে; অন্তর্নিহিত বিতরণ নিরীক্ষা করুন।
- **একসাথে বেশ কয়েকটি পরিবর্তন অবতরণ করার সময় একটি সরঞ্জামের জন্য পুরো পথ উন্নতির দাবি করা** — দায়িত্বের জন্য একটি তুলনাকারী প্রয়োজন।
