# 更早介入

如果被釋放的產能能讓從業者更早地處理診斷積壓，病患就能更快地從等候名單轉入積極治療——而更早治療通常比更晚治療更便宜、效果也更好，因為未經治療的病情會不斷進展。

## 為何重要

疾病進展是醫療領域的"複利"。一名帶著未經治療的病情等候的病患，並不處於一個穩定狀態：癌症會發生分期上移，心力衰竭會失代償，輕度抑鬱會轉為重度。因此，更早介入能帶來雙重紅利——**更好的結果**（獲得更多QALY，且是從更健康的基線開始治療）以及往往**更低的治療成本**（早期治療強度通常低於晚期搶救）。正是這一機制，將"更快的診療路徑"從一項錦上添花的營運改善，提升為臨床與經濟雙重意義上的必要之舉——這也是[延遲成本](../延遲成本/)之所以適用於臨床軟體的深層原因。

## 計算方法

```
更早介入的價值（每名病患） =
    [晚期治療成本 − 早期治療成本]                    （治療成本衝抵）
  + [早期治療QALY − 晚期治療QALY] × λ                （健康獲益 × 閾值）
  × P(等待期間發生病情進展的機率)                     （機率加權）
```

機率加權這一環節至關重要：並非每一位等候病患都會病情進展。應基於自然病程資料，對單位時間內的轉變機率建模，而不是按最壞情形估算。隨後還需貼現：數年後才避免的成本，其現值更低（參見[貼現](../貼現與時間偏好/)）——並且需要注意，大多數早期介入是具有成本*效果*，而非直接*節省*成本（參見[預防經濟學](../預防經濟學/)）。

## 實例演算

糖尿病視網膜病變篩查積壓：4,000名病患，積壓達6個月。AI輔助分級將吞吐量提升至三倍，8周內清空積壓。自然病程資料顯示：等待期間未被複查的病患中，每年約2%會進展至威脅視力的階段。

```
因提前約4個月而避免的病情進展事件：
  4,000 × 2% × (4/12) ≈ 27名病患

每例避免的病情進展：
  治療成本衝抵（玻璃體內注射治療 對比 鐳射治療）≈ £4,000
  QALY獲益（保留視力）≈ 0.8 QALY × £20,000 = £16,000

價值 ≈ 27 × (4,000 + 16,000) ≈ £540,000——這還僅僅是一次性清空
一批積壓所帶來的價值，尚未計入永久性的吞吐量提升。
```

## 與軟體工程的聯絡

這裡有兩層遷移關係。第一層是顯而易見的：能加速診斷與治療路徑的軟體（分診、AI分級、結果路由）正是透過這套模型實現貨幣化——而這套模型也告訴你應優先加速哪條路徑：應是那條進展曲線最陡峭的路徑，而非佇列最長的那條。第二層是工程領域的映象："缺陷"同樣會"進展"。一個在設計階段就被發現的bug，代價只是一次討論；而到了生產環境才被發現，代價則是一次事件；"左移"成本曲線（按階段相差10–100倍）本身就是一個進展模型，而其誠實的版本也帶有相同的告誡——早期檢測通常是具有成本效果，而非天上掉下來的免費午餐，因為評審與測試本身都有真實成本，而且大多數被發現的問題本來也未必會真正進展惡化。

## 陷阱

- **對所有人都假設最壞情形的病情進展**——機率加權正是區分"分析"與"倡導性宣傳"的關鍵所在。
- **前導時間偏倚**：更早發現疾病卻並未改變最終結果，看似是效益，實則不然；真正的主張應是更早的*有效介入*，而不僅僅是更早的檢測本身（參見[篩查經濟學](../篩查經濟學/)）。
- **重複計算**：等候名單主張與轉診至治療主張若都建立在同一次加速之上——應記住，這是一次路徑改進，只對應一組效益，只應分配計算一次。
