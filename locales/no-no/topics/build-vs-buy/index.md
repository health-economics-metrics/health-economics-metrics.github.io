# Bygge kontra kjøpe

Analysen bygge kontra kjøpe sammenligner total eierkostnad og risiko for intern utvikling med anskaffelse av kommersiell programvare.

## Hvorfor det er viktig

Et feil valg kan koste millioner av pund og år med kostnad ved forsinkelse.

## Matematikken

```
Forskjell i netto nåverdi = NNV(kjøpe) − NNV(bygge)
```

## Gjennomarbeidet eksempel

Et pasienttimebestillingssystem: kjøpe = £2 millioner/5 år; bygge = £3,2 millioner/5 år (inkludert vedlikehold).

## Kobling til programvareutvikling

Beregninger av [total eierkostnad](../total-cost-of-ownership/) er en nøkkelfaktor for denne beslutningen.

## Fallgruver

- **Å ignorere leverandørbindingskostnader.**
