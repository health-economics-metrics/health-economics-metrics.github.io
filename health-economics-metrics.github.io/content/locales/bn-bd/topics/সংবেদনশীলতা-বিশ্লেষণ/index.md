# সংবেদনশীলতা বিশ্লেষণ

নির্ধারক সংবেদনশীলতা বিশ্লেষণ (DSA) একটি সম্ভাব্য পরিসরে একবারে একটি অনুমান পরিবর্তন করে দেখে যে সিদ্ধান্ত টিকে থাকে কিনা। প্রমিত ভিজ্যুয়ালাইজেশন হলো একটি টর্নেডো ডায়াগ্রাম: প্যারামিটারগুলোকে ফলাফল কতটা দোলায় তার দ্বারা র‍্যাঙ্ক করা।

## কেন এটি গুরুত্বপূর্ণ

প্রতিটি অর্থনৈতিক মডেল অনুমানের উপর নির্মিত — সাশ্রয়ী সময়, গ্রহণের হার, একক ব্যয়। স্বাস্থ্য প্রযুক্তি মূল্যায়ন একটি একক অনুমান ("ROI ৩৪০%") গ্রহণ করতে অস্বীকার করে যদি না এমন প্রমাণ থাকে যে ইনপুট সম্পর্কে যুক্তিসঙ্গত মতবিরোধ সত্ত্বেও সিদ্ধান্ত দৃঢ়। একটি টর্নেডো ডায়াগ্রাম সিদ্ধান্ত গ্রহণকারীকে বলে *কোন অনুমানটি জিজ্ঞাসাবাদ করতে হবে*: যদি সবচেয়ে বিতর্কিত প্যারামিটার সবচেয়ে আশাবাদী প্রান্তে থাকলেই ক্ষেত্রটি কাজ করে, তবে সবাই তা অবিলম্বে দেখতে পাবে।

স্বাস্থ্য অর্থনীতি থেকে সফটওয়্যার ব্যবসায়িক ক্ষেত্রে এটি সবচেয়ে স্থানান্তরযোগ্য একক অভ্যাস।

## গণিত

সম্ভাব্য পরিসর [p_নিম্ন, p_উচ্চ] সহ প্রতিটি প্যারামিটার p-এর জন্য:

```
ফলাফল_নিম্ন  = মডেল(p = p_নিম্ন,  বাকি সব মূল ক্ষেত্রে)
ফলাফল_উচ্চ = মডেল(p = p_উচ্চ, বাকি সব মূল ক্ষেত্রে)
দোলন(p)    = |ফলাফল_উচ্চ − ফলাফল_নিম্ন|
```

দোলন দিয়ে প্যারামিটার র‍্যাঙ্ক করুন; মূল-ক্ষেত্র ফলাফলের চারপাশে অনুভূমিক বার আঁকুন। রূপ: দ্বি-মুখী DSA (একটি গ্রিডে দুটি প্যারামিটার পরিবর্তন করা), থ্রেশহোল্ড বিশ্লেষণ (যে প্যারামিটার মানে সিদ্ধান্ত পাল্টে যায় তা খুঁজে বের করা)।

## সমাধানকৃত উদাহরণ

২০০ জন ডেভেলপারের জন্য একটি AI কোডিং সহায়ক। মূল ক্ষেত্র: £৩৯/ডেভেলপার/মাস লাইসেন্স; প্রতিদিন ৩০ মিনিট/ডেভেলপার সাশ্রয়; সম্পূর্ণ বরাদ্দকৃত ব্যয় £৬০/ঘণ্টা; ২২০ কার্যদিবস।

```
মূল-ক্ষেত্র বার্ষিক সুবিধা = 200 × 0.5h × 220 × £60 = £1,320,000
বার্ষিক ব্যয়            = 200 × £39 × 12         = £93,600
মূল-ক্ষেত্র নিট           = £1,226,400
```

টর্নেডো (একবারে একটি প্যারামিটার):

```
সাশ্রয়ী সময় 0.1–1.0 ঘণ্টা/দিন: নিট = £170,400 … £2,546,400   (দোলন £2.38M) ← প্রধান
সম্পূর্ণ ব্যয় £40–£80/ঘণ্টা:    নিট = £786,400 … £1,666,400   (দোলন £0.88M)
কার্যদিবস 200–240:              নিট = £1,106,400 … £1,346,400 (দোলন £0.24M)
লাইসেন্স £30–£50/মাস:           নিট = £1,248,000 … £1,200,000 (দোলন £48k)
```

থ্রেশহোল্ড বিশ্লেষণ: প্রায় **প্রতিদিন ২.১ মিনিট** সাশ্রয়ে নিট সুবিধা শূন্যে পৌঁছায়। সিদ্ধান্তটি লাইসেন্স মূল্যের প্রতি সংবেদনশীল নয় এবং সম্পূর্ণভাবে সাশ্রয়ী সময়ের অনুমানের উপর নির্ভর করে — তাই বাকি সবকিছু নয়, সেটিই পরিমাপ করুন। (এবং মনে রাখুন ফলাফল নগদ নয়, ক্ষমতা — দেখুন [নগদ-মুক্তকারী বনাম অ-নগদ-মুক্তকারী সাশ্রয়](../নগদ-মুক্তকারী-বনাম-অ-নগদ-মুক্তকারী-সাশ্রয়/)।)

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

প্রকৌশলীরা ইতিমধ্যে "আমরা যদি X সম্পর্কে ভুল হই?" এই সহজাত প্রবৃত্তি হিসেবে এটি করেন — DSA শুধু এটিকে পদ্ধতিগত এবং দৃশ্যমান করে তোলে। প্রতিটি টুলিং প্রস্তাব, ক্ষমতা পরিকল্পনা, এবং তৈরি-বনাম-কেনা বিশ্লেষণে একটি টর্নেডো ডায়াগ্রাম রাখুন। এটি কার প্রবৃত্তি সঠিক তা নিয়ে তর্ককে কোন প্যারামিটার পরিমাপ করতে হবে তার চুক্তিতে রূপান্তরিত করে — প্রায়ই একটি পাইলটের মাধ্যমে, যার মূল্যও নির্ধারণ করা যায় ([নিখুঁত তথ্যের প্রত্যাশিত মূল্য](../নিখুঁত-তথ্যের-প্রত্যাশিত-মূল্য/) দেখুন)।

## ঝুঁকিপূর্ণ দিক

- **তোষামোদের জন্য নির্বাচিত পরিসর**: প্রকৃত অনিশ্চয়তা নির্বিশেষে প্রতিটি ইনপুটের ±১০%। সাশ্রয়ী সময়ের অনুমানে ±৮০% প্রাপ্য; লাইসেন্স মূল্যে ±১০%।
- **একবারে একটি করে মিথস্ক্রিয়া মিস করে** — সম্পর্কযুক্ত প্যারামিটার (গ্রহণ এবং সাশ্রয়ী সময়) দ্বি-মুখী বিশ্লেষণ বা সম্পূর্ণ [সম্ভাব্যতাভিত্তিক সংবেদনশীলতা বিশ্লেষণ](../সম্ভাব্যতাভিত্তিক-সংবেদনশীলতা-বিশ্লেষণ/) প্রয়োজন।
- **বিশ্লেষণ করে তা উপেক্ষা করা**: যদি টর্নেডো বলে ক্ষেত্রটি একটি নরম সংখ্যার উপর নির্ভরশীল, পরবর্তী পদক্ষেপ পরিমাপ, অনুমোদন নয়।
