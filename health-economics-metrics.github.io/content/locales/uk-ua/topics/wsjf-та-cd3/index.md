# WSJF та CD3

CD3 та WSJF — це правила пріоритизації роботи на основі **щільності цінності**.

## Чому це важливо

Кожен беклог — це проблема нормування.

## Математика

```
CD3 = вартість затримки (£/тиждень) / тривалість (тижні)
```

## Розібраний приклад

Три функції, одна команда: порядок CD3: B, C, A.

## Зв'язок з інженерією програмного забезпечення

Для портфелів програмного забезпечення охорони здоров'я виражайте CoD у QALY/тиждень.
