# Analyysinäkökulma

Analyysinäkökulma määrittää, kenen kustannukset ja hyödyt lasketaan taloudellisessa arvioinnissa: maksajan, palveluntarjoajan vai koko yhteiskunnan.

## Miksi se on tärkeä

Sama interventio voi näyttää kustannustehokkaalta yhdestä näkökulmasta ja kustannuksia lisäävältä toisesta, riippuen siitä, kuka maksaa laskun.

## Matematiikka

```
Nettokustannus(näkökulma) = Σ kustannukset, jotka ovat relevantteja kyseiselle näkökulmalle
```

## Ratkaistu esimerkki

Etäseurantapalvelu maksaa palveluntarjoajalle £200 000/vuosi, mutta säästää yhteiskunnalle £500 000/vuosi menetettyä tuottavuutta.

## Yhteys ohjelmistokehitykseen

Muistuttaa sen valitsemista, kuka on "asiakas" ominaisuuksia priorisoitaessa — sisäinen tiimi, loppukäyttäjä vai laajempi organisaatio.

## Sudenkuopat

- **Näkökulman hiljainen vaihtaminen kesken analyysin.**
- **Yhteiskunnallisten hyötyjen väittäminen budjetoitaessa maksajan näkökulmasta.**

## Lähteet
