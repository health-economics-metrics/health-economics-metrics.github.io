# 미방문율(DNA)

DNA율은 예약된 예약 중 환자가 방문하지도 취소하지도 않는 비율입니다.

## 왜 중요한가

NHS England 통계(2019): 놓친 GP 예약이 연간 1,500만 건 이상 — 연간 **£2억1,600만** 이상.

## 수식

```
DNA율 = DNA / 예약된 예약 × 100
```

## 계산 예시

외래 부서: 연간 200,000건 예약, DNA율 8%.

## 소프트웨어 공학과의 연관성

이것은 **일정 관리 시스템 문제**입니다.

## 함정

- **취소-후-재예약을 이중 계산하기.**
