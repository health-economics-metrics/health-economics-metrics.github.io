# 人群歸因分數 (Population Attributable Fraction, PAF)

PAF 是人群中疾病或結局負擔裡可歸因於接觸某一特定危險因素的比例——若完全消除這一暴露就會消失的那部分。它把“這個危險因素使你的機率翻倍”變成規劃者真正可以據以規劃的人群層面數位：這一暴露在病例數和成本方面值得多大力度去對抗。

## 為什麼重要

Levin 在 1953 年提出 PAF，以回答一個狹窄而具體的問題：如果沒有人吸菸，會有多少肺癌消失？同樣的算術如今在各處決定著國家預防規劃的規模，從菸草和肥胖戰略，到世界衛生組織全球疾病負擔研究的危險因素排名，因為單是相對風險對影響的說明太少——一個危險因素可能使罕見事件的機率翻倍，卻幾乎不改變人群的疾病負擔；也可能只把常見事件的機率略微抬高，卻仍能解釋大部分病例。PAF 把“危險因素 X 很危險”變成“消除危險因素 X 每年將預防這麼多病例”，這正是預防專案商業案例真正需要的數位。該數位到手後，關於如何為據此採取行動核算成本，見[預防經濟學](../預防經濟學/)。

## 計算方法

```
PAF = 暴露流行率 × (相對風險 − 1) / (1 + 暴露流行率 × (相對風險 − 1))

暴露流行率 = 暴露於該危險因素的人群比例 (0–1)
相對風險   = 暴露者與非暴露者的結局風險之比（如 2.5 = 2.5 倍）

可歸因病例 = 總病例數 × PAF
```

PAF 隨暴露流行率和相對風險兩者增大——與非常普遍的暴露相關聯的中度升高的相對風險（比如 1.5 倍），可能給出比與罕見暴露相關聯的驚人相對風險（比如 5 倍）更大的 PAF。這就是它作為一個獨立於相對風險的數位而存在的全部理由。

## 算例

某危險因素存在於 30% 的人群中（`暴露流行率 = 0.3`），並使結局風險升高 2.5 倍（`相對風險 = 2.5`）：

```
PAF = 0.3 × (2.5 − 1) / (1 + 0.3 × (2.5 − 1))
    = 0.3 × 1.5 / (1 + 0.3 × 1.5)
    = 0.45 / 1.45
    ≈ 0.3103 (31.0%)

人群中每年 1,000 例：
可歸因病例 = 1,000 × 0.3103 ≈ 每年 310 例
```

該結局年度負擔的略少於三分之一可歸因於這一暴露——完全消除它（理論上限；沒有任何實際介入能消除 100% 的暴露）每年將預防約 310 例（每 1,000 例中）。

## 與軟體工程的關聯

PAF 是“我們的事故量中有多大比例可歸因於這一根因？”這一問題的流行病學版本——團隊在把某一類部署或依賴與生產事故集合對照衡量時，問的就是同類問題，而不是把每起事故都當作同等值得修復。一個出現在大多數部署中、但引發事故的相對風險只是中等的根因類別，在“工程精力應當先投向哪裡”這一點上，可能勝過一個罕見而相對風險很高的類別——這正是 PAF 的觀察，換了個說法。

## 陷阱

- **跨危險因素相加 PAF**：影響同一結局的多個因素的 PAF 之和不等於 100%——合起來甚至可能超過，因為各因素相互作用並共享因果通路。把每個 PAF 當作“如果只消除這一個因素”，而絕不是對總風險的劃分。
- **在人群之間轉移相對風險**：在一個人群中估計的相對風險（基線暴露流行率不同、混雜因素不同），套用到另一人群的暴露流行率上會給出誤導性的 PAF。
- **把 PAF 與暴露者中的歸因風險混淆**：PAF 是人群層面的，取決於暴露流行率；暴露者中的歸因風險是個體層面的，不取決於流行率。它們回答不同的問題——不要用一個去回答另一個的問題。
