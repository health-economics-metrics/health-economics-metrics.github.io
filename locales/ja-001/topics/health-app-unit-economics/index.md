# 健康アプリの単位経済学

消費者向け健康製品の商業的な計算:顧客獲得費用(CAC)、生涯価値(LTV)、利用者1人あたりの平均収益(ARPU)、加入者1人あたり月額(PMPM)の価格設定、そして雇用主市場における**ROIとVOI**(投資対効果)の区別。

## なぜ重要か

健康アプリは構造的な板挟みに直面しています:獲得は高価(規制された主張、信頼の壁、コンプライアンス費用)である一方、定着はどのソフトウェア分野よりも最悪です(30日以内に約90%が離脱 — [定着と離脱](../retention-and-churn/)を参照)。したがって、標準的な存続可能性のテスト — **LTV:CAC≥3:1** — は消費者向け健康において過酷なほど困難であり、これが、業界がB2B2Cモデルへと移行する理由です:雇用主、保険者、医療システムが集団に対してPMPMを支払い、購入者は離脱する個人ではありません。

## 数式

```
CAC   = 営業+マーケティング支出 / 新規有料顧客数
ARPU  = 収益 / アクティブユーザー数(期間あたり)
LTV   = ARPU × 平均生涯期間  =  ARPU / 離脱率
存続可能性:LTV:CAC≥3、回収期間≤12〜18か月

定着した利用者1人あたりの実効CAC = CAC / 定着(t)
  — D30定着率4%では、1インストールあたり£5は、30日定着した利用者
    1人あたり£125になる

PMPM収益 = 料率 × 加入者数 × 月数
  ベンダーの利益率 = PMPM − 加入者1人あたり月あたりのサービス提供費用
  — エンゲージメントは符号が反転する:B2Cサブスクリプションのもとでは
    エンゲージメントが収益を促進するが、PMPMのもとでは、エンゲージメントの
    高い加入者は休眠中の加入者よりもサービス提供費用が「高く」つき、
    成果連動型契約は再びそれを反転させる
```

## 計算例

あるB2Cの睡眠アプリ:月額£6.99、月次離脱率18%、混合CAC£38。

```
LTV = 6.99 / 0.18 ≈ £38.8 → LTV:CAC ≈ 1.0 — 存続不可能

雇用主向けPMPMへの転換:£1.20 PMPM × 40,000人の対象者 = 月£4.8万
サービス提供費用:インフラ£0.15 + サポート£0.10 + コンテンツ£0.05
  加入者あたり ≈ £0.30 → 利益率約75%、営業サイクルは長いが離脱は
  利用者レベル(日次)ではなく契約レベル(年次)

雇用主の問いはメトリクスをシフトさせます:硬い金銭的なROI(請求の削減、
欠勤の削減)は、ウェルネス製品にとってめったに実証可能ではありません —
業界の答えはVOIです:生産性、採用の魅力、エンゲージメント — これは
ROIとして装われるのではなくVOIとしてラベル付けされたときにのみ正直です
(投資収益率と社会的投資収益率を参照)。
```

## ソフトウェア工学との関連

エンジニアリングの選択は、この比率の両側を決定します:**サービス提供費用**はアーキテクチャです([クラウド単位経済学](../cloud-unit-economics/) — PMPMの利益率は、加入者あたりのインフラ費用によって生き死にします)、そして**LTV**は定着のエンジニアリングです(各離脱ポイントは算術的な収益であり、[定着](../retention-and-churn/)の文書のQALYの数学には正確な収益の双子があります)。健康製品に特化して言えば、単位経済学のダッシュボードには、LTVとCACの隣に3つ目の行があるべきです:**獲得された利用者1人あたりの健康価値**(定着で重み付けされたQALY×閾値) — なぜなら、支払者とDiGA式の市場はますますそれに基づいて価格を決めており、商業的な単位経済学と臨床的な単位経済学が乖離する製品(利益は出るが健康には無関係、あるいは効果的だが資金提供不可能)は、自分たちがどちらの問題を抱えているかを知る必要があるからです。

## 落とし穴

- **早期コホートの離脱からのLTV**:離脱は下方に安定します;しかし生存者バイアスもあります — 早期採用者は、規模が拡大した後の利用者よりも定着が良いです。成熟したコホートのデータを使ってください。
- **チャネルにわたって混合されたCAC**:有料ソーシャルのCACと臨床医紹介のCACは10倍異なり、正反対の定着プロファイルを持ちます — セグメント化しなければ誤解を招きます。
- **利用上限のないPMPM**:外れ値のように熱心な加入者は利益率を反転させることがあります;平均ではなく分布をモデル化してください。
- CFOに**ROIとして提示されるVOI** — これは雇用主向けウェルネス業界が10年かけて得た信頼性の失敗です。
