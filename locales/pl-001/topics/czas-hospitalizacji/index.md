# Czas hospitalizacji

Czas hospitalizacji mierzy liczbę dni, które pacjent spędza w szpitalu, od przyjęcia do wypisu — czas cyklu szpitala.

## Dlaczego to ważne

Krótszy czas hospitalizacji oszczędza zasoby i zmniejsza ryzyko powikłań związanych ze szpitalem, ale zbyt agresywne skracanie zwiększa readmisje.

## Matematyka

```
Średni czas hospitalizacji = Całkowita liczba dni łóżkowych / Liczba przyjęć
```

## Rozwiązany przykład

Oddział skraca średni czas hospitalizacji z 6 do 4,5 dnia dzięki lepszej koordynacji wypisów, uwalniając zdolność łóżkową dla 25% więcej pacjentów bez dodatkowych łóżek.

## Powiązanie z inżynierią oprogramowania

Przypomina czas cyklu we [wskaźnikach przepływu](../wskaźniki-przepływu/) — jak długo zadanie znajduje się w systemie od początku do ukończenia.

## Pułapki

- **Skracanie czasu hospitalizacji bez uwzględnienia wpływu na readmisje.**
- **Używanie średnich zniekształconych przez ekstremalne wartości odstające.**
