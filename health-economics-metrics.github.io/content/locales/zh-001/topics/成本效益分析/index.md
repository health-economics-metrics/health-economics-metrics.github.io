# 成本效益分析（CBA）

成本效益分析将成本*与*结果都以货币形式估值。它是唯一能够回答"这件事到底值不值得做"这一问题的分析类型——而不只是回答"哪个选项更好"——因为已被货币化的效益可以直接与成本相比较。

## 为何重要

成本效益分析是英国HM Treasury《绿皮书》用于一切公共支出评审的标准方法，只要结果能够被货币化，医疗领域也不例外。当[成本效果分析（CEA）](../成本效果分析/)/[成本效用分析（CUA）](../成本效用分析/)止步于"每单位健康的成本"时，成本效益分析则会为健康本身定价（QALY × 阈值），并为时间、交通、碳排放等一切其他因素定价，最终报告一个单一的净值。每一份完整的NHS数字化商业论证，都包含一个成本效益分析形态的经济案例。

## 计算方法

```
净现值（社会净现值） = Σ_t [ (效益_t − 成本_t) / (1 + r)^t ]
效益成本比（BCR）    = 效益现值 / 成本现值

若净现值 > 0（等价于效益成本比 > 1），则应采纳；排序应按净现值，而非效益成本比。
r = 3.5%（《绿皮书》社会时间偏好率）
```

健康效果可通过QALY × λ的方式纳入货币化计算（参见[支付意愿阈值](../支付意愿阈值/)）。《绿皮书》同时要求进行**乐观偏差调整**——按有实证依据的百分比上调成本估算、下调效益估算，因为评审结果系统性地过于乐观。

## 实例演算

某电子转诊系统，5年时间范围，贴现率3.5%：

```
成本：建设£120万（第0年），运营每年£300,000（第1–5年）
效益：行政节省每年£250,000，避免重复检查每年£280,000，
     患者节省时间每年40,000小时 × £15 = 每年£600,000 → 每年£1,130,000

成本现值 = 1,200,000 + 300,000 × 4.515（年金系数） = £2,555,000
效益现值 = 1,130,000 × 4.515                        = £5,102,000

净现值 = 5,102,000 − 2,555,000 = +£2,547,000     效益成本比 = 2.0
```

应用《绿皮书》乐观偏差调整（例如建设成本上调+40%，效益下调−20%）：成本现值约为£3,035,000，效益现值约为£4,082,000，净现值约为**+£1,047,000**——仍为正值，而这正是该调整的意义所在：论证应当经得起自身乐观偏差的考验。

## 与软件工程的联系

工程领域的商业论证本质上就是非正式的成本效益分析。以下这些来自《绿皮书》的升级做法值得借鉴：

- **将乐观偏差作为标准上调项**——工程师低估迁移成本的一贯程度，不亚于各部委低估基础设施成本；应采用一个明示的上调系数，而不是假装"这次会不一样"。
- **诚实地为主导效益定价，否则就不要定价**——患者/用户的时间应按可站得住脚的费率货币化；而"品牌价值"则不应如此。
- **应按净现值排序，而非效益成本比**：一个效益成本比为5的小项目，其重要性可能远不及一个效益成本比为1.6的大项目。

## 陷阱

- **为无法货币化的事物强行货币化**，以虚增效益（如士气、"战略契合度"）——这些应保持为定性描述，参照[成本后果分析](../成本后果分析/)的做法。
- **将转移支付计为效益**：资金在公共机构之间的流动，从社会[视角](../分析视角/)看净值为零。
- **缺乏反事实对照**：效益应相对于"最低限度维持"方案来衡量，而非相对于"零"来衡量。
