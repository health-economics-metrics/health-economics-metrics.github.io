# حساسیت کا تجزیہ

یقینی حساسیت کا تجزیہ (DSA) ایک ممکنہ حد میں ایک وقت میں ایک مفروضے کو تبدیل کرتا ہے یہ دیکھنے کے لیے کہ نتیجہ برقرار رہتا ہے یا نہیں۔ معیاری تصویری خاکہ ایک ٹورنیڈو خاکہ ہے۔

## یہ کیوں اہم ہے

ہر معاشی ماڈل اندازوں پر بنا ہوتا ہے — بچایا گیا وقت، اپنانے کی شرح، اکائی کی قیمت۔

## ریاضی

```
نتیجہ_کم = ماڈل(p = p_کم, باقی سب بنیادی کیس میں)
نتیجہ_زیادہ = ماڈل(p = p_زیادہ, باقی سب بنیادی کیس میں)
جھولاؤ(p) = |نتیجہ_زیادہ − نتیجہ_کم|
```

## حل شدہ مثال

200 ڈویلپرز کے لیے ایک AI کوڈنگ اسسٹنٹ۔ سب سے زیادہ اثر انگیز پیرامیٹر بچایا گیا وقت ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرز پہلے سے ہی "اگر ہم X کے بارے میں غلط ہیں تو کیا ہوگا؟" کی صورت میں یہ کرتے ہیں۔
