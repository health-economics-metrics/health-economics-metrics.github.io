# 確実な現金化削減(赤字防衛)

確実な現金化削減とは、あなたのソフトウェアのおかげで、病院が来月の予算から実際に**削除できる**項目のことです。厳格な財務会計士にとって — そして赤字を運営するトラストにとって — これが完全に数えられる唯一の便益カテゴリーです。

## なぜ重要か

多くのNHSトラストは、あらゆる支出項目を徹底的に精査される赤字回復計画のもとで運営されています。そのような環境では、容量の便益や質の改善は — どれだけ本物であっても — ギャップを埋めません;現金だけが埋めます。予算項目を削除できることを証明できるソフトウェア製品は、*CFOの視点から自己資金を賄う*ものであり、これは調達を一変させます:議論は「これを買う余裕があるか?」から「買わない余裕があるか?」に変わります。この文書は、[現金化可能な節約と非現金化節約](../現金化可能な節約と非現金化節約/)の赤字に直面する先端部分です。

## 数式

NHSの最も信頼できる確実な現金目標は**割増料金の臨時スタッフ**です。トラストは、内部の「バンク」スタッフ(ほぼ標準的な料率で支払われる)と外部の「派遣」スタッフ(しばしばAgenda for Changeの料率の2〜3倍、上限はあるが希少な役割では頻繁に超過される)でギャップを埋めます。

```
確実な節約 = 回避された割増シフト × (割増料率 − 本来の料率)
           + 回避された残業時間 × 残業割増
           + 解約された外部契約 × 契約価値

仕組みの要件:具体的な予算項目と、その削減を確認する管理者を名指しすること。
誰もその項目を指し示せなければ、それは確実な現金ではありません。
```

## 計算例

バンド6の看護師は、シフトごとに管理上のオーバーヘッドで約1時間を失います;文書作成は定期的にシフト終了を過ぎて残業にこぼれ、病棟は文書作成の追いつきのために追加のバンクカバーを予約します。

ソフトウェアは、300人の看護師にわたって、その1時間をスケジュールされたシフトに返します:

```
回避された残業:   300人の看護師 × 週2.5有給残業時間 × £8の割増 × 46週
                ≈ 年間£276,000
バンク/派遣シフト:週15件の追いつきシフト × £180の割増 × 52
                ≈ 年間£140,400
確実な現金の合計  ≈ 年間£416,000、ライセンス費用約£150,000に対して
```

すべての£1は、eローステリングと給与システムに対して監査可能です — これはまさに、[便益実現](../便益実現/)を通じて毎月、この便益がどう証拠づけられるべきかです。(公表されたNHSの人員モデルは、この仕組みで支出された£1あたり最大£11以上の節約という比率を主張してきました;そのような比率は、持ち運び可能な事実としてではなく、*あなたの*トラストのローステリングデータに対する仮説として扱ってください。)

## ソフトウェア工学との関連

派遣の割増料金に相当するエンジニアリングのものは、組織自身の窮余の購入です:デリバリーのギャップを埋める外部委託業者の日次料金、インシエントによる残業、迅速なサポート契約、そしてクラウドのスポット価格へのパニック買いです。確実な現金を主張する生産性ソフトウェアは、同じ規律をもってこれらの項目を狙うべきです — 予算項目、責任者、そしてそれが縮小する月を名指しすること。それが提供する他のすべては容量([価値創出容量](../価値創出容量/))か質であり、それらは本物で価値がありますが、別物です。

## 落とし穴

- **容量を「節約」と呼ぶこと** — 財務部門にとって即座に信頼性を殺すものです;[現金化可能な節約と非現金化節約](../現金化可能な節約と非現金化節約/)の分類法を参照してください。
- **ベンダーのモデルの比率を地域の事実として提示すること**(£11:£1問題) — トラスト自身のローステリングデータでモデルを再構築してください。
- **一度限りと反復的なものの混同**:解約された契約はその価値を年に一度節約するのであり、一度きりではありません;削除された職位は、削除されたままである限りにおいてのみ給与を節約します。
