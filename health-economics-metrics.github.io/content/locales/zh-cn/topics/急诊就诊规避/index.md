# 急诊就诊规避 (Emergency Attendance Avoidance)

急诊就诊规避统计的是通过上游干预——分诊应用、远程监测、虚拟病房、急诊分流——而避免的急诊科 (ED/A&E) 就诊与急诊入院。它把"我们更早发现了问题"转化为一个可计价的主张。

## 为什么重要

急诊是系统中最昂贵的常规就诊场所(根据 National Cost Collection / PSSRU 数据,ED 就诊单位成本约在 250–400 英镑区间;一次急诊入院则高达数千英镑),而 ED 拥堵会连锁引发救护车延误和择期手术取消。任何能在上游安全化解需求的手段——自我护理建议、当日初级保健、社区响应——都能在系统压力最大的节点上换取容量。这正是症状检查工具、111 式分诊服务以及[远程患者监测](../远程患者监测经济学/)的标准收益条目。

## 计算方法

```
避免的就诊次数 = 人群规模 × (基线就诊率 − 干预后就诊率)
毛节省          = 避免的就诊次数 × 每次就诊的单位成本
                 (+ 避免的入院次数 × 入院成本,单独计算)

净节省          = 毛节省 − 干预成本 − 新路径使用产生的成本
                 (被分流的需求并非免费:一通 111 电话、一个 GP 号源、
                  一天虚拟病房服务,都各有单位成本)
```

因果主张需要一个对照组:就诊率本身存在趋势变化和季节性波动,因此单纯的前后对比无法证明任何东西。

## 实例演算

面向 3,000 名高风险患者的 COPD 远程监测服务。匹配对照评估显示,与恶化相关的 ED 就诊率从每患者年 0.9 次降至 0.7 次,急诊入院率从 0.5 降至 0.42。

```
避免的就诊 = 3,000 × 0.2  = 600 × £300   = £180,000
避免的入院 = 3,000 × 0.08 = 240 × £3,800 = £912,000
毛收益                                     £1,092,000/年

成本:监测服务 £600,000;额外的社区护士响应 £150,000
净收益 ≈ +£342,000/年——尚未计入更早治疗恶化事件所带来的 QALY 增益。
```

注意入院这一项占主导:单靠避免就诊很少能覆盖监测服务的成本;真正的效益来自*避免入院*。

## 与软件工程的关联

这就是**事故规避经济学**。可观测性、金丝雀部署和早期预警系统的价值,体现为避免的"急诊就诊"——寻呼告警、作战室、一级严重事故 (sev-1)——每一项都有其加权成本(工程师工时 × 费率 + 客户影响)。同样的建模规则也适用于此:要扣除新上游路径本身的成本(告警分诊并非免费),要警惕替代效应(只产生工作量却不能预防事故的告警,是"健康焦虑"而非"健康"),并用对照组证明反事实(团队的事故率同样存在趋势变化和均值回归,与 ED 就诊率如出一辙)。

## 常见误区

- **均值回归**:在表现糟糕的一年被挑选出来的高风险队列,即便不加干预也会自行改善;匹配对照组或阶梯楔形设计是必需的。
- **供给诱导需求**:便捷的数字分诊可能*增加*总接触量(降低了寻求帮助的门槛),同时降低 ED 的占比——应统计系统总成本。
- **按平均成本为就诊估值**,而 ED 的固定成本并不会随之下降——参见[边际成本与平均成本](../边际成本与平均成本/)。
