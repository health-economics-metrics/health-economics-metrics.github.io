# قابل اجتناب آؤٹ سورسنگ کے اخراجات

جب ایک ٹرسٹ اندرونی صلاحیت کے ساتھ ہدف پورا نہیں کر سکتا، وہ پریمیم شرحوں پر صلاحیت خریدتے ہیں۔

## یہ کیوں اہم ہے

انتخابی-بحالی کے دباؤ کے تحت، ٹرسٹ باقاعدگی سے نجی-شعبے کی اسپاٹ قیمتیں ادا کرتے ہیں۔

## ریاضی

```
قابل اجتناب آؤٹ سورسنگ قیمت = اندرونی طور پر منتقل سرگرمی ×
    (آؤٹ سورس اکائی قیمت − فی کیس اندرونی حاشیائی قیمت)
```

## حل شدہ مثال

ایک ٹرسٹ سالانہ 800 موتیا کے آپریشن آؤٹ سورس کرتا ہے: بچت = سالانہ £275,000 — نقد جاری کرنے والی۔

## سافٹ ویئر انجینئرنگ سے تعلق

براہ راست مثال **ٹھیکیدار اور مشیر پریمیم** ہے۔

## عام غلطیاں

- مکمل صلاحیت کی زنجیر کے بغیر **واپسی کا دعویٰ کرنا۔**
