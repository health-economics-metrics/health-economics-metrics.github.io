# 从业者时间

从业者时间是大多数医疗系统中最稀缺的资源。要衡量为临床医生每天节省几分钟的价值，需要从简单的薪资算术，转向**机会成本与系统产能**的视角：在一个国家医疗服务体系内，从业者的时间是一个刚性的运营瓶颈，而非一条可以弹性伸缩的成本科目。

## 为何重要

你无法迅速培养出更多的全科医生、顾问医生或专科护士——培训周期长达5–15年，且岗位空缺长期存在。因此，节省下来的一小时从业者时间，并不是"避免支付的工资"（该从业者依然照常领取薪水）；它是*被释放出来的瓶颈产能*，而瓶颈产能的价值，取决于该瓶颈所能产出的东西。这正是为什么"每次问诊节省10分钟"这类主张，既是数字健康领域中最常见的一条效益线，也是最常被错误定价的一条。

## 计算方法

三个估值层级，诚实度依次递增：

```
1. 薪资基础：      小时数 × 负荷薪资费率（PSSRU单位成本）
                  ——衡量的是这段时间的成本，而非它所产生的价值
2. 产出基础：      小时数 → 转化为可完成的问诊/操作数 × 标准价格
                  （参见national-tariff-and-unit-costs.md）
3. 瓶颈基础：      若该角色是整条路径的关卡，则为 小时数 × 被释放的
                  路径吞吐量价值（约束理论）
```

碎片化折扣：低于可用最小单元的零散节省时间（例如一次门诊中分散节省的3分钟），很难被有效重新部署；应采用一个明示的利用率折扣因子。

## 实例演算

环境语音记录技术为每次问诊节省全科医生2分钟，每天30次问诊：每天60分钟，按220个工作日计算，相当于**每名全科医生每年220小时**。

```
薪资基础：   220 × £80（负荷后的全科医生小时成本，PSSRU区域数据）≈ 每名全科医生每年£17,600
产出基础：   每天60分钟 = 每天多完成5次12分钟的问诊
            = 每名全科医生每年多完成1,100次问诊 × £42 ≈ 每年£46,200
            ——或者，同样这些问诊时间也可能被吸收为减少的加班时间，
            以及更从容、不匆忙的问诊质量（这属于定性效益线）
```

在一个由50名全科医生组成的联合体中，按产出基础计算的这部分产能价值约为每年£230万——前提是这些分钟数是真实的（经过实测，而非供应商单方面宣称）、是被整合起来的（完整的问诊时段，而非零碎片段），并且确实被重新部署投入使用（参见[现金释放型与非现金释放型](../现金释放型与非现金释放型节省/)）。

## 与软件工程的联系

资深工程师的时间表现出完全相同的模式：它是设计、评审与事件处理所流经的瓶颈，因此应按该瓶颈所把控的产出来估值，而非仅按薪资估值。同样的三层估值方法，适用于任何"AI为每名开发者节省X分钟"的主张——薪资算术容易美化微小的数字；真正诚实的问题在于，这些分钟数是否能整合成可用的时间块，以及被释放出的产能究竟真正产出了什么。当被节省的这一小时属于所有人都在等待的那个人时，其乘数效应参见[下游资源优化](../下游资源优化/)。

## 陷阱

- **分钟数 × 薪资 = 节省**——这是最经典的虚增手法；它其实是产能，且只有在明示的利用率下才成立。
- **忽视最小可用单元问题**：12次5分钟的节省，并不等于1个完整空闲的小时。
- **对所有角色一视同仁地估值**：路径瓶颈处的一小时，其价值远高于非关卡角色的一小时。
