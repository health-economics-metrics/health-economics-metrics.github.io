# 敏感性分析 (Sensitivity Analysis)

确定性敏感性分析（DSA）在一个合理范围内每次只改变一项假设，以检验结论是否依然成立。其标准可视化方式是龙卷风图（tornado diagram）：按照对结果的影响幅度对各参数进行排序。

## 为什么重要

每一个经济学模型都建立在估计值之上——节省的时间、采用率、单位成本。卫生技术评估拒绝在没有证据表明结论对输入的合理分歧具有稳健性的情况下，接受一个点估计值（例如"ROI 是 340%"）。龙卷风图能告诉决策者*应该质疑哪一项假设*：如果论证只有在最具争议的参数处于最乐观一端时才成立，所有人都能立刻看出这一点。

这是从卫生经济学迁移到软件商业论证中，最具可迁移性的一个习惯。

## 计算方法

对每个参数 p，给定其合理范围 [p_low, p_high]：

```
结果_低  = 模型(p = p_low，其余参数取基准值)
结果_高  = 模型(p = p_high，其余参数取基准值)
摆动幅度(p) = |结果_高 − 结果_低|
```

按摆动幅度对各参数排序；围绕基准情形结果绘制水平条形图。变体包括：双向 DSA（在网格上同时改变两个参数）、阈值分析（找出使决策发生翻转的参数取值）。

## 实例计算

一款面向 200 名开发者的 AI 编程助手。基准情形：每位开发者每月 £39 许可费；每位开发者每天节省 30 分钟；负荷成本每小时 £60；220 个工作日。

```
基准情形年度收益 = 200 × 0.5小时 × 220 × £60 = £1,320,000
年度成本         = 200 × £39 × 12         = £93,600
基准情形净收益   = £1,226,400
```

龙卷风图（每次只改变一个参数）：

```
每天节省时间 0.1-1.0 小时：净收益 = £170,400 … £2,546,400（摆动 £2.38M）← 主导因素
负荷成本 £40-£80/小时：    净收益 = £786,400 … £1,666,400（摆动 £0.88M）
工作日 200-240：           净收益 = £1,106,400 … £1,346,400（摆动 £0.24M）
许可费 £30-£50/月：        净收益 = £1,248,000 … £1,200,000（摆动 £48k）
```

阈值分析：当每天节省时间约为**2.1 分钟**时，净收益归零。这项决策对许可费价格不敏感，完全取决于节省时间的估计值——所以应该去测量这一项，而不是其他项。（并且要记住，这里的结果是产能，而非现金——参见[现金释放型与非现金释放型收益](../现金释放型-vs-非现金释放型节约/)。）

## 与软件工程的关联

工程师们早已凭直觉在做这件事——"如果我们对 X 的判断错了怎么办？"——DSA 只是把它系统化、可视化。应在每一份工具提案、产能规划和自建 vs 购买（build-vs-buy）分析中都加入一张龙卷风图。它能把"到底谁的直觉更靠谱"这类争论，转化为"应该去实测哪个参数"这类共识——往往可以通过一次试点来实现，而这次试点本身的价值也可以被定价（参见[完美信息的期望价值](../完全信息期望价值/)）。

## 常见陷阱

- **为了讨好而选择范围**：不论实际不确定性大小，一律对每项输入取 ±10%。节省时间的估计值理应取 ±80%；许可费价格取 ±10% 即可。
- **单变量分析会遗漏交互效应**——存在相关性的参数（采用率与节省时间）需要双向分析，或完整的[概率敏感性分析](../概率敏感性分析/)。
- **做了分析却置之不理**：如果龙卷风图表明论证的成败系于某一个软性数字，下一步就应该是测量它，而不是直接签字通过。
