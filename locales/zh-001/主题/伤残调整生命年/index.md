# 伤残调整生命年（DALY）

DALY代表损失一年的健康生命——是[QALY](../质量调整生命年/)在负担一侧的镜像指标。QALY计算的是健康的*获得*，而DALY计算的是因疾病而*损失*的健康；干预措施的价值以所**避免**的DALY来衡量。

## 为何重要

DALY是全球健康领域的标准指标（WHO、全球疾病负担研究，以及大多数中低收入国家的卫生部都以DALY来做规划）。如果你的软件面向国际卫生系统、捐助方，或与WHO对接的项目，那么其价值语言应是"避免的DALY"，而非"获得的QALY"。WHO-CHOICE的历史基准是：每避免一个DALY的成本低于人均GDP1倍，属于"高度具有成本效果"；1–3倍人均GDP之间，属于"具有成本效果"（WHO目前不鼓励僵化地套用这些区间，但它们在实践中依然被广泛使用）。

## 计算方法

```
DALY = YLL + YLD

YLL（寿命损失年数） = 死亡人数 × 该死亡年龄下的标准预期寿命差值
YLD（伤残存活年数） = 患病人数 × 伤残权重

伤残权重 ∈ [0, 1]，0代表完全健康，1相当于死亡
（权重数据由全球疾病负担研究发布）
```

## 实例演算

某地区的一个筛查提醒平台，提升了某疾病的早期检出率。它每年可预防10例过早死亡（每例相对标准预期寿命损失20年），并使200人免于带着伤残权重为0.2的病症生活一年。

```
避免的YLL = 10 × 20        = 200
避免的YLD = 200 × 0.2      = 40
避免的DALY合计              = 每年240
```

若该平台每年运行成本为60万美元，则每避免一个DALY的成本为 600,000 / 240 = **2,500美元**。在一个人均GDP为8,000美元的国家，这远低于1倍GDP的基准线——按WHO-CHOICE的标准即属于"高度具有成本效果"。

## 与软件工程的联系

- 面向全球健康资助方（Gavi、全球基金、各国政府项目）的数字健康产品，应以**每避免一个DALY的成本**来表述其影响——这正是拨款评审人早已习惯使用的指标语言。
- DALY同样为工程领域提供了一个实用的*负担核算*模板：事件、不稳定构建与历史遗留摩擦，相当于一个代码库的"带伤残存活的年数"——一份按繁重程度加权的负担清单，能告诉你哪里的补救工作能换来最多的"健康工程年"，正如全球疾病负担表能指引卫生支出方向一样。

## 陷阱

- **"获得的QALY"在数值上并不等同于"避免的DALY"**——二者权重不同、生命表不同、约定俗成的计算方式也不同（DALY历史上在其计算内部还包含了年龄加权与贴现）。不要随意进行换算。
- **把"GDP倍数阈值"当作机械的橡皮图章使用**——WHO自身也警示，这类阈值忽视了预算约束与机会成本；参见[支付意愿阈值](../支付意愿阈值/)。
- **从单用户层面的疗效直接主张人群规模的DALY效益**，却未按采纳率与依从性逐层相乘——参见[触达与公平](../触达与公平/)。
