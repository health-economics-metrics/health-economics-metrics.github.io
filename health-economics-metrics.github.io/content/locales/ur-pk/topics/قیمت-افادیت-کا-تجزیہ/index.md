# قیمت-افادیت کا تجزیہ (CUA)

CUA ایک **عمومی، ترجیح-وزن دار نتیجے** کے ساتھ قیمت-تاثیر کا تجزیہ ہے — تقریباً ہمیشہ [QALY](../معیار-کے-لحاظ-سے-ایڈجسٹ-شدہ-زندگی-کا-سال/)۔

## یہ کیوں اہم ہے

ایک قومی صحت کی خدمت کو ایک بجٹ سے کینسر کی دوا، ذہنی-صحت کی ایپ، اور جراحی روبوٹ کے درمیان انتخاب کرنا ہوتا ہے۔

## ریاضی

```
ICUR = Δقیمت / ΔQALY
```

## حل شدہ مثال

معتدل تشویش کے لیے ایک CBT ایپ بمقابلہ آمنے سامنے تھراپی کی انتظار کی فہرست۔

## سافٹ ویئر انجینئرنگ سے تعلق

CUA کا گہرا خیال — *غیر مشابہ چیزوں کے موازنے کے لیے ایک متحد، ترجیح-وزن دار اکائی*۔

## عام غلطیاں

- **آلے کی حساسیت سے کم افادیت کے فوائد۔**
