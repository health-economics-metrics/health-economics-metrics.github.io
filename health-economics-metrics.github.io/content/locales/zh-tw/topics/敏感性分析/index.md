# 敏感性分析

確定性敏感性分析（DSA）在一個合理區間內，每次只改變一個假設，觀察結論是否依然成立。其標準視覺化形式是龍捲風圖：按引數對結果的擺動幅度進行排序。

## 為何重要

每一個經濟學模型都建立在各種估計之上——節省的時間、採納率、單位成本。衛生技術評估拒絕接受一個點估計（"ROI是340%"），除非有證據表明該結論在對輸入資料存在合理分歧的情況下依然穩健。龍捲風圖能告訴決策者*應該質詢哪一個假設*：如果這個論證只有在爭議最大的那個引數取樂觀值時才成立，所有人都能立刻看清這一點。

這是健康經濟學中最具可遷移性、最適合直接用於軟體商業案例的一項習慣。

## 計算方法

對每一個引數p，在其合理區間[p_低, p_高]內：

```
結果_低  = 模型(p = p_低,  其餘引數取基準情形)
結果_高  = 模型(p = p_高, 其餘引數取基準情形)
擺動幅度(p) = |結果_高 − 結果_低|
```

按擺動幅度對各引數排序；圍繞基準情形的結果繪製水平條形圖。其變體包括：雙向DSA（在網格上同時改變兩個引數）、閾值分析（找出使決策發生翻轉的引數取值）。

## 實例演算

面向200名開發者的AI程式設計助手。基準情形：每名開發者每月許可費£39；每名開發者每天節省30分鐘；負荷成本£60/小時；220個工作日。

```
基準情形年度效益 = 200 × 0.5小時 × 220 × £60 = £1,320,000
年度成本         = 200 × £39 × 12         = £93,600
基準情形淨值     = £1,226,400
```

龍捲風圖（每次改變一個引數）：

```
每天節省時間0.1–1.0小時：淨值 = £170,400 … £2,546,400   （擺動£238萬）← 主導因素
負荷成本£40–£80/小時：    淨值 = £786,400 … £1,666,400   （擺動£88萬）
工作日數200–240：         淨值 = £1,106,400 … £1,346,400 （擺動£24萬）
許可費£30–£50/月：        淨值 = £1,248,000 … £1,200,000 （擺動£48,000）
```

閾值分析：淨效益在每天節省約**2.1分鐘**時歸零。這項決策對許可價格並不敏感，而完全取決於"節省時間"這一項估計——因此應重點測量這一項，而非其他項。（並請記住，這個結果代表的是產能，而非現金——參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)。）

## 與軟體工程的聯絡

工程師早已憑直覺在做這件事——"如果我們對X的判斷是錯的怎麼辦？"——DSA只是把這一過程變得系統化、視覺化。應在每一份工具提案、產能規劃以及自建與外購分析中，都附上一張龍捲風圖。它能把"到底誰的直覺更準"這類爭論，轉化為"應該去實測哪個引數"這樣的共識——往往可以透過一次試點來實現，而這次試點本身的價值也可以被定價（參見[完美資訊期望價值](../完美資訊期望價值/)）。

## 陷阱

- **為博取好感而選定區間**：無論實際不確定性如何，一律對每項輸入取±10%。節省時間的估計理應取±80%的區間；許可價格則可取±10%。
- **一次一個引數會遺漏互動效應**——存在相關性的引數（如採納率與節省時間）需要雙向分析，或完整的[機率敏感性分析](../機率敏感性分析/)。
- **做了分析卻對其置之不理**：如果龍捲風圖顯示整個論證繫於一個軟性數位之上，下一步應是去實測它，而不是直接批准放行。
