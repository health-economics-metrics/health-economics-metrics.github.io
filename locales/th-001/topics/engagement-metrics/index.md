# ตัวชี้วัดการมีส่วนร่วม

ตัวชี้วัดการมีส่วนร่วมวัดว่าผู้ใช้มีส่วนร่วมกับผลิตภัณฑ์สุขภาพดิจิทัลมากเพียงใด — ความถี่ ระยะเวลา และความลึก — ซึ่งมักเป็นเงื่อนไขเบื้องต้นสำหรับการบรรลุผลลัพธ์ด้านสุขภาพ

## ทำไมจึงสำคัญ

การแทรกแซงด้านสุขภาพดิจิทัลไม่สามารถสร้างประโยชน์ด้านสุขภาพได้หากผู้ป่วยไม่ใช้งาน การมีส่วนร่วมเป็นตัวชี้วัดกลางที่ทำนายผลลัพธ์ทางคลินิกขั้นสุดท้าย

## คณิตศาสตร์

```
อัตราการมีส่วนร่วม = จำนวนผู้ใช้ที่ใช้งานอยู่ / จำนวนผู้ใช้ที่ลงทะเบียนทั้งหมด × 100%
```

## ตัวอย่างที่คำนวณแล้ว

แอปจัดการโรคเรื้อรังที่มีผู้ใช้ลงทะเบียน 10,000 คนและผู้ใช้ที่ใช้งานรายเดือน 3,000 คน ให้อัตราการมีส่วนร่วม 30% ซึ่งบ่งชี้ถึงการเลิกใช้งานอย่างมีนัยสำคัญ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

เปรียบเทียบได้โดยตรงกับตัวชี้วัดการมีส่วนร่วมของผลิตภัณฑ์ (DAU/MAU) ในผลิตภัณฑ์ซอฟต์แวร์โดยทั่วไป

## ข้อผิดพลาดที่พบบ่อย

- **การสับสนระหว่างการมีส่วนร่วมกับผลลัพธ์ด้านสุขภาพโดยไม่พิสูจน์ความเป็นเหตุเป็นผล**
- **การใช้ตัวชี้วัดการมีส่วนร่วมแบบผิวเผิน (จำนวนครั้งที่เปิดแอป) โดยไม่วัดการใช้งานที่มีความหมาย**
