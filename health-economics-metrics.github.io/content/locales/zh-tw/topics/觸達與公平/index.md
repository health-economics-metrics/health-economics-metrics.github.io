# 觸達與公平

RE-AIM——觸達（Reach）、有效性（Effectiveness）、採納（Adoption）、實施（Implementation）、維持（Maintenance）——是判斷一項介入措施*人群層面*影響力的標準框架。其核心算式是：**公共衛生影響 ≈ 觸達率 × 有效性**。數位化工具則額外帶來了一個公平維度：數位鴻溝意味著觸達率本身就系統性地不均衡，而以數位化為主的服務交付方式，反而可能擴大它本想縮小的健康差距。

## 為何重要

將RE-AIM應用於移動健康（mHealth）的系統性綜述，一致發現了同一種特徵：觸達與採納表現強勁，**有效性與維持表現薄弱**——應用容易迅速傳播，也容易迅速衰退。對一個國家醫療服務體系而言，這意味著一款單使用者表現亮眼的產品，可能是一項糟糕的人群層面投資；反之亦然：一款效果適中、卻能觸達數百萬人的工具，其產出可能超過一款效果出色、卻只能觸達數千人的工具（參見[HALE](../健康調整預期壽命/)的算術）。公平並非一項附帶約束，而是一個價值驅動因素：數位排斥往往與年齡、貧困程度、殘障狀況和語言能力高度相關——而這些恰恰正是承載著最多可治療負擔的人群——因此，那名處於邊緣、被排斥在外的使用者，其潛在獲益往往*高於*平均水平。 關於衡量社會經濟健康不平等的正式統計量，見[集中指數](../集中指數/)。

## 計算方法

```
人群影響 ≈ 觸達率 × 有效性
  觸達率  = 參與人數 / 符合條件人群數（參見activation-and-uptake.md）
  有效性  = 參與者中的真實世界效果（按留存加權——
           參見retention-and-churn.md）

按公平維度分層的版本：
  群體g的影響 = 觸達率_g × 有效性_g，按貧困五分位數/
  年齡段/語言群體分別報告
  公平差距 = 最高五分位數群體的影響 − 最低五分位數群體的影響

分佈性成本效果分析：按接受者群體對QALY施加公平權重——
處境最差群體所獲得的一個QALY，計數應更高（這是一種正日益
成為主流的衛生技術評估擴充套件方法）。
```

## 實例演算

某數位化糖尿病預防專案，以兩種方式呈現：

```
彙總口徑：觸達率12%，每名參與者效果0.02 QALY → 每名符合條件人員0.0024 QALY

分層口徑（按貧困五分位數）：
  第1分位（最不貧困）：觸達率22%，效果0.02 → 0.0044
  第5分位（最貧困）：  觸達率4%， 效果0.025 → 0.0010

該專案為最不貧困群體所交付的健康價值是最貧困群體的4.4倍——
而第5分位群體的人均效果反而更高（改善空間更大）。一項
輔助數位化方案（電話輔導+社群接入渠道），每名第5分位參與者
成本增加20%，卻能將該群體觸達率提升至12%，使其影響力
提高至三倍，同時也改善了彙總數位——在這裡，公平投資
正是效率投資本身。
```

## 與軟體工程的聯絡

觸達率在很大程度上是一個工程層面的產物：裝置與作業系統的最低要求、頻寬假設、語言支援、無障礙合規性（WCAG）、身份驗證門檻，以及僅限應用商店的分發方式，每一項都會把部分人群排除在分母之外——而且通常是不可見的，因為被排斥的使用者根本不會出現在分析資料中。能夠推動公平的工程實踐包括：測量*分母*本身（對符合條件的人群進行埋點，而非僅僅統計使用者）；為老舊裝置與不良網路連線預算相應的效能表現；將輔助數位化路徑（電話、簡訊、自助終端）作為一等公民的流程來交付，而非令人羞於使用的備選渠道；並按公平維度對每一塊儀表盤指標進行分層——未經分層的平均值，正是不公平藏身之處（[GDS使用率](../GDS服務指標/)也帶有同樣的警示）。

## 陷阱

- **有效性只按完成者報告，影響力卻按整個人群主張**——觸達率這一項被悄悄丟棄了。
- **把公平當作事後審計**，而非設計輸入；事後補救觸達率，遠比一開始就為其設計要昂貴得多。
- **對"維持"這一環節的遺忘**：這是移動健康領域中RE-AIM最薄弱的維度——影響力的主張常常超出了證據所覆蓋的時間範圍。
- **僅限數位渠道的節省**，實際上是把成本轉嫁給了被排斥的使用者與一線員工（參見[GDS服務指標](../GDS服務指標/)）。
