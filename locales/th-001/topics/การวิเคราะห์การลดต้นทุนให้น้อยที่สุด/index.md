# การวิเคราะห์การลดต้นทุนให้น้อยที่สุด (CMA)

การวิเคราะห์การลดต้นทุนให้น้อยที่สุดเลือกตัวเลือกที่ถูกที่สุด หลังจากพิสูจน์แล้วว่าทางเลือกทั้งหมดให้ผลลัพธ์ด้านสุขภาพเทียบเท่ากัน

## ทำไมจึงสำคัญ

เมื่อประสิทธิผลเท่ากันอย่างแท้จริง การวิเคราะห์ความคุ้มทุนที่ซับซ้อนกว่าก็ไม่จำเป็น — การตัดสินใจง่ายขึ้นเป็นเรื่องของต้นทุนเพียงอย่างเดียว

## คณิตศาสตร์

```
เลือกตัวเลือกที่มี min(ต้นทุน) โดยที่ ผลลัพธ์(A) = ผลลัพธ์(B) = ... = ผลลัพธ์(N)
```

## ตัวอย่างที่คำนวณแล้ว

ยาสามัญสองยี่ห้อพิสูจน์แล้วว่ามีฤทธิ์ทางชีวภาพเทียบเท่ากัน (bioequivalent) ยี่ห้อหนึ่งราคา £10 ต่อเดือน อีกยี่ห้อราคา £15 — เลือกยี่ห้อที่ถูกกว่าเพราะผลลัพธ์เหมือนกันทุกประการ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการเลือกผู้ให้บริการคลาวด์ที่ถูกที่สุดเมื่อบริการที่เสนอมีความน่าเชื่อถือและประสิทธิภาพเทียบเท่ากันอย่างแท้จริงในทุกมิติที่สำคัญ

## ข้อผิดพลาดที่พบบ่อย

- **การสันนิษฐานว่าผลลัพธ์เทียบเท่ากันโดยไม่มีหลักฐานทางสถิติที่เข้มงวด**
- **การมองข้ามความแตกต่างเล็กน้อยในผลข้างเคียงหรือประสบการณ์ผู้ป่วยที่ CMA ไม่จับภาพไว้**
