# 健康调整预期寿命（HALE）

HALE是一项人群层面的汇总指标：一个人预期能够*在完全健康状态下*生活的年数，需扣除因疾病或伤残而度过的年数。2019年WHO数据显示，全球出生时HALE约为61.9岁，而预期寿命为73.3岁——人类平均在其生命的最后十年中，处于不完全健康的状态。

## 为何重要

HALE是国家与全球卫生政策的北极星指标——"健康老龄化"目标的分子，而它所揭示的差距（预期寿命减去HALE）正是预防、早期干预与慢性病管理所要弥合的负担。在部委层面，数字健康战略正是以HALE为依据来论证其正当性的；一整套应用、筛查服务与监测项目组合，最终都汇总体现在这一指标上。

## 计算方法

标准计算方法是**Sullivan法**：

```
HALE_年龄x = Σ (生命表中每个年龄段 ≥ x 的人年数 × 完全健康状态占比)
            / 存活至年龄x的人数

"完全健康状态占比" = 1 − Σ (患病率_病症 × 伤残权重)
```

输入数据包括：一份标准生命表，以及各健康状态的患病率与伤残权重（来自全球疾病负担研究数据）。HALE与[DALY](../伤残调整生命年/)相关联——人群DALY负担与HALE差距，是同一份健康损失的两种不同视角。

## 实例演算

某国家级数字高血压管理项目：50万人注册，血压控制的改善程度足以使中风发生率每年下降0.2个百分点。以该队列的终生周期建模，被避免的中风共节省15,000个伤残权重年（其中YLD按权重0.32计算，另加因致命性中风而损失的YLL）。

```
对HALE的贡献 ≈ 15,000个健康年 / 50万人
            ≈ 每名注册者0.03年（约11天）的HALE
```

11天听起来微不足道——但在人群规模上，国家层面的指标正是这样一点一滴移动的：各国卫生部委购买的正是数以百万计的这类微小的人均获益。这套算术也说明了为什么**触达范围至关重要**：一项效果是其两倍、但注册人数只有其十分之一的干预措施，对HALE的推动作用反而只有前者的五分之一。参见[触达与公平](../触达与公平/)。

## 与软件工程的联系

HALE是一种"机群健康度"指标模式：**预期服务寿命 × 该寿命中处于健康状态的占比**。一个平台团队同样可以在其整个资产范围内计算"健康服务寿命预期"——一项服务预期能运行的年数，再扣除处于降级、已弃用或故障状态的时间（权重来自SLO缺口）。这能将可靠性从"某一时点的可用性"重新构建为"整个生命周期的健康度"，并将补救工作导向那些正在拖累整个资产组合HALE数值的系统。

## 陷阱

- **HALE的变动缓慢且多因素叠加**——没有任何单一干预措施能带来可测量的、独立的"HALE变动"；应主张其建模贡献值，而非笼统套用国家层面的统计数字。
- **患病率数据存在滞后**，通常滞后官方数据数年；近期的获益不会立即体现在官方HALE数字中。
- **跨国比较HALE**存在陷阱，因为各国健康状态测量方式不同；应在同一体系内做纵向比较。
