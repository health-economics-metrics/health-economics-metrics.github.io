# आपातकालीन उपस्थिति से बचाव

आपातकालीन उपस्थिति से बचाव अपस्ट्रीम हस्तक्षेप — ट्राइएज ऐप, दूरस्थ निगरानी, वर्चुअल वार्ड — द्वारा रोकी गई ED यात्राओं और आपातकालीन प्रवेशों को गिनता है।

## यह क्यों महत्वपूर्ण है

आपातकालीन देखभाल प्रणाली में सबसे महंगी नियमित सेटिंग है।

## गणित

```
बचाई गई उपस्थिति = जनसंख्या × (आधाररेखा दर − हस्तक्षेप दर)
शुद्ध बचत        = सकल बचत − हस्तक्षेप लागत − नए मार्ग उपयोग की लागत
```

## हल किया गया उदाहरण

3,000 उच्च-जोखिम रोगियों के लिए एक COPD दूरस्थ-निगरानी सेवा:

```
बचाई गई उपस्थिति = 3,000 × 0.2 = 600 × £300 = £180,000
शुद्ध ≈ सालाना +£342,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यह **घटना-बचाव अर्थशास्त्र** है।
