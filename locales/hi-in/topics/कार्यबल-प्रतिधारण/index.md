# कार्यबल प्रतिधारण

कार्यबल प्रतिधारण अर्थशास्त्र यह मापता है कि स्टाफ परिवर्तन एक स्वास्थ्य प्रणाली को कितना खर्च कराता है — भर्ती, ऑनबोर्डिंग, रिक्ति कवर।

## यह क्यों महत्वपूर्ण है

जब एक चिकित्सक चला जाता है, ट्रस्ट तीन बार भुगतान करता है: एक प्रतिस्थापन भर्ती करने, उन्हें ऑनबोर्ड करने, और इस बीच रिक्ति को कवर करने के लिए।

## गणित

```
प्रति छोड़ने वाला लागत = भर्ती लागत + ऑनबोर्डिंग/उत्पादकता-वृद्धि लागत
                       + रिक्ति कवर प्रीमियम × रिक्ति अवधि
```

## हल किया गया उदाहरण

एक ट्रस्ट 1,200 नर्सों को नियुक्त करता है; परिवर्तन 11%/वर्ष।

```
आधाररेखा परिवर्तन लागत ≈ सालाना £2.44M
दस्तावेज़ीकरण-बोझ सॉफ़्टवेयर परिवर्तन 1 प्रतिशत बिंदु घटा सकता है:
मूल्य = सालाना £222,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इंजीनियरिंग प्रतिधारण गणित समान है: एक वरिष्ठ इंजीनियर को बदलने में 6–12 महीने का पूर्ण-आवंटित वेतन खर्च होता है।

## सामान्य गलतियाँ

- **सभी परिवर्तन आंदोलन को अपने हस्तक्षेप के लिए ज़िम्मेदार ठहराना।**
- **दोहरी गिनती।**
