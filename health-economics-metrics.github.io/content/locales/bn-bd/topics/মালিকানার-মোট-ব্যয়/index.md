# মালিকানার মোট ব্যয় (TCO)

TCO হলো একটি ব্যবস্থার জীবদ্দশায় সম্পূর্ণ ব্যয়: অধিগ্রহণ বা নির্মাণ, একীকরণ, পরিচালনা, রক্ষণাবেক্ষণ, সহায়তা, প্রশিক্ষণ, এবং অবসান। অস্বস্তিকর বেসলাইন: **রক্ষণাবেক্ষণ সফটওয়্যার TCO-এর ৫০–৮০%**।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য প্রযুক্তি মূল্যায়ন অনেক আগেই শিখেছে যে একটি ওষুধের মূল্য তার ব্যয় নয় — প্রশাসন, পর্যবেক্ষণ, এবং পার্শ্ব-প্রতিক্রিয়া ব্যবস্থাপনা সবই মডেলে অন্তর্ভুক্ত।

## গণিত

```
TCO = প্রাথমিক ব্যয় (নির্মাণ/লাইসেন্স + একীকরণ + তথ্য মাইগ্রেশন + প্রশিক্ষণ)
    + Σ_t [পরিচালনা + রক্ষণাবেক্ষণ + সহায়তা + অবকাঠামো + আপগ্রেড]_t / (1 + r)^t
    + অবসান ব্যয়
```

## সমাধানকৃত উদাহরণ

একটি ই-অবজারভেশন ব্যবস্থার দুটি বিকল্প, ৫-বছরের দিগন্ত:

```
                        বিক্রেতা SaaS    ইন-হাউস নির্মাণ
বছর 0 (লাইসেন্স/নির্মাণ) £250,000        £900,000
বার্ষিক পরিচালনা (1-5)   £120,000/বছর    £190,000/বছর

অ-ছাড়যুক্ত TCO           £1,090,000      £2,030,000
```

নির্মাণ বিকল্পের প্রকৌশল অনুমান (£৯০০হাজার) এর প্রকৃত TCO-এর মাত্র ৪৪% ছিল।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

প্রকৌশলীরা নির্মাণ সমর্থন করার সময় তাদের নিজস্ব ক্ষেত্রের রক্ষণাবেক্ষণ তথ্যকে কম গুরুত্ব দেয়: বার্ষিক রক্ষণাবেক্ষণ নিয়ম মানে প্রতিটি £১০ লক্ষ ব্যবস্থা নীরবে বার্ষিক £১৫হাজার–২০হাজার ভবিষ্যত ক্ষমতা প্রতিশ্রুতিবদ্ধ করে। ওপরের মতো একটি বহু-বছর TCO সংখ্যা সময়ের সাথে অনেক ব্যয় আইটেমের যোগফল — মডেলকে সেন্ট পর্যন্ত মিলতে হলে সেই যোগফল কেন ভাসমান-বিন্দুর বদলে নিখুঁত দশমিক হওয়া উচিত তার জন্য [মুদ্রা-নিরাপদ ব্যয় সংকলন](../মুদ্রা-নিরাপদ-ব্যয়-সংকলন/) দেখুন, এবং সেন্ট না হারিয়ে একটি মোট TCO ব্যয় কেন্দ্রগুলোর মধ্যে ভাগ করতে [নিখুঁত-সেন্ট ব্যয় বণ্টন](../নিখুঁত-সেন্ট-ব্যয়-বণ্টন/) দেখুন।

## ঝুঁকিপূর্ণ দিক

- **চালু-খরচ নোঙর করা**: ০-বছরের ব্যয়ে বিকল্প তুলনা করা যখন র‍্যাঙ্কিং ৩ বছরে উল্টে যায়।
- **বিনামূল্যে-অভ্যন্তরীণ-শ্রম ভ্রান্তি**।
- **প্রস্থান ব্যয় উপেক্ষা করা**।
