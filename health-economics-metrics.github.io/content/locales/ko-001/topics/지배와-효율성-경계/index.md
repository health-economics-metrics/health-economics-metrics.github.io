# 지배와 효율성 경계

한 옵션은 다른 옵션이 더 적게 비용이 들고 *더 많이* 제공하면 **지배당한** 것입니다. **효율성 경계**는 지배당한 옵션들을 제거한 후 남는 것입니다.

## 왜 중요한가

임계값이나 예산에 대한 어떤 논쟁 전에, 보건기술평가는 먼저 아무도 선택해서는 안 되는 옵션들을 제거합니다.

## 수식

```
엄격한 지배: 비용_A ≤ 비용_B이고 효과_A ≥ 효과_B이면 A가 B를 지배함
```

## 계산 예시

놓친 예약을 줄이는 네 가지 옵션. 전화 통화는 SMS + AI 트리아지에 의해 엄격하게 지배당합니다.
