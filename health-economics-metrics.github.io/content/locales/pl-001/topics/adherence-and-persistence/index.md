# Przestrzeganie zaleceń i wytrwałość

Przestrzeganie zaleceń mierzy stopień, w jakim przepisane leczenie lub interwencja jest przestrzegane; wytrwałość mierzy, czy leczenie jest kontynuowane w czasie.

## Dlaczego to ważne

Leczenie, którego się nie przestrzega, nie przynosi korzyści w praktyce, nawet jeśli jest skuteczne w badaniach klinicznych.

## Matematyka

```
Przestrzeganie (MPR) = przepisane dni dostarczone / okres obserwacji (dni) × 100%
```

## Rozwiązany przykład

Użytkownicy cyfrowej aplikacji przypominającej o lekach: MPR poprawia się z 65% przed interwencją do 82% po niej.

## Powiązanie z inżynierią oprogramowania

Łączy się z [wynikami raportowanymi przez pacjenta](../patient-reported-outcomes/) w celu weryfikacji rzeczywistego efektu interwencji cyfrowych.
