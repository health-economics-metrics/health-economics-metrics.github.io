# 现金释放型与非现金释放型节省

现金释放型节省会减少实际支出——某条预算科目金额真正变小。非现金释放型节省则是释放出时间或产能，但这些被*重新利用*，而非真正入账。医疗系统的财务总监将二者视为完全不同的两个物种，你也应当如此。

## 为何重要

这是应用于任何国家医疗服务体系数字化商业论证中最严苛的诚实度检验。NHS的效益框架明确要求，将每一项声称的效益归类为现金释放型、非现金释放型或定性效益三类之一。大多数数字健康类"节省"——每名患者节省的临床人员分钟数、更快的文书记录——都属于非现金释放型：有价值，但不会缩小财政赤字。面对资金缺口的信托机构首席财务官，能花的只有现金。另见[硬性现金释放型节省](../硬性现金释放型节省赤字防线/)。

## 计算方法

```
现金释放型节省 = 变动前的预算科目金额 − 变动后的预算科目金额
                （必须是可真正抽取出来的：被取消的合同、被关闭的病区、
                 减少的中介用工支出、被避免的采购）

非现金释放型价值 = 被释放的时间 × 该时间的单位成本
                  （按机会成本估值；这笔钱并*不能*被抽取出来）
```

同一个物理事件（节省下来的一小时），落入哪一类完全取决于接下来发生了什么：

```
节省一小时 → 加班/中介班次被取消          → 现金释放型
节省一小时 → 临床人员多看了一名等候患者    → 非现金释放型（产能）
节省一小时 → 被吸收进冗余时间，什么都没改变 → 完全没有效益
```

## 实例演算

某软件为100名护士每人每个班次节省30分钟。合计为100 × 0.5 × 每周5个班次 × 46周 ≈ 每年11,500小时。按5级职级约£25/小时的雇主成本计算，一个诱人的头条数字是每年£287,500。

诚实的拆分应为：

- 20%的时间落在病区目前需以银行/中介溢价来覆盖文书记录超时的场景中：2,300小时 × £35中介费率 = **£80,500现金释放型**（这些班次确实不再需要预订）。
- 60%被重新投入直接患者照护：6,900小时 × £25 = **£172,500非现金释放型产能**——真实价值，但应单独报告，绝不能称为"节省"。
- 20%消散在休息与打断之中：**£0**。若主张这部分收益，则纯属虚构。

一份呈现"£80,500现金 + £172,500产能"的商业论证是可信的。而一份呈现"£287,500节省"的商业论证，会被第一位读到它的会计师直接否决。

## 与软件工程的联系

完全相同的逻辑也适用于AI编程助手的投资回报率："每名开发者每天30分钟"属于非现金释放型产能，除非人员编制、承包商支出或云成本真的因此下降。应分类分别报告：

- 现金释放型：被取消的承包商合作、被停用的工具许可、下降的云支出。
- 产能：更早交付的功能（其价值通过[延迟成本](../延迟成本/)体现）、被消化掉的积压任务。
- 无效益：碎片化在上下文切换中而消失的分钟数。

同时也要追踪*被释放的时间实际去了哪里*——效益兑现（参见[benefits-realization.md](../效益兑现/)）之所以存在，正是因为声称的产能收益在审计时往往会蒸发消失。

## 陷阱

- **用分钟数乘以薪资，再称之为"节省"**——这是最经典的罪过。
- **按平均负荷成本为释放出的时间估值**，而该时间的边际用途其实价值很低——参见[边际成本与平均成本](../边际成本与平均成本/)。
- **同一小时被重复计算两次**：既算作现金（避免了一个班次），又算作产能（多看了几名患者）。
