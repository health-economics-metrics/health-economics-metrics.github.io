# 통화 간 ICER 비교

한 나라의 통화로 계산한 [ICER](../incremental-cost-effectiveness-ratio/)를 다른 나라의 [지불의사 임계값](../willingness-to-pay-thresholds/)과 비교하거나, 다국가 시험에서 수집한 비용 데이터를 합칠 때는 명시적이고 감사 가능한 통화 환산 단계가 필요합니다. 환산 방법을 잘못 고르면, 임상 데이터나 비용 데이터는 아무것도 바뀌지 않았는데도 같은 근거가 도입 결정을 뒤집을 수 있습니다.

## 왜 중요한가

ISPOR의 다국가 임상시험 방법론 지침(Willke 외, *Health Economics*, 1998)은 국가 간 자원의 실질 경제적 가치를 비교할 때 시장 환율이 아니라 **구매력평가(PPP)**로 자원 비용을 환산하고, 시장 외환 환율은 본래의 용도인 실제 국경 간 현금 지급 흐름을 모델링하는 데에만 쓰도록 권고합니다. 이 둘을 혼동하는 것은 다국가 HTA에서 가장 흔한 방법론 오류 중 하나인데, 지침을 읽지 않은 사람에게는 둘 다 "환율"로 보이고 스프레드시트는 잘못 사용하는 것을 막아 주지 않기 때문입니다.

## 수식

```
현지통화_ICER = 환산(원통화_ICER, 환산계수)

환산계수는 다음이어야 함:
  PPP 환산계수     — 국가 간 자원의 실질 경제적 가치를 비교할 때
                     (다국가 CEA에 ISPOR가 권고)
  시장 환율        — 실제 국경 간 현금 지급에만

현지통화_ICER < 현지_임계값 이면 도입
```

의사결정 규칙 자체는 일반적인 [ICER 임계값 규칙](../willingness-to-pay-thresholds/), 즉 `ICER < λ이면 도입`입니다. 이 주제가 다루는 방법론적 문제는 그 규칙이 적용되는 `현지통화_ICER` 수치를 *어떤 환산계수*가 만들어 내는가에 전적으로 달려 있습니다.

## 계산 예시

미국 시험에서 나온 어떤 약물의 ICER은 $45,000/QALY입니다. 가상의 수입국이 자체 설명용 임계값을 £34,000/QALY로 정했습니다(이 예시만을 위한 가상의 국가별 수치이며, 실제 임계값은 나라마다 다르고 시간이 지나며 바뀌므로 항상 출처와 날짜를 밝혀야 합니다).

**PPP 환산계수 0.72를 사용할 때**(설명용, 이 계산 예시에만 해당): $45,000 × 0.72 = £32,400/QALY. £32,400 < £34,000 → **도입**.

**대신 시장 환율 0.79를 사용할 때**(설명용): $45,000 × 0.79 = £35,550/QALY. £35,550 > £34,000 → **기각**.

같은 $45,000/QALY의 ICER이 PPP 환산에서는 도입, 시장 환율 환산에서는 기각이라는 결정을 낳습니다. 이는 ISPOR 지침이 환산계수의 선택을 방법론적으로 중요한 문제로 다루는 이유를 보여 주는 구체적인 사례입니다. 반올림의 세부 사항이 아니며, 아무도 다시 확인하지 않는 스프레드시트 수식에 암묵적으로 맡겨 둘 것도 아닙니다.

## 소프트웨어 공학과의 연관성

이는 잘 알려진 공학 영역의 보건경제학판입니다. 상용 소프트웨어의 i18n/l10n 다통화 가격 책정의 정확성으로, SaaS 가격 페이지는 `$` 금액과 `£` 가격을 조용히 비교해서는 안 됩니다. 잘 만든 `Money` 타입이 제공하는 타입 수준의 보장, 곧 통화가 다른 값의 비교를 거부하고 먼저 명시적인 환산 단계를 강제하는 비교 메서드는, 여기서의 보건경제학적 방법론 요점에 직접 대응하는 소프트웨어 공학적 병행물입니다. 환산되지 않은 수치를 통화 간에 비교하지 말고, 환산 단계를 암묵적이거나 문서화되지 않은 채로 두지 말아야 합니다.

## 함정

- **서로 다른 통화의 금액을 조용히 비교하기**: 환산 단계 없이 달러 수치와 파운드 수치를 빼거나 비교하는 임시방편의 스프레드시트 기반 HTA 작업. 통화를 인식하는 진짜 `Money` 타입은 이를 구조적으로 잡아내며, 조용한 오류로 남겨 두지 않습니다.
- **시장 환율과 PPP를 혼동하기**: ISPOR 지침에 따른 다국가 HTA에서 가장 흔한 방법론 오류로, 두 수치는 상당히 다를 수 있으며 서로 다른 질문(실질 경제적 가치 대 실제 현금 흐름)에 답합니다.
- **사용한 환율이나 PPP 지수의 날짜를 밝히지 않기**: 둘 다 시간에 따라 변하므로, 인용하는 환산계수에는 이 저장소가 다른 기준 수치(그린북 탄소 가치, 예방된 사망의 가치 등)에 날짜를 붙이는 것과 같은 방식으로 날짜를 붙여야 합니다.
