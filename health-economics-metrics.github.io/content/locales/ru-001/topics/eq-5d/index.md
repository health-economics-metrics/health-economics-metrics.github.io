# EQ-5D

EQ-5D — это стандартизированный опросник группы EuroQol для измерения качества жизни, связанного со здоровьем. Это инструмент, который создаёт веса полезности внутри большинства расчётов [QALY](../год-жизни-с-поправкой-на-качество/) — базовый случай NICE называет его предпочтительной мерой для взрослых.

## Почему это важно

Любой продукт цифрового здравоохранения, желающий заявить QALY, нуждается в полезностях из валидированного инструмента, и EQ-5D является выбором по умолчанию в Великобритании и большей части Европы. Он достаточно короткий, чтобы встроить его в приложение (5 вопросов + визуальная шкала), что означает, что программные продукты могут собирать данные результатов уровня ОМТ как побочный эффект обычного использования — структурное преимущество перед лекарствами, которым нужны специальные исследования.

## Расчёт

EQ-5D-5L задаёт один вопрос по каждому из **5 измерений** — подвижность, самообслуживание, привычная деятельность, боль/дискомфорт, тревога/депрессия — каждый отвечается по **5 уровням** (нет проблем … крайние проблемы), плюс визуальная аналоговая шкала 0-100 (EQ VAS).

```
Состояние здоровья = 5-значный профиль, напр. «21221»
Индекс полезности = набор_значений(профиль)

Набор значений специфичен для страны, получен из опросов
компромисса по времени/дискретного выбора среди широкой публики. Якоря: 1 = полное
здоровье, 0 = смерть; состояния хуже смерти отрицательны (нижняя граница
набора 3L в Великобритании: −0,594).
```

Затем арифметика QALY продолжается как `длительность × полезность`.

## Разобранный пример

Приложение опорно-двигательной реабилитации измеряет EQ-5D-5L при онбординге и через 6 месяцев для 1000 завершивших пользователей.

```
Средняя полезность на базовой линии:  0,62
Средняя полезность через 6 месяцев:  0,71
Устойчивая (предполагаемая) выгода за 1 год: (0,71 − 0,62) × 1,0 = 0,09 QALY на пользователя
```

Против изменения контрольной группы 0,03 (естественное восстановление), относимая выгода составляет 0,06 QALY/пользователя. Монетизировано по £20 000-30 000/QALY: **£1200-1800 ценности здоровья на завершившего пользователя** — цифра, которая закрепляет переговоры о цене приложения с плательщиком. (Минимальные клинически значимые разницы для индекса EQ-5D обычно находятся в диапазоне 0,03-0,08, поэтому 0,06 правдоподобно, но должно пройти сравнение с контролем; см. [результаты, сообщаемые пациентами](../результаты-сообщаемые-пациентами/)).

## Связь с программной инженерией

- **Инструментируйте это.** EQ-5D при регистрации и на интервалах наблюдения — это несколько экранов интерфейса; отдача — доказательства уровня ОМТ. Получите лицензию от EuroQol (требуется, бесплатно для некоторых применений).
- **Используйте правильный набор значений** для страны развёртывания — одни и те же ответы оцениваются по-разному в Великобритании против Германии против Японии.
- **Урок проектирования**: EQ-5D показывает, как небольшой стандартизированный опрос плюс опубликованная функция подсчёта баллов даёт единый сопоставимый индекс. Это же шаблон для любого достоверного индекса опыта разработчика — стандартизированный инструмент, опубликованные веса, а не специальные догадки. См. [SPACE и DevEx](../space-и-devex/).

## Подводные камни

- **До/после без компаратора** — регрессия к среднему и естественное восстановление завышают наивные выгоды.
- **Смещение выживания**: измерение только пользователей, остававшихся вовлечёнными (см. [удержание и отток](../удержание-и-отток/)).
- **Смешение версий 3L и 5L или наборов значений** между исследованиями — систематически разные цифры.
- **Эффекты потолка** в слегка затронутых популяциях: многие пользователи оценивают близко к 1,0 на базовой линии, не оставляя пространства для демонстрации выгоды.
- **Принятие набора значений за самоочевидное**: значения полезности, которые возвращает набор значений, сами были получены от населения в исследованиях обмена времени (или родственных опросах выбора) — как именно, см. [Выявление полезности методом обмена времени (TTO)](../выявление-полезности-методом-обмена-времени/).
