# لاگت-فائدہ تجزیہ (CBA)

CBA اخراجات *اور* نتائج دونوں کی پیسوں میں قدر کرتا ہے۔ یہ واحد قسم کا تجزیہ ہے جو "کیا یہ بالکل کرنے کے قابل ہے؟" کا جواب دے سکتا ہے — صرف "کون سا آپشن بہتر ہے؟" نہیں — کیونکہ رقمی فوائد کو براہ راست اخراجات کے خلاف موازنہ کیا جا سکتا ہے۔

## یہ کیوں اہم ہے

CBA برطانیہ کے HM Treasury **Green Book** کا معیار ہے تمام عوامی اخراجات کی تشخیص کے لیے، بشمول صحت جب نتائج کو رقمی شکل دی جا سکے۔ جہاں [CEA](../لاگت-تاثیر-تجزیہ/)/[CUA](../لاگت-افادیت-تجزیہ/) "فی یونٹ صحت لاگت" پر رک جاتے ہیں، CBA خود صحت کی قیمت طے کرتی ہے (QALY × حد کی قیمت) اور باقی سب کچھ — وقت، سفر، کاربن — اور ایک خالص عدد رپورٹ کرتی ہے۔ ہر مکمل NHS ڈیجیٹل کاروباری کیس میں CBA شکل کا اقتصادی کیس شامل ہے۔

## حساب

```
NPV (خالص موجودہ سماجی قدر) = Σ_t [ (فوائد_t − اخراجات_t) / (1 + r)^t ]
BCR (فائدہ-لاگت تناسب)         = PV(فوائد) / PV(اخراجات)

اپنائیں اگر NPV > 0 (مساوی BCR > 1)؛ NPV کے مطابق درجہ بندی کریں، BCR نہیں۔
r = 3.5% (Green Book کی سماجی وقت ترجیح شرح)
```

صحت کے اثرات QALYs × λ کے طور پر رقمی شکل میں داخل ہو سکتے ہیں (دیکھیں [ادائیگی کی رضامندی کی حدیں](../ادائیگی-کی-رضامندی-کی-حدود/))۔ Green Book **خوش گمانی تعصب کی ایڈجسٹمنٹ** بھی لازمی کرتی ہے — ثبوت پر مبنی فیصد سے لاگت کے تخمینے بڑھانا اور فوائد کم کرنا، کیونکہ تشخیصات منظم طور پر بہت خوش کن ہوتی ہیں۔

## حل شدہ مثال

ایک ای-ریفرل نظام، 5-سال کی حد، 3.5% ڈسکاؤنٹ:

```
اخراجات:  تعمیر £1.2M (سال 0)، چلانا £300ہزار/سال (سال 1–5)
فوائد: انتظامی بچتیں £250ہزار/سال، اجتناب شدہ ڈپلیکیٹ تشخیصات £280ہزار/سال،
          بچایا گیا مریض وقت 40,000 گھنٹے/سال × £15 = £600ہزار/سال → £1,130ہزار/سال

PV اخراجات    = 1,200ہزار + 300ہزار × 4.515 (سالانہ عنصر) = £2,555ہزار
PV فوائد = 1,130ہزار × 4.515                          = £5,102ہزار

NPV = 5,102 − 2,555 = +£2,547ہزار     BCR = 2.0
```

Green Book کا خوش گمانی تعصب لاگو کریں (کہیں +40% تعمیری لاگت پر، −20% فوائد پر): PV اخراجات ≈ £3,035ہزار، PV فوائد ≈ £4,082ہزار، NPV ≈ **+£1,047ہزار** — ابھی بھی مثبت، جو ایڈجسٹمنٹ کا نکتہ ہے: کیسز کو اپنی خود کی خوش گمانی سے بچنا چاہیے۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرنگ کاروباری کیسز غیر رسمی CBAs ہیں۔ Green Book کی بہتریاں جو چرانے کے لائق ہیں:

- **ایک معیاری اضافے کے طور پر خوش گمانی تعصب** — انجینئرز ہجرت کی لاگت کو اتنی ہی قابل اعتمادی سے کم سمجھتے ہیں جتنا وزارتیں انفراسٹرکچر کی لاگت کو کم سمجھتی ہیں؛ یہ دکھاوا کرنے کی بجائے کہ اس بار مختلف ہے ایک بیان کردہ اضافہ لاگو کریں۔
- **غالب فائدے کو ایمانداری سے رقمی شکل دیں یا بالکل نہیں** — مریض/صارف کا وقت قابل دفاع شرحوں پر رقمی ہے؛ "برانڈ کی قدر" نہیں ہے۔
- **NPV درجہ بندی کرتا ہے، BCR نہیں**: BCR 5 کے ساتھ ایک چھوٹا پروجیکٹ BCR 1.6 کے ساتھ ایک بڑے سے کم اہم ہو سکتا ہے۔

## نقصانات

- فوائد بڑھانے کے لیے **غیر-رقمی چیز کو رقمی بنانا** (حوصلہ، "اسٹریٹیجک صف بندی") — انہیں معیاری رکھیں، [لاگت-نتائج تجزیہ](../لاگت-نتائج-تجزیہ/) کے مطابق۔
- **منتقلیوں کو فوائد کے طور پر شمار کرنا**: پیسہ جو عوامی اداروں کے درمیان منتقل ہوتا ہے سماجی [نقطہ نظر](../تجزیاتی-نقطہ-نظر/) میں صفر پر خالص ہوتا ہے۔
- **کوئی مخالف حقیقت نہیں**: فوائد کم-سے-کم آپشن کے خلاف ناپے جاتے ہیں، صفر کے خلاف نہیں۔
