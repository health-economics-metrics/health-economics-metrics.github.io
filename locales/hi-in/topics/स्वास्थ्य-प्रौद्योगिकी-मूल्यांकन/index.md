# स्वास्थ्य प्रौद्योगिकी मूल्यांकन (HTA)

HTA वह औपचारिक, संस्थागत प्रक्रिया है जिसके द्वारा स्वास्थ्य प्रणालियाँ तय करती हैं कि कोई तकनीक — दवा, उपकरण, या सॉफ़्टवेयर — भुगतान के लायक है या नहीं।

## यह क्यों महत्वपूर्ण है

यदि आप किसी राष्ट्रीय स्वास्थ्य सेवा को बेचते हैं, तो एक HTA निकाय शाब्दिक रूप से आपकी बाज़ार पहुँच तय कर सकता है।

## गणित

HTA की शक्ति एक सूत्र नहीं बल्कि एक **अनिवार्य पद्धति** है।

## हल किया गया उदाहरण

एक डिजिटल थेराप्यूटिक NICE-शैली मूल्यांकन में प्रस्तुत करती है:

```
मॉडल: ΔC = +£450/रोगी, ΔE = +0.03 QALY → ICER = £15,000/QALY ✓
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

स्थानांतरणीय कलाकृति **आंतरिक संदर्भ मामला** है।

बहु-चक्र HTA मॉडल का वास्तव में अनुकरण कैसे होता है, समूह-दर-समूह और चक्र-दर-चक्र, इसके लिए [मार्कोव समूह अनुकरण](../मार्कोव-समूह-अनुकरण/) देखें।

## सामान्य गलतियाँ
