# Anni di Vita Guadagnati (LYG)

Gli anni di vita guadagnati sono la sopravvivenza aggiuntiva attribuibile a un intervento, senza alcun aggiustamento di qualità. L'evLYG è una variante moderna che accredita ugualmente ogni prolungamento della vita.

## Perché è importante

Gli LYG sono il risultato sanitario più grezzo: per quanto tempo in più vivono le persone? L'evLYG (utilizzato dall'istituto ICER statunitense) esiste per una ragione etica.

## La matematica

```
LYG = sopravvivenza media_nuova − sopravvivenza media_comparatore
```

## Esempio risolto

Un algoritmo di allerta precoce per la sepsi in un ospedale risparmia 96 anni di vita all'anno.

## Collegamento con l'ingegneria del software

L'analisi di sopravvivenza è una cassetta degli attrezzi condivisa.
