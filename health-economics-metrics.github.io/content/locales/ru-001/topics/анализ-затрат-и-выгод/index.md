# Анализ затрат и выгод (АЗВ)

АЗВ оценивает как затраты, так и результаты в деньгах. Это единственный тип анализа, который может ответить «стоит ли это вообще делать?» — не просто «какой вариант лучше?» — потому что монетизированные выгоды можно напрямую сравнивать с затратами.

## Почему это важно

АЗВ является стандартом **Зелёной книги** казначейства Её Величества Великобритании для всей оценки государственных расходов, включая здравоохранение, когда результаты можно монетизировать. Там, где [АЭЭ](../анализ-экономической-эффективности/)/[АЗП](../анализ-затрат-и-полезности/) останавливаются на «стоимости на единицу здоровья», АЗВ оценивает само здоровье (QALY × пороговое значение) и всё остальное — время, поездки, углерод — и представляет одну чистую цифру. Каждый полный цифровой бизнес-кейс NHS содержит экономический кейс в форме АЗВ.

## Расчёт

```
ЧПС (чистая приведённая социальная стоимость) = Σ_t [ (Выгоды_t − Затраты_t) / (1 + r)^t ]
СВЗ (соотношение выгод и затрат)       = ТС(выгоды) / ТС(затраты)

Принимайте, если ЧПС > 0 (эквивалентно СВЗ > 1); ранжируйте по ЧПС, не по СВЗ.
r = 3,5% (ставка общественного временного предпочтения Зелёной книги)
```

Эффекты на здоровье могут входить монетизированными как QALY × λ (см. [пороги готовности платить](../пороги-готовности-платить/)). Зелёная книга также требует **корректировок предвзятости оптимизма** — повышения оценок затрат и урезания выгод на основанные на доказательствах проценты, потому что оценки систематически оптимистичны.

## Разобранный пример

Система электронных направлений, горизонт 5 лет, дисконт 3,5%:

```
Затраты:    разработка £1,2 млн (год 0), эксплуатация £300 тыс/год (годы 1–5)
Выгоды: административная экономия £250 тыс/год, избежанные дублирующие диагностики £280 тыс/год,
          сэкономленное время пациентов 40 000 ч/год × £15 = £600 тыс/год → £1130 тыс/год

ТС затрат    = 1200 тыс + 300 тыс × 4,515 (коэффициент аннуитета) = £2555 тыс
ТС выгод = 1130 тыс × 4,515                          = £5102 тыс

ЧПС = 5102 − 2555 = +£2547 тыс     СВЗ = 2,0
```

Примените предвзятость оптимизма Зелёной книги (скажем, +40% к стоимости разработки, −20% к выгодам): ТС затрат ≈ £3035 тыс, ТС выгод ≈ £4082 тыс, ЧПС ≈ **+£1047 тыс** — всё ещё положительно, что и является смыслом корректировки: кейсы должны выживать при собственном оптимизме.

## Связь с программной инженерией

Инженерные бизнес-кейсы — это неформальные АЗВ. Улучшения Зелёной книги, которые стоит позаимствовать:

- **Предвзятость оптимизма как стандартная надбавка** — инженеры недооценивают стоимость миграции так же надёжно, как министерства недооценивают стоимость инфраструктуры; применяйте заявленную надбавку вместо того, чтобы притворяться, что в этот раз всё иначе.
- **Монетизируйте доминирующую выгоду честно или не монетизируйте вовсе** — время пациента/пользователя монетизируется по обоснованным ставкам; «ценность бренда» — нет.
- **ЧПС ранжирует, СВЗ — нет**: маленький проект с СВЗ 5 может значить меньше, чем большой с СВЗ 1,6.

## Подводные камни

- **Монетизация немонетизируемого** для завышения выгод (мораль, «стратегическое соответствие») — держите это качественным, согласно [анализу затрат и последствий](../анализ-затрат-и-последствий/).
- **Учёт трансфертов как выгод**: деньги, перемещающиеся между государственными органами, обнуляются в общественной [перспективе](../перспектива-анализа/).
- **Отсутствие контрфактического сценария**: выгоды измеряются относительно варианта минимальных действий, а не относительно нуля.
