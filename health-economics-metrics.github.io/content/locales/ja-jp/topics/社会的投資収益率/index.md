# 社会的投資収益率(SROI)

SROIは、[ROI](../投資収益率/)を、市場が値付けしないアウトカム — ウェルビーイング、社会的つながり、環境への影響 — にまで拡張します。財務的な代理指標を使ってそれらを金銭化し、影響を受ける*すべての*利害関係者について評価します。

## なぜ重要か

医療やコミュニティ介入が生み出すものの多くは、決して予算項目に触れません:孤独の軽減、介護者の負担軽減、雇用の獲得、尊厳。SROIは、Social Value Internationalの7つの原則(利害関係者を関与させる、重要なことを評価する、過剰に主張しない、透明であること、検証する…)によって統治され、「投資£1あたり£3.20の社会的価値」といった記述を生み出します。英国の公共調達における社会的価値の要件により、SROI形式の証拠は商業的に重要になっています:公共契約(NHSを含む)への入札は、実証された社会的価値に対して得点します。

## 数式

```
SROI比率 = PV(金銭化された社会的アウトカム) / PV(投資)

各アウトカムについて:
  価値 = 数量 × 財務的代理指標 × 帰属 × (1 − 死荷重) × (1 − 置き換え)

死荷重   = とにかく起こったであろうもの
帰属     = 他者によって引き起こされた割合
置き換え = 創出されたのではなく他所から移動しただけの便益
逓減     = 年を経るごとのアウトカムの減衰
```

これらの調整係数こそが、この手法の誠実さです:それらがなければ、SROIは通貨記号のついたフィクションにすぎません。

## 計算例

孤立した高齢者をボランティアと結びつける「ふれあい」アプリ;プログラム費用は年間£200,000;アクティブなペアは1,500組。

```
アウトカム:1,500人の孤独の軽減
  代理指標:「孤独からの解放」のウェルビーイング評価 ≈ £1,800/人/年
  死荷重25%(一部はとにかくつながりを見つけていたであろう)
  帰属80%(一部は他のサービスの功績)

価値 = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

アウトカム:GP受診の減少、1,500 × 1.2件 × £42 = £75,600(支払者にとって実質的)

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5:1
```

この比率の96%が代理指標で評価されたウェルビーイングであり、4%が実際の現金であることに注目してください。それは正当なSROIですが — 社会的価値として提示されなければならず、£170万が現金化可能であることを示唆することは決して許されません。

## ソフトウェア工学との関連

SROIは、受益者が支払っているチームの外部にあるエンジニアリング作業にとって正直な枠組みです:オープンソースの保守、アクセシビリティの改善、他のチームが消費するプラットフォーム作業、開発者コミュニティへの投資。転用できる仕組み:すべての利害関係者を特定し、明示された代理指標で金銭化し、死荷重/帰属の割引を適用する(そのOSSの修正はとにかく起こっていたか?獲得のどれだけがあなたの作業で、どれだけがエコシステムのものか?)。*自らの影響の主張を割り引く*という規律こそが、SROIをマーケティング上の数字から区別するものです。

## 落とし穴

- **代理指標の都合の良い選択**:入手可能な最も気前の良いウェルビーイング評価を選ぶこと。
- **死荷重/帰属を省略すること** — 最も一般的な水増しであり、しばしば比率を2倍にします。
- **研究間での比率の比較**:SROIの比率は手法に敏感です;一貫した枠組みの中でのみ比較してください。
- **社会的価値を、予算保有者に対して現金化可能な節約であるかのように提示すること**。
