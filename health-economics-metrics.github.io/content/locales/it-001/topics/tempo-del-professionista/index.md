# Tempo del Professionista

Il tempo del professionista è la risorsa più scarsa nella maggior parte dei sistemi sanitari.

## Perché è importante

Non si possono creare rapidamente più medici di base, consulenti o infermieri specialisti.

## La matematica

```
1. Base salariale: ore × tariffa salariale completamente allocata
2. Base di output: ore → appuntamenti resi possibili × valore dello schema
```

## Esempio risolto

La trascrizione ambientale risparmia 2 minuti per consultazione del medico di base: **220 ore per medico all'anno**.

## Collegamento con l'ingegneria del software

Il tempo di un ingegnere senior si comporta allo stesso modo.

## Insidie

- **Minuti × stipendio = risparmio.**
