# Dampak Daftar Tunggu

Dampak daftar tunggu mengubah kapasitas klinis yang dihemat menjadi pasien yang dikeluarkan dari (atau dipindahkan lebih cepat melalui) daftar tunggu.

## Mengapa ini penting

Daftar tunggu elektif adalah tantangan pasca-pandemi yang mendefinisikan NHS.

## Matematika

```
Slot tambahan = jam yang dibebaskan / durasi slot × utilisasi
```

## Contoh yang diselesaikan

Perangkat lunak dokumentasi ambien menghemat 45 menit per hari untuk 20 perawat klinik.

## Hubungan dengan rekayasa perangkat lunak

Daftar tunggu adalah backlog.

## Jebakan

- **Slot ≠ pasien.**
