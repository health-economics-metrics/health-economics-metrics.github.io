# তৈরি বনাম কেনা

তৈরি-বনাম-কেনা হলো কাস্টম উন্নয়ন এবং বাণিজ্যিক অধিগ্রহণের একটি কাঠামোবদ্ধ তুলনা, ছাড়যুক্ত [TCO](../মালিকানার-মোট-ব্যয়/), ডেলিভারি সময়, এবং ঝুঁকির উপর। অভিজ্ঞতাভিত্তিক পূর্ব-ধারণা একমুখী: **প্রকৃত নির্মাণ ব্যয় সাধারণত প্রক্ষেপণকে ৩০–৪০% অতিক্রম করে**।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্য ব্যবস্থা ক্রমাগত এই সিদ্ধান্তের মুখোমুখি হয়, এবং প্রকৌশল সংস্থাগুলো পদ্ধতিগতভাবে নির্মাণের দিকে এটি ভুল করে — কারণ নির্মাতারা নির্মাণ অনুমান করে, [TCO](../মালিকানার-মোট-ব্যয়/) নয়।

## গণিত

```
একই ৩–৫ বছরের দিগন্তে তুলনা করুন, ছাড়যুক্ত:
NPV_বিকল্প = PV(সুবিধা, সময়-থেকে-মূল্য দ্বারা স্থানান্তরিত) − PV(TCO)

ঝুঁকি সমন্বয় (গ্রিন বুক "আশাবাদী পক্ষপাত" প্যাটার্ন):
  নির্মাণ ব্যয় × 1.3–1.4        (অতিক্রমের পূর্ব-ধারণা)
  নির্মাণ সময়-থেকে-মূল্য + 40–60% (স্থাপনা বিলম্ব পূর্ব-ধারণা)
```

## সমাধানকৃত উদাহরণ

একটি ট্রাস্টের একটি ই-সম্মতি ব্যবস্থা প্রয়োজন। কেনা: £১৫০হাজার/বছর SaaS, ৩ মাসে চালু। নির্মাণ: আনুমানিক £৬০০হাজার + £১২০হাজার/বছর রক্ষণাবেক্ষণ, ১২ মাসে চালু।

```
ঝুঁকি-সমন্বিত নির্মাণ: 600k × 1.35 = £810k; সময়-থেকে-মূল্য ≈ 18 মাস
5-বছর TCO:  কেনা = 150k × 5 = £750k
           নির্মাণ = 810k + 120k × 5 = £1,410k
বিলম্ব পদ: সম্মতি ডিজিটাইজেশন মাসে £25k সাশ্রয় করে; নির্মাণ 15 মাস দেরিতে
            → CoD = 15 × 25k = £375k
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

স্থানান্তরযোগ্য স্বাস্থ্য-অর্থনীতি শৃঙ্খলা তিনগুণ: **পূর্ব-ধারণা-ভিত্তিক ঝুঁকি সমন্বয়**; **তুলনাকারী সততা** (নির্মাণের বিকল্প "কিছু না" নয়, এটি সেরা উপলব্ধ কেনা); এবং **ব্যয় তুলনার আগে সমতা পরীক্ষা**।

## ঝুঁকিপূর্ণ দিক

- **বিক্রেতার তালিকা মূল্যকে ঝুঁকি-সমন্বয়হীন নির্মাণ অনুমানের সাথে তুলনা করা**।
- **শূন্য-মূল্যের অভ্যন্তরীণ শ্রম**।
- **পরিচয়-চালিত নির্মাণ**: "এটি আমাদের জন্য মূল" প্লাম্বিংয়ের জন্য দাবি করা।
