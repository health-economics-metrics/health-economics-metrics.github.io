# 費用効果分析(CEA)

CEAは、代替的な介入の費用を、**自然単位**で測定された単一のアウトカムと比較します — 生存年数、発見された症例数、回避された入院、血圧の低下mmHgなど。その出力は、アウトカム1単位あたりの費用です。

## なぜ重要か

CEAは、すべての選択肢が同じアウトカムを目標とする場合の主力の比較手法です。「Xを達成するこれらの方法のうち、どれが最もお金の使い方として優れているか?」に答えますが、「そもそもXを達成する価値はあるのか?」(これには[費用便益分析](../cost-benefit-analysis/)が必要です)や「Xは無関係な優先事項とどう比較されるのか?」(これには[費用効用分析](../cost-utility-analysis/)とQALYのような汎用アウトカムが必要です)には答え*ません*。

## 数式

比較のための統計量は、自然単位での[ICER](../incremental-cost-effectiveness-ratio/)です:

```
ICER = (費用_A − 費用_B) / (効果_A − 効果_B)
     = 追加で発見された1症例あたりの£ / 回避された1入院あたり / など
```

手順:アウトカムの単位を定義する;すべての選択肢を、同じ[視点](../analysis-perspective/)から、同じ[評価期間](../time-horizon/)にわたって費用計算する;劣位の選択肢を排除する([効率フロンティア](../dominance-and-efficiency-frontier/));フロンティアに沿って増分比を計算する。

## 計算例

人口100,000人における未診断の心房細動を見つける3つの方法:

```
選択肢                    費用         発見症例数
機会的な脈拍チェック      £150,000     300
薬局スクリーニングイベント £400,000     520
ウェアラブルによるスクリーニング £900,000  610

ICER 薬局 対 脈拍:       (400k−150k)/(520−300) = 追加症例1件あたり£1,136
ICER ウェアラブル 対 薬局:(900k−400k)/(610−520) = 追加症例1件あたり£5,556
```

追加症例1件あたり£5,556が「価値がある」かどうかは、見つかった症例の価値(下流での脳卒中予防)次第です — CEAは選択肢を順位付けしますが、採用の意思決定にはその外部評価が必要です。ウェアラブルの選択肢の*平均*費用/症例(900k/610 = £1,475)は良く見えることに注目してください;*増分*の£5,556が、拡大の意思決定にとって正直な数値です。

## ソフトウェア工学との関連

CEAは、選択肢が1つのアウトカムを共有する場合には常に正しいテンプレートです:3つの修復アプローチにわたる、排除された不安定なテスト1件あたりの費用;観測可能性ベンダーにわたる、回避されたインシデント1件あたりの費用;CIアーキテクチャにわたる、成功したデプロイ1回あたりの費用。これが強制する規律 — 1つの明示されたアウトカム単位、増分(平均ではない)比率、劣位の選択肢を先に排除すること — は、価格交渉が始まる前に、ほとんどの悪いベンダー比較を葬り去ります。

## 落とし穴

- 1つのCEAの中で**異なるアウトカムを持つ選択肢を比較すること**(「発見症例数」対「満足度」) — それには[費用結果分析](../cost-consequence-analysis/)か汎用アウトカムが必要です。
- 増分比率が必要な場面で提示される**平均費用効果比**(上記のウェアラブルの例)。
- **都合よく選ばれたアウトカム単位**:「生成されたアラート数」はアウトプットであってアウトカムではありません;価値を伴う単位を要求してください。
