# ব্যয়-উপযোগিতা বিশ্লেষণ (CUA)

CUA হলো একটি **সাধারণ, পছন্দ-ওজনযুক্ত ফলাফল**সহ ব্যয়-কার্যকারিতা বিশ্লেষণ — প্রায় সবসময় [QALY](../মান-সমন্বিত-জীবন-বছর/) (বা এড়ানো [DALY](../অক্ষমতা-সমন্বিত-জীবন-বছর/))। ফলাফল এককটি সার্বজনীন হওয়ায়, CUA সম্পূর্ণ ভিন্ন রোগ জুড়ে হস্তক্ষেপ তুলনা করতে পারে।

## কেন এটি গুরুত্বপূর্ণ

একটি জাতীয় স্বাস্থ্যসেবাকে একটি বাজেট থেকে একটি ক্যান্সারের ওষুধ, একটি মানসিক-স্বাস্থ্য অ্যাপ, এবং একটি সার্জিক্যাল রোবটের মধ্যে বেছে নিতে হয়। প্রাকৃতিক একক এগুলো তুলনা করতে পারে না; QALY পারে। তাই CUA হলো NICE এবং বেশিরভাগ HTA সংস্থার রেফারেন্স-কেস পদ্ধতি: এর আউটপুট — প্রতি QALY ব্যয়, একটি [থ্রেশহোল্ড](../প্রদানের-ইচ্ছার-সীমা/)-এর বিরুদ্ধে বিচার করা — স্বাস্থ্য নীতির সবচেয়ে কাছাকাছি একটি সার্বজনীন বিনিময় হার।

## গণিত

```
ICUR = Δব্যয় / ΔQALY      (প্রভাব একক হিসেবে QALY সহ ICER)

ΔQALY = Σ(সময়কাল_i × উপযোগিতা_i)_নতুন − Σ(সময়কাল_i × উপযোগিতা_i)_পুরনো
```

উপযোগিতা যাচাইকৃত যন্ত্র থেকে ([EQ-5D](../eq-5d/)); ব্যয় এবং QALY উভয়ই ৩.৫%-এ [ছাড়যুক্ত](../ছাড়-এবং-সময়-অগ্রাধিকার/) (NICE রেফারেন্স কেস); অনিশ্চয়তা [PSA](../সম্ভাব্যতাভিত্তিক-সংবেদনশীলতা-বিশ্লেষণ/)-এর মাধ্যমে।

## সমাধানকৃত উদাহরণ

মাঝারি উদ্বেগের জন্য একটি CBT অ্যাপ বনাম মুখোমুখি থেরাপির অপেক্ষমাণ তালিকা, প্রতি রোগী:

```
ব্যয়:  অ্যাপ লাইসেন্স + সহায়তা      £250
       স্থানচ্যুত থেরাপি              −£680   (৪০% ব্যবহারকারীর আর প্রয়োজন নেই)
       ΔC = 250 − 680 = −£430 (অর্থ সাশ্রয় করে)

QALY:  অপেক্ষার সময় উপযোগিতা ০.৬৮-এর পরিবর্তে ৬ মাস ০.৭৬-এ
       ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALY
```

ΔC < 0 এবং ΔE > 0: অ্যাপটি **আধিপত্য করে** — ভালো এবং সস্তা, কোনো অনুপাত প্রয়োজন নেই। থেরাপি-স্থানচ্যুতি অনুমান মাত্র ১০% হলে, ΔC = 250 − 170 = +£80, এবং ICUR = 80 / 0.04 = **£2,000/QALY** — তবুও £২০,০০০-এর অনেক নিচে।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

CUA-র গভীর ধারণা — *অসদৃশ জিনিস তুলনা করার জন্য একটি সমন্বিত, পছন্দ-ওজনযুক্ত একক* — অসদৃশ প্রকৌশল বিনিয়োগ (নিরাপত্তা বনাম ডেভেলপার অভিজ্ঞতা বনাম নির্ভরযোগ্যতা) তুলনার প্যাটার্ন। CUA যা সতর্ক করে তা হলো নকল সমন্বিত সূচক: একটি "প্রভাব স্কোর" যার ওজন পছন্দের বিকল্পকে জেতানোর জন্য ঘটনার পরে টিউন করা হয়েছিল।

## ঝুঁকিপূর্ণ দিক

- **যন্ত্রের সংবেদনশীলতার নিচে উপযোগিতা লাভ** — ছোট ΔE বড় জনসংখ্যা দিয়ে গুণ করা একটি ক্লাসিক লন্ডারিং কৌশল।
- **তুলনাকারী যত্নের স্থানচ্যুতি মিস করা** — ডিজিটাল পণ্যের জন্য সবচেয়ে বড় ব্যয় প্রায়ই তারা যা প্রতিস্থাপন করে।
- যাচাইকৃত নয় এমন ক্রসওয়াক দিয়ে **অ-পছন্দ স্কোরকে উপযোগিতায় ম্যাপ করা**।
