# Haiglaravi kestus

Haiglaravi kestus mõõdab päevade arvu, mille patsient veedab haiglas, vastuvõtust väljakirjutamiseni — haigla tsükliaeg.

## Miks see on oluline

Lühem haiglaravi kestus säästab ressursse ja vähendab haiglaga seotud tüsistuste riski, kuid liiga agressiivne lühendamine suurendab taasvastuvõtte.

## Matemaatika

```
Keskmine haiglaravi kestus = Voodipäevade koguarv / Vastuvõttude arv
```

## Lahendatud näide

Osakond lühendab keskmist haiglaravi kestust 6-lt 4,5 päevale tänu paremale väljakirjutamise koordineerimisele, vabastades voodivõimsuse 25% rohkemate patsientide jaoks ilma lisavoodite'ta.

## Seos tarkvaraarendusega

Sarnaneb tsükliajaga [vooniitajates](../flow-metrics/) — kui kaua ülesanne süsteemis algusest lõpetamiseni viibib.

## Lõksud

- **Haiglaravi kestuse lühendamine ilma taasvastuvõttudele avalduvat mõju arvestamata.**
- **Äärmuslike kõrvalekallete poolt moonutatud keskmiste kasutamine.**
