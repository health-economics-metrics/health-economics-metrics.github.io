# Väntelistans påverkan

Väntelistans påverkan mäter hur sparade kliniska timmar eller förbättrad effektivitet omvandlas till faktiskt behandlade extra patienter.

## Varför det är viktigt

Effektivitetsvinster ger bara verkligt värde när de omvandlas till extra genomströmning — annars förblir de teoretiska.

## Matematiken

```
Extra behandlade patienter = Sparade kliniska timmar / Genomsnittlig tid per patientkonsultation
```

## Genomarbetat exempel

Ett effektivitetsprojekt sparar 500 kliniska timmar per månad; vid en genomsnittlig konsultationstid på 20 minuter motsvarar det 1 500 extra behandlade patienter per månad.

## Koppling till mjukvaruutveckling

Liknar att omvandla sparad CI/CD-pipelinetid till faktiskt levererade extra funktioner, snarare än att bara hävda "snabbare byggen".

## Fallgropar

- **Att anta att sparad tid automatiskt återanvänds för extra patienter — se [kassafrigörande kontra icke-kassafrigörande besparingar](../cash-releasing-vs-non-cash-releasing/).**
- **Att ignorera uppdämd efterfrågan som snabbt fyller väntelistan igen.**
