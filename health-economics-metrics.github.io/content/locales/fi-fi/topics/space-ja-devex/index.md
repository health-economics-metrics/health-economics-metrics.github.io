# SPACE ja DevEx

SPACE ja DevEx ovat viitekehyksiä kehittäjien tuottavuuden mittaamiseen **moniulotteisesti**.

## Miksi se on tärkeä

Molemmat viitekehykset sisältävät saman opetuksen, jonka terveysvaikutustutkimus oppi vuosikymmeniä sitten.

## Matematiikka

```
SPACE-sääntö: ≥ 3 ulottuvuutta, ≥ 1 perkeptuaalinen + ≥ 1 järjestelmämittari
```

## Ratkaistu esimerkki

Alustatiimi perustelee DevEx-investoinnin 300 kehittäjälle.

## Yhteys ohjelmistokehitykseen

Tämä dokumentti on *täsmälleen* ohjelmistopuoli; siirto virtaa kohti terveystaloustiedettä.
