# 활성화와 채택

활성화는 신규 사용자가 앱의 핵심 가치를 처음 경험하는 시점을 측정하며, 채택은 대상 인구 중 실제로 서비스를 사용하기 시작하는 비율을 측정합니다.

## 왜 중요한가

낮은 채택률은 훌륭하게 설계된 개입도 인구 수준에서 무의미하게 만듭니다.

## 수식

```
채택률 = 활성 사용자 수 / 대상 인구 × 100%
```

## 계산 예시

원격 혈압 모니터링 프로그램: 대상 인구 10,000명, 활성 사용자 2,400명 = 채택률 24%.
