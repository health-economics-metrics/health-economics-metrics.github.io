# Час практикуючого лікаря

Час практикуючого лікаря слід оцінювати як потужність вузького місця — те, що система може доставити — а не просто як витрати на заробітну плату.

## Чому це важливо

Година заощадженого часу лікаря часто набагато цінніша, ніж передбачає погодинна оплата лікаря, оскільки час лікаря є обмежувальним фактором системної потужності.

## Математика

```
Цінність заощадженого часу = Заощаджені години × тіньова ціна потужності вузького місця
```

## Розібраний приклад

Радіолог заробляє £80/годину, але кожна година заощадженого часу радіолога ефективно уможливлює £300 подальшого потоку пацієнтів через тиск списку очікування.

## Зв'язок з інженерією програмного забезпечення

Подібно до оцінки часу старшого архітектора на основі цінності вузького місця їхніх рішень, а не лише їхньої зарплати.

## Підводні камені

- **Використання лише витрат на заробітну плату для оцінки заощадженого часу.**
- **Надання ролям, які не є вузьким місцем, тієї ж тіньової ціни, що й ролям вузького місця.**
