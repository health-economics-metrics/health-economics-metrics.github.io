# Tasso di Riammissione

Il tasso di riammissione a 30 giorni è la percentuale di pazienti dimessi che tornano come emergenza entro 30 giorni.

## Perché è importante

Una riammissione significa che la prima dimissione non ha retto.

## La matematica

```
Tasso di riammissione = riammissioni di emergenza entro 30 giorni / dimissioni indice × 100
```

## Esempio risolto

Un'app di supporto alla dimissione per insufficienza cardiaca: riammissioni evitate 80 all'anno.

## Collegamento con l'ingegneria del software

La riammissione è il **tasso di fallimento del cambiamento** del sistema sanitario.

- **Manipolazione tramite ri-etichettatura.**
