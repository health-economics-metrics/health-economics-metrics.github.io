# Kostnadseffektivitetsanalys (CEA)

Kostnadseffektivitetsanalys jämför interventioner baserat på kostnad per naturlig utfallsenhet, till exempel räddade liv eller förhindrade fall.

## Varför det är viktigt

CEA låter beslutsfattare jämföra interventioner utan att omvandla allt till monetärt värde, vilket är användbart när monetär värdering är kontroversiell.

## Matematiken

```
CEA-kvot = (Kostnad_A − Kostnad_B) / (Naturliga enheter_A − Naturliga enheter_B)
```

## Genomarbetat exempel

Två screeningprogram jämförda på kostnad per upptäckt fall: program A kostar £50/screenad person och upptäcker 1 av 200; program B kostar £80 och upptäcker 1 av 150.

## Koppling till mjukvaruutveckling

Liknar att jämföra arkitekturer på kostnad per löst supportärende istället för en monetär ROI.

## Fallgropar

- **Att jämföra interventioner med olika naturliga enheter.**
- **Att använda CEA när livskvalitet är det dominerande utfallet (använd CUA istället).**

## Källor

- Drummond MF, et al., Methods for the Economic Evaluation of Health Care Programmes.
- NICE, Guide to the methods of technology appraisal.
