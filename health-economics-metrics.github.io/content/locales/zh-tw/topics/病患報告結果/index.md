# 病患報告結果（PROM、PREM、MCID）

PROM是一類標準化量表工具，由病患自行報告自身的健康狀況（症狀、功能、生活品質）；PREM則記錄的是照護*體驗*本身。**MCID**——最小臨床重要差異——是病患能夠真正感知為有益的最小分數變化：任何聲稱的改善都必須跨過這一門檻。

## 為何重要

PROM是數位健康領域最主要的療效貨幣：應用很少能撼動死亡率，但它們能可信地改變經過驗證的症狀評分。真正重要、且已標準化的量表工具並不多——**PHQ-9**（抑鬱症，0–27分；嚴重程度分界為5/10/15/20）、**GAD-7**（焦慮症，0–21分；分界為5/10/15）、**EQ-5D**（用於[QALY](../品質調整生命年/)計算的效用值）——監管機構、衛生技術評估機構與支付方之所以接受這些量表，正是因為它們能夠跨產品、跨試驗進行比較。MCID正是一道誠實度關卡：PHQ-9的MCID約為5分，GAD-7約為4分，EQ-5D指數通常約為0.03–0.08——在一個大樣本中，一個具有統計顯著性的1.5分PHQ-9變化，*確實真實存在，但在臨床上毫無意義*，任何一位證據評審人都會這樣指出。

## 計算方法

```
PROM計分：按各量表工具自身規則求和（例如PHQ-9 = Σ 9個條目 × 0–3分）

MCID估算方法：
  錨定法：      在自我報告"有所好轉"的病患中觀察分數變化
  分佈法：      ≈ 基線分數標準差(SD) × 0.5（粗略經驗法則）

回應率框架（用於試驗與申報材料）：
  回應者 = 改善幅度 ≥ MCID 的病患（或按PHQ-9慣例取≥50%改善）
  NNT = 1 / (治療組回應率 − 對照組回應率)
  ——參見number-needed-to-treat.md
```

## 實例演算

某抑鬱症支援應用，隨機對照試驗對比等候名單組，為期12周：

```
PHQ-9變化：應用組−6.2分，對照組−2.1分 → 調整後差異−4.1分
MCID檢驗：4.1 < 5 → 均值差異低於MCID；改為報告回應者比例：
  回應者（分數下降≥5分）：應用組48%，對照組22% → 絕對風險降幅26%
  NNT = 1/0.26 ≈ 4——每4名使用者接受治療，即可多獲得1例臨床回應

經濟學橋樑：回應者的EQ-5D獲益為0.06，持續6個月
  = 0.03 QALY；每1,000名使用者：260名額外回應者 × 0.03 = 7.8 QALY
  按NICE閾值折算約為£156,000–£234,000的健康價值
```

在均值差異低於MCID、本會被直接否決的情況下，改用"回應者/NNT"這一框架，反而能夠經受住評審的檢驗。

## 與軟體工程的聯絡

PROM本質上是一個資料採集問題，而軟體恰好處於獨一無二的有利位置來解決它：嵌入應用內的量表工具，能實現紙質問卷從未達到過的完成率與縱向資料密度，從而將日常產品遙測資料轉化為達到衛生技術評估標準的證據（[EQ-5D](../EQ-5D/)只需要五個介面）。工程層面的規則：應*原樣*使用經過驗證的量表工具（改寫措辭會使其失效——且涉及授權許可問題）；應按協議規定的時間點進行測量，而非按參與便利性來安排（只測量活躍使用者會造成存活者偏倚——參見[留存](../留存與流失/)）；並應像對待任何資料模式一樣對量表資料進行版本鎖定——研究進行中途更改措辭，等同於資料損壞。PREM對應的是CSAT/NPS一類的量表工具，同樣的教訓在此適用：只要受眾是支付方，標準化工具就總是勝過自制工具。 關於專門針對工作效率的工具，見 [WPAI](../工作效率與活動受損量表/)。

## 陷阱

- **將低於MCID的統計顯著性，呈現為臨床獲益**——這是該領域中最常見的虛增手法。
- **均值迴歸**：使用者往往在症狀最嚴重時入組；單臂前後對比會嚴重高估效果——對照組是不可或缺的。
- **量表購物**：同時使用PHQ-9、GAD-7和WHO-5三個量表，然後只報告變化最明顯的那一個——應事先登記好主要指標。
- **數位化知情同意調查中的誘導壓力**：引導使用者給出更有利的回答會破壞量表工具本身的有效性（而評審人對這類基礎比率心知肚明）。
