# アクティベーションと普及

アクティベーション率とは、登録者のうち最初の意味のある価値(「アハ」の瞬間 — 最初に記録された測定値、最初に完了したレッスン)に到達する割合のことです。普及は集団版です:*対象となる*人口のうち、とにかく採用する割合です。合わせて、これらは価値のファネルの前の門です:獲得 → 普及 → アクティベーション → [定着](../retention-and-churn/) → アウトカム。

## なぜ重要か

アクティベートされていない利用者は純粋な費用です:獲得の支出、プロビジョニング、サポートの対応 — 臨床的価値はゼロです。ベンチマークは、ヘルスケアソフトウェアのアクティベーションを業界横断の平均*以下*に置きます(あるSaaSベンチマークセットでは、新規利用者のアクティベーションが約24%対約37%;オンボーディングチェックリストの完了率は約20%)。これは、より重いオンボーディング(本人確認、同意、臨床的安全性)を反映しています。普及は集団としての賭け金を伴います:[RE-AIMの枠組み](../reach-and-equity/)では、公衆衛生への影響≈到達範囲×有効性 — 対象人口の3%に採用された優れたアプリは、集団の針を3%分動かします。処方されるデジタル治療薬については、普及のゲートは全国データに見えます:**ドイツのDiGA処方の約81%がアクティベートされます** — 処方され対価が支払われた治療の5件に1件は決して始まりません([ドイツのDiGA早期承認](../diga-fast-track/)を参照)。

## 数式

```
アクティベーション率 = 期間内に主要な行動を完了する利用者数 / 登録者数 × 100
普及率              = 採用者数 / 対象人口 × 100
DTx充足率           = アクティベートされた処方コード数 / 発行された処方数 × 100

ファネル価値モデル:
  対象人口 × 普及率 × アクティベーション率 × 定着で重み付けされた便益 = 集団価値
  — 4つの乗算;最も小さい要因を改善することが通常支配的です
  (ファネルのための制約理論)
```

## 計算例

あるコミッショナーが、対象となる住民80,000人に糖尿病予防アプリを提供します:

```
招待 → 登録:  80,000 → 12,000(普及率15%)
登録 → アクティベート(初回セッション+目標設定、7日): 12,000 → 5,400(45%)
アクティベート → 6か月プログラム完了: 5,400 → 1,600(30%)

プログラムの効果(試験、完了者):0.03QALY+£180の回避された費用
集団価値 = 1,600 × (0.03 × £20,000 + £180) ≈ £125万
対象1人あたりの価値 = £15.6 — すべての対象者が完了した場合の£780に対して。
```

どこに投資すべきか?普及率を倍にする(15→30%)と価値は倍になります;アクティベーションを45→65%に上げると約44%追加されます;どちらも、すでに完了している1,600人のためにプログラム内容をさらに磨くことに勝ります。

## ソフトウェア工学との関連

アクティベーションはファネルの中で最もエンジニアリングで扱いやすい段階です:本人確認の摩擦、同意のフロー、空の状態の設計、初回価値到達までの時間はポリシーではなくコードです(ベンチマークデータにおけるヘルスケアの初回価値到達までの時間の中央値は約1日7時間 — その1時間ごとが離脱のリスクです)。普及は分配システムの問題です:紹介経路への統合(処方の瞬間)、GPが推薦する招待(信頼の移転)、そしてアクセシビリティ(言語、デジタルスキル — [到達範囲と公平性](../reach-and-equity/)を参照)。上記のファネル価値モデルは、両方のためのビジネスケース生成器です:要因を掛け合わせ、制約を見つけ、それが解放する集団価値に対して修正に値段をつけてください。

## 落とし穴

- 臨床的な意味(最初の治療的行動)ではなく**便宜として定義されるアクティベーション**(メール確認済み) — メトリクスを膨らませ、価値連鎖を壊します。
- **普及の分母のごまかし**:「サイトを訪問した人のうち」対、本当に対象となる人口 — コミッショナーは後者を気にかけます。
- **選択効果**:アクティベートしやすい利用者は最も病状が軽く最も貧困でない人々です;ファネルの改善は、平均を改善しながら公平性のギャップを広げることがあります。
