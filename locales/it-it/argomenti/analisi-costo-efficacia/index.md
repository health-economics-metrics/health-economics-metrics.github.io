# Analisi Costo-Efficacia (CEA)

La CEA confronta i costi di interventi alternativi rispetto a un unico risultato misurato in **unità naturali** — anni di vita, casi rilevati, ricoveri evitati.

## Perché è importante

La CEA è il confronto principale quando tutte le opzioni mirano allo stesso risultato.

## La matematica

```
ICER = (Costo_A − Costo_B) / (Effetto_A − Effetto_B)
```

## Esempio risolto

Tre modi per trovare la fibrillazione atriale non diagnosticata in una popolazione di 100.000 persone.

## Collegamento con l'ingegneria del software

La CEA è il modello giusto ogni volta che le opzioni condividono un risultato.

## Insidie

- **Confrontare opzioni con risultati diversi in un'unica CEA.**
