# Kostenminimalisatieanalyse (CMA)

Kostenminimalisatieanalyse kiest de goedkoopste optie nadat is aangetoond dat de vergeleken interventies gelijkwaardige effectiviteit hebben.

## Waarom het ertoe doet

Wanneer effectiviteit al bewezen gelijkwaardig is, is het onnodig om complexe kosteneffectiviteitsberekeningen uit te voeren — kies simpelweg de goedkoopste.

## De wiskunde

```
Kies optie met min(Kosten), gegeven Effecten_A = Effecten_B
```

## Uitgewerkt voorbeeld

Twee generieke medicijnen met bewezen identieke werkzaamheid: kies degene met de laagste inkoopprijs, zonder verdere analyse.

## Verbinding met software-engineering

Vergelijkbaar met het kiezen van de goedkoopste cloudprovider nadat is bevestigd dat beide voldoen aan dezelfde prestatie- en betrouwbaarheidseisen.

## Valkuilen

- **Gelijkwaardigheid aannemen zonder degelijk bewijs.**
- **CMA gebruiken wanneer effecten in werkelijkheid subtiel verschillen.**
