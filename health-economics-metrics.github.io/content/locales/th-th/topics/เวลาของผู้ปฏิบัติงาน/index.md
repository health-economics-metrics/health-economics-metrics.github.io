# เวลาของผู้ปฏิบัติงาน

เวลาของผู้ปฏิบัติงานควรได้รับการประเมินมูลค่าในฐานะความสามารถของคอขวด — สิ่งที่ระบบสามารถส่งมอบได้ — ไม่ใช่เพียงต้นทุนเงินเดือน

## ทำไมจึงสำคัญ

ชั่วโมงแพทย์ที่ประหยัดได้มักมีค่ามากกว่าอัตราค่าจ้างรายชั่วโมงของแพทย์มาก เนื่องจากเวลาของแพทย์เป็นข้อจำกัดที่ผูกมัดความสามารถของทั้งระบบ

## คณิตศาสตร์

```
มูลค่าของเวลาที่ประหยัดได้ = ชั่วโมงที่ประหยัดได้ × ราคาเงาของความสามารถของคอขวด
```

## ตัวอย่างที่คำนวณแล้ว

นักรังสีวิทยาได้รับเงินเดือน £80/ชั่วโมง แต่ทุกชั่วโมงนักรังสีวิทยาที่ประหยัดได้ช่วยให้มีความจุผู้ป่วยในขั้นตอนถัดไปมูลค่า £300 เนื่องจากแรงกดดันของบัญชีรายชื่อรอ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการประเมินมูลค่าเวลาของสถาปนิกอาวุโสตามมูลค่าคอขวดของการตัดสินใจของพวกเขา ไม่ใช่แค่เงินเดือน

## ข้อผิดพลาดที่พบบ่อย

- **การใช้เฉพาะต้นทุนเงินเดือนในการประเมินมูลค่าเวลาที่ประหยัดได้**
- **การให้ราคาเงาเดียวกันกับบทบาทที่ไม่ใช่คอขวดเหมือนกับบทบาทที่เป็นคอขวด**
