# Mitteilmumise määr (DNA)

Mitteilmumise määr mõõdab broneeritud visiitide osakaalu, kus patsient ei ilmu kohale ilma tühistamata.

## Miks see on oluline

Vahelejäetud visiidid on ehk puhtaim raiskamisnäitaja tervishoius: täielikult broneeritud võimsus, mis annab nullväärtuse.

## Matemaatika

```
DNA määr = Vahelejäetud visiitide arv / Broneeritud visiitide koguarv × 100%
```

## Lahendatud näide

Ambulatoorne kliinik 10 000 visiidiga aastas ja 8% DNA määraga kaotab 800 visiidikohta, igaüks hinnatud täiskliinilise omahinna järgi.

## Seos tarkvaraarendusega

Sarnaneb pilveplaneerimises broneeritud, kuid kasutamata arvutusvõimsusega — täielikult makstud, null tarnitud väärtust.

## Lõksud

- **DNA kulude hindamine keskmise, mitte piirkulu järgi.**
- **Meeldetuletussüsteemide rakendamine ilma aluseks olevaid juurdepääsutõkkeid lahendamata.**
