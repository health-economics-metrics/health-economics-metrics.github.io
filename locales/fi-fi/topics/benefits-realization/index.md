# Hyötyjen toteutuminen

Hyötyjen toteutuminen on kurinalaisuutta seurata ja varmistaa, toimittiko projekti todella luvatut hyödyt.

## Miksi se on tärkeä

Liiketoimintatapaus lupaa hyötyjä, mutta ilman seurantaa et koskaan tiedä, toteutuivatko ne.

## Matematiikka

```
Hyötyjen toteutumisaste = todelliset hyödyt / suunnitellut hyödyt × 100 %
```

## Ratkaistu esimerkki

Digitaalinen triage-työkalu: suunniteltu säästö £500 000/vuosi; 12 kuukauden jälkeen todellinen £320 000 = 64 % toteutuminen.
