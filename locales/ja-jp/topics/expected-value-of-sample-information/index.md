# 標本情報の期待価値(EVSI)

EVSIは、*特定の提案された研究*(特定のデザイン、特定の標本サイズ)の価値を、実施前に評価したものです。あらゆる不確実性の完全な解消を価格づける[EVPI](../expected-value-of-perfect-information/)とは対照的です。EVSIは、研究資金提供者が実際に直面する問いに答えます。「*この*規模の*この*試験は、その費用に見合うか」という問いです。

## なぜ重要か

EVPIは、どのような研究にも付けうる価値の上限を示しますが、目の前の試験が基準を満たすかどうかは教えてくれません。50人の予備試験と500人の決定的な試験のどちらかを選ぶ国の研究資金提供者は、全知の価値だけでなく、*個々の具体的なデザイン*にどれだけの価値があるかを知る必要があります。EVSIはその数値を提供し、標本サイズに応じて変化するため、資金提供者は当て推量ではなく、期待純便益を最大化する標本サイズを見つけられます。

これは、EVSIが常にEVPI以下である理由でもあります。有限の標本は不確実性を部分的にしか解消できず、完全情報より価値が高く見える研究は、実際の結果ではなく計算が誤っているしるしです。

## 数式

```
一般形:
EVSI(n) = E_データ[ max_d E_θ|データ[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (入れ子の期待値: 外側は起こりうる研究結果にわたり、内側はその結果を見た後の
  θに関する事後的な信念にわたる — 通常は確率的感度分析のサンプルに対する
  入れ子のモンテカルロ法/ベイズ更新で推定する)

閉形式の正規近似(単一の不確実なパラメータ、共役な正規-正規モデル —
標準的な近道であり、すべてのモデルで正確とは限らない):
EVSI(n) = EVPI × n / (n + n0)

n  = 提案された研究の標本サイズ
n0 = 「事前分布と等価な標本サイズ」 — 現在の事前分布と同じ情報量を持つ
     仮想の標本のサイズで、データ分散と事前分散の比から導かれる
ENBS(n) = EVSI(n) − コスト(n)
母集団EVSI = 意思決定あたりEVSI × 影響を受ける意思決定の数
```

一般形が入れ子の期待値なのは、研究の将来の結果自体が不確実だからです。研究が生み出しうるあらゆるデータセットにわたって平均をとり、それぞれについて更新された(事後的な)信念のもとでの最善の意思決定を計算し直す必要があります。閉形式の正規近似は、その計算コストを単一の比と引き換えにするもので、不確実なパラメータとデータが(ほぼ)正規分布で共役である場合に有効です。これは便宜であって普遍の法則ではありません。その仮定が成り立たない場合の汎用的な方法は、完全な入れ子のモンテカルロ法です。EVSIを推定する際の元になるPSAのサンプルについては、[確率的感度分析](../probabilistic-sensitivity-analysis/)を参照してください。

## 計算例

[EVPI](../expected-value-of-perfect-information/)の計算例(5,000人の臨床医にAI文書作成アシスタントを展開し、EVPIが£1.2Mだったもの)を引き継ぎ、同じEVPIをここでは整数のポンドで表します。**EVPI = £1,200,000**。

50人の臨床医による予備試験が提案されています。事前の信念の分散と予備試験の測定精度の比から、事前分布と等価な標本サイズは`n0 = 75`になります。

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

予備試験の費用は£120,000です。

```
ENBS = EVSI − コスト = 480,000 − 120,000 = £360,000
```

明確に正のENBSです。予備試験に資金を出すべきです。同じ調達判断が3つの似た地域トラストで繰り返される場合、予備試験の価値は拡大します。

```
母集団EVSI = 480,000 × 3 = £1,440,000
```

## ソフトウェア工学との関連

EVSIは、パイロットやA/Bテストを実施するかどうかだけでなく、それを*どれくらいの規模*にすべきかを選ぶ経済学です。

- **投資判断としての標本サイズ。** ユーザー50人のベータ版と5,000人への段階的ロールアウトは、異なるEVSIと異なるコストを持つ別々の「研究」です。EVSIは、「データは多いほど良い」というデフォルトに頼らず、同じ基準でそれらを比較させてくれます。
- **発注の判断基準はEVSI単独ではなくENBSです。** EVSIが高くてもコストがその大半を食いつぶす研究は弱い提案です。判断ルールは標本調査の期待純便益であり、ビジネスケースが便益だけを報告せず便益からコストを差し引くのと同じです。
- **収穫逓減が明示的になります。** EVSI(n)は`n/(n+n0)`で増加するため、パイロットの規模を2倍にしても価値は決して2倍になりません。大きな実験ほど限界的な情報価値が逓減するというエンジニアの直感を、形式化したものです。

## 落とし穴

- **正規近似をその前提の外で使うこと。** これは、ほぼ共役な単一パラメータの不確実性にしか当てはまりません。本当に非線形、あるいは複数パラメータの意思決定モデルには、この近道ではなく完全な入れ子のモンテカルロ法が必要です。
- **EVSIを現金コストだけと比較すること。** EVSIは、研究自体の意思決定の遅延コスト([遅延コスト](../cost-of-delay/)を参照)を含む、研究の*全体*の費用と比べる必要があり、研究の請求書だけではありません。
- **EVSI > EVPIを実際の発見として扱うこと。** EVSIは構造上、EVPIを超えることはありえません。そうなる計算はモデルのバグであり、発見ではありません。
