# Analisi dell'Impatto sul Bilancio (BIA)

La BIA stima cosa fa l'adozione di un intervento al **bilancio** di uno specifico pagatore nei prossimi 1–5 anni.

## Perché è importante

La domanda del direttore finanziario non è mai "qual è l'ICER?" — ma "cosa fa al bilancio dell'anno prossimo?"

## La matematica

```
BI_anno_t = Costo_scenario_nuovo(t) − Costo_scenario_attuale(t)
```

## Esempio risolto

Un pagatore che copre 2 milioni di persone considera una terapia digitale a £300/paziente/anno.

## Collegamento con l'ingegneria del software

La BIA è il complemento perfetto orientato al CFO per un'affermazione di ROI per postazione.
