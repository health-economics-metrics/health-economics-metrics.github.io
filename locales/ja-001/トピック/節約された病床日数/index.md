# 節約された病床日数

病床日とは、1人の患者が1つの病院の病床を1日占有することです。「節約された病床日数」 — 早期退院、入院回避、あるいはバーチャル病棟を通じたもの — はNHSのデジタルビジネスケースの主力の便益であり、最も過大評価されやすいものです。

## なぜ重要か

病床は急性期ケアの拘束制約です:病床が埋まると、選択的手術がキャンセルされ、救急車が列を作り、救急部門が滞留します。したがって、病床日を解放する介入には実際の価値がありますが、*どのような種類*の価値かは、解放された病床がその後どうなるかに完全に依存します。財務担当者は、素朴な病床日の主張を大幅に割り引くことを学んでいます;この計算を正しく行うことは信頼性のテストです。

## 数式

```
節約された病床日数 = 影響を受けた患者数 × Δ在院日数(または回避された入院数 × 平均在院日数)

価値は解放された容量の使われ方に依存する:
  選択的な活動で再び埋められる → 価値 = 活動収入または待機リストの便益
  病棟が閉鎖/縮小される       → 価値 = 解放された人件費+運営費(現金)
  余裕として吸収される        → 価値 ≈ 限界(ホテル)費用のみ、£50〜£150/日
```

急性期病床日の全額配賦済み平均費用はしばしば£400以上と引用されます(National Cost Collectionでは歴史的に超過病床日で約£350) — しかし[限界費用と平均費用](../限界費用と平均費用/)を参照してください:平均が節約額になることはほとんどありません。

## 計算例

遠隔モニタリングの「バーチャル病棟」により、年間600人の患者が2日早く帰宅できるようになります:1,200病床日の節約です。

- **素朴な主張**:1,200 × £400 = £480,000。病棟が閉鎖されない限り誤りです。
- **正直な主張**:トラストは、その病床を選択的な整形外科の患者で埋め戻します。1,200病床日 ÷ 平均3日の在院 = 出来高払い制度のもとで1件あたり約£6,000の収入となる400件の追加の選択的入院 = **£240万の追加の資金提供された活動**(それらの患者を治療する限界費用を差し引く)、*加えて*、待機リストから外れる400人の患者。バーチャル病棟の運用費(£350,000)はこれと相殺されます。

*再利用される*解放された容量は、しばしば素朴な現金の主張よりも価値がありますが — それは異なる種類の価値であり、そのようにラベル付けされなければなりません([現金化可能な節約と非現金化節約](../現金化可能な節約と非現金化節約/))。

## ソフトウェア工学との関連

「節約されたサーバー日数」はまったく同じように振る舞います。常時稼働環境の廃止は、インスタンスが実際に終了されるか予約が失効した場合にのみ現金を解放します;プールに戻って吸収された容量は、その限界費用(コミット済みの支出ではほぼゼロ)の価値しかありません。並行する規律:主張されるすべての節約について、その*仕組み*を名指ししてください — 終了されたのか、価値ある作業で埋め戻されたのか、それとも蒸発したのか。病院の在院日数を減らすソフトウェア(退院調整、遠隔モニタリング、診断のターンアラウンド)は、これら3つのシナリオすべてをモデル化し、病棟ごとにトラストに選ばせるべきです。

## 落とし穴

- 限界的な容量の**平均費用による評価** — 典型的な誤りです。
- **二重計上**:同じ解放された病床から、節約された病床日数*と*回避された入院*と*待機リストの削減を数えること。
- **節約された日数が高価な日数であると想定すること**:在院の終わり近くで節約される日は、最も低い重症度の最も安価な日です。
