# กรอบมาตรฐานหลักฐานของ NICE

กรอบมาตรฐานหลักฐานของ NICE ให้แนวทางที่มีโครงสร้างสำหรับเทคโนโลยีสุขภาพดิจิทัลเกี่ยวกับระดับหลักฐานที่จำเป็นสำหรับระดับความเสี่ยงและกรณีการใช้งานที่แตกต่างกัน

## ทำไมจึงสำคัญ

กรอบนี้แยกแยะข้อกำหนดหลักฐานตามระดับความเสี่ยง — แอปสุขภาวะความเสี่ยงต่ำต้องการหลักฐานน้อยกว่าเครื่องมือสนับสนุนการตัดสินใจทางคลินิกความเสี่ยงสูง ช่วยประหยัดเวลาและเงินของนักพัฒนา

## คณิตศาสตร์

ไม่มีสูตรที่เป็นทางการ; กรอบใช้หมวดหมู่ระดับหลักฐาน (ระดับ 1–3b) ตามการจำแนกประเภทฟังก์ชัน

## ตัวอย่างที่คำนวณแล้ว

แอปดูแลตนเองด้านสุขภาพจิตถูกจัดอยู่ในระดับ 2 ต้องการการศึกษาก่อน-หลังอย่างดีที่สุด ในขณะที่แอปวินิจฉัยโรคในระดับ 3b ต้องการการทดลองแบบสุ่มที่มีกลุ่มควบคุม

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับกลยุทธ์การทดสอบตามความเสี่ยง — เส้นทางวิกฤตได้รับการครอบคลุมการทดสอบอย่างละเอียด ในขณะที่ฟีเจอร์ความเสี่ยงต่ำได้รับการตรวจสอบที่เบากว่า

## ข้อผิดพลาดที่พบบ่อย

- **การจัดประเภทผิดระดับเพื่อหลีกเลี่ยงข้อกำหนดหลักฐานที่เข้มงวดกว่า**
- **การปฏิบัติต่อกรอบนี้เป็นประตูครั้งเดียวแทนที่จะเป็นกระบวนการรวบรวมหลักฐานอย่างต่อเนื่อง**
