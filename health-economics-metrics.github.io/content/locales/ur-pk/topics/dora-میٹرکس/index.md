# DORA میٹرکس

DORA میٹرکس سافٹ ویئر ڈیلیوری کی کارکردگی کے چار پیمانے ہیں — ڈیپلائمنٹ کی تعدد، تبدیلی کے لیے لیڈ ٹائم، تبدیلی کی ناکامی کی شرح، اور بحالی کا وقت۔

## یہ کیوں اہم ہے

DORA کی ایک دہائی کی تحقیق ان میٹرکس کو تنظیمی کارکردگی سے جوڑتی ہے۔

## ریاضی

```
لیڈ ٹائم = t(ڈیپلائے) − t(کمٹ)، درمیانی
```

## حل شدہ مثال

ایک ٹرسٹ کی مریض-بہاؤ سافٹ ویئر ٹیم، پہلے/بعد: ڈیپلائے ماہانہ → ہفتہ وار۔
