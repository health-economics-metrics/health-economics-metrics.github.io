# DORA-mått

DORA-mått är fyra mått på mjukvaruleveransprestanda — driftsättningsfrekvens, ledtid för ändringar, felfrekvens vid förändring och återställningstid.

## Varför det är viktigt

Tio års DORA-forskning kopplar dessa mått till organisatorisk prestanda.

## Matematiken

```
Ledtid = t(driftsättning) − t(commit), median
```

## Genomarbetat exempel

Ett teams mjukvara för patientflöde, före/efter: driftsättningar från månatliga → veckovisa.

## Koppling till mjukvaruutveckling

Detta är *precis* mjukvarusidan.

## Fallgropar

- **Måttmanipulation.**
