# Kaugjälgimise majandus

Kaugjälgimise majandus hindab kulusid ja kasu patsientide terviseandmete jälgimisel kodus, mitte näost-näkku kliinilistel visiitidel.

## Miks see on oluline

Kaugjälgimine võib vähendada kliiniliste visiitide vajadust ja tuvastada halvenemist varem, kuid see nõuab investeeringuid tehnoloogiasse ja personali andmete ülevaatamiseks.

## Matemaatika

```
Netosääst = (Väldatud visiidid × visiidi kulu) + (Väldatud erakorralised vastuvõtud × vastuvõtu kulu) − jälgimisprogrammi kulud
```

## Lahendatud näide

Südamepuudulikkuse kaugjälgimise programm 500 patsiendiga maksab £300/patsient/aastas, kuid väldib 100 erakorralist vastuvõttu aastas hinnaga £3000 igaüks: kogukasu £300 000 versus kogukulu £150 000, netokasu £150 000.

## Seos tarkvaraarendusega

Otseselt analoogne [kauglogimise ja seirega](../dora-metrics/) tarkvarasüsteemides — pidev jälgimine võimaldab varajast probleemide tuvastamist enne, kui need eskaleeruvad.

## Lõksud

- **Jälgimisandmete ülevaatamiseks vajaliku personaliaja alahindamine.**
- **Eeldus, et kõik patsiendid saavad ja soovivad kasutada kaugjälgimistehnoloogiat.**
