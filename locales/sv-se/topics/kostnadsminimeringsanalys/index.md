# Kostnadsminimeringsanalys (CMA)

Kostnadsminimeringsanalys väljer det billigaste alternativet efter att det har bevisats att de jämförda interventionerna har likvärdig effektivitet.

## Varför det är viktigt

När effektiviteten redan har bevisats vara likvärdig är det onödigt att utföra komplexa kostnadseffektivitetsberäkningar — välj bara det billigaste.

## Matematiken

```
Välj alternativ med min(Kostnad), givet Effekt_A = Effekt_B
```

## Genomarbetat exempel

Två generiska läkemedel med bevisat identisk effekt: välj det med lägst inköpspris, utan ytterligare analys.

## Koppling till mjukvaruutveckling

Liknar att välja den billigaste molnleverantören efter att ha bekräftat att båda uppfyller samma prestanda- och tillförlitlighetskrav.

## Fallgropar

- **Att anta likvärdighet utan gedigna bevis.**
- **Att använda CMA när effekterna faktiskt skiljer sig subtilt.**
