# Коэффициент неявки (DNA)

Коэффициент неявки (DNA) — это процент забронированных приёмов, на которые пациент ни приходит, ни отменяет. Клиницист, кабинет и слот оплачены; ничего не происходит. Это самая чистая метрика потерь в здравоохранении — и одна из наиболее поддающихся исправлению с помощью ПО.

## Почему это важно

Данные NHS England (2019): пропущенные приёмы у семейного врача превышают 15 миллионов в год по ~£30 каждый — более **£216 млн/год** — а неявки на амбулаторные приёмы в больницах составляют ~8 млн/год (~6,4% приёмов) при среднем ~**£160** за пропущенный слот. Поскольку предельная стоимость напоминания составляет копейки, а восстановленная ценность — это полностью укомплектованный персоналом клинический слот, сокращение DNA имеет одну из лучших арифметик ROI в цифровом здравоохранении, поэтому SMS-напоминания, лёгкое перепланирование и предиктивное перебронирование были среди первых доказанных побед цифрового здравоохранения.

## Расчёт

```
Коэффициент DNA = DNA / забронированные приёмы × 100

Ценность сокращения = приёмы × Δкоэффициент DNA × ценность на восстановленный слот

ценность на восстановленный слот: слот перезаполнен (ценность деятельности / сокращение
листа ожидания) или нет (время персонала частично повторно используемо) — механизм
важен, как в bed-days-saved.md.
```

## Разобранный пример

Амбулаторное отделение: 200 000 приёмов/год, коэффициент DNA 8%. Служба напоминаний-плюс-перепланирования (SMS с перепланированием в одно касание, информацией о транспорте, доступными форматами) снижает DNA до 5,5%.

```
Восстановленные слоты = 200 000 × 0,025 = 5000/год
Перезаполнены из листа ожидания по средней амбулаторной ценности ~£160:
  5000 × £160 = £800 000/год восстановленной деятельности
Стоимость услуги: 200 000 × £0,40 = £80 000/год

Отдача ≈ 10:1, плюс 5000 пациентов из листа ожидания принято раньше
(см. waiting-list-impact.md и referral-to-treatment.md).
```

Размер эффекта (2,5 пункта) реалистичен: РКИ напоминаний последовательно показывают относительное снижение DNA на 25-40%.

## Связь с программной инженерией

- **Это проблема систем планирования**: напоминания, самообслуживание перепланирования, автоматическое заполнение листа ожидания из отмен и модели предсказания неявки, которые управляют целевым двойным бронированием. Каждая из них — это обычная программная инженерия с необычно чётким экономическим кейсом.
- **Инженерный аналог**: неявки для зарезервированной мощности — забронированные-но-неактивные слоты CI, зарезервированная облачная мощность, переговорные комнаты, комиссии для собеседований. Экономика переносится: дешёвый автоматизированный толчок (или автоматическое высвобождение неиспользуемых резерваций) восстанавливает дорогую зафиксированную мощность.
- **Предварительный взгляд на этику предсказания**: модели неявки, обученные на данных посещаемости, кодируют обездоленность и барьеры доступа; их использование для *понижения приоритета* вероятных неявившихся усиливает неравенство, использование для *поддержки* посещаемости (помощь с транспортом, телефонные альтернативы) снижает его. См. [охват и равенство](../охват-и-справедливость/).

## Подводные камни

- **Двойной учёт отменённого-и-перепланированного как восстановленной ценности.**
- **Оценка восстановленных слотов, которые не перезаполнены** — пустой слот с отправленным напоминанием всё ещё пуст.
- **Погоня за DNA до нуля**: последние пункты DNA — это пациенты, сталкивающиеся с реальными барьерами; карательные подходы (выписка после N DNA) сокращают метрику, отказываясь от пациентов.
