# Ootenimekirja mõju

Ootenimekirja mõju mõõdab, kuidas säästetud kliinilised tunnid või paranenud tõhusus muutuvad tegelikult raviks vastuvõetud lisapatsientideks.

## Miks see on oluline

Tõhususekasud annavad tegelikku väärtust ainult siis, kui need muutuvad lisapropustvõimeks — vastasel juhul jäävad need teoreetiliseks.

## Matemaatika

```
Lisaravitud patsiendid = Säästetud kliinilised tunnid / Keskmine aeg patsiendikonsultatsiooni kohta
```

## Lahendatud näide

Tõhususeprojekt säästab 500 kliinilist tundi kuus; keskmise 20-minutilise konsultatsiooniajaga vastab see 1500 lisaravitud patsiendile kuus.

## Seos tarkvaraarendusega

Sarnaneb säästetud CI/CD torustikuaja muutmisega tegelikult tarnitud lisafunktsioonideks, mitte lihtsalt "kiiremate ehituste" väitmisega.

## Lõksud

- **Eeldus, et säästetud aeg kasutatakse automaatselt uuesti lisapatsientidele — vt [raha vabastavad versus mitte-raha-vabastavad säästud](../raha-vabastavad-versus-mitte-raha-vabastavad-säästud/).**
- **Kuhjunud nõudluse eiramine, mis täidab ootenimekirja kiiresti uuesti.**
