# EQ-5D

EQ-5Dは、健康関連の生活の質を測定するための、EuroQolグループによる標準化された質問票です。これは、ほとんどの[QALY](../quality-adjusted-life-year/)計算の中にある効用の重みを生み出す測定手法です — NICEの基準ケースは、これを成人向けの優先測定手法として指定しています。

## なぜ重要か

QALYを主張したいデジタルヘルス製品は、検証済みの測定手法から効用を得る必要があり、EQ-5Dはイギリスやヨーロッパのほとんどでデフォルトです。アプリに組み込めるほど短く(5つの質問+視覚的な尺度)、これはつまり、ソフトウェア製品が通常の利用の副産物として、HTAグレードのアウトカムデータを収集できることを意味します — 専用の研究が必要な医薬品に対する構造的な優位性です。

## 数式

EQ-5D-5Lは、**5つの次元**(移動の程度、身の回りの管理、普段の活動、痛み/不快感、不安/ふさぎ込み)それぞれについて1つの質問を尋ね、それぞれ**5段階**(問題なし…極度の問題)で回答し、さらに0〜100の視覚アナログ尺度(EQ VAS)を伴います。

```
健康状態 = 5桁のプロファイル、例:"21221"
効用指数 = 価値セット(プロファイル)

価値セットは国ごとに異なり、一般市民を対象とした
タイムトレードオフ/離散選択調査から導出される。
基準点:1 = 完全な健康、0 = 死亡;死よりも悪い状態は負
(英国の3L価値セットの下限:−0.594)。
```

QALYの計算はその後、「期間 × 効用」として進みます。

## 計算例

ある筋骨格系リハビリアプリが、1,000人の完了利用者について、登録時と6か月後にEQ-5D-5Lを測定します。

```
ベースラインの平均効用: 0.62
6か月後の平均効用:      0.71
1年間持続すると仮定した獲得分: (0.71 − 0.62) × 1.0 = 利用者1人あたり0.09QALY
```

対照群の変化0.03(自然回復)と比較すると、帰属できる獲得は利用者1人あたり0.06QALYです。£20,000〜£30,000/QALYで金銭化すると:**完了した利用者1人あたり£1,200〜£1,800の健康価値** — この数値が、支払者とのアプリの価格交渉の基準となります。(EQ-5D指数の最小臨床的に重要な差は一般に0.03〜0.08の範囲にあるため、0.06はもっともらしいですが、対照群との比較をクリアしなければなりません;[患者報告アウトカム](../patient-reported-outcomes/)を参照してください。)

## ソフトウェア工学との関連

- **計測を組み込んでください。** 登録時とフォローアップ間隔でのEQ-5Dは、数画面のUIにすぎません;見返りはHTAグレードの証拠です。EuroQolからライセンスを取得してください(必須で、一部の用途では無料です)。
- 展開先の国に応じて**正しい価値セットを使ってください** — 同じ回答でも、英国、ドイツ、日本で異なるスコアになります。
- **設計上の教訓**:EQ-5Dは、小さな標準化された調査に公表されたスコアリング関数を組み合わせることで、比較可能な単一の指数が得られることを示しています。それは、信頼できる開発者体験指数にも当てはまるパターンです — 標準化された測定手法、公表された重み、その場しのぎの感覚ではなく。[SPACEとDevEx](../space-and-devex/)を参照してください。

## 落とし穴

- **比較対照なしの前後比較** — 平均への回帰と自然回復が、素朴な獲得量を過大に見せます。
- **生存者バイアス**:関与を続けた利用者だけを測定すること([定着と離脱](../retention-and-churn/)を参照)。
- 研究間で**3Lバージョンと5Lバージョン、または価値セットを混在させること** — 体系的に異なる数値になります。
- 軽度な影響を受けた集団での**天井効果**:多くの利用者がベースラインで1.0近いスコアとなり、獲得を示す余地が残りません。
- **価値セットをそれ自体で正当なものとして扱うこと**:価値セットが返す効用の数値そのものが、タイムトレードオフ(または関連する選択に基づく)調査を通じて一般市民から引き出されたものです。
- **価値セットを自己正当化的なものとして扱うこと**: 価値セットが返す効用値自体が、タイムトレードオフ(または関連する選択ベースの)調査を通じて一般市民から導出されたものです。その方法については[タイムトレードオフ(TTO)による効用値の導出](../time-trade-off-utility/)を参照してください。
