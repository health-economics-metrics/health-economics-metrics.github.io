# جرمنی کا DiGA فاسٹ ٹریک

DiGA جرمنی کا قانونی "نسخے پر ایپس" کا راستہ ہے — دنیا کا پہلا قومی نظام جہاں ڈاکٹر منظور شدہ صحت کی ایپس تجویز کرتے ہیں۔

## یہ کیوں اہم ہے

DiGA نے اس سوال کا جواب دیا جو ہر ڈیجیٹل صحت کمپنی پوچھتی ہے — "اصل میں ادائیگی کون کرے گا؟"

## ریاضی

```
آمدنی = نسخے × فعال کرنے کی شرح × فی نسخہ مدت قیمت
```

## حل شدہ مثال

ایک ڈپریشن-انتظام ایپ €450/سہ ماہی پر عارضی طور پر درج ہے: سال 1 میں ≈€7.3M آمدنی۔

DiGA کا نمونہ انجینئرنگ-ٹول حکمرانی کے لیے براہ راست کاپی کرنے کے قابل ہے۔
