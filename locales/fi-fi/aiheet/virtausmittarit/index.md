# Virtausmittarit

Virtausmittarit mittaavat, kuinka työ liikkuu toimitusjärjestelmän läpi: sykliaika, läpimenoaika, läpimeno ja keskeneräinen työ (WIP).

## Miksi se on tärkeä

Suurin osa toimitusajasta on odottamista, ei työtä.

## Matematiikka

```
Littlen laki: keskimääräinen WIP = läpimeno × keskimääräinen sykliaika
```

## Ratkaistu esimerkki

Tiimillä on 40 keskeneräistä kohdetta: WIP:n vähentäminen 15:een palauttaa sykliajan **1,5 viikkoon**.

## Yhteys ohjelmistokehitykseen

Virtausmittarit ovat toimitustekniikan ja terveydenhuollon toiminnan jaettu kieli.
