# 재원일수(LOS)

재원일수는 입원부터 퇴원까지의 일수입니다.

## 왜 중요한가

LOS는 급성기 병원 경제학의 거의 모든 것을 지배합니다: 병상 용량, 선택적 처리량, 인력.

## 수식

```
LOS(에피소드당) = 퇴원일 − 입원일
평균 LOS = 점유된 병상일 / 퇴원 수
```

## 계산 예시

한 트러스트가 평균 LOS 6.0일로 하루 40명의 응급 내과 환자를 입원시킵니다: 240개 병상이 영구적으로 점유됩니다.

## 소프트웨어 공학과의 연관성

LOS는 병원의 사이클 타임입니다.
