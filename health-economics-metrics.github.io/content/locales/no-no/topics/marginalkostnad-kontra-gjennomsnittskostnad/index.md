# Marginalkostnad kontra gjennomsnittskostnad

Marginalkostnad er kostnaden for én ekstra enhet; gjennomsnittskostnad er totalkostnaden delt på antall enheter. De er sjelden like.

## Hvorfor det er viktig

Besparelsespåstander basert på gjennomsnittskostnad overvurderer nesten alltid den reelle besparelsen, fordi faste kostnader ikke forsvinner når volumet minker.

## Matematikken

```
Marginalkostnad = ΔTotalkostnad / ΔMengde
Gjennomsnittskostnad = Totalkostnad / Mengde
```

## Gjennomarbeidet eksempel

En sykehusseng har en gjennomsnittskostnad på £400/dag (inkludert overhead), men å frigjøre én seng sparer bare rundt £150/dag i faktisk unngåelige kostnader.

## Kobling til programvareutvikling

Ligner på skyinfrastruktur: å skalere ned én instans sparer marginalkostnaden for beregning, ikke gjennomsnittskostnaden per bruker inkludert faste plattformkostnader.

## Fallgruver

- **Å bruke gjennomsnittskostnad for å estimere besparelser fra småskala endringer.**
- **Å behandle faste kostnader som variable.**
