# জার্মানির DiGA দ্রুত-পথ

DiGA (Digitale Gesundheitsanwendungen) হলো জার্মানির সংবিধিবদ্ধ "প্রেসক্রিপশনে অ্যাপ" পথ — বিশ্বের প্রথম জাতীয় ব্যবস্থা যেখানে ডাক্তাররা অনুমোদিত স্বাস্থ্য অ্যাপ প্রেসক্রাইব করেন এবং সংবিধিবদ্ধ বীমা তা পরিশোধ করতে বাধ্য।

## কেন এটি গুরুত্বপূর্ণ

DiGA আইন (DVG, ২০১৯) দিয়ে সেই প্রশ্নের উত্তর দিয়েছে যা প্রতিটি ডিজিটাল স্বাস্থ্য কোম্পানি জিজ্ঞাসা করে — "প্রকৃতপক্ষে কে পরিশোধ করবে?" নকশাটি উল্লেখযোগ্য: **দ্রুত সিদ্ধান্ত** (৩ মাস), **সাময়িক তালিকাভুক্তি** (প্রমাণ তৈরি করার সময় ১২ মাস), **প্রমাণের সময়সীমা** (একটি তুলনামূলক গবেষণা দিয়ে "ইতিবাচক স্বাস্থ্যসেবা প্রভাব" প্রমাণ করুন বা তালিকা থেকে বাদ দেওয়া হয়)।

## গণিত

```
রাজস্ব = প্রেসক্রিপশন × অ্যাক্টিভেশন হার × প্রতি প্রেসক্রিপশন সময়কাল মূল্য
প্রমাণ ব্যয় = ১২-মাসের উইন্ডোর মধ্যে মূল RCT (সাধারণত €1M–3M)
```

## সমাধানকৃত উদাহরণ

একটি বিষণ্নতা-ব্যবস্থাপনা অ্যাপ প্রতি চতুর্থাংশ €৪৫০-এ সাময়িকভাবে তালিকাভুক্ত হয়:

```
বছর ১: 20,000 প্রেসক্রিপশন × 81% অ্যাক্টিভেশন × €450 ≈ €7.3M রাজস্ব
RCT ব্যয়: €2M, সমান্তরালে চলমান
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

DiGA-র প্যাটার্ন — **পূর্ব-নিবন্ধিত সাফল্য সূচকসহ সাময়িক গ্রহণ এবং একটি স্বয়ংক্রিয় সানসেট** — প্রকৌশল-টুল গভর্নেন্সের জন্য সরাসরি অনুলিপিযোগ্য।

## ঝুঁকিপূর্ণ দিক

- **তালিকাভুক্তিকে সমাপ্তি রেখা হিসেবে বিবেচনা করা** — প্রেসক্রিপশনের জন্য প্রেসক্রাইবারের বিশ্বাস প্রয়োজন।
- রাজস্ব বছরে অর্থ সাশ্রয়ের জন্য **মূল গবেষণাকে কম শক্তিশালী করা**।
- **প্রদানকারী ছাড়া মডেল স্থানান্তর করা**।
