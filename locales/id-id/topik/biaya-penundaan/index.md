# Biaya Penundaan (CoD)

Biaya penundaan adalah nilai ekonomi yang hilang per unit waktu ketika suatu fitur, produk, atau layanan *tidak* dikirimkan.

## Mengapa ini penting

Aturan Reinertsen: "Jika Anda hanya mengukur satu hal, ukurlah Biaya Penundaan."

## Matematika

```
CoD = manfaat yang hilang per unit waktu saat belum dikirimkan (£/minggu atau QALY/minggu)
```

## Contoh yang diselesaikan

**Operasional**: perangkat lunak menghemat £200 per pasien dalam suatu jalur; CoD = £10.000/minggu.

## Hubungan dengan rekayasa perangkat lunak

CoD adalah metrik yang membuat [waktu tunggu DORA](../metrik-dora/) dapat dibaca secara finansial.
