# Omkostningseffektivitetsanalyse (CEA)

Omkostningseffektivitetsanalyse sammenligner interventioner baseret på omkostning pr. naturlig udfaldsenhed, såsom reddede liv eller undgåede tilfælde.

## Hvorfor det er vigtigt

CEA lader beslutningstagere sammenligne interventioner uden at omregne alt til pengeværdi, hvilket er nyttigt, når pengeværdisætning er kontroversiel.

## Matematikken

```
CEA-ratio = (Omkostning_A − Omkostning_B) / (Naturlige enheder_A − Naturlige enheder_B)
```

## Gennemarbejdet eksempel

To screeningprogrammer sammenlignet på omkostning pr. opdaget tilfælde: program A koster £50/screenet person og opdager 1 ud af 200; program B koster £80 og opdager 1 ud af 150.

## Forbindelse til softwareudvikling

Ligner det at sammenligne arkitekturer på omkostning pr. løst supportsag i stedet for et pengemæssigt ROI.

## Faldgruber

- **At sammenligne interventioner med forskellige naturlige enheder.**
- **At bruge CEA, når livskvalitet er det dominerende udfald (brug CUA i stedet).**
