# Värdegenererande kapacitet (operativ vändning)

Värdegenererande kapacitet mäter hur mycket extra klinisk kapacitet som skapas genom operativa förbättringar, utan att anställa mer personal.

## Varför det är viktigt

Att "skapa" ny kapacitet genom effektivitet är ofta snabbare och billigare än att rekrytera, särskilt inom personalbristsspecialiteter.

## Matematiken

```
Skapad kapacitet = (ursprunglig genomströmning × % effektivitetsvinst) − implementeringskostnader omräknade till motsvarande genomströmning
```

## Genomarbetat exempel

En operativ vändning på en röntgenavdelning ökar skanningskapaciteten med 30 % genom schemaläggningsoptimering, motsvarande att anställa 3 extra radiologer utan rekryteringskostnaderna.

## Koppling till mjukvaruutveckling

Liknar att öka driftsättningsfrekvensen genom pipelineoptimering istället för att anställa fler ingenjörer för att leverera samma volym.

## Fallgropar

- **Att underskatta implementeringskostnaderna för den operativa förändringen.**
- **Att hävda vinster som egentligen härrör från tillfälliga extraordinära insatser snarare än varaktig förändring.**
