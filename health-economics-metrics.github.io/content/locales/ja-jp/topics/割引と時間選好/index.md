# 割引と時間選好

割引とは、将来の費用と便益を現在価値に変換することです。なぜなら、今日の便益は5年後の同じ便益よりも価値があるからです。

## なぜ重要か

あらゆる医療経済学の評価、そしてあらゆる真剣な公共部門のビジネスケースは、複数年にわたるキャッシュフローを割り引きます。英国財務省のGreen Bookは年率3.5%の社会的時間選好率を定めており、NICEの基準ケースは費用と健康効果の両方を年率3.5%で割り引きます(30年以上にわたる便益を持つ、ほぼ治癒に近い治療については、基準ケース外の割引率として1.5%が用いられます)。もしあなたのソフトウェアのビジネスケースが「10年間で£500万の節約」を主張するなら、財務担当者はすぐに割引後の数値を求めるでしょう。

## 数式

将来の金額の現在価値:

```
PV = FV / (1 + r)^t

PV = 現在価値
FV = t年目の将来価値
r  = 割引率(NICE/Green Book:0.035)
t  = 今からの年数
```

n年間にわたる一定の年間便益Bの場合(年金方式):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## 計算例

あなたのソフトウェアは、稼働開始の1年後から5年間、NHSトラストに年間£100,000を節約します。

割引前の合計:£500,000。

3.5%で割り引くと:

```
1年目: 100,000 / 1.035^1 = £96,618
2年目: 100,000 / 1.035^2 = £93,351
3年目: 100,000 / 1.035^3 = £90,194
4年目: 100,000 / 1.035^4 = £87,144
5年目: 100,000 / 1.035^5 = £84,197

PV合計 ≈ £451,505
```

誠実な見出しの数値は約£451,000であり、素朴な合計よりおよそ10%少なくなります。ここで、提供が1年遅れたとしましょう。すべての項が1年後ろにずれ、PVは約£436,000まで下がります — これが[遅延コスト](../遅延コスト/)を割引の観点から見たものです。

## ソフトウェア工学との関連

- **技術的負債の返済とプラットフォーム移行**は、何年も先の便益の流れを約束します。今四半期に回収できる仕事と比較する前に、それらを割り引いてください。
- **前倒しの費用、後倒しの便益**は移行の標準的な形です。割引はその形を正しく不利に扱います。それは、今キャパシティを投入して後で価値を得るという、リスクフリーな時間価値を正しく価格に反映しているのです。
- **「5年目に節約」という主張**は二重に懐疑的に見るべきです — それは大きく割り引かれる上に、非常に不確実だからです([感度分析](../感度分析/)を参照)。

## 落とし穴

- **費用は割り引くが便益は割り引かない**(またはその逆)。基準ケースでは両方を同じ率で割り引きます。
- **公共部門のケースで商業的な割引率(8〜12%)を使う**、あるいはベンチャー投資案件で3.5%を使う。割引率は意思決定者に合わせてください。
- **割引とインフレを混同する。** 割引は*実質*(インフレ調整後)の値に適用されます。両方を暗黙のうちに行わないでください。
