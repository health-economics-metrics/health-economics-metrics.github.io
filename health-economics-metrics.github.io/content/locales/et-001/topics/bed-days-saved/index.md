# Säästetud voodipäevad

Säästetud voodipäevad mõõdavad, mitu päeva haiglaravi sekkumine väldib — levinud näitaja digitervise sekkumiste väärtuse jaoks.

## Miks see on oluline

Voodipäevad on äriprojektide kõige levinum "peamine" kasu, kuid neid hinnatakse sageli valesti, kasutades keskmist kulu piirkulu asemel.

## Matemaatika

```
Säästetud voodipäevad = Σ (väldatud vastuvõtud × keskmine haiglaravi kestus)
```

## Lahendatud näide

Varajase väljakirjutamise programm väldib 500 vastuvõttu keskmiselt 4 päeva kaupa: 2000 säästetud voodipäeva, hinnatud piirkulu £150/päevas järgi = £300 000.

## Seos tarkvaraarendusega

Sarnaneb säästetud serveriinstantside hindamisega arvutuse piirkulu, mitte fikseeritud üldkulusid sisaldava keskmise kulu järgi.

## Lõksud

- **Voodipäevade hindamine keskmise kulu, mitte piirkulu järgi — vt [piirkulu versus keskmine kulu](../marginal-vs-average-cost/).**
- **Eeldus, et vaba voodikoht kasutatakse automaatselt uuesti.**
