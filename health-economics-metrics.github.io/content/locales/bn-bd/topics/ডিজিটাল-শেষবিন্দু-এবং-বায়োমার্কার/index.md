# ডিজিটাল শেষবিন্দু এবং বায়োমার্কার

একটি ডিজিটাল বায়োমার্কার হলো সেন্সরের মাধ্যমে সংগৃহীত একটি বস্তুনিষ্ঠ শারীরবৃত্তীয় বা আচরণগত পরিমাপ। একটি ডিজিটাল শেষবিন্দু হলো এমন একটি পরিমাপ যা একটি **ট্রায়াল ফলাফল**-এ উন্নীত।

## কেন এটি গুরুত্বপূর্ণ

ঐতিহ্যবাহী ট্রায়াল শেষবিন্দু বিক্ষিপ্ত এবং ব্যয়বহুল; ডিজিটাল শেষবিন্দু ক্রমাগত, পরিবেশগত, এবং প্রতি-পর্যবেক্ষণ সস্তা। ধরাটি হলো যাচাইকরণ: গৃহীত কাঠামোর জন্য **যাচাইকরণ/বিশ্লেষণাত্মক বৈধতা**, **ক্লিনিক্যাল বৈধতা**, এবং একটি প্রদর্শিত **স্বাস্থ্যের অর্থপূর্ণ দিক** প্রয়োজন।

## গণিত

```
বিশ্লেষণাত্মক বৈধতা: রেফারেন্সের সাথে চুক্তি (MAPE, CCC, Bland-Altman)
ক্লিনিক্যাল বৈধতা:   ক্লিনিক্যাল নোঙরের বিরুদ্ধে সম্পর্ক/বৈষম্য

শেষবিন্দু অর্থনীতি:
  প্রতি রোগী-বছর সনাক্তকৃত ঘটনা (ক্রমাগত) বনাম প্রতি-ভ্রমণ নমুনা
```

## সমাধানকৃত উদাহরণ

একটি পার্কিনসন ট্রায়াল একটি কব্জি সেন্সর থেকে গতির গতি বনাম ত্রৈমাসিক ক্লিনিক-রেটেড স্কোর বিবেচনা করে:

```
ক্লিনিক শেষবিন্দু:  বছরে 4 পরিমাপ/রোগী, উচ্চ দৈনিক গোলমাল
ডিজিটাল শেষবিন্দু: বছরে ~200 প্যাসিভ পরিমাপ/রোগী

ঘন নমুনায় বার্ষিক-পরিবর্তন অনুমানের বৈচিত্র্য ~5× কমে
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

ডিজিটাল শেষবিন্দু ক্লিনিক্যাল পোশাক পরা একটি তথ্য-প্রকৌশল শৃঙ্খলা: **উৎস এবং সংস্করণ** এবং **অনুপস্থিত-তথ্য নকশা**।

## ঝুঁকিপূর্ণ দিক

- **সম্পূর্ণ যাচাইকরণ হিসেবে ক্লিনিকের-সাথে-সম্পর্ক**।
- **নতুন-শেষবিন্দু নিয়ন্ত্রক ঝুঁকি**।
