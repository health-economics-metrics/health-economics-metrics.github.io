# 机会成本

机会成本是指当你投入一项资源时，所放弃的最佳替代方案的价值。在一个预算固定的医疗系统中，把100万英镑花在某件事上，就意味着有100万英镑的健康价值*不会*在其他地方被创造出来。

## 为何重要

机会成本是健康经济学中最深刻的理念，也是软件工程师最常忽略的一个。在任何给定年度，医疗预算都是固定的，因此一项新技术从来都不是靠"额外"的钱来获得资助——它总是在替代某样东西。支付方实际提出的问题从来都不是"这个东西好不好？"，而是"它是否比同样这笔钱目前正在购买的东西更好？"

这正是成本效果阈值之所以存在的根本原因：该阈值本质上是对"这笔钱在当前系统的边际上能买到多少健康"的一种估算。参见[支付意愿阈值](../支付意愿阈值/)。

## 计算方法

没有单一公式；机会成本本质上是一种比较纪律：

```
选择A的机会成本 = 被放弃的最佳替代方案B的价值
选择A的净收益   = 价值(A) − 价值(B)
```

经验性基准：Claxton等人（2015年）估算，NHS在边际上每产生一个QALY的成本约为**£13,000**。因此，如果将£13,000花在一项产生不到一个QALY的技术上，即便该技术"确实有效"，整个国家的健康水平实际上也会*下降*。

## 实例演算

某NHS信托机构的转型预算恰好只够资助以下两个方案中的一个：

- **方案A**：电子排班软件——每年节省£400,000的中介用工支出。
- **方案B**：出院协调软件——每年节省2,000个床位天。按每个真正被释放的床位天约£150的边际成本计算，相当于每年£300,000，外加等候患者更早获得治疗的额外获益。

资助A就意味着放弃B。A的机会成本，就是B所带来的£300,000加上患者获益；A方案真正的*净*论证依据，其实只是二者之间的差额，而非A那个表面亮眼的£400,000。任何将某项提案与"什么都不做"相比较、而非与最佳替代方案相比较的商业论证，都会高估其自身价值。

## 与软件工程的联系

工程产能同样是一份固定预算——只不过单位是路线图席位，而非英镑。一个平台团队若花£500/小时资助工具A来节省工程师工时，而工具B能以£200/小时提供同样的效果，那么这个团队实际上是在毁灭产能——这与一个医疗系统资助一款每QALY成本£40,000的药物、从而挤出每QALY成本£13,000的其他照护，是完全相同的道理。这套纪律可以直接迁移：

- 始终明确指出对照对象（"相对于什么？"）。
- 应按工程师时间原本能产生的价值来估值，而非仅仅按薪资来估值。
- 应把"我们还有预算剩余"当作分析的*起点*，而非终点。

## 陷阱

- **与"什么都不做"相比较。**正确的对照对象，应是这笔钱的次优用途，而这几乎从来都不是"什么都不做"。
- **假设节省下来的时间机会成本为零。**节省下来的时间只有在被重新投入到有价值的事情上时才真正有价值——参见[现金释放型与非现金释放型节省](../现金释放型与非现金释放型节省/)。
- **忽视替代效应。**"预算会相应扩张来容纳新支出"这种说法，在一个国家医疗服务体系的当年度预算中几乎从未成真。
- **忽视由哪种方法为被挤出的资源估值。** 尤其是对因疾病、残疾或员工离职而损失的生产率——见[人力资本法与摩擦成本法](../人力资本法与摩擦成本法/)，这是该思想在生产率成本上的专门版本。
