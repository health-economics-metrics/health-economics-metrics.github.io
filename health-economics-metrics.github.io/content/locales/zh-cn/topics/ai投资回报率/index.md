# AI投资回报率 (AI Return on Investment)

AI投资回报率（AI ROI）指可归因于AI相关举措、可实测的损益（P&L）回报。一个发人深省的基准数据是：MIT于2025年发布的"GenAI鸿沟"（GenAI Divide）研究发现，尽管企业级GenAI投资已达300–400亿美元，但**约95%的试点项目未显示出可测量的损益回报**——而成功的那5%具有一些可识别的共同特征。

## 为何重要

卫生系统对AI试点的这种模式早有专门称呼：**"试点病"（pilotitis）**——指NHS里那些前景看好的应用被永远试点、却从未真正规模化的现象。MIT的研究发现与卫生技术评估领域早已知晓的道理完全吻合：价值主张需要预先设定的终点指标，归因需要对照组，而"大家都感觉它有帮助"算不上一条收益线。MIT数据中成功的少数案例，大多集中在拥有可追踪成本基线的后台自动化场景，而且**采购的现成工具成功率约为67%，而内部自建方案的成功率大约只有其三分之一**——这些先验经验应当纳入每一份AI投资论证（参见[自建与外购](../自建与外购/)）。

## 计算方法

```
AI投资回报率 = (可归因收益 − AI总成本) / AI总成本

AI总成本 = 许可证/推理费用（参见inference-unit-economics.md）
         + 系统集成 + 数据就绪度整备 + 评测
         + 工作流重新设计 + 治理/保障
         （许可证费用通常只占分母中的一小部分）

可归因收益：须相对于基线或对照组进行测量，并按cash-releasing-vs-non-cash-releasing.md
分类为现金收益/产能收益/质量收益
```

## 实例演算

某医院集团针对两个应用场景部署AI：

```
应用场景A —— 临床信件起草（后台场景，可追踪）：
  基线：外包转录费用，每年£38万
  部署后：转录合同已取消；临床医生审核时间增加£6万
  AI成本：全包每年£12万
  投资回报率 = (38万 − 6万 − 12万) / 12万 ≈ 167%——现金释放型，可审计 ✓

应用场景B ——"面向临床医生的AI协作助手"（覆盖面广，未被追踪）：
  收益主张："为4,000名员工节省时间"——未采集基线数据
  实测的损益影响：无法证实
  → 归入那95%的失败案例，无论它是否真的有帮助
```

差异并不在于AI本身的质量高低——而在于该收益是否有一个**基线、责任人和预算科目**（参见[收益实现](../收益实现/)）。

## 与软件工程的关联

面向AI投资的、脱胎于HTA思路的操作手册是：**像[NICE证据标准框架分级](../nice-证据标准框架/)一样分阶段积累证据**——低风险工具可采用演示级证据，机构层面大规模投入前先做有对照的试点，并预先登记推广门槛（参见[DiGA](../德国-diga-快速通道/)"限期临时上市"这一模式）；**像健康经济学计算"需求规避"那样计算"成本规避"**——只有当某条具体预算真正下降时，这类收益才算真实；以及**用[完美信息期望值（EVPI）](../完全信息期望价值/)为试点本身定价**——一个无法改变推广决策的试点，其价值为£0。至于开发者工具这一细分领域，可参见[AI开发者生产力](../ai与开发者生产力/)。

## 常见陷阱

- **收益被稀释分散**：价值分散在成千上万用户身上，从本质上就无法测量；应选择收益集中、可追踪基线的应用场景。
- **只计许可证成本**：系统集成、评测和工作流重新设计的成本通常才是分母中的主体。
- **归因盗用**：AI与流程重新设计同时部署，却把全部收益变化都算到AI头上。
- **沉没试点的持续加码**：因为叫停等于承认失败，就不断延长失败的试点——终止日期必须提前商定。
