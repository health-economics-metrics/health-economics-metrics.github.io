# 節省的床位天數

一個床位天，是指一名病患佔用一張醫院床位一天。透過提前出院、避免入院或虛擬病房實現的"節省床位天數"，是NHS數位化商業案例中最常用的效益線，也是最常被高估的一條。

## 為何重要

床位是急症醫療中起決定作用的約束條件：一旦床位滿員，擇期手術就會被取消，救護車就會排隊等候，急診科也會隨之積壓。因此，能釋放床位天數的介入措施確實具有真實價值——但價值的*型別*完全取決於被釋放的床位後續被如何使用。財務總監們早已學會對樸素的床位天數主張大打折扣；把這套算術做對，本身就是一道信譽檢驗。

## 計算方法

```
節省的床位天數 = 受影響病患數 × Δ住院時長（或：避免的入院數 × 平均住院時長）

價值取決於被釋放產能的實際用途：
  重新用於擇期活動     → 價值 = 活動收入或等候名單收益
  病區關閉/縮減規模     → 價值 = 釋放出的人員配置與營運成本（現金）
  被吸收為冗餘產能      → 價值 ≈ 僅相當於邊際（"酒店式"）成本，每天£50–£150
```

一個急症床位天的平均全成本常被引用為£400以上（"全國成本採集"資料中，超額床位天歷史上約為£350）——但參見[邊際成本與平均成本](../邊際成本與平均成本/)：幾乎從來都不是平均成本才是真正的節省。

## 實例演算

某遠端監測"虛擬病房"專案使每年600名病患提前2天出院：共節省1,200個床位天。

- **樸素主張**：1,200 × £400 = £480,000。除非真的關閉了一個病區，否則這是錯的。
- **誠實的主張**：該信託機構將這些床位重新用於骨科擇期病患。1,200個床位天 ÷ 平均3天住院時長 = 400臺額外的擇期手術，在按活動付費機制下每臺約創造£6,000收入 = **共計£240萬的額外可獲資助活動量**（需扣除治療這些病患的邊際成本），*此外*還有400名病患從等候名單中移出。虛擬病房本身的營運成本（£350,000）需與此相抵。

被*重新利用*的釋放產能，其價值往往高於樸素的現金主張——但這是另一種型別的價值，必須如實標註（參見[現金釋放型與非現金釋放型](../現金釋放型與非現金釋放型節省/)）。

## 與軟體工程的聯絡

"節省的伺服器天數"表現出完全相同的邏輯。停用常駐運作的環境，只有在實例被真正終止或預留資源到期失效時，才會釋放現金；被重新吸收回資源池的產能，其價值僅相當於邊際成本（在已承諾支出下約等於0）。相同的紀律在此依然適用：對於每一項聲稱的節省，都應說明其*具體機制*——是被終止了、被重新用於有價值的工作，還是就此蒸發消失了。能縮短住院時長的軟體（出院協調、遠端監測、診斷週轉）應當對上述三種情形分別建模，並讓各病區自行選擇適用哪一種。

## 陷阱

- **對邊際產能採用平均成本估值**——這是經典的錯誤。
- **重複計算**：同一張被釋放的床位，既被計為"節省的床位天數"，又被計為"避免的入院"，還被計為"等候名單縮減"。
- **假設被節省的天數就是花費最高的天數**：住院末期被節省的那些天數，往往恰恰是病情最輕、花費最低的那些天。
