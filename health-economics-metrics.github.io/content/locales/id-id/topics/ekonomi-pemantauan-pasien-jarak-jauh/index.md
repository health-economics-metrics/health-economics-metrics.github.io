# Ekonomi Pemantauan Pasien Jarak Jauh

Ekonomi penggantian dan penyesuaian biaya dari memantau pasien di rumah: di AS, tumpukan pendapatan kode CPT yang ditentukan; dalam layanan kesehatan nasional, penghindaran rawat inap dan ekonomi bangsal virtual.

## Mengapa ini penting

RPM adalah tempat data perangkat menjadi layanan kesehatan yang dapat ditagih.

```
99453  penyiapan dan edukasi pasien   ~$19,73
99454  penyediaan+transmisi perangkat ~$43,03  setiap 30 hari — memerlukan ≥16 hari
```

## Matematika

```
Pendapatan RPM (AS) = terdaftar × fraksi kepatuhan penagihan × tumpukan kode PMPM
```

## Contoh yang diselesaikan

Praktik AS mendaftarkan 400 pasien hipertensi: margin ≈ $100 ribu/tahun.

## Hubungan dengan rekayasa perangkat lunak

Platform RPM adalah produk langka di mana **waktu aktif dan keandalan sinkronisasi berubah langsung menjadi pendapatan**.

## Jebakan

- **Pendaftaran ≠ pendapatan.**
