# Nilai Harapan Informasi Sempurna (EVPI)

EVPI adalah jumlah maksimum yang harus dibayar pembuat keputusan untuk menghilangkan ketidakpastian sebelum memutuskan.

## Mengapa ini penting

Sistem kesehatan terus-menerus menghadapi pilihan: mengadopsi sekarang dengan bukti yang tidak sempurna, atau mendanai lebih banyak penelitian terlebih dahulu.

## Matematika

```
EVPI = E_θ[ max_j NMB(j, θ) ] − max_j E_θ[ NMB(j, θ) ]
```

## Contoh yang diselesaikan

Meluncurkan asisten dokumentasi AI ke 5.000 klinisi: EVPI = £1,2 juta.

## Hubungan dengan rekayasa perangkat lunak

EVPI adalah ekonomi dari spike, percontohan, dan uji A/B.

## Jebakan

- **Menjalankan percontohan tanpa aturan keputusan.**
