# लागत-परिणाम विश्लेषण (CCA)

CCA लागत को **सभी परिणामों की एक विभाजित तालिका** के साथ प्रस्तुत करता है — नैदानिक, परिचालनात्मक, अनुभवात्मक — उन्हें एक ही अनुपात या स्कोर में संकुचित किए बिना।

## यह क्यों महत्वपूर्ण है

CCA डिजिटल स्वास्थ्य प्रौद्योगिकियों के लिए NICE का **पसंदीदा आर्थिक प्रारूप** है।

## गणित

आउटपुट एक तालिका है:

```
                     हस्तक्षेप   तुलनाकर्ता   अंतर
लागत (वार्षिक)       £X          £Y           ΔC
परिणाम 1             …           …            Δ1
```

## हल किया गया उदाहरण

डिजिटल प्री-ऑपरेटिव मूल्यांकन प्लेटफ़ॉर्म बनाम फोन-आधारित प्रक्रिया:

```
                        डिजिटल      फोन
चलाने की लागत           £180,000    £95,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

CCA एक अच्छे प्लेटफ़ॉर्म प्रस्ताव द्वारा पहले से उपयोग किए जा रहे संतुलित स्कोरकार्ड का औपचारिक संस्करण है।

## सामान्य गलतियाँ

- **चुनिंदा परिणाम।**
- **छिपी हुई समग्रता।**

## स्रोत
