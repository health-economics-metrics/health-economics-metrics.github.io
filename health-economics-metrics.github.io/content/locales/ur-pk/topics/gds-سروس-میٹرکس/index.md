# GDS سروس میٹرکس

برطانیہ کی Government Digital Service (GDS) سروس مینوئل ہر سرکاری ڈیجیٹل سروس کے لیے چار KPIs لازمی قرار دیتا ہے: فی لین دین قیمت، صارف کی اطمینان، تکمیل کی شرح، اور ڈیجیٹل اپنانا۔

## یہ کیوں اہم ہے

GDS میٹرکس اس چینل-شفٹ کاروباری کیس کو انکوڈ کرتے ہیں جس نے سرکاری ڈیجیٹلائزیشن کی ایک دہائی کی مالی اعانت کی۔

## ریاضی

```
فی لین دین قیمت = کل سروس قیمت / مکمل لین دین
```

## حل شدہ مثال

ایک NHS اپائنٹمنٹ-انتظام سروس: سالانہ 20 لاکھ لین دین، اپنانے کی شفٹ بچت سالانہ £1,475,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

یہ چار KPIs ایک پروڈکشن-گریڈ [قیمت-نتیجہ جدول](../قیمت-نتیجہ-کا-تجزیہ/) کی مثال ہیں۔
