# Рамки стандартів доказів NICE

Рамки стандартів доказів NICE визначають вимоги до доказів за рівнем ризику для технологій цифрового здоров'я, від додатків для благополуччя низького ризику до діагностичних інструментів високого ризику.

## Чому це важливо

Продукти цифрового здоров'я не всі повинні відповідати однаковій планці доказів — рамки масштабують вимоги до рівня ризику.

## Математика

```
Рівень доказів = f(клас функціонального ризику, рівень клінічного ризику)
```

Жодної числової формули; це система класифікації з відповідними порогами доказів.

## Розібраний приклад

Додаток для зниження стресу потрапляє до рівня 1 (достатньо описових доказів); діагностичний інструмент зі штучним інтелектом для виявлення раку потрапляє до рівня 3b (потрібні рандомізовані контрольовані дослідження).

## Зв'язок з інженерією програмного забезпечення

Подібно до вимог тестування на основі ризику — внутрішній інструмент потребує менш суворої валідації, ніж система, критична для безпеки пацієнтів.

## Підводні камені

- **Неправильна класифікація інструменту для відповідності нижчим вимогам доказів.**
- **Непереглядання вимог до доказів при зміні функціональності продукту.**
