# การจำลองกลุ่มประชากรแบบมาร์คอฟ

แบบจำลองกลุ่มประชากรแบบมาร์คอฟเป็นเทคนิคการสร้างแบบจำลองมาตรฐานของ HTA สำหรับมาตรการแทรกแซงที่ผลคลี่คลายหลายช่วงเวลา (รอบ) แทนที่จะเกิดครั้งเดียว กลุ่มสมมุติเริ่มต้นอยู่ในสถานะสุขภาพเดียวทั้งหมด และในแต่ละรอบชุดความน่าจะเป็นการเปลี่ยนสถานะคงที่ย้ายสัดส่วนของกลุ่มระหว่างสถานะ ต้นทุนและ QALY สะสมในแต่ละรอบตามสัดส่วนของกลุ่มที่อยู่ในแต่ละสถานะ แล้วคิดลดเป็นมูลค่าปัจจุบัน วิศวกรซอฟต์แวร์ที่สร้างแบบจำลองกรณีธุรกิจสุขภาพดิจิทัลหลายปี ซึ่งผู้ใช้หรือผู้ป่วยเคลื่อนไหวระหว่างสถานะเช่น "ใช้งานอยู่" "หลุดออก" หรือ "ยกเลิก" ตามเวลา กำลังสร้างโครงสร้างเดียวกันนี้

## ทำไมจึงสำคัญ

การตัดสินใจเทคโนโลยีสุขภาพจริงส่วนใหญ่ไม่ใช่การเปรียบเทียบต้นทุนและผลลัพธ์ช่วงเดียว ภาวะเรื้อรังลุกลาม กำเริบ ตอบสนองต่อการรักษา หรือทำให้เสียชีวิตเมื่อผ่านไปหลายปี และ[การวิเคราะห์ความคุ้มทุน](../การวิเคราะห์ความคุ้มทุน/)ช่วงเดียวแสดงสิ่งนั้นไม่ได้ ข้อเสนอของ NICE, ICER และ CADTH สำหรับมาตรการแทรกแซงโรคเรื้อรังที่ประเมินผ่าน[การประเมินเทคโนโลยีด้านสุขภาพ](../การประเมินเทคโนโลยีด้านสุขภาพ/) เกือบทั้งหมดสร้างเป็นแบบจำลองกลุ่มประชากรแบบมาร์คอฟด้วยขอบเขตเวลาตลอดชีวิต เพราะทางเลือกอื่น — การสร้างแบบจำลองทุกเส้นทางผู้ป่วยรายบุคคลที่เป็นไปได้ — แก้ไม่ได้ในระดับใหญ่ แบบจำลองมาร์คอฟระดับกลุ่มแลกความสมจริงระดับบุคคลบางส่วน (แสดงความจำเกี่ยวกับสถานะก่อนหน้าได้ยาก นั่นคือที่มาของคำว่า "มาร์คอฟ": อนาคตขึ้นกับสถานะปัจจุบันเท่านั้น) กับแบบจำลองที่โปร่งใส ตรวจสอบได้ และเร็วพอที่จะรันหลายพันครั้งใน[การวิเคราะห์ความอ่อนไหวเชิงความน่าจะเป็น](../การวิเคราะห์ความอ่อนไหวเชิงความน่าจะเป็น/)

## คณิตศาสตร์

```
การปรับปรุงกลุ่มในหนึ่งรอบ (เวกเตอร์แถว × เมทริกซ์การเปลี่ยนสถานะ):
  สถานะ_ใหม่[j] = ผลรวม_i สถานะ[i] * เมทริกซ์การเปลี่ยนสถานะ[i][j]

ต้นทุนของหนึ่งรอบ:
  ต้นทุนรอบ = ผลรวม_s สถานะ[s] * ต้นทุนต่อรอบ[s]

QALY ของหนึ่งรอบ:
  qaly_รอบ = ผลรวม_s สถานะ[s] * อรรถประโยชน์[s] * ความยาวรอบ_ปี

การจำลองเต็มตลอด `รอบ` รอบ คิดลดที่ `อัตราคิดลด`:
  ต้นทุนคิดลดรวม = ผลรวม_{t=0}^{รอบ-1} ต้นทุนรอบ(สถานะ_t) / (1 + อัตราคิดลด)^t
  qaly คิดลดรวม = ผลรวม_{t=0}^{รอบ-1} qaly_รอบ(สถานะ_t) / (1 + อัตราคิดลด)^t
  โดยที่ สถานะ_0 = การกระจายเริ่มต้น, สถานะ_{t+1} = เดินหน้ากลุ่ม(สถานะ_t, เมทริกซ์การเปลี่ยนสถานะ)
```

การคิดลดแต่ละรอบเป็นมูลค่าปัจจุบันใช้สูตรเดียวกับ[การคิดลดและความชอบเวลา](../การคิดลดและความชอบเวลา/) ใช้ทีละรอบ ไม่ใช่ทีละปี

## ตัวอย่างที่คำนวณแล้ว

**ทางคลินิก**: แบบจำลอง 2 สถานะ — `สุขภาพดี` และ `เสียชีวิต` — ที่ 10% ของกลุ่มเสียชีวิตในแต่ละรอบ และ `เสียชีวิต` เป็นสถานะดูดกลืน (ความน่าจะเป็นอยู่ในสถานะเดิมคือ 1.0 หากไม่มีลูปนี้ มวลของกลุ่มจะหายไปหลังหนึ่งรอบใน `เสียชีวิต`) กลุ่มเริ่มต้น `สุขภาพดี` ทั้งหมด ต้นทุน £1,000 ต่อรอบขณะ `สุขภาพดี` (£0 เมื่อ `เสียชีวิต`) และได้ 0.8 QALY ต่อปีขณะ `สุขภาพดี` จำลอง 3 รอบรายปีที่อัตราคิดลด 3.5% ของ NICE:

```
รอบ 0: สถานะ = [1.00, 0.00] (100% สุขภาพดี)
  ต้นทุน = £1,000.00, qaly = 0.800, ตัวคูณคิดลด = 1.000000
  คิดลดแล้ว: ต้นทุน = £1,000.00, qaly = 0.8000

รอบ 1: สถานะ = [0.90, 0.10] (90% สุขภาพดี, 10% เสียชีวิต)
  ต้นทุน = £900.00, qaly = 0.720, ตัวคูณคิดลด = 0.966184
  คิดลดแล้ว: ต้นทุน = £869.57, qaly = 0.6957

รอบ 2: สถานะ = [0.81, 0.19] (81% สุขภาพดี, 19% เสียชีวิต)
  ต้นทุน = £810.00, qaly = 0.648, ตัวคูณคิดลด = 0.933511
  คิดลดแล้ว: ต้นทุน = £756.14, qaly = 0.6049

ต้นทุนคิดลดรวม ≈ £2,625.71
QALY คิดลดรวม ≈ 2.1006
```

สถานะของแต่ละรอบคือสถานะรอบก่อนหน้าที่ผ่านเมทริกซ์การเปลี่ยนสถานะ — 90% ของ 90% ที่ยัง `สุขภาพดี` ในรอบ 1 ยังคง `สุขภาพดี` ในรอบ 2 (0.9 × 0.9 = 0.81) ขณะที่อีก 19% เสียชีวิตแล้ว (0.9 × 0.1 + 0.1 × 1.0 = 0.19) สังเกตว่ากลุ่มไม่เคยทำให้สถานะ `สุขภาพดี` ว่างเปล่าสนิท: ด้วยอัตราตาย 10% คงที่ต่อรอบและไม่มีการกลับคืน สัดส่วน `สุขภาพดี` ลดลงแบบเรขาคณิต ไม่ถึงศูนย์ในจำนวนรอบจำกัดใดๆ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

สำหรับวิธีที่แบบจำลองหลายรอบของ HTA ถูกใช้ในการประเมินจริง ดู[การประเมินเทคโนโลยีด้านสุขภาพ](../การประเมินเทคโนโลยีด้านสุขภาพ/) — กรณีอ้างอิงที่กำหนดอัตราคิดลด แหล่งอรรถประโยชน์ และขอบเขตเวลาที่แบบจำลองมาร์คอฟที่ส่งต้องใช้

แบบจำลองกลุ่มประชากรแบบมาร์คอฟโดยโครงสร้างคือเครื่องสถานะ (state machine) ที่มีการเปลี่ยนสถานะเชิงความน่าจะเป็น รันตามจำนวนจังหวะที่กำหนด คิดลดมูลค่าทุกจังหวะ รูปแบบเดียวกันจำลองการคงอยู่ของกลุ่มผู้ใช้/การเปลี่ยนสถานะตามเวลา — ดู[ตัวชี้วัด DORA](../ตัวชี้วัด-dora/) สำหรับเวอร์ชันความน่าเชื่อถือ: "ระบบสัดส่วนเท่าใดอยู่ในสถานะเสื่อมถอยในช่วงนี้และมีต้นทุนเท่าใด" โดยเฉพาะ:

- **การสร้างแบบจำลองการคงอยู่/การเลิกใช้** คือแบบจำลองกลุ่มมาร์คอฟที่มีสถานะเช่น "ใช้งานอยู่" "เสี่ยง" "เลิกใช้": เมทริกซ์การเปลี่ยนสถานะรายเดือนคงที่ รัน 12 หรือ 24 รอบรายเดือน ให้จำนวนผู้ใช้ที่ใช้งานอยู่คาดหวัง (และรายได้) ในเดือนอนาคตใดๆ เช่นเดียวกับที่ `สุขภาพดี`/`เสียชีวิต` ให้ผู้รอดชีวิตคาดหวัง
- **ความน่าเชื่อถือและเศรษฐศาสตร์เหตุการณ์**: สถานะของระบบ (ปกติ เสื่อมถอย ล่ม) สร้างแบบจำลองเดียวกันได้ ด้วย "ต้นทุนต่อรอบ" สำหรับความเสียหายจากการหยุดทำงานที่สะสมขณะระบบอยู่ในสถานะเสื่อมถอย/ล่ม — เปลี่ยนข้อโต้แย้งเรื่องความถี่เหตุการณ์ให้เป็นข้อโต้แย้งเรื่องต้นทุนคิดลดที่เปรียบเทียบกับต้นทุนงานความน่าเชื่อถือที่จะเปลี่ยนความน่าจะเป็นการเปลี่ยนสถานะ
- **สถานะดูดกลืนเป็นสถานะสิ้นสุด**: `เสียชีวิต` ในแบบจำลองทางคลินิกคือ "สมัครสมาชิกที่ยกเลิกแล้ว" หรือ "ออฟไลน์ถาวร" ในแบบจำลองซอฟต์แวร์ — ทั้งสองต้องมีความน่าจะเป็นอยู่ในสถานะเดิมเท่ากับ 1.0 อย่างชัดเจน มิฉะนั้นการจำลองจะสูญเสียมวลอย่างเงียบๆ

## ข้อผิดพลาดที่พบบ่อย

- **ความน่าจะเป็นการเปลี่ยนสถานะที่แถวรวมไม่เท่ากับ 1** แถวที่รวมมากกว่าหรือน้อยกว่า 1 ทำให้มวลของกลุ่ม "รั่ว" หรือ "งอก" ทุกรอบอย่างเงียบๆ — ตรวจผลรวมแถวเสมอก่อนไว้ใจผลลัพธ์ เพราะโครงสร้างแบบจำลองเองไม่ส่งสัญญาณข้อผิดพลาดนี้
- **ความยาวรอบหยาบเกินไปสำหรับพลวัตจริงของโรค** รอบรายปีสำหรับสถานะที่เปลี่ยนในไม่กี่สัปดาห์ประเมินการเปลี่ยนสถานะกลางรอบต่ำเกิน เลือกความยาวรอบที่สั้นเมื่อเทียบกับความเร็วที่กระบวนการที่สร้างแบบจำลองเคลื่อนไหวจริง
- **ลืมลูปของสถานะดูดกลืน** สถานะดูดกลืน (ตาย ยกเลิกถาวร) ต้องมีความน่าจะเป็นอยู่ในสถานะเดิมเท่ากับ 1.0 พอดี หากละไว้ มวลของกลุ่มจะระเหยจากสถานะนั้นหลังหนึ่งรอบ และประเมินต้นทุนสะสมหรือการสูญเสีย QALY ต่ำเกิน
- **ถือว่าแบบจำลองผ่านการตรวจสอบเพราะรันได้** แบบจำลองมาร์คอฟที่มีความน่าจะเป็นการเปลี่ยนสถานะน่าเชื่อถือก็ยังผิดเชิงโครงสร้างได้ (ขาดสถานะ พฤติกรรมดูดกลืนผิด) ตรวจสอบกับเกณฑ์เปรียบเทียบทางระบาดวิทยาที่ทราบ (เช่น การรอดชีวิต 5 ปีที่จำลองตรงกับเส้นโค้งการรอดชีวิตที่เผยแพร่หรือไม่) ก่อนไว้ใจผลลัพธ์
