# ব্যয়-সুবিধা বিশ্লেষণ (CBA)

CBA ব্যয় *এবং* ফলাফল উভয়কেই অর্থে মূল্যায়ন করে। এটি একমাত্র বিশ্লেষণ ধরন যা "এটি করা মোটেও মূল্যবান কিনা?" উত্তর দিতে পারে — শুধু "কোন বিকল্প সেরা?" নয় — কারণ অর্থমূল্যযুক্ত সুবিধা সরাসরি ব্যয়ের বিরুদ্ধে তুলনা করা যায়।

## কেন এটি গুরুত্বপূর্ণ

CBA হলো যুক্তরাজ্যের HM Treasury **গ্রিন বুক**-এর সমস্ত সরকারি ব্যয় মূল্যায়নের মান, স্বাস্থ্যও অন্তর্ভুক্ত যখন ফলাফল অর্থমূল্যায়িত করা যায়। যেখানে [CEA](../ব্যয়-কার্যকারিতা-বিশ্লেষণ/)/[CUA](../ব্যয়-উপযোগিতা-বিশ্লেষণ/) "স্বাস্থ্যের প্রতি এককে ব্যয়"-এ থেমে যায়, CBA স্বাস্থ্য নিজেই (QALY × থ্রেশহোল্ড মূল্য) এবং বাকি সবকিছু — সময়, ভ্রমণ, কার্বন — মূল্যায়ন করে এবং একটি নিট সংখ্যা রিপোর্ট করে।

## গণিত

```
NPV (নিট বর্তমান সামাজিক মূল্য) = Σ_t [ (সুবিধা_t − ব্যয়_t) / (1 + r)^t ]
BCR (সুবিধা-ব্যয় অনুপাত)       = PV(সুবিধা) / PV(ব্যয়)

NPV > 0 হলে গ্রহণ করুন (সমতুল্যভাবে BCR > 1); BCR নয়, NPV দিয়ে র‍্যাঙ্ক করুন।
r = 3.5% (গ্রিন বুক সামাজিক সময় অগ্রাধিকার হার)
```

## সমাধানকৃত উদাহরণ

একটি ই-রেফারেল ব্যবস্থা, ৫-বছরের দিগন্ত, ৩.৫% ছাড়:

```
ব্যয়:     নির্মাণ £1.2M (বছর 0), পরিচালনা £300k/বছর (1–5 বছর)
সুবিধা:   প্রশাসনিক সাশ্রয় £250k/বছর, এড়ানো ডুপ্লিকেট নির্ণয় £280k/বছর,
          রোগীর সাশ্রয়ী সময় 40,000 ঘণ্টা/বছর × £15 = £600k/বছর → £1,130k/বছর

PV ব্যয়    = 1,200k + 300k × 4.515 (বার্ষিকী ফ্যাক্টর) = £2,555k
PV সুবিধা  = 1,130k × 4.515                             = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

গ্রিন বুক আশাবাদী পক্ষপাত প্রয়োগ করুন (নির্মাণ ব্যয়ে +৪০%, সুবিধায় −২০%): PV ব্যয় ≈ £3,035k, PV সুবিধা ≈ £4,082k, NPV ≈ **+£1,047k** — এখনও ইতিবাচক, যা এই সমন্বয়ের মূল বিষয়: ক্ষেত্রগুলো তাদের নিজস্ব আশাবাদকে ছাড় দিয়েও টিকে থাকা উচিত।

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

- **মানক আশাবাদী পক্ষপাত হিসেবে** — প্রকৌশলীরা মাইগ্রেশন ব্যয় নির্ভরযোগ্যভাবে যতটা কম মূল্যায়ন করে ততটাই মন্ত্রণালয় অবকাঠামো ব্যয় কম মূল্যায়ন করে; এবার ভিন্ন হবে ভান না করে একটি ঘোষিত বৃদ্ধি প্রয়োগ করুন।
- **আধিপত্যকারী সুবিধা সৎভাবে অর্থমূল্যায়ন করুন অথবা একেবারেই না** — রোগী/ব্যবহারকারীর সময় প্রতিরক্ষাযোগ্য হারে অর্থমূল্যায়িত হয়; "ব্র্যান্ড মূল্য" নয়।
- **NPV র‍্যাঙ্ক করে, BCR করে না**: BCR ৫-সহ একটি ক্ষুদ্র প্রকল্প BCR ১.৬-সহ একটি বড় প্রকল্পের চেয়ে কম গুরুত্বপূর্ণ হতে পারে।

## ঝুঁকিপূর্ণ দিক

- সুবিধা বাড়ানোর জন্য **অ-মূল্যায়নযোগ্যকে মূল্যায়ন করা** (মনোবল, "কৌশলগত সমন্বয়") — সেগুলোকে গুণগত রাখুন, [ব্যয়-পরিণাম বিশ্লেষণ](../ব্যয়-পরিণাম-বিশ্লেষণ/) অনুযায়ী।
- **স্থানান্তরকে সুবিধা হিসেবে গণনা করা**: সরকারি সংস্থার মধ্যে অর্থ স্থানান্তর সামাজিক [দৃষ্টিকোণ](../বিশ্লেষণের-দৃষ্টিকোণ/)-এ নিট শূন্য।
- **কোনো প্রতিতথ্য নেই**: সুবিধা ন্যূনতম-করা বিকল্পের বিপরীতে পরিমাপ করা উচিত, শূন্যের বিপরীতে নয়।
