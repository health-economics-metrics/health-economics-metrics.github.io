# Dominans og effektivitetsfronten

Én mulighed dominerer en anden, når den er billigere og mindst lige så effektiv. Effektivitetsfronten viser de ikke-dominerede muligheder.

## Hvorfor det er vigtigt

Dominerede muligheder kan elimineres med det samme, hvilket forenkler beslutningsrummet, før detaljerede omkostningseffektivitetsberegninger er nødvendige.

## Matematikken

```
Mulighed A dominerer mulighed B, hvis: omkostning(A) ≤ omkostning(B) OG effekt(A) ≥ effekt(B)
```

## Gennemarbejdet eksempel

Fire behandlingsmuligheder på en omkostnings-effektgraf: mulighed C koster mere end mulighed B, men giver mindre sundhed end en blanding af A og D — mulighed C er udvidet domineret og elimineres.

## Forbindelse til softwareudvikling

Ligner det at eliminere arkitekturmuligheder, der er både dyrere og langsommere end et alternativ.

## Faldgruber

- **At overse udvidet dominans og kun kontrollere simpel dominans.**
- **At sammenligne muligheder parvis i stedet for mod hele fronten.**
