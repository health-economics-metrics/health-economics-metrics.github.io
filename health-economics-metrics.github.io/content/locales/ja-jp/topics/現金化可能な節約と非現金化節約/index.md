# 現金化可能な節約と非現金化節約

現金化可能な節約は、実際の支出を減らします — 予算項目が小さくなります。非現金化節約は、時間や容量を解放しますが、それは蓄えられるのではなく*再利用*されます。医療システムの財務担当者はこれらを別物として扱いますが、あなたもそうすべきです。

## なぜ重要か

これは、国のヘルスケアサービスにおけるあらゆるデジタルのビジネスケースに適用される、最も厳しい誠実さのテストです。NHSの便益フレームワークは、主張されるすべての便益を明示的に、現金化可能、非現金化、または定性的のいずれかに分類します。デジタルヘルスの「節約」のほとんど — 患者あたりの臨床医の節約時間、より速い文書作成 — は非現金化です:価値はありますが、赤字を減らしません。資金不足に直面するトラストのCFOは現金しか使えません。[確実な現金化削減](../確実な現金化削減/)も参照してください。

## 数式

```
現金化可能な節約 = 予算項目(前) − 予算項目(後)
                  (取り出せるものでなければならない:解約された契約、
                   閉鎖された病棟、削減された派遣費用、回避された購入)

非現金化の価値  = 解放された時間 × その時間の単位費用
                  (機会費用で評価される。その金額は取り出せ「ない」)
```

同じ物理的な出来事(1時間の節約)は、その後何が起こるかによって、どちらかのカテゴリーに分類されます:

```
1時間の節約 → 残業/派遣シフトがキャンセルされた       → 現金化可能
1時間の節約 → 臨床医がもう1人の待機患者を診た          → 非現金化(容量)
1時間の節約 → 余裕時間に吸収され、何も変わらない        → 便益なし
```

## 計算例

あるソフトウェアが100人の看護師それぞれについて、1シフトあたり30分を節約するとします。これは100 × 0.5 × 週5シフト × 46週 ≈ 年間11,500時間です。バンド5の雇用者コスト約£25/時間とすると、魅力的な見出しは年間£287,500です。

誠実な内訳:

- 20%の時間は、病棟が現在文書作成の超過を賄うためにバンク/派遣の割増料金を支払っている部分に該当します:2,300時間 × £35(派遣単価)= **£80,500の現金化可能な節約**(実際にシフトが組まれなくなった分)。
- 60%は直接的な患者ケアに再投入されます:6,900時間 × £25 = **£172,500の非現金化容量** — 実際の価値ですが、別途報告され、決して「節約」とは呼ばれません。
- 20%は休憩や中断に消えます:**£0**。これを主張するのはフィクションです。

£80,500の現金 + £172,500の容量を提示するビジネスケースは信頼できます。£287,500の「節約」を提示するものは、最初に読んだ会計担当者に却下されます。

## ソフトウェア工学との関連

同一の論理がAIコーディングアシスタントのROIを支配します:「開発者1人あたり1日30分」は、人員、外部委託費用、あるいはクラウド費用が実際に減らない限り、非現金化の容量です。カテゴリーは別々に報告してください:

- 現金化可能:解約された外部委託契約、廃止されたツールのライセンス、削減されたクラウド費用。
- 容量:より早く出荷された機能([遅延コスト](../遅延コスト/)による価値)、消化されたバックログ。
- なし:コンテキストスイッチに分断されて消える節約時間。

また、*解放された時間が実際にどこへ行ったか*も追跡してください — 便益実現管理([benefits-realization.md](../便益実現/))が存在するのは、主張された容量の増加が監査でしばしば蒸発してしまうからです。

## 落とし穴

- **分単位に給与を掛けて節約と呼ぶこと** — 典型的な誤りです。
- **解放された時間を、その限界的な使い道が低価値であるにもかかわらず、平均的な全負担コストで評価すること** — [限界費用と平均費用](../限界費用と平均費用/)を参照してください。
- **同じ1時間を二重に数えること**:現金(避けられたシフト)としてと、容量(追加で診た患者)として。
