# Направлення на лікування (RTT)

RTT вимірює час від першого направлення до початку лікування, зі стандартом 18 тижнів як головним національним показником продуктивності.

## Чому це важливо

RTT по суті є метрикою часу виконання доставки, застосованою до догляду за пацієнтами — скільки часу потрібно, щоб доставити цінність (лікування) після запиту (направлення).

## Математика

```
Дотримання RTT = Кількість пацієнтів, пролікованих протягом 18 тижнів / Загальна кількість пацієнтів у списку очікування RTT × 100%
```

## Розібраний приклад

Спеціальність з 5000 пацієнтами на шляху RTT, з яких 4100 лікуються протягом 18 тижнів: дотримання 82%, нижче національного стандарту 92%.

## Зв'язок з інженерією програмного забезпечення

Прямий аналог [часу виконання DORA](../dora-metrics/) — час від коміту (направлення) до доставки (лікування).

## Підводні камені

- **Неправильне застосування зупинок годинника (ініціатива пацієнта) для спотворення показників дотримання.**
- **Звертання уваги лише на середнє значення, коли хвіст розподілу є реальною проблемою.**
