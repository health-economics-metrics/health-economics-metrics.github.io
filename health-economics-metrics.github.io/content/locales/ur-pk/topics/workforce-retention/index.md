# افرادی قوت کی برقراری

افرادی قوت کی برقراری کی معاشیات یہ ماپتی ہے کہ عملے کی تبدیلی ایک صحت کے نظام کو کتنا خرچ کراتی ہے۔

## یہ کیوں اہم ہے

جب ایک معالج چلا جاتا ہے، ٹرسٹ تین بار ادا کرتا ہے: ایک متبادل بھرتی کرنے، انہیں شامل کرنے، اور اس دوران خالی جگہ کو پر کرنے کے لیے۔

## ریاضی

```
فی چھوڑنے والا قیمت = بھرتی کی قیمت + شمولیت/پیداواریت-اضافہ قیمت
                     + خالی جگہ کور پریمیم × خالی جگہ کی مدت
```

## حل شدہ مثال

ایک ٹرسٹ 1,200 نرسوں کو ملازم رکھتا ہے؛ تبدیلی 11%/سال۔ دستاویزی-بوجھ سافٹ ویئر: سالانہ £222,000۔

## سافٹ ویئر انجینئرنگ سے تعلق

انجینئرنگ برقراری کی ریاضی ایک جیسی ہے۔

## عام غلطیاں

- **تمام تبدیلی کی حرکت کو اپنی مداخلت سے منسوب کرنا۔**

## ذرائع

- NHS England, reducing agency spend.
- NHS Staff Survey.
