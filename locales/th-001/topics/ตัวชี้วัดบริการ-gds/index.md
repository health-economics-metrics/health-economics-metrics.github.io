# ตัวชี้วัดบริการ GDS

ตัวชี้วัดบริการ GDS (Government Digital Service) เป็นชุดตัวชี้วัดมาตรฐานที่ใช้ประเมินประสิทธิภาพของบริการดิจิทัลภาครัฐ รวมถึงความพึงพอใจของผู้ใช้ อัตราการเสร็จสิ้น และต้นทุนต่อธุรกรรม

## ทำไมจึงสำคัญ

ตัวชี้วัดเหล่านี้ให้กรอบที่สอดคล้องกันสำหรับบริการดิจิทัลภาครัฐ ซึ่งช่วยให้สามารถเปรียบเทียบระหว่างบริการและสร้างความรับผิดชอบต่อการใช้เงินภาครัฐ

## คณิตศาสตร์

```
ต้นทุนต่อธุรกรรม = ต้นทุนบริการรวม / จำนวนธุรกรรมที่เสร็จสิ้น
```

## ตัวอย่างที่คำนวณแล้ว

บริการต่ออายุใบสั่งยาดิจิทัลที่มีต้นทุน £500,000/ปีและประมวลผล 1 ล้านธุรกรรม มีต้นทุน £0.50 ต่อธุรกรรม เทียบกับ £8 สำหรับกระบวนการบนกระดาษ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการวัดข้อมูลทางไกลของผลิตภัณฑ์ที่ติดตามอัตราการเสร็จสิ้นของเส้นทางผู้ใช้ในบริการดิจิทัลโดยทั่วไป

## ข้อผิดพลาดที่พบบ่อย

- **การดูต้นทุนต่อธุรกรรมโดยไม่พิจารณาคุณภาพบริการหรือการเข้าถึง**
- **การเปรียบเทียบตัวชี้วัดบริการดิจิทัลระหว่างบริการที่มีความซับซ้อนต่างกัน**
