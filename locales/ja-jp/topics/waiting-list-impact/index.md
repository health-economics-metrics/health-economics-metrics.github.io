# 待機リストへの影響

待機リストへの影響は、節約された臨床容量を、待機リストから外れた(あるいはより速く進んだ)患者数に変換します。節約された時間を追加の診療枠に変換することは、トラストの待機リストの規模を直接削減します — これは、解放された容量が*何のためにあるか*を医療システムに示す最も具体的な方法です。

## なぜ重要か

選択的処置の待機リストは、パンデミック後のNHSを特徴づける課題であり(その規模は国の政治的な指標です)、すべてのトラストはそれに対する選択的処置回復プログラムを運用しています。「2,000看護師時間を節約する」というビジネスケースは抽象的ですが、「4,000件の追加予約枠を作り、3,800人の待機中の患者を診察し、その専門科のリストを9%削減する」というものは、最高執行責任者が理事会に持っていける物語です。待機リストへの影響は、[非現金化容量](../cash-releasing-vs-non-cash-releasing/)にとって自然な*会計単位*です。

## 数式

```
追加の枠         = 解放された時間 / 枠の長さ × 稼働率
診察された患者   = 追加の枠 × (1 − DNA率)
リストの削減     = 診察された患者 − 誘発された新規需要
待機時間の改善   = より高いサービス率によるキューの改善
                  (安定したキューでは、サービス率μで滞留Nを
                   ΔN削減すると、全員が~ΔN/μだけ前に進む)
```

待機短縮の健康価値:患者は、治療前のより低い効用状態で過ごす週数が少なくなります — [紹介から治療まで](../referral-to-treatment/)のQALY計算です。

## 計算例

アンビエント文書作成ソフトウェアが、20人の診療所看護師それぞれについて1日45分を節約します。250日にわたって:20 × 0.75 × 250 = 年間3,750時間。

```
枠(30分、85%利用可能) = 3,750 / 0.5 × 0.85 = 6,375枠
診察された患者(DNA率7%) = 6,375 × 0.93       ≈ 年間5,929人
```

12,000人のリストと年間24,000件の需要に見合った容量を持つ専門科では、約5,900件の追加予約が平均待機をおよそ4分の1削減します — 雇用なしでトラストを18週間基準に実質的に近づけます。受診1件あたり約£160の制度上の価値で、この活動は年間約£949,000の価値があります([全国診療報酬と単位費用](../national-tariff-and-unit-costs/)を参照) — しかし、まず*待機リスト*の枠組みを提示してください;それがシステムが管理されている単位です。

## ソフトウェア工学との関連

待機リストはバックログであり、バックログ消化の経済学は双方向に転用できます。医療からソフトウェアへ:バックログ削減を、閉じたアイテム数ではなく、*利用者*が価値をどれだけ待つかで評価してください(キューに入れられたアイテムあたりの[遅延コスト](../cost-of-delay/))。ソフトウェアから医療へ:リトルの法則は、サービス率が到着率を上回る場合にのみリストが縮小すると言います — 増加する紹介によって吸収された容量の獲得は待機を変えないため、到着もモデル化してください。そしてどちらの領域でも、先入れ先出しではなく、重症度で重み付けした価値(臨床的な緊急度のカテゴリー ↔ [重症度修正因子](../qaly-shortfall-and-severity-modifiers/))で優先順位を付けてください。

## 落とし穴

- **枠 ≠ 患者**:DNA率と、解放された時間の使えない断片を忘れること。
- **誘発需要**:目に見える追加の容量は紹介を引き寄せます;正味のリストへの影響は総額よりも小さくなります。
- **現金を主張すること**:待機リストへの影響は容量の価値です;現金の主張(バックログ作業の外部委託の回避)は別の項目です — [回避可能な外部委託費用](../avoidable-outsourcing-costs/)を参照してください。
