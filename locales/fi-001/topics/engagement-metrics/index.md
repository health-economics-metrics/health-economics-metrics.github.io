# Sitoutumismittarit

Sitoutumismittarit mittaavat, kuinka usein ja kuinka syvästi käyttäjät ovat vuorovaikutuksessa terveyssovelluksen tai digitaalisen palvelun kanssa: aktiiviset käyttäjät, istuntotaajuus, viipymisaika.

## Miksi se on tärkeä

Terveyssovellus ilman sitoutumista ei voi vaikuttaa — riippumatta siitä, kuinka vahva kliininen näyttö on.

## Matematiikka

```
DAU/MAU-suhde = päivittäin aktiiviset käyttäjät / kuukausittain aktiiviset käyttäjät
```

## Ratkaistu esimerkki

Diabeteksenhallintasovellus: DAU 3 000, MAU 12 000 = 0,25 (hyvä terveyssovellukselle).
