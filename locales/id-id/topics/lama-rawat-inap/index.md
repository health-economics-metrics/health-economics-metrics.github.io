# Lama Rawat Inap (LOS)

Lama rawat inap adalah jumlah hari dari masuk rumah sakit hingga pemulangan.

## Mengapa ini penting

LOS mengendalikan hampir semua ekonomi rumah sakit akut: kapasitas tempat tidur, throughput elektif, staf.

## Matematika

```
LOS (per episode) = tanggal pemulangan − tanggal masuk
LOS rata-rata = hari tempat tidur yang ditempati / pemulangan
```

## Contoh yang diselesaikan

Sebuah trust merawat 40 pasien medis darurat per hari dengan LOS rata-rata 6,0 hari: 240 tempat tidur ditempati secara permanen.

## Hubungan dengan rekayasa perangkat lunak

LOS adalah waktu siklus rumah sakit.

## Jebakan

- **Pelaporan hanya rata-rata.**
