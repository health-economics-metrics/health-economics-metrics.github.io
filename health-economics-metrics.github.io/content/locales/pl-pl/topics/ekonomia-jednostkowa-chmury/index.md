# Ekonomia jednostkowa chmury

Ekonomia jednostkowa chmury mierzy koszt infrastruktury na pojedynczą transakcję, pacjenta lub żądanie.

## Dlaczego to ważne

Rachunki za chmurę pokazują sumę całkowitą, ale nie która funkcja lub ścieżka pacjenta powoduje koszt.

## Matematyka

```
Koszt jednostkowy = wydatki na chmurę (£/miesiąc) / wolumen transakcji (miesięcznie)
```

## Rozwiązany przykład

Usługa przechowywania obrazów: £40 000/miesiąc, 200 000 skanów = £0,20 za skan.

## Powiązanie z inżynierią oprogramowania

Rozkłada [całkowity koszt posiadania](../całkowity-koszt-posiadania/) na skalę operacyjną.

## Pułapki

- **Ignorowanie rabatów rezerwacyjnych i obliczanie po cenach na żądanie.**
