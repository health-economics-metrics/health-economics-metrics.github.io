# ความสามารถในการสร้างมูลค่า (การพลิกฟื้นการดำเนินงาน)

ความสามารถในการสร้างมูลค่าวัดว่ามีความจุทางคลินิกเพิ่มเติมเท่าใดที่ถูกสร้างขึ้นผ่านการปรับปรุงการดำเนินงาน โดยไม่ต้องจ้างพนักงานเพิ่มเติม

## ทำไมจึงสำคัญ

การ "สร้าง" ความจุใหม่ผ่านประสิทธิภาพมักเร็วกว่าและถูกกว่าการสรรหาพนักงาน โดยเฉพาะในสาขาที่ขาดแคลนพนักงาน

## คณิตศาสตร์

```
ความจุที่สร้างขึ้น = (ความจุเดิม × เปอร์เซ็นต์ประสิทธิภาพที่ได้รับ) − ต้นทุนการดำเนินการ แปลงเป็นความจุเทียบเท่า
```

## ตัวอย่างที่คำนวณแล้ว

การพลิกฟื้นการดำเนินงานของแผนกเอกซเรย์เพิ่มความจุการสแกน 30% ผ่านการเพิ่มประสิทธิภาพตารางงาน เทียบเท่ากับการจ้างนักรังสีวิทยาเพิ่ม 3 คนโดยไม่มีต้นทุนการสรรหา

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการเพิ่มความถี่ในการปรับใช้ผ่านการเพิ่มประสิทธิภาพไปป์ไลน์ แทนที่จะจ้างวิศวกรเพิ่มเพื่อส่งมอบปริมาณงานเดียวกัน

## ข้อผิดพลาดที่พบบ่อย

- **การประเมินต้นทุนการดำเนินการของการเปลี่ยนแปลงต่ำเกินไป**
- **การอ้างผลประโยชน์ที่จริงแล้วมาจากความพยายามพิเศษชั่วคราว ไม่ใช่การเปลี่ยนแปลงถาวร**
