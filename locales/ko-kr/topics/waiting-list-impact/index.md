# 대기 명단 영향

대기 명단 영향은 절약된 임상 용량을 대기 명단에서 제거된(또는 더 빠르게 통과한) 환자로 전환합니다.

## 왜 중요한가

선택적 대기 명단은 NHS를 정의하는 팬데믹 이후 과제입니다.

## 수식

```
추가 슬롯 = 해방된 시간 / 슬롯 기간 × 활용도
```

## 계산 예시

주변 문서화 소프트웨어가 20명의 클리닉 간호사 각각에 대해 하루 45분을 절약합니다.

## 소프트웨어 공학과의 연관성

대기 명단은 백로그입니다.

## 함정

- **슬롯 ≠ 환자.**
