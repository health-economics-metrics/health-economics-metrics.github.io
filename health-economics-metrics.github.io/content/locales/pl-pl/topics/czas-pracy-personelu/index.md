# Czas pracy personelu

Czas pracy personelu powinien być wyceniany jako zdolność wąskiego gardła — to, co system może dostarczyć — a nie tylko jako koszt płac.

## Dlaczego to ważne

Zaoszczędzona godzina lekarza jest często o wiele bardziej wartościowa, niż sugeruje stawka godzinowa lekarza, ponieważ czas lekarza jest wiążącym ograniczeniem zdolności systemowej.

## Matematyka

```
Wartość zaoszczędzonego czasu = Zaoszczędzone godziny × cena cienia zdolności wąskiego gardła
```

## Rozwiązany przykład

Radiolog zarabia £80/godzinę, ale każda zaoszczędzona godzina radiologa efektywnie umożliwia £300 przepustowości pacjentów niżej w łańcuchu z powodu presji kolejki.

## Powiązanie z inżynierią oprogramowania

Przypomina wycenę czasu starszego architekta na podstawie wartości wąskiego gardła jego decyzji, a nie tylko pensji.

## Pułapki

- **Używanie tylko kosztu płac do wyceny zaoszczędzonego czasu.**
- **Nadawanie rolom niebędącym wąskim gardłem tej samej ceny cienia co rolom będącym wąskim gardłem.**

## Źródła

- Goldratt EM, Theory of Constraints.
