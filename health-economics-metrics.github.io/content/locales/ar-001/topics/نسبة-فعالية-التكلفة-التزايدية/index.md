# نسبة فعالية التكلفة التزايدية (ICER)

ICER هي التكلفة الإضافية لكل وحدة إضافية من الأثر الصحي عند اختيار خيار على البديل الأفضل-التالي. إنه الرقم الرئيسي لتقييم التقنية الصحية. (عندما تكون وحدة الأثر QALY، يُسمَّى أيضًا نسبة التكلفة والمنفعة التزايدية، ICUR.)

## لماذا يهم هذا

أنظمة الصحة لا تُقيِّم تقنية بمعزل عن غيرها أبدًا - دائمًا *تزايديًا*، مقابل ما سيُفعَل بدلًا من ذلك. NICE تقارن نسبة ICER الخاصة بتقنية مع عتبتها البالغة **20,000-30,000£ لكل QALY**؛ معهد ICER الأمريكي يُقرِّر عبر 50,000-200,000 دولار/QALY؛ كندا تعمل عند نحو 50,000 دولار كندي/QALY. هل منتجك "يستحق ذلك" لنظام صحة وطني هو، رسميًا، هل تجتاز نسبة ICER الخاصة به العتبة المحلية. انظر [عتبات الاستعداد للدفع](../عتبات-الاستعداد-للدفع/).

## طريقة الحساب

```
ICER = (التكلفة_الجديدة − التكلفة_المقارِنة) / (الأثر_الجديد − الأثر_المقارِن)
     = ΔC / ΔE
```

قواعد التفسير:

- ΔC < 0، ΔE > 0: الخيار الجديد **يهيمن** - أرخص وأفضل؛ لا نسبة مطلوبة.
- ΔC > 0، ΔE > 0: احسب ICER، قارنها بالعتبة λ؛ تبنَّ إذا كانت ICER < λ.
- ΔC > 0، ΔE < 0: الخيار الجديد مُهيمَن عليه - ارفض.
- النسب تتصرف بشكل سيء قرب ΔE = 0 - فضِّل [شُدد المنفعة النقدية](../صافي-المنفعة-النقدية/) للترتيب.

المقارِن يجب أن يكون *أفضل خيار غير مُهيمَن عليه تاليًا*، لا "لا تفعل شيئًا" - انظر [الهيمنة وحدود الكفاءة](../الهيمنة-وحدود-الكفاءة/).

## مثال محلول

خدمة مراقبة عن بُعد لمرضى فشل القلب، لكل 1,000 مريض/سنة، مقابل الرعاية المعتادة:

```
التكاليف: الخدمة 900,000£؛ حالات الدخول المُتجنَّبة توفّر 600,000£
         ΔC = 900,000 − 600,000 = 300,000£
الآثار:   التدخل الأسبق يكسب 25 QALY
         ΔE = 25

ICER = 300,000 / 25 = 12,000£ لكل QALY
```

12,000£/QALY أدنى بشكل مريح من عتبة NICE البالغة 20,000£ - حالة قوية. لاحظ كيف تهم التكلفة *الصافية*: بدون مقاصّة 600,000£ ستكون ICER 36,000£/QALY والحالة ستفشل على الأرجح. مقاصّات التكلفة وجودة أدلتها هي حيث تُكسَب وتُفقَد هذه التحليلات (انظر [التكاليف المصبّية المُتجنَّبة](../التكاليف-المصبية-المتجنبة/)).

## الصلة بهندسة البرمجيات

انضباط ICER ينتقل بالكامل إلى قرارات الهندسة:

```
(تكلفة الخيار B − تكلفة الخيار A) / (نتيجة B − نتيجة A)
```

- تكلفة تزايدية لكل نشر إضافي، لكل ساعة مهندس مُوفَّرة، لكل حادثة مُتجنَّبة - دائمًا مقابل البديل الأفضل-التالي، لا مقابل عدم فعل شيء. عادتان تستحقان السرقة: (1) *سمِّ المقارِن صراحةً*؛ أغلب دعاوى ROI للأدوات تقارن سرًا مقابل رجل قش؛ (2) *اطرح التكاليف أولًا* - أداة تكلّف 100 ألف£ لكن تستبدل 80 ألف£ من إنفاق موجود لها ΔC = 20 ألف£.

## المزالق

- **خداع المقارِن**: المقارنة مقابل خط أساس عفا عليه الزمن أو سيء بشكل مصطنع تُضخِّم ΔE وتُجمِّل ICER.
- **متوسطات بدلًا من تزايدات**: التكلفة لكل QALY لبرنامج كامل ليست ICER لتوسيعه أو تبنّيه.
- **عبادة التقدير النقطي**: نسب ICER هي نسب فارقين غير مؤكَّدين؛ أبلِغ عن عدم اليقين عبر [PSA وCEAC](../تحليل-الحساسية-الاحتمالي/).
- **نسب ICER السالبة غامضة** (أرخص-وأفضل مقابل أغلى-وأسوأ تُعطيان العلامة نفسها) - لا تُبلِغ أبدًا عن نسبة ICER سالبة دون ذكر أي ربع هي.
- **مقارنة ICER عبر العملات دون خطوة تحويل صريحة**: يجب تحويل ICER المحسوب بعملة بلد ما بطريقة معلنة قبل مقارنته بعتبة بلد آخر — انظر [مقارنة ICER عبر العملات](../مقارنة-icer-عبر-العملات/) لمعرفة لماذا يمكن أن يقلب اختيار معامل التحويل (تعادل القوة الشرائية مقابل سعر الصرف السوقي) قرار الاعتماد بذاته.
