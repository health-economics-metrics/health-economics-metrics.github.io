# चिकित्सक समय

चिकित्सक समय अधिकांश स्वास्थ्य प्रणालियों में सबसे दुर्लभ संसाधन है। इसके मूल्यांकन के लिए सरल वेतन गणित से **अवसर लागत और प्रणाली क्षमता** की ओर बदलाव की आवश्यकता है।

## यह क्यों महत्वपूर्ण है

आप जल्दी से अधिक GP, परामर्शदाता, या विशेषज्ञ नर्स नहीं बना सकते।

## गणित

```
1. वेतन आधार:     घंटे × पूर्ण-आवंटित वेतन दर
2. आउटपुट आधार:   घंटे → सक्षम नियुक्तियाँ × योजना मूल्य
3. बाधा आधार:      यदि यह भूमिका पूरे मार्ग को नियंत्रित करती है
```

## हल किया गया उदाहरण

एम्बिएंट स्क्राइबिंग एक GP के प्रति परामर्श 2 मिनट बचाता है, प्रतिदिन 30 परामर्श: **प्रति GP सालाना 220 घंटे**।

```
वेतन आधार: 220 × £80 ≈ प्रति GP सालाना £17,600
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

वरिष्ठ इंजीनियर का समय उसी तरह व्यवहार करता है।
