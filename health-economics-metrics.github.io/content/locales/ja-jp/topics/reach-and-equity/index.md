# 到達範囲と公平性

RE-AIM — 到達範囲、有効性、採用、実装、維持 — は、介入の*集団への*影響を判断するための標準的な枠組みです。その中心的な計算:**公衆衛生への影響≈到達範囲×有効性**。デジタルツールは公平性の次元を加えます:デジタルデバイドは到達範囲が体系的に不均一であることを意味し、デジタルファーストの提供は、それが埋めようとしている健康格差を広げることがあります。

## なぜ重要か

mHealthにRE-AIMを適用した系統的レビューは、一貫したパターンを見つけています:強い到達範囲と採用、**弱い有効性と維持** — アプリは容易に広まり、速く衰えます。国の医療サービスにとって、これは、1人あたりでは印象的な製品が集団への投資としては乏しいものになり得ることを意味し、その逆もまた然りです:何百万人にも到達する適度に効果的なツールは、何千人にしか到達しない優れたツールを上回る成果を出すことがあります([HALE](../health-adjusted-life-expectancy/)の計算を参照)。公平性は副次的な制約ではなく価値の推進力です:デジタル排除は、年齢、貧困、障害、言語を追跡します — まさに最も治療可能な負担を抱える集団です — したがって、限界的に排除される利用者は、しばしば*平均以上*の潜在的な便益を持ちます。

## 数式

```
集団への影響 ≈ 到達範囲 × 有効性
  到達範囲 = 参加者数 / 対象人口(アクティベーションと普及を参照)
  有効性   = 参加者の間での実世界の効果(定着で重み付け —
            定着と離脱を参照)

公平性で層別化されたバージョン:
  影響_集団g = 到達範囲_g × 有効性_g、貧困の五分位/年齢層/
  言語グループごとに報告される
  公平性のギャップ = 最上位五分位の影響 − 最下位五分位の影響

分配的費用効果:受益者グループごとにQALYに公平性の重みを適用する —
最も恵まれない人々へのQALYはより高く数えられる(ますます主流になっている
HTAの拡張)。
```

## 計算例

あるデジタル糖尿病予防プログラム、2通りの方法で報告:

```
集計:到達範囲12%、効果0.02QALY/参加者 → 対象1人あたり0.0024QALY

層別化(貧困の五分位):
  Q1(最も貧困でない):到達範囲22%、効果0.02 → 0.0044
  Q5(最も貧困):     到達範囲4%、 効果0.025 → 0.0010

このプログラムは、最も貧困でない人々に4.4倍多くの健康を届けています —
一方でQ5の参加者1人あたりの効果は「より高い」(より多くの伸びしろ)。
Q5参加者1人あたり20%多い費用がかかる支援付きデジタルの部門(電話コーチング
+コミュニティアクセス)がQ5の到達範囲を12%に引き上げると、Q5の影響は
3倍になり、集計も改善します — ここでは公平性への投資が効率への投資「そのもの」です。
```

## ソフトウェア工学との関連

到達範囲は実質的にエンジニアリングの成果物です:機器とOSの下限要件、帯域幅の前提、言語サポート、アクセシビリティ適合(WCAG)、本人確認のハードル、アプリストアのみの配布は、それぞれ分母から集団を切り取ります — 通常は目に見えない形で、なぜなら排除された利用者は決して分析に現れないからです。公平性を動かすエンジニアリングの実践:*分母*を測定すること(利用者だけでなく対象人口を計測すること);古い機器と貧弱な接続性のためにパフォーマンスの予算を組むこと;支援付きデジタル経路(電話、SMS、キオスク)を恥ずべきチャネルとしてではなく第一級のフローとして出荷すること;そしてあらゆるダッシュボードのメトリクスを公平性の次元で層別化すること — 層別化されていない平均は不公平が隠れる場所です([GDSの利用率](../gds-service-metrics/)も同じ警告を伴います)。

## 落とし穴

- **完了者について報告される有効性、集団について主張される影響** — 到達範囲の項が静かに落とされています。
- 設計上の入力ではなく**後付けの監査としての公平性**;到達範囲を後付けすることは、それを設計することよりもはるかに費用がかかります。
- **維持の健忘症**:RE-AIMの最も弱いmHealthの次元 — 証拠の評価期間を超えた影響の主張。
- 費用を排除された利用者と最前線のスタッフに移すだけの**デジタル専用チャネルの節約**([GDSサービスメトリクス](../gds-service-metrics/)を参照)。
