# 獲得的生命年（LYG）

獲得的生命年，是指某項介入所帶來的額外生存時間，不作任何品質調整：即"有該介入"與"無該介入"兩條生存曲線之間的面積。等值獲得生命年（evLYG）是一種現代變體，對所有延長的生命一視同仁地賦予相同價值。

## 為何重要

獲得的生命年是最原始的健康結果指標：人們究竟多活了多久？在缺乏品質資料時、在面對對QALY持懷疑態度的受眾時，以及在腫瘤學領域（生存曲線是主要的試驗產出）中，這一指標都至關重要。**evLYG**（美國ICER研究所在每QALY成本之外同時採用的指標）的存在有其倫理學上的原因：QALY是按病患本人的效用值來衡量延長一年生命的價值，因此延長一名殘障人士的生命，在計算上會"算得更少"——而evLYG則以固定效用值來衡量每一個被延長的年份，從而消除了這種歧視性。

## 計算方法

```
獲得的生命年 = 新方案下的平均生存時間 − 對照方案下的平均生存時間
            = 生存曲線之間的面積（限定在所考察的時間範圍內）

生命延長的QALY視角：   延長時間 × 病患本人的效用值
生命延長的evLYG視角：  延長時間 × 固定效用值（ICER採用約0.851，
                      即美國人群的平均效用值）
```

在經濟學模型中，二者都需要進行[貼現](../貼現與時間偏好/)。

## 實例演算

某醫院的膿毒症早期預警演算法：建模顯示，更早使用抗生素每年可預防12例死亡；這些病患的平均年齡意味著每人平均還剩8年生命，效用值為0.7。

```
獲得的生命年 = 12 × 8            = 每年96個生命年
QALY        = 96 × 0.7          = 67.2
evLYG       = 96 × 0.851        = 81.7
```

按每QALY £20,000計算，QALY口徑下這部分生存獲益價值為每年£134萬；而evLYG口徑下則為£163萬。這一差距，恰恰體現了"一個效用值為0.7的生命年，是否應算作一個'完整'生命年價值的70%"這一倫理判斷本身。嚴謹的申報材料應同時報告這兩種口徑。

## 與軟體工程的聯絡

- 生存分析是雙方共用的工具箱：用於病患的Kaplan-Meier曲線，與用於*服務*的曲線（故障間隔時間、流失間隔時間）遵循同一套數學原理。某項可靠性投資帶來的"獲得的服務年數"= 該系統"有該投資"與"無該投資"兩條生存曲線之間的面積——這比單點的平均故障間隔時間（MTTF）主張更為誠實。
- evLYG同樣對工程領域的指標設計提出了警示：任何按"團隊品質"因子對產出加權的生產力指標，都會系統性地低估那些資源受限或正在掙扎中的團隊所取得的改進——有時你恰恰應當有意選擇"等值"這一變體。

## 陷阱

- **中位數與均值生存時間的混淆**：經濟學模型需要的是均值（即曲線下面積）；而試驗結果通常以中位數作為頭條數位呈現。在偏斜分佈下，二者可能相差很大。
- **超出試驗隨訪期的外推**，在慢性病建模中往往主導著"獲得的生命年"這一數位——應明確說明所採用的外推模型，並在[敏感性分析](../敏感性分析/)中對其進行檢驗。
- **僅憑觀察性的前後對比資料就主張預防了多少例死亡**，而未對病例組合與長期趨勢做調整。
