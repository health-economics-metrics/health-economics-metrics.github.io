# EQ-5D

EQ-5D는 건강 관련 삶의 질을 측정하기 위한 EuroQol 그룹의 표준화된 설문지입니다.

## 왜 중요한가

QALY를 주장하고자 하는 모든 디지털 헬스 제품은 검증된 도구로부터의 효용이 필요합니다.

## 수식

```
건강 상태 = 5자리 프로필, 예: "21221"
효용 지수 = 가치_세트(프로필)
```

## 계산 예시

근골격계 재활 앱이 등록 시점과 6개월 후에 EQ-5D-5L을 측정합니다.

## 소프트웨어 공학과의 연관성

**이를 계측하세요.**

## 함정

- **비교군 없는 전후 비교.**
- **가치 집합을 자기 정당화적인 것으로 취급하기**: 가치 집합이 반환하는 효용값은 그 자체가 시간교환(또는 관련 선택 기반) 조사를 통해 일반 대중으로부터 도출된 것입니다. 방법은 [시간교환(TTO) 효용 도출](../시간교환-tto-효용-도출/)을 참고하세요.

## 출처

- EuroQol: EQ-5D-5L.
- NICE health technology evaluations: the manual (PMG36).
