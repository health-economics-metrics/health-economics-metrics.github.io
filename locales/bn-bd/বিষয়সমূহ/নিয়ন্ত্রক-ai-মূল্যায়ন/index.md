# নিয়ন্ত্রক AI মূল্যায়ন

স্বাস্থ্যসেবায় AI নিয়ন্ত্রণকারী নিয়ন্ত্রক কাঠামো — FDA-র Software as a Medical Device (SaMD) ব্যবস্থা **পূর্ব-নির্ধারিত পরিবর্তন নিয়ন্ত্রণ পরিকল্পনা (PCCP)**সহ।

## কেন এটি গুরুত্বপূর্ণ

নিয়ন্ত্রণ **মার্কেট এন্ট্রির প্রমাণ ব্যয়** এবং **প্রতিটি পরবর্তী মডেল আপডেটের ব্যয়** উভয়ই নির্ধারণ করে। **PCCP নির্দেশিকা (ডিসেম্বর ২০২৪ চূড়ান্ত)** অর্থনীতি পরিবর্তন করেছে।

## গণিত

```
প্রতি মডেল আপডেটের ব্যয় (ঐতিহ্যবাহী) = পুনঃজমাদান ব্যয় + পর্যালোচনা বিলম্ব × CoD
প্রতি মডেল আপডেটের ব্যয় (PCCP-নির্দিষ্ট) = শুধুমাত্র প্রোটোকল-নির্বাহ ব্যয়
```

## সমাধানকৃত উদাহরণ

একটি রেডিওলজি-AI বিক্রেতা ৩ বছরে ত্রৈমাসিক মডেল উন্নতি পরিকল্পনা করে (১২টি আপডেট):

```
ঐতিহ্যবাহী: 12 × (£80k জমাদান + 4 মাস × £50k/মাস বিলম্বিত-সুবিধা CoD) = £3.36M
PCCP পথ:  £250k PCCP রচনা + 12 × £30k প্রোটোকল নির্বাহ = £610k
সাশ্রয় ≈ £2.75M
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

PCCP-কে ভালোভাবে প্রকৌশলী করা একটি সফটওয়্যার সমস্যা: পূর্ব-নির্দিষ্ট মূল্যায়ন স্যুট, সংস্করণযুক্ত ডেটাসেট, স্বয়ংক্রিয় যাচাইকরণ পাইপলাইন।

## ঝুঁকিপূর্ণ দিক

- **PCCP সুযোগ-বৃদ্ধির স্বপ্ন**: শুধুমাত্র *নির্দিষ্ট* পরিবর্তনের ধরন পূর্ব-অনুমোদিত।
- **নিরীক্ষণহীন প্রকৃত-বিশ্ব প্রবাহ**।
