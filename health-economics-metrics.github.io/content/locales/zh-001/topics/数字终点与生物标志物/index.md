# 数字终点与生物标志物

数字生物标志物是通过传感器采集的、客观的生理或行为测量指标（来自手机的步态速度、来自可穿戴设备的睡眠数据、来自加速度计的震颤数据）。数字终点则是将这样一种测量指标提升为**试验结果指标**——用以证明治疗效果。从"设备产生的数据"晋升为"监管机构认可的证据"，需要经过一套明确界定的验证阶梯。

## 为何重要

传统的试验终点是片段性的（每3个月一次门诊访视），且成本高昂；数字终点则是连续的、生态化的（真实生活场景，而非门诊表现），且单次观测成本低廉——它们能够缩小试验规模、更早检测到效应，并支持去中心化研究。但其代价在于验证：被广泛接受的框架（与FDA标准一致，包含三大支柱）要求：**验证/分析层面的确认**（传感器能否准确测量该物理量）、**临床验证**（该测量指标是否真实反映其所声称代表的临床状态），以及被证实具有**对健康有意义的方面**（患者是否真的在意它所捕捉的内容）。缺少这三者中任何一项，得到的都只是遥测数据，而非证据。

## 计算方法

```
分析验证：与参照标准的一致性（参见wearable-validation.md——
          MAPE、CCC、Bland-Altman法）
临床验证：与临床锚点之间的相关性/区分能力
          （已知组别效度、对变化的响应能力）
终点经济学：
  每患者-年检测到的事件数（连续监测） 对比 按访视抽样
  试验功效：当访视间方差占主导时，连续测量能减少所需样本量
  ——N ∝ σ²/Δ²，而σ²会随采样密度增加而下降
```

## 实例演算

某帕金森病试验，比较腕部传感器采集的步态速度与季度门诊评分：

```
门诊终点：  每患者每年4次测量，日间波动噪声较大
数字终点：  每患者每年约200次被动测量

年度变化估计值的方差随采样密度提升下降约5倍 →
在固定功效下，可检测的效应量提升约√5 ≈ 2.2倍，
等价于在相同假设检验下，样本量可减少约40–60%。
按每名入组患者£25,000计算，减少200名患者
约相当于每项试验节省£500万——这正是那笔验证投资
（本身或许需要100万–200万英镑）在赞助方整条产品管线中
所对应的商业论证。
```

## 与软件工程的联系

数字终点本质上是一门披着临床外衣的数据工程学科：**来源可追溯性与版本管理**（研究进行期间对算法的更新会威胁到结果的可比性——这正是[PCCP](../AI监管评估/)问题在试验场景中的对应形态；应锁定版本并进行桥接验证）；**缺失数据的设计处理**（佩戴时间的缺口本身就是有信息量的，而非随机的——参见[可穿戴设备验证](../可穿戴设备验证/)；插补方式的选择本身就是一种科学主张）；以及**边缘/云端拆分决策**会改变日后究竟哪些原始信号还能被恢复。从第一天起就将测量流水线当作受监管软件来对待——经过测试、有版本管理、有文档记录——的团队，能以较低成本换来其终点数据的可信度；而在一条快速迭代的流水线上事后补做验证，正是数字终点项目走向失败的常见原因。

## 陷阱

- **将"与门诊结果相关"当作完整验证**：与一个本身有缺陷的门诊测量指标相吻合，只能证明其"继承了"该缺陷，并不能证明其真实性；应针对真正有意义的健康方面进行验证。
- **新型终点的监管风险**：一个前所未有的终点可能在科学上更为优越，却仍可能导致申报失败——应尽早与监管机构接触（相关资格认定项目是存在的）。
- **传感器与目标人群不匹配**：在年轻健康人群的手腕上完成验证，却部署到患有震颤、且皮肤色素差异是PPG（光电容积描记）传感器从未见过的老年患者身上。
- **特征漂移**：在新数据上重新训练步态算法，会在研究进行过程中悄然重新定义该终点本身。
