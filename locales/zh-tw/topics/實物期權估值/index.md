# 實物期權估值 (Real Options Valuation)

實物期權估值把金融期權定價的邏輯應用於真實的（不在金融市場交易的）投資決策——具體而言是*擴張期權*：若專案成功，日後擴大該專案的權利，而無需承擔必須這樣做的義務。簡化的單期二叉樹模型（Cox、Ross、Rubinstein，1979）可以直接為這種靈活性估值，把“先小規模交付，再看情況”從直覺變成可定價的數位。

## 為什麼重要

靜態現值計算把專案當作“全有或全無”的賭注來定價：按今天的規模資助或不資助，永遠如此。真實專案——尤其是分階段推廣的數位健康專案——很少這樣安排：衛生系統可以資助一個小試點，看看結果，只有在它有效時才追加投入。這種靈活性有真實的價值，忽視它會系統性地低估分階段投資相對於一次性投資的價值，這恰恰與獎勵看起來更安全的分階段提案的採購流程相反。實物期權估值為靈活性本身定價，使分階段的提案可以與全額承諾的備選方案公平比較，而不是因為在樸素的現值一行上顯得更小而受罰。

## 計算方法

```
“上漲”狀態的風險中性機率：
  p = ((1 + 無風險利率) − 下跌因子) / (上漲因子 − 下跌因子)

每個狀態下的擴張收益（下限為零——擴張是可選的）：
  收益_上漲 = max(專案價值 × 上漲因子 − 擴張成本, 0)
  收益_下跌 = max(專案價值 × 下跌因子 − 擴張成本, 0)

期權價值（折現後的期望收益）：
  期權價值 = (p × 收益_上漲 + (1 − p) × 收益_下跌) / (1 + 無風險利率)

擴充套件 NPV = 靜態_npv + 期權價值
```

專案價值到下一個決策點要麼上漲（`上漲因子`），要麼下跌（`下跌因子`）。只有在該狀態下有利可圖時才行使擴張——收益的零下限正是使它成為真正的*期權*而非義務的原因。關於如何為先收集資訊的期權（而不是日後擴張的期權）定價，見[完全資訊期望價值](../完美資訊期望價值/)。關於等待這一決策的成本，見[延遲成本](../延遲成本/)。

## 算例

一個數位服務試點，`專案價值 = £1,000,000`，到下一個決策點可能上漲至 1.5 倍或下跌至 0.5 倍，無風險利率 8%，擴張成本 £600,000：

```
p = (1.08 − 0.5) / (1.5 − 0.5) = 0.58

收益_上漲 = max(1,000,000 × 1.5 − 600,000, 0) =  900,000
收益_下跌 = max(1,000,000 × 0.5 − 600,000, 0) = max(−100,000, 0) = 0

下限起作用：若市場令人失望，該期權將不會被行使——
擴張成本 £600,000 超過專案在“下跌”狀態下價值的 £500,000。

期權價值 = (0.58 × 900,000 + 0.42 × 0) / 1.08
         = 522,000 / 1.08
         ≈ £483,333.33
```

把期權價值加到靜態 NPV 基數 £200,000 上：擴充套件 NPV = 200,000 + 483,333.33 ≈ **£683,333.33**。只報告靜態 NPV £200,000 而沒有這一期權的價值，會把分階段專案的真實價值低估一倍以上。

## 與軟體工程的關聯

這是“現在先交付最小版本，保留在它見效時追加投資的選擇權”的形式化版本——與數位健康產品的分階段推廣直接相關，在結構上與[延遲成本](../延遲成本/)和 [WSJF 與 CD3](../WSJF與CD3/)中不確定性下的排序框架平行，並與[完全資訊期望價值](../完美資訊期望價值/)和[樣本資訊期望價值](../樣本資訊期望價值/)互補——三者從不同角度為不確定性下的靈活性或資訊定價。

## 陷阱

- **借用風險中性定價卻不具備其依賴的可交易資產假設**：實物期權模型借用金融期權定價中的風險中性機率，而它假定標的價值是*可交易*資產——對真正不可交易的實際專案，這是建模的便利，而不是字面意義上的市場事實。
- **把 `上漲因子`/`下跌因子` 當作自由引數**：二叉樹的上漲/下跌輸入本身就是需要論證的假設，不是為了得到想要的答案而挑選的自由引數。
- **只報告期權價值**：實物期權的價值是*加到*獨立專案的靜態 NPV 上的——常見錯誤是隻報告期權價值而省略基準情形，這在靜態 NPV 為負時誇大了論證，而在完全省略靜態 NPV 時（如上面的算例）又低估了它。
