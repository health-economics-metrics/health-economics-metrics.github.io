# ความขาดแคลน QALY และตัวปรับความรุนแรง

ตัวปรับความรุนแรงเพิ่มน้ำหนักให้กับ QALY ที่ได้รับจากการรักษาผู้ป่วยที่มีความขาดแคลนสุขภาพรุนแรงกว่า เพื่อสะท้อนความเสมอภาคในการจัดสรรทรัพยากร

## ทำไมจึงสำคัญ

วิธี ICER มาตรฐานปฏิบัติต่อ QALY ทุกหน่วยเท่ากัน แต่สังคมมักให้คุณค่ากับการช่วยเหลือผู้ป่วยที่ป่วยหนักที่สุดมากกว่า — ตัวปรับความรุนแรงพยายามจับความชอบทางศีลธรรมนี้เข้าไปในกรอบการตัดสินใจ

## คณิตศาสตร์

```
QALY ที่ปรับน้ำหนักแล้ว = QALY ดิบ × ตัวปรับความรุนแรง (1.0–1.7 ขึ้นอยู่กับความขาดแคลนสุขภาพสัมบูรณ์และสัดส่วน)
```

## ตัวอย่างที่คำนวณแล้ว

NICE ใช้ตัวปรับ 1.2 สำหรับความขาดแคลน QALY ปานกลางและ 1.7 สำหรับความขาดแคลนรุนแรง หมายความว่าการรักษาโรครุนแรงสามารถมี ICER สูงกว่าเกณฑ์มาตรฐานถึง 70% และยังคงได้รับการอนุมัติ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการให้ลำดับความสำคัญสูงกว่ากับการแก้ไขข้อบกพร่องที่ส่งผลกระทบต่อผู้ใช้ที่ได้รับผลกระทบรุนแรงที่สุดอยู่แล้ว (เช่น ผู้ใช้ที่มีความพิการ) แม้ว่าจำนวนผู้ใช้ที่ได้รับผลกระทบจะน้อยกว่าก็ตาม

## ข้อผิดพลาดที่พบบ่อย

- **การใช้ตัวปรับความรุนแรงโดยไม่มีหลักฐานที่แข็งแกร่งเกี่ยวกับความขาดแคลนสุขภาพที่แท้จริง**
- **การปฏิบัติต่อตัวปรับเป็นค่าคงที่แทนที่จะเป็นการตัดสินใจเชิงนโยบายที่ถกเถียงได้**
