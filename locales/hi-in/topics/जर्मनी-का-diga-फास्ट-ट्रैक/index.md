# जर्मनी का DiGA फास्ट-ट्रैक

DiGA जर्मनी का सांविधिक "नुस्खे पर ऐप्स" मार्ग है — दुनिया की पहली राष्ट्रीय प्रणाली जहाँ डॉक्टर स्वीकृत स्वास्थ्य ऐप्स लिखते हैं।

## यह क्यों महत्वपूर्ण है

DiGA ने उस प्रश्न का उत्तर दिया जो हर डिजिटल स्वास्थ्य कंपनी पूछती है — "वास्तव में भुगतान कौन करेगा?"

## गणित

```
राजस्व = नुस्खे × सक्रियण दर × प्रति नुस्खा अवधि मूल्य
```

## हल किया गया उदाहरण

एक अवसाद-प्रबंधन ऐप €450/तिमाही पर अस्थायी रूप से सूचीबद्ध है:

```
वर्ष 1: 20,000 × 81% × €450 ≈ €7.3M राजस्व
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

DiGA का पैटर्न इंजीनियरिंग-टूल गवर्नेंस के लिए सीधे कॉपी करने योग्य है।
