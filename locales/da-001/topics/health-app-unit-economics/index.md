# Sundhedsappens enhedsøkonomi

Sundhedsappens enhedsøkonomi måler omkostning pr. bruger for anskaffelse, drift og skabt værdi.

## Hvorfor det er vigtigt

Selv klinisk effektive apps kan ikke skaleres, hvis enhedsøkonomien ikke er bæredygtig.

## Matematikken

```
Forhold mellem levetidsværdi og anskaffelsesomkostning = brugerens levetidsværdi (LTV) / brugerens anskaffelsesomkostning (CAC)
```

## Gennemarbejdet eksempel

En app til håndtering af kronisk sygdom: LTV £180, CAC £45 = forhold 4:1 (anset som bæredygtigt).

## Forbindelse til softwareudvikling

[Fastholdelse og churn](../retention-and-churn/) er den vigtigste drivkraft for LTV, og [skyens enhedsøkonomi](../cloud-unit-economics/) udgør driftsomkostningssiden.

## Faldgruber

- **Ikke at inkludere genanskaffelsesomkostninger (efter churn) i anskaffelsesomkostningen.**
