# ต้นทุนการจ้างภายนอกที่หลีกเลี่ยงได้

ต้นทุนการจ้างภายนอกที่หลีกเลี่ยงได้วัดค่าใช้จ่ายส่วนเกินที่จ่ายให้กับพนักงานเอเจนซี่หรือบริการที่จ้างภายนอก ซึ่งสามารถจัดหาได้ด้วยต้นทุนที่ต่ำกว่าผ่านความสามารถภายใน

## ทำไมจึงสำคัญ

การขาดแคลนพนักงานเรื้อรังบังคับให้องค์กรต้องใช้อัตราเอเจนซี่ที่มีราคาแพง — มักสูงกว่าอัตราปกติ 2–3 เท่า — เพื่อให้บริการที่สำคัญดำเนินต่อไปได้

## คณิตศาสตร์

```
ต้นทุนที่หลีกเลี่ยงได้ = (อัตราเอเจนซี่ − อัตราภายใน) × ชั่วโมงที่ส่งมอบ
```

## ตัวอย่างที่คำนวณแล้ว

แผนกหนึ่งใช้ชั่วโมงเอเจนซี่ 2,000 ชั่วโมงต่อปีที่ £70/ชั่วโมง เทียบกับอัตราภายในที่ £30/ชั่วโมง: ต้นทุนส่วนเกินที่หลีกเลี่ยงได้ = £80,000/ปี

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการจ้างที่ปรึกษาราคาแพงเพื่อเติมเต็มการขาดแคลนพนักงานเรื้อรัง แทนที่จะลงทุนในความสามารถของทีมถาวร

## ข้อผิดพลาดที่พบบ่อย

- **การปฏิบัติต่อต้นทุนเอเจนซี่ว่าหลีกเลี่ยงไม่ได้ แทนที่จะเป็นอาการของปัญหาการวางแผนกำลังคนที่แท้จริง**
- **การเพิกเฉยต่อผลกระทบด้านคุณภาพของการหมุนเวียนพนักงานสูงต่อการดูแลผู้ป่วย**
