# 成本效益分析（CBA）

成本效益分析將成本*與*結果都以貨幣形式估值。它是唯一能夠回答"這件事到底值不值得做"這一問題的分析型別——而不只是回答"哪個選項更好"——因為已被貨幣化的效益可以直接與成本相比較。

## 為何重要

成本效益分析是英國HM Treasury《綠皮書》用於一切公共支出評審的標準方法，只要結果能夠被貨幣化，醫療領域也不例外。當[成本效果分析（CEA）](../成本效果分析/)/[成本效用分析（CUA）](../成本效用分析/)止步於"每單位健康的成本"時，成本效益分析則會為健康本身定價（QALY × 閾值），併為時間、交通、碳排放等一切其他因素定價，最終報告一個單一的淨值。每一份完整的NHS數位化商業案例，都包含一個成本效益分析形態的經濟案例。

## 計算方法

```
淨現值（社會淨現值） = Σ_t [ (效益_t − 成本_t) / (1 + r)^t ]
效益成本比（BCR）    = 效益現值 / 成本現值

若淨現值 > 0（等價於效益成本比 > 1），則應採納；排序應按淨現值，而非效益成本比。
r = 3.5%（《綠皮書》社會時間偏好率）
```

健康效果可透過QALY × λ的方式納入貨幣化計算（參見[支付意願閾值](../支付意願閾值/)）。《綠皮書》同時要求進行**樂觀偏差調整**——按有實證依據的百分比上調成本估算、下調效益估算，因為評審結果系統性地過於樂觀。

## 實例演算

某電子轉診系統，5年時間範圍，貼現率3.5%：

```
成本：建設£120萬（第0年），營運每年£300,000（第1–5年）
效益：行政節省每年£250,000，避免重複檢查每年£280,000，
     病患節省時間每年40,000小時 × £15 = 每年£600,000 → 每年£1,130,000

成本現值 = 1,200,000 + 300,000 × 4.515（年金係數） = £2,555,000
效益現值 = 1,130,000 × 4.515                        = £5,102,000

淨現值 = 5,102,000 − 2,555,000 = +£2,547,000     效益成本比 = 2.0
```

應用《綠皮書》樂觀偏差調整（例如建設成本上調+40%，效益下調−20%）：成本現值約為£3,035,000，效益現值約為£4,082,000，淨現值約為**+£1,047,000**——仍為正值，而這正是該調整的意義所在：論證應當經得起自身樂觀偏差的考驗。

## 與軟體工程的聯絡

工程領域的商業案例本質上就是非正式的成本效益分析。以下這些來自《綠皮書》的升級做法值得借鑑：

- **將樂觀偏差作為標準上調項**——工程師低估遷移成本的一貫程度，不亞於各部委低估基礎設施成本；應採用一個明示的上調係數，而不是假裝"這次會不一樣"。
- **誠實地為主導效益定價，否則就不要定價**——病患/使用者的時間應按可站得住腳的費率貨幣化；而"品牌價值"則不應如此。
- **應按淨現值排序，而非效益成本比**：一個效益成本比為5的小專案，其重要性可能遠不及一個效益成本比為1.6的大專案。

## 陷阱

- **為無法貨幣化的事物強行貨幣化**，以虛增效益（如士氣、"戰略契合度"）——這些應保持為定性描述，參照[成本後果分析](../成本後果分析/)的做法。
- **將轉移支付計為效益**：資金在公共機構之間的流動，從社會[視角](../分析視角/)看淨值為零。
- **缺乏反事實對照**：效益應相對於"最低限度維持"方案來衡量，而非相對於"零"來衡量。
