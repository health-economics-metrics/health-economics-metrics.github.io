# تحليل فعالية التكلفة (CEA)

يقارن CEA تكاليف تدخلات بديلة مقابل نتيجة واحدة مقيسة بـ**وحدات طبيعية** - سنوات حياة، حالات مكتشَفة، حالات دخول مُتجنَّبة، ملم زئبق من خفض ضغط الدم. مُخرَجه هو تكلفة لكل وحدة نتيجة.

## لماذا يهم هذا

CEA هي مقارنة العمل الأساسية عندما تستهدف كل الخيارات النتيجة نفسها. تجيب على "أي من هذه الطرق لتحقيق X هو الاستخدام الأفضل للمال؟" - لكن *ليس* "هل يستحق X التحقيق أصلًا؟" (يحتاج ذلك [تحليل التكلفة والمنفعة](../تحليل-التكلفة-والمنفعة/)) و*ليس* "كيف يقارَن X بأولويات غير مرتبطة؟" (يحتاج ذلك [تحليل التكلفة والمنفعة العامة](../تحليل-التكلفة-والمنفعة-العامة/) ونتيجة عامة كـQALY).

## طريقة الحساب

إحصائية المقارنة هي [نسبة فعالية التكلفة التزايدية (ICER)](../نسبة-فعالية-التكلفة-التزايدية/) بوحدات طبيعية:

```
ICER = (التكلفة_A − التكلفة_B) / (الأثر_A − الأثر_B)
     = £ لكل حالة إضافية مكتشَفة / حالة دخول مُتجنَّبة / إلخ

```

الإجراء: عرِّف وحدة النتيجة؛ حدّد تكلفة كل خيار من نفس [المنظور](../منظور-التحليل/) على نفس [الأفق الزمني](../الأفق-الزمني/)؛ استبعد الخيارات المُهيمَن عليها ([حدود الكفاءة](../الهيمنة-وحدود-الكفاءة/))؛ احسب النسب التزايدية على طول الحدود.

## مثال محلول

ثلاث طرق للعثور على رجفان أذيني غير مُشخَّص في جمهرة من 100,000 شخص:

```
الخيار                       التكلفة      الحالات المكتشَفة
فحوصات نبض عرضية              150,000£     300
فعاليات فحص بالصيدلية          400,000£     520
فحص بالجهاز القابل للارتداء   900,000£     610

ICER الصيدلية مقابل النبض:  (400ألف−150ألف)/(520−300) = 1,136£ لكل حالة إضافية
ICER القابل للارتداء مقابل الصيدلية: (900ألف−400ألف)/(610−520) = 5,556£ لكل حالة إضافية
```

هل 5,556£ لكل حالة إضافية "تستحق" ذلك يعتمد على قيمة حالة مكتشَفة (منع سكتة مصبّيًا) - CEA يُرتِّب الخيارات لكن قرار التبني يحتاج ذلك التثمين الخارجي. لاحظ أن التكلفة *المتوسطة* لخيار الجهاز القابل للارتداء لكل حالة (900ألف/610 = 1,475£) تبدو جيدة؛ الـ5,556£ *التزايدية* هي الرقم الصادق لقرار التوسّع.

## الصلة بهندسة البرمجيات

CEA هو القالب الصحيح متى ما شاركت الخيارات نتيجة واحدة: التكلفة لكل اختبار متقطّع مُزال عبر ثلاث مناهج علاج؛ التكلفة لكل حادثة مُتجنَّبة عبر مورّدي رصد؛ التكلفة لكل نشر ناجح عبر بنى CI. الانضباط الذي يفرضه - وحدة نتيجة واحدة مُعلَنة، نسب تزايدية (لا متوسطة)، استبعاد الخيارات المُهيمَن عليها أولًا - يقتل أغلب مقارنات المورّدين السيئة قبل أن تبدأ مناقشة التسعير.

## المزالق

- **مقارنة خيارات بنتائج مختلفة** ("حالات مكتشَفة" مقابل "رضا") في CEA واحد - يحتاج ذلك [تحليل التكلفة والنتائج](../تحليل-التكلفة-والنتائج/) أو نتيجة عامة.
- **نسب فعالية تكلفة متوسطة** مُقدَّمة حيث تكون التزايدية مطلوبة (مثال الجهاز القابل للارتداء أعلاه).
- **وحدات نتيجة مختارة للتجميل**: "تنبيهات مُولَّدة" مُخرَج، لا نتيجة؛ اطلب وحدات تحمل قيمة.
