# 클라우드 단위 경제학

클라우드 단위 경제학은 개별 거래, 환자, 또는 요청당 인프라 비용을 측정합니다.

## 왜 중요한가

클라우드 청구서는 총액을 보여주지만 어떤 기능이나 환자 경로가 비용을 유발하는지는 보여주지 않습니다.

## 수식

```
단위 비용 = 클라우드 지출(£/월) / 거래량(월별)
```

## 계산 예시

영상 저장 서비스: £40,000/월, 200,000건의 스캔 = 스캔당 £0.20.
