# Kostnadsnyttoanalys (CUA)

Kostnadsnyttoanalys jämför interventioner på kostnad per QALY, vilket gör helt olikartade behandlingar jämförbara på en enda skala.

## Varför det är viktigt

CUA är standardmetoden för NICE och de flesta HTA-organ eftersom den kan jämföra ett hjärtläkemedel med en insats för psykisk hälsa.

## Matematiken

```
CUA-kvot (ICER) = (Kostnad_A − Kostnad_B) / (QALY_A − QALY_B)
```

## Genomarbetat exempel

Ett nytt läkemedel mot reumatism kostar £8 000 mer och ger 0,4 QALY mer jämfört med standardvård: £20 000/QALY.

## Koppling till mjukvaruutveckling

Liknar att normalisera kostnad per enhet användarvärde över helt olika typer av funktioner.

## Fallgropar

- **Att använda nyttovikter som inte är validerade för den aktuella populationen.**
- **Att blanda CUA- och CEA-resultat utan att specificera enheten.**
