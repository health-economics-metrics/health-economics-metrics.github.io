# टाले जा सकने वाले आउटसोर्सिंग खर्च

जब एक ट्रस्ट आंतरिक क्षमता के साथ लक्ष्य पूरा नहीं कर सकता, वे प्रीमियम दरों पर क्षमता खरीदते हैं: अपने स्टाफ के लिए सप्ताहांत ओवरटाइम, या निजी प्रदाताओं को प्रक्रियाएँ आउटसोर्स करना।

## यह क्यों महत्वपूर्ण है

वैकल्पिक-पुनर्प्राप्ति दबाव के तहत, ट्रस्ट नियमित रूप से निजी-क्षेत्र स्पॉट मूल्य चुकाते हैं।

## गणित

```
टाली जा सकने वाली आउटसोर्सिंग लागत = इन-हाउस में स्थानांतरित गतिविधि ×
    (आउटसोर्स इकाई मूल्य − प्रति मामला आंतरिक सीमांत लागत)
```

## हल किया गया उदाहरण

एक ट्रस्ट सालाना 800 मोतियाबिंद प्रक्रियाएँ आउटसोर्स करता है प्रत्येक £900 पर:

```
सीमांत लागत ≈ £350
बचत = 500 × (900 − 350) = सालाना £275,000 — नकद-मुक्तकारी
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

सीधी उपमा है **ठेकेदार और परामर्शदाता प्रीमियम**।

## सामान्य गलतियाँ

- पूर्ण क्षमता श्रृंखला के बिना **प्रत्यावर्तन का दावा करना।**
