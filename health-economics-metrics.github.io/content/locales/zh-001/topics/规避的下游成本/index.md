# 规避的下游成本

规避的下游成本（成本冲抵）是指因更早或更好的干预行动而得以避免的未来治疗支出，需与干预措施自身的成本相抵。冲抵是干预措施得以成为*占优方案*——既更便宜**又**更有效——的机制所在，同时也是健康经济学中最容易被重复计算、最容易被过度主张的一条效益线。

## 为何重要

几乎每一个数字健康价值主张中都包含某种冲抵主张："我们的应用能预防住院"、"我们的预警能防止病情恶化"、"我们的平台能避免重复检查"。当冲抵确实真实存在时，它能彻底改变整个经济学结论（参见[ICER](../增量成本效果比/)的实例演算，其中£600,000的冲抵扭转了整个论证）。支付方深知这一点——因此冲抵主张在任何评审中都会受到最严格的审查。以下这些可信度规则，正是区分"可获资助的模型"与"营销话术"的分水岭。

## 计算方法

```
净成本 = 干预成本 − Σ冲抵项

一项有效的冲抵必须满足：
  可归因性 —— 与该干预措施存在因果关联（有对照组证据支撑）
  边际性  —— 那笔钱真的不再被花出去了，且是按边际成本
             而非平均成本计算（参见marginal-vs-average-cost.md）
  概率加权 —— 按"该下游事件本会发生"的概率加权
  已贴现  —— 未来规避的成本需折算为现值
  唯一性  —— 只在一条效益线中计入一次
```

## 实例演算

"一个做对了的迁移风险主张"：某伤口监测应用面向5,000名术后患者，主张能避免因感染导致的再入院。

```
基线感染再入院率：4.0%；使用该应用后（随机对照试验数据）：3.1%
可归因避免事件数 = 5,000 × 0.009 = 每年45例
每次再入院疗程的边际成本（该信托机构口径）：£3,200
冲抵额 = 45 × 3,200 = 每年£144,000
应用成本 = 5,000 × £20 = 每年£100,000
净成本 = −£44,000 → 真正意义上的成本节约，且同时满足：
  来自随机对照试验的归因 ✓  边际成本核算 ✓  基于试验数据的概率 ✓
```

同样的主张，若建立在"再入院平均花费£5,800，我们能防止一大堆"这种说法之上，则四项检验全部不通过，理应遭到拒绝。

## 与软件工程的联系

"这次迁移能避免未来的重写"本身就是一种冲抵主张，而健康经济学的这些规则能让它变得诚实可信：

- **反事实成本**：那次重写实际上会花多少钱？有何证据支撑？
- **概率**：那个未来场景发生的可能性有多大？（并非100%——产品会被砍掉，优先级会改变。）
- **贴现**：以3.5%–10%的贴现率计算，第4年才规避的一次重写，其价值远低于其面值。
- **唯一性**：不要在技术债务线和留存率线中，重复主张同一次被规避的重写。

`冲抵价值 = P(未来事件发生) × 反事实成本 × 贴现因子`——在提案中写下这一行，你会看到这个估算立刻变得可以被质疑与讨论，而这正是其意义所在。

## 陷阱

- **重复计算**——同一次被避免的入院，同时被计为冲抵、床位天数、以及附带成本的QALY。
- **对那些固定成本无论如何都会持续发生的事件，使用平均成本计算冲抵**。
- **对仅仅"有可能"发生的下游事件，悄悄按100%概率计算**。
- **将转嫁给其他预算的冲抵，包装成向正被要求付费的支付方展示的"节省"**——参见[分析视角](../分析视角/)。
