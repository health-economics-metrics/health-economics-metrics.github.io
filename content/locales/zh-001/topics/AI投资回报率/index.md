# AI投资回报率

AI投资回报率指可归因于AI项目、且可测量的损益表回报。一个发人深省的基准数据：麻省理工学院2025年的"生成式AI鸿沟"（GenAI Divide）研究发现，尽管企业级生成式AI投资高达300–400亿美元，但**约95%的试点项目未展现出可测量的损益表回报**——而成功的那5%则共享着一些可识别的共同做法。

## 为何重要

医疗系统对这种AI试点模式有个专门的说法：**"试点症"（pilotitis）**——NHS的应用坟场里，堆满了被永远试点、却从未真正推广的"有前景"应用。麻省理工的发现，与卫生技术评估领域早已知晓的道理高度吻合：价值主张需要预先设定的终点指标，归因需要对照组，而"大家都觉得它有帮助"并不能构成一条真正的效益线。在麻省理工的数据中，成功的少数派集中在具有可追踪成本基线的后台自动化场景，并且**采购的现成工具成功率约为67%，而内部自建工具的成功率大约只有其三分之一**——这一先验经验应当纳入每一份AI投资论证（参见[自建与外购](../自建与外购/)）。

## 计算方法

```
AI投资回报率 = (可归因效益 − AI总成本) / AI总成本

AI总成本 = 许可/推理费用（参见inference-unit-economics.md）
         + 集成成本 + 数据就绪成本 + 评估成本
         + 工作流程重新设计成本 + 治理/保障成本
         （许可费用通常只占分母中的一小部分）

可归因效益：需相对于基线或对照组测量，并按照
cash-releasing-vs-non-cash-releasing.md分类为现金/产能/质量三类
```

## 实例演算

某医院集团在两个用例中部署AI：

```
用例A——临床信函起草（后台场景，可追踪）：
  基线：外包转录费用 每年£380,000
  实施后：转录合同已取消；临床医生复核时间成本增加£60,000
  AI成本：全包每年£120,000
  投资回报率 = (380,000 − 60,000 − 120,000) / 120,000 ≈ 167%——现金释放型，可审计 ✓

用例B——"面向临床医生的AI副驾"（覆盖面广，未被追踪）：
  效益主张："为4,000名员工节省时间"——未采集任何基线数据
  实测损益表影响：无法证实
  → 落入那95%的失败群体，无论其实际上是否真的有帮助
```

二者的差别并不在于AI本身的质量高低——而在于该效益是否拥有**基线、责任人和预算科目**（参见[效益兑现](../效益兑现/)）。

## 与软件工程的联系

适用于AI投资的卫生技术评估式打法：**像[NICE证据标准框架分级](../NICE证据标准框架/)那样分阶段积累证据**——低风险工具用演示级证据，全组织铺开前先做对照试点，并预先登记推广关口（参照[DiGA](../德国DiGA快速通道/)"附截止日期的临时挂网"模式）；**像健康经济学计算"需求规避"那样计算"成本规避"**——只有当某个具体预算科目真正发生变化时，它才是真实的；并且**用[完美信息期望价值（EVPI）](../完美信息期望价值/)为试点本身定价**——一个无法改变推广决策的试点，其价值为£0。关于开发者工具这一细分领域，另见[AI开发者生产力](../AI与开发者生产力/)。

## 陷阱

- **效益稀释**：价值若稀薄地分散在成千上万名用户身上，从结构上就注定无法测量；应选择基线集中、可追踪的用例。
- **只计算许可费用**：集成、评估与工作流程重新设计的成本，通常才是分母中的主导部分。
- **归因窃取**：AI与流程重新设计同时部署时，AI会"窃取"全部收益归因。
- **沉没试点的持续升级**：仅仅因为停止会等于承认失败，就不断延长已经失败的试点——退出日期必须提前商定。
