# Helseappens enhetsøkonomi

Helseappens enhetsøkonomi måler kostnad per bruker for anskaffelse, drift og generert verdi.

## Hvorfor det er viktig

Selv klinisk effektive apper kan ikke skaleres hvis enhetsøkonomien ikke er bærekraftig.

## Matematikken

```
Forhold mellom livstidsverdi og anskaffelseskostnad = brukerens livstidsverdi (LTV) / brukerens anskaffelseskostnad (CAC)
```

## Gjennomarbeidet eksempel

En app for håndtering av kronisk sykdom: LTV £180, CAC £45 = forhold 4:1 (ansett som bærekraftig).

## Kobling til programvareutvikling

[Retensjon og churn](../retensjon-og-churn/) er hoveddriveren for LTV, og [skyens enhetsøkonomi](../skyens-enhetsøkonomi/) utgjør driftskostnadssiden.

## Fallgruver

- **Å ikke inkludere gjenanskaffelseskostnader (etter churn) i anskaffelseskostnaden.**
