# Arvoa tuottava kapasiteetti (operatiivinen käänne)

Arvoa tuottava kapasiteetti mittaa, kuinka paljon lisäkliinistä kapasiteettia luodaan operatiivisilla parannuksilla ilman lisähenkilöstön palkkaamista.

## Miksi se on tärkeä

Uuden kapasiteetin "lyöminen" tehokkuuden avulla on usein nopeampaa ja halvempaa kuin rekrytointi, erityisesti henkilöstöpulasta kärsivillä erikoisaloilla.

## Matematiikka

```
Luotu kapasiteetti = (alkuperäinen läpimeno × tehokkuushyöty %) − käyttöönottokustannukset muunnettuna vastaavaksi läpimenoksi
```

## Ratkaistu esimerkki

Röntgenosaston operatiivinen käänne lisää kuvantamiskapasiteettia 30 % aikataulutuksen optimoinnin avulla, vastaten 3 lisäradiologin palkkaamista ilman rekrytointikustannuksia.

## Yhteys ohjelmistokehitykseen

Muistuttaa käyttöönottotaajuuden lisäämistä putkilinjan optimoinnilla sen sijaan, että palkattaisiin lisää insinöörejä saman määrän toimittamiseksi.

## Sudenkuopat

- **Operatiivisen muutoksen käyttöönottokustannusten aliarviointi.**
- **Hyötyjen väittäminen, jotka todellisuudessa johtuvat tilapäisestä poikkeuksellisesta ponnistelusta eivätkä kestävästä muutoksesta.**
