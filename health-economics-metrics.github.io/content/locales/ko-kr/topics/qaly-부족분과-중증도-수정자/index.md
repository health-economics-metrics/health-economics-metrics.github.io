# QALY 부족분과 중증도 수정자

QALY 부족분은 일반 인구와 비교하여 질병이 환자로부터 얼마나 많은 미래 건강을 빼앗는지 측정합니다.

## 왜 중요한가

2022년 NICE 매뉴얼 이후, 중증도는 건강 이득의 가치에 대한 명시적인 승수입니다.

## 수식

```
절대 부족분 = QALY_일반인구 − QALY_질환보유
```

## 계산 예시

공격적인 질환을 가진 환자, 평균 연령 60세. 절대 부족분 = 12.1(≥ 12 → ×1.2 자격).

## 소프트웨어 공학과의 연관성

중증도 가중치는 공학 조직이 본능적으로 하는 일의 공식적인 버전입니다.
