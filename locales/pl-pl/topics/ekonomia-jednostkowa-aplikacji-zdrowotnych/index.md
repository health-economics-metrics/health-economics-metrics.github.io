# Ekonomia jednostkowa aplikacji zdrowotnych

Ekonomia jednostkowa aplikacji zdrowotnych mierzy koszt na użytkownika dla pozyskania, eksploatacji i wygenerowanej wartości.

## Dlaczego to ważne

Nawet klinicznie skuteczne aplikacje nie mogą skalować się, jeśli ekonomia jednostkowa jest niezrównoważona.

## Matematyka

```
Stosunek wartości życiowej do kosztu pozyskania = wartość życiowa użytkownika (LTV) / koszt pozyskania użytkownika (CAC)
```

## Rozwiązany przykład

Aplikacja do zarządzania chorobą przewlekłą: LTV £180, CAC £45 = stosunek 4:1 (uznawany za zrównoważony).
