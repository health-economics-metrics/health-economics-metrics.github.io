# 概率敏感性分析 (Probabilistic Sensitivity Analysis, PSA)

PSA 为每一个不确定参数赋予一个概率分布，将所有参数同时抽样数千次（蒙特卡洛方法），并报告某一方案是最佳选择的*概率*——而不是给出单一的点估计值。

## 为什么重要

NICE 的参考病例（reference case）*要求*必须使用 PSA。确定性分析回答的是"如果某一项输入有误会怎样？"；PSA 回答的是"在我们同时对许多事情都不确定的情况下，我们做出正确决策的可能性有多大？"其标志性产出——**成本效益可接受曲线（CEAC）**——将某方案具有成本效益的概率，相对于支付意愿阈值绘制出来，从而将"ICER 是每 QALY £24,000"转化为"在 £30,000 的阈值下，这是正确选择的概率为 78%"。

## 计算方法

```
对 N 次抽样中的每一次（N ≈ 10,000）：
  从各自的分布中对每个参数 θ 抽样
    （成本 ~ 伽马分布，概率 ~ Beta 分布，效用值 ~ Beta 分布，效应 ~ 正态/对数正态分布）
  为每个方案 j 计算 NMB_j(θ) = λ × 效应_j(θ) − 成本_j(θ)

CEAC_j(λ) = 在阈值 λ 下，方案 j 的 NMB 最高的抽样占全部抽样的比例
```

关于 NMB 参见[净货币效益](../净货币效益/)，关于 λ 参见[支付意愿阈值](../支付意愿阈值/)。

## 实例计算

平台迁移商业论证案例。三个不确定输入：

```
迁移成本      ~ 伽马分布，均值 £800k，标准差 £200k
年度效益      ~ 正态分布，均值 £350k，标准差 £150k
效益持续期    ~ 均匀分布，3-6 年
```

对 10,000 次抽样中的每一次，计算净效益 = 持续期 × 年度效益 − 成本（为清晰起见省略贴现）。示例结果：

```
平均净效益：            £775k
净效益 > 0 的概率：      0.86
第 5-95 百分位区间：    −£180k … +£1.9M
```

点估计的结论是"显然应该做"。而 PSA 的结论是"86% 的概率应该做，但存在一个真实的尾部风险，可能亏损 £180k 以上"——这才是项目组合负责人真正需要的信息，它也为先开展一次探索性调研（discovery spike）的做法提供了定价依据（参见 [EVPI](../完全信息期望价值/)）。

## 与软件工程的关联

工程师们早已信任蒙特卡洛方法用于交付预测（吞吐量抽样优于点估计）。将同样的机制延伸到资金问题上：为采用率、节省时间和薪资建立分布，然后报告"该平台投资净收益为正的概率"，而不是一个虚假精确的 ROI 数字。一条 CEAC 风格的曲线——将"成为最佳方案的概率"表示为组织对工程师工时估值的函数——对资金委员会而言，比任何单一数字都是真正更优的决策依据。

## 常见陷阱

- **垃圾分布**：使用凭空捏造的标准差做 PSA，本质上是穿着实验服的确定性分析。分布应基于数据或结构化的专家引导（structured expert elicitation）。
- **忽略参数间的相关性**（高采用率通常与高时间节省相关）；独立抽样会低估尾部风险。
- **只报告模拟的均值**——PSA 的全部意义正在于分布本身及其决策概率。
