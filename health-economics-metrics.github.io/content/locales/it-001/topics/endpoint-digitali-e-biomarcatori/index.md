# Endpoint Digitali e Biomarcatori

Un biomarcatore digitale è una misura fisiologica o comportamentale oggettiva raccolta tramite sensori. Un endpoint digitale è una tale misura elevata a **esito di uno studio clinico**.

## Perché è importante

Gli endpoint tradizionali degli studi sono episodici e costosi; gli endpoint digitali sono continui ed ecologici.

## La matematica

```
Validità analitica: accordo con il riferimento (MAPE, CCC, Bland-Altman)
```

## Esempio risolto

Uno studio sul Parkinson considera la velocità dell'andatura da un sensore al polso: la varianza scende di ~5× con campionamento denso.

## Collegamento con l'ingegneria del software

Gli endpoint digitali sono una disciplina di ingegneria dei dati vestita con abiti clinici.

## Insidie

- **Correlazione-con-la-clinica come validazione completa.**
