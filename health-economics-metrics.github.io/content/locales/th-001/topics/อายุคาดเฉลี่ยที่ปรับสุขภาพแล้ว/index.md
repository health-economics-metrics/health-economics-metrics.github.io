# อายุคาดเฉลี่ยที่ปรับสุขภาพแล้ว (HALE)

HALE วัดจำนวนปีเฉลี่ยที่บุคคลในประชากรคาดว่าจะมีชีวิตอยู่ในสุขภาพที่ดี โดยหักปีที่ใช้ชีวิตด้วยความเจ็บป่วยหรือความพิการออก

## ทำไมจึงสำคัญ

HALE ให้มุมมองระดับประชากรที่สมบูรณ์กว่าอายุคาดเฉลี่ยทั่วไป เพราะคำนึงถึงคุณภาพของปีชีวิตเหล่านั้น ไม่ใช่แค่ปริมาณ ทำให้เหมาะสำหรับการติดตามความก้าวหน้าด้านสาธารณสุขระดับชาติ

## คณิตศาสตร์

```
HALE = อายุคาดเฉลี่ย − ปีเฉลี่ยที่ใช้ชีวิตด้วยความเจ็บป่วยหรือความพิการ (ปรับน้ำหนักตามความรุนแรง)
```

## ตัวอย่างที่คำนวณแล้ว

ประเทศหนึ่งมีอายุคาดเฉลี่ย 80 ปี แต่ HALE เพียง 70 ปี แสดงว่าประชากรโดยเฉลี่ยใช้ชีวิต 10 ปีสุดท้ายด้วยความเจ็บป่วยเรื้อรังหรือความพิการในระดับหนึ่ง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการวัด "เวลาทำงานที่มีคุณภาพ" ของระบบ แทนที่จะวัดเวลาทำงานทั้งหมด — ระบบอาจทำงานอยู่ 99.9% ของเวลา แต่หากประสิทธิภาพต่ำในบางช่วง "เวลาทำงานที่มีคุณภาพ" จริงจะต่ำกว่านั้น

## ข้อผิดพลาดที่พบบ่อย

- **การเปรียบเทียบ HALE ระหว่างประเทศที่ใช้วิธีการเก็บข้อมูลความพิการต่างกัน**
- **การสับสนระหว่าง HALE (ระดับประชากร) กับ QALY (ระดับบุคคล/การแทรกแซง)**
