# Manfaat Moneter Bersih (NMB)

NMB mengubah hasil efektivitas biaya menjadi satu nilai moneter: perolehan kesehatan yang dinilai pada ambang batas kesediaan membayar, dikurangi biaya.

## Mengapa ini penting

Rasio ([ICER](../incremental-cost-effectiveness-ratio/)) canggung: mereka meledak dekat efek nol. NMB bersifat linier.

## Matematika

```
NMB = (ΔE × λ) − ΔC
```

## Contoh yang diselesaikan

Tiga opsi untuk layanan diabetes, λ = £20.000/QALY.

## Hubungan dengan rekayasa perangkat lunak

`(jam yang dihemat × tarif per jam yang dialokasikan penuh) − biaya alat`.

## Jebakan

- **Menyembunyikan ambang batas.**
