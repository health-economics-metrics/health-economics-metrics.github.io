# Kustannus-seuraamusanalyysi (CCA)

Kustannus-seuraamusanalyysi esittää kustannukset ja useita tuloksia rinnakkain hajautetussa taulukossa yhdistämättä niitä yhdeksi suhteeksi.

## Miksi se on tärkeä

CCA sopii erityisen hyvin digitaalisen terveydenhuollon interventioihin, joissa vaikutukset kattavat useita ulottuvuuksia (kliininen, käyttäjäkokemus, operatiivinen), jotka eivät sulaudu siististi yhdeksi QALY-luvuksi.

## Matematiikka

```
Ei yhtä kaavaa: esitä {Kustannus, Tulos_1, Tulos_2, ..., Tulos_n} taulukkona
```

## Ratkaistu esimerkki

Digitaalinen terveyssovellus raportoi: kustannus £200 000/vuosi, 15 %:n vähennys uudelleensisäänotoissa, 20 %:n kasvu potilastyytyväisyydessä ja 500 säästettyä kliinistä tuntia — kukin esitettynä erikseen.

## Yhteys ohjelmistokehitykseen

Muistuttaa hallintapaneelia, joka näyttää useita KPI:tä (viive, virhemäärä, käyttäjätyytyväisyys) rinnakkain sen sijaan, että ne tiivistettäisiin yhdeksi pistemääräksi.

## Sudenkuopat

- **Liian monen tuloksen sisällyttäminen, mikä lamaannuttaa päätöksenteon auttamisen sijaan.**
- **Tulosten valikoiva esittäminen suotuisan vaikutelman luomiseksi.**

## Lähteet

- NICE, Evidence Standards Framework for digital health technologies.
- Drummond MF, et al., Methods for the Economic Evaluation of Health Care Programmes.
