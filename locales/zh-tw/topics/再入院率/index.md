# 再入院率

30天再入院率是指出院病患中，在30天內以急診方式重新入院的比例。它是醫療系統衡量*出院品質*的標準指標——並且直接附帶財務處罰。

## 為何重要

再入院意味著第一次出院其實沒有真正"站住腳"：過早出院、用藥交接失敗、缺乏隨訪，或社會支援缺失。支付方對此設有明確的處罰機制——美國的Hospital Readmissions Reduction Program最高可扣減醫院3%的Medicare付款；NHS歷來對可避免的30天急診再入院不予支付。因此，避免再入院是少數幾個*直接*與提供方現金掛鉤、而不僅僅是產能相關的效益類別之一。

## 計算方法

```
再入院率 = 30天內急診再入院人次 / 首次出院人次 × 100

風險標準化比較會對病例組合進行調整；處罰類專案
則將觀察值與同類醫院的預期值進行比較。

避免再入院的價值 = 避免的再入院人次 × (每次再入院療程成本
                  + 每次再入院對應的處罰風險敞口)
```

## 實例演算

某心力衰竭出院支援應用（症狀追蹤、體重預警、用藥提醒、護士升級回應）：每年2,000例出院，基線再入院率18%，試驗顯示使用該應用後降至14%。

```
避免的再入院 = 2,000 × (0.18 − 0.14) = 每年80例
每次再入院療程成本約£3,500 → 每年避免£280,000的治療成本
外加這些療程對應的處罰/拒付風險敞口。
應用成本：2,000 × £60 = 每年£120,000

淨收益 ≈ 每年+£160,000，這還不包括因避免病情惡化而產生的任何QALY主張。
```

真正需要捍衛的數位，是那4個百分點的效應量：它必須來自一項對照比較，因為再入院率本身會隨病例組合與季節而波動。

## 與軟體工程的聯絡

再入院正是醫療系統版本的**變更失敗率**（參見[DORA指標](../DORA指標/)）：一項已經"交付"卻在30天內被打回來的工作。這一類比相當深刻——被重新開啟的工單與迴歸性事件，同樣反映出糟糕的"出院品質"（驗證不足、過早關閉、交接檔案缺失）；處罰式核算方式（由造成問題的團隊買單，而非接手的團隊）會改變行為；而兩個領域都學到了同一個教訓：在不投入交接環節的情況下一味追求原始吞吐量（更快出院、更快交付），只會把可見的佇列轉化為不可見的返工。任何一個以週期時間為榮的團隊儀表盤，都應該納入一項"30天重新開啟率"指標。

## 陷阱

- **透過重新編碼來操縱指標**：將再入院編碼為觀察性留院，或編碼為新發病症；應審計其定義是否被規避。
- **全因再入院 vs 相關病因再入院**：30天全因再入院會包含一些確實無關的事件；處罰機制通常正是出於"相關病因"容易被操縱這一原因，才採用全因口徑。
- **對病例組合視而不見**：一家服務於病情更重、更貧困人群的醫院，其再入院率會更高，原因並非任何應用所能解決——比較之前應先做風險調整。
