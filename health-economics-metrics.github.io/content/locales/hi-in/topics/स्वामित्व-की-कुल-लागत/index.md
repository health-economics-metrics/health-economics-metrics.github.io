# स्वामित्व की कुल लागत (TCO)

TCO एक प्रणाली के जीवनकाल में पूर्ण लागत है: अधिग्रहण या निर्माण, एकीकरण, संचालन, रखरखाव। असुविधाजनक आधाररेखा: **रखरखाव सॉफ़्टवेयर TCO का 50–80% है**।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य प्रौद्योगिकी मूल्यांकन ने बहुत पहले सीखा कि दवा की कीमत उसकी लागत नहीं है।

## गणित

```
TCO = प्रारंभिक लागत + Σ_t [संचालन + रखरखाव + सहायता]_t / (1 + r)^t
```

## हल किया गया उदाहरण

एक ई-ऑब्ज़र्वेशन प्रणाली के दो विकल्प, 5-वर्ष क्षितिज:

```
                        विक्रेता SaaS    इन-हाउस निर्माण
अ-छूट प्राप्त TCO       £1,090,000       £2,030,000
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

इंजीनियर निर्माण की वकालत करते समय अपने ही क्षेत्र के रखरखाव डेटा को कम आंकते हैं। ऊपर जैसी बहु-वर्षीय TCO संख्या समय के साथ बहुत-सी लागत मदों का योग है — मॉडल को सेंट तक मिलना हो तो वह योग फ़्लोटिंग-पॉइंट की बजाय यथार्थ दशमलव क्यों होना चाहिए इसके लिए [मुद्रा-सुरक्षित लागत संकलन](../मुद्रा-सुरक्षित-लागत-संकलन/) देखें, और कुल TCO को बिना सेंट खोए लागत केंद्रों में बाँटने के लिए [यथार्थ-सेंट लागत आवंटन](../यथार्थ-सेंट-लागत-आवंटन/) देखें।
