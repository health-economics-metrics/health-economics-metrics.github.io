# 傷殘調整生命年（DALY）

DALY代表損失一年的健康生命——是[QALY](../品質調整生命年/)在負擔一側的映象指標。QALY計算的是健康的*獲得*，而DALY計算的是因疾病而*損失*的健康；介入措施的價值以所**避免**的DALY來衡量。

## 為何重要

DALY是全球健康領域的標準指標（WHO、全球疾病負擔研究，以及大多數中低收入國家的衛生部都以DALY來做規劃）。如果你的軟體面向國際衛生系統、捐助方，或與WHO對接的專案，那麼其價值語言應是"避免的DALY"，而非"獲得的QALY"。WHO-CHOICE的歷史基準是：每避免一個DALY的成本低於人均GDP1倍，屬於"高度具有成本效果"；1–3倍人均GDP之間，屬於"具有成本效果"（WHO目前不鼓勵僵化地套用這些區間，但它們在實踐中依然被廣泛使用）。

## 計算方法

```
DALY = YLL + YLD

YLL（壽命損失年數） = 死亡人數 × 該死亡年齡下的標準預期壽命差值
YLD（傷殘存活年數） = 患病人數 × 傷殘權重

傷殘權重 ∈ [0, 1]，0代表完全健康，1相當於死亡
（權重資料由全球疾病負擔研究釋出）
```

## 實例演算

某地區的一個篩查提醒平臺，提升了某疾病的早期檢出率。它每年可預防10例過早死亡（每例相對標準預期壽命損失20年），並使200人免於帶著傷殘權重為0.2的病症生活一年。

```
避免的YLL = 10 × 20        = 200
避免的YLD = 200 × 0.2      = 40
避免的DALY合計              = 每年240
```

若該平臺每年運作成本為60萬美元，則每避免一個DALY的成本為 600,000 / 240 = **2,500美元**。在一個人均GDP為8,000美元的國家，這遠低於1倍GDP的基準線——按WHO-CHOICE的標準即屬於"高度具有成本效果"。

## 與軟體工程的聯絡

- 面向全球健康資助方（Gavi、全球基金、各國政府專案）的數位健康產品，應以**每避免一個DALY的成本**來表述其影響——這正是撥款評審人早已習慣使用的指標語言。
- DALY同樣為工程領域提供了一個實用的*負擔核算*模板：事件、不穩定建置與歷史遺留摩擦，相當於一個程式碼庫的"帶傷殘存活的年數"——一份按繁重程度加權的負擔清單，能告訴你哪裡的補救工作能換來最多的"健康工程年"，正如全球疾病負擔表能指引衛生支出方向一樣。

## 陷阱

- **"獲得的QALY"在數值上並不等同於"避免的DALY"**——二者權重不同、生命表不同、約定俗成的計算方式也不同（DALY歷史上在其計算內部還包含了年齡加權與貼現）。不要隨意進行換算。
- **把"GDP倍數閾值"當作機械的橡皮圖章使用**——WHO自身也警示，這類閾值忽視了預算約束與機會成本；參見[支付意願閾值](../支付意願閾值/)。
- **從單使用者層面的療效直接主張人群規模的DALY效益**，卻未按採納率與依從性逐層相乘——參見[觸達與公平](../觸達與公平/)。
