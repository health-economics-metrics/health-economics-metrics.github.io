# Työvoiman pysyvyys

Työvoiman pysyvyys mittaa työntekijöiden osuutta, jotka pysyvät työssä tietyn ajanjakson aikana, vaihtuvuuskustannusten ja loppuunpalamisen talouden ollessa taloudellinen kääntöpuoli.

## Miksi se on tärkeä

Jokainen lähtevä työntekijä maksaa huomattavasti enemmän kuin pelkät rekrytointikustannukset — perehdytysaika, menetetty tuottavuus ja tiimien häiriöt vaikuttavat kaikki.

## Matematiikka

```
Vaihtuvuuskustannus = rekrytointikustannus + perehdytyskustannus + (tuottavuustappio × perehdytysjakso)
```

Arviot nousevat tyypillisesti 50–200 %:iin lähtevän työntekijän vuosipalkasta.

## Ratkaistu esimerkki

Sairaanhoitaja, jonka vuosipalkka on £35 000 ja joka lähtee, maksaa arviolta £45 000 kokonaisvaihtuvuuskustannuksia, kun rekrytointi, perehdytys ja väliaikainen henkilöstöpula lasketaan mukaan.

## Yhteys ohjelmistokehitykseen

Suoraan verrattavissa [SPACE ja DevEx](../space-ja-devex/) — tiimin vaihtuvuus tuhoaa hiljaista tietoa ja häiritsee toimitusta, paljon kalliimpaa kuin miltä se näyttää.

## Sudenkuopat

- **Vain suorien rekrytointikustannusten laskeminen, tietämyksen menetyksen jättäminen huomiotta.**
- **Loppuunpalamisen aiheuttaman vaihtuvuuden syiden liittäminen yksilöllisiin eikä systeemisiin syihin.**
