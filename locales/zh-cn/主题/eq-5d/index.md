# EQ-5D

EQ-5D 是 EuroQol 集团用于测量健康相关生活质量的标准化问卷。它是绝大多数 [QALY](../质量调整生命年/) 计算中效用权重的来源工具——NICE 的参考方案将其指定为成人的首选测量工具。

## 为什么重要

任何希望主张 QALY 收益的数字健康产品,都需要来自经过验证工具的效用值,而 EQ-5D 是英国及欧洲大部分地区的默认选择。它足够简短,可以嵌入应用中(5 个问题外加一个视觉量表),这意味着软件产品可以在正常使用过程中,顺带采集达到 HTA 标准的结局数据——这是相对于药物的一项结构性优势,因为药物需要专门开展研究。

## 计算方法

EQ-5D-5L 在 **5 个维度**——行动能力、自我照顾、日常活动、疼痛/不适、焦虑/抑郁——各提出一个问题,每题有 **5 个等级**(无问题……极度问题),外加一个 0–100 的视觉模拟量表(EQ VAS)。

```
健康状态 = 5 位数字组成的档案,例如 "21221"
效用指数 = value_set(健康状态档案)

价值集(value set)因国家而异,来源于对普通公众进行的时间权衡法 /
离散选择实验调查。锚点:1 = 完全健康,0 = 死亡;比死亡更差的状态
为负值(英国 3L 价值集下限:−0.594)。
```

QALY 的计算随后按 `持续时间 × 效用值` 进行。

## 实例演算

某肌肉骨骼康复应用在入组时和 6 个月后,对 1,000 名完成随访的用户测量 EQ-5D-5L。

```
基线平均效用值:  0.62
6 个月后平均效用值:0.71
假设增益维持 1 年:(0.71 − 0.62) × 1.0 = 每位用户 0.09 QALY
```

相对于对照组 0.03 的变化(自然恢复),可归因增益为每位用户 0.06 QALY。按每 QALY 20,000–30,000 英镑折算价值:**每位完成随访用户 1,200–1,800 英镑的健康价值**——这一数字正是该应用与支付方进行价格谈判的锚点。(EQ-5D 指数的最小临床重要差异通常在 0.03–0.08 区间,因此 0.06 是合理的,但仍必须通过对照组比较验证;参见[患者报告结局](../患者报告结局/)。)

## 与软件工程的关联

- **将其嵌入埋点。**在注册时及随访节点采集 EQ-5D,只需几屏 UI;回报却是达到 HTA 标准的证据。需从 EuroQol 获取授权(必需,部分用途可免费)。
- **使用适用于部署所在国家的正确价值集**——同样的答案,在英国、德国、日本的计分结果各不相同。
- **设计启示**:EQ-5D 展示了一个微小的标准化问卷加一个已发表的计分函数,如何产生一个可比较的单一指数。这同样是任何具有可信度的开发者体验指数应遵循的模式——标准化工具、已发表的权重,而不是随意拍脑袋。参见 [SPACE 与 DevEx](../space-与-devex/)。

## 常见误区

- **没有对照组的前后对比**——均值回归和自然恢复会虚增朴素的增益数字。
- **幸存者偏差**:只测量那些持续保持参与的用户(参见[留存与流失](../留存与流失/))。
- **在不同研究间混用 3L 与 5L 版本或价值集**——会系统性地产生不同的数值。
- **天花板效应**:在轻度受影响的人群中,许多用户基线时得分已接近 1.0,几乎没有空间展现增益。
- **把价值集当作不言自明**：价值集所返回的效用值，本身是通过时间权衡研究（或相关的选择调查）从公众那里获取的——具体方法见[时间权衡效用获取法 (TTO)](../时间权衡效用获取法/)。
