# EQ-5D

EQ-5D — це стандартизований інструмент, який вимірює стан здоров'я за п'ятьма вимірами для генерування вагових коефіцієнтів корисності для розрахунків QALY.

## Чому це важливо

Більшість розрахунків QALY на практиці ґрунтуються на даних EQ-5D, що робить цей інструмент фактичною основою за числами, представленими як абстрактна "корисність".

## Математика

```
Індекс корисності = f(мобільність, самообслуговування, звичайна діяльність, біль/дискомфорт, тривога/депресія)
```

## Розібраний приклад

Пацієнт повідомляє про помірні проблеми з мобільністю та болем, без проблем в інших сферах: цей профіль стану відповідає корисності приблизно 0,73 за британським набором оцінок.

## Зв'язок з інженерією програмного забезпечення

Подібно до складеного показника задоволеності користувачів, побудованого з кількох виміряних вимірів замість одного грубого показника.

## Підводні камені

- **Використання набору оцінок з неправильної країни.**
- **Змішування старішої версії EQ-5D-3L та новішої EQ-5D-5L без коригування.**
