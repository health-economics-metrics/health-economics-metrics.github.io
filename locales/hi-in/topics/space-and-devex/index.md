# SPACE और DevEx

SPACE और DevEx डेवलपर उत्पादकता को **बहु-आयामी रूप से** मापने के ढाँचे हैं।

## यह क्यों महत्वपूर्ण है

दोनों ढाँचे वही कठिन-अर्जित सबक एन्कोड करते हैं जो स्वास्थ्य परिणाम शोध ने दशकों पहले सीखा था।

## गणित

```
SPACE नियम: ≥ 3 आयाम, ≥ 1 अवधारणात्मक + ≥ 1 सिस्टम मीट्रिक
```

## हल किया गया उदाहरण

एक प्लेटफ़ॉर्म टीम 300 डेवलपरों के लिए एक DevEx निवेश को न्यायसंगत ठहराती है:

```
आधाररेखा: CI p75 = 28 मिनट
बाद:      CI p75 = 9 मिनट
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

यह दस्तावेज़ *है* सॉफ़्टवेयर पक्ष; स्थानांतरण स्वास्थ्य अर्थशास्त्र की ओर बहता है।
