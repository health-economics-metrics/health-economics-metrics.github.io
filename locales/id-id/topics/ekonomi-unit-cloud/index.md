# Ekonomi Unit Cloud (FinOps)

Ekonomi unit cloud mengubah pengeluaran cloud mentah menjadi **biaya per unit output**.

## Mengapa ini penting

Angka pengeluaran total tidak dapat menjawab pertanyaan penting: apakah produk menjadi lebih efisien?

## Matematika

```
Biaya satuan = total biaya yang dialokasikan / unit yang disediakan
```

## Contoh yang diselesaikan

Layanan triase digital: biaya cloud £62.000/bulan, menangani 380.000 episode triase per bulan: biaya rata-rata ≈ £0,163.

## Hubungan dengan rekayasa perangkat lunak

Ekonomi unit adalah tempat pilihan rekayasa menjadi dapat dibaca secara finansial.

## Jebakan

- **Mengabaikan biaya bersama.**
