# 成本最小化分析（CMA）

成本最小化分析只比较成本，并选择最便宜的方案——*只有*在已证明各备选方案的结果彼此等效的前提下，这样做才是正当的。

## 为何重要

成本最小化分析是最简单的分析方法，也是最容易被滥用的一种。真正起关键作用的是"等效性"这一主张：如果结果确实没有差异（例如生物类似药与其原研药之间；两家供应商提供满足同一规格的同一服务），那么成本就是唯一需要考虑的问题，此时使用成本最小化分析是正确的。其严谨性体现在*事先证明*等效性这一步——通常需要借助带有预先设定边界值的非劣效性研究——而这恰恰是采购方最常跳过的一步。

## 计算方法

```
若有证据表明 效果_A ≈ 效果_B （在预先设定的边界值δ范围内）：
选择 min(成本_A, 成本_B)

成本须以相同视角、相同时间范围计算，
并须包含切换/过渡成本。
```

如果等效性无法被证实，成本最小化分析就不成立——此时应改用[成本效果分析](../成本效果分析/)/[成本效用分析](../成本效用分析/)。

## 实例演算

某信托机构在两个视频问诊平台之间做选择。一项为期3个月的平行试点显示，完成率分别为94.1%与93.8%，患者满意度均为4.4——差异均落在事先约定的2个百分点边界值δ之内。结果：等效。3年期成本如下：

```
                     平台A          平台B
许可费用             £360,000       £210,000
集成成本             £80,000        £150,000
培训/支持            £60,000        £90,000
总计                £500,000       £450,000
```

平台B以£50,000的优势胜出——且这已*包含*了它更高的集成成本。如果没有那次试点，等效性的主张就只能依赖供应商的宣传册，而一个百分点的完成率差异（相当于每年数千次失败的问诊）足以远远超过£50,000这一成本差距。

## 与软件工程的联系

成本最小化分析是大宗商品化采购的正式形态：两家满足相同SLO（服务水平目标）的CI服务提供商，两个具有相同持久性规格的对象存储服务。健康经济学在此给出的教训在于*操作顺序*：先用证据证明等效性（针对你自己的工作负载做基准测试，针对你自己的SLO做试点，并事先约定好边界值），再比较包含迁移成本在内的总成本。跳过第一步、直接说"它们基本一样，B更便宜"，正是许多组织最终买到"便宜10%却差40%"的工具的原因所在。推论：当供应商以价格为论据时，应要求其同时承诺等效性——这一约束在反方向上同样有效。

## 陷阱

- **假定等效性**——这是最典型的错误；没有证据显示存在差异，并不等于有证据证明二者等效（功效不足的试点很容易"免费"就"证明"了等效性）。
- **遗漏切换成本**——迁移、重新培训与并行运行的成本，都应计入成本一侧。
- **在错误的结果上求等效**：在被测量的指标上等效，却在某个真正重要的方面存在差异（可及性、尾部延迟、数据出口）。
