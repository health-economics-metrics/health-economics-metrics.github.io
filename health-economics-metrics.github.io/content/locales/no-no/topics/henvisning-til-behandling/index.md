# Henvisning til behandling (RTT)

RTT måler tiden fra første henvisning til start av behandling, med 18-ukersstandarden som det viktigste nasjonale ytelsesmålet.

## Hvorfor det er viktig

RTT er i bunn og grunn et leveringsledetidsmål anvendt på pasientbehandling — hvor lang tid det tar å levere verdi (behandling) etter en forespørsel (henvisning).

## Matematikken

```
RTT-etterlevelse = Antall pasienter behandlet innen 18 uker / Totalt antall pasienter i RTT-køen × 100 %
```

## Gjennomarbeidet eksempel

En spesialitet med 5 000 pasienter i RTT-forløpet der 4 100 behandles innen 18 uker: etterlevelse 82 %, under den nasjonale standarden på 92 %.

## Kobling til programvareutvikling

Direkte analogi til [DORA-ledetid](../dora-mål/) — tiden fra commit (henvisning) til levering (behandling).

## Fallgruver

- **Å feilaktig anvende klokkestopp (pasientinitiativ) for å forvrenge etterlevelsestall.**
- **Å bare se på gjennomsnittet når halen av fordelingen er det reelle problemet.**
