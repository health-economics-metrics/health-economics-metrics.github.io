# 爽约率 (Did-Not-Attend，DNA Rate)

DNA 率是指已预约的就诊中，患者既未到场也未取消的比例。临床人员、诊室和时段的成本都已支付，却什么都没发生。这是医疗领域最纯粹的浪费指标——也是最容易通过软件修复的指标之一。

## 为什么重要

NHS England 的数据（2019 年）：全科医生 (GP) 爽约每年超过 1500 万次，每次约 £30——总计超过 **£216M/年**；医院门诊爽约每年约 800 万次（约占预约的 6.4%），每个爽约时段平均约 **£160**。由于一条提醒短信的边际成本只是几便士，而挽回的价值是一个配备齐全的临床时段，因此降低 DNA 率是数字健康领域投资回报率最优的算式之一——这也是短信提醒、便捷改约以及预测性超额预约成为数字健康领域最早被证实有效的举措之一的原因。

## 计算方法

```
DNA 率 = 爽约次数 / 已预约次数 × 100

减少所带来的价值 = 预约总数 × ΔDNA 率 × 每个被挽回时段的价值

每个被挽回时段的价值：该时段要么被重新填补（活动量价值 / 候诊名单缩短），
要么没有被填补（人员时间只能部分再利用）——机制很重要，
与 bed-days-saved.md 中的情形类似。
```

## 算例

某门诊科室：每年 200,000 次预约，DNA 率 8%。一项"提醒 + 改约"服务（一键改约的短信、交通信息、无障碍格式）将 DNA 率降至 5.5%。

```
挽回的时段 = 200,000 × 0.025 = 5,000/年
以平均约 £160 的门诊价值从候诊名单重新填补：
  5,000 × £160 = £800,000/年 的挽回活动量
服务成本：200,000 × £0.40 = £80,000/年

回报比 ≈ 10:1，此外还有 5,000 名候诊患者获得更早就诊
（参见 waiting-list-impact.md 与 referral-to-treatment.md）。
```

这一效应大小（2.5 个百分点）是符合现实的：提醒类随机对照试验一贯显示 DNA 相对降低 25–40%。

## 与软件工程的关联

- **这本质上是一个排期系统问题**：提醒、自助改约、从取消预约中自动回填候诊名单，以及驱动定向双重预约的爽约预测模型。每一项都是普通的软件工程工作，却拥有异常清晰的经济论证。
- **工程领域的类比**：已预留容量的"爽约"——已预订但空闲的 CI 时段、已预留的云容量、会议室、面试小组。这套经济学同样适用：一条廉价的自动化提醒（或对未使用预留的自动释放）就能挽回昂贵的已承诺容量。
- **预测伦理的预览**：基于历史出勤数据训练的爽约模型会编码进社会剥夺和就医障碍等因素；如果用它来*降低*可能爽约者的优先级，会放大不公平；如果用它来*支持*患者到场（交通协助、电话替代方案），则会减少不公平。参见[覆盖面与公平性](../覆盖面与公平性/)。

## 陷阱

- **把"已取消并改约"重复计算为挽回价值。**
- **为未被重新填补的挽回时段估值**——一个已发送提醒但仍空着的时段依然是空的。
- **把 DNA 追求到零**：DNA 率最后剩下的部分，往往是真正面临障碍的患者；惩罚性做法（连续 N 次 DNA 后除名）会通过放弃这些患者来"降低"指标。
