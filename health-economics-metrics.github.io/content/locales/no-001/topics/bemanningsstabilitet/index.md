# Bemanningsstabilitet

Bemanningsstabilitet måler andelen ansatte som blir værende over en gitt periode, med turnoverkostnader og utbrenthetsøkonomi som den økonomiske bakdelen.

## Hvorfor det er viktig

Hver ansatt som slutter, koster betydelig mer enn bare rekrutteringskostnader — opplæringstid, tapt produktivitet og forstyrrelser i team teller alle med.

## Matematikken

```
Turnoverkostnad = rekrutteringskostnad + opplæringskostnad + (produktivitetstap × opplæringsperiode)
```

Estimater når typisk 50–200 % av årslønnen til den ansatte som slutter.

## Gjennomarbeidet eksempel

En sykepleier med en årslønn på £35 000 som slutter, koster anslagsvis £45 000 i totale turnoverkostnader når rekruttering, opplæring og midlertidig underbemanning telles med.

## Kobling til programvareutvikling

Direkte sammenlignbart med [SPACE og DevEx](../space-og-devex/) — teamturnover ødelegger stilltiende kunnskap og forstyrrer leveranse, mye dyrere enn det ser ut til.

## Fallgruver

- **Å bare telle direkte rekrutteringskostnader, ignorere kunnskapstap.**
- **Å tilskrive utbrenthetsdrevet turnover til individuelle i stedet for systemiske årsaker.**
