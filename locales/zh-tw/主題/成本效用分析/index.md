# 成本效用分析（CUA）

成本效用分析是採用**通用的、經偏好加權的結果指標**的成本效果分析——幾乎總是使用[QALY](../品質調整生命年/)（或所避免的[DALY](../傷殘調整生命年/)）。由於結果計量單位是通用的，成本效用分析能夠跨越完全不同的疾病領域比較各種介入措施。

## 為何重要

一個國家醫療服務體系必須在同一份預算下，在一種抗癌藥物、一款心理健康應用和一臺手術機器人之間做出選擇。自然單位無法用來比較這三者；QALY則可以。因此，成本效用分析是NICE及大多數衛生技術評估機構的參考案例方法：其輸出——每QALY成本，並依據某個[閾值](../支付意願閾值/)進行判斷——是衛生政策領域所擁有的、最接近"通用匯率"的東西。如果你希望自己的軟體*取代其他方案*獲得資助，成本效用分析就是那個角力場。

## 計算方法

```
增量成本效用比（ICUR） = ΔCost / ΔQALY      （即以QALY作為效果單位的ICER）

ΔQALY = Σ (時長_i × 效用值_i)_新方案 − Σ (時長_i × 效用值_i)_舊方案
```

效用值來自經過驗證的量表工具（[EQ-5D](../EQ-5D/)）；成本與QALY均按3.5%（NICE參考案例標準）進行[貼現](../貼現與時間偏好/)；不確定性透過[機率敏感性分析（PSA）](../機率敏感性分析/)處理。

## 實例演算

一款用於中度焦慮症的CBT應用，對比面對面治療的等候名單，按每名病患計算：

```
成本：應用許可+支援費用              £250
     被替代的治療費用                −£680   （40%的使用者不再需要面對面治療）
     ΔC = 250 − 680 = −£430（節省了成本）

QALY：候診期間效用值從0.68提升為0.76，持續6個月
     ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALY
```

ΔC < 0 且 ΔE > 0：該應用屬於**佔優方案**——既更好又更便宜，無需再計算比值。若"治療替代率"這一假設僅為10%，則ΔC = 250 − 170 = +£80，此時ICUR = 80 / 0.04 = **每QALY £2,000**——仍遠低於£20,000。即便將這一關鍵假設大幅削弱，該論證依然成立：這正是一份穩健的成本效用分析應有的樣子（[龍捲風圖](../敏感性分析/)可以證明這一點）。

## 與軟體工程的聯絡

成本效用分析背後的深層理念——*用一個複合的、經偏好加權的單一單位，來比較彼此不同的事物*——正是比較不同型別工程投資（安全性 對比 開發者體驗 對比 可靠性）時所需要的模式。誠實的選擇要麼是一個站得住腳的複合單位（罕見），要麼是一份明確的[成本後果表](../成本後果分析/)（更常見）。成本效用分析所警示的，是那種虛假的複合指標：一個"影響力評分"，其權重是在結果出來之後才被反向調整、以確保偏好的方案勝出。健康經濟學花了數十年時間將效用值的獲取方法標準化，正是為了確保權重的確定必須先於比較本身。

## 陷阱

- **效用增益低於量表工具的靈敏度**（參見[病患報告結果](../病患報告結果/)中的最小臨床重要差異概念）——用一個微小的ΔE乘以一個龐大的人群規模，是一種經典的"洗資料"手法。
- **遺漏對照護理的替代效應**——對數位化產品而言，最大的成本項往往正是它們所取代的東西。
- **將非偏好量表得分對映為效用值**，卻使用了未經驗證的換算方法。
