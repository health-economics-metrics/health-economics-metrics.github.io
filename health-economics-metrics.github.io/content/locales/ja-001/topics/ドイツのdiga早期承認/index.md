# ドイツのDiGA早期承認

DiGA(Digitale Gesundheitsanwendungen)は、ドイツの法定「処方箋アプリ」経路であり — 医師が承認された健康アプリを処方し、法定保険がそれを償還しなければならない世界初の国家制度です。これは、デジタル治療薬に国レベルで対価を支払うという、現在進行中の主要な実験です。

## なぜ重要か

DiGAは、あらゆるデジタルヘルス企業が問う質問 — 「実際に誰が支払うのか?」 — に、法律(DVG、2019年)で答えました。その設計は驚くべきものです:

- **迅速な決定**:規制当局であるBfArMは3か月以内に決定しなければなりません。
- **暫定的な掲載**:アプリは*証拠を生成しながら*12か月間掲載できます — 重要な研究の間に収益を得ます。
- **証拠の期限**:比較研究 — 通常はRCT — を通じて「肯定的な医療効果」(医学的便益、あるいは患者に関連する構造的/手続き的な改善)を証明するか、掲載を取り消されます。暫定的な登録のおよそ半分が転換に失敗します。
- **価格設定**:製造業者は初年度の価格を自由に設定します;その後、保険者連盟と交渉されます。最初の3か月の価格の中央値は約500ユーロ;成果連動型の価格設定要素が2026年から導入されます。

市場の現実チェック(2024年末までの調査):約68のアプリが掲載され、累計100万件超の処方、処方の約81%がアクティベートされ、累計約2億3,400万ユーロの保険者支出 — 実際の市場ですが、誇大宣伝に対しては控えめであり、アクティベート後のアドヒアランスは依然として弱点です。

## 数式

すべてのDiGA創業者が運用する商業モデル:

```
収益 = 処方数 × アクティベート率 × 処方期間あたりの価格
証拠の費用 = 12か月の期間内の重要なRCT(通常100万〜300万ユーロ)
期待値 = P(証拠が成功する) × 定常状態の収益 − 証拠の費用

転換失敗率が約50%であるため、Pは正直に評価されなければなりません —
分野の半分がRCTの資金を使い、掲載を失います。
```

## 計算例

うつ病管理アプリが、四半期あたり450ユーロで暫定的に掲載されます:

```
1年目:20,000件の処方 × 81%のアクティベート × 450ユーロ ≈ 730万ユーロの収益
RCT費用:200万ユーロ、並行して実施
結果A(証拠が肯定的):恒久的な掲載、交渉された価格約380ユーロ、
  定常状態で年間60,000件の処方 ≈ 年間1,850万ユーロ
結果B(証拠が失敗):12か月目に掲載取り消し;収益は止まる。
```

暫定的な年は、証拠生成の資金を賄います — これがこの経路の核心的な革新です。従来の順序(まず証拠、何年も後に収益)と対比してください。それはまさに、DiGAが存在してほしいと望む製品を枯渇させます。

## ソフトウェア工学との関連

DiGAのパターン — **事前登録された成功指標と自動的な日没条項を伴う暫定的な採用** — は、エンジニアリングツールのガバナンスに直接コピーできます:ツールを本番利用者に12か月出荷し、指標を事前登録し(測定された節約時間、インシデントの削減)、証拠が得られなければ自動的に失効させます。これは、パイロットのパラドックス(価値を証明するには規模が必要だが、規模を得ることのないツール)を、証明されていない技術に永続的な地位を与えることなく解決します。81%のアクティベート率/低いアドヒアランスというデータもまた、製品上の教訓を伴います:処方(あるいは経営陣の命令)はインストールをもたらしますが、持続的な利用をもたらすのは製品の質だけです — [アドヒアランスと継続](../アドヒアランスと継続/)を参照してください。

## 落とし穴

- **掲載をゴールとして扱うこと** — 処方には処方者の信頼が必要です;多くの掲載されたDiGAは無視できるほどの量しか見ていません。
- 収益の年に費用を節約するために**重要な研究の検出力を不足させること** — これが50%の失敗率の多くを説明する偽りの節約です。
- **支払者なしでこのモデルを移植すること**:DiGAが機能するのは償還が法定であるからです;義務付けられた支払いなしのコピーは単なるパイロットプログラムにすぎません。
