# এড়ানো নিম্নধারা ব্যয়

এড়ানো নিম্নধারা ব্যয় (ব্যয় অফসেট) হলো আগাম বা ভালো পদক্ষেপ দ্বারা প্রতিরোধিত ভবিষ্যত চিকিৎসা ব্যয়, হস্তক্ষেপের নিজস্ব ব্যয়ের বিপরীতে নিট করা।

## কেন এটি গুরুত্বপূর্ণ

প্রায় প্রতিটি ডিজিটাল স্বাস্থ্য মূল্য প্রস্তাবে একটি অফসেট দাবি রয়েছে: "আমাদের অ্যাপ ভর্তি প্রতিরোধ করে।" যখন অফসেট প্রকৃত, তারা অর্থনীতি রূপান্তরিত করে।

## গণিত

```
নিট ব্যয় = হস্তক্ষেপ ব্যয় − Σ অফসেট

একটি বৈধ অফসেট অবশ্যই হতে হবে:
  দায়যোগ্য — হস্তক্ষেপের সাথে কার্যকারণভাবে যুক্ত
  প্রান্তিক     — অর্থ প্রকৃতপক্ষে খরচ হওয়া বন্ধ হয়ে যায়, প্রান্তিক ব্যয়ে
  সম্ভাব্যতা-  — P(নিম্নধারা ঘটনা ঘটত) দ্বারা ওজনযুক্ত
  ওজনযুক্ত
  ছাড়যুক্ত   — ভবিষ্যত এড়ানো ব্যয় বর্তমান মূল্যে
  অনন্য       — একবার গণনা করা, একটি সুবিধা লাইনে
```

## সমাধানকৃত উদাহরণ

"এই মাইগ্রেশন-ঝুঁকি দাবি, সঠিকভাবে করা": ৫,০০০ অস্ত্রোপচার-পরবর্তী রোগীর জন্য একটি ক্ষত-পর্যবেক্ষণ অ্যাপ সংক্রমণ-সম্পর্কিত পুনঃভর্তি এড়ানো দাবি করে।

```
বেসলাইন সংক্রমণ পুনঃভর্তি: 4.0%; অ্যাপসহ (RCT): 3.1%
দায়যোগ্য এড়ানো ঘটনা = 5,000 × 0.009 = বছরে 45
অফসেট = 45 × 3,200 = বছরে £144,000
অ্যাপ ব্যয় = 5,000 × £20 = বছরে £100,000
নিট ব্যয় = −£44,000 → প্রকৃতপক্ষে ব্যয়-সাশ্রয়ী
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

"এই মাইগ্রেশন ভবিষ্যত পুনর্লিখন এড়ায়" একটি অফসেট দাবি, এবং স্বাস্থ্য-অর্থনীতির নিয়ম এটিকে সৎ করে তোলে: প্রতিতথ্য ব্যয়, সম্ভাব্যতা, ছাড়, এবং অনন্যতা।

## ঝুঁকিপূর্ণ দিক

- **দ্বিগুণ গণনা** — একই এড়ানো ভর্তি অফসেট, শয্যা-দিন, এবং ব্যয়-সংযুক্ত QALY হিসেবে দাবি করা।
- স্থির ব্যয় যাই হোক চলতে থাকা ঘটনার জন্য **গড়-ব্যয় অফসেট**।
- শুধুমাত্র সম্ভব ছিল এমন নিম্নধারা ঘটনায় **নীরব ১০০% সম্ভাব্যতা**।
