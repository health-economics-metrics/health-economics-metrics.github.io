# Technische schuld

Technische schuld is de impliciete toekomstige kost van eerdere beslissingen die op het moment zelf handig waren in een codebase: onbetaalde correctiewerkzaamheden (**hoofdsom**) en de voortdurende weerstand die ze op levering uitoefenen (**rente**).

## Waarom het ertoe doet

Zonder kwantificering is technische schuld een klacht; met kwantificering is het een businesscase.

## De wiskunde

```
SQALE-hoofdsom = Σ overtredingen(correctietijd) × ontwikkelaarskostentarief
```

## Uitgewerkt voorbeeld

Een integratielaag van 400.000 regels code voor klinische dossiers: rente ≈ £276.000/jaar.

## Verbinding met software-engineering

Gezondheidseconomische importen die het debat over technische schuld verrijken.
