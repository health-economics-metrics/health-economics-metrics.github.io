# নিম্নধারা সম্পদ অপ্টিমাইজেশন

একজন সিনিয়র চিকিৎসকের জন্য এক ঘণ্টা সাশ্রয় করা — একজন GP, সিনিয়র রেজিস্ট্রার, পরামর্শদাতা — প্রায়ই নার্স, প্রশাসনিক কেরানি, এবং থেরাপিস্টদের একটি সম্পূর্ণ বহু-বিভাগীয় দলের (MDT) জন্য বাধাগ্রস্ত বিলম্ব প্রতিরোধ করে।

## কেন এটি গুরুত্বপূর্ণ

স্বাস্থ্যসেবা অনুমোদন শৃঙ্খলে চলে: স্রাব পরামর্শদাতার অনুমোদনের জন্য অপেক্ষা করে, চিকিৎসা পরিকল্পনা MDT পর্যালোচনার জন্য অপেক্ষা করে। যখন প্রবেশদ্বার ভূমিকা বিলম্বিত হয়, ব্যয় একজন ব্যক্তির ঘণ্টা নয় — এটি প্রতিটি নির্ভরশীল ভূমিকা জুড়ে অলস বা বাধাগ্রস্ত সময়।

## গণিত

```
অবরোধমুক্তির মূল্য = Σ নিম্নধারা ভূমিকা জুড়ে (মুক্ত বাধাগ্রস্ত ঘণ্টা × একক ব্যয়)
                    + পথ থ্রুপুট লাভ × প্রতি পথ সম্পূর্ণতা মূল্য
```

## সমাধানকৃত উদাহরণ

একটি ওয়ার্ডের স্রাবের জন্য প্রতি সকালে পরামর্শদাতা পর্যালোচনা প্রয়োজন। পরামর্শদাতা সিস্টেম জুড়ে ছড়িয়ে থাকা তথ্য একত্রিত করতে দিনে ৯০ মিনিট ব্যয় করেন। একটি স্রাব-সারাংশ ড্যাশবোর্ড একত্রীকরণকে ২০ মিনিটে কমায়:

```
এড়ানো শয্যা-দিন = ৬টির মধ্যে ৪টি দেরি স্রাব × 365 ≈ বছরে 1,460 শয্যা-দিন
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

এটি কোড পর্যালোচনা, স্থাপত্য অনুমোদন, এবং স্টাফ ইঞ্জিনিয়ারের ইনবক্স। যখন পাঁচজন প্রকৌশলী একজন ব্যক্তির জন্য একদিন অপেক্ষা করে যিনি একটি নকশা অনুমোদন করতে পারেন, ব্যয় হলো পাঁচ প্রকৌশলী-দিন প্লাস কাজের নিজস্ব একদিনের বিলম্বের ব্যয়।

## ঝুঁকিপূর্ণ দিক

- **অ-সীমাবদ্ধতা অপ্টিমাইজ করা**: একটি ভূমিকার জন্য সুন্দর টুলিং যার পেছনে কিছুই সারিবদ্ধ হয় না প্রায় শূন্য মূল্য তৈরি করে।
- **সীমাবদ্ধতার স্থানান্তর**: পরামর্শদাতাকে অবরোধমুক্ত করুন এবং সীমাবদ্ধতা সরে যায়।
- **নিম্নধারা ঘণ্টাকে নগদ হিসেবে গণনা করা**: বাধাগ্রস্ত-সময় মুক্তি ক্ষমতা।
