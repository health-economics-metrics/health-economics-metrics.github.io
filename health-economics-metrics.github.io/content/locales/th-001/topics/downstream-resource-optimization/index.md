# การเพิ่มประสิทธิภาพทรัพยากรปลายน้ำ

การเพิ่มประสิทธิภาพทรัพยากรปลายน้ำมุ่งเน้นไปที่การเปิดบทบาทหรือกระบวนการที่ทุกคนรอคอย แทนที่จะเพิ่มประสิทธิภาพแบบสุ่ม

## ทำไมจึงสำคัญ

การปรับปรุงขั้นตอนที่ไม่ใช่คอขวดในเส้นทางการรักษาจะไม่ส่งผลต่อเวลานำส่งโดยรวม — มีเพียงคอขวดเท่านั้นที่กำหนดความสามารถของระบบ

## คณิตศาสตร์

```
ปริมาณงานของระบบ = ปริมาณงานของขั้นตอนที่จำกัด (คอขวด)
```

## ตัวอย่างที่คำนวณแล้ว

เส้นทางการวินิจฉัยมี 5 ขั้นตอน ขั้นตอนที่ 3 (การตีความภาพ) มีเวลารอนานที่สุด การเร่งขั้นตอน 1, 2, 4 และ 5 จะไม่ส่งผลต่อเวลานำส่งโดยรวมจนกว่าขั้นตอนที่ 3 จะได้รับการแก้ไข

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายโดยตรงกับทฤษฎีข้อจำกัดที่นำไปใช้กับไปป์ไลน์ CI/CD — เร่งความเร็วขั้นตอนที่ช้าที่สุด ไม่ใช่ขั้นตอนแบบสุ่ม

## ข้อผิดพลาดที่พบบ่อย

- **การลงทุนทรัพยากรในกระบวนการที่ไม่ใช่คอขวดเพราะง่ายต่อการปรับปรุงกว่า**
- **การไม่ระบุคอขวดใหม่หลังจากแก้ไขคอขวดเดิมแล้ว (คอขวดเคลื่อนย้ายไปที่อื่น)**
