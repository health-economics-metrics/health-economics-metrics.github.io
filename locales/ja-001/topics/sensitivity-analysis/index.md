# 感度分析

決定論的感度分析(DSA)は、結論が持ちこたえるかどうかを見るために、もっともらしい範囲の中で一度に1つの前提を変化させます。標準的な可視化手法はトルネード図です:パラメータを、結果をどれだけ揺さぶるかによって順位付けします。

## なぜ重要か

あらゆる経済モデルは推定値の上に成り立っています — 節約時間、普及率、単位費用。医療技術評価は、入力に関する合理的な意見の相違に対して結論が頑健であるという証拠なしに、単一の推定値(「ROIは340%」)を受け入れることを拒みます。トルネード図は意思決定者に*どの前提を問い質すべきか*を教えます:最も議論の余地がある変数が楽観的な端にあるときにしかケースが成り立たないなら、誰もがそれを即座に見て取れます。

これは、医療経済学からソフトウェアのビジネスケースへと転用できる、最も汎用性の高い習慣です。

## 数式

もっともらしい範囲 [p_低, p_高] を持つ各パラメータpについて:

```
結果_低  = モデル(p = p_低,  他はすべて基本ケース)
結果_高  = モデル(p = p_高,  他はすべて基本ケース)
振れ幅(p) = |結果_高 − 結果_低|
```

パラメータを振れ幅で順位付けし、基本ケースの結果の周りに水平の棒を描画します。派生形:二元DSA(2つのパラメータをグリッド上で変化させる)、閾値分析(意思決定が反転するパラメータ値を見つける)。

## 計算例

200人の開発者向けAIコーディングアシスタント。基本ケース:£39/開発者/月のライセンス、1日あたり30分の節約、全負担コスト£60/時間、220営業日。

```
基本ケースの年間便益 = 200 × 0.5時間 × 220 × £60 = £1,320,000
年間費用             = 200 × £39 × 12            = £93,600
基本ケースの正味      = £1,226,400
```

トルネード(一度に1つのパラメータ):

```
節約時間 0.1〜1.0時間/日: 正味 = £170,400 … £2,546,400 (振れ幅£2.38M) ← 支配的
全負担コスト £40〜£80/時: 正味 = £786,400 … £1,666,400 (振れ幅£0.88M)
営業日数 200〜240:        正味 = £1,106,400 … £1,346,400 (振れ幅£0.24M)
ライセンス £30〜£50/月:   正味 = £1,248,000 … £1,200,000 (振れ幅£48k)
```

閾値分析:正味便益は、節約時間が約**1日2.1分**でゼロになります。この意思決定はライセンス価格には鈍感で、節約時間の推定値に完全に左右されます — だからそれを測定すべきであり、他のものではありません。(そして、結果は現金ではなく容量であることを忘れないでください — [現金化可能な節約と非現金化節約](../cash-releasing-vs-non-cash-releasing/)を参照。)

## ソフトウェア工学との関連

エンジニアはすでに「Xについて間違っていたらどうなる?」という本能的な形でこれを行っています — DSAはそれを体系的かつ可視化するだけです。あらゆるツール提案、キャパシティ計画、内製か購入かの分析にトルネード図を入れてください。それは、誰の勘が正しいかという議論を、次にどのパラメータを測定すべきかという合意に変えます — しばしばパイロット試験を通じて、その価値自体も値付けできます([完全情報の期待価値](../expected-value-of-perfect-information/)を参照)。

## 落とし穴

- **都合の良い範囲を選ぶこと**:実際の不確実性にかかわらず、すべての入力に一律±10%を使うこと。節約時間の推定には±80%が、ライセンス価格には±10%がふさわしい。
- **一度に1つずつでは相互作用を見逃す** — 相関するパラメータ(普及率と節約時間)には、二元分析または完全な[確率的感度分析](../probabilistic-sensitivity-analysis/)が必要です。
- **分析をしても無視すること**:トルネードがケースが1つの曖昧な数値に左右されると示しているなら、次のステップは測定であり、承認ではありません。
