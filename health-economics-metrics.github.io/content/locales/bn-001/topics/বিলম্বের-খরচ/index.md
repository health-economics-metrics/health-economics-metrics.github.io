# বিলম্বের খরচ (CoD)

বিলম্বের খরচ হল একটি ফিচার, পণ্য বা পরিষেবা *প্রদান না করার* প্রতি ইউনিট সময়ে হারানো অর্থনৈতিক মূল্য। এটি সফটওয়্যার প্রদান মেট্রিক এবং স্বাস্থ্য অর্থনীতির মধ্যে একক সবচেয়ে শক্তিশালী সেতু: এটি "আমরা দেরিতে প্রেরণ করেছি"-কে মুদ্রায় রূপান্তরিত করে — অথবা QALY-তে।

## কেন এটি গুরুত্বপূর্ণ

রাইনার্টসেনের নিয়ম: "যদি আপনি শুধুমাত্র একটি জিনিস পরিমাপ করেন, বিলম্বের খরচ পরিমাপ করুন।" বেশিরভাগ সংস্থা জানে একটি প্রকল্প কী খরচ করে কিন্তু জানে না এক মাসের বিলম্ব কী খরচ করে, তাই তারা সময়-মূল্য রক্তক্ষরণ করার সময় বাজেট অপ্টিমাইজ করে। স্বাস্থ্যসেবা সফটওয়্যারের জন্য বাজিগুলি আক্ষরিক: প্রতি সপ্তাহ একটি পথ উন্নতি বিলম্বিত হয়, রোগীরা খারাপ স্বাস্থ্য অবস্থায় বেশি সময় অপেক্ষা করে। CoD হল NHS স্টেকহোল্ডারদের কাছে উপস্থাপন করার সবচেয়ে শক্তিশালী গাণিতিক কাঠামো কারণ এটি আপনার সফটওয়্যারের *অনুপস্থিতির* মূল্য নির্ধারণ করে।

## গণনা

```
CoD = অপ্রদত্ত থাকাকালীন প্রতি ইউনিট সময়ে বিসর্জিত সুবিধা   (£/সপ্তাহ বা QALY/সপ্তাহ)

মোট বিলম্ব ক্ষতি = CoD × বিলম্ব সময়কাল

অগ্রাধিকারের জন্য, দেখুন wsjf-and-cd3.md: CD3 = CoD / সময়কাল।
```

ক্লিনিক্যাল সফটওয়্যারের জন্য, টাকার পাশাপাশি স্বাস্থ্যেও প্রকাশ করুন:

```
CoD_স্বাস্থ্য = প্রতি সপ্তাহে প্রভাবিত রোগী × প্রতি রোগীতে QALY লাভ
CoD_টাকা     = CoD_স্বাস্থ্য × λ (পরিশোধ করার ইচ্ছার প্রান্তসীমা, £20হাজার-30হাজার/QALY)
             + প্রতি সপ্তাহে বিসর্জিত অপারেশনাল সঞ্চয়
```

## বিস্তারিত উদাহরণ

**অপারেশনাল**: সফটওয়্যার একটি পথে প্রতি রোগীতে £200 সাশ্রয় করে; একটি ট্রাস্ট সপ্তাহে 50 জন এমন রোগী প্রক্রিয়া করে।

```
CoD = 200 × 50 = £10,000/সপ্তাহ
একটি 10-সপ্তাহের সংগ্রহ বিলম্ব 200 × 50 × 10 = £100,000 এড়ানো যায় এমন অপচয় খরচ করে।
```

**ক্লিনিক্যাল**: একটি ট্রায়াজ উন্নতি সপ্তাহে 100 জন রোগীর জন্য অপেক্ষার 5 সপ্তাহ অপসারণ করে (উপযোগিতা 0.68 → 0.80 আগে):

```
প্রতি রোগীতে QALY লাভ = (5/52) × 0.12 ≈ 0.0115
CoD_স্বাস্থ্য = 100 × 0.0115 = 1.15 QALY/সপ্তাহ
CoD_টাকা     = 1.15 × £20,000 ≈ £23,000/সপ্তাহ স্বাস্থ্য মূল্য
```

6-মাসের স্থাপনা বিলম্ব ~30 QALY "খরচ করে" — যুক্তি যা একটি IT গো-লাইভ পিছলে যাওয়াকে একটি ক্লিনিক্যাল ঘটনা হিসেবে পুনর্গঠন করে। (স্কেলের জন্য বেঞ্চমার্ক: Black Swan Farming-এর বিখ্যাত Maersk বিশ্লেষণে CoD ≈ $200হাজার/সপ্তাহ সহ একক ফিচার পাওয়া গেছে যা 38 সপ্তাহ অপেক্ষা করেছিল।)

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

CoD হল মেট্রিক যা [DORA লিড টাইম](../dora-মেট্রিক/) এবং [প্রবাহ দক্ষতা](../প্রবাহ-মেট্রিক/)-কে আর্থিকভাবে পাঠযোগ্য করে তোলে: লিড টাইম × CoD = সারিতে পোড়ানো টাকা (বা স্বাস্থ্য)। ব্যবহার:

- **অগ্রাধিকার**: সবচেয়ে উচ্চস্বরের স্টেকহোল্ডারের পরিবর্তে CoD/সময়কাল ([WSJF/CD3](../wsjf-ও-cd3/)) দ্বারা কাজ র‍্যাংক করুন।
- **প্রক্রিয়া অর্থনীতি**: একটি 2-সপ্তাহের রিলিজ ছন্দে ক্রমাগত প্রদানের বিরুদ্ধে প্রতি ফিচারে প্রত্যাশিত বিলম্ব খরচ ~1 সপ্তাহ × CoD আছে — ব্যাচের মূল্য নির্ধারণ করুন।
- **সংগ্রহ**: NHS সংগ্রহ চক্র 6-18 মাসের একটি CoD আছে; এটি দেখানো জরুরিতা আলোচনা পরিবর্তন করে (সাশ্রয়ীতা প্রতিরূপের জন্য দেখুন [বাজেট প্রভাব বিশ্লেষণ](../বাজেট-প্রভাব-বিশ্লেষণ/))।

## ঝুঁকি

- **রৈখিক CoD ধরে নেওয়া**: কিছু কাজের দেড লাইন-আকৃতির মূল্য আছে (নিয়ন্ত্রক তারিখ — তারিখের পরে অসীম CoD, আগে শূন্য) বা ক্ষয়প্রাপ্ত মূল্য (প্রথম-চালক জানালা)। গুণ করার আগে জরুরিতা প্রোফাইল শ্রেণীবদ্ধ করুন।
- **কেউ চায় না এমন আউটপুটে CoD**: বিলম্ব শুধুমাত্র খরচ করে যদি জিনিসটির মূল্য থাকে; বিলম্বিত আবর্জনা বিনামূল্যে।
- **বিলম্ব এবং ছাড়করণ দ্বৈত গণনা**: [ছাড়করণ](../ছাড়করণ-ও-সময়-পছন্দ/) ইতিমধ্যে বহু-বছরের দিগন্তে সময়ের মূল্য নির্ধারণ করে; CoD হল দিগন্তের মধ্যে অপারেশনাল সংস্করণ। সপ্তাহ/মাসের জন্য CoD ব্যবহার করুন, বছরের জন্য NPV স্থানান্তর।
