# มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ

มูลค่าคาดหวังของข้อมูลที่สมบูรณ์แบบ (EVPI) วัดมูลค่าของการขจัดความไม่แน่นอนทั้งหมดในการตัดสินใจ — ใช้เพื่อตัดสินว่าควรลงทุนในการวิจัยเพิ่มเติมหรือไม่

## ทำไมจึงสำคัญ

EVPI ตอบคำถามที่ปฏิบัติได้จริง: ควรใช้จ่ายเงินกับการศึกษานำร่องหรือการทดลองเพิ่มเติมหรือไม่ หากมูลค่าของข้อมูลที่สมบูรณ์แบบต่ำกว่าต้นทุนการวิจัย ก็ไม่ควรทำการวิจัยนั้น

## คณิตศาสตร์

```
EVPI = E[มูลค่าสูงสุดภายใต้ข้อมูลที่สมบูรณ์แบบ] − มูลค่าของการตัดสินใจที่ดีที่สุดในปัจจุบัน
```

## ตัวอย่างที่คำนวณแล้ว

EVPI ต่อผู้ป่วยคำนวณได้ที่ £500 และประชากรเป้าหมายมี 10,000 คนต่อปี ให้ EVPI รวม £5 ล้าน — หากการทดลองเพิ่มเติมมีค่าใช้จ่ายน้อยกว่า £5 ล้าน ก็คุ้มค่าที่จะทำ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการตัดสินใจว่าควรทำการทดสอบ A/B เพิ่มเติมหรือไม่ก่อนตัดสินใจเรื่องฟีเจอร์ครั้งใหญ่ — หากมูลค่าของความแน่นอนเพิ่มเติมต่ำกว่าต้นทุนของการทดสอบ ก็ควรตัดสินใจไปเลยโดยไม่ต้องทดสอบเพิ่ม

## ข้อผิดพลาดที่พบบ่อย

- **การคำนวณ EVPI โดยไม่พิจารณาขนาดประชากรที่ได้รับผลกระทบ**
- **การสับสนระหว่าง EVPI กับมูลค่าคาดหวังของข้อมูลตัวอย่าง (EVSI) ซึ่งสมจริงกว่าแต่ซับซ้อนกว่า**
