# เกณฑ์ความเต็มใจจ่าย

เกณฑ์ความเต็มใจจ่ายคือจำนวนเงินสูงสุดที่ระบบสุขภาพเต็มใจจ่ายต่อหนึ่งหน่วยผลลัพธ์สุขภาพ (เช่น ต่อ QALY) ก่อนที่จะปฏิเสธเทคโนโลยีว่าไม่คุ้มทุน

## ทำไมจึงสำคัญ

เกณฑ์นี้เป็นเส้นแบ่งที่ชัดเจนที่กำหนดว่าเทคโนโลยีใหม่จะได้รับเงินทุนหรือไม่ และสะท้อนถึงต้นทุนค่าเสียโอกาสของระบบ — จำนวนสุขภาพที่เงินจำนวนเดียวกันซื้อได้จากที่อื่นในระบบ

## คณิตศาสตร์

ไม่มีสูตรเดียว; เกณฑ์มักกำหนดเป็นช่วง เช่น £20,000–30,000 ต่อ QALY ของ NICE ในสหราชอาณาจักร หรือ $50,000–150,000 ที่ใช้กันทั่วไปในสหรัฐอเมริกา

## ตัวอย่างที่คำนวณแล้ว

เทคโนโลยีที่มี ICER £35,000/QALY มักจะถูกปฏิเสธโดย NICE เว้นแต่จะมีปัจจัยพิเศษ (เช่น โรคหายากหรือการดูแลระยะสุดท้าย) ที่ทำให้เกณฑ์สูงขึ้นได้

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับเกณฑ์งบประมาณสูงสุดต่อหน่วยประสิทธิภาพที่ทีมวิศวกรรมยินดีจ่ายสำหรับการอัปเกรดโครงสร้างพื้นฐาน — เกินกว่านั้นถือว่าไม่คุ้มค่า

## ข้อผิดพลาดที่พบบ่อย

- **การปฏิบัติต่อเกณฑ์เป็นตัวเลขตายตัวแทนที่จะเป็นค่าประมาณของต้นทุนค่าเสียโอกาสของระบบ**
- **การเพิกเฉยต่อความแตกต่างของเกณฑ์ระหว่างประเทศเมื่อเปรียบเทียบการตัดสินใจ**
