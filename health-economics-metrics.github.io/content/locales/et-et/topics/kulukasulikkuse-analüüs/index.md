# Kulukasulikkuse analüüs (CUA)

Kulukasulikkuse analüüs võrdleb sekkumisi kulu alusel QALY kohta, muutes täiesti erinevad ravimeetodid ühel skaalal võrreldavaks.

## Miks see on oluline

CUA on NICE-i ja enamiku HTA organite standardmeetod, kuna see võimaldab võrrelda südameravimit vaimse tervise sekkumisega.

## Matemaatika

```
CUA suhe (ICER) = (Kulu_A − Kulu_B) / (QALY_A − QALY_B)
```

## Lahendatud näide

Uus reumaravim maksab £8000 rohkem ja annab 0,4 QALY rohkem võrreldes standardraviga: £20 000/QALY.

## Seos tarkvaraarendusega

Sarnaneb kasutajaväärtuse ühiku kulu normaliseerimisega täiesti erinevate funktsioonitüüpide vahel.

## Lõksud

- **Asjaomase populatsiooni jaoks valideerimata kasulikkuse kaalude kasutamine.**
- **CUA ja CEA tulemuste segiajamine ilma ühikut määratlemata.**
