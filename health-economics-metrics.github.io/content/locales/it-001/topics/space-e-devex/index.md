# SPACE e DevEx

SPACE e DevEx sono framework per misurare la produttività degli sviluppatori in modo **multidimensionale**.

## Perché è importante

Entrambi i framework codificano la stessa lezione appresa dalla ricerca sui risultati sanitari decenni fa.

## La matematica

```
Regola SPACE: ≥ 3 dimensioni, ≥ 1 percettiva + ≥ 1 metrica di sistema
```

## Esempio risolto

Un team di piattaforma giustifica un investimento DevEx per 300 sviluppatori.
