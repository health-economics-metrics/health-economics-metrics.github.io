# उपचार के लिए आवश्यक संख्या (NNT)

NNT एक निर्दिष्ट समय-सीमा में **एक** अतिरिक्त रोगी को लाभान्वित करने के लिए कितने रोगियों को एक हस्तक्षेप प्राप्त करना चाहिए, यह संख्या है।

## यह क्यों महत्वपूर्ण है

"हृदय के दौरे को 25% कम करता है!" निर्णायक लगता है। यदि आधाररेखा जोखिम 5 वर्षों में 4% है, तो पूर्ण कमी 1 प्रतिशत बिंदु है, इसलिए **1 को लाभ के लिए 100 को 5 वर्षों तक दवा लेनी होगी**।

## गणित

```
ARR = नियंत्रण घटना दर − उपचार घटना दर
NNT = 1 / ARR
```

## हल किया गया उदाहरण

एक अस्पताल में एक गिरावट-भविष्यवाणी प्रणाली उच्च-जोखिम रोगियों को हस्तक्षेप के लिए चिह्नित करती है।

```
ARR = 0.8 प्रतिशत बिंदु → NNT = 1/0.008 = 125
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

NNT किसी भी गेट या जाँच के लिए सही इकाई है जो कई वस्तुओं पर काम करके कम पकड़ती है।

## सामान्य गलतियाँ
