# Аналіз мінімізації витрат (CMA)

Аналіз мінімізації витрат обирає найдешевший варіант після доведення того, що порівнювані втручання мають еквівалентну ефективність.

## Чому це важливо

Коли ефективність уже доведено еквівалентною, непотрібно проводити складні розрахунки економічної ефективності — просто оберіть найдешевший.

## Математика

```
Обрати варіант з min(Витрати), за умови Ефекти_A = Ефекти_B
```

## Розібраний приклад

Два генеричні препарати з доведеною ідентичною ефективністю: оберіть той, що має найнижчу закупівельну ціну, без подальшого аналізу.

## Зв'язок з інженерією програмного забезпечення

Подібно до вибору найдешевшого хмарного провайдера після підтвердження, що обидва відповідають однаковим вимогам продуктивності та надійності.

## Підводні камені

- **Припущення еквівалентності без надійних доказів.**
- **Використання CMA, коли ефекти насправді тонко відрізняються.**
