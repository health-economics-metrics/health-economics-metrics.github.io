# Retensjon og churn

Retensjon og churn måler om brukere fortsetter å bruke en helseapp over tid, eller slutter.

## Hvorfor det er viktig

Churnrater for helseapper har en tendens til å være mye høyere enn for vanlige forbrukerapper.

## Matematikken

```
Månedlig churnrate = antall tapte brukere den måneden / totalt antall brukere ved månedens start × 100 %
```

## Gjennomarbeidet eksempel

En app for psykisk helse: ved start 5 000, tapt 750 = månedlig churnrate 15 %.

## Kobling til programvareutvikling

Det langsiktige resultatet av [engasjementsmål](../engagement-metrics/) og påvirker direkte [helseappens enhetsøkonomi](../health-app-unit-economics/).

## Fallgruver

- **Å se det innledende brukerfrafallet som normalt uten videre undersøkelse.**
