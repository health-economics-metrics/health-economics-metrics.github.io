# 正味金銭的便益(NMB)

NMBは、費用効果の結果を単一の金銭的価値に変換します:支払意思額の閾値で値付けした健康の獲得から、費用を差し引いたものです。その双子である正味健康便益(NHB)は、同じルールを健康の単位で表現します。

## なぜ重要か

比率([ICER](../増分費用効果比/))は扱いにくいものです:効果がゼロに近づくと発散し、不確実性の抽出にわたって平均を取ることができず、3つ以上の選択肢をきれいに順位付けできません。NMBはこれらすべてを解決します — 線形なので、選択肢を順位付けし、モンテカルロ抽出を平均し、寄与を分解できます。また、これはすべてのエンジニアがすでに知っている形の医療経済学の数式でもあります:*価値マイナス費用*。

## 数式

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = 増分効果(例:QALY)
ΔC = 増分費用
λ  = 支払意思額の閾値(willingness-to-pay-thresholds.mdを参照)

意思決定ルール:NMB > 0 なら採用する(同等にNHB > 0)。
代替案の中では:最も高いNMBを選ぶ。
```

NMB > 0 ⇔ ICER < λ(ΔE > 0のとき)なので、2つのルールは一致します — NMBはただ振る舞いが良いだけです。

## 計算例

糖尿病サービスの3つの選択肢、患者1,000人あたり、λ = £20,000/QALY:

```
選択肢             ΔC         ΔE(QALY)   NMB = 20,000×ΔE − ΔC
アプリ+コーチング  £400,000   30          600,000 − 400,000 = £200,000
アプリのみ         £150,000   12          240,000 − 150,000 = £90,000
追加の診療所       £700,000   32          640,000 − 700,000 = −£60,000
```

追加の診療所は最も多くのQALYを獲得しますが、この閾値では価値を破壊します(NMB < 0)。アプリ+コーチングが勝ちます。NMBによって*3つすべてを一度に*順位付けできることに注目してください — 対のICERでは[優越関係と効率フロンティア](../優越関係と効率フロンティア/)のフロンティア手順が必要であり、それでも同じ答えに到達します。

勝者のNHBの見方:30 − 400,000/20,000 = 30 − 20 = **正味10QALY** — 同じお金を他所で使った場合に生み出されたであろう健康を超えて得られた健康です。

## ソフトウェア工学との関連

「(節約された時間 × 全負担時給) − ツールの費用」 — 日常的なツール導入のビジネスケース — は文字通り、λ = エンジニアの全負担費用としたNMBの計算です。医療経済学が加える2つの改善点:

- **λを定数ではなく変数にすること。** λ(「エンジニア1時間の価値」)に対してNMBをプロットし、意思決定が反転する場所を示してください;そうすれば、異なる利害関係者があなたの数式をやり直すことなく自分自身の評価を適用できます。
- **NHB的な思考**:「このプラットフォームは5,000エンジニア時間を節約するが、それがなければ3,000エンジニア時間分の外部委託の容量を買えたはずの予算を消費する — 正味2,000時間」という考え方は、容量の単位での機会費用の比較を強制します。[機会費用](../機会費用/)を参照してください。

## 落とし穴

- **閾値を隠すこと**:λを明示しなければNMBは無意味です;£20kと£30kでのNMBを報告するか、曲線をプロットしてください。
- **NMBを使ってわずかな効果を粉飾すること**:巨大な人口に無視できるほど小さな1人あたりの効果を掛けると、大きなNMBが生み出されることがあります — 1人あたりの効果も併せて報告してください。
- **NMBがΔCとΔEのあらゆる不確実性を受け継ぐことを忘れること** — [確率的感度分析](../確率的感度分析/)と組み合わせてください。
