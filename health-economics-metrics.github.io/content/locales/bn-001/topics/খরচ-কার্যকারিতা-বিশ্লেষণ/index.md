# খরচ-কার্যকারিতা বিশ্লেষণ (CEA)

CEA **প্রাকৃতিক ইউনিটে** পরিমাপিত একটি একক ফলাফলের বিরুদ্ধে বিকল্প হস্তক্ষেপের খরচ তুলনা করে — জীবন-বছর, সনাক্তকৃত কেস, এড়ানো ভর্তি, mmHg রক্তচাপ হ্রাস। এর আউটপুট হল প্রতি ইউনিট ফলাফলে খরচ।

## কেন এটি গুরুত্বপূর্ণ

CEA হল কর্মঘোড়া তুলনা যখন সমস্ত বিকল্প একই ফলাফলকে লক্ষ্য করে। এটি "X অর্জনের এই উপায়গুলির মধ্যে কোনটি টাকার সেরা ব্যবহার?" এর উত্তর দেয় — কিন্তু "X অর্জন করার মূল্য আছে কিনা?" নয় (এর জন্য [খরচ-সুবিধা বিশ্লেষণ](../খরচ-সুবিধা-বিশ্লেষণ/) প্রয়োজন) এবং "X অসম্পর্কিত অগ্রাধিকারের সাথে কীভাবে তুলনা করে?" নয় (এর জন্য [খরচ-উপযোগিতা বিশ্লেষণ](../খরচ-উপযোগিতা-বিশ্লেষণ/) এবং QALY-র মতো একটি জেনেরিক ফলাফল প্রয়োজন)।

## গণনা

তুলনা পরিসংখ্যান হল প্রাকৃতিক ইউনিটে [ICER](../ইনক্রিমেন্টাল-খরচ-কার্যকারিতা-অনুপাত/):

```
ICER = (খরচ_A − খরচ_B) / (প্রভাব_A − প্রভাব_B)
     = প্রতি অতিরিক্ত সনাক্তকৃত কেস / এড়ানো ভর্তি / ইত্যাদিতে £
```

পদ্ধতি: ফলাফল ইউনিট সংজ্ঞায়িত করুন; একই [সময় দিগন্ত](../সময়-দিগন্ত/) জুড়ে একই [দৃষ্টিকোণ](../বিশ্লেষণ-দৃষ্টিকোণ/) থেকে প্রতিটি বিকল্প খরচ করুন; প্রভাবিত বিকল্পগুলি বাদ দিন ([দক্ষতা সীমান্ত](../প্রাধান্য-ও-দক্ষতা-সীমান্ত/)); সীমান্ত বরাবর ইনক্রিমেন্টাল অনুপাত গণনা করুন।

## বিস্তারিত উদাহরণ

100,000 জনসংখ্যায় অনির্ণীত অলিন্দ কম্পন খুঁজে বের করার তিনটি উপায়:

```
বিকল্প                        খরচ          পাওয়া কেস
সুযোগ-নির্ভর নাড়ি পরীক্ষা      £150,000       300
ফার্মেসি স্ক্রিনিং ইভেন্ট        £400,000       520
ওয়্যারেবল-ভিত্তিক স্ক্রিনিং     £900,000       610

ICER ফার্মেসি বনাম নাড়ি:      (400হাজার−150হাজার)/(520−300) = প্রতি অতিরিক্ত কেসে £1,136
ICER ওয়্যারেবল বনাম ফার্মেসি: (900হাজার−400হাজার)/(610−520) = প্রতি অতিরিক্ত কেসে £5,556
```

প্রতি অতিরিক্ত কেসে £5,556 "মূল্যবান" কিনা তা নির্ভর করে একটি পাওয়া কেসের মূল্যের উপর (নিম্নমুখী স্ট্রোক প্রতিরোধ) — CEA বিকল্পগুলি র‍্যাংক করে কিন্তু গ্রহণ সিদ্ধান্তের জন্য সেই বাহ্যিক মূল্যায়ন প্রয়োজন। লক্ষ্য করুন ওয়্যারেবল বিকল্পের *গড়* প্রতি কেস খরচ (900হাজার/610 = £1,475) ভালো দেখায়; *ইনক্রিমেন্টাল* £5,556 সম্প্রসারণ সিদ্ধান্তের জন্য সৎ সংখ্যা।

## সফটওয়্যার ইঞ্জিনিয়ারিং সংযোগ

CEA সঠিক টেমপ্লেট যখনই বিকল্পগুলি একটি ফলাফল ভাগ করে: তিনটি প্রতিকার পদ্ধতি জুড়ে প্রতি নির্মূলকৃত অস্থির পরীক্ষায় খরচ; পর্যবেক্ষণযোগ্যতা বিক্রেতাদের জুড়ে প্রতি এড়ানো ঘটনায় খরচ; CI স্থাপত্য জুড়ে প্রতি সফল স্থাপনায় খরচ। এটি যে শৃঙ্খলা প্রয়োগ করে — একটি ঘোষিত ফলাফল ইউনিট, ইনক্রিমেন্টাল (গড় নয়) অনুপাত, প্রভাবিত বিকল্প প্রথমে বাদ — মূল্য নির্ধারণ আলোচনা শুরু হওয়ার আগে বেশিরভাগ খারাপ বিক্রেতা তুলনা মেরে ফেলে।

## ঝুঁকি

- **ভিন্ন ফলাফল সহ বিকল্প তুলনা করা** ("পাওয়া কেস" বনাম "সন্তুষ্টি") একটি CEA-তে — এর জন্য [খরচ-পরিণতি বিশ্লেষণ](../খরচ-পরিণতি-বিশ্লেষণ/) বা একটি জেনেরিক ফলাফল প্রয়োজন।
- **গড় খরচ-কার্যকারিতা অনুপাত** উপস্থাপিত যেখানে ইনক্রিমেন্টাল প্রয়োজন (উপরের ওয়্যারেবল উদাহরণ)।
- **স্তুতির জন্য বেছে নেওয়া ফলাফল ইউনিট**: "উৎপন্ন সতর্কতা" একটি আউটপুট, ফলাফল নয়; মূল্য বহনকারী ইউনিটে জোর দিন।
