# ดัชนีความเข้มข้น

ดัชนีความเข้มข้น (Wagstaff, Paci, van Doorslaer, 1991) เป็นมาตรวัดทางสถิติมาตรฐานของความไม่เท่าเทียมทางเศรษฐกิจและสังคมในตัวแปรด้านสุขภาพ มีค่าตั้งแต่ −1 ถึง 1 ค่าลบหมายความว่าตัวแปรสุขภาพกระจุกตัวอยู่ในกลุ่มที่ด้อยโอกาสทางเศรษฐกิจและสังคม ค่าบวกหมายความว่ากระจุกตัวอยู่ในกลุ่มที่มีฐานะดีกว่า และศูนย์หมายความว่าไม่มีความลาดชันทางเศรษฐกิจและสังคมที่สม่ำเสมอ มันเปลี่ยนความสงสัยเรื่องการกระจายที่ไม่เท่ากันให้เป็นตัวเลขเดียวที่เปรียบเทียบได้

## ทำไมจึงสำคัญ

โครงการหนึ่งอาจดูมีประสิทธิผลในภาพรวม แต่ส่งมอบประโยชน์เกือบทั้งหมดให้กับคนที่มีฐานะดีอยู่แล้ว ข้อกังวลด้านการกระจายเช่นนี้เองที่ [การเข้าถึงและความเสมอภาค](../การเข้าถึงและความเสมอภาค/) ติดตามเชิงพรรณนา — การเข้าถึงที่แบ่งชั้นตามควินไทล์ของความขาดแคลน ช่องว่างความเสมอภาคระหว่างกลุ่มบนสุดและล่างสุด — แต่ตารางที่แบ่งชั้นไม่สามารถย่อให้เหลือเส้นแนวโน้มเส้นเดียว และเปรียบเทียบข้ามสองมาตรการที่แตกต่างกันโดยสิ้นเชิงซึ่งวัดด้วยมาตราส่วนต่างกันได้ยาก ดัชนีความเข้มข้นแก้ทั้งสองปัญหา: คำนวณด้วยวิธีเดียวกันสำหรับตัวแปรสุขภาพใดๆ เทียบกับการจัดอันดับทางเศรษฐกิจและสังคมใดๆ ดังนั้นบริการสุขภาพแห่งชาติจึงติดตามได้ว่าความไม่เท่าเทียมของบริการดิจิทัลเฉพาะรายการกำลังกว้างขึ้นหรือแคบลงจากรุ่นสู่รุ่น และเปรียบเทียบความเป็นธรรมในการกระจายของการเปิดตัวแอปกับ เช่น โครงการคัดกรอง บนมาตราส่วนที่ปรับให้เป็นมาตรฐานเดียวกัน

## คณิตศาสตร์

```
CI = (2 / ค่าเฉลี่ย(ค่าสุขภาพ)) × Cov(ค่าสุขภาพ, อันดับทางเศรษฐกิจและสังคม)

Cov(X, Y) = ค่าเฉลี่ย(X × Y) − ค่าเฉลี่ย(X) × ค่าเฉลี่ย(Y)   (ความแปรปรวนร่วมของประชากร)

อันดับทางเศรษฐกิจและสังคม: อันดับแบบเศษส่วนของแต่ละคนในการกระจายทาง
เศรษฐกิจและสังคม ในช่วง [0, 1] (0 = ด้อยโอกาสที่สุด, 1 = ได้เปรียบที่สุด;
สำหรับข้อมูลที่จัดกลุ่ม/แบ่งช่วง โดยปกติใช้อันดับจุดกึ่งกลางของแต่ละกลุ่ม)
```

นี่คือ "สูตรความแปรปรวนร่วมที่สะดวก" (O'Donnell, van Doorslaer, Wagstaff, Lindelow, ธนาคารโลก 2008) — ทางลัดมาตรฐานของนักปฏิบัติสำหรับคำนวณดัชนีความเข้มข้นโดยตรงจากข้อมูลสังเกตที่จับคู่กัน โดยไม่ต้องวาดและอินทิเกรตใต้เส้นโค้งความเข้มข้นก่อน

## ตัวอย่างที่คำนวณแล้ว

คะแนนสุขภาพดีที่รายงานด้วยตนเอง (1 = แย่ที่สุด, 4 = ดีที่สุด) ที่สังเกตข้ามสี่ควอร์ไทล์ทางเศรษฐกิจและสังคมขนาดเท่ากัน แต่ละควอร์ไทล์แทนด้วยอันดับจุดกึ่งกลาง:

```
ค่าสุขภาพ                  = [1.0, 2.0, 3.0, 4.0]
อันดับทางเศรษฐกิจและสังคม  = [0.125, 0.375, 0.625, 0.875]

ค่าเฉลี่ย(ค่าสุขภาพ)        = 2.5
ค่าเฉลี่ย(สุขภาพ × อันดับ)  = ค่าเฉลี่ย([0.125, 0.75, 1.875, 3.5]) = 1.5625
ค่าเฉลี่ย(อันดับ)           = 0.5

Cov = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

ค่า `0.25` ที่เป็นบวกหมายความว่าคะแนนสุขภาพนี้กระจุกตัวอยู่ในกลุ่มที่ได้เปรียบทางเศรษฐกิจและสังคม — ผู้ตอบที่มีคะแนนสูงกว่าเอนไปทางปลายที่มีฐานะดีกว่าของการจัดอันดับ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

นี่คือการวัดความไม่เท่าเทียมบนพื้นฐานความแปรปรวนร่วมแบบเดียวกับที่ใช้ในเศรษฐศาสตร์โดยทั่วไป (ญาติของสัมประสิทธิ์จีนี) และแปลไปสู่การวัดว่าประโยชน์ของผลิตภัณฑ์ซอฟต์แวร์กระจุกตัวอยู่ในกลุ่มผู้ใช้ที่ได้เปรียบอยู่แล้วหรือกระจายอย่างเป็นธรรม — เป็นส่วนขยายโดยตรงของ[การเข้าถึงและความเสมอภาค](../การเข้าถึงและความเสมอภาค/) (มิติ "reach" ของ RE-AIM) ไปสู่มาตรวัดทางสถิติอย่างเป็นทางการแทนช่องว่างที่บรรยายไว้ ขณะที่การเข้าถึงและความเสมอภาครายงานผลกระทบรายชั้น ดัชนีความเข้มข้นบีบการกระจายทั้งหมดให้เป็นตัวเลขมีเครื่องหมายตัวเดียว เหมาะเป็น KPI เดี่ยวที่ติดตามข้ามรุ่น — ใช้งานได้จริงสำหรับแดชบอร์ดที่การแจกแจงแบบแบ่งชั้นเต็มรูปแบบไม่พอดี

## ข้อผิดพลาดที่พบบ่อย

- **ข้อตกลงเรื่องเครื่องหมายคลาดเคลื่อน**: เครื่องหมายขึ้นอยู่กับว่านิยามทั้งตัวแปรสุขภาพและอันดับอย่างไร — การพลิกอย่างใดอย่างหนึ่งจะพลิกเครื่องหมาย ดังนั้นต้องระบุข้อตกลงที่ใช้อย่างชัดเจนทุกครั้งที่รายงานค่า
- **ใช้อันดับที่ขอบเขตแทนอันดับจุดกึ่งกลาง**: ข้อมูลทางเศรษฐกิจและสังคมที่จัดกลุ่มหรือแบ่งช่วง (เช่น ควินไทล์) ต้องใช้อันดับเศษส่วนของแต่ละกลุ่มที่ *จุดกึ่งกลาง* ไม่ใช่ที่ขอบ มิฉะนั้นดัชนีจะมีอคติ
- **อ่านว่า "ใกล้ศูนย์" เท่ากับ "ไม่มีความไม่เท่าเทียม"**: ดัชนีความเข้มข้นที่ใกล้ศูนย์หมายถึง "ไม่มีความลาดชันทางเศรษฐกิจและสังคมที่สม่ำเสมอ" ไม่ใช่ "ไม่มีความไม่เท่าเทียม" ในความหมายสัมบูรณ์ — ความไม่เท่าเทียมที่หักล้างกันในทิศทางต่างๆ อาจหักล้างกันจนหมด
