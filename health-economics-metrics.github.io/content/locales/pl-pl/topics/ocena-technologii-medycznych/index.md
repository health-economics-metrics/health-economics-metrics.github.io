# Ocena technologii medycznych (HTA)

Ocena technologii medycznych to formalny proces, w którym organy takie jak NICE, ICER (USA) i CADTH oceniają, czy nowa technologia warta jest finansowania.

## Dlaczego to ważne

Organy HTA w praktyce decydują o dostępie rynkowym dla nowych technologii medycznych w większości rozwiniętych systemów opieki zdrowotnej.

## Matematyka

```
Rekomendacja HTA = f(ICER kontra próg, wpływ budżetowy, jakość dowodów, względy równości)
```

## Rozwiązany przykład

NICE ocenia nowe narzędzie diagnostyczne: ICER £18 000/QALY (poniżej progu), umiarkowany wpływ budżetowy i solidne dowody kliniczne prowadzą do pozytywnej rekomendacji dla rutynowego użycia.

## Powiązanie z inżynierią oprogramowania

Przypomina formalny proces zatwierdzania architektury, który ocenia koszt, ryzyko i dowody skuteczności przed zatwierdzeniem nowej technologii w całej organizacji.

O tym, jak wielocyklowy model HTA jest faktycznie symulowany, kohorta po kohorcie, cykl po cyklu, zobacz [symulację kohortową Markowa](../symulacja-kohortowa-markowa/).

## Pułapki

- **Zakładanie, że pozytywne badanie kliniczne automatycznie prowadzi do zatwierdzenia HTA.**
- **Traktowanie wpływu budżetowego i efektywności kosztowej jako tego samego kryterium.**

## Źródła

- NICE, technology appraisal process.
- ICER (US), value assessment framework.
