# Aikahorisontti

Aikahorisontti on ajanjakso, jonka aikana kustannukset ja vaikutukset lasketaan taloudellisessa arvioinnissa.

## Miksi se on tärkeä

Liian lyhyt horisontti jättää huomiotta myöhäiset hyödyt (ennaltaehkäisy); liian pitkä horisontti lisää epävarmoja oletuksia.

## Matematiikka

```
Kokonaisarvo = Σ(t=0 horisonttiin) (hyödyt_t − kustannukset_t) / (1+r)^t
```

## Ratkaistu esimerkki

Diabeteksen ennaltaehkäisyohjelma osoittaa nettosäästöjä vasta 15 vuoden kuluttua; 5 vuoden horisontilla tehty arviointi arvioisi ohjelman virheellisesti kustannuksia lisääväksi.

## Yhteys ohjelmistokehitykseen

Muistuttaa mittausikkunan valitsemista teknisen velan takaisinmaksun ROI:lle.

## Sudenkuopat

- **Horisontin manipulointi: suotuisimman tuloksen antavan ajanjakson valitseminen.**
- **Jäännösvaikutusten jättäminen huomiotta horisontin jälkeen.**

## Lähteet

- NICE, time horizon guidance in technology appraisal.
- ISPOR, good practices for cost-effectiveness analysis.
