# 全國統一收費標準與單位成本

NHS按照一套基於規則的全國價目表為醫療提供方的活動付費——歷史上稱為"全國統一收費標準/按結果付費"，自2023年4月1日起被**NHS支付方案（NHSPS）**取代。在這些價格背後，是一整套全國性的單位成本核算基礎設施：**全國成本採集（NCC）**，以及**PSSRU《醫療與社會照護單位成本》**彙編。

## 為何重要

這些資料是每一份可信的NHS商業案例的分母所在。當某個主張說"一次門診就診價值£160"或"一個5級職級護士-小時的成本為£31"時，這些數位正是來自這套基礎設施——使用官方數位而非憑空捏造的數位，正是讓獨立評估具有可比性、讓財務團隊願意配合的關鍵所在。對供應商而言，該收費標準同樣界定了*收入*的一側：你的軟體所促成的活動（額外的門診、被重新填滿的床位）會按標準價格計價。

## 計算方法

```
每單位活動的標準價格（HRG編碼住院單元、門診就診）
  = 全國平均單位成本（來自NCC）× 市場力量係數（本地調整因子）
  在NHSPS下：混合固定+可變（"對齊支付與激勵機制"）要素

NCC單位成本 = 各信託機構報告的某類活動總成本 / 活動量
             （建立在病人層面資訊與成本系統PLICS之上）

PSSRU彙編：約80項標準單位成本（全科醫師問診、按職級劃分的護士-小時、
急診就診……）——英國經濟學評估中的預設資料來源。
```

## 實例演算

你的軟體在一個250個工作日的年度中，為一名5級職級護士每天釋放1小時時間：

```
基於PSSRU資料的5級職級成本（含管理費用）約為£31/小時（需核對當前版本）
產能價值 = 250 × £31 = 每名護士每年£7,750（非現金釋放型）
```

或者，這名護士可以用這些時間每天多完成2次門診複診，按標準價格約£160計算：500 × £160 = **每年£80,000的可獲資助活動量**——同樣的時間，僅因重新部署方式不同，所主張的價值就相差十倍，而這一切都基於官方單位成本資料。兩種主張都是可審計的，因為它們的分母都是公開發布的；這正是整套體系的意義所在。

## 與軟體工程的聯絡

這正是**內部價目手冊**這一模式的體現。英國健康經濟學之所以行得通，是因為每一項評估都使用同一套已釋出的單位成本；而工程組織大多缺乏這樣一套體系，因此每一份商業案例都在自行編造一個工程師-小時、一次事件、一次部署各自的成本。平臺團隊完全可以釋出這樣一本價目手冊——按職級劃分的每工程師-小時負荷成本、按嚴重程度劃分的每次事件成本、每建置分鐘成本——並要求所有提案都必須採用這套統一標準。內部計費系統同樣會復現這套收費標準已知的失靈模式：按平均成本定價會助長用量操縱，固定付費則會導致供給不足。NHSPS從純粹按活動付費、演變為混合固定+可變支付的這二十年曆程，正是內部平臺定價激勵機制設計方面的寶貴經驗教訓。

## 陷阱

- **資料陳舊**：NCC、PSSRU與NHSPS的價格每年都會更新——每一個數位都應標註日期。
- **標準價格 ≠ 成本**：價格是經過調整的全國平均值；你所在地的邊際成本可能與之不同（參見[邊際成本與平均成本](../邊際成本與平均成本/)）。
- **按標準價格為產能估值，卻沒有真正實現並獲得那部分額外活動付費的實際機制**。
