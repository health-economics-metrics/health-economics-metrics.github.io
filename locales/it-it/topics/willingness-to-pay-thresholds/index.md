# Soglie di Disponibilità a Pagare

La soglia di disponibilità a pagare (WTP) è l'importo massimo che un decisore pagherà per unità di guadagno di salute.

## Perché è importante

| Ente | Soglia |
|---|---|
| NICE (Inghilterra) | £20.000–£30.000 per QALY |
| ICER (USA) | $100.000–$150.000 per QALY |
| Canada (CADTH) | ≈ CAD$50.000 per QALY |

## La matematica

```
Accetta se ICER = ΔC/ΔE < λ
```

## Esempio risolto

La vostra terapia digitale offre un ICER di £16.000/QALY.

## Collegamento con l'ingegneria del software

Ogni organizzazione ingegneristica ha un λ interno implicito.

## Insidie

- **Fare shopping di soglie tra giurisdizioni.**
