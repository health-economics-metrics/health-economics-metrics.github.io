# การตรวจสอบความถูกต้องของอุปกรณ์สวมใส่

การตรวจสอบความถูกต้องของอุปกรณ์สวมใส่เป็นกระบวนการพิสูจน์ว่าอุปกรณ์สวมใส่สำหรับผู้บริโภคหรือทางคลินิกวัดสิ่งที่อ้างว่าวัดได้อย่างแม่นยำ

## ทำไมจึงสำคัญ

อุปกรณ์สวมใส่ไม่ได้ถูกสร้างขึ้นมาเท่าเทียมกันทั้งหมด — การใช้งานเพื่อการตัดสินใจทางคลินิกต้องการการตรวจสอบความถูกต้องที่เข้มงวดกว่าการติดตามความเป็นอยู่ที่ดีทั่วไป

## คณิตศาสตร์

```
ความแม่นยำของการตรวจสอบความถูกต้อง = ความสัมพันธ์กับการวัดมาตรฐานทองคำ (เช่น ค่าสัมประสิทธิ์ r หรือ ICC)
```

## ตัวอย่างที่คำนวณแล้ว

นาฬิกาอัจฉริยะที่อ้างว่าวัดอัตราการเต้นของหัวใจด้วยความแม่นยำ ±2 ครั้งต่อนาที ต้องพิสูจน์สิ่งนี้เทียบกับคลื่นไฟฟ้าหัวใจทางการแพทย์ในหลายสภาวะ (การพักผ่อน การออกกำลังกาย สีผิวที่แตกต่างกัน) ก่อนที่จะได้รับความเชื่อถือในบริบททางคลินิก

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

คล้ายกับการปรับเทียบและตรวจสอบความถูกต้องของเซ็นเซอร์ในระบบ IoT ก่อนที่จะเชื่อถือข้อมูลสำหรับการตัดสินใจที่สำคัญ

## ข้อผิดพลาดที่พบบ่อย

- **การยอมรับข้อเรียกร้องความแม่นยำของผู้ผลิตโดยไม่มีการตรวจสอบความถูกต้องอย่างอิสระ**
- **การสันนิษฐานว่าการตรวจสอบความถูกต้องในประชากรหนึ่ง (เช่น ผู้ใหญ่ที่มีสุขภาพดีอายุน้อย) ใช้ได้กับทุกประชากร**
