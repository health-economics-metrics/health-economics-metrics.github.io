# 员工留任 (Workforce Retention)

员工留任经济学量化了人员流失给卫生系统带来的成本——招聘、入职、空缺期覆盖——从而也量化了能够减轻行政性职业倦怠的软件的价值。重复性行政数据工作所导致的职业倦怠，是 NHS 员工流失和病假缺勤的主要驱动因素之一。

## 为什么重要

当一名临床人员离职时，信托机构要为此付三次钱：招聘替代人选（广告、中介费、面试）、为其入职（数月生产力下降、需要督导），以及在此期间覆盖空缺——通常以中介或临时医生的形式，费率为在职 Agenda for Change 薪级的 2–3 倍（参见[可避免的外包成本](../可避免的外包成本/)与[硬性现金释放型节约](../硬性现金释放节省/)）。由于流失成本是实打实的现金，留任率的改善是财务总监少数能够真正入账的人力资源效益之一。行政摩擦始终是被反复提及的临床职业倦怠主要驱动因素之一，这使其成为一项软件可以解决的成本。

## 计算方法

```
每名离职人员的成本 = 招聘成本 + 入职/生产力爬坡成本
                    + 空缺覆盖溢价 × 空缺持续时间

年度流失成本 = 员工人数 × 流失率 × 每名离职人员的成本

软件的价值 = 员工人数 × Δ流失率 × 每名离职人员的成本
           + 病假缺勤减少量 × 每日覆盖成本
```

这条因果链上有两个需要估计的环节——软件 → 职业倦怠/摩擦，以及职业倦怠 → 流失——因此两者都需要证据支撑（前后对比的员工问卷；已发表的职业倦怠—流失关联研究），并且所主张的 Δ 应保持保守。

## 算例

某信托机构雇用 1,200 名护士；流失率 11%/年。每名离职人员的成本：

```
招聘 ≈ £4,500；入职/爬坡 ≈ £6,000
空缺覆盖：4 个月 × 0.6 全职当量，按中介溢价覆盖 ≈ £8,000
合计 ≈ 每名离职人员 £18,500
基线流失成本 = 1,200 × 0.11 × 18,500 ≈ 每年 £2.44M
```

文书负担类软件（自动填充的评估表、单点登录、语音转录）可以合理地使流失率下降 1 个百分点：

```
价值 = 1,200 × 0.01 × 18,500 = 每年 £222,000（与现金相关）
```

一个由员工问卷摩擦评分支撑的 1 个百分点主张是可信的；一个 4 个百分点的主张则不可信。应对 Δ流失率做[龙卷风分析](../敏感性分析/)：它在整个模型中的影响力压倒其他一切因素。

## 与软件工程的关联

工程领域的留任算法完全相同，只是证据文献更少：替换一名资深工程师的成本相当于 6–12 个月的满载薪资（招聘、爬坡、丢失的上下文），因此一个 200 人的组织，在 15% 的流失率下每年要为人员更替烧掉数百万。开发者体验投资（[SPACE 与 DevEx](../space-与-devex/)）与为护士减轻文书负担直接对应——也应以同样的方式论证：实测的摩擦评分、对流失率保守的主张、以你自己财务数据得出的每名离职人员成本。值得照搬的卫生经济学纪律，是*诚实地为离职者的成本定价*，而不是去争论人们"到底是不是"因为工具而离职。

## 陷阱

- **把全部流失率变化都归功于你的干预**——劳动力市场对流失率的影响远大于软件；应使用对照组，或至少做行业趋势调整。
- **重复计算**：留任节约与中介支出节约存在重叠（空缺覆盖*本身就是*中介支出）；须核对这两条线不要重复。
- **忽视滞后效应**：职业倦怠驱动的流失是在 1–2 年内对摩擦变化做出响应，而不是下个季度就见效。
