# 필요치료수(NNT)

NNT는 지정된 기간 내에 **한 명**의 추가 환자가 혜택을 받기 위해 몇 명의 환자가 개입을 받아야 하는지를 나타내는 수입니다.

## 왜 중요한가

"심장마비를 25% 줄입니다!"는 결정적으로 들립니다. 기준 위험이 5년간 4%라면, 절대 감소는 1퍼센트포인트입니다.

## 수식

```
ARR = 대조군 사건율 − 치료군 사건율
NNT = 1 / ARR
```

## 계산 예시

병원의 낙상 예측 시스템: NNT = 125.

## 소프트웨어 공학과의 연관성

NNT는 많은 항목에 작용하여 적은 것을 포착하는 모든 게이트나 검사에 적합한 단위입니다. [필요선별수](../number-needed-to-screen/)는 치료 하나가 아니라 선별 후 치료하는 프로그램 전체에 대한, 한 단계 위의 대응하는 수치입니다.

## 함정

- **시간 프레임 없음.**
