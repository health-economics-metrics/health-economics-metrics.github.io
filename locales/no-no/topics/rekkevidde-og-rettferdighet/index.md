# Rekkevidde og rettferdighet

Rekkevidde og rettferdighet måler hvor rettferdig en digital helseintervensjon når hele målpopulasjonen, spesielt sårbare og marginaliserte grupper.

## Hvorfor det er viktig

Digitale intervensjoner risikerer å forsterke digitale helseforskjeller ved å nå uforholdsmessig mange grupper som allerede har bedre tilgang. For et formelt statistisk mål på sosioøkonomisk betinget helseulikhet, se [konsentrasjonsindeks](../konsentrasjonsindeks/).

## Matematikken

```
Rettferdighetsgap = rekkeviddeandel(høy inntekt) − rekkeviddeandel(lav inntekt)
```

## Gjennomarbeidet eksempel

En diabetesapp: rekkeviddeandel høy inntekt 45 %, lav inntekt 22 % = rettferdighetsgap 23 prosentpoeng.

## Kobling til programvareutvikling

Nedbrutt etter befolkningsundergrupper i [aktivering og adopsjon](../aktivering-og-adopsjon/) avslører gapet.

## Fallgruver

- **Å bare se på den gjennomsnittlige rekkevidden, skjule undergruppegap.**
