# Швидкий шлях DiGA Німеччини

Швидкий шлях DiGA (Digitale Gesundheitsanwendungen) — це німецька система попереднього включення додатків цифрового здоров'я до реєстру за рецептом, з дедлайном на докази у дванадцять місяців.

## Чому це важливо

DiGA дозволяє виробникам отримати раннє відшкодування на основі попередніх доказів, з зобов'язанням надати остаточні докази позитивного ефекту на догляд протягом року.

## Математика

```
Попередня ціна (рік 1) → остаточна ціна (після доказів позитивного ефекту на догляд)
```

## Розібраний приклад

Додаток для лікування тинітусу отримує попереднє включення DiGA та відшкодовується, поки виробник проводить дослідження, щоб продемонструвати позитивний ефект на догляд протягом 12 місяців.

## Зв'язок з інженерією програмного забезпечення

Подібно до бета-запуску з встановленим дедлайном для доведення показників успіху перед наданням повного статусу продукту.

## Підводні камені

- **Недотримання дедлайну на докази, що призводить до вилучення з реєстру.**
- **Припущення, що попереднє включення рівнозначне постійному відшкодуванню.**
