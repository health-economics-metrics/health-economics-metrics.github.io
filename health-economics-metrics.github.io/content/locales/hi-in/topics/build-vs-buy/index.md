# बनाएँ बनाम खरीदें

बनाएँ-बनाम-खरीदें कस्टम विकास और वाणिज्यिक अधिग्रहण की एक संरचित तुलना है, छूट प्राप्त [TCO](../total-cost-of-ownership/), डिलीवरी समय, और जोखिम पर।

## यह क्यों महत्वपूर्ण है

स्वास्थ्य प्रणालियाँ लगातार इस निर्णय का सामना करती हैं।

## गणित

```
NPV_विकल्प = PV(लाभ, समय-से-मूल्य द्वारा स्थानांतरित) − PV(TCO)
```

## हल किया गया उदाहरण

एक ट्रस्ट को एक ई-सहमति प्रणाली की आवश्यकता है। खरीदें: £150k/वर्ष SaaS, 3 महीने में लाइव।

```
5-वर्ष TCO: खरीदें = £750k
           निर्माण = £1,410k
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

स्थानांतरणीय स्वास्थ्य-अर्थशास्त्र अनुशासन तीन गुना है।

## सामान्य गलतियाँ

- **विक्रेता सूची मूल्य की जोखिम-असमायोजित निर्माण अनुमानों से तुलना करना।**
