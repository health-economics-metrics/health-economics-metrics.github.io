# Eelarvemõju analüüs (BIA)

Eelarvemõju analüüs hindab maksja kulutuste netomuutust uue sekkumise kasutuselevõtul, sõltumata selle kulutõhususest.

## Miks see on oluline

Sekkumine võib olla väga kulutõhus (madal £/QALY), kuid siiski taskukohatu, kuna üldine eelarvemõju on liiga suur.

## Matemaatika

```
Eelarvemõju = (Uue sekkumise kulu × eeldatav maht) − (Asendatud sekkumise kulu × eeldatav maht)
```

## Lahendatud näide

Uuel ravil ICER-iga £15 000/QALY (hästi alla läve) on siiski eelarvemõju £200 miljonit/aastas suure patsiendipopulatsiooni tõttu, mis nõuab järkjärgulist kasutuselevõttu.

## Seos tarkvaraarendusega

Sarnaneb hindamisega, kas tehniliselt parem lahendus mahub aastasesse infrastruktuuri eelarvesse, sõltumata sellest, kas see on parim arhitektuur.

## Lõksud

- **Kulutõhususe segiajamine taskukohasusega.**
- **Eeldatava mahu alahindamine laienevate uute näidustuste puhul.**
