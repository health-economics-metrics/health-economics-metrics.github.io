# Rendement op AI-investering

AI-ROI meet de financiële waarde die wordt gegenereerd ten opzichte van de kosten van het bouwen en exploiteren van AI-systemen.

## Waarom het ertoe doet

AI-projecten hebben vaak verborgen operationele kosten: infrastructuur, modeltraining, en doorlopende inferentiekosten.

## De wiskunde

```
AI-ROI = (gegenereerde waarde − (ontwikkelingskosten + operationele kosten)) / (ontwikkelingskosten + operationele kosten) × 100%
```

## Uitgewerkt voorbeeld

AI voor klinische documentatiesamenvatting: ontwikkeling £300.000 + operatie £100.000/jaar; bespaarde artsentijd = £600.000/jaar = 50% ROI in jaar 1.
