# Validering av bærbare enheter

Validering av bærbare enheter er prosessen med å verifisere om data fra forbrukernes bærbare enheter (smartklokker, aktivitetsmålere) er klinisk nøyaktige og pålitelige.

## Hvorfor det er viktig

Forbrukernes bærbare enheter er ofte ikke validert etter regulatoriske standarder for medisinsk utstyr.

## Matematikken

```
Gjennomsnittlig absolutt prosentvis feil (MAPE) = (1/n) × Σ |faktisk verdi − målt verdi| / faktisk verdi × 100 %
```

## Gjennomarbeidet eksempel

En håndleddsbåret pulssensor: MAPE 4,2 % sammenlignet med EKG-standard (øker til 8,5 % under trening).

## Kobling til programvareutvikling

Datakvalitetsgrunnlaget for [digitale endepunkter og biomarkører](../digitale-endepunkter-og-biomarkører/) og [økonomi for fjernpasientovervåking](../økonomi-for-fjernpasientovervåking/).
