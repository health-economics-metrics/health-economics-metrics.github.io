# সক্রিয়করণ এবং গ্রহণ

সক্রিয়করণ হার হলো সাইন-আপের ভাগ যারা প্রথম অর্থপূর্ণ মূল্যে পৌঁছায়। গ্রহণ হলো জনসংখ্যা সংস্করণ: *যোগ্য* জনসংখ্যার ভাগ যারা মোটেও গ্রহণ করে।

## কেন এটি গুরুত্বপূর্ণ

অ-সক্রিয় ব্যবহারকারী বিশুদ্ধ ব্যয়: অধিগ্রহণ ব্যয়, প্রভিশনিং, সহায়তা — শূন্য ক্লিনিক্যাল মূল্য। বেঞ্চমার্ক স্বাস্থ্যসেবা সফটওয়্যারের সক্রিয়করণকে ক্রস-ইন্ডাস্ট্রি গড়ের *নিচে* রাখে।

## গণিত

```
সক্রিয়করণ হার = উইন্ডোর মধ্যে মূল কর্ম সম্পন্নকারী ব্যবহারকারী / সাইন-আপ × 100
গ্রহণ হার     = গ্রহণকারী / যোগ্য জনসংখ্যা × 100

ফানেল মূল্য মডেল:
  যোগ্য × গ্রহণ × সক্রিয়করণ × ধরে-রাখা-ওজনযুক্ত সুবিধা = জনসংখ্যা মূল্য
```

## সমাধানকৃত উদাহরণ

একজন কমিশনার ৮০,০০০ যোগ্য বাসিন্দাকে একটি ডায়াবেটিস-প্রতিরোধ অ্যাপ প্রদান করেন:

```
আমন্ত্রিত → নিবন্ধিত: 80,000 → 12,000 (গ্রহণ 15%)
নিবন্ধিত → সক্রিয়: 12,000 → 5,400 (45%)
সক্রিয় → 6-মাসের প্রোগ্রাম সম্পন্ন: 5,400 → 1,600 (30%)

জনসংখ্যা মূল্য = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
```

## সফটওয়্যার প্রকৌশলের সাথে সংযোগ

সক্রিয়করণ ফানেলের সবচেয়ে প্রকৌশল-নমনীয় পর্যায়: পরিচয়-যাচাই ঘর্ষণ, সম্মতি প্রবাহ, খালি-অবস্থা নকশা, প্রথম-মূল্য-পর্যন্ত-সময় সব কোড, নীতি নয়।

## ঝুঁকিপূর্ণ দিক

- **সুবিধা হিসেবে সংজ্ঞায়িত সক্রিয়করণ** (ইমেইল যাচাই) ক্লিনিক্যাল অর্থের পরিবর্তে (প্রথম থেরাপিউটিক কর্ম)।
- **গ্রহণ হর কারচুপি**।
