# उपचार के लिए रेफरल (RTT)

उपचार के लिए रेफरल एक GP रेफरल से परामर्शदाता-नेतृत्व वाले उपचार की शुरुआत तक बीता समय है। NHS संविधान मानक निर्धारित करता है: **92% रोगियों को 18 सप्ताह के भीतर उपचार शुरू करना चाहिए**।

## यह क्यों महत्वपूर्ण है

RTT लक्ष्य चूकने वाले ट्रस्ट नियामक जाँच का सामना करते हैं।

## गणित

```
RTT प्रदर्शन = 18 सप्ताह के भीतर इलाज किए गए रोगी / कुल इलाज × 100
```

## हल किया गया उदाहरण

एक विशेषता सालाना 5,000 पथ रोगियों का इलाज करती है; औसत प्रतीक्षा 24 सप्ताह।

```
QALY लाभ = 5,000 × (5/52) × (0.80 − 0.68) = सालाना 57.7 QALY
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

RTT एक **बहु-चरण कतार में लीड-टाइम मीट्रिक** है।
