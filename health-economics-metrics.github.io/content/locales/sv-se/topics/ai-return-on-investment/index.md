# Avkastning på AI-investering

AI-ROI mäter det finansiella värde som genereras jämfört med kostnaderna för att bygga och driva AI-system.

## Varför det är viktigt

AI-projekt har ofta dolda driftskostnader: infrastruktur, modellträning och löpande inferenskostnader.

## Matematiken

```
AI-ROI = (genererat värde − (utvecklingskostnad + driftskostnad)) / (utvecklingskostnad + driftskostnad) × 100 %
```

## Genomarbetat exempel

AI för sammanfattning av klinisk dokumentation: utveckling £300 000 + drift £100 000/år; sparad läkartid = £600 000/år = 50 % ROI under år 1.

## Koppling till mjukvaruutveckling

Kombinerar [avkastning på investering](../return-on-investment/) med [inferensens enhetsekonomi](../inference-unit-economics/).

## Fallgropar

- **Att utelämna inferenskostnader från driftsbudgeten.**
