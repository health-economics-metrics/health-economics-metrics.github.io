# 自建與外購

自建與外購是一種結構化比較，基於貼現後的[總擁有成本（TCO）](../總擁有成本/)、交付時間與風險，對定製開發與商業採購兩條路徑進行比較。經驗性的先驗證據是一邊倒的：**實際自建成本通常超出預測30–40%**，採購的解決方案部署速度快40–60%，而麻省理工2025年的生成式AI研究發現，採購的AI工具成功率約為67%，而內部自建工具的成功率大約只有其三分之一。

## 為何重要

醫療系統頻繁面臨這一決策（NHS的說法是"自制 vs 委託"），而工程組織系統性地偏向自建方向，且往往做錯——因為自建者估算的是"建造"本身，而非[總擁有成本](../總擁有成本/)；也因為建造本身更有樂趣。經濟學視角強制推行誠實的比較：兩個選項都按同一時間範圍定價，都經過風險調整，並且*把時間差價格化為[延遲成本](../延遲成本/)*——這一項往往才是最終決定答案的關鍵，卻也最常被遺漏。

## 計算方法

```
在相同的3–5年時間範圍內進行貼現比較：

方案淨現值 = 現值(效益，按價值實現時間偏移) − 現值(總擁有成本)

風險調整（《綠皮書》"樂觀偏差"模式）：
  自建成本 × 1.3–1.4        （超支先驗係數）
  自建價值實現時間 + 40–60%  （部署延遲先驗係數）
  外購：改為加入整合現實性核查成本與退出成本

決策驅動因素，按其通常起決定作用的順序：
  1. 差異化程度——這項能力是你產品的核心，還是基礎管道？
  2. 價值實現時間 × 延遲成本
  3. 經風險調整後的總擁有成本
```

## 實例演算

某信託機構需要一套電子知情同意系統。外購：SaaS方案每年£150,000，3個月內上線。自建：預估£600,000 + 每年£120,000維護費，12個月上線。

```
經風險調整的自建成本：600,000 × 1.35 = £810,000；價值實現時間約為18個月
5年總擁有成本：外購 = 150,000 × 5 = £750,000
             自建 = 810,000 + 120,000 × 5 = £1,410,000
延遲項：知情同意數位化每月節省£25,000；自建方案晚15個月上線
       → 延遲成本 = 15 × 25,000 = £375,000

實際比較結果：£750,000 對比 £1,785,000——外購勝出約£100萬，
而在自建成本本身之外，最大的單項因素正是那筆此前無人計價的延遲成本。
```

當該能力具有差異化意義（你產品的核心演算法）、沒有任何供應商能滿足硬性約束（臨床安全、資料駐留要求），或供應商鎖定風險嚴重且已被定價時，自建仍然是正確選擇。

## 與軟體工程的聯絡

可遷移的健康經濟學紀律有三點：**基於先驗的風險調整**（30–40%的超支上浮係數就是軟體版的《綠皮書》樂觀偏差——應機械地應用它，為例外情形提出論證，而非從例外情形出發論證）；**對比物件的誠實性**（自建的替代方案不是"什麼都不做"，而是可獲得的最佳外購方案——參見[機會成本](../機會成本/)）；以及**在比較成本之前先做等效性檢驗**（如果外購與自建在規格上確實等效，這就是[成本最小化分析](../成本最小化分析/)，更便宜的一方勝出；如果不等效，那麼結果上的差異必須被賦予價值，而非僅憑斷言）。

## 陷阱

- **將供應商標價與未經風險調整的自建估算相比較**——這是雙重偏向自建的做法。
- **零定價的內部人力**（"反正團隊已經在這裡了"）。
- **雙向均未定價的鎖定風險**：供應商退出成本固然存在，但自建方案自身的"巴士係數"與維護延續性同樣是風險。
- **出於身份認同而驅動的自建決策**："這對我們而言是核心"這種說法，其實往往只是基礎管道——應以"客戶是否會注意到"來檢驗其差異化程度是否成立。
