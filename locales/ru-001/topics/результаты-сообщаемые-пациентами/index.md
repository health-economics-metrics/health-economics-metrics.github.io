# Результаты, сообщаемые пациентами (PROM, PREM, ММЗР)

PROM — это стандартизированные инструменты, где пациенты сообщают о собственном состоянии здоровья (симптомы, функция, качество жизни); PREM фиксируют *опыт* помощи. **ММЗР** — минимальная клинически значимая разница — это наименьшее изменение балла, которое пациенты реально воспринимают как полезное: планка, которую должно преодолеть любое заявленное улучшение.

## Почему это важно

PROM — это основная валюта эффективности для цифрового здравоохранения: приложения редко двигают смертность, но могут достоверно двигать валидированные баллы симптомов. Инструменты, которые имеют значение, немногочисленны и стандартизированы — **PHQ-9** (депрессия, 0–27; полосы тяжести на 5/10/15/20), **GAD-7** (тревога, 0–21; полосы на 5/10/15), **EQ-5D** (полезность для [QALY](../год-жизни-с-поправкой-на-качество/)) — и регуляторы, органы ОМТ и плательщики принимают их именно потому, что они сопоставимы между продуктами и испытаниями. ММЗР — это ворота честности: ММЗР PHQ-9 ≈ 5 баллов, GAD-7 ≈ 4, индекс EQ-5D обычно ~0,03–0,08 — статистически значимое изменение PHQ-9 на 1,5 балла на большой выборке *реально, но клинически незначимо*, и рецензент доказательств это скажет.

## Расчёт

```
Подсчёт PROM: суммы, специфичные для инструмента (напр., PHQ-9 = Σ 9 пунктов × 0–3)

Оценка ММЗР:
  на основе якоря:      изменение балла среди пациентов, сообщающих «немного лучше»
  на основе распределения: ≈ 0,5 × СО базовых баллов (грубая эвристика)

Рамка коэффициента ответа (для испытаний и досье):
  ответивший = пациент, улучшившийся на ≥ ММЗР (или ≥50% по конвенции PHQ-9)
  ЧБНЛ = 1 / (коэффициент_ответа_лечение − коэффициент_ответа_контроль)
  — см. number-needed-to-treat.md
```

## Разобранный пример

Приложение поддержки при депрессии, РКИ против листа ожидания, 12 недель:

```
Изменение PHQ-9: приложение −6,2 балла, контроль −2,1 → скорректированная разница −4,1
Проверка ММЗР: 4,1 < 5 → средняя разница ниже ММЗР; вместо этого отчитывайтесь об ответивших:
  ответившие (снижение ≥5 баллов): приложение 48%, контроль 22% → АСР 26%
  ЧБНЛ = 1/0,26 ≈ 4 — четыре пользователя пролечены на дополнительный клинический ответ

Экономический мост: выгода EQ-5D ответивших 0,06, устойчивая 6 месяцев
  = 0,03 QALY; на 1000 пользователей: 260 дополнительных ответивших × 0,03 = 7,8 QALY
  ≈ £156 000–234 000 ценности здоровья при порогах NICE
```

Рамка ответивший/ЧБНЛ выживает при рецензии там, где разница средних ниже ММЗР была бы отклонена.

## Связь с программной инженерией

PROM — это проблема сбора данных, для решения которой ПО находится в уникальном положении: инструменты внутри приложения получают коэффициенты завершения и продольную плотность, которых бумага никогда не достигала, превращая рутинную телеметрию продукта в доказательства уровня ОМТ ([EQ-5D](../eq-5d/) — это пять экранов). Инженерные правила: используйте валидированный инструмент *дословно* (переформулировка делает его недействительным — применяется лицензирование); планируйте измерение по протоколу, а не по удобству вовлечённости (измерение только активных пользователей — это смещение выживания — см. [удержание и отток](../удержание-и-отток/)); и фиксируйте версию данных инструмента как любую схему — изменение формулировки в середине исследования — это повреждение данных. PREM сопоставляются с инструментами в стиле CSAT/NPS, и тот же урок применим: стандартизированное побеждает самодельное везде, где аудитория — плательщик. Об инструменте, специфичном для рабочей продуктивности, см. [WPAI](../рабочая-продуктивность-и-нарушение-активности/).

## Подводные камни

- **Статистическая значимость ниже ММЗР**, представленная как клиническая выгода — самая распространённая инфляция в области.
- **Регрессия к среднему**: пользователи регистрируются на пиках симптомов; однорукое до/после сильно переоценивает — компараторы не подлежат обсуждению.
- **Шопинг инструментов**: запуск PHQ-9, GAD-7 и WHO-5, затем отчёт о том, что сдвинулось — заранее зарегистрируйте первичный.
- **Давление опроса цифрового согласия**: подталкивание пользователей к благоприятным ответам искажает инструмент (и рецензенты знают базовые показатели).
