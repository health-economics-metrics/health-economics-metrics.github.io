# Kantavate seadmete valideerimine

Kantavate seadmete valideerimine on protsess, mille käigus tõendatakse, et tarbija- või kliinilised kantavad seadmed mõõdavad täpselt seda, mida nad väidavad mõõtvat.

## Miks see on oluline

Mitte kõik kantavad seadmed pole loodud võrdselt — kliinilisteks otsusteks kasutamine nõuab rangemat valideerimist kui üldine heaolu jälgimine.

## Matemaatika

```
Valideerimise täpsus = Korrelatsioon kullastandardi mõõtmisega (nt r või ICC koefitsient)
```

## Lahendatud näide

Nutikell, mis väidab mõõta südame löögisagedust täpsusega ±2 lööki minutis, peab seda tõendama võrdluses meditsiinilise elektrokardiogrammiga paljudes tingimustes (puhkus, treening, erinevad nahatoonid) enne kliinilises kontekstis usaldamist.

## Seos tarkvaraarendusega

Sarnaneb andurite kalibreerimise ja valideerimisega IoT-süsteemides enne andmete usaldamist kriitiliste otsuste tegemiseks.

## Lõksud

- **Tootja täpsusnõuete aktsepteerimine ilma sõltumatu valideerimiseta.**
- **Eeldus, et valideerimine ühes populatsioonis (nt noored tervisid täiskasvanud) kehtib kõigis populatsioonides.**
