# 预算影响分析 (Budget Impact Analysis, BIA)

BIA估算的是，在未来1–5年内，采纳某项干预措施会对特定支付方的**预算**产生什么影响。它回答的是*可负担性*问题；而成本效果分析回答的是*价值*问题。一项技术完全可能价值极高却难以负担——也可能负担得起却价值不高。严谨的评估两者都需要具备。

## 为何重要

财务总监关心的问题从来不是"ICER是多少？"，而是"这会对明年的预算造成什么影响？"ISPOR的良好实践指南（该领域的行业标准）明确规定：应采用支付方自身的视角、1–5年的时间跨度、*不贴现*的年度现金流、切合实际的采纳曲线，以及基于情景（而非概率）的不确定性分析。NICE要求在提交成本效果数据的同时一并提供预算影响信息；在英格兰，若某产品的全国预算影响超过约£2,000万/年，无论其ICER如何，都会触发商业谈判程序。

## 计算方法

```
第t年预算影响 = 采用新方案情景下的成本(t) − 现有方案情景下的成本(t)

情景成本(t) = Σ（按患者群体求和）：
   第t年符合条件人群数 × 第t年采纳率 × 第t年每名患者的净成本

每名患者的净成本 = 干预成本 − 被替代的医疗成本 + 被诱发的新增医疗成本
```

关键建模选择包括：符合条件人群的增长趋势、采纳曲线（采纳从来不是瞬间完成的）、新方案会替代掉什么，以及它可能*诱发*出多少新增需求（更便捷的可及性→更多用户）。

## 实例演算

某覆盖200万人的支付方正在考虑一款数字疗法，每名患者每年费用£300；1.5%的参保人符合条件（30,000人）；第1至第3年的采纳率分别为20%→40%→60%；每名用户每年可替代£120的其他医疗支出。

```
每名用户的净成本 = 300 − 120 = £180

第1年：30,000 × 0.20 × 180 = £108万
第2年：30,000 × 0.40 × 180 = £216万
第3年：30,000 × 0.60 × 180 = £324万
```

即便该产品的ICER高达每QALY仅£8,000这样出色的水平，支付方到第3年仍必须找到£324万的*新增资金*——那被替代掉的£120，分散摊薄在众多其他预算科目之中，并不会以现金形式被释放出来（参见[现金释放型与非现金释放型](../现金释放型-vs-非现金释放型节约/)）。这正是为什么单位价值与可负担性是两道彼此独立的门槛。

## 与软件工程的关联

BIA正是面向CFO视角、与按席位计价的ROI主张相辅相成的补充分析："它按每名开发者计算是具有成本效益的，但我们这个财年能负担得起在全机构范围内推广吗？"应对许可证分级、采纳S型曲线、只有在旧合同真正终止时才会现金释放的被替代工具支出，以及被诱发的新增使用量（更便宜的CI意味着更多的CI用量）进行建模。将一张3年期预算影响表与ROI一并呈现，正是让企业级工具提案在财务层面具备可信度的关键所在。 把已公布的预算影响数字按地点、人群或财年拆分——使各份与已公布数字恰好吻合——就是[精确到分的成本分摊](../精确到分的成本分摊/)；把汇入该总额的大量条目相加，则是[币种安全的成本汇总](../币种安全的成本汇总/)。

## 常见陷阱

- **瞬时全面采纳的幻想**：第1年的影响却按稳态采纳水平来计算。
- **把被替代的成本当作现金计入**——而它实际上只是分散的产能。
- **忽视被诱发的新增需求**——可及性的改善会扩大符合条件人群的使用量。
- **混淆BIA与CEA的时间跨度/贴现设定**：BIA按设计就应是短周期、不贴现、且针对特定支付方的分析。
