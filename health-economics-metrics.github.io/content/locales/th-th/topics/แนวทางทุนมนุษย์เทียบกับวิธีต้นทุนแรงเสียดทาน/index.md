# แนวทางทุนมนุษย์เทียบกับวิธีต้นทุนแรงเสียดทาน

สองวิธีนี้เป็นคู่แข่งในการประเมินมูลค่าผลิตภาพที่สูญเสียไปจากการเจ็บป่วย ความพิการ หรือการเสียชีวิต ในการศึกษาต้นทุนโรคและต้นทุนผลประโยชน์ แนวทางทุนมนุษย์ (HCA) ตีมูลค่าผลผลิตที่สูญเสียทั้งหมดตลอดช่วงที่ขาดงานด้วยอัตราค่าจ้าง ส่วนวิธีต้นทุนแรงเสียดทาน (FCM) ตีมูลค่าเฉพาะช่วงสั้นกว่าที่นายจ้างต้องใช้จริงเพื่อฟื้นฟูการผลิต การเลือกระหว่างสองวิธีเปลี่ยนค่าประมาณต้นทุนทางอ้อมได้สองเท่าหรือมากกว่า

## ทำไมจึงสำคัญ

ต้นทุนทางอ้อม (ผลิตภาพ) เป็นหนึ่งในรายการที่ถกเถียงกันมากที่สุดในเศรษฐศาสตร์สุขภาพ ก็เพราะสองวิธีมาตรฐานให้ผลต่างกันมาก HCA ถือว่าทุกวันที่ขาดงานเป็นวันที่เศรษฐกิจสูญเสียผลผลิตจริง ตีมูลค่าด้วยค่าจ้างเต็มตลอดระยะเวลา — หรือตลอดชีวิตการทำงานที่เหลือในกรณีเสียชีวิตหรือพิการถาวร FCM โต้ว่าในเศรษฐกิจที่มีการว่างงานและมีส่วนเกินในตลาดแรงงาน การขาดงานระยะยาวส่วนใหญ่ไม่ได้ลดผลผลิตระดับชาติจริง เมื่อนายจ้างฝึกคนทดแทนหรือจัดงานใหม่ เฉพาะ "ช่วงแรงเสียดทาน" — เวลาที่ใช้ฟื้นฟูการผลิตสู่ระดับเดิม — เป็นการสูญเสียที่แท้จริง FCM จึงให้ค่าประมาณต้นทุนทางอ้อมต่ำกว่าและระมัดระวังกว่า HCA อย่างเป็นระบบ และทั้งสองไม่ใช่เชิงอรรถที่ใช้แทนกันได้: เป็นทฤษฎีเศรษฐศาสตร์ต่างกันว่า "ผลิตภาพที่สูญเสีย" หมายถึงอะไร นี่ยังเป็นเหตุผลที่ [กรณีอ้างอิงของ NICE](../การประเมินเทคโนโลยีด้านสุขภาพ/) ละต้นทุนผลิตภาพเป็นค่าเริ่มต้น และรายงาน หากมี แยกเป็นการวิเคราะห์ความอ่อนไหวมุมมองสังคม แทนที่จะผสมเข้าใน ICER กรณีอ้างอิง — ดู[มุมมองการวิเคราะห์](../มุมมองการวิเคราะห์/)

## คณิตศาสตร์

```
แนวทางทุนมนุษย์:
ต้นทุน_HCA = ค่าจ้างรายวัน × วันที่สูญเสีย

วิธีต้นทุนแรงเสียดทาน (แบบง่าย ฝาด้วยช่วงแรงเสียดทาน):
ต้นทุน_FCM = ค่าจ้างรายวัน × min(วันที่สูญเสีย, วันช่วงแรงเสียดทาน)

วันช่วงแรงเสียดทาน = ค่าประมาณเฉพาะประเทศ/ภาคส่วนของเวลาที่ใช้ฟื้นฟูการผลิต
                     (ในอดีตราว 85 วันในคู่มือต้นทุนของ iMTA เนเธอร์แลนด์;
                     แตกต่างตามประเทศและมีการประเมินใหม่เป็นระยะ)
```

ความขัดแย้งทั้งหมดระหว่างสองวิธีอยู่ที่ `min()`: HCA ไม่เคยจำกัด `วันที่สูญเสีย` ต้นทุนจึงโตตลอดช่วงที่ขาดงาน ส่วน FCM จำกัดวันที่นับไว้ที่ช่วงแรงเสียดทาน ไม่ว่าการขาดงานจริงจะยาวเพียงใด

## ตัวอย่างที่คำนวณแล้ว

พนักงานขาดงาน `วันที่สูญเสีย = 180` วัน มี `ค่าจ้างรายวัน = £150`

**แนวทางทุนมนุษย์**:

```
ต้นทุน_HCA = 150 × 180 = £27,000
```

**วิธีต้นทุนแรงเสียดทาน** ด้วย `วันช่วงแรงเสียดทาน = 85` (เกณฑ์เปรียบเทียบเดิมของ iMTA เนเธอร์แลนด์ ตามการประเมินใหม่เป็นระยะของคู่มือ):

```
ต้นทุน_FCM = 150 × min(180, 85) = 150 × 85 = £12,750
```

£12,750 ของ FCM น้อยกว่าครึ่งของ £27,000 ของ HCA สำหรับการขาดงาน *เดียวกัน* — การเลือกวิธีอย่างเดียวก็เปลี่ยนกรณีต้นทุนโรคได้มากแล้ว ก่อนจะแตะข้อสมมติอื่นใด

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

สิ่งนี้แมปตรงกับวิธีที่ทีมประเมินต้นทุนการลาออกของวิศวกร:

- **การคิดต้นทุนการลาออกแบบ HCA**: ตีมูลค่าการสูญเสียเป็นเงินเดือนเต็มของวิศวกรที่ลาออกตลอดช่วงที่ตำแหน่งว่าง นี่คือรูปแบบไร้เดียงสาของแบบจำลองต้นทุนการลาออกส่วนใหญ่ และประเมินสูงเกินด้วยเหตุผลเดียวกับที่ HCA ประเมินผลิตภาพที่สูญเสียสูงเกิน — สมมุติว่าความสามารถที่ว่างนั้นผลิตเต็มที่ตลอดและไม่มีสิ่งอื่นดูดซับช่องว่าง ดู[การรักษาพนักงานไว้](../การรักษาพนักงานไว้/) ซึ่งหาปริมาณห่วงโซ่การสรรหา/ปรับตัว/ครอบคลุมตำแหน่งว่างที่วิธีนี้ป้อนเข้า
- **การคิดต้นทุนการลาออกแบบ FCM**: ตีมูลค่าการสูญเสียเฉพาะเวลาจริงที่ใช้หาและปรับตัวคนทดแทน — "ช่วงแรงเสียดทาน" ของงานวิศวกรรม นี่เป็นตัวเลขที่ปกป้องได้มากกว่าสำหรับกรณีธุรกิจ เช่นเดียวกับที่ FCM เป็นทางเลือกที่ระมัดระวังกว่าในการศึกษาต้นทุนโรค
- วินัยเบื้องหลังเดียวกับ[ต้นทุนค่าเสียโอกาส](../ต้นทุนค่าเสียโอกาส/): ตีมูลค่าทรัพยากรที่ถูกแทนที่ตามสิ่งที่สูญเสียจริง ไม่ใช่ตามผลคูณของระยะเวลาพาดหัวกับอัตรา

## ข้อผิดพลาดที่พบบ่อย

- **ผสม HCA และ FCM ในการวิเคราะห์เดียว หรือรายงานเพียงวิธีเดียวโดยไม่เปิดเผยการเลือก** ข้อมูลการขาดงานชุดเดียวกันให้ต้นทุนที่รายงานต่างกัน 2 เท่าหรือมากกว่าตามวิธี ต้องระบุการเลือก ไม่ใช่ซ่อน
- **ใช้ HCA ในกรณีมุมมองสังคมโดยไม่ระบุว่าเป็นการวิเคราะห์ความอ่อนไหว** กรณีอ้างอิงของ NICE ละต้นทุนผลิตภาพอย่างชัดเจน ค่าประมาณ HCA มุมมองสังคมควรอยู่ในการวิเคราะห์สถานการณ์ ไม่ใช่ใน ICER พาดหัว
- **ใช้วิธีใดวิธีหนึ่งกับงานที่ไม่ได้รับค่าจ้างหรืองานนอกตลาด (เช่น การดูแล) โดยไม่ปรับ** ทั้งสองวิธีใช้อัตราค่าจ้างเป็นตัวแทนมูลค่า ซึ่งไม่ส่งต่อไปยังงานที่ไม่มีค่าจ้างตลาดอย่างสะอาด
