# Ennaltaehkäisyn talous

Ennaltaehkäisyn talous tutkii, miksi ennaltaehkäisevät interventiot ovat lähes aina kustannustehokkaita mutta harvoin todella säästävät rahaa koko järjestelmälle.

## Miksi se on tärkeä

Päätöksentekijät väittävät usein, että ennaltaehkäisy säästää rahaa, mutta useimmat ennaltaehkäisytoimet tuovat terveyttä kohtuulliseen hintaan alentamatta kokonaismenoja. Ennen ehkäisyohjelman kustannuslaskentaa [väestön attribuoitava osuus](../väestön-attribuoitava-osuus/) vastaa ensin mitoituskysymykseen — kuinka suuren osan kohdennetusta tautitaakasta ohjelman käsittelemä riskitekijä voisi uskottavasti poistaa.

## Matematiikka

```
Kustannuksia säästävä: Kustannus(ennaltaehkäisy) < Kustannus(vältetty sairaus)
Kustannustehokas mutta ei säästävä: Kustannus(ennaltaehkäisy) > Kustannus(vältetty sairaus), mutta ICER < kynnys
```

## Ratkaistu esimerkki

Tupakoinnin lopettamisohjelma maksaa £200/osallistuja ja säästää keskimäärin £150 tulevia terveydenhuoltokustannuksia osallistujaa kohden, mutta tuottaa 0,1 QALY:a — kustannustehokas (£500/QALY) mutta ei säästävä.

## Yhteys ohjelmistokehitykseen

Muistuttaa automatisoituun testaukseen investoimista: se tuo arvoa (vähemmän vikoja) kohtuulliseen hintaan, mutta säästää harvoin todella rahaa kokonaiskehityskustannuksista.

## Sudenkuopat

- **"Kustannustehokas" ja "kustannuksia säästävä" sekoittaminen liiketoimintatapauksissa.**
- **Vain suorien terveydenhuoltokustannusten laskeminen, laajempien yhteiskunnallisten hyötyjen jättäminen huomiotta.**
