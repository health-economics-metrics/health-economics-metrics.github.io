# Tasso di Mancata Presentazione (DNA)

Il tasso DNA è la percentuale di appuntamenti prenotati in cui il paziente non si presenta né cancella.

## Perché è importante

Statistiche NHS England (2019): appuntamenti dal medico di base mancati oltre 15 milioni all'anno — oltre **£216 milioni** all'anno.

## La matematica

```
Tasso DNA = DNA / appuntamenti prenotati × 100
```

## Esempio risolto

Un reparto ambulatoriale: 200.000 appuntamenti all'anno, tasso DNA 8%.

## Collegamento con l'ingegneria del software

Questo è un **problema di sistema di pianificazione**.

## Insidie

- **Contare due volte cancellazione-e-riprenotazione.**
