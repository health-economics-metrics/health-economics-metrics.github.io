# QALY 短缺与严重程度修正系数 (QALY Shortfall and Severity Modifiers)

QALY 短缺衡量的是，与一般人群相比，某种疾病从患者身上夺走了多少未来的健康。NICE 用它来应用**严重程度修正系数（severity modifiers）**：人群病情越重，每获得一个 QALY 的价值就越高——最高可达标准阈值的 1.7 倍。

## 为什么重要

自 NICE 2022 版手册起，严重程度成为健康收益价值的一个明确乘数，取代了旧有的临终期溢价机制。针对严重病情的技术，其评判所依据的有效阈值可高达约每 QALY £51,000，而非 £30,000。如果你的软件服务于病情严重的人群（晚期心力衰竭、重度精神疾病），严重程度修正系数可能决定一项经济学论证是否能获得资助——而你需要短缺计算方法来主张这一点。

## 计算方法

两项指标，均基于当前标准治疗下的剩余预期寿命计算：

```
绝对短缺   = 一般人群的 QALY − 患病人群的 QALY
比例短缺   = 绝对短缺 / 一般人群的 QALY
```

NICE 2022 权重（以两项指标中给出更高权重的那个为准）：

```
权重 ×1.0：绝对值 < 12 且比例 < 0.85
权重 ×1.2：绝对值 ≥ 12 或比例 ≥ 0.85
权重 ×1.7：绝对值 ≥ 18 或比例 ≥ 0.95
```

该权重会乘以 ΔE（等价于乘以阈值）：有效 λ 在 ×1.2 时变为 £24k-£36k，在 ×1.7 时变为 £34k-£51k。

## 实例计算

患有一种侵袭性疾病的患者，平均年龄 60 岁。60 岁的一般人群预期贴现后 QALY 为 14.2；患病后在当前治疗下为 2.1。

```
绝对短缺   = 14.2 − 2.1 = 12.1（≥ 12 → 符合 ×1.2 资格）
比例短缺   = 12.1 / 14.2 = 0.852（≥ 0.85 → 同样适用 ×1.2）
```

你的监测平台 ICER 为每 QALY £26,000——高于 £20k-£30k 的标准中间判断区间，处于边缘地带。应用 ×1.2 权重后：有效 ICER = 26,000 / 1.2 ≈ **£21,700/QALY**——明显可获资助。短缺计算直接改变了决策结果。

## 与软件工程的关联

严重程度加权是工程组织凭直觉早已在做的事的正式版本：对状况最差的系统，每单位改进投入更多资源。可迁移的模式是——计算每个服务的"SLO 短缺"（它相对于预期健康基线的偏离程度，包括绝对值和比例值），并据此加权补救工作的价值。这用算术而非争论，证明了为什么那个濒临崩溃的遗留系统，每节省一小时所获得的投入应远高于一个健康系统。它还带来同样的治理教训：在优先级排序会议*之前*就公布权重，否则每个团队都会声称自己"很严重"。

## 常见陷阱

- **对照错误的基线计算短缺**：短缺应基于*当前标准治疗*下测算，而非未经治疗的自然病程。
- **年龄敏感性**：短缺高度依赖人群年龄（年轻患者可损失的 QALY 更多 → 绝对短缺更高）；应使用实际接受治疗人群的年龄分布。
- **假设该修正系数适用于其他场合**——这是 NICE（英格兰）特有的机制；其他 HTA 机构对严重程度的处理方式不同（甚至完全不处理）。
