# Corsia Preferenziale DiGA della Germania

Il DiGA è il percorso statutario tedesco "app su prescrizione" — il primo sistema nazionale al mondo in cui i medici prescrivono app sanitarie approvate.

## Perché è importante

Il DiGA ha risposto alla domanda che ogni azienda di sanità digitale si pone — "chi pagherà effettivamente?"

## La matematica

```
Ricavi = prescrizioni × tasso di attivazione × prezzo per periodo di prescrizione
```

## Esempio risolto

Un'app per la gestione della depressione è elencata provvisoriamente a €450/trimestre: ≈€7,3 milioni di ricavi nell'anno 1.

## Collegamento con l'ingegneria del software

Il modello DiGA è direttamente copiabile per la governance degli strumenti ingegneristici.
