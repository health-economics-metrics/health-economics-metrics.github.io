# Pysyvyys ja poistuma

Pysyvyys ja poistuma mittaavat, jatkavatko käyttäjät terveyssovelluksen käyttöä ajan mittaan vai lopettavatko.

## Miksi se on tärkeä

Terveyssovellusten poistumaosuudet ovat yleensä paljon korkeammat kuin tavallisten kuluttajasovellusten.

## Matematiikka

```
Kuukausittainen poistumaosuus = kyseisenä kuukautena menetettyjen käyttäjien määrä / käyttäjien kokonaismäärä kuukauden alussa × 100 %
```

## Ratkaistu esimerkki

Mielenterveyssovellus: alussa 5 000, menetetty 750 = kuukausittainen poistumaosuus 15 %.
