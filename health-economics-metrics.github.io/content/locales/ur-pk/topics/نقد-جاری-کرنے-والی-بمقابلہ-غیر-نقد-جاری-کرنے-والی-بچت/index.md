# نقد جاری کرنے والی بمقابلہ غیر نقد جاری کرنے والی بچت

نقد جاری کرنے والی بچت اصل اخراجات کو کم کرتی ہے۔ غیر نقد جاری کرنے والی بچت وقت یا صلاحیت آزاد کرتی ہے، لیکن اسے جمع نہیں کیا جاتا — اسے *دوبارہ استعمال* کیا جاتا ہے۔

## یہ کیوں اہم ہے

یہ قومی صحت کی خدمت کے کسی بھی ڈیجیٹل کاروباری کیس پر لاگو ہونے والا سخت ترین ایمانداری کا امتحان ہے۔

## ریاضی

```
نقد جاری کرنے والی بچت = بجٹ لائن(پہلے) − بجٹ لائن(بعد)
غیر نقد جاری کرنے والی قدر = آزاد شدہ وقت × اس وقت کی اکائی قیمت
```

## حل شدہ مثال

فرض کریں ایک سافٹ ویئر 100 نرسوں کے لیے فی شفٹ 30 منٹ بچاتا ہے۔ ایماندار تقسیم: £80,500 نقد جاری کرنے والی بچت، £172,500 غیر نقد جاری کرنے والی صلاحیت۔
