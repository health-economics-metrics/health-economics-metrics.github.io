# علاج کے لیے حوالگی (RTT)

علاج کے لیے حوالگی ایک GP حوالگی سے مشیر-قیادت والے علاج کے آغاز تک گزرا ہوا وقت ہے۔ NHS آئین معیار طے کرتا ہے: **92% مریضوں کو 18 ہفتوں کے اندر علاج شروع کرنا چاہیے**۔

## یہ کیوں اہم ہے

RTT ہدف چوکنے والے ٹرسٹ ریگولیٹری جانچ کا سامنا کرتے ہیں۔

## ریاضی

```
RTT کارکردگی = 18 ہفتوں کے اندر علاج شدہ مریض / کل علاج × 100
```

## حل شدہ مثال

ایک خاصیت سالانہ 5,000 راستے کے مریضوں کا علاج کرتی ہے۔

## سافٹ ویئر انجینئرنگ سے تعلق

RTT ایک **کثیر مرحلہ قطار میں لیڈ-ٹائم میٹرک** ہے۔

## عام غلطیاں

- **غیر-رکاوٹ مرحلے میں بہتری۔**
