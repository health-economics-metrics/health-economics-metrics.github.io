# 支付意願閾值

支付意願（WTP）閾值，是決策者願意為每單位健康獲益支付的最高金額——正是這條線，將一項[ICER](../增量成本效果比/)轉化為一個採納或拒絕的決策。

## 為何重要

閾值，正是健康經濟學從"測量"跨越到"政策"的地方。每一個國家體系都有一個這樣的閾值，無論是明示還是默示的，瞭解當地的具體數位，就能準確知道該如何為一項健康價值主張定價：

| 機構 | 閾值（截至2024–2025年的研究資料） |
|---|---|
| NICE（英格蘭） | 每QALY £20,000–£30,000；實證平均決策閾值約為£24,400（2022–24年）；嚴重程度調整因子可將有效上限提高至約£36,000–£51,000；高度專科化技術可達£100,000以上 |
| ICER（美國，非政府組織） | 每QALY/evLYG價格基準為$100,000–$150,000；報告範圍為$50,000–$200,000 |
| 加拿大（CADTH/CDA-AMC） | 工作閾值約為每QALY CAD$50,000 |
| WHO-CHOICE（歷史性，全球） | 每避免一個DALY，人均GDP的1–3倍（目前已不再鼓勵使用，因過於粗略） |
| 英國供給側實證資料（Claxton等） | NHS邊際上實際被擠出的健康，約為每QALY £13,000 |

## 計算方法

閾值λ貫穿於每一條決策規則之中：

```
若ICER = ΔC/ΔE < λ，則採納
等價地：若NMB = λ×ΔE − ΔC > 0，則採納
```

關於λ究竟*是什麼*，存在兩種理論：

- **需求側**：社會願意為健康支付多少（一種價值判斷）。
- **供給側**：當前預算在邊際上實際能產生多少健康（一個實證數量——Claxton的研究約為每QALY £13,000）。如果用於決策的λ超過了供給側速率，那麼批准一項新技術，實際擠出的健康量會超過它所增加的健康量。

## 實例演算

你的數位療法為每名接受治療的病患帶來0.05 QALY，淨成本（價格減去衝抵）為£800。

```
ICER = 800 / 0.05 = 每QALY £16,000
```

- 英格蘭：低於£20,000 → 可獲資助。可論證的最高價格：在λ = £20,000時，最高價格 = 0.05 × 20,000 + 衝抵額 = £1,000 + 衝抵額。
- 美國商業框架下按每QALY $150,000計算：基於價值的定價要高得多。
- 一個人均GDP閾值為$4,000的國家：同一款產品的淨成本必須低於約$200。

同一款產品，三個市場，三個價格——閾值本身*就是*定價模型。這正是從λ反推而來的基於價值的定價方法。

## 與軟體工程的聯絡

每一個工程組織都有一個隱含的λ：即它為每節省一個工程師-小時願意資助工具投入的門檻。將其明確化——"我們資助任何每可信節省一個工程師-小時成本低於£40的專案"——能使平臺投資像每QALY成本排行榜為衛生支出排序那樣，進行排行榜式的比較。供給側的教訓同樣可以遷移：你真正的內部λ，應是你*當前*積壓任務在邊際上實際產出的價值，而非管理層聲稱時間值多少錢。

## 陷阱

- **跨司法轄區的閾值購物**，或將高度專科技術（HST）的上限用於普通產品。
- **把λ當作價格下限**：跨過閾值是必要條件，而非充分條件——[預算影響](../預算影響分析/)依然可能使一個單價可負擔的產品被否決。
- **忽視閾值會隨時間變化**：NICE的嚴重程度調整因子（2022年）以及定期審查，都會改變有效的λ；應為你的主張標註日期。
- **把另一種貨幣的 ICER 與閾值比較卻不先換算**：見[跨幣種 ICER 比較](../跨幣種-icer-比較/)——換算方法（購買力平價與市場匯率）在方法學上具有決定性，不是舍入細節。
- **把基於 λ 的估值與勞動力市場的 VSL/VPF 傳統混用**：它們來自不同的理論傳統（受衛生預算約束的方法論與從工資—風險權衡中揭示的偏好），並不總是相容——關於為生命估值的替代性揭示偏好方法，見[統計生命價值](../統計生命價值/)。
