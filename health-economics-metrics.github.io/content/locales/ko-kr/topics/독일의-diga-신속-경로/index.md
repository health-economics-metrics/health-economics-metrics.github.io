# 독일의 DiGA 신속 경로

DiGA는 독일의 법정 "처방전상의 앱" 경로입니다 — 의사가 승인된 건강 앱을 처방하는 세계 최초의 국가 시스템입니다.

## 왜 중요한가

DiGA는 모든 디지털 헬스 회사가 묻는 질문에 답했습니다 — "실제로 누가 지불할 것인가?"

## 수식

```
수익 = 처방 × 활성화율 × 처방 기간당 가격
```

## 계산 예시

우울증 관리 앱이 분기당 €450에 잠정 등재됩니다: 1년차 ≈€730만 수익.

## 소프트웨어 공학과의 연관성

DiGA 모델은 공학 도구 거버넌스에 직접 복사할 수 있습니다.
