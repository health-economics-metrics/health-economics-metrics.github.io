# SPACE og DevEx

SPACE og DevEx er rammeverk for å måle utviklerproduktivitet **flerdimensjonalt**.

## Hvorfor det er viktig

Begge rammeverkene inneholder den samme lærdommen som helseutfallsforskningen lærte for tiår siden.

## Matematikken

```
SPACE-regel: ≥ 3 dimensjoner, ≥ 1 perseptuell + ≥ 1 systemmål
```

## Gjennomarbeidet eksempel

Et plattformteam begrunner en DevEx-investering for 300 utviklere.

## Kobling til programvareutvikling

Dette dokumentet er *nøyaktig* programvaresiden; overføringen flyter mot helseøkonomi.

## Fallgruver

- **Reduksjon til ett enkelt mål.**
