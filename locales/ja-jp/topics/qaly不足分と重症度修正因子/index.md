# QALY不足分と重症度修正因子

QALY不足分は、ある疾患が一般人口と比較して患者から将来の健康をどれだけ奪うかを測定します。NICEはこれを使って**重症度修正因子**を適用します:集団の病状が重いほど、獲得された各QALYの価値は高くなります — 標準の閾値の最大1.7倍まで。

## なぜ重要か

NICEの2022年マニュアル以降、重症度は健康の獲得の価値に対する明示的な乗数となり、旧来の終末期プレミアムに取って代わりました。重症な状態に対する技術は、£30,000ではなく最大約£51,000/QALYまでの実効閾値に対して判断されます。あなたのソフトウェアが重症な影響を受けた集団(進行性心不全、重度の精神疾患)にサービスを提供するなら、重症度修正因子は資金提供可能な経済的ケースと不可能なケースの分かれ目になり得ます — そしてそれを主張するには不足分の計算が必要です。

## 数式

現在の標準治療のもとでの残りの生涯にわたって計算される2つの測定値:

```
絶対不足分   = QALY_一般人口 − QALY_疾患あり
比例不足分   = 絶対不足分 / QALY_一般人口
```

NICE 2022年の重み(どちらの測定値でも、より高い重みが適用される):

```
重み×1.0:絶対 < 12 かつ 比例 < 0.85
重み×1.2:絶対 ≥ 12 または 比例 ≥ 0.85
重み×1.7:絶対 ≥ 18 または 比例 ≥ 0.95
```

この重みはΔE(あるいは同等に閾値)に掛けられます:実効λは×1.2で£24k〜£36k、×1.7で£34k〜£51kになります。

## 計算例

進行性の疾患を持つ患者、平均年齢60歳。60歳の一般人口は割引後14.2QALYを期待できます;現在のケアのもとでその疾患を持つ場合は2.1です。

```
絶対不足分   = 14.2 − 2.1 = 12.1(≥ 12 → ×1.2の対象)
比例不足分   = 12.1 / 14.2 = 0.852(≥ 0.85 → こちらも×1.2)
```

あなたのモニタリングプラットフォームのICERは£26,000/QALYです — 標準の£20k〜£30kの中間的な判断を上回り、境界線上です。×1.2の重みを適用すると:実効ICER = 26,000 / 1.2 ≈ **£21,700/QALY** — 余裕を持って資金提供可能です。不足分の計算が、まさに意思決定を動かしました。

## ソフトウェア工学との関連

重症度による重み付けは、エンジニアリング組織が本能的に行っていることの正式な版です:最も状態の悪いシステムに、改善単位あたりでより多く支出すること。転用できるパターンは、各サービスの「SLO不足分」(期待される健全なベースラインからどれだけ絶対的・比例的に下回って稼働しているか)を計算し、それに応じて修復の価値を重み付けすることです。これは、議論ではなく計算によって、なぜ燃え盛るレガシーシステムが健全なシステムよりも、節約時間1時間あたりでより多くの投資を得るのかを正当化します。これはまた、同じガバナンス上の教訓も伴います:優先順位付け会議の*前に*重みを公表してください、さもなければすべてのチームが重症度を主張します。

## 落とし穴

- **誤ったベースラインに対して不足分を計算すること**:これは*現在の標準治療*のもとで測定されるのであり、未治療の自然経過ではありません。
- **年齢への感度**:不足分は集団の年齢に大きく依存します(若い患者ほど失うQALYが多い → 絶対不足分が高くなる);実際に治療を受けた集団の年齢分布を使ってください。
- **修正因子が他でも適用されると仮定すること** — これはNICE(イングランド)の仕組みです;他のHTA機関は重症度を異なる方法で扱う(あるいはまったく扱わない)ことがあります。
