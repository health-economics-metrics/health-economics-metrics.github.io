# WSJF och CD3

CD3 och WSJF är regler för att prioritera arbete baserat på **värdedensitet**.

## Varför det är viktigt

Varje backlogg är ett ransoneringsproblem.

## Matematiken

```
CD3 = kostnad för fördröjning (£/vecka) / varaktighet (veckor)
```

## Genomarbetat exempel

Tre funktioner, ett team: CD3-ordning: B, C, A.

## Koppling till mjukvaruutveckling

För mjukvaruportföljer inom hälso- och sjukvård, uttryck CoD i QALY/vecka.

## Fallgropar

- **WSJF-poängteater.**

## Källor

- Black Swan Farming, CD3 and WSJF.
- SAFe, WSJF.
