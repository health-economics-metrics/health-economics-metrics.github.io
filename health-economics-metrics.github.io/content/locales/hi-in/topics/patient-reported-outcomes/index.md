# रोगी-रिपोर्टेड परिणाम (PROM, PREM, MCID)

PROM मानकीकृत उपकरण हैं जहाँ रोगी अपनी स्वयं की स्वास्थ्य स्थिति रिपोर्ट करते हैं। **MCID** सबसे छोटा स्कोर परिवर्तन है जिसे रोगी वास्तव में लाभकारी मानते हैं।

## यह क्यों महत्वपूर्ण है

PROM डिजिटल स्वास्थ्य के लिए प्राथमिक प्रभावकारिता मुद्रा है।

## गणित

```
प्रतिक्रिया दर ढाँचा:
  प्रतिक्रियाकर्ता = रोगी जिसमें सुधार ≥ MCID
  NNT = 1 / (प्रतिक्रिया_दर_उपचार − प्रतिक्रिया_दर_नियंत्रण)
```

## हल किया गया उदाहरण

एक अवसाद-सहायता ऐप, RCT बनाम प्रतीक्षा सूची, 12 सप्ताह:

```
PHQ-9 परिवर्तन: ऐप −6.2, नियंत्रण −2.1 → समायोजित अंतर −4.1
NNT = 1/0.26 ≈ 4
```

## सॉफ़्टवेयर इंजीनियरिंग से संबंध

PROM एक डेटा-संग्रह समस्या है जिसे सॉफ़्टवेयर विशिष्ट रूप से हल कर सकता है।
